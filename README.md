# Python курсы — «Python класс Программирования» үйірмесі

[Русская версия](README_ru.md)

Сабақ материалдары үйірменің 2026–2027 оқу жылына арналған бағдарламасының күнтізбелік-тақырыптық жоспары бойынша дайындалған.

Әр сабақтың өз папкасы бар, онда екі файл:

- `teoriya.md` — теориялық материал (мақсат, сабақ барысы, түсіндірме, мысалдар, жиі қателер, бекіту сұрақтары);
- `praktika.md` — практикалық тапсырмалар (базалық, кеңейтілген, ★ олимпиадалық деңгей, үй тапсырмасы, педагогке арналған шешімдер).
