**6-тапсырма.**
```python
import datetime
import json
from pathlib import Path

CAPSULE = Path("time_capsule.json")


def bury(letter, open_date):
    CAPSULE.write_text(json.dumps({"letter": letter, "open": open_date.isoformat()},
                                  ensure_ascii=False), encoding="utf-8")


def dig(today=None):
    today = today or datetime.date.today()
    data = json.loads(CAPSULE.read_text(encoding="utf-8"))
    open_date = datetime.date.fromisoformat(data["open"])
    if today < open_date:
        return f"Хат {(open_date - today).days} күннен кейін ашылады"
    return data["letter"]


bury("Сәлем, болашақтағы мен! Flask-ты үйрендің бе?", datetime.date(2028, 5, 25))
print(dig(datetime.date(2027, 5, 26)))
print(dig(datetime.date(2028, 5, 25)))
CAPSULE.unlink()
```

```text
Хат 365 күннен кейін ашылады
Сәлем, болашақтағы мен! Flask-ты үйрендің бе?
```

**7-тапсырма.**
```python
import math
from collections import Counter

EXAMPLES = [
    ((2, 10), "жоғары"), ((1, 12), "жоғары"), ((3, 9), "жоғары"),
    ((8, 4), "орташа"), ((6, 5), "орташа"), ((7, 6), "орташа"),
    ((14, 1), "төмен"), ((12, 2), "төмен"), ((15, 2), "төмен"),
]
TESTS = [((2, 9), "жоғары"), ((7, 5), "орташа"), ((10, 3), "төмен")]


def predict(point, k=3):
    nearest = sorted(EXAMPLES, key=lambda ex: math.dist(point, ex[0]))[:k]
    return Counter(label for _, label in nearest).most_common(1)[0][0]


for k in (1, 3, 5):
    correct = sum(predict(p, k) == answer for p, answer in TESTS)
    print(f"k={k}: дәлдік {correct}/{len(TESTS)} = {correct * 100 // len(TESTS)}%")
```
Нәтижесі:
```text
k=1: дәлдік 2/3 = 66%
k=3: дәлдік 2/3 = 66%
k=5: дәлдік 2/3 = 66%
```
Талқылау: `(10, 3)` нүктесі «орташа» мен «төмен» топтарының шекарасында тұр — модель оны «орташа» деп табады. Бұл «шекаралық мәндер» (99-сабақ) ЖИ-де де ең қиын жағдай екенін көрсетеді; көбірек мысал қажет.

**8-тапсырма.**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.route("/api/add")
def add():
    try:
        a = float(request.args["a"])
        b = float(request.args["b"])
    except (KeyError, ValueError):
        return jsonify({"error": "a және b сан болуы керек"}), 400
    return jsonify({"result": a + b})


if __name__ == "__main__":
    app.run(port=5000)
```
