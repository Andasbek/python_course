### 2.1. Веб-разработка: Flask

**Flask** — лёгкий фреймворк для создания веб-сайтов и веб-приложений на Python. С `requests` программа **получает** данные с сайтов (является клиентом); с Flask она сама становится **сервером**: браузер отправляет нам запрос, мы возвращаем ответ (HTML или JSON).

```python
"""app.py — минимальное приложение на Flask."""
from flask import Flask, jsonify

app = Flask(__name__)

OPERATIONS = [
    {"category": "Еда", "amount": 800},
    {"category": "Транспорт", "amount": 200},
]


@app.route("/")
def index():
    """Главная страница: показывает HTML в браузере."""
    total = sum(op["amount"] for op in OPERATIONS)
    return f"<h1>Карманные деньги</h1><p>Всего расходов: {total} тг</p>"


@app.route("/api/operations")
def api_operations():
    """Наш собственный API: возвращает JSON (как внешние API, с которыми работает requests)."""
    return jsonify(OPERATIONS)


if __name__ == "__main__":
    app.run(debug=True)       # в браузере: http://127.0.0.1:5000
```

Знакомые вещи: `@app.route` — декоратор (как `@property`); `jsonify` — превращает словарь/список в JSON-ответ; `/api/operations` — созданный нами API, его может вызвать другая программа через `requests.get()`. Логика проекта (`logic.py`) и слой данных (`database.py`) переходят в веб-версию **без изменений** — вот польза от разделения на слои. Flask — сторонний пакет: `pip install flask`.

### 2.2. Сетевые приложения: клиент и сервер

В сетевой программе две стороны: **сервер** ждёт, **клиент** подключается. Они обмениваются байтами через **сокет** (socket) — уровень ниже HTTP.

```python
"""В одной программе: сервер (в отдельном потоке) и клиент."""
import socket
import threading

HOST, PORT = "127.0.0.1", 50007
ready = threading.Event()


def server():
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as srv:
        srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        srv.bind((HOST, PORT))
        srv.listen(1)
        ready.set()                                   # сигнал «я готов»
        conn, _ = srv.accept()                        # ожидание клиента
        with conn:
            text = conn.recv(1024).decode("utf-8")
            conn.sendall(f"Сервер получил: {text.upper()}".encode("utf-8"))


thread = threading.Thread(target=server, daemon=True)
thread.start()
ready.wait()

with socket.create_connection((HOST, PORT)) as client:
    client.sendall("привет, сервер!".encode("utf-8"))
    print(client.recv(1024).decode("utf-8"))
thread.join()
```

Результат:
```text
Сервер получил: ПРИВЕТ, СЕРВЕР!
```

На основе этой идеи строятся чаты, сетевые игры (два игрока на разных компьютерах), информационные табло. Сервер запущен в отдельном потоке (`threading`), а `threading.Event` сообщает клиенту, что сервер уже слушает порт.

### 2.3. Основы искусственного интеллекта: обучение на данных

В обычной программе **мы пишем правило**: `if temp > 25: "жарко"`. В машинном обучении (machine learning) программа **сама находит правило по примерам**. Один из простейших методов — **k ближайших соседей** (k-NN): новый объект относят к классу самых похожих на него примеров.

```python
import math
from collections import Counter

# Примеры (обучающие данные): (часов игр в неделю, часов учёбы в неделю) -> успеваемость
EXAMPLES = [
    ((2, 10), "высокая"), ((1, 12), "высокая"), ((3, 9), "высокая"),
    ((8, 4), "средняя"), ((6, 5), "средняя"), ((7, 6), "средняя"),
    ((14, 1), "низкая"), ((12, 2), "низкая"), ((15, 2), "низкая"),
]


def predict(point, k=3):
    """Возвращает класс большинства из k ближайших примеров."""
    nearest = sorted(EXAMPLES, key=lambda ex: math.dist(point, ex[0]))[:k]
    votes = Counter(label for _, label in nearest)
    return votes.most_common(1)[0][0]


for student in [(2, 11), (9, 4), (13, 3)]:
    print(student, "->", predict(student))
```

Результат:
```text
(2, 11) -> высокая
(9, 4) -> средняя
(13, 3) -> низкая
```

Мы не писали правило «если много игр — успеваемость низкая» — программа сама «заметила» его в примерах. Эта идея развивается в библиотеке `scikit-learn` (`KNeighborsClassifier` и десятки других моделей) на настоящих наборах данных, подготовленных в Pandas. Важна и этика ИИ: модель может «выучить» искажения (предвзятость) в данных — например, вывод этого маленького примера нельзя использовать для принятия решений о реальных людях.

## Частые ошибки

**1. Запуск Flask с `debug=True` на общедоступном сервере.** Режим отладки позволяет выполнить произвольный код через страницу ошибки. Правильно: `debug=True` — только на своём компьютере.

**2. Подстановка пользовательских данных в HTML через f-строку.** `f"<p>{name}</p>"` при вводе `<script>...</script>` выполнит чужой код в браузере (XSS). Правильно: шаблоны Jinja2 (`render_template`) автоматически экранируют значения, вручную — `markupsafe.escape()`.

**3. `recv(1024)` как «прочитать всё сообщение».** TCP — поток байтов: длинное сообщение может прийти частями, а несколько коротких — склеиться. Правильно: договориться о формате (например, длина + данные или разделитель `\n`) и читать в цикле.

**4. Повторный запуск сервера: `OSError: Address already in use`.** Порт ещё занят предыдущим процессом. Правильно: `SO_REUSEADDR` (как в примере) или другой порт.

**5. Оценивать модель на тех же примерах, на которых она обучена.** k-NN всегда «угадывает» обучающие точки. Правильно: отложить часть данных для проверки (тестовая выборка).

## Основные понятия
| Понятие | Пояснение |
|---|---|
| Веб-фреймворк (Flask) | набор инструментов, упрощающий создание веб-приложений |
| Маршрут (route) | связь между URL-адресом и функцией, которая его обрабатывает |
| Сервер / клиент | программы, которые предоставляют услугу и отправляют ей запросы |
| Сокет | конечная точка обмена данными по сети |
| Машинное обучение | самостоятельное нахождение программой правила по примерам |
| k ближайших соседей (k-NN) | метод классификации нового объекта по самым похожим примерам |
| Обучающая / тестовая выборка | данные, на которых модель обучается, и отдельные данные для проверки её качества |

## Примечание

- Встроенный сервер Flask (`app.run()`) предназначен только для разработки; для публикации используют WSGI-серверы (gunicorn, waitress) или хостинги вроде PythonAnywhere.
- В Flask 2.2+ функция-обработчик может вернуть словарь или список — Flask сам превратит его в JSON, `jsonify` при этом не обязателен.
- `socket.create_connection()` удобнее ручного `socket.socket()` + `connect()`: он сам перебирает адреса и поддерживает `timeout`.
- `math.dist()` (евклидово расстояние) появилась в Python 3.8; для k-NN признаки с разными масштабами (часы и, например, тенге) нужно предварительно нормировать.
- Документация: https://flask.palletsprojects.com, https://docs.python.org/3/library/socket.html, https://scikit-learn.org/stable/modules/neighbors.html
