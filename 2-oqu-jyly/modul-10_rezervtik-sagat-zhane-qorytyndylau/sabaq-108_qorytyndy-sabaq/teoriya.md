Python негіздерінен (айнымалы, цикл, функция, тізім) бастап меңгерілген материал шағын қосымшаның толық стегіне дейін өсті:

## 2. Келесі бағыттар: веб, желі, жасанды интеллект

Меңгерілген технологиялар үш бағытта табиғи түрде жалғасады: бағдарламалар тек бір компьютерде емес, браузерде, желіде жұмыс істейді және «ақылды» бола бастайды.

```text
     Меңгерілген технологиялар               Келесі қадам
  ОБП ─────────────────────┐
  SQLite, JSON ────────────┼──>  Веб-әзірлеу (Flask): сайттар, веб-қосымшалар, REST API
  HTTP, requests, API, HTML┘
  HTTP, JSON, ағындар ─────────>  Желілік қосымшалар: клиент–сервер, сокеттер, чат
  Pandas, NumPy, Matplotlib ───>  Жасанды интеллект негіздері: деректерден үйрену, модельдер
```

### 2.1. Веб-әзірлеу: Flask

**Flask** — Python-да веб-сайт пен веб-қосымша жасауға арналған жеңіл фреймворк. `requests` арқылы бағдарлама сайттардан деректер **алады** (клиент болады); Flask-пен ол өзі **сервер** болады: браузер бізге сұраныс жібереді, біз жауап (HTML немесе JSON) қайтарамыз.

```python
"""app.py — ең қарапайым Flask қосымшасы."""
from flask import Flask, jsonify

app = Flask(__name__)

OPERATIONS = [
    {"category": "Тамақ", "amount": 800},
    {"category": "Көлік", "amount": 200},
]


@app.route("/")
def index():
    """Басты бет: браузерде HTML көрсетеді."""
    total = sum(op["amount"] for op in OPERATIONS)
    return f"<h1>Қалта ақшасы</h1><p>Барлық шығыс: {total} тг</p>"


@app.route("/api/operations")
def api_operations():
    """Өз API-мыз: JSON қайтарады (requests жұмыс істейтін сыртқы API-лар сияқты)."""
    return jsonify(OPERATIONS)


if __name__ == "__main__":
    app.run(debug=True)       # браузерде: http://127.0.0.1:5000
```

Таныс нәрселер: `@app.route` — декоратор (`@property` сияқты); `jsonify` — сөздік/тізімді JSON жауапқа айналдырады; `/api/operations` — біз жасаған API, оны `requests.get()` арқылы басқа бағдарлама шақыра алады. Жобаның логикасы (`logic.py`) мен деректер қабаты (`database.py`) **өзгеріссіз** веб-нұсқаға көшеді — қабаттарды бөлудің пайдасы осы. Flask — бөгде пакет: `pip install flask`.

### 2.2. Желілік қосымшалар: клиент және сервер

Желілік бағдарламада екі тарап бар: **сервер** күтеді, **клиент** қосылады. Олар **сокет** (socket) арқылы байттармен алмасады — HTTP-тің астындағы деңгей.

```python
"""Бір бағдарламада: сервер (бөлек ағында) және клиент."""
import socket
import threading

HOST, PORT = "127.0.0.1", 50007
ready = threading.Event()


def server():
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as srv:
        srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        srv.bind((HOST, PORT))
        srv.listen(1)
        ready.set()                                   # «дайынмын» белгісі
        conn, _ = srv.accept()                        # клиентті күту
        with conn:
            text = conn.recv(1024).decode("utf-8")
            conn.sendall(f"Сервер алды: {text.upper()}".encode("utf-8"))


thread = threading.Thread(target=server, daemon=True)
thread.start()
ready.wait()

with socket.create_connection((HOST, PORT)) as client:
    client.sendall("сәлем, сервер!".encode("utf-8"))
    print(client.recv(1024).decode("utf-8"))
thread.join()
```

Нәтижесі:
```text
Сервер алды: СӘЛЕМ, СЕРВЕР!
```

Осы идеяның негізінде чаттар, желілік ойындар (екі ойыншы әртүрлі компьютерде), ақпарат таблолары құрылады. Сервер бөлек ағында (`threading`) іске қосылған, ал `threading.Event` клиентке сервердің портты тыңдап тұрғанын хабарлайды.

### 2.3. Жасанды интеллект негіздері: деректерден үйрену

Әдеттегі бағдарламада **біз ереже жазамыз**: `if temp > 25: "ыстық"`. Машиналық оқытуда (machine learning) бағдарлама ережені **мысалдардан өзі табады**. Ең қарапайым әдістердің бірі — **k жақын көрші** (k-NN): жаңа нысан өзіне ең ұқсас мысалдардың класына жатқызылады.

```python
import math
from collections import Counter

# Мысалдар (үйрету деректері): (апталық ойын сағаты, апталық оқу сағаты) -> үлгерімі
EXAMPLES = [
    ((2, 10), "жоғары"), ((1, 12), "жоғары"), ((3, 9), "жоғары"),
    ((8, 4), "орташа"), ((6, 5), "орташа"), ((7, 6), "орташа"),
    ((14, 1), "төмен"), ((12, 2), "төмен"), ((15, 2), "төмен"),
]


def predict(point, k=3):
    """k ең жақын мысалдың көпшілігінің класын қайтарады."""
    nearest = sorted(EXAMPLES, key=lambda ex: math.dist(point, ex[0]))[:k]
    votes = Counter(label for _, label in nearest)
    return votes.most_common(1)[0][0]


for student in [(2, 11), (9, 4), (13, 3)]:
    print(student, "->", predict(student))
```

Нәтижесі:
```text
(2, 11) -> жоғары
(9, 4) -> орташа
(13, 3) -> төмен
```

Біз «ойын көп болса — үлгерім төмен» деген ережені жазған жоқпыз — бағдарлама оны мысалдардан «байқады». Бұл идея `scikit-learn` кітапханасында (`KNeighborsClassifier` және ондаған басқа модель) Pandas-та дайындалған нағыз деректер жиындарында дамиды. ЖИ этикасы да маңызды: модель деректердегі бұрмалауды (біржақтылықты) да «үйреніп» алуы мүмкін — мысалы, бұл кішкене мысалдың қорытындысын нақты адамдар туралы шешім қабылдауға қолдануға болмайды.

## Жиі кездесетін қателер

**1. Flask-ты жалпыға қолжетімді серверде `debug=True` режимімен іске қосу.** Жөндеу режимі қате беті арқылы кез келген кодты орындауға мүмкіндік береді. Дұрысы: `debug=True` — тек өз компьютеріңізде.

**2. Пайдаланушы деректерін HTML-ге f-жол арқылы қою.** `<script>...</script>` енгізілсе, `f"<p>{name}</p>"` браузерде бөгде кодты орындайды (XSS). Дұрысы: Jinja2 үлгілері (`render_template`) мәндерді автоматты түрде экрандайды, қолмен — `markupsafe.escape()`.

**3. `recv(1024)`-ті «бүкіл хабарламаны оқу» деп түсіну.** TCP — байттар ағыны: ұзын хабарлама бөліктермен келуі, ал бірнеше қысқасы жабысып қалуы мүмкін. Дұрысы: пішімге келісу (мысалы, ұзындық + деректер немесе `\n` бөлгіші) және циклмен оқу.

**4. Серверді қайта іске қосу: `OSError: Address already in use`.** Порт алдыңғы процесте әлі бос емес. Дұрысы: `SO_REUSEADDR` (мысалдағыдай) немесе басқа порт.

**5. Модельді өзі оқыған мысалдарда бағалау.** k-NN оқыту нүктелерін әрдайым «табады». Дұрысы: деректердің бір бөлігін тексеруге қалдыру (тестілік іріктеме).

## Негізгі ұғымдар
| Ұғым | Түсіндірме |
|---|---|
| Веб-фреймворк (Flask) | веб-қосымша жасауды жеңілдететін құралдар жиыны |
| Маршрут (route) | URL мекенжайы мен оны өңдейтін функцияның байланысы |
| Сервер / клиент | қызмет көрсететін және оған сұраныс жіберетін бағдарламалар |
| Сокет | желі арқылы деректер алмасудың соңғы нүктесі |
| Машиналық оқыту | бағдарламаның ережені мысалдардан өзі табуы |
| k жақын көрші (k-NN) | жаңа нысанды ең ұқсас мысалдар бойынша жіктеу әдісі |
| Оқыту / тестілік іріктеме | модель оқитын деректер және оның сапасын тексеруге арналған бөлек деректер |

## Ескерту

- Flask-тың кіріктірілген сервері (`app.run()`) тек әзірлеуге арналған; жариялау үшін WSGI-серверлер (gunicorn, waitress) немесе PythonAnywhere сияқты хостингтер қолданылады.
- Flask 2.2+ нұсқасында өңдеуші функция сөздік немесе тізім қайтара алады — Flask оны өзі JSON-ға айналдырады, бұл жағдайда `jsonify` міндетті емес.
- `socket.create_connection()` қолмен жазылған `socket.socket()` + `connect()`-тен ыңғайлы: ол мекенжайларды өзі іріктейді және `timeout`-ты қолдайды.
- `math.dist()` (евклидтік қашықтық) Python 3.8-де пайда болды; k-NN үшін масштабы әртүрлі белгілерді (сағат және, мысалы, теңге) алдын ала нормалау керек.
- Құжаттама: https://flask.palletsprojects.com, https://docs.python.org/3/library/socket.html, https://scikit-learn.org/stable/modules/neighbors.html
