**Задание 6.**
```python
import datetime
import json
from pathlib import Path

CAPSULE = Path("time_capsule.json")


def bury(letter, open_date):
    CAPSULE.write_text(json.dumps({"letter": letter, "open": open_date.isoformat()},
                                  ensure_ascii=False), encoding="utf-8")


def dig(today=None):
    today = today or datetime.date.today()
    data = json.loads(CAPSULE.read_text(encoding="utf-8"))
    open_date = datetime.date.fromisoformat(data["open"])
    if today < open_date:
        return f"Письмо откроется через {(open_date - today).days} дн."
    return data["letter"]


bury("Привет, будущий я! Ты выучил Flask?", datetime.date(2028, 5, 25))
print(dig(datetime.date(2027, 5, 26)))
print(dig(datetime.date(2028, 5, 25)))
CAPSULE.unlink()
```
Результат:
```text
Письмо откроется через 365 дн.
Привет, будущий я! Ты выучил Flask?
```

**Задание 7.**
```python
import math
from collections import Counter

EXAMPLES = [
    ((2, 10), "высокая"), ((1, 12), "высокая"), ((3, 9), "высокая"),
    ((8, 4), "средняя"), ((6, 5), "средняя"), ((7, 6), "средняя"),
    ((14, 1), "низкая"), ((12, 2), "низкая"), ((15, 2), "низкая"),
]
TESTS = [((2, 9), "высокая"), ((7, 5), "средняя"), ((10, 3), "низкая")]


def predict(point, k=3):
    nearest = sorted(EXAMPLES, key=lambda ex: math.dist(point, ex[0]))[:k]
    return Counter(label for _, label in nearest).most_common(1)[0][0]


for k in (1, 3, 5):
    correct = sum(predict(p, k) == answer for p, answer in TESTS)
    print(f"k={k}: точность {correct}/{len(TESTS)} = {correct * 100 // len(TESTS)}%")
```
Результат:
```text
k=1: точность 2/3 = 66%
k=3: точность 2/3 = 66%
k=5: точность 2/3 = 66%
```
Обсуждение: точка `(10, 3)` находится на границе групп «средняя» и «низкая» — модель относит её к «средней». Это показывает, что «граничные значения» (урок 99) и в ИИ — самый трудный случай; нужно больше примеров.

**Задание 8.**
```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.route("/api/add")
def add():
    try:
        a = float(request.args["a"])
        b = float(request.args["b"])
    except (KeyError, ValueError):
        return jsonify({"error": "a и b должны быть числами"}), 400
    return jsonify({"result": a + b})


if __name__ == "__main__":
    app.run(port=5000)
```
Клиент (в отдельном терминале, после запуска сервера):
```python
import requests

response = requests.get("http://127.0.0.1:5000/api/add", params={"a": 2, "b": 3}, timeout=5)
print(response.status_code, response.json())
```
Результат:
```text
200 {'result': 5.0}
```
