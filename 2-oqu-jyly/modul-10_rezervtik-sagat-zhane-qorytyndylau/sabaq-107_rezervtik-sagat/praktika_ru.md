**Задание 7.**
```python
import io

SECTIONS = [("Исправление:", "Исправлено"), ("Тест:", "Тесты")]
DEFAULT = "Добавлено / Изменено"


def build_changelog(log_lines, version, date):
    """Собирает раздел CHANGELOG из строк git log (%ad;%s)."""
    groups = {name: [] for _, name in SECTIONS}
    groups[DEFAULT] = []
    for line in log_lines:
        line = line.strip()
        if not line or ";" not in line:
            continue
        _, message = line.split(";", 1)
        for prefix, name in SECTIONS:
            if message.startswith(prefix):
                groups[name].append(message[len(prefix):].strip())
                break
        else:                                   # ни один префикс не подошёл
            groups[DEFAULT].append(message)
    out = [f"## [{version}] — {date}"]
    for name, items in groups.items():
        if items:
            out.append(f"### {name}")
            out.extend(f"- {item}" for item in items)
    return "\n".join(out)


# В настоящем проекте: git log v1.0..HEAD --pretty=format:"%ad;%s" --date=short > new.txt
LOG = io.StringIO("""2027-05-24;Исправление: ошибка диаграммы при пустой БД (#31)
2027-05-24;Тест: граничные значения для parse_amount
2027-05-24;README: исправлена команда установки
2027-05-24;Исправление: ширина таблицы при длинном комментарии (#21)
""")
print(build_changelog(LOG, "1.0.1", "2027-05-24"))
```

```text
### Исправлено
- ошибка диаграммы при пустой БД (#31)
- ширина таблицы при длинном комментарии (#21)
### Тесты
- граничные значения для parse_amount
### Добавлено / Изменено
- README: исправлена команда установки
```
Конструкция `for ... else`: блок `else` выполняется, только если цикл завершился без `break`, — редко используемая, но удобная именно для такого случая конструкция.
