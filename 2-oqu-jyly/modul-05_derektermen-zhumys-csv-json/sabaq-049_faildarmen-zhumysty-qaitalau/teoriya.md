## 1. Файл дегеніміз не?

**Файл** — дискіде атауымен сақталған байттар тізбегі. Компьютер үшін кез келген файл — тек сандар (0–255 аралығындағы байттар). Оларды қалай түсіндіру керектігін **формат** анықтайды.

**Аналогия:** жедел жад (RAM) — тақтадағы бор жазуы: компьютерді өшірсең, өшіріледі. Файл — дәптерге жазу: келесі күні де ашып оқисың.

| Түрі | Ішінде не бар | Мысалдар | Блокнотпен ашса |
|---|---|---|---|
| **Мәтіндік** | Таңбалар (әріптер, сандар, жол ауысу) белгілі бір кодтауда | `.txt`, `.py`, `.csv`, `.json`, `.html`, `.ini` | Оқылады |
| **Екілік (бинарлы)** | Еркін байттар, формат ережесі бойынша | `.png`, `.jpg`, `.mp3`, `.exe`, `.db`, `.zip` | «Бұдыр-бұдыр» символдар |

## 2. Файлды ашу: `open()` және режимдер

```python
f = open("notes.txt", "r", encoding="utf-8")
```

| Режим | Мағынасы | Файл жоқ болса | Файл бар болса |
|---|---|---|---|
| `"r"` | оқу (әдепкі) | `FileNotFoundError` | басынан оқиды |
| `"w"` | жазу | жаңасын құрады | **ішін толық өшіреді!** |
| `"a"` | соңына қосу (append) | жаңасын құрады | соңына жазады |
| `"x"` | тек жаңа файл құру | құрады | `FileExistsError` |
| `"b"` | екілік режим (`"rb"`, `"wb"`, `"ab"`) | — | — |
| `"+"` | оқу әрі жазу (`"r+"`, `"w+"`) | — | — |

### Кодтау (encoding)

Мәтіндік файлда әр таңба байттарға **кодталады**. Қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) үшін әрқашан **UTF-8** қолданамыз:

```python
with open("salem.txt", "w", encoding="utf-8") as f:
    f.write("Сәлем, Қазақстан!")
```

`encoding` көрсетілмесе, Windows-та жүйелік кодтау (мысалы, `cp1251`) қолданылуы мүмкін — сонда «ә», «ң» әріптері бұзылады немесе `UnicodeEncodeError` шығады.

## 3. `with` операторы — файлды өзі жабады

```python
# Ескі тәсіл
f = open("data.txt", "w", encoding="utf-8")
f.write("бірінші жол\n")
f.close()          # ұмытып кетсең — деректер жазылмай қалуы мүмкін

# Дұрыс тәсіл
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("бірінші жол\n")
# блоктан шыққанда файл автоматты жабылады (қате болса да)
```

`with` — **контекст менеджері**: «ашып, жұмыс істеп, міндетті түрде жап» дегенді қамтамасыз етеді.

## 4. Мәтіндік файлды жазу және оқу

### Жазу

```python
cities = ["Алматы", "Астана", "Шымкент", "Ақтөбе"]

with open("cities.txt", "w", encoding="utf-8") as f:
    f.write("Қазақстанның ірі қалалары\n")
    for city in cities:
        f.write(city + "\n")

with open("cities.txt", "a", encoding="utf-8") as f:
    f.writelines(["Қарағанды\n", "Тараз\n"])   # жолдар тізімін жазу

print("Файл жазылды")
```

Нәтижесі:

```text
Файл жазылды
```

`write()` жол ауысуды (`\n`) өзі қоспайды — оны өзің жазасың. `print(..., file=f)` та қолдануға болады: ол `\n`-ді өзі қосады.

### Оқудың төрт тәсілі

| Әдіс | Нәтижесі | Қашан қолдану керек |
|---|---|---|
| `f.read()` | бүкіл файл — бір жол (`str`) | шағын файл |
| `f.readline()` | келесі бір жол | тақырып жолын бөлек оқу |
| `f.readlines()` | барлық жолдардың тізімі | жолдарды индекспен алу керек болса |
| `for line in f:` | жолдарды бір-бірлеп | **үлкен файлдар** — жадты үнемдейді |

```python
with open("cities.txt", encoding="utf-8") as f:
    title = f.readline().strip()        # бірінші жол — тақырып
    cities = [line.strip() for line in f]  # қалғаны

print(title)
print(cities)
print("Қалалар саны:", len(cities))
```

Нәтижесі:

```text
Қазақстанның ірі қалалары
['Алматы', 'Астана', 'Шымкент', 'Ақтөбе', 'Қарағанды', 'Тараз']
Қалалар саны: 6
```

`strip()` — жол соңындағы `\n` мен бос орындарды алып тастайды.

### Сандарды сақтау

Мәтіндік файлда бәрі **мәтін**. Санды жазарда `str()`, оқығанда `int()` / `float()`:

```python
scores = [85, 92, 78, 100]
with open("scores.txt", "w", encoding="utf-8") as f:
    for s in scores:
        f.write(f"{s}\n")

with open("scores.txt", encoding="utf-8") as f:
    numbers = [int(line) for line in f if line.strip()]

print("Орташа балл:", sum(numbers) / len(numbers))
```

Нәтижесі:

```text
Орташа балл: 88.75
```

## 5. Файл жолдары: `os.path` және `pathlib`

Бағдарлама файлды **ағымдағы жұмыс папкасынан** іздейді. VS Code-та бағдарламаны басқа папкадан іске қоссаң, файл «табылмай» қалуы мүмкін. Шешім — жолды скрипт орналасқан папкаға қатысты құру.

```python
from pathlib import Path

BASE_DIR = Path(__file__).parent            # скрипт тұрған папка
data_dir = BASE_DIR / "data"                # / операторы жолдарды біріктіреді
data_dir.mkdir(exist_ok=True)               # папка жоқ болса — құрады

path = data_dir / "log.txt"
path.write_text("Бағдарлама іске қосылды\n", encoding="utf-8")

print(path.name)        # файл атауы
print(path.suffix)      # кеңейтімі
print(path.exists())    # бар ма?
print(path.read_text(encoding="utf-8").strip())
```

Нәтижесі:

```text
log.txt
.txt
True
Бағдарлама іске қосылды
```

| `os.path` (ескі) | `pathlib` (жаңа) |
|---|---|
| `os.path.join("data", "a.txt")` | `Path("data") / "a.txt"` |
| `os.path.exists(p)` | `p.exists()` |
| `os.path.basename(p)` | `p.name` |
| `os.path.getsize(p)` | `p.stat().st_size` |
| `os.listdir("data")` | `Path("data").iterdir()` |

## 7. Екілік файлдар және `bytes` типі

Екілік режимде (`"rb"`, `"wb"`) Python мәтінді кодтамайды, файлдағы байттарды **сол күйінде** береді. Нәтиже типі — `str` емес, **`bytes`**.

```python
text = "Сәлем"
data = text.encode("utf-8")       # str → bytes
print(data)
print(len(text), "таңба,", len(data), "байт")
print(list(data))                 # әр байт — 0..255 саны
print(data.decode("utf-8"))       # bytes → str
```

Нәтижесі:

```text
b'\xd0\xa1\xd3\x99\xd0\xbb\xd0\xb5\xd0\xbc'
5 таңба, 10 байт
[208, 161, 211, 153, 208, 187, 208, 181, 208, 188]
Сәлем
```

Кириллица әріптері UTF-8-де **2 байттан** алады, латын әріптері — 1 байт. Сондықтан «таңба саны» мен «файл өлшемі» әртүрлі.

| | `str` | `bytes` |
|---|---|---|
| Ішінде | Unicode таңбалар | 0–255 сандар |
| Жазылуы | `"мәтін"` | `b"text"` |
| Ашу режимі | `"r"`, `"w"` + `encoding` | `"rb"`, `"wb"` (encoding жоқ) |
| Түрлендіру | `.encode("utf-8")` → bytes | `.decode("utf-8")` → str |

### Екілік файлды жазу және оқу

```python
data = bytes([137, 80, 78, 71, 13, 10, 26, 10])  # 8 байт

with open("test.bin", "wb") as f:
    f.write(data)

with open("test.bin", "rb") as f:
    content = f.read()

print(content)
print(content[1:4])
print("Өлшемі:", len(content), "байт")
```

Нәтижесі:

```text
b'\x89PNG\r\n\x1a\n'
b'PNG'
Өлшемі: 8 байт
```

Бұл 8 байт — кез келген PNG суретінің **сигнатурасы** («сиқырлы сандар», magic numbers). Файлдың кеңейтімін өзгертуге болады, бірақ сигнатурасы шын форматын көрсетеді.

| Формат | Алғашқы байттары |
|---|---|
| PNG | `89 50 4E 47` (`\x89PNG`) |
| JPEG | `FF D8 FF` |
| GIF | `47 49 46 38` (`GIF8`) |
| ZIP, DOCX, XLSX | `50 4B 03 04` (`PK`) |
| PDF | `25 50 44 46` (`%PDF`) |
| SQLite | `SQLite format 3\x00` |

```python
def detect_format(path):
    """Файлдың алғашқы байттары бойынша форматын анықтайды."""
    signatures = {
        b"\x89PNG": "PNG сурет",
        b"\xff\xd8\xff": "JPEG сурет",
        b"GIF8": "GIF анимация",
        b"PK\x03\x04": "ZIP архив (немесе DOCX/XLSX)",
        b"%PDF": "PDF құжат",
    }
    with open(path, "rb") as f:
        head = f.read(8)
    for sign, name in signatures.items():
        if head.startswith(sign):
            return name
    return "белгісіз формат"


print(detect_format("test.bin"))
```

Нәтижесі:

```text
PNG сурет
```

### Үлкен екілік файлды бөліктермен көшіру

Видео бірнеше гигабайт болуы мүмкін — оны бір `read()`-пен жадқа жүктеу қауіпті. Бөліктермен (chunk) оқимыз:

```python
def copy_file(src, dst, chunk_size=64 * 1024):
    """Файлды 64 КБ бөліктермен көшіреді, көшірілген байт санын қайтарады."""
    total = 0
    with open(src, "rb") as fin, open(dst, "wb") as fout:
        while True:
            chunk = fin.read(chunk_size)
            if not chunk:          # бос bytes — файл бітті
                break
            fout.write(chunk)
            total += len(chunk)
    return total


print("Көшірілді:", copy_file("test.bin", "test_copy.bin"), "байт")
```

Нәтижесі:

```text
Көшірілді: 8 байт
```

## 8. Деректерді сақтау тәсілдерін жүйелеу

| Тәсіл | Түрі | Артықшылығы | Кемшілігі | Қашан |
|---|---|---|---|---|
| `.txt` | мәтін | қарапайым, адам оқиды | құрылымы жоқ | лог, жазбалар, бір сан |
| `.csv` | мәтін | кесте, Excel ашады | тек «жазық» кесте | бағалар журналы, тізімдер |
| `.json` | мәтін | тізім/сөздік кірістірілген құрылым | үлкен көлемде баяу | баптаулар, API жауаптары |
| `.ini` / `.toml` | мәтін | баптауларға ыңғайлы | тек параметрлер | бағдарлама баптаулары |
| `pickle` | екілік | кез келген Python объектісі | тек Python; **қауіпті** | уақытша кэш |
| SQLite `.db` | екілік | іздеу, сүзу, мыңдаған жазба | SQL үйрену керек | оқушылар базасы, дүкен |

Әр тәсіл үшін Python-да өз құралы бар: кірістірілген `open()`, стандартты кітапхананың `csv`, `json`, `configparser`, `tomllib` (Python 3.11+), `pickle` және `sqlite3` модульдері.

### `pickle` туралы ескерту

`pickle` Python объектілерін екілік түрде сақтайды:

```python
import pickle

player = {"name": "Айдана", "level": 3, "items": ["қылыш", "қалқан"]}
with open("save.pkl", "wb") as f:
    pickle.dump(player, f)

with open("save.pkl", "rb") as f:
    loaded = pickle.load(f)
print(loaded)
```

Нәтижесі:

```text
{'name': 'Айдана', 'level': 3, 'items': ['қылыш', 'қалқан']}
```

> **Қауіпсіздік:** бөтен адамнан алынған `.pkl` файлын **ешқашан** `pickle.load` арқылы ашпа — ішінде зиянды код болуы мүмкін. Деректерді алмасу үшін JSON қолданылады.

## Жиі кездесетін қателер

**1. `"w"` режимі деректерді өшіреді.**

```python
# Қате: әр іске қосқанда бұрынғы жазбалар жоғалады
with open("diary.txt", "w", encoding="utf-8") as f:
    f.write("Бүгінгі жазба\n")
```

Дұрыс: жазбаны қосу үшін `"a"` режимі.

**2. `encoding` ұмытылады** → Windows-та қазақ әріптері бұзылады. Дұрыс: мәтіндік файлда әрқашан `encoding="utf-8"`.

**3. Мәтіндік режимде `bytes` жазу немесе керісінше.**

```python
# Қате: TypeError: write() argument must be str, not bytes
# with open("a.txt", "w") as f:
#     f.write(b"abc")
with open("a.bin", "wb") as f:
    f.write(b"abc")            # дұрыс: екілік режим
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("abc")             # дұрыс: мәтін
```

**4. Екілік файлды мәтін ретінде оқу** → `UnicodeDecodeError`. Сурет, дыбыс — тек `"rb"`.

**5. `\n` қалып қояды.** `readlines()` нәтижесі `['Алматы\n', ...]`, сондықтан `"Алматы" == line` шарты `False` болады. Дұрыс: `line.strip()`.

**6. Санды жазу:** `f.write(100)` → `TypeError`. Дұрыс: `f.write(str(100))` немесе `f.write(f"{100}\n")`.

## Негізгі ұғымдар

| Ұғым | Түсіндірмесі |
|---|---|
| Файл | Дискіде атауымен сақталған байттар тізбегі |
| Мәтіндік файл | Таңбалары белгілі кодтауда (UTF-8) жазылған файл |
| Екілік файл | Еркін байттардан тұратын файл (сурет, дыбыс, db) |
| Кодтау (encoding) | Таңбаларды байттарға айналдыру ережесі |
| `bytes` | Байттар тізбегін сақтайтын өзгермейтін тип |
| Режим | Файлды ашу тәсілі: `r`, `w`, `a`, `x`, `b`, `+` |
| Контекст менеджері | `with` — ресурсты автоматты жабатын құрылым |
| Сигнатура | Файл форматын анықтайтын алғашқы байттар |
| Chunk | Үлкен файлды бөліп оқитын бөлік |
| `pathlib.Path` | Файл жолдарымен жұмыс істейтін заманауи класс |

## Ескерту

- Python 3.15-тен бастап (PEP 686) `open()` барлық ОЖ-да әдепкі бойынша UTF-8 кодтауын қолданады; оған дейін нәтиже жүйеге байланысты, сондықтан `encoding="utf-8"` анық көрсетіледі. Бұл әрекетті алдын ала `python -X utf8` жалаушасымен қосуға болады.
- `newline` жол ауысуын басқарады: мәтіндік режимде Python оқығанда `\r\n`-ды (Windows) `\n`-ға айналдырады, ал жазғанда — қайтадан жүйелік нұсқаға. Екілік режимде ешқандай түрлендіру жоқ.
- BOM-ы бар файл (көбіне Блокнот/Excel сақтайды) көрінбейтін `\ufeff` таңбасынан басталады; оны `encoding="utf-8-sig"` арқылы оқыңыз, сонда BOM автоматты түрде алынып тасталады.
- Жазу буферленеді: деректер дискіге файл жабылғанда немесе `f.flush()` кезінде түседі. Сондықтан `with`/`close()`-сыз соңғы жолдар жоғалуы мүмкін.
- `Path.read_text()`, `Path.write_text()`, `Path.read_bytes()`, `Path.write_bytes()` файлды өздері ашып-жабады — шағын файлдар үшін ыңғайлы.
- Құжаттама: https://docs.python.org/3/library/functions.html#open және https://docs.python.org/3/library/pathlib.html
