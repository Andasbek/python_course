# Сабақ 53. Практикалық тапсырмалар: реляциялық модель ұғымдары

Бүгінгі практика екі бөлімнен тұрады: **«қағаз» тапсырмалар** (кестелерді талдау) және **Python тапсырмалары** (кестені тізім-сөздік ретінде модельдеу).

## Базалық деңгей

### 1-тапсырма. Кестені «оқу»

`books` кестесі берілген:

| inv_no | title | author | year | pages | shelf |
|---|---|---|---|---|---|
| 1001 | Абай жолы | Мұхтар Әуезов | 1942 | 512 | A-3 |
| 1002 | Көшпенділер | Ілияс Есенберлин | 1976 | 640 | A-4 |
| 1003 | Абай жолы | Мұхтар Әуезов | 1942 | 512 | A-3 |
| 1004 | Менің атым Қожа | Бердібек Соқпақбаев | 1957 | 176 | B-1 |

Жауап бер:
1. Кесте атауы қандай? Неше өріс, неше жазба бар?
2. 3-жазбаның `shelf` өрісінің мәні қандай?
3. 1001 және 1003 жазбалары бірдей ме? Оларды не ажыратады?
4. Қай өріс бастапқы кілт бола алады? Неге `title` бола алмайды?
5. Әр өріске SQLite типін таңда (`INTEGER`, `REAL`, `TEXT`).

### 2-тапсырма. Кілтті таңда

Әр кесте үшін бастапқы кілтті ұсын және себебін жаз (табиғи ма, суррогат па?):

| Кесте | Өрістері |
|---|---|
| `citizens` (азаматтар) | iin, last_name, first_name, birth_date |
| `cars` (көліктер) | number_plate, brand, color, owner_iin |
| `players` (ойыншылар) | nickname, email, level, registered |
| `grades` (бағалар) | student_id, subject, date, mark |
| `cities` (қалалар) | name, region, population |

### 3-тапсырма. Қателерді тап

Төмендегі кестеде реляциялық модель ережелерінің **5 бұзылуын** тап және түзету жолын ұсын:

| id | name | phone | clubs | age | name |
|---|---|---|---|---|---|
| 1 | Айгерім | 87011234567 | Python, Шахмат | 15 | Нұрланқызы |
| 2 | Бауыржан | 8 702 555 44 33 | Робототехника | он төрт | Сейітов |
| 2 | Дәулет |  | Python | 15 | Оспанов |

### 4-тапсырма. Python: кестені модельдеу

Үш оқушыдан тұратын `students` кестесін сөздіктер тізімі ретінде жаз (өрістер: `id`, `name`, `class`, `score`). Бағдарлама:
1. өрістер атауын және жазбалар санын шығарсын;
2. пайдаланушы енгізген `id` бойынша жазбаны тапсын (жоқ болса — «Жазба табылмады»);
3. барлық жазбаларды кесте түрінде шығарсын.

```text
Енгізу:
id: 2
Шығару:
Өрістер: id, name, class, score | Жазбалар: 3
Табылды: {'id': 2, 'name': 'Бауыржан', 'class': '9А', 'score': 78}
id | name       | class | score
1  | Айгерім    | 9А    | 95
2  | Бауыржан   | 9А    | 78
3  | Дәулет     | 9Ә    | 88
```

## Кеңейтілген деңгей

### 5-тапсырма. Кілттің бірегейлігін тексеру

`add_record(table, record, key="id")` функциясын жаз: егер кестеде мұндай кілт бар болса немесе кілт `None` болса — жазбаны қоспай, қате хабарламасын шығарады. Кейін `email` өрісі үшін `UNIQUE` шектеуін де қос.

### 6-тапсырма. Кестені екіге бөлу

Мына «жалпақ» кестені (бір тізім) екі кестеге — `classes` (id, name, teacher) және `students` (id, name, class_id) — бөлетін бағдарлама жаз. Сынып жетекшілері қайталанбауы тиіс.

```text
flat = [
    ("Айгерім", "9А", "Ермекова Г.С."),
    ("Бауыржан", "9А", "Ермекова Г.С."),
    ("Дәулет", "9Ә", "Оспанова А.Б."),
    ("Сымбат", "9Ә", "Оспанова А.Б."),
    ("Ерлан", "10А", "Қасымов Т.Н."),
]
Шығару:
classes: [(1, '9А', 'Ермекова Г.С.'), (2, '9Ә', 'Оспанова А.Б.'), (3, '10А', 'Қасымов Т.Н.')]
students: [(1, 'Айгерім', 1), (2, 'Бауыржан', 1), (3, 'Дәулет', 2), (4, 'Сымбат', 2), (5, 'Ерлан', 3)]
```

### 7-тапсырма. Сілтемелік тұтастық

6-тапсырмадағы кестелер үшін `check_integrity(students, classes)` функциясын жаз: `class_id` мәні `classes`-та жоқ барлық оқушыны тауып шығарсын. Сосын `delete_class(class_id)` функциясын жаз: егер сол сыныпта оқушылар болса — сыныпты жоюға рұқсат бермесін.

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Индекс неге керек?

100 000 кездейсоқ жазбадан тұратын «кесте» жаса (`id`, `iin` — 12 цифрлық жол, `name`). Кездейсоқ 1000 ЖСН бойынша іздеуді екі тәсілмен орында және уақытын өлше (`time.perf_counter()`):
1. тізімді циклмен қарап шығу (толық қарау — full scan);
2. алдын ала `{iin: жазба}` сөздігін (индекс) құрып, сол арқылы іздеу.

Нәтижелерді салыстырып, деректер қорындағы **индекс** ұғымының мәнін түсіндір.

### 9-тапсырма. Өз деректер қорыңның идеясы

Өзіңе қызықты тақырып таңда (футбол лигасы, аниме каталогы, үй жануарлары емханасы, мектеп асханасы) және қағазда: кемінде 3 кесте, әрқайсысында 4–6 өріс (типтерімен), бастапқы және сыртқы кілттерді белгіле. Әр кестеге 3 жазбадан мысал жаз.

## Үй тапсырмасы

1. Өз сыныбыңның сабақ кестесін деректер қоры ретінде ойлап көр: қандай кестелер керек (пәндер, мұғалімдер, кабинеттер, сабақтар)? Әр кестенің өрістерін және кілттерін жаз.
2. Телефоныңдағы кез келген қосымшаны (мысалы, «Контактілер» немесе музыка) таңдап, оның деректері қандай кестелерде сақталуы мүмкін екенін болжап жаз.

```python
def add_record(table, record, key="id", unique=("email",)):
    """Жазбаны PRIMARY KEY және UNIQUE шектеулерін тексеріп қосады."""
    if record.get(key) is None:
        print(f"Қате: {key} бос болмауы керек")
        return False
    for row in table:
        if row[key] == record[key]:
            print(f"Қате: {key}={record[key]} бар (PRIMARY KEY қайталанды)")
            return False
        for field in unique:
            if field in record and row.get(field) == record[field]:
                print(f"Қате: {field}={record[field]} бар (UNIQUE)")
                return False
    table.append(record)
    return True


players = []
add_record(players, {"id": 1, "nick": "Qyran", "email": "q@mail.kz"})
add_record(players, {"id": 1, "nick": "Bars", "email": "b@mail.kz"})
add_record(players, {"id": 2, "nick": "Bars", "email": "q@mail.kz"})
add_record(players, {"id": None, "nick": "Tulpar", "email": "t@mail.kz"})
print("Кестеде:", len(players), "жазба")
```

**7-тапсырма**

```python
classes = [(1, "9А", "Ермекова Г.С."), (2, "9Ә", "Оспанова А.Б."), (3, "10А", "Қасымов Т.Н.")]
students = [(1, "Айгерім", 1), (2, "Бауыржан", 1), (3, "Дәулет", 2), (4, "Сымбат", 9)]


def check_integrity(students, classes):
    ids = {c[0] for c in classes}
    return [s for s in students if s[2] not in ids]


def delete_class(class_id):
    if any(s[2] == class_id for s in students):
        print(f"Сынып {class_id} жойылмайды: онда оқушылар бар")
        return
    classes[:] = [c for c in classes if c[0] != class_id]
    print(f"Сынып {class_id} жойылды")


print("Тұтастық бұзылған:", check_integrity(students, classes))
delete_class(1)
delete_class(3)
print("Қалған сыныптар:", [c[1] for c in classes])
```

**8-тапсырма**

```python
import random
import time

random.seed(1)
table = [{"id": i, "iin": f"{random.randint(0, 10**12 - 1):012d}", "name": f"Азамат {i}"}
         for i in range(1, 100_001)]
queries = [random.choice(table)["iin"] for _ in range(1000)]

start = time.perf_counter()
for q in queries:
    for row in table:              # толық қарау
        if row["iin"] == q:
            break
scan_time = time.perf_counter() - start

start = time.perf_counter()
index = {row["iin"]: row for row in table}   # индекс құру
build_time = time.perf_counter() - start
start = time.perf_counter()
for q in queries:
    row = index[q]
index_time = time.perf_counter() - start

print(f"Толық қарау: {scan_time:.3f} с")
print(f"Индекс құру: {build_time:.3f} с, индекспен іздеу: {index_time:.5f} с")
print(f"Индекспен іздеу ~{scan_time / index_time:.0f} есе жылдам")
```

Нәтиже компьютерге байланысты, бірақ индекспен іздеу мыңдаған есе жылдам болады. Түсіндірме: деректер қоры бастапқы кілт пен индекстелген өрістер бойынша «каталог» (B-дарақ) жүргізеді, сондықтан жазбаны бүкіл кестені қарамай-ақ табады. Индекстің бағасы — қосымша жад және жазбаны қосу/өзгерту кезінде индексті жаңарту уақыты.
