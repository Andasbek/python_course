## 1. Жобаның техникалық тапсырмасы (ТТ)

**Атауы:** «Оқушылар базасы» (Student Base).
**Пайдаланушы:** үйірме жетекшісі немесе сынып жетекшісі.
**Мақсаты:** оқушылар туралы деректерді графикалық интерфейс арқылы сақтау, қарау, өзгерту, іздеу.

| № | Талап | Кезең |
|---|---|---|
| 1 | Оқушыны қосу (аты-жөні, сынып, қала, телефон, орташа балл) | 1 |
| 2 | Барлық оқушыны кестеде көрсету | 1 |
| 3 | Енгізуді тексеру (бос өріс, сынып 1–11, балл 0–100) | 1 |
| 4 | Кестеден таңдап, деректерді өзгерту | 2 |

## 2. Қосымшаның архитектурасы

Ең жиі қате — SQL кодын батырма функцияларына «шашып» жазу. Сонда код оқылмайды, қайталанады, тестілеу қиын. Біз **екі қабатқа** бөлеміз:

```text
┌───────────────────────────┐
│  app.py  (Tkinter GUI)     │  ← пайдаланушы көретін бөлік
│  батырмалар, форма, кесте  │
└────────────┬──────────────┘
             │ әдістерді шақырады: add(), get_all() ...
┌────────────▼──────────────┐
│  db.py  (StudentDB класы)  │  ← тек SQL және sqlite3
└────────────┬──────────────┘
             │
        students.db
```

**Пайда:** ертең Tkinter-ді веб-интерфейске ауыстырсақ, `db.py` өзгермейді. Ал SQLite-ты басқа ДҚБЖ-ға ауыстырсақ, `app.py` өзгермейді. Бұл — **жауапкершілікті бөлу** (separation of concerns) қағидасы.

Жоба құрылымы:
```text
student_base/
├── db.py          # деректер қабаты
├── app.py         # GUI
├── students.db    # автоматты жасалады
└── .gitignore     # students.db, __pycache__/
```

## 3. Деректер қабаты: `StudentDB` класы

```python
import sqlite3


class StudentDB:
    """Оқушылар деректер қорымен жұмыс істейтін класс."""

    def __init__(self, path="students.db"):
        self.conn = sqlite3.connect(path)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS students (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                name TEXT NOT NULL,
                grade INTEGER NOT NULL CHECK (grade BETWEEN 1 AND 11),
                city TEXT,
                phone TEXT,
                score REAL CHECK (score BETWEEN 0 AND 100)
            )
        """)
        self.conn.commit()

    def add(self, name, grade, city, phone, score):
        cur = self.conn.execute(
            "INSERT INTO students (name, grade, city, phone, score) VALUES (?, ?, ?, ?, ?)",
            (name, grade, city, phone, score),
        )
        self.conn.commit()
        return cur.lastrowid

    def get_all(self):
        return self.conn.execute(
            "SELECT id, name, grade, city, phone, score FROM students ORDER BY name"
        ).fetchall()

    def count(self):
        return self.conn.execute("SELECT COUNT(*) FROM students").fetchone()[0]

    def close(self):
        self.conn.close()


if __name__ == "__main__":
    db = StudentDB(":memory:")          # тест үшін жадтағы қор
    db.add("Айгерім Сәрсенова", 9, "Алматы", "+77011234567", 92.5)
    db.add("Ержан Бекұлы", 11, "Астана", "", 81)
    for row in db.get_all():
        print(row)
    print("Барлығы:", db.count())
```

Нәтижесі:
```text
(1, 'Айгерім Сәрсенова', 9, 'Алматы', '+77011234567', 92.5)
(2, 'Ержан Бекұлы', 11, 'Астана', '', 81.0)
Барлығы: 2
```

Назар аударыңыз:
- **`CHECK`** шектеулері — деректер қорының өзі қате мәнді (мысалы, 15-сынып) қабылдамайды. Бұл — «екінші қорғаныс сызығы».
- **`if __name__ == "__main__":`** — модульді GUI-сыз бөлек тексеруге мүмкіндік береді.
- **`":memory:"`** — дискке жазбайтын уақытша қор, тест үшін өте ыңғайлы.

## 4. Интерфейс макеті

Орналастыру үшін `grid` (форма) және `pack` (үлкен блоктар) бірге қолданылады, бірақ **бір контейнердің ішінде** тек біреуін ғана. Сондықтан формаға жеке `Frame` (немесе `ttk.LabelFrame`) жасаймыз.

## 5. `ttk.Treeview` — кесте виджеті

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
cols = ("id", "name", "grade")
tree = ttk.Treeview(root, columns=cols, show="headings", height=5)
tree.heading("id", text="ID")
tree.heading("name", text="Аты-жөні")
tree.heading("grade", text="Сынып")
tree.column("id", width=40, anchor="center")
tree.column("name", width=200)
tree.column("grade", width=60, anchor="center")
tree.insert("", "end", values=(1, "Айгерім", 9))
tree.pack(fill="both", expand=True)
root.mainloop()
```

Негізгі әдістер:

| Әдіс | Не істейді |
|---|---|
| `tree.insert("", "end", values=(...))` | Соңына жол қосады |
| `tree.get_children()` | Барлық жолдың идентификаторлары |
| `tree.delete(*tree.get_children())` | Кестені толық тазалайды |
| `tree.selection()` | Таңдалған жолдар |
| `tree.item(iid, "values")` | Жолдың мәндері |

Кестені жаңарту үлгісі — «бәрін өшіріп, қайта толтыру»:

```python
def refresh(tree, rows):
    tree.delete(*tree.get_children())
    for row in rows:
        tree.insert("", "end", values=row)
```

## 6. Валидация: енгізуді тексеру

Пайдаланушы кез келген нәрсе жаза алады. Тексеруді бөлек функцияға шығарамыз — оны GUI-сыз да тестілеуге болады:

```python
def validate(name, grade, score):
    """Қате болса — қате мәтінін, бәрі дұрыс болса — None қайтарады."""
    if not name.strip():
        return "Аты-жөні бос болмауы керек"
    if not grade.isdigit() or not 1 <= int(grade) <= 11:
        return "Сынып 1-ден 11-ге дейінгі бүтін сан болуы керек"
    try:
        s = float(score.replace(",", "."))
    except ValueError:
        return "Балл сан болуы керек"
    if not 0 <= s <= 100:
        return "Балл 0–100 аралығында болуы керек"
    return None

print(validate("Дана", "9", "88,5"))
print(validate("", "9", "88"))
print(validate("Дана", "15", "88"))
```

Нәтижесі:
```text
None
Аты-жөні бос болмауы керек
Сынып 1-ден 11-ге дейінгі бүтін сан болуы керек
```

`score.replace(",", ".")` — пайдаланушы «88,5» деп үтірмен жазса да қабылдаймыз.

## 7. GUI мен ДҚ-ны байланыстыру: «Қосу» батырмасы

## 8. Кезең-кезеңмен әзірлеу және Git

- Әр қадамнан кейін бағдарламаны іске қосып тексеріңіз — 100 жол жазып, бір-ақ рет тексеру қауіпті.
- Әр аяқталған қадамнан кейін Git коммит жасаңыз: `git commit -m "StudentDB класы қосылды"`.
- `students.db` файлын `.gitignore`-ға қосыңыз — репозиторийге код салынады, жеке деректер (телефондар!) салынбайды.

## Жиі кездесетін қателер

**1. `grid` пен `pack`-ты бір контейнерде араластыру** — бағдарлама «қатып» қалады немесе `TclError` шығады.
```python
# Қате:
# tk.Label(root, text="Аты").grid(row=0, column=0)
# tree.pack()
# Дұрыс: формаға бөлек Frame
# form = tk.Frame(root); form.pack()
# tk.Label(form, text="Аты").grid(row=0, column=0)
```

**2. `command=self.add_student()` — жақшамен** — функция батырма басылғанда емес, бағдарлама іске қосылғанда бірден орындалады. Дұрысы: `command=self.add_student`.

**3. `commit()` ұмыту** — кестеде жол көрінеді, бірақ бағдарламаны қайта ашқанда жоқ болады.

**4. Кестені жаңартқанда ескі жолдарды өшірмеу** — әр қосқанда тізім екі еселенеді. Алдымен `tree.delete(*tree.get_children())`.

**5. `int(grade_entry.get())` тексерусіз** — бос өрісте `ValueError` шығып, қосымша құлайды. Алдымен `validate()`.

## Ескерту

- `pack` пен `grid`-ті бір контейнерде араластыруға болмайды — Tkinter қатып қалады немесе `TclError` шығарады. Әр топ үшін жеке `Frame` жасаңыз.
- `sqlite3`-те әрқашан `?` параметрлі сұраныстарды қолданыңыз, f-жолдарды емес — бұл SQL-инъекциядан қорғайды (https://docs.python.org/3/library/sqlite3.html).
- SQLite әдепкі бойынша сыртқы кілттерді тексермейді: әр қосылымда `PRAGMA foreign_keys = ON` орындау керек.
- `with sqlite3.connect(...) as con:` блогы транзакцияны (commit/rollback) басқарады, бірақ қосылымды **жаппайды** — `con.close()` бөлек шақырылады.
- PEP 8 бойынша модуль атаулары кіші әріппен (`db.py`, `app.py`), класс атаулары CapWords стилінде (`StudentDB`) жазылады. `ttk` құжаттамасы: https://docs.python.org/3/library/tkinter.ttk.html.
