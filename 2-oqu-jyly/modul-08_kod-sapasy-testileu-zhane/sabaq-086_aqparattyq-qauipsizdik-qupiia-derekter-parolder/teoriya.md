## 1. Ақпараттық қауіпсіздіктің үш қағидаты (CIA)

| Қағидат | Мағынасы | Бұзылу мысалы | Қорғау |
|---|---|---|---|
| **Құпиялық** (Confidentiality) | Ақпаратты тек рұқсаты бар адам көреді | Парольдер базасы ағып кетті | Хэштеу, шифрлау, қолжетімділікті шектеу |
| **Тұтастық** (Integrity) | Ақпарат рұқсатсыз өзгертілмейді | Біреу журналдағы бағаны өзгертті | Тексеру, логтау, сақтық көшірме, хэш |
| **Қолжетімділік** (Availability) | Ақпарат керек кезде қолжетімді | Сервер құлап, сайт ашылмайды | Сақтық көшірме, резервтік сервер |

## 2. Құпия деректерді кодтан бөлек сақтау

**Құпия деректер** (секреттер): API кілттері, деректер қорының паролі, токендер, бот токені (Telegram), электрондық пошта паролі.

**Негізгі ереже:** құпия **ешқашан** код ішінде, README-де, скриншотта, логта және Git тарихында болмауы керек.

### Орта айнымалылары арқылы

```python
import os

api_key = os.environ.get("WEATHER_API_KEY")
if api_key is None:
    print("Қате: WEATHER_API_KEY орта айнымалысы орнатылмаған")
else:
    print("Кілт жүктелді, ұзындығы:", len(api_key))   # кілттің өзін ешқашан шығармаймыз!
```

`.env` файлы + `python-dotenv` кітапханасы (`pip install python-dotenv`):

```text
# .env  (бұл файл .gitignore-да!)
WEATHER_API_KEY=sk-...
DB_PASSWORD=...
```

```python
import os

```

Репозиторийге **`.env.example`** үлгісін жүктейміз (мәндерсіз), басқалар оны көшіріп, өз кілтін жазады:

```text

```

### Құпия кездейсоқ жарияланып кетсе

1. **Дереу** кілтті жарамсыз етіңіз (қызмет сайтында «Revoke / Regenerate»). Бұл — ең маңызды қадам!
2. Жаңа кілт алып, оны `.env`-ке жазыңыз.

Тек файлды өшіріп, жаңа коммит жасау **жеткіліксіз**: ескі коммиттерде кілт сақталып қалады және `git log -p` арқылы көрінеді.

## 3. Парольдер

### Пароль енгізу: `getpass`

```python
from getpass import getpass

parol = getpass("Пароль: ")      # терминалда енгізілген таңбалар көрінбейді
```

(VS Code-тың кейбір шығыс терезелерінде `getpass` ескерту беруі мүмкін — кәдімгі терминалда іске қосыңыз.)

### Парольді ешқашан ашық түрде сақтамаймыз

Деректер қоры ағып кетсе, ашық парольдер бірден ұрланады. Сондықтан **хэш** сақтаймыз.

**Хэш функциясы** — кез келген мәтінді белгіленген ұзындықтағы «саусақ ізіне» айналдырады:
- бір мәтіннен әрдайым бір хэш шығады;
- хэштен бастапқы мәтінді қалпына келтіру мүмкін емес (бір бағытты);
- бір таңбаның өзгеруі хэшті толығымен өзгертеді.

```python
import hashlib

print(hashlib.sha256("qwerty123".encode()).hexdigest())
print(hashlib.sha256("qwerty124".encode()).hexdigest())
```

Нәтижесі:
```text
daaad6e5604e8e17bd9f108d91e26afe6281dac8fda0091040a7a6d7bd9b43b5
45163e5dd5f90a71b49d4f9d3dd0b3ec40e576f7795bc26e0decf337cafba5d1
```

**Хэштеу ≠ шифрлау.** Шифрланған мәтінді кілтпен ашуға болады; хэшті «ашу» мүмкін емес. Кіргенде енгізілген парольді қайта хэштеп, сақталған хэшпен салыстырамыз.

### Тұз (salt) және баяу хэш

Қарапайым SHA-256 жеткіліксіз: (1) екі адамның паролі бірдей болса, хэштері де бірдей; (2) шабуылдаушылар танымал парольдердің дайын хэш кестелерін қолданады; (3) SHA-256 тым **жылдам** — секундына миллиардтаған нұсқаны тексеруге болады.

Шешімі:
- **тұз** — әр пайдаланушыға арналған кездейсоқ жол, парольге қосылып хэштеледі және хэшпен бірге сақталады;
- **баяу хэш** — `hashlib.pbkdf2_hmac` хэшті жүз мыңдаған рет қайталайды; заңды пайдаланушыға бұл байқалмайды, ал миллиондаған нұсқаны тексеретін шабуылдаушыға өте қымбатқа түседі.

```python
import hashlib
import hmac
import secrets

QAITALAU = 200_000


def parol_hashtau(parol):
    """Парольдің тұзы мен хэшін (екеуі де hex мәтін) қайтарады."""
    tuz = secrets.token_bytes(16)
    hash_bytes = hashlib.pbkdf2_hmac("sha256", parol.encode(), tuz, QAITALAU)
    return tuz.hex(), hash_bytes.hex()


def parol_tekseru(parol, tuz_hex, hash_hex):
    """Енгізілген парольдің сақталған хэшке сәйкес келетінін тексереді."""
    zhana = hashlib.pbkdf2_hmac("sha256", parol.encode(), bytes.fromhex(tuz_hex), QAITALAU)
    return hmac.compare_digest(zhana.hex(), hash_hex)


tuz, h = parol_hashtau("Almaty#2027")
print("Тұз:", tuz)
print("Хэш:", h[:20] + "...")
print(parol_tekseru("Almaty#2027", tuz, h))
print(parol_tekseru("almaty#2027", tuz, h))
```

Нәтижесі (тұз бен хэш әр іске қосқанда өзгеше):
```text
Тұз: 3f9a1c0b7e5d42a8916c0de4b2f57a13
Хэш: 8c41e0a9b3f2d7615e0c...
True
False
```

`hmac.compare_digest` — салыстыруды тұрақты уақытта жасайды, сондықтан шабуылдаушы жауап уақытына қарап хэшті таба алмайды. Кәсіби жобаларда `bcrypt` немесе `argon2` кітапханалары да қолданылады.

### `random` емес, `secrets`

`random` модулі ойындар мен модельдеуге арналған — оның нәтижесін болжауға болады. Пароль, токен, растау коды үшін **`secrets`**:

```python
import secrets
import string

alfavit = string.ascii_letters + string.digits + "!@#$%&*"
parol = "".join(secrets.choice(alfavit) for _ in range(14))
print("Жаңа пароль:", parol)
print("Токен:", secrets.token_urlsafe(16))
print("SMS коды:", f"{secrets.randbelow(1_000_000):06d}")
```

### Мықты пароль ережелері

- кемінде 12 таңба; ұзындық күрделіліктен маңыздырақ;
- кіші және бас әріптер, цифрлар, арнайы таңбалар;
- сөздіктегі сөз, туған күн, аты-жөн, `123456`, `qwerty` емес;
- әр сайтқа — **бөлек** пароль (бір сайт ағып кетсе, қалғандары қауіпсіз);
- пароль менеджері және **екі факторлы аутентификация** (2FA) — SMS немесе қосымшадағы код.

**Құпия сөз-фраза** (passphrase): `Таңертең-3-кесе-шай-ішемін!` — есте сақтауға оңай, бұзуға қиын.

## 4. SQL инъекциясы

Дерекқормен (мысалы, SQLite) жұмыс істегенде сұранысты f-жолмен құрастыру — **қауіпті**:

```python
import sqlite3

conn = sqlite3.connect(":memory:")
conn.execute("CREATE TABLE users (login TEXT, parol_hash TEXT)")
conn.execute("INSERT INTO users VALUES ('aliya', 'x'), ('erlan', 'y')")

login = "' OR '1'='1"                                     # шабуылдаушының «логині»
qauipti = f"SELECT * FROM users WHERE login = '{login}'"
print(conn.execute(qauipti).fetchall())                   # БАРЛЫҚ пайдаланушы!

qauipsiz = "SELECT * FROM users WHERE login = ?"
print(conn.execute(qauipsiz, (login,)).fetchall())        # ешкім табылмайды
```

Нәтижесі:
```text
[('aliya', 'x'), ('erlan', 'y')]
[]
```

f-жолда енгізу SQL **кодының бөлігіне** айналады: `WHERE login = '' OR '1'='1'` — әрдайым ақиқат. Параметрлі сұраныста (`?`) енгізу әрдайым **мән** ретінде қабылданады. Ереже: пайдаланушыдан келген мәнді SQL-ға тек `?` арқылы береміз.

Жалпы ереже — **пайдаланушы енгізуіне ешқашан сенбе**: ұзындығын, типін, форматын тексер (валидация).

## 5. Жеке деректер және этика

### Жеке деректер дегеніміз не

**Дербес (жеке) деректер** — адамды тікелей немесе жанама анықтауға мүмкіндік беретін кез келген ақпарат: аты-жөні, ЖСН, телефон, мекенжай, фото, туған күні, геолокация, баға, денсаулық туралы мәлімет.

Қазақстанда бұл сала **«Дербес деректер және оларды қорғау туралы» ҚР Заңымен** (2013 ж.) реттеледі. Еуропада — GDPR. Негізгі талаптар ұқсас.

### Деректерді өңдеудің қағидаттары

| Қағидат | Мағынасы | Бағдарламашы не істейді |
|---|---|---|
| **Келісім** | Адам өз деректерін жинауға келісім береді | Тіркелу формасында «Келісемін» белгісі, түсінікті мақсат |
| **Мақсатқа сәйкестік** | Деректер тек айтылған мақсатқа қолданылады | Сауалнама деректерін жарнамаға сатпау |
| **Азайту (минимизация)** | Тек қажетті деректер жиналады | Ойынға ЖСН мен мекенжай қажет емес |
| **Сақтау мерзімі** | Қажеттілік біткенде деректер жойылады | Ескі есептерді жою |
| **Қауіпсіздік** | Деректер қорғалған | Хэштеу, қолжетімділікті шектеу, сақтық көшірме |
| **Субъект құқығы** | Адам өз деректерін көріп, түзетіп, жоюды сұрай алады | «Аккаунтты жою» функциясы |

### Деректерді жасыру (анонимдеу, маскалау)

Талдау немесе көрсету үшін адамның толық деректері қажет емес:

```python
def telefon_maska(tel):
    """Телефон нөмірінің ортасын жасырады: +7 701 *** ** 67"""
    cifr = "".join(c for c in tel if c.isdigit())
    return f"+7 {cifr[1:4]} *** ** {cifr[-2:]}"


def zhsn_maska(zhsn):
    """ЖСН-нің тек алғашқы 6 цифрын (туған күнін) қалдырады."""
    return zhsn[:6] + "******"


print(telefon_maska("+7 (701) 555-12-67"))
print(zhsn_maska("050315501230"))
```

Нәтижесі:
```text
+7 701 *** ** 67
050315******
```

**Анонимдеу** — адамды мүлде анықтау мүмкін болмайтындай ету (аты-жөнді жою, жасты топқа айналдыру «15–17 жас»). **Псевдонимдеу** — атты кодпен ауыстыру (`Оқушы_017`), кодтар кестесі бөлек, қорғалған жерде сақталады.

### Этикалық сұрақтар

Заң бәрін қамти бермейді. Әр бағдарламашы өзіне сұрақ қоюы керек:
- Мен бұл деректерді жинағанымды адам біле ме? Ол бұған қарсы болмас па еді?
- Бұл ақпарат ағып кетсе, кімге зиян келеді?
- Менің бағдарламам біреуді кемсітпей ме (мысалы, жынысына, ұлтына қарай)?
- Мен бұл кодты басқаның есептік жазбасына рұқсатсыз кіру үшін қолданып отырған жоқпын ба?

**Есте сақтаңыз:** басқа адамның аккаунтына, компьютеріне, желісіне рұқсатсыз кіру — тіпті «ойын үшін», «тексеру үшін» болса да — ҚР Қылмыстық кодексі бойынша жауапкершілікке әкеледі. Қауіпсіздікті тек **өз** жүйеңізде немесе иесінің жазбаша рұқсатымен тексеруге болады.

## Жиі кездесетін қателер

**1. Кілтті кодқа жазып, «кейін алып тастаймын» деу.**
```python
API_KEY = "sk-live-12345abcdef"      # бір рет push жасалса — жарияланды
```
Дұрысы:
```python
import os

API_KEY = os.getenv("API_KEY")
```

**2. Парольді ашық түрде сақтау немесе логқа жазу.**
```python
import logging

parol = "Almaty#2027"
logging.info("Кіру әрекеті: login=aliya, parol=%s", parol)    # ЖОҚ!
```
Логқа тек логин мен нәтижені жазамыз: `logging.info("Кіру әрекеті: login=%s, сәтті=%s", "aliya", False)`.

**3. Пароль үшін `random` қолдану** — нәтижесін болжауға болады. `secrets` қолданыңыз.

**4. Тұзсыз MD5/SHA-256** — дайын кестелер арқылы бірнеше секундта табылады.

**5. «Пароль қате» мен «Мұндай пайдаланушы жоқ» деп бөлек хабарлау.** Шабуылдаушы осы арқылы қандай логиндер бар екенін біледі. Бір хабар: «Логин немесе пароль қате».

## Ескерту

- `load_dotenv()` әдепкі бойынша жүйеде бұрыннан берілген орта айнымалыларын **қайта жазбайды**; `.env` мәндері басым болуы үшін `load_dotenv(override=True)` қолданыңыз.
- Құпиясы бар файл Git-ке түсіп қойса, `.gitignore` оны жасырмайды: файлды индекстен `git rm --cached .env` командасымен алып тастап, кілтті кері шақыру керек.
- SHA-256 негізіндегі `pbkdf2_hmac` үшін OWASP жүздеген мың итерацияны ұсынады (бағдар — 600 000); кейін көбейту мүмкін болуы үшін итерация санын тұз бен хэшпен бірге сақтаңыз.
- Python 3.6+ нұсқасында `secrets` модулі — криптографиялық берік кездейсоқ мәндер алудың стандартты тәсілі; `random.seed()` `random` тізбегін толық қайталанатын етеді, сондықтан ол парольдерге жарамайды.
- Параметрленген сұраныстар тек **мәндерді** қорғайды; кесте мен баған атауларын `?` арқылы беруге болмайды — оларды алдын ала берілген рұқсат етілген атаулар тізімінен таңдайды.
- Құжаттама: [secrets](https://docs.python.org/3/library/secrets.html), [hashlib](https://docs.python.org/3/library/hashlib.html), [sqlite3 — placeholders](https://docs.python.org/3/library/sqlite3.html#sqlite3-placeholders).
