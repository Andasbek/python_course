## Базалық деңгей

**1-тапсырма. Пікірді сындарлы ет.** Төмендегі пікірлерді теориядағы ережелер бойынша қайта жазыңыз (белгі + нақты мәселе + ұсыныс):
1. «Мынау не деген код?»
2. «Атаулар түсініксіз.»
3. «Тест жоқ, нашар.»
4. «Неге цикл? Ақымақтық.»
5. «Мен мұны бұлай жазбас едім.»
6. «ОК.» (кодта пароль ашық сақталып тұр)

## Кеңейтілген деңгей

**4-тапсырма. Жұптық review GitHub-та.** Жұбыңызбен:
1. Әрқайсыңыз өз жобаңыздан 50–100 жолдық бір файлды таңдаңыз (86-сабақтың үй тапсырмасы).
2. Жұбыңызды репозиторийге Collaborator ретінде шақырыңыз.
3. Жаңа тармақ ашыңыз (`git checkout -b review/<файл>`), файлға кемінде бір жақсарту енгізіп (мысалы, docstring қосу), `push` жасап, **Pull Request** ашыңыз; PR сипаттамасына не өзгергенін және не тексеруді сұрайтыныңызды жазыңыз.
4. Рецензент ретінде жұбыңыздың PR-ына **кемінде 5 жол-түсініктеме** қалдырыңыз: кемінде 1 [Міндетті] немесе [Ұсыныс], 1 [Сұрақ], 1 [Мақтау]; кемінде бір **Suggestion**. Соңында «Approve» немесе «Request changes».
5. Автор ретінде әр пікірге жауап беріп, қажеттілерін түзетіп, жаңа коммит жасаңыз. Бекітілгеннен кейін — Merge.

**5-тапсырма. Автор ретінде жауап беру.** Сіздің кодыңызға мына пікірлер келді. Әрқайсысына сыпайы, дәлелді жауап жазыңыз (келісу, нақтылау немесе дәлелмен келіспеу):
1. «[Міндетті] `json.load` файл жоқ болса құлайды.»
2. «[Ұсыныс] Барлық функцияны класқа айналдырған дұрыс шығар.»
3. «[Сұрақ] Неге `print` емес, `logging` қолдандың?»
4. «[Ұсыныс] `i`, `j` атауларын ұзынырақ етсең.» (код: `for i in range(n): for j in range(m):` — кестенің жолдары мен бағандары)

**6-тапсырма. Жұптық бағдарламалау (20 мин).** Жүргізуші/штурман рөлдерімен, 10 минуттан кейін рөл ауыстырып, функция жазыңыз: `kesteni_tekseru(kesteh)` — сабақ кестесінің сөздігін (`{"Дс": ["Алгебра", "Физика", ...], ...}`) тексеріп, (а) күніне 7-ден көп сабақ, (ә) бір күнде бір пән 2 реттен көп, (б) бос күн бар болса — ескертулер тізімін қайтарсын. Соңында бір-біріңізге: «Штурман ретінде маған ... қиын/жеңіл болды» деп кері байланыс беріңіз.

## ★ Олимпиадалық / шығармашылық тапсырма

**7-тапсырма. Өз линтерің.** `ast` модулін (Python кодын синтаксистік ағашқа айналдырады) пайдаланып, `mini_lint.py` жазыңыз. Ол файлды тексеріп, мына ескертулерді жол нөмірімен шығарсын:
- жол 79 таңбадан ұзын;
- жол соңында артық бос орын;
- функция атауы `snake_case` емес / класс атауы `CamelCase` емес;
- функцияда немесе класта docstring жоқ;
- f-жолмен құрастырылған SQL (`execute(f"...")`) — қауіпсіздік ескертуі.

2-тапсырмадағы кодқа қолданыңыз.

## Үй тапсырмасы

1. 4-тапсырманы аяқтаңыз: PR бекітіліп, біріктірілсін.
2. «Code review күнделігіне» жазыңыз: маған айтылған ең пайдалы пікір; мен берген ең жақсы пікір; келесі жобада не істеймін.
3. **Қорытынды жобаға дайындық:** келесі сабақтан бастап IX модуль — қорытынды жеке жоба. 2–3 жоба идеясын ойланып келіңіз: қандай мәселені шешеді, кімге пайдалы, қандай технологиялар (ОБП, Tkinter, Pygame, SQLite, API, Pandas) қолданылады.

## Бағалау критерийлері

Бұл сабақта review **сапасы** формативті бағаланады (4-тапсырма бойынша):

**2-тапсырма — табылуы тиіс мәселелер:**

8. (19–29-жолдар) [Ұсыныс] екі бірдей цикл (copy-paste); SQL-дың өзімен есептеуге болады: `SELECT SUM(sany) FROM kitaptar WHERE zhyly < 2000` (58-сабақ).
9. (19-жол) [Ұсыныс] `stats` нәтижені `print` етеді — тестілеуге қиын; мәндерді `return` еткен дұрыс.
10. (бүкіл файл) [Ұсыныс] PEP 8: операторлар айналасында бос орын жоқ, әдістер арасында бос жол жоқ; docstring-тер жоқ; тест жоқ.

12. [Мақтау] `CREATE TABLE IF NOT EXISTS` қолданылған — бағдарлама қайта іске қосылғанда құламайды.

**3-тапсырма — түзетілген нұсқа:**
```python
"""Мектеп кітапханасының кітаптарын есепке алу модулі."""

import sqlite3


class Kitaphana:
    """SQLite негізіндегі кітапхана."""

    def __init__(self, db_path="kitaphana.db"):
        """Деректер қорына қосылып, кестені жасайды."""
        self.conn = sqlite3.connect(db_path)
        self.conn.execute(
            "CREATE TABLE IF NOT EXISTS kitaptar ("
            "atauy TEXT PRIMARY KEY, avtory TEXT, zhyly INTEGER, sany INTEGER)"
        )

    def qosu(self, atauy, avtory, zhyly, sany):
        """Жаңа кітап қосады."""
        if sany < 0:
            raise ValueError("Кітап саны теріс болмайды")
        self.conn.execute(
            "INSERT INTO kitaptar VALUES (?, ?, ?, ?)",
            (atauy, avtory, zhyly, sany),
        )
        self.conn.commit()

    def tabu(self, atauy):
        """Кітапты атауы бойынша табады; жоқ болса None."""
        return self.conn.execute(
            "SELECT atauy, avtory, zhyly, sany FROM kitaptar WHERE atauy = ?",
            (atauy,),
        ).fetchone()

    def beru(self, atauy):
        """Оқушыға кітап береді. Сәтті болса True қайтарады."""
        kitap = self.tabu(atauy)
        if kitap is None or kitap[3] == 0:
            return False
        self.conn.execute(
            "UPDATE kitaptar SET sany = sany - 1 WHERE atauy = ?", (atauy,)
        )
        self.conn.commit()
        return True

    def statistika(self, zhyl_shegi=2000):
        """Барлық кітаптар санын және zhyl_shegi-ге дейінгілерін қайтарады."""
        barlygy = self.conn.execute(
            "SELECT COALESCE(SUM(sany), 0) FROM kitaptar"
        ).fetchone()[0]
        eski = self.conn.execute(
            "SELECT COALESCE(SUM(sany), 0) FROM kitaptar WHERE zhyly < ?",
            (zhyl_shegi,),
        ).fetchone()[0]
        return barlygy, eski

    def zhabu(self):
        """Деректер қорымен байланысты жабады."""
        self.conn.close()


if __name__ == "__main__":
    k = Kitaphana(":memory:")
    k.qosu("Абай жолы", "М. Әуезов", 1942, 3)
    k.qosu("Көшпенділер", "І. Есенберлин", 1976, 2)
    k.qosu("Python негіздері", "А. Автор", 2023, 5)
    print(k.beru("Абай жолы"), k.beru("Жоқ кітап"))
    print("Барлығы және 2000 жылға дейінгі:", k.statistika())
    k.zhabu()
```
Нәтижесі: `True False`, `Барлығы және 2000 жылға дейінгі: (9, 4)`. Ескерту: `flake8` әдепкі шегі 79 таңба; кейбір жобаларда `--max-line-length=99` қолданылады.

`flake8 kitaphana_bad.py` — шамамен 25–30 ескерту; жиі кодтар: `E401` (бір жолда бірнеше импорт), `F401` (қолданылмайтын импорт), `E225` (оператор айналасында бос орын жоқ), `E231` (үтірден кейін бос орын жоқ), `E301`/`E302` (бос жолдар жетіспейді), `E501` (жол ұзын).

```python
from collections import Counter


def kesteni_tekseru(kesteh):
    """Сабақ кестесін тексеріп, ескертулер тізімін қайтарады."""
    eskertuler = []
    for kun, sabaqtar in kesteh.items():
        if not sabaqtar:
            eskertuler.append(f"{kun}: бос күн")
            continue
        if len(sabaqtar) > 7:
            eskertuler.append(f"{kun}: сабақ тым көп ({len(sabaqtar)})")
        for pan, san in Counter(sabaqtar).items():
            if san > 2:
                eskertuler.append(f"{kun}: «{pan}» {san} рет")
    return eskertuler


kesteh = {
    "Дс": ["Алгебра", "Физика", "Алгебра", "Алгебра"],
    "Сс": ["Тарих", "Химия", "Биология", "Ағылшын", "Қазақ тілі", "Әдебиет", "Дене шын.", "Информатика"],
    "Ср": [],
}
for e in kesteni_tekseru(kesteh):
    print(e)
```

```python
import ast
import re
import sys


def tekseru(path):
    """Файлды қарапайым ережелер бойынша тексереді."""
    with open(path, encoding="utf-8") as f:
        matin = f.read()
    eskertuler = []
    for nomir, zhol in enumerate(matin.splitlines(), start=1):
        if len(zhol) > 79:
            eskertuler.append((nomir, f"жол тым ұзын ({len(zhol)} > 79)"))
        if zhol != zhol.rstrip():
            eskertuler.append((nomir, "жол соңында артық бос орын"))
        if re.search(r"execute\(\s*f[\"']", zhol):
            eskertuler.append((nomir, "f-жолды SQL — инъекция қаупі, '?' қолданыңыз"))

    agash = ast.parse(matin)
    for tuyin in ast.walk(agash):
        if isinstance(tuyin, ast.FunctionDef):
            if not re.fullmatch(r"_{0,2}[a-z][a-z0-9_]*_{0,2}", tuyin.name):
                eskertuler.append((tuyin.lineno, f"функция атауы snake_case емес: {tuyin.name}"))
            if ast.get_docstring(tuyin) is None:
                eskertuler.append((tuyin.lineno, f"docstring жоқ: {tuyin.name}()"))
        elif isinstance(tuyin, ast.ClassDef):
            if not re.fullmatch(r"[A-Z][A-Za-z0-9]*", tuyin.name):
                eskertuler.append((tuyin.lineno, f"класс атауы CamelCase емес: {tuyin.name}"))
            if ast.get_docstring(tuyin) is None:
                eskertuler.append((tuyin.lineno, f"docstring жоқ: class {tuyin.name}"))

    for nomir, habar in sorted(eskertuler):
        print(f"{path}:{nomir}: {habar}")
    print("Барлығы:", len(eskertuler))


if __name__ == "__main__":
    tekseru(sys.argv[1] if len(sys.argv) > 1 else __file__)
```
