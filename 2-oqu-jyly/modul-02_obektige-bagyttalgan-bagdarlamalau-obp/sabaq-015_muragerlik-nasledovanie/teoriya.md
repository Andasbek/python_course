## 1. Мұрагерлік деген не?

**Мұрагерлік** (наследование, inheritance) — бар кластың негізінде жаңа класс құру механизмі: жаңа класс бар кластың **барлық атрибуттары мен әдістерін** мұраға алады және оларға **өзінікін қоса** алады.

| Термин | Синонимдері | Мағынасы |
|---|---|---|
| **Ата-класс** | базалық класс, суперкласс, родительский класс, parent | ортақ қасиеттер жазылған жалпы класс |
| **Ұрпақ класс** | туынды класс, ішкі класс, подкласс, дочерний класс, child, subclass | ата-кластан мұра алатын, нақтыланған класс |

Аналогиялар:
- **Биология:** баланың көзінің түсі, бойы ата-анасынан беріледі, бірақ оның өз ерекшеліктері де бар.
- **Жіктеу:** «Жануар» → «Сүтқоректі» → «Мысық». Әр мысық — сүтқоректі, әр сүтқоректі — жануар.
- **Құжат үлгісі:** мектептің ресми бланкі (логотип, мекенжай) — ата-класс; оның негізінде жасалған анықтама, бұйрық, хабарландыру — ұрпақтар.

Негізгі идея: **ортақ** нәрсені бір рет ата-класқа жазамыз, **ерекше** нәрсені — ұрпақтарға.

## 2. Синтаксис

```text
class ҰрпақКласс(АтаКласс):
    ...жаңа атрибуттар мен әдістер...
```

Мысал — ойын кейіпкерлері:

```python
class Hero:
    """Барлық ойын кейіпкерлерінің ата-класы."""

    def __init__(self, name):
        self.name = name
        self.hp = 100
        self.level = 1

    def take_damage(self, amount):
        """Зақым алады."""
        self.hp = max(0, self.hp - amount)

    def is_alive(self):
        """Тірі ме?"""
        return self.hp > 0

    def info(self):
        """Қысқаша ақпарат."""
        return f"{self.name}: {self.hp} HP, {self.level}-деңгей"


class Warrior(Hero):
    """Жауынгер — кейіпкердің бір түрі."""

    def strike(self):
        return f"{self.name} қылышпен шабады!"


class Mage(Hero):
    """Сиқыршы — кейіпкердің бір түрі."""

    def cast(self):
        return f"{self.name} от шарын лақтырады!"


batyr = Warrior("Батыр")
merlin = Mage("Мерлин")

print(batyr.strike())          # өз әдісі
print(merlin.cast())           # өз әдісі
merlin.take_damage(30)         # мұраға алынған әдіс
print(batyr.info())            # мұраға алынған әдіс
print(merlin.info())
print(merlin.is_alive())
```
Нәтижесі:
```text
Батыр қылышпен шабады!
Мерлин от шарын лақтырады!
Батыр: 100 HP, 1-деңгей
Мерлин: 70 HP, 1-деңгей
True
```

`Warrior` пен `Mage` кластарында `__init__` жоқ — бірақ `Warrior("Батыр")` жұмыс істейді: конструктор **ата-кластан** мұраға алынды. Барлық ортақ код — тек `Hero`-да. `take_damage`-ті түзетсек, барлық кейіпкер бірден түзетіледі.

### UML-дегі мұрагерлік
```text
              ┌──────────────────────┐
              │        Hero          │
              ├──────────────────────┤
              │ name, hp, level      │
              ├──────────────────────┤
              │ take_damage(amount)  │
              │ is_alive()           │
              │ info()               │
              └──────────▲───────────┘
                         │  (бос үшбұрышты нұсқама = «мұрагер»)
           ┌─────────────┴─────────────┐
┌──────────┴──────────┐     ┌──────────┴──────────┐
│      Warrior        │     │        Mage         │
├─────────────────────┤     ├─────────────────────┤
│ strike()            │     │ cast()              │
└─────────────────────┘     └─────────────────────┘
```
Нұсқама ұрпақтан **ата-класқа** қарай бағытталады: «Warrior — Hero-ның түрі».

## 3. Ұрпақ класс нені мұраға алады?

| Ата-кластағы | Ұрпақта бар ма? |
|---|---|
| Ашық атрибуттар мен әдістер | иә |
| Класс атрибуттары | иә (ортақ, бірақ ұрпақта «жабуға» болады) |
| `__init__` конструкторы | иә, егер ұрпақта өз `__init__` болмаса |
| `@property` қасиеттері | иә |
| `_қорғалған` атрибуттар | иә — «ұрпақтарға арналған ішкі» деген мағына осы |
| `__жабық` атрибуттар | бар, бірақ атауы `_АтаКласс__x` болып бұрмаланған, ұрпақтың әдістерінен `self.__x` арқылы **қатынау мүмкін емес** |

Соңғы жол маңызды: ұрпақтар қолдануы тиіс ішкі деректерге **бір** астын сызу (`_hp`) қолданған дұрыс.

```python
class Base:
    def __init__(self):
        self._shared = "ұрпақтарға қолжетімді"
        self.__secret = "тек Base ішінде"


class Child(Base):
    def show(self):
        print(self._shared)
        # print(self.__secret)  # AttributeError: 'Child' object has no attribute '_Child__secret'


Child().show()
```
Нәтижесі:
```text
ұрпақтарға қолжетімді
```

## 4. Ұрпақ класты кеңейту

Ұрпаққа жаңа **класс атрибуттарын** және **әдістерін** қосуға болады. Ұрпақтың әдістері ата-класс атрибуттарын (`self.name`, `self.hp`) еркін қолданады:

```python
class Archer(Hero):
    """Садақшы."""
    max_arrows = 10                      # тек садақшыларға тән класс атрибуты

    def shoot(self, target):
        """Нысанаға оқ атады (оқ саны шектеулі)."""
        if not hasattr(self, "arrows"):
            self.arrows = self.max_arrows
        if self.arrows == 0:
            return f"{self.name}: жебе бітті!"
        self.arrows -= 1
        target.take_damage(15)
        return f"{self.name} → {target.name}: -15 HP (жебе қалды: {self.arrows})"


arman = Archer("Арман")
print(arman.shoot(batyr))
print(arman.shoot(batyr))
print(batyr.info())
```
Нәтижесі:
```text
Арман → Батыр: -15 HP (жебе қалды: 9)
Арман → Батыр: -15 HP (жебе қалды: 8)
Батыр: 70 HP, 1-деңгей
```

Байқасаң, `arrows` атрибутын `hasattr` арқылы «кейін» қостық — бұл ыңғайсыз. Ұрпақ өз конструкторында **жаңа атрибуттар** (жебе саны, мана) қосуы керек, бірақ ата-класс конструкторын да **сақтауы** керек. Ол үшін ұрпақ өз `__init__` әдісін жариялап, ішінде `super().__init__(...)` арқылы ата-класс конструкторын шақырады. Сондай-ақ ұрпақ ата-класс әдісін **қайта анықтай** (override) алады — мысалы, сиқыршының `info()` әдісі мананы да көрсетсін:

```python
class ManaMage(Hero):
    """Мана қоры бар сиқыршы."""

    def __init__(self, name, mana=50):
        super().__init__(name)      # name, hp, level атрибуттарын Hero береді
        self.mana = mana

    def info(self):                 # ата-класс әдісін қайта анықтау
        return f"{super().info()}, мана: {self.mana}"


print(ManaMage("Мерлин").info())
```
Нәтижесі:
```text
Мерлин: 100 HP, 1-деңгей, мана: 50
```

## 5. Кластар иерархиясы

Мұрагерлік **көп деңгейлі** болуы мүмкін:

```python
class Animal:
    """Жануар."""

    def __init__(self, name):
        self.name = name

    def breathe(self):
        return f"{self.name} тыныс алады"


class Mammal(Animal):
    """Сүтқоректі."""

    def feed_milk(self):
        return f"{self.name} төлін сүтпен қоректендіреді"


class Cat(Mammal):
    """Мысық."""

    def meow(self):
        return f"{self.name}: Мияу!"


class Bird(Animal):
    """Құс."""

    def fly(self):
        return f"{self.name} ұшып барады"


murzik = Cat("Мұрзик")
print(murzik.meow())        # Cat
print(murzik.feed_milk())   # Mammal-дан
print(murzik.breathe())     # Animal-дан
burkit = Bird("Бүркіт")
print(burkit.fly(), "|", burkit.breathe())
# burkit.meow()             # AttributeError — құс мияуламайды
```
Нәтижесі:
```text
Мұрзик: Мияу!
Мұрзик төлін сүтпен қоректендіреді
Мұрзик тыныс алады
Бүркіт ұшып барады | Бүркіт тыныс алады
```

```text
             Animal
            /      \
        Mammal     Bird
          |
         Cat
```

### Атрибутты іздеу реті (MRO)
`murzik.breathe()` шақырылғанда Python әдісті **төменнен жоғары** іздейді: алдымен `Cat`, табылмаса — `Mammal`, кейін — `Animal`, соңында — `object`. Бұл рет **MRO** (Method Resolution Order, әдістерді іздеу реті) деп аталады:

```python
print([cls.__name__ for cls in Cat.__mro__])
```
Нәтижесі:
```text
['Cat', 'Mammal', 'Animal', 'object']
```

### `object` — барлық кластардың «бабасы»
Python 3-те ата-класы көрсетілмеген әрбір класс автоматты түрде **`object`** класынан мұра алады. `class Animal:` ≡ `class Animal(object):`. Сондықтан кез келген объектіде `__init__`, `__str__`, `__eq__` сияқты әдістер бар — олар `object`-тен келеді (оларды өз кластарыңда қайта анықтауға болады).

## 6. `isinstance()` және `issubclass()`

```python
print(isinstance(murzik, Cat))       # True
print(isinstance(murzik, Mammal))    # True — мысық сүтқоректі де
print(isinstance(murzik, Animal))    # True
print(isinstance(murzik, Bird))      # False
print(issubclass(Cat, Animal))       # True — класс деңгейінде тексеру
print(issubclass(Bird, Mammal))      # False
print(type(murzik) == Mammal)        # False — type тек нақты класты көрсетеді
```
Нәтижесі:
```text
True
True
True
False
True
False
False
```

Ұрпақ объектісі — сонымен қатар ата-класстың да объектісі. Сондықтан ата-класс күтілетін жерде ұрпақты қолдана аламыз:

```python
heroes = [Warrior("Батыр"), Mage("Мерлин"), Archer("Арман")]
for hero in heroes:
    hero.take_damage(20)          # кез келген Hero-да бар әдіс
    print(hero.info(), "| сиқыршы" if isinstance(hero, Mage) else "")
```
Нәтижесі:
```text
Батыр: 80 HP, 1-деңгей 
Мерлин: 80 HP, 1-деңгей | сиқыршы
Арман: 80 HP, 1-деңгей 
```
Бұл — **полиморфизмнің** негізі.

## 7. «Болып табылады» (is-a) және «бар» (has-a)

Мұрагерлікті **дұрыс** қолдану үшін тексеру сұрағы:

> «Ұрпақ — ата-класстың **бір түрі** ме?» (is-a)

| Қатынас | Сұрақ | Дұрыс шешім | Мысал |
|---|---|---|---|
| **is-a** («...болып табылады») | Мысық — жануар ма? Иә | **мұрагерлік** | `class Cat(Animal)` |
| **has-a** («...бар») | Көлікте қозғалтқыш бар ма? Иә. Көлік — қозғалтқыш па? Жоқ | **композиция** (атрибут) | `self.engine = Engine()` |

Қате мысалдар:
- `class Car(Engine)` — көлік қозғалтқыштың түрі емес → композиция.
- `class Library(Book)` — кітапхана кітаптың түрі емес, онда кітаптар **бар** → `self.books = []`.
- `class Student(Classroom)` — оқушы сыныптың түрі емес.

Дұрыс мысалдар:
- `class Teacher(Person)`, `class Student(Person)` — мұғалім де, оқушы да — адам.
- `class SavingsAccount(BankAccount)` — жинақ шоты — банк шотының түрі.
- `class EBook(Book)` — электронды кітап — кітаптың түрі.

## 8. Мектеп мысалы: `Person` → `Student`, `Teacher`

```python
class Person:
    """Мектептегі адам."""
    school = "№35 мектеп-гимназия"

    def __init__(self, name, birth_year):
        self.name = name
        self.birth_year = birth_year

    def age(self, current_year=2026):
        return current_year - self.birth_year

    def introduce(self):
        return f"Мен — {self.name}, {self.age()} жастамын."


class Student(Person):
    """Оқушы."""

    def study(self, subject):
        return f"{self.name} {subject} пәнін оқып отыр."


class Teacher(Person):
    """Мұғалім."""

    def teach(self, subject, grade):
        return f"{self.name} {grade}-сыныпқа {subject} пәнінен сабақ береді."


people = [Student("Әлия", 2012), Teacher("Гүлнар Серікқызы", 1985)]
for p in people:
    print(p.introduce(), p.school)
print(people[0].study("информатика"))
print(people[1].teach("информатика", 7))
```
Нәтижесі:
```text
Мен — Әлия, 14 жастамын. №35 мектеп-гимназия
Мен — Гүлнар Серікқызы, 41 жастамын. №35 мектеп-гимназия
Әлия информатика пәнін оқып отыр.
Гүлнар Серікқызы 7-сыныпқа информатика пәнінен сабақ береді.
```

## 9. Көптік мұрагерлік (қысқаша шолу)

Python-да класс **бірнеше** ата-класстан мұра ала алады: `class FlyingCar(Car, Airplane):`. Бұл күшті, бірақ шатасуы оңай құрал (әдіс екі ата-класта да болса, қайсысы алынады? — MRO шешеді). Іс жүзінде көбіне **жалғыз** мұрагерлік қолданылады. Ең жиі кездесетін жағдай — дайын кітапхана класынан мұра алу, мысалы Pygame-дағы `class Player(pygame.sprite.Sprite):`.

## 10. Мұрагерліктің артықшылықтары

1. **Кодты қайта пайдалану** — ортақ код бір рет жазылады (DRY).
2. **Жеңіл түзету** — қатені ата-класта түзетсең, барлық ұрпақта түзетіледі.
3. **Кеңейту оңай** — жаңа кейіпкер түрі = бірнеше жол.
4. **Логикалық құрылым** — кластар иерархиясы нақты әлемдегі жіктеуді бейнелейді.
5. **Дайын кітапханаларды қолдану** — Tkinter, Pygame, unittest кластарынан мұра алып, өз мүмкіндігіңді қосасың.

## Жиі кездесетін қателер

**1. Ата-класты жақшада көрсетуді ұмыту.**
```python
class Hero:
    def is_alive(self):
        return True


class Warrior:               # (Hero) жоқ — мұрагерлік жоқ!
    pass


# Warrior().is_alive()       # AttributeError: 'Warrior' object has no attribute 'is_alive'
```

**2. Ата-класты ұрпақтан кейін жариялау.**
```text
class Warrior(Hero): ...   ← Hero әлі жарияланбаған
class Hero: ...
→ NameError: name 'Hero' is not defined
```
Ата-класс файлда **жоғарырақ** (немесе импортталған) болуы керек.

**3. Ұрпақтан ата-класс конструкторының аргументтерін бермеу.**
```text
Warrior()  →  TypeError: Hero.__init__() missing 1 required positional argument: 'name'
```
Ұрпақ ата-класс конструкторын мұраға алды — оның параметрлерін беру керек.

**4. Ата-класстың `__жабық` атрибутына ұрпақтан қатынау.** `AttributeError: ... '_Child__x'`. Ұрпақтарға арналған деректер үшін `_x` қолдан.

**5. «has-a» жағдайда мұрагерлік қолдану** (`class Car(Engine)`). Сұрақ қой: «ұрпақ — ата-класстың түрі ме?»

**6. Тым терең иерархия.** `A → B → C → D → E → F` — түсінуге қиын. Әдетте 2–3 деңгей жеткілікті.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Мұрагерлік (inheritance) | Бар кластың негізінде жаңа класс құру |
| Ата-класс (parent, суперкласс) | Ортақ атрибуттар мен әдістер жазылған класс |
| Ұрпақ класс (child, подкласс) | Ата-кластан мұра алатын класс |
| Кластар иерархиясы | Кластардың мұрагерлік «ағашы» |
| `object` | Python-дағы барлық кластардың ата-класы |
| MRO | Әдіс пен атрибутты іздеу реті |
| `isinstance(obj, C)` | Объект C класына (немесе оның ұрпағына) жата ма |
| `issubclass(A, B)` | A класы B-ның ұрпағы ма |
| is-a | «...болып табылады» — мұрагерлік белгісі |
| has-a | «...бар» — композиция белгісі |

## Ескерту

- Ұрпақта өз `__init__` жазылса, ата-класс конструкторы автоматты түрде **шақырылмайды** — `super().__init__(...)` шақыруын ұмытсаң, ата-класс атрибуттары жасалмай қалады.
- `type(obj) == Parent` орнына `isinstance(obj, Parent)` қолдан: ол ұрпақ кластарды да ескереді. `isinstance` екінші аргумент ретінде кортеж қабылдайды: `isinstance(x, (Warrior, Mage))`.
- Кірістірілген типтерден де мұра алуға болады (`class MyList(list):`), бірақ `dict` пен `list` әдістерін қайта анықтау үшін `collections.UserDict` / `UserList` қауіпсізірек.
- PEP 8 ережесі: ата-класс та, ұрпақ та `PascalCase` стилінде аталады; ұрпақ атауы көбіне ата-класс атауын нақтылайды (`SavingsAccount(BankAccount)`).
- Ресми құжаттама: https://docs.python.org/3/tutorial/classes.html#inheritance.
