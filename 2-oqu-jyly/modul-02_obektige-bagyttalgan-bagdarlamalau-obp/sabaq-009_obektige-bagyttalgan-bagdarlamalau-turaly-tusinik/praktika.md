# Сабақ 9. Практикалық тапсырмалар: класс және объект ұғымдары

## Базалық деңгей

### 1-тапсырма. «Класс па, объект пе?»
Төмендегі ұғымдарды екі бағанға бөл: **класс** (жалпы түр, үлгі) немесе **объект** (нақты дана). Әр объектінің жанына оның класын жаз.

`Қала`, `Алматы`, `Смартфон`, `Менің Samsung Galaxy A54 телефоным`, `Оқушы`, `Айгерім Нұрланқызы`, `Өзен`, `Іле`, `Футбол командасы`, `«Қайрат» ФК`, `Ит`, `Көршінің Бөрібасар деген төбеті`.

### 3-тапсырма. UML диаграммасы
«Мектеп кітапханасы» бағдарламасына арналған `Book` класының UML диаграммасын дәптерге сал: атауы, кемінде 4 атрибут (типімен), кемінде 3 әдіс. Абстракция қағидасын есте сақта: тек кітапханаға қажет деректер.

### 4-тапсырма. Алғашқы класс
`Dog` класын құр: класс атрибуттары `species = "үй иті"` және `legs = 4`. Үш объект жаса, әрқайсысына нүкте арқылы `name` және `breed` (тұқымы) атрибуттарын бер. Әр иттің мәліметін шығар.

```text
Бөрібасар — төбет, үй иті, 4 аяқ
Ақтөс — тазы, үй иті, 4 аяқ
Шарик — дворняга, үй иті, 4 аяқ
```

### 5-тапсырма. «Бәрі — объект»
Төмендегі мәндердің әрқайсысы үшін `type()` нәтижесін және оның бір әдісін қолдану мысалын жаз: `"Python"`, `[3, 1, 2]`, `{"a": 1}`, `{1, 2}`, `3.75`. Кейін `isinstance()` арқылы тексер: `"5"` — `int` па? `[1]` — `list` пе? 4-тапсырмадағы итің — `Dog` па?

## Кеңейтілген деңгей

### 6-тапсырма. Класс атрибутын өзгерту
`Dog` класында `Dog.legs = 3` деп өзгертсек, бұрын жасалған объектілердің `legs` мәні өзгере ме? Ал `bori.legs = 3` деп тек бір объектіде өзгертсек? Тәжірибе жасап, нәтижені түсіндір. (Кеңес: объектінің өз атрибуттарын `vars(bori)` арқылы көр.)

### 7-тапсырма. Процедуралықтан ОБП-ға
Төмендегі сөздік + функция кодын оқып шық. Оны ОБП түрінде қайта жазу үшін **қандай класс** керек, оның **атрибуттары** мен **әдістері** қандай болады — UML диаграммасын сал. (Кодты келесі сабақтарда жазамыз.)

```python
account = {"owner": "Дана", "balance": 15000}


def deposit(acc, amount):
    acc["balance"] += amount


def withdraw(acc, amount):
    if amount <= acc["balance"]:
        acc["balance"] -= amount
    else:
        print("Қаражат жеткіліксіз")


def show(acc):
    print(acc["owner"], acc["balance"], "₸")
```

### 8-тапсырма. Объектілер санауышы
`Robot` класын құр, класс атрибуты `count = 0`. Әр объект жасалғаннан кейін (қолмен) `Robot.count += 1` орында және роботқа `serial` атрибутын `f"R-{Robot.count:03}"` түрінде бер. 5 робот жаса және сериялық нөмірлерін шығар.

```text
R-001 R-002 R-003 R-004 R-005
Барлығы: 5 робот
```

**6-тапсырма**
```python
class Dog:
    legs = 4


bori = Dog()
aktos = Dog()

Dog.legs = 3
print(bori.legs, aktos.legs)   # 3 3 — класс атрибуты өзгерді, бәрі көреді

bori.legs = 5                  # bori-де ЖЕКЕ атрибут пайда болды
print(bori.legs, aktos.legs)   # 5 3
print(vars(bori), vars(aktos)) # {'legs': 5} {}
```
Түсіндірме: Python алдымен объектінің өз атрибуттарынан іздейді, табылмаса — класстан. `bori.legs = 5` класс атрибутын өзгертпейді, объектіге жаңа атрибут қосады.

**8-тапсырма**
```python
class Robot:
    """Роботтар зауыты."""
    count = 0


robots = []
for _ in range(5):
    robot = Robot()
    Robot.count += 1
    robot.serial = f"R-{Robot.count:03}"
    robots.append(robot)

print(" ".join(robot.serial for robot in robots))
print("Барлығы:", Robot.count, "робот")
```
