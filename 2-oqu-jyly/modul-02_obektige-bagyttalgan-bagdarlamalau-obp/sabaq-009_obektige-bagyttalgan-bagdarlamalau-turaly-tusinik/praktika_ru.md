account = {"owner": "Дана", "balance": 15000}

**Задание 6**
```python
class Dog:
    legs = 4


bori = Dog()
aktos = Dog()

Dog.legs = 3
print(bori.legs, aktos.legs)   # 3 3 — атрибут класса изменился, его видят все

bori.legs = 5                  # у bori появился СОБСТВЕННЫЙ атрибут
print(bori.legs, aktos.legs)   # 5 3
print(vars(bori), vars(aktos)) # {'legs': 5} {}
```
Пояснение: Python сначала ищет атрибут среди собственных атрибутов объекта, а если не находит — в классе. `bori.legs = 5` не меняет атрибут класса, а добавляет объекту новый атрибут.

    """Завод роботов."""
    count = 0

    robot = Robot()
