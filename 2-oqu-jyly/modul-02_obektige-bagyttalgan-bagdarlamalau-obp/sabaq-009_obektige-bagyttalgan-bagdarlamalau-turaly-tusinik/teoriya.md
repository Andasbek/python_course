## 1. Бағдарламалау парадигмалары

**Парадигма** — бағдарлама жазудың тәсілі, «ойлау стилі».

| Парадигма | Негізгі идея | Python-дағы құралдар |
|---|---|---|
| Императивтік (тізбекті) | командалар бірінен соң бірі орындалады | меншіктеу, `input`, `print`, `if`, циклдер |
| Процедуралық | бағдарлама функцияларға (процедураларға) бөлінеді | `def`, `return`, модульдер |
| **Объектіге бағытталған (ОБП)** | бағдарлама өзара әрекеттесетін **объектілерден** тұрады | `class`, объектілер, әдістер |
| Функционалдық | бағдарлама — функциялардың композициясы | `map`, `filter`, `lambda` |

Python — **көп парадигмалы** тіл: бір бағдарламада барлық тәсілді біріктіруге болады.

**Объектіге бағытталған бағдарламалау** (ООП, object-oriented programming, OOP) — бағдарламаны **объектілердің** жиынтығы ретінде құру тәсілі; әр объект өз деректерін (күйін) сақтайды және өз әрекеттерін орындай алады.

ОБП-ны қолданатын тілдер: Python, Java, C#, C++, JavaScript, Kotlin, Swift. Tkinter (терезелер мен батырмалар — объектілер), Pygame (спрайттар — объектілер), Pandas (DataFrame — объект) — бәрі ОБП негізінде жасалған.

## 2. Объект деген не?

**Объект** — нақты бір нысанның бағдарламадағы бейнесі. Ол екі нәрседен тұрады:

| | Сұрақ | Бағдарламада | Мысал (телефон) |
|---|---|---|---|
| **Күйі (state)** | «Ол қандай?» | **атрибуттар** (айнымалылар) | маркасы, түсі, заряд деңгейі, нөмірі |
| **Мінез-құлқы (behavior)** | «Ол не істей алады?» | **әдістер** (функциялар) | қоңырау шалу, хабарлама жіберу, зарядталу |

Тағы мысалдар:

| Объект | Атрибуттар | Әдістер |
|---|---|---|
| Мысық Мұрзик | аты, түсі, жасы, тоқтығы | мияулау, ұйықтау, тамақтану |
| Автобус №92 | маршруты, жолаушылар саны, жылдамдығы | жүру, тоқтау, жолаушы алу |
| Банк картасы | иесі, нөмірі, балансы | толтыру, төлеу, балансты көрсету |
| Ойын кейіпкері | аты, денсаулығы, координатасы | жүру, секіру, шабуыл |
| Оқушы | аты, сыныбы, бағалары | баға алу, орташаны есептеу |

Атрибуттар — әдетте **зат есім** (түсі, балансы), әдістер — **етістік** (төлеу, жүру).

## 3. Класс деген не?

**Класс** (класс, class) — бірдей типтегі объектілерді жасауға арналған **үлгі (шаблон, сызба)**. Класс объектінің қандай атрибуттары мен әдістері болатынын сипаттайды, ал **объект** — сол кластың нақты **данасы** (экземпляр, instance).

Аналогиялар:

| Класс | Объектілер |
|---|---|
| Үйдің сызбасы (чертеж) | сол сызба бойынша салынған нақты үйлер |
| Печенье қалыбы | қалыппен кесілген печеньелер |
| «Оқушы» анкетасының бос бланкі | толтырылған анкеталар: Әлия, Бекзат, ... |
| Автомобиль моделі «Toyota Camry» | көшеде жүрген нақты көліктер (әр түрлі түсті, нөмірлі) |

```text
            ┌──────────────────────┐
            │   Класс: Cat         │   ← сызба (бір рет жазамыз)
            │   атрибуттар: name,  │
            │   color, age         │
            │   әдістер: meow(),   │
            │   sleep()            │
            └──────────┬───────────┘
          ┌────────────┼────────────┐
          ▼            ▼            ▼
   ┌────────────┐ ┌────────────┐ ┌────────────┐
   │ Мұрзик     │ │ Ақтабан    │ │ Барсик     │   ← объектілер (даналар)
   │ сұр, 3 жас │ │ ақ, 1 жас  │ │ қара, 5 жас│
   └────────────┘ └────────────┘ └────────────┘
```

Маңызды:
- Бір кластан **қанша болса да** объект жасауға болады.
- Барлық объектінің атрибуттары **бірдей** (бәрінде `name` бар), бірақ **мәндері әртүрлі** (Мұрзик, Ақтабан).
- Әдістер барлық объектіге **ортақ**, бірақ әрқайсысы өз деректерімен жұмыс істейді.

## 4. Python-дағы класс: алғашқы қадам

Класс `class` кілт сөзімен жарияланады. Класс атауы — **PascalCase** (бас әріппен): `Cat`, `BankAccount`, `Student`.

```python
class Cat:
    """Мысықты сипаттайтын класс."""
    pass


murzik = Cat()     # объект (дана) жасау — класты функция сияқты «шақырамыз»
aktaban = Cat()

print(murzik)
print(type(murzik))
print(murzik is aktaban)
```
Нәтижесі (адрестер әр компьютерде әртүрлі):
```text
<__main__.Cat object at 0x7f3a2c1b9d50>
<class '__main__.Cat'>
False
```
`pass` — «әзірге бос» деген белгі. `Cat()` — жаңа объект жасайды; `murzik` пен `aktaban` — **екі бөлек** объект.

### Класс атрибуттары
Класс ішінде жарияланған айнымалылар — **класс атрибуттары**; олар барлық объектіге **ортақ**:

```python
class Cat:
    """Мысықты сипаттайтын класс."""
    species = "үй мысығы"
    legs = 4


murzik = Cat()
aktaban = Cat()
print(murzik.species, murzik.legs)
print(aktaban.species, aktaban.legs)
print(Cat.legs)
```
Нәтижесі:
```text
үй мысығы 4
үй мысығы 4
4
```
Атрибутқа **нүкте** арқылы қатынаймыз: `объект.атрибут`.

### Объектінің жеке атрибуттары (алдын ала қарау)
Әр мысықтың аты әртүрлі. Объектіге атрибутты нүкте арқылы тікелей қосуға болады:

```python
class Cat:
    """Мысықты сипаттайтын класс."""
    legs = 4


murzik = Cat()
murzik.name = "Мұрзик"
murzik.color = "сұр"

aktaban = Cat()
aktaban.name = "Ақтабан"
aktaban.color = "ақ"

print(murzik.name, murzik.color, murzik.legs)
print(aktaban.name, aktaban.color, aktaban.legs)
```
Нәтижесі:
```text
Мұрзик сұр 4
Ақтабан ақ 4
```

Бұл жұмыс істейді, бірақ ыңғайсыз әрі қауіпті: бір объектіге `color` қосуды ұмытсаң — `AttributeError` болады. Сондықтан атрибуттарды объект **жасалған сәтте** автоматты түрде беретін **`__init__` конструкторында** анықтайды.

### Әдіс (алдын ала қарау)
Әдіс — класс ішінде жарияланған функция. Мысал:

```python
class Cat:
    """Мысықты сипаттайтын класс."""

    def meow(self):
        """Мысық мияулайды."""
        print("Мияу!")


murzik = Cat()
murzik.meow()
```
Нәтижесі:
```text
Мияу!
```

## 5. Python-да бәрі — объект

Тіпті ең қарапайым Python бағдарламасы да объектілерді **байқатпай** қолданады:

```python
name = "алматы"
grades = [5, 3, 4]

print(type(name), type(grades), type(5), type(print))
print(name.upper())          # str класының upper() әдісі
grades.append(5)             # list класының append() әдісі
grades.sort()
print(grades)
print(isinstance(name, str), isinstance(grades, dict))
```
Нәтижесі:
```text
<class 'str'> <class 'list'> <class 'int'> <class 'builtin_function_or_method'>
АЛМАТЫ
[3, 4, 5, 5]
True False
```

- `str`, `list`, `dict`, `int` — Python-ның **кірістірілген кластары**.
- `"алматы"` — `str` класының объектісі; `upper()` — оның әдісі.
- `grades.append(5)` — «`grades` объектісі, өзіңе 5-ті қос» деген **хабарлама**.
- `isinstance(объект, Класс)` — объект осы кластың данасы ма, соны тексереді.

`class` арқылы **өз кластарыңды** жасауға болады — яғни Python-ға жаңа типтер қосу.

## 6. Процедуралық және ОБП тәсілдерін салыстыру

| | Процедуралық | Объектіге бағытталған |
|---|---|---|
| Негізгі бірлік | функция | объект (класс) |
| Деректер мен әрекеттер | бөлек | бір объектіде біріктірілген |
| Шақыру | `move(player, 3, 0)` | `player.move(3, 0)` |
| Шағын бағдарламаға | қарапайым, жылдам | артық болуы мүмкін |
| Үлкен жобаға | ретсіз болып кетеді | құрылымды, кеңейтуге оңай |
| Нақты өмірді модельдеу | қиынырақ | табиғи («заттар» және «әрекеттер») |

ОБП стиліндегі ойын кейіпкерінің мысалы (`__init__` және `self` төменде түсіндірілген тақырыптарда толық қарастырылады):
```python
class Player:
    """Ойын кейіпкері."""

    def __init__(self, name, hp, x, y):
        self.name = name
        self.hp = hp
        self.x = x
        self.y = y

    def move(self, dx, dy):
        """Кейіпкерді жылжытады."""
        self.x += dx
        self.y += dy

    def take_damage(self, damage):
        """Денсаулықты азайтады."""
        self.hp -= damage


batyr = Player("Батыр", 100, 0, 0)
naiza = Player("Найза", 80, 5, 2)
batyr.move(3, 0)
naiza.take_damage(15)
print(batyr.name, batyr.x, naiza.name, naiza.hp)
```
Нәтижесі:
```text
Батыр 3 Найза 65
```
Енді деректер мен әрекеттер бірге: `Player` класына қарап, кейіпкердің не білетінін және не істей алатынын бірден көреміз.

## 7. ОБП-нің төрт қағидасы (шолу)

| Қағида | Қысқаша мәні | Өмірлік мысал |
|---|---|---|
| **Инкапсуляция** | деректерді объект ішінде жасырып, тек әдістер арқылы өзгертуге рұқсат беру | банкомат: шотқа тікелей қол жеткізбейсің, тек батырмалар арқылы |
| **Мұрагерлік** | жаңа класс бар кластың қасиеттерін мұраға алады | «Электромобиль» — «Автомобильдің» барлығын біледі + зарядталады |
| **Полиморфизм** | бірдей атаулы әдіс әртүрлі объектілерде әртүрлі жұмыс істейді | «дыбыс шығар» — мысық мияулайды, ит үреді |
| **Абстракция** | маңыздысын ғана қалдырып, артық бөлшектерді жасыру | көлік жүргізуші қозғалтқыштың ішін білмейді — руль мен педаль жеткілікті |

## 8. Класты жобалау: UML класс диаграммасы

Код жазбас бұрын класты **жобалайды**. Бағдарламашылар бұл үшін **UML** (Unified Modeling Language) класс диаграммасын қолданады — үш бөліктен тұратын тіктөртбұрыш:

```text
┌─────────────────────────┐
│        Student          │  ← класс атауы
├─────────────────────────┤
│ name: str               │  ← атрибуттар
│ grade: int              │
│ marks: list             │
├─────────────────────────┤
│ add_mark(mark)          │  ← әдістер
│ average() -> float      │
│ print_info()            │
└─────────────────────────┘
```

Класты жобалау алгоритмі:
1. Нысанды атап ал (зат есім) → класс атауы.
2. «Ол қандай?» → атрибуттар (зат есімдер, сипаттар).
3. «Ол не істей алады? Онымен не істеуге болады?» → әдістер (етістіктер).
4. Тек **бағдарламаға қажет** нәрселерді қалдыр (абстракция!). Мектеп журналына оқушының көзінің түсі керек емес.

## Жиі кездесетін қателер

**1. Класс пен объектіні шатастыру.** «Мұрзик — класс» — қате. `Cat` — класс (үлгі), Мұрзик — объект (дана).

**2. Объект жасағанда жақшаны ұмыту.**
```python
class Cat:
    legs = 4


wrong = Cat      # бұл объект емес, класстың өзіне сілтеме!
right = Cat()    # жаңа объект
print(wrong, right)
```

**3. Класс атауын кіші әріппен жазу.** `class cat:` — жұмыс істейді, бірақ PEP 8 бойынша дұрысы `class Cat:`.

**4. Жоқ атрибутқа қатынау.**
```python
class Cat:
    legs = 4


murzik = Cat()
# print(murzik.name)   # AttributeError: 'Cat' object has no attribute 'name'
murzik.name = "Мұрзик"
print(murzik.name)
```

**5. Шегіністі ұмыту.** Класс денесі (атрибуттар, әдістер) `class` жолынан кейін 4 бос орынмен ішке жылжиды.

**6. Әр нәрсеге класс жасау.** Екі санды қосу үшін класс керек емес. ОБП — деректер мен әрекеттер тығыз байланысқан нысандарға арналған.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Парадигма | Бағдарлама жазу тәсілі |
| ОБП (OOP) | Бағдарламаны объектілерден құру парадигмасы |
| Класс | Объектілер жасауға арналған үлгі (сызба) |
| Объект (дана, экземпляр) | Класс бойынша жасалған нақты нысан |
| Атрибут | Объектінің қасиеті (айнымалысы) |
| Әдіс (метод) | Объектінің әрекеті (класс ішіндегі функция) |
| Күй (state) | Объект атрибуттарының ағымдағы мәндері |
| Класс атрибуты | Барлық объектіге ортақ атрибут |
| `isinstance()` | Объектінің берілген класқа жататынын тексеру |
| UML диаграммасы | Класты сызбамен жобалау тәсілі |

## Ескерту

- Python 3-те барлық кластар `object` класынан жасырын түрде мұра алады, сондықтан `class Cat:` пен `class Cat(object):` бірдей. `(object)` жазуы Python 2-ге арналған ескі кодта кездеседі.
- Өзгермелі объектіні (мысалы, тізімді) сақтайтын класс атрибуты барлық данаға ортақ: `class Cat: toys = []` — бір мысыққа ойыншық қосу оны бәріне «қосады». Өзгермелі деректерді `__init__` ішінде жасайды.
- `dir(obj)` кірістірілген функциясы объектінің барлық атрибуттары мен әдістерін, ал `vars(obj)` (немесе `obj.__dict__`) — дананың тек өз атрибуттарын көрсетеді.
- `type(obj) is Cat` класстың дәл сәйкестігін тексереді, ал `isinstance(obj, Cat)` ұрпақ кластарды да ескереді — көбінесе `isinstance` қолайлырақ.
- Кластар туралы ресми нұсқаулық: https://docs.python.org/3/tutorial/classes.html.
