## 1. Полиморфизм дегеніміз не?

**Полиморфизм (полиморфизм, polymorphism)** — грекше «көп пішінділік». Бағдарламалауда: **бірдей атаулы әрекет әртүрлі объектілерде әртүрлі орындалады**, ал оны шақыратын код бірдей болып қалады.

Өмірлік аналогия: «Ойнат» (▶) батырмасы. Оны теледидарда басасыз — фильм басталады, музыкалық колонкада — ән ойнайды, ойын консолінде — ойын жүреді. Батырма бір, әрекет — құрылғыға байланысты.

### Python-да полиморфизм бізді бұрыннан қоршап тұр

```python
print(len("Алматы"))          # жолдың ұзындығы
print(len([1, 2, 3]))         # тізім элементтерінің саны
print(len({"a": 1, "b": 2}))  # сөздіктегі кілттер саны

print(5 + 3)                  # сандарды қосу
print("Сәлем, " + "әлем")     # жолдарды біріктіру
print([1, 2] + [3])           # тізімдерді біріктіру
```

Нәтижесі:
```text
6
3
2
8
Сәлем, әлем
[1, 2, 3]
```

`len()` функциясы мен `+` операторы — бір, бірақ объектінің типіне қарай әртүрлі жұмыс істейді. Бұл — полиморфизм.

## 2. Кластардағы полиморфизм

Кластардағы полиморфизм әдістерді қайта анықтауға (override) негізделеді: ата-класта жалпы әдіс, ұрпақтарда — өз нұсқасы. Сосын бәрін **бір циклде** өңдейміз:

```python
class Shape:
    def __init__(self, name):
        self.name = name

    def area(self):
        return 0


class Rectangle(Shape):
    def __init__(self, a, b):
        super().__init__("Тіктөртбұрыш")
        self.a = a
        self.b = b

    def area(self):
        return self.a * self.b


class Circle(Shape):
    def __init__(self, r):
        super().__init__("Шеңбер")
        self.r = r

    def area(self):
        return round(3.14159 * self.r ** 2, 2)


class Triangle(Shape):
    def __init__(self, a, h):
        super().__init__("Үшбұрыш")
        self.a = a
        self.h = h

    def area(self):
        return self.a * self.h / 2


shapes = [Rectangle(4, 5), Circle(3), Triangle(6, 4)]
total = 0
for s in shapes:
    print(f"{s.name}: ауданы = {s.area()}")
    total += s.area()
print("Жалпы аудан:", round(total, 2))
```

Нәтижесі:
```text
Тіктөртбұрыш: ауданы = 20
Шеңбер: ауданы = 28.27
Үшбұрыш: ауданы = 12.0
Жалпы аудан: 60.27
```

**Маңызды:** цикл ішіндегі код фигураның түрін **тексермейді** (`if` жоқ!). Жаңа фигура (мысалы, `Square`) қоссақ, циклді өзгертудің қажеті жоқ. Бұл — полиморфизмнің басты пайдасы.

### Полиморфизмсіз қалай болар еді?

```python
shapes = [("rect", 4, 5), ("circle", 3), ("tri", 6, 4)]
for s in shapes:
    if s[0] == "rect":
        print(s[1] * s[2])
    elif s[0] == "circle":
        print(round(3.14159 * s[1] ** 2, 2))
    elif s[0] == "tri":
        print(s[1] * s[2] / 2)
```

Әр жаңа фигура үшін `elif` қосу керек — код ұзарып, қате көбейеді.

## 3. Полиморфты функция

Бір функция кез келген «фигураны» қабылдай алады:

```python
class Dog:
    def speak(self):
        return "Ау-ау"

class Cat:
    def speak(self):
        return "Мяу"

class Cow:
    def speak(self):
        return "Мөө"

def concert(animals):
    for a in animals:
        print(type(a).__name__, "->", a.speak())

concert([Dog(), Cat(), Cow()])
```

Нәтижесі:
```text
Dog -> Ау-ау
Cat -> Мяу
Cow -> Мөө
```

Назар аударыңыз: бұл кластардың **ортақ ата-класы жоқ**! Python үшін ең бастысы — объектіде `speak()` әдісі болуы.

## 4. «Үйрек типтеу» (duck typing)

> «Егер ол үйрек сияқты жүрсе және үйрек сияқты барылдаса — демек ол үйрек».

Python объектінің типін емес, оның **не істей алатынын** қарайды. Бұл — **үйрек типтеу (утиная типизация, duck typing)**.

```python
class Duck:
    def swim(self):
        print("Үйрек жүзіп жүр")

class Robot:
    def swim(self):
        print("Су асты роботы жүзіп жүр")

class Stone:
    pass

def go_swimming(obj):
    if hasattr(obj, "swim"):
        obj.swim()
    else:
        print(f"{type(obj).__name__} жүзе алмайды :(")

for thing in [Duck(), Robot(), Stone()]:
    go_swimming(thing)
```

Нәтижесі:
```text
Үйрек жүзіп жүр
Су асты роботы жүзіп жүр
Stone жүзе алмайды :(
```

`hasattr(obj, "atau")` — объектіде осындай атрибут/әдіс бар-жоғын тексереді.

## 5. Абстракция

**Абстракция (абстракция, abstraction)** — объектінің маңызды қасиеттерін ғана бөліп алып, ұсақ бөлшектерін жасыру. Біз көлікті айдағанда руль, педаль, тежегішті білеміз, бірақ қозғалтқыштың ішін білмейміз — бұл абстракция.

Бағдарламада абстракция — «**не істеу керек**» екенін анықтау, ал «**қалай істеу керек**» екенін нақты кластарға қалдыру.

Мысалы, «Фигура» — абстрактілі ұғым. «Жай фигураның» ауданын есептеу мүмкін емес — тек нақты шеңбердің, шаршының ауданы бар. Сондықтан `Shape()` объектісін құрудың мағынасы жоқ.

### abc модулі: абстрактілі класс

Python-да абстрактілі класс `abc` (Abstract Base Classes) модулімен жасалады:

```python
from abc import ABC, abstractmethod


class Shape(ABC):                 # абстрактілі класс
    @abstractmethod
    def area(self):
        pass                      # іске асыру жоқ — тек «келісім»

    @abstractmethod
    def perimeter(self):
        pass

    def info(self):               # кәдімгі әдіс те болуы мүмкін
        print(f"Ауданы: {self.area()}, периметрі: {self.perimeter()}")


class Square(Shape):
    def __init__(self, a):
        self.a = a

    def area(self):
        return self.a ** 2

    def perimeter(self):
        return 4 * self.a


sq = Square(5)
sq.info()

try:
    s = Shape()
except TypeError as e:
    print("Қате:", e)
```

Нәтижесі:
```text
Ауданы: 25, периметрі: 20
Қате: Can't instantiate abstract class Shape without an implementation for abstract methods 'area', 'perimeter'
```

(Python 3.10–3.11 нұсқаларында қате мәтіні сәл өзгеше: `... with abstract methods area, perimeter`.)

Ережелер:
- `ABC`-тен мұра алған және `@abstractmethod` әдісі бар класстың **объектісін құруға болмайды**;
- ұрпақ класс **барлық** абстрактілі әдістерді іске асыруы тиіс, әйтпесе оның да объектісі құрылмайды;
- абстрактілі класс — ұрпақтарға арналған «келісімшарт» (интерфейс): «Сендерде міндетті түрде `area()` пен `perimeter()` болуы керек».

```python
from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class Kaspi(Payment):
    def pay(self, amount):
        print(f"Kaspi QR арқылы {amount} тг төленді")

class Cash(Payment):
    def pay(self, amount):
        print(f"Қолма-қол {amount} тг төленді")

class Card(Payment):
    pass     # pay жазуды ұмыттық!

for method in [Kaspi(), Cash()]:
    method.pay(1500)

try:
    Card()
except TypeError:
    print("Card класы pay әдісін іске асырмаған!")
```

Нәтижесі:
```text
Kaspi QR арқылы 1500 тг төленді
Қолма-қол 1500 тг төленді
Card класы pay әдісін іске асырмаған!
```

Абстрактілі класс қатені **ертерек** — объект құрған сәтте-ақ көрсетеді.

## 6. ОБП-ның төрт принципі — жалпы шолу

| Принцип | Мәні | Python-дағы құралы | Аналогия |
|---|---|---|---|
| Инкапсуляция | Деректерді жасыру, тек әдіс арқылы қол жеткізу | `_attr`, `__attr`, `@property` | Банкомат: ақшаны тек карта арқылы аласың |
| Мұрагерлік | Ата-кластың мүмкіндіктерін қайта пайдалану | `class B(A):`, `super()` | Бала ата-анадан қасиет алады |
| Полиморфизм | Бір интерфейс — әртүрлі іске асыру | override, duck typing | «Ойнат» батырмасы |
| Абстракция | Маңыздысын ғана көрсету, бөлшекті жасыру | `ABC`, `@abstractmethod` | Көлік айдау: қозғалтқышты білмей-ақ |

## Жиі кездесетін қателер

**1. Полиморфизм орнына `if type(...)` тексерістерін жазу**

```python
class Dog:
    pass

class Cat:
    pass

def speak(animal):
    if type(animal) == Dog:
        print("Ау-ау")
    elif type(animal) == Cat:
        print("Мяу")

speak(Dog())
```

Дұрысы — әр класқа `speak()` әдісін жазып, жай ғана `animal.speak()` шақыру.

**2. Ұрпақта әдіс атын басқаша жазу** — `area` орнына `get_area`. Сонда ортақ цикл ата-кластың нұсқасын шақырады немесе `AttributeError` береді.

**3. Абстрактілі класстың объектісін құру** — `Shape()` → `TypeError`. Тек нақты ұрпақ кластардың объектілерін құрамыз.

**4. `@abstractmethod` декораторын қойып, `ABC`-тен мұра алмау**

```python
from abc import abstractmethod

class Shape:              # ABC жоқ — тексеріс жұмыс істемейді!
    @abstractmethod
    def area(self):
        pass

s = Shape()               # қате шықпайды
print("Объект құрылды, бірақ бұл дұрыс емес")
```

Дұрысы: `class Shape(ABC):`.

**5. Абстрактілі әдістердің бәрін іске асырмау** — бір әдіс қалса да, ұрпақ класс та абстрактілі болып қалады.

## Негізгі ұғымдар

| Ұғым | Түсіндірмесі |
|---|---|
| Полиморфизм | Бір атаулы әрекеттің әр объектіде өзінше орындалуы |
| Duck typing | Типке емес, объектінің әдістері бар-жоғына қарау |
| `hasattr(obj, "x")` | Объектіде `x` атрибуты бар-жоғын тексеру |
| Абстракция | Маңызды қасиеттерді бөліп алу, ұсақ бөлшекті жасыру |
| Абстрактілі класс | Объектісі құрылмайтын, ұрпақтарға үлгі болатын класс |
| `ABC`, `@abstractmethod` | `abc` модуліндегі абстрактілі класс пен абстрактілі әдіс құралдары |
| Интерфейс | Класта міндетті түрде болуы тиіс әдістер жиыны |

## Ескерту

- `type(obj) == Class` орнына `isinstance(obj, Class)` жақсырақ: `isinstance` мұрагерлікті ескереді (ұрпақ кластың объектісі ата-кластың данасы болып та саналады).
- Абстракті әдісте әдепкі іске асыру болуы мүмкін — ұрпақ оны міндетті түрде қайта анықтайды, бірақ бастапқы нұсқаны `super()` арқылы шақыра алады.
- `@abstractmethod` декораторы `@property`, `@classmethod`, `@staticmethod`-пен бірге қолданылады; бұл жағдайда `@abstractmethod` **ең төменде** (`def`-ке жақын) жазылады.
- `collections.abc` модулінде дайын абстракті кластар бар: `Iterable`, `Sized`, `Sequence`, `Mapping` т.б.
- Статикалық тексерісі бар үйрек типтеу үшін `typing.Protocol` (Python 3.8+) бар: класта керекті әдістер болса жеткілікті, мұрагерлік талап етілмейді.
- Құжаттама: https://docs.python.org/3/library/abc.html
