## 1. Конструктор `__init__`

**Конструктор** (инициализатор) — специальный метод, который **автоматически** вызывается в момент создания объекта. В Python его имя — `__init__` (по два подчёркивания с каждой стороны: «дандер init», double underscore).

Аналогия: когда в роддоме рождается малыш, ему сразу надевают браслет с именем, датой рождения и весом. `__init__` — это и есть процедура «надевания браслета».

```python
class Cat:
    """Класс, описывающий кошку."""

    def __init__(self, name, color, age):
        self.name = name
        self.color = color
        self.age = age


murzik = Cat("Мурзик", "серый", 3)
barsik = Cat("Барсик", "чёрный", 5)

print(murzik.name, murzik.color, murzik.age)
print(barsik.name, barsik.color, barsik.age)
```
Результат:
```text
Мурзик серый 3
Барсик чёрный 5
```

### Что происходит? По шагам
Когда выполняется строка `murzik = Cat("Мурзик", "серый", 3)`:
1. Python создаёт новый пустой объект `Cat`.
2. Вызывает метод `__init__`: `self` — этот новый объект, `name = "Мурзик"`, `color = "серый"`, `age = 3`.
3. `self.name = name` — записывает значение параметра в атрибут `name` **объекта**.
4. Готовый объект присваивается переменной `murzik`.

```text
Cat("Мурзик", "серый", 3)
        │
        ▼
 ┌──────────────────┐     __init__(self, name, color, age)
 │ новый пустой     │ ──► self.name  = "Мурзик"
 │ объект           │     self.color = "серый"
 └──────────────────┘     self.age   = 3
        │
        ▼
 murzik ──► ┌──────────────────────┐
            │ name  = "Мурзик"     │
            │ color = "серый"      │
            │ age   = 3            │
            └──────────────────────┘
```

### Что такое `self`? (кратко)
`self` означает «сам этот объект». Конструктор общий для всех кошек, а через `self` он знает, **какой именно кошке** записывает атрибуты: при создании `murzik` `self` — это `murzik`, при создании `barsik` — `barsik`.

- `self` — **первый** параметр метода, при вызове его **не передают**: `Cat("Мурзик", "серый", 3)` — три аргумента, а в `__init__` четыре параметра.
- `self.name` — атрибут объекта (хранится, пока существует объект).
- `name` (без self) — просто параметр, локальная переменная (исчезает после завершения `__init__`).

Точно так же `self` работает в методах: первый параметр любого метода — объект, у которого метод вызван.

## 2. Параметры конструктора

### Значения по умолчанию
Как и в функциях, параметрам можно задавать значения по умолчанию:

```python
class Student:
    """Учащийся кружка."""

    def __init__(self, name, grade, city="Алматы"):
        self.name = name
        self.grade = grade
        self.city = city


aliya = Student("Алия", 8)
bekzat = Student("Бекзат", 9, "Конаев")
dana = Student(name="Дана", grade=7)      # именованные аргументы

for s in [aliya, bekzat, dana]:
    print(f"{s.name}, {s.grade} класс, {s.city}")
```
Результат:
```text
Алия, 8 класс, Алматы
Бекзат, 9 класс, Конаев
Дана, 7 класс, Алматы
```

### Атрибуты, не получаемые из параметров
Не все атрибуты обязаны приходить из параметров. Некоторые начинаются с начального значения:

```python
class Student:
    """Учащийся кружка."""

    def __init__(self, name, grade):
        self.name = name
        self.grade = grade
        self.marks = []          # оценки — начинаются с пустого списка
        self.is_active = True    # новый ученик активен
        self.points = 0


aliya = Student("Алия", 8)
aliya.marks.append(5)
aliya.marks.append(4)
aliya.points += 10
print(aliya.name, aliya.marks, aliya.points, aliya.is_active)
```
Результат:
```text
Алия [5, 4] 10 True
```

Важно: `self.marks = []` находится **внутри** конструктора — поэтому у каждого ученика будет **свой** список.

### Вычисляемые атрибуты
Внутри конструктора можно вычислять значения из других атрибутов:

```python
class Rectangle:
    """Прямоугольник."""

    def __init__(self, width, height):
        self.width = width
        self.height = height
        self.area = width * height
        self.perimeter = 2 * (width + height)
        self.is_square = width == height


r = Rectangle(4, 6)
print(r.area, r.perimeter, r.is_square)
```
Результат:
```text
24 20 False
```
Внимание: если потом изменить `r.width = 10`, `r.area` автоматически **не обновится** (она вычислена один раз). Эту проблему решают, вычисляя площадь в методе или с помощью декоратора `property`.

### Проверка начальных значений
Конструктор может гарантировать «правильное» рождение объекта:

```python
class BankAccount:
    """Банковский счёт."""

    def __init__(self, owner, balance=0):
        if balance < 0:
            print("Начальный баланс не может быть отрицательным, установлен 0")
            balance = 0
        self.owner = owner.strip().title()
        self.balance = balance


acc = BankAccount("  дана серикказы ", -500)
print(acc.owner, acc.balance)
```
Результат:
```text
Начальный баланс не может быть отрицательным, установлен 0
Дана Серикказы 0
```
(В профессиональных программах в таком случае вместо сообщения «выбрасывается» ошибка: `raise ValueError("Баланс не может быть отрицательным")` — тогда некорректный объект вообще не создаётся.)

## 3. Атрибуты объекта и атрибуты класса

| | Атрибут объекта | Атрибут класса |
|---|---|---|
| Где объявляется | внутри `__init__`, `self.x = ...` | в теле класса, вне методов |
| Кому принадлежит | только этому объекту | общий для всех объектов |
| Пример | `self.name`, `self.age` | `species = "домашняя кошка"`, `count = 0` |
| Доступ | `murzik.name` | `Cat.species` или `murzik.species` |

```python
class Student:
    """Учащийся кружка."""
    club = "Кружок Python"       # атрибут класса — общий для всех
    count = 0                    # количество созданных учеников

    def __init__(self, name, grade):
        self.name = name         # атрибуты объекта
        self.grade = grade
        Student.count += 1       # изменение атрибута класса — через имя класса!
        self.student_id = Student.count


a = Student("Алия", 8)
b = Student("Бекзат", 9)
print(a.club, b.club)
print(a.student_id, b.student_id, Student.count)
```
Результат:
```text
Кружок Python Кружок Python
1 2 2
```

Как Python ищет атрибут: сначала среди собственных атрибутов **объекта**, если не находит — в **классе**. Поэтому `a.club` работает, но если написать `a.club = "..."`, у `a` появится собственный атрибут, а атрибут класса не изменится.

## 4. Работа с атрибутами

### Чтение и изменение
```python
class Phone:
    """Смартфон."""

    def __init__(self, brand, model, battery=100):
        self.brand = brand
        self.model = model
        self.battery = battery


my_phone = Phone("Samsung", "Galaxy A54")
print(my_phone.battery)
my_phone.battery -= 35          # изменение
my_phone.model = "Galaxy A55"   # замена
print(my_phone.model, my_phone.battery)
```
Результат:
```text
100
Galaxy A55 65
```

### Заглянуть внутрь объекта: `vars()` и `__dict__`
```python
print(vars(my_phone))
print(my_phone.__dict__)
```
Результат:
```text
{'brand': 'Samsung', 'model': 'Galaxy A55', 'battery': 65}
{'brand': 'Samsung', 'model': 'Galaxy A55', 'battery': 65}
```
Внутри атрибуты объекта — это словарь! Так ООП связано со словарями. В отладчике VS Code атрибуты объекта видны точно так же.

### Динамическая работа с атрибутами
```python
print(hasattr(my_phone, "color"))        # есть ли атрибут?
print(getattr(my_phone, "color", "неизвестно"))
setattr(my_phone, "color", "чёрный")
print(my_phone.color)
```
Результат:
```text
False
неизвестно
чёрный
```
Правило: все атрибуты лучше объявлять **внутри `__init__`** — тогда, глядя на класс, сразу видно, что есть у объекта. `setattr` и добавление новых атрибутов снаружи класса — только в особых случаях.

## 5. Объекты раздельны, но будь внимателен со ссылками

```python
class Cat:
    """Кошка."""

    def __init__(self, name):
        self.name = name


a = Cat("Мурзик")
b = a                 # НЕ новый объект — второе имя того же объекта
b.name = "Барсик"
print(a.name)         # Барсик!

c = Cat("Мурзик")
d = Cat("Мурзик")
print(c is d, c.name == d.name)
```
Результат:
```text
Барсик
False True
```
- `b = a` — две «наклейки» на одном объекте (как со списками).
- Два объекта с одинаковыми атрибутами — всё равно **два разных** объекта (`is` → `False`).

## 6. Объект внутри объекта (композиция — первое знакомство)

Значением атрибута может быть любой тип — список, словарь и даже **объект другого класса**:

```python
class Engine:
    """Двигатель."""

    def __init__(self, power, fuel):
        self.power = power      # лошадиные силы
        self.fuel = fuel


class Car:
    """Автомобиль."""

    def __init__(self, brand, engine):
        self.brand = brand
        self.engine = engine    # атрибут — объект Engine


car = Car("Toyota", Engine(181, "бензин"))
print(car.brand, car.engine.power, car.engine.fuel)
```
Результат:
```text
Toyota 181 бензин
```
«У автомобиля **есть** двигатель» — это **композиция**. Так же строятся и коллекции объектов: «в библиотеке есть книги» — атрибут со списком объектов `Book`.

## 7. От проектирования класса к коду

UML:
```text
┌────────────────────────────┐
│           Book             │
├────────────────────────────┤
│ title: str                 │
│ author: str                │
│ year: int                  │
│ pages: int                 │
│ is_available: bool = True  │
└────────────────────────────┘
```
Код:
```python
class Book:
    """Книга библиотеки."""

    def __init__(self, title, author, year, pages):
        self.title = title
        self.author = author
        self.year = year
        self.pages = pages
        self.is_available = True


books = [
    Book("Путь Абая", "Мухтар Ауэзов", 1942, 480),
    Book("Кочевники", "Ильяс Есенберлин", 1976, 960),
]
for book in books:
    status = "в наличии" if book.is_available else "выдана"
    print(f"«{book.title}» — {book.author}, {book.year} г., {book.pages} стр. ({status})")
```
Результат:
```text
«Путь Абая» — Мухтар Ауэзов, 1942 г., 480 стр. (в наличии)
«Кочевники» — Ильяс Есенберлин, 1976 г., 960 стр. (в наличии)
```

## Частые ошибки

**1. Ошибка в имени `__init__`** (`__int__`, `_init_`, `__init`). Python не распознаёт его как конструктор:
```text
TypeError: Cat() takes no arguments
```
Правильно: по **два** подчёркивания с каждой стороны — `__init__`.

**2. Забыли `self`.**
```python
class Cat:
    def __init__(self, name):
        name = name          # атрибут не создан! просто локальная переменная


class CatFixed:
    def __init__(self, name):
        self.name = name     # правильно
```
`Cat("Мурзик").name` → `AttributeError: 'Cat' object has no attribute 'name'`.

**3. Не указан параметр `self` в определении `__init__`.**
```text
def __init__(name):  →  TypeError: Cat.__init__() takes 1 positional argument but 2 were given
```

**4. Несоответствие количества аргументов.**
```text
Cat("Мурзик")  →  TypeError: Cat.__init__() missing 2 required positional arguments: 'color' and 'age'
```

**5. Возврат значения из `__init__`.** Конструктор не должен возвращать значение через `return` (кроме `None`) — `TypeError: __init__() should return None`.

**6. Объявление изменяемого значения как атрибута класса.**
```python
class Student:
    marks = []               # ОШИБКА: ОБЩИЙ список для всех учеников!

    def __init__(self, name):
        self.name = name


a = Student("Алия")
b = Student("Бекзат")
a.marks.append(5)
print(b.marks)               # [5] — Бекзату тоже «поставили оценку»
```
Правильно: `self.marks = []` — внутри `__init__`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Конструктор (`__init__`) | Метод, автоматически вызываемый при создании объекта |
| `self` | Внутри метода — «сам этот объект» |
| Атрибут объекта | `self.x` — значение, принадлежащее только этому объекту |
| Атрибут класса | Значение, объявленное в теле класса, общее для всех объектов |
| Инициализация | Установка начального состояния объекта |
| Значение по умолчанию | Значение, используемое, если аргумент не передан |
| `vars()` / `__dict__` | Словарь атрибутов объекта |
| Композиция | Наличие другого объекта в качестве атрибута объекта |

## Примечание

- `__init__` не создаёт объект, а только настраивает (инициализирует) его. Создаёт объект метод `__new__`; переопределять его приходится очень редко.
- Для классов, которые в основном хранят данные, удобен модуль `dataclasses` (Python 3.7+): декоратор `@dataclass` автоматически создаёт `__init__`, `__repr__` и `__eq__`. Документация: https://docs.python.org/3/library/dataclasses.html.
- Не используй изменяемый объект как значение по умолчанию: `def __init__(self, marks=[])` — список окажется общим для всех объектов. Правильно: `marks=None`, а внутри `self.marks = marks if marks is not None else []`.
- `print(obj)` по умолчанию выводит `<__main__.Cat object at 0x...>`. Для понятного текста в класс добавляют метод `__str__` или `__repr__`.
- По PEP 8 все атрибуты рекомендуется объявлять в `__init__` — Pylance и другие анализаторы могут предупреждать об атрибутах, созданных вне `__init__`.
