## 1. Что такое портфолио и почему важен GitHub?

**Портфолио** — собрание работ программиста. При поступлении в университет, на олимпиаде, при трудоустройстве профиль GitHub — ваше «электронное резюме». Каждый проект должен:
- иметь понятное название,
- быть описан в README,
- иметь чистую структуру,
- иметь осмысленную историю (коммиты).

## 2. Структура репозитория проекта

```text
school-journal/
├── README.md            # описание проекта
├── .gitignore           # файлы, которые Git не отслеживает
├── main.py              # точка входа программы
├── models.py            # классы (Student, ClassJournal ...)
├── data/
│   └── journal.json     # данные (при необходимости)
└── screenshots/
    └── demo.png         # скриншот работы
```

Если вынести классы в отдельный файл, в `main.py` их импортируем:

```python
# main.py
# from models import Student, ClassJournal   # когда файл models.py лежит рядом


def main():
    print("Школьный журнал запущен")


if __name__ == "__main__":
    main()
```

`if __name__ == "__main__":` — `main()` выполняется только при прямом запуске файла, а при импорте в другой файл — нет.

## 5. Команды загрузки

```bash
cd school-journal
git init
git add .
git commit -m "Мини-проект по ООП: Школьный журнал"
git branch -M main
git remote add origin https://github.com/<логин>/school-journal.git
git push -u origin main
```

Если репозиторий уже существует, только:

```bash
git add .
git commit -m "Добавлены README и .gitignore"
git push
```

## 6. Проверка проекта перед публикацией

Перед `git push` полезно убедиться, что в репозиторий попадёт именно то, что нужно:

```bash
git status            # какие файлы изменены и какие будут закоммичены
git diff              # что именно изменилось в коде
git log --oneline     # краткая история коммитов
python main.py        # программа запускается без ошибок
```

Контрольный список:
- `README.md` описывает назначение проекта, возможности и команду запуска;
- `.gitignore` исключает `__pycache__/`, `venv/`, настройки редактора;
- в коде нет паролей, токенов и личных данных;
- тестовый код спрятан в `if __name__ == "__main__":`;
- имена файлов, классов и функций соответствуют PEP 8 (`models.py`, `ClassJournal`, `add_grade`).

## 7. Шпаргалка по ООП

| Тема | Синтаксис | Суть |
|---|---|---|
| Класс и объект | `class A:`, `a = A()` | Класс — шаблон, объект — экземпляр |
| Конструктор | `def __init__(self, ...)` | Заполняет атрибуты нового объекта |
| Атрибуты | `self.x` / `A.x` | Атрибут объекта / атрибут класса |
| Инкапсуляция | `_x`, `__x`, `@property` | Сокрытие данных, доступ через методы |
| Наследование | `class B(A):` | B получает атрибуты и методы A |
| Override, `super()` | `def m(self): super().m()` | Замена или расширение метода родителя |
| Полиморфизм | один вызов `obj.m()` | Каждый класс выполняет `m` по-своему |
| Абстракция | `ABC`, `@abstractmethod` | Класс-«договор», объект не создаётся |
| Магические методы | `__str__`, `__repr__`, `__len__`, `__eq__` | Поддержка `print`, `len`, `==` |

Все темы в одном примере:

```python
from abc import ABC, abstractmethod


class Person(ABC):                        # абстрактный класс
    count = 0                             # атрибут класса

    def __init__(self, name):             # конструктор
        self.name = name                  # атрибут объекта
        Person.count += 1

    @abstractmethod
    def role(self):                       # абстрактный метод
        pass

    def __str__(self):                    # магический метод
        return f"{self.role()} {self.name}"


class Student(Person):                    # наследование
    def __init__(self, name, grade):
        super().__init__(name)            # вызов родителя
        self._grade = grade               # «защищённый» атрибут

    @property
    def grade(self):                      # инкапсуляция: только чтение
        return self._grade

    def role(self):                       # переопределение (override)
        return "Ученик"


class Teacher(Person):
    def role(self):
        return "Преподаватель"


people = [Student("Ару", 8), Teacher("Сауле")]
for p in people:                          # полиморфизм
    print(p)
print("Создано объектов:", Person.count)
```

Результат:
```text
Ученик Ару
Преподаватель Сауле
Создано объектов: 2
```

## Частые ошибки

**1. Загрузка папки `venv` или `__pycache__` в репозиторий** — создавайте файл `.gitignore` **до** push. Если всё же загрузилось:

```bash
git rm -r --cached venv
git commit -m "venv удалён из репозитория"
git push
```

**2. README отсутствует или пустой** — проект на GitHub будет непонятен.

**3. Всё в одном коммите** — весь проект внутри «Initial commit». Делайте коммиты часто в процессе работы.

**4. Код выполняется при импорте**

```python
# в models.py:
class Student:
    def __init__(self, name):
        self.name = name

print("Тест:", Student("Ару").name)   # выводится и при импорте!
```

Исправление: поместить тестовый код в блок `if __name__ == "__main__":`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Портфолио | Собрание работ программиста (профиль GitHub) |
| README.md | Markdown-файл с описанием проекта |
| .gitignore | Список файлов, которые Git не отслеживает |
| `if __name__ == "__main__":` | Блок, выполняемый только при прямом запуске файла |
| `git status` | Показывает изменённые и подготовленные к коммиту файлы |

## Примечание

- `.gitignore` не действует на файлы, которые **уже** добавлены в репозиторий: их сначала убирают из индекса командой `git rm --cached`.
- GitHub не принимает обычный пароль при `git push` по HTTPS — нужен personal access token или SSH-ключ.
- Сторонние библиотеки проекта перечисляют в `requirements.txt` (`pip freeze > requirements.txt`), установка: `pip install -r requirements.txt`.
- Готовый шаблон для Python-проектов: файл `Python.gitignore` в репозитории https://github.com/github/gitignore.
- В README блоки кода оформляют тройными обратными кавычками с указанием языка (```` ```python ````) — GitHub подсвечивает синтаксис.
- Команда запуска зависит от системы: в Windows обычно `python main.py` или `py main.py`, в Linux/macOS — `python3 main.py`.
