## 1. Создание игрового окна

```python
screen = pygame.display.set_mode((ширина, высота), флаги)
```

`set_mode` возвращает нам объект **Surface** (поверхность, холст) — это «бумага», на которой мы рисуем. Размер окна задаётся в пикселях.

| Популярные размеры | Соотношение | Применение |
|---|---|---|
| 640 × 480 | 4:3 | Старые игры, упражнения |
| 800 × 600 | 4:3 | Учебные игры |
| 1280 × 720 | 16:9 | HD, современные игры |
| 1920 × 1080 | 16:9 | Full HD, полноэкранный режим |

**Методы настройки окна:**

| Метод | Что делает |
|---|---|
| `pygame.display.set_caption("Название")` | Заголовок окна |
| `pygame.display.set_icon(surface)` | Значок окна (картинка 32×32) |
| `screen.get_width()`, `screen.get_height()` | Ширина и высота окна |
| `screen.get_size()` | Кортеж `(ширина, высота)` |
| `pygame.display.Info()` | Информация о мониторе (`current_w`, `current_h`) |

**Режимы окна (флаги):**

| Флаг | Значение |
|---|---|
| `pygame.RESIZABLE` | Размер окна можно менять мышью |
| `pygame.FULLSCREEN` | Полноэкранный режим |
| `pygame.NOFRAME` | Окно без рамки |
| `pygame.SCALED` | Масштабирование маленького окна под экран |

```python
import pygame

WIDTH, HEIGHT = 800, 600          # константы пишутся заглавными буквами

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT), pygame.RESIZABLE)
pygame.display.set_caption("Космическое путешествие")

icon = pygame.Surface((32, 32))   # поверхность 32×32 для значка
icon.fill((255, 200, 0))
pygame.display.set_icon(icon)

info = pygame.display.Info()
print("Монитор:", info.current_w, "x", info.current_h)
print("Окно:", screen.get_size())

clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.VIDEORESIZE:
            print("Новый размер:", event.w, event.h)
    screen.fill((10, 10, 40))
    pygame.display.flip()
    clock.tick(60)
pygame.quit()
```

Результат (пример):
```text
Монитор: 1920 x 1080
Окно: (800, 600)
Новый размер: 912 650
```

Выносить размер окна в **константы** (`WIDTH`, `HEIGHT`) — хорошая привычка: изменив размер в одном месте, мы подстроим под него всю игру.

## 2. Цвета: модель RGB

Каждый пиксель на экране состоит из трёх источников света: **Красный (Red)**, **Зелёный (Green)**, **Синий (Blue)**. Яркость каждой компоненты — от 0 до 255. Поэтому цвет — это кортеж из трёх чисел `(R, G, B)`.

**Аналогия:** три цветных фонарика в тёмной комнате. Если включить все три на полную мощность — белый свет, если выключить все — темнота (чёрный).

| Цвет | RGB | Цвет | RGB |
|---|---|---|---|
| Чёрный | `(0, 0, 0)` | Белый | `(255, 255, 255)` |
| Красный | `(255, 0, 0)` | Жёлтый | `(255, 255, 0)` |
| Зелёный | `(0, 255, 0)` | Голубой (циан) | `(0, 255, 255)` |
| Синий | `(0, 0, 255)` | Пурпурный (маджента) | `(255, 0, 255)` |
| Серый | `(128, 128, 128)` | Оранжевый | `(255, 165, 0)` |
| Голубой цвет флага Казахстана | `(0, 175, 202)` | Золотисто-жёлтый | `(254, 197, 1)` |

Каждая из трёх компонент принимает 256 значений: 256 × 256 × 256 = **16 777 216** цветов.

**Три способа задать цвет:**

```python
import pygame

color1 = (0, 175, 202)                  # 1) кортеж RGB
color2 = pygame.Color("gold")           # 2) по названию (на английском)
color3 = pygame.Color("#00AFCA")        # 3) HEX-код (как в веб-дизайне)

print(color2)
print(color3.r, color3.g, color3.b)
```

Результат:
```text
(255, 215, 0, 255)
0 175 202
```

Четвёртое число — **альфа** (прозрачность): 255 — полностью непрозрачный, 0 — полностью прозрачный.

**HEX-код** — запись RGB в шестнадцатеричной системе: `#00AFCA` → `00`=0, `AF`=175, `CA`=202. Цвета удобно брать с веб-сайтов (например, через поиск «color picker»).

Объявлять **цвета как константы** в начале файла — хорошая практика:

```python
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
SKY = (135, 206, 235)
GRASS = (34, 139, 34)
SUN = (255, 215, 0)
```

## 3. Система координат Pygame

Самое важное отличие: **начало координат (0, 0) — ЛЕВЫЙ ВЕРХНИЙ угол окна**, а **ось Y растёт ВНИЗ**.

```text
(0,0) ───────────── X растёт ─────────────▶ (799,0)
  │
  │        (200, 100)
  │            •
  Y
 растёт                   (400, 300) — центр
  │                           •
  ▼
(0,599)                                    (799,599)
```

| | Математика | Pygame |
|---|---|---|
| Начало координат | В центре | Левый верхний угол |
| Ось X | Растёт вправо | Растёт вправо |
| Ось Y | Растёт **вверх** | Растёт **вниз** |
| Отрицательные координаты | Есть на плоскости | За пределами окна (не видны) |

В окне 800×600 пиксели нумеруются по X от 0 до 799, по Y — от 0 до 599.

**Вычисление важных точек:**

| Точка | Формула | Для 800×600 |
|---|---|---|
| Центр | `(WIDTH // 2, HEIGHT // 2)` | `(400, 300)` |
| Левый верхний | `(0, 0)` | `(0, 0)` |
| Правый верхний | `(WIDTH - 1, 0)` | `(799, 0)` |
| Левый нижний | `(0, HEIGHT - 1)` | `(0, 599)` |
| Правый нижний | `(WIDTH - 1, HEIGHT - 1)` | `(799, 599)` |

**Что это значит в игре:**
- если персонаж прыгает **вверх** — `y` **уменьшается** (`y -= 10`);
- если падает — `y` **увеличивается** (`y += 10`);
- если идёт вправо — `x` увеличивается, влево — `x` уменьшается.

## 4. Закраска области: fill(color, rect)

Если передать методу `fill()` вторым аргументом прямоугольник `(x, y, ширина, высота)`, закрасится только эта область. Здесь `(x, y)` — **левый верхний** угол прямоугольника.

```python
import pygame

WIDTH, HEIGHT = 600, 300
BLUE = (0, 175, 202)
YELLOW = (254, 197, 1)

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Закраска областей")
clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill(BLUE)                                  # весь фон
    screen.fill(YELLOW, (0, 0, 40, HEIGHT))            # полоса слева
    screen.fill(YELLOW, (WIDTH // 2 - 30, HEIGHT // 2 - 30, 60, 60))  # квадрат в центре
    pygame.display.flip()
    clock.tick(60)
pygame.quit()
```

Чтобы поставить квадрат точно в центр, мы вычли половину его размера: `WIDTH // 2 - 30`. Это очень часто используемый приём в программировании игр.

## 5. Работа с отдельными пикселями: set_at и get_at

```python
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((400, 300))
pygame.display.set_caption("Звёздное небо")
screen.fill((0, 0, 30))
for _ in range(300):
    x = random.randint(0, 399)
    y = random.randint(0, 299)
    screen.set_at((x, y), (255, 255, 255))   # сделать один пиксель белым
print(screen.get_at((0, 0)))                  # прочитать цвет пикселя

clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    pygame.display.flip()
    clock.tick(30)
pygame.quit()
```

Здесь звёзды нарисованы один раз **до** цикла, а в цикле нет `fill()` — поэтому картинка сохраняется. Когда нет движения, такой приём подходит.

## 6. Работа с пропорциями: деление экрана на части

Рисование с учётом размера окна — залог правильного отображения на любом экране.

```python
WIDTH, HEIGHT = 800, 600
stripe = HEIGHT // 3
for i in range(3):
    print(f"Полоса {i + 1}: y = {i * stripe} .. {(i + 1) * stripe - 1}")
```

Результат:
```text
Полоса 1: y = 0 .. 199
Полоса 2: y = 200 .. 399
Полоса 3: y = 400 .. 599
```

## Частые ошибки

**1. Компонента цвета больше 255 или отрицательная**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode((200, 200))
screen.fill((300, 0, 0))     # ValueError: invalid color argument
```
Правильно: ограничивать через `min(255, max(0, value))`.

**2. Размер задан не кортежем**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode(800, 600)   # TypeError
```
Правильно: `pygame.display.set_mode((800, 600))` — двойные скобки.

**3. Считать, что ось Y как в математике** — писать `y += 5` для «перемещения вверх». В Pygame вверх — это `y -= 5`.

**4. Не учитывать размер объекта при вычислении центра** — в точку `(WIDTH // 2, HEIGHT // 2)` попадает угол квадрата, а сам квадрат смещается вправо-вниз. Правильно: `x = WIDTH // 2 - size // 2`.

**5. Использование `/` вместо `//`** — результат `WIDTH / 2` имеет тип `float`. Многие функции его принимают, но в `range()` и индексах будет ошибка. Для пикселей используйте `//`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Surface | Поверхность (холст), на которой можно рисовать; само окно тоже Surface |
| Пиксель | Наименьшая точка на экране |
| RGB | Модель построения цвета из красной, зелёной и синей компонент (0–255) |
| HEX-код | Шестнадцатеричная запись цвета, например `#FF8800` |
| Альфа-канал | Уровень прозрачности |
| Система координат | Система с началом в левом верхнем углу, Y растёт вниз |
| Константа | Неизменяемое значение, имя пишется заглавными: `WIDTH`, `WHITE` |
| `RESIZABLE`, `FULLSCREEN` | Флаги режимов окна |

## Примечание

- Цвет можно задавать не только кортежем, но и объектом `pygame.Color`: `pygame.Color("red")`, `pygame.Color("#ff8800")` — именованные и HEX-цвета.
- В Pygame ось Y растёт **вниз**: `(0, 0)` — левый верхний угол окна. Не путайте с математической системой координат.
- `pygame.display.flip()` обновляет весь экран, а `pygame.display.update(rect)` — только указанную область.
- `set_at()` и `get_at()` работают медленно; для работы со множеством пикселей используют `pygame.PixelArray` или `pygame.surfarray` (NumPy).
- В Pygame 2 флаг `pygame.display.set_mode(size, pygame.SCALED)` масштабирует окно под размер экрана — удобно для пиксельных игр.
