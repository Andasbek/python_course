## 1. Ойын терезесін құру

```python
screen = pygame.display.set_mode((ені, биіктігі), жалаулар)
```

`set_mode` бізге **Surface** (бет, кенеп) объектісін қайтарады — бұл біз сурет салатын «қағаз». Терезе өлшемі пиксельмен беріледі.

| Танымал өлшемдер | Қатынасы | Қолданылуы |
|---|---|---|
| 640 × 480 | 4:3 | Ескі ойындар, жаттығулар |
| 800 × 600 | 4:3 | Оқу ойындары |
| 1280 × 720 | 16:9 | HD, қазіргі ойындар |
| 1920 × 1080 | 16:9 | Full HD, толық экран |

**Терезені баптау әдістері:**

| Әдіс | Не істейді |
|---|---|
| `pygame.display.set_caption("Атауы")` | Терезе тақырыбы |
| `pygame.display.set_icon(surface)` | Терезе белгішесі (32×32 сурет) |
| `screen.get_width()`, `screen.get_height()` | Терезенің ені мен биіктігі |
| `screen.get_size()` | `(ені, биіктігі)` кортежі |
| `pygame.display.Info()` | Монитор туралы ақпарат (`current_w`, `current_h`) |

**Терезе режимдері (жалаулар):**

| Жалау | Мағынасы |
|---|---|
| `pygame.RESIZABLE` | Терезе өлшемін тінтуірмен өзгертуге болады |
| `pygame.FULLSCREEN` | Толық экран режимі |
| `pygame.NOFRAME` | Жақтаусыз терезе |
| `pygame.SCALED` | Кішкене терезені экранға сай масштабтау |

```python
import pygame

WIDTH, HEIGHT = 800, 600          # тұрақтылар (константалар) бас әріппен

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT), pygame.RESIZABLE)
pygame.display.set_caption("Ғарыш саяхаты")

icon = pygame.Surface((32, 32))   # белгіше үшін 32×32 бет
icon.fill((255, 200, 0))
pygame.display.set_icon(icon)

info = pygame.display.Info()
print("Монитор:", info.current_w, "x", info.current_h)
print("Терезе:", screen.get_size())

clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.VIDEORESIZE:
            print("Жаңа өлшем:", event.w, event.h)
    screen.fill((10, 10, 40))
    pygame.display.flip()
    clock.tick(60)
pygame.quit()
```

Нәтижесі (мысал):
```text
Монитор: 1920 x 1080
Терезе: (800, 600)
Жаңа өлшем: 912 650
```

Терезе өлшемін **тұрақтыларға** (`WIDTH`, `HEIGHT`) шығару — жақсы әдет: өлшемді бір жерден өзгертсек, бүкіл ойын соған бейімделеді.

## 2. Түстер: RGB моделі

Экрандағы әр пиксель үш түрлі жарық көзінен тұрады: **Қызыл (Red)**, **Жасыл (Green)**, **Көк (Blue)**. Әр компоненттің жарықтығы 0-ден 255-ке дейін. Сондықтан түс — үш санның кортежі `(R, G, B)`.

**Аналогия:** қараңғы бөлмеде үш түсті фонарь. Үшеуін де толық қоссақ — ақ жарық, бәрін сөндірсек — қараңғы (қара).

| Түс | RGB | Түс | RGB |
|---|---|---|---|
| Қара | `(0, 0, 0)` | Ақ | `(255, 255, 255)` |
| Қызыл | `(255, 0, 0)` | Сары | `(255, 255, 0)` |
| Жасыл | `(0, 255, 0)` | Көгілдір (циан) | `(0, 255, 255)` |
| Көк | `(0, 0, 255)` | Қызғылт (маджента) | `(255, 0, 255)` |
| Сұр | `(128, 128, 128)` | Қызғылт сары | `(255, 165, 0)` |
| Қазақстан туының көгілдірі | `(0, 175, 202)` | Алтын сары | `(254, 197, 1)` |

Үш компоненттің әрқайсысы 256 мән қабылдайды: 256 × 256 × 256 = **16 777 216** түс.

**Түсті берудің үш тәсілі:**

```python
import pygame

color1 = (0, 175, 202)                  # 1) RGB кортежі
color2 = pygame.Color("gold")           # 2) атауы бойынша (ағылшынша)
color3 = pygame.Color("#00AFCA")        # 3) HEX коды (веб-дизайндағыдай)

print(color2)
print(color3.r, color3.g, color3.b)
```

Нәтижесі:
```text
(255, 215, 0, 255)
0 175 202
```

Төртінші сан — **альфа** (мөлдірлік): 255 — толық мөлдір емес, 0 — толық мөлдір.

**HEX коды** — RGB-ның 16-лық жүйедегі жазбасы: `#00AFCA` → `00`=0, `AF`=175, `CA`=202. Түстерді веб-сайттардан (мысалы, «color picker» іздеу арқылы) алуға ыңғайлы.

**Түстерді тұрақтылар ретінде** файлдың басында жариялау — жақсы тәжірибе:

```python
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
SKY = (135, 206, 235)
GRASS = (34, 139, 34)
SUN = (255, 215, 0)
```

## 3. Pygame координаталар жүйесі

Ең маңызды айырмашылық: **бас нүкте (0, 0) — терезенің СОЛ ЖАҚ ЖОҒАРҒЫ бұрышы**, ал **Y осі ТӨМЕН** қарай өседі.

```text
(0,0) ───────────── X өседі ──────────────▶ (799,0)
  │
  │        (200, 100)
  │            •
  Y
 өседі                    (400, 300) — ортасы
  │                           •
  ▼
(0,599)                                    (799,599)
```

| | Математика | Pygame |
|---|---|---|
| Бас нүкте | Ортада | Сол жақ жоғарғы бұрыш |
| X осі | Оңға өседі | Оңға өседі |
| Y осі | **Жоғары** өседі | **Төмен** өседі |
| Теріс координаталар | Жазықтықта бар | Терезеден тыс (көрінбейді) |

800×600 терезеде пиксельдер X бойынша 0..799, Y бойынша 0..599 нөмірленеді.

**Маңызды нүктелерді есептеу:**

| Нүкте | Формула | 800×600 үшін |
|---|---|---|
| Ортасы | `(WIDTH // 2, HEIGHT // 2)` | `(400, 300)` |
| Сол жақ жоғарғы | `(0, 0)` | `(0, 0)` |
| Оң жақ жоғарғы | `(WIDTH - 1, 0)` | `(799, 0)` |
| Сол жақ төменгі | `(0, HEIGHT - 1)` | `(0, 599)` |
| Оң жақ төменгі | `(WIDTH - 1, HEIGHT - 1)` | `(799, 599)` |

**Ойындағы мағынасы:**
- кейіпкер **жоғары** секірсе — `y` **азаяды** (`y -= 10`);
- құласа — `y` **артады** (`y += 10`);
- оңға жүрсе — `x` артады, солға — `x` азаяды.

## 4. Аймақты бояу: fill(color, rect)

`fill()` әдісіне екінші аргумент ретінде тіктөртбұрыш `(x, y, ені, биіктігі)` берсек, тек сол аймақ боялады. Мұндағы `(x, y)` — тіктөртбұрыштың **сол жақ жоғарғы** бұрышы.

```python
import pygame

WIDTH, HEIGHT = 600, 300
BLUE = (0, 175, 202)
YELLOW = (254, 197, 1)

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Аймақтарды бояу")
clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill(BLUE)                                  # бүкіл фон
    screen.fill(YELLOW, (0, 0, 40, HEIGHT))            # сол жақтағы жолақ
    screen.fill(YELLOW, (WIDTH // 2 - 30, HEIGHT // 2 - 30, 60, 60))  # ортадағы шаршы
    pygame.display.flip()
    clock.tick(60)
pygame.quit()
```

Ортадағы шаршыны дәл ортаға қою үшін оның өлшемінің жартысын шегердік: `WIDTH // 2 - 30`. Бұл — ойын бағдарламалауда өте жиі қолданылатын тәсіл.

## 5. Жеке пиксельмен жұмыс: set_at және get_at

```python
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((400, 300))
pygame.display.set_caption("Жұлдызды аспан")
screen.fill((0, 0, 30))
for _ in range(300):
    x = random.randint(0, 399)
    y = random.randint(0, 299)
    screen.set_at((x, y), (255, 255, 255))   # бір пиксельді ақ ету
print(screen.get_at((0, 0)))                  # пиксель түсін оқу

clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    pygame.display.flip()
    clock.tick(30)
pygame.quit()
```

Мұнда жұлдыздарды циклден **бұрын** бір рет салдық, ал циклде `fill()` жоқ — сондықтан сурет сақталады. Қозғалыс жоқ кезде бұл тәсіл жарайды.

## 6. Пропорциялармен жұмыс: экранды бөліктерге бөлу

Терезе өлшеміне тәуелді салу — кез келген экранда дұрыс көрінудің кепілі.

```python
WIDTH, HEIGHT = 800, 600
stripe = HEIGHT // 3
for i in range(3):
    print(f"{i + 1}-жолақ: y = {i * stripe} .. {(i + 1) * stripe - 1}")
```

Нәтижесі:
```text
1-жолақ: y = 0 .. 199
2-жолақ: y = 200 .. 399
3-жолақ: y = 400 .. 599
```

## Жиі кездесетін қателер

**1. Түс компоненті 255-тен үлкен немесе теріс**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode((200, 200))
screen.fill((300, 0, 0))     # ValueError: invalid color argument
```
Дұрысы: `min(255, max(0, value))` арқылы шектеу.

**2. Өлшемді кортежсіз беру**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode(800, 600)   # TypeError
```
Дұрысы: `pygame.display.set_mode((800, 600))` — қос жақша.

**3. Y осін математикадағыдай деп ойлау** — «жоғары жылжыту» үшін `y += 5` жазу. Pygame-де жоғары — `y -= 5`.

**4. Ортаны есептегенде объект өлшемін ескермеу** — `(WIDTH // 2, HEIGHT // 2)` нүктесіне шаршының бұрышы түседі, шаршының өзі оңға-төмен ығысады. Дұрысы: `x = WIDTH // 2 - size // 2`.

**5. `/` орнына `//` қолданбау** — `WIDTH / 2` нәтижесі `float`. Көп функциялар оны қабылдайды, бірақ `range()` және индекстерде қате береді. Пиксельдер үшін `//` қолданыңыз.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Surface | Сурет салуға болатын бет (кенеп); терезенің өзі де Surface |
| Пиксель | Экрандағы ең кіші нүкте |
| RGB | Қызыл, жасыл, көк компоненттерінен түс құру моделі (0–255) |
| HEX коды | Түстің 16-лық жазбасы, мысалы `#FF8800` |
| Альфа-арна | Мөлдірлік деңгейі |
| Координаталар жүйесі | Бас нүктесі сол жақ жоғарғы бұрышта, Y төмен өсетін жүйе |
| Тұрақты (константа) | Өзгермейтін мән, атауы бас әріппен: `WIDTH`, `WHITE` |
| `RESIZABLE`, `FULLSCREEN` | Терезе режимдерінің жалаулары |

## Ескерту

- Түсті кортежбен ғана емес, `pygame.Color` объектісімен де беруге болады: `pygame.Color("red")`, `pygame.Color("#ff8800")` — атаулы және HEX түстер.
- Pygame-де Y осі **төмен** қарай өседі: `(0, 0)` — терезенің сол жақ жоғарғы бұрышы. Математикалық координаталармен шатастырмаңыз.
- `pygame.display.flip()` бүкіл экранды жаңартады, ал `pygame.display.update(rect)` — тек көрсетілген аймақты.
- `set_at()` және `get_at()` баяу жұмыс істейді; көп пиксельмен жұмыс үшін `pygame.PixelArray` немесе `pygame.surfarray` (NumPy) қолданылады.
- Pygame 2-де `pygame.display.set_mode(size, pygame.SCALED)` жалаушасы терезені экран өлшеміне сәйкес масштабтайды — пиксельді ойындарға ыңғайлы.
