## 1. Что такое Pygame?

**Pygame** — бесплатная библиотека для создания 2D-игр и мультимедийных программ на языке Python. Она построена поверх библиотеки **SDL** (Simple DirectMedia Layer), написанной на C, поэтому быстро работает с графикой, звуком, клавиатурой и мышью.

| Что умеет Pygame | Модуль |
|---|---|
| Создание окна, рисование на экране | `pygame.display`, `pygame.draw` |
| Загрузка изображений | `pygame.image` |
| Клавиатура, мышь, джойстик | `pygame.event`, `pygame.key`, `pygame.mouse` |
| Звук и музыка | `pygame.mixer` |
| Вывод текста | `pygame.font` |
| Управление временем | `pygame.time` |
| Спрайты и столкновения | `pygame.sprite`, `pygame.Rect` |

## 3. Как работает игра? Понятие кадра

Кино состоит из 24 картинок (кадров) в секунду — глаз воспринимает их как непрерывное движение. Игра устроена так же: программа **перерисовывает** экран 30–60 раз в секунду. Каждая картинка — **кадр** (frame), количество кадров в секунду — **FPS** (frames per second).

Игровая программа в одном цикле на каждом кадре выполняет три действия:

```text
          +---------------------------+
          |  1. ОБРАБОТКА СОБЫТИЙ      |  нажата клавиша? мышь? окно закрыто?
          +-------------+-------------+
                        |
          +-------------v-------------+
          |  2. ОБНОВЛЕНИЕ СОСТОЯНИЯ   |  перемещение персонажа, подсчёт очков, столкновения
          +-------------+-------------+
                        |
          +-------------v-------------+
          |  3. ОТРИСОВКА НА ЭКРАНЕ    |  очистка фона, рисование объектов, flip()
          +-------------+-------------+
                        |
                 clock.tick(60)  -> следующий кадр
```

**Аналогия: художник-мультипликатор.** На каждом листе художник: (1) слушает указание режиссёра, (2) вычисляет новое положение персонажа, (3) рисует новую картинку. Если быстро пролистать листы — получится мультфильм.

## 4. Разница между Tkinter и Pygame

| | Tkinter | Pygame |
|---|---|---|
| Цикл | `mainloop()` — готовый, скрытый | `while running:` — пишем сами |
| Экран | Виджеты рисуются сами | На каждом кадре всё перерисовываем сами |
| События | `command=`, `bind()` | `pygame.event.get()` внутри цикла |
| Назначение | Приложения (формы, кнопки) | Игры, анимация |

## 5. Каркас программы на Pygame

Любая игра на Pygame начинается с этого каркаса — его нужно знать наизусть:

```python
import pygame

pygame.init()                                   # 1. Запуск всех модулей
screen = pygame.display.set_mode((800, 600))    # 2. Создание окна
pygame.display.set_caption("Моя первая игра")
clock = pygame.time.Clock()                     # 3. Часы для управления временем

running = True
while running:                                  # 4. ИГРОВОЙ ЦИКЛ
    # 4.1 Обработка событий
    for event in pygame.event.get():
        if event.type == pygame.QUIT:           # кнопка «×» окна
            running = False

    # 4.2 Обновление состояния (пока пусто)

    # 4.3 Отрисовка на экране
    screen.fill((30, 30, 60))                   # закрашиваем фон
    pygame.display.flip()                       # показываем нарисованное на экране

    clock.tick(60)                              # не более 60 кадров в секунду

pygame.quit()                                   # 5. Корректное завершение Pygame
```

**Построчный разбор:**

| Строка | Объяснение |
|---|---|
| `pygame.init()` | Подготавливает все внутренние модули Pygame (дисплей, звук, шрифты) |
| `set_mode((800, 600))` | Создаёт окно шириной 800 и высотой 600 пикселей и возвращает его поверхность (`Surface`) |
| `set_caption(...)` | Заголовок окна |
| `pygame.time.Clock()` | Объект, контролирующий скорость кадров |
| `running = True` | Флаг цикла: когда станет `False`, игра остановится |
| `pygame.event.get()` | Возвращает список всех событий с прошлого кадра и очищает очередь |
| `pygame.QUIT` | Событие, возникающее, когда пользователь хочет закрыть окно |
| `screen.fill(...)` | Закрашивает весь экран одним цветом («стирает» предыдущий кадр) |
| `pygame.display.flip()` | Выводит нарисованный в памяти кадр на экран |
| `clock.tick(60)` | Ждёт, чтобы цикл не крутился чаще 60 раз в секунду |
| `pygame.quit()` | Освобождает ресурсы и закрывает окно |

## 6. Очередь событий (event queue)

Каждое действие пользователя (нажатие клавиши, движение мыши, закрытие окна) попадает в очередь как **событие**. На каждом кадре мы читаем очередь через `pygame.event.get()`. Если не читать её, очередь переполнится, и операционная система предупредит: «Программа не отвечает».

Чтобы увидеть события, выведем их в консоль:

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((400, 300))
clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        print(pygame.event.event_name(event.type))
        if event.type == pygame.QUIT:
            running = False
    screen.fill((0, 0, 0))
    pygame.display.flip()
    clock.tick(30)
pygame.quit()
```

Результат (если подвигать мышь, нажать клавишу и закрыть окно):
```text
WindowShown
MouseMotion
MouseMotion
KeyDown
KeyUp
WindowClose
Quit
```

## 7. Игровой цикл в действии: счётчик кадров

Будем менять переменную на каждом кадре и убедимся, что цикл действительно повторяется. Цвет фона плавно меняется на каждом кадре:

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((600, 400))
pygame.display.set_caption("Счётчик кадров")
clock = pygame.time.Clock()

frame = 0
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    frame += 1                       # обновление состояния
    red = frame % 256                # циклически в диапазоне 0..255

    screen.fill((red, 0, 100))
    pygame.display.flip()
    pygame.display.set_caption(f"Кадр: {frame}")
    clock.tick(60)

pygame.quit()
print("Всего кадров:", frame)
```

Результат (если окно открыто 10 секунд, примерно):
```text
Всего кадров: 600
```

60 FPS × 10 секунд ≈ 600 кадров. Если убрать строку `clock.tick(60)`, число будет намного больше — компьютер будет крутить цикл максимально быстро.

## Частые ошибки

**1. Забыт `pygame.init()`** — некоторые модули (например, шрифты) выдают ошибку `pygame.error: font not initialized`.

**2. События не обрабатываются**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode((400, 300))
while True:
    screen.fill((0, 0, 0))
    pygame.display.flip()
```
Окно «зависает» и не закрывается. Правильно: в цикле обязательны `for event in pygame.event.get():` и проверка `QUIT`.

**3. Не вызван `flip()`** — ничего из нарисованного не видно на экране (окно чёрное или белое).

**4. `pygame.quit()` внутри цикла**
```python
import pygame
pygame.init()
screen = pygame.display.set_mode((400, 300))
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            pygame.quit()
    screen.fill((0, 0, 0))   # pygame.error: display Surface quit
```
Правильно: в цикле только устанавливать `running = False`, а `pygame.quit()` вызывать **после** цикла.

**5. Файл назван `pygame.py`** — `import pygame` импортирует ваш файл и выдаёт `AttributeError: module 'pygame' has no attribute 'init'`. Назовите файл иначе.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Pygame | Библиотека для создания 2D-игр на Python |
| SDL | Мультимедийная библиотека, на которой основан Pygame |
| Игровой цикл (game loop) | Цикл «события → обновление → отрисовка», повторяющийся всё время игры |
| Кадр (frame) | Один оборот игрового цикла, одна картинка на экране |
| FPS | Количество кадров в секунду |
| Событие (event) | Сообщение о действии пользователя (клавиша, мышь, закрытие) |
| `Clock` | Объект, управляющий частотой кадров |
| `flip()` | Вывод нарисованного кадра на экран |

## Примечание

- `pygame` и `pygame-ce` (community edition) — два разных пакета, оба импортируются как `import pygame`. Не устанавливайте их в одно виртуальное окружение — они конфликтуют.
- Для самой новой версии Python готовые пакеты (wheel) pygame могут появиться с задержкой. Если `pip install pygame` пытается собрать библиотеку из исходников и выдаёт ошибку — используйте предыдущую версию Python.
- Чтобы скрыть приветствие при импорте, до `import pygame` задайте переменную окружения: `os.environ["PYGAME_HIDE_SUPPORT_PROMPT"] = "1"`.
- `pygame.quit()` только останавливает модули Pygame, но не завершает программу. Чтобы полностью выйти изнутри цикла, после него вызывают `sys.exit()`.
- Официальная документация Pygame: https://www.pygame.org/docs/
