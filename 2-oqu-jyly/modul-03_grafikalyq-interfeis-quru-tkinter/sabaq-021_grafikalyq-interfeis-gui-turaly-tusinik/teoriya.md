## 1. Интерфейс дегеніміз не?

**Интерфейс (интерфейс, interface)** — адам мен бағдарлама арасындағы «байланыс тілі»: адам қалай мәлімет береді және нәтижені қалай көреді.

Өмірлік аналогия: көліктің интерфейсі — руль, педаль, спидометр. Банкоматтың интерфейсі — экран мен батырмалар.

### Интерфейс түрлері

| Түрі | Толық атауы | Мысалдар |
|---|---|---|
| CLI | Command Line Interface — командалық жол интерфейсі | Терминал, `git`, `pip`, `input()`/`print()` қолданатын скриптер |
| GUI | Graphical User Interface — графикалық пайдаланушы интерфейсі | Word, браузер, калькулятор, ойындар |
| VUI | Voice User Interface — дауыстық интерфейс | Алиса, Siri |
| Web UI | Браузердегі интерфейс | Kundelik.kz, eGov.kz |

## 2. Консольдік және графикалық бағдарламалардың айырмашылығы

| Белгі | Консольдік (CLI) | Графикалық (GUI) |
|---|---|---|
| Енгізу | Пернетақта, `input()` | Тінтуір, пернетақта, сенсор; өрістер, батырмалар |
| Шығару | Мәтін, `print()` | Терезелер, суреттер, түстер |
| Жұмыс тәртібі | **Сызықтық**: жоғарыдан төмен, бағдарлама сұрайды | **Оқиғалық**: пайдаланушы не істесе, соған жауап береді |
| Пайдаланушы | Көбіне мамандар | Барлық адамдар |
| Ресурс | Аз | Көбірек (жад, графика) |
| Жазу қиындығы | Оңай | Күрделірек |

### Сызықтық логика (консоль)

```python
name = "Ару"            # input("Атыңыз: ") болуы мүмкін
age = 14                # int(input("Жасыңыз: "))
print(f"Сәлем, {name}! Келесі жылы сізге {age + 1} жас болады.")
```

Нәтижесі:
```text
Сәлем, Ару! Келесі жылы сізге 15 жас болады.
```

Бағдарлама өзі «басқарады»: алдымен атын, сосын жасын сұрайды — басқа ретпен енгізу мүмкін емес.

### Оқиғалық логика (GUI)

GUI бағдарламасы терезені көрсетіп, **күтеді**. Пайдаланушы батырманы басады, мәтін жазады, терезені жабады — бұлар **оқиғалар (события, events)**. Әр оқиғаға бағдарлама тиісті функцияны орындайды. Бұл — **оқиғаға бағытталған бағдарламалау (event-driven programming)**.

```text
        ┌──────────────────────────────────────┐
        │  Терезені құру, виджеттерді орналастыру │
        └──────────────────┬───────────────────┘
                           ▼
        ┌──────────────────────────────────────┐
   ┌───>│   Оқиғаны күту (mainloop)            │
   │    └──────────────────┬───────────────────┘
   │                       ▼
   │    ┌──────────────────────────────────────┐
   │    │ Оқиға болды? (басу, теру, жабу)      │
   │    └──────────────────┬───────────────────┘
   │                       ▼
   │    ┌──────────────────────────────────────┐
   └────│  Тиісті функцияны орындау            │
        └──────────────────────────────────────┘
          (терезе жабылғанда цикл аяқталады)
```

## 3. Python-дағы GUI кітапханалары

| Кітапхана | Ерекшелігі |
|---|---|
| **Tkinter** | Python-мен бірге орнатылады, үйренуге оңай, стандартты кітапханаға кіреді |
| PyQt / PySide | Кәсіби, мүмкіндігі мол, күрделірек |
| Kivy | Мобильді қосымшалар, сенсорлы экрандар |
| wxPython | Операциялық жүйенің «туған» стилі |
| CustomTkinter | Tkinter негізіндегі заманауи дизайн |

**Tkinter** = «Tk interface». Tk — 1990 жылдары жасалған кроссплатформалы графикалық құралдар жиынтығы. Tkinter Windows, macOS, Linux-та бірдей жұмыс істейді.

Tkinter орнатылғанын тексеру (терминалда):

```bash
python -m tkinter
```

Кішкентай тексеру терезесі ашылса — бәрі дайын. (Linux-та кейде бөлек орнату керек: `sudo apt install python3-tk`.)

## 4. Tkinter-дегі алғашқы терезе

```python
import tkinter as tk

root = tk.Tk()              # 1. Басты терезе (объект!)
root.title("Менің алғашқы терезем")

label = tk.Label(root, text="Сәлем, әлем!")   # 2. Виджет құру
label.pack()                                   # 3. Терезеге орналастыру

root.mainloop()             # 4. Оқиғаларды күту циклі
```

Бұл кодты іске қоссаңыз, «Сәлем, әлем!» жазуы бар кішкене терезе ашылады.

Әр жолды талдайық:

| Жол | Мағынасы |
|---|---|
| `import tkinter as tk` | Кітапхананы `tk` деген қысқа атпен импорттау |
| `root = tk.Tk()` | `Tk` класының объектісі — басты терезе |
| `root.title(...)` | Терезе тақырыбын орнату |
| `tk.Label(root, text=...)` | `Label` (жазу) виджеті; бірінші аргумент — **ата-виджет** (қай терезеде орналасады) |
| `label.pack()` | Виджетті терезеге қою (орналастыру менеджері) |
| `root.mainloop()` | Бағдарламаны «тірі» ұстап, оқиғаларды өңдейтін шексіз цикл |

**Маңызды:** Tkinter — толығымен ОБП негізінде! `Tk`, `Label`, `Button` — кластар, ал біз олардың объектілерін құрамыз және әдістерін (`title`, `pack`, `mainloop`) шақырамыз.

## 5. Виджет дегеніміз не?

**Виджет (виджет, widget)** — терезедегі кез келген элемент: жазу, батырма, енгізу өрісі, тізім, сурет салу алаңы т.б.

| Виджет | Не үшін | Модуль |
|---|---|---|
| `Label` | Мәтін немесе сурет көрсету | `tkinter` |
| `Button` | Батырма | `tkinter` |
| `Entry` | Бір жолдық енгізу өрісі | `tkinter` |
| `Checkbutton`, `Radiobutton` | Таңдау | `tkinter` |
| `Listbox` | Тізімнен таңдау | `tkinter` |
| `Combobox` | Ашылмалы тізім | `tkinter.ttk` |
| `Text`, `Scrollbar` | Көп жолды мәтін, айналдыру | `tkinter` |
| `Menu` | Мәзір | `tkinter` |
| `Canvas` | Сурет салу алаңы | `tkinter` |

## 6. Батырмасы бар бағдарлама — алғашқы оқиға

```python
import tkinter as tk


def say_hello():
    label.config(text="Батырма басылды! Қош келдіңіз!")


root = tk.Tk()
root.title("Сәлемдесу")

label = tk.Label(root, text="Батырманы басыңыз", font=("Arial", 14))
label.pack(padx=20, pady=10)

button = tk.Button(root, text="Басу", command=say_hello)
button.pack(pady=10)

root.mainloop()
```

Мұнда:
- `command=say_hello` — батырма басылғанда шақырылатын функция (**жақшасыз!**);
- `label.config(text=...)` — бар виджеттің қасиетін өзгерту;
- `padx`, `pady` — виджеттің айналасындағы бос орын (пиксельмен).

Консольдік бағдарламадан айырмашылығы: бағдарлама батырманың **қашан** басылатынын білмейді — ол жай күтеді.

## 7. Консольдік бағдарламаны GUI-ге айналдыру: салыстыру

Консольдік нұсқа:

```python
def to_fahrenheit(c):
    return c * 9 / 5 + 32

c = 25                      # c = float(input("Цельсий: "))
print("Фаренгейт:", to_fahrenheit(c))
```

Нәтижесі:
```text
Фаренгейт: 77.0
```

GUI нұсқасының қаңқасы (`Entry` — бір жолдық енгізу өрісі, `entry.get()` енгізілген мәтінді қайтарады):

```python
import tkinter as tk


def to_fahrenheit(c):
    return c * 9 / 5 + 32


def convert():
    c = float(entry.get())
    result.config(text=f"Фаренгейт: {to_fahrenheit(c)}")


root = tk.Tk()
root.title("Температура")
entry = tk.Entry(root)
entry.pack(padx=10, pady=5)
tk.Button(root, text="Есептеу", command=convert).pack()
result = tk.Label(root, text="")
result.pack(pady=5)
root.mainloop()
```

Есептеу функциясы (`to_fahrenheit`) **өзгерген жоқ** — тек интерфейс өзгерді. Бұл маңызды идея: **логиканы интерфейстен бөліп** жазу.

## Жиі кездесетін қателер

**1. `mainloop()` ұмыту** — терезе пайда болмайды немесе бірден жабылады.

**2. `pack()` (немесе басқа орналастыру менеджерін) ұмыту**

```python
import tkinter as tk
root = tk.Tk()
label = tk.Label(root, text="Мені көрмейсіз")   # pack жоқ — терезеде көрінбейді
root.mainloop()
```

**3. `command`-қа функцияны жақшамен беру**

```python
import tkinter as tk

def hello():
    print("Сәлем!")

root = tk.Tk()
# ҚАТЕ: command=hello()  -> функция бірден орындалады, батырма жұмыс істемейді
btn = tk.Button(root, text="Басу", command=hello)   # дұрыс
btn.pack()
root.mainloop()
```

**4. Файлды `tkinter.py` деп атау** — `import tkinter` сіздің файлыңызды импорттайды да, `AttributeError: module 'tkinter' has no attribute 'Tk'` шығады. Файлдарды `tkinter.py`, `tk.py` деп атамаңыз!

**5. `Tk` орнына `tk`** — `root = tk.tk()` → қате. Класс атауы бас әріппен: `tk.Tk()`.

**6. Бірнеше `Tk()` объектісін құру** — бір бағдарламада бір ғана басты терезе. Қосымша терезелер үшін `Toplevel` қолданылады.

## Негізгі ұғымдар

| Ұғым | Түсіндірмесі |
|---|---|
| Интерфейс | Адам мен бағдарламаның өзара әрекеттесу тәсілі |
| CLI | Командалық жол (консольдік) интерфейсі |
| GUI | Графикалық пайдаланушы интерфейсі |
| Оқиға (event) | Пайдаланушының немесе жүйенің әрекеті: басу, теру, жабу |
| Оқиғаға бағытталған бағдарламалау | Бағдарлама оқиғаларды күтіп, оларға жауап береді |
| Tkinter | Python-ның стандартты GUI кітапханасы |
| Виджет | Терезедегі графикалық элемент |
| `mainloop()` | Оқиғаларды өңдейтін басты цикл |

## Ескерту

- Python 3-те модуль `tkinter` (кіші әріппен) деп аталады; Python 2-де ол `Tkinter` болған, сондықтан интернеттегі ескі мысалдар жұмыс істемеуі мүмкін.
- `mainloop()` орындалуды тоқтатып тұрады: одан кейін жазылған код тек терезе жабылғаннан кейін орындалады.
- Tkinter ағындар үшін қауіпсіз емес: виджеттерді тек бағдарламаның негізгі ағынынан өзгертуге болады.
- Tk нұсқасын `tk.TkVersion` көрсетеді (қазіргі Python жинақтарында әдетте 8.6).
- IDLE ортасының өзі Tkinter-де жазылған, сондықтан GUI-бағдарламалар онда кейде басқаша жұмыс істейді — оғаш әрекет байқалса, файлды терминалдан іске қосыңыз.
- Құжаттама: https://docs.python.org/3/library/tkinter.html
