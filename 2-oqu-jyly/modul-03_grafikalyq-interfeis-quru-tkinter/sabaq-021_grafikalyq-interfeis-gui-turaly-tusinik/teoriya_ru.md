## 1. Что такое интерфейс?

**Интерфейс (interface)** — «язык общения» между человеком и программой: как человек передаёт данные и как видит результат.

Жизненная аналогия: интерфейс автомобиля — руль, педали, спидометр. Интерфейс банкомата — экран и кнопки.

### Виды интерфейсов

| Вид | Полное название | Примеры |
|---|---|---|
| CLI | Command Line Interface — интерфейс командной строки | Терминал, `git`, `pip`, скрипты с `input()`/`print()` |
| GUI | Graphical User Interface — графический пользовательский интерфейс | Word, браузер, калькулятор, игры |
| VUI | Voice User Interface — голосовой интерфейс | Алиса, Siri |
| Web UI | Интерфейс в браузере | Kundelik.kz, eGov.kz |

## 2. Различие консольных и графических программ

| Признак | Консольная (CLI) | Графическая (GUI) |
|---|---|---|
| Ввод | Клавиатура, `input()` | Мышь, клавиатура, сенсор; поля, кнопки |
| Вывод | Текст, `print()` | Окна, изображения, цвета |
| Порядок работы | **Линейный**: сверху вниз, программа спрашивает | **Событийный**: отвечает на то, что делает пользователь |
| Пользователь | Чаще специалисты | Все люди |
| Ресурсы | Мало | Больше (память, графика) |
| Сложность написания | Легко | Сложнее |

### Линейная логика (консоль)

```python
name = "Ару"            # может быть input("Ваше имя: ")
age = 14                # int(input("Ваш возраст: "))
print(f"Привет, {name}! В следующем году вам исполнится {age + 1}.")
```

Результат:
```text
Привет, Ару! В следующем году вам исполнится 15.
```

Программа сама «управляет»: сначала спрашивает имя, затем возраст — ввести в другом порядке невозможно.

### Событийная логика (GUI)

GUI-программа показывает окно и **ждёт**. Пользователь нажимает кнопку, пишет текст, закрывает окно — это **события (events)**. На каждое событие программа выполняет соответствующую функцию. Это **событийно-ориентированное программирование (event-driven programming)**.

```text
        ┌──────────────────────────────────────┐
        │  Создание окна, размещение виджетов  │
        └──────────────────┬───────────────────┘
                           ▼
        ┌──────────────────────────────────────┐
   ┌───>│   Ожидание события (mainloop)        │
   │    └──────────────────┬───────────────────┘
   │                       ▼
   │    ┌──────────────────────────────────────┐
   │    │ Произошло событие? (нажатие, ввод,   │
   │    │ закрытие)                            │
   │    └──────────────────┬───────────────────┘
   │                       ▼
   │    ┌──────────────────────────────────────┐
   └────│  Выполнение нужной функции           │
        └──────────────────────────────────────┘
          (цикл завершается при закрытии окна)
```

## 3. GUI-библиотеки в Python

| Библиотека | Особенность |
|---|---|
| **Tkinter** | Устанавливается вместе с Python, легко изучать, входит в стандартную библиотеку |
| PyQt / PySide | Профессиональная, много возможностей, сложнее |
| Kivy | Мобильные приложения, сенсорные экраны |
| wxPython | «Родной» стиль операционной системы |
| CustomTkinter | Современный дизайн на основе Tkinter |

**Tkinter** = «Tk interface». Tk — кроссплатформенный набор графических инструментов, созданный в 1990-х годах. Tkinter одинаково работает в Windows, macOS, Linux.

Проверка установки Tkinter (в терминале):

```bash
python -m tkinter
```

Если открылось маленькое тестовое окно — всё готово. (В Linux иногда нужно установить отдельно: `sudo apt install python3-tk`.)

## 4. Первое окно в Tkinter

```python
import tkinter as tk

root = tk.Tk()              # 1. Главное окно (объект!)
root.title("Моё первое окно")

label = tk.Label(root, text="Привет, мир!")   # 2. Создание виджета
label.pack()                                   # 3. Размещение в окне

root.mainloop()             # 4. Цикл ожидания событий
```

Если запустить этот код, откроется маленькое окно с надписью «Привет, мир!».

Разберём каждую строку:

| Строка | Смысл |
|---|---|
| `import tkinter as tk` | Импорт библиотеки под коротким именем `tk` |
| `root = tk.Tk()` | Объект класса `Tk` — главное окно |
| `root.title(...)` | Установка заголовка окна |
| `tk.Label(root, text=...)` | Виджет `Label` (надпись); первый аргумент — **родительский виджет** (в каком окне размещается) |
| `label.pack()` | Помещение виджета в окно (менеджер размещения) |
| `root.mainloop()` | Бесконечный цикл, который держит программу «живой» и обрабатывает события |

**Важно:** Tkinter полностью основан на ООП! `Tk`, `Label`, `Button` — классы, а мы создаём их объекты и вызываем их методы (`title`, `pack`, `mainloop`).

## 5. Что такое виджет?

**Виджет (widget)** — любой элемент окна: надпись, кнопка, поле ввода, список, область для рисования и т.д.

| Виджет | Для чего | Модуль |
|---|---|---|
| `Label` | Показ текста или изображения | `tkinter` |
| `Button` | Кнопка | `tkinter` |
| `Entry` | Однострочное поле ввода | `tkinter` |
| `Checkbutton`, `Radiobutton` | Выбор | `tkinter` |
| `Listbox` | Выбор из списка | `tkinter` |
| `Combobox` | Выпадающий список | `tkinter.ttk` |
| `Text`, `Scrollbar` | Многострочный текст, прокрутка | `tkinter` |
| `Menu` | Меню | `tkinter` |
| `Canvas` | Область для рисования | `tkinter` |

## 6. Программа с кнопкой — первое событие

```python
import tkinter as tk


def say_hello():
    label.config(text="Кнопка нажата! Добро пожаловать!")


root = tk.Tk()
root.title("Приветствие")

label = tk.Label(root, text="Нажмите кнопку", font=("Arial", 14))
label.pack(padx=20, pady=10)

button = tk.Button(root, text="Нажать", command=say_hello)
button.pack(pady=10)

root.mainloop()
```

Здесь:
- `command=say_hello` — функция, вызываемая при нажатии кнопки (**без скобок!**);
- `label.config(text=...)` — изменение свойства существующего виджета;
- `padx`, `pady` — свободное место вокруг виджета (в пикселях).

Отличие от консольной программы: программа не знает, **когда** будет нажата кнопка — она просто ждёт.

## 7. Превращение консольной программы в GUI: сравнение

Консольная версия:

```python
def to_fahrenheit(c):
    return c * 9 / 5 + 32

c = 25                      # c = float(input("Цельсий: "))
print("Фаренгейт:", to_fahrenheit(c))
```

Результат:
```text
Фаренгейт: 77.0
```

Каркас GUI-версии (`Entry` — однострочное поле ввода, `entry.get()` возвращает введённый текст):

```python
import tkinter as tk


def to_fahrenheit(c):
    return c * 9 / 5 + 32


def convert():
    c = float(entry.get())
    result.config(text=f"Фаренгейт: {to_fahrenheit(c)}")


root = tk.Tk()
root.title("Температура")
entry = tk.Entry(root)
entry.pack(padx=10, pady=5)
tk.Button(root, text="Вычислить", command=convert).pack()
result = tk.Label(root, text="")
result.pack(pady=5)
root.mainloop()
```

Функция вычисления (`to_fahrenheit`) **не изменилась** — изменился только интерфейс. Это важная идея: писать **логику отдельно от интерфейса**.

## Частые ошибки

**1. Забыли `mainloop()`** — окно не появляется или сразу закрывается.

**2. Забыли `pack()` (или другой менеджер размещения)**

```python
import tkinter as tk
root = tk.Tk()
label = tk.Label(root, text="Вы меня не увидите")   # нет pack — в окне не видно
root.mainloop()
```

**3. Передача функции в `command` со скобками**

```python
import tkinter as tk

def hello():
    print("Привет!")

root = tk.Tk()
# ОШИБКА: command=hello()  -> функция выполнится сразу, кнопка не будет работать
btn = tk.Button(root, text="Нажать", command=hello)   # правильно
btn.pack()
root.mainloop()
```

**4. Назвать файл `tkinter.py`** — `import tkinter` импортирует ваш файл, и появится `AttributeError: module 'tkinter' has no attribute 'Tk'`. Не называйте файлы `tkinter.py`, `tk.py`!

**5. `tk` вместо `Tk`** — `root = tk.tk()` → ошибка. Имя класса с заглавной буквы: `tk.Tk()`.

**6. Создание нескольких объектов `Tk()`** — в одной программе только одно главное окно. Для дополнительных окон используется `Toplevel`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Интерфейс | Способ взаимодействия человека и программы |
| CLI | Интерфейс командной строки (консольный) |
| GUI | Графический пользовательский интерфейс |
| Событие (event) | Действие пользователя или системы: нажатие, ввод, закрытие |
| Событийно-ориентированное программирование | Программа ждёт событий и отвечает на них |
| Tkinter | Стандартная GUI-библиотека Python |
| Виджет | Графический элемент окна |
| `mainloop()` | Главный цикл обработки событий |

## Примечание

- В Python 3 модуль называется `tkinter` (строчными буквами); в Python 2 он назывался `Tkinter`, поэтому старые примеры из интернета могут не работать.
- `mainloop()` блокирует выполнение: код, написанный после него, выполнится только после закрытия окна.
- Tkinter не потокобезопасен: изменять виджеты можно только из главного потока программы.
- Версию Tk показывает `tk.TkVersion` (в современных сборках Python обычно 8.6).
- Среда IDLE сама написана на Tkinter, поэтому GUI-программы в ней иногда ведут себя иначе — при странном поведении запускайте файл из терминала.
- Документация: https://docs.python.org/3/library/tkinter.html
