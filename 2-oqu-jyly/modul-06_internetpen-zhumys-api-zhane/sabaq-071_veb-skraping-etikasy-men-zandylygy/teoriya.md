## 1. Скрапинг заңды ма?

Қысқа жауап: **жағдайға байланысты**. Әлемнің көп елінде ашық жарияланған деректерді жинаудың өзі тыйым салынбаған, бірақ мынадай шектеулер бар:

| Фактор | Сұрақ | Қауіп |
|---|---|---|
| Сайт ережелері (Terms of Service) | Сайт автоматты жинауға тыйым сала ма? | Аккаунтты бұғаттау, сот талабы |
| Қолжетімділік | Деректер ашық па, әлде логин/құпия сөз арқылы ма? | Рұқсатсыз қол жеткізу — құқық бұзушылық |
| Авторлық құқық | Мәтін, сурет, мақала біреудің шығармасы ма? | Көшіріп жариялау — авторлық құқықты бұзу |
| Жеке деректер | Адамдардың аты, телефоны, email, фотосы бар ма? | Дербес деректер туралы заңды бұзу |
| Серверге жүктеме | Сайт жұмысына кедергі жасай ма? | DoS-шабуылға теңестірілуі мүмкін |

**Қазақстанда** ескерілетін заңдар (танысу деңгейінде):
- «Дербес деректер және оларды қорғау туралы» ҚР Заңы (2013) — адамның келісімінсіз оның дербес деректерін жинауға, өңдеуге, таратуға болмайды;
- «Авторлық құқық және сабақтас құқықтар туралы» ҚР Заңы — шығармаларды автордың рұқсатынсыз пайдалануды шектейді;
- ақпараттандыру саласындағы заңнама — ақпараттық жүйелерге рұқсатсыз кіру мен олардың жұмысын бұзу жауапкершілікке әкеледі.

Еуропада осыған ұқсас GDPR ережелері әрекет етеді. **Біз заңгер емеспіз**, сондықтан ереже қарапайым: күмән болса — жинамаймыз немесе сайт иесінен рұқсат сұраймыз.

## 2. Сайт ережелері (Terms of Service)

Сайттың төменгі жағында әдетте «Пайдалану шарттары», «Terms of Use», «Пользовательское соглашение» сілтемесі болады. Ішінен мына сөздерді іздеңіз: *automated*, *scraping*, *crawl*, *robots*, «автоматизированный сбор». Егер тыйым салынса — сол сайттан скрапинг жасамаймыз.

## 3. robots.txt — сайттың «кіру ережелері»

**robots.txt** — сайт түбіріндегі мәтіндік файл (`https://сайт/robots.txt`), онда сайт иесі роботтарға (іздеу жүйелері, скраперлер) қай бөлімдерге кіруге болатынын жазады. Бұл — **келісім**, техникалық қорғаныс емес: әдепті робот оны сақтайды.

Мысал:

```text
User-agent: *
Allow: /search/about
Disallow: /admin/
Disallow: /search
Crawl-delay: 5

User-agent: BadBot
Disallow: /

Sitemap: https://example.kz/sitemap.xml
```

| Директива | Мағынасы |
|---|---|
| `User-agent: *` | Келесі ережелер барлық роботқа қатысты |
| `User-agent: BadBot` | Тек осы атаулы роботқа |
| `Disallow: /admin/` | `/admin/` деп басталатын беттерге кіруге болмайды |
| `Disallow: /` | Бүкіл сайтқа тыйым |
| `Disallow:` (бос) | Барлығына рұқсат |
| `Allow: /search/about` | Тыйым салынған бөлім ішіндегі ерекшелік (кейбір роботтар ережелерді ретімен оқитындықтан, `Allow` жолын `Disallow`-дан бұрын жазған дұрыс) |
| `Crawl-delay: 5` | Сұраныстар арасында кемінде 5 секунд |
| `Sitemap:` | Сайт картасының мекенжайы |

Браузерде тексеріп көріңіз: `https://www.wikipedia.org/robots.txt`, `https://github.com/robots.txt`, `https://books.toscrape.com/robots.txt`.

## 4. robots.txt-ті Python-да тексеру

Стандартты `urllib.robotparser` модулі бар:

```python
from urllib.robotparser import RobotFileParser

rules = """
User-agent: *
Allow: /search/about
Disallow: /admin/
Disallow: /search
Crawl-delay: 5

User-agent: BadBot
Disallow: /
""".splitlines()

rp = RobotFileParser()
rp.parse(rules)

for path in ["/", "/news/1", "/admin/users", "/search?q=python", "/search/about"]:
    url = "https://example.kz" + path
    print(f"{path:18} → {'рұқсат' if rp.can_fetch('PythonClubBot', url) else 'тыйым'}")
print("BadBot үшін /news:", rp.can_fetch("BadBot", "https://example.kz/news"))
print("Crawl-delay:", rp.crawl_delay("PythonClubBot"))
```

Нәтижесі:
```text
/                  → рұқсат
/news/1            → рұқсат
/admin/users       → тыйым
/search?q=python   → тыйым
/search/about      → рұқсат
BadBot үшін /news: False
Crawl-delay: 5
```

Нақты сайт үшін файлды интернеттен оқу:

```python
from urllib.robotparser import RobotFileParser

rp = RobotFileParser("https://books.toscrape.com/robots.txt")
try:
    rp.read()                                   # файлды жүктеп, талдайды
    print(rp.can_fetch("*", "https://books.toscrape.com/catalogue/page-2.html"))
except OSError:
    print("robots.txt жүктелмеді — интернетті тексеріңіз")
```

**Ескерту:** `robots.txt` табылмаса (404), `robotparser` барлығына рұқсат деп есептейді. Бірақ бұл сайт ережелерін (ToS) тексеруді алмастырмайды.

## 5. Сұраныс жиілігі: серверге құрмет

Бір адам браузерде секундына 1 бетті әрең ашады. Ал скрипт секундына жүздеген сұраныс жібере алады — бұл кішкентай сайт үшін **DoS-шабуылға** ұқсайды.

**Әдепті скрапер ережелері:**

| Ереже | Қалай іске асырамыз |
|---|---|
| Кідіріс жасау | `time.sleep(1)` немесе `Crawl-delay` мәні (қайсысы үлкен болса) |
| Параллель сұраныс жібермеу | Бір уақытта — бір сұраныс |
| Өзін таныстыру | `User-Agent: PythonClubBot/1.0 (+email немесе сайт)` |
| Тек қажеттіні жүктеу | Барлық сайтты емес, нақты беттерді |
| Қайта жүктемеу (кэш) | Бір рет жүктелген бетті файлда сақтау |
| 429/503 кодын құрметтеу | Тоқтау, күту (`Retry-After` тақырыбы) |
| Түнгі уақытты таңдау | Сайттың жүктемесі аз кезде |

## 6. «Әдепті скрапер» класы

```python
import time
from urllib.parse import urlparse
from urllib.robotparser import RobotFileParser

import requests


class PoliteScraper:
    """robots.txt-ті сақтайтын және сұраныс жиілігін шектейтін скрапер."""

    def __init__(self, base_url, user_agent="PythonClubBot/1.0 (oqu maqsatynda)", min_delay=1.0):
        self.user_agent = user_agent
        self.session = requests.Session()
        self.session.headers["User-Agent"] = user_agent
        self.robots = RobotFileParser(base_url.rstrip("/") + "/robots.txt")
        try:
            self.robots.read()
        except OSError:
            pass
        crawl_delay = self.robots.crawl_delay(user_agent) or 0
        self.delay = max(min_delay, crawl_delay)
        self.last_request = 0.0
        self.cache = {}

    def get(self, url):
        if not self.robots.can_fetch(self.user_agent, url):
            print("robots.txt тыйым салады:", url)
            return None
        if url in self.cache:                         # қайта жүктемейміз
            return self.cache[url]
        wait = self.delay - (time.monotonic() - self.last_request)
        if wait > 0:
            time.sleep(wait)
        r = self.session.get(url, timeout=10)
        self.last_request = time.monotonic()
        if r.status_code in (429, 503):
            print("Сервер жүктелген, кейінірек көріңіз. Код:", r.status_code)
            return None
        r.raise_for_status()
        self.cache[url] = r.text
        return r.text

# scraper = PoliteScraper("https://books.toscrape.com")
# html = scraper.get("https://books.toscrape.com/catalogue/page-1.html")
```

`requests.Session()` — бір сайтқа бірнеше сұраныс жібергенде қосылымды қайта пайдаланады (жылдамырақ, серверге жеңілірек) және тақырыптарды бір рет орнатуға мүмкіндік береді.

## 7. Жеке деректерді қорғау

**Дербес (жеке) деректер** — адамды тікелей немесе жанама анықтауға мүмкіндік беретін кез келген ақпарат:

| Түрі | Мысалдар |
|---|---|
| Тікелей анықтайтын | Аты-жөні, ЖСН (ИИН), паспорт нөмірі, фото |
| Байланыс | Телефон, email, мекенжай |
| Цифрлық із | Логин, IP-мекенжай, геолокация |
| Ерекше санаттар | Денсаулық, бағалар, діни көзқарас, биометрия |

**Ережелер:**
1. **Жинамаңыз**, егер жоба мақсатына қажет болмаса (деректерді азайту қағидасы).
2. Әлеуметтік желілерден адамдардың профильдерін, фотоларын, байланыстарын жаппай жинау — **рұқсат етілмейді**, тіпті олар ашық тұрса да.
3. Қажет болса — **анонимдеу/маскалау**: аттың орнына ID, телефонның орнына `+7 701 *** ** 67`.
4. Жинаған деректерді **таратпаңыз**, GitHub-қа жүктемеңіз (`.gitignore`-ға қосыңыз).
5. Жобадан кейін **өшіріңіз**.

Маскалау мысалы (`re` модулі):

```python
import re

text = "Байланыс: aigerim.s@mail.kz, тел. +7 701 123 45 67, Нұрлан: +77019876543"

email_re = re.compile(r"\b([\w.]{2})[\w.]*@([\w-]+\.[a-z]{2,})\b")
phone_re = re.compile(r"\+7[\s-]?(\d{3})[\s-]?\d{3}[\s-]?\d{2}[\s-]?(\d{2})")

masked = email_re.sub(r"\1***@\2", text)
masked = phone_re.sub(r"+7 \1 *** ** \2", masked)
print(masked)
```

Нәтижесі:
```text
Байланыс: ai***@mail.kz, тел. +7 701 *** ** 67, Нұрлан: +7 701 *** ** 43
```

## 8. Шешім қабылдау алгоритмі

```text
Деректер керек
   │
   ├─ Ресми API бар ма? ── иә ──► API қолдан (кілтті қауіпсіз сақта)
   │        жоқ
   ├─ Сайт ережелері (ToS) тыйым сала ма? ── иә ──► Жинама / рұқсат сұра
   │        жоқ
   ├─ robots.txt бұл бетке рұқсат бере ме? ── жоқ ──► Жинама
   │        иә
   ├─ Жеке деректер бар ма? ── иә ──► Жинама немесе тек анонимделген түрде
   │        жоқ
   ├─ Авторлық мазмұн ба? ── иә ──► Тек жеке талдау үшін, жарияламай, дереккөзді көрсетіп
   │        жоқ
   └─► Әдепті скрапер: кідіріс, User-Agent, кэш, тек қажетті беттер
```

## 9. «Скрапер этикасы кодексі»

1. Алдымен API іздеймін.
2. Сайт ережелері мен robots.txt-ті оқимын және сақтаймын.
3. Серверді жүктемеймін: кідіріс, бір уақытта бір сұраныс.
4. Өзімді таныстырамын (`User-Agent`).
5. Жеке деректерді жинамаймын, жарияламаймын.
6. Біреудің мазмұнын өзімдікі деп таратпаймын, дереккөзді көрсетемін.
7. Сайт иесі сұраса — тоқтатамын.

## Жиі кездесетін қателер

**1. «Деректер ашық тұр — демек, бәрін жинай беруге болады».** Ашық болу — кез келген мақсатта қолдануға рұқсат дегенді білдірмейді (әсіресе жеке деректер мен авторлық мазмұн).

**2. `time.sleep()` жоқ цикл:**
```python
import time
pages = ["/page-1", "/page-2", "/page-3"]
for p in pages:
    # requests.get(base + p)   ← кідіріссіз жүздеген сұраныс — дұрыс емес
    time.sleep(1)              # дұрыс: әр сұраныстан кейін кідіріс
print("Дайын")
```

**3. Браузер болып «жасырыну»** — User-Agent-ті жалған браузер жолымен ауыстырып, бұғаттауды айналып өту этикаға қайшы. Сайт сізді бұғаттаса — бұл «жоқ» деген жауап.

**4. robots.txt-ті тек бір рет, қолмен оқу** — ол өзгеруі мүмкін; бағдарлама әр іске қосылғанда тексеруі тиіс.

**5. Скрапинг нәтижесін (жеке деректермен) GitHub-қа жүктеу** — `.gitignore`-ға деректер папкасын қосыңыз.

**6. 429 кодын елемей, қайта-қайта сұрау** — сервер IP-ді біржола бұғаттауы мүмкін.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Terms of Service (ToS) | Сайтты пайдалану шарттары |
| robots.txt | Роботтарға арналған кіру ережелері файлы |
| `User-agent` / `Disallow` / `Allow` | robots.txt директивалары: кімге / тыйым / ерекшелік |
| `Crawl-delay` | Сұраныстар арасындағы ұсынылған кідіріс |
| `RobotFileParser` | robots.txt-ті талдайтын Python класы |
| Rate limiting | Сұраныс жиілігін шектеу |
| DoS | Серверді шамадан тыс сұраныспен істен шығару |
| Дербес деректер | Адамды анықтауға мүмкіндік беретін ақпарат |
| Анонимдеу / маскалау | Жеке деректерді анықталмайтын түрге келтіру |
| Авторлық құқық | Шығарма авторының заңмен қорғалатын құқықтары |

## Ескерту

- `urllib.robotparser.RobotFileParser` стандартты кітапханаға кіреді: `can_fetch(useragent, url)`, ал Python 3.6+ нұсқасында `crawl_delay(useragent)` және `request_rate(useragent)` бар (https://docs.python.org/3/library/urllib.robotparser.html).
- `robots.txt` табылмаса (404), `RobotFileParser` бәріне рұқсат бар деп санайды; 401/403 жауабында — бәріне тыйым салынған деп санайды.
- Тұрақты кідірісті кездейсоқ бөлікпен толықтыруға болады (`random.uniform(1, 2)`); `429` жауабында `Retry-After` тақырыбын ескеріңіз.
- Бір іске қосу ішіндегі қайталанатын сұраныстарды кэштеу үшін `{url: html}` сөздігі немесе `functools.lru_cache` жарайды.
- `robots.txt`-те тыйым болмауы сайт ережелерін (Terms of Service) және дербес деректер туралы заңдарды жоймайды.
