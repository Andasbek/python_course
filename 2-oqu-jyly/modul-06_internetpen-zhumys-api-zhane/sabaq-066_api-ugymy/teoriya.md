## 1. API деген не?

**API (Application Programming Interface)** — бағдарламалардың бір-бірімен сөйлесу ережелері, яғни «бағдарламалық интерфейс».

**Аналогия: мейрамхана мәзірі.** Сіз ас үйге кіріп, өзіңіз тамақ жасамайсыз. Мәзірден (API құжаттамасы) таңдап, даяшыға (HTTP сұраныс) айтасыз, дайын тамақ (JSON жауап) келеді. Ас үйдің ішінде не болып жатқанын білудің қажеті жоқ.

| Интерфейс түрі | Кімге арналған | Мысал |
|---|---|---|
| GUI (графикалық) | Адамға | Tkinter терезесі, сайт беті |
| API (бағдарламалық) | Бағдарламаға | `https://api.open-meteo.com/v1/forecast` |

Біз API-мен бұрын да жұмыс істедік: `sqlite3` модулінің `connect()`, `execute()` әдістері — SQLite-тың Python API-ы. Бүгін — **Web API**: интернет арқылы HTTP көмегімен шақырылатын API.

### API неге керек?

- Kaspi қосымшасы валюта бағамын өзі есептемейді — банк API-ынан алады.
- 2GIS, Яндекс Такси — карта API-ын қолданады.
- Ауа райы виджеттері — метеорологиялық API.
- Біздің бағдарламамыз да 10 жол кодпен әлемдік деректерге қол жеткізеді!

## 2. REST API негіздері

Көптеген Web API **REST** стилінде жасалған. Негізгі қағидалары:

- Әр **ресурстың** өз URL-і бар (эндпоинт): `/users`, `/users/5`, `/forecast`.
- Әрекет **HTTP әдісімен** анықталады: GET — алу, POST — құру, PUT — өзгерту, DELETE — өшіру.
- Жауап — көбіне **JSON**.
- Сервер клиенттің алдыңғы сұраныстарын «есте сақтамайды» (stateless) — әр сұраныста қажетті ақпараттың бәрі болады.

```text
Базалық URL (base URL)           Эндпоинт        Параметрлер
https://api.open-meteo.com   +   /v1/forecast  + ?latitude=43.25&longitude=76.95
```

**Эндпоинт (endpoint)** — API-дің нақты бір мүмкіндігіне сәйкес мекенжай.

## 3. API құжаттамасын оқу

Кез келген API-мен жұмыс **құжаттаманы** оқудан басталады. Онда:

| Бөлім | Не жазылады |
|---|---|
| Base URL | Барлық эндпоинттердің ортақ басы |
| Endpoints | Қол жетімді мекенжайлар тізімі |
| Parameters | Міндетті (required) және қосымша (optional) параметрлер, олардың типтері |
| Response | Жауаптың құрылымы, өрістердің мағынасы, өлшем бірліктері |
| Authentication | Кілт керек пе, қалай беріледі |
| Rate limits | Қанша сұраныс жіберуге болады |
| Errors | Қате кодтары және олардың мағынасы |

Open-Meteo құжаттамасы: `https://open-meteo.com/en/docs`. Онда интерактивті конструктор бар — параметрлерді белгілесеңіз, дайын URL жасап береді.

## 4. API түрлері: кілт және шектеулер

| Түрі | Сипаттамасы | Мысал |
|---|---|---|
| Ашық (кілтсіз) | Тіркелусіз, бірден қолдануға болады | Open-Meteo, open.er-api.com |
| Тегін, кілтпен | Тіркеліп, жеке API кілтін (API key) аласыз | OpenWeatherMap, NewsAPI |
| Ақылы | Сұраныс санына қарай төлем | Google Maps, OpenAI |

**Rate limit (сұраныс шектеуі)** — уақыт бірлігіндегі рұқсат етілген сұраныс саны. Мысалы, Open-Meteo коммерциялық емес қолдану үшін күніне 10 000 сұранысқа дейін рұқсат етеді. Шектен асса — `429 Too Many Requests`.

**API кілті** — сіздің «жеке пропускіңіз». Оны код ішінде сақтауға болмайды. Төмендегі мысалдарда кілтсіз API-лар қолданылады.

## 5. Open-Meteo: ауа райы API

Эндпоинт: `https://api.open-meteo.com/v1/forecast`

| Параметр | Мағынасы | Мысал |
|---|---|---|
| `latitude`, `longitude` | Ендік, бойлық (міндетті) | `43.25`, `76.95` |
| `current` | Қазіргі мәндер тізімі | `temperature_2m,wind_speed_10m,weather_code` |
| `daily` | Күндік болжам | `temperature_2m_max,temperature_2m_min` |
| `timezone` | Уақыт белдеуі | `Asia/Almaty` немесе `auto` |
| `forecast_days` | Болжам күні (1–16) | `3` |

```python
import requests

URL = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 43.25,
    "longitude": 76.95,
    "current": "temperature_2m,relative_humidity_2m,wind_speed_10m,weather_code",
    "timezone": "auto",
}
r = requests.get(URL, params=params, timeout=10)
r.raise_for_status()
data = r.json()

cur = data["current"]
units = data["current_units"]
print("Уақыты:", cur["time"])
print("Температура:", cur["temperature_2m"], units["temperature_2m"])
print("Ылғалдылық:", cur["relative_humidity_2m"], units["relative_humidity_2m"])
print("Жел:", cur["wind_speed_10m"], units["wind_speed_10m"])
print("Ауа райы коды:", cur["weather_code"])
```

Нәтижесі (мәндер әр сәтте әртүрлі):
```text
Уақыты: 2027-02-09T14:15
Температура: -1.8 °C
Ылғалдылық: 71 %
Жел: 6.4 km/h
Ауа райы коды: 3
```

### Ауа райы кодтары (WMO)

API ауа райын сөзбен емес, **сандық кодпен** береді. Оны сөздік арқылы аударамыз:

```python
WEATHER_CODES = {
    0: "Ашық аспан ☀️", 1: "Негізінен ашық 🌤", 2: "Ішінара бұлтты ⛅", 3: "Бұлтты ☁️",
    45: "Тұман 🌫", 48: "Қырау тұманы 🌫",
    51: "Әлсіз сіркіреме", 53: "Сіркіреме", 55: "Күшті сіркіреме",
    61: "Әлсіз жаңбыр 🌦", 63: "Жаңбыр 🌧", 65: "Нөсер 🌧",
    71: "Әлсіз қар 🌨", 73: "Қар 🌨", 75: "Қалың қар ❄️",
    80: "Аздаған жауын", 81: "Жауын", 82: "Қатты жауын",
    95: "Найзағай ⛈",
}

def describe(code):
    return WEATHER_CODES.get(code, f"Белгісіз ({code})")

print(describe(3))
print(describe(73))
```

Нәтижесі:
```text
Бұлтты ☁️
Қар 🌨
```

## 6. Геокодтау: қала атауы → координаталар

Пайдаланушы координаталарды білмейді, ол «Қарағанды» деп жазады. **Геокодтау (geocoding)** — атауды координаталарға айналдыру.

```python
import requests

def find_city(name):
    r = requests.get(
        "https://geocoding-api.open-meteo.com/v1/search",
        params={"name": name, "count": 1, "language": "ru"},
        timeout=10,
    )
    r.raise_for_status()
    results = r.json().get("results")      # табылмаса "results" кілті болмайды
    if not results:
        return None
    c = results[0]
    return c["name"], c.get("country", ""), c["latitude"], c["longitude"]

print(find_city("Караганда"))
print(find_city("Qwertyuiop"))
```

Нәтижесі:
```text
('Караганда', 'Казахстан', 49.80187, 73.10211)
None
```

Назар аударыңыз: `.get("results")` — кілт жоқ болса, `KeyError` емес, `None` қайтарады. API жауабының құрылымы әрқашан біз күткендей бола бермейді!

## 7. Валюта бағамы API

Эндпоинт: `https://open.er-api.com/v6/latest/<БАЗАЛЫҚ_ВАЛЮТА>` — кілтсіз, күніне бір рет жаңарады.

```python
import requests

r = requests.get("https://open.er-api.com/v6/latest/USD", timeout=10)
r.raise_for_status()
data = r.json()

if data["result"] == "success":
    rates = data["rates"]
    print("Жаңартылған:", data["time_last_update_utc"])
    for code in ("KZT", "RUB", "EUR", "CNY"):
        print(f"1 USD = {rates[code]:.2f} {code}")
```

Нәтижесі (бағам күн сайын өзгереді):
```text
Жаңартылған: Tue, 09 Feb 2027 00:02:31 +0000
1 USD = 512.40 KZT
1 USD = 91.25 RUB
1 USD = 0.92 EUR
1 USD = 7.18 CNY
```

### Валюта айырбастағыш

Кросс-бағам: егер 1 USD = 512 KZT және 1 USD = 0.92 EUR болса, онда 1 EUR = 512 / 0.92 KZT.

```python
def convert(amount, from_cur, to_cur, rates):
    """rates — USD негізіндегі бағамдар сөздігі."""
    usd = amount / rates[from_cur]
    return usd * rates[to_cur]

rates = {"USD": 1, "KZT": 512.4, "EUR": 0.92, "RUB": 91.25}
print(f"100 EUR = {convert(100, 'EUR', 'KZT', rates):,.0f} KZT")
print(f"10000 KZT = {convert(10000, 'KZT', 'RUB', rates):.2f} RUB")
```

Нәтижесі:
```text
100 EUR = 55,696 KZT
10000 KZT = 1780.84 RUB
```

## 8. API-мен жұмыстың алтын ережелері

1. **Құжаттаманы оқы** — параметр атауларын ойдан шығарма.
2. **Алдымен браузерде тексер** — URL-ді браузерде ашып, JSON құрылымын көр.
3. **`timeout` және `try/except`** — желі сенімсіз.
4. **Жауапты тексер** — `status_code`, `result`, `.get()`.
5. **Шектеулерді сақта** — циклде жүздеген сұраныс жіберме; деректер жиі өзгермесе, сақтап қой (кэш).
6. **Дереккөзді көрсет** — көптеген тегін API-лар «Data by Open-Meteo.com» деген сілтемені талап етеді.

## Жиі кездесетін қателер

**1. Параметр атауын қате жазу** — `lat` орнына `latitude` керек. API `400 Bad Request` қайтарады, ал дене ішінде себебі жазылады:
```python
import requests
r = requests.get("https://api.open-meteo.com/v1/forecast", params={"lat": 43.25}, timeout=10)
print(r.status_code, r.json().get("reason"))
```

**2. `KeyError` — жауап құрылымын білмей кілтке жүгіну.** Алдымен `print(data.keys())` немесе браузерде қараңыз; міндетті емес өрістерге `.get()`.

**3. Бағамды кері қолдану** — `rates["KZT"]` = «1 USD үшін теңге». Теңгені долларға айналдыру үшін **бөлеміз**, көбейтпейміз.

**4. Ендік пен бойлықты ауыстырып алу** — Алматының орнына Қытайдағы бір нүктенің немесе мұхиттың ауа райын аласыз. Ендік (latitude) — солтүстік/оңтүстік, Қазақстан үшін ≈ 40–55.

**5. Әр секунд сайын API-ға сұраныс** — ауа райы әр 15 минутта, бағам күніне бір рет жаңарады. Жиі сұрау — шектеуді бекер жұмсау.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| API | Бағдарламалардың өзара әрекеттесу интерфейсі |
| Web API | HTTP арқылы шақырылатын API |
| REST | Ресурстар мен HTTP әдістеріне негізделген API стилі |
| Эндпоинт | API-дің нақты мүмкіндігіне сәйкес URL |
| Base URL | Барлық эндпоинттердің ортақ бөлігі |
| API кілті | Пайдаланушыны анықтайтын құпия жол |
| Rate limit | Сұраныс санына шектеу |
| Геокодтау | Мекенжай/атауды координаталарға айналдыру |
| WMO коды | Ауа райы жағдайының халықаралық сандық коды |
| Кросс-бағам | Үшінші валюта арқылы есептелген бағам |

## Ескерту

- Сұраныс параметрлерін `params=` арқылы беріңіз — `requests` URL-дегі бос орындар мен кириллицаны өзі кодтайды (`"Алматы"` → `%D0%90...`).
- Open-Meteo `timezone` параметрі берілмесе, уақытты UTC бойынша қайтарады (мысалы, `timezone="auto"` немесе `"Asia/Almaty"` беріңіз).
- Валюта бағамымен ақша есептеулері үшін `float` орнына `decimal.Decimal` дұрысырақ: `0.1 + 0.2 != 0.3` (https://docs.python.org/3/library/decimal.html).
- API жауабының құрылымы нұсқалар арасында (`/v1/`, `/v2/`) өзгеруі мүмкін — URL-дегі нұсқаны және құжаттаманы тексеріңіз.
- Бірдей сұраныстарға лимитті жұмсамау үшін жауаптарды кэштеңіз (мысалы, сұраныс уақыты бар сөздікте).
