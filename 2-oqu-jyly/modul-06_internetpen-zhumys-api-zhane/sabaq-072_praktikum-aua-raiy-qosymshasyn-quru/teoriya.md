### Өз ерекшелігіміз (exception)

API қабаты GUI-ге «қала табылмады» дегенді қалай хабарлайды? `print` емес — **ерекшелік лақтырады**, ал GUI оны ұстап, `messagebox` көрсетеді. ОБП модулінен (II модуль) білетін мұрагерлікті қолданамыз:

```python
class CityNotFound(Exception):
    """Геокодтау API-ы қаланы таппағанда лақтырылады."""


def find_city_demo(name, known):
    if name not in known:
        raise CityNotFound(f"«{name}» қаласы табылмады")
    return known[name]


try:
    find_city_demo("Атлантида", {"Алматы": (43.25, 76.95)})
except CityNotFound as e:
    print("Қате:", e)
```

Нәтижесі:
```text
Қате: «Атлантида» қаласы табылмады
```

## 5. Терезе неге «қатып» қалады?

Tkinter бір ағында (thread) жұмыс істейді: `mainloop()` оқиғаларды өңдейді, терезені қайта салады. Егер батырма функциясы `requests.get()` арқылы 3 секунд күтсе, осы 3 секундта терезе ешнәрсеге жауап бермейді («Не отвечает»).

**Қарапайым шешім (базалық деңгей):** курсорды «күту» түріне ауыстырып, `update_idletasks()` арқылы «Жүктелуде...» жазуын көрсету — терезе бәрібір қатады, бірақ пайдаланушы не болып жатқанын түсінеді.

**Дұрыс шешім (кеңейтілген деңгей):** сұранысты **фондық ағында** (`threading.Thread`) орындау, ал нәтижені GUI-ге `root.after()` арқылы негізгі ағынға қайтару. Ереже: **Tkinter виджеттерін тек негізгі ағыннан өзгертеміз**.

```python
import threading
import time


def slow_request(city):
    time.sleep(1)                       # requests.get(...) имитациясы
    return f"{city}: −2 °C"


def on_search(city, show):
    def worker():
        result = slow_request(city)
        show(result)                    # Tkinter-де: root.after(0, show, result)
    threading.Thread(target=worker, daemon=True).start()
    print("Сұраныс жіберілді, терезе жауап беріп тұр...")


on_search("Алматы", print)
time.sleep(1.5)
```

Нәтижесі:
```text
Сұраныс жіберілді, терезе жауап беріп тұр...
Алматы: −2 °C
```

`daemon=True` — бағдарлама жабылғанда фондық ағын да тоқтайды.

## 6. Баптауларды сақтау

Баптауларды JSON файлында сақтау ыңғайлы:

```python
import json
from pathlib import Path

SETTINGS = Path("settings.json")


def load_settings():
    try:
        return json.loads(SETTINGS.read_text(encoding="utf-8"))
    except (FileNotFoundError, json.JSONDecodeError):
        return {"last_city": "Алматы"}


def save_settings(data):
    SETTINGS.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


s = load_settings()
s["last_city"] = "Шымкент"
save_settings(s)
print(load_settings())
```

Нәтижесі:
```text
{'last_city': 'Шымкент'}
```

## 8. Қысқаша анықтамалық: HTTP, API, скрапинг

| Тақырып | Негізгісі |
|---|---|
| HTTP | Сұраныс: әдіс + URL + тақырыптар (+ дене); жауап: күй коды + тақырыптар + дене |
| Күй кодтары | `200` OK, `301/302` бағыттау, `404` табылмады, `429` сұраныс тым көп, `500` сервер қатесі |
| `requests` | `get(url, params=..., headers=..., timeout=...)`, `raise_for_status()`, `json()` |
| Кілттер | `.env` + `python-dotenv`, `.env` — `.gitignore`-да |
| Скрапинг | `BeautifulSoup(html, "html.parser")`, `find/find_all`, `select/select_one` |
| Этика | robots.txt, сұраныстар арасындағы кідіріс, дербес деректерсіз |

```python
import requests
from bs4 import BeautifulSoup

try:
    r = requests.get("https://api.open-meteo.com/v1/forecast",
                     params={"latitude": 43.24, "longitude": 76.89,
                             "current": "temperature_2m"},
                     timeout=10)
    r.raise_for_status()
    print(r.json()["current"]["temperature_2m"])
except requests.exceptions.RequestException as e:
    print("Желі қатесі:", e)

html = "<ul><li class='city'>Алматы</li><li class='city'>Астана</li></ul>"
soup = BeautifulSoup(html, "html.parser")
print([li.get_text(strip=True) for li in soup.select("li.city")])
```

## Жиі кездесетін қателер

**1. GUI ішінде `requests` және API ішінде `messagebox`** — қабаттар араласады. API қабаты тек деректер немесе ерекшелік қайтарады.

**2. Фондық ағыннан виджетті тікелей өзгерту** — кездейсоқ «құлау» немесе `RuntimeError`. Әрқашан `root.after(0, функция, аргумент)`.

**3. Жаңа іздеуде кестені тазаламау** — болжам жолдары жинала береді: `tree.delete(*tree.get_children())`.

**4. `except Exception: pass`** — қате «жұтылады», пайдаланушы ештеңе көрмейді. Әр қате түріне нақты хабар.

**5. Сезілетін температура мен нақты температураны шатастыру** — `apparent_temperature` жел мен ылғалды ескереді.

**6. Батырманы бірнеше рет басу** — бірнеше параллель сұраныс. Сұраныс кезінде батырманы `state="disabled"` етіңіз.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| API қабаты | Желімен жұмыс істейтін, GUI-ден тәуелсіз модуль |
| Пайдаланушылық ерекшелік | `Exception`-нан мұраланған өз қате класы |
| Ағын (thread) | Бағдарлама ішіндегі параллель орындалу жолы |
| `threading.Thread` | Фондық ағын жасау класы |
| `root.after()` | Функцияны Tkinter-дің негізгі ағынында кейінірек орындау |
| `daemon=True` | Бағдарламамен бірге тоқтайтын фондық ағын |
| `settings.json` | Пайдаланушы баптаулары файлы |

## Ескерту

- Tkinter ағындар үшін қауіпсіз емес: виджеттерді тек негізгі ағыннан өзгертіңіз, фондық ағыннан — `root.after()` арқылы (https://docs.python.org/3/library/tkinter.html#threading-model).
- `daemon=True` ағыны бағдарламадан шыққанда күштеп тоқтатылады — онда үзуге болмайтын файл жазу әрекеттерін орындамаңыз.
- Өз ерекшеліктеріңізді `BaseException`-нан емес, `Exception`-нан мұралаңыз және PEP 8 бойынша `Error` жұрнағымен атаңыз: `CityNotFoundError`.
- `json.dump(..., ensure_ascii=False)` кириллицаны оқылатын күйде сақтайды; файлды `encoding="utf-8"` арқылы ашыңыз.
- `settings.json` жолын ағымдағы қалтадан емес, скрипт орналасқан жерден құрыңыз: `Path(__file__).parent / "settings.json"`.
