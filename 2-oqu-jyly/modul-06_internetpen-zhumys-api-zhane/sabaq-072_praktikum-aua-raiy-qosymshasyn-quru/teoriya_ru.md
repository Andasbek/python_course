### Собственное исключение (exception)

Как слою API сообщить GUI, что «город не найден»? Не через `print` — он **выбрасывает исключение**, а GUI его перехватывает и показывает `messagebox`. Используем наследование, известное из модуля ООП (II модуль):

```python
class CityNotFound(Exception):
    """Выбрасывается, когда API геокодирования не нашёл город."""


def find_city_demo(name, known):
    if name not in known:
        raise CityNotFound(f"Город «{name}» не найден")
    return known[name]


try:
    find_city_demo("Атлантида", {"Алматы": (43.25, 76.95)})
except CityNotFound as e:
    print("Ошибка:", e)
```

Результат:
```text
Ошибка: Город «Атлантида» не найден
```

## 5. Почему окно «зависает»?

Tkinter работает в одном потоке (thread): `mainloop()` обрабатывает события, перерисовывает окно. Если функция кнопки 3 секунды ждёт `requests.get()`, в эти 3 секунды окно ни на что не реагирует («Не отвечает»).

**Простое решение (базовый уровень):** сменить курсор на «ожидание» и показать надпись «Загрузка...» через `update_idletasks()` — окно всё равно зависнет, но пользователь понимает, что происходит.

**Правильное решение (продвинутый уровень):** выполнять запрос в **фоновом потоке** (`threading.Thread`), а результат возвращать в GUI в основной поток через `root.after()`. Правило: **виджеты Tkinter изменяем только из основного потока**.

```python
import threading
import time


def slow_request(city):
    time.sleep(1)                       # имитация requests.get(...)
    return f"{city}: −2 °C"


def on_search(city, show):
    def worker():
        result = slow_request(city)
        show(result)                    # в Tkinter: root.after(0, show, result)
    threading.Thread(target=worker, daemon=True).start()
    print("Запрос отправлен, окно отвечает...")


on_search("Алматы", print)
time.sleep(1.5)
```

Результат:
```text
Запрос отправлен, окно отвечает...
Алматы: −2 °C
```

`daemon=True` — при закрытии программы фоновый поток тоже останавливается.

## 6. Сохранение настроек

Настройки удобно хранить в JSON-файле:

```python
import json
from pathlib import Path

SETTINGS = Path("settings.json")


def load_settings():
    try:
        return json.loads(SETTINGS.read_text(encoding="utf-8"))
    except (FileNotFoundError, json.JSONDecodeError):
        return {"last_city": "Алматы"}


def save_settings(data):
    SETTINGS.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


s = load_settings()
s["last_city"] = "Шымкент"
save_settings(s)
print(load_settings())
```

Результат:
```text
{'last_city': 'Шымкент'}
```

## 8. Краткая шпаргалка: HTTP, API, скрапинг

| Тема | Главное |
|---|---|
| HTTP | Запрос: метод + URL + заголовки (+ тело); ответ: код состояния + заголовки + тело |
| Коды состояния | `200` OK, `301/302` перенаправление, `404` не найдено, `429` слишком много запросов, `500` ошибка сервера |
| `requests` | `get(url, params=..., headers=..., timeout=...)`, `raise_for_status()`, `json()` |
| Ключи | `.env` + `python-dotenv`, `.env` — в `.gitignore` |
| Скрапинг | `BeautifulSoup(html, "html.parser")`, `find/find_all`, `select/select_one` |
| Этика | robots.txt, паузы между запросами, без персональных данных |

```python
import requests
from bs4 import BeautifulSoup

try:
    r = requests.get("https://api.open-meteo.com/v1/forecast",
                     params={"latitude": 43.24, "longitude": 76.89,
                             "current": "temperature_2m"},
                     timeout=10)
    r.raise_for_status()
    print(r.json()["current"]["temperature_2m"])
except requests.exceptions.RequestException as e:
    print("Ошибка сети:", e)

html = "<ul><li class='city'>Алматы</li><li class='city'>Астана</li></ul>"
soup = BeautifulSoup(html, "html.parser")
print([li.get_text(strip=True) for li in soup.select("li.city")])
```

## Частые ошибки

**1. `requests` внутри GUI и `messagebox` внутри API** — слои смешиваются. Слой API возвращает только данные или исключение.

**2. Прямое изменение виджета из фонового потока** — случайные «падения» или `RuntimeError`. Всегда `root.after(0, функция, аргумент)`.

**3. Таблица не очищается при новом поиске** — строки прогноза накапливаются: `tree.delete(*tree.get_children())`.

**4. `except Exception: pass`** — ошибка «проглатывается», пользователь ничего не видит. Для каждого типа ошибки — конкретное сообщение.

**5. Путаница ощущаемой и фактической температуры** — `apparent_temperature` учитывает ветер и влажность.

**6. Многократное нажатие кнопки** — несколько параллельных запросов. На время запроса делайте кнопку `state="disabled"`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Слой API | Модуль, работающий с сетью, независимый от GUI |
| Пользовательское исключение | Собственный класс ошибки, унаследованный от `Exception` |
| Поток (thread) | Параллельный путь выполнения внутри программы |
| `threading.Thread` | Класс для создания фонового потока |
| `root.after()` | Отложенное выполнение функции в основном потоке Tkinter |
| `daemon=True` | Фоновый поток, останавливающийся вместе с программой |
| `settings.json` | Файл пользовательских настроек |

## Примечание

- Tkinter не потокобезопасен: виджеты меняют только из главного потока, а из фонового — через `root.after()` (https://docs.python.org/3/library/tkinter.html#threading-model).
- Поток с `daemon=True` принудительно останавливается при выходе из программы — не выполняйте в нём запись файлов, которую нельзя прерывать.
- Собственные исключения наследуйте от `Exception` (не от `BaseException`) и по PEP 8 называйте с суффиксом `Error`: `CityNotFoundError`.
- `json.dump(..., ensure_ascii=False)` сохраняет кириллицу в читаемом виде; открывайте файл с `encoding="utf-8"`.
- Путь к `settings.json` стройте от расположения скрипта, а не от текущей папки запуска: `Path(__file__).parent / "settings.json"`.
