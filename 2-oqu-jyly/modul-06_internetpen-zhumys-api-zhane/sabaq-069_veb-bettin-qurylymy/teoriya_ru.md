## 1. Что такое HTML?

**HTML (HyperText Markup Language)** — язык гипертекстовой разметки. Это **не** язык программирования (нет циклов, условий), он описывает **структуру** текста: здесь заголовок, здесь абзац, здесь ссылка.

Три «слоя» веб-страницы:

| Технология | Роль | Аналогия (дом) |
|---|---|---|
| HTML | Структура, содержимое | Стены, комнаты |
| CSS | Оформление (цвет, шрифт, расположение) | Обои, мебель |
| JavaScript | Интерактивность | Электричество, лифт |

Для скрапинга самое важное для нас — **HTML**.

## 2. Тег, элемент, атрибут

```html
<a href="https://python.org" class="link">Сайт Python</a>
```

```text
<a href="https://python.org" class="link">Сайт Python</a>
 │  └──────────┬───────────┘ └────┬─────┘ └─────┬────┘ └┬┘
 │       атрибут 1          атрибут 2    содержимое  закрывающий тег
 └ имя открывающего тега
└────────────────────── элемент (целиком) ───────────────────┘
```

- **Тег** — знак в угловых скобках: `<p>`, `</p>`.
- **Элемент** — открывающий тег + содержимое + закрывающий тег.
- **Атрибут** — дополнительная информация для тега: `имя="значение"`.
- **Пустые (незакрываемые) теги:** `<img>`, `<br>`, `<input>`, `<meta>`, `<hr>` — без содержимого.

## 3. Структура HTML-документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Кружок Python</title>
</head>
<body>
    <h1>Добро пожаловать в кружок Python!</h1>
    <p>Мы изучаем программирование <b>в Алматы</b>.</p>
</body>
</html>
```

| Часть | Значение |
|---|---|
| `<!DOCTYPE html>` | Тип документа: HTML5 |
| `<html lang="ru">` | Корневой элемент, язык — русский |
| `<head>` | Служебная информация (не видна на экране): кодировка, название во вкладке браузера, ссылки на CSS |
| `<meta charset="UTF-8">` | Кодировка — чтобы казахские и русские буквы отображались правильно |
| `<title>` | Название вкладки |
| `<body>` | Всё содержимое, видимое на экране |

## 4. Часто используемые теги

### Текст

| Тег | Значение |
|---|---|
| `<h1>` … `<h6>` | Заголовки (h1 — самый важный) |
| `<p>` | Абзац |
| `<b>`, `<strong>` | Жирный / важный текст |
| `<i>`, `<em>` | Курсив / выделение |
| `<br>` | Новая строка |
| `<span>` | Часть текста внутри строки (сам по себе ничего не меняет) |

### Ссылки и изображения

```html
<a href="https://open-meteo.com" target="_blank">Сайт Open-Meteo</a>
<a href="/news/15">Новость №15</a>             <!-- относительная ссылка -->
<img src="images/logo.png" alt="Логотип кружка" width="200">
```

- `href` — адрес ссылки. Может быть **абсолютным** (`https://...`) или **относительным** (`/news/15`) — важно для скрапинга!
- `src` — файл изображения, `alt` — текст, который выводится, если изображение не отображается.

### Списки

```html
<ul>                       <!-- ненумерованный список -->
    <li>Python</li>
    <li>JavaScript</li>
</ul>
<ol>                       <!-- нумерованный список -->
    <li>Регистрация</li>
    <li>Приход на занятие</li>
</ol>
```

### Таблицы

```html
<table>
    <tr>
        <th>Город</th>
        <th>Население (тыс.)</th>
    </tr>
    <tr>
        <td>Алматы</td>
        <td>2200</td>
    </tr>
    <tr>
        <td>Астана</td>
        <td>1500</td>
    </tr>
</table>
```

`<table>` — таблица, `<tr>` — строка (table row), `<th>` — ячейка заголовка, `<td>` — ячейка данных. На многих сайтах есть ещё теги `<thead>` (часть заголовков) и `<tbody>` (тело). Таблицы — самый «выгодный» объект скрапинга!

### Контейнеры

```html
<div class="card">
    <h3 class="card-title">Ноутбук Lenovo</h3>
    <span class="price">349 990 ₸</span>
</div>
```

`<div>` — блочный контейнер (начинается с новой строки), `<span>` — строчный контейнер. Сами по себе не имеют смысла, но «называются» через `class`. В HTML5 есть и смысловые контейнеры: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`.

### Форма (для знакомства)

```html
<form action="/search" method="get">
    <input type="text" name="q" placeholder="Поиск...">
    <button type="submit">Найти</button>
</form>
```

Заметьте: `method="get"` и `name="q"` → браузер отправит URL `/search?q=...`. Это параметры URL (query string).

## 5. Атрибуты `class` и `id`

| Атрибут | Особенность | Пример |
|---|---|---|
| `id` | **Уникален** на странице (только у одного элемента) | `<div id="main-menu">` |
| `class` | Повторяется у многих элементов; у одного элемента может быть несколько классов | `<div class="card product">` |

Например, каждая карточка товара в интернет-магазине имеет `class="product-card"`. При скрапинге мы говорим «найди все элементы с классом `product-card`» — это очень удобно.

## 6. DOM-дерево

Браузер превращает HTML в **DOM (Document Object Model)** — дерево элементов. Между элементами есть «родственные» отношения:

```text
html
├── head
│   └── title  → "Магазин"
└── body
    ├── h1  → "Товары"
    └── div.catalog
        ├── div.card            ← родитель (parent) — для h3 и span
        │   ├── h3.card-title   ← потомок первого уровня (child)
        │   └── span.price      ← сосед (sibling) — для h3
        └── div.card
            ├── h3.card-title
            └── span.price
```

| Термин | Значение |
|---|---|
| Родитель (parent) | Элемент, непосредственно содержащий данный |
| Дочерний (child) | Элемент непосредственно внутри |
| Потомок (descendant) | Вложенный элемент на любой глубине |
| Сосед (sibling) | Элемент с общим родителем |

Скрапинг — это «путешествие» по этому дереву: «из каждого `div.card` внутри `div.catalog` возьми текст `span.price`».

## 7. CSS-селекторы (то, что нужно для скрапинга)

CSS-селектор — «адрес» для поиска элементов. Именно такие селекторы принимает метод `select()` в BeautifulSoup.

| Селектор | Что находит |
|---|---|
| `p` | Все `<p>` |
| `.price` | Элементы с `class="price"` |
| `#main-menu` | Элемент с `id="main-menu"` |
| `div.card` | `<div>` с классом `card` |
| `div.card span` | Все `<span>` внутри `div.card` (потомки) |
| `ul > li` | `li` — непосредственные дочерние элементы `ul` |
| `a[href]` | Ссылки с атрибутом `href` |
| `table tr td:nth-child(2)` | Ячейки 2-го столбца таблицы |

## 8. Исследование структуры в браузере

1. **Просмотр кода страницы** — `Ctrl+U` (или правая кнопка → «Просмотр кода страницы»). Это **исходный** HTML, отправленный сервером (именно его получает `requests`!).
2. **DevTools → Elements** — `F12` или правой кнопкой по элементу → «Inspect / Посмотреть код». Здесь — DOM **после** выполнения браузером JavaScript.
3. Если навести мышь на тег в панели Elements, соответствующий элемент подсветится на странице.
4. Правая кнопка по элементу → **Copy → Copy selector** — даёт готовый CSS-селектор.
5. `Ctrl+F` (внутри Elements) — поиск по селектору: введите `.price` и посмотрите, сколько элементов найдено.

**Важное различие:** некоторые сайты подгружают содержимое позже через JavaScript. Тогда в `Ctrl+U` данных нет, а в Elements они есть. Такие сайты трудно скрапить через `requests` + BeautifulSoup — чаще правильнее найти API, стоящий за ними (Network → Fetch/XHR).

## 9. Создание HTML с помощью Python

HTML — обычный текст, поэтому его легко генерировать в Python. Например, страница с таблицей городов:

```python
import webbrowser
from pathlib import Path

cities = [("Алматы", 2200), ("Астана", 1500), ("Шымкент", 1250)]

rows = "\n".join(f"        <tr><td>{name}</td><td>{pop}</td></tr>" for name, pop in cities)
html = f"""<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Города</title>
</head>
<body>
    <h1>Крупные города Казахстана</h1>
    <table border="1">
        <tr><th>Город</th><th>Население (тыс.)</th></tr>
{rows}
    </table>
</body>
</html>"""

path = Path("cities.html")
path.write_text(html, encoding="utf-8")
print("Файл создан:", path.resolve())
# webbrowser.open(path.resolve().as_uri())   # открыть в браузере
```

Результат:
```text
Файл создан: /home/student/cities.html
```

Этот способ полезен для создания отчётов: например, можно вывести HTML-отчёт из «Базы учеников».

**Примечание:** вставляя в HTML текст, введённый пользователем, символы `<`, `>`, `&` нужно обезопасить через `html.escape()`.

```python
import html
print(html.escape("5 < 7 & <b>жирный</b>"))
```

Результат:
```text
5 &lt; 7 &amp; &lt;b&gt;жирный&lt;/b&gt;
```

## Частые ошибки

**1. Тег не закрыт или закрыт в неправильном порядке:**
```html
<!-- Неправильно -->
<p>Текст <b>жирный</p></b>
<!-- Правильно: последний открытый закрывается первым -->
<p>Текст <b>жирный</b></p>
```

**2. Нет `<meta charset="UTF-8">`** — казахские и русские буквы отображаются «кракозябрами».

**3. Один `id` у нескольких элементов** — `id` должен быть уникальным; для повторяющихся элементов — `class`.

**4. Значение атрибута без кавычек:** `<a href=page.html>` иногда работает, но ломается, если есть пробел. Всегда `"..."`.

**5. Путать `Ctrl+U` и Elements** — данные для скрапинга должны быть в `Ctrl+U`, иначе `requests` их не увидит.

**6. Считать относительную ссылку полным URL:** `href="/news/15"` — нужно добавить впереди домен сайта (`urllib.parse.urljoin`).

## Основные понятия

| Понятие | Объяснение |
|---|---|
| HTML | Язык разметки, описывающий структуру веб-страницы |
| Тег | Знак в угловых скобках, например `<p>`, `</p>` |
| Элемент | Открывающий тег + содержимое + закрывающий тег |
| Атрибут | Дополнительное свойство тега: `href`, `src`, `class`, `id` |
| `class` / `id` | Имя повторяющегося / уникального элемента |
| DOM | Дерево элементов страницы |
| Родитель / дочерний / сосед | Отношения элементов в DOM-дереве |
| CSS-селектор | Выражение для поиска элементов: `div.card > span.price` |
| DevTools (Elements) | Инструмент браузера для исследования структуры страницы |
| Абсолютный / относительный URL | Полный адрес / путь внутри сайта |

## Примечание

- Браузер «прощает» ошибки в HTML (незакрытые теги), поэтому код в DevTools (Elements) может отличаться от исходного HTML (View Source, `Ctrl+U`) — скрапер получает именно исходный.
- Содержимое, которое сайт подгружает JavaScript-ом, отсутствует в исходном HTML — его нельзя получить простым `requests.get()`.
- При генерации HTML из Python экранируйте пользовательские данные: `html.escape("<b>")` → `&lt;b&gt;` (https://docs.python.org/3/library/html.html).
- `id` должен быть уникальным на странице, а `class` может повторяться и содержать несколько значений через пробел: `class="card sale"`.
- Сохраняйте HTML-файлы с `encoding="utf-8"` и указывайте `<meta charset="utf-8">`, иначе кириллица отобразится неправильно.
