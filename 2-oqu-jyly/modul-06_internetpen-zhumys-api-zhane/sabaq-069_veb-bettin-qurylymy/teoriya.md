## 1. HTML деген не?

**HTML (HyperText Markup Language)** — гипермәтінді белгілеу тілі. Ол бағдарламалау тілі **емес** (цикл, шарт жоқ), ол мәтіннің **құрылымын** сипаттайды: мұнда тақырып, мұнда абзац, мұнда сілтеме.

Веб-беттің үш «қабаты»:

| Технология | Рөлі | Аналогия (үй) |
|---|---|---|
| HTML | Құрылым, мазмұн | Қабырғалар, бөлмелер |
| CSS | Безендіру (түс, қаріп, орналасу) | Тұсқағаз, жиһаз |
| JavaScript | Интерактивтілік | Электр, лифт |

Скрапинг үшін бізге ең маңыздысы — **HTML**.

## 2. Тег, элемент, атрибут

```html
<a href="https://python.org" class="link">Python сайты</a>
```

```text
<a href="https://python.org" class="link">Python сайты</a>
 │  └──────────┬───────────┘ └────┬─────┘ └─────┬─────┘ └┬┘
 │       атрибут 1          атрибут 2       мазмұн    жабушы тег
 └ ашушы тегтің атауы
└────────────────────── элемент (толығымен) ──────────────────┘
```

- **Тег** — бұрыштық жақшадағы белгі: `<p>`, `</p>`.
- **Элемент** — ашушы тег + мазмұн + жабушы тег.
- **Атрибут** — тегке қосымша ақпарат: `атау="мән"`.
- **Бос (жабылмайтын) тегтер:** `<img>`, `<br>`, `<input>`, `<meta>`, `<hr>` — мазмұны жоқ.

## 3. HTML құжатының құрылымы

```html
<!DOCTYPE html>
<html lang="kk">
<head>
    <meta charset="UTF-8">
    <title>Python үйірмесі</title>
</head>
<body>
    <h1>Python үйірмесіне қош келдіңіз!</h1>
    <p>Біз <b>Алматыда</b> бағдарламалауды үйренеміз.</p>
</body>
</html>
```

| Бөлік | Мағынасы |
|---|---|
| `<!DOCTYPE html>` | Құжат түрі: HTML5 |
| `<html lang="kk">` | Түбірлік элемент, тілі — қазақ |
| `<head>` | Қызметтік ақпарат (экранда көрінбейді): кодировка, браузер қойындысындағы атау, CSS сілтемелері |
| `<meta charset="UTF-8">` | Кодировка — қазақ әріптері дұрыс көрінуі үшін |
| `<title>` | Қойынды атауы |
| `<body>` | Экранда көрінетін барлық мазмұн |

## 4. Жиі қолданылатын тегтер

### Мәтін

| Тег | Мағынасы |
|---|---|
| `<h1>` … `<h6>` | Тақырыптар (h1 — ең маңызды) |
| `<p>` | Абзац |
| `<b>`, `<strong>` | Қалың / маңызды мәтін |
| `<i>`, `<em>` | Курсив / екпін |
| `<br>` | Жаңа жол |
| `<span>` | Жол ішіндегі мәтін бөлігі (өздігінен ештеңе өзгертпейді) |

### Сілтемелер мен суреттер

```html
<a href="https://open-meteo.com" target="_blank">Open-Meteo сайты</a>
<a href="/news/15">Жаңалық №15</a>             <!-- салыстырмалы сілтеме -->
<img src="images/logo.png" alt="Үйірме логотипі" width="200">
```

- `href` — сілтеме мекенжайы. **Абсолютті** (`https://...`) немесе **салыстырмалы** (`/news/15`) болуы мүмкін — скрапингте маңызды!
- `src` — сурет файлы, `alt` — сурет көрінбесе шығатын мәтін.

### Тізімдер

```html
<ul>                       <!-- нөмірленбеген тізім -->
    <li>Python</li>
    <li>JavaScript</li>
</ul>
<ol>                       <!-- нөмірленген тізім -->
    <li>Тіркелу</li>
    <li>Сабаққа келу</li>
</ol>
```

### Кестелер

```html
<table>
    <tr>
        <th>Қала</th>
        <th>Халқы (мың)</th>
    </tr>
    <tr>
        <td>Алматы</td>
        <td>2200</td>
    </tr>
    <tr>
        <td>Астана</td>
        <td>1500</td>
    </tr>
</table>
```

`<table>` — кесте, `<tr>` — жол (table row), `<th>` — тақырып ұяшығы, `<td>` — деректер ұяшығы. Көп сайтта `<thead>` (тақырып бөлігі) және `<tbody>` (дене) тегтері де болады. Кестелер — скрапингтің ең «тиімді» нысаны!

### Контейнерлер

```html
<div class="card">
    <h3 class="card-title">Ноутбук Lenovo</h3>
    <span class="price">349 990 ₸</span>
</div>
```

`<div>` — блоктық контейнер (жаңа жолдан басталады), `<span>` — жол ішіндегі контейнер. Өздігінен мағынасы жоқ, бірақ `class` арқылы «аталады». HTML5-те мағыналы контейнерлер де бар: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`.

### Форма (танысу үшін)

```html
<form action="/search" method="get">
    <input type="text" name="q" placeholder="Іздеу...">
    <button type="submit">Табу</button>
</form>
```

Байқаңыз: `method="get"` және `name="q"` → браузер `/search?q=...` URL-ін жібереді. Бұл — URL параметрлері (query string).

## 5. `class` және `id` атрибуттары

| Атрибут | Ерекшелігі | Мысал |
|---|---|---|
| `id` | Бетте **бірегей** (тек бір элементте) | `<div id="main-menu">` |
| `class` | Көп элементте қайталанады; бір элементте бірнеше класс болуы мүмкін | `<div class="card product">` |

Мысалы, интернет-дүкендегі әр тауар карточкасы `class="product-card"` болады. Скрапинг кезінде «барлық `product-card` класты элементтерді тап» деп айтамыз — бұл өте ыңғайлы.

## 6. DOM-ағаш

Браузер HTML-ді **DOM (Document Object Model)** — элементтер ағашына айналдырады. Элементтер арасында «отбасылық» қатынас бар:

```text
html
├── head
│   └── title  → "Дүкен"
└── body
    ├── h1  → "Тауарлар"
    └── div.catalog
        ├── div.card            ← ата-ана (parent) — h3 пен span үшін
        │   ├── h3.card-title   ← бала (child)
        │   └── span.price      ← бауыр (sibling) — h3 үшін
        └── div.card
            ├── h3.card-title
            └── span.price
```

| Термин | Мағынасы |
|---|---|
| Ата-ана (parent) | Элементті тікелей қамтитын элемент |
| Бала (child) | Тікелей ішіндегі элемент |
| Ұрпақ (descendant) | Кез келген тереңдіктегі ішкі элемент |
| Бауыр (sibling) | Ата-анасы ортақ элемент |

Скрапинг — осы ағашта «саяхаттау»: «`div.catalog` ішіндегі әр `div.card`-тан `span.price` мәтінін ал».

## 7. CSS-селекторлар (скрапингке қажеттісі)

CSS-селектор — элементтерді табу «мекенжайы». BeautifulSoup-тың `select()` әдісі дәл осындай селекторларды қабылдайды.

| Селектор | Нені табады |
|---|---|
| `p` | Барлық `<p>` |
| `.price` | `class="price"` элементтер |
| `#main-menu` | `id="main-menu"` элемент |
| `div.card` | `card` класы бар `<div>` |
| `div.card span` | `div.card` ішіндегі барлық `<span>` (ұрпақтар) |
| `ul > li` | `ul`-дың тікелей балалары `li` |
| `a[href]` | `href` атрибуты бар сілтемелер |
| `table tr td:nth-child(2)` | Кестенің 2-бағанындағы ұяшықтар |

## 8. Браузерде құрылымды зерттеу

1. **Бет кодын көру** — `Ctrl+U` (немесе оң батырма → «Просмотр кода страницы»). Бұл — сервер жіберген **бастапқы** HTML (`requests` алатын дәл осы!).
2. **DevTools → Elements** — `F12` немесе элементті оң батырмамен басып → «Inspect / Посмотреть код». Мұнда — браузер JavaScript-ті орындағаннан **кейінгі** DOM.
3. Elements панелінде тышқанды тегтің үстіне апарсаңыз, бетте сол элемент жарықтанады.
4. Элементті оң батырма → **Copy → Copy selector** — дайын CSS-селекторды береді.
5. `Ctrl+F` (Elements ішінде) — селектор бойынша іздеу: `.price` жазып, қанша элемент табылғанын көріңіз.

**Маңызды айырмашылық:** кейбір сайттар мазмұнды JavaScript арқылы кейін жүктейді. Онда `Ctrl+U`-да деректер жоқ, ал Elements-те бар. Мұндай сайттарды `requests` + BeautifulSoup арқылы скрапинг жасау қиын — көбіне олардың артындағы API-ды (Network → Fetch/XHR) іздеген дұрыс.

## 9. Python арқылы HTML жасау

HTML — жай мәтін, сондықтан оны Python-да оңай генерациялаймыз. Мысалы, қалалар кестесі бар бет:

```python
import webbrowser
from pathlib import Path

cities = [("Алматы", 2200), ("Астана", 1500), ("Шымкент", 1250)]

rows = "\n".join(f"        <tr><td>{name}</td><td>{pop}</td></tr>" for name, pop in cities)
html = f"""<!DOCTYPE html>
<html lang="kk">
<head>
    <meta charset="UTF-8">
    <title>Қалалар</title>
</head>
<body>
    <h1>Қазақстанның ірі қалалары</h1>
    <table border="1">
        <tr><th>Қала</th><th>Халқы (мың)</th></tr>
{rows}
    </table>
</body>
</html>"""

path = Path("cities.html")
path.write_text(html, encoding="utf-8")
print("Файл жасалды:", path.resolve())
# webbrowser.open(path.resolve().as_uri())   # браузерде ашу
```

Нәтижесі:
```text
Файл жасалды: /home/student/cities.html
```

Бұл тәсіл есептер жасауға пайдалы: мысалы, «Оқушылар базасы»-нан HTML есеп шығаруға болады.

**Ескерту:** пайдаланушы енгізген мәтінді HTML-ге қойғанда, `<`, `>`, `&` таңбаларын `html.escape()` арқылы қауіпсіз ету керек.

```python
import html
print(html.escape("5 < 7 & <b>қалың</b>"))
```

Нәтижесі:
```text
5 &lt; 7 &amp; &lt;b&gt;қалың&lt;/b&gt;
```

## Жиі кездесетін қателер

**1. Тегті жаппау немесе қате ретпен жабу:**
```html
<!-- Қате -->
<p>Мәтін <b>қалың</p></b>
<!-- Дұрыс: соңғы ашылған — бірінші жабылады -->
<p>Мәтін <b>қалың</b></p>
```

**2. `<meta charset="UTF-8">` жоқ** — қазақ әріптері «кракозябра» болып көрінеді.

**3. `id`-ді бірнеше элементке беру** — `id` бірегей болуы тиіс; қайталанатын элементтерге `class`.

**4. Атрибут мәнін тырнақшасыз жазу:** `<a href=page.html>` кейде жұмыс істейді, бірақ бос орын болса бұзылады. Әрқашан `"..."`.

**5. `Ctrl+U` мен Elements-ті шатастыру** — скрапинг жасайтын деректер `Ctrl+U`-да болуы керек, әйтпесе `requests` оларды көрмейді.

**6. Салыстырмалы сілтемені толық URL деп ойлау:** `href="/news/15"` — алдына сайт доменін қосу керек (`urllib.parse.urljoin`).

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| HTML | Веб-беттің құрылымын сипаттайтын белгілеу тілі |
| Тег | `<p>`, `</p>` сияқты бұрыштық жақшадағы белгі |
| Элемент | Ашушы тег + мазмұн + жабушы тег |
| Атрибут | Тегтің қосымша қасиеті: `href`, `src`, `class`, `id` |
| `class` / `id` | Қайталанатын / бірегей элемент атауы |
| DOM | Беттің элементтер ағашы |
| Ата-ана / бала / бауыр | DOM-ағаштағы элементтер қатынастары |
| CSS-селектор | Элементтерді табу өрнегі: `div.card > span.price` |
| DevTools (Elements) | Браузердегі бет құрылымын зерттеу құралы |
| Абсолютті / салыстырмалы URL | Толық мекенжай / сайт ішіндегі жол |

## Ескерту

- Браузер HTML-дегі қателерді (жабылмаған тегтер) «кешіреді», сондықтан DevTools-тағы (Elements) код бастапқы HTML-ден (View Source, `Ctrl+U`) өзгеше болуы мүмкін — скрапер бастапқысын алады.
- Сайт JavaScript арқылы кейін жүктейтін мазмұн бастапқы HTML-де болмайды — оны қарапайым `requests.get()` арқылы алу мүмкін емес.
- Python-нан HTML жасағанда пайдаланушы деректерін экрандаңыз: `html.escape("<b>")` → `&lt;b&gt;` (https://docs.python.org/3/library/html.html).
- `id` бетте бірегей болуы тиіс, ал `class` қайталана алады және бос орын арқылы бірнеше мән қабылдайды: `class="card sale"`.
- HTML файлдарын `encoding="utf-8"` арқылы сақтап, `<meta charset="utf-8">` көрсетіңіз — әйтпесе кириллица бұзылып көрінеді.
