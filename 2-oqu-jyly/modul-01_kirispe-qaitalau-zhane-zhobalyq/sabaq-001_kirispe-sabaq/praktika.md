# Сабақ 1. Практикалық тапсырмалар: танысу, қауіпсіздік, жыл мақсаты

## Базалық деңгей

### 1-тапсырма. «Менің визиткам»
Оқушыдан аты, жасы, сыныбы, сүйікті пәні сұралатын бағдарлама жаз. Мәліметтерді жұлдызша (`*`) жиектің ішінде әдемі шығар.

Мысал:
```text
Атың? Нұрлан
Жасың? 12
Сыныбың? 6
Сүйікті пәнің? математика
******************************
Аты: Нұрлан
Жасы: 12, сыныбы: 6
Сүйікті пәні: математика
******************************
```
Кеңес: `"*" * 30` өрнегі 30 жұлдызшадан тұратын жол береді.

### 2-тапсырма. «Бітіруге қанша қалды?»
Оқушының сыныбын енгіз. 11-сыныпты бітіруге неше жыл және шамамен неше оқу күні қалғанын шығар (бір оқу жылында 170 оқу күні деп ал).

```text
Сыныбың? 7
Мектепті бітіруге 4 жыл қалды.
Бұл шамамен 680 оқу күні.
```

### 3-тапсырма. «Қауіпсіздік викторинасы»
3 сұрақтан тұратын викторина жаз (ережелер бойынша). Әр дұрыс жауапқа 1 ұпай, соңында жалпы ұпайды шығар.

Сұрақ мысалдары:
- «Жұмыс үстеліне шай қоюға бола ма? (иә/жоқ)» → дұрыс жауабы: жоқ.
- «Монитор көзден неше см-ден кем емес қашықтықта болуы керек?» → 50.
- «Ақау байқасаң, кімге айтасың?» → педагогке.

```text
Жұмыс үстеліне шай қоюға бола ма? (иә/жоқ): жоқ
Дұрыс!
...
Нәтижең: 3 / 3
```

### 4-тапсырма. «Сергіту таймері»
Пайдаланушы компьютер алдында неше минут отырғанын енгізеді. Бағдарлама осы уақытта неше рет сергіту жаттығуын жасау керек екенін есептейді (әр 20 минут сайын бір рет).

```text
Неше минут отырдың? 90
Сен 4 рет сергіту жаттығуын жасауың керек еді.
```

## Кеңейтілген деңгей

### 5-тапсырма. «Модульдер картасы»
Екінші жылдың модульдерін сөздікке сақта: кілті — модуль нөмірі, мәні — (атауы, сағат саны) кортежі. Бағдарлама:
1. барлық модульді кесте түрінде шығарады;
2. жалпы сағат санын есептейді (216 шығуы керек);
3. ең ұзақ модульді табады.

```text
 1. Кіріспе. Қайталау және жобалық жұмыс құралдары — 16 сағ
 2. ОБП негіздері — 24 сағ
...
Барлығы: 216 сағат
Ең ұзақ модуль: Қорытынды жеке жоба (34 сағ)
```

### 6-тапсырма. «Сыныптастар тізімі»
Пайдаланушы бос жол енгізгенше топтағы оқушылардың аттарын енгізеді. Соңында: оқушылар саны, алфавит бойынша сұрыпталған тізім, ең ұзын есім шығады.

## ★ Олимпиадалық / шығармашылық тапсырма

### 7-тапсырма. «Жыл соңына кері санақ»
Оқу жылы 01.09.2026 басталып, 31.05.2027 аяқталады. `datetime` модулін қолданып, бүгінгі күннен оқу жылының соңына дейін неше күн қалғанын, ал оқу жылының неше пайызы өткенін шығар. Пайызды 20 символдан тұратын «прогресс-жолақпен» көрсет:

```text
Оқу жылының соңына дейін 232 күн қалды.
Өтті: [###.................] 15.4%
```

### 8-тапсырма. «ASCII-логотип»
Тек `print` және жолдарды көбейту арқылы үйірменің логотипін (мысалы, «PY» әріптері немесе жылан) салатын бағдарлама жаз. Ең шығармашыл логотип үйірме репозиторийінің README-сіне қойылады.

## Үй тапсырмасы

1. Қауіпсіздік ережелерінің ішінен ең маңызды деп санайтын 5 ережені дәптерге жазып, әрқайсысының себебін түсіндір.
2. «Жыл соңындағы мақсатым» бағдарламасын жаз: оқушы өзі жасағысы келетін 3 жобаның идеясын енгізеді, бағдарлама оларды нөмірлеп, әр жоба қай модульге жататынын (ойын — IV, деректер қоры — V, т.б.) сұрап, кестемен шығарады.
3. Бірінші жылдың конспектісін қарап шық: келесі сабақта мәліметтер типтері, `if`, `for`, `while` бойынша қайталау болады.

```python
    8: ("Код сапасы, тестілеу және құжаттау", 10),
    9: ("Қорытынды жеке жоба", 34),
    10: ("Резервтік сағат және қорытындылау", 8),
}

total = 0
longest = 1
for number, (title, hours) in modules.items():
    print(f"{number:2}. {title} — {hours} сағ")
    total += hours
    if hours > modules[longest][1]:
        longest = number

print("Барлығы:", total, "сағат")
print(f"Ең ұзақ модуль: {modules[longest][0]} ({modules[longest][1]} сағ)")
```

**7-тапсырма**
```python
from datetime import date

start = date(2026, 9, 1)
end = date(2027, 5, 31)
today = date.today()

if today < start:
    today = start
if today > end:
    today = end

days_left = (end - today).days
total_days = (end - start).days
percent = (today - start).days / total_days * 100
filled = round(percent / 5)
bar = "#" * filled + "." * (20 - filled)

print("Оқу жылының соңына дейін", days_left, "күн қалды.")
print(f"Өтті: [{bar}] {percent:.1f}%")
```
