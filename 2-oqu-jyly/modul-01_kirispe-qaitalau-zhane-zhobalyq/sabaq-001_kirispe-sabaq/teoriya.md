## 1. Python экожүйесі: екінші жылдың технологиялары

Python — жалпы мақсаттағы тіл: онда консольдік утилиталар, терезелі бағдарламалар, ойындар, веб-сервистер, деректерді талдау скрипттері жазылады. Python-ның күші — **кітапханалардың** (дайын модульдердің) көптігінде. Олардың бір бөлігі **стандартты кітапханаға** кіреді (Python-мен бірге орнатылады), қалғандары `pip` пакет менеджері арқылы орнатылады.

| Бағыт | Құралдар мен кітапханалар | Не жасауға болады |
|---|---|---|
| Әзірлеуші құралдары | VS Code, venv, pip, Git, GitHub, PEP 8 | Нұсқалар тарихы бар ұқыпты жоба |
| Объектіге бағытталған бағдарламалау | `class`, объектілер, әдістер, мұрагерлік | «Кітапхана», «Мектеп журналы» моделі |
| Графикалық интерфейс | `tkinter` (стандартты кітапхана) | Калькулятор, істер тізімі (To-Do List) |
| Компьютерлік ойындар | `pygame` (pip арқылы) | Спрайттары, дыбысы, мәзірі бар 2D ойын |
| Деректермен жұмыс | `csv`, `json`, `sqlite3` (стандартты кітапхана), SQL | Оқушылар базасы, баптауларды сақтау |
| Интернет | `requests`, `BeautifulSoup`, HTTP, API | «Ауа райы» қосымшасы, сайттардан дерек жинау |
| Деректерді талдау | `numpy`, `pandas`, `matplotlib` | Кестелер, статистика, графиктер |
| Код сапасы | жөндеуші (debugger), `logging`, `unittest`, README | Тестіленген және құжатталған бағдарлама |

Мысал: стандартты кітапхана модулі бірден қосылады, сыртқысы — тек орнатқаннан кейін.

```python
import json      # стандартты кітапхана — бірден жұмыс істейді
import random    # бұл да стандартты

data = {"name": "Айгерім", "score": random.randint(1, 10)}
print(json.dumps(data, ensure_ascii=False))
# import pygame  # сыртқы кітапхана: алдымен  pip install pygame
```

## 2. Python бағдарламасы қалай құрылған

Python бағдарламасы — `.py` кеңейтімі бар мәтіндік файл. Оны **интерпретатор** орындайды: жолдарды жоғарыдан төмен оқып, бірден орындайды. Терминалдан іске қосу:

```text
python main.py      (Windows)
python3 main.py     (Linux / macOS)
```

Кез келген бағдарлама дерлік **енгізу → өңдеу → шығару** сызбасына бағынады:

```text
Енгізу (input, файл, желі) → Өңдеу (есептеу, шарт, цикл) → Шығару (print, файл, терезе)
```

Бағдарлама өскен сайын бөліктерге бөлінеді: **функциялар** (атауы бар код блоктары), **кластар** (деректер + мінез-құлық), **модульдер** (жеке `.py` файлдар). Кіру нүктесін былай рәсімдеу қабылданған:

```python
def main():
    """Бағдарламаның басты функциясы."""
    print("Бағдарлама іске қосылды")


if __name__ == "__main__":
    main()
```

`if __name__ == "__main__":` шарты файл басқа модульден импортталғанда емес, тікелей іске қосылғанда ғана ақиқат болады. Бұл артық кодты орындамай, файлдың функцияларын қайта пайдалануға мүмкіндік береді.

## 3. Бағдарламалық жобаның өмірлік циклі

Кез келген жоба (кішісі де, үлкені де) бірдей циклмен жүреді:

```text
Идея → Талаптар (ТТ) → Жобалау → Әзірлеу → Тестілеу → Құжаттау → Қорғау
  ↑                                                                 |
  └──────────────── пікір алу және жетілдіру ─────────────────────┘
```

- **Идея** — қандай мәселені шешеміз? Кімге керек?
- **Техникалық тапсырма (ТТ)** — бағдарлама нені істеуі керек (талаптар тізімі).
- **Жобалау** — қандай бөліктерден (функция, класс, файл) тұрады.
- **Әзірлеу** — код жазу, Git арқылы нұсқаларды сақтау.
- **Тестілеу** — қателерді іздеу және түзету.
- **Құжаттау** — README, іске қосу нұсқаулығы.
- **Қорғау** — жобаны таныстыру.

Командалық жобаларда рөлдер бөлінеді: бағдарламашы, дизайнер, дыбыс маманы, тестілеуші, құжаттама жазушы. Дайын жобалар **GitHub**-та жарияланып, бағдарламашының **портфолиосын** құрайды.

## 4. Мысал: «Менің визиткам» бағдарламасы

Ең қарапайым нұсқа — тек `input`, `int` және `print`:

```python
name = input("Атың кім? ")
age = int(input("Жасың нешеде? "))
hobby = input("Хоббиің? ")

print("=" * 30)
print("Аты:", name)
print("Жасы:", age)
print("Хоббиі:", hobby)
print("Келесі жылы", age + 1, "жаста боласың!")
print("=" * 30)
```

Нәтижесі:
```text
Атың кім? Айгерім
Жасың нешеде? 13
Хоббиің? шахмат
==============================
Аты: Айгерім
Жасы: 13
Хоббиі: шахмат
Келесі жылы 14 жаста боласың!
==============================
```

Дәл осы нәтижені функция, сөздік, тізім генераторы және f-жолдар арқылы алуға болады — код әмбебап болады: визитка өрістердің кез келген санына және ұзындығына бейімделеді.

```python
def make_card(person):
    """Оқушының визиткасын жол түрінде қайтарады."""
    lines = [f"{key}: {value}" for key, value in person.items()]
    width = max(len(line) for line in lines) + 4
    border = "*" * width
    body = "\n".join(f"* {line.ljust(width - 4)} *" for line in lines)
    return f"{border}\n{body}\n{border}"


student = {"Аты": "Ерлан", "Сыныбы": "8 «Ә»", "Арманы": "ойын жасау"}
print(make_card(student))
```

Нәтижесі:
```text
**********************
* Аты: Ерлан         *
* Сыныбы: 8 «Ә»      *
* Арманы: ойын жасау *
**********************
```

Мұнда `str.ljust(n)` жолды оң жағынан бос орындармен `n` ұзындыққа дейін толықтырады, ал `"\n".join(...)` жолдарды жаңа жол таңбасы арқылы біріктіреді.

## 5. Код қауіпсіздігі және цифрлық этика

- Құпиясөздерді, токендерді, API кілттерін және жеке деректерді кодта сақтама және GitHub-қа жүктеме. Құпия мәліметтерді бөлек файлға (мысалы, `.env`) шығарып, оны `.gitignore`-ға қосады.
- Бейтаныс скрипттерді іске қоспа және күмәнді атаулы пакеттерді орнатпа: `pip` арқылы зиянды код орнатып алуға болады (*typosquatting* деп аталады — `requests` орнына `reqeusts`).
- Біреудің кодын пайдалансаң, дереккөзін көрсет және оның **лицензиясын** (MIT, GPL т.б.) сақта.
- Жұмысыңды үнемі сақтап, Git-те коммит жаса — сонда ештеңе жоғалмайды.

## Жиі кездесетін қателер

**1. Санды енгізгенде `int()` ұмыту.**
```python
age = input("Жасың? ")
# print(age + 1)  # TypeError: can only concatenate str (not "int") to str
```
Түсіндірме: `input()` әрқашан жол (str) қайтарады. Дұрыс нұсқа:
```python
age = int(input("Жасың? "))
print(age + 1)
```

**2. Тырнақшаларды жабуды ұмыту.**
```text
print("Сәлем)   →  SyntaxError: unterminated string literal
```
Дұрыс: `print("Сәлем")`.

**3. Файлды стандартты кітапхана модулінің атымен атау.** Өз файлыңды `random.py` немесе `json.py` деп атасаң, `import random` стандартты модульдің орнына сенің файлыңды жүктейді де, `AttributeError: module 'random' has no attribute 'randint'` сияқты қате шығады. Файлдарға бірегей атау бер.

## Ескерту

- Python нұсқасын `python --version` командасымен тексеруге болады; курста Python 3.10 және одан жаңасы қолданылады (мысалы, `match` операторы тек 3.10-да пайда болды).
- Python 2 2020 жылдан бастап ресми қолдау таппайды — ескі мақалалардағы жақшасыз `print "text"` мысалдары жұмыс істемейді.
- Ресми құжаттама мен оқулық: https://docs.python.org/3/ (Tutorial бөлімі) және стандартты кітапхана модульдерінің тізімі https://docs.python.org/3/library/.
- PEP 8 бойынша файл мен модуль атаулары кіші әріптермен, астын сызу арқылы жазылады: `My Card.py` емес, `my_card.py` — атаудағы бос орын импортқа кедергі келтіреді.
- `input()` әрқашан `str` қайтарады; пайдаланушы сан емес мән енгізсе, `int()` `ValueError` шығарады — нақты бағдарламаларда мұны ескеру керек.
