# Урок 1. Практические задания: знакомство, безопасность, цель на год

## Базовый уровень

### Задание 1. «Моя визитка»
Напиши программу, которая спрашивает у учащегося имя, возраст, класс и любимый предмет. Красиво выведи данные внутри рамки из звёздочек (`*`).

Пример:
```text
Как тебя зовут? Нурлан
Сколько тебе лет? 12
В каком ты классе? 6
Любимый предмет? математика
******************************
Имя: Нурлан
Возраст: 12, класс: 6
Любимый предмет: математика
******************************
```
Подсказка: выражение `"*" * 30` даёт строку из 30 звёздочек.

### Задание 2. «Сколько осталось до выпуска?»
Введи класс учащегося. Выведи, сколько лет и примерно сколько учебных дней осталось до окончания 11-го класса (считай, что в одном учебном году 170 учебных дней).

```text
В каком ты классе? 7
До окончания школы осталось 4 года.
Это примерно 680 учебных дней.
```

### Задание 3. «Викторина по технике безопасности»
Напиши викторину из 3 вопросов (по правилам). За каждый правильный ответ — 1 балл, в конце выведи общий балл.

Примеры вопросов:
- «Можно ли ставить чай на рабочий стол? (да/нет)» → правильный ответ: нет.
- «На расстоянии не менее скольких см от глаз должен находиться монитор?» → 50.
- «Кому ты сообщишь, если заметишь неисправность?» → педагогу.

```text
Можно ли ставить чай на рабочий стол? (да/нет): нет
Правильно!
...
Твой результат: 3 / 3
```

### Задание 4. «Таймер физминуток»
Пользователь вводит, сколько минут он сидел за компьютером. Программа вычисляет, сколько раз за это время нужно было сделать физминутку (один раз каждые 20 минут).

```text
Сколько минут ты сидел? 90
Тебе нужно было сделать физминутку 4 раз(а).
```

## Продвинутый уровень

### Задание 5. «Карта модулей»
Сохрани модули второго года в словарь: ключ — номер модуля, значение — кортеж (название, количество часов). Программа:
1. выводит все модули в виде таблицы;
2. вычисляет общее количество часов (должно получиться 216);
3. находит самый длинный модуль.

```text

 2. Основы ООП — 24 ч
...
Всего: 216 часов
Самый длинный модуль: Итоговый личный проект (34 ч)
```

## ★ Олимпиадная / творческая задача

### Задание 7. «Обратный отсчёт до конца года»
Учебный год начинается 01.09.2026 и заканчивается 31.05.2027. С помощью модуля `datetime` выведи, сколько дней осталось от сегодняшнего дня до конца учебного года и сколько процентов учебного года прошло. Покажи процент в виде «полосы прогресса» из 20 символов:

```text
До конца учебного года осталось 232 дн.
Прошло: [###.................] 15.4%
```

```python
    1: ("Введение. Повторение и инструменты проектной работы", 16),

    9: ("Итоговый личный проект", 34),
    10: ("Резервные часы и подведение итогов", 8),
}

total = 0
longest = 1
for number, (title, hours) in modules.items():
    print(f"{number:2}. {title} — {hours} ч")
    total += hours
    if hours > modules[longest][1]:
        longest = number

print("Всего:", total, "часов")
print(f"Самый длинный модуль: {modules[longest][0]} ({modules[longest][1]} ч)")
```

**Задание 7**
```python
from datetime import date

start = date(2026, 9, 1)
end = date(2027, 5, 31)
today = date.today()

if today < start:
    today = start
if today > end:
    today = end

days_left = (end - today).days
total_days = (end - start).days
percent = (today - start).days / total_days * 100
filled = round(percent / 5)
bar = "#" * filled + "." * (20 - filled)

print("До конца учебного года осталось", days_left, "дн.")
print(f"Прошло: [{bar}] {percent:.1f}%")
```
