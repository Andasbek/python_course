## 1. Python-ның базалық дағдылары: бақылау тізімі

Объектіге бағытталған бағдарламалауға және жобаларға кіріспес бұрын бірінші жылдың негіздерін және әзірлеуші құралдарын сенімді меңгеру керек.

| Тақырып | Не істей білу керек | Шағын мысал |
|---|---|---|
| Типтер және енгізу | енгізуді түрлендіру, `int`, `float`, `str`, `bool` типтерімен жұмыс | `age = int(input())` |
| Шарттар | `if/elif/else` тізбегін, күрделі шарттарды құру | `if 12 <= age <= 17 and has_ticket:` |
| Циклдер | `range`-пен `for`, `while`, `break`, `continue` | `for i in range(1, 11, 2):` |
| Жинақтар | тізім, кортеж, сөздік, жиын және олардың әдістері | `freq[w] = freq.get(w, 0) + 1` |
| Функциялар | параметрлер, әдепкі мәндер, `return`, docstring | `def avg(nums, digits=2):` |
| Код құрылымы | модульдер, `import`, `main()`, `if __name__ == "__main__":` | `from utils import avg` |
| Құралдар | venv, pip, Git, GitHub, PEP 8 | `git commit -m "..."` |

Базалық дағдылардың көбін біріктіретін бағдарлама мысалы:

```python
def describe(grades):
    """Бағалар тізімі бойынша статистикасы бар сөздік қайтарады."""
    if not grades:
        return {}
    return {
        "орташа": round(sum(grades) / len(grades), 2),
        "ең жақсы": max(grades),
        "бестер": grades.count(5),
    }


journal = {"Әлия": [5, 4, 5], "Бекзат": [3, 4], "Дана": []}
for name, grades in journal.items():
    stats = describe(grades)
    status = stats if stats else "бағасы жоқ"
    print(f"{name}: {status}")
```

Нәтижесі:
```text
Әлия: {'орташа': 4.67, 'ең жақсы': 5, 'бестер': 2}
Бекзат: {'орташа': 3.5, 'ең жақсы': 4, 'бестер': 0}
Дана: бағасы жоқ
```

Мұнда docstring-і бар функция, бос тізімді тексеру, сөздік, `sum`, `len`, `max`, `round` кірістірілген функциялары, `count` әдісі, `items()` бойынша цикл, тернарлы өрнек және f-жол қолданылған.

## 2. Жобалық ойлау

**Жоба** — белгілі бір **мәселені** шешетін, нақты **нәтижесі** (өнімі) және **мерзімі** бар жұмыс.

Жобаның құрамдас бөліктері:

```text
Мәселе ──► Пайдаланушы ──► Шешім (идея) ──► Мүмкіндіктер ──► Технологиялар ──► Нәтиже
"Неге?"     "Кімге?"        "Не жасаймыз?"   "Не істей алады?"  "Немен?"         "Қалай өлшейміз?"
```

Мысал:
- **Мәселе:** оқушылар үй тапсырмасының мерзімін ұмытады.
- **Пайдаланушы:** 5–11 сынып оқушылары.
- **Шешім:** «Үй тапсырмасы күнделігі» — терезелік қосымша.
- **Мүмкіндіктер:** тапсырма қосу, пән бойынша сүзу, мерзімі жақындағанда ескерту, статистика графигі.
- **Технологиялар:** ОБП (кластар), Tkinter, SQLite, Matplotlib.
- **Нәтиже:** 5 сыныптасым бір апта қолданып, пікір берді.

### Жақсы жоба идеясының белгілері
1. **Нақты мәселені шешеді** — «қызық болғандықтан» ғана емес, біреуге пайдалы.
2. **Авторға қызық** — үлкен жобамен ұзақ жұмыс істеледі, ынта маңызды.
3. **Орындалатын** — білім деңгейіне және уақытқа сай (тым оңай да, тым күрделі де емес).
4. **Кеңейтуге болады** — алдымен қарапайым нұсқа (MVP), кейін мүмкіндіктер қосылады.
5. **Бірнеше технологияны біріктіреді** — мысалы: ОБП + Tkinter + SQLite + API.

**MVP** (minimum viable product, ең аз жұмыс істейтін өнім) — негізгі функциясы ғана бар алғашқы нұсқа. Аналогия: велосипед жасағың келсе, алдымен самокат жаса — ол да жүреді, кейін оны жетілдіресің. Ал дөңгелектің өзі ғана — MVP емес.

### Идеяны тексеру: SMART
| Әріп | Мағынасы | Сұрақ |
|---|---|---|
| S — Specific | Нақты | Бағдарлама дәл не істейді? |
| M — Measurable | Өлшенетін | Дайын екенін қалай білеміз? |
| A — Achievable | Қолжетімді | Білім мен уақыт жете ме? |
| R — Relevant | Өзекті | Кімге және неге керек? |
| T — Time-bound | Мерзімі белгілі | Қашан аяқталады? |

## 3. Идея табу әдістері

### 3.1. Миға шабуыл (brainstorming)
- Қысқа уақыт ішінде **мүмкіндігінше көп** идея жазу, оларды сынамау.
- Кейін ұқсас идеяларды топтастырып, 2-бөлімдегі белгілер бойынша ең жақсыларын таңдау.

### 3.2. «Мәселе → Шешім»
Айналаңа қара: мектепте, үйде, қалада қандай ыңғайсыздықтар бар?
- «Асханада кезек ұзақ» → алдын ала тапсырыс беру қосымшасы.
- «Үй тапсырмасын ұмытамын» → күнделік-қосымша.
- «Ағылшын сөздерін жаттау қиын» → флеш-карталар ойыны.
- «Қалада ауа ластануы туралы түсінікті ақпарат жоқ» → API-дан деректер алып, график салатын бағдарлама.

### 3.3. «Технологиядан идеяға»
Python технологиясын ал да, «бұл құралмен не жасауға болады?» деп сұра:

| Технология | Не жасауға болады |
|---|---|
| ОБП | ойын кейіпкерлері, кітапхана жүйесі, банк шоты |
| Tkinter | калькулятор, күнделік, тест-бағдарлама, аудармашы |
| Pygame | платформер, «жылан», ғарыш атысы, білім беру ойыны |
| SQLite | оқушылар базасы, кітапхана каталогы, дүкен қоймасы |
| API | ауа райы, валюта бағамы, ғарыш суреттері, жер сілкінісі картасы |
| BeautifulSoup | жаңалықтар жинағышы, бағаларды салыстыру |
| Pandas + Matplotlib | бағалар статистикасы, спорт нәтижелері, ауа сапасы талдауы |

### 3.4. SCAMPER (бар нәрсені жақсарту)
Бар бағдарламаны ал (мысалы, «жылан» ойыны) да өзгерт: **S**ubstitute — ауыстыр (жыланның орнына ғарыш кемесі), **C**ombine — біріктір (ойын + ағылшын сөздері), **A**dapt — бейімде, **M**odify — өзгерт, **P**ut to other use — басқа мақсатқа қолдан, **E**liminate — алып таста, **R**everse — керісінше жаса.

## 5. Идеядан кодқа: декомпозиция және MVP

**Декомпозиция** — үлкен есепті әрқайсысын бөлек бағдарламалауға болатын кішкентай бөліктерге бөлу. MVP-дің әр мүмкіндігі функцияға (кейін — класс әдісіне), ал деректер құрылымға (сөздіктер тізіміне, кейін — объектілер мен деректер қоры кестесіне) айналады.

```text
«Үй тапсырмасы күнделігі»
├── тапсырмаларды сақтау     → homeworks сөздіктер тізімі
├── тапсырма қосу            → add_homework()
└── жақын тапсырмаларды көрсету → upcoming()
```

Python-дағы консольдік MVP:

```python
"""«Үй тапсырмасы күнделігі» MVP: консольдік нұсқа."""

from datetime import date

homeworks = []


def add_homework(subject, text, deadline):
    """Тапсырманы тізімге қосады."""
    homeworks.append({"subject": subject, "text": text, "deadline": deadline})


def upcoming(days=2, today=None):
    """Мерзімі days күннен кешікпейтін тапсырмаларды қайтарады."""
    today = today or date.today()
    return [hw for hw in homeworks if 0 <= (hw["deadline"] - today).days <= days]


def main():
    add_homework("Математика", "№ 145–150", date(2026, 9, 18))
    add_homework("Тарих", "§ 3, конспект", date(2026, 9, 25))
    for hw in upcoming(today=date(2026, 9, 17)):
        print(f"{hw['deadline']}: {hw['subject']} — {hw['text']}")


if __name__ == "__main__":
    main()
```

Нәтижесі:
```text
2026-09-18: Математика — № 145–150
```

Екі `date` объектісін азайтқанда `timedelta` объектісі шығады, оның `.days` атрибуты — күндердегі айырма. Әрі қарай MVP нұсқалар бойынша дамиды: кластар (ОБП) → терезе (Tkinter) → сақтау (SQLite) → графиктер (Matplotlib); әр нұсқа Git-те коммитпен бекітіледі.

## 6. Питч — идеяны 1 минутта таныстыру

**Питч** (elevator pitch, «лифттегі презентация») — идеяны өте қысқа, нанымды түрде айту.

Құрылымы (60 секунд):
1. **Ілмек** (10 с): «Сендер үй тапсырмасын ұмытып көрдіңдер ме?»
2. **Мәселе** (10 с): кімге және неге қиын.
3. **Шешім** (20 с): бағдарлама не істейді, 2–3 негізгі мүмкіндік.
4. **Технологиялар** (10 с): немен жасалады.
5. **Шақыру** (10 с): «Командаға дизайнер іздеймін» немесе «Пікірлеріңді күтемін».

## Жиі кездесетін қателер

**Кодта:**
1. `input()`-ты санға айналдырмау → есептеуде `TypeError`.
2. Бос тізімнің `len()`-іне бөлу → `ZeroDivisionError`; алдымен `if not items:` арқылы тексер.
3. Бағдарламаны әртүрлі деректермен тексермеу — оны кемінде 2–3 түрлі енгізумен, соның ішінде шекаралық мәндермен (0, бос жол, бос тізім) іске қос.

**Жоба идеясын таңдағанда:**
1. **Тым үлкен идея:** «Minecraft сияқты 3D ойын» немесе «Kaspi сияқты қосымша» — бір жылда жалғыз жасау мүмкін емес. Шешімі: MVP-ге дейін кішірейт.
2. **Тым кішкентай идея:** «екі санды қосатын бағдарлама» — үлкен жобаға жетпейді, технологиялар біріктірілмейді.
3. **Мәселесіз идея:** «Жай ғана терезе жасаймын» — кімге және не үшін керек екенін ойла.
4. **Көшірме:** интернеттегі дайын жобаны өз үлесіңсіз қайталау. Шабыт алуға болады, бірақ өз идеяңды қосып, дереккөзін көрсет.

## Ескерту

- `datetime` модулі стандартты кітапханаға кіреді: `date.today()` бүгінгі күнді қайтарады, `date.fromisoformat("2026-09-18")` жолды күнге айналдырады. Құжаттама: https://docs.python.org/3/library/datetime.html.
- `homeworks` глобалды тізімі MVP үшін ыңғайлы, бірақ үлкен бағдарламаларда деректерді параметрлер арқылы берген немесе класс объектісінде сақтаған дұрыс — мұндай кодты тестілеу оңайырақ.
- `today = today or date.today()` үлгісінде әдепкі мән әр шақыруда есептеледі. `def upcoming(today=date.today())` деп жазуға болмайды: әдепкі мән функция анықталған кезде бір рет қана есептеледі.
- Идеялар мен жоспарларды тікелей репозиторийде Markdown түрінде (`ideas.md`, `README.md`) жүргізіп, міндеттерді GitHub Issues арқылы бақылаған ыңғайлы.
- Өзің жазбас бұрын https://pypi.org/ сайтынан дайын кітапханаларды ізде — көбінесе қажет мүмкіндік әлдеқашан жасалған.
