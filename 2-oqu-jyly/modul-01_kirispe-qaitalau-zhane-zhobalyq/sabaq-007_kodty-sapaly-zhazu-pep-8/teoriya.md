## 1. PEP 8 деген не?

**PEP** (Python Enhancement Proposal) — Python тілін дамыту бойынша ұсыныстар құжаттары. **PEP 8** — Python кодын жазу стилінің ресми нұсқаулығы (2001 жылдан бері, Гвидо ван Россум және т.б.). Python қауымдастығының барлығы — Google, NASA, Instagram бағдарламашылары — осы стильді ұстанады.

PEP 8-тің басты идеясы: **«Код жазылғанынан гөрі әлдеқайда жиі оқылады»**.

Python философиясы PEP 20-да («The Zen of Python») сипатталған, оны интерпретатордың өзінен шақыруға болады:
```python
import this
```
Нәтижесі (үзінді):
```text
Beautiful is better than ugly.
Explicit is better than implicit.
Simple is better than complex.
Readability counts.
```
«Әдемі — ұсқыныстан жақсы. Айқын — жасырыннан жақсы. Қарапайым — күрделіден жақсы. Оқылымдылық маңызды».

## 2. Пішімдеу ережелері

### 2.1. Шегініс (отступ)
- Әр деңгейге **4 бос орын**. Tab пен бос орынды араластырма (VS Code Tab-ты автоматты түрде 4 бос орынға айналдырады).

### 2.2. Жол ұзындығы
- Бір жол — **79 таңбадан** аспасын (көптеген командалар 88–100-ге дейін рұқсат етеді). Ұзын жолды жақша ішінде тасымалда:

```python
total_price = (
    notebook_price * notebook_count
    + pen_price * pen_count
    + bag_price
)
```

### 2.3. Бос жолдар
- Жоғарғы деңгейдегі функциялар мен кластардың арасында — **2 бос жол**.
- Класс ішіндегі әдістердің арасында — 1 бос жол.
- Функция ішінде логикалық бөліктерді 1 бос жолмен бөлуге болады.

### 2.4. Бос орындар (пробелдер)

| Дұрыс | Дұрыс емес | Ереже |
|---|---|---|
| `x = 5` | `x=5` | `=` айналасында бос орын |
| `a + b * c` | `a+b*c` | амалдар айналасында |
| `print(x, y)` | `print( x , y )` | жақша ішінде шетінде жоқ, үтірден кейін бар |
| `grades[0]` | `grades [0]` | индекстің алдында жоқ |
| `def f(x, y=0):` | `def f(x, y = 0):` | әдепкі мәндегі `=` айналасында жоқ |
| `area(width=3)` | `area(width = 3)` | атаулы аргументте де жоқ |

### 2.5. Импорттар
- Файлдың ең басында, әрқайсысы бөлек жолда.
- Реті: стандартты кітапхана → сыртқы пакеттер → өз модульдерің, топтар арасында бос жол.

```python
import os
import random

import requests

from grades_utils import calc_average
```
`from module import *` жазбау — қай атаудың қайдан келгені белгісіз болады.

### 2.6. Бір жолда — бір әрекет
```python
# Жаман
if x > 0: print("оң"); count += 1

# Жақсы
if x > 0:
    print("оң")
    count += 1
```

### 2.7. Салыстырулар
```python
items = []
is_ready = True
result = None

if not items:            # if len(items) == 0: орнына
    print("Тізім бос")
if is_ready:             # if is_ready == True: орнына
    print("Дайын")
if result is None:       # if result == None: орнына
    print("Нәтиже жоқ")
```
Нәтижесі:
```text
Тізім бос
Дайын
Нәтиже жоқ
```

## 3. Атау беру ережелері

| Нысан | Стиль | Мысал |
|---|---|---|
| Айнымалы, функция, әдіс | `snake_case` (кіші әріп + астын сызу) | `student_name`, `calc_average()` |
| Тұрақты (константа) | `UPPER_SNAKE_CASE` | `MAX_SPEED`, `TAX_RATE` |
| Класс | `PascalCase` (CapWords) | `Student`, `BankAccount` |
| Модуль (файл) | қысқа `snake_case` | `grades_utils.py` |
| «Ішкі» атау | алдында `_` | `_helper()` |

`_` префиксінің кластардағы мағынасы ОБП тақырыбында (инкапсуляция) толығырақ қарастырылады.

### Жақсы атаудың белгілері
1. **Мағыналы**: `d` емес, `days_left`; `lst` емес, `student_names`.
2. **Ағылшынша немесе түсінікті транслит** — бір жобада бір тілде: `price`, `baga` емес аралас.
3. **Функция — етістік**: `get_weather()`, `print_report()`, `is_valid()`.
4. **Логикалық айнымалы — сұрақ**: `is_open`, `has_ticket`, `can_jump`.
5. **Тізім — көпше түр**: `grades`, `students`; бір элемент — жекеше: `for student in students`.
6. **Бір әріпті атаулар** — тек қысқа циклдерде (`i`, `j`) және математикада (`x`, `y`).
7. Кірістірілген атауларды «жаппа»: `list`, `str`, `sum`, `max`, `input` деп айнымалы атама.
8. `l` (кіші L), `O` (бас О), `I` (бас i) — жалғыз әріп ретінде қолданба: `1` және `0`-мен шатасады.

```python
# Жаман
sum = 0
list = [3, 5]
for l in list:
    sum += l
# print(sum([1, 2]))  →  TypeError: 'int' object is not callable

# Жақсы
total = 0
prices = [3, 5]
for price in prices:
    total += price
print(total, sum([1, 2]))
```

## 4. Түсініктемелер (комментарийлер)

Түсініктеме код **не** істейтінін емес, **неге** солай істелгенін түсіндіруі керек. Жақсы атаулар «не»-ні өздері айтады.

```python
# Жаман — кодты қайталайды
i = i + 1  # i-ге 1 қосамыз

# Жақсы — себебін түсіндіреді
attempts += 1  # пайдаланушыға 3 әрекет беріледі, кейін бұғатталады
```

PEP 8 ережелері:
- `#`-тен кейін бір бос орын: `# түсініктеме`.
- Жол соңындағы түсініктеме кодтан кемінде 2 бос орынмен бөлінеді.
- Түсініктеме толық сөйлем түрінде, кодпен сәйкес болуы тиіс — кодты өзгертсең, түсініктемені де жаңарт. **Ескірген түсініктеме түсініктеменің болмағанынан да жаман.**
- Қажетсіз кодты түсініктемеге айналдырып сақтама — Git бар, ескі нұсқа тарихта сақталады.

## 5. Docstring — құжаттама жолы

**Docstring** — функцияның, модульдің немесе класстың бірінші жолында тұратын үш тырнақшадағы (`"""..."""`) жол. Түсініктемеден айырмашылығы — ол бағдарламаның **ішінде сақталады** және `help()` арқылы оқылады (PEP 257).

### Бір жолдық docstring
```python
def square(n):
    """Санның квадратын қайтарады."""
    return n * n
```

### Көп жолдық docstring
```python
def convert_currency(amount, rate, commission=0.01):
    """Теңгені шетел валютасына айналдырады.

    Args:
        amount: теңгедегі сома.
        rate: 1 валюта бірлігінің теңгедегі бағамы.
        commission: банк комиссиясы (үлес түрінде, әдепкі 1%).

    Returns:
        Комиссия ұсталғаннан кейінгі валюта сомасы (2 таңбаға дейін).
    """
    result = amount / rate * (1 - commission)
    return round(result, 2)


print(convert_currency(50_000, 500))
help(convert_currency)
```
Нәтижесі:
```text
99.0
Help on function convert_currency in module __main__:

convert_currency(amount, rate, commission=0.01)
    Теңгені шетел валютасына айналдырады.

    Args:
        amount: теңгедегі сома.
        rate: 1 валюта бірлігінің теңгедегі бағамы.
        commission: банк комиссиясы (үлес түрінде, әдепкі 1%).

    Returns:
        Комиссия ұсталғаннан кейінгі валюта сомасы (2 таңбаға дейін).
```

Docstring ережелері:
- бірінші жол — қысқа, нүктемен бітетін сөйлем: функция **не істейді / не қайтарады**;
- күрделі функцияда — бос жол, кейін параметрлер (`Args`) және нәтиже (`Returns`);
- `__doc__` атрибуты арқылы да оқуға болады: `print(square.__doc__)`;
- VS Code функцияның үстіне тінтуірді апарғанда docstring-ті көрсетеді.

### Модуль docstring
Файлдың ең бірінші жолы:
```python
"""Мектеп журналымен жұмыс істейтін көмекші функциялар.

Авторы: Айгерім Н., 2026.
"""
```

## 6. Тип аннотациялары (қысқаша)

Python 3.5+ параметрлер мен нәтиженің күтілетін типін көрсетуге мүмкіндік береді. Бағдарламаның жұмысына әсер етпейді, бірақ оқуды және VS Code-тың көмегін жақсартады:

```python
def greet(name: str, times: int = 1) -> str:
    """Сәлемдесу жолын times рет қайталап қайтарады."""
    return ("Сәлем, " + name + "! ") * times


print(greet("Ерлан", 2))
```
Нәтижесі:
```text
Сәлем, Ерлан! Сәлем, Ерлан! 
```

## 7. Автоматты құралдар

Стильді қолмен тексеру ұзақ — бағдарламашылар құралдарды қолданады:

| Құрал | Түрі | Не істейді |
|---|---|---|
| **Black** | форматтаушы | кодты бірыңғай стильге автоматты келтіреді |
| **Ruff** | линтер + форматтаушы | қателер мен стиль бұзушылықтарын табады (өте жылдам) |
| **Flake8** / **pycodestyle** | линтер | PEP 8 бұзушылықтарын тізімдейді |
| **Pylance** (VS Code) | талдаушы | қолданылмаған айнымалылар, қате атаулар |

```bash
pip install ruff
ruff check main.py
ruff format main.py
```
Нәтижесі (мысал):
```text
main.py:1:1: F401 [*] `os` imported but unused
main.py:7:5: E741 Ambiguous variable name: `l`
Found 2 errors.
```

VS Code-та: Extensions → «Ruff» немесе «Black Formatter» → баптауларда `Format On Save` қос. Енді әр сақтауда (`Ctrl+S`) код автоматты түрде пішімделеді.

## 8. Рефакторинг мысалы

**Рефакторинг** — бағдарламаның әрекетін өзгертпей, кодтың құрылымы мен оқылымын жақсарту.

Бастапқы код:
```python
import random,os
def Game(n):
    x=random.randint(1,n)
    T=0
    while True:
        a=int(input("?"))
        T+=1
        if a==x: print("ok",T);break
        elif a<x:print("up")
        else:print("down")
Game(100)
```

Рефакторингтен кейін:
```python
"""«Санды тап» ойыны."""

import random

MAX_NUMBER = 100


def play_guess_game(max_number):
    """Компьютер ойлаған санды табу ойынын өткізеді.

    Returns:
        Ойыншының жасаған әрекет саны.
    """
    secret = random.randint(1, max_number)
    attempts = 0
    while True:
        guess = int(input(f"1–{max_number} аралығындағы сан: "))
        attempts += 1
        if guess == secret:
            print(f"Таптың! Әрекет саны: {attempts}")
            return attempts
        if guess < secret:
            print("Үлкенірек")
        else:
            print("Кішірек")


if __name__ == "__main__":
    play_guess_game(MAX_NUMBER)
```
Не өзгерді: қолданылмаған `os` алынды, импорт бөлек жолда, тұрақты `MAX_NUMBER`, функция атауы `snake_case` және етістік, мағыналы айнымалылар, бір жолда бір әрекет, бос орындар, docstring-тер, түсінікті хабарламалар, `if __name__ == "__main__":`.

## Жиі кездесетін қателер

**1. Кірістірілген функцияның атын айнымалыға беру** (`sum`, `list`, `max`, `input`). Нәтижесі — `TypeError: 'int' object is not callable`. Шешімі — басқа атау: `total`, `items`.

**2. Docstring-ті түсініктемемен шатастыру.**
```python
def area(a, b):
    # Тіктөртбұрыштың ауданы   ← бұл docstring емес, help() көрсетпейді
    return a * b


def area_ok(a, b):
    """Тіктөртбұрыштың ауданын қайтарады."""
    return a * b
```

**3. Docstring-ті функцияның бірінші жолына қоймау.** Docstring `def`-тен кейінгі **ең бірінші** жол болуы тиіс, әйтпесе ол жай жол болып қалады.

**4. Араласқан стиль:** `studentName`, `Student_name`, `STUDENTname` — бір жобада. Python-да айнымалылар үшін тек `snake_case`.

**5. Шамадан тыс түсініктеме** — әр жолға «не істейтінін» жазу. Оның орнына атауларды жақсарт.

**6. Tab пен бос орынды араластыру.**
```text
TabError: inconsistent use of tabs and spaces in indentation
```

## Ескерту

- PEP 8 өзі «ақылсыз бірізділік — шағын ақылдың құбыжығы» дейді: егер жобада өз стилі қабылданған болса, жаңа кодты сол стильмен жазу маңыздырақ.
- Black әдепкі бойынша жол ұзындығын 88 таңба деп алады, ал PEP 8 — 79. Ruff пен Black баптауларын `pyproject.toml` файлында (`line-length`) бір мәнге келтір.
- Docstring форматының бірнеше кең тараған стилі бар: Google стилі (`Args:`/`Returns:`), NumPy стилі және reStructuredText (`:param x:`). Бір жобада біреуін ғана қолдан.
- Типтер аннотациясы орындау кезінде тексерілмейді: `greet(5)` қатесіз іске қосылуы мүмкін. Типтерді тексеру үшін `mypy` немесе Pylance сияқты статикалық талдағыштар қолданылады. Python 3.9-дан бастап `list[int]`, 3.10-нан бастап `int | None` жазуға болады.
- Ресми мәтіндер: PEP 8 — https://peps.python.org/pep-0008/, PEP 257 (docstring) — https://peps.python.org/pep-0257/.
