## Базовый уровень

### Задание 1. «Чек в магазине»
Введи цену товара (в тенге, может быть дробной) и количество. Вычисли общую сумму. Если сумма больше 10 000 ₸, дай скидку 10%. Выведи итоговую сумму, округлив до 2 знаков.

```text
Цена: 2450.5
Количество: 5
Общая сумма: 12252.5 ₸
Скидка: 1225.25 ₸
К оплате: 11027.25 ₸
```

### Задание 2. «Время года»
Введи номер месяца (1–12). Программа выводит время года; если номер неверный — «Такого месяца нет».

```text
Номер месяца: 4
Весна
```

### Задание 3. «Сумма цифр»
Введи натуральное число. С помощью цикла `while` найди сумму его цифр и количество цифр (не превращая в строку, через `%` и `//`).

```text
Число: 2026
Количество цифр: 4
Сумма цифр: 10
```

### Задание 4. «Таблица умножения»
Введи число. Выведи таблицу умножения этого числа от 1 до 10.

```text
Число: 7
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

### Задание 5. «Счётчик чётных и нечётных»
Пользователь вводит числа, пока не введёт 0. В конце выведи количество чётных и нечётных чисел и сумму всех чисел (0 не учитывается).

```text
Число: 4
Число: 7
Число: 10
Число: 0
Чётных: 2, нечётных: 1, сумма: 21
```

## ★ Олимпиадная / творческая задача

### Задание 9. «Счастливый билет»
Номер автобусного билета состоит из 6 цифр (от 000000 до 999999). Билет «счастливый», если сумма первых трёх цифр равна сумме последних трёх. Найди количество всех счастливых билетов. Дополнительно: оптимизируй решение так, чтобы оно работало быстрее 1 секунды (не проверяя миллион билетов напрямую).

Ответ: `55252`.

### Задание 10. «Последовательность Коллатца»

**Задание 9** — оптимальное решение: для каждой суммы (0–27) один раз вычисляем количество трёхзначных комбинаций и складываем их квадраты.
```python
counts = [0] * 28
for a in range(10):
    for b in range(10):
        for c in range(10):
            counts[a + b + c] += 1

lucky = 0
for k in counts:
    lucky += k * k
print(lucky)  # 55252
```

best_n = 1
best_steps = 0
for start in range(1, 1001):
    n = start
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
        steps += 1

Домашнее задание 1 (образец):
```python
import random

while True:
    level = input("Уровень (1 — лёгкий, 2 — средний, 3 — сложный): ")
    limits = {"1": (10, 5), "2": (50, 7), "3": (100, 8)}
    if level not in limits:
        print("Выбери 1, 2 или 3")
        continue
    top, max_tries = limits[level]
    secret = random.randint(1, top)
    for attempt in range(1, max_tries + 1):
        guess = int(input(f"Число от 1 до {top} ({attempt}/{max_tries}): "))
        if guess == secret:
            print("Угадал!")
            break
        print("Больше" if guess < secret else "Меньше")
    else:
        print("Попытки закончились. Ответ:", secret)
    if input("Сыграешь ещё? (да/нет): ").lower() != "да":
        break
```
