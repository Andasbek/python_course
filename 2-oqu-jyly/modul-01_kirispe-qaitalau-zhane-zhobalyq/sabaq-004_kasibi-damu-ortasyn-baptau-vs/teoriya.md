## 1. Даму ортасы деген не?

| Ұғым | Түсіндірме | Мысал |
|---|---|---|
| Интерпретатор | Python кодын жолма-жол орындайтын бағдарлама | `python.exe`, `python3` |
| Код редакторы | Мәтін (код) жазуға арналған бағдарлама | Notepad++, Sublime Text |
| IDE (integrated development environment, интеграцияланған даму ортасы) | Редактор + іске қосу + отладчик + терминал + Git бір жерде | PyCharm, VS Code (кеңейтімдермен), Thonny |
| Терминал (консоль, командалық жол) | Компьютерді мәтіндік командалармен басқару терезесі | PowerShell, cmd, bash |

Аналогия: интерпретатор — қозғалтқыш, редактор — руль, IDE — толық жабдықталған көлік кабинасы (руль, спидометр, навигатор, айналар).

**Неге VS Code?** Тегін, жеңіл, Windows/macOS/Linux-та жұмыс істейді, Python, Git, Markdown, HTML-ге қолдау бар, әлемдегі ең танымал редакторлардың бірі. PyCharm Community — Python-ға арнайы қуатты IDE, оны да қолдануға болады.

## 2. VS Code-пен танысу

### Орнату және бастапқы баптау
1. code.visualstudio.com сайтынан жүктеп орнату (Windows-та «Add to PATH» белгісін қою).
2. Кеңейтімдер (Extensions, `Ctrl+Shift+X`) бөлімінен **Python** (Microsoft) кеңейтімін орнату — ол Pylance (код талдау) және Python Debugger кеңейтімдерін де қосады.
3. Қажет болса — интерфейс тілі (Language Pack), тақырып (Theme).

### Интерфейс бөліктері
```text
┌───┬──────────────┬──────────────────────────────┐
│ А │  Explorer    │  Редактор (main.py)          │
│ к │  (файлдар)   │                              │
│ т │              │                              │
│ и │              ├──────────────────────────────┤
│ в │              │  Терминал / Output / Problems│
└───┴──────────────┴──────────────────────────────┘
             Күй жолағы (Python нұсқасы, venv)
```
- **Activity Bar** (сол жақ шеттегі белгішелер): Explorer, Search, Source Control (Git), Run and Debug, Extensions.
- **Explorer** — жоба папкасының файлдары.
- **Редактор** — код жазатын аймақ, бірнеше файл қатар ашылады.
- **Панель** — терминал (`` Ctrl+` ``), қателер (Problems), шығыс (Output).
- **Күй жолағы** — таңдалған Python интерпретаторы көрсетіледі.

### Маңызды ереже: файлды емес, **папканы** аш
File → Open Folder... арқылы жоба папкасын ашамыз. Сонда VS Code бүкіл жобаны көреді, терминал сол папкада ашылады.

### Пайдалы пернелер тіркесімі

| Перне | Әрекет |
|---|---|
| `Ctrl+Shift+P` | Командалар палитрасы (кез келген команданы іздеу) |
| `Ctrl+P` | Файлды атауы бойынша жылдам ашу |
| `` Ctrl+` `` | Терминалды ашу/жабу |
| `F5` | Отладкамен іске қосу |
| `Ctrl+/` | Жолды түсініктемеге айналдыру |
| `Alt+↑ / Alt+↓` | Жолды жоғары/төмен жылжыту |
| `Shift+Alt+F` | Кодты автоматты пішімдеу |
| `F2` | Айнымалының атын барлық жерде өзгерту |
| `Ctrl+D` | Келесі осындай сөзді қоса белгілеу (көп курсор) |

### Бағдарламаны іске қосу
- Жоғарғы оң жақтағы ▷ (Run Python File) батырмасы;
- немесе терминалда: `python main.py` (macOS/Linux-та `python3 main.py`).

### Отладчик (debugger) — қатені іздеудің кәсіби құралы
1. Жол нөмірінің сол жағын басып **тоқтау нүктесін** (breakpoint, қызыл нүкте) қой.
2. `F5` → Python File.
3. Бағдарлама сол жолда тоқтайды; сол жақта айнымалылардың **ағымдағы мәндері** көрінеді.
4. `F10` — келесі жол (Step Over), `F11` — функция ішіне кіру (Step Into), `F5` — жалғастыру.

```python
def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i      # осы жолға breakpoint қойып, result өзгерісін бақыла
    return result


print(factorial(5))
```
Нәтижесі:
```text
120
```

## 4. Виртуалды орта (venv)

### Мәселе
Елестет: 1-жобаңа `pygame` 2.5 нұсқасы керек, ал досыңның жобасы 2.1 нұсқасында ғана жұмыс істейді. Барлық пакет компьютерге **ортақ** орнатылса, нұсқалар қақтығысы туады. Сонымен қатар жобаны басқа компьютерге көшіргенде қандай пакеттер керек екені белгісіз болады.

### Шешім
**Виртуалды орта** (virtual environment) — жобаның ішіндегі жеке, оқшауланған Python «бөлмесі»: өзінің пакеттері мен нұсқалары бар. Аналогия: әр оқушының жеке пеналы — біреудің қаламы басқаның пеналына араласпайды.

```text
my_game/
├── .venv/            ← виртуалды орта (Git-ке жүктелмейді)
│   ├── Scripts/      (Windows) немесе bin/ (macOS/Linux)
│   └── Lib/site-packages/   ← осы жобаның пакеттері
├── main.py
└── requirements.txt  ← қажетті пакеттер тізімі
```

### Құру және белсендіру
```bash
# 1. Жоба папкасына өту
cd my_game

# 2. Виртуалды орта құру (.venv — папка атауы)
python -m venv .venv          # Windows
python3 -m venv .venv         # macOS / Linux

# 3. Белсендіру
.venv\Scripts\activate        # Windows (cmd / PowerShell)
source .venv/bin/activate     # macOS / Linux

# 4. Өшіру (деактивация)
deactivate
```

Белсендірілгенде терминал жолының басында `(.venv)` жазуы пайда болады:
```text
(.venv) C:\Users\Aigerim\my_game>
```

Windows PowerShell-де «running scripts is disabled» қатесі шықса, бір рет мына команданы орындау жеткілікті:
```bash
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**VS Code-та интерпретаторды таңдау:** `Ctrl+Shift+P` → «Python: Select Interpreter» → `.venv` ішіндегі Python. Осыдан кейін VS Code терминалы ортаны автоматты түрде белсендіреді.

Python ішінен қай ортада жұмыс істеп тұрғаныңды тексеру:
```python
import sys

print(sys.executable)      # қай интерпретатор жұмыс істеп тұр
print(sys.prefix != sys.base_prefix)   # True болса — виртуалды ортадамыз
```

## 5. pip — пакет менеджері

**Пакет** (кітапхана) — басқа бағдарламашылар жазған, дайын модульдер жиынтығы. Олар **PyPI** (pypi.org, Python Package Index) — Python пакеттерінің ресми «дүкенінде» сақталады (500 мыңнан астам пакет). **pip** — сол дүкеннен пакеттерді жүктеп орнататын құрал. Аналогия: смартфондағы App Store / Play Market.

| Команда | Мағынасы |
|---|---|
| `pip install requests` | Пакетті орнату |
| `pip install pygame==2.5.2` | Нақты нұсқасын орнату |
| `pip install --upgrade requests` | Жаңарту |
| `pip uninstall requests` | Жою |
| `pip list` | Орнатылған пакеттер тізімі |
| `pip show requests` | Пакет туралы мәлімет |
| `pip freeze > requirements.txt` | Тәуелділіктерді файлға жазу |
| `pip install -r requirements.txt` | Файлдағы барлық пакетті орнату |

Кеңес: `python -m pip install ...` түрінде жазу сенімдірек — пакет дәл қазіргі Python-ға орнатылады.

### requirements.txt
Жобаның «сатып алу тізімі»: қандай пакеттер және қай нұсқасы керек.

```text
colorama==0.4.6
requests==2.32.3
```

Досың жобаңды жүктеп алғанда, екі команда жеткілікті:
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Мысал: бірінші сыртқы пакет — colorama
```bash
pip install colorama
```
```python
from colorama import Fore, Style, init

init()  # Windows терминалында түстерді қосу
print(Fore.GREEN + "Сәтті орнатылды!" + Style.RESET_ALL)
print(Fore.RED + "Қате мысалы" + Style.RESET_ALL)
print(Fore.YELLOW + "Ескерту" + Style.RESET_ALL)
```
Нәтижесі (терминалда түрлі түсті):
```text
Сәтті орнатылды!
Қате мысалы
Ескерту
```

Пакет орнатылмаған болса:
```text
ModuleNotFoundError: No module named 'colorama'
```
Бұл — «пакет осы ортада жоқ» деген сигнал: venv белсендірілгенін және VS Code-та дұрыс интерпретатор таңдалғанын тексер.

### Пакеттердің қауіпсіздігі
- Тек танымал, құжаттамасы бар пакеттерді орнат (атауын pypi.org-тан тексер).
- Атауы ұқсас жалған пакеттер болады (`reqeusts` сияқты қате жазылған атаулар) — мұқият бол.
- Орнатпас бұрын pypi.org сайтында пакеттің авторын, жүктелу санын және соңғы жаңартылған күнін тексер.

## 6. Жоба құрылымының үлгісі

```text
project_name/
├── .venv/              # виртуалды орта
├── .gitignore          # Git елемейтін файлдар (.venv/, __pycache__/)
├── README.md           # жоба сипаттамасы
├── requirements.txt    # тәуелділіктер
├── main.py             # кіру нүктесі
└── utils.py            # көмекші функциялар
```

Жұмыс алгоритмі (әр жаңа жоба үшін):
1. Папка құр → VS Code-та **Open Folder**.
2. `python -m venv .venv` → интерпретаторды таңда.
3. Қажет пакеттерді `pip install` → `pip freeze > requirements.txt`.
4. `main.py` жаз → іске қос.
5. `git init` — Git арқылы нұсқаларды сақтауды баста.

## Жиі кездесетін қателер

**1. `python` командасы табылмайды.**
```text
'python' is not recognized as an internal or external command
```
Себебі: Python орнатқанда «Add Python to PATH» белгіленбеген. Шешімі: Python-ды қайта орнату (белгімен) немесе Windows-та `py` командасын қолдану.

**2. Пакетті орнаттым, бірақ `ModuleNotFoundError`.**
Себебі: пакет бір интерпретаторға орнатылды, ал VS Code басқасын қолданып тұр. Шешімі: «Python: Select Interpreter» → `.venv`; `python -m pip install ...`.

**3. Файлға стандартты модульдің атын беру.**
```text
random.py  ← өз файлыңды осылай атасаң, import random сенің файлыңды импорттайды
```
Шешімі: файлдарды `random.py`, `turtle.py`, `pygame.py` деп атама.

**4. `.venv` папкасын қолмен өзгерту немесе басқа компьютерге көшіру.**
Виртуалды орта көшіруге арналмаған. Оның орнына `requirements.txt` арқылы жаңа орта құр.

**5. venv белсендірмей `pip install` жасау** — пакет жалпы жүйеге орнатылып кетеді.

## Ескерту

- `venv` модулі Python 3.3-тен бастап стандартты кітапханаға кіреді, оны бөлек орнату қажет емес. Кейбір Linux жүйелерінде `python3-venv` пакетін қосымша орнату керек болуы мүмкін.
- `.venv` папкасын Git-ке қоспау үшін `.gitignore` файлына `.venv/` жолын жаз; ортаны кез келген уақытта `requirements.txt` бойынша қайта құруға болады.
- `pip freeze` ортадағы барлық пакеттерді, соның ішінде жанама тәуелділіктерді де жазады. Сондықтан `requirements.txt` жасамас бұрын ортада артық пакет жоқ екеніне көз жеткіз.
- Жаңа Linux және macOS жүйелерінде жүйелік Python-ға `pip install` жасау `externally-managed-environment` қатесімен бұғатталуы мүмкін (PEP 668) — бұл виртуалды ортаны пайдаланудың тағы бір себебі.
- Ресми құжаттама: https://docs.python.org/3/library/venv.html және https://pip.pypa.io/.
