## 1. GitHub деген не?

**GitHub** — Git репозиторийлерін интернетте сақтайтын, бөлісетін және бірлесіп әзірлейтін платформа. Онда 100 миллионнан астам бағдарламашы бар; Python тілінің өзі де, VS Code, pygame, pandas сияқты жобалар да GitHub-та әзірленеді.

Ұқсас сервистер: GitLab, Bitbucket — жұмыс принципі бірдей.

| Ұғым | Түсіндірме |
|---|---|
| Жергілікті репозиторий (local) | Сенің компьютеріңдегі `.git` |
| Қашықтағы репозиторий (remote) | GitHub серверіндегі көшірме |
| `origin` | Қашықтағы репозиторийдің әдепкі атауы |
| Public | Барлығы көре алады (портфолио үшін) |
| Private | Тек сен және шақырылғандар көреді |

Аналогия: жергілікті репозиторий — телефондағы фотоальбом, GitHub — бұлттағы альбом. `push` — суреттерді бұлтқа жүктеу, `pull` — бұлттан жаңаларын телефонға алу, `clone` — жаңа телефонға бүкіл альбомды көшіру.

```text
   Сенің компьютерің                         GitHub (origin)
 ┌───────────────────┐      git push       ┌───────────────────┐
 │ жергілікті        │ ──────────────────► │ қашықтағы         │
 │ репозиторий       │                     │ репозиторий       │
 │                   │ ◄────────────────── │                   │
 └───────────────────┘   git pull / clone  └───────────────────┘
```

## 2. Аккаунт және қауіпсіздік

1. github.com → **Sign up**: пошта, құпиясөз, пайдаланушы атауы (username).
2. Пайдаланушы атауы — портфолиоңның мекенжайы: `https://github.com/aigerim-dev`. Кәсіби, түсінікті ат таңда (`super_killer_2013` емес).
3. Құпиясөз — күрделі, ешкімге айтпа; **екі факторлы аутентификацияны** (2FA) қос.
4. Жеке поштаңды жасыру: Settings → Emails → «Keep my email addresses private». Сонда GitHub `12345678+aigerim-dev@users.noreply.github.com` түріндегі пошта береді — оны Git-ке баптаймыз:

```bash
git config --global user.email "12345678+aigerim-dev@users.noreply.github.com"
```

**Ешқашан жария репозиторийге жүктеме:** құпиясөздер, API кілттері, үй мекенжайы, телефон, жеке құжаттардың суреттері.

## 3. GitHub-та репозиторий құру

1. Оң жақ жоғарғы бұрыштағы **+** → **New repository**.
2. **Repository name**: `calculator` (кіші әріп, бос орынсыз, сөздер сызықшамен: `todo-app`).
3. **Description**: «Python тіліндегі консольдық калькулятор».
4. **Public**.
5. Егер жергілікті репозиторий бұрыннан бар болса — README, .gitignore, license **қоспа** (бос репозиторий құр), әйтпесе тарихтар қақтығысады.
6. **Create repository**.

GitHub репозиторийді байланыстыру нұсқаулығын көрсетеді — оның командалары төменде берілген.

## 4. Жергілікті репозиторийді GitHub-пен байланыстыру

```bash
cd calculator
git remote add origin https://github.com/aigerim-dev/calculator.git
git remote -v
git branch -M main
git push -u origin main
```

| Команда | Мағынасы |
|---|---|
| `git remote add origin URL` | Қашықтағы репозиторийді `origin` деген атпен тіркеу |
| `git remote -v` | Тіркелген remote-тарды көру |
| `git branch -M main` | Тармақ атауын `main` деп бекіту |
| `git push -u origin main` | Коммиттерді жіберу; `-u` — байланысты есте сақтау |

Нәтижесі:
```text
Enumerating objects: 15, done.
Counting objects: 100% (15/15), done.
Writing objects: 100% (15/15), 1.85 KiB | 1.85 MiB/s, done.
To https://github.com/aigerim-dev/calculator.git
 * [new branch]      main -> main
branch 'main' set up to track 'origin/main'.
```

Бірінші `push` кезінде браузерде GitHub-қа кіру терезесі ашылады (Git Credential Manager). GitHub 2021 жылдан бастап терминалда кәдімгі құпиясөзді қабылдамайды: браузер арқылы кіру немесе **жеке қатынау токені** (Personal Access Token) қолданылады. Токен — құпиясөз сияқты құпия, оны кодқа немесе репозиторийге жазба.

Келесі жолдары жай ғана:
```bash
git add .
git commit -m "Дәрежеге шығару амалы қосылды"
git push
```

GitHub бетін жаңартсаң — файлдар, коммиттер саны, соңғы коммит хабарламасы көрінеді. **Commits** бөлімінде бүкіл тарих, әр коммиттің diff-і бар.

## 5. git pull — өзгерістерді алу

Репозиторий екі жерде өзгеруі мүмкін: мысалы, екі түрлі компьютерде немесе екі адам бір жобамен жұмыс істегенде. GitHub-тағы жаңа коммиттерді жергілікті репозиторийге алу үшін:

```bash
git pull
```
Нәтижесі:
```text
remote: Enumerating objects: 5, done.
Updating 9c41e02..b7d3a10
Fast-forward
 README.md | 4 ++++
 1 file changed, 4 insertions(+)
```

**Алтын ереже:** жұмысты бастамас бұрын — `git pull`, аяқтағаннан кейін — `git push`.

`push` қабылданбаса:
```text
! [rejected]        main -> main (fetch first)
error: failed to push some refs to 'https://github.com/aigerim-dev/calculator.git'
hint: Updates were rejected because the remote contains work that you do not have locally.
```
Себебі — GitHub-та сенде жоқ коммиттер бар. Шешімі: алдымен `git pull`, сосын `git push`. (Екі жерде бір жол өзгерсе, **қақтығыс** (conflict) болады — оны файлдағы `<<<<<<<`, `=======`, `>>>>>>>` белгілері арасынан дұрыс нұсқаны таңдап, қолмен шешеді, сосын `git add` және `git commit` жасайды.)

## 6. git clone — репозиторийді көшіру

Басқа компьютерде (немесе біреудің жобасын) жүктеп алу:
```bash
git clone https://github.com/aigerim-dev/calculator.git
cd calculator
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
`clone` бүкіл тарихты көшіреді және `origin`-ді автоматты түрде баптайды.

| Команда | Қашан |
|---|---|
| `git clone URL` | Жобаны бірінші рет жүктеу (бір рет) |
| `git pull` | Бар жобаны жаңарту (жиі) |
| `git push` | Өз өзгерістеріңді жіберу (жиі) |

## 7. Markdown және README.md

**README.md** — репозиторийдің «мұқабасы»: GitHub оны жобаның басты бетінде көрсетеді. Ол **Markdown** — қарапайым белгілеу тілінде жазылады.

| Markdown | Нәтижесі |
|---|---|
| `# Тақырып` | Үлкен тақырып |
| `## Ішкі тақырып` | Кіші тақырып |
| `**қалың**` | **қалың** |
| `*курсив*` | *курсив* |
| `- пункт` | маркерлі тізім |
| `1. пункт` | нөмірлі тізім |
| `` `код` `` | `код` |
| `[мәтін](https://...)` | сілтеме |
| `![сурет](screenshot.png)` | сурет |
| ` ```python ... ``` ` | код блогы |

README үлгісі:
````text
# Калькулятор

Python тілінде жазылған консольдық калькулятор: +, -, *, /, ** амалдары.

## Мүмкіндіктері
- 5 арифметикалық амал
- нөлге бөлуді тексеру
- циклде жұмыс істейді, 0 — шығу

## Іске қосу
```bash
python calc.py
```

## Скриншот
![Жұмыс үлгісі](screenshot.png)

## Авторы
Айгерім Н., «Python» үйірмесі, 2026
````

## 8. Портфолио

**Портфолио** — сенің жұмыстарыңның витринасы. GitHub-та ол екі бөліктен тұрады:

1. **Профиль README** — пайдаланушы атауымен **бірдей** аталатын арнайы репозиторий (`aigerim-dev/aigerim-dev`). Оның README.md файлы профиль бетінің жоғарғы жағында көрсетіледі.
2. **Жоба репозиторийлері** — әр модуль жобасы бөлек репозиторий: `calculator`, `library-oop`, `todo-tkinter`, `space-game`, `students-db`, `weather-app`, `data-analysis`, `final-project`.

Профиль README үлгісі:
```text
# Сәлем! Мен — Айгерім 👋

Алматыдағы «Python» үйірмесінің 2-жыл оқушысымын.

## Үйреніп жатқаным
- Python, ОБП, Git
- Келесі мақсатым: Tkinter және Pygame

## Жобаларым
| Жоба | Сипаттамасы | Технологиялар |
|---|---|---|
| [calculator](https://github.com/aigerim-dev/calculator) | Консольдық калькулятор | Python |

## Байланыс
GitHub арқылы issue жазыңыз.
```

Портфолио ережелері:
- әр жобада README және скриншот;
- мағыналы коммиттер (тарих — сенің жұмыс стилің);
- жоба атауы түсінікті, ағылшынша кіші әріппен;
- **жеке деректер жоқ** (мектеп нөмірі, телефон, мекенжай);
- репозиторийде `.venv`, `__pycache__` жоқ (`.gitignore`).

## 9. GitHub-тың басқа мүмкіндіктері (шолу)

| Мүмкіндік | Не үшін |
|---|---|
| ⭐ Star | Ұнаған жобаны белгілеу |
| Fork | Біреудің жобасын өз аккаунтыңа көшіру |
| Issues | Қателер мен идеялар тізімі |
| Pull Request | Өзгеріс ұсыну (командалық жұмыста) |

| Insights → Contributors | Кім қанша үлес қосқанын көру |

## Жиі кездесетін қателер

**1. GitHub-та README-мен репозиторий құрып, кейін жергілікті тарихты push жасау.**
```text
! [rejected] main -> main (fetch first)
```
Шешімі: бос репозиторий құр, немесе `git pull origin main --allow-unrelated-histories`; соңғы тәсілді абайлап қолдан.

**2. `remote origin already exists`.** origin бұрын тіркелген. Тексер: `git remote -v`; өзгерту: `git remote set-url origin НАҚТЫ_URL`.

**3. Терминалда кәдімгі құпиясөзді енгізу.** `Authentication failed` — браузер арқылы кір немесе токен қолдан.

**4. URL-ді қате көшіру** (`github.com/aigerim-dev` — профиль сілтемесі, репозиторийдікі емес). Дұрыс: `https://github.com/aigerim-dev/calculator.git`.

**5. Коммиттемей push жасау.** `Everything up-to-date` — жіберетін жаңа коммит жоқ. Алдымен `add` + `commit`.

**6. Құпия ақпаратты жүктеу.** Файлды кейін жойсаң да, ол **тарихта қалады**! Сондықтан алдын ала `.gitignore` және мұқият тексеру. Құпиясөз жүктеліп кетсе — оны бірден ауыстыр.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| GitHub | Git репозиторийлерін бұлтта сақтау және бірлесу платформасы |
| Remote / origin | Қашықтағы репозиторий / оның әдепкі атауы |
| push | Жергілікті коммиттерді GitHub-қа жіберу |
| pull | GitHub-тағы жаңа коммиттерді алу |
| clone | Репозиторийді толық тарихымен көшіру |
| README.md | Жобаның басты сипаттамасы |
| Markdown | Мәтінді белгілеудің қарапайым тілі |
| Портфолио | Жобалар жинағы, бағдарламашының «визиткасы» |
| Токен (PAT) | Құпиясөздің орнына қолданылатын қатынау кілті |
| 2FA | Екі факторлы аутентификация |

## Ескерту

- GitHub 2020 жылдан бастап жаңа репозиторийлердің негізгі тармағын `master` емес, `main` деп атайды. Ескі нұсқаулықтарда `git push origin master` кездеседі.
- `git pull` — бұл `git fetch` (жаңа коммиттерді жүктеу) пен `git merge` (біріктіру) командаларының тіркесімі. Өзгерістерді біріктірмей тек көру үшін `git fetch`, сосын `git log origin/main` қолданылады.
- HTTPS орнына SSH кілттері арқылы да қосылуға болады (`git@github.com:user/repo.git`); бұл жағдайда әр `push` кезінде кіру қажет емес.
- GitHub README файлын GitHub Flavored Markdown ережелерімен көрсетеді: кестелер, тапсырмалар тізімі (`- [ ]`) және код блоктарын тілдік бояу (```python) қолдайды.
- Ресми құжаттама: https://docs.github.com/ және Markdown бойынша қысқаша нұсқаулық: https://docs.github.com/en/get-started/writing-on-github.
