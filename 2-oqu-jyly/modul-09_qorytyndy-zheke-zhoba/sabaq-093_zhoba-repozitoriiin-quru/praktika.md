# Сабақ 93. Практикалық тапсырмалар: репозиторий және жоба жоспары

## Базалық деңгей

### 1-тапсырма. Жоба репозиторийін құру (міндетті)
Теориядағы 2-бөлімнің қадамдарын өз жобаңызға орындаңыз:
1. Жоба папкасы, `venv`, қажетті кітапханалар, `requirements.txt`.
2. Папкалық құрылым: `main.py`, пакет папкасы (`__init__.py`-мен), `tests/`, `docs/`, (ойын болса `assets/`).
3. `.gitignore` (кемінде: `__pycache__/`, `venv/`, `.env`, `*.db`).
4. Бастапқы `README.md` (атауы, 1–2 сөйлем сипаттама, технологиялар, «әзірленуде»).
5. 91–92 сабақтардың материалдары: `docs/data_model.md`, `docs/er.png`, `prototype.py`.
6. Алғашқы коммит және GitHub-қа `push`.

Тексеру: `git status` командасы `venv/` пен `.db` файлдарын көрсетпейді; GitHub бетінде құрылым көрінеді.

### 2-тапсырма. Коммит хабарламаларын түзету
Жаман хабарламаларды жақсы хабарламаға айналдырыңыз:
1. `upd`
2. `fixed bug`
3. `123`
4. `жасадым`
5. `final final 2`

Контекст: 1) ойыншының жылдамдығы қосылды; 2) бос атпен тіркелуге болатын қате; 3) README-ге скриншот қосылды; 4) рекордтарды JSON-ға сақтау; 5) соңғы түзетулер — шын мәнінде 3 түрлі өзгеріс.

### 3-тапсырма. Декомпозиция
«Викторина» жобасының мына үлкен тапсырмаларын 1–2 сағаттық тапсырмаларға бөліңіз (әрқайсысына кемінде 3 тапсырма, әр тапсырмаға «дайын болды деп есептеледі, егер...» белгісі):
- А. «Сұрақтармен жұмыс»
- Ә. «Ойын барысы»
- Б. «Рекордтар кестесі»

### 4-тапсырма. MoSCoW
Өз жобаңыздың барлық мүмкіндігін (ТТ-дан) MoSCoW кестесіне бөліңіз. Тексеріңіз: Must бөлігі 97-сабаққа (MVP) дейін бітетіндей ме?

## Кеңейтілген деңгей

### 5-тапсырма. GitHub Issues, Milestones, Projects
1. Екі milestone құрыңыз: `MVP` (мерзімі 29.04.27) және `v1.0` (мерзімі 11.05.27).
2. 3-тапсырмадағыдай кемінде 10 issue құрыңыз; әрқайсысына белгі (`must/should/could`) және milestone беріңіз.
3. Projects-те Kanban тақтасын құрыңыз: *Жоспарда → Жұмыста → Тексеруде → Дайын*. Барлық issue-ді «Жоспарда» бағанына қойыңыз, 94-сабақтың тапсырмаларын «Жұмыста»-ға ауыстырыңыз.
4. Бір коммитті issue-мен байланыстырыңыз (`... (#1)`).

### 6-тапсырма. Гант кестесі
Жобаңыздың тапсырмаларын 94–102 сабақтарға бөліп, теориядағыдай мәтіндік Гант кестесін `docs/plan.md` файлына жазыңыз. Әр сабаққа 2 сағаттан артық жұмыс қоймаңыз, тесттер мен құжаттауды ұмытпаңыз.

### 7-тапсырма. Прогресс есептегіш
`docs/plan.csv` файлын (баған: `task,stage,deadline,status`) оқып, мыналарды шығаратын `tools/progress.py` скриптін жазыңыз:
- орындалған пайыз және прогресс-жолақ;
- мерзімі өткен, бірақ `done` емес тапсырмалар (бүгінгі күнді `datetime.date.today()` арқылы алыңыз; мерзім `КК.АА.ЖЖ` форматында).

Шығару мысалы:


## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Критикалық жол
Тапсырмалардың ұзақтығы (сағатпен) және тәуелділіктері берілген. Жобаны аяқтаудың ең аз уақытын (критикалық жолды) есептейтін бағдарлама жазыңыз.

```text
A: 2 сағ, тәуелділік жоқ        (models.py)
B: 3 сағ, A-дан кейін           (logic.py)
C: 2 сағ, A-дан кейін           (database.py)
D: 4 сағ, B және C-дан кейін    (gui.py)
E: 1 сағ, B-дан кейін           (тесттер)
F: 2 сағ, D және E-ден кейін    (README)
```
Шығару: `Ең аз уақыт: 11 сағ, жол: A -> B -> D -> F`.

### 9-тапсырма. Issue шаблоны
Репозиторийге `.github/ISSUE_TEMPLATE/bug_report.md` шаблонын қосыңыз: «Не болды», «Қалай қайталауға болады (қадамдар)», «Не күтілді», «Скриншот». Бұл шаблон 98–99 сабақтарда қателерді тіркеуге қолданылады.

## Үй тапсырмасы
1. Репозиторийді аяқтап, сілтемесін педагогке жіберіңіз (сынып чатына / кестеге).
2. Kanban тақтасындағы 94-сабақтың тапсырмаларын қайта оқып, қай кластан бастайтыныңызды шешіңіз.
3. 3–5 тақырыпты қайталаңыз: класс, `__init__`, әдістер (9–18 сабақтар) — келесі сабақта негізгі логиканы жазамыз.

**7-тапсырма.**
```python
import csv
import datetime
import sys


def load(path):
    with open(path, encoding="utf-8") as f:
        return list(csv.DictReader(f))


def parse_date(text):
    """'26.04.27' -> datetime.date(2027, 4, 26)"""
    return datetime.datetime.strptime(text, "%d.%m.%y").date()


def report(rows, today):
    done = sum(1 for r in rows if r["status"] == "done")
    percent = done * 100 // len(rows) if rows else 0
    bar = "#" * (percent // 10) + "-" * (10 - percent // 10)
    print(f"Прогресс: {percent}% [{bar}]")
    for r in rows:
        if r["status"] != "done" and parse_date(r["deadline"]) < today:
            print(f"Мерзімі өткен: {r['task']} ({r['deadline']})")


if __name__ == "__main__":
    path = sys.argv[1] if len(sys.argv) > 1 else "docs/plan.csv"
    report(load(path), datetime.date.today())
```

**8-тапсырма.** Тапсырмалар тәуелділік ретімен берілгендіктен, «ең ерте аяқталу уақытын» бір өтумен есептеуге болады (жалпы жағдайда топологиялық сұрыптау керек).
```python
tasks = {
    "A": (2, []),
    "B": (3, ["A"]),
    "C": (2, ["A"]),
    "D": (4, ["B", "C"]),
    "E": (1, ["B"]),
    "F": (2, ["D", "E"]),
}

finish = {}   # тапсырманың ең ерте аяқталу уақыты
prev = {}     # критикалық жолдағы алдыңғы тапсырма


def earliest_finish(name):
    if name in finish:
        return finish[name]
    duration, deps = tasks[name]
    start = 0
    prev[name] = None
    for d in deps:
        if earliest_finish(d) > start:
            start = earliest_finish(d)
            prev[name] = d
    finish[name] = start + duration
    return finish[name]


last = max(tasks, key=earliest_finish)
path = []
node = last
while node is not None:
    path.append(node)
    node = prev[node]
print(f"Ең аз уақыт: {finish[last]} сағ, жол: {' -> '.join(reversed(path))}")
```
Нәтижесі:
```text
Ең аз уақыт: 11 сағ, жол: A -> B -> D -> F
```
