## 1. Күрделі есепті бөлу: «жоғарыдан төменге»

Күрделі тапсырманы бірден кодтамаймыз. Алдымен оны **бір сөйлеммен** айтып, сосын қадамдарға бөлеміз; әр қадам — жеке функция. Бұл әдіс **жоғарыдан төменге жобалау** (нисходящее проектирование, top-down design) деп аталады.

Мысал: «Ай соңындағы есеп: қанша кірді, қанша шықты, ең көп жұмсалған санат, күніне орташа шығыс, лимиттен асқан санаттар».

```text
monthly_report(year, month)
├── operations_in_month(year, month)      -> айдың операциялары
├── sum_by_kind(ops)                      -> {'кіріс': ..., 'шығыс': ...}
├── total_by_category(ops)                -> {'Тамақ': ...}
│   └── top_category(totals)              -> ('Тамақ', 2300)
├── average_per_day(total, year, month)   -> күніне орташа
└── check_limits(totals)                  -> асқан санаттар
```

Әр функция **5–15 жол**, бір ғана жұмыс істейді және оны бөлек тексеруге болады.

## 2. Псевдокод

**Псевдокод** — алгоритмді адам тілінде, бірақ код құрылымымен жазу. Синтаксиске алаңдамай, логиканы ойлауға мүмкіндік береді.

```text
ФУНКЦИЯ жинау_күнін_болжау(мақсат, қазіргі_баланс, операциялар):
    ЕГЕР қазіргі_баланс >= мақсат: ҚАЙТАР "бүгін"
    соңғы 30 күннің операцияларын ал
    таза_жинақ = кірістер - шығыстар
    ЕГЕР таза_жинақ <= 0: ҚАЙТАР "бұл қарқынмен жинау мүмкін емес"
    күніне = таза_жинақ / 30
    қалған_күн = жоғары_дөңгелекте((мақсат - қазіргі_баланс) / күніне)
    ҚАЙТАР бүгін + қалған_күн
```

Псевдокод дайын болғанда, оны кодқа аудару оңай:

```python
import datetime
import math


def forecast_goal_date(goal, balance, ops_last_30_days, today):
    """Мақсатқа жететін күнді болжайды. ops: (сома_таңбасымен, күні) тізімі."""
    if balance >= goal:
        return today
    net = sum(amount for amount, _ in ops_last_30_days)
    if net <= 0:
        return None                     # бұл қарқынмен жинау мүмкін емес
    per_day = net / 30
    days_left = math.ceil((goal - balance) / per_day)
    return today + datetime.timedelta(days=days_left)


today = datetime.date(2027, 4, 26)
ops = [(3000, today), (-800, today), (-200, today), (3000, today), (-1000, today)]
result = forecast_goal_date(60000, 12000, ops, today)
print("Велосипедке жинайтын күн:", result)
print(forecast_goal_date(60000, 12000, [(-500, today)], today))
```

Нәтижесі:
```text
Велосипедке жинайтын күн: 2028-04-20
None
```

(Айына 4000 тг жиналады → күніне ≈133,3 тг → қалған 48 000 тг үшін 360 күн, яғни шамамен бір жыл. Мұндай болжам пайдаланушыға «шығысты азайтсаң, ертерек жинайсың» деген ой салады — бұл жобаның пайдалы мүмкіндігі.)

## 3. Деректерді өңдеудің негізгі тәсілдері

### 3.1. Сүзу (фильтр)
Тізімнен шартқа сай элементтерді таңдау — тізім генераторы (list comprehension) арқылы:

```python
import datetime

ops = [
    {"amount": 800, "cat": "Тамақ", "date": datetime.date(2027, 4, 1), "note": "түскі ас"},
    {"amount": 200, "cat": "Көлік", "date": datetime.date(2027, 4, 2), "note": "автобус"},
    {"amount": 1500, "cat": "Ойын-сауық", "date": datetime.date(2027, 4, 20), "note": "кино"},
    {"amount": 600, "cat": "Тамақ", "date": datetime.date(2027, 3, 30), "note": "балмұздақ"},
]


def filter_ops(ops, start=None, end=None, category=None, text=""):
    """Бірнеше шарт бойынша сүзу; берілмеген шарт тексерілмейді."""
    result = []
    for op in ops:
        if start and op["date"] < start:
            continue
        if end and op["date"] > end:
            continue
        if category and op["cat"] != category:
            continue
        if text and text.lower() not in op["note"].lower():
            continue
        result.append(op)
    return result


april = filter_ops(ops, datetime.date(2027, 4, 1), datetime.date(2027, 4, 30))
print(len(april), [o["note"] for o in april])
print([o["note"] for o in filter_ops(ops, category="Тамақ")])
print([o["note"] for o in filter_ops(ops, text="КИН")])
```

Нәтижесі:
```text
3 ['түскі ас', 'автобус', 'кино']
['түскі ас', 'балмұздақ']
['кино']
```

### 3.2. Сұрыптау: `key` және `lambda`
```python
ops = [("Тамақ", 800), ("Көлік", 200), ("Кино", 1500)]
by_amount = sorted(ops, key=lambda op: op[1], reverse=True)
print(by_amount)
# Бірнеше белгі бойынша: алдымен сома кему ретімен, тең болса — атауы бойынша
ops2 = [("Б", 500), ("А", 500), ("В", 900)]
print(sorted(ops2, key=lambda op: (-op[1], op[0])))
```

Нәтижесі:
```text

[('В', 900), ('А', 500), ('Б', 500)]
```

### 3.3. Топтау және агрегация
`collections.defaultdict` — жоқ кілтке әдепкі мән беретін сөздік. `get(..., 0)`-ді әр жолы жазудан құтқарады:

```python
from collections import defaultdict
import datetime

ops = [
    (800, datetime.date(2027, 3, 30)),
    (200, datetime.date(2027, 4, 2)),
    (1500, datetime.date(2027, 4, 20)),
    (400, datetime.date(2027, 5, 1)),
]
by_month = defaultdict(int)
for amount, d in ops:
    by_month[d.strftime("%Y-%m")] += amount

for month in sorted(by_month):
    print(month, by_month[month])
best = max(by_month, key=by_month.get)
print("Ең көп жұмсалған ай:", best)
```

Нәтижесі:
```text
2027-03 800
2027-04 1700
2027-05 400
Ең көп жұмсалған ай: 2027-04
```

### 3.4. Күндермен жұмыс
| Міндет | Код |
|---|---|
| Бүгін | `datetime.date.today()` |
| N күннен кейін | `d + datetime.timedelta(days=N)` |
| Екі күн арасы | `(d2 - d1).days` |
| Мәтіннен күн | `datetime.date.fromisoformat("2027-04-26")` |
| Күннен мәтін | `d.strftime("%d.%m.%Y")` → `'26.04.2027'` |
| Айдағы күн саны | `calendar.monthrange(2027, 2)[1]` → `28` |

## 4. Күй машинасы (state machine)

Ойындарда, викториналарда, тапсырыс жүйелерінде объект бір **күйден** екіншісіне ауысады. Мұны `if`-тердің шатасқан тізбегімен емес, **ауысулар кестесімен** сипаттау анық әрі қатесіз.

```text
           start            pause
  [menu] --------> [game] --------> [paused]
     ^               |   <--------     |
     |          lose |     resume      | quit
     |               v                 |
     +--- restart [over] <-------------+
```

```python
TRANSITIONS = {
    ("menu", "start"): "game",
    ("game", "pause"): "paused",
    ("paused", "resume"): "game",
    ("paused", "quit"): "over",
    ("game", "lose"): "over",
    ("over", "restart"): "menu",
}


class GameState:
    def __init__(self):
        self.state = "menu"

    def send(self, event):
        """Оқиға бойынша күйді ауыстырады; рұқсат етілмесе — ValueError."""
        key = (self.state, event)
        if key not in TRANSITIONS:
            raise ValueError(f"'{self.state}' күйінде '{event}' мүмкін емес")
        self.state = TRANSITIONS[key]
        return self.state


g = GameState()
for e in ["start", "pause", "resume", "lose", "restart"]:
    print(e, "->", g.send(e))
try:
    g.send("pause")
except ValueError as err:
    print("Қате:", err)
```

Нәтижесі:
```text
start -> game
pause -> paused
resume -> game
lose -> over
restart -> menu
Қате: 'menu' күйінде 'pause' мүмкін емес
```

Pygame циклінде пернені басқанда тек `g.send("pause")` шақырылады, ал экранға не салу керегін `g.state` анықтайды.

## 5. Жылдам тексеру: `assert`

`assert шарт, "хабар"` — шарт жалған болса, `AssertionError` көтереді. Логиканы жазып болған соң, файлдың соңына бірнеше `assert` қойып, ерекше жағдайларды тексеру ыңғайлы (толық тесттер `unittest` модулі арқылы жазылады).

```python
def average(values):
    """Орташа мән; бос тізім үшін 0."""
    if not values:
        return 0
    return sum(values) / len(values)


assert average([2, 4, 6]) == 4
assert average([]) == 0, "бос тізім 0 қайтаруы керек"
assert average([5]) == 5
print("Барлық тексеріс өтті")
```

Нәтижесі:
```text
Барлық тексеріс өтті
```

**Ерекше жағдайлар (шекаралық мәндер) тізімі** — әр функцияға осыларды ойлаңыз:
- бос тізім / бос жол;
- бір ғана элемент;
- нөл, теріс сан, өте үлкен сан;
- айдың соңғы күні, ақпанның 28/29-ы, жыл ауысуы (31.12 → 01.01);
- бірдей мәндер (сұрыптаудағы тең сомалар);
- қазақ әріптері мен бос орындар (`"Тамақ "` ≠ `"Тамақ"`).

## 6. Рефакторинг: кодты жақсарту

**Рефакторинг** — бағдарламаның **не істейтінін өзгертпей**, кодтың құрылымын жақсарту. 2-кезеңде логика өскен сайын қайталанған код пайда болады.

**DRY ережесі** (Don't Repeat Yourself — «Өзіңді қайталама»):

Рефакторингке дейін:
```python
def total_food(ops):
    s = 0
    for op in ops:
        if op["cat"] == "Тамақ":
            s += op["amount"]
    return s


def total_transport(ops):
    s = 0
    for op in ops:
        if op["cat"] == "Көлік":
            s += op["amount"]
    return s
```

Рефакторингтен кейін:
```python
def total_for(ops, category):
    """Берілген санаттың қосындысы."""
    return sum(op["amount"] for op in ops if op["cat"] == category)


ops = [{"cat": "Тамақ", "amount": 800}, {"cat": "Көлік", "amount": 200},
       {"cat": "Тамақ", "amount": 500}]
print(total_for(ops, "Тамақ"), total_for(ops, "Көлік"))
```

Нәтижесі:
```text
1300 200
```

«Кодтың жағымсыз иістері» (code smells) — рефакторинг керек екенінің белгілері:

| Белгі | Не істейміз |
|---|---|
| Функция 30 жолдан ұзын | бірнеше функцияға бөлеміз |
| Бір код 2–3 жерде қайталанады | ортақ функция/әдіс |
| Сиқырлы сандар (`if score > 37`) | атауы бар тұрақты: `WIN_SCORE = 37` |
| 4–5 деңгейлі кірістірілген `if` | ерте `return`/`continue`, сөздік-кесте |
| `a`, `x1`, `tmp2` атаулар | мағыналы атаулар (PEP 8) |

> **Маңызды:** рефакторингтен кейін бағдарламаны міндетті түрде қайта іске қосып, `assert`-тексерулерді жүргізіңіз — бұзылған жоқ па?

## Жиі кездесетін қателер

**1. Циклде тізімді өзгерту.**
```python
nums = [1, 2, 2, 3]
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)     # [1, 2, 3] — бір «2» қалып қойды!
```
Түсіндірме: элемент өшкенде индекстер жылжиды, цикл бір элементті өткізіп жібереді. Дұрысы — жаңа тізім құру:
```python
nums = [1, 2, 2, 3]
nums = [n for n in nums if n != 2]
print(nums)     # [1, 3]
```

**2. Бос тізімде `max()` немесе нөлге бөлу.** `max([])` → `ValueError`, `sum([]) / len([])` → `ZeroDivisionError`. Дұрысы: `max(values, default=0)` және алдын ала `if not values` тексеру.

**3. Күнді мәтін ретінде салыстыру.** `"9.04.2027" > "10.04.2027"` → `True` (мәтін бойынша «9» > «1»). Дұрысы: `datetime.date` объектілерін немесе ISO форматын (`2027-04-09`) салыстыру.

**4. Сиқырлы сандар.** `if len(ops) > 50` — «50» не екені түсініксіз. Дұрысы: `MAX_HISTORY = 50`.

**5. Бір функция бәрін істейді** — есептейді, сүзеді және форматтайды. Дұрысы: есептеу бөлек, форматтау (мәтін құрау) — интерфейс қабатында.

## Негізгі ұғымдар
| Ұғым | Түсіндірме |
|---|---|
| Жоғарыдан төменге жобалау | үлкен есепті біртіндеп кіші функцияларға бөлу |
| Псевдокод | алгоритмді адам тілінде, код құрылымымен жазу |
| `lambda` | атаусыз қысқа функция, жиі `key=` үшін |
| `defaultdict` | жоқ кілтке әдепкі мән беретін сөздік |
| Күй машинасы | күйлер мен ауысуларды кестемен сипаттау |
| `assert` | шарт жалған болса қате беретін жылдам тексеру |
| Рефакторинг | мінез-құлықты өзгертпей кодты жақсарту |
| DRY | «өзіңді қайталама» ережесі |
| Шекаралық мән | бос, нөл, ең үлкен т.б. ерекше кіріс деректер |

## Ескерту

- Python `-O` жалаушасымен іске қосылғанда `assert` өшіріледі: оны пайдаланушы енгізуін тексеру үшін қолданбаңыз — ол үшін `if ... raise ValueError(...)` керек.
- `sorted()` пен `list.sort()` тұрақты: кілті тең элементтер бастапқы ретін сақтайды, сондықтан бірнеше өтуде сұрыптауға болады (алдымен қосымша кілт, содан кейін негізгі кілт бойынша).
- `lambda op: op[1]` орнына `operator.itemgetter(1)`, ал объектілер үшін `operator.attrgetter("amount")` қолдануға болады: қысқарақ әрі сәл жылдамырақ.
- `collections.Counter` санауға ыңғайлы (`Counter(cats).most_common(3)`), ал `defaultdict(list)` — элементтерді кілт бойынша топтауға.
- Python 3.10+ нұсқасында күй машинасын `match`/`case` арқылы да сипаттауға болады, бірақ сөздіктегі өтулер кестесін кеңейту мен тексеру оңайырақ.
- Құжаттама: https://docs.python.org/3/howto/sorting.html және https://docs.python.org/3/library/collections.html
