**1-тапсырма.** Ескертулер:
- [С] `API_KEY` кодта ашық — құпия дерек GitHub-қа түседі (рекордтар модуліне мүлде керек емес).
- [С] `avg()` бос тізімде `ZeroDivisionError`; `best()` бос тізімде `IndexError`.
- [С] `LoadData` файл жоқ болса `FileNotFoundError` — бірінші іске қосуда бағдарлама құлайды.
- [М] `data.sort()` тізімдерді **аты** бойынша сұрыптайды, ұпай бойынша емес → `best()` ең үздік нәтижені емес, алфавит бойынша біріншіні қайтарады.
- [М] Файлдар жабылмайды (`with` жоқ), `encoding="utf-8"` және `ensure_ascii=False` жоқ.
- [Ұ] `global data` — ғаламдық күй; класқа (`Records`) немесе параметрге ауыстыру.
- [Ұ] Атаулар: `LoadData` (PEP 8 бойынша `load_data`), `n`, `s`, `t`, `f`; docstring жоқ; `[n, s]` орнына сөздік `{"name":..., "score":...}`.
- [Т] `range(len(data))` орнына тікелей итерация немесе `sum(...)`.
Артықшылықтар: функциялар қысқа; деректер JSON-да — оқуға ыңғайлы.

Түзетілген нұсқа (талқылау үшін):
```python
import json

RECORDS_FILE = "records.json"


class Records:
    """Ойын рекордтары: JSON файлында сақталады."""

    def __init__(self, path=RECORDS_FILE):
        self.path = path
        self.items = self._load()

    def _load(self):
        try:
            with open(self.path, encoding="utf-8") as f:
                return json.load(f)
        except (FileNotFoundError, json.JSONDecodeError):
            return []

    def add(self, name, score):
        """Нәтижені қосып, ұпай бойынша сұрыптап, сақтайды."""
        self.items.append({"name": name, "score": score})
        self.items.sort(key=lambda r: r["score"], reverse=True)
        with open(self.path, "w", encoding="utf-8") as f:
            json.dump(self.items, f, ensure_ascii=False, indent=2)

    def best(self):
        """Ең үздік нәтиже немесе None."""
        return self.items[0] if self.items else None

    def average(self):
        """Орташа ұпай; рекорд жоқ болса 0."""
        if not self.items:
            return 0
        return sum(r["score"] for r in self.items) / len(self.items)
```

**8-тапсырма.**
```python
import ast
import re
import sys
from pathlib import Path

MAX_LINES = 30
SNAKE = re.compile(r"^_{0,2}[a-z][a-z0-9_]*_{0,2}$")


def check_file(path):
    tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    problems = []
    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
            name = node.name
            if ast.get_docstring(node) is None:
                problems.append((node.lineno, f"{name}: docstring жоқ"))
            if not isinstance(node, ast.ClassDef):
                length = node.end_lineno - node.lineno + 1
                if length > MAX_LINES:
                    problems.append((node.lineno, f"{name}: функция ұзын ({length} жол)"))
                if not SNAKE.match(name):
                    problems.append((node.lineno, f"{name}: атау snake_case емес"))
        elif isinstance(node, ast.Global):
            problems.append((node.lineno, "global қолданылған"))
    return sorted(problems)


def main(root="."):
    for path in sorted(Path(root).rglob("*.py")):
        if "venv" in path.parts:
            continue
        for line, message in check_file(path):
            print(f"{path}:{line} {message}")


if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else ".")
```
