**Задание 1.** Замечания:
- [К] `API_KEY` открыто в коде — секретные данные попадут на GitHub (модулю рекордов он вообще не нужен).
- [К] `avg()` на пустом списке — `ZeroDivisionError`; `best()` на пустом списке — `IndexError`.
- [К] `LoadData`: если файла нет — `FileNotFoundError`, программа падает при первом запуске.
- [В] `data.sort()` сортирует списки по **имени**, а не по очкам → `best()` возвращает не лучший результат, а первый по алфавиту.
- [В] Файлы не закрываются (нет `with`), нет `encoding="utf-8"` и `ensure_ascii=False`.
- [П] `global data` — глобальное состояние; заменить на класс (`Records`) или параметр.
- [П] Имена: `LoadData` (по PEP 8 `load_data`), `n`, `s`, `t`, `f`; нет docstring; вместо `[n, s]` — словарь `{"name":..., "score":...}`.
- [М] Вместо `range(len(data))` — прямая итерация или `sum(...)`.
Достоинства: функции короткие; данные в JSON — удобно читать.

Исправленная версия (для обсуждения):
```python
import json

RECORDS_FILE = "records.json"


class Records:
    """Рекорды игры: хранятся в JSON-файле."""

    def __init__(self, path=RECORDS_FILE):
        self.path = path
        self.items = self._load()

    def _load(self):
        try:
            with open(self.path, encoding="utf-8") as f:
                return json.load(f)
        except (FileNotFoundError, json.JSONDecodeError):
            return []

    def add(self, name, score):
        """Добавляет результат, сортирует по очкам и сохраняет."""
        self.items.append({"name": name, "score": score})
        self.items.sort(key=lambda r: r["score"], reverse=True)
        with open(self.path, "w", encoding="utf-8") as f:
            json.dump(self.items, f, ensure_ascii=False, indent=2)

    def best(self):
        """Лучший результат или None."""
        return self.items[0] if self.items else None

    def average(self):
        """Средний балл; если рекордов нет — 0."""
        if not self.items:
            return 0
        return sum(r["score"] for r in self.items) / len(self.items)
```

**Задание 8.**
```python
import ast
import re
import sys
from pathlib import Path

MAX_LINES = 30
SNAKE = re.compile(r"^_{0,2}[a-z][a-z0-9_]*_{0,2}$")


def check_file(path):
    tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    problems = []
    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
            name = node.name
            if ast.get_docstring(node) is None:
                problems.append((node.lineno, f"{name}: нет docstring"))
            if not isinstance(node, ast.ClassDef):
                length = node.end_lineno - node.lineno + 1
                if length > MAX_LINES:
                    problems.append((node.lineno, f"{name}: функция длинная ({length} строк)"))
                if not SNAKE.match(name):
                    problems.append((node.lineno, f"{name}: имя не в snake_case"))
        elif isinstance(node, ast.Global):
            problems.append((node.lineno, "используется global"))
    return sorted(problems)


def main(root="."):
    for path in sorted(Path(root).rglob("*.py")):
        if "venv" in path.parts:
            continue
        for line, message in check_file(path):
            print(f"{path}:{line} {message}")


if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else ".")
```
Примечание: чтобы выводить методы в виде `Wallet.balance`, нужно отдельно обходить узлы внутри класса — это дополнительный уровень сложности. В настоящих проектах эту работу выполняют инструменты `flake8` и `pylint` (`pip install flake8`, `flake8 qalta/`).
