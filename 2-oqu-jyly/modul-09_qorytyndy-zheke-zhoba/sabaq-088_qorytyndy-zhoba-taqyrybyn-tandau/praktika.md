# Сабақ 88. Практикалық тапсырмалар: жоба идеясын таңдау және негіздеу

## Базалық деңгей

**1-тапсырма. 5 мәселе (5 мин, жеке).** Стикерлерге (немесе `ideas.md` файлына) өз өміріңізден **5 мәселе** жазыңыз — шешімсіз, тек мәселе. Әр мәселе бір сөйлем: «*Кім* *не* істегенде *қандай қиындық* көреді».

Мысал: «Мен ағылшын сөздерін жаттағанда қайсысын ұмытқанымды білмеймін».

**2-тапсырма. 3 идея (7 мин).** Ең қызық 3 мәселеге идея формуласы бойынша шешім ойлаңыз:
```text
[ПАЙДАЛАНУШЫ] ... [МӘСЕЛЕ] ..., сондықтан мен [ШЕШІМ] жасаймын,
ол [НЕГІЗГІ МҮМКІНДІК] арқылы [ПАЙДА] береді.
Технологиялар: 1) ... 2) ... 3) ...
```

**3-тапсырма. Бағалау матрицасы (8 мин).** Үш идеяңызды кестеде бағалаңыз (1–5 ұпай × салмақ). Ең жоғары ұпай алған идеяны таңдаңыз. Ұпайы жақын болса — «қайсысын бір ай бойы жасағым келеді?» деген сұраққа жауап беріңіз.

| Критерий | Салмақ | Идея 1 | Идея 2 | Идея 3 |
|---|---|---|---|---|
| Өзектілігі (нақты мәселе, нақты пайдаланушы) | ×2 | | | |
| Дербестігі (менің идеям, ерекшелігі бар) | ×1 | | | |
| Жүзеге асырылуы (≈ 15–18 сағатта, білімім жетеді) | ×2 | | | |
| Технологиялар (≥ 3, табиғи түрде) | ×1 | | | |
| Маған қызықтылығы | ×2 | | | |
| **Барлығы (макс. 40)** | | | | |

**4-тапсырма. Идея карточкасы.** Таңдалған идеяға карточка толтырыңыз (`docs/idea.md` — бұл файл болашақ репозиторийіңіздің бірінші құжаты болады):

```markdown

## 3. Шешім
```

## Кеңейтілген деңгей

**5-тапсырма. Питч (1 минут) және талқылау.** Питч құрылымы: ілмек → мәселе және пайдаланушы → шешім → технологиялар → неге мен. Құрбыларыңыздың алдында таныстырыңыз (таймер!). Тыңдаушылар төмендегі парақты толтырады.

**Құрбының пікір парағы**

| Автор / идея | Өзектілігі түсінікті ме? (1–3) | Ауқымы дұрыс па? (тым кіші / дұрыс / тым үлкен) | Ең күшті жағы | Тәуекел / сұрақ | Ұсыныс |
|---|---|---|---|---|---|
| | | | | | |

**6-тапсырма. «Уақыт қалтасы».** MVP-дегі әр мүмкіндікке және міндетті жұмыстарға (тесттер, README, презентация) сағат бағалаңыз. Барлығы ≈ 25–28 сағаттан аспауы керек (оның ішінде әзірлеу ≈ 15–18 сағат). Асып кетсе — ауқымды кішірейтіңіз.

| Жұмыс | Бағаланған уақыт, сағ |
|---|---|
| Мүмкіндік 1: ... | |
| Мүмкіндік 2: ... | |
| Мүмкіндік 3: ... | |
| Деректер қоры / файлдар | |
| Интерфейс | |
| Тесттер және қателерді түзету | |
| README, нұсқаулық, презентация | |
| **Барлығы** | |

## ★ Олимпиадалық / шығармашылық тапсырма

**7-тапсырма. Матрица бағдарламасы.** Идеяларды бағалау матрицасын есептейтін бағдарлама жазыңыз: критерийлер мен салмақтар сөздікте, идеялардың бағалары — JSON файлда (`ideas.json`). Бағдарлама әр идеяның жалпы ұпайын есептеп, рейтинг кестесін шығарсын және Matplotlib-пен көлденең бағаналы диаграмма салсын (ең жақсы идея — акцент түспен).

**8-тапсырма. Пайдаланушымен сұхбат.** Болашақ пайдаланушыңызбен (сыныптас, мұғалім, ата-ана) 5 минуттық сұхбат жүргізіңіз. Алдын ала 5 сұрақ дайындаңыз (мысалы: «Бұл мәселе сізде қаншалықты жиі болады?», «Қазір оны қалай шешесіз?», «Бағдарламада ең маңызды не болуы керек?»). Жауаптарды `docs/interview.md`-ге жазыңыз және идея карточкасын солар бойынша түзетіңіз. Бұл — «өзектілік» критерийінің ең күшті дәлелі.

## Үй тапсырмасы

1. Идея карточкасын талқылаудағы пікірлер бойынша аяқтаңыз; педагогтің «Бекітілді» белгісін алыңыз (немесе түзетіп, қайта ұсыныңыз).
2. Жобаңызға ұқсас 2 бар шешімді (қосымша, сайт, GitHub жобасы) тауып, олардың артықшылығы мен кемшілігін жазыңыз — бұл ТТ-ға қажет болады.
3. GitHub-та жоба үшін бос репозиторий ашып (атауы — ағылшынша, қысқа, мысалы `ubt-trainer`), `docs/idea.md` файлын жүктеңіз.

## Бағалау критерийлері

Бұл кезең формативті бағаланады және қорытынды жобаның «Тақырыптың өзектілігі мен идеяның дербестігі (20%)» критерийіне негіз болады:

| Көрсеткіш | Ұпай | Толық ұпай үшін |
|---|---|---|
| Мәселе мен пайдаланушы нақты анықталған | 0–5 | Нақты пайдаланушы, нақты мәселе, қазіргі шешімнің кемшілігі |
| Идеяның дербестігі | 0–5 | Өз идеясы, ұқсас шешімдерден айырмашылығы көрсетілген |
| MVP және ауқым | 0–5 | 3–5 нақты мүмкіндік, уақыт бағаланған, тәуекелдер ойластырылған |
| Технологиялар | 0–5 | ≥ 3 технология, әрқайсысының рөлі түсінікті |
| Питч және талқылауға қатысу | 0–5 | 1 минутқа сыйды, сұрақтарға жауап берді, құрбыларына пікір жазды |
| **Барлығы** | **25** | |

<details><summary>Шешімдерді көрсету</summary>

**4-тапсырма — толтырылған карточка үлгісі (қысқаша):**
- Мәселе: 9–11-сынып оқушылары ҰБТ-ға дайындалғанда қай тақырыптан әлсіз екенін білмейді; қағаз тесттердің нәтижесі жинақталмайды.
- Пайдаланушы: 9–11-сынып оқушылары (бірінші пайдаланушы — автордың сыныптастары).
- MVP: 1) тақырып бойынша тест тапсыру; 2) нәтижені SQLite-та сақтау; 3) тақырыптар бойынша дұрыс жауап пайызының бағаналы графигі; 4) сұрақтарды CSV-ден импорттау.
- Қосымша: таймер, «қате жауаптарды қайталау» режимі, бірнеше пайдаланушы.
- Технологиялар: ОБП (Sual, Test, Natije кластары), Tkinter, SQLite, Pandas + Matplotlib.
- Тәуекел: сұрақтар базасын толтыру көп уақыт алады → алдымен 30 сұрақпен шектелу.

**Педагогке кеңес — карточкаларды қарау тізімі:** (1) пайдаланушы нақты ма; (2) MVP-де 3–5 мүмкіндік пе (10-нан көп болса — кішірейту); (3) 3 технология шынымен қажет пе, әлде «жасанды» қосылған ба; (4) деректер көзі шынайы ма; (5) оқушының деңгейіне сай ма (күшті оқушыға — қосымша технология, мысалы Flask немесе API; әлсіз оқушыға — дайын шаблоннан бастау).

**7-тапсырма**
```python
import json

import matplotlib.pyplot as plt

SALMAQTAR = {
    "ozektilik": 2,
    "derbestik": 1,
    "zhuzege_asyru": 2,
    "tehnologiyalar": 1,
    "qyzyqtylyq": 2,
}

ULGI = {
    "ҰБТ тренажері": {"ozektilik": 5, "derbestik": 3, "zhuzege_asyru": 5,
                      "tehnologiyalar": 5, "qyzyqtylyq": 4},
    "Ауа сапасы мониторы": {"ozektilik": 5, "derbestik": 4, "zhuzege_asyru": 4,
                            "tehnologiyalar": 5, "qyzyqtylyq": 5},
    "3D ату ойыны": {"ozektilik": 2, "derbestik": 2, "zhuzege_asyru": 1,
                     "tehnologiyalar": 2, "qyzyqtylyq": 5},
}


def zhukteu(path="ideas.json"):
    """Идеялар бағасын JSON-нан оқиды; файл жоқ болса үлгіні сақтап қайтарады."""
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        with open(path, "w", encoding="utf-8") as f:
            json.dump(ULGI, f, ensure_ascii=False, indent=2)
        return ULGI


def esepteu(ideyalar):
    """Әр идеяның салмақты ұпайын есептеп, кему ретімен қайтарады."""
    natije = {}
    for atau, bagalar in ideyalar.items():
        natije[atau] = sum(bagalar[k] * s for k, s in SALMAQTAR.items())
    return sorted(natije.items(), key=lambda x: x[1], reverse=True)


reiting = esepteu(zhukteu())
for orny, (atau, upai) in enumerate(reiting, start=1):
    print(f"{orny}. {atau:<22} {upai}/40")

ataular = [r[0] for r in reiting][::-1]
upailar = [r[1] for r in reiting][::-1]
tuster = ["#2A9D8F" if u == max(upailar) else "lightgray" for u in upailar]
fig, ax = plt.subplots(figsize=(7, 3.5))
b = ax.barh(ataular, upailar, color=tuster)
ax.bar_label(b)
ax.set_xlim(0, 40)
ax.set_xlabel("Салмақты ұпай (макс. 40)")
ax.set_title("Идеялар рейтингі", loc="left", fontweight="bold")
ax.spines[["top", "right"]].set_visible(False)
plt.tight_layout()
plt.show()
```
Нәтижесі: `1. Ауа сапасы мониторы 37/40`, `2. ҰБТ тренажері 36/40`, `3. 3D ату ойыны 20/40`.
