# Сабақ 102. Практикалық тапсырмалар: жариялау, презентация және демо

## Базалық деңгей

### 1-тапсырма. Релиз v1.0 (міндетті)
1. Теориядағы 1-бөлімнің 9 пунктін тексеріп, әрқайсысына белгі қойыңыз.
2. `git tag -a v1.0 -m "..."`, `git push origin main --tags`.
3. GitHub-та Release жасаңыз: атауы, CHANGELOG-тан сипаттама, (қаласаңыз) `.exe`.
4. Репозиторийдің About бөлімін толтырыңыз: сипаттама, 4–6 topic.
5. Репозиторийді профиліңізде бекітіңіз (Pin).

Тексеру: сілтемені жасырын (инкогнито) терезеде ашыңыз — README, скриншоттар және Release көрінуі керек. Сілтемені педагогтің кестесіне енгізіңіз.

### 3-тапсырма. Слайдтар (міндетті)
2-тапсырма бойынша 7–10 слайд жасаңыз. Өзіңізді тексеріңіз:
- [ ] әр слайдта ≤ 4 жол мәтін, қаріп ≥ 24 pt;
- [ ] кемінде 3 сурет (скриншот, сызба, диаграмма);
- [ ] техникалық слайдта қолданылған **кемінде 3 технология** анық көрінеді;
- [ ] бір код үзіндісі (≤ 12 жол), ең қызықты жері;
- [ ] соңғы слайдта репозиторий сілтемесі;
- [ ] емле тексерілген.

Слайдтарды PDF ретінде `docs/presentation.pdf`-ке сақтаңыз (қорғау күні флешкаға да көшіріңіз).

### 4-тапсырма. Демо сценарийі және демо деректері (міндетті)
- 3–5 қадамнан тұратын демо сценарийін жазыңыз (не басамын / не айтамын), теориядағы 6-бөлімнің үлгісі бойынша.
- Демо үшін шынайы деректер дайындаңыз (ДҚ/JSON, ойын болса — дайын рекордтар, ашық деңгейлер).
- Plan B: 1 минуттық демо бейнесі немесе демо қадамдарының скриншоттары.

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. QR-код
`qrcode` кітапханасымен (`pip install qrcode[pil]`) репозиторийіңіздің сілтемесіне QR-код жасайтын скрипт жазыңыз да, кодты соңғы слайдқа және көрмеге арналған постерге орналастырыңыз.

### 9-тапсырма. Көрме постері
103-сабақтағы жобалар көрмесіне A4/A3 постер жасаңыз: атауы, бір сөйлемдік сипаттама, 2 скриншот, технологиялар белгішелері, QR-код, авторы. Постер 3 метрден оқылуы керек.

## Үй тапсырмасы
1. Баяндаманы кемінде **екі рет** таймермен жаттықтырыңыз (бірі — отбасы мүшесіне).
2. Демо сценарийін 3 рет орындап шығыңыз; демо деректерін сақтық көшірме ретінде флешкаға/бұлтқа сақтаңыз.
3. Қорғау күні алып келу керек: ноутбук (болса) + зарядтағыш, флешка (слайдтар PDF, `.exe` немесе жоба папкасы, демо бейнесі), басылған демо сценарийі.

- *Неге SQLite, JSON емес?* — «Операциялар мен санаттар байланысқан, ай бойынша сүзу мен санат бойынша қосынды керек. SQL-де бұл бір `JOIN` + `GROUP BY` сұранысы (`database.py`, `operations` әдісі). JSON-да бәрін қолмен есептеуге тура келер еді.»

- *Интернет жоқ болса?* — «`currency.py` соңғы бағамды кэште сақтайды. Кэш те жоқ болса, долларға аудару көрсетілмейді, бірақ бағдарламаның қалғаны жұмыс істейді.»
- *Кодты өзіңіз жаздыңыз ба?* — шынайы жауап; көмек алған жерлер README-де көрсетілгені маңызды.

**8-тапсырма.**
```python
"""tools/make_qr.py — репозиторий сілтемесіне QR-код."""
import sys

import qrcode


def make_qr(url, filename="docs/repo_qr.png"):
    qr = qrcode.QRCode(box_size=10, border=2)
    qr.add_data(url)
    qr.make(fit=True)
    image = qr.make_image(fill_color="black", back_color="white")
    image.save(filename)
    return filename


if __name__ == "__main__":
    link = sys.argv[1] if len(sys.argv) > 1 else "https://github.com/<логин>/qalta-aqshasy"
    print("Сақталды:", make_qr(link))
```
Іске қосу: `python tools/make_qr.py https://github.com/<логин>/<репозиторий>`.
