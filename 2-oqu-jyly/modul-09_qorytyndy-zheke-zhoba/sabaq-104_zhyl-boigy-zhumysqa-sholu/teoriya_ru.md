## 2. Полный цикл разработки проекта

```text
Идея → ТЗ → Архитектура → Модель данных → Прототип → Репозиторий и план
  → Код (логика → данные → интерфейс) → Code review → Тест → Доработка
  → Документация → Релиз (тег, GitHub Release) → Сопровождение
```

Этот цикл — упрощённая версия того, как работают профессиональные команды. В реальных проектах он повторяется итерациями: после релиза v1.0 собирают отзывы, планируют v1.1 и снова проходят те же шаги.

## 3. Портфолио разработчика на GitHub

**Портфолио** — собрание завершённых проектов, которое показывает, что разработчик **умеет делать**. Для программиста основное портфолио — профиль GitHub.

### Критерии хорошего портфолио
| Критерий | Вопрос | Признак хорошего |
|---|---|---|
| **Завершённость** | Запускаются ли проекты? | запускаются по README, нет «половинчатых» проектов |
| **Качество** | Аккуратны ли код и документация? | PEP 8, docstring, README, скриншоты, тесты |
| **Разнообразие** | Какие технологии представлены? | GUI, игра, БД, API, анализ данных |
| **Динамика роста** | Видно ли развитие? | разница между первым и последним проектом очевидна |
| **Подача** | Понятен ли профиль? | README профиля, закреплены 4–6 лучших проектов, описания и topics |
| **Самостоятельность** | Это ваша работа? | собственные идеи, история коммитов, указаны источники и помощь |

## 4. Анализ портфолио средствами Python

### 4.1. Список репозиториев через GitHub API
GitHub предоставляет открытый REST API. Запрос `GET https://api.github.com/users/<логин>/repos` возвращает JSON-список публичных репозиториев с названием, языком, описанием и датой последнего изменения:

```python
import requests


def fetch_repos(login):
    """Список публичных репозиториев пользователя (без форков)."""
    url = f"https://api.github.com/users/{login}/repos"
    response = requests.get(url, params={"per_page": 100, "sort": "pushed"}, timeout=10)
    response.raise_for_status()
    return [repo for repo in response.json() if not repo["fork"]]


def audit(repos):
    """Проверяет оформление репозиториев: описание и topics."""
    for repo in repos:
        problems = []
        if not repo.get("description"):
            problems.append("нет описания")
        if not repo.get("topics"):
            problems.append("нет topics")
        status = ", ".join(problems) if problems else "OK"
        print(f"{repo['name']:20} {repo.get('language') or '—':10} {status}")


# Пример ответа API (в проекте: audit(fetch_repos("<логин>")))
sample = [
    {"name": "qalta-aqshasy", "language": "Python", "fork": False,
     "description": "Учёт карманных денег", "topics": ["python", "tkinter"]},
    {"name": "steppe-run", "language": "Python", "fork": False,
     "description": "", "topics": []},
]
audit(sample)
```

Результат:
```text
qalta-aqshasy        Python     OK
steppe-run           Python     нет описания, нет topics
```

### 4.2. Статистика по языкам и активности
```python
from collections import Counter

repos = [
    {"name": "qalta-aqshasy", "language": "Python", "pushed_at": "2027-05-11T10:00:00Z"},
    {"name": "steppe-run", "language": "Python", "pushed_at": "2027-01-20T09:30:00Z"},
    {"name": "portfolio-site", "language": "HTML", "pushed_at": "2026-11-02T15:00:00Z"},
]
languages = Counter(repo["language"] for repo in repos)
latest = max(repos, key=lambda repo: repo["pushed_at"])
print("Языки:", languages.most_common())
print("Последний обновлённый:", latest["name"])
```

Результат:
```text
Языки: [('Python', 2), ('HTML', 1)]
Последний обновлённый: qalta-aqshasy
```

Даты в формате ISO 8601 можно сравнивать как строки, а для вычислений — превратить в `datetime`: `datetime.datetime.fromisoformat("2027-05-11T10:00:00+00:00")`.

### 4.3. Карта навыков (радарная диаграмма)
Каждый навык оценивается от 1 до 5: **1** — «слышал», **2** — «могу сделать по образцу», **3** — «могу сделать самостоятельно», **4** — «уверенно применяю в проекте», **5** — «могу объяснить другому». Две линии на полярной диаграмме Matplotlib показывают изменение:

```python
import math

import matplotlib.pyplot as plt

skills = ["ООП", "Tkinter", "Pygame", "SQLite/SQL", "API/requests",
          "Pandas", "Matplotlib", "Git/GitHub", "Тестирование", "Документирование"]
start = [1, 1, 1, 1, 1, 1, 1, 2, 1, 1]       # начало года
end = [4, 4, 3, 4, 3, 3, 4, 4, 3, 4]         # конец года


def closed(values):
    """Добавляем первое значение в конец, чтобы линия радара замкнулась."""
    return values + values[:1]


angles = [2 * math.pi * i / len(skills) for i in range(len(skills))]
fig, ax = plt.subplots(figsize=(6, 6), subplot_kw={"projection": "polar"})
ax.plot(closed(angles), closed(start), "o--", color="#9e9e9e", label="Начало года")
ax.plot(closed(angles), closed(end), "o-", color="#1565c0", label="Конец года")
ax.fill(closed(angles), closed(end), color="#1565c0", alpha=0.15)
ax.set_xticks(angles)
ax.set_xticklabels(skills)
ax.set_ylim(0, 5)
ax.set_yticks([1, 2, 3, 4, 5])
ax.set_title("Карта навыков", pad=20)
ax.legend(loc="lower right", bbox_to_anchor=(1.25, -0.05))
plt.tight_layout()
plt.savefig("skills_radar.png", dpi=120)
plt.show()
```

`subplot_kw={"projection": "polar"}` создаёт полярные оси: углы — навыки, радиус — уровень. Функция `closed()` повторяет первую точку в конце, иначе многоугольник останется незамкнутым.

## Частые ошибки

**1. В портфолио только один проект.** Не видна динамика развития. Аккуратно оформите все завершённые проекты (README + скриншот).

**2. Закреплены «половинчатые» проекты.** Не закрепляйте незавершённый проект или открыто напишите в README «в разработке».

**3. Запрос к GitHub API без `timeout` и без обработки ошибок.** Без интернета программа «зависает» или падает. Правильно: `timeout=10`, `raise_for_status()`, перехват `requests.RequestException`.

**4. Превышение лимита GitHub API.** Без авторизации — 60 запросов в час с одного IP; при превышении ответ `403`. Правильно: не вызывать API в цикле без необходимости, кэшировать ответ в JSON.

**5. Незамкнутая радарная диаграмма.** Если не добавить первую точку в конец, многоугольник не замкнётся. Правильно: `values + values[:1]` для углов и значений.

## Примечание

- `datetime.fromisoformat()` принимает суффикс `Z` (UTC) только начиная с Python 3.11; в более ранних версиях замените его: `s.replace("Z", "+00:00")`.
- Поле `topics` в ответе GitHub API возвращается в списке репозиториев; если его нет, используйте `repo.get("topics", [])`, чтобы не получить `KeyError`.
- Для авторизованных запросов к GitHub API (лимит 5000 в час) передают токен в заголовке `Authorization: Bearer <токен>`; токен хранят в переменной окружения, а не в коде.
- `plt.show()` блокирует выполнение до закрытия окна; в скриптах, которые только сохраняют картинку, достаточно `plt.savefig()` и `plt.close(fig)`.
- Документация: https://docs.github.com/ru/rest/repos/repos и https://matplotlib.org/stable/gallery/specialty_plots/radar_chart.html
