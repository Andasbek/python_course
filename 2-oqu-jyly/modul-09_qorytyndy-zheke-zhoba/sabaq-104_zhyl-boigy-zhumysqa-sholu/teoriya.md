## 2. Жобаны әзірлеудің толық циклі

```text
Идея → ТТ → Архитектура → Деректер моделі → Прототип → Репозиторий және жоспар
  → Код (логика → деректер → интерфейс) → Code review → Тест → Жетілдіру
  → Құжат → Релиз (тег, GitHub Release) → Сүйемелдеу
```

Бұл цикл — кәсіби командалар жұмысының жеңілдетілген нұсқасы. Нағыз жобаларда ол итерациялармен қайталанады: v1.0 релизінен кейін пікірлер жиналады, v1.1 жоспарланады және сол қадамдар қайта өтіледі.

## 3. GitHub-тағы әзірлеуші портфолиосы

**Портфолио** — әзірлеушінің не **істей алатынын** көрсететін аяқталған жобалар жинағы. Бағдарламашы үшін негізгі портфолио — GitHub профилі.

### Жақсы портфолионың критерийлері
| Критерий | Сұрақ | Жақсы белгісі |
|---|---|---|
| **Аяқталғандығы** | Жобалар іске қосыла ма? | README бойынша іске қосылады, «жарты» жобалар жоқ |
| **Сапасы** | Код пен құжат ұқыпты ма? | PEP 8, docstring, README, скриншоттар, тесттер |
| **Әртүрлілігі** | Қандай технологиялар көрсетілген? | GUI, ойын, ДҚ, API, деректерді талдау |
| **Өсу динамикасы** | Даму көрінеді ме? | алғашқы мен соңғы жобаның айырмашылығы анық |
| **Таныстырылуы** | Профиль түсінікті ме? | профиль README, бекітілген үздік 4–6 жоба, сипаттамалар мен topics |
| **Дербестігі** | Бұл сіздің жұмысыңыз ба? | өзіндік идеялар, коммиттер тарихы, дереккөздер мен көмек көрсетілген |

## 4. Портфолионы Python құралдарымен талдау

### 4.1. GitHub API арқылы репозиторийлер тізімі
GitHub ашық REST API ұсынады. `GET https://api.github.com/users/<логин>/repos` сұранысы атауы, тілі, сипаттамасы және соңғы өзгеріс күні бар ашық репозиторийлердің JSON-тізімін қайтарады:

```python
import requests


def fetch_repos(login):
    """Пайдаланушының ашық репозиторийлер тізімі (форктарсыз)."""
    url = f"https://api.github.com/users/{login}/repos"
    response = requests.get(url, params={"per_page": 100, "sort": "pushed"}, timeout=10)
    response.raise_for_status()
    return [repo for repo in response.json() if not repo["fork"]]


def audit(repos):
    """Репозиторийлердің безендірілуін тексереді: сипаттама және topics."""
    for repo in repos:
        problems = []
        if not repo.get("description"):
            problems.append("сипаттама жоқ")
        if not repo.get("topics"):
            problems.append("topics жоқ")
        status = ", ".join(problems) if problems else "OK"
        print(f"{repo['name']:20} {repo.get('language') or '—':10} {status}")


# API жауабының мысалы (жобада: audit(fetch_repos("<логин>")))
sample = [
    {"name": "qalta-aqshasy", "language": "Python", "fork": False,
     "description": "Қалта ақшасын есептеу", "topics": ["python", "tkinter"]},
    {"name": "steppe-run", "language": "Python", "fork": False,
     "description": "", "topics": []},
]
audit(sample)
```

Нәтижесі:
```text
qalta-aqshasy        Python     OK
steppe-run           Python     сипаттама жоқ, topics жоқ
```

### 4.2. Тілдер мен белсенділік статистикасы
```python
from collections import Counter

repos = [
    {"name": "qalta-aqshasy", "language": "Python", "pushed_at": "2027-05-11T10:00:00Z"},
    {"name": "steppe-run", "language": "Python", "pushed_at": "2027-01-20T09:30:00Z"},
    {"name": "portfolio-site", "language": "HTML", "pushed_at": "2026-11-02T15:00:00Z"},
]
languages = Counter(repo["language"] for repo in repos)
latest = max(repos, key=lambda repo: repo["pushed_at"])
print("Тілдер:", languages.most_common())
print("Соңғы жаңартылғаны:", latest["name"])
```

Нәтижесі:
```text
Тілдер: [('Python', 2), ('HTML', 1)]
Соңғы жаңартылғаны: qalta-aqshasy
```

ISO 8601 пішіміндегі күндерді жол ретінде салыстыруға болады, ал есептеулер үшін `datetime`-қа айналдырады: `datetime.datetime.fromisoformat("2027-05-11T10:00:00+00:00")`.

### 4.3. Дағдылар картасы (радар диаграмма)
Әр дағды 1-ден 5-ке дейін бағаланады: **1** — «естідім», **2** — «үлгімен жасай аламын», **3** — «өз бетімше жасай аламын», **4** — «жобада сенімді қолданамын», **5** — «басқаға түсіндіре аламын». Matplotlib полярлық диаграммасындағы екі сызық өзгерісті көрсетеді:

```python
import math

import matplotlib.pyplot as plt

skills = ["ОБП", "Tkinter", "Pygame", "SQLite/SQL", "API/requests",
          "Pandas", "Matplotlib", "Git/GitHub", "Тестілеу", "Құжаттау"]
start = [1, 1, 1, 1, 1, 1, 1, 2, 1, 1]       # жыл басы
end = [4, 4, 3, 4, 3, 3, 4, 4, 3, 4]         # жыл соңы


def closed(values):
    """Радар сызығы тұйықталуы үшін бірінші мәнді соңына қосамыз."""
    return values + values[:1]


angles = [2 * math.pi * i / len(skills) for i in range(len(skills))]
fig, ax = plt.subplots(figsize=(6, 6), subplot_kw={"projection": "polar"})
ax.plot(closed(angles), closed(start), "o--", color="#9e9e9e", label="Жыл басы")
ax.plot(closed(angles), closed(end), "o-", color="#1565c0", label="Жыл соңы")
ax.fill(closed(angles), closed(end), color="#1565c0", alpha=0.15)
ax.set_xticks(angles)
ax.set_xticklabels(skills)
ax.set_ylim(0, 5)
ax.set_yticks([1, 2, 3, 4, 5])
ax.set_title("Дағдылар картасы", pad=20)
ax.legend(loc="lower right", bbox_to_anchor=(1.25, -0.05))
plt.tight_layout()
plt.savefig("skills_radar.png", dpi=120)
plt.show()
```

`subplot_kw={"projection": "polar"}` полярлық осьтер жасайды: бұрыштар — дағдылар, радиус — деңгей. `closed()` функциясы бірінші нүктені соңында қайталайды, әйтпесе көпбұрыш тұйықталмайды.

## Жиі кездесетін қателер

**1. Портфолиода бір ғана жоба.** Даму динамикасы көрінбейді. Аяқталған барлық жобаны ұқыпты безендіріңіз (README + скриншот).

**2. «Жарты» жобалар бекітілген.** Аяқталмаған жобаны бекітпеңіз немесе README-де «әзірленуде» деп ашық жазыңыз.

**3. GitHub API-ге `timeout`-сыз және қателерді өңдеусіз сұраныс.** Интернет болмаса, бағдарлама «қатып қалады» немесе құлайды. Дұрысы: `timeout=10`, `raise_for_status()`, `requests.RequestException`-ді ұстау.

**4. GitHub API лимитінен асу.** Авторизациясыз — бір IP-ден сағатына 60 сұраныс; асып кетсе, `403` жауабы келеді. Дұрысы: API-ді қажетсіз циклде шақырмау, жауапты JSON-да кэштеу.

**5. Тұйықталмаған радар диаграмма.** Бірінші нүктені соңына қоспаса, көпбұрыш тұйықталмайды. Дұрысы: бұрыштар мен мәндер үшін `values + values[:1]`.

## Ескерту

- `datetime.fromisoformat()` `Z` (UTC) жұрнағын тек Python 3.11-ден бастап қабылдайды; ертерек нұсқаларда оны ауыстырыңыз: `s.replace("Z", "+00:00")`.
- GitHub API жауабындағы `topics` өрісі репозиторийлер тізімінде қайтарылады; ол болмаса, `KeyError` алмау үшін `repo.get("topics", [])` қолданыңыз.
- GitHub API-ге авторизацияланған сұраныстар үшін (сағатына 5000 лимит) токен `Authorization: Bearer <токен>` тақырыбында беріледі; токен кодта емес, орта айнымалысында сақталады.
- `plt.show()` терезе жабылғанша орындалуды тоқтатады; тек суретті сақтайтын скриптерде `plt.savefig()` пен `plt.close(fig)` жеткілікті.
