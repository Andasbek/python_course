# Сабақ 104. Практикалық тапсырмалар: жылға шолу, портфолио және өзін-өзі бағалау

## Базалық деңгей

### 1-тапсырма. «Уақыт сызығы» (топпен, 10 мин)
Стикерлерге жазылған модульдер, жобалар және технологиялар (педагог береді) араласқан. Топпен оларды тақтадағы уақыт сызығына ретімен орналастырыңыз да, әр жобаның жанына ол **қай алдыңғы білімге сүйенгенін** жебемен көрсетіңіз. Мысалы: «Оқушылар базасы» ← ОБП + Tkinter + SQLite.

### 2-тапсырма. Портфолио аудиті (міндетті)
Өз GitHub профиліңіздегі барлық жобаны кестеге енгізіп, теориядағы критерийлер бойынша тексеріңіз:

| Жоба | Модуль | Технологиялар | README | Скриншот | Іске қосылады | Сипаттама/topics | Жақсарту керек |
|---|---|---|---|---|---|---|---|
| ... | II | ОБП | иә/жоқ | иә/жоқ | иә/жоқ | иә/жоқ | ... |

Қорытынды:
- аяқталған жобалар саны: __ (бағдарлама талабы — кемінде 5–6);
- портфолионың ең күшті 4–6 жобасын профильде бекітіңіз (Pin);
- «Жақсарту керек» бағанынан 3 нақты әрекет таңдап, жазғы демалысқа дейін орындаңыз.

### 3-тапсырма. Дағдылар картасы (міндетті)
Теориядағы 10 дағдыны жыл басы мен жыл соңы үшін 1–5 шкаласымен бағалаңыз (әр бағаға бір сөйлем дәлел). Радар диаграмманы теориядағы кодпен салып, `skills_radar.png` ретінде портфолио репозиторийіне (немесе профиль README-ге) қосыңыз.

### 4-тапсырма. SWOT және рефлексия (міндетті)
1. Өзіңізге SWOT-кестесін толтырыңыз (әр шаршыда кемінде 2 пункт).
2. «Не? Сонымен не? Енді не?» рефлексиясын қорытынды жоба бойынша жазыңыз (әр бөлім 2–3 сөйлем).
3. 103-сабақтағы өзін-өзі бағалауыңызды комиссия бағасымен критерий бойынша салыстырыңыз. Айырмашылығы 3 балдан асқан критерийді талдаңыз.

## Кеңейтілген деңгей

### 5-тапсырма. Мамандықтармен танысу
Теориядағы кестеден өзіңізге қызық 2 мамандықты таңдап, әрқайсысы туралы жазыңыз:
- бұл маман күнделікті не істейді (3 сөйлем);
- біздің екі жылдағы қай жобаңыз осы мамандыққа ең жақын және неге;
- осы бағытта келесі үйренетін 3 нәрсе.

### 6-тапсырма. SMART мақсат және жазғы жоспар
Келесі оқу жылына бір SMART мақсат және жазғы демалысқа шағын жоспар құрыңыз (мысалы, «шілдеде — қорытынды жобаның 3 issue-ін жабу, тамызда — бір ойын жамына қатысу»). Мақсатты профиль README-ге «Қазір үйреніп жатырмын / Мақсатым» бөлімі ретінде қосуға болады.

### 7-тапсырма. Бірінші бағдарлама vs соңғы бағдарлама
1-жылдың бірінші сабақтарындағы бағдарламаңызды (немесе алғашқы жобаңызды) тауып, қорытынды жобаңызбен салыстырыңыз: көлемі (жол саны), құрылымы (функциялар, кластар, модульдер), қолданылған технологиялар, құжаттама. Нәтижені 5–6 сөйлеммен жазыңыз — бұл өсуіңіздің ең жарқын дәлелі.

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Портфолио аудитін автоматтандыру
GitHub-тың ашық API-ы арқылы (кілтсіз: `https://api.github.com/users/<логин>/repos`) пайдаланушының барлық ашық репозиторийін тексеретін скрипт жазыңыз: сипаттамасы бар ма, тақырыптары (topics) бар ма, соңғы жаңартылған күні, негізгі тілі. README бар-жоғын `https://api.github.com/repos/<логин>/<репо>/readme` сұранысының жауап коды (200 / 404) арқылы тексеріңіз.

Шығару мысалы:
```text
qalta-aqshasy        Python  2027-05-11  сипаттама: иә  topics: 5  README: иә
dala-run             Python  2027-01-20  сипаттама: жоқ topics: 0  README: иә
Портфолио ұпайы: 7/10. Ұсыныс: 2 репозиторийге сипаттама қосыңыз.
```
*Ескерту:* кілтсіз сұраныстарға GitHub сағатына шектеу қояды (шамамен 60 сұраныс), сондықтан скриптті жиі іске қоспаңыз.

### 9-тапсырма. Портфолио беті
Барлық жобаларыңыз туралы деректерді (атауы, жылы, модулі, технологиялары, сипаттамасы, скриншоты, сілтемесі) `portfolio.json`-да сақтап, одан профиль README-нің «Жобаларым» кестесін автоматты түрде құрайтын скрипт жазыңыз.

## Үй тапсырмасы
1. 2-тапсырмадағы 3 жақсарту әрекетін орындаңыз.
2. Профиль README-ді жаңартыңыз: екі жылдағы жобалар, дағдылар диаграммасы, мақсатыңыз.
3. Резервтік сағаттарға дайындық: дағдылар картаңыздағы ең төмен 2 дағдыны жазып келіңіз — 105–106 сабақтарда соларды қайталаймыз.

## Бағалау критерийлері
| Критерий | Үлес | Не тексеріледі |
|---|---|---|
| Портфолионың толықтығы мен ресімделуі | 40% | 5–6 аяқталған жоба, README мен скриншоттар, бекітілген жобалар, профиль README |
| Өзін-өзі бағалаудың негізділігі | 25% | дағдылар картасы дәлелдермен, комиссия бағасымен салыстыру, SWOT |
| Рефлексия мен мақсаттың сапасы | 20% | «Не? Сонымен не? Енді не?» нақты; SMART мақсат |
| Белсенділік | 15% | топтық «уақыт сызығына» қатысу, жоспарды уақытында тапсыру |

Ескерту: бұл сабақта «дұрыс» немесе «бұрыс» өзін-өзі бағалау жоқ — бағаланатыны оның **дәлелденгені**.

**8-тапсырма.**
```python
"""tools/portfolio_audit.py — GitHub портфолиосын тексеру (кілтсіз ашық API)."""
import sys

import requests

API = "https://api.github.com"
HEADERS = {"Accept": "application/vnd.github+json"}


def get_repos(login):
    response = requests.get(f"{API}/users/{login}/repos",
                            params={"per_page": 100, "sort": "updated"},
                            headers=HEADERS, timeout=10)
    response.raise_for_status()
    return [r for r in response.json() if not r["fork"]]


def has_readme(login, repo):
    response = requests.get(f"{API}/repos/{login}/{repo}/readme", headers=HEADERS, timeout=10)
    return response.status_code == 200


def audit(login):
    repos = get_repos(login)
    if not repos:
        print("Ашық репозиторий табылмады.")
        return
    points, no_description = 0, 0
    for r in repos:
        readme = has_readme(login, r["name"])
        described = bool(r["description"])
        topics = len(r.get("topics", []))
        points += readme + described + (topics > 0)
        no_description += not described
        print(f"{r['name']:<20} {r['language'] or '-':<7} {r['pushed_at'][:10]}  "
              f"сипаттама: {'иә' if described else 'жоқ':<3} topics: {topics}  "
              f"README: {'иә' if readme else 'жоқ'}")
    score = round(points / (3 * len(repos)) * 10)
    print(f"Портфолио ұпайы: {score}/10.", end=" ")
    if no_description:
        print(f"Ұсыныс: {no_description} репозиторийге сипаттама қосыңыз.")
    else:
        print("Керемет!")


if __name__ == "__main__":
    try:
        audit(sys.argv[1] if len(sys.argv) > 1 else "octocat")
    except requests.RequestException as err:
        print("GitHub-қа қосылу мүмкін болмады:", err)
```
Ескерту: `True + True` = 2 — Python-да `bool` типі `int`-тің ұрпағы (мұрагерлік, 15-сабақ), сондықтан логикалық мәндерді қосуға болады — бұл қызықты талқылау тақырыбы.

**9-тапсырма.**
```python
import json

PORTFOLIO = json.loads("""[
  {"title": "Кітапхана", "year": 2026, "module": "ОБП", "tech": ["ОБП"],
   "url": "https://github.com/example/library"},
  {"title": "Қалта ақшасы", "year": 2027, "module": "Қорытынды жоба",
   "tech": ["Tkinter", "SQLite", "Matplotlib", "API"],
   "url": "https://github.com/example/qalta-aqshasy"}
]""")


def projects_table(items):
    lines = ["| Жоба | Жылы | Модуль | Технологиялар |", "|---|---|---|---|"]
    for p in sorted(items, key=lambda p: p["year"], reverse=True):
        lines.append(f"| [{p['title']}]({p['url']}) | {p['year']} | {p['module']} | "
                     f"{', '.join(p['tech'])} |")
    return "\n".join(lines)


print(projects_table(PORTFOLIO))
```
