# Сабақ 92. Практикалық тапсырмалар: интерфейс жобалау және прототип

## Базалық деңгей

### 1-тапсырма. Персона және сценарийлер
Өз жобаңыз үшін:
1. Персона жазыңыз (аты, жасы, кім, мақсаты, компьютерді қандай деңгейде біледі) — 3–4 сөйлем.
2. ТТ-дағы ең маңызды 3 мүмкіндікке пайдаланушы сценарийін жазыңыз (әрқайсысы 3–6 қадам).

Үлгі:
```text
Сценарий: «Викторинадан өту»
1. Бағдарламаны ашады -> аты-жөнін енгізеді
2. Тақырыпты таңдайды (Тарих / География)
3. 10 сұраққа жауап береді (әр сұрақта 4 нұсқа)
4. Нәтижені көреді: 8/10, рекордтар кестесіндегі орны
```

### 2-тапсырма. Экрандар картасы
Жобаңыздың барлық экранын (терезесін) және олардың арасындағы өтулерді сызба түрінде салыңыз. Экран саны 7-ден аспасын. Әр экранның жанына ол қандай кестеден/файлдан деректер алатынын жазыңыз (91-сабақтағы модельмен байланыс).

### 3-тапсырма. Қағаз прототип
Әр экранның қағаз эскизін салыңыз (бір экран — бір парақ). Батырмаларды стикерге салсаңыз, оларды жылжытуға болады. Эскизде:
- терезе атауы;
- барлық енгізу өрістері мен батырмалар (атаулары етістікпен);
- бос жағдай («Әзірге дерек жоқ») мен қате хабарламасы қайда шығатыны.

### 4-тапсырма. Ыңғайсыз интерфейсті табу
Төмендегі прототипті іске қосып, ыңғайлылықтың 8 ережесінің қайсысы бұзылғанын кесте түрінде жазыңыз (кемінде 5 қате), содан кейін түзетілген нұсқасын жасаңыз.

```python
import tkinter as tk

root = tk.Tk()
root.title("tk")
tk.Label(root, text="sum").pack()
e1 = tk.Entry(root)
e1.pack()
tk.Label(root, text="category (жазыңыз)").pack()
e2 = tk.Entry(root)
e2.pack()


def save():
    value = int(e1.get())
    print(value, e2.get())


def delete_all():
    print("Барлығы өшірілді")


tk.Button(root, text="OK", command=save).pack()
tk.Button(root, text="Del", command=delete_all, bg="green").pack()
tk.Button(root, text="Жіберу", command=save).pack()
root.mainloop()
```

## Кеңейтілген деңгей

### 5-тапсырма. Tkinter- немесе Pygame-қаңқа (міндетті)
Қағаз прототипіңізді логикасыз бағдарламаға айналдырыңыз:
- барлық экран (терезе / `Frame` / ойын күйі) бар;
- батырмалар бір экраннан екіншісіне өтеді немесе «Прототип» хабарламасын шығарады;
- тізімдер мен кестелерде **жалған деректер** бар;
- файл атауы: `prototype.py` (келесі сабақта репозиторийге жүктейсіз).

### 6-тапсырма. Бес минуттық тест
Құрбыңызбен орын ауыстырыңыз. Оның прототипіне 3 тапсырма беріп, бақылау хаттамасын толтырыңыз:

| Тапсырма | Орындады ма? | Қай жерде кідірді/қателесті | Ұсыныс |
|---|---|---|---|
| 1. ... | иә / жоқ / көмекпен | ... | ... |

Өз прототипіңізге берілген пікірлер бойынша кемінде 2 түзету енгізіңіз.

### 7-тапсырма. Экрандарды ауыстыру (бір терезеде)
Бір `Tk` терезесінде бірнеше `Frame`-ді ауыстыратын прототип жасаңыз: «Басты», «Тарих», «Статистика». Әр экранда «Артқа» батырмасы болсын. *Кеңес:* барлық фреймді `grid(row=0, column=0, sticky="nsew")` арқылы бір ұяшыққа қойып, керегін `tkraise()` арқылы алдыға шығарыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Тақырып (тема) ауыстырғыш
Прототипіңізге «Күндізгі / Түнгі режим» ауыстырғышын қосыңыз. Барлық түстерді бір сөздікте сақтап (`THEMES = {"light": {...}, "dark": {...}}`), ауыстырғанда барлық виджетке қайта қолданыңыз.

### 9-тапсырма. Figma/Penpot макеті
Басты экранның түсті макетін Figma немесе Penpot-та жасаңыз: 1 негізгі түс, 1 екпін түсі, бір қаріп отбасы, бірдей аралықтар. PNG экспорттап, `docs/mockup.png` ретінде сақтаңыз.

## Үй тапсырмасы
1. `prototype.py`-ді 6-тапсырмадағы пікірлер бойынша түзетіп аяқтаңыз.
2. Экрандар картасы мен эскиздерді суретке түсіріп, `docs/` папкасына салыңыз.
3. GitHub аккаунтыңызға кіруді тексеріңіз (құпия сөзді/токенді еске түсіріңіз) — келесі сабақта жоба репозиторийін құрамыз.

## Бағалау критерийлері

**1–3-тапсырмалар** жеке тексеріледі. Тексеру сұрақтары: «Персонаңыз осы батырманы табады ма?», «Ең жиі әрекетке неше басу керек?», «Деректер жоқ кезде экран қалай көрінеді?»

**4-тапсырма.** Бұзылған ережелер:

| Қате | Ереже |
|---|---|
| Терезе атауы `tk`, белгі `sum` — ағылшын/түсініксіз | 2 — пайдаланушы тілі |
| Санат қолмен жазылады | 3 — қатені болдырма |
| `int(e1.get())` — бос енгізуде бағдарлама қатемен құлайды | 2, 3 |
| Сақталғаннан кейін ешқандай хабар жоқ | 1 — жағдай көрінсін |
| «Del» бәрін растаусыз өшіреді, оның үстіне жасыл (қауіпсіз түс) | 4 — бас тарту; түстердің мағынасы |
| «OK» және «Жіберу» бір әрекетті орындайды | 5 — біркелкілік, 7 — минимализм |

Түзетілген нұсқа:
```python
import tkinter as tk
from tkinter import ttk, messagebox

root = tk.Tk()
root.title("Қалта ақшасы — шығыс қосу")
frame = ttk.Frame(root, padding=10)
frame.pack()

ttk.Label(frame, text="Сома (тг):").grid(row=0, column=0, sticky="w", pady=4)
amount_entry = ttk.Entry(frame, width=20)
amount_entry.grid(row=0, column=1, pady=4)

ttk.Label(frame, text="Санат:").grid(row=1, column=0, sticky="w", pady=4)
category_box = ttk.Combobox(frame, values=["Тамақ", "Көлік", "Ойын-сауық"],
                            state="readonly", width=18)
category_box.current(0)
category_box.grid(row=1, column=1, pady=4)

status = ttk.Label(frame, text="")
status.grid(row=3, column=0, columnspan=2)


def save():
    text = amount_entry.get().strip()
    if not text.isdigit() or int(text) == 0:
        messagebox.showwarning("Қате", "Соманы оң бүтін сан түрінде енгізіңіз.")
        return
    status.config(text=f"Сақталды: {text} тг, {category_box.get()}")
    amount_entry.delete(0, "end")


def delete_all():
    if messagebox.askyesno("Растау", "Барлық операцияны өшіру керек пе? Бұл әрекетті қайтару мүмкін емес."):
        status.config(text="Барлығы өшірілді")


ttk.Button(frame, text="Сақтау", command=save).grid(row=2, column=1, sticky="e", pady=6)
tk.Button(frame, text="Барлығын өшіру", command=delete_all,
          bg="#c62828", fg="white").grid(row=2, column=0, sticky="w", pady=6)
root.mainloop()
```

**5-тапсырма.** Теориядағы «Қалта ақшасы» прототипі үлгі бола алады. Талап: бағдарлама іске қосылып, барлық батырма қатесіз жауап береді.

**7-тапсырма.**
```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Экрандар прототипі")
root.geometry("400x250")
root.rowconfigure(0, weight=1)
root.columnconfigure(0, weight=1)

screens = {}


def show(name):
    screens[name].tkraise()


for name in ("Басты", "Тарих", "Статистика"):
    frame = ttk.Frame(root, padding=20)
    frame.grid(row=0, column=0, sticky="nsew")
    ttk.Label(frame, text=f"{name} экраны", font=("Arial", 16)).pack(pady=10)
    screens[name] = frame

for name in ("Тарих", "Статистика"):
    ttk.Button(screens["Басты"], text=name,
               command=lambda n=name: show(n)).pack(pady=4)
    ttk.Button(screens[name], text="← Артқа",
               command=lambda: show("Басты")).pack(pady=4)

show("Басты")
root.mainloop()
```
Назар аударыңыз: `lambda n=name: show(n)` — циклдегі айнымалыны «бекіту» үшін әдепкі параметр қолданылады; онсыз барлық батырма соңғы экранды ашады.

**8-тапсырма.**
```python
import tkinter as tk

THEMES = {
    "light": {"bg": "#ffffff", "fg": "#222222", "btn": "#e0e0e0"},
    "dark": {"bg": "#202124", "fg": "#f1f1f1", "btn": "#3c4043"},
}
current = "light"

root = tk.Tk()
root.title("Тақырып ауыстырғыш")
label = tk.Label(root, text="Баланс: 12 450 тг", font=("Arial", 16))
label.pack(padx=20, pady=20)
button = tk.Button(root, text="Түнгі режим")
button.pack(pady=10)


def apply_theme():
    colors = THEMES[current]
    root.config(bg=colors["bg"])
    label.config(bg=colors["bg"], fg=colors["fg"])
    button.config(bg=colors["btn"], fg=colors["fg"],
                  text="Күндізгі режим" if current == "dark" else "Түнгі режим")


def toggle():
    global current
    current = "dark" if current == "light" else "light"
    apply_theme()


button.config(command=toggle)
apply_theme()
root.mainloop()
```
