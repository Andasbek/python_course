# Сабақ 103. Практикалық тапсырмалар: қорытынды жобаларды қорғау және көрме

## Базалық деңгей

### 1-тапсырма. Қорытынды жобаны қорғау (міндетті)
Регламент бойынша жобаңызды қорғаңыз:
- баяндама + демо: 5–7 минут (102-сабақтағы жоспар бойынша);
- комиссия және көрермендер сұрақтарына жауап: 3–5 минут;
- қорғауға дейін: репозиторий сілтемесі мен слайдтар (PDF) педагогте, бағдарлама проектор компьютерінде (немесе өз ноутбугыңызда) тексерілген.

**Қорғауға дейінгі соңғы чек-парақ (5 минут бұрын):**
- [ ] слайдтар ашық, бірінші слайдта;
- [ ] бағдарлама іске қосылған, демо деректері жүктелген, терезе өлшемі проекторға сай;
- [ ] интернет қажет болса — тексерілген; болмаса — кэш/офлайн режимі дайын;
- [ ] Plan B (бейне/скриншоттар) флешкада;
- [ ] демо сценарийі қолда;
- [ ] шаршы тыныс: 4–4–4–4.

### 2-тапсырма. Көрермен карточкасы (міндетті)
Әр құрбыңыздың қорғауында карточка толтырыңыз және кемінде бір жобаға ауызша сұрақ қойыңыз.

```text
Жоба: ____________________  Автор: ______________

Ұнаған бір нәрсе: __________________________________
Бір сұрақ немесе ұсыныс: ____________________________
Жалпы әсер:   1   2   3   4   5
```
Карточкалар қорғаудан кейін авторға беріледі.

### 3-тапсырма. Жобалар көрмесі
- Өз жобаңызды компьютер жанында 1 минуттық «лифттегі баяндамамен» таныстырыңыз; келушіге өзі басып көруге мүмкіндік беріңіз.
- Өзіңіз кемінде 3 басқа жобаны көріп, «Көрермендер таңдауына» бір дауыс беріңіз (өз жобаңызға емес).

### 4-тапсырма. Өзін-өзі бағалау
Қорғаудан кейін бірден, комиссияның бағасын көрмей тұрып, өз жобаңызды төмендегі бағалау кестесі бойынша бағалаңыз (әр критерий бойынша балл + бір сөйлем дәлел). Келесі сабақта комиссия бағасымен салыстырамыз.

## Кеңейтілген деңгей

### 5-тапсырма. Уақыт сақшысы / техникалық көмекші
Кезекпен рөлді атқарыңыз: уақыт сақшысы — «2 мин», «1 мин», «Уақыт бітті» карточкалары; техникалық көмекші — келесі баяндамашының слайдтарын алдын ала ашу, проектор мен дыбысты тексеру. (Рөлді атқарған оқушыға «өз бетінше жұмыс» критерийі бойынша қосымша балл.)

### 6-тапсырма. Ең жақсы сұрақ
Барлық қорғаудан кейін өзіңіз естіген ең жақсы сұрақты (комиссиядан немесе көрермендерден) жазып, оның неге жақсы екенін түсіндіріңіз. Өз жобаңызға осы сұрақ қойылса, қалай жауап берер едіңіз (Т–Д–М)?

## ★ Олимпиадалық / шығармашылық тапсырма

### 7-тапсырма. Дауыс беру нәтижелері
Көрермендер таңдауының дауыстары CSV файлында (`voter,project`) жиналды. Бағдарлама жазыңыз:
- бір адам бір рет қана дауыс бере алады (қайталанса — соңғы дауысы есептеледі);
- өз жобасына берілген дауыс есептелмейді (дауыс берушінің аты жоба авторымен сәйкес келсе);
- нәтижені кему ретімен және мәтіндік гистограммамен шығарыңыз.

Шығару мысалы:
```text
Қалта ақшасы (Әлихан)   ████████ 8
Дала жүгірісі (Мадина)  ██████ 6
Ауа сапасы (Тимур)      ███ 3
```

### 8-тапсырма. Көрме сайты
Барлық жобаның атауы, авторы, бір сөйлемдік сипаттамасы, скриншоты және GitHub сілтемесі бар бір беттік HTML «көрме каталогын» Python скриптімен (деректер JSON-нан) генерациялаңыз.

## Үй тапсырмасы
1. Комиссия мен көрермендердің пікірлерін оқып, `docs/review.md`-ге «Қорғаудан кейінгі пікірлер» бөлімін қосыңыз.
2. Қорғауда айтылған ұсақ ақауларды түзетсеңіз — `v1.0.1` нұсқасы ретінде (CHANGELOG + тег).
3. Келесі сабаққа: GitHub профиліңіздегі екі жылдағы барлық жобаның тізімін жасап келіңіз (атауы, модулі, технологиялары, сілтемесі).

## Бағалау критерийлері
**Қорытынды жобаны бағалау парағы (комиссияға).** Әр комиссия мүшесі жеке толтырады; қорытынды балл — орташа мән.

| Критерий | Ең жоғары балл | Балл | Түсініктеме |
|---|---|---|---|
| Тақырыптың өзектілігі мен идеяның дербестігі | 20 | | |
| Техникалық орындалу деңгейі (өтілген тақырыптарды қамтуы; кемінде үш технологияны біріктіруі) | 25 | | |
| Бағдарламаның тұрақты әрі қатесіз жұмыс істеуі, тестілеу нәтижесі | 20 | | |
| Код сапасы, құжаттамасы және жұмыстың безендірілуі | 15 | | |
| Жобаны таныстыру және сұрақтарға жауап беру сапасы | 20 | | |
| **Барлығы** | **100** | | |

Меңгеру деңгейі: **жоғары** — 85–100; **орта** — 60–84; **бастапқы** — 40–59. 40-тан төмен болса, 107-сабақта (резервтік сағат) жобаны жетілдіріп, қайта қорғау ұсынылады.

**Техникалық орындалу бойынша нақтылау (кемінде үш технология):** ОБП (кластар), Tkinter/Pygame, SQLite/JSON/CSV, requests/API, BeautifulSoup, Pandas/Matplotlib, unittest, Git/GitHub. Технология «мағыналы» болып есептеледі, егер ол жобаның мүмкіндігін жүзеге асырса (мысалы, бір рет `import pandas` жеткіліксіз).

## Педагогке: шешімдер

**Қорғауды ұйымдастыру бойынша кеңестер.**
- Ретті алдын ала жариялаңыз; бірінші болып сенімді оқушы шықсын (үлгі береді), бірақ ең күштісін соңына қалдырмаңыз.
- Әр жобаға кемінде бір «код туралы» сұрақ қойыңыз: «Мына функцияны ашып, не істейтінін түсіндіріп беріңізші» — жобаның дербестігін тексерудің ең сенімді жолы.
- Бағалау парақтарын бірден толтырыңыз; бағаны барлығына бір уақытта (сабақ соңында немесе келесі сабақта) жариялаңыз.
- Толқып, сөзін ұмытқан оқушыға жетекші сұрақ қойыңыз: «Бағдарламаңыздың ең ұнайтын мүмкіндігін көрсетіңізші».

**7-тапсырма.**
```python
import csv
import io

AUTHORS = {"Қалта ақшасы": "Әлихан", "Дала жүгірісі": "Мадина", "Ауа сапасы": "Тимур"}

VOTES_CSV = """voter,project
Әлихан,Дала жүгірісі
Мадина,Қалта ақшасы
Мадина,Мадинаның өз жобасы емес
Тимур,Тимурдың өзі
Тимур,Қалта ақшасы
Аружан,Ауа сапасы
Аружан,Қалта ақшасы
Тимур,Ауа сапасы
"""


def count_votes(file, authors):
    last_vote = {}
    for row in csv.DictReader(file):
        last_vote[row["voter"].strip()] = row["project"].strip()   # соңғы дауыс қалады
    totals = {project: 0 for project in authors}
    for voter, project in last_vote.items():
        if project not in authors:
            continue                                  # белгісіз жоба
        if authors[project] == voter:
            continue                                  # өз жобасына дауыс есептелмейді
        totals[project] += 1
    return totals


def show(totals, authors):
    rows = sorted(totals.items(), key=lambda kv: (-kv[1], kv[0]))
    labels = {p: f"{p} ({authors[p]})" for p in totals}
    width = max(len(label) for label in labels.values())
    for project, votes in rows:
        print(f"{labels[project]:<{width}}  {'█' * votes} {votes}")


show(count_votes(io.StringIO(VOTES_CSV), AUTHORS), AUTHORS)
```
Нәтижесі:
```text
Дала жүгірісі (Мадина)  █ 1
Қалта ақшасы (Әлихан)   █ 1
Ауа сапасы (Тимур)       0
```
Түсіндірме: Әлихан — «Дала жүгірісі»; Мадинаның алғашқы дауысы («Қалта ақшасы») соңғысымен ауыстырылды, ал соңғысы белгісіз жобаға — есептелмейді; Тимурдың соңғы дауысы өз жобасына («Ауа сапасы») — есептелмейді; Аружанның соңғы дауысы — «Қалта ақшасы». Тең дауыстағы жобалар атауы бойынша сұрыпталады. Бұл мысал «соңғы дауыс» ережесінің салдарын жақсы көрсетеді — оқушылармен ереженің әділдігін талқылауға болады.

**8-тапсырма.**
```python
import html
import json

PROJECTS_JSON = """[
  {"title": "Қалта ақшасы", "author": "Әлихан", "about": "Оқушының кіріс-шығыс есепшісі",
   "image": "img/qalta.png", "url": "https://github.com/example/qalta-aqshasy"},
  {"title": "Дала жүгірісі", "author": "Мадина", "about": "Pygame платформер ойыны",
   "image": "img/dala.png", "url": "https://github.com/example/dala-run"}
]"""


def build_catalog(projects):
    cards = []
    for p in projects:
        e = {k: html.escape(str(v)) for k, v in p.items()}   # HTML-инъекциядан қорғау
        cards.append(f"""  <article>
    <img src="{e['image']}" alt="{e['title']}">
    <h2>{e['title']}</h2>
    <p>{e['about']}</p>
    <p><b>Авторы:</b> {e['author']} · <a href="{e['url']}">GitHub</a></p>
  </article>""")
    return ("<!doctype html>\n<html lang=\"kk\"><head><meta charset=\"utf-8\">"
            "<title>Жобалар көрмесі 2027</title></head>\n<body>\n<h1>Жобалар көрмесі 2027</h1>\n"
            + "\n".join(cards) + "\n</body></html>")


page = build_catalog(json.loads(PROJECTS_JSON))
print(page.count("<article>"), "жоба каталогқа қосылды")
```
Нәтижесі:
```text
2 жоба каталогқа қосылды
```
Нағыз нұсқада `page` → `open("catalog.html", "w", encoding="utf-8").write(page)`; CSS қосуды оқушының өзіне қалдыруға болады (HTML негіздері — 69-сабақ).
