**Задание 7.**
```python
import csv
import io

AUTHORS = {"Карманные деньги": "Алихан", "Степной забег": "Мадина", "Качество воздуха": "Тимур"}

VOTES_CSV = """voter,project
Алихан,Степной забег
Мадина,Карманные деньги
Мадина,Не проект Мадины
Тимур,Сам Тимур
Тимур,Карманные деньги
Аружан,Качество воздуха
Аружан,Карманные деньги
Тимур,Качество воздуха
"""


def count_votes(file, authors):
    last_vote = {}
    for row in csv.DictReader(file):
        last_vote[row["voter"].strip()] = row["project"].strip()   # остаётся последний голос
    totals = {project: 0 for project in authors}
    for voter, project in last_vote.items():
        if project not in authors:
            continue                                  # неизвестный проект
        if authors[project] == voter:
            continue                                  # голос за свой проект не учитывается
        totals[project] += 1
    return totals


def show(totals, authors):
    rows = sorted(totals.items(), key=lambda kv: (-kv[1], kv[0]))
    labels = {p: f"{p} ({authors[p]})" for p in totals}
    width = max(len(label) for label in labels.values())
    for project, votes in rows:
        print(f"{labels[project]:<{width}}  {'█' * votes} {votes}")


show(count_votes(io.StringIO(VOTES_CSV), AUTHORS), AUTHORS)
```
Результат:
```text
Карманные деньги (Алихан)  █ 1
Степной забег (Мадина)     █ 1
Качество воздуха (Тимур)    0
```
Пояснение: Алихан — «Степной забег»; первый голос Мадины («Карманные деньги») заменён последним, а последний — за неизвестный проект, не учитывается; последний голос Тимура — за свой проект («Качество воздуха»), не учитывается; последний голос Аружан — «Карманные деньги». Проекты с равным числом голосов сортируются по названию. Этот пример хорошо показывает последствия правила «последнего голоса» — можно обсудить с учениками, справедливо ли это правило.

**Задание 8.**
```python
import html
import json

PROJECTS_JSON = """[
  {"title": "Карманные деньги", "author": "Алихан", "about": "Учёт доходов и расходов ученика",
   "image": "img/qalta.png", "url": "https://github.com/example/qalta-aqshasy"},
  {"title": "Степной забег", "author": "Мадина", "about": "Игра-платформер на Pygame",
   "image": "img/dala.png", "url": "https://github.com/example/dala-run"}
]"""


def build_catalog(projects):
    cards = []
    for p in projects:
        e = {k: html.escape(str(v)) for k, v in p.items()}   # защита от HTML-инъекции
        cards.append(f"""  <article>
    <img src="{e['image']}" alt="{e['title']}">
    <h2>{e['title']}</h2>
    <p>{e['about']}</p>
    <p><b>Автор:</b> {e['author']} · <a href="{e['url']}">GitHub</a></p>
  </article>""")
    return ("<!doctype html>\n<html lang=\"ru\"><head><meta charset=\"utf-8\">"
            "<title>Выставка проектов 2027</title></head>\n<body>\n<h1>Выставка проектов 2027</h1>\n"
            + "\n".join(cards) + "\n</body></html>")


page = build_catalog(json.loads(PROJECTS_JSON))
print("Проектов добавлено в каталог:", page.count("<article>"))
```
Результат:
```text
Проектов добавлено в каталог: 2
```
