## Базовый уровень

### Задание 1. 30-секундный тест (разминка, 5 мин)
Откройте репозиторий одноклассника и смотрите только 30 секунд. Затем запишите на бумаге: (1) что делает этот проект? (2) для кого он? (3) как он запускается? Отдайте автору — пусть сравнит, что говорит README и что поняли вы.

### Задание 2. Полный README (обязательно)
Напишите README.md по 11 разделам из части 3 теории. Обязательные требования:
- описание в одно предложение и не менее **1 скриншота** вверху;
- «Проблема и решение» — конкретный пользователь и проблема;
- таблица технологий (не менее 3 технологий и для чего каждая используется);
- команды установки в блоке кода `bash`;
- структура проекта, команда запуска тестов, автор.

Проверка: в VS Code `Ctrl+Shift+V`, затем вид на GitHub (изображения, таблицы, блоки кода).

### Задание 3. Руководство пользователя (обязательно)
Напишите файл `docs/user_guide.md`:
- что делает программа (2–3 предложения);
- скриншот «Знакомство с окном» с номерами (поставьте отметки 1, 2, 3... в любом графическом редакторе);
- не менее **3 основных задач** («Как ...?»), каждая с пронумерованными шагами и строкой «Результат:»;
- не менее **4 вопросов** в разделе «Частые вопросы» (помогут тест-кейсы урока 99 и отзывы урока 98).

### Задание 4. Проверка руководства (перекрёстная)
Возьмите руководство одноклассника и попробуйте пользоваться программой **только по руководству** (не спрашивая автора). Записывайте каждое препятствие: «На шаге 3 говорится о кнопке “Добавить”, а в окне написано “Сохранить”». Автор вносит исправления.

**Задание 6.** Проверка: в результате `python -m doctest` — `Test passed`; в выводе `pydoc` есть описание каждой открытой функции.

**Задание 8.**
```python
import re
import sys
from pathlib import Path

REQUIRED = ["Установка", "Использование", "Технологии", "Автор"]
FENCE = "`" * 3


def check_readme(path="README.md"):
    readme = Path(path)
    text = readme.read_text(encoding="utf-8")
    base = readme.parent
    ok = True

    headings = [h.strip() for h in re.findall(r"^#{1,6}\s+(.+)$", text, re.M)]
    for name in REQUIRED:
        if any(name.lower() in h.lower() for h in headings):
            print(f"[OK]   раздел «{name}» есть")
        else:
            print(f"[НЕТ]  раздел «{name}» не найден")
            ok = False

    for is_image, target in re.findall(r"(!?)\[[^\]]*\]\(([^)\s]+)\)", text):
        if target.startswith(("http://", "https://", "#", "mailto:")):
            continue
        if not (base / target).exists():
            kind = "изображение" if is_image else "ссылка"
            print(f"[НЕТ]  не найден файл ({kind}): {target}")
            ok = False

    fences = sum(1 for line in text.splitlines() if line.strip().startswith(FENCE))
    if fences % 2 == 0:
        print(f"[OK]   блоки кода закрыты ({fences // 2})")
    else:
        print(f"[НЕТ]  есть незакрытый блок кода ({fences} ограничителей)")
        ok = False
    return ok


if __name__ == "__main__":
    sys.exit(0 if check_readme(*sys.argv[1:]) else 1)
```
Примечание: ``FENCE = "`" * 3`` — чтобы не писать три обратные кавычки прямо в тексте скрипта (иначе сломается блок кода в этом markdown-файле) — хороший пример для обсуждения с учениками.
