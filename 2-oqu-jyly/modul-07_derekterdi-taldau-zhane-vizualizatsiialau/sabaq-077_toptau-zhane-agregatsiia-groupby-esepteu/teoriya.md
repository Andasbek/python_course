## 1. «Бөл — есепте — біріктір» (Split — Apply — Combine)

Топтау үш қадамнан тұрады:

```text
          Бастапқы кесте                 1. БӨЛУ (split)          2. ЕСЕПТЕУ (apply)   3. БІРІКТІРУ (combine)
 aty     synyp  matem                  9-сынып: 87, 78, 72   →   mean = 79.0          synyp  matem
 Әлия      9     87                   10-сынып: 92, 95, 80   →   mean = 89.0     →      9    79.0
 Нұрлан   10     92        →          11-сынып: 65, 88       →   mean = 76.5           10    89.0
 ...                                                                                   11    76.5
```

Өмірлік аналогия: дәптерлерді сыныптар бойынша **үйіп** (бөлу), әр үйінді **санап** (есептеу), содан кейін нәтижені бір **кестеге жазады** (біріктіру).

Барлық мысалдарда қолданылатын кесте:

```python
import pandas as pd

df = pd.DataFrame({
    "aty": ["Әлия", "Нұрлан", "Дана", "Ерлан", "Аружан", "Темірлан", "Мадина", "Санжар"],
    "synyp": [9, 10, 9, 11, 10, 11, 9, 10],
    "qala": ["Алматы", "Астана", "Алматы", "Шымкент", "Алматы", "Астана", "Шымкент", "Алматы"],
    "matem": [87, 92, 78, 65, 95, 88, 72, 80],
    "fizika": [80, 85, 70, 60, 90, 91, 75, 68],
})
```

## 2. `groupby()` — негізгі синтаксис

```text
df.groupby("ТОПТАУ_БАҒАНЫ")["ЕСЕПТЕЛЕТІН_БАҒАН"].АГРЕГАТ_ФУНКЦИЯ()
```

```python
print(df.groupby("synyp")["matem"].mean())
```

Нәтижесі:
```text
synyp
9     79.0
10    89.0
11    76.5
Name: matem, dtype: float64
```

**Тұжырым:** 10-сыныптың математикадан орташа баллы ең жоғары.

### Агрегат функциялар

| Функция | Мағынасы | SQL баламасы |
|---|---|---|
| `count()` | Мәндер саны (бос емес) | `COUNT()` |
| `sum()` | Қосынды | `SUM()` |
| `mean()` | Орташа мән | `AVG()` |
| `median()` | Медиана | — |
| `min()` / `max()` | Ең кіші / ең үлкен | `MIN()` / `MAX()` |
| `size()` | Топтағы жолдар саны (бос мәндермен қоса) | `COUNT(*)` |
| `nunique()` | Бірегей мәндер саны | `COUNT(DISTINCT ...)` |
| `std()` | Стандартты ауытқу (шашырау өлшемі) | — |

### Санау: `value_counts()`

Тек «әр топта қанша?» деген сұрақ үшін қысқа жол бар:

```python
print(df["qala"].value_counts())
```

Нәтижесі:
```text
qala
Алматы     4
Астана     2
Шымкент    2
Name: count, dtype: int64
```

Бұл `df.groupby("qala").size()` нәтижесімен бірдей, тек кему ретімен сұрыпталған.

### Бірнеше бағанды есептеу

```python
print(df.groupby("synyp")[["matem", "fizika"]].mean().round(1))
```

Нәтижесі:
```text
       matem  fizika
synyp               
9       79.0    75.0
10      89.0    81.0
11      76.5    75.5
```

## 3. `agg()` — бірнеше көрсеткіш бір мезетте

```python
print(df.groupby("synyp")["matem"].agg(["count", "mean", "min", "max"]))
```

Нәтижесі:
```text
       count  mean  min  max
synyp                       
9          3  79.0   72   87
10         3  89.0   80   95
11         2  76.5   65   88
```

**Атаулы агрегация** — нәтиже бағандарына өз атымызды береміз: `жаңа_ат=("баған", "функция")`.

```python
qorytyndy = df.groupby("qala").agg(
    oqushy_sany=("aty", "count"),
    matem_ortasha=("matem", "mean"),
    fizika_max=("fizika", "max"),
)
print(qorytyndy)
```

Нәтижесі:
```text
         oqushy_sany  matem_ortasha  fizika_max
qala                                           
Алматы             4           85.0          90
Астана             2           90.0          91
Шымкент            2           68.5          75
```

Бұл — дайын аналитикалық кесте: оны есепке қоюға немесе ол бойынша диаграмма (Matplotlib) салуға болады.

## 4. Бірнеше баған бойынша топтау

```python
print(df.groupby(["qala", "synyp"])["matem"].mean())
```

Нәтижесі:
```text
qala     synyp
Алматы   9        82.5
         10       87.5
Астана   10       92.0
         11       88.0
Шымкент  9        72.0
         11       65.0
Name: matem, dtype: float64
```

Индекс екі деңгейлі (MultiIndex) болды. Оны оқуға ыңғайлы кестеге айналдыру үшін **жиынтық кесте** (сводная таблица, pivot table) қолданамыз:

```python
zhiyntyq = pd.pivot_table(df, values="matem", index="qala", columns="synyp", aggfunc="mean")
print(zhiyntyq)
```

Нәтижесі:
```text
synyp      9     10    11
qala                     
Алматы   82.5  87.5   NaN
Астана    NaN  92.0  88.0
Шымкент  72.0   NaN  65.0
```

`NaN` — бұл комбинацияда оқушы жоқ дегенді білдіреді (мысалы, Алматыдан 11-сынып жоқ). Excel-дегі «Сводная таблица» дәл осылай жұмыс істейді.

## 5. Нәтижені қорытындылау

**Сұрыптау** — ең үлкенінен бастап:

```python
reiting = df.groupby("synyp")["matem"].mean().sort_values(ascending=False)
print(reiting)
```

Нәтижесі:
```text
synyp
10    89.0
9     79.0
11    76.5
Name: matem, dtype: float64
```

**Ең үздік топты табу:** `reiting.idxmax()` → `10` (ең үлкен мәннің индексі), `reiting.max()` → `89.0`.

**Индексті қайта баған ету** — нәтижені CSV-ге сақтау немесе әрі қарай өңдеу үшін:

```python
natije = df.groupby("synyp")["matem"].mean().reset_index()
print(natije)
natije.to_csv("synyp_ortasha.csv", index=False)
```

Нәтижесі:
```text
   synyp  matem
0      9   79.0
1     10   89.0
2     11   76.5
```

## 6. `transform()` — әр жолға топтық мәнді қосу

Кейде әр оқушыны **өз сыныбының** орташасымен салыстыру керек. `transform` топтық нәтижені бастапқы кестенің әр жолына «таратып» береді:

```python
df["synyp_ortasha"] = df.groupby("synyp")["matem"].transform("mean")
df["ortashadan_joqary"] = df["matem"] > df["synyp_ortasha"]
print(df[["aty", "synyp", "matem", "synyp_ortasha", "ortashadan_joqary"]])
```

Нәтижесі:
```text
        aty  synyp  matem  synyp_ortasha  ortashadan_joqary
0      Әлия      9     87           79.0               True
1    Нұрлан     10     92           89.0               True
2      Дана      9     78           79.0              False
3     Ерлан     11     65           76.5              False
4    Аружан     10     95           89.0               True
5  Темірлан     11     88           76.5               True
6    Мадина      9     72           79.0              False
7    Санжар     10     80           89.0              False
```

## 7. Заңдылық қалай табылады?

Топтау — тек есептеу емес, **сұраққа жауап іздеу**. Жұмыс реті:

1. **Сұрақ қой:** «Қай күні сатылым көп?», «Ұл мен қыздың орташа баллы ерекшеленеді ме?»
2. **Топтау бағанын таңда** (санат: күн, сынып, қала) және **есептелетін бағанды** (сан: балл, түсім).
3. **Агрегатты таңда:** жалпы көлем → `sum`; әдеттегі деңгей → `mean`/`median`; жиілік → `count`.
4. **Сұрыпта және салыстыр:** ең үлкен/кіші топ, айырмашылық неше пайыз?
5. **Тұжырым жаз:** «10-сынып математикадан 9-сыныптан орта есеппен 10 баллға жоғары».
6. **Абай бол:** топта 2 ғана адам болса, қорытынды сенімсіз. Әрдайым `count`-ты да қара!

## Жиі кездесетін қателер

**1. Мәтін бағанынан орташа есептеу.**
```python
df.groupby("synyp").mean()    # aty, qala мәтін бағандары — TypeError
```
Дұрысы — сандық бағандарды нақты көрсету:
```python
df.groupby("synyp")[["matem", "fizika"]].mean()
```
(немесе `df.groupby("synyp").mean(numeric_only=True)`)

**2. Жақшаны ұмыту.** `df.groupby("synyp")["matem"].mean` — функцияның өзі, нәтиже емес. `mean()` дұрыс.

**3. `agg` ішінде функция атын тырнақсыз жазу.**
```python
df.groupby("synyp")["matem"].agg([count, mean])    # NameError
```
Дұрысы:
```python
df.groupby("synyp")["matem"].agg(["count", "mean"])
```

**4. `count` пен `size` шатастыру.** `count` бос мәндерді санамайды, `size` санайды. Тазаланбаған деректе олар әртүрлі сан береді.

**5. Топтау нәтижесіндегі баған атын іздеу.** `groupby("synyp")` кейін `synyp` баған емес, **индекс** болады. `natije["synyp"]` қате береді — алдымен `reset_index()`.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Топтау (grouping) | Кестені бір бағанның мәндері бойынша топтарға бөлу |
| Агрегация (aggregation) | Топтағы көп мәнді бір санға «жинау» (қосынды, орташа т.б.) |
| `groupby()` | Pandas-тағы топтау әдісі |
| `agg()` | Бірнеше агрегатты бірден қолдану |
| `value_counts()` | Әр мәннің неше рет кездесетінін санау |
| `pivot_table()` | Жиынтық кесте: жолдар — бір санат, бағандар — екінші санат |
| `transform()` | Топтық нәтижені бастапқы әр жолға тарату |
| `reset_index()` | Индексті кәдімгі бағанға айналдыру |

## Ескерту

- Pandas 2.x нұсқасында мәтіндік бағандары бар кестеде `df.groupby(...).mean()` `TypeError` береді; сандық бағандарды нақты таңдаңыз немесе `numeric_only=True` беріңіз.
- Әдепкі бойынша `groupby` кілті `NaN` болатын топтарды **тастап кетеді**. Оларды сақтау үшін: `df.groupby("qala", dropna=False)`.
- `as_index=False` параметрі топ индексі жоқ кәдімгі кестені бірден қайтарады: `df.groupby("synyp", as_index=False)["matem"].mean()` — `.reset_index()`-пен бірдей.
- Категориялық (`category`) баған бойынша топтағанда `observed=True` көрсетіңіз, әйтпесе нәтижеге бос комбинациялар кіреді; Pandas-тың жаңа нұсқаларында бұл әдепкі мән өзгереді.
- Агрегат функцияларды `np.mean` емес, жол түрінде (`"mean"`, `"sum"`) берген дұрыс — Pandas жылдам ішкі іске асыруды қолданады және ескерту шығармайды.
- Құжаттама: [Group by: split-apply-combine](https://pandas.pydata.org/docs/user_guide/groupby.html).
