## 1. «Раздели — вычисли — объедини» (Split — Apply — Combine)

Группировка состоит из трёх шагов:

```text
         Исходная таблица             1. РАЗДЕЛЕНИЕ (split)     2. ВЫЧИСЛЕНИЕ (apply)  3. ОБЪЕДИНЕНИЕ (combine)
 aty     synyp  matem                  9 класс: 87, 78, 72   →   mean = 79.0          synyp  matem
 Әлия      9     87                   10 класс: 92, 95, 80   →   mean = 89.0     →      9    79.0
 Нұрлан   10     92        →          11 класс: 65, 88       →   mean = 76.5           10    89.0
 ...                                                                                   11    76.5
```

Жизненная аналогия: тетради **раскладывают** в стопки по классам (разделение), **пересчитывает** каждую стопку (вычисление), а затем **записывает** результат в одну таблицу (объединение).

Таблица, которая используется во всех примерах:

```python
import pandas as pd

df = pd.DataFrame({
    "aty": ["Әлия", "Нұрлан", "Дана", "Ерлан", "Аружан", "Темірлан", "Мадина", "Санжар"],
    "synyp": [9, 10, 9, 11, 10, 11, 9, 10],
    "qala": ["Алматы", "Астана", "Алматы", "Шымкент", "Алматы", "Астана", "Шымкент", "Алматы"],
    "matem": [87, 92, 78, 65, 95, 88, 72, 80],
    "fizika": [80, 85, 70, 60, 90, 91, 75, 68],
})
```

## 2. `groupby()` — основной синтаксис

```text
df.groupby("СТОЛБЕЦ_ГРУППИРОВКИ")["ВЫЧИСЛЯЕМЫЙ_СТОЛБЕЦ"].АГРЕГАТНАЯ_ФУНКЦИЯ()
```

```python
print(df.groupby("synyp")["matem"].mean())
```

Результат:
```text
synyp
9     79.0
10    89.0
11    76.5
Name: matem, dtype: float64
```

**Вывод:** у 10 класса самый высокий средний балл по математике.

### Агрегатные функции

| Функция | Значение | Аналог в SQL |
|---|---|---|
| `count()` | Количество значений (непустых) | `COUNT()` |
| `sum()` | Сумма | `SUM()` |
| `mean()` | Среднее значение | `AVG()` |
| `median()` | Медиана | — |
| `min()` / `max()` | Наименьшее / наибольшее | `MIN()` / `MAX()` |
| `size()` | Количество строк в группе (включая пустые значения) | `COUNT(*)` |
| `nunique()` | Количество уникальных значений | `COUNT(DISTINCT ...)` |
| `std()` | Стандартное отклонение (мера разброса) | — |

### Подсчёт: `value_counts()`

Для вопроса «сколько в каждой группе?» есть короткий путь:

```python
print(df["qala"].value_counts())
```

Результат:
```text
qala
Алматы     4
Астана     2
Шымкент    2
Name: count, dtype: int64
```

Это то же самое, что `df.groupby("qala").size()`, только отсортировано по убыванию.

### Вычисление по нескольким столбцам

```python
print(df.groupby("synyp")[["matem", "fizika"]].mean().round(1))
```

Результат:
```text
       matem  fizika
synyp               
9       79.0    75.0
10      89.0    81.0
11      76.5    75.5
```

## 3. `agg()` — несколько показателей одновременно

```python
print(df.groupby("synyp")["matem"].agg(["count", "mean", "min", "max"]))
```

Результат:
```text
       count  mean  min  max
synyp                       
9          3  79.0   72   87
10         3  89.0   80   95
11         2  76.5   65   88
```

**Именованная агрегация** — даём столбцам результата собственные имена: `новое_имя=("столбец", "функция")`.

```python
qorytyndy = df.groupby("qala").agg(
    oqushy_sany=("aty", "count"),
    matem_ortasha=("matem", "mean"),
    fizika_max=("fizika", "max"),
)
print(qorytyndy)
```

Результат:
```text
         oqushy_sany  matem_ortasha  fizika_max
qala                                           
Алматы             4           85.0          90
Астана             2           90.0          91
Шымкент            2           68.5          75
```

Это готовая аналитическая таблица: её можно вставить в отчёт или построить по ней диаграмму (Matplotlib).

## 4. Группировка по нескольким столбцам

```python
print(df.groupby(["qala", "synyp"])["matem"].mean())
```

Результат:
```text
qala     synyp
Алматы   9        82.5
         10       87.5
Астана   10       92.0
         11       88.0
Шымкент  9        72.0
         11       65.0
Name: matem, dtype: float64
```

Индекс стал двухуровневым (MultiIndex). Чтобы превратить его в удобную для чтения таблицу, используем **сводную таблицу** (pivot table):

```python
zhiyntyq = pd.pivot_table(df, values="matem", index="qala", columns="synyp", aggfunc="mean")
print(zhiyntyq)
```

Результат:
```text
synyp      9     10    11
qala                     
Алматы   82.5  87.5   NaN
Астана    NaN  92.0  88.0
Шымкент  72.0   NaN  65.0
```

`NaN` означает, что в этой комбинации учеников нет (например, нет 11-классников из Алматы). «Сводная таблица» в Excel работает точно так же.

## 5. Подведение итогов

**Сортировка** — начиная с наибольшего:

```python
reiting = df.groupby("synyp")["matem"].mean().sort_values(ascending=False)
print(reiting)
```

Результат:
```text
synyp
10    89.0
9     79.0
11    76.5
Name: matem, dtype: float64
```

**Найти лучшую группу:** `reiting.idxmax()` → `10` (индекс наибольшего значения), `reiting.max()` → `89.0`.

**Вернуть индекс в столбец** — чтобы сохранить результат в CSV или обрабатывать дальше:

```python
natije = df.groupby("synyp")["matem"].mean().reset_index()
print(natije)
natije.to_csv("synyp_ortasha.csv", index=False)
```

Результат:
```text
   synyp  matem
0      9   79.0
1     10   89.0
2     11   76.5
```

## 6. `transform()` — добавить групповое значение в каждую строку

Иногда нужно сравнить каждого ученика со средним **его класса**. `transform` «раздаёт» групповой результат каждой строке исходной таблицы:

```python
df["synyp_ortasha"] = df.groupby("synyp")["matem"].transform("mean")
df["ortashadan_joqary"] = df["matem"] > df["synyp_ortasha"]
print(df[["aty", "synyp", "matem", "synyp_ortasha", "ortashadan_joqary"]])
```

Результат:
```text
        aty  synyp  matem  synyp_ortasha  ortashadan_joqary
0      Әлия      9     87           79.0               True
1    Нұрлан     10     92           89.0               True
2      Дана      9     78           79.0              False
3     Ерлан     11     65           76.5              False
4    Аружан     10     95           89.0               True
5  Темірлан     11     88           76.5               True
6    Мадина      9     72           79.0              False
7    Санжар     10     80           89.0              False
```

## 7. Как находится закономерность?

Группировка — это не просто вычисление, а **поиск ответа на вопрос**. Порядок работы:

1. **Поставь вопрос:** «В какой день продаж больше?», «Отличается ли средний балл мальчиков и девочек?»
2. **Выбери столбец группировки** (категория: день, класс, город) и **вычисляемый столбец** (число: балл, выручка).
3. **Выбери агрегат:** общий объём → `sum`; обычный уровень → `mean`/`median`; частота → `count`.
4. **Отсортируй и сравни:** самая большая/маленькая группа, на сколько процентов разница?
5. **Запиши вывод:** «10 класс по математике в среднем на 10 баллов выше 9 класса».
6. **Будь осторожен:** если в группе всего 2 человека, вывод ненадёжен. Всегда смотри и на `count`!

## Частые ошибки

**1. Вычисление среднего по текстовому столбцу.**
```python
df.groupby("synyp").mean()    # aty, qala — текстовые столбцы — TypeError
```
Правильно — явно указать числовые столбцы:
```python
df.groupby("synyp")[["matem", "fizika"]].mean()
```
(или `df.groupby("synyp").mean(numeric_only=True)`)

**2. Забыли скобки.** `df.groupby("synyp")["matem"].mean` — это сама функция, а не результат. Правильно — `mean()`.

**3. Имя функции в `agg` без кавычек.**
```python
df.groupby("synyp")["matem"].agg([count, mean])    # NameError
```
Правильно:
```python
df.groupby("synyp")["matem"].agg(["count", "mean"])
```

**4. Путаница `count` и `size`.** `count` не считает пустые значения, `size` считает. На неочищенных данных они дают разные числа.

**5. Поиск имени столбца в результате группировки.** После `groupby("synyp")` `synyp` становится не столбцом, а **индексом**. `natije["synyp"]` вызовет ошибку — сначала `reset_index()`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Группировка (grouping) | Разбиение таблицы на группы по значениям одного столбца |
| Агрегация (aggregation) | «Сведение» множества значений группы к одному числу (сумма, среднее и т.д.) |
| `groupby()` | Метод группировки в Pandas |
| `agg()` | Применение нескольких агрегатов сразу |
| `value_counts()` | Подсчёт, сколько раз встречается каждое значение |
| `pivot_table()` | Сводная таблица: строки — одна категория, столбцы — другая |
| `transform()` | Распространение группового результата на каждую исходную строку |
| `reset_index()` | Превращение индекса в обычный столбец |

## Примечание

- В Pandas 2.x `df.groupby(...).mean()` по таблице с текстовыми столбцами вызывает `TypeError`; явно выбирайте числовые столбцы или передавайте `numeric_only=True`.
- По умолчанию `groupby` **отбрасывает** группы, где ключ равен `NaN`. Чтобы их сохранить: `df.groupby("qala", dropna=False)`.
- Параметр `as_index=False` сразу возвращает обычную таблицу без индекса группы: `df.groupby("synyp", as_index=False)["matem"].mean()` — то же, что `.reset_index()`.
- Для группировки по категориальному столбцу (`category`) указывайте `observed=True`, иначе в результат попадут пустые комбинации; в новых версиях Pandas это значение по умолчанию меняется.
- Агрегатные функции лучше передавать строками (`"mean"`, `"sum"`), а не `np.mean` — так Pandas использует быстрые встроенные реализации и не выводит предупреждений.
- Документация: [Group by: split-apply-combine](https://pandas.pydata.org/docs/user_guide/groupby.html).
