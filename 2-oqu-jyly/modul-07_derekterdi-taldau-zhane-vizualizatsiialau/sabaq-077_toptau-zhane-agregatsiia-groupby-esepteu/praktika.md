# Сабақ 77. Практикалық тапсырмалар: groupby және агрегация

**Дайындық.** Кітап дүкендері желісінің бір апталық сатылымы. Бағдарламаны `make_data.py` атымен сақтап, бір рет іске қосыңыз — `kitap_dukeni.csv` файлы пайда болады.

```python
import pandas as pd

              "Кеңсе", "Ойыншық", "Кітап", "Кеңсе"],
```

Бағандар: `kun` — апта күні, `filial` — дүкен қаласы, `sanat` — тауар санаты, `sany` — сатылған дана, `baga` — бір дананың бағасы (теңге).

## Базалық деңгей

**1-тапсырма. Түсім бағаны.** Файлды оқып, `tusim = sany * baga` бағанын қосыңыз. Аптаның жалпы түсімін шығарыңыз.
```text
Аптаның жалпы түсімі: 233100 теңге
```

**2-тапсырма. Қай филиал озат?** Әр филиалдың жалпы түсімін есептеп, кему ретімен шығарыңыз. Ең көп табыс тапқан филиалды бөлек жолмен жазыңыз (`idxmax()`).

**3-тапсырма. Ең көп сатылатын санат.** Әр санат бойынша сатылған **дана** санын есептеңіз. Қай санат дана бойынша көшбасшы?

**4-тапсырма. Жиілік.** `value_counts()` арқылы әр апта күнінде неше сатылым жазбасы болғанын шығарыңыз.

## Кеңейтілген деңгей

**5-тапсырма. Филиалдар есебі.** Атаулы агрегация арқылы мына кестені құрыңыз:
```text
         satylym_sany  zhalpy  ortasha_chek
filial                                     
Алматы              8  116200       14525.0
Астана              6   80100       13350.0
Шымкент             6   36800        6133.0
```
Мұнда `ortasha_chek` — бір сатылымның орташа сомасы (бүтінге дейін дөңгелектеңіз).

**6-тапсырма. Жиынтық кесте.** `pivot_table` арқылы жолдары — филиал, бағандары — санат, мәні — түсім қосындысы болатын кесте құрыңыз (бос орындарды 0-мен толтырыңыз: `fill_value=0`). Кестеге қарап 2 заңдылық жазыңыз.

**7-тапсырма. Апта күндері бойынша түсім.** Күндер бойынша түсімді есептеңіз. Демалыс күндері (Сб, Жс) түсімі жұмыс күндерінің түсімінен неше есе көп? Кеңес: `df["demalys"] = df["kun"].isin(["Сб", "Жс"])` бағанын қосып, сол бойынша топтаңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

**8-тапсырма. Әр филиалдың «жұлдыз» сатылымы.** `transform` арқылы әр сатылымның өз филиалы түсіміндегі үлесін (%) есептеңіз. Әр филиал үшін үлесі ең үлкен бір сатылымды шығарыңыз.

**9-тапсырма. Мәтіндік аналитикалық есеп.** Бағдарлама барлық есептеулерді жасап, директорға арналған 5–6 сөйлемдік есепті **автоматты түрде** құрастырсын, мысалы:
```text
Апта ішінде желі 233100 теңге табыс тапты.
Ең табысты филиал — Алматы (116200 теңге, жалпы түсімнің 49.8%).
Ең табысты күн — Сб.
...
```
Сандар мен атаулар кодта жазылмауы керек — бәрі деректерден есептелсін (f-жолдар).

**5–7-тапсырмалар**

```python
import pandas as pd

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]

# 5
esep = df.groupby("filial").agg(
    satylym_sany=("tusim", "count"),
    zhalpy=("tusim", "sum"),
    ortasha_chek=("tusim", "mean"),
).round(0)
print(esep)

# 6
kesteh = pd.pivot_table(df, values="tusim", index="filial", columns="sanat",
                        aggfunc="sum", fill_value=0)
print(kesteh)

# 7
kunder = df.groupby("kun", sort=False)["tusim"].sum()
print(kunder)
df["demalys"] = df["kun"].isin(["Сб", "Жс"])
bolu = df.groupby("demalys")["tusim"].sum()
print(bolu)
print("Демалыс / жұмыс күндері:", round(bolu[True] / bolu[False], 2))
```

```python
import pandas as pd

df = pd.read_csv("kitap_dukeni.csv")
```

**9-тапсырма**
```python
import pandas as pd

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]
zhalpy = df["tusim"].sum()
filial = df.groupby("filial")["tusim"].sum()
kun = df.groupby("kun")["tusim"].sum()
sanat = df.groupby("sanat")["tusim"].sum()
sanat_dana = df.groupby("sanat")["sany"].sum()

print(f"Апта ішінде желі {zhalpy} теңге табыс тапты.")
print(f"Ең табысты филиал — {filial.idxmax()} ({filial.max()} теңге, "
      f"жалпы түсімнің {filial.max() / zhalpy * 100:.1f}%).")
print(f"Ең әлсіз филиал — {filial.idxmin()} ({filial.min()} теңге).")
print(f"Ең табысты күн — {kun.idxmax()}, ең әлсіз күн — {kun.idxmin()}.")
print(f"Түсім бойынша көшбасшы санат — {sanat.idxmax()}, "
      f"ал дана бойынша — {sanat_dana.idxmax()}.")
print(f"Бір сатылымның орташа сомасы — {df['tusim'].mean():.0f} теңге.")
```
