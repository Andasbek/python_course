## Базовый уровень

**Задание 1. Столбец выручки.** Прочитайте файл и добавьте столбец `tusim = sany * baga`. Выведите общую выручку за неделю.
```text
Общая выручка за неделю: 233100 тенге
```

**Задание 2. Какой филиал лучший?** Вычислите общую выручку каждого филиала и выведите в порядке убывания. Филиал с наибольшим доходом выведите отдельной строкой (`idxmax()`).

**Задание 3. Самая продаваемая категория.** Вычислите количество проданных **штук** по каждой категории. Какая категория лидирует по количеству штук?

**Задание 4. Частота.** С помощью `value_counts()` выведите, сколько записей о продажах было в каждый день недели.

## Продвинутый уровень

**Задание 5. Отчёт по филиалам.** С помощью именованной агрегации постройте такую таблицу:
```text

filial                                     
Алматы              8  116200       14525.0
Астана              6   80100       13350.0
```

Здесь `ortasha_chek` — средняя сумма одной продажи (округлите до целого).

**Задание 6. Сводная таблица.** С помощью `pivot_table` постройте таблицу, где строки — филиалы, столбцы — категории, значения — сумма выручки (пустые места заполните нулями: `fill_value=0`). Глядя на таблицу, запишите 2 закономерности.

**Задание 7. Выручка по дням недели.** Вычислите выручку по дням. Во сколько раз выручка выходных дней (Сб, Вс) больше выручки будних дней? Подсказка: добавьте столбец `df["demalys"] = df["kun"].isin(["Сб", "Вс"])` и сгруппируйте по нему.

## ★ Олимпиадная / творческая задача

**Задание 8. «Звёздная» продажа каждого филиала.** С помощью `transform` вычислите долю (%) каждой продажи в выручке её филиала. Для каждого филиала выведите одну продажу с наибольшей долей.

**Задание 9. Текстовый аналитический отчёт.** Программа должна выполнить все вычисления и **автоматически** составить отчёт для директора из 5–6 предложений, например:
```text

```
Числа и названия не должны быть записаны в коде — всё вычисляется из данных (f-строки).
