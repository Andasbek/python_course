## 1. Деректерді талдау деген не?

**Деректер ғылымы (Data Science)** — статистика, бағдарламалау және пән саласы білімін біріктіретін сала.

```text
  «Қай айда      CSV, API, SQLite      бос мәндер,     орташа, топтау,           графиктер         есеп, шешім
```

## 2. NumPy және оның артықшылығы

**NumPy (Numerical Python)** — көп өлшемді сандық массивтермен жұмыс істеуге арналған кітапхана.

```bash
pip install numpy
```

```python
import numpy as np          # жалпы қабылданған қысқа атау — np

print(np.__version__)
```

### Тізім мен массивтің айырмашылығы

| | Python тізімі (`list`) | NumPy массиві (`ndarray`) |
|---|---|---|
| Элемент типтері | Кез келген, аралас | Бір тип (мысалы, бәрі `float64`) |
| `* 2` амалы | Тізімді қайталайды | Әр элементті 2-ге көбейтеді |
| Жылдамдық | Баяу (цикл) | 10–100 есе жылдам (C тілінде) |
| Жад | Көп | Аз, үздіксіз блок |

```python
import numpy as np

nums = [1, 2, 3]
arr = np.array([1, 2, 3])
print(nums * 2)      # тізім қайталанады
print(arr * 2)       # әр элемент көбейтіледі
print(nums + [10])   # тізімге элемент қосылады
print(arr + 10)      # әр элементке 10 қосылады
```

Нәтижесі:
```text
[1, 2, 3, 1, 2, 3]
[2 4 6]
[1, 2, 3, 10]
[11 12 13]
```

Жылдамдықты салыстырайық:

```python
import time
import numpy as np

n = 1_000_000
lst = list(range(n))
arr = np.arange(n)

t = time.perf_counter()
s1 = sum(x * x for x in lst)
t_list = time.perf_counter() - t

t = time.perf_counter()
s2 = int((arr * arr).sum())
t_np = time.perf_counter() - t

print(s1 == s2)
print(f"Тізім: {t_list:.3f} с, NumPy: {t_np:.4f} с, ≈ {t_list / t_np:.0f} есе жылдам")
```

Нәтижесі (компьютерге байланысты):
```text
True
Тізім: 0.051 с, NumPy: 0.0052 с, ≈ 10 есе жылдам
```

## 3. Массив құру

```python
import numpy as np

a = np.array([5, 3, 8, 1])               # тізімнен
b = np.arange(0, 10, 2)                  # range сияқты: 0, 2, 4, 6, 8
c = np.linspace(0, 1, 5)                 # 0-ден 1-ге дейін 5 бірқалыпты нүкте
z = np.zeros(3)                          # нөлдер
o = np.ones((2, 3))                      # бірліктерден тұратын 2×3 матрица
rng = np.random.default_rng(42)          # кездейсоқ сандар генераторы (42 — қайталанатын нәтиже үшін)
r = rng.integers(1, 6, size=5)           # 1–5 аралығындағы 5 бүтін сан (баға!)

for name, x in [("a", a), ("b", b), ("c", c), ("z", z), ("o", o), ("r", r)]:
    print(name, "=", x)
```

Нәтижесі:
```text
a = [5 3 8 1]
b = [0 2 4 6 8]
c = [0.   0.25 0.5  0.75 1.  ]
z = [0. 0. 0.]
o = [[1. 1. 1.]
 [1. 1. 1.]]
r = [1 4 4 3 3]
```

```python
grades = np.array([[5, 4, 5, 3],

```

## 4. Векторлық амалдар

Циклсіз — бүкіл массивке бірден амал жасау **векторлау** (vectorization) деп аталады.

```python
import numpy as np

celsius = np.array([-12.5, -3.0, 0.0, 8.4, 21.7])
fahrenheit = celsius * 9 / 5 + 32
print(fahrenheit)

prices_kzt = np.array([4500, 6000, 5200])
discount = prices_kzt * 0.85               # 15% жеңілдік
print(discount)

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print(a + b, a * b, b / a, a ** 2)         # элемент бойынша амалдар
print(np.sqrt(np.array([4, 9, 16])))       # математикалық функциялар
print(np.round(np.array([2.345, 7.891]), 1))
```

Нәтижесі:
```text
[ 9.5  26.6  32.   47.12 71.06]
[3825. 5100. 4420.]
[11 22 33] [10 40 90] [10. 10. 10.] [1 4 9]
[2. 3. 4.]
[2.3 7.9]
```

**Тарату (broadcasting)** — өлшемі әртүрлі массивтерді «созып» сәйкестендіру. Мысалы, `celsius * 9` — 9 саны массивтің әр элементіне «таратылады». Матрицаның әр жолына бір вектор қосуға да болады (2D бөлімінде).

## 5. Агрегат функциялары

```python
import numpy as np

temps = np.array([-6.1, -8.3, -4.0, 0.4, 2.7, 1.5, -2.2])   # бір аптаның температурасы

print("Қосынды:", temps.sum())
print("Орташа:", temps.mean().round(2))
print("Медиана:", np.median(temps))
print("Мин / Макс:", temps.min(), temps.max())
print("Ең суық күн индексі:", temps.argmin())
print("Стандартты ауытқу:", temps.std().round(2))
print("Құбылу ауқымы:", np.ptp(temps).round(2))      # max - min
```

Нәтижесі:
```text
Қосынды: -16.0
Орташа: -2.29
Медиана: -2.2
Мин / Макс: -8.3 2.7
Ең суық күн индексі: 1
Стандартты ауытқу: 3.78
Құбылу ауқымы: 11.0
```

| Функция | Мағынасы |
|---|---|
| `sum`, `mean`, `median` | Қосынды, орташа, медиана (ортаңғы мән) |
| `min`, `max`, `argmin`, `argmax` | Ең кіші/үлкен мән және оның индексі |
| `std`, `var` | Стандартты ауытқу, дисперсия — мәндердің «шашырауы» |
| `cumsum` | Жинақталған қосынды |

**Орташа мен медиана:** `[100, 110, 120, 1000]` жалақыларының орташасы 332.5, ал медианасы 115. Медиана «шеткі» мәндерге сезімтал емес.

## 6. Индекстеу, кесінді, логикалық маска

```python
import numpy as np

t = np.array([-6.1, -8.3, -4.0, 0.4, 2.7, 1.5, -2.2])

print(t[0], t[-1])          # бірінші және соңғы
print(t[2:5])               # кесінді: 2, 3, 4 индекстер
print(t[::2])               # әр екінші

mask = t > 0                # логикалық маска
print(mask)
print(t[mask])              # тек оң мәндер
print("Аязды күндер саны:", (t < 0).sum())
print(t[(t > -5) & (t < 2)])   # бірнеше шарт: & (және), | (немесе), жақшалар міндетті!

t2 = t.copy()
t2[t2 < -5] = -5            # маска арқылы өзгерту: -5-тен суықтарды -5-ке «қию»
print(t2)
```

Нәтижесі:
```text
-6.1 -2.2
[-4.   0.4  2.7]
[-6.1 -4.   2.7 -2.2]
[False False False  True  True  True False]
[0.4 2.7 1.5]
Аязды күндер саны: 4
[-4.   0.4  1.5 -2.2]
[-5.  -5.  -4.   0.4  2.7  1.5 -2.2]
```

`(t < 0).sum()` — `True` 1 ретінде, `False` 0 ретінде саналады.

## 7. Екі өлшемді массивтер (матрицалар)

```python
import numpy as np

subjects = ["Математика", "Физика", "Информатика", "Тарих"]
students = ["Айгерім", "Нұрлан", "Дана"]
grades = np.array([[5, 4, 5, 3],
                   [4, 4, 5, 5],
                   [3, 5, 4, 4]])

print(grades[1, 2])          # Нұрланның информатикадан бағасы
print(grades[0])             # Айгерімнің барлық бағалары (жол)
print(grades[:, 0])          # барлығының математикадан бағалары (баған)

print("Әр оқушының ортасы:", grades.mean(axis=1).round(2))   # axis=1 — жол бойынша
print("Әр пәннің ортасы:", grades.mean(axis=0).round(2))     # axis=0 — баған бойынша

best = grades.mean(axis=1).argmax()
print("Үздік оқушы:", students[best])
hardest = grades.mean(axis=0).argmin()
print("Ең қиын пән:", subjects[hardest])

bonus = np.array([0, 1, 0, 0])            # тарату: физикадан барлығына +1
print(np.minimum(grades + bonus, 5))      # 5-тен аспасын
```

Нәтижесі:
```text
5
[5 4 5 3]
[5 4 3]
Әр оқушының ортасы: [4.25 4.5  4.  ]
Әр пәннің ортасы: [4.   4.33 4.67 4.  ]
Үздік оқушы: Нұрлан
Ең қиын пән: Математика
[[5 5 5 3]
 [4 5 5 5]
 [3 5 4 4]]
```

`axis` ережесі: **`axis=0`** — бағандар бойынша есептеу (жолдарды «жинау», нәтиже — әр бағанға бір сан), **`axis=1`** — жолдар бойынша (нәтиже — әр жолға бір сан).

```text
            axis=1 →
         ┌───────────┐
axis=0   │ 5  4  5  3 │ → 4.25
   ↓     │ 4  4  5  5 │ → 4.5
         │ 3  5  4  4 │ → 4.0
         └───────────┘
           4 4.33 4.67 4
```

## 8. Мысал: бір айдың температурасын талдау

```python
import numpy as np

rng = np.random.default_rng(7)
days = np.arange(1, 29)                                  # ақпанның 28 күні
temps = np.round(rng.normal(loc=-4, scale=5, size=28), 1)  # орташасы -4, шашырауы 5

print(f"Орташа: {temps.mean():.1f} °C")
print(f"Ең жылы: {temps.max()} °C ({days[temps.argmax()]} ақпан)")
print(f"Ең суық: {temps.min()} °C ({days[temps.argmin()]} ақпан)")
print("Жылымық күндер (>0):", days[temps > 0])
weekly = temps.reshape(4, 7).mean(axis=1).round(1)
print("Апталық орташа:", weekly)
print("Ең жылы апта:", weekly.argmax() + 1)
```

Нәтижесі (кездейсоқ, бірақ `seed=7` болғандықтан әр ретте бірдей):
```text
Орташа: -6.2 °C
Ең жылы: 2.7 °C (8 ақпан)
Ең суық: -16.6 °C (27 ақпан)
Жылымық күндер (>0): [8]
Апталық орташа: [-5.6 -3.8 -8.4 -7.1]
Ең жылы апта: 2
```

`rng.normal(loc, scale, size)` — қалыпты (Гаусс) үлестірім бойынша кездейсоқ сандар: нақты өмірдегі өлшемдер көбіне осылай таралады.

## Жиі кездесетін қателер

**1. `np.array(1, 2, 3)`** — тізім жақшасыз. Дұрысы: `np.array([1, 2, 3])`.

**2. Шарттарда `and`/`or` қолдану:**
```python
import numpy as np
t = np.array([-3, 1, 5])
# Қате: t[(t > 0) and (t < 4)]  → ValueError: truth value of an array ... is ambiguous
print(t[(t > 0) & (t < 4)])       # Дұрыс: & және жақшалар
```

**3. Әртүрлі ұзындықтағы массивтерді қосу:** `np.array([1, 2]) + np.array([1, 2, 3])` → `ValueError: operands could not be broadcast together`.

**4. Аралас типтер:** `np.array([1, "2", 3])` — бәрі мәтінге айналады (`dtype='<U21'`), есептеу мүмкін емес. Деректерді алдымен тазалаңыз.

**5. `axis`-ті шатастыру** — «әр оқушының ортасы» (жол) = `axis=1`. Күмән болса, нәтиженің ұзындығын тексеріңіз: `.shape`.

**6. Көшірме мен «көрініс» (view):** `b = a[1:3]` — жаңа массив емес, `a`-ның бөлігі; `b[0] = 99` → `a` да өзгереді. Тәуелсіз көшірме: `a[1:3].copy()`.

## Ескерту

- NumPy массиві біртекті: әртүрлі типтер араласса, бәрі бір типке келтіріледі (`np.array([1, 2.5])` → `float64`, `np.array([1, "a"])` → жолдар).
- Массивтің кесіндісі — көшірме емес, **көрініс** (view): кесіндіні өзгерту бастапқы массивті де өзгертеді; көшірме — `.copy()`.
- Логикалық шарттар үшін `and`/`or`/`not` емес, әр шартты жақшаға алып, `&`, `|`, `~` қолданыңыз.
- Бүтін сан массивтерінің өлшемі тұрақты (`int64`/`int32`), Python-ның `int` типінен айырмашылығы — қатесіз асып кетуі (overflow) мүмкін.
- Кездейсоқ сандар үшін заманауи ұсынылатын тәсіл — `np.random.default_rng()` (https://numpy.org/doc/stable/reference/random/generator.html). Жалпы қабылданған импорт: `import numpy as np`.
