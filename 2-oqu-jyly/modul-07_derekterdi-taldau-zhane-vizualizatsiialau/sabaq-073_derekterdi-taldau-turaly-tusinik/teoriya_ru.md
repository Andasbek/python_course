## 1. Что такое анализ данных?

**Анализ данных (data analysis)** — процесс получения полезной информации, закономерностей и выводов из «сырых» данных.

**Наука о данных (Data Science)** — область, объединяющая статистику, программирование и знания предметной области.

### Этапы анализа

```text
1. Постановка  →  2. Сбор данных  →  3. Очистка  →  4. Исследование и анализ  →  5. Визуализация  →  6. Выводы
  вопроса         CSV, API, SQLite    пропуски,      среднее, группировка,       графики          отчёт, решение
  «В каком мес.   (модули V–VI)       дубли (76)     сравнение (74–77)           (78–80)          (81–82)
   холоднее?»
```

### Применение

| Область | Пример |
|---|---|
| Торговля | Kaspi: «с этим товаром также покупают...» |
| Медицина | Прогноз распространения заболеваний |
| Спорт | Статистика футболистов, тактика игры |
| Образование | Анализ успеваемости учеников, выявление трудных тем |
| Метеорология | Прогноз погоды |
| Город | 2GIS: карта пробок |

## 2. NumPy и его преимущества

**NumPy (Numerical Python)** — библиотека для работы с многомерными числовыми массивами.


```python
import numpy as np          # общепринятое короткое имя — np
```

### Разница между списком и массивом

| | Список Python (`list`) | Массив NumPy (`ndarray`) |
|---|---|---|
| Типы элементов | Любые, смешанные | Один тип (например, все `float64`) |
| Операция `* 2` | Повторяет список | Умножает каждый элемент на 2 |
| Скорость | Медленно (цикл) | В 10–100 раз быстрее (на языке C) |
| Память | Много | Мало, непрерывный блок |

```python
import numpy as np

nums = [1, 2, 3]
arr = np.array([1, 2, 3])
print(nums * 2)      # список повторяется
print(arr * 2)       # каждый элемент умножается
print(nums + [10])   # к списку добавляется элемент
print(arr + 10)      # к каждому элементу прибавляется 10
```

Результат:
```text
[1, 2, 3, 1, 2, 3]
[2 4 6]
[1, 2, 3, 10]
[11 12 13]
```

Сравним скорость:

```python
import time
import numpy as np

n = 1_000_000
lst = list(range(n))
arr = np.arange(n)

t = time.perf_counter()
s1 = sum(x * x for x in lst)
t_list = time.perf_counter() - t

t = time.perf_counter()
s2 = int((arr * arr).sum())
t_np = time.perf_counter() - t

print(s1 == s2)
print(f"Список: {t_list:.3f} с, NumPy: {t_np:.4f} с, быстрее ≈ в {t_list / t_np:.0f} раз")
```

Результат (зависит от компьютера):
```text
True
Список: 0.051 с, NumPy: 0.0052 с, быстрее ≈ в 10 раз
```

## 3. Создание массивов

```python
import numpy as np

a = np.array([5, 3, 8, 1])               # из списка
b = np.arange(0, 10, 2)                  # как range: 0, 2, 4, 6, 8
c = np.linspace(0, 1, 5)                 # 5 равномерных точек от 0 до 1
z = np.zeros(3)                          # нули
o = np.ones((2, 3))                      # матрица 2×3 из единиц
rng = np.random.default_rng(42)          # генератор случайных чисел (42 — для повторяемого результата)
r = rng.integers(1, 6, size=5)           # 5 целых чисел от 1 до 5 (оценки!)

for name, x in [("a", a), ("b", b), ("c", c), ("z", z), ("o", o), ("r", r)]:
    print(name, "=", x)
```

Результат:
```text
a = [5 3 8 1]
b = [0 2 4 6 8]
c = [0.   0.25 0.5  0.75 1.  ]
z = [0. 0. 0.]
o = [[1. 1. 1.]
 [1. 1. 1.]]
r = [1 4 4 3 3]
```

```python
import numpy as np

grades = np.array([[5, 4, 5, 3],
```

## 4. Векторные операции

Выполнение операции сразу над всем массивом без цикла называется **векторизацией** (vectorization).

```python
import numpy as np

celsius = np.array([-12.5, -3.0, 0.0, 8.4, 21.7])
fahrenheit = celsius * 9 / 5 + 32
print(fahrenheit)

prices_kzt = np.array([4500, 6000, 5200])
discount = prices_kzt * 0.85               # скидка 15%
print(discount)

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print(a + b, a * b, b / a, a ** 2)         # поэлементные операции
print(np.sqrt(np.array([4, 9, 16])))       # математические функции
print(np.round(np.array([2.345, 7.891]), 1))
```

Результат:
```text
[ 9.5  26.6  32.   47.12 71.06]
[3825. 5100. 4420.]
[11 22 33] [10 40 90] [10. 10. 10.] [1 4 9]
[2. 3. 4.]
[2.3 7.9]
```

**Транслирование (broadcasting)** — «растягивание» массивов разной формы для согласования. Например, в `celsius * 9` число 9 «транслируется» на каждый элемент массива. Можно также прибавить один вектор к каждой строке матрицы (в разделе о 2D).

## 5. Агрегатные функции

```python
import numpy as np

temps = np.array([-6.1, -8.3, -4.0, 0.4, 2.7, 1.5, -2.2])   # температура за одну неделю

print("Сумма:", temps.sum())
print("Среднее:", temps.mean().round(2))
print("Медиана:", np.median(temps))
print("Мин / Макс:", temps.min(), temps.max())
print("Индекс самого холодного дня:", temps.argmin())
print("Стандартное отклонение:", temps.std().round(2))
print("Размах:", np.ptp(temps).round(2))      # max - min
```

Результат:
```text
Сумма: -16.0
Среднее: -2.29
Медиана: -2.2
Мин / Макс: -8.3 2.7
Индекс самого холодного дня: 1
Стандартное отклонение: 3.78
Размах: 11.0
```

| Функция | Значение |
|---|---|
| `sum`, `mean`, `median` | Сумма, среднее, медиана (серединное значение) |
| `min`, `max`, `argmin`, `argmax` | Наименьшее/наибольшее значение и его индекс |
| `std`, `var` | Стандартное отклонение, дисперсия — «разброс» значений |
| `cumsum` | Накопленная сумма |

**Среднее и медиана:** у зарплат `[100, 110, 120, 1000]` среднее 332.5, а медиана 115. Медиана нечувствительна к «крайним» значениям.

## 6. Индексация, срез, логическая маска

```python
import numpy as np

t = np.array([-6.1, -8.3, -4.0, 0.4, 2.7, 1.5, -2.2])

print(t[0], t[-1])          # первый и последний
print(t[2:5])               # срез: индексы 2, 3, 4
print(t[::2])               # каждый второй

mask = t > 0                # логическая маска
print(mask)
print(t[mask])              # только положительные значения
print("Морозных дней:", (t < 0).sum())
print(t[(t > -5) & (t < 2)])   # несколько условий: & (и), | (или), скобки обязательны!

t2 = t.copy()
t2[t2 < -5] = -5            # изменение через маску: «обрезаем» всё холоднее -5 до -5
print(t2)
```

Результат:
```text
-6.1 -2.2
[-4.   0.4  2.7]
[-6.1 -4.   2.7 -2.2]
[False False False  True  True  True False]
[0.4 2.7 1.5]
Морозных дней: 4
[-4.   0.4  1.5 -2.2]
[-5.  -5.  -4.   0.4  2.7  1.5 -2.2]
```

`(t < 0).sum()` — `True` считается как 1, `False` — как 0.

## 7. Двумерные массивы (матрицы)

```python
import numpy as np

subjects = ["Математика", "Физика", "Информатика", "История"]
students = ["Айгерім", "Нұрлан", "Дана"]
grades = np.array([[5, 4, 5, 3],
                   [4, 4, 5, 5],
                   [3, 5, 4, 4]])

print(grades[1, 2])          # оценка Нурлана по информатике
print(grades[0])             # все оценки Айгерим (строка)
print(grades[:, 0])          # оценки всех по математике (столбец)

print("Среднее каждого ученика:", grades.mean(axis=1).round(2))   # axis=1 — по строке
print("Среднее по каждому предмету:", grades.mean(axis=0).round(2))     # axis=0 — по столбцу

best = grades.mean(axis=1).argmax()
print("Лучший ученик:", students[best])
hardest = grades.mean(axis=0).argmin()
print("Самый трудный предмет:", subjects[hardest])

bonus = np.array([0, 1, 0, 0])            # транслирование: всем +1 по физике
print(np.minimum(grades + bonus, 5))      # не больше 5
```

Результат:
```text
5
[5 4 5 3]
[5 4 3]
Среднее каждого ученика: [4.25 4.5  4.  ]
Среднее по каждому предмету: [4.   4.33 4.67 4.  ]
Лучший ученик: Нұрлан
Самый трудный предмет: Математика
[[5 5 5 3]
 [4 5 5 5]
 [3 5 4 4]]
```

Правило `axis`: **`axis=0`** — вычисление по столбцам («сворачиваем» строки, результат — по одному числу на каждый столбец), **`axis=1`** — по строкам (результат — по одному числу на каждую строку).

```text
            axis=1 →
         ┌───────────┐
axis=0   │ 5  4  5  3 │ → 4.25
   ↓     │ 4  4  5  5 │ → 4.5
         │ 3  5  4  4 │ → 4.0
         └───────────┘
           4 4.33 4.67 4
```

### Изменение формы

```python
import numpy as np

week = np.arange(1, 15)          # 14 дней
two_weeks = week.reshape(2, 7)   # 2 недели × 7 дней
print(two_weeks)
print(two_weeks.T.shape)         # транспонирование: строки ↔ столбцы
```


## 8. Пример: анализ температуры за месяц

```python
import numpy as np

rng = np.random.default_rng(7)
days = np.arange(1, 29)                                  # 28 дней февраля
temps = np.round(rng.normal(loc=-4, scale=5, size=28), 1)  # среднее -4, разброс 5

print(f"Среднее: {temps.mean():.1f} °C")
print(f"Самый тёплый: {temps.max()} °C ({days[temps.argmax()]} февраля)")
print(f"Самый холодный: {temps.min()} °C ({days[temps.argmin()]} февраля)")
print("Дни оттепели (>0):", days[temps > 0])
weekly = temps.reshape(4, 7).mean(axis=1).round(1)
print("Среднее по неделям:", weekly)
print("Самая тёплая неделя:", weekly.argmax() + 1)
```

Результат (случайный, но благодаря `seed=7` каждый раз одинаковый):
```text
Среднее: -6.2 °C
Самый тёплый: 2.7 °C (8 февраля)
Самый холодный: -16.6 °C (27 февраля)
Дни оттепели (>0): [8]
Среднее по неделям: [-5.6 -3.8 -8.4 -7.1]
Самая тёплая неделя: 2
```

`rng.normal(loc, scale, size)` — случайные числа по нормальному (гауссову) распределению: так чаще всего распределяются измерения в реальной жизни.

## Частые ошибки

**1. `np.array(1, 2, 3)`** — без квадратных скобок списка. Правильно: `np.array([1, 2, 3])`.

**2. Использование `and`/`or` в условиях:**
```python
import numpy as np
t = np.array([-3, 1, 5])
# Неправильно: t[(t > 0) and (t < 4)]  → ValueError: truth value of an array ... is ambiguous
print(t[(t > 0) & (t < 4)])       # Правильно: & и скобки
```

**3. Сложение массивов разной длины:** `np.array([1, 2]) + np.array([1, 2, 3])` → `ValueError: operands could not be broadcast together`.

**4. Смешанные типы:** `np.array([1, "2", 3])` — всё превращается в текст (`dtype='<U21'`), вычисления невозможны. Сначала очистите данные.

**5. Путаница с `axis`** — «среднее каждого ученика» (строка) = `axis=1`. Если сомневаетесь, проверьте длину результата: `.shape`.

**6. Копия и «представление» (view):** `b = a[1:3]` — не новый массив, а часть `a`; `b[0] = 99` → изменится и `a`. Независимая копия: `a[1:3].copy()`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Анализ данных | Процесс получения полезных выводов из данных |
| Data Science | Статистика + программирование + знание предметной области |
| NumPy | Библиотека числовых массивов |
| `ndarray` | Многомерный массив NumPy |
| `shape` / `ndim` / `dtype` | Форма / число измерений / тип элементов |
| Векторизация | Применение операции ко всему массиву без цикла |
| Транслирование (broadcasting) | Автоматическое согласование массивов разной формы |
| Агрегатная функция | Функция, вычисляющая одно значение из многих (`mean`, `sum`) |
| Логическая маска | Фильтрация с помощью массива `True`/`False` |
| `axis` | Направление вычисления: 0 — столбцы, 1 — строки |
| Медиана / стандартное отклонение | Серединное значение / мера разброса значений |

## Примечание

- Массив NumPy однороден: при смешивании типов всё приводится к одному (`np.array([1, 2.5])` → `float64`, `np.array([1, "a"])` → строки).
- Срез массива — это не копия, а **представление** (view): изменение среза меняет исходный массив; копия — `.copy()`.
- Для логических условий используйте `&`, `|`, `~` со скобками вокруг каждого условия, а не `and`/`or`/`not`.
- Целочисленные массивы имеют фиксированный размер (`int64`/`int32`) и, в отличие от `int` Python, могут переполняться без ошибки (overflow).
- Современный рекомендуемый способ получения случайных чисел — `np.random.default_rng()` (https://numpy.org/doc/stable/reference/random/generator.html). Общепринятый импорт: `import numpy as np`.
