## 1-нұсқа. «Мектеп асханасы»

**Деректер.** Төмендегі кодты файлыңыздың басына көшіріп, бір рет іске қосыңыз — `asxana.csv` жасалады.

**А. Теориялық сұрақтар (әрқайсысы 2 ұпай, барлығы 10).**
1. `NaN` дегеніміз не? Оны неге `==` арқылы тексеруге болмайды?
2. `dropna()` пен `fillna()` айырмашылығы неде?
3. `groupby` жұмысының үш қадамын атаңыз.
4. Гистограмма мен бағаналы диаграмманың бір айырмашылығын айтыңыз.
5. «Бүтіннің үлесін» көрсету үшін қандай диаграмма қолданылады және оның бір шектеуі қандай?

**Ә. Практикалық тапсырмалар.**

**1-тапсырма (20 ұпай). Тазалау.** Файлды оқып, бос мәндер мен дубликаттар санын шығарыңыз. Тазалаңыз: дубликаттарды жойыңыз; `tagam` бағанын біркелкі етіңіз (бос орынсыз, бас әріппен); бос `baga` мәнін **сол тағамның** бағасымен толтырыңыз; `sany` ≤ 0 жолдарды алып тастаңыз. Тазалаудан кейінгі жол санын шығарыңыз.

**2-тапсырма (25 ұпай). Талдау.** `tusim = baga * sany` бағанын қосыңыз. Атаулы агрегация арқылы әр тағам бойынша сатылған дана (`dana`) мен түсімді (`tusim`) есептеп, түсім бойынша кему ретімен шығарыңыз. Апта бойғы жалпы түсімді және ең табысты күнді шығарыңыз.

**3-тапсырма (30 ұпай). Визуализация.** Бір фигурада (`plt.subplots(1, 2)`) екі график:
а) тағамдар бойынша түсім — бағаналы диаграмма (мәндер бағананың үстінде, Y осі 0-ден);
ә) апта күндері бойынша түсім — сызықтық диаграмма.
Әр графикте тақырып және бірлігі бар ось атаулары; фигура `asxana.png` болып сақталсын.

**4-тапсырма (15 ұпай). Қорытынды.** Бағдарлама соңында асхана меңгерушісіне арналған 2–3 сөйлемдік қорытындыны f-жолдар арқылы шығарыңыз (сандар кодтан есептелсін).

### 1-нұсқа

**Теория — үлгі жауаптар:**
1. `NaN` — жоқ (бос) мән белгісі; `NaN == NaN` әрдайым `False`, сондықтан `isna()` қолданылады.
2. `dropna()` бос мәні бар жолдарды/бағандарды жояды; `fillna()` бос орынды берілген мәнмен толтырады.
3. Бөлу (split), есептеу (apply), біріктіру (combine).
4. Бағаналы — санаттар, бағаналар арасында бос орын; гистограмма — сандық аралықтар бойынша таралу, бағаналар тиіп тұрады.
5. Дөңгелек; 5–6 бөліктен көп болмауы керек / бұрыштарды дәл салыстыру қиын.

**Практика:**
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("asxana.csv")
print("Бос мәндер:", df.isna().sum().sum())
print("Дубликаттар:", df.duplicated().sum())

# 1. Тазалау
df = df.drop_duplicates()
df["tagam"] = df["tagam"].str.strip().str.capitalize()
df["baga"] = df["baga"].fillna(df.groupby("tagam")["baga"].transform("median"))
df = df[df["sany"] > 0].copy()
print("Тазалаудан кейін:", len(df), "жол")

# 2. Талдау
df["tusim"] = df["baga"] * df["sany"]
tagam = df.groupby("tagam").agg(dana=("sany", "sum"), tusim=("tusim", "sum"))
tagam = tagam.sort_values("tusim", ascending=False)
print(tagam)
kun = df.groupby("kun", sort=False)["tusim"].sum()
zhalpy = df["tusim"].sum()
print("Жалпы түсім:", int(zhalpy), "теңге")
print("Ең табысты күн:", kun.idxmax())

# 3. Визуализация
fig, ax = plt.subplots(1, 2, figsize=(12, 4.5))
b = ax[0].bar(tagam.index, tagam["tusim"] / 1000, color="#2A9D8F")
ax[0].bar_label(b, fmt="%.1f")
ax[0].set_ylim(0, 140)
ax[0].set_title("Тағамдар бойынша түсім")
ax[0].set_xlabel("Тағам")
ax[0].set_ylabel("Түсім, мың теңге")
ax[1].plot(kun.index, kun.values / 1000, marker="o", color="#E76F51")
ax[1].set_title("Апта күндері бойынша түсім")
ax[1].set_xlabel("Күн")
ax[1].set_ylabel("Түсім, мың теңге")
plt.tight_layout()
fig.savefig("asxana.png", dpi=150)
plt.show()

# 4. Қорытынды
print(f"Апта бойы асхана {int(zhalpy)} теңге түсім тапты.")
print(f"Ең көп табыс әкелген тағам — {tagam.index[0]} ({int(tagam['tusim'].iloc[0])} теңге), "
      f"ал дана бойынша көшбасшы — {tagam['dana'].idxmax()}.")
print(f"Ең табысты күн — {kun.idxmax()}, сондықтан бұл күні өнімді көбірек дайындау ұсынылады.")
```
Күтілетін нәтижелер: бос мән — 1, дубликат — 1; тазалаудан кейін 13 жол. Самса — 351 дана, 122 850 ₸; Палау — 120, 108 000 ₸; Лағман — 95, 80 750 ₸; Шай — 240, 24 000 ₸. Жалпы түсім — 335 600 ₸; ең табысты күн — Жм (82 500 ₸).

### 2-нұсқа

**Теория — үлгі жауаптар:**
1. Лас деректен жасалған қорытынды қате болады; «қоқыс кірсе — қоқыс шығады».
2. Қай көшірмені қалдыру керегін көрсетеді: `"first"`, `"last"` немесе `False` (бәрін жою).
3. Әр мәннің (топтың) неше рет кездесетінін; `value_counts` кему ретімен сұрыптайды.
4. Екі сандық шама арасындағы байланысты; −0,9 — күшті теріс байланыс (біреуі өссе, екіншісі азаяды).
5. `show()` терезе жабылғаннан кейін фигураны тазалайды, сондықтан кейін сақталған сурет бос болады.

**Практика:**
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitaphana.csv")
print("Бос мәндер:", df.isna().sum().sum())
print("Дубликаттар:", df.duplicated().sum())

# 1. Тазалау
df = df.drop_duplicates()
df["zhanr"] = df["zhanr"].str.strip().str.capitalize()
df = df.dropna(subset=["kitap_sany"])
df = df[df["kitap_sany"] <= 100].copy()
print("Тазалаудан кейін:", len(df), "жол")

# 2. Талдау
zhanr = df.groupby("zhanr")["kitap_sany"].agg(["sum", "mean"]).round(1)
zhanr = zhanr.sort_values("sum", ascending=False)
print(zhanr)
ai = df.groupby("ai", sort=False)["kitap_sany"].sum()
print(ai)
print("Ең белсенді ай:", ai.idxmax())

# 3. Визуализация
fig, ax = plt.subplots(1, 2, figsize=(12, 4.5))
ax[0].pie(zhanr["sum"], labels=zhanr.index, autopct="%1.1f%%", startangle=90)
ax[0].set_title("Жанрлардың үлесі")
b = ax[1].bar(ai.index, ai.values, color="#264653")
ax[1].bar_label(b, fmt="%.0f")
ax[1].set_title("Айлар бойынша берілген кітаптар")
ax[1].set_xlabel("Ай")
ax[1].set_ylabel("Кітап саны, дана")
plt.tight_layout()
fig.savefig("kitaphana.png", dpi=150)
plt.show()

# 4. Қорытынды
zhalpy = int(df["kitap_sany"].sum())
print(f"Төрт айда кітапхана {zhalpy} кітап берді.")
print(f"Ең сұранысты жанр — {zhanr.index[0]} ({int(zhanr['sum'].iloc[0])} кітап, "
      f"{zhanr['sum'].iloc[0] / zhalpy * 100:.0f}%).")
print(f"Ең белсенді ай — {ai.idxmax()}, ең төмені — {ai.idxmin()}.")
```
Күтілетін нәтижелер: бос мән — 1, дубликат — 1; тазалаудан кейін 11 жол (дубликат, бос мән және 300 кітапты «Фантастика» жолы жойылады). Ертегі — 117 (орташа 29,2), Ғылыми — 62 (15,5), Тарих — 55 (18,3). Айлар: Қыр 61, Қаз 62, Қар 44, Жел 67; ең белсенді — Жел. Барлығы 234 кітап; Ертегі үлесі ≈ 50%.
