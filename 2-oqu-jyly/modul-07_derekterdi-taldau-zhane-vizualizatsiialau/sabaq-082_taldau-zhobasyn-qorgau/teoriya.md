## 2. Кез келген компьютерде іске қосылатын жоба

Талдау жобасы қайталанатын болуы керек: басқа адам репозиторийді клондап, тәуелділіктерді орнатып, дәл сондай кестелер мен графиктер алады.

```text
taldau-zhobasy/
├── data/
│   ├── raw.csv          ← бастапқы деректер (тек оқу)
│   └── clean.csv        ← бағдарлама жасайды
├── images/              ← бағдарлама жасайды
├── analysis.py
├── requirements.txt     ← pandas, matplotlib, numpy
└── README.md
```

Жолдарды `pathlib` арқылы бағдарлама файлына қатысты құрамыз — сонда код қай қалтадан іске қосылса да жұмыс істейді:

```python
from pathlib import Path

import pandas as pd

BASE = Path(__file__).resolve().parent
DATA = BASE / "data"
IMAGES = BASE / "images"


def main():
    IMAGES.mkdir(exist_ok=True)                  # қалта жоқ болса, жасау
    df = pd.read_csv(DATA / "raw.csv")
    df = df.drop_duplicates()
    df.to_csv(DATA / "clean.csv", index=False)


if __name__ == "__main__":
    main()
```

Тәуелділіктер `pip freeze > requirements.txt` командасымен бекітіліп, `pip install -r requirements.txt` командасымен орнатылады.

## 3. Деректерді талдаудағы шешімдерді негіздеу

Жобадағы әр техникалық шешімнің түсіндірмесі болуы керек:

| Шешім | Негіздеме |
|---|---|
| Бос мәндер орташамен емес, медианамен толтырылды | Медиана шығарындыларға төзімді; орташа мәнді аномалиялар «тартады» |
| Бос мәні бар жолдар жойылмады | `dropna()` деректің үлкен бөлігін жояр еді; алдымен `isna().sum()` |
| Дөңгелек емес, бағаналы диаграмма | Бағаналардың ұзындығы секторлардың бұрыштарына қарағанда дәлірек салыстырылады |
| Бағаналардың Y осі 0-ден басталады | Әйтпесе бағаналар арасындағы айырма көзге үлкейіп көрінеді |
| Орташа мәннің қасында `count` көрсетілген | 2–3 жазбадан тұратын топтың орташасы сенімсіз |
| Қорытынды себеп емес, байланыс ретінде айтылған | Корреляция себеп-салдарлық байланысты дәлелдемейді |

Қорытындының тұрақтылығын тексеру жолы: есептеуді деректің бір бөлігінде қайталап (`df.sample(frac=0.5, random_state=1)`), топтар арасындағы айырма сақтала ма, соны қарау.

```python
import pandas as pd

df = pd.DataFrame({
    "sport": ["иә", "жоқ", "иә", "жоқ", "иә", "жоқ", "иә", "жоқ"],
    "ball": [82, 70, 78, 74, 90, 65, 85, 72],
})
for seed in range(3):
    bolik = df.sample(frac=0.75, random_state=seed)
    print(seed, bolik.groupby("sport")["ball"].mean().round(1).to_dict())
```

Егер айырманың таңбасы іріктемеден іріктемеге өзгерсе, қорытынды сенімсіз.

## Ескерту

- `Path(__file__)` тек `.py` файлында жұмыс істейді; Jupyter Notebook-та `__file__` айнымалысы жоқ, онда `Path.cwd()` қолданылады.
- `pathlib` қажетті бөлгішті (`/` немесе `\`) өзі қояды, сондықтан бір код Windows, macOS және Linux жүйелерінде жұмыс істейді.
- `pip freeze` ортадағы **барлық** пакеттерді жазады; тізім қысқа әрі нақты болуы үшін әр жобаға жеке виртуалды орта ұстаңыз (`python -m venv .venv`).
- `random_state` берілмесе, `df.sample()` әр жолы әртүрлі жолдарды қайтарады; қайталанатын нәтиже үшін `random_state` әрдайым көрсетіңіз.
- Құжаттама: [pathlib](https://docs.python.org/3/library/pathlib.html), [venv](https://docs.python.org/3/library/venv.html).
