### Вариант 1

**Теория — образцы ответов:**
1. `NaN` — обозначение отсутствующего (пустого) значения; `NaN == NaN` всегда `False`, поэтому используется `isna()`.
2. `dropna()` удаляет строки/столбцы с пропусками; `fillna()` заполняет пустое место заданным значением.
3. Разделение (split), вычисление (apply), объединение (combine).
4. Столбчатая — категории, между столбцами промежутки; гистограмма — распределение по числовым интервалам, столбцы соприкасаются.
5. Круговая; частей должно быть не больше 5–6 / трудно точно сравнивать углы.

**Практика:**
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("asxana.csv")
print("Пропуски:", df.isna().sum().sum())
print("Дубликаты:", df.duplicated().sum())

# 1. Очистка
df = df.drop_duplicates()
df["tagam"] = df["tagam"].str.strip().str.capitalize()
df["baga"] = df["baga"].fillna(df.groupby("tagam")["baga"].transform("median"))
df = df[df["sany"] > 0].copy()
print("После очистки:", len(df), "строк")

# 2. Анализ
df["tusim"] = df["baga"] * df["sany"]
tagam = df.groupby("tagam").agg(dana=("sany", "sum"), tusim=("tusim", "sum"))
tagam = tagam.sort_values("tusim", ascending=False)
print(tagam)
kun = df.groupby("kun", sort=False)["tusim"].sum()
zhalpy = df["tusim"].sum()
print("Общая выручка:", int(zhalpy), "тенге")
print("Самый доходный день:", kun.idxmax())

# 3. Визуализация
fig, ax = plt.subplots(1, 2, figsize=(12, 4.5))
b = ax[0].bar(tagam.index, tagam["tusim"] / 1000, color="#2A9D8F")
ax[0].bar_label(b, fmt="%.1f")
ax[0].set_ylim(0, 140)
ax[0].set_title("Выручка по блюдам")
ax[0].set_xlabel("Блюдо")
ax[0].set_ylabel("Выручка, тыс. тенге")
ax[1].plot(kun.index, kun.values / 1000, marker="o", color="#E76F51")
ax[1].set_title("Выручка по дням недели")
ax[1].set_xlabel("День")
ax[1].set_ylabel("Выручка, тыс. тенге")
plt.tight_layout()
fig.savefig("asxana.png", dpi=150)
plt.show()

# 4. Вывод
print(f"За неделю столовая получила {int(zhalpy)} тенге выручки.")
print(f"Больше всего дохода принесло блюдо {tagam.index[0]} ({int(tagam['tusim'].iloc[0])} тенге), "
      f"а лидер по количеству штук — {tagam['dana'].idxmax()}.")
print(f"Самый доходный день — {kun.idxmax()}, поэтому в этот день рекомендуется готовить больше продукции.")
```

### Вариант 2

**Теория — образцы ответов:**
1. Вывод, сделанный по грязным данным, будет ошибочным; «мусор на входе — мусор на выходе».
2. Указывает, какую копию оставить: `"first"`, `"last"` или `False` (удалить все).
3. Сколько раз встречается каждое значение (группа); `value_counts` сортирует по убыванию.
4. Связь между двумя числовыми величинами; −0,9 — сильная отрицательная связь (если одна растёт, другая уменьшается).
5. `show()` очищает фигуру после закрытия окна, поэтому сохранённый после этого рисунок будет пустым.

**Практика:**
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitaphana.csv")
print("Пропуски:", df.isna().sum().sum())
print("Дубликаты:", df.duplicated().sum())

# 1. Очистка
df = df.drop_duplicates()
df["zhanr"] = df["zhanr"].str.strip().str.capitalize()
df = df.dropna(subset=["kitap_sany"])
df = df[df["kitap_sany"] <= 100].copy()
print("После очистки:", len(df), "строк")

# 2. Анализ
zhanr = df.groupby("zhanr")["kitap_sany"].agg(["sum", "mean"]).round(1)
zhanr = zhanr.sort_values("sum", ascending=False)
print(zhanr)
ai = df.groupby("ai", sort=False)["kitap_sany"].sum()
print(ai)
print("Самый активный месяц:", ai.idxmax())

# 3. Визуализация
fig, ax = plt.subplots(1, 2, figsize=(12, 4.5))
ax[0].pie(zhanr["sum"], labels=zhanr.index, autopct="%1.1f%%", startangle=90)
ax[0].set_title("Доли жанров")
b = ax[1].bar(ai.index, ai.values, color="#264653")
ax[1].bar_label(b, fmt="%.0f")
ax[1].set_title("Выданные книги по месяцам")
ax[1].set_xlabel("Месяц")
ax[1].set_ylabel("Количество книг, шт.")
plt.tight_layout()
fig.savefig("kitaphana.png", dpi=150)
plt.show()

# 4. Вывод
zhalpy = int(df["kitap_sany"].sum())
print(f"За четыре месяца библиотека выдала {zhalpy} книг.")
print(f"Самый востребованный жанр — {zhanr.index[0]} ({int(zhanr['sum'].iloc[0])} книг, "
      f"{zhanr['sum'].iloc[0] / zhalpy * 100:.0f}%).")
print(f"Самый активный месяц — {ai.idxmax()}, самый низкий — {ai.idxmin()}.")
```
Ожидаемые результаты: пропусков — 1, дубликатов — 1; после очистки 11 строк (удаляются дубликат, пропуск и строка «Фантастика» с 300 книгами). Сказки — 117 (в среднем 29,2), Научные — 62 (15,5), История — 55 (18,3). По месяцам: Сен 61, Окт 62, Ноя 44, Дек 67; самый активный — Дек. Всего 234 книги; доля сказок ≈ 50%.
