## 1. Шпаргалка: NumPy, Pandas, Matplotlib

### NumPy

```python
import numpy as np

a = np.array([3, 7, 1, 9, 4])
print(a * 2)                   # операция над каждым элементом (векторная)
print(a.mean(), a.max(), a.sum())
print(a[a > 3])                # булев фильтр
print(np.arange(0, 10, 2))     # 0 2 4 6 8
```

Результат:
```text
[ 6 14  2 18  8]
4.8 9 24
[7 9 4]
[0 2 4 6 8]
```

### Pandas — основные универсальные команды

| Задача | Код |
|---|---|
| Чтение / сохранение | `pd.read_csv("f.csv")`, `df.to_csv("f.csv", index=False)` |
| Просмотр | `df.head()`, `df.shape`, `df.info()`, `df.describe()`, `df.dtypes` |
| Выбор | `df["a"]`, `df[["a", "b"]]`, `df.loc[условие, "a"]`, `df.iloc[0:5]` |
| Фильтрация | `df[(df["a"] > 5) & (df["b"] == "X")]`, `df[df["c"].isin([...])]` |
| Сортировка | `df.sort_values("a", ascending=False)` |
| Новый столбец | `df["c"] = df["a"] * df["b"]` |
| Пропуски | `isna().sum()`, `dropna(subset=[...])`, `fillna(значение)` |
| Дубликаты | `duplicated().sum()`, `drop_duplicates()` |
| Текст | `df["a"].str.strip().str.capitalize()` |
| Тип | `pd.to_numeric(df["a"], errors="coerce")`, `astype(int)` |
| Группировка | `df.groupby("a")["b"].mean()`, `.agg(at=("b", "sum"))` |
| Подсчёт | `df["a"].value_counts()` |
| Сводная таблица | `pd.pivot_table(df, values=, index=, columns=, aggfunc=)` |
| Корреляция | `df["a"].corr(df["b"])` |

## 2. Проект, который запускается на любом компьютере

Аналитический проект должен воспроизводиться: другой человек клонирует репозиторий, устанавливает зависимости и получает те же таблицы и графики.

```text
taldau-zhobasy/
├── data/
│   ├── raw.csv          ← исходные данные (только чтение)
│   └── clean.csv        ← создаётся программой
├── images/              ← создаётся программой
├── analysis.py
├── requirements.txt     ← pandas, matplotlib, numpy
└── README.md
```

Пути строим относительно файла программы с помощью `pathlib` — тогда код работает независимо от того, из какой папки его запустили:

```python
from pathlib import Path

import pandas as pd

BASE = Path(__file__).resolve().parent
DATA = BASE / "data"
IMAGES = BASE / "images"


def main():
    IMAGES.mkdir(exist_ok=True)                  # создать папку, если её нет
    df = pd.read_csv(DATA / "raw.csv")
    df = df.drop_duplicates()
    df.to_csv(DATA / "clean.csv", index=False)


if __name__ == "__main__":
    main()
```

Зависимости фиксируются командой `pip freeze > requirements.txt` и устанавливаются командой `pip install -r requirements.txt`.

## 3. Обоснование решений в анализе данных

Каждое техническое решение в проекте должно иметь объяснение:

| Решение | Обоснование |
|---|---|
| Пропуски заполнены медианой, а не средним | Медиана устойчива к выбросам; среднее «тянут» аномальные значения |
| Строки с пропусками не удалены | `dropna()` удалил бы большую долю данных; сначала `isna().sum()` |
| Столбчатая диаграмма вместо круговой | Длины столбцов сравниваются точнее, чем углы секторов |
| Ось Y столбцов начинается с 0 | Иначе разница между столбцами визуально преувеличивается |
| Рядом со средним показан `count` | Среднее по группе из 2–3 записей ненадёжно |
| Вывод сформулирован как связь, а не причина | Корреляция не доказывает причинно-следственную связь |

Проверить устойчивость вывода можно так: повторить расчёт на части данных (`df.sample(frac=0.5, random_state=1)`) и посмотреть, сохранится ли разница между группами.

```python
import pandas as pd

df = pd.DataFrame({
    "sport": ["да", "нет", "да", "нет", "да", "нет", "да", "нет"],
    "ball": [82, 70, 78, 74, 90, 65, 85, 72],
})
for seed in range(3):
    bolik = df.sample(frac=0.75, random_state=seed)
    print(seed, bolik.groupby("sport")["ball"].mean().round(1).to_dict())
```

Если знак разницы меняется от выборки к выборке, вывод ненадёжен.

## Частые ошибки

**1. Абсолютный путь к файлу.** Путь `C:/Users/...` отсутствует на другом компьютере. Используйте относительный путь или `pathlib`:
```python
df = pd.read_csv("C:/Users/Erlan/Desktop/data.csv")   # на другом компьютере FileNotFoundError
```
Правильно:
```python
df = pd.read_csv("data/raw.csv")
```

**2. У графиков только стандартное название «Figure 1».** У каждого графика должен быть заголовок и подписи осей.

**3. Вывод без чисел: «Данные были интересными».** Это не вывод. Вывод формулируется через числа: «на 10 баллов ниже», «r = −0,49».

**4. Нет `requirements.txt`.** Без него неизвестно, какие библиотеки и версии нужны для запуска.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Воспроизводимость | Возможность получить те же результаты, запустив код на тех же данных |
| Относительный путь | Путь к файлу относительно папки проекта (`data/raw.csv`) |
| `pathlib.Path` | Объект пути в Python; пути соединяются оператором `/` |
| `requirements.txt` | Список зависимостей проекта для `pip install -r` |
| Выборка (`sample`) | Случайная часть строк таблицы |
| Векторная операция | Операция NumPy/Pandas сразу над всем массивом без цикла |

## Примечание

- `Path(__file__)` работает только в файле `.py`; в Jupyter Notebook переменной `__file__` нет, там используют `Path.cwd()`.
- `pathlib` сам подставляет нужный разделитель (`/` или `\`), поэтому один и тот же код работает в Windows, macOS и Linux.
- `pip freeze` записывает **все** пакеты окружения; держите для каждого проекта отдельное виртуальное окружение (`python -m venv .venv`), чтобы список был коротким и точным.
- `df.sample()` без `random_state` каждый раз возвращает разные строки; для воспроизводимых результатов всегда задавайте `random_state`.
- Документация: [pathlib](https://docs.python.org/3/library/pathlib.html), [venv](https://docs.python.org/3/library/venv.html).
