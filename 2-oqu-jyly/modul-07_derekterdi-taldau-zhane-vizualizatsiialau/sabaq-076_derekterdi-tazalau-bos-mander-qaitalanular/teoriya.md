## 1. Деректерді талдау циклі және тазалаудың орны

Деректерді талдау бірнеше кезеңнен тұрады:

```text
Деректерді жинау → Оқу (read_csv) → ТАЗАЛАУ → Талдау (groupby) → Визуализация → Қорытынды
                                       ↑
                               осы тақырыптың кезеңі
```

Тазалау — тамақ дайындау алдында көкөністі жуып, шірігенін алып тастағанмен бірдей. Оны өткізіп жіберсеңіз, тамақ қаншалықты шебер пісірілсе де, бүлінеді.

**Лас деректердің негізгі түрлері:**

| Түрі | Мысал | Неге пайда болады |
|---|---|---|
| Бос мән (пропуск, missing value) | Жасы жазылмаған | Сауалнамада жауап бермеген, датчик істемей қалған |
| Қайталану (дубликат, duplicate) | Бір оқушы екі рет | Форманы екі рет жіберген, файлдарды біріктіргенде |
| Формат сәйкессіздігі | `"Алматы"`, `"алматы "`, `"АЛМАТЫ"` | Қолмен енгізу, артық бос орын |
| Қате тип | Сан орнына `"он алты"` мәтіні | Пайдаланушы мәтін жазған |
| Мүмкін емес мән (аномалия, выброс) | Жасы 170, баға −5 | Қате басылған перне, бірлік шатасқан |

## 2. «Лас» кесте мысалы

Төмендегі барлық мысалдар бір кестені пайдаланады:

```python
import pandas as pd

data = {
    "aty": ["Әлия", "Нұрлан", "Дана", "Нұрлан", "Ерлан", "Аружан", None],
    "synyp": [9, 10, 9, 10, 11, 9, 10],
    "zhasy": [15, 16, None, 16, 170, 15, 16],
    "qala": ["Алматы", "алматы ", "Астана", "алматы ", "Шымкент", None, "Астана"],
    "ball": [87, 92, 78, 92, -5, 95, 81],
}
df = pd.DataFrame(data)
print(df)
```

Нәтижесі:
```text
      aty  synyp  zhasy     qala  ball
0    Әлия      9   15.0   Алматы    87
1  Нұрлан     10   16.0  алматы     92
2    Дана      9    NaN   Астана    78
3  Нұрлан     10   16.0  алматы     92
4   Ерлан     11  170.0  Шымкент    -5
5  Аружан      9   15.0      NaN    95
6     NaN     10   16.0   Астана    81
```

Байқаңыз: Pandas бос мәнді **`NaN`** (Not a Number — «сан емес») деп көрсетеді. Бос мән бар бағанның сандары `float` типіне (15.0) айналады — себебі `NaN` өзі бөлшек сан типіне жатады.

## 3. Бос мәндер (NaN)

### 3.1. Бос мәндерді табу

| Әдіс | Не қайтарады |
|---|---|
| `df.isna()` | Әр ұяшық үшін `True` (бос) / `False` |
| `df.isna().sum()` | Әр бағандағы бос мәндер саны |
| `df.isna().sum().sum()` | Бүкіл кестедегі бос мәндер саны |
| `df.notna()` | Керісінше: толтырылған ұяшықтар |
| `df[df["zhasy"].isna()]` | Жасы бос жолдарды ғана көрсету |

```python
print(df.isna().sum())
print("Барлығы:", df.isna().sum().sum())
```

Нәтижесі:
```text
aty      1
synyp    0
zhasy    1
qala     1
ball     0
dtype: int64
Барлығы: 3
```

`isnull()` — `isna()` әдісінің екінші атауы, екеуі бірдей жұмыс істейді.

### 3.2. Бос мәні бар жолдарды жою — `dropna()`

```python
df.dropna()                     # кемінде бір бос мәні бар БАРЛЫҚ жолды жояды
df.dropna(subset=["aty"])       # тек "aty" бағаны бос болса жояды
df.dropna(axis=1)               # бос мәні бар БАҒАНДАРДЫ жояды
df.dropna(thresh=4)             # кемінде 4 толтырылған ұяшығы бар жолдарды қалдырады
```

**Абай болыңыз!** `dropna()` деректі жоғалтады. 1000 жолдың 300-інде бір ғана баған бос болса, `dropna()` кестенің үштен бірін жойып жібереді. Сондықтан алдымен `isna().sum()` арқылы санап, содан кейін шешім қабылдаймыз.

### 3.3. Бос мәндерді толтыру — `fillna()`

Жолды жою орнына бос орынды «ақылға қонымды» мәнмен толтыруға болады:

| Деректің түрі | Немен толтырған дұрыс | Код |
|---|---|---|
| Сан, аномалиясы бар | Медиана (ортаңғы мән) | `df["zhasy"].fillna(df["zhasy"].median())` |
| Сан, біркелкі | Орташа мән | `df["ball"].fillna(df["ball"].mean())` |
| Санат (қала, жыныс) | Ең жиі мән немесе «Белгісіз» | `df["qala"].fillna("Белгісіз")` |
| Уақыт қатары | Алдыңғы мән | `df["temp"].ffill()` |

**Неге медиана?** Жастар: 15, 16, 16, 15, 170. Орташа мәні — 46,4 (170 «тартып» кетті). Медианасы — 16. Медиана аномалияларға сезімтал емес.

```python
df["zhasy"] = df["zhasy"].fillna(df["zhasy"].median())
df["qala"] = df["qala"].fillna("Белгісіз")
```

> Ескерту: ескі кітаптарда `df["zhasy"].fillna(..., inplace=True)` жазылады. Pandas-тың жаңа нұсқаларында бұл ескерту береді, сондықтан нәтижені әрдайым қайта меншіктейміз: `df["zhasy"] = df["zhasy"].fillna(...)`.

## 4. Қайталанатын жазбалар (дубликаттар)

```python
print(df.duplicated())          # әр жол бұрын кездескен бе?
print(df.duplicated().sum())    # қайталану саны
```

Нәтижесі:
```text
0    False
1    False
2    False
3     True
4    False
5    False
6    False
dtype: bool
1
```

3-жол 1-жолдың дәл көшірмесі. Жою:

```python
df = df.drop_duplicates()                          # толық бірдей жолдарды жою
df = df.drop_duplicates(subset=["aty", "synyp"])   # тек аты мен сыныбы бірдей болса
df = df.drop_duplicates(keep="last")               # соңғы көшірмені қалдыру
```

`keep` параметрі: `"first"` (әдепкі, біріншісі қалады), `"last"` (соңғысы қалады), `False` (барлық көшірмелер жойылады).

**Маңызды:** «Алматы» мен «алматы » Pandas үшін — **әртүрлі** мәтін. Сондықтан дубликаттарды іздемес бұрын мәтінді біркелкі түрге келтірген дұрыс (5-бөлім).

## 5. Қате жазбаларды түзету

### 5.1. Мәтінді біркелкі ету — `.str` әдістері

```python
df["qala"] = df["qala"].str.strip()        # басы-соңындағы бос орындарды алу
df["qala"] = df["qala"].str.capitalize()   # "алматы" → "Алматы"
# тізбектеп те жазуға болады:
df["qala"] = df["qala"].str.strip().str.capitalize()
```

Басқа пайдалы әдістер: `.str.lower()`, `.str.upper()`, `.str.title()`, `.str.replace("ё", "е")`.

### 5.2. Мәндерді ауыстыру — `replace()`

Бір мағына әртүрлі жазылса:

```python
import pandas as pd

d = pd.DataFrame({"jynys": ["ер", "Ер", "ұл", "қыз", "Қ"]})
d["jynys"] = d["jynys"].str.lower().replace({"ұл": "ер", "қ": "қыз"})
print(d["jynys"].value_counts())
```

Нәтижесі:
```text
jynys
ер     3
қыз    2
Name: count, dtype: int64
```

### 5.3. Типті түзету — `pd.to_numeric()` және `astype()`

CSV-ден оқылған сан кейде мәтін (`object`) болып қалады, себебі бағанда бір ғана «он алты» деген жазба бар. `errors="coerce"` түрлендіруге келмейтін мәндерді `NaN`-ға айналдырады:

```python
import pandas as pd

s = pd.Series(["15", "16", "он алты", "", "14"])
print(pd.to_numeric(s, errors="coerce"))
```

Нәтижесі:
```text
0    15.0
1    16.0
2     NaN
3     NaN
4    14.0
dtype: float64
```

Енді бұл `NaN`-дарды 3-бөлімдегідей өңдейміз. Бос мәні жоқ бағанды бүтін санға келтіру: `df["zhasy"] = df["zhasy"].astype(int)`.

### 5.4. Логикалық тексеру (мүмкін емес мәндер)

Әр бағанға «ақылға қонымды шекара» қоямыз: балл 0..100, оқушы жасы 10..18, баға теріс болмайды.

```python
qate = df[(df["ball"] < 0) | (df["ball"] > 100)]
print("Қате баллдар:\n", qate)

df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]   # тек дұрыс жолдар қалады
```

Қате мәнді әрдайым жою міндетті емес: кейде оны `NaN`-ға ауыстырып, содан кейін толтырамыз:

```python
df.loc[df["zhasy"] > 18, "zhasy"] = None
```

## 6. Толық тазалау мысалы

```python
import pandas as pd

data = {
    "aty": ["Әлия", "Нұрлан", "Дана", "Нұрлан", "Ерлан", "Аружан", None],
    "synyp": [9, 10, 9, 10, 11, 9, 10],
    "zhasy": [15, 16, None, 16, 170, 15, 16],
    "qala": ["Алматы", "алматы ", "Астана", "алматы ", "Шымкент", None, "Астана"],
    "ball": [87, 92, 78, 92, -5, 95, 81],
}
df = pd.DataFrame(data)
print("Бастапқы жол саны:", len(df))

df = df.drop_duplicates()                                  # 1. дубликаттар
df = df.dropna(subset=["aty"])                             # 2. аты жоқ жазба мағынасыз
df["zhasy"] = df["zhasy"].fillna(df["zhasy"].median())    # 3. жасты толтыру
df["qala"] = df["qala"].fillna("Белгісіз")                 # 4. қаланы толтыру
df["qala"] = df["qala"].str.strip().str.capitalize()       # 5. мәтінді біркелкі ету
df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]           # 6. қате баллды алып тастау

print("Тазаланған жол саны:", len(df))
print(df)
```

Нәтижесі:
```text
Бастапқы жол саны: 7
Тазаланған жол саны: 4
      aty  synyp  zhasy      qala  ball
0    Әлия      9   15.0    Алматы    87
1  Нұрлан     10   16.0    Алматы    92
2    Дана      9   15.5    Астана    78
5  Аружан      9   15.0  Белгісіз    95
```

Индекстер (0, 1, 2, 5) «тесік» болып қалды. Қайта нөмірлеу үшін: `df = df.reset_index(drop=True)`. Тазаланған деректі сақтау: `df.to_csv("oqushylar_taza.csv", index=False)`.

## 7. Тазалау чек-парағы

1. `df.shape`, `df.info()`, `df.head()` — деректі «көзбен» қарау.
2. `df.isna().sum()` — бос мәндерді санау → жою немесе толтыру шешімі.
3. Мәтін бағандарын `str.strip()`, `str.lower()/capitalize()` арқылы біркелкі ету.
4. `df.duplicated().sum()` → `drop_duplicates()`.
5. Типтерді тексеру: `df.dtypes` → `pd.to_numeric(..., errors="coerce")`.
6. `df.describe()` арқылы min/max қарау → мүмкін емес мәндерді сүзу.
7. Әр қадамнан кейін жол санын тексеру (`len(df)`) және тазаланған файлды **жаңа атпен** сақтау (бастапқы файлды ешқашан бүлдірмеу!).

## Жиі кездесетін қателер

**1. Нәтижені меншіктемеу.**
```python
df.drop_duplicates()     # кесте өзгермейді! Әдіс жаңа кесте қайтарады
```
Дұрысы:
```python
df = df.drop_duplicates()
```

**2. `NaN`-ды `==` арқылы тексеру.** `NaN == NaN` әрдайым `False`.
```python
bos = df[df["zhasy"] == None]    # бос кесте шығады
```
Дұрысы:
```python
bos = df[df["zhasy"].isna()]
```

**3. Шарттарды `and`/`or` арқылы біріктіру.** Pandas-та `&`, `|` және жақша қажет.
```python
df = df[df["ball"] >= 0 and df["ball"] <= 100]    # ValueError
```
Дұрысы:
```python
df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]
```

**4. Ойланбай `dropna()` шақыру** — деректің жартысын жоғалтуға болады. Алдымен санаңыз.

**5. Орташа мәнмен толтыру аномалия алынбай тұрып** — орташа мән бұрмаланады. Не алдымен аномалияны алыңыз, не медиананы қолданыңыз.

| Ұғым | Түсіндірме |
|---|---|
| Деректерді тазалау (data cleaning) | Талдау алдында қате, бос, қайталанған жазбаларды түзету |

| `isna()` / `dropna()` / `fillna()` | Бос мәнді табу / жою / толтыру |
| Медиана | Сұрыпталған мәндердің ортасындағысы; аномалияға төзімді |

| `pd.to_numeric(errors="coerce")` | Мәтінді санға түрлендіру, болмаса `NaN` |

## Ескерту

- `NaN` — `float` типті мән, сондықтан бос мәні бар бүтін сан бағаны `float64`-ке айналады. Бүтін сандарды бос мәндермен бірге сақтау керек болса, `"Int64"` типін (бас әріппен) қолданыңыз: `df["zhasy"].astype("Int64")`, бос мән `<NA>` болып көрсетіледі.
- `pd.read_csv()` ішінде қандай жолдарды бос мән деп санауды бірден көрсетуге болады: `pd.read_csv("f.csv", na_values=["-", "жоқ", "?"])`.
- Pandas 2.x нұсқасында `fillna(method="ffill")` және жеке бағанға `inplace=True` ескірген: `df["x"] = df["x"].ffill()` және `df["x"] = df["x"].fillna(...)` деп жазыңыз.
- Сүзгілеу кезінде кестенің «кесіндісі» алынады; кейін өзгерткенде `SettingWithCopyWarning` ескертуі шықпауы үшін көшірме жасаңыз: `df = df[шарт].copy()`.
- `df.duplicated()` мәндерді таңбалап салыстырады: регистр мен бос орындар маңызды, сондықтан дубликат іздеуден бұрын мәтінді біркелкі етіңіз.
- Құжаттама: [Working with missing data](https://pandas.pydata.org/docs/user_guide/missing_data.html) және [drop_duplicates](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.drop_duplicates.html).
