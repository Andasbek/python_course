## 1. Цикл анализа данных и место очистки

Анализ данных состоит из нескольких этапов:

```text
Сбор данных → Чтение (read_csv) → ОЧИСТКА → Анализ (groupby) → Визуализация → Выводы
                                     ↑
                                 этап этой темы
```

Очистка — то же самое, что вымыть овощи и убрать испорченные перед приготовлением еды. Если пропустить этот шаг, блюдо будет испорчено, как бы искусно его ни приготовили.

**Основные виды грязных данных:**

| Вид | Пример | Почему возникает |
|---|---|---|
| Пропущенное значение (пропуск, missing value) | Не указан возраст | Не ответили в анкете, датчик не сработал |
| Повтор (дубликат, duplicate) | Один ученик записан дважды | Форму отправили дважды, при объединении файлов |
| Несоответствие формата | `"Алматы"`, `"алматы "`, `"АЛМАТЫ"` | Ручной ввод, лишние пробелы |
| Неверный тип | Текст `"шестнадцать"` вместо числа | Пользователь написал текстом |
| Невозможное значение (аномалия, выброс) | Возраст 170, оценка −5 | Нажата не та клавиша, перепутаны единицы измерения |

## 2. Пример «грязной» таблицы

Все примеры ниже используют одну таблицу:

```python
import pandas as pd

data = {
    "aty": ["Әлия", "Нұрлан", "Дана", "Нұрлан", "Ерлан", "Аружан", None],
    "synyp": [9, 10, 9, 10, 11, 9, 10],
    "zhasy": [15, 16, None, 16, 170, 15, 16],
    "qala": ["Алматы", "алматы ", "Астана", "алматы ", "Шымкент", None, "Астана"],
    "ball": [87, 92, 78, 92, -5, 95, 81],
}
df = pd.DataFrame(data)
print(df)
```

Результат:
```text
      aty  synyp  zhasy     qala  ball
0    Әлия      9   15.0   Алматы    87
1  Нұрлан     10   16.0  алматы     92
2    Дана      9    NaN   Астана    78
3  Нұрлан     10   16.0  алматы     92
4   Ерлан     11  170.0  Шымкент    -5
5  Аружан      9   15.0      NaN    95
6     NaN     10   16.0   Астана    81
```

Обратите внимание: Pandas обозначает пропущенное значение как **`NaN`** (Not a Number — «не число»). Числа в столбце с пропуском превращаются в тип `float` (15.0) — потому что сам `NaN` относится к типу дробных чисел.

## 3. Пропущенные значения (NaN)

### 3.1. Поиск пропущенных значений

| Метод | Что возвращает |
|---|---|
| `df.isna()` | Для каждой ячейки `True` (пусто) / `False` |
| `df.isna().sum()` | Количество пропусков в каждом столбце |
| `df.isna().sum().sum()` | Количество пропусков во всей таблице |
| `df.notna()` | Наоборот: заполненные ячейки |
| `df[df["zhasy"].isna()]` | Показать только строки с пустым возрастом |

```python
print(df.isna().sum())
print("Всего:", df.isna().sum().sum())
```

Результат:
```text
aty      1
synyp    0
zhasy    1
qala     1
ball     0
dtype: int64
Всего: 3
```

`isnull()` — второе название метода `isna()`, оба работают одинаково.

### 3.2. Удаление строк с пропусками — `dropna()`

```python
df.dropna()                     # удаляет ВСЕ строки, где есть хотя бы один пропуск
df.dropna(subset=["aty"])       # удаляет, только если пуст столбец "aty"
df.dropna(axis=1)               # удаляет СТОЛБЦЫ, в которых есть пропуски
df.dropna(thresh=4)             # оставляет строки, где заполнено не меньше 4 ячеек
```

**Будьте осторожны!** `dropna()` приводит к потере данных. Если из 1000 строк в 300 пуст всего один столбец, `dropna()` удалит треть таблицы. Поэтому сначала считаем с помощью `isna().sum()`, а затем принимаем решение.

### 3.3. Заполнение пропусков — `fillna()`

Вместо удаления строки можно заполнить пустое место «разумным» значением:

| Тип данных | Чем лучше заполнить | Код |
|---|---|---|
| Число, есть аномалии | Медианой (срединным значением) | `df["zhasy"].fillna(df["zhasy"].median())` |
| Число, однородное | Средним значением | `df["ball"].fillna(df["ball"].mean())` |
| Категория (город, пол) | Самым частым значением или «Неизвестно» | `df["qala"].fillna("Неизвестно")` |
| Временной ряд | Предыдущим значением | `df["temp"].ffill()` |

**Почему медиана?** Возрасты: 15, 16, 16, 15, 170. Среднее — 46,4 (170 «потянуло» его вверх). Медиана — 16. Медиана нечувствительна к аномалиям.

```python
df["zhasy"] = df["zhasy"].fillna(df["zhasy"].median())
df["qala"] = df["qala"].fillna("Неизвестно")
```

> Примечание: в старых книгах пишут `df["zhasy"].fillna(..., inplace=True)`. В новых версиях Pandas это вызывает предупреждение, поэтому результат всегда присваиваем заново: `df["zhasy"] = df["zhasy"].fillna(...)`.

## 4. Повторяющиеся записи (дубликаты)

```python
print(df.duplicated())          # встречалась ли каждая строка раньше?
print(df.duplicated().sum())    # количество повторов
```

Результат:
```text
0    False
1    False
2    False
3     True
4    False
5    False
6    False
dtype: bool
1
```

Строка 3 — точная копия строки 1. Удаление:

```python
df = df.drop_duplicates()                          # удалить полностью одинаковые строки
df = df.drop_duplicates(subset=["aty", "synyp"])   # только если совпадают имя и класс
df = df.drop_duplicates(keep="last")               # оставить последнюю копию
```

Параметр `keep`: `"first"` (по умолчанию, остаётся первая), `"last"` (остаётся последняя), `False` (удаляются все копии).

**Важно:** «Алматы» и «алматы » для Pandas — **разные** строки. Поэтому перед поиском дубликатов лучше привести текст к единому виду (раздел 5).

## 5. Исправление ошибочных записей

### 5.1. Приведение текста к единому виду — методы `.str`

```python
df["qala"] = df["qala"].str.strip()        # убрать пробелы в начале и в конце
df["qala"] = df["qala"].str.capitalize()   # "алматы" → "Алматы"
# можно записать и цепочкой:
df["qala"] = df["qala"].str.strip().str.capitalize()
```

Другие полезные методы: `.str.lower()`, `.str.upper()`, `.str.title()`, `.str.replace("ё", "е")`.

### 5.2. Замена значений — `replace()`

Если одно и то же значение записано по-разному:

```python
import pandas as pd

d = pd.DataFrame({"jynys": ["муж", "Муж", "мальчик", "жен", "Ж"]})
d["jynys"] = d["jynys"].str.lower().replace({"мальчик": "муж", "ж": "жен"})
print(d["jynys"].value_counts())
```

Результат:
```text
jynys
муж    3
жен    2
Name: count, dtype: int64
```

### 5.3. Исправление типа — `pd.to_numeric()` и `astype()`

Число, прочитанное из CSV, иногда остаётся текстом (`object`), потому что в столбце есть хотя бы одна запись вроде «шестнадцать». `errors="coerce"` превращает значения, которые невозможно преобразовать, в `NaN`:

```python
import pandas as pd

s = pd.Series(["15", "16", "шестнадцать", "", "14"])
print(pd.to_numeric(s, errors="coerce"))
```

Результат:
```text
0    15.0
1    16.0
2     NaN
3     NaN
4    14.0
dtype: float64
```

Теперь эти `NaN` обрабатываем так же, как в разделе 3. Привести столбец без пропусков к целому типу: `df["zhasy"] = df["zhasy"].astype(int)`.

### 5.4. Логическая проверка (невозможные значения)

Для каждого столбца задаём «разумные границы»: балл 0..100, возраст ученика 10..18, оценка не бывает отрицательной.

```python
qate = df[(df["ball"] < 0) | (df["ball"] > 100)]
print("Ошибочные баллы:\n", qate)

df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]   # остаются только правильные строки
```

Ошибочное значение не всегда обязательно удалять: иногда его заменяют на `NaN`, а затем заполняют:

```python
df.loc[df["zhasy"] > 18, "zhasy"] = None
```

## 6. Полный пример очистки

```python
import pandas as pd

data = {
    "aty": ["Әлия", "Нұрлан", "Дана", "Нұрлан", "Ерлан", "Аружан", None],
    "synyp": [9, 10, 9, 10, 11, 9, 10],
    "zhasy": [15, 16, None, 16, 170, 15, 16],
    "qala": ["Алматы", "алматы ", "Астана", "алматы ", "Шымкент", None, "Астана"],
    "ball": [87, 92, 78, 92, -5, 95, 81],
}
df = pd.DataFrame(data)
print("Исходное число строк:", len(df))

df = df.drop_duplicates()                                  # 1. дубликаты
df = df.dropna(subset=["aty"])                             # 2. запись без имени бессмысленна
df["zhasy"] = df["zhasy"].fillna(df["zhasy"].median())    # 3. заполнить возраст
df["qala"] = df["qala"].fillna("Неизвестно")               # 4. заполнить город
df["qala"] = df["qala"].str.strip().str.capitalize()       # 5. привести текст к единому виду
df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]           # 6. убрать ошибочные баллы

print("Строк после очистки:", len(df))
print(df)
```

Результат:
```text
Исходное число строк: 7
Строк после очистки: 4
      aty  synyp  zhasy        qala  ball
0    Әлия      9   15.0      Алматы    87
1  Нұрлан     10   16.0      Алматы    92
2    Дана      9   15.5      Астана    78
5  Аружан      9   15.0  Неизвестно    95
```

Индексы (0, 1, 2, 5) остались «дырявыми». Чтобы перенумеровать: `df = df.reset_index(drop=True)`. Сохранить очищенные данные: `df.to_csv("oqushylar_taza.csv", index=False)`.

## 7. Чек-лист очистки

1. `df.shape`, `df.info()`, `df.head()` — посмотреть на данные «глазами».
2. `df.isna().sum()` — посчитать пропуски → решить: удалять или заполнять.
3. Привести текстовые столбцы к единому виду с помощью `str.strip()`, `str.lower()/capitalize()`.
4. `df.duplicated().sum()` → `drop_duplicates()`.
5. Проверить типы: `df.dtypes` → `pd.to_numeric(..., errors="coerce")`.
6. Посмотреть min/max через `df.describe()` → отфильтровать невозможные значения.
7. После каждого шага проверять количество строк (`len(df)`) и сохранять очищенный файл **под новым именем** (исходный файл никогда не портить!).

## Частые ошибки

**1. Результат не присвоен.**
```python
df.drop_duplicates()     # таблица не изменится! Метод возвращает новую таблицу
```
Правильно:
```python
df = df.drop_duplicates()
```

**2. Проверка `NaN` через `==`.** `NaN == NaN` всегда `False`.
```python
bos = df[df["zhasy"] == None]    # получится пустая таблица
```
Правильно:
```python
bos = df[df["zhasy"].isna()]
```

**3. Объединение условий через `and`/`or`.** В Pandas нужны `&`, `|` и скобки.
```python
df = df[df["ball"] >= 0 and df["ball"] <= 100]    # ValueError
```
Правильно:
```python
df = df[(df["ball"] >= 0) & (df["ball"] <= 100)]
```

**4. Вызов `dropna()` не подумав** — можно потерять половину данных. Сначала посчитайте.

**5. Заполнение средним значением до удаления аномалий** — среднее искажается. Либо сначала уберите аномалию, либо используйте медиану.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Очистка данных (data cleaning) | Исправление ошибочных, пустых, повторяющихся записей перед анализом |
| `NaN` | Обозначение пустого (отсутствующего) значения в Pandas |
| `isna()` / `dropna()` / `fillna()` | Найти / удалить / заполнить пропуски |
| Медиана | Значение в середине отсортированного ряда; устойчива к аномалиям |
| Дубликат | Повторяющаяся запись в таблице |
| `drop_duplicates()` | Удаление дубликатов |
| Аномалия (выброс, outlier) | Значение, резко отличающееся от остальных, часто ошибочное |
| `pd.to_numeric(errors="coerce")` | Преобразование текста в число, иначе `NaN` |

## Примечание

- `NaN` — значение типа `float`, поэтому целочисленный столбец с пропуском становится `float64`. Если нужно хранить целые числа вместе с пропусками, используйте тип `"Int64"` (с заглавной буквы): `df["zhasy"].astype("Int64")`, пропуск будет показан как `<NA>`.
- В `pd.read_csv()` можно сразу указать, какие строки считать пропуском: `pd.read_csv("f.csv", na_values=["-", "нет", "?"])`.
- Методы `fillna(method="ffill")` и `inplace=True` для отдельного столбца в Pandas 2.x устарели: пишите `df["x"] = df["x"].ffill()` и `df["x"] = df["x"].fillna(...)`.
- При фильтрации получается «срез» таблицы; чтобы избежать предупреждения `SettingWithCopyWarning` при последующем изменении, делайте копию: `df = df[условие].copy()`.
- `df.duplicated()` сравнивает значения посимвольно: регистр и пробелы важны, поэтому нормализуйте текст до поиска дубликатов.
- Документация: [Working with missing data](https://pandas.pydata.org/docs/user_guide/missing_data.html) и [drop_duplicates](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.drop_duplicates.html).
