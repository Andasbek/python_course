**Задания 5–7 (полная очистка)**
```python
import pandas as pd

df = pd.read_csv("dukenn_satylym.csv")
bastapqy = len(df)

# дубликаты
dup = df.duplicated().sum()
df = df.drop_duplicates()

# записи без названия товара — бессмысленны
atau_zhoq = df["tauar"].isna().sum()
df = df.dropna(subset=["tauar"])

# приведение текста к единому виду
for col in ["tauar", "sanat", "qala"]:
    df[col] = df[col].str.strip().str.capitalize()
df["qala"] = df["qala"].fillna("Неизвестно")

# типы
df["baga"] = pd.to_numeric(df["baga"], errors="coerce")
df["sany"] = pd.to_numeric(df["sany"], errors="coerce")

# ошибочное количество: пусто или отрицательное
qate_sany = df["sany"].isna() | (df["sany"] <= 0)
# ошибочная цена: слишком дорого
qate_baga = df["baga"] > 10000
qate = (qate_sany | qate_baga).sum()
df = df[~(qate_sany | qate_baga)]

# заполнить пустую цену медианой цены этого же товара
df["baga"] = df["baga"].fillna(df.groupby("tauar")["baga"].transform("median"))
df["sany"] = df["sany"].astype(int)

print("=== Отчёт об очистке ===")
print("Исходных записей:", bastapqy)
print("Удалено дубликатов:", dup)
print("Записей без названия товара:", atau_zhoq)
print("Записей с ошибочным количеством/ценой:", qate)
print("Осталось записей:", len(df))

df["tusim"] = df["baga"] * df["sany"]
print(df)
print("Общая выручка:", int(df["tusim"].sum()), "тенге")
df.to_csv("dukenn_taza.csv", index=False)
```
Ответ: ошибочные записи — «Яблоки» (−3), «Тетрадь» («два»), «Шоколад» (45000). Цена «Ручки» заполняется ценой из другой строки «Ручка» (120). Осталось 7 записей; общая выручка: 1000 + 960 + 1500 + 1000 + 600 + 480 + 360 = 5900 тенге.

**Задание 8**
```python
import pandas as pd


def clean_report(df):
    """Возвращает отчёт о качестве данных по каждому столбцу."""
    rows = []
    for col in df.columns:
        s = df[col]
        row = {
            "bagana": col,
            "tipi": str(s.dtype),
            "bos": int(s.isna().sum()),
            "bos_%": round(s.isna().mean() * 100, 1),
            "biregei": s.nunique(),
        }
        if pd.api.types.is_numeric_dtype(s):
            row["min"] = s.min()
            row["max"] = s.max()
        rows.append(row)
    return pd.DataFrame(rows)


df = pd.read_csv("dukenn_satylym.csv")
print(clean_report(df))
```
