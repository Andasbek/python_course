## Базалық деңгей

**1-тапсырма. Деректермен танысу.**
`dukenn_satylym.csv` файлын оқып, мына ақпаратты шығарыңыз: жол және баған саны, алғашқы 5 жол, әр бағанның типі (`dtypes`).
Сұрақ: `baga` және `sany` бағандары неге сан емес, `object` (мәтін) болып тұр? Жауабын түсініктемеге жазыңыз.

**2-тапсырма. Бос мәндер есебі.**
Әр бағандағы бос мәндер санын және кестедегі барлық бос мәндер санын шығарыңыз. Содан кейін бос мәні бар жолдарды ғана көрсетіңіз.
Кеңес: `df[df.isna().any(axis=1)]`.

Күтілетін шығыс (үлгі):
```text
Бос мәндер:
kun      0
tauar    1
sanat    0
baga     1
sany     0
qala     1
Барлығы: 3
```

**3-тапсырма. Дубликаттар.**
Толық бірдей жолдар санын шығарып, оларды жойыңыз. Жоюға дейінгі және кейінгі жол санын көрсетіңіз.

**4-тапсырма. Мәтінді біркелкі ету.**
`sanat` және `qala` бағандарындағы артық бос орындарды алып, бірінші әрпін бас әріпке келтіріңіз. `value_counts()` арқылы нәтижені тексеріңіз: санаттар тек «Азық» және «Кеңсе» болуы керек.

## Кеңейтілген деңгей

**5-тапсырма. Типтерді түзету және логикалық тексеру.**
1. `baga` және `sany` бағандарын `pd.to_numeric(..., errors="coerce")` арқылы санға айналдырыңыз.
2. `sany` бос болса немесе 0-ден кіші болса — ол жолды жойыңыз.
3. `baga` бос болса — сол тауардың басқа жолдардағы бағасының медианасымен толтырыңыз (кеңес: қарапайым жолы — бүкіл бағанның медианасы; күрделі жолы — `groupby("tauar")["baga"].transform("median")`).
4. 10 000 теңгеден қымбат бағаны қате деп санап, оны шығарып тастаңыз.

**6-тапсырма. Тазалау есебі.**
Бағдарлама соңында тазалау туралы қысқаша есеп шығарсын:
```text
=== Тазалау есебі ===
Бастапқы жазбалар: 12
Жойылған дубликаттар: 1
Тауар атауы жоқ жазбалар: 1
Қате саны/бағасы бар жазбалар: 3
Қалған жазбалар: 7
```
Тазаланған деректерді `dukenn_taza.csv` файлына `index=False` арқылы сақтаңыз. Сандар сіздің шешіміңізге қарай сәл өзгеше болуы мүмкін — әр шешімді түсініктемеде негіздеңіз.

**7-тапсырма. Түсім бағаны.**
Тазаланған кестеге `tusim = baga * sany` бағанын қосып, жалпы түсімді теңгемен шығарыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

**8-тапсырма. Әмбебап тазалағыш функция.**
`clean_report(df)` функциясын жазыңыз: ол кез келген DataFrame үшін әр баған бойынша кесте қайтарсын — баған аты, типі, бос мәндер саны мен пайызы, бірегей мәндер саны, сандық бағандар үшін min және max. Кестені `dukenn_satylym.csv`-ге қолданып көріңіз.

**9-тапсырма. IQR әдісімен аномалия іздеу.**
Статистикада аномалия көбіне былай анықталады: Q1 = 25-перцентиль, Q3 = 75-перцентиль, IQR = Q3 − Q1; мән `Q1 − 1.5·IQR`-дан кіші немесе `Q3 + 1.5·IQR`-дан үлкен болса — аномалия. `baga` бағаны үшін осы шекараларды есептеп (`quantile()`), аномалияларды шығаратын бағдарлама жазыңыз.

**5–7-тапсырмалар (толық тазалау)**
```python
import pandas as pd

df = pd.read_csv("dukenn_satylym.csv")
bastapqy = len(df)

# дубликаттар
dup = df.duplicated().sum()
df = df.drop_duplicates()

# тауар атауы жоқ жазбалар — мағынасыз
atau_zhoq = df["tauar"].isna().sum()
df = df.dropna(subset=["tauar"])

# мәтінді біркелкі ету
for col in ["tauar", "sanat", "qala"]:
    df[col] = df[col].str.strip().str.capitalize()
df["qala"] = df["qala"].fillna("Белгісіз")

# типтер
df["baga"] = pd.to_numeric(df["baga"], errors="coerce")
df["sany"] = pd.to_numeric(df["sany"], errors="coerce")

# қате сан: бос немесе теріс
qate_sany = df["sany"].isna() | (df["sany"] <= 0)
# қате баға: тым қымбат
qate_baga = df["baga"] > 10000
qate = (qate_sany | qate_baga).sum()
df = df[~(qate_sany | qate_baga)]

# бос бағаны сол тауардың медианасымен толтыру
df["baga"] = df["baga"].fillna(df.groupby("tauar")["baga"].transform("median"))
df["sany"] = df["sany"].astype(int)

print("=== Тазалау есебі ===")
print("Бастапқы жазбалар:", bastapqy)
print("Жойылған дубликаттар:", dup)
print("Тауар атауы жоқ жазбалар:", atau_zhoq)
print("Қате саны/бағасы бар жазбалар:", qate)
print("Қалған жазбалар:", len(df))

df["tusim"] = df["baga"] * df["sany"]
print(df)
print("Жалпы түсім:", int(df["tusim"].sum()), "теңге")
df.to_csv("dukenn_taza.csv", index=False)
```
Жауап: қате жазбалар — «Алма» (−3), «Дәптер» («екі»), «Шоколад» (45000). «Қалам» бағасы басқа «Қалам» жолының бағасымен (120) толтырылады. Қалған 7 жазба; жалпы түсім: 1000 + 960 + 1500 + 1000 + 600 + 480 + 360 = 5900 теңге.

**8-тапсырма**
```python
import pandas as pd


def clean_report(df):
    """Әр баған бойынша сапа есебін қайтарады."""
    rows = []
    for col in df.columns:
        s = df[col]
        row = {
            "bagana": col,
            "tipi": str(s.dtype),
            "bos": int(s.isna().sum()),
            "bos_%": round(s.isna().mean() * 100, 1),
            "biregei": s.nunique(),
        }
        if pd.api.types.is_numeric_dtype(s):
            row["min"] = s.min()
            row["max"] = s.max()
        rows.append(row)
    return pd.DataFrame(rows)


df = pd.read_csv("dukenn_satylym.csv")
print(clean_report(df))
```
