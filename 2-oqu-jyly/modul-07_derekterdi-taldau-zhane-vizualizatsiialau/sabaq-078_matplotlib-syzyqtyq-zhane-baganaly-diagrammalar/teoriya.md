## 1. Matplotlib кітапханасы

**Matplotlib** — Python-дағы ең танымал визуализация кітапханасы (2003 жылдан бері). Pandas, Seaborn сияқты кітапханалар графикті ішінде дәл осы Matplotlib арқылы салады.

Орнату (venv белсенді болуы керек):

```bash
pip install matplotlib
```

Қосу — қалыптасқан дәстүр бойынша `plt` деген қысқа атпен:

```python
import matplotlib.pyplot as plt
```

### Графиктің құрылымы

```text
┌──────────────────── Figure (фигура — бүкіл терезе/сурет) ──────────────────┐
│                         Title (тақырып)                                    │
│   ┌──────────────── Axes (координаталық аймақ) ────────────────┐           │
│ Y │      ●───●                                                  │  Legend   │
│ - │     /     \        ●                                        │  (аңыз)   │
│ о │ ●──●       ●──●───/                                         │           │
│ с │                                                             │           │
│ і └─────────────────────────────────────────────────────────────┘           │
│                          X-осі (xlabel)                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **Figure** — сурет салатын «қағаз парағы»;
- **Axes** — сол парақтағы бір график (осьтері бар аймақ);
- **Axis** — X және Y осьтері, бөліктері (ticks), белгілері (labels).

Ең қарапайым жол — `plt.` функциялары (pyplot стилі). Ол «ағымдағы» графикке сурет салады.

### Минималды бағдарлама

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 1, 5, 3]
plt.plot(x, y)
plt.show()
```

Нәтижесі: бес нүктені қосатын көк сынық сызығы бар терезе ашылады. `plt.show()` — терезені көрсетеді; онсыз VS Code-та график шықпайды. Терезені жапқанда бағдарлама жалғасады.

## 2. Сызықтық диаграмма — `plt.plot()`

**Қашан қолданамыз?** Уақыт бойынша **өзгерісті, трендті** көрсету үшін: айлар бойынша температура, апта бойынша қадам саны, жылдар бойынша халық саны. X осінде — уақыт (немесе реттелген шама).

```python
import matplotlib.pyplot as plt

ailar = ["Қаң", "Ақп", "Нау", "Сәу", "Мам", "Мау",
         "Шіл", "Там", "Қыр", "Қаз", "Қар", "Жел"]
almaty = [-4.7, -3.0, 3.9, 11.6, 16.8, 21.8, 24.4, 23.4, 18.0, 10.7, 2.7, -2.9]

plt.plot(ailar, almaty)
plt.title("Алматыдағы орташа айлық температура (шамамен)")
plt.xlabel("Ай")
plt.ylabel("Температура, °C")
plt.show()
```

Нәтижесі: қыста төмен, шілдеде ең жоғары (24,4°) болатын «дөңес» сызық.

### Сызықтың сыртқы түрі

`plot()` функциясының жиі қолданылатын параметрлері:

| Параметр | Мағынасы | Мысал |
|---|---|---|
| `color` | Түс | `color="red"`, `color="#1f77b4"` |
| `linestyle` | Сызық түрі | `"-"` тұтас, `"--"` штрих, `":"` нүкте, `"-."` |
| `linewidth` | Қалыңдығы | `linewidth=2` |
| `marker` | Нүкте белгісі | `"o"` дөңгелек, `"s"` шаршы, `"^"` үшбұрыш, `"*"` |
| `label` | Аңыздағы аты | `label="Алматы"` |

Қысқа формат жолы да бар: `plt.plot(x, y, "ro--")` — қызыл (`r`), дөңгелек нүкте (`o`), штрих сызық (`--`).

### Бірнеше сызық бір графикте

`plot()`-ты бірнеше рет шақырсақ, сызықтар бір Axes-ке салынады. Оларды ажырату үшін `label` + `plt.legend()`:

```python
import matplotlib.pyplot as plt

ailar = ["Қаң", "Ақп", "Нау", "Сәу", "Мам", "Мау",
         "Шіл", "Там", "Қыр", "Қаз", "Қар", "Жел"]
almaty = [-4.7, -3.0, 3.9, 11.6, 16.8, 21.8, 24.4, 23.4, 18.0, 10.7, 2.7, -2.9]
astana = [-14.2, -13.4, -6.0, 5.5, 13.6, 19.1, 20.9, 18.8, 12.5, 4.4, -5.0, -11.5]

plt.plot(ailar, almaty, marker="o", color="orange", label="Алматы")
plt.plot(ailar, astana, marker="s", color="steelblue", linestyle="--", label="Астана")
plt.axhline(0, color="gray", linewidth=0.8)     # 0° деңгейіндегі көлденең сызық
plt.title("Алматы мен Астананың температурасы")
plt.ylabel("°C")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

Нәтижесі: екі сызық; Астананың сызығы барлық айда төменірек, әсіресе қыста айырма 10°-тан асады. Бұл — **салыстыру** арқылы табылған заңдылық.

## 3. Бағаналы диаграмма — `plt.bar()`

**Қашан қолданамыз?** **Санаттарды салыстыру** үшін: филиалдар түсімі, сыныптардың орташа баллы, пәндер бойынша оқушы саны. X осінде — санаттар (реті маңызды емес).

```python
import matplotlib.pyplot as plt

panderi = ["Математика", "Информатика", "Физика", "Ағылшын", "Тарих"]
oqushy_sany = [12, 18, 7, 10, 5]

plt.bar(panderi, oqushy_sany, color="mediumseagreen")
plt.title("Сүйікті пән бойынша сауалнама")
plt.ylabel("Оқушы саны")
plt.show()
```

Нәтижесі: бес жасыл бағана, ең биігі — «Информатика» (18).

### Бағаналарға мән жазу

```python
import matplotlib.pyplot as plt

panderi = ["Математика", "Информатика", "Физика", "Ағылшын", "Тарих"]
oqushy_sany = [12, 18, 7, 10, 5]

baganalar = plt.bar(panderi, oqushy_sany, color="mediumseagreen")
plt.bar_label(baganalar)          # әр бағананың үстіне мәнін жазады
plt.ylim(0, 20)                   # Y осінің шегі
plt.title("Сүйікті пән бойынша сауалнама")
plt.show()
```

### Көлденең бағаналар — `plt.barh()`

Санат атаулары ұзын болса немесе санат көп болса (рейтинг) — көлденең бағана ыңғайлы:

```python
import matplotlib.pyplot as plt

qalalar = ["Алматы", "Астана", "Шымкент", "Ақтөбе", "Қарағанды"]
halyq_mln = [2.3, 1.4, 1.2, 0.6, 0.5]     # шамамен, млн адам

plt.barh(qalalar, halyq_mln, color="slateblue")
plt.gca().invert_yaxis()        # ең үлкені жоғарыда тұрсын
plt.xlabel("Халық саны, млн")
plt.title("Қазақстанның ірі қалалары (шамамен)")
plt.show()
```

### Топтастырылған бағаналар

Екі санатты қатар салыстыру үшін бағаналарды X бойынша сәл жылжытамыз:

```python
import matplotlib.pyplot as plt

synyptar = ["9-сынып", "10-сынып", "11-сынып"]
matem = [79.0, 89.0, 76.5]
fizika = [75.0, 81.0, 75.5]

x = range(len(synyptar))                    # 0, 1, 2
eni = 0.4
plt.bar([i - eni / 2 for i in x], matem, width=eni, label="Математика")
plt.bar([i + eni / 2 for i in x], fizika, width=eni, label="Физика")
plt.xticks(list(x), synyptar)                # 0,1,2 орнына сынып атауларын жазу
plt.ylabel("Орташа балл")
plt.legend()
plt.show()
```

Нәтижесі: әр сыныпта екі бағана қатар тұр — көк (математика) және сарғылт (физика).

## 4. Pandas + Matplotlib: groupby-дан графикке

Топтау (`groupby`) нәтижесін бірден графикке айналдыруға болады:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]
filial = df.groupby("filial")["tusim"].sum().sort_values(ascending=False)

plt.bar(filial.index, filial.values, color=["gold", "silver", "peru"])
plt.title("Филиалдардың апталық түсімі")
plt.ylabel("Теңге")
plt.show()
```

`filial.index` — санат атаулары (X), `filial.values` — сандар (Y).

Pandas-тың өзінде `.plot()` әдісі бар — ол Matplotlib-ті ішінен шақырады:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]

df.groupby("filial")["tusim"].sum().plot(kind="bar", color="teal", title="Түсім")
plt.show()

kunder = df.groupby("kun", sort=False)["tusim"].sum()
kunder.plot(kind="line", marker="o", title="Күндер бойынша түсім")
plt.show()
```

`kind` параметрі: `"line"`, `"bar"`, `"barh"` (сондай-ақ `"pie"`, `"hist"`, `"scatter"` т.б.).

## 5. Графикті файлға сақтау

```python
import matplotlib.pyplot as plt

plt.plot([2021, 2022, 2023, 2024, 2025], [120, 150, 170, 210, 260], marker="o")
plt.title("Үйірмеге қатысушылар саны")
plt.savefig("qatysushylar.png", dpi=150, bbox_inches="tight")
plt.show()
```

- `savefig` **`show()`-дан бұрын** шақырылуы керек (терезе жабылған соң график тазаланады);
- `dpi` — сапасы (нүкте/дюйм), `bbox_inches="tight"` — шетіндегі артық бос орынды кеседі;
- форматтар: `.png`, `.jpg`, `.svg`, `.pdf`.

## 6. Сызықтық па, бағаналы ма?

| Сұрақ | Диаграмма |
|---|---|
| Уақыт өте шама **қалай өзгерді**? | Сызықтық |
| Қай санат **үлкен/кіші**? | Бағаналы |
| Санаттар көп, атаулары ұзын, рейтинг | Көлденең бағаналы |
| Екі-үш топты санаттар бойынша салыстыру | Топтастырылған бағаналы |
| Бірнеше қатардың **трендтерін** салыстыру | Бірнеше сызық |

**Ереже:** бағаналы диаграмманың Y осі **0-ден** басталуы керек — әйтпесе айырмашылық үлкейіп, көрерменді алдайды.

## Жиі кездесетін қателер

**1. `plt.show()` ұмыту** — бағдарлама қатесіз аяқталады, бірақ график шықпайды.

**2. X пен Y ұзындығы әртүрлі.**
```python
plt.plot([1, 2, 3], [10, 20])     # ValueError: x and y must have same first dimension
```
Дұрысы: `plt.plot([1, 2, 3], [10, 20, 30])`.

**3. `savefig` пен `show` ретін ауыстыру.**
```python
plt.show()
plt.savefig("a.png")    # бос (ақ) сурет сақталады
```
Дұрысы:
```python
plt.savefig("a.png")
plt.show()
```

**4. `label` беріп, `plt.legend()` шақырмау** — аңыз шықпайды.

**5. Санаттарды сызықпен көрсету.** «Филиалдар» бойынша сызықтық диаграмма Алматыдан Астанаға «өсу» бар сияқты әсер береді — бұл мағынасыз. Санаттарға — бағана.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Визуализация | Деректі сурет (график, диаграмма) түрінде бейнелеу |
| Matplotlib / `pyplot` | Python-дағы негізгі график кітапханасы / оның қарапайым интерфейсі |
| Figure / Axes | Бүкіл сурет / ішіндегі осьтері бар график аймағы |
| `plt.plot()` | Сызықтық диаграмма |
| `plt.bar()` / `plt.barh()` | Тік / көлденең бағаналы диаграмма |
| `marker`, `linestyle`, `color` | Сызықтың сыртқы түрі параметрлері |
| `plt.legend()` | Аңыз — қай сызық/бағана нені білдіретінін көрсетеді |
| `plt.savefig()` | Графикті файлға сақтау |

## Ескерту

- Jupyter Notebook пен VS Code Interactive ортасында графиктер автоматты түрде шығады, ал кәдімгі `.py` скриптте `plt.show()` болмаса терезе ашылмайды.
- X осінде мәтіндік белгілері бар `plt.bar()` санаттарды берілген ретпен салады; диаграмма оңай оқылуы үшін деректі алдын ала сұрыптаңыз (`sort_values`).
- Әр `plt.figure()` шақыруы жаңа сурет жасайды; циклдерде қажетсіздерін `plt.close()` арқылы жабыңыз, әйтпесе жад шығыны өседі (20-дан көп фигура ашылса, Matplotlib ескерту береді).
- Графикалық терезесіз жұмыс үшін (серверде) тек `savefig()` қолданыңыз; қажет болса, `pyplot`-ты импорттамай тұрып бэкендті көрсетіңіз: `import matplotlib; matplotlib.use("Agg")`.
- Pandas-тың `Series.plot()` әдісі `Axes` объектісін қайтарады, сондықтан оны әрі қарай баптауға болады: `ax = s.plot(kind="bar"); ax.set_ylabel("Теңге")`.
- Құжаттама және мысалдар галереясы: [matplotlib.org/stable/gallery](https://matplotlib.org/stable/gallery/index.html).
