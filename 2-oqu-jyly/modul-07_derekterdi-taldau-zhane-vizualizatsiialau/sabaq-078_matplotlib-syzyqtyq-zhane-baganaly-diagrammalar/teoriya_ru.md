## 1. Библиотека Matplotlib

**Matplotlib** — самая популярная библиотека визуализации в Python (существует с 2003 года). Такие библиотеки, как Pandas и Seaborn, внутри строят графики именно с помощью Matplotlib.

Установка (venv должен быть активирован):

```bash
pip install matplotlib
```

Подключение — по сложившейся традиции под коротким именем `plt`:

```python
import matplotlib.pyplot as plt
```

### Структура графика

```text
┌──────────────────── Figure (фигура — всё окно/рисунок) ────────────────────┐
│                         Title (заголовок)                                  │
│   ┌──────────────── Axes (координатная область) ───────────────┐           │
│ Y │      ●───●                                                  │  Legend   │
│ - │     /     \        ●                                        │ (легенда) │
│ о │ ●──●       ●──●───/                                         │           │
│ с │                                                             │           │
│ ь └─────────────────────────────────────────────────────────────┘           │
│                          Ось X (xlabel)                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **Figure** — «лист бумаги», на котором рисуем;
- **Axes** — один график на этом листе (область с осями);
- **Axis** — оси X и Y, их деления (ticks) и подписи (labels).

Самый простой способ — функции `plt.` (стиль pyplot). Они рисуют на «текущем» графике.

### Минимальная программа

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 1, 5, 3]
plt.plot(x, y)
plt.show()
```

Результат: открывается окно с синей ломаной линией, соединяющей пять точек. `plt.show()` показывает окно; без него в VS Code график не появится. Когда окно закрывают, программа продолжает работу.

## 2. Линейный график — `plt.plot()`

**Когда используем?** Чтобы показать **изменение, тренд** во времени: температура по месяцам, количество шагов по неделям, численность населения по годам. По оси X — время (или упорядоченная величина).

```python
import matplotlib.pyplot as plt

ailar = ["Янв", "Фев", "Мар", "Апр", "Май", "Июн",
         "Июл", "Авг", "Сен", "Окт", "Ноя", "Дек"]
almaty = [-4.7, -3.0, 3.9, 11.6, 16.8, 21.8, 24.4, 23.4, 18.0, 10.7, 2.7, -2.9]

plt.plot(ailar, almaty)
plt.title("Среднемесячная температура в Алматы (приблизительно)")
plt.xlabel("Месяц")
plt.ylabel("Температура, °C")
plt.show()
```

Результат: «выпуклая» линия — низкая зимой, наивысшая в июле (24,4°).

### Внешний вид линии

Часто используемые параметры функции `plot()`:

| Параметр | Значение | Пример |
|---|---|---|
| `color` | Цвет | `color="red"`, `color="#1f77b4"` |
| `linestyle` | Тип линии | `"-"` сплошная, `"--"` штриховая, `":"` пунктир, `"-."` |
| `linewidth` | Толщина | `linewidth=2` |
| `marker` | Маркер точки | `"o"` круг, `"s"` квадрат, `"^"` треугольник, `"*"` |
| `label` | Подпись в легенде | `label="Алматы"` |

Есть и короткая строка формата: `plt.plot(x, y, "ro--")` — красный (`r`), круглые точки (`o`), штриховая линия (`--`).

### Несколько линий на одном графике

Если вызвать `plot()` несколько раз, линии рисуются на одних Axes. Чтобы их различать — `label` + `plt.legend()`:

```python
import matplotlib.pyplot as plt

ailar = ["Янв", "Фев", "Мар", "Апр", "Май", "Июн",
         "Июл", "Авг", "Сен", "Окт", "Ноя", "Дек"]
almaty = [-4.7, -3.0, 3.9, 11.6, 16.8, 21.8, 24.4, 23.4, 18.0, 10.7, 2.7, -2.9]
astana = [-14.2, -13.4, -6.0, 5.5, 13.6, 19.1, 20.9, 18.8, 12.5, 4.4, -5.0, -11.5]

plt.plot(ailar, almaty, marker="o", color="orange", label="Алматы")
plt.plot(ailar, astana, marker="s", color="steelblue", linestyle="--", label="Астана")
plt.axhline(0, color="gray", linewidth=0.8)     # горизонтальная линия на уровне 0°
plt.title("Температура в Алматы и Астане")
plt.ylabel("°C")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

Результат: две линии; линия Астаны ниже во все месяцы, особенно зимой разница превышает 10°. Это закономерность, найденная через **сравнение**.

## 3. Столбчатая диаграмма — `plt.bar()`

**Когда используем?** Для **сравнения категорий**: выручка филиалов, средний балл классов, количество учеников по предметам. По оси X — категории (порядок не важен).

```python
import matplotlib.pyplot as plt

panderi = ["Математика", "Информатика", "Физика", "Английский", "История"]
oqushy_sany = [12, 18, 7, 10, 5]

plt.bar(panderi, oqushy_sany, color="mediumseagreen")
plt.title("Опрос о любимом предмете")
plt.ylabel("Количество учеников")
plt.show()
```

Результат: пять зелёных столбцов, самый высокий — «Информатика» (18).

### Подписи значений на столбцах

```python
import matplotlib.pyplot as plt

panderi = ["Математика", "Информатика", "Физика", "Английский", "История"]
oqushy_sany = [12, 18, 7, 10, 5]

baganalar = plt.bar(panderi, oqushy_sany, color="mediumseagreen")
plt.bar_label(baganalar)          # пишет значение над каждым столбцом
plt.ylim(0, 20)                   # пределы оси Y
plt.title("Опрос о любимом предмете")
plt.show()
```

### Горизонтальные столбцы — `plt.barh()`

Если названия категорий длинные или категорий много (рейтинг), удобны горизонтальные столбцы:

```python
import matplotlib.pyplot as plt

qalalar = ["Алматы", "Астана", "Шымкент", "Актобе", "Караганда"]
halyq_mln = [2.3, 1.4, 1.2, 0.6, 0.5]     # приблизительно, млн человек

plt.barh(qalalar, halyq_mln, color="slateblue")
plt.gca().invert_yaxis()        # чтобы наибольший был сверху
plt.xlabel("Население, млн")
plt.title("Крупнейшие города Казахстана (приблизительно)")
plt.show()
```

### Сгруппированные столбцы

Чтобы сравнить две категории рядом, немного сдвигаем столбцы по X:

```python
import matplotlib.pyplot as plt

synyptar = ["9 класс", "10 класс", "11 класс"]
matem = [79.0, 89.0, 76.5]
fizika = [75.0, 81.0, 75.5]

x = range(len(synyptar))                    # 0, 1, 2
eni = 0.4
plt.bar([i - eni / 2 for i in x], matem, width=eni, label="Математика")
plt.bar([i + eni / 2 for i in x], fizika, width=eni, label="Физика")
plt.xticks(list(x), synyptar)                # подписать классы вместо 0,1,2
plt.ylabel("Средний балл")
plt.legend()
plt.show()
```

Результат: в каждом классе два столбца рядом — синий (математика) и оранжевый (физика).

## 4. Pandas + Matplotlib: от groupby к графику

Результат группировки (`groupby`) можно сразу превратить в график:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]
filial = df.groupby("filial")["tusim"].sum().sort_values(ascending=False)

plt.bar(filial.index, filial.values, color=["gold", "silver", "peru"])
plt.title("Недельная выручка филиалов")
plt.ylabel("Тенге")
plt.show()
```

`filial.index` — названия категорий (X), `filial.values` — числа (Y).

У самого Pandas есть метод `.plot()` — он вызывает Matplotlib изнутри:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("kitap_dukeni.csv")
df["tusim"] = df["sany"] * df["baga"]

df.groupby("filial")["tusim"].sum().plot(kind="bar", color="teal", title="Выручка")
plt.show()

kunder = df.groupby("kun", sort=False)["tusim"].sum()
kunder.plot(kind="line", marker="o", title="Выручка по дням")
plt.show()
```

Параметр `kind`: `"line"`, `"bar"`, `"barh"` (а также `"pie"`, `"hist"`, `"scatter"` и др.).

## 5. Сохранение графика в файл

```python
import matplotlib.pyplot as plt

plt.plot([2021, 2022, 2023, 2024, 2025], [120, 150, 170, 210, 260], marker="o")
plt.title("Количество участников кружка")
plt.savefig("qatysushylar.png", dpi=150, bbox_inches="tight")
plt.show()
```

- `savefig` нужно вызывать **до `show()`** (после закрытия окна график очищается);
- `dpi` — качество (точек на дюйм), `bbox_inches="tight"` — обрезает лишние поля по краям;
- форматы: `.png`, `.jpg`, `.svg`, `.pdf`.

## 6. Линейный или столбчатый?

| Вопрос | Диаграмма |
|---|---|
| **Как изменялась** величина со временем? | Линейная |
| Какая категория **больше/меньше**? | Столбчатая |
| Категорий много, длинные названия, рейтинг | Горизонтальная столбчатая |
| Сравнение двух-трёх групп по категориям | Сгруппированная столбчатая |
| Сравнение **трендов** нескольких рядов | Несколько линий |

**Правило:** ось Y столбчатой диаграммы должна начинаться **с 0** — иначе разница преувеличивается и вводит зрителя в заблуждение.

## Частые ошибки

**1. Забыли `plt.show()`** — программа завершается без ошибок, но график не появляется.

**2. Разная длина X и Y.**
```python
plt.plot([1, 2, 3], [10, 20])     # ValueError: x and y must have same first dimension
```
Правильно: `plt.plot([1, 2, 3], [10, 20, 30])`.

**3. Перепутан порядок `savefig` и `show`.**
```python
plt.show()
plt.savefig("a.png")    # сохранится пустой (белый) рисунок
```
Правильно:
```python
plt.savefig("a.png")
plt.show()
```

**4. Задали `label`, но не вызвали `plt.legend()`** — легенда не появится.

**5. Отображение категорий линией.** Линейный график по «филиалам» создаёт впечатление «роста» от Алматы к Астане — это бессмысленно. Для категорий — столбцы.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Визуализация | Представление данных в виде изображения (графика, диаграммы) |
| Matplotlib / `pyplot` | Основная библиотека графиков в Python / её простой интерфейс |
| Figure / Axes | Весь рисунок / область графика с осями внутри него |
| `plt.plot()` | Линейный график |
| `plt.bar()` / `plt.barh()` | Вертикальная / горизонтальная столбчатая диаграмма |
| `marker`, `linestyle`, `color` | Параметры внешнего вида линии |
| `plt.legend()` | Легенда — показывает, что означает каждая линия/столбец |
| `plt.savefig()` | Сохранение графика в файл |

## Примечание

- В Jupyter Notebook и VS Code Interactive графики выводятся автоматически, а в обычном скрипте `.py` без `plt.show()` окно не появится.
- `plt.bar()` с текстовыми подписями по оси X рисует категории в том порядке, в каком они переданы; отсортируйте данные заранее (`sort_values`), чтобы диаграмма читалась легче.
- Каждый вызов `plt.figure()` создаёт новый рисунок; в циклах закрывайте ненужные через `plt.close()`, иначе растёт расход памяти (Matplotlib предупреждает, когда открыто больше 20 фигур).
- Для работы без графического окна (на сервере) используйте только `savefig()`; при необходимости задайте бэкенд: `import matplotlib; matplotlib.use("Agg")` до импорта `pyplot`.
- Метод `Series.plot()` из Pandas возвращает объект `Axes`, поэтому его можно дальше настраивать: `ax = s.plot(kind="bar"); ax.set_ylabel("Тенге")`.
- Документация и галерея примеров: [matplotlib.org/stable/gallery](https://matplotlib.org/stable/gallery/index.html).
