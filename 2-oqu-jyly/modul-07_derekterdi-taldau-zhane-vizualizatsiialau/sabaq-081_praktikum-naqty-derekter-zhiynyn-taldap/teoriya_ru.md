## 1. Полный цикл анализа

```text
 1. ВОПРОС        →  Что мы хотим узнать? (3–5 вопросов)
 2. ДАННЫЕ        →  Откуда берём? Какие есть столбцы? (read_csv, head, info)
 3. ОЧИСТКА       →  Пропуски, дубликаты, ошибки (dropna, fillna, drop_duplicates)
 4. ИССЛЕДОВАНИЕ  →  describe, value_counts, гистограммы — «почувствовать» данные
 5. АНАЛИЗ        →  groupby, agg, pivot_table, corr
 6. ВИЗУАЛИЗАЦИЯ  →  на каждый вопрос — один правильный график (Matplotlib)
 7. ВЫВОДЫ        →  ответы на вопросы, ограничения, рекомендации
```

Цикл начинается с **вопроса**, а не с данных. Анализ без вопроса — путешествие без карты: идёшь долго, но никуда не приходишь.

### Хороший исследовательский вопрос

| Плохой вопрос | Хороший вопрос |
|---|---|
| «Что есть в данных?» | «У какого класса самый высокий средний балл?» |
| «Об учениках» | «Ниже ли балл у учеников, которые много сидят в телефоне?» |
| «Как продажи?» | «Насколько продажи в выходные больше, чем в будни?» |

Хороший вопрос: **конкретный**, **ответ на него можно найти в данных**, **содержит сравнение**.

## 2. Где найти наборы данных

- **data.egov.kz** — портал открытых данных Казахстана (CSV/JSON);
- **stat.gov.kz** — Бюро национальной статистики Республики Казахстан (население, цены, образование);
- **Kaggle.com** — мировые наборы данных (на английском): игры, фильмы, спорт, погода;
- **Open-Meteo API** — получить историю погоды в JSON и превратить в DataFrame;
- **собственный опрос** — Google Forms → экспорт в CSV;
- **синтетические данные** — моделирование с помощью NumPy (для обучения).

**Этика:** в персональных данных (ФИО, телефон, адрес) нельзя публиковать информацию, по которой можно установить личность — удаляем или скрываем её.

## 4. Образец проекта: «Образ жизни и успеваемость ученика»

**Данные:** опрос 150 учеников (синтетический): `synyp`, `jynys`, `uiqy` (сон, ч), `telefon` (в телефоне в день, ч), `sport` (занимается ли спортом), `ball` (средний балл, по 100-балльной шкале).

**Вопросы:**
1. Различается ли успеваемость между классами?
2. Выше ли балл у учеников, занимающихся спортом?
3. Есть ли связь между временем в телефоне и баллом?
4. Влияет ли продолжительность сна на балл?

Данные хранятся в файле `oqushy_omiri.csv` (сгенерированы с помощью NumPy). Код анализа:

```python
import pandas as pd
import matplotlib.pyplot as plt


def load_data(path):
    """Читает CSV-файл и выводит основную информацию."""
    df = pd.read_csv(path)
    print("Размер:", df.shape)
    print("Пропуски:", df.isna().sum().sum(), "| Дубликаты:", df.duplicated().sum())
    return df


def clean_data(df):
    """Исправляет дубликаты, пропуски, формат и невозможные значения."""
    df = df.drop_duplicates()
    df["jynys"] = df["jynys"].str.strip().str.capitalize()
    df["uiqy"] = df["uiqy"].fillna(df["uiqy"].median())
    df = df[df["ball"].between(0, 100) & (df["telefon"] >= 0)].copy()
    print("После очистки:", len(df), "записей")
    return df


def analyze(df):
    """Выводит таблицы, отвечающие на исследовательские вопросы."""
    print(df.describe().round(1))
    print("\n1. Средний балл по классам:")
    print(df.groupby("synyp")["ball"].mean().round(1))
    print("\n2. По спорту:")
    print(df.groupby("sport")["ball"].agg(["count", "mean"]).round(1))
    print("\n3–4. Корреляция:")
    print(df[["uiqy", "telefon", "ball"]].corr().round(2))
    df["telefon_top"] = pd.cut(df["telefon"], bins=[0, 2, 4, 7],
                               labels=["до 2 ч", "2–4 ч", "более 4 ч"])
    print(df.groupby("telefon_top", observed=True)["ball"].agg(["count", "mean"]).round(1))
    return df


def make_charts(df):
    """Строит основные графики и сохраняет их в файлы."""
    top = df.groupby("telefon_top", observed=True)["ball"].mean()
    fig, ax = plt.subplots(figsize=(7, 4.5))
    b = ax.bar(top.index.astype(str), top.values, color=["#2A9D8F", "#E9C46A", "#E76F51"])
    ax.bar_label(b, fmt="%.1f")
    ax.set_ylim(0, 100)
    ax.set_title("Чем больше времени в телефоне, тем ниже балл", loc="left", fontweight="bold")
    ax.set_xlabel("Время в телефоне в день")
    ax.set_ylabel("Средний балл")
    ax.spines[["top", "right"]].set_visible(False)
    fig.savefig("telefon_ball.png", dpi=150, bbox_inches="tight")

    fig, ax = plt.subplots(figsize=(7, 4.5))
    ax.scatter(df["uiqy"], df["ball"], alpha=0.6, color="#264653")
    ax.set_title("Сон и балл: слабая положительная связь", loc="left", fontweight="bold")
    ax.set_xlabel("Сон, часы")
    ax.set_ylabel("Балл")
    ax.spines[["top", "right"]].set_visible(False)
    fig.savefig("uiqy_ball.png", dpi=150, bbox_inches="tight")
    plt.show()


data = load_data("oqushy_omiri.csv")
data = clean_data(data)
data = analyze(data)
make_charts(data)
data.to_csv("oqushy_omiri_taza.csv", index=False)
```

Основные результаты (фрагмент):
```text
Размер: (153, 6)
Пропуски: 3 | Дубликаты: 3
После очистки: 148 записей
...
3–4. Корреляция:
         uiqy  telefon  ball
uiqy     1.00     0.08  0.29
telefon  0.08     1.00 -0.49
ball     0.29    -0.49  1.00
             count  mean
telefon_top             
до 2 ч          25  81.4
2–4 ч           51  76.2
более 4 ч       72  70.9
```

**Выводы:**
1. Разница между классами невелика (73,0–76,6) — класс не оказывает решающего влияния на успеваемость.
2. У занимающихся спортом балл немного выше (75,1 против 73,8), но разница небольшая.
3. Между временем в телефоне и баллом **умеренная отрицательная** связь (r = −0,49): средний балл тех, кто сидит в телефоне больше 4 часов в день, примерно на 10 баллов ниже, чем у тех, кто сидит до 2 часов.
4. Между сном и баллом **слабая положительная** связь (r = 0,29).

**Ограничения:** данные синтетические; корреляция не доказывает причину (возможно, ученик с низким баллом больше отвлекается на телефон, а не наоборот).

**Признаки хорошего вывода:**
- выражен через числа («на 10 баллов ниже», «r = −0,49»), а не «больше/меньше»;

- содержит **рекомендацию** («ученикам рекомендуется ограничить время в телефоне 2 часами»).

## Частые ошибки

**1. Запись поверх исходного файла.** `df.to_csv("raw.csv")` — исходные данные теряются. Очищенные данные всегда сохраняйте в **новый** файл.

**2. Графики без вопросов.** 10 графиков, но ни один не отвечает на вопрос. Каждый график — на один вопрос.

**3. В выводах только описание графика.** «На графике три столбца» — это не вывод. «У тех, кто сидит в телефоне больше 4 часов, балл на 10 баллов ниже» — вывод.

**4. Большой вывод по маленькой группе.** Если в группе всего 3 ученика — утверждение ненадёжно. Всегда показывайте `count`.

**5. `SettingWithCopyWarning`.** Появляется при изменении отфильтрованной таблицы. Решение: после фильтрации добавить `.copy()`: `df = df[df["ball"] <= 100].copy()`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Цикл анализа | 7 этапов от вопроса до выводов |
| Исследовательский вопрос | Вопрос, на который можно найти конкретный ответ в данных |
| Разведочный анализ (EDA) | Первичное «знакомство» с данными через `describe`, гистограммы и т.д. |
| Аналитический отчёт | Документ, в котором описаны вопросы, методы, результаты, выводы |
| Гипотеза | Предположение, которое нужно проверить |
| Ограничения | Факторы, снижающие надёжность результата |
| `pd.cut()` | Разбиение числового столбца на категории по интервалам |

## Примечание

- Файлы с сайтов Казахстана часто сохранены в кодировке `cp1251` или с разделителем `;`: `pd.read_csv("f.csv", sep=";", encoding="cp1251")`. Ошибка `UnicodeDecodeError` почти всегда означает неверную кодировку.
- `df.info()` показывает типы и количество непустых значений — это самый быстрый способ увидеть, какие столбцы прочитались как текст (`object`) вместо чисел.
- В `pd.cut()` интервалы по умолчанию открыты слева: `(0, 2]`, поэтому значение `0` не попадёт ни в один интервал. Используйте `include_lowest=True` или начинайте границы с `-1`.
- Для воспроизводимости результатов фиксируйте зерно генератора (`np.random.default_rng(42)`) и указывайте версии библиотек в `requirements.txt`.
- Защитный приём `if __name__ == "__main__":` позволяет импортировать функции `load_data`, `clean_data` в другие файлы (например, в тесты) без запуска всего анализа.
- Документация: [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html), [pandas.cut](https://pandas.pydata.org/docs/reference/api/pandas.cut.html).
