## 1. Толық талдау циклі

```text
 1. СҰРАҚ        →  Не білгіміз келеді? (3–5 сұрақ)
 2. ДЕРЕК        →  Қайдан аламыз? Қандай бағандар бар? (read_csv, head, info)
 3. ТАЗАЛАУ      →  Бос мән, дубликат, қате (dropna, fillna, drop_duplicates)
 4. ЗЕРТТЕУ      →  describe, value_counts, гистограммалар — деректі «сезіну»
 5. ТАЛДАУ       →  groupby, agg, pivot_table, corr
 6. ВИЗУАЛИЗАЦИЯ →  әр сұраққа — бір дұрыс график (Matplotlib)
 7. ҚОРЫТЫНДЫ    →  сұрақтарға жауап, шектеулер, ұсыныстар
```

Цикл **сұрақтан** басталады, деректен емес. Сұрақсыз талдау — картасыз саяхат: көп жүресің, бірақ еш жерге жетпейсің.

Жақсы сұрақ: **нақты**, **деректен жауап табуға болатын**, **салыстыруы бар**.

## 4. Үлгі жоба: «Оқушының өмір салты және үлгерімі»

**Деректер:** 150 оқушы туралы сауалнама (синтетикалық): `synyp`, `jynys`, `uiqy` (ұйқы, сағ), `telefon` (күніне телефонда, сағ), `sport` (спортпен айналыса ма), `ball` (орташа балл, 100 балдық).

**Сұрақтар:**
1. Сыныптар арасында үлгерім ерекшеленеді ме?
2. Спортпен айналысатын оқушылардың баллы жоғары ма?
3. Телефонда өткізетін уақыт пен балл арасында байланыс бар ма?
4. Ұйқы ұзақтығы баллға әсер ете ме?

Деректер `oqushy_omiri.csv` файлында сақталған (NumPy көмегімен жасалған). Талдау коды:

```python
import pandas as pd
import matplotlib.pyplot as plt


def load_data(path):
    """CSV файлды оқып, негізгі ақпаратты шығарады."""
    df = pd.read_csv(path)
    print("Өлшемі:", df.shape)
    print("Бос мәндер:", df.isna().sum().sum(), "| Дубликаттар:", df.duplicated().sum())
    return df


def clean_data(df):
    """Дубликат, бос мән, формат және мүмкін емес мәндерді түзетеді."""
    df = df.drop_duplicates()
    df["jynys"] = df["jynys"].str.strip().str.capitalize()
    df["uiqy"] = df["uiqy"].fillna(df["uiqy"].median())
    df = df[df["ball"].between(0, 100) & (df["telefon"] >= 0)].copy()
    print("Тазалаудан кейін:", len(df), "жазба")
    return df


def analyze(df):
    """Зерттеу сұрақтарына жауап беретін кестелерді шығарады."""
    print(df.describe().round(1))
    print("\n1. Сыныптар бойынша орташа балл:")
    print(df.groupby("synyp")["ball"].mean().round(1))
    print("\n2. Спорт бойынша:")
    print(df.groupby("sport")["ball"].agg(["count", "mean"]).round(1))
    print("\n3–4. Корреляция:")
    print(df[["uiqy", "telefon", "ball"]].corr().round(2))
    df["telefon_top"] = pd.cut(df["telefon"], bins=[0, 2, 4, 7],
                               labels=["2 сағ дейін", "2–4 сағ", "4 сағ көп"])
    print(df.groupby("telefon_top", observed=True)["ball"].agg(["count", "mean"]).round(1))
    return df


def make_charts(df):
    """Негізгі графиктерді салып, файлға сақтайды."""
    top = df.groupby("telefon_top", observed=True)["ball"].mean()
    fig, ax = plt.subplots(figsize=(7, 4.5))
    b = ax.bar(top.index.astype(str), top.values, color=["#2A9D8F", "#E9C46A", "#E76F51"])
    ax.bar_label(b, fmt="%.1f")
    ax.set_ylim(0, 100)
    ax.set_title("Телефонда көп отырған сайын балл төмендейді", loc="left", fontweight="bold")
    ax.set_xlabel("Телефонда өткізетін уақыт, күніне")
    ax.set_ylabel("Орташа балл")
    ax.spines[["top", "right"]].set_visible(False)
    fig.savefig("telefon_ball.png", dpi=150, bbox_inches="tight")

    fig, ax = plt.subplots(figsize=(7, 4.5))
    ax.scatter(df["uiqy"], df["ball"], alpha=0.6, color="#264653")
    ax.set_title("Ұйқы мен балл: әлсіз оң байланыс", loc="left", fontweight="bold")
    ax.set_xlabel("Ұйқы, сағат")
    ax.set_ylabel("Балл")
    ax.spines[["top", "right"]].set_visible(False)
    fig.savefig("uiqy_ball.png", dpi=150, bbox_inches="tight")
    plt.show()


data = load_data("oqushy_omiri.csv")
data = clean_data(data)
data = analyze(data)
make_charts(data)
data.to_csv("oqushy_omiri_taza.csv", index=False)
```

## Жиі кездесетін қателер

**1. Бастапқы файлдың үстіне жазу.** `df.to_csv("raw.csv")` — бастапқы дерек жоғалады. Тазаланғанды әрдайым **жаңа** файлға сақтаңыз.

**2. Сұрақсыз графиктер.** 10 график бар, бірақ біреуі де сұраққа жауап бермейді. Әр график — бір сұраққа.

**3. Қорытындыда графикті сипаттау ғана.** «Графикте үш бағана бар» — бұл қорытынды емес. «4 сағаттан көп отыратындардың баллы 10 баллға төмен» — қорытынды.

**4. Аз топтан үлкен қорытынды.** Топта 3 оқушы ғана болса — тұжырым сенімсіз. `count`-ты әрдайым көрсетіңіз.

**5. `SettingWithCopyWarning`.** Сүзілген кестені өзгерткенде пайда болады. Шешімі: сүзгеннен кейін `.copy()` қосу: `df = df[df["ball"] <= 100].copy()`.

## Ескерту

- Қазақстандық сайттардағы файлдар жиі `cp1251` кодтауында немесе `;` бөлгішімен сақталады: `pd.read_csv("f.csv", sep=";", encoding="cp1251")`. `UnicodeDecodeError` қатесі әдетте кодтаудың қате екенін білдіреді.
- `df.info()` типтер мен бос емес мәндер санын көрсетеді — қай бағандар сан орнына мәтін (`object`) болып оқылғанын көрудің ең жылдам жолы.
- `pd.cut()` аралықтары әдепкі бойынша сол жақтан ашық: `(0, 2]`, сондықтан `0` мәні ешбір аралыққа түспейді. `include_lowest=True` қолданыңыз немесе шекараны `-1`-ден бастаңыз.
- Нәтиже қайталанатын болуы үшін генератордың бастапқы мәнін бекітіңіз (`np.random.default_rng(42)`) және кітапхана нұсқаларын `requirements.txt` файлында көрсетіңіз.
- `if __name__ == "__main__":` қорғаныс тәсілі `load_data`, `clean_data` функцияларын бүкіл талдауды іске қоспай басқа файлдарға (мысалы, тестерге) импорттауға мүмкіндік береді.
- Құжаттама: [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html), [pandas.cut](https://pandas.pydata.org/docs/reference/api/pandas.cut.html).
