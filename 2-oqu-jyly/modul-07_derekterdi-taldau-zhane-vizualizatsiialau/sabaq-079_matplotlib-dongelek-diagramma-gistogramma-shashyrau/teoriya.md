## 1. Дөңгелек диаграмма — `plt.pie()`

**Қашан?** Бір **бүтіннің бөліктерін** (үлесін) көрсету үшін: бюджеттің құрылымы, сауалнамадағы жауаптар үлесі. Бөліктердің қосындысы 100% болуы керек.

```python
import matplotlib.pyplot as plt

baptar = ["Тамақ", "Көлік", "Коммуналдық", "Киім", "Ойын-сауық"]
shygys = [120000, 30000, 45000, 25000, 20000]    # теңге, айына

plt.pie(shygys, labels=baptar, autopct="%1.1f%%", startangle=90)
plt.title("Отбасының айлық шығыны")
plt.axis("equal")      # дөңгелек сопақ болып кетпес үшін
plt.show()
```

Нәтижесі: бес секторлы дөңгелек; ең үлкен сектор — «Тамақ» (50,0%), қалғандары: Коммуналдық 18,8%, Көлік 12,5%, Киім 10,4%, Ойын-сауық 8,3%.

| Параметр | Мағынасы |
|---|---|
| `labels` | Секторлардың атаулары |
| `autopct="%1.1f%%"` | Әр секторға пайызын жазу (бір ондық таңбамен) |
| `startangle=90` | Бірінші сектор «сағат 12-ден» басталады |
| `explode` | Секторды «шығарып» көрсету, мыс. `[0.1, 0, 0, 0, 0]` |
| `colors` | Түстер тізімі |
| `wedgeprops={"width": 0.4}` | Сақина (donut) диаграммасы |

Pandas нұсқасы: `df["qala"].value_counts().plot(kind="pie", autopct="%1.0f%%")`.

**Дөңгелек диаграмманың шектеулері:**
- секторлар **5–6-дан** аспағаны дұрыс (кішілерін «Басқа» деп біріктіру);
- адам көзі бұрыштарды нашар салыстырады: 23% пен 25%-ды ажырату қиын — дәл салыстыру керек болса, бағана жақсы;
- уақыт бойынша өзгерісті ешқашан дөңгелекпен көрсетпейміз.

## 2. Гистограмма — `plt.hist()`

**Қашан?** **Бір сандық шаманың таралуын** көрсету үшін: мәндер қай аралықта жиі кездеседі? Мысалы: 200 оқушының ҰБТ баллы, сынып оқушыларының бойы, такси сапарының ұзақтығы.

Гистограмма мәндерді **аралықтарға (bin, интервал)** бөліп, әр аралыққа неше мән түскенін санайды:

```text
Баллдар: 52, 61, 64, 68, 71, 72, 75, 77, 78, 81, 83, 85, 88, 94

Аралық     Саны
50–60      █               1
60–70      ███             3
70–80      █████           5
80–90      ████            4
90–100     █               1
```

```python
import matplotlib.pyplot as plt

ballar = [52, 61, 64, 68, 71, 72, 75, 77, 78, 81, 83, 85, 88, 94]

plt.hist(ballar, bins=[50, 60, 70, 80, 90, 100], color="skyblue", edgecolor="black")
plt.title("Бақылау жұмысының нәтижелері")
plt.xlabel("Балл")
plt.ylabel("Оқушы саны")
plt.show()
```

Нәтижесі: бес бағана, ең биігі 70–80 аралығында (5 оқушы).

`bins` параметрі:
- сан болса (`bins=10`) — мин мен макс арасы 10 тең аралыққа бөлінеді;
- тізім болса — аралық шекаралары өзіміз береміз.

Тым аз bin — ақпарат жоғалады; тым көп — «тарақ» сияқты шулы сурет шығады. Әдетте 8–20 жақсы.

### Үлкен деректегі таралу

NumPy-мен 1000 «оқушының бойын» модельдейік (кездейсоқ сандар генераторы `np.random.default_rng`):

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
boiy = rng.normal(loc=165, scale=8, size=1000)   # орташа 165 см, шашырау 8 см

plt.hist(boiy, bins=20, color="mediumpurple", edgecolor="white")
plt.axvline(boiy.mean(), color="red", linestyle="--", label=f"Орташа: {boiy.mean():.1f} см")
plt.title("1000 оқушының бойы")
plt.xlabel("Бойы, см")
plt.ylabel("Оқушы саны")
plt.legend()
plt.show()
```

Нәтижесі: «қоңырау» тәрізді пішін — ортасы биік, шеттері төмен. Бұл — **қалыпты таралу** (нормальное распределение). Табиғаттағы көп шама (бой, салмақ, қате өлшем) осылай таралады.

### Бағаналы диаграмма ≠ гистограмма

| | Бағаналы диаграмма | Гистограмма |
|---|---|---|
| X осінде | Санаттар (қалалар, пәндер) | Сандық аралықтар (60–70, 70–80) |
| Бағаналар арасы | Бос орын бар | Бір-біріне тиіп тұрады |
| Ретін ауыстыруға бола ма | Иә | Жоқ (сан осі) |
| Деректі алдын ала санау керек пе | Иә (`groupby`/`value_counts`) | Жоқ, `hist` өзі санайды |
| Сұрақ | «Қай санат көп?» | «Мәндер қалай таралған?» |

## 3. Шашырау графигі — `plt.scatter()`

**Қашан?** **Екі сандық шаманың арасындағы байланысты** көрсету үшін. Әр нысан (оқушы, қала, тауар) — бір нүкте: X — бір шама, Y — екінші шама.

```python
import matplotlib.pyplot as plt

uiqy_sagat = [5, 6, 6.5, 7, 7, 7.5, 8, 8, 8.5, 9, 6, 5.5]
ball = [62, 68, 70, 75, 72, 80, 85, 82, 88, 90, 65, 60]

plt.scatter(uiqy_sagat, ball, color="darkgreen", s=60)
plt.title("Ұйқы ұзақтығы мен бақылау баллы")
plt.xlabel("Ұйқы, сағат")
plt.ylabel("Балл")
plt.grid(True, alpha=0.3)
plt.show()
```

Нәтижесі: нүктелер сол жақ төменнен оң жақ жоғарыға қарай созылған «бұлт» құрайды — **ұйқы көбейген сайын балл да жоғарылайды**.

### Корреляция (байланыс) түрлері

```text
 Оң корреляция          Теріс корреляция         Байланыс жоқ
 Y│        • •          Y│ • •                   Y│ •   •    •
  │     • •              │   • •                  │   •  •  •
  │   • •                │      • •               │ •    •   •
  │ • •                  │         • •            │    •   •
  └──────── X            └──────────── X          └──────────── X
 (ұйқы ↑ → балл ↑)     (телефон ↑ → балл ↓)     (бой ↔ балл)
```

Байланыстың күшін сан ретінде **корреляция коэффициенті** (r) көрсетеді: −1-ден +1-ге дейін. +1-ге жақын — күшті оң, −1-ге жақын — күшті теріс, 0-ге жақын — байланыс жоқ.

```python
import pandas as pd

df = pd.DataFrame({
    "uiqy": [5, 6, 6.5, 7, 7, 7.5, 8, 8, 8.5, 9, 6, 5.5],
    "ball": [62, 68, 70, 75, 72, 80, 85, 82, 88, 90, 65, 60],
})
print("Корреляция:", round(df["uiqy"].corr(df["ball"]), 2))
```

Нәтижесі:
```text
Корреляция: 0.98
```

> **Маңызды:** корреляция ≠ себеп-салдар! Балмұздақ сатылымы мен суға бату оқиғалары бірге өседі, бірақ балмұздақ себеп емес — екеуінің де себебі жаздың ыстығы.

### Нүктелерді түрлі түспен және өлшеммен

`scatter` нүктеге үшінші, төртінші ақпаратты да «кодтай» алады:

```python
import matplotlib.pyplot as plt

halyq = [2.3, 1.4, 1.2, 0.6, 0.5, 0.4]           # млн адам (шамамен)
audan = [0.68, 0.80, 1.17, 2.30, 0.55, 0.38]     # мың км² (шамамен)
qalalar = ["Алматы", "Астана", "Шымкент", "Ақтөбе", "Қарағанды", "Тараз"]

plt.scatter(audan, halyq, s=[h * 300 for h in halyq], c=halyq, cmap="viridis", alpha=0.7)
for i in range(len(qalalar)):
    plt.text(audan[i], halyq[i], qalalar[i], fontsize=9)
plt.colorbar(label="Халық, млн")
plt.xlabel("Ауданы, мың км²")
plt.ylabel("Халық, млн")
plt.title("Қалалар: ауданы мен халқы")
plt.show()
```

- `s` — нүкте өлшемі (тізім берсек, әр нүкте өз өлшемімен — «көпіршік диаграмма»);
- `c` + `cmap` — мәнге қарай түс;
- `alpha` — мөлдірлік (нүктелер бір-бірін жапқанда пайдалы).

## 4. Диаграмма түрін таңдау

| Талдау сұрағы | Диаграмма | Matplotlib |
|---|---|---|
| Уақыт бойынша қалай өзгерді? | Сызықтық | `plot` |
| Санаттарды салыстыру | Бағаналы | `bar`, `barh` |
| Бүтіннің құрамы, үлесі (≤ 6 бөлік) | Дөңгелек | `pie` |
| Бір шаманың таралуы | Гистограмма | `hist` |
| Екі шама арасындағы байланыс | Шашырау | `scatter` |

**Таңдау алгоритмі:**
1. Неше сандық шама қатысады? Біреу → бағана/дөңгелек/гистограмма; екеу → шашырау; уақыт + шама → сызық.
2. Бір шама болса: санаттар бойынша ма (бағана), бүтіннің бөлігі ме (дөңгелек), әлде таралуы ма (гистограмма)?
3. Көрерменге не маңызды: дәл салыстыру ма (бағана), әлде жалпы әсер ме (дөңгелек)?

## Жиі кездесетін қателер

**1. Дөңгелекке теріс немесе 100%-ға қатысы жоқ мәндер беру.** Температуралар, жылдар бойынша мәндер — дөңгелекке жарамайды.

**2. Гистограмма орнына бағана салу.**
```python
plt.bar(range(len(ballar)), ballar)    # әр оқушыға бір бағана — таралу көрінбейді
```
Дұрысы:
```python
plt.hist(ballar, bins=5)
```

**3. `scatter`-ге санаттық X беру.** `plt.scatter(["Алматы", "Астана"], [2.3, 1.4])` жұмыс істейді, бірақ мағынасы — бағаналы диаграмма. Шашырау тек екі **сан** үшін.

**4. `autopct` жолын қате жазу.** `autopct="%1.1f%"` → қате; пайыз белгісі екі рет: `"%1.1f%%"`.

**5. `pie` нәтижесі сопақ.** Ескі нұсқаларда `plt.axis("equal")` қажет.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Дөңгелек диаграмма (pie chart) | Бүтіннің бөліктерін секторлармен көрсетеді |
| Гистограмма (histogram) | Сандық шаманың аралықтар бойынша таралуы |
| Bin (аралық) | Гистограммадағы бір интервал |
| Таралу (распределение) | Мәндердің қай жерде жиі/сирек кездесетіні |
| Шашырау графигі (scatter plot) | Екі сандық шаманың нүктелік бейнесі |
| Корреляция | Екі шаманың бірге өзгеру дәрежесі (−1..+1) |
| `autopct` | Дөңгелек диаграммадағы пайыз форматы |
| `cmap` | Түс картасы (мәнге қарай түс беру) |

## Ескерту

- `plt.pie()` мәндерді өзі 100%-ға келтіреді, сондықтан пайызды алдын ала есептеп беру міндетті емес; теріс мәндер `ValueError` тудырады.
- Matplotlib 3.x нұсқасында дөңгелек диаграмма әдепкі бойынша дөңгелек болып салынады, бірақ фигура өлшемі ерекше болса, `plt.axis("equal")` артық болмайды.
- `plt.hist()` `(counts, bins, patches)` кортежін қайтарады: одан аралықтар бойынша нақты сандарды алуға болады. Үлес түріндегі жиілік үшін `density=True` қолданыңыз.
- Екі таралуды бір гистограммада салыстыру үшін бірдей `bins` және `alpha=0.5` беріңіз, әйтпесе бағаналар бірін-бірі жауып қалады.
- `df.corr()` әдепкі бойынша Пирсон коэффициентін (сызықтық байланыс) есептейді; сызықтық емес монотонды байланыс үшін `method="spearman"` бар. Pandas 2.x нұсқасында мәтіндік бағандары бар кесте үшін `numeric_only=True` қажет.
- Құжаттама: [pyplot.pie](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.pie.html), [pyplot.hist](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.hist.html), [pyplot.scatter](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.scatter.html).
