## Базалық деңгей

**1-тапсырма. «Диаграмманы таңда» (ауызша/жазбаша).** Әр жағдайға диаграмма түрін таңдап, неге екенін бір сөйлеммен түсіндіріңіз:
1. Соңғы 10 жылдағы Қазақстан халқының саны.
2. Үйірме оқушыларының 10–17 жас бойынша таралуы (60 оқушы).
3. Мектеп асханасындағы сатылымның тағамдар бойынша үлесі (5 тағам).
4. Оқушылардың ойынға жұмсайтын уақыты мен орташа бағасы.
5. 5 мектептің олимпиададағы жүлде саны.
6. Ұялы телефон батареясының сыйымдылығы мен бағасы (30 модель).

**2-тапсырма. Апталық уақыт.** Аружан бір аптада уақытын былай бөлді (сағат): Ұйқы — 56, Мектеп — 35, Үй тапсырмасы — 14, Спорт — 6, Гаджеттер — 21, Басқа — 36. Дөңгелек диаграмма салыңыз: пайыздар көрсетілсін, «Гаджеттер» секторы `explode` арқылы бөлініп тұрсын.

**3-тапсырма. Бақылау нәтижелері.** 30 оқушының баллы:

**4-тапсырма. Тауар бағасы мен сатылымы.** Бір дүкендегі 8 тауар: баға (теңге) `[300, 450, 600, 800, 1000, 1200, 1500, 2000]`, айлық сатылым (дана) `[520, 470, 390, 330, 260, 210, 150, 90]`. Шашырау графигін салыңыз. Байланыс қандай — оң, теріс, жоқ? Корреляция коэффициентін есептеңіз.

## Кеңейтілген деңгей

**5-тапсырма. Модельденген сынып.** NumPy арқылы 200 оқушының деректерін жасаңыз:
```python
import numpy as np

rng = np.random.default_rng(7)
telefon = rng.uniform(1, 8, 200)                       # күніне телефонда, сағат
ball = 95 - 4 * telefon + rng.normal(0, 6, 200)        # балл
```
а) `telefon` гистограммасы (15 bin);
ә) `ball` гистограммасы;
б) `telefon` × `ball` шашырау графигі, `alpha=0.5`;
в) корреляцияны есептеп, графиктің тақырыбына жазыңыз (`f"r = {r:.2f}"`).

**6-тапсырма. Бір DataFrame — үш сұрақ.** `kitap_dukeni.csv` бойынша:
а) Санаттардың жалпы түсімдегі үлесі — дөңгелек диаграмма;
ә) Бір сатылымның сомасы (`tusim`) қалай таралған — гистограмма;
б) `baga` мен `sany` арасындағы байланыс — шашырау графигі, нүктелер санат бойынша түрлі түсті.
Әр графиктен кейін түсініктемеге бір тұжырым жазыңыз.

**7-тапсырма. Сақина диаграммасы.** 2-тапсырманы `wedgeprops={"width": 0.4}` арқылы сақина (donut) түріне келтіріп, ортасына `plt.text(0, 0, "168 сағат", ha="center")` жазыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

**8-тапсырма. Корреляцияны өзің есепте.** Пирсон корреляция коэффициентін формула бойынша **Pandas-сыз**, тек циклдармен есептейтін `korrelyatsiya(x, y)` функциясын жазыңыз:

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √(Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²)

4-тапсырманың деректерінде нәтижені `pandas.Series.corr` нәтижесімен салыстырыңыз.

**8-тапсырма**
```python
import pandas as pd


def korrelyatsiya(x, y):
    """Пирсон корреляция коэффициенті."""
    n = len(x)
    x_orta = sum(x) / n
    y_orta = sum(y) / n
    alym = 0
    sx = 0
    sy = 0
    for i in range(n):
        dx = x[i] - x_orta
        dy = y[i] - y_orta
        alym += dx * dy
        sx += dx ** 2
        sy += dy ** 2
    return alym / (sx * sy) ** 0.5


baga = [300, 450, 600, 800, 1000, 1200, 1500, 2000]
satylym = [520, 470, 390, 330, 260, 210, 150, 90]
print(round(korrelyatsiya(baga, satylym), 4))
print(round(pd.Series(baga).corr(pd.Series(satylym)), 4))
```
Екі нәтиже бірдей болуы керек.
