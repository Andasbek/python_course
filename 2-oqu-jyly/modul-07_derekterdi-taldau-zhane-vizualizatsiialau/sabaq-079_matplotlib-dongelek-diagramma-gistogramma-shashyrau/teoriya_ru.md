## 1. Круговая диаграмма — `plt.pie()`

**Когда?** Чтобы показать **части одного целого** (доли): структуру бюджета, доли ответов в опросе. Сумма частей должна составлять 100%.

```python
import matplotlib.pyplot as plt

baptar = ["Еда", "Транспорт", "Коммунальные", "Одежда", "Развлечения"]
shygys = [120000, 30000, 45000, 25000, 20000]    # тенге в месяц

plt.pie(shygys, labels=baptar, autopct="%1.1f%%", startangle=90)
plt.title("Ежемесячные расходы семьи")
plt.axis("equal")      # чтобы круг не стал овалом
plt.show()
```

Результат: круг из пяти секторов; самый большой сектор — «Еда» (50,0%), остальные: Коммунальные 18,8%, Транспорт 12,5%, Одежда 10,4%, Развлечения 8,3%.

| Параметр | Значение |
|---|---|
| `labels` | Названия секторов |
| `autopct="%1.1f%%"` | Подписать процент на каждом секторе (с одним знаком после запятой) |
| `startangle=90` | Первый сектор начинается «с 12 часов» |
| `explode` | «Выдвинуть» сектор, напр. `[0.1, 0, 0, 0, 0]` |
| `colors` | Список цветов |
| `wedgeprops={"width": 0.4}` | Кольцевая (donut) диаграмма |

Вариант на Pandas: `df["qala"].value_counts().plot(kind="pie", autopct="%1.0f%%")`.

**Ограничения круговой диаграммы:**
- лучше, чтобы секторов было не более **5–6** (мелкие объединяют в «Прочее»);
- глаз человека плохо сравнивает углы: 23% и 25% различить трудно — если нужно точное сравнение, лучше столбцы;
- изменение во времени никогда не показываем круговой диаграммой.

## 2. Гистограмма — `plt.hist()`

**Когда?** Чтобы показать **распределение одной числовой величины**: в каком диапазоне значения встречаются чаще? Например: баллы ЕНТ 200 учеников, рост учеников класса, длительность поездки на такси.

Гистограмма разбивает значения на **интервалы (bin)** и считает, сколько значений попало в каждый интервал:

```text
Баллы: 52, 61, 64, 68, 71, 72, 75, 77, 78, 81, 83, 85, 88, 94

Интервал   Количество
50–60      █               1
60–70      ███             3
70–80      █████           5
80–90      ████            4
90–100     █               1
```

```python
import matplotlib.pyplot as plt

ballar = [52, 61, 64, 68, 71, 72, 75, 77, 78, 81, 83, 85, 88, 94]

plt.hist(ballar, bins=[50, 60, 70, 80, 90, 100], color="skyblue", edgecolor="black")
plt.title("Результаты контрольной работы")
plt.xlabel("Балл")
plt.ylabel("Количество учеников")
plt.show()
```

Результат: пять столбцов, самый высокий — в интервале 70–80 (5 учеников).

Параметр `bins`:
- если это число (`bins=10`) — отрезок между min и max делится на 10 равных интервалов;
- если список — границы интервалов задаём сами.

Слишком мало bin — информация теряется; слишком много — получается шумная картинка, похожая на «расчёску». Обычно хорошо 8–20.

### Распределение в больших данных

Смоделируем с NumPy рост 1000 «учеников» (генератор случайных чисел `np.random.default_rng`):

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
boiy = rng.normal(loc=165, scale=8, size=1000)   # в среднем 165 см, разброс 8 см

plt.hist(boiy, bins=20, color="mediumpurple", edgecolor="white")
plt.axvline(boiy.mean(), color="red", linestyle="--", label=f"Среднее: {boiy.mean():.1f} см")
plt.title("Рост 1000 учеников")
plt.xlabel("Рост, см")
plt.ylabel("Количество учеников")
plt.legend()
plt.show()
```

Результат: форма «колокола» — высокая середина, низкие края. Это **нормальное распределение**. Так распределены многие величины в природе (рост, вес, ошибка измерения).

### Столбчатая диаграмма ≠ гистограмма

| | Столбчатая диаграмма | Гистограмма |
|---|---|---|
| По оси X | Категории (города, предметы) | Числовые интервалы (60–70, 70–80) |
| Между столбцами | Есть промежутки | Столбцы соприкасаются |
| Можно ли менять порядок | Да | Нет (числовая ось) |
| Нужно ли заранее подсчитать данные | Да (`groupby`/`value_counts`) | Нет, `hist` считает сам |
| Вопрос | «Какой категории больше?» | «Как распределены значения?» |

## 3. Диаграмма рассеяния — `plt.scatter()`

**Когда?** Чтобы показать **связь между двумя числовыми величинами**. Каждый объект (ученик, город, товар) — одна точка: X — одна величина, Y — другая.

```python
import matplotlib.pyplot as plt

uiqy_sagat = [5, 6, 6.5, 7, 7, 7.5, 8, 8, 8.5, 9, 6, 5.5]
ball = [62, 68, 70, 75, 72, 80, 85, 82, 88, 90, 65, 60]

plt.scatter(uiqy_sagat, ball, color="darkgreen", s=60)
plt.title("Продолжительность сна и балл за контрольную")
plt.xlabel("Сон, часы")
plt.ylabel("Балл")
plt.grid(True, alpha=0.3)
plt.show()
```

Результат: точки образуют «облако», вытянутое из левого нижнего угла в правый верхний — **чем больше сна, тем выше балл**.

### Виды корреляции (связи)

```text
 Положительная          Отрицательная            Связи нет
 Y│        • •          Y│ • •                   Y│ •   •    •
  │     • •              │   • •                  │   •  •  •
  │   • •                │      • •               │ •    •   •
  │ • •                  │         • •            │    •   •
  └──────── X            └──────────── X          └──────────── X
 (сон ↑ → балл ↑)       (телефон ↑ → балл ↓)     (рост ↔ балл)
```

Силу связи в виде числа показывает **коэффициент корреляции** (r): от −1 до +1. Близко к +1 — сильная положительная, близко к −1 — сильная отрицательная, близко к 0 — связи нет.

```python
import pandas as pd

df = pd.DataFrame({
    "uiqy": [5, 6, 6.5, 7, 7, 7.5, 8, 8, 8.5, 9, 6, 5.5],
    "ball": [62, 68, 70, 75, 72, 80, 85, 82, 88, 90, 65, 60],
})
print("Корреляция:", round(df["uiqy"].corr(df["ball"]), 2))
```

Результат:
```text
Корреляция: 0.98
```

> **Важно:** корреляция ≠ причинно-следственная связь! Продажи мороженого и случаи утопления растут вместе, но мороженое не причина — причина обоих явлений в летней жаре.

### Точки разного цвета и размера

`scatter` может «закодировать» в точке и третью, и четвёртую характеристику:

```python
import matplotlib.pyplot as plt

halyq = [2.3, 1.4, 1.2, 0.6, 0.5, 0.4]           # млн человек (приблизительно)
audan = [0.68, 0.80, 1.17, 2.30, 0.55, 0.38]     # тыс. км² (приблизительно)
qalalar = ["Алматы", "Астана", "Шымкент", "Актобе", "Караганда", "Тараз"]

plt.scatter(audan, halyq, s=[h * 300 for h in halyq], c=halyq, cmap="viridis", alpha=0.7)
for i in range(len(qalalar)):
    plt.text(audan[i], halyq[i], qalalar[i], fontsize=9)
plt.colorbar(label="Население, млн")
plt.xlabel("Площадь, тыс. км²")
plt.ylabel("Население, млн")
plt.title("Города: площадь и население")
plt.show()
```

- `s` — размер точки (если передать список, у каждой точки свой размер — «пузырьковая диаграмма»);
- `c` + `cmap` — цвет в зависимости от значения;
- `alpha` — прозрачность (полезно, когда точки перекрывают друг друга).

## 4. Выбор типа диаграммы

| Вопрос анализа | Диаграмма | Matplotlib |
|---|---|---|
| Как изменялось во времени? | Линейная | `plot` |
| Сравнение категорий | Столбчатая | `bar`, `barh` |
| Состав целого, доли (≤ 6 частей) | Круговая | `pie` |
| Распределение одной величины | Гистограмма | `hist` |
| Связь между двумя величинами | Рассеяния | `scatter` |

**Алгоритм выбора:**
1. Сколько числовых величин участвует? Одна → столбцы/круговая/гистограмма; две → рассеяние; время + величина → линия.
2. Если величина одна: по категориям (столбцы), часть целого (круговая) или распределение (гистограмма)?
3. Что важно зрителю: точное сравнение (столбцы) или общее впечатление (круговая)?

## Частые ошибки

**1. Отрицательные значения или значения, не связанные со 100%, в круговой диаграмме.** Температуры, значения по годам — для круговой не подходят.

**2. Столбцы вместо гистограммы.**
```python
plt.bar(range(len(ballar)), ballar)    # по столбцу на ученика — распределения не видно
```
Правильно:
```python
plt.hist(ballar, bins=5)
```

**3. Категориальный X в `scatter`.** `plt.scatter(["Алматы", "Астана"], [2.3, 1.4])` работает, но по смыслу это столбчатая диаграмма. Рассеяние — только для двух **чисел**.

**4. Ошибка в строке `autopct`.** `autopct="%1.1f%"` → ошибка; знак процента дважды: `"%1.1f%%"`.

**5. Круг `pie` получается овальным.** В старых версиях нужен `plt.axis("equal")`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Круговая диаграмма (pie chart) | Показывает части целого секторами |
| Гистограмма (histogram) | Распределение числовой величины по интервалам |
| Bin (интервал) | Один интервал гистограммы |
| Распределение | Где значения встречаются часто/редко |
| Диаграмма рассеяния (scatter plot) | Точечное изображение двух числовых величин |
| Корреляция | Степень совместного изменения двух величин (−1..+1) |
| `autopct` | Формат процентов в круговой диаграмме |
| `cmap` | Цветовая карта (цвет в зависимости от значения) |

## Примечание

- `plt.pie()` сам нормирует значения к 100%, поэтому передавать заранее посчитанные проценты не обязательно; отрицательные значения вызывают `ValueError`.
- В Matplotlib 3.x круговая диаграмма по умолчанию уже рисуется круглой, но `plt.axis("equal")` не помешает при нестандартном размере фигуры.
- `plt.hist()` возвращает кортеж `(counts, bins, patches)`: из него можно взять точные количества по интервалам. Для частот в долях используйте `density=True`.
- Для сравнения двух распределений на одной гистограмме задавайте одинаковые `bins` и `alpha=0.5`, иначе столбцы перекроют друг друга.
- `df.corr()` по умолчанию считает коэффициент Пирсона (линейная связь); для нелинейной монотонной связи есть `method="spearman"`. В Pandas 2.x для таблицы с текстовыми столбцами нужен `numeric_only=True`.
- Документация: [pyplot.pie](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.pie.html), [pyplot.hist](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.hist.html), [pyplot.scatter](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.scatter.html).
