# Сабақ 66. Практикалық тапсырмалар: жобаның негізгі логикасы

> Бүгін әр оқушы **өз жобасымен** жұмыс істейді. Төмендегі деңгейлер – жұмыс кезеңдері. Тұрып қалсаң – «Көмек карточкаларын» қара.

## Базалық деңгей (міндетті – MVP)

**1-қадам. Бүгінгі мақсат.** Дәптерге/файлға жаз: «Сабақ соңында менің бағдарламам ... істей алады». Мысалы: «10 сұрақ қойып, ұпайды шығарады».

**2-қадам. Деректер.** Жобаңа қажетті деректерді (сұрақтар, сөздер, тауарлар, бөлмелер) әзірге код ішінде тізім немесе сөздік ретінде жаз (кемінде 5 жазба).

**3-қадам. Ең кішкентай функция.** Жоспарыңдағы ең қарапайым «таза логика» функциясын (ішінде `input` жоқ) жаз және оны 3 түрлі мәнмен тексер:

```python
def is_even(n):
    return n % 2 == 0

# Тексеру
print(is_even(4), is_even(7), is_even(0))   # True False True
```

**4-қадам. Қалған логика функциялары.** Жоспарыңдағы функцияларды бірінен соң бірін жаз. Әрқайсысынан кейін – іске қосу және тексеру.

**5-қадам. MVP біріктіру.** Функцияларды бірге шақырып, бағдарламаның басынан аяғына дейін жұмыс істейтінін тексер. Көшірмесін сақта: `жоба_2027-05-03.py`.

## Кеңейтілген деңгей

**6-қадам. Енгізуді тексеру.** Пайдаланушы енгізетін әр мән үшін ойлан: бос жол, әріп, теріс сан енгізілсе не болады? `try...except` және `while` арқылы қорға (58-сабақ).

**7-қадам. Шекаралық мәндер.** Логика функцияларыңды шекаралық мәндермен тексер (0, ең үлкен мән, бос тізім, бір элементті тізім) және нәтижесін түсініктемеге жаз.

**8-қадам. «Жақсы нұсқа» мүмкіндігі.** MVP дайын болса, жоспардағы «жақсы нұсқадан» бір мүмкіндікті қос (мысалы, кездейсоқ рет, статистика, деңгейлер).

## ★ Олимпиадалық / шығармашылық тапсырма

**9. Өз модулің.** Логика функцияларын жеке `logic.py` файлына шығарып, `main.py`-да `import logic` арқылы қолдан (62-сабақ). Бұл – нағыз жобалардағыдай құрылым.

**10. Автотест.** Логика функцияларын тексеретін `test_logic()` функциясын жаз: ол функцияларды белгілі мәндермен шақырып, нәтиже күтілгенге тең болмаса «ҚАТЕ: ...» деп шығарады, барлығы дұрыс болса «Барлық тест өтті!». (Келесі жылы мұны `assert` және `pytest` арқылы жасаймыз.)

```python
operations = [
    {"type": "кіріс", "sum": 5000, "category": "әжем берді"},
    {"type": "шығыс", "sum": 1200, "category": "тамақ"},
    {"type": "шығыс", "sum": 800, "category": "кітап"},
]


def balance(operations):
    total = 0
    for op in operations:
        if op["type"] == "кіріс":
            total += op["sum"]
        else:
            total -= op["sum"]
    return total


print("Қалдық:", balance(operations), "теңге")   # 3000
```

**Демо-жоба: «Қазақстан викторинасы» – 66-сабақ соңындағы күйі (MVP):**

```python
import random

QUESTIONS = {
    "Қазақстанның астанасы қай қала?": "астана",
    "Қазақстанның ұлттық валютасы?": "теңге",
    "Қазақстан тәуелсіздігін қай жылы жариялады?": "1991",
    "Қазақстандағы ең үлкен көлдердің бірі – Балқаш па, әлде Байкал ма?": "балқаш",
    "Алматыдағы биік таулы мұз айдыны?": "медеу",
}


def normalize(text):
    """Жауапты салыстыруға дайындайды."""
    return text.strip().lower()


def check_answer(user_answer, correct_answer):
    """Жауап дұрыс болса True қайтарады."""
    return normalize(user_answer) == normalize(correct_answer)


def ask_question(number, question, answer):
    """Бір сұрақ қойып, нәтижесін қайтарады."""
    user = input(f"{number}. {question} ")
    if check_answer(user, answer):
        print("Дұрыс!")
        return True
    print("Қате. Дұрыс жауап:", answer)
    return False


def grade(score, total):
    """Ұпайды бағаға айналдырады."""
    percent = score / total * 100
    if percent >= 85:
        return "5 – керемет!"
    elif percent >= 65:
        return "4 – жақсы"
    elif percent >= 40:
        return "3 – жаман емес"
    return "2 – тағы дайындал"


def play(questions):
    """Ойын циклі, ұпайды қайтарады."""
    items = list(questions.items())
    random.shuffle(items)
    score = 0
    number = 1
    for question, answer in items:
        if ask_question(number, question, answer):
            score += 1
        number += 1
    return score


score = play(QUESTIONS)
print(f"Нәтиже: {score}/{len(QUESTIONS)}. Баға: {grade(score, len(QUESTIONS))}")
```

**10-тапсырма – автотест үлгісі:**

```python
def check_answer(user_answer, correct_answer):
    return user_answer.strip().lower() == correct_answer.strip().lower()


def grade(score, total):
    percent = score / total * 100
    if percent >= 85:
        return "5"
    elif percent >= 65:
        return "4"
    elif percent >= 40:
        return "3"
    return "2"


def test_logic():
    tests = [
        (check_answer(" Астана", "астана"), True),
        (check_answer("Алматы", "астана"), False),
        (grade(10, 10), "5"),
        (grade(0, 10), "2"),
        (grade(4, 10), "3"),
    ]
    ok = True
    for i in range(len(tests)):
        got, expected = tests[i]
        if got != expected:
            print(f"ҚАТЕ: {i + 1}-тест, күтілді {expected}, алынды {got}")
            ok = False
    if ok:
        print("Барлық тест өтті!")


test_logic()
```

**Педагогке кеңестер:**
- Сабақтың алғашқы 20 минутында әр оқушының қасына барып, MVP көлемін тексер; тым үлкен болса – бірден қысқарт.
- Бір қатеге 10 минуттан артық «тұрып қалған» оқушыға бағыттаушы сұрақ қой («Бұл функция не қабылдайды? Не қайтаруы керек? Қолмен тексеріп көрейікші»), дайын код берме.
- Жылдам оқушыларды «көмекші» ретінде тарт (код шолуы), бірақ олар басқаның кодын жазбауы керек.
- Сабақ соңында әр оқушының көшірме сақтағанын тексер.
