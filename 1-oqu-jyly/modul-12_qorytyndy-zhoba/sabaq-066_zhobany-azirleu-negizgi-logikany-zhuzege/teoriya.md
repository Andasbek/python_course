## 1. Негізгі логика деген не?

Кез келген бағдарламаны екі қабатқа бөлуге болады:

| Қабат | Не істейді | Викторинадағы мысал |
|---|---|---|
| **Негізгі логика** (бизнес-логика, «ми») | Есептейді, тексереді, шешім қабылдайды | Жауапты тексеру, ұпай санау, бағалау |
| **Интерфейс** («бет») | Пайдаланушымен сөйлеседі | Мәзір, `input`, `print`, әдемі безендіру |
| **Деректерді сақтау** («жады») | Файлға жазады, оқиды | `questions.txt`, `results.txt` |

Әзірлеу әдетте **логикадан** («мидан») басталады, ал **интерфейс пен сақтау** соның үстіне қосылады.

**Аналогия.** Автокөлікте қозғалтқыш (логика) мен руль/орындықтар (интерфейс) бар. Алдымен қозғалтқышты жасап, оның жұмыс істейтінін тексереміз – содан кейін ғана әдемі салон орнатамыз.

Логиканы интерфейстен **бөліп** жазудың пайдасы:
- функцияларды тексеру оңай (`input` күтпей-ақ);
- интерфейсті өзгертсең (мысалы, консольді Tkinter терезесімен алмастырсаң), логика сол күйі қалады.

## 2. Әзірлеу стратегиясы: кішкене қадамдармен

```text
  +---------------+     +-------------+     +-----------+
  | 1 функция жаз | --> | Іске қос,   | --> | Жұмыс     |
  | (5-15 жол)    |     | тексер      |     | істей ме? |
  +---------------+     +-------------+     +-----------+
         ^                                    |      |
         |                 иә: келесісіне өт  |      | жоқ: түзет
         +------------------------------------+      v
                                              (қатені тап,
                                               қайта тексер)
```

**Ережелер:**
1. Бір уақытта **бір** функциямен жұмыс істе.
2. Функцияны жазған бойда оны **жеке тексер**: файлдың соңында шақырып, нәтижесін `print` арқылы шығар.
3. Әр 10–15 минут сайын бағдарламаны **іске қос**. 50 жол жазып, кейін іске қоссаң – 10 қатеге тап боласың.
4. Шықпай жатса – қате мәтінін (Traceback) оқы, айнымалылардың мәнін `print` немесе жөндеуіш арқылы тексер, құжаттаманы қара.
5. Жұмыс істейтін нұсқаны **сақта** (көшірме) – содан кейін ғана жаңа нәрсе қос.

### «Жоғарыдан төменге» әдісі

Алдымен «қаңқа» жазылады: функциялар бар, бірақ іші бос (бітеуіш, заглушка). Содан кейін олар **бірінен соң бірі** толтырылады. Бағдарлама әр уақытта іске қосылатын күйде қалады.

```python
def play(questions):
    """Әзірге бітеуіш: кейін толтырамыз."""
    print("[play әлі жазылмаған]")
    return 0

print(play({}))
```

Нәтижесі:
```text
[play әлі жазылмаған]
0
```

## 3. Демо-жоба: «Қазақстан викторинасының» логикасы

### 1-қадам. Деректер

Логиканы тексеру үшін алғашқы қадамда деректерді тікелей код ішінде сақтауға болады (кейін оларды файлға шығарады):

```python
QUESTIONS = {
    "Қазақстанның астанасы қай қала?": "астана",
    "Қазақстанның ұлттық валютасы?": "теңге",
    "Қазақстан тәуелсіздігін қай жылы жариялады?": "1991",
    "Қазақстандағы ең үлкен көлдердің бірі – Балқаш па, әлде Байкал ма?": "балқаш",
    "Алматыдағы биік таулы мұз айдыны?": "медеу",
}
print("Сұрақтар саны:", len(QUESTIONS))
```

Нәтижесі:
```text
Сұрақтар саны: 5
```

(Бас әріппен жазылған `QUESTIONS` – **тұрақты** (константа): бағдарлама барысында өзгермейтін деректер.)

### 2-қадам. Ең кішкентай функция – жауапты тексеру

```python
def normalize(text):
    """Жауапты салыстыруға дайындайды: бос орын мен регистрді алып тастайды."""
    return text.strip().lower()


def check_answer(user_answer, correct_answer):
    """Жауап дұрыс болса True қайтарады."""
    return normalize(user_answer) == normalize(correct_answer)


# тексеру
print(check_answer("  Астана ", "астана"))
print(check_answer("Алматы", "астана"))
```

Нәтижесі:
```text
True
False
```

`check_answer` ішінде `input` те, `print` те жоқ – ол **таза логика**. Сондықтан оны оңай тексереміз.

### 3-қадам. Ұпайды бағаға айналдыру

```python
def grade(score, total):
    """Ұпайды бағаға айналдырады."""
    percent = score / total * 100
    if percent >= 85:
        return "5 – керемет!"
    elif percent >= 65:
        return "4 – жақсы"
    elif percent >= 40:
        return "3 – жаман емес"
    return "2 – тағы дайындал"


print(grade(5, 5), "|", grade(3, 5), "|", grade(1, 5))
```

Нәтижесі:
```text
5 – керемет! | 3 – жаман емес | 2 – тағы дайындал
```

**Шекаралық мәндерді** тексер: 85% дәл болғанда не болады? 0 ұпай болғанда ше?

### 4-қадам. Бір сұрақ және бүкіл ойын

```python
import random


def normalize(text):
    return text.strip().lower()


def check_answer(user_answer, correct_answer):
    return normalize(user_answer) == normalize(correct_answer)


def ask_question(number, question, answer):
    """Бір сұрақ қойып, нәтижесін (True/False) қайтарады."""
    user = input(f"{number}. {question} ")
    if check_answer(user, answer):
        print("Дұрыс!")
        return True
    print("Қате. Дұрыс жауап:", answer)
    return False


def play(questions):
    """Ойын: сұрақтарды кездейсоқ ретпен қояды, ұпайды қайтарады."""
    items = list(questions.items())
    random.shuffle(items)
    score = 0
    number = 1
    for question, answer in items:
        if ask_question(number, question, answer):
            score += 1
        number += 1
    return score


QUESTIONS = {"Қазақстанның астанасы қай қала?": "астана", "Ұлттық валюта?": "теңге"}
result = play(QUESTIONS)
print(f"Нәтиже: {result}/{len(QUESTIONS)}")
```

Нәтижесі (мысал):
```text
1. Ұлттық валюта? Теңге
Дұрыс!
2. Қазақстанның астанасы қай қала? Алматы
Қате. Дұрыс жауап: астана
Нәтиже: 1/2
```

MVP дайын! Енді бұл – жұмыс істейтін бағдарлама. Келесі қадамдар – мәзір, файлдар және безендіру.

## 4. Әртүрлі жобалардағы «негізгі логика»

| Жоба | Негізгі логика (функциялар) |
|---|---|
| Дар ағашы | `choose_word()`, `mask_word(word, guessed)`, `is_won(word, guessed)` |
| Қалта ақшасы | `add_operation(...)`, `balance(operations)`, `by_category(operations)` |
| Тамагочи | `feed(pet)`, `play_with(pet)`, `tick(pet)` (уақыт өтуі), `is_alive(pet)` |
| Күнделік | `add_task(...)`, `overdue(tasks, today)`, `mark_done(...)` |
| Тренажер | `make_example(level)`, `check(...)`, `statistics(results)` |
| Квест | `rooms` сөздігі, `move(room, direction)`, `take(item, inventory)` |

Мысал – «Дар ағашы» логикасының өзегі:

```python
def mask_word(word, guessed):
    """Табылмаған әріптерді _ белгісімен жасырады."""
    result = ""
    for ch in word:
        if ch in guessed:
            result += ch + " "
        else:
            result += "_ "
    return result.strip()


def is_won(word, guessed):
    """Сөздің барлық әріпі табылса True."""
    for ch in word:
        if ch not in guessed:
            return False
    return True


print(mask_word("python", {"p", "o"}))
print(is_won("тау", {"т", "а", "у", "к"}))
```

Нәтижесі:
```text
p _ _ _ o _
True
```

## 5. Деректерді функциялар арасында беру

Жаһандық айнымалыларды функция ішінде (`global` арқылы) өзгертуден аулақ бол. Дұрыс жол – **параметр арқылы беру** және **`return` арқылы қайтару**:

```python
def add_points(score, points):
    return score + points

score = 0
score = add_points(score, 10)
score = add_points(score, 5)
print("Ұпай:", score)
```

Нәтижесі:
```text
Ұпай: 15
```

Бірнеше мәнді бірге сақтау керек болса (мысалы, тамагочидің күйі), **сөздікті** қолдан – ол функцияға беріліп, ішінде өзгертіле алады:

```python
def feed(pet):
    pet["hunger"] = max(0, pet["hunger"] - 30)
    pet["mood"] = min(100, pet["mood"] + 5)

pet = {"name": "Мысық", "hunger": 70, "mood": 50}
feed(pet)
print(pet)
```

Нәтижесі:
```text
{'name': 'Мысық', 'hunger': 40, 'mood': 55}
```

## 6. Нұсқаларды сақтау және кодты құжаттау

Жұмыс істейтін нұсқаны өзгерте бастамай тұрып сақтау керек:
- ең қарапайым тәсіл – **күні жазылған көшірме**: `quiz_2027-05-03.py`, жоба папкасы бұлтта немесе флешкада;
- кәсіби тәсіл – **Git** нұсқаларды басқару жүйесі: `git init` (репозиторий құру), `git add .` және `git commit -m "Жауапты тексеру қосылды"` (суретін сақтау), `git log` (тарих).

Аяқталмаған жерлерді кодта `# TODO:` түсіндірмесімен белгілейді, ал әр функцияның міндетін **docstring**-те сипаттайды:

```python
def play(questions):

    # TODO: уақыт шектеуін қосу

```

## Жиі кездесетін қателер

**1. Бәрін бірден жазу.** 100 жол жазып, бірінші рет іске қосу – қателер тауы. Кішкене қадам + тексеру!

**2. Функция `return` орнына `print` жасайды.**

```python
def total_price(prices):
    print(sum(prices))     # нәтижені басқа функция қолдана алмайды

def total_price_ok(prices):
    return sum(prices)     # дұрыс: мәнді қайтарады

bill = total_price_ok([500, 1200, 300])
print("Барлығы:", bill, "теңге")
```

**3. Функцияны жариялау алдында шақыру.** Python кодты жоғарыдан төмен оқиды: функцияны шақыру оның `def` жолынан **кейін** болуы керек (немесе `main()` ішінде, ал `main()` файлдың соңында шақырылады).

**4. Цикл ішінде «жоғалған» `return`.** `return` циклді де, функцияны да бірден тоқтатады. Цикл соңына дейін жүруі керек болса, `return`-ді цикл сыртына шығар.

**5. Тексерусіз «әдемілеу».** Логика жұмыс істемей тұрып, түстер мен безендіруге уақыт кетірме – алдымен MVP!

**6. Көшірме сақтамау.** Жұмыс істейтін нұсқаны «жақсартып» жүріп бұзып алу – ең жиі кездесетін өкініш. Әр сәтті қадамнан кейін сақта.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Негізгі логика | Бағдарламаның есептейтін, шешім қабылдайтын бөлігі |
| Интерфейс | Пайдаланушымен өзара әрекет бөлігі |
| Бітеуіш (заглушка, stub) | Уақытша, әлі толтырылмаған функция |
| Инкрементті әзірлеу | Кішкене қадамдармен, әр қадамды тексеріп жазу |
| Тұрақты (константа) | Өзгермейтін мән, атауы БАС ӘРІППЕН жазылады |
| Шекаралық мән | Шарттың шекарасындағы мән (0, 85%, бос тізім) |
| Docstring | Функция басындағы құжаттама жолы |

## Ескерту

- «Логика / интерфейс / сақтау» бөлінісі – көптеген бағдарламалар архитектурасының негізі (үлкен жобаларда бұл MVC үлгілері, қабатты архитектура). `input`/`print`-сіз таза функцияларды `assert` немесе `unittest` модулі арқылы тексеру оңай.
- PEP 8 бойынша тұрақтылар `UPPER_CASE` түрінде жазылып, модуль басында жарияланады; Python оларды өзгертуге тыйым салмайды – бұл тек келісім.
- Функцияға берілген өзгермелі объектілер (тізім, сөздік) «орнында» өзгереді – шақырған код өзгерістерді көреді. Бұл қажет болмаса, көшірмесін бер: `dict(pet)` немесе `pet.copy()`.
- Өзгермелі әдепкі мәндерді қолданба: `def f(items=[])` – тізім бір рет құрылып, шақырулар арасында деректерді «жинайды». Дұрысы: `def f(items=None)` және ішінде `if items is None: items = []`.
- `random.shuffle()` тек тізіммен жұмыс істейді; сөздік үшін алдымен жұптар тізімін ал: `list(d.items())`.
- Құжаттама: [Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions), [PEP 257 – Docstring Conventions](https://peps.python.org/pep-0257/).
