# Сабақ 65. Практикалық тапсырмалар: жоба тақырыбы және жоспары

> Бүгінгі сабақтың нәтижесі – толтырылған **жоба паспорты**, **техникалық тапсырма**, **функциялар кестесі**, **псевдокод/блок-схема** және **жұмыс жоспары**. Барлығын `project_plan.txt` (немесе дәптерге) жазып, педагогке көрсет.

## Базалық деңгей

**1-тапсырма. Идеялар миға шабуылы (10 мин).** Төмендегі тізімнен немесе өз ойыңнан 3 идеяны жаз. Әрқайсысына 1–5 баллмен баға қой: «маған қызықты ма?», «орындай аламын ба?», «өтілген тақырыптарды көрсете ме?». Ең көп балл жинағанын таңда.

**2-тапсырма. Жоба паспорты.** Үлгіні көшіріп, толтыр:

```text
ЖОБА ПАСПОРТЫ
Автор(лар): ______________________   Жасы/сыныбы: ______
Жобаның атауы: ____________________________________________
Түрі: ойын / тренажер / пайдалы құрал / есептеуіш / графика
Мақсаты (қандай мәселені шешеді?): _________________________
Кімге арналған: ___________________________________________
Неге осы тақырыпты таңдадым: _______________________________
Қолданылатын тақырыптар (белгіле):
  [ ] if/elif/else   [ ] for/while   [ ] тізім   [ ] сөздік/жиын
  [ ] жолдар         [ ] функциялар  [ ] файлдар [ ] try...except
  [ ] math  [ ] random  [ ] time/datetime  [ ] turtle
Деңгейі: ★ / ★★ / ★★★
```

**3-тапсырма. MVP және қосымшалар.** Үш деңгейлі кесте құр: MVP (міндетті, 3–5 мүмкіндік), «жақсы нұсқа» (2–3 мүмкіндік), «үздік нұсқа» (1–3 мүмкіндік).

**4-тапсырма. Техникалық тапсырма.** Теориядағы үлгі бойынша өз жобаңның ТТ-ын жаз (атауы, мақсаты, кемінде 5 функционалдық талап, кіріс/шығыс, технологиялар, шектеулер).

## Кеңейтілген деңгей

**5-тапсырма. Функциялар кестесі.** Жобаңды кемінде 5 функцияға бөл. Әрқайсысы үшін: атауы, міндеті, параметрлері, қайтаратын мәні.

```text
| Функция          | Міндеті                    | Параметрлер     | Қайтарады |
|------------------|----------------------------|-----------------|-----------|
| load_questions   | Сұрақтарды файлдан оқиды   | file_name       | сөздік    |
| ...              | ...                        | ...             | ...       |
```

**6-тапсырма. Псевдокод немесе блок-схема.** Бағдарламаның басты циклін (мәзірін) және ең күрделі функциясының алгоритмін псевдокодпен немесе блок-схемамен сипатта.

**7-тапсырма. Бағдарлама «қаңқасы».** Компьютерде `main.py` файлын құрып, барлық функцияларды бос «бітеуіш» (заглушка) ретінде жаз. Бағдарлама іске қосылып, мәзір шығуы керек. Үлгі:

```python
def load_questions(file_name):
    """Сұрақтарды файлдан оқиды (әзірге уақытша деректер)."""
    return {"Қазақстанның астанасы?": "астана"}


def play(questions):
    """Ойын: сұрақтарды қояды, ұпай қайтарады."""
    print("Ойын әзірге дайын емес...")
    return 0


def show_records():
    """Рекордтарды көрсетеді."""
    print("Рекордтар әзірге жоқ.")


def main():
    questions = load_questions("questions.txt")
    while True:
        print("\n1 – Ойнау\n2 – Рекордтар\n0 – Шығу")
        choice = input("Таңдауың: ")
        if choice == "1":
            score = play(questions)
            print("Ұпай:", score)
        elif choice == "2":
            show_records()
        elif choice == "0":
            print("Сау бол!")
            break
        else:
            print("Мәзірден таңда!")


main()
```

## ★ Олимпиадалық / шығармашылық тапсырма

**8-тапсырма. Жұптық жоба.** Егер досыңмен бірге жоба жасағың келсе: ТТ-ға **рөлдерді бөлу** бөлімін қос (кім қай функцияларды жазады), функциялардың параметрлері мен қайтаратын мәндерін алдын ала **келісіп** жаз – сонда бөліктерің бір-біріне дәл сәйкес келеді.

**9-тапсырма. Пайдаланушы сценарийі.** Жобаңды бірінші рет қолданатын адамның әрекеттерін қадам-қадаммен сипатта («Пайдаланушы бағдарламаны ашады → мәзірді көреді → 1-ді басады → ...») және экранда не шығатынын «макет» ретінде мәтінмен сал.

## Үй тапсырмасы

1. Жоба паспорты мен ТТ-ды аяқтап, `project_plan.txt` файлына көшір.
2. Жобаңа қажетті деректерді дайында: сұрақтар, сөздер, тауарлар тізімі т.б. (кемінде 10 жазба) – оларды файлға `;` немесе `|` бөлгішімен жаз.
3. Келесі сабақта жазатын 2 функцияңды таңда.
