**Задание 1 – 5 ошибок, которые нужно найти:**

1. `total_cost`: `total = ...` – вместо суммы считается только последний товар → `total += ...` (тест 1 даёт 120, а не 420).
2. `discount`: `total > 2000` – граница не включается, а по требованию «включая 2000» → `>=` (тест 2).
3. `discount`: `total * 0.1` – возвращает **саму скидку**, а не цену → `total * 0.9` (тест 3 даёт 300.0, а не 2700.0).
4. Несуществующий товар → `KeyError` (тест 4) – при вводе проверка `if item not in PRICES:`.
5. Количество не число → `ValueError` (тест 5); количество повторно введённого товара не суммируется, а заменяется (тест 6) → `cart[item] = cart.get(item, 0) + count`.

Исправленная версия:

```python
"""Школьный магазин – исправленная версия упражнения по тестированию."""
PRICES = {"тетрадь": 150, "ручка": 120, "линейка": 200, "ластик": 80}
DISCOUNT_FROM = 2000      # порог скидки (тенге)
DISCOUNT_RATE = 0.10      # 10%


def total_cost(cart):
    """Возвращает общую стоимость товаров в корзине."""
    total = 0
    for item, count in cart.items():
        total += PRICES[item] * count
    return total


def discount(total):
    """Возвращает цену со скидкой, начиная с порога (включительно)."""
    if total >= DISCOUNT_FROM:
        return total * (1 - DISCOUNT_RATE)
    return total


def read_count(prompt):
    """Спрашивает, пока не будет введено положительное целое число."""
    while True:
        try:
            count = int(input(prompt))
        except ValueError:
            print("Введи число")
            continue
        if count > 0:
            return count
        print("Количество должно быть больше 0")


def main():
    cart = {}
    while True:
        item = input("Товар (для завершения 'чек'): ").strip().lower()
        if item == "чек":
            break
        if item not in PRICES:
            print("Такого товара нет. Есть товары:", ", ".join(PRICES))
            continue
        cart[item] = cart.get(item, 0) + read_count("Количество: ")
    total = total_cost(cart)
    print("К оплате:", discount(total), "тенге")


# автотесты
assert total_cost({"тетрадь": 2, "ручка": 1}) == 420
assert discount(2000) == 1800.0
assert discount(1999) == 1999
assert discount(total_cost({"тетрадь": 20})) == 2700.0
main()
```

Примечание: результат `discount(2000)` – `1800.0`, дробное число; обсуди с учениками округление до тенге через `round()` или `int()`.

def grade(score, total):
    percent = score / total * 100
    if percent >= 85:
        return 5
    elif percent >= 65:
        return 4
    elif percent >= 40:
        return 3
    return 2


cases = [((17, 20), 5), ((16, 20), 4), ((13, 20), 4), ((8, 20), 3), ((0, 20), 2)]

with open("test_report.txt", "w", encoding="utf-8") as f:
    for args, expected in cases:

        status = "ПРОЙДЕН" if got == expected else "НЕ ПРОЙДЕН"
        if got == expected:

    print(f"Итого: {passed}/{len(cases)} ({passed / len(cases) * 100:.0f}%)", file=f)
print("Отчёт записан в файл test_report.txt")
