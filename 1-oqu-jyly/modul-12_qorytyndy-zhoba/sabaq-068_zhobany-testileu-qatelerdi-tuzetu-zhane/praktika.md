## Базалық деңгей

**1-тапсырма. Жаттығу: «Багтарды аула».** Төмендегі «Мектеп дүкені» бағдарламасында **5 қате** бар (синтаксистік қате жоқ – бағдарлама іске қосылады). Тест-кейстерді орындап, қателерді тап, баг-репорт жаз және түзет.

```python
PRICES = {"дәптер": 150, "қалам": 120, "сызғыш": 200, "өшіргіш": 80}


def total_cost(cart):
    total = 0
    for item, count in cart.items():
        total = PRICES[item] * count
    return total


def discount(total):
    # 2000 теңгеден бастап (2000 қоса) 10% жеңілдік
    if total > 2000:
        return total * 0.1
    return total


def main():
    cart = {}
    while True:
        item = input("Тауар (бітсе 'чек'): ")
        if item == "чек":
            break
        count = int(input("Саны: "))
        cart[item] = count
    total = total_cost(cart)
    print("Төлеуге:", discount(total), "теңге")


main()
```

**1-тапсырма – табылуы тиіс 5 қате:**

1. `total_cost`: `total = ...` – қосындының орнына соңғы тауар ғана есептеледі → `total += ...` (1-тест 120 береді, 420 емес).
2. `discount`: `total > 2000` – шекара қоспайды, ал талап «2000 қоса» → `>=` (2-тест).
3. `discount`: `total * 0.1` – жеңілдіктің **өзін** қайтарады, бағаны емес → `total * 0.9` (3-тест 2700.0 емес, 300.0 береді).
4. Жоқ тауар → `KeyError` (4-тест) – енгізгенде `if item not in PRICES:` тексеру.
5. Саны сан емес → `ValueError` (5-тест); қайта енгізілген тауар саны қосылмайды, ауыстырылады (6-тест) → `cart[item] = cart.get(item, 0) + count`.

Түзетілген нұсқа:

```python
"""Мектеп дүкені – тестілеу жаттығуының түзетілген нұсқасы."""
PRICES = {"дәптер": 150, "қалам": 120, "сызғыш": 200, "өшіргіш": 80}
DISCOUNT_FROM = 2000      # жеңілдік шегі (теңге)
DISCOUNT_RATE = 0.10      # 10%


def total_cost(cart):
    """Себеттегі тауарлардың жалпы құнын қайтарады."""
    total = 0
    for item, count in cart.items():
        total += PRICES[item] * count
    return total


def discount(total):
    """Шектен бастап (шекті қоса) жеңілдікпен бағаны қайтарады."""
    if total >= DISCOUNT_FROM:
        return total * (1 - DISCOUNT_RATE)
    return total


def read_count(prompt):
    """Оң бүтін сан енгізілгенше сұрайды."""
    while True:
        try:
            count = int(input(prompt))
        except ValueError:
            print("Сан енгіз")
            continue
        if count > 0:
            return count
        print("Саны 0-ден үлкен болуы керек")


def main():
    cart = {}
    while True:
        item = input("Тауар (бітсе 'чек'): ").strip().lower()
        if item == "чек":
            break
        if item not in PRICES:
            print("Мұндай тауар жоқ. Бар тауарлар:", ", ".join(PRICES))
            continue
        cart[item] = cart.get(item, 0) + read_count("Саны: ")
    total = total_cost(cart)
    print("Төлеуге:", discount(total), "теңге")


# автотестер
assert total_cost({"дәптер": 2, "қалам": 1}) == 420
assert discount(2000) == 1800.0
assert discount(1999) == 1999
assert discount(total_cost({"дәптер": 20})) == 2700.0
main()
```

Ескерту: `discount(2000)` нәтижесі `1800.0` – бөлшек сан; оқушылармен `round()` немесе `int()` арқылы теңгеге дөңгелектеуді талқыла.

**8-тапсырма:**

```python
def grade(score, total):
    percent = score / total * 100
    if percent >= 85:
        return 5
    elif percent >= 65:
        return 4
    elif percent >= 40:
        return 3
    return 2


cases = [((17, 20), 5), ((16, 20), 4), ((13, 20), 4), ((8, 20), 3), ((0, 20), 2)]
passed = 0
with open("test_report.txt", "w", encoding="utf-8") as f:
    for args, expected in cases:
        got = grade(args[0], args[1])
        status = "ӨТТІ" if got == expected else "ӨТПЕДІ"
        if got == expected:
            passed += 1
        print(f"grade{args} -> {got} (күтілді {expected}): {status}", file=f)
    print(f"Барлығы: {passed}/{len(cases)} ({passed / len(cases) * 100:.0f}%)", file=f)
print("Есеп test_report.txt файлына жазылды")
```
