## 1. Тестілеу деген не?

**Тестілеу** (тестирование, testing) – бағдарламаның талаптарға сай жұмыс істейтінін тексеру және қателерді **табу** процесі.

**Жөндеу** (отладка, debugging) – табылған қатенің **себебін** анықтап, оны **түзету**.

> Тестілеудің мақсаты – «бағдарлама жұмыс істейтінін дәлелдеу» емес, **қателерді табу**. Жақсы тестер – бағдарламаны «бұзуға» тырысатын тестер.

### Тестілеу түрлері

| Түрі | Нені тексереді | Викторинадағы мысал |
|---|---|---|
| Функционалдық | ТТ-дағы әр талап орындала ма | Ойын 8 сұрақ қояды, ұпайды дұрыс санайды |
| Шекаралық | Шарттардың шекарасындағы мәндер | 0 ұпай, барлық жауап дұрыс, 85% дәл |
| Негативтік | Қате, күтілмеген енгізу | Мәзірге «а» енгізу, бос ат, файл жоқ |
| Пайдаланушылық | Ыңғайлылық, түсініктілік | Досың нұсқаусыз ойнай ала ма? |
| Регрессиялық | Түзетуден кейін бұрынғы бөліктер бұзылмады ма | Рекордтарды түзеткен соң, ойын әлі жұмыс істей ме? |

## 2. Тест-кейс

**Тест-кейс** – бір тексерудің нақты сипаттамасы: **не істейміз** → **не күтеміз** → **не болды**.

| № | Әрекет (енгізу) | Күтілетіні | Нақтысы | Өтті ме? |
|---|---|---|---|---|
| 1 | Мәзірде `1`, аты `Дана`, барлық жауап дұрыс | `8/8`, баға 5 | `8/8`, баға 5 | ✔ |
| 2 | Мәзірде `5` | «Мүмкін нұсқалар: 1, 2, 3, 0» | Солай | ✔ |
| 3 | Мәзірде `абв` | Қайта сұрайды | Солай | ✔ |
| 4 | Атты бос қалдыру (Enter) | «Бос болмауы керек!» | Солай | ✔ |
| 5 | Жауапты бас әріппен: `АСТАНА` | Дұрыс деп саналады | Солай | ✔ |
| 6 | Жауапты бос орынмен: `  теңге ` | Дұрыс деп саналады | Солай | ✔ |
| 7 | `results.txt` жоқ кезде «Рекордтар» | «Әзірге нәтижелер жоқ» | **Бағдарлама құлады** | ✘ |
| 8 | `questions.txt` жоқ кезде «Ойнау» | «Сұрақтар жоқ» хабарламасы | Солай | ✔ |
| 9 | Сұрақ қосып, ойнау | Жаңа сұрақ ойында бар | Солай | ✔ |
| 10 | `results.txt` ішінде бүлінген жол | Жол өткізіледі | Солай | ✔ |

7-тест **сәтсіз** – баг табылды, оны түзету керек (4-бөлімді қара).

### Шекаралық мәндерді қалай таңдаймыз?

Шарт `if percent >= 85:` болса, тексереміз: **84**, **85**, **86** – шекараның екі жағы және өзі. Сондай-ақ «ерекше» мәндер: **0**, **бос жол**, **бос тізім**, **өте үлкен сан**, **теріс сан**.

```python
def grade(score, total):
    percent = score / total * 100
    if percent >= 85:
        return 5
    elif percent >= 65:
        return 4
    elif percent >= 40:
        return 3
    return 2

# шекаралық тестер
print(grade(17, 20), grade(16, 20), grade(13, 20), grade(0, 20))
```

Нәтижесі:
```text
5 4 4 2
```

17/20 = 85% → 5 ✔; 16/20 = 80% → 4 ✔; 13/20 = 65% → 4 ✔; 0 → 2 ✔. Ал `grade(0, 0)` ше? → `ZeroDivisionError`! Сұрақ саны 0 болуы мүмкін бе? Болса – қорғау керек.

## 3. assert – автоматты тексеру

`assert шарт` – шарт жалған болса, бағдарлама `AssertionError` қатесімен тоқтайды. Бұл логика функцияларын **автоматты** тексерудің ең қарапайым тәсілі:

```python
def check_answer(user_answer, correct_answer):
    return user_answer.strip().lower() == correct_answer.strip().lower()

assert check_answer("Астана", "астана") == True
assert check_answer("  теңге ", "теңге") == True
assert check_answer("Алматы", "астана") == False
print("Барлық тест өтті!")
```

Нәтижесі:
```text
Барлық тест өтті!
```

Бұл идеяның кәсіби дамуы – стандартты кітапханадағы `unittest` модулі және сыртқы `pytest` кітапханасы: олар жобаның барлық тестілерін өздері тауып, іске қосады.

## 4. Қатені түзету алгоритмі

```text
1. ҚАЙТАЛА   – қатені тұрақты түрде қайталайтын әрекеттерді тап
2. ОРНЫН ТАП – Traceback (жол нөмірі), print, жөндеуіш
3. СЕБЕБІН ТҮСІН – «Неге бұл айнымалы мұндай мән алды?»
4. ТҮЗЕТ     – ең аз өзгеріспен
5. ҚАЙТА ТЕКСЕР – сол тест + барлық бұрынғы тестер (регрессия)
```

### 7-тест бойынша мысал

Бағдарлама құлады:

```text
Traceback (most recent call last):
  File "quiz.py", line 58, in load_results
    with open(file_name, encoding="utf-8") as f:
FileNotFoundError: [Errno 2] No such file or directory: 'results.txt'
```

Себебі: ойын әлі бірде-бір рет ойналмаған, файл жоқ. Түзету – `try...except`:

```python
def load_results(file_name):
    results = []
    try:
        with open(file_name, encoding="utf-8") as f:
            for line in f:
                parts = line.strip().split(";")
                if len(parts) == 4:
                    results.append(parts)
    except FileNotFoundError:
        pass                     # файл әлі жоқ – бос тізім қайтарамыз
    return results

print(load_results("жоқ_файл.txt"))
```

Нәтижесі:
```text
[]
```

### Жөндеу құралдары

| Құрал | Қашан қолданамыз |
|---|---|
| Traceback | Бағдарлама құласа – қай жол, қандай қате |
| Уақытша `print` | Айнымалылардың мәнін бақылау (кейін өшіруді ұмытпа!) |
| Thonny жөндеуіші | Кодты жолма-жол орындап, айнымалыларды көру (🐞, F6/F7) |
| «Резеңке үйрек» әдісі | Кодыңды жолма-жол біреуге (тіпті ойыншыққа) дауыстап түсіндір – көбіне қатені өзің табасың |
| Кодты «бөлу» | Қате қай бөлікте екенін табу үшін бір бөлікті уақытша өшіріп (`#`) тексеру |

## 5. Кодты безендіру: код сапасы

Код компьютер үшін ғана емес, **адамдар** үшін жазылады (әріптестер, команда, бір айдан кейінгі өзің). Python-да кодты жазу стилінің ресми ұсыныстары – **PEP 8**.

### Негізгі ережелер

| Ереже | Нашар | Жақсы |
|---|---|---|
| Мағыналы атаулар | `a`, `x1`, `f()` | `score`, `total_price`, `load_questions()` |
| Айнымалы/функция атауы – кіші әріп + `_` | `TotalPrice`, `LoadQ` | `total_price`, `load_questions` |
| Тұрақтылар – БАС ӘРІП | `file = "q.txt"` | `QUESTIONS_FILE = "questions.txt"` |
| Шегініс – 4 бос орын | 2 немесе 8 | 4 |
| Амалдар айналасында бос орын | `x=a+b*2` | `x = a + b * 2` |
| Функциялар арасында 2 бос жол | бос жолсыз | 2 бос жол |
| Жол ұзындығы | 150 таңба | ≤ 79–99 таңба |
| «Сиқырлы сандар» жоқ | `if p >= 85:` түсініксіз | `EXCELLENT = 85` |
| Қайталанатын код жоқ | 3 жерде бірдей 5 жол | бір функция |

### Түсініктеме және docstring

```python
def grade(score, total):
    """Ұпайды пайызға айналдырып, 2-ден 5-ке дейінгі баға қайтарады.

    score – дұрыс жауаптар саны, total – барлық сұрақ саны (> 0).
    """
    percent = score / total * 100
    if percent >= 85:
        return 5
    elif percent >= 65:
        return 4
    elif percent >= 40:
        return 3
    return 2


help(grade)
```

Нәтижесі:
```text
Help on function grade in module __main__:

grade(score, total)
    Ұпайды пайызға айналдырып, 2-ден 5-ке дейінгі баға қайтарады.

    score – дұрыс жауаптар саны, total – барлық сұрақ саны (> 0).
```

- **docstring** (`"""..."""`) – функция **не істейтінін** сипаттайды; `help()` оны көрсетеді.
- **түсініктеме** (`#`) – **неге** осылай жазылғанын түсіндіреді (айқын нәрсені емес!):

```python
total = 0
total += 1         # нашар: «total-ға 1 қосамыз» – мұны код өзі айтып тұр
total -= 1         # жақсы: «тақырып жолын есептемейміз»
print(total)
```

Файлдың басына жобаның **тақырыптық түсініктемесін** жаз:

```python
"""
Қазақстан викторинасы – консольдік викторина ойыны.
Автор: Дана Әбілова, 2027
Іске қосу: python quiz.py (questions.txt файлы қасында болуы керек)
"""
```

- VS Code: **Shift+Alt+F** – кодты автоматты форматтау (Python кеңейтімі орнатылған болса).

## Жиі кездесетін қателер

**1. Тек «бақытты жолды» тестілеу.** Тек дұрыс енгізумен тексеру – қате енгізуде бағдарлама құлайды. Әр енгізуге кемінде бір негативтік тест жаз.

**2. Бір қатені түзетіп, басқасын бұзу.** Түзетуден кейін **барлық** тест-кейстерді қайта өткіз (регрессия).

**3. `except:` арқылы қатені «жасыру».** Бағдарлама құламайды, бірақ дұрыс жұмыс та істемейді. Нақты қате түрін көрсет және пайдаланушыға хабарла.

**4. Уақытша `print`-терді қалдыру.** Пайдаланушы экранда `DEBUG: i = 3` көреді.

**5. Соңғы минутта үлкен өзгерістер.** Шығару алдында жаңа мүмкіндік қоспа – тек түзет және безендір.

**6. Нұсқаны сақтамау.** Тестілеуден өткен нұсқаны міндетті түрде көшір: `quiz_final.py`.

## Ескерту

- `assert`-ті өшіруге болады: `python -O` арқылы іске қосқанда барлық `assert` тексерулері өткізіліп жіберіледі. Сондықтан `assert` тестілер үшін жарайды, бірақ пайдаланушы енгізуін тексеруге емес – онда `if` пен ерекше жағдайлар керек.
- `assert` ішінде `True`/`False`-пен `==` арқылы салыстыру міндетті емес: PEP 8 `assert check_answer(...)` және `assert not check_answer(...)` деп жазуды ұсынады.
- Бөлшек сандарды дәл теңдікке тексеруге болмайды: `0.1 + 0.2 == 0.3` → `False`. `math.isclose()` немесе `round()` қолдан.
- Код стилі автоматты тексеріледі: `flake8`, `pylint`, `ruff` PEP 8 бұзылуларын табады, ал `black` кодты өзі пішімдейді.
- Python 3.11+ нұсқасында Traceback жолдағы қатенің нақты орнын көрсетеді (`^^^^` астын сызу), бұл жөндеуді жеделдетеді.
- Құжаттама: [PEP 8](https://peps.python.org/pep-0008/), [unittest](https://docs.python.org/3/library/unittest.html), [pdb – жөндеуіш](https://docs.python.org/3/library/pdb.html).
