## 1. Что такое пользовательский интерфейс?

**Пользовательский интерфейс** (UI – User Interface) – способ «общения» человека с программой. Простейший вариант – **консольный (текстовый) интерфейс**: вывод текста и ввод с клавиатуры. Существуют также **графические** интерфейсы (GUI: окна Tkinter, игры на Pygame) и веб-интерфейсы.

**UX** (User Experience – пользовательский опыт) – насколько **удобно и приятно** пользоваться программой.

### 7 правил хорошего консольного интерфейса

1. **Понятно, что делать** – каждый `input` задаёт конкретный вопрос: `"Введи свой возраст (7-18): "`, а не просто `"?"`.
2. **Меню** – возможные действия в виде нумерованного списка.
3. **Неверный ввод не роняет программу** – она выводит понятное сообщение и спрашивает снова.
4. **Обратная связь** – после каждого действия сообщается результат: «Сохранено!», «Не найдено».
5. **Структура** – разделительные линии, заголовки, выравнивание (f-строки).
6. **Единообразие** – все меню в одном стиле, «0 – выход» всегда на одном месте.
7. **Грамотный язык** – текст без ошибок и вежливый.

### Плохой и хороший интерфейс

Плохой:
```text
?1
ok
?
```

Хороший:
```text
========================================
         ВИКТОРИНА О КАЗАХСТАНЕ
========================================
  1 – Играть
  2 – Рекорды (ТОП-5)
  3 – Добавить новый вопрос
  0 – Выход
========================================
Твой выбор: 5
Возможные варианты: 1, 2, 3, 0
Твой выбор:
```

## 2. Меню и главный цикл

Почти во всех проектах используется один шаблон – **главный цикл** (main loop):

```python
def show_menu():
    print("=" * 30)
    print("1 – Играть")
    print("2 – Рекорды")
    print("0 – Выход")
    print("=" * 30)


def main():
    while True:
        show_menu()
        choice = input("Твой выбор: ").strip()
        if choice == "1":
            print("Игра началась...")
        elif choice == "2":
            print("Рекорды...")
        elif choice == "0":
            print("Пока!")
            break
        else:
            print("Выбери пункт меню!")


main()
```

Здесь `main()` – **точка входа** программы: «дирижёр», объединяющий все части. В конце файла вызывается только `main()`.

## 3. Вспомогательные функции проверки ввода

Чтобы не повторять одну и ту же проверку везде, создаём **вспомогательные функции** (шаблон `while True` + `try...except`):

```python
def read_int(prompt, low, high):
    """Спрашивает, пока не будет введено целое число из диапазона low..high."""
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("Введи число!")
            continue
        if low <= value <= high:
            return value
        print(f"Число должно быть от {low} до {high}.")


def read_choice(prompt, options):
    """Принимает только одно из разрешённых значений."""
    while True:
        choice = input(prompt).strip().lower()
        if choice in options:
            return choice
        print("Возможные варианты:", ", ".join(options))


def read_text(prompt):
    """Спрашивает, пока не будет введена непустая строка."""
    while True:
        text = input(prompt).strip()
        if text:
            return text
        print("Не должно быть пусто!")
```

Использование:

```text
age = read_int("Твой возраст (7-18): ", 7, 18)
answer = read_choice("Продолжаем? (да/нет): ", ["да", "нет"])
name = read_text("Твоё имя: ")
```

Результат (пример):
```text
Твой возраст (7-18): десять
Введи число!
Твой возраст (7-18): 25
Число должно быть от 7 до 18.
Твой возраст (7-18): 13
```

## 4. Оформление вывода

```python
LINE = "=" * 40
title = "ВИКТОРИНА О КАЗАХСТАНЕ"
print(LINE)
print(title.center(40))
print(LINE)

results = [("Дана", 8, 8), ("Арман", 6, 8), ("Айгерим", 5, 8)]
print(f"{'№':<3}{'Имя':<10}{'Баллы':>6}")
for i in range(len(results)):
    name, score, total = results[i]
    print(f"{i + 1:<3}{name:<10}{score:>3}/{total}")
```

Результат:
```text
========================================
         ВИКТОРИНА О КАЗАХСТАНЕ
========================================
№  Имя        Баллы
1  Дана        8/8
2  Арман       6/8
3  Айгерим     5/8
```

Полезные инструменты:
- `str.center(n)`, `ljust(n)`, `rjust(n)` – выравнивание строки;
- форматы f-строк `:<10`, `:>6`, `:.2f`;
- `time.sleep(0.5)` – эффектная пауза (модуль `time`);
- ASCII-рисунок (рисунок из символов) – хорошо подходит для игр;
- вместо «очистки экрана» – `print("\n" * 3)`, несколько пустых строк.

## 5. Хранение данных

### Что нужно сохранять?

| Проект | Что сохраняется | Файл |
|---|---|---|
| Викторина | Вопросы; результаты игроков | `questions.txt`, `results.txt` |
| Дневник | Задания (предмет, текст, срок, выполнено ли) | `tasks.txt` |
| Карманные деньги | Операции (дата, тип, сумма, категория) | `money.txt` |
| Тамагочи | Состояние питомца (имя, голод, настроение) | `pet.txt` |
| Виселица | Список слов; рекорд | `words.txt`, `record.txt` |

### Выбор формата файла

Каждая запись – одна строка, поля – через разделитель (как в CSV):

```text
Дана;8;8;05.05.2027 14:20
Арман;6;8;05.05.2027 14:35
```

В качестве разделителя выбирай символ, который **не встречается** в данных: если в вопросе может быть `;`, лучше выбрать `|`.

### Функции загрузки и сохранения

Для каждого вида данных – две функции: `load_...()` и `save_...()` (или `add_...()`).

```python
def load_questions(file_name):
    """Читает вопросы из файла: в каждой строке 'вопрос|ответ'."""
    questions = {}
    try:
        with open(file_name, encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if line == "" or line.startswith("#") or "|" not in line:
                    continue
                question, answer = line.split("|", 1)
                questions[question.strip()] = answer.strip()
    except FileNotFoundError:
        print(f"Предупреждение: {file_name} не найден.")
    return questions
```

Здесь:
- пустые строки и строки-комментарии, начинающиеся с `#`, пропускаются;
- `split("|", 1)` – делит только по **первому** `|`;
- если файла нет, программа не падает – возвращает пустой словарь.

```python
from datetime import datetime


def save_result(file_name, name, score, total):
    """Добавляет результат в файл: имя;баллы;всего;дата."""
    stamp = datetime.now().strftime("%d.%m.%Y %H:%M")
    with open(file_name, "a", encoding="utf-8") as f:
        f.write(f"{name};{score};{total};{stamp}\n")
```

### Шаблон «загрузить всё – изменить – сохранить всё»

Если данные **изменяются** (отметить задание как «выполнено», удалить), удобен такой способ: в начале программы загрузи всё в память, во время работы изменяй список/словарь в памяти, после каждого изменения (или при выходе) **перезаписывай весь файл в режиме `w`**:

```python
def load_tasks(file_name):
    tasks = []
    try:
        with open(file_name, encoding="utf-8") as f:
            for line in f:
                parts = line.strip().split(";")
                if len(parts) == 3:
                    tasks.append({"subject": parts[0], "text": parts[1], "done": parts[2] == "1"})
    except FileNotFoundError:
        pass
    return tasks


def save_tasks(file_name, tasks):
    with open(file_name, "w", encoding="utf-8") as f:
        for t in tasks:
            done = "1" if t["done"] else "0"
            f.write(f"{t['subject']};{t['text']};{done}\n")


tasks = [{"subject": "Математика", "text": "задача №125", "done": False}]
save_tasks("tasks.txt", tasks)
tasks = load_tasks("tasks.txt")
tasks[0]["done"] = True
save_tasks("tasks.txt", tasks)
print(load_tasks("tasks.txt"))
```

Результат:
```text
[{'subject': 'Математика', 'text': 'задача №125', 'done': True}]
```

## 6. Объединение частей: структура программы

Раздели файл проекта на разделы и расположи их по порядку:

```text
"""Название проекта, автор, краткое описание."""
import ...                     # 1. Импорты

КОНСТАНТЫ = ...                # 2. Константы (имена файлов и т.д.)

# ---- Хранение данных ----    # 3. Функции load_/save_
# ---- Основная логика ----    # 4. Функции логики
# ---- Интерфейс ----          # 5. read_..., show_..., меню

def main(): ...                # 6. Функция, объединяющая всё

main()                         # 7. Запуск
```

**Правило:** в функциях логики не должно быть `input`/`print` (или совсем мало), функции интерфейса не вычисляют – только вызывают логику.

## Частые ошибки

**1. `int(input())` в меню – падает при вводе буквы.** Сравнивай выбор в меню как строку: `if choice == "1":`, или используй `read_choice()`.

**2. Забыли вызвать `main()`.** Программа запускается, и ничего не происходит. Напиши в конце файла `main()`.

**3. Добавление результатов в файл в режиме `w`** – каждая игра стирает прежние рекорды. Для накопления результатов – `a`.

**4. Символ-разделитель встречается внутри данных.** Если пользователь напишет в имени `;`, `split(";")` даст 5 частей. Решение: убрать разделитель из ввода: `name.replace(";", ",")` или проверять количество частей.

**5. Использование числа из файла в виде строки.** `"8" > "10"` – `True` (строки сравниваются посимвольно)! Перед сортировкой используй `int()`.

**6. Файл создаётся в другой папке.** Thonny запускает программу в папке, где она сохранена; в VS Code текущая папка терминала может быть другой. Работай, открыв папку проекта.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Пользовательский интерфейс (UI) | Способ взаимодействия человека с программой |
| Пользовательский опыт (UX) | Удобство использования программы |
| Меню | Нумерованный список возможных действий |
| Главный цикл (main loop) | Цикл `while True`, снова и снова показывающий меню |
| Точка входа (`main`) | Главная функция, запускающая программу |
| Вспомогательная функция | Небольшая функция, выполняющая часто повторяющееся действие |
| Хранение данных (persistence) | Сохранение данных после закрытия программы |
| Объединение (интеграция) | Соединение отдельно написанных частей в одну программу |

## Примечание

- Вместо `main()` в конце файла принято писать `if __name__ == "__main__": main()` – тогда файл можно импортировать (например, для тестов), не запуская меню.
- Начиная с Python 3.10 многоуровневые `if/elif` в меню можно заменить конструкцией `match choice: case "1": ...` (structural pattern matching).
- Для настоящей очистки консоли используют `os.system("cls" if os.name == "nt" else "clear")`, но во встроенной оболочке Thonny это не работает.
- При перезаписи важного файла надёжнее сначала записать данные во временный файл, а затем заменить им старый (`os.replace(tmp, name)`) – так данные не потеряются при сбое во время записи.
- Для хранения структурированных данных стандартная библиотека предлагает `json` (списки и словари), `csv` (таблицы) и `sqlite3` (встроенная база данных SQL).
- Документация: [json](https://docs.python.org/3/library/json.html), [sqlite3](https://docs.python.org/3/library/sqlite3.html), [match statement](https://docs.python.org/3/tutorial/controlflow.html#match-statements).
