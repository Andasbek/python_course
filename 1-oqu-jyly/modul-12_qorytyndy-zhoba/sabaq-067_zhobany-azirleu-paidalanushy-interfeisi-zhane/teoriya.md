## 1. Пайдаланушы интерфейсі деген не?

**Пайдаланушы интерфейсі** (UI – User Interface) – адам мен бағдарламаның «сөйлесу» тәсілі. Ең қарапайым нұсқа – **консольдік (мәтіндік) интерфейс**: мәтін шығару және пернетақтадан енгізу. Сондай-ақ **графикалық** интерфейстер (GUI: Tkinter терезелері, Pygame ойындары) және веб-интерфейстер бар.

**UX** (User Experience – пайдаланушы тәжірибесі) – бағдарламаны қолдану қаншалықты **ыңғайлы әрі жағымды**.

### Жақсы консольдік интерфейстің 7 ережесі

1. **Не істеу керек екені түсінікті** – әр `input` нақты сұрақ қояды: `"Жасыңды енгіз (7-18): "`, жай `"?"` емес.
2. **Мәзір** – мүмкін әрекеттер нөмірленген тізім түрінде.
3. **Қате енгізу бағдарламаны құлатпайды** – түсінікті хабарлама беріп, қайта сұрайды.
4. **Кері байланыс** – әр әрекеттен кейін нәтиже айтылады: «Сақталды!», «Табылмады».
5. **Құрылым** – бөлгіш сызықтар, тақырыптар, туралау (f-жолдар).
6. **Бірізділік** – барлық мәзірлер бірдей стильде, «0 – шығу» әрқашан бір жерде.
7. **Қазақ тілі сауатты** – қатесіз, сыпайы мәтін.

## 2. Мәзір және басты цикл

Барлық жобаларда дерлік бір үлгі қолданылады – **басты цикл** (main loop):

```python
def show_menu():
    print("=" * 30)
    print("1 – Ойнау")
    print("2 – Рекордтар")
    print("0 – Шығу")
    print("=" * 30)


def main():
    while True:
        show_menu()
        choice = input("Таңдауың: ").strip()
        if choice == "1":
            print("Ойын басталды...")
        elif choice == "2":
            print("Рекордтар...")
        elif choice == "0":
            print("Сау бол!")
            break
        else:
            print("Мәзірден таңда!")


main()
```

Мұндағы `main()` – бағдарламаның **кіру нүктесі**: барлық бөліктерді біріктіретін «дирижер». Файлдың соңында тек `main()` шақырылады.

## 3. Енгізуді тексеретін көмекші функциялар

Бір тексеруді әр жерде қайталап жазбау үшін **көмекші функциялар** жасаймыз (`while True` + `try...except` үлгісі):

```python
def read_int(prompt, low, high):
    """low..high аралығындағы бүтін сан енгізілгенше сұрайды."""
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("Сан енгіз!")
            continue
        if low <= value <= high:
            return value
        print(f"Сан {low} мен {high} аралығында болуы керек.")


def read_choice(prompt, options):
    """Тек рұқсат етілген мәндердің бірін қабылдайды."""
    while True:
        choice = input(prompt).strip().lower()
        if choice in options:
            return choice
        print("Мүмкін нұсқалар:", ", ".join(options))


def read_text(prompt):
    """Бос емес жол енгізілгенше сұрайды."""
    while True:
        text = input(prompt).strip()
        if text:
            return text
        print("Бос болмауы керек!")
```

Қолданылуы:

```text
age = read_int("Жасың (7-18): ", 7, 18)
answer = read_choice("Жалғастырамыз ба? (иә/жоқ): ", ["иә", "жоқ"])
name = read_text("Атың: ")
```

Нәтижесі (мысал):
```text
Жасың (7-18): он
Сан енгіз!
Жасың (7-18): 25
Сан 7 мен 18 аралығында болуы керек.
Жасың (7-18): 13
```

## 4. Шығаруды безендіру

```python
LINE = "=" * 40
title = "ҚАЗАҚСТАН ВИКТОРИНАСЫ"
print(LINE)
print(title.center(40))

results = [("Дана", 8, 8), ("Арман", 6, 8), ("Айгерім", 5, 8)]
print(f"{'№':<3}{'Аты':<10}{'Ұпай':>6}")

```

Нәтижесі:
```text
========================================
         ҚАЗАҚСТАН ВИКТОРИНАСЫ
========================================
№  Аты         Ұпай
1  Дана        8/8
2  Арман       6/8
3  Айгерім     5/8
```

Пайдалы құралдар:
- `str.center(n)`, `ljust(n)`, `rjust(n)` – жолды туралау;
- f-жол пішімдері `:<10`, `:>6`, `:.2f`;
- `time.sleep(0.5)` – әсерлі кідіріс (`time` модулі);
- ASCII-сурет (таңбалардан салынған сурет) – ойындарға жарасады;
- «экранды тазалау» орнына `print("\n" * 3)` – бірнеше бос жол.

## 5. Деректерді сақтау

### Не сақталуы керек?

| Жоба | Не сақталады | Файл |
|---|---|---|
| Викторина | Сұрақтар; ойыншылар нәтижесі | `questions.txt`, `results.txt` |
| Күнделік | Тапсырмалар (пән, мәтін, мерзім, орындалды ма) | `tasks.txt` |
| Қалта ақшасы | Операциялар (күні, түрі, сомасы, санаты) | `money.txt` |
| Тамагочи | Жануардың күйі (аты, аштығы, көңілі) | `pet.txt` |
| Дар ағашы | Сөздер тізімі; рекорд | `words.txt`, `record.txt` |

### Файл пішімін таңдау

Әр жазба – бір жол, өрістер – бөлгішпен (CSV-дағыдай):

```text
Дана;8;8;05.05.2027 14:20
Арман;6;8;05.05.2027 14:35
```

Бөлгіш ретінде деректерде **кездеспейтін** таңбаны таңда: сұрақта `;` болуы мүмкін болса, `|` таңдаған дұрыс.

### Жүктеу және сақтау функциялары

Әр деректер түріне екі функция: `load_...()` және `save_...()` (немесе `add_...()`).

```python
def load_questions(file_name):
    """Сұрақтарды файлдан оқиды: әр жолда 'сұрақ|жауап'."""
    questions = {}
    try:
        with open(file_name, encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if line == "" or line.startswith("#") or "|" not in line:
                    continue
                question, answer = line.split("|", 1)
                questions[question.strip()] = answer.strip()
    except FileNotFoundError:
        print(f"Ескерту: {file_name} табылмады.")
    return questions
```

Мұнда:
- бос жолдар мен `#`-тан басталатын түсініктеме жолдары өткізіледі;
- `split("|", 1)` – тек **бірінші** `|` бойынша бөледі;
- файл жоқ болса, бағдарлама құламайды – бос сөздік қайтарады.

```python
from datetime import datetime


def save_result(file_name, name, score, total):
    """Нәтижені файлға қосады: аты;ұпай;барлығы;күні."""
    stamp = datetime.now().strftime("%d.%m.%Y %H:%M")
    with open(file_name, "a", encoding="utf-8") as f:
        f.write(f"{name};{score};{total};{stamp}\n")
```

### «Барлығын жүктеу – өзгерту – барлығын сақтау» үлгісі

Деректер **өзгертілетін** болса (тапсырманы «орындалды» деп белгілеу, жою), ыңғайлы тәсіл: бағдарлама басында бәрін жадқа жүкте, жұмыс барысында жадтағы тізімді/сөздікті өзгерт, әр өзгерістен кейін (немесе шығарда) **бүкіл файлды `w` режимімен қайта жаз**:

```python
def load_tasks(file_name):
    tasks = []
    try:
        with open(file_name, encoding="utf-8") as f:
            for line in f:
                parts = line.strip().split(";")
                if len(parts) == 3:
                    tasks.append({"subject": parts[0], "text": parts[1], "done": parts[2] == "1"})
    except FileNotFoundError:
        pass
    return tasks


def save_tasks(file_name, tasks):
    with open(file_name, "w", encoding="utf-8") as f:
        for t in tasks:
            done = "1" if t["done"] else "0"
            f.write(f"{t['subject']};{t['text']};{done}\n")


tasks = [{"subject": "Математика", "text": "№125 есеп", "done": False}]
save_tasks("tasks.txt", tasks)
tasks = load_tasks("tasks.txt")
tasks[0]["done"] = True
save_tasks("tasks.txt", tasks)
print(load_tasks("tasks.txt"))
```

Нәтижесі:
```text
[{'subject': 'Математика', 'text': '№125 есеп', 'done': True}]
```

## 6. Бөліктерді біріктіру: бағдарлама құрылымы

Жобаның файлын үш бөлімге бөліп, ретімен орналастыр:

```text
"""Жобаның атауы, авторы, қысқаша сипаттамасы."""
import ...                     # 1. Импорттар

ТҰРАҚТЫЛАР = ...               # 2. Тұрақтылар (файл атаулары т.б.)

# ---- Деректерді сақтау ----  # 3. load_/save_ функциялары
# ---- Негізгі логика ----     # 4. Логика функциялары
# ---- Интерфейс ----          # 5. read_..., show_..., мәзір

def main(): ...                # 6. Барлығын біріктіретін функция

main()                         # 7. Іске қосу
```

**Ереже:** логика функцияларында `input`/`print` болмауы керек (немесе өте аз), интерфейс функциялары есептемейді – тек логиканы шақырады.

## Жиі кездесетін қателер

**1. Мәзірде `int(input())` – әріп енгізілсе құлайды.** Мәзір таңдауын жол ретінде салыстыр: `if choice == "1":`, немесе `read_choice()` қолдан.

**2. `main()`-ді шақыруды ұмыту.** Бағдарлама іске қосылады да, ештеңе болмайды. Файлдың соңына `main()` жаз.

**3. Файлға `w` режимімен нәтижелерді қосу** – әр ойын бұрынғы рекордтарды өшіреді. Нәтижелерді жинау – `a`.

**4. Бөлгіш таңба деректің ішінде кездеседі.** Пайдаланушы атына `;` жазса, `split(";")` 5 бөлік береді. Шешімі: енгізуден бөлгішті алып таста: `name.replace(";", ",")`, немесе бөлік санын тексер.

**5. Файлдағы санды жол күйінде қолдану.** `"8" > "10"` – `True` (жолдар әріп бойынша салыстырылады)! Сұрыптау алдында `int()` қолдан.

**6. Файл басқа папкада құрылады.** Thonny бағдарламаны сақталған папкасында іске қосады; VS Code-та терминалдың ағымдағы папкасы басқа болуы мүмкін. Жоба папкасын ашып жұмыс істе.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Пайдаланушы интерфейсі (UI) | Адам мен бағдарламаның өзара әрекет тәсілі |
| Пайдаланушы тәжірибесі (UX) | Бағдарламаны қолданудың ыңғайлылығы |
| Мәзір | Мүмкін әрекеттердің нөмірленген тізімі |
| Басты цикл (main loop) | Мәзірді қайта-қайта көрсететін `while True` циклі |
| Кіру нүктесі (`main`) | Бағдарламаны іске қосатын басты функция |
| Көмекші функция | Жиі қайталанатын әрекетті орындайтын шағын функция |
| Деректерді сақтау (persistence) | Деректердің бағдарлама жабылғаннан кейін сақталуы |
| Біріктіру (интеграция) | Бөлек жазылған бөліктерді бір бағдарламаға қосу |

## Ескерту

- Файл соңында `main()` орнына `if __name__ == "__main__": main()` деп жазу қабылданған – сонда файлды мәзірді іске қоспай-ақ импорттауға (мысалы, тестілер үшін) болады.
- Python 3.10-нан бастап мәзірдегі көп деңгейлі `if/elif`-ті `match choice: case "1": ...` конструкциясымен (structural pattern matching) алмастыруға болады.
- Консольді шынымен тазарту үшін `os.system("cls" if os.name == "nt" else "clear")` қолданылады, бірақ Thonny-дің кірістірілген қабықшасында бұл жұмыс істемейді.
- Маңызды файлды қайта жазғанда деректерді алдымен уақытша файлға жазып, содан кейін ескісін соған ауыстыру (`os.replace(tmp, name)`) сенімдірек – сонда жазу кезінде ақау болса да деректер жоғалмайды.
- Құрылымды деректерді сақтау үшін стандартты кітапхана `json` (тізімдер мен сөздіктер), `csv` (кестелер) және `sqlite3` (кірістірілген SQL дерекқоры) ұсынады.
- Құжаттама: [json](https://docs.python.org/3/library/json.html), [sqlite3](https://docs.python.org/3/library/sqlite3.html), [match statement](https://docs.python.org/3/tutorial/controlflow.html#match-statements).
