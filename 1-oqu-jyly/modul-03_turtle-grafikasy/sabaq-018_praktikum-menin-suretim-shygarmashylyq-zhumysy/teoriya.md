## 1. Графикалық бағдарлама жасау кезеңдері

Кез келген бағдарламалық жоба — тіпті шағын сурет те — бірдей кезеңдерден өтеді:

```text
 1. ИДЕЯ  →  2. ЭСКИЗ  →  3. ДЕКОМПОЗИЦИЯ  →  4. КОД  →  5. ТЕСТІЛЕУ  →  6. БЕЗЕНДІРУ
```

### 1.1. Идея
Не шығуы керектігін бір сөйлеммен тұжырымдаңыз: «Таудың етегіндегі киіз үй және күн». Идея неғұрлым қарапайым әрі нақты болса, оны алгоритмге айналдыру соғұрлым жеңіл.

### 1.2. Эскиз
Торкөз қағазда координаталар осьтерін сызыңыз (мысалы, бір торкөз = 20 пиксель). Суретті салып, маңызды нүктелерді белгілеңіз: фигуралардың бұрыштары, шеңберлердің центрлері.

### 1.3. Декомпозиция — бөліктер кестесі

| № | Бөлік | Фигура | Нүктелер/өлшемдер | Жиек/бояу түсі |
|---|---|---|---|---|
| 1 | Жер | тіктөртбұрыш | (−400; −300) … (400; −100) | `green` / `green` |
| 2 | Киіз үй | тіктөртбұрыш + жарты шеңбер | (−80; −100) … (80; 0), r = 80 | `black` / `white` |
| 3 | Күн | шеңбер | центрі (250; 200), r = 40 | `orange` / `yellow` |

**Салу реті:** артқы план (фон, жер, аспан) → үлкен нысандар → ұсақ бөлшектер → мәтін. Кейін салынған нәрсе бұрын салынғанды жауып қалады.

### 1.4. Код жазу
- Бағдарлама басында — баптаулар: `import`, `setup`, `bgcolor`, `speed(0)`.
- Әр бөлік — үстінде түсініктемесі бар жеке блок (`# --- Күн ---`).
- Әр блоктан кейін бағдарламаны іске қосып тексерген жөн: осылай қатенің орнын табу оңайырақ.

### 1.5. Тестілеу
Тестілеу — бағдарламаның ойлағандай жұмыс істейтінін тексеру. Сурет үшін мыналар тексеріледі: қатесіз іске қосылуы, артық сызықтардың жоқтығы, боялған фигуралардың тұйықтығы, суреттің терезеге сыюы.

### 1.6. Безендіру
`write` арқылы қолтаңба (атауы, авторы), соңында `hideturtle()`, түсінікті түсініктемелер мен айнымалы атаулары.

## 2. Сурет-бағдарлама шаблоны

```python
# Жоба: «Менің суретім»
# Авторы: ___________
import turtle

# --- Баптаулар ---
turtle.setup(800, 600)
turtle.title("Менің суретім")
turtle.bgcolor("lightyellow")
t = turtle.Turtle()
t.speed(0)

# --- 1-бөлік: ... ---
t.penup()
t.goto(-100, -100)
t.pendown()
t.color("black", "orange")
t.begin_fill()
t.goto(100, -100)
t.goto(0, 50)
t.goto(-100, -100)
t.end_fill()

# --- 2-бөлік: ... ---

# --- Атауы мен авторы ---
t.penup()
t.goto(0, 250)
t.write("Менің суретім", align="center", font=("Arial", 22, "bold"))
t.goto(300, -280)
t.write("Авторы: ...", align="right", font=("Arial", 12, "italic"))

t.hideturtle()
turtle.done()
```

`write` командасының `align` параметрі тасбақа тұрған нүктеге қатысты `"left"` (әдепкі), `"center"` немесе `"right"` мәндерін қабылдайды.

## 3. Пайдалы «рецептер»

| Не керек | Қалай |
|---|---|
| Центрі (a; b), радиусы r шеңбер | `penup()`, `goto(a, b - r)`, `setheading(0)`, `pendown()`, `circle(r)` |
| Жарты шеңбер (күн шығуы, доға) | `circle(r, 180)` |
| Тіктөртбұрыш (x1; y1)–(x2; y2) | `goto` арқылы төрт бұрышты айналып шығу |
| Жұлдыз | 5 рет `forward(a)` + `right(144)` |
| Мәтінді ортаға қою | `write("...", align="center")` |
| Жұмсақ түстер | `"lightblue"`, `"lightgreen"`, `"peachpuff"`, `"lavender"` |
| Қою түстер | `"navy"`, `"darkgreen"`, `"maroon"`, `"indigo"` |

### Мысал: бес бұрышты жұлдыз

Жұлдызды айналып шыққанда тасбақа бұрылыстарының қосындысы 720° (екі толық айналым), сондықтан әр бұрылыс — 720 / 5 = **144°**.

```python
import turtle

t = turtle.Turtle()
t.color("gold", "yellow")
t.begin_fill()
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.end_fill()
t.hideturtle()
turtle.done()
```

### Мысал: тіктөртбұрыш пен жарты шеңберден киіз үй

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.color("black", "white")
# қабырға: тіктөртбұрыш (-80; -100) ... (80; 0)
t.penup()
t.goto(-80, -100)
t.pendown()
t.begin_fill()
t.goto(80, -100)
t.goto(80, 0)
t.goto(-80, 0)
t.goto(-80, -100)
t.end_fill()
# күмбез: қабырға үстіндегі радиусы 80 жарты шеңбер
t.penup()
t.goto(80, 0)
t.setheading(90)
t.pendown()
t.begin_fill()
t.circle(80, 180)
t.goto(80, 0)
t.end_fill()
t.hideturtle()
turtle.done()
```

(80; 0) нүктесіндегі тасбақа жоғары қарап тұр, ал `circle(80, 180)` оны сағат тіліне қарсы доғамен (−80; 0) нүктесіне апарады — күмбез шығады.

## 4. Суретті тексеру чек-парағы

- [ ] Бағдарлама қатесіз іске қосылады.
- [ ] Ортадан немесе фигуралар арасында артық сызық жоқ (жаңа орынға әр `goto` алдында — `penup()`).
- [ ] Барлық боялатын фигуралар тұйық, әр `begin_fill()`-дің `end_fill()`-і бар.
- [ ] Сурет терезеге толық сыяды (координаталар `setup` шегінде).
- [ ] Атауы мен авторы жазылған.
- [ ] Соңында `hideturtle()` және `turtle.done()` бар.
- [ ] Түсініктемелер бар, айнымалылар түсінікті аталған.

## 5. turtle модулі бойынша анықтамалық

| Топ | Командалар |
|---|---|
| Жасау және терезе | `import turtle`, `t = turtle.Turtle()`, `turtle.setup(w, h)`, `turtle.title(...)`, `turtle.bgcolor(...)`, `turtle.done()` |
| Салыстырмалы қозғалыс | `forward`, `back`, `left`, `right`, `circle(r)`, `circle(r, бұрыш)` |
| Абсолютті қозғалыс | `goto(x, y)`, `setx`, `sety`, `setheading(a)`, `home()` |
| Қалам | `penup()`, `pendown()`, `pencolor`, `pensize`, `color(a, b)` |
| Бояу | `fillcolor`, `begin_fill()`, `end_fill()` |
| Басқалары | `dot(d, түс)`, `write(мәтін, align=..., font=...)`, `speed(n)`, `shape(...)`, `hideturtle()` |
| Күйі | `position()`, `xcor()`, `ycor()`, `heading()` |

Осы уақытқа дейін қарастырылған turtle бағдарламаларының бәрі — **сызықтық алгоритмдер**: командалар қатаң түрде жоғарыдан төмен орындалады. Бағдарлама шартқа байланысты әрекет таңдауы үшін **тармақталу** (`if`, `else`, `elif`) қолданылады, ал қайталанатын командалар **циклдер** арқылы жазылады.

## Жиі кездесетін қателер

**1. Бәрін бірден жазып, кейін іске қосу.** Қате қай жерде екенін табу қиын. Әр бөліктен кейін бағдарламаны іске қосыңыз.

**2. Бөліктер ретін шатастыру.** Кейін салынған фигура бұрын салынғанды жауып қалады. Жерді үйден кейін салсаңыз, үйдің төменгі бөлігі жерге «батып» кетеді:

```text
# қате рет: алдымен үй, сосын жер
```

**3. Боялатын фигураның алдында `penup()` қалып қою.** Қалам көтеріліп тұрса, жиек сызылмайды, бірақ бояу орындалады — бұл кейде пайдалы, бірақ көбіне күтпеген нәтиже береді.

**4. Файлды `turtle.py` деп сақтау.** Сонда `import turtle` модульдің орнына сіздің файлыңызды жүктейді. Қолайлы атау: `menin_suretim.py`.

**5. Айнымалы атауларында кириллица.** Python 3 мұны рұқсат етеді (`күн = 40` жұмыс істейді), бірақ PEP 8 келісімдері бойынша атаулар латынша жазылады: `sun_radius = 40`.

## Ескерту

- Суретті файлға сақтауға болады: `turtle.getscreen().getcanvas().postscript(file="surret.eps")` векторлық EPS файлын жасайды; PNG алу үшін оны басқа бағдарламамен түрлендіреді (мысалы, Pillow + Ghostscript).
- Фигуралар көп болса, басында `turtle.tracer(0)`, соңында `turtle.update()` қолданыңыз — сурет бірден пайда болады.
- Егер контур тұйықталмаса, `end_fill()` бояу аймағын соңғы нүктеден біріншіге дейін түзумен өзі тұйықтайды (жиексіз). Сегментті осылай бояуға болады: `begin_fill()`, `circle(r, 180)`, `end_fill()`.
- `write` командасындағы қаріп `(атауы, өлшемі, стилі)` кортежімен беріледі; жүйеде ондай қаріп болмаса, Tk қатесіз әдепкі қаріпті қоя салады.
- Python-ның стандартты жинағында дайын мысалдар бар: `python -m turtledemo` демонстрациялық бағдарламалар мен олардың коды бар терезені ашады.
- Құжаттама: https://docs.python.org/3/library/turtle.html
