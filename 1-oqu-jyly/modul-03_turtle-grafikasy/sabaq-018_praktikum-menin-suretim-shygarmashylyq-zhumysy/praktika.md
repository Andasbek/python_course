# Сабақ 18. Практикалық тапсырмалар: «Менің суретім» практикумы

## Базалық деңгей

Практикум — бір үлкен жоба. Оны төмендегі қадамдармен орындаңыз. Базалық деңгейге 1–5 қадамды толық орындау жеткілікті.

### 1-қадам. Идеяны таңдау (5 мин)
Өз идеяңыз болмаса, тізімнен таңдаңыз:

| № | Тақырып | Негізгі бөліктер |
|---|---|---|
| 1 | «Тау етегіндегі киіз үй» | аспан, таулар (үшбұрыштар), жайлау, киіз үй (тіктөртбұрыш + доға), күн |
| 2 | «Түнгі қала» | қараңғы фон, ай, жұлдыздар (`dot`), үйлер, жарық терезелер |
| 3 | «Ғарыш» | қара фон, планеталар (шеңберлер), зымыран (тіктөртбұрыш + үшбұрыш), жұлдыздар |
| 4 | «Менің мектебім» | ғимарат, терезелер, есік, ту, ағаштар |
| 5 | «Теңіз жағасы» | аспан, теңіз, құм, қайық (трапеция + үшбұрыш желкен), күн |
| 6 | «Автобус» | корпус, терезелер, дөңгелектер (шеңберлер), жол |
| 7 | «Робот» | бас, дене, қол-аяқтар (тіктөртбұрыштар), көздер (`dot`), антенна |
| 8 | «Гүлзар» | жер, сабақтар (сызықтар), гүлдер (шеңберлер), көбелек |

### 2-қадам. Эскиз және бөліктер кестесі (7 мин)
Торкөз қағазға эскиз салып (1 торкөз = 20 пиксель), кестені толтырыңыз:

| № | Бөлік | Фигура | Нүктелер/өлшемдер | Жиек/бояу түсі |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

### 3-қадам. Баптаулар блогы
Теориядағы шаблонды көшіріп, атауын, фон түсін, терезе өлшемін орнатыңыз.

### 4-қадам. Бөліктерді кезекпен кодтау
Кестедегі әр бөлікті жеке блок етіп жазыңыз. Әр блоктан кейін іске қосып тексеріңіз.

### 5-қадам. Атауы, авторы, тестілеу
`write` арқылы атауы мен атыңызды жазыңыз. Чек-парақ бойынша тексеріңіз:

- [ ] Қатесіз іске қосылады
- [ ] ≥ 5 бөлік, ≥ 3 түс, ≥ 2 боялған фигура
- [ ] `goto`, `penup`/`pendown`, `circle` немесе `dot` бар
- [ ] Артық сызық жоқ, тасбақа жасырылған
- [ ] Түсініктемелер бар

## Кеңейтілген деңгей

### 6-қадам. Интерактивтілік
Бағдарлама басында `input()` арқылы пайдаланушыдан бір нәрсе сұраңыз және оны суретте қолданыңыз. Мысалдар:
- «Аспанның түсін енгізіңіз (ағылшынша):» → `bgcolor`;
- «Ғарышкердің аты:» → `write` арқылы зымыранның жанына жазу;
- «Үйдің қабат саны (1–3):» → әр қабаттың биіктігін есептеу: `biiktik = qabat * 60`.

### 7-қадам. Күрделі пішіндер
Суретке кемінде бір күрделі элемент қосыңыз: жұлдыз (`right(144)`), доға (`circle(r, 180)`), көпбұрыш (бесбұрыш, алтыбұрыш).

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-қадам. «Масштаб»
Пайдаланушыдан `k` масштаб коэффициентін (мысалы, 0.5, 1, 2) сұраңыз. Суреттің негізгі нысанының **барлық** өлшемдері мен координаталары `k`-ға көбейтілсін (`t.goto(100 * k, 50 * k)`). k = 2 болғанда сурет екі есе үлкейеді.

### 9-қадам. «Қайталама суреттер»
Бір нысанды (мысалы, ағашты) әртүрлі жерге үш рет салыңыз. Ол үшін нысанның барлық нүктелерін `x0`, `y0` айнымалыларына қатысты жазыңыз (`t.goto(x0 + 20, y0 + 60)`), сосын `x0`, `y0` мәндерін өзгертіп, блокты көшіріңіз. Ойланыңыз: бұл қайталауды болашақта қалай қысқартуға болады?

## Үй тапсырмасы

1. Жұмысыңызды көрмедегі кері байланыс бойынша жетілдіріңіз («тілекті» орындаңыз).
2. Скриншот жасап, файлмен бірге педагогке жіберіңіз (немесе флешкаға сақтаңыз).
3. Келесі модульге дайындық: «Егер жаңбыр жауса, қолшатыр аламын, әйтпесе — кепка» сияқты күнделікті өмірден 3 «егер … онда … әйтпесе …» сөйлемін жазыңыз.

## Бағалау критерийлері

| № | Критерий | Ұпай |
|---|---|---|
| 1 | Жоспарлау: эскиз және бөліктер кестесі бар | 2 |
| 2 | Техникалық орындалу: бағдарлама қатесіз іске қосылады | 2 |
| 3 | Командаларды қолдану: `goto`, `penup`/`pendown`, бояу, `circle`/`dot`, `write` | 3 |
| 4 | Талаптар: ≥ 5 бөлік, ≥ 3 түс, ≥ 2 боялған фигура, артық сызық жоқ | 3 |
| 5 | Код мәдениеті: түсініктемелер, бөліктерге бөлу, түсінікті айнымалылар | 2 |
| 6 | Шығармашылық: идеяның дербестігі, композиция, эстетика | 3 |
| 7 | Қосымша: `input()`, күрделі пішін, масштаб | 2 |
| 8 | Таныстыру: құрылым сақталған, анық, сұраққа жауап берді | 3 |
| | **Барлығы** | **20** |

| Ұпай | Деңгей |
|---|---|
| 18–20 | Өте жақсы |
| 14–17 | Жақсы |
| 10–13 | Қанағаттанарлық |
| 0–9 | Қосымша жұмыс қажет (педагогпен бірге жетілдіру) |

**Көрме регламенті:** баяндама — 1–2 минут; сұрақтар мен пікірлер — 1 минут; кезек — педагог шақыруы бойынша немесе жеребемен; соңында «Көрермендер жүлдесі» дауыс беру.

## Педагогке: шешімдер

<details><summary>Шешімдерді көрсету</summary>

**Үлгі жоба: «Тау етегіндегі киіз үй»** (базалық + кеңейтілген деңгей; `input` арқылы аспан түсі таңдалады).

```python
# Жоба: «Тау етегіндегі киіз үй»
# Авторы: педагог үлгісі
import turtle

aspan = input("Аспанның түсін енгізіңіз (мысалы skyblue): ")

# --- Баптаулар ---
turtle.setup(800, 600)
turtle.title("Тау етегіндегі киіз үй")
turtle.bgcolor(aspan)
t = turtle.Turtle()
t.speed(0)

# --- 1. Таулар ---
t.penup()
t.goto(-400, -50)
t.pendown()
t.color("dimgray", "gray")
t.begin_fill()
t.goto(-200, 200)
t.goto(0, -50)
t.goto(-400, -50)
t.end_fill()
t.begin_fill()
t.goto(-100, -50)
t.goto(150, 230)
t.goto(400, -50)
t.goto(-100, -50)
t.end_fill()
# қарлы шың
t.penup()
t.goto(150, 230)
t.pendown()
t.color("white", "white")
t.begin_fill()
t.goto(105, 180)
t.goto(195, 180)
t.goto(150, 230)
t.end_fill()

# --- 2. Жайлау ---
t.penup()
t.goto(-400, -300)
t.pendown()
t.color("green", "limegreen")
t.begin_fill()
t.goto(400, -300)
t.goto(400, -50)
t.goto(-400, -50)
t.goto(-400, -300)
t.end_fill()

# --- 3. Киіз үй: керегесі ---
t.penup()
t.goto(-80, -180)
t.pendown()
t.color("saddlebrown", "ivory")
t.pensize(2)
t.begin_fill()
t.goto(80, -180)
t.goto(80, -100)
t.goto(-80, -100)
t.goto(-80, -180)
t.end_fill()

# --- 4. Киіз үй: күмбезі (жарты шеңбер) ---
t.penup()
t.goto(80, -100)
t.setheading(90)
t.pendown()
t.color("saddlebrown", "ivory")
t.begin_fill()
t.circle(80, 180)
t.goto(80, -100)
t.end_fill()

# --- 5. Есік ---
t.penup()
t.goto(-20, -180)
t.setheading(0)
t.pendown()
t.color("saddlebrown", "orangered")
t.begin_fill()
t.goto(20, -180)
t.goto(20, -120)
t.goto(-20, -120)
t.goto(-20, -180)
t.end_fill()

# --- 6. Шаңырақ ---
t.penup()
t.goto(0, -20)
t.dot(20, "saddlebrown")

# --- 7. Күн ---
t.goto(-300, 160)
t.setheading(0)
t.pendown()
t.color("orange", "yellow")
t.begin_fill()
t.circle(40)
t.end_fill()

# --- Атауы мен авторы ---
t.penup()
t.pencolor("black")
t.goto(0, 250)
t.write("Тау етегіндегі киіз үй", align="center", font=("Arial", 22, "bold"))
t.goto(380, -290)
t.write("Авторы: педагог", align="right", font=("Arial", 12, "italic"))

t.hideturtle()
turtle.done()
```

Түсіндірме: күмбез — тасбақа (80; −100) нүктесінде жоғары қарап тұрып, `circle(80, 180)` арқылы сол жаққа қарай жарты шеңбер сызады да, (−80; −100) нүктесіне келеді; `goto(80, -100)` фигураны тұйықтайды.

**8-қадам (масштаб) үлгісі** — киіз үйдің керегесі:

```python
import turtle

k = float(input("Масштаб (мысалы 0.5, 1, 2): "))
t = turtle.Turtle()
t.penup()
t.goto(-80 * k, -180 * k)
t.pendown()
t.color("saddlebrown", "ivory")
t.begin_fill()
t.goto(80 * k, -180 * k)
t.goto(80 * k, -100 * k)
t.goto(-80 * k, -100 * k)
t.goto(-80 * k, -180 * k)
t.end_fill()
turtle.done()
```

**9-қадам үлгісі** — ағаш үш рет (`x0`, `y0` — діңнің сол-төменгі бұрышы):

```python
import turtle

t = turtle.Turtle()
t.speed(0)

# --- 1-ағаш ---
x0 = -200
y0 = -100
t.penup()
t.goto(x0, y0)
t.pendown()
t.color("brown", "brown")
t.begin_fill()
t.goto(x0 + 20, y0)
t.goto(x0 + 20, y0 + 50)
t.goto(x0, y0 + 50)
t.goto(x0, y0)
t.end_fill()
t.penup()
t.goto(x0 - 40, y0 + 50)
t.pendown()
t.color("darkgreen", "green")
t.begin_fill()
t.goto(x0 + 60, y0 + 50)
t.goto(x0 + 10, y0 + 140)
t.goto(x0 - 40, y0 + 50)
t.end_fill()

# --- 2-ағаш: тек x0, y0 өзгерді ---
x0 = 0
y0 = -150
t.penup()
t.goto(x0, y0)
t.pendown()
t.color("brown", "brown")
t.begin_fill()
t.goto(x0 + 20, y0)
t.goto(x0 + 20, y0 + 50)
t.goto(x0, y0 + 50)
t.goto(x0, y0)
t.end_fill()
t.penup()
t.goto(x0 - 40, y0 + 50)
t.pendown()
t.color("darkgreen", "green")
t.begin_fill()
t.goto(x0 + 60, y0 + 50)
t.goto(x0 + 10, y0 + 140)
t.goto(x0 - 40, y0 + 50)
t.end_fill()

# --- 3-ағаш ---
x0 = 200
y0 = -100
t.penup()
t.goto(x0, y0)
t.pendown()
t.color("brown", "brown")
t.begin_fill()
t.goto(x0 + 20, y0)
t.goto(x0 + 20, y0 + 50)
t.goto(x0, y0 + 50)
t.goto(x0, y0)
t.end_fill()
t.penup()
t.goto(x0 - 40, y0 + 50)
t.pendown()
t.color("darkgreen", "green")
t.begin_fill()
t.goto(x0 + 60, y0 + 50)
t.goto(x0 + 10, y0 + 140)
t.goto(x0 - 40, y0 + 50)
t.end_fill()

t.hideturtle()
turtle.done()
```

Ойлануға жауап: бір блокты бірнеше рет көшіру — болашақта **цикл** (26-сабақ) және **функция** арқылы қысқартылады.

**Педагогке әдістемелік кеңестер:**
- Әлсіз оқушыларға дайын шаблон мен 1–2 бөлігі бар бастама береді; күшті оқушыларға 8–9-қадамдарды ұсыныңыз.
- Көрмеге уақыт жетпесе, жұмыстарды скриншот түрінде топтық чатқа/слайдқа жинап, келесі сабақтың басында 5 минут көрме өткізуге болады.
- Модульдің «ең үздік жұмыстарын» орталықтың стендіне немесе әлеуметтік желісіне (ата-ана келісімімен) жариялауға болады.
