## 1. Этапы создания графической программы

Любой программный проект — даже небольшой рисунок — проходит одни и те же этапы:

```text
 1. ИДЕЯ  →  2. ЭСКИЗ  →  3. ДЕКОМПОЗИЦИЯ  →  4. КОД  →  5. ТЕСТИРОВАНИЕ  →  6. ОФОРМЛЕНИЕ
```

### 1.1. Идея
Сформулируйте, что должно получиться, одним предложением: «Юрта у подножия гор и солнце». Чем проще и конкретнее идея, тем легче превратить её в алгоритм.

### 1.2. Эскиз
На бумаге в клетку начертите оси координат (например, одна клетка = 20 пикселей). Нарисуйте рисунок и отметьте важные точки: углы фигур, центры окружностей.

### 1.3. Декомпозиция — таблица частей

| № | Часть | Фигура | Точки/размеры | Цвет обводки/заливки |
|---|---|---|---|---|
| 1 | Земля | прямоугольник | (−400; −300) … (400; −100) | `green` / `green` |
| 2 | Юрта | прямоугольник + полуокружность | (−80; −100) … (80; 0), r = 80 | `black` / `white` |
| 3 | Солнце | окружность | центр (250; 200), r = 40 | `orange` / `yellow` |

**Порядок рисования:** задний план (фон, земля, небо) → крупные объекты → мелкие детали → текст. То, что нарисовано позже, перекрывает нарисованное раньше.

### 1.4. Написание кода
- В начале программы — настройки: `import`, `setup`, `bgcolor`, `speed(0)`.
- Каждая часть — отдельный блок с комментарием сверху (`# --- Солнце ---`).
- После каждого блока программу стоит запустить и проверить: так ошибку проще локализовать.

### 1.5. Тестирование
Тестирование — проверка того, что программа работает так, как задумано. Для рисунка проверяют: запуск без ошибок, отсутствие лишних линий, замкнутость закрашенных фигур, попадание рисунка в окно.

### 1.6. Оформление
Подпись (название, автор) через `write`, `hideturtle()` в конце, понятные комментарии и имена переменных.

## 2. Шаблон программы-рисунка

```python
# Проект: «Мой рисунок»
# Автор: ___________
import turtle

# --- Настройки ---
turtle.setup(800, 600)
turtle.title("Мой рисунок")
turtle.bgcolor("lightyellow")
t = turtle.Turtle()
t.speed(0)

# --- Часть 1: ... ---
t.penup()
t.goto(-100, -100)
t.pendown()
t.color("black", "orange")
t.begin_fill()
t.goto(100, -100)
t.goto(0, 50)
t.goto(-100, -100)
t.end_fill()

# --- Часть 2: ... ---

# --- Название и автор ---
t.penup()
t.goto(0, 250)
t.write("Мой рисунок", align="center", font=("Arial", 22, "bold"))
t.goto(300, -280)
t.write("Автор: ...", align="right", font=("Arial", 12, "italic"))

t.hideturtle()
turtle.done()
```

Параметр `align` у `write` принимает `"left"` (по умолчанию), `"center"` или `"right"` — относительно точки, где стоит черепашка.

## 3. Полезные «рецепты»

| Что нужно | Как |
|---|---|
| Окружность с центром (a; b) и радиусом r | `penup()`, `goto(a, b - r)`, `setheading(0)`, `pendown()`, `circle(r)` |
| Полуокружность (восход солнца, дуга) | `circle(r, 180)` |
| Прямоугольник (x1; y1)–(x2; y2) | обойти четыре угла с помощью `goto` |
| Звезда | 5 раз `forward(a)` + `right(144)` |
| Текст по центру | `write("...", align="center")` |
| Мягкие цвета | `"lightblue"`, `"lightgreen"`, `"peachpuff"`, `"lavender"` |
| Тёмные цвета | `"navy"`, `"darkgreen"`, `"maroon"`, `"indigo"` |

### Пример: пятиконечная звезда

Сумма поворотов черепашки при обходе звезды равна 720° (два полных оборота), поэтому каждый поворот — 720 / 5 = **144°**.

```python
import turtle

t = turtle.Turtle()
t.color("gold", "yellow")
t.begin_fill()
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.forward(150)
t.right(144)
t.end_fill()
t.hideturtle()
turtle.done()
```

### Пример: юрта из прямоугольника и полуокружности

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.color("black", "white")
# стена: прямоугольник (-80; -100) ... (80; 0)
t.penup()
t.goto(-80, -100)
t.pendown()
t.begin_fill()
t.goto(80, -100)
t.goto(80, 0)
t.goto(-80, 0)
t.goto(-80, -100)
t.end_fill()
# купол: полуокружность радиуса 80 над стеной
t.penup()
t.goto(80, 0)
t.setheading(90)
t.pendown()
t.begin_fill()
t.circle(80, 180)
t.goto(80, 0)
t.end_fill()
t.hideturtle()
turtle.done()
```

Черепашка в точке (80; 0) смотрит вверх, а `circle(80, 180)` ведёт её против часовой стрелки по дуге в точку (−80; 0) — получается купол.

## 4. Чек-лист проверки рисунка

- [ ] Программа запускается без ошибок.
- [ ] Нет лишних линий от центра или между фигурами (перед каждым `goto` в новое место — `penup()`).
- [ ] Все закрашиваемые фигуры замкнуты, у каждого `begin_fill()` есть `end_fill()`.
- [ ] Рисунок полностью помещается в окно (координаты в пределах `setup`).
- [ ] Написаны название и автор.
- [ ] В конце есть `hideturtle()` и `turtle.done()`.
- [ ] Есть комментарии, переменные названы понятно.

## 5. Шпаргалка по модулю turtle

| Группа | Команды |
|---|---|
| Создание и окно | `import turtle`, `t = turtle.Turtle()`, `turtle.setup(w, h)`, `turtle.title(...)`, `turtle.bgcolor(...)`, `turtle.done()` |
| Относительное движение | `forward`, `back`, `left`, `right`, `circle(r)`, `circle(r, угол)` |
| Абсолютное движение | `goto(x, y)`, `setx`, `sety`, `setheading(a)`, `home()` |
| Перо | `penup()`, `pendown()`, `pencolor`, `pensize`, `color(a, b)` |
| Заливка | `fillcolor`, `begin_fill()`, `end_fill()` |
| Прочее | `dot(d, цвет)`, `write(текст, align=..., font=...)`, `speed(n)`, `shape(...)`, `hideturtle()` |
| Состояние | `position()`, `xcor()`, `ycor()`, `heading()` |

Все программы на turtle, рассмотренные до сих пор, — **линейные алгоритмы**: команды выполняются строго сверху вниз. Чтобы программа могла выбирать действие в зависимости от условия, используется **ветвление** (`if`, `else`, `elif`), а повторяющиеся команды записываются с помощью **циклов**.

## Частые ошибки

**1. Написать всё сразу и запустить потом.** Трудно найти, где ошибка. Запускайте программу после каждой части.

**2. Путаница в порядке частей.** Фигура, нарисованная позже, закрывает раньше нарисованную. Если нарисовать землю после дома, нижняя часть дома «утонет» в земле:

```text
# неверный порядок: сначала дом, потом земля
```

**3. Оставленный `penup()` перед закрашиваемой фигурой.** Если перо поднято, обводка не рисуется, но заливка выполняется — иногда это полезно, но чаще даёт неожиданный результат.

**4. Сохранение файла как `turtle.py`.** Тогда `import turtle` загрузит ваш файл вместо модуля. Подходящее имя: `menin_suretim.py`.

**5. Кириллица в именах переменных.** Python 3 это допускает (`солнце = 40` работает), но по соглашениям PEP 8 имена принято писать латиницей: `sun_radius = 40`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Эскиз | Предварительный набросок рисунка на бумаге с координатами |
| Декомпозиция | Разбиение сложной задачи на простые части |
| Комментарий | Строка после `#`, поясняющая код; Python её не выполняет |
| Тестирование | Проверка правильности работы программы |
| Чек-лист | Список пунктов для проверки |
| Линейный алгоритм | Алгоритм, команды которого выполняются по порядку, без условий и повторений |

## Примечание

- Рисунок можно сохранить в файл: `turtle.getscreen().getcanvas().postscript(file="risunok.eps")` создаёт векторный файл EPS; для PNG его потом конвертируют сторонней программой (например, Pillow + Ghostscript).
- При большом количестве фигур используйте `turtle.tracer(0)` в начале и `turtle.update()` в конце — рисунок появится мгновенно.
- Если контур не замкнут, `end_fill()` сам замыкает область заливки прямой от последней точки к первой (без обводки). Так можно закрасить сегмент: `begin_fill()`, `circle(r, 180)`, `end_fill()`.
- Шрифт в `write` задаётся кортежем `(название, размер, стиль)`; если шрифта нет в системе, Tk тихо подставит шрифт по умолчанию, ошибки не будет.
- В стандартной поставке Python есть набор готовых примеров: `python -m turtledemo` открывает окно с демонстрационными программами и их кодом.
- Документация: https://docs.python.org/3/library/turtle.html
