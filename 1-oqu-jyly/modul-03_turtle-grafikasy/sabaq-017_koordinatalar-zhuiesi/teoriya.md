## 1. Координаталар жүйесі

Математикадан таныс **тікбұрышты (Декарт) координаталар жүйесі** turtle терезесінде де бар:

- **X осі** — көлденең: оңға қарай мән өседі, солға қарай азаяды (теріс болады);
- **Y осі** — тік: жоғары қарай өседі, төмен қарай азаяды;
- **бас нүкте (0; 0)** — терезенің дәл ортасы, тасбақа осы жерден бастайды.

```text
                    Y
                    ↑  (0; 200)
                    |
     (-200; 100) •  |        • (150; 100)
                    |
 ———————————————————•———————————————————→ X
 (-300; 0)       (0; 0)              (300; 0)
                    |
         • (-100; -150)
                    |
```

| Ширек | x | y | Мысал |
|---|---|---|---|
| Оң жақ жоғарғы | + | + | (100; 50) |
| Сол жақ жоғарғы | − | + | (−100; 50) |
| Сол жақ төменгі | − | − | (−100; −50) |
| Оң жақ төменгі | + | − | (100; −50) |

> Аналогия: сыныптағы парталар. «3-қатар, 2-парта» деген — координата. Нүктенің мекенжайы да осылай екі санмен беріледі: алдымен **x**, сосын **y**.

Терезенің өлшемін білу үшін: `turtle.window_width()` және `turtle.window_height()`. Өлшемді өзіміз де орната аламыз: `turtle.setup(800, 600)` — сонда x шамамен −400…400, y −300…300 аралығында болады.

## 2. goto() және setpos() — нүктеге бару

`t.goto(x, y)` — тасбақа **түзу сызықпен** (x; y) нүктесіне барады. `setpos(x, y)` және `setposition(x, y)` — дәл осы команданың басқа атаулары.

```python
import turtle

t = turtle.Turtle()
t.goto(100, 0)
t.goto(100, 100)
t.goto(0, 100)
t.goto(0, 0)
turtle.done()
```

Нәтижесі: қабырғасы 100 шаршы — бірде-бір `left` жоқ!

**Маңызды:** `goto` тасбақаның **бағытын өзгертпейді**. Ол «қырындап» жүре береді. Қалам төмен тұрса — із қалады.

### Үшбұрышты бұрышын есептемей салу

Салыстырмалы қозғалыста үшбұрыш үшін бұрылу бұрышын (мысалы, 120°) есептеу керек. Координатамен кез келген үшбұрышты бірден саламыз:

```python
import turtle

t = turtle.Turtle()
t.color("purple", "violet")
t.begin_fill()
t.goto(150, 0)
t.goto(40, 120)
t.goto(0, 0)
t.end_fill()
turtle.done()
```

### Із қалдырмай бару

Жаңа фигураны басқа жерде бастау үшін — қаламды көтеріп, `goto`:

```python
import turtle

t = turtle.Turtle()
t.penup()
t.goto(-200, 100)   # жаңа орынға секіру
t.pendown()
t.circle(40)
t.penup()
t.goto(150, -100)
t.pendown()
t.circle(40)
turtle.done()
```

## 3. setx(), sety(), home()

| Команда | Не істейді |
|---|---|
| `t.setx(x)` | тек x координатасын өзгертеді (көлденең жылжиды) |
| `t.sety(y)` | тек y координатасын өзгертеді (тік жылжиды) |
| `t.home()` | (0; 0) нүктесіне қайтады және бағытын оңға (0°) бұрады |

```python
import turtle

t = turtle.Turtle()
t.setx(120)    # (120; 0)
t.sety(80)     # (120; 80)
t.home()       # (0; 0) — диагональ сызық
turtle.done()
```

Нәтижесі: тікбұрышты үшбұрыш.

## 4. Тасбақа қайда тұр? position(), xcor(), ycor()

| Команда | Нәтижесі |
|---|---|
| `t.position()` / `t.pos()` | ағымдағы координаталар `(x, y)` |
| `t.xcor()` | тек x |
| `t.ycor()` | тек y |
| `t.heading()` | ағымдағы бағыт (градуспен) |

```python
import turtle

t = turtle.Turtle()
t.forward(100)
t.left(90)
t.forward(50)
print("Орны:", t.position())
print("x =", t.xcor(), "y =", t.ycor())
print("Бағыты:", t.heading())
turtle.done()
```

Нәтижесі:
```text
Орны: (100.00,50.00)
x = 100.0 y = 50.0
Бағыты: 90.0
```

Бұл командалар **алгоритмді тексеруге** өте пайдалы: тасбақа күткен жерге жетті ме, жоқ па — бірден көреміз.

## 5. Абсолютті бағыт: setheading()

`t.setheading(a)` (қысқа түрі `t.seth(a)`) — тасбақаны қазір қайда қарап тұрғанына қарамастан, нақты бағытқа бұрады:

| Бұрыш | Бағыт |
|---|---|
| 0 | оңға (шығыс) |
| 90 | жоғары (солтүстік) |
| 180 | солға (батыс) |
| 270 | төмен (оңтүстік) |

```python
import turtle

t = turtle.Turtle()
t.setheading(90)    # жоғары қарау
t.forward(100)
t.setheading(0)     # оңға қарау
t.forward(100)
turtle.done()
```

## 6. Салыстырмалы және абсолютті қозғалыс

| | Салыстырмалы | Абсолютті |
|---|---|---|
| Командалар | `forward`, `back`, `left`, `right` | `goto`, `setpos`, `setx`, `sety`, `setheading`, `home` |
| Нәтиже неге тәуелді | тасбақаның **қазіргі** орны мен бағытына | тек берілген сандарға |
| Аналогия | «10 қадам алға жүр де, оңға бұрыл» | «Абай даңғылы, 15-үйге бар» |
| Ыңғайлы | дұрыс көпбұрыштар, шеңберлер | нақты нүктелері бар суреттер, орын ауыстыру |

Екі тәсілді **бірге** қолдану — ең тиімдісі: `goto` арқылы бастапқы нүктеге барамыз, сосын `forward`/`left` арқылы фигураны саламыз.

## 7. Мәтін жазу: write()

```python
import turtle

t = turtle.Turtle()
t.hideturtle()
t.penup()
t.goto(-120, 150)
t.write("Менің суретім", font=("Arial", 20, "bold"))
turtle.done()
```

`write` мәтінді тасбақа тұрған нүктеден бастап жазады. `font` — (қаріп, өлшемі, стиль); стиль: `"normal"`, `"bold"`, `"italic"`. `align="center"` параметрі мәтінді нүктеге қатысты ортаға қояды.

## 8. Күрделі сурет салу алгоритмі

Үлкен суретті бірден салу қиын. Бағдарламашылар **декомпозиция** (бөлшектеу) әдісін қолданады: күрделі тапсырманы шағын, қарапайым бөліктерге бөледі.

**Қадамдар:**
1. **Эскиз.** Суретті торкөз қағазға салыңыз.
2. **Бөліктерге бөлу.** Суретті қарапайым фигураларға жіктеңіз: тіктөртбұрыштар, үшбұрыштар, шеңберлер.
3. **Координаталарды анықтау.** Әр фигураның негізгі нүктелерін (бұрыштарын, центрін) жазып алыңыз.
4. **Реттілік.** Қай фигура алдымен салынады? (Артқы фон → үлкен заттар → ұсақ бөлшектер.)
5. **Кодты кезең-кезеңімен жазу.** Әр бөліктің алдына `# --- Күн ---` сияқты түсініктеме қойыңыз. Әр бөлікті жазған сайын іске қосып тексеріңіз.
6. **Түзету және безендіру.** Түстер, қалыңдық, `hideturtle()`.

### Мысал: «Дала үйі»

Эскиз бойынша бөліктер кестесі:

| № | Бөлік | Фигура | Негізгі нүктелер | Түсі |
|---|---|---|---|---|
| 1 | Аспан | фон | — | `skyblue` |
| 2 | Жер | тіктөртбұрыш | (−400; −300) … (400; −100) | `green` |
| 3 | Үй қабырғасы | тіктөртбұрыш | (−100; −100) … (100; 50) | `burlywood` |
| 4 | Шатыр | үшбұрыш | (−120; 50), (120; 50), (0; 150) | `brown` |
| 5 | Есік | тіктөртбұрыш | (−20; −100) … (20; −20) | `saddlebrown` |
| 6 | Күн | шеңбер | центрі (250; 200), r = 40 | `yellow` |

```python
import turtle

turtle.setup(800, 600)
turtle.bgcolor("skyblue")              # 1. Аспан
t = turtle.Turtle()
t.speed(0)
t.hideturtle()

# --- 2. Жер ---
t.penup()
t.goto(-400, -300)
t.pendown()
t.color("green", "green")
t.begin_fill()
t.goto(400, -300)
t.goto(400, -100)
t.goto(-400, -100)
t.goto(-400, -300)
t.end_fill()

# --- 3. Үй қабырғасы ---
t.penup()
t.goto(-100, -100)
t.pendown()
t.color("black", "burlywood")
t.begin_fill()
t.goto(100, -100)
t.goto(100, 50)
t.goto(-100, 50)
t.goto(-100, -100)
t.end_fill()

# --- 4. Шатыр ---
t.penup()
t.goto(-120, 50)
t.pendown()
t.color("black", "brown")
t.begin_fill()
t.goto(120, 50)
t.goto(0, 150)
t.goto(-120, 50)
t.end_fill()

# --- 5. Есік ---
t.penup()
t.goto(-20, -100)
t.pendown()
t.color("black", "saddlebrown")
t.begin_fill()
t.goto(20, -100)
t.goto(20, -20)
t.goto(-20, -20)
t.goto(-20, -100)
t.end_fill()

# --- 6. Күн: центрі (250; 200), сондықтан (250; 160)-тан бастаймыз ---
t.penup()
t.goto(250, 160)
t.setheading(0)
t.pendown()
t.color("orange", "yellow")
t.begin_fill()
t.circle(40)
t.end_fill()

turtle.done()
```

> Байқаңыз: шеңбердің центрі (a; b) болуы үшін тасбақаны (a; b − r) нүктесіне апарып, `setheading(0)` жасаймыз. Бұл — пайдалы «формула».

## Жиі кездесетін қателер

**1. Координаталарды бөлек жазбау / тырнақшаға алу.**

```text
t.goto(100 100)       # SyntaxError: үтір жоқ
t.goto("100, 100")    # қате: мәтін берілді
```

```python
import turtle
t = turtle.Turtle()
t.goto(100, 100)      # дұрыс
turtle.done()
```

**2. x пен y-ті шатастыру.** `goto(50, 200)` — оңға 50, жоғары 200. Бірінші сан әрқашан көлденең (x).

**3. Бастапқы нүктеге қалам төмен тұрғанда бару.** Ортадан фигураға дейін артық сызық пайда болады. Шешімі: `penup()` → `goto(...)` → `pendown()`.

**4. `goto` бағытты өзгертеді деп ойлау.** `goto`-дан кейін `forward` жазсаңыз, тасбақа бұрынғы бағытымен жүреді. Керек болса, `setheading()` қолданыңыз.

**5. Нүкте терезеден тыс.** `goto(1000, 0)` — сурет көрінбейді. `turtle.setup(...)` өлшемін тексеріңіз.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Координаталар жүйесі | X (көлденең) және Y (тік) осьтері бар жазықтық |
| Бас нүкте (0; 0) | Терезенің ортасы |
| `goto(x, y)` / `setpos(x, y)` | (x; y) нүктесіне түзу сызықпен бару |
| `setx(x)` / `sety(y)` | Бір координатаны ғана өзгерту |
| `home()` | (0; 0)-ге қайту, бағыт 0° |
| `setheading(a)` | Абсолютті бағыт орнату (0 — оң, 90 — жоғары) |
| `position()`, `xcor()`, `ycor()` | Тасбақаның ағымдағы орны |
| `write("мәтін")` | Экранға мәтін жазу |
| Декомпозиция | Күрделі тапсырманы қарапайым бөліктерге бөлу |

## Ескерту

- `goto` бір кортежді де қабылдайды: `t.goto((100, 50))` немесе `t.goto(t.position())`. `position()` мәні — `Vec2D` объектісі, оны векторлар сияқты қосып-азайтуға болады.
- Координаталар бөлшек сан (`float`) түрінде сақталады, сондықтан көп бұрылыстан кейін `xcor()` `100` орнына `99.99999999999999` қайтаруы мүмкін. Салыстыру үшін `round(t.xcor())` қолданыңыз.
- `t.distance(x, y)` нүктеге дейінгі қашықтықты, ал `t.towards(x, y)` сол нүктеге қарау үшін орнату керек бұрышты (`setheading`) қайтарады.
- `turtle.setworldcoordinates(x1, y1, x2, y2)` өз координаталар жүйесін орнатады (мысалы, бас нүкте сол жақ төменгі бұрышта), бірақ терезе мен координаталардың пропорциясы әртүрлі болса, экрандағы бұрыштар бұрмалануы мүмкін.
- `turtle.tracer(0)` анимацияны өшіреді, ал `turtle.update()` дайын суретті бірден шығарады — бұл үлкен суреттерді шығаруды едәуір жылдамдатады.
- Құжаттама: https://docs.python.org/3/library/turtle.html#turtle-motion
