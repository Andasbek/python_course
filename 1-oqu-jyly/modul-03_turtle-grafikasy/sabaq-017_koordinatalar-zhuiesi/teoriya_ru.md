## 1. Система координат

Знакомая из математики **прямоугольная (декартова) система координат** есть и в окне turtle:

- **ось X** — горизонтальная: вправо значения растут, влево уменьшаются (становятся отрицательными);
- **ось Y** — вертикальная: вверх растут, вниз уменьшаются;
- **начало координат (0; 0)** — точный центр окна, черепашка начинает отсюда.

```text
                    Y
                    ↑  (0; 200)
                    |
     (-200; 100) •  |        • (150; 100)
                    |
 ———————————————————•———————————————————→ X
 (-300; 0)       (0; 0)              (300; 0)
                    |
         • (-100; -150)
                    |
```

| Четверть | x | y | Пример |
|---|---|---|---|
| Правая верхняя | + | + | (100; 50) |
| Левая верхняя | − | + | (−100; 50) |
| Левая нижняя | − | − | (−100; −50) |
| Правая нижняя | + | − | (100; −50) |

> Аналогия: парты в классе. «3-й ряд, 2-я парта» — это координата. Адрес точки тоже задаётся двумя числами: сначала **x**, потом **y**.

Чтобы узнать размер окна: `turtle.window_width()` и `turtle.window_height()`. Размер можно задать и самим: `turtle.setup(800, 600)` — тогда x будет примерно в диапазоне −400…400, y — −300…300.

## 2. goto() и setpos() — переход в точку

`t.goto(x, y)` — черепашка идёт **по прямой** в точку (x; y). `setpos(x, y)` и `setposition(x, y)` — другие имена той же команды.

```python
import turtle

t = turtle.Turtle()
t.goto(100, 0)
t.goto(100, 100)
t.goto(0, 100)
t.goto(0, 0)
turtle.done()
```

Результат: квадрат со стороной 100 — и ни одного `left`!

**Важно:** `goto` **не меняет направление** черепашки. Она движется «боком». Если перо опущено — остаётся след.

### Треугольник без вычисления углов

При относительном движении для треугольника нужно вычислять угол поворота (например, 120°). С координатами любой треугольник рисуется сразу:

```python
import turtle

t = turtle.Turtle()
t.color("purple", "violet")
t.begin_fill()
t.goto(150, 0)
t.goto(40, 120)
t.goto(0, 0)
t.end_fill()
turtle.done()
```

### Переход без следа

Чтобы начать новую фигуру в другом месте — поднимаем перо и делаем `goto`:

```python
import turtle

t = turtle.Turtle()
t.penup()
t.goto(-200, 100)   # прыжок на новое место
t.pendown()
t.circle(40)
t.penup()
t.goto(150, -100)
t.pendown()
t.circle(40)
turtle.done()
```

## 3. setx(), sety(), home()

| Команда | Что делает |
|---|---|
| `t.setx(x)` | меняет только координату x (движение по горизонтали) |
| `t.sety(y)` | меняет только координату y (движение по вертикали) |
| `t.home()` | возвращается в точку (0; 0) и поворачивает направление вправо (0°) |

```python
import turtle

t = turtle.Turtle()
t.setx(120)    # (120; 0)
t.sety(80)     # (120; 80)
t.home()       # (0; 0) — диагональная линия
turtle.done()
```

Результат: прямоугольный треугольник.

## 4. Где черепашка? position(), xcor(), ycor()

| Команда | Результат |
|---|---|
| `t.position()` / `t.pos()` | текущие координаты `(x, y)` |
| `t.xcor()` | только x |
| `t.ycor()` | только y |
| `t.heading()` | текущее направление (в градусах) |

```python
import turtle

t = turtle.Turtle()
t.forward(100)
t.left(90)
t.forward(50)
print("Положение:", t.position())
print("x =", t.xcor(), "y =", t.ycor())
print("Направление:", t.heading())
turtle.done()
```

Результат:
```text
Положение: (100.00,50.00)
x = 100.0 y = 50.0
Направление: 90.0
```

Эти команды очень полезны для **проверки алгоритма**: сразу видно, дошла черепашка до ожидаемого места или нет.

## 5. Абсолютное направление: setheading()

`t.setheading(a)` (краткая форма `t.seth(a)`) — поворачивает черепашку в конкретном направлении независимо от того, куда она смотрит сейчас:

| Угол | Направление |
|---|---|
| 0 | вправо (восток) |
| 90 | вверх (север) |
| 180 | влево (запад) |
| 270 | вниз (юг) |

```python
import turtle

t = turtle.Turtle()
t.setheading(90)    # смотреть вверх
t.forward(100)
t.setheading(0)     # смотреть вправо
t.forward(100)
turtle.done()
```

## 6. Относительное и абсолютное движение

| | Относительное | Абсолютное |
|---|---|---|
| Команды | `forward`, `back`, `left`, `right` | `goto`, `setpos`, `setx`, `sety`, `setheading`, `home` |
| От чего зависит результат | от **текущего** положения и направления черепашки | только от заданных чисел |
| Аналогия | «Пройди 10 шагов вперёд и поверни направо» | «Иди на проспект Абая, дом 15» |
| Удобно для | правильных многоугольников, окружностей | рисунков с конкретными точками, перемещений |

Использовать оба способа **вместе** — самое эффективное: с помощью `goto` переходим в начальную точку, затем рисуем фигуру через `forward`/`left`.

## 7. Вывод текста: write()

```python
import turtle

t = turtle.Turtle()
t.hideturtle()
t.penup()
t.goto(-120, 150)
t.write("Мой рисунок", font=("Arial", 20, "bold"))
turtle.done()
```

`write` пишет текст, начиная с точки, где стоит черепашка. `font` — (шрифт, размер, стиль); стиль: `"normal"`, `"bold"`, `"italic"`. Параметр `align="center"` выравнивает текст по центру относительно точки.

## 8. Алгоритм создания сложного рисунка

Большой рисунок сложно нарисовать сразу. Программисты используют метод **декомпозиции** (разбиения): делят сложную задачу на небольшие простые части.

**Шаги:**
1. **Эскиз.** Нарисуйте рисунок на бумаге в клетку.
2. **Разбиение на части.** Разложите рисунок на простые фигуры: прямоугольники, треугольники, окружности.
3. **Определение координат.** Запишите основные точки каждой фигуры (углы, центр).
4. **Последовательность.** Какая фигура рисуется первой? (Задний фон → крупные объекты → мелкие детали.)
5. **Поэтапное написание кода.** Перед каждой частью ставьте комментарий вроде `# --- Солнце ---`. После написания каждой части запускайте и проверяйте.
6. **Исправление и оформление.** Цвета, толщина, `hideturtle()`.

### Пример: «Дом в степи»

Таблица частей по эскизу:

| № | Часть | Фигура | Основные точки | Цвет |
|---|---|---|---|---|
| 1 | Небо | фон | — | `skyblue` |
| 2 | Земля | прямоугольник | (−400; −300) … (400; −100) | `green` |
| 3 | Стена дома | прямоугольник | (−100; −100) … (100; 50) | `burlywood` |
| 4 | Крыша | треугольник | (−120; 50), (120; 50), (0; 150) | `brown` |
| 5 | Дверь | прямоугольник | (−20; −100) … (20; −20) | `saddlebrown` |
| 6 | Солнце | окружность | центр (250; 200), r = 40 | `yellow` |

```python
import turtle

turtle.setup(800, 600)
turtle.bgcolor("skyblue")              # 1. Небо
t = turtle.Turtle()
t.speed(0)
t.hideturtle()

# --- 2. Земля ---
t.penup()
t.goto(-400, -300)
t.pendown()
t.color("green", "green")
t.begin_fill()
t.goto(400, -300)
t.goto(400, -100)
t.goto(-400, -100)
t.goto(-400, -300)
t.end_fill()

# --- 3. Стена дома ---
t.penup()
t.goto(-100, -100)
t.pendown()
t.color("black", "burlywood")
t.begin_fill()
t.goto(100, -100)
t.goto(100, 50)
t.goto(-100, 50)
t.goto(-100, -100)
t.end_fill()

# --- 4. Крыша ---
t.penup()
t.goto(-120, 50)
t.pendown()
t.color("black", "brown")
t.begin_fill()
t.goto(120, 50)
t.goto(0, 150)
t.goto(-120, 50)
t.end_fill()

# --- 5. Дверь ---
t.penup()
t.goto(-20, -100)
t.pendown()
t.color("black", "saddlebrown")
t.begin_fill()
t.goto(20, -100)
t.goto(20, -20)
t.goto(-20, -20)
t.goto(-20, -100)
t.end_fill()

# --- 6. Солнце: центр (250; 200), поэтому начинаем из (250; 160) ---
t.penup()
t.goto(250, 160)
t.setheading(0)
t.pendown()
t.color("orange", "yellow")
t.begin_fill()
t.circle(40)
t.end_fill()

turtle.done()
```

> Обратите внимание: чтобы центр окружности был в точке (a; b), переводим черепашку в точку (a; b − r) и делаем `setheading(0)`. Это полезная «формула».

## Частые ошибки

**1. Координаты не разделены / взяты в кавычки.**

```text
t.goto(100 100)       # SyntaxError: нет запятой
t.goto("100, 100")    # ошибка: передан текст
```

```python
import turtle
t = turtle.Turtle()
t.goto(100, 100)      # правильно
turtle.done()
```

**2. Путаница x и y.** `goto(50, 200)` — 50 вправо, 200 вверх. Первое число всегда горизонтальное (x).

**3. Переход в начальную точку с опущенным пером.** Появляется лишняя линия от центра до фигуры. Решение: `penup()` → `goto(...)` → `pendown()`.

**4. Мысль, что `goto` меняет направление.** Если после `goto` написать `forward`, черепашка пойдёт в прежнем направлении. При необходимости используйте `setheading()`.

**5. Точка за пределами окна.** `goto(1000, 0)` — рисунок не виден. Проверьте размер в `turtle.setup(...)`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Система координат | Плоскость с осями X (горизонтальная) и Y (вертикальная) |
| Начало координат (0; 0) | Центр окна |
| `goto(x, y)` / `setpos(x, y)` | Переход по прямой в точку (x; y) |
| `setx(x)` / `sety(y)` | Изменение только одной координаты |
| `home()` | Возврат в (0; 0), направление 0° |
| `setheading(a)` | Установка абсолютного направления (0 — вправо, 90 — вверх) |
| `position()`, `xcor()`, `ycor()` | Текущее положение черепашки |
| `write("текст")` | Вывод текста на экран |
| Декомпозиция | Разбиение сложной задачи на простые части |

## Примечание

- `goto` принимает и одну пару в виде кортежа: `t.goto((100, 50))` или `t.goto(t.position())`. Значение `position()` — объект `Vec2D`, с которым можно выполнять сложение и вычитание как с векторами.
- Координаты хранятся как дробные числа (`float`), поэтому после многих поворотов `xcor()` может вернуть `99.99999999999999` вместо `100`. Для сравнения используйте `round(t.xcor())`.
- `t.distance(x, y)` возвращает расстояние до точки, а `t.towards(x, y)` — угол, на который нужно встать (`setheading`), чтобы смотреть на эту точку.
- `turtle.setworldcoordinates(x1, y1, x2, y2)` задаёт собственную систему координат (например, начало в левом нижнем углу), но после неё углы на экране могут искажаться, если пропорции окна и координат разные.
- `turtle.tracer(0)` отключает анимацию, а `turtle.update()` выводит готовый рисунок сразу — это значительно ускоряет вывод больших рисунков.
