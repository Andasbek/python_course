## 1. Что такое перо?

«Перо» черепашки — это след, который она оставляет. У пера есть несколько **параметров (параметр, parameter)**:

| Параметр | Значение | Значение по умолчанию |
|---|---|---|
| Цвет | цвет линии | чёрный (`"black"`) |
| Толщина | ширина линии (в пикселях) | 1 |
| Состояние | опущено (рисует) или поднято (не рисует) | опущено |

> Аналогия: настоящий фломастер. У него есть цвет, кончик бывает тонким или толстым, и его можно оторвать от бумаги и перенести в другое место.

## 2. Цвет пера: pencolor

```python
import turtle

t = turtle.Turtle()
t.pencolor("red")      # красное перо
t.forward(100)
t.pencolor("blue")     # синее перо
t.forward(100)
turtle.done()
```

Результат: одна прямая линия, наполовину красная, наполовину синяя.

### Названия цветов

Цвета записываются **английскими** названиями в кавычках:

| Название | Цвет | Название | Цвет |
|---|---|---|---|
| `"red"` | красный | `"black"` | чёрный |
| `"green"` | зелёный | `"white"` | белый |
| `"blue"` | синий | `"gray"` | серый |
| `"yellow"` | жёлтый | `"orange"` | оранжевый |
| `"purple"` | фиолетовый | `"pink"` | розовый |
| `"brown"` | коричневый | `"gold"` | золотистый |
| `"skyblue"` | небесно-голубой | `"darkgreen"` | тёмно-зелёный |

### Коды цветов (HEX)

Любой цвет можно задать кодом вида `"#RRGGBB"`: RR — доля красного, GG — зелёного, BB — синего, каждая от 00 до FF (шестнадцатеричная система счисления).

```python
import turtle

t = turtle.Turtle()
t.pencolor("#00AFCA")   # голубой цвет флага Казахстана
t.pensize(5)
t.forward(150)
t.pencolor("#FEC50C")   # золотисто-жёлтый цвет
t.forward(150)
turtle.done()
```

| Код | Цвет |
|---|---|
| `"#FF0000"` | чистый красный |
| `"#00FF00"` | чистый зелёный |
| `"#0000FF"` | чистый синий |
| `"#000000"` | чёрный |
| `"#FFFFFF"` | белый |

## 3. Толщина пера: pensize

`t.pensize(n)` или её синоним `t.width(n)` — делает ширину линии равной `n` пикселям.

```python
import turtle

t = turtle.Turtle()
t.pensize(1)
t.forward(80)
t.pensize(5)
t.forward(80)
t.pensize(15)
t.forward(80)
turtle.done()
```

Результат: линия из трёх частей, которая постепенно становится толще.

## 4. Поднятие и опускание пера: penup, pendown

| Команда | Краткая форма | Что делает |
|---|---|---|
| `t.penup()` | `t.up()`, `t.pu()` | поднимает перо — черепашка движется, но следа не оставляет |
| `t.pendown()` | `t.down()`, `t.pd()` | опускает перо — снова рисует |

Эти команды пишутся **со скобками**, но внутри ничего не передаётся.

```python
import turtle

t = turtle.Turtle()
t.pensize(4)
t.forward(50)      # линия
t.penup()
t.forward(30)      # пустой промежуток
t.pendown()
t.forward(50)      # снова линия
t.penup()
t.forward(30)
t.pendown()
t.forward(50)
turtle.done()
```

Результат: пунктирная линия («— — —»), похожая на дорожную разметку.

### Рисуем две фигуры отдельно

```python
import turtle

t = turtle.Turtle()
# квадрат 1
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
# сдвиг вправо без следа
t.penup()
t.forward(100)
t.pendown()
# квадрат 2
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
turtle.done()
```

## 5. Закрашивание фигуры

Закрашивание внутренней части замкнутой фигуры состоит из четырёх шагов:

1. `t.fillcolor("цвет")` — выбрать цвет заливки;
2. `t.begin_fill()` — отметить «начинаю закрашивать отсюда»;
3. нарисовать фигуру;
4. `t.end_fill()` — фигура закончена, закрасить её внутреннюю часть.

```python
import turtle

t = turtle.Turtle()
t.pencolor("darkgreen")
t.pensize(3)
t.fillcolor("lightgreen")
t.begin_fill()
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.end_fill()
turtle.done()
```

Результат: треугольник с тёмно-зелёной обводкой и светло-зелёной заливкой.

### color — задать два цвета сразу

`t.color(цвет_обводки, цвет_заливки)` — задаёт `pencolor` и `fillcolor` в одной строке. Если указать только один цвет — оба будут этого цвета.

```python
import turtle

t = turtle.Turtle()
t.color("red", "yellow")   # обводка красная, заливка жёлтая
t.begin_fill()
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.end_fill()
turtle.done()
```

## 6. Дополнительные полезные команды

| Команда | Что делает |
|---|---|
| `t.circle(r)` | рисует окружность радиуса `r` (в сторону **левее** черепашки) |
| `t.circle(r, 180)` | полуокружность (дуга) |
| `t.dot(d, "цвет")` | полностью закрашенная точка диаметром `d` |
| `turtle.bgcolor("цвет")` | цвет фона окна |
| `t.hideturtle()` | спрятать черепашку (рисунок выглядит чище) |
| `t.showturtle()` | снова показать черепашку |

```python
import turtle

turtle.bgcolor("skyblue")
t = turtle.Turtle()
t.hideturtle()
t.speed(0)
# солнце
t.color("orange", "yellow")
t.begin_fill()
t.circle(50)
t.end_fill()
# точка
t.penup()
t.forward(150)
t.dot(30, "white")
turtle.done()
```

Результат: на голубом фоне жёлтое солнце и белая точка (начало облака).

> Запомните: `circle(r)` рисует окружность не **под** черепашкой, а **слева** от неё — черепашка стоит в нижней точке окружности, а центр находится в `r` пикселях левее (выше) неё.

## 7. Порядок алгоритма рисования

При рисовании цветного рисунка порядок команд очень важен:

1. **Сначала** настроить цвет и толщину.
2. Перевести черепашку в нужное место с поднятым пером.
3. Опустить перо, `begin_fill()`.
4. Нарисовать фигуру.
5. `end_fill()`, поднять перо.
6. Перейти к следующей фигуре.

## Частые ошибки

**1. Забыт `end_fill()`** — фигура не закрашивается.

```text
t.begin_fill()
t.circle(50)
# нет end_fill() — круг останется незакрашенным
```

```python
import turtle
t = turtle.Turtle()
t.fillcolor("pink")
t.begin_fill()
t.circle(50)
t.end_fill()       # правильно
turtle.done()
```

**2. Цвет написан без кавычек или по-русски.**

```text
t.pencolor(red)        # NameError: name 'red' is not defined
t.pencolor("красный")  # TurtleGraphicsError: bad color string
```

Правильно: `t.pencolor("red")`.

**3. Команда `penup` написана без скобок.**

```text
t.penup        # это не ошибка, но ничего не происходит — команда не вызвана!
```

Правильно: `t.penup()`. Команда без скобок **не выполняется**, и такую ошибку трудно найти.

**4. Фигура не замкнута.** Если последняя сторона не доходит до начальной точки, turtle закрашивает фигуру, соединяя начальную и конечную точки прямой, — форма получается неожиданной.

**5. Забыт `pendown()`** — после поднятия пера все следующие фигуры не видны.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| `pencolor("цвет")` | Цвет пера (линии) |
| `pensize(n)` / `width(n)` | Толщина линии |
| `penup()` / `pendown()` | Поднять / опустить перо |
| `fillcolor("цвет")` | Цвет заливки |
| `begin_fill()` / `end_fill()` | Начать заливку / закончить и закрасить внутреннюю часть фигуры |
| `color(a, b)` | Цвет обводки `a`, цвет заливки `b` |
| HEX-код | Код цвета вида `"#RRGGBB"` |
| `circle(r)` | Окружность радиуса `r` |
| `dot(d, "цвет")` | Закрашенная точка |
| `bgcolor("цвет")` | Цвет фона окна |
| `hideturtle()` | Спрятать черепашку |

## Примечание

- Кроме названий и HEX-кодов, цвет можно задать кортежем RGB: `t.pencolor((0.2, 0.6, 1.0))` — по умолчанию значения от 0 до 1. После `turtle.colormode(255)` можно писать привычные числа от 0 до 255: `t.pencolor(0, 175, 202)`.
- Список допустимых названий цветов берётся из Tk; полный список — в документации Tk (страница «colors»). Названия не зависят от регистра: `"Red"` и `"red"` — одно и то же.
- Вызов без аргументов возвращает текущее значение: `t.pencolor()`, `t.pensize()`, `t.isdown()` (True, если перо опущено) — удобно для проверки состояния.
- `circle(r)` с отрицательным радиусом рисует окружность **справа** от черепашки (по часовой стрелке), а `circle(r, steps=6)` рисует правильный шестиугольник, вписанный в окружность.
- Заливка самопересекающихся фигур (например, пятиконечной звезды) в разных операционных системах может выглядеть по-разному: центр звезды иногда остаётся незакрашенным.
- Документация: https://docs.python.org/3/library/turtle.html#color-control
