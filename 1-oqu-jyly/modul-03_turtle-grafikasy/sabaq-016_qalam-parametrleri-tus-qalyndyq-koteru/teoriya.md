## 1. Қалам деген не?

Тасбақаның «қаламы» — оның жүрген ізі. Қаламның бірнеше **параметрі (параметр, parameter)** бар:

| Параметр | Мағынасы | Әдепкі мәні |
|---|---|---|
| Түсі | сызықтың түсі | қара (`"black"`) |
| Қалыңдығы | сызықтың ені (пиксельмен) | 1 |
| Күйі | төмен (сызады) немесе жоғары (сызбайды) | төмен |

> Аналогия: шынайы фломастер. Оның түсі бар, ұшы жіңішке не жуан болады, және оны қағаздан көтеріп, басқа жерге апаруға болады.

## 2. Қаламның түсі: pencolor

```python
import turtle

t = turtle.Turtle()
t.pencolor("red")      # қызыл қалам
t.forward(100)
t.pencolor("blue")     # көк қалам
t.forward(100)
turtle.done()
```

Нәтижесі: бір түзу сызықтың жартысы қызыл, жартысы көк.

### Түс атаулары

Түстер **ағылшынша** атауымен, тырнақша ішінде жазылады:

| Атауы | Түс | Атауы | Түс |
|---|---|---|---|
| `"red"` | қызыл | `"black"` | қара |
| `"green"` | жасыл | `"white"` | ақ |
| `"blue"` | көк | `"gray"` | сұр |
| `"yellow"` | сары | `"orange"` | қызғылт сары |
| `"purple"` | күлгін | `"pink"` | қызғылт |
| `"brown"` | қоңыр | `"gold"` | алтын түсті |
| `"skyblue"` | аспан көк | `"darkgreen"` | қою жасыл |

### Түс кодтары (HEX)

Кез келген түсті `"#RRGGBB"` түріндегі кодпен беруге болады: RR — қызыл, GG — жасыл, BB — көк үлесі, әрқайсысы 00-ден FF-ке дейін (16-лық санау жүйесі).

```python
import turtle

t = turtle.Turtle()
t.pencolor("#00AFCA")   # Қазақстан туының көгілдір түсі
t.pensize(5)
t.forward(150)
t.pencolor("#FEC50C")   # алтын-сары түс
t.forward(150)
turtle.done()
```

| Код | Түс |
|---|---|
| `"#FF0000"` | таза қызыл |
| `"#00FF00"` | таза жасыл |
| `"#0000FF"` | таза көк |
| `"#000000"` | қара |
| `"#FFFFFF"` | ақ |

## 3. Қаламның қалыңдығы: pensize

`t.pensize(n)` немесе оның синонимі `t.width(n)` — сызықтың енін `n` пиксель етеді.

```python
import turtle

t = turtle.Turtle()
t.pensize(1)
t.forward(80)
t.pensize(5)
t.forward(80)
t.pensize(15)
t.forward(80)
turtle.done()
```

Нәтижесі: бірте-бірте жуандайтын үш бөліктен тұратын сызық.

## 4. Қаламды көтеру және түсіру: penup, pendown

| Команда | Қысқа түрі | Не істейді |
|---|---|---|
| `t.penup()` | `t.up()`, `t.pu()` | қаламды көтереді — тасбақа жүреді, бірақ із қалдырмайды |
| `t.pendown()` | `t.down()`, `t.pd()` | қаламды түсіреді — қайтадан сызады |

Бұл командалар **жақшамен** жазылады, бірақ ішіне ештеңе берілмейді.

```python
import turtle

t = turtle.Turtle()
t.pensize(4)
t.forward(50)      # сызық
t.penup()
t.forward(30)      # бос аралық
t.pendown()
t.forward(50)      # тағы сызық
t.penup()
t.forward(30)
t.pendown()
t.forward(50)
turtle.done()
```

Нәтижесі: үзік сызық («— — —»), жол белгісіне ұқсас.

### Екі фигураны бөлек салу

```python
import turtle

t = turtle.Turtle()
# 1-шаршы
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
# із қалдырмай оңға жылжу
t.penup()
t.forward(100)
t.pendown()
# 2-шаршы
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
t.forward(60)
t.left(90)
turtle.done()
```

## 5. Фигураны бояу

Тұйық фигураның ішін бояу төрт қадамнан тұрады:

1. `t.fillcolor("түс")` — бояу түсін таңдау;
2. `t.begin_fill()` — «бояуды осы жерден бастаймын» деп белгілеу;
3. фигураны салу;
4. `t.end_fill()` — фигура аяқталды, ішін бояу.

```python
import turtle

t = turtle.Turtle()
t.pencolor("darkgreen")
t.pensize(3)
t.fillcolor("lightgreen")
t.begin_fill()
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.end_fill()
turtle.done()
```

Нәтижесі: қою жасыл жиекті, іші ашық жасыл үшбұрыш.

### color — екі түсті бірден беру

`t.color(жиек_түсі, бояу_түсі)` — `pencolor` пен `fillcolor`-ды бір жолда береді. Бір ғана түс берсек — екеуі де сол түс болады.

```python
import turtle

t = turtle.Turtle()
t.color("red", "yellow")   # жиегі қызыл, іші сары
t.begin_fill()
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.end_fill()
turtle.done()
```

## 6. Қосымша пайдалы командалар

| Команда | Не істейді |
|---|---|
| `t.circle(r)` | радиусы `r` шеңбер салады (тасбақадан **солға** қарай) |
| `t.circle(r, 180)` | жарты шеңбер (доға) |
| `t.dot(d, "түс")` | диаметрі `d` толық боялған нүкте |
| `turtle.bgcolor("түс")` | терезенің фон түсі |
| `t.hideturtle()` | тасбақаны жасыру (сурет таза көрінеді) |
| `t.showturtle()` | тасбақаны қайта көрсету |

```python
import turtle

turtle.bgcolor("skyblue")
t = turtle.Turtle()
t.hideturtle()
t.speed(0)
# күн
t.color("orange", "yellow")
t.begin_fill()
t.circle(50)
t.end_fill()
# нүкте
t.penup()
t.forward(150)
t.dot(30, "white")
turtle.done()
```

Нәтижесі: көк фонда сары күн және ақ нүкте (бұлттың бастамасы).

> Есте сақтаңыз: `circle(r)` шеңберді тасбақаның **астынан** емес, **сол жағынан** бастап салады — тасбақа шеңбердің төменгі нүктесінде тұрады, ал центр одан `r` пиксель солда (жоғарыда) болады.

## 7. Сурет салу алгоритмінің реті

Түсті сурет салғанда командалар реті өте маңызды:

1. Түс пен қалыңдықты **алдымен** баптау.
2. Тасбақаны қалам көтеріліп тұрғанда керекті орынға апару.
3. Қаламды түсіру, `begin_fill()`.
4. Фигураны салу.
5. `end_fill()`, қаламды көтеру.
6. Келесі фигураға көшу.

## Жиі кездесетін қателер

**1. `end_fill()` ұмытылады** — фигура боялмайды.

```text
t.begin_fill()
t.circle(50)
# end_fill() жоқ — шеңбер боялмай қалады
```

```python
import turtle
t = turtle.Turtle()
t.fillcolor("pink")
t.begin_fill()
t.circle(50)
t.end_fill()       # дұрыс
turtle.done()
```

**2. Түсті тырнақшасыз немесе қазақша жазу.**

```text
t.pencolor(red)        # NameError: name 'red' is not defined
t.pencolor("қызыл")    # TurtleGraphicsError: bad color string
```

Дұрысы: `t.pencolor("red")`.

**3. `penup` командасын жақшасыз жазу.**

```text
t.penup        # қате емес, бірақ ештеңе болмайды — команда шақырылмады!
```

Дұрысы: `t.penup()`. Жақшасыз команда **орындалмайды**, бұл қатені табу қиын.

**4. Фигура тұйықталмаған.** Егер соңғы қабырға бастапқы нүктеге жетпесе, turtle бояуды бастапқы мен соңғы нүктені түзумен қосып жасайды — пішін күтпеген болып шығады.

**5. `pendown()` ұмытылады** — қалам көтерілген соң барлық келесі фигуралар көрінбейді.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| `pencolor("түс")` | Қаламның (сызықтың) түсі |
| `pensize(n)` / `width(n)` | Сызықтың қалыңдығы |
| `penup()` / `pendown()` | Қаламды көтеру / түсіру |
| `fillcolor("түс")` | Бояу түсі |
| `begin_fill()` / `end_fill()` | Бояуды бастау / аяқтап, фигураның ішін бояу |
| `color(a, b)` | Жиек түсі `a`, бояу түсі `b` |
| HEX-код | `"#RRGGBB"` түріндегі түс коды |
| `circle(r)` | Радиусы `r` шеңбер |
| `dot(d, "түс")` | Боялған нүкте |
| `bgcolor("түс")` | Терезе фонының түсі |
| `hideturtle()` | Тасбақаны жасыру |

## Ескерту

- Атау мен HEX-кодтан бөлек, түсті RGB кортежімен де беруге болады: `t.pencolor((0.2, 0.6, 1.0))` — әдепкіде мәндер 0-ден 1-ге дейін. `turtle.colormode(255)` командасынан кейін 0-ден 255-ке дейінгі таныс сандарды жазуға болады: `t.pencolor(0, 175, 202)`.
- Рұқсат етілген түс атауларының тізімі Tk кітапханасынан алынады; толық тізім Tk құжаттамасында («colors» беті). Атаулар регистрге тәуелді емес: `"Red"` пен `"red"` — бірдей.
- Аргументсіз шақыру ағымдағы мәнді қайтарады: `t.pencolor()`, `t.pensize()`, `t.isdown()` (қалам түсірулі болса True) — күйді тексеруге ыңғайлы.
- Теріс радиуспен `circle(r)` шеңберді тасбақаның **оң жағынан** (сағат тілімен) салады, ал `circle(r, steps=6)` шеңберге іштей сызылған дұрыс алтыбұрыш салады.
- Өзін-өзі қиып өтетін фигураларды (мысалы, бес бұрышты жұлдызды) бояу әр түрлі операциялық жүйеде әртүрлі көрінуі мүмкін: жұлдыздың ортасы кейде боялмай қалады.
- Құжаттама: https://docs.python.org/3/library/turtle.html#color-control
