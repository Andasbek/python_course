## 1. Что такое turtle?

**Turtle** (англ. «черепаха») — графический модуль, входящий в **стандартную библиотеку** Python. Он происходит от языка **Logo**, придуманного в 1960-х годах для обучения детей программированию. Тогда по полу ездил маленький робот-черепаха с карандашом и рисовал на бумаге.

Наша черепашка — маленький указатель (стрелка) на экране. Она:
- знает своё **положение** (в каком месте экрана находится);
- знает своё **направление** (куда смотрит);
- имеет **перо**: оставляет линию на пройденном пути.

> Аналогия: представьте художника с завязанными глазами. Он выполняет только ваши команды: «пройди 100 шагов вперёд», «повернись направо на 90 градусов». Если вы даёте правильные команды — получается красивый рисунок.

## 2. Понятие модуля и import

**Модуль (модуль, module)** — файл с набором готовых функций и команд. В Python тысячи модулей: `math` для математики, `random` для случайных чисел, `turtle` для графики. Чтобы использовать модуль, подключаем его в **начале** программы:

```python
import turtle
```

Теперь, написав `turtle.`, после точки можно вызвать команду модуля. Самая простая программа:

```python
import turtle

turtle.forward(100)   # 100 шагов вперёд
turtle.done()         # держать окно открытым
```

Результат: открывается новое окно, из его центра вправо рисуется линия длиной 100 пикселей.

`turtle.done()` (или `turtle.mainloop()`) — оставляет окно открытым после того, как рисунок закончен. Без неё в некоторых средах окно сразу закрывается. Её всегда пишем **в самой последней строке**.

### Сохранение черепашки в переменную

Часто удобно сохранить черепашку в отдельную переменную. `turtle.Turtle()` создаёт новую черепашку:

```python
import turtle

t = turtle.Turtle()   # t — наша черепашка
t.forward(100)
turtle.done()
```

Дальше мы будем писать именно так: `t.forward(...)` — коротко и понятно.

## 3. Экран и начальное состояние черепашки

Когда окно открывается, черепашка:
- стоит **точно в центре** экрана;
- смотрит **вправо (на восток)**;
- её перо **опущено** (то есть при движении остаётся линия).

```text
              вверх
                ↑
                |
 влево ←—————————➤—————————→ вправо
                |   (черепашка в центре, смотрит вправо)
                ↓
              вниз
```

Расстояние измеряется в **пикселях** (точках на экране). Обычное окно имеет ширину примерно 700–900 пикселей, поэтому 100–200 шагов — удобная длина.

## 4. Движение вперёд и назад: forward, back

| Команда | Краткая форма | Что делает |
|---|---|---|
| `t.forward(n)` | `t.fd(n)` | проходит `n` пикселей вперёд в направлении, куда смотрит |
| `t.back(n)` | `t.bk(n)`, `t.backward(n)` | отступает на `n` пикселей назад, не меняя направления |

```python
import turtle

t = turtle.Turtle()
t.forward(150)   # вправо на 150
t.back(50)       # назад на 50 — черепашка всё ещё смотрит вправо
turtle.done()
```

Результат: всего одна линия (длиной 150), потому что при движении назад черепашка вернулась по той же линии. В конце она стоит в 100 пикселях правее начальной точки.

> Важно: `back` **не поворачивает** черепашку! Она «пятится», и её нос остаётся в прежнем направлении.

## 5. Повороты: right, left

| Команда | Краткая форма | Что делает |
|---|---|---|
| `t.right(a)` | `t.rt(a)` | поворачивается по часовой стрелке (вправо) на `a` градусов |
| `t.left(a)` | `t.lt(a)` | поворачивается против часовой стрелки (влево) на `a` градусов |

При повороте черепашка **не сдвигается с места**, а только меняет направление.

### Вспомним углы

| Угол | Значение |
|---|---|
| 90° | прямой угол — «четверть оборота» |
| 180° | разворот — «посмотреть назад» |
| 360° | полный оборот — возврат в начальное направление |
| 45° | половина прямого угла — диагональ |

### Рисуем квадрат — первый линейный алгоритм

Алгоритм (словами):
1. Пройди вперёд 100. 2. Повернись влево на 90°. 3–8. Повтори это ещё три раза.

```python
import turtle

t = turtle.Turtle()
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)    # последний поворот возвращает черепашку в начальное направление
turtle.done()
```

Результат: квадрат со стороной 100 пикселей, черепашка в начальной точке, смотрит вправо.

Одна пара команд повторилась четыре раза. С помощью **цикла** (`for`) это можно записать в одну-две строки, но здесь используется линейный алгоритм: каждый шаг записан отдельно.

### Равносторонний треугольник — самый интересный угол

Внутренний угол равностороннего треугольника равен 60°. Но черепашка должна повернуться на **внешний угол**: 180° − 60° = **120°**.

```python
import turtle

t = turtle.Turtle()
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
turtle.done()
```

> Правило: при рисовании замкнутой фигуры черепашка за все повороты в сумме поворачивается на **360°**. В квадрате 4 × 90° = 360°, в треугольнике 3 × 120° = 360°. Значит, в правильном n-угольнике каждый поворот = 360 / n.

| Фигура | Число углов | Один поворот |
|---|---|---|
| Треугольник | 3 | 120° |
| Квадрат | 4 | 90° |
| Пятиугольник | 5 | 72° |
| Шестиугольник | 6 | 60° |

## 6. Внешний вид и скорость черепашки

```python
import turtle

t = turtle.Turtle()
t.shape("turtle")   # настоящая форма черепашки
t.speed(1)          # самая медленная — чтобы видеть каждый шаг
t.forward(100)
t.right(90)
t.forward(100)
turtle.done()
```

- Формы `shape(...)`: `"arrow"` (по умолчанию), `"turtle"`, `"circle"`, `"square"`, `"triangle"`, `"classic"`.
- `speed(...)`: 1 — самая медленная, 10 — быстрая, 0 — самая быстрая (без анимации).
- Изменить заголовок окна: `turtle.title("Моя черепашка")`.

## 7. Линейный алгоритм и блок-схема

Программа для черепашки — самый наглядный пример **линейного алгоритма**: команды выполняются сверху вниз, по одной, по порядку. Если поменять две команды местами — рисунок изменится:

```python
import turtle

t = turtle.Turtle()
# Вариант 1: сначала идёт, потом поворачивает
t.forward(100)
t.left(90)
t.forward(50)
turtle.done()
```

```python
import turtle

t = turtle.Turtle()
# Вариант 2: сначала поворачивает, потом идёт — рисунок другой!
t.left(90)
t.forward(100)
t.forward(50)
turtle.done()
```

Первый вариант рисует угол, похожий на букву «Г», второй — вертикальную линию, направленную вверх.

**Подсказка:** перед сложным рисунком нарисуйте его на бумаге и запишите каждый шаг с номером — это и будет готовый алгоритм.

## 8. turtle и input вместе

Функции `input()` и `int()` хорошо сочетаются с черепашкой:

```python
import turtle

a = int(input("Введите сторону квадрата: "))
t = turtle.Turtle()
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
turtle.done()
```

Например, если ввести 200, нарисуется большой квадрат, если 50 — маленький.

## Частые ошибки

**1. Сохранение файла под именем `turtle.py`.** Это самая опасная ошибка! По команде `import turtle` Python вместо стандартного модуля загрузит ваш файл.

```text
AttributeError: partially initialized module 'turtle' has no attribute 'Turtle'
```

Решение: сохраните файл под другим именем, например `tasbaqa.py`, `sabaq15.py`, и удалите файл `turtle.py` из папки.

**2. Забыта заглавная буква.**

```text
t = turtle.turtle()     # ошибка: имя класса пишется с заглавной буквы
```

```python
import turtle
t = turtle.Turtle()     # правильно
```

**3. Не указано число в скобках или указан текст.**

```text
t.forward()          # TypeError: число не передано
t.forward("100")     # ошибка: число пишется без кавычек
```

```python
import turtle
t = turtle.Turtle()
t.forward(100)       # правильно
turtle.done()
```

**4. Команды после строки `turtle.done()`.** Команды после `done()` не выполняются. Это всегда последняя строка.

**5. Путаница с углами.** Если для треугольника написать `left(60)` — фигура не замкнётся. Вычислите внешний угол: 180 − 60 = 120.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Модуль (module) | Файл Python с набором готовых команд |
| `import` | Ключевое слово для подключения модуля к программе |
| Черепашка (turtle) | Указатель, который движется по экрану и оставляет след |
| Пиксель | Самая маленькая точка на экране, единица измерения расстояния |
| `forward(n)` / `fd(n)` | Пройти `n` пикселей вперёд |
| `back(n)` / `bk(n)` | Пройти `n` пикселей назад (направление не меняется) |
| `right(a)` / `rt(a)` | Повернуть вправо на `a` градусов |
| `left(a)` / `lt(a)` | Повернуть влево на `a` градусов |
| Внешний угол | Угол поворота черепашки = 180° − внутренний угол |
| `turtle.done()` | Держит окно открытым, последняя строка программы |

## Примечание

- Модуль `turtle` построен на библиотеке **Tkinter**. В некоторых сборках Python для Linux её нужно установить отдельно (например, пакет `python3-tk`); в онлайн-редакторах без графического окна turtle может не работать.
- У каждой команды есть «модульная» форма (`turtle.forward(100)`) и «объектная» (`t.forward(100)`). Обе управляют черепашкой, но объектная форма позволяет создать несколько черепашек и считается более понятной.
- Углы в turtle по умолчанию задаются в **градусах**. Команда `turtle.radians()` переключает на радианы, `turtle.degrees()` — обратно.
- Отрицательные значения тоже работают: `t.forward(-50)` то же, что `t.back(50)`, а `t.left(-90)` то же, что `t.right(90)`.
- Если окно «зависло» или не закрывается в IDLE, запустите программу заново или используйте `turtle.exitonclick()` — окно закроется по щелчку мыши.
- Полная документация модуля: https://docs.python.org/3/library/turtle.html
