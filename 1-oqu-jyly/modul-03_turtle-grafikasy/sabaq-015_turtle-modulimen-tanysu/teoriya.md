## 1. turtle деген не?

**Turtle** (ағылш. «тасбақа») — Python-ның **стандартты кітапханасына** кіретін графикалық модуль. Ол 1960 жылдары балаларды бағдарламалауға үйрету үшін ойлап табылған **Logo** тілінен шыққан. Сол кезде еденде қаламы бар кішкентай робот-тасбақа жүріп, қағазға сурет салған.

Біздің тасбақа — экрандағы кішкентай нұсқар (стрелка). Ол:
- **орнын** біледі (экранның қай жерінде тұр);
- **бағытын** біледі (қайда қарап тұр);
- **қаламы** бар: жүрген жолында сызық қалдырады.

> Аналогия: көзі байланған суретшіні елестетіңіз. Ол тек сіздің командаңызды орындайды: «100 қадам алға жүр», «90 градусқа оңға бұрыл». Сіз дұрыс команда берсеңіз — әдемі сурет шығады.

## 2. Модуль ұғымы және import

**Модуль (модуль, module)** — дайын функциялар мен командалар жинағы бар файл. Python-да мыңдаған модуль бар: математикаға `math`, кездейсоқ сандарға `random`, графикаға `turtle`. Модульді қолдану үшін оны бағдарламаның **басында** қосамыз:

```python
import turtle
```

Енді `turtle.` деп жазып, нүктеден кейін модульдің командасын шақыра аламыз. Ең қарапайым бағдарлама:

```python
import turtle

turtle.forward(100)   # 100 қадам алға
turtle.done()         # терезені жаппай ұстап тұру
```

Нәтижесі: жаңа терезе ашылады, ортасынан оңға қарай 100 пиксель ұзындықтағы сызық сызылады.

`turtle.done()` (немесе `turtle.mainloop()`) — суретті салып болғаннан кейін терезені ашық қалдырады. Онсыз кейбір орталарда терезе бірден жабылып қалады. Оны әрқашан **ең соңғы жолға** жазамыз.

### Тасбақаны айнымалыға сақтау

Көп жағдайда тасбақаны жеке айнымалыға сақтау ыңғайлы. `turtle.Turtle()` жаңа тасбақа жасайды:

```python
import turtle

t = turtle.Turtle()   # t — біздің тасбақамыз
t.forward(100)
turtle.done()
```

Бұдан былай біз осы жолмен жазамыз: `t.forward(...)` қысқа әрі түсінікті.

## 3. Экран мен тасбақаның бастапқы күйі

Терезе ашылғанда тасбақа:
- экранның **дәл ортасында** тұрады;
- **оңға (шығысқа)** қарап тұрады;
- қаламы **төмен түсірілген** (яғни жүрсе, сызық қалады).

```text
              жоғары
                ↑
                |
  сол ←—————————➤—————————→ оң
                |   (тасбақа ортада, оңға қарап тұр)
                ↓
              төмен
```

Қашықтық **пиксельмен** (экрандағы нүктелер) өлшенеді. Әдеттегі терезенің ені шамамен 700–900 пиксель, сондықтан 100–200 қадам — ыңғайлы ұзындық.

## 4. Алға және артқа жүру: forward, back

| Команда | Қысқа түрі | Не істейді |
|---|---|---|
| `t.forward(n)` | `t.fd(n)` | қарап тұрған бағытқа қарай `n` пиксель алға жүреді |
| `t.back(n)` | `t.bk(n)`, `t.backward(n)` | бағытын өзгертпей, `n` пиксель артқа шегінеді |

```python
import turtle

t = turtle.Turtle()
t.forward(150)   # оңға 150
t.back(50)       # артқа 50 — тасбақа әлі де оңға қарап тұр
turtle.done()
```

Нәтижесі: бір ғана сызық (ұзындығы 150), өйткені артқа жүргенде тасбақа сол сызықтың үстімен қайтты. Соңында ол басталған нүктеден 100 пиксель оңда тұр.

> Маңызды: `back` тасбақаны **бұрмайды**! Ол «шегіншектеп» жүреді, тұмсығы бұрынғы бағытта қалады.

## 5. Бұрылу: right, left

| Команда | Қысқа түрі | Не істейді |
|---|---|---|
| `t.right(a)` | `t.rt(a)` | сағат тілімен (оңға) `a` градусқа бұрылады |
| `t.left(a)` | `t.lt(a)` | сағат тіліне қарсы (солға) `a` градусқа бұрылады |

Бұрылу кезінде тасбақа **орнынан қозғалмайды**, тек бағытын өзгертеді.

### Бұрыштарды еске түсірейік

| Бұрыш | Мағынасы |
|---|---|
| 90° | тік бұрыш — «ширек айналым» |
| 180° | кері бұрылу — «артқа қарау» |
| 360° | толық айналым — бастапқы бағытқа оралу |
| 45° | тік бұрыштың жартысы — диагональ |

### Шаршы салу — алғашқы сызықтық алгоритм

Алгоритм (сөзбен):
1. 100 алға жүр. 2. Солға 90° бұрыл. 3–8. Осыны тағы үш рет қайтала.

```python
import turtle

t = turtle.Turtle()
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)    # соңғы бұрылыс — тасбақаны бастапқы бағытына қайтарады
turtle.done()
```

Нәтижесі: қабырғасы 100 пиксель болатын шаршы, тасбақа бастапқы нүктеде, оңға қарап тұр.

Бір жұп команда төрт рет қайталанды. **Цикл** (`for`) арқылы мұны бір-екі жолмен жазуға болады, бірақ мұнда сызықтық алгоритм қолданылған: әр қадам жеке жазылған.

### Тең қабырғалы үшбұрыш — ең қызық бұрыш

Тең қабырғалы үшбұрыштың ішкі бұрышы 60°. Бірақ тасбақа **сыртқы бұрышқа** бұрылуы керек: 180° − 60° = **120°**.

```python
import turtle

t = turtle.Turtle()
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
t.forward(120)
t.left(120)
turtle.done()
```

> Ереже: тұйық фигураны салғанда тасбақа барлық бұрылыстарда қосындысы **360°** бұрылады. Шаршыда 4 × 90° = 360°, үшбұрышта 3 × 120° = 360°. Демек, дұрыс n-бұрышта әр бұрылыс = 360 / n.

| Фигура | Бұрыштар саны | Бір бұрылыс |
|---|---|---|
| Үшбұрыш | 3 | 120° |
| Шаршы | 4 | 90° |
| Бесбұрыш | 5 | 72° |
| Алтыбұрыш | 6 | 60° |

## 6. Тасбақаның сыртқы түрі және жылдамдығы

```python
import turtle

t = turtle.Turtle()
t.shape("turtle")   # нағыз тасбақа пішіні
t.speed(1)          # ең баяу — әр қадамды көру үшін
t.forward(100)
t.right(90)
t.forward(100)
turtle.done()
```

- `shape(...)` пішіндері: `"arrow"` (әдепкі), `"turtle"`, `"circle"`, `"square"`, `"triangle"`, `"classic"`.
- `speed(...)`: 1 — ең баяу, 10 — жылдам, 0 — ең жылдам (анимациясыз).
- Терезе тақырыбын өзгерту: `turtle.title("Менің тасбақам")`.

## 7. Сызықтық алгоритм және блок-схема

Тасбақаға арналған бағдарлама — **сызықтық алгоритмнің** ең көрнекі мысалы: командалар жоғарыдан төмен, бір-бірден, ретімен орындалады. Егер екі команданың орнын ауыстырсақ — сурет өзгереді:

```python
import turtle

t = turtle.Turtle()
# 1-нұсқа: алдымен жүріп, сосын бұрылады
t.forward(100)
t.left(90)
t.forward(50)
turtle.done()
```

```python
import turtle

t = turtle.Turtle()
# 2-нұсқа: алдымен бұрылып, сосын жүреді — сурет басқаша!
t.left(90)
t.forward(100)
t.forward(50)
turtle.done()
```

Бірінші нұсқа «Г» әрпіне ұқсас бұрыш салады, екіншісі — жоғары қараған тік сызық.

**Кеңес:** күрделі сурет алдында қағазға салып, әр қадамды нөмірлеп жазыңыз — бұл дайын алгоритм болады.

## 8. turtle және input бірге

`input()` пен `int()` функциялары тасбақамен жақсы үйлеседі:

```python
import turtle

a = int(input("Шаршының қабырғасын енгізіңіз: "))
t = turtle.Turtle()
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
t.forward(a)
t.left(90)
turtle.done()
```

Мысалы 200 енгізсек, үлкен шаршы, 50 енгізсек — кішкентай шаршы салынады.

## Жиі кездесетін қателер

**1. Файлды `turtle.py` деп сақтау.** Бұл ең қауіпті қате! Python `import turtle` дегенде стандартты модульдің орнына сіздің файлыңызды жүктейді.

```text
AttributeError: partially initialized module 'turtle' has no attribute 'Turtle'
```

Шешімі: файлды `tasbaqa.py`, `sabaq15.py` сияқты басқа атпен сақтаңыз және папкадағы `turtle.py` файлын жойыңыз.

**2. Бас әріп ұмытылады.**

```text
t = turtle.turtle()     # қате: класс атауы бас әріппен
```

```python
import turtle
t = turtle.Turtle()     # дұрыс
```

**3. Жақша ішіне сан жазбау немесе мәтін жазу.**

```text
t.forward()          # TypeError: сан берілмеген
t.forward("100")     # қате: сан тырнақшасыз жазылады
```

```python
import turtle
t = turtle.Turtle()
t.forward(100)       # дұрыс
turtle.done()
```

**4. `turtle.done()` жолынан кейін команда жазу.** `done()`-нан кейінгі командалар орындалмайды. Ол әрқашан соңғы жол.

**5. Бұрышты шатастыру.** Үшбұрыш салу үшін `left(60)` жазу — фигура тұйықталмайды. Сыртқы бұрышты есептеңіз: 180 − 60 = 120.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Модуль (module) | Дайын командалар жинағы бар Python файлы |
| `import` | Модульді бағдарламаға қосу кілт сөзі |
| Тасбақа (turtle) | Экранда жүріп, із қалдыратын нұсқар |
| Пиксель | Экрандағы ең кіші нүкте, қашықтық өлшемі |
| `forward(n)` / `fd(n)` | `n` пиксель алға жүру |
| `back(n)` / `bk(n)` | `n` пиксель артқа жүру (бағыт өзгермейді) |
| `right(a)` / `rt(a)` | `a` градусқа оңға бұрылу |
| `left(a)` / `lt(a)` | `a` градусқа солға бұрылу |
| Сыртқы бұрыш | Тасбақа бұрылатын бұрыш = 180° − ішкі бұрыш |
| `turtle.done()` | Терезені ашық ұстау, бағдарламаның соңғы жолы |

## Ескерту

- `turtle` модулі **Tkinter** кітапханасына негізделген. Linux-тағы кейбір Python жинақтарында оны бөлек орнату керек (мысалы, `python3-tk` пакеті); графикалық терезесі жоқ онлайн-редакторларда turtle жұмыс істемеуі мүмкін.
- Әр команданың «модульдік» түрі (`turtle.forward(100)`) және «объектілік» түрі (`t.forward(100)`) бар. Екеуі де тасбақаны басқарады, бірақ объектілік түр бірнеше тасбақа жасауға мүмкіндік береді және түсініктірек саналады.
- turtle-да бұрыштар әдепкіде **градуспен** беріледі. `turtle.radians()` командасы радианға ауыстырады, `turtle.degrees()` — қайтадан градусқа.
- Теріс мәндер де жұмыс істейді: `t.forward(-50)` — `t.back(50)` дегенмен бірдей, ал `t.left(-90)` — `t.right(90)` дегенмен бірдей.
- Егер терезе IDLE-де «қатып» қалса немесе жабылмаса, бағдарламаны қайта іске қосыңыз немесе `turtle.exitonclick()` қолданыңыз — терезе тышқанмен шерткенде жабылады.
- Модульдің толық құжаттамасы: https://docs.python.org/3/library/turtle.html
