## Кеңейтілген деңгей

**5-тапсырма. Дұрыс енгізгенше.** `read_int(prompt, low, high)` функциясын жаз: ол пайдаланушыдан бүтін сан сұрайды, сан емес немесе `[low; high]` аралығынан тыс болса қайта сұрайды, дұрыс санды `return` арқылы қайтарады. Функцияны қолданып, оқушының бойын (100–220 см) және салмағын (20–150 кг) сұрап, дене салмағы индексін (ДСИ = салмақ / (бой/100)²) екі ондық белгімен шығар.

**6-тапсырма. Логикалық қатені тап.** Төмендегі бағдарлама 1-ден n-ге дейінгі жұп сандардың қосындысын табуы керек, бірақ қате нәтиже береді. Аралық `print` немесе Thonny жөндеуішін қолданып, қатені тап және түзет.

```python
n = 10
total = 0
for i in range(1, n):
    if i % 2 == 1:
        total += i
print("Жұп сандар қосындысы:", total)
```

Күтілетін нәтиже: `Жұп сандар қосындысы: 30`.

## ★ Олимпиадалық / шығармашылық тапсырма

**8-тапсырма. Қате статистикасы.** `data = ["12", "7", "он", "0", "-3", "4.5", "", "100"]` тізімі берілген. Әр элементті бүтін санға айналдырып, 1000-ды осы санға бөл. Нәтижесінде: сәтті бөлулер тізімін, `ValueError` санын және `ZeroDivisionError` санын шығар. Қатенің түрін сөздікке санап жина (`{"ValueError": 3, ...}`). Кеңес: `except (ValueError, ZeroDivisionError) as e:` және `type(e).__name__`.

- а) синтаксистік – жақша жабылмаған: `print("Сәлем, әлем!")`;

**5-тапсырма.**

```python
def read_int(prompt, low, high):
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("Бүтін сан енгіз.")
            continue
        if low <= value <= high:
            return value
        print(f"Мән {low} мен {high} аралығында болуы керек.")

height = read_int("Бойың (см): ", 100, 220)
weight = read_int("Салмағың (кг): ", 20, 150)
bmi = weight / (height / 100) ** 2
print(f"ДСИ: {bmi:.2f}")
```

**7-тапсырма.**

```python
while True:
    line = input("Өрнек: ")
    if line == "стоп":
        print("Сау бол!")
        break
    parts = line.split()
    if len(parts) != 3:
        print("Пішім: сан амал сан (мысалы 12 / 4)")
        continue
    try:
        a = float(parts[0])
        b = float(parts[2])
    except ValueError:
        print("Қате: сандарды дұрыс жаз.")
        continue
    op = parts[1]
    try:
        if op == "+":
            print("=", a + b)
        elif op == "-":
            print("=", a - b)
        elif op == "*":
            print("=", a * b)
        elif op == "/":
            print("=", a / b)
        else:
            print("Белгісіз амал:", op)
    except ZeroDivisionError:
        print("Нөлге бөлуге болмайды!")
```

**8-тапсырма.**

```python
data = ["12", "7", "он", "0", "-3", "4.5", "", "100"]
results = []
errors = {}
for item in data:
    try:
        results.append(round(1000 / int(item), 2))
    except (ValueError, ZeroDivisionError) as e:
        name = type(e).__name__
        errors[name] = errors.get(name, 0) + 1
print("Сәтті:", results)
print("Қателер:", errors)
```
