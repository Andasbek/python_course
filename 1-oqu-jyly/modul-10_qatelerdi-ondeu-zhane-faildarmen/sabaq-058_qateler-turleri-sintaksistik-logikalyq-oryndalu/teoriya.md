## 1. Қате деген не және ол қайдан шығады?

Бағдарламашылар қатені **баг** (bug – «қоңыз») деп атайды. Ал қатені іздеп, түзету процесі **жөндеу** (отладка, debugging) деп аталады. Ең тәжірибелі бағдарламашы да қателеседі – маңыздысы, қатені тез тауып, түзете білу.

Python-дағы қателерді үш үлкен топқа бөлеміз:

| Қате түрі | Қашан білінеді? | Python хабарлай ма? | Мысал |
|---|---|---|---|
| Синтаксистік (syntax error) | Бағдарлама іске қосылмай тұрып | Иә, `SyntaxError` | Қос нүкте ұмытылған |
| Орындалу кезіндегі (runtime error, exception) | Бағдарлама жұмыс істеп жатқанда | Иә, `ValueError`, `ZeroDivisionError` т.б. | Нөлге бөлу |
| Логикалық (logic error) | Бағдарлама «жұмыс істейді», бірақ жауап қате | Жоқ! | `+` орнына `-` жазылған |

**Аналогия.** Бағдарламаны ас үйдегі рецепт деп елестет:
- *синтаксистік қате* – рецепт сауатсыз жазылған, аспаз оны оқи алмайды («тұз 2 қасық ыдысқа сал ;;;»);
- *орындалу қатесі* – рецепт дұрыс, бірақ тоңазытқышта жұмыртқа жоқ болып шықты – жұмыс ортасында тоқтадық;
- *логикалық қате* – рецепт оқылды, тағам дайын, бірақ қант орнына тұз салынған – нәтиже «дұрыс емес».

## 2. Синтаксистік қателер

Синтаксис – тілдің жазылу ережелері. Ереже бұзылса, Python бағдарламаның **бірде-бір жолын орындамайды**.

Қатесі бар код (бұл код әдейі іске қосылмайды):

```text
age = 15
if age > 10
    print("Сен үйірмеге қабылдандың!")
```

Нәтижесі:
```text
  File "main.py", line 2
    if age > 10
               ^
SyntaxError: expected ':'
```

Жиі кездесетін синтаксистік қателер:
- `if`, `for`, `while`, `def`, `else` соңындағы `:` ұмытылуы;
- жақшалар мен тырнақшалардың жабылмауы: `print("Сәлем)`;
- шегіністің (отступ) дұрыс болмауы – `IndentationError`;
- `=` (меншіктеу) мен `==` (салыстыру) шатастыру: `if x = 5:`;
- кілт сөзді айнымалы атауы ретінде қолдану: `for = 3`.

Дұрыс код:

```python
age = 15
if age > 10:
    print("Сен үйірмеге қабылдандың!")
```

Нәтижесі:
```text
Сен үйірмеге қабылдандың!
```

> **Кеңес.** Python көрсеткен жолды ғана емес, оның **алдындағы** жолды да тексер: жабылмаған жақша көбіне бір жол бұрын қалып қояды.

## 3. Орындалу кезіндегі қателер (ерекше жағдайлар)

Синтаксис дұрыс, бағдарлама іске қосылды, бірақ қандай да бір жолда орындау мүмкін болмай қалды. Мұндай жағдайды Python **ерекше жағдай** (исключение, exception) деп атайды.

```python
a = 10
b = 0
print("Бөлуді бастаймыз...")
print(a / b)
print("Бұл жол ешқашан шықпайды")
```

Нәтижесі:
```text
Бөлуді бастаймыз...
Traceback (most recent call last):
  File "main.py", line 4, in <module>
    print(a / b)
ZeroDivisionError: division by zero
```

Байқа: бірінші `print` орындалды, ал қате болған жерде бағдарлама **тоқтап қалды**.

### Traceback-ті қалай оқу керек?

Қате хабарламасын **төменнен жоғары** қарай оқы:
1. Ең соңғы жол – **қатенің түрі** (`ZeroDivisionError`) және **сипаттамасы** (`division by zero`).
2. Оның үстінде – қате болған **код жолы** (`print(a / b)`).
3. Тағы жоғарыда – **файл аты мен жол нөмірі** (`line 4`).

### Жиі кездесетін ерекше жағдайлар

| Ерекше жағдай | Қашан туады | Мысал |
|---|---|---|
| `ValueError` | Мән типке сәйкес келмейді | `int("он")` |
| `ZeroDivisionError` | Нөлге бөлу | `5 / 0`, `5 % 0` |
| `TypeError` | Сәйкес емес типтермен амал | `"5" + 3` |
| `NameError` | Жарияланбаған айнымалы | `print(sco)` |
| `IndexError` | Тізімде жоқ индекс | `[1, 2][5]` |
| `KeyError` | Сөздікте жоқ кілт | `{"a": 1}["b"]` |
| `AttributeError` | Объектіде мұндай әдіс жоқ | `[1, 2].upper()` |
| `FileNotFoundError` | Файл табылмады | `open("жоқ.txt")` |

```python
cities = ["Алматы", "Астана", "Шымкент"]
print(cities[3])
```

Нәтижесі:
```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(cities[3])
IndexError: list index out of range
```

## 4. Логикалық қателер

Ең «қулық» қате – бағдарлама еш хабарламасыз жұмыс істейді, бірақ **нәтиже қате**. Мұны Python таба алмайды, тек сен – тестілеу арқылы.

Мысал: үш бағаның орташасы.

```python
a, b, c = 5, 4, 3
average = a + b + c / 3   # логикалық қате!
print("Орташа баға:", average)
```

Нәтижесі:
```text
Орташа баға: 10.0
```

Орташа баға 10 бола алмайды! Себебі амалдар реті: алдымен `c / 3`, содан кейін қосу. Дұрысы:

```python
a, b, c = 5, 4, 3
average = (a + b + c) / 3
print("Орташа баға:", average)
```

Нәтижесі:
```text
Орташа баға: 4.0
```

Логикалық қатені табу тәсілдері:
- **Қолмен есептелген жауаппен салыстыру** – бағдарламаға жауабы белгілі деректерді беру.
- **Аралық `print`** – айнымалылардың мәнін қадам сайын шығару.
- **Шекаралық мәндерді тексеру** – 0, теріс сан, бос тізім, ең үлкен мән.
- **Thonny-дегі жөндеуіш (Debugger)** – кодты жолма-жол орындап, айнымалыларды бақылау (🐞 батырмасы, F7 – келесі қадам).

```python
# Аралық print арқылы циклді тексеру
total = 0
for i in range(1, 5):
    total = total + i
    print("i =", i, "total =", total)   # тексеру үшін уақытша жол
print("1-ден 4-ке дейінгі қосынды:", total)
```

Нәтижесі:
```text
i = 1 total = 1
i = 2 total = 3
i = 3 total = 6
i = 4 total = 10
1-ден 4-ке дейінгі қосынды: 10
```

## 5. try...except конструкциясы

Орындалу қатесін алдын ала «ұстап алып», бағдарламаның құламауын қамтамасыз етуге болады.

```text
try:
    # қате шығуы мүмкін код
except ҚатеТүрі:
    # қате шықса, орындалатын код
```

**Аналогия.** Акробат арқанмен жүргенде астында **қорғаныш торы** тұрады. `try` – арқанмен жүру, `except` – тор. Құласа – тор ұстап алады, қойылым жалғаса береді.

```python
try:
    age = int(input("Жасыңды енгіз: "))
    print("Келесі жылы сен", age + 1, "жаста боласың")
except ValueError:
    print("Қате! Жасты цифрмен жазу керек.")
print("Бағдарлама аяқталды.")
```

Нәтижесі (енгізу `он бес`):
```text
Жасыңды енгіз: он бес
Қате! Жасты цифрмен жазу керек.
Бағдарлама аяқталды.
```

Жұмыс реті:
1. `try` ішіндегі код орындалады.
2. Қате болмаса – `except` блогы **өткізіліп жіберіледі**.
3. Қате болса – `try` ішіндегі қалған жолдар орындалмайды, бірден сәйкес `except` блогына өтеді.
4. Одан кейін бағдарлама әрі қарай жұмысын жалғастырады.

### Бірнеше except блогы

```python
try:
    a = int(input("Бірінші сан: "))
    b = int(input("Екінші сан: "))
    print("Бөлінді:", a / b)
except ValueError:
    print("Сан енгізу керек еді!")
except ZeroDivisionError:
    print("Нөлге бөлуге болмайды!")
```

Нәтижесі (енгізу `12` және `0`):
```text
Бірінші сан: 12
Екінші сан: 0
Нөлге бөлуге болмайды!
```

### Қате туралы мәлімет алу: `as`

```python
try:
    number = int("12а")
except ValueError as e:
    print("Қате шықты:", e)
```

Нәтижесі:
```text
Қате шықты: invalid literal for int() with base 10: '12а'
```

### else және finally

- `else` – қате **болмаған** жағдайда орындалады;
- `finally` – қате болса да, болмаса да **әрқашан** орындалады (мысалы, файлды жабу немесе ресурсты босату үшін).

```python
try:
    price = float(input("Тауар бағасы (теңге): "))
except ValueError:
    print("Баға сан болуы керек.")
else:
    print("ҚҚС-пен баға:", round(price * 1.12, 2), "теңге")
finally:
    print("Есептеу аяқталды.")
```

Нәтижесі (енгізу `1000`):
```text
Тауар бағасы (теңге): 1000
ҚҚС-пен баға: 1120.0 теңге
Есептеу аяқталды.
```

### Дұрыс енгізгенше сұрау (while + try)

Ең пайдалы үлгі – пайдаланушы дұрыс мән енгізгенше қайталап сұрау:

```python
while True:
    try:
        grade = int(input("Бағаңды енгіз (1-5): "))
        if 1 <= grade <= 5:
            break
        print("Баға 1 мен 5 аралығында болуы керек.")
    except ValueError:
        print("Бұл сан емес, қайтадан көр.")
print("Сенің бағаң:", grade)
```

Нәтижесі:
```text
Бағаңды енгіз (1-5): бес
Бұл сан емес, қайтадан көр.
Бағаңды енгіз (1-5): 7
Баға 1 мен 5 аралығында болуы керек.
Бағаңды енгіз (1-5): 5
Сенің бағаң: 5
```

### Функция ішінде try...except

Қатені өңдеуді функция ішіне жасыруға ыңғайлы – «қауіпсіз» функция шығады:

```python
def safe_int(text, default=0):
    """Жолды санға айналдырады, болмаса default қайтарады."""
    try:
        return int(text)
    except ValueError:
        return default

print(safe_int("25"))
print(safe_int("жиырма"))
print(safe_int("", -1))
```

Нәтижесі:
```text
25
0
-1
```

> **Ереже.** `except:` деп (түрін көрсетпей) жазу жаман әдет: ол **барлық** қатені, тіпті өзіңнің логикалық қателеріңді де жасырып қалады. Әрқашан нақты қате түрін жаз.

## Жиі кездесетін қателер

**1. Қате түрін дұрыс көрсетпеу.**

```python
try:
    x = int("abc")
except ZeroDivisionError:      # ValueError болуы керек еді
    print("Қате")
```

Бұл код `ValueError`-ды ұстамайды – бағдарлама бәрібір құлайды. Дұрысы:

```python
try:
    x = int("abc")
except ValueError:
    print("Сан емес мәтін енгізілді")
```

**2. try ішіне тым көп код салу.** Қате қай жерде болғаны түсініксіз болады. `try` ішінде тек қате шығуы мүмкін жолдарды қалдыр, қалғанын `else`-ге шығар.

**3. Синтаксистік қатені try арқылы ұстауға тырысу.** Синтаксистік қате бар файл мүлдем іске қосылмайды, сондықтан `try` көмектеспейді – оны жай ғана түзету керек.

**4. except ішінде ештеңе істемеу.**

```python
try:
    n = int(input("Сан: "))
except ValueError:
    pass   # жаман: пайдаланушы не болғанын білмейді
```

Пайдаланушыға әрқашан түсінікті хабарлама бер.

**5. Шартпен тексерілетін нәрсені try-ға жүктеу.** Мысалы, сөздікте кілт бар-жоғын `if key in d:` арқылы тексеру оңайырақ әрі түсініктірек.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Баг (bug) | Бағдарламадағы қате |
| Жөндеу (отладка, debugging) | Қатені іздеп табу және түзету |
| Синтаксистік қате | Тіл ережесінің бұзылуы, бағдарлама іске қосылмайды |
| Орындалу қатесі / ерекше жағдай (exception) | Жұмыс барысында туған қате, бағдарлама тоқтайды |
| Логикалық қате | Бағдарлама жұмыс істейді, бірақ нәтиже қате |
| Traceback | Қатенің орны мен түрі туралы Python хабарламасы |
| `try` | Қате шығуы мүмкін код блогы |
| `except` | Қатені ұстап, өңдейтін блок |
| `else` | Қате болмағанда орындалатын блок |
| `finally` | Әрқашан орындалатын блок |

## Ескерту

- Синтаксистік қатені `try` ұстай алмайды: мұндай файл толығымен компиляцияланбайды. Ерекшелік – `eval()`/`exec()` арқылы орындалатын код немесе импортталатын модуль.
- Python 3.10–3.12 нұсқаларынан бастап қате хабарламалары толығырақ болды: `SyntaxError: expected ':'`, `NameError` пен `AttributeError` үшін `Did you mean: 'score'?` түріндегі кеңестер. Ескі нұсқаларда хабарлама мәтіні басқаша.
- Барлық стандартты ерекше жағдайлар иерархия құрайды: мысалы, `ZeroDivisionError` – `ArithmeticError`-дың ұрпағы, ал барлығы дерлік `Exception`-ның ұрпақтары. `except` реті маңызды: бірінші жазылған жалпы түр нақтырақ түрлерді де «ұстап алады».
- Бірнеше түрді бір блокпен ұстауға болады: `except (ValueError, TypeError):`.
- Ерекше жағдайды өзің `raise ValueError("хабарлама")` операторымен тудыра аласың – бұл функция аргументтерін тексергенде пайдалы.
- Құжаттама: [Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html) және [Built-in Exceptions](https://docs.python.org/3/library/exceptions.html).
