**Задание 1.**
- а) синтаксическая – не закрыта скобка: `print("Привет, мир!")`;
- б) выполнения, `IndexError` – индекс последнего элемента 2: `print(numbers[2])` или `numbers[-1]`;
- в) логическая – периметр `4 * side` (= 20);
- г) выполнения, `TypeError` – `"Мне лет: " + str(12)` или f-строка;
- д) синтаксическая – нет `:`: `for i in range(5):`;
- е) выполнения, `KeyError` – ключа нет; `scores.get("Айбек", "нет")`.

**Задание 5.**

```python
def read_int(prompt, low, high):
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("Введи целое число.")
            continue
        if low <= value <= high:
            return value
        print(f"Значение должно быть от {low} до {high}.")

height = read_int("Твой рост (см): ", 100, 220)
weight = read_int("Твой вес (кг): ", 20, 150)
bmi = weight / (height / 100) ** 2
print(f"ИМТ: {bmi:.2f}")
```

**Задание 7.**

```python
while True:
    line = input("Выражение: ")
    if line == "стоп":
        print("Пока!")
        break
    parts = line.split()
    if len(parts) != 3:
        print("Формат: число операция число (например 12 / 4)")
        continue
    try:
        a = float(parts[0])
        b = float(parts[2])
    except ValueError:
        print("Ошибка: правильно запиши числа.")
        continue
    op = parts[1]
    try:
        if op == "+":
            print("=", a + b)
        elif op == "-":
            print("=", a - b)
        elif op == "*":
            print("=", a * b)
        elif op == "/":
            print("=", a / b)
        else:
            print("Неизвестная операция:", op)
    except ZeroDivisionError:
        print("На ноль делить нельзя!")
```

**Задание 8.**

```python
data = ["12", "7", "десять", "0", "-3", "4.5", "", "100"]
results = []
errors = {}
for item in data:
    try:
        results.append(round(1000 / int(item), 2))
    except (ValueError, ZeroDivisionError) as e:
        name = type(e).__name__
        errors[name] = errors.get(name, 0) + 1
print("Успешно:", results)
print("Ошибки:", errors)
```

```text
Ошибки: {'ValueError': 3, 'ZeroDivisionError': 1}
```
