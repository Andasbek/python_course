## 1. Что такое файл?

**Файл** – именованный набор данных на диске (жёстком диске, флешке). Даже если программа закрыта или компьютер выключен, информация в файле сохраняется.

Существует два вида файлов:

| Вид | Примеры | Особенность |
|---|---|---|
| Текстовые (text) | `.txt`, `.py`, `.csv`, `.html` | Можно открыть и прочитать в Блокноте |
| Двоичные (binary) | `.jpg`, `.mp3`, `.exe`, `.docx` | Нужна специальная программа |

Дальше речь идёт о **текстовых файлах**.

**Аналогия.** Файл – это книга в библиотеке. Чтобы её прочитать, нужно: 1) найти книгу (имя и место файла), 2) открыть (`open`), 3) прочитать (`read`), 4) закрыть (`close`) – иначе другие не смогут её взять.

### Путь к файлу (path)

- **Относительный путь**: `"poem.txt"` – файл ищется в папке, где лежит программа (файл `.py`). Это самый частый вариант.
- **Абсолютный путь**: `"C:/Users/Aibek/Desktop/poem.txt"` – полный адрес.

> **Важно.** В Windows при записи пути используй прямую косую черту `/`, а не обратную `\`, или ставь перед строкой `r`: `r"C:\Users\Aibek\poem.txt"`.

### Кодировка (encoding)

Компьютер хранит буквы в виде чисел. Чтобы русские и казахские буквы (ё, ы, э, ә, ғ, қ, ң, ө, ұ, ү, һ, і) читались правильно, мы всегда открываем файл в кодировке **UTF-8**: `encoding="utf-8"`. Иначе могут появиться непонятные символы вроде «Ð°Ò›».

## 2. Пример текстового файла

Текстовый файл можно создать в любом редакторе (в Thonny: **File → New**, затем сохранить с расширением `.txt`). Во всех примерах ниже используется файл `poem.txt`, лежащий **в одной папке** с программой `.py`:

```text
Рассвет настал, взошло светило,
Компьютер мой включён опять.
На Python код пишу с усердием,
Ошибки учат всё понять.
```


## 3. Функция open() и метод read()

```text
file = open("имя_файла", "режим", encoding="utf-8")
```

- первый аргумент – имя файла (путь);
- второй аргумент – **режим**: `"r"` – чтение (read). Этот режим используется по умолчанию, поэтому его можно не писать;
- `encoding="utf-8"` – кодировка.

`open()` возвращает не сам файл, а **файловый объект** – через него мы и читаем.

```python
file = open("poem.txt", "r", encoding="utf-8")
text = file.read()      # прочитать весь файл как одну строку
file.close()            # закрыть файл
print(text)
print("Количество символов:", len(text))
```

Результат:
```text
Рассвет настал, взошло светило,
Компьютер мой включён опять.
На Python код пишу с усердием,
Ошибки учат всё понять.

Количество символов: 116
```

(Количество символов может отличаться в зависимости от текста в файле.)

Результат `read()` – обычная **строка (str)**. Значит, к ней можно применять все строковые методы (`split`, `count`, `upper` и т.д.):

```python
file = open("poem.txt", encoding="utf-8")
text = file.read()
file.close()

words = text.split()
print("Количество слов:", len(words))
print("Буква 'а' встречается", text.count("а"), "раз")
print("Заглавными буквами:", text.upper()[:20])
```

Результат:
```text
Количество слов: 18
Буква 'а' встречается 5 раз
Заглавными буквами: РАССВЕТ НАСТАЛ, ВЗОШ
```

`read(n)` – читает только первые `n` символов: `file.read(10)`.

### Зачем закрывать файл?

- Открытый файл занимает системные ресурсы;
- при записи данные попадают на диск полностью только после закрытия (данные сначала копятся в буфере);
- некоторые операционные системы не дают открытый файл другой программе.

## 4. readline() и readlines()

`\n` – **символ конца строки** (переход на новую строку). В файле в конце каждой строки стоит невидимый `\n`.

| Метод | Что возвращает | Пример результата |
|---|---|---|
| `read()` | Весь файл – одна строка | `"строка 1\nстрока 2\n"` |
| `readline()` | Одну следующую строку | `"строка 1\n"` |
| `readlines()` | Список всех строк | `["строка 1\n", "строка 2\n"]` |

```python
file = open("poem.txt", encoding="utf-8")
first = file.readline()
second = file.readline()
file.close()
print("Строка 1:", first)
print("Строка 2:", second)
```

Результат:
```text
Строка 1: Рассвет настал, взошло светило,

Строка 2: Компьютер мой включён опять.

```

Между ними появилась пустая строка – потому что внутри самой строки уже есть `\n`, а `print` добавляет ещё один `\n`. Лекарство – `strip()`:

```python
file = open("poem.txt", encoding="utf-8")
lines = file.readlines()
file.close()

print(lines[0])            # с \n
print(len(lines), "строки")
for i in range(len(lines)):
    print(i + 1, lines[i].strip())
```

Результат:
```text
Рассвет настал, взошло светило,

4 строки
1 Рассвет настал, взошло светило,
2 Компьютер мой включён опять.
3 На Python код пишу с усердием,
4 Ошибки учат всё понять.
```

> **Файловый курсор.** Файловый объект «помнит», до какого места он прочитан. Если после `read()`, прочитавшего весь файл, снова вызвать `read()`, получишь пустую строку `""`.

### Цикл по файлу

Самый простой и эффективный способ – передать файловый объект прямо в цикл `for`. На каждом шаге читается одна строка:

```python
file = open("poem.txt", encoding="utf-8")
number = 1
for line in file:
    print(f"{number:2}) {line.strip()}")
    number += 1
file.close()
```

Результат:
```text
 1) Рассвет настал, взошло светило,
 2) Компьютер мой включён опять.
 3) На Python код пишу с усердием,
 4) Ошибки учат всё понять.
```

Этот способ эффективен для больших файлов: весь файл не загружается в память сразу.

## 5. Конструкция with

Забыть написать `close()` легко. А если при чтении файла возникнет ошибка, `close()` может вообще не выполниться. Поэтому в Python есть конструкция **`with`** – она **автоматически** закрывает файл по окончании блока (даже если произошла ошибка).

```text
with open("файл", "r", encoding="utf-8") as file:
    # работа с файлом (с отступом)
# здесь файл уже закрыт
```

```python
with open("poem.txt", encoding="utf-8") as file:
    lines = file.readlines()

print("Файл закрыт?", file.closed)
print("Количество строк:", len(lines))
print("Последняя строка:", lines[-1].strip())
```

Результат:
```text
Файл закрыт? True
Количество строк: 4
Последняя строка: Ошибки учат всё понять.
```

**Аналогия.** `with` – автоматическая дверь: вошёл – открылась, вышел – сама закрылась.

> **Используй `with` всегда.** Это стандартный, рекомендуемый способ работы с файлами в Python.

## 6. Чтение файла с числами

Всё, что прочитано из файла, – **строки**. Чтобы считать с числами, их нужно преобразовать через `int()` или `float()`.

Файл `scores.txt` (в каждой строке один балл):

```text
85
92
78
100
64
```

```python
with open("scores.txt", encoding="utf-8") as f:
    scores = []
    for line in f:
        line = line.strip()
        if line != "":            # пропускаем пустые строки
            scores.append(int(line))

print("Баллы:", scores)
print("Среднее:", sum(scores) / len(scores))
print("Наибольший:", max(scores))
```

Результат:
```text
Баллы: [85, 92, 78, 100, 64]
Среднее: 83.8
Наибольший: 100
```

### Несколько данных в одной строке (с разделителем)

`cities.txt` – город и численность населения (тыс. человек), разделённые точкой с запятой:

```text
Алматы;2300
Астана;1500
Шымкент;1250
Караганда;500
```

```python
with open("cities.txt", encoding="utf-8") as f:
    for line in f:
        name, people = line.strip().split(";")
        people = int(people)
        print(f"{name:<10} – {people} тыс. человек")
```

Результат:
```text
Алматы     – 2300 тыс. человек
Астана     – 1500 тыс. человек
Шымкент    – 1250 тыс. человек
Караганда  – 500 тыс. человек
```

## 7. Если файл не найден: FileNotFoundError

Если имя файла написано с ошибкой или файл лежит в другой папке, Python выдаёт `FileNotFoundError`. Его можно перехватить с помощью `try...except`:

```python
name = input("Какой файл открыть? ")
try:
    with open(name, encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print(f"Файл '{name}' не найден. Проверь имя и папку.")
else:
    print("В файле", len(content.splitlines()), "строк(и).")
```

Результат (ввод `poema.txt`):
```text
Какой файл открыть? poema.txt
Файл 'poema.txt' не найден. Проверь имя и папку.
```

Можно перехватывать и случай, когда данные внутри файла повреждены:

```python
with open("scores.txt", encoding="utf-8") as f:
    good = []
    bad_count = 0
    for line in f:
        try:
            good.append(int(line))
        except ValueError:
            bad_count += 1
print("Корректных строк:", len(good), "| Повреждённых строк:", bad_count)
```

(`int()` сам игнорирует пробелы и `\n` в начале и в конце строки.)

## Частые ошибки

**1. Не указана кодировка.** В Windows `open("poem.txt")` может исказить русские и казахские буквы или выдать `UnicodeDecodeError`.

```python
with open("poem.txt", encoding="utf-8") as f:   # правильно
    print(f.read())
```

**2. Файл лежит в другой папке.** Файл должен находиться в одной папке с программой `.py`. В Thonny сначала сохрани программу и положи файл туда же.

**3. Забыли про `\n`.** `if line == "Алматы":` никогда не выполнится, потому что значение `line` – `"Алматы\n"`. Правильно: `if line.strip() == "Алматы":`.

**4. Не преобразовали в число.**

```python
with open("scores.txt", encoding="utf-8") as f:
    lines = f.readlines()
# sum(lines) -> TypeError, потому что элементы – строки
total = sum([int(x) for x in lines])
print(total)
```

**5. Чтение за пределами блока `with`.**

```python
with open("poem.txt", encoding="utf-8") as f:
    first = f.readline()
# f.read() здесь -> ValueError: I/O operation on closed file
print(first.strip())
```

**6. Попытка прочитать файл дважды.** После первого `read()` курсор стоит в конце файла; второй `read()` вернёт пустую строку. Сохрани текст в переменной и работай с ней.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Файл | Именованные данные, хранящиеся на диске |
| Текстовый файл | Файл, состоящий из символов (`.txt`, `.csv`, `.py`) |
| Путь к файлу (path) | Местоположение файла: относительное или абсолютное |
| Кодировка (encoding) | Правило перевода символов в числа; у нас `utf-8` |
| `open()` | Открывает файл и возвращает файловый объект |
| `read()` | Читает весь файл как одну строку |
| `readline()` | Читает одну следующую строку |
| `readlines()` | Возвращает все строки в виде списка |
| `close()` | Закрывает файл |
| `with` | Конструкция, автоматически закрывающая файл |
| `\n` | Символ конца строки (перехода на новую строку) |
| `FileNotFoundError` | Исключение, возникающее, если файл не найден |

## Примечание

- Если не указать `encoding`, Python берёт кодировку системы по умолчанию (в Windows часто `cp1251`), поэтому один и тот же код может работать на одном компьютере и ломаться на другом. В Python 3.15 по умолчанию планируется UTF-8 ([PEP 686](https://peps.python.org/pep-0686/)), но явное `encoding="utf-8"` остаётся лучшей практикой.
- Файлы, сохранённые Блокнотом Windows как «UTF-8 с BOM», начинаются с невидимого символа `\ufeff`. Чтобы он не попал в первую строку, открывай такие файлы с `encoding="utf-8-sig"`.
- Относительный путь считается от **текущей рабочей папки**, а не всегда от папки со скриптом. Надёжный вариант – `pathlib`: `Path(__file__).parent / "poem.txt"`.
- `readlines()` и `read()` загружают весь файл в память; для больших файлов лучше цикл `for line in f`.
- Для простого чтения есть короткий способ: `from pathlib import Path; text = Path("poem.txt").read_text(encoding="utf-8")`.
- Документация: [Reading and Writing Files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files), [open()](https://docs.python.org/3/library/functions.html#open).
