## 1. Файл деген не?

**Файл** – дискіде (қатты дискіде, флешкада) атауы бар деректер жиынтығы. Бағдарлама жабылса да, компьютер өшсе де файлдағы ақпарат сақталады.

Файлдардың екі түрі бар:

| Түрі | Мысалдар | Ерекшелігі |
|---|---|---|
| Мәтіндік (text) | `.txt`, `.py`, `.csv`, `.html` | Блокнотпен ашып оқуға болады |
| Екілік (binary) | `.jpg`, `.mp3`, `.exe`, `.docx` | Арнайы бағдарлама керек |

Әрі қарай **мәтіндік файлдар** туралы сөз болады.

**Аналогия.** Файл – кітапханадағы кітап. Оны оқу үшін: 1) кітапты табу керек (файл атауы мен орны), 2) ашу керек (`open`), 3) оқу керек (`read`), 4) жабу керек (`close`) – әйтпесе басқалар ала алмайды.

### Файл жолы (путь, path)

- **Салыстырмалы жол**: `"poem.txt"` – файл бағдарлама (`.py` файлы) тұрған папкада іздейді. Бұл ең жиі қолданылатын нұсқа.
- **Абсолюттік жол**: `"C:/Users/Aibek/Desktop/poem.txt"` – толық мекенжай.

> **Маңызды.** Windows-та жолды жазғанда кері қиғаш сызық `\` емес, түзу `/` қолдан, немесе жолдың алдына `r` қой: `r"C:\Users\Aibek\poem.txt"`.

### Кодтау (кодировка, encoding)

Компьютер әріптерді сан түрінде сақтайды. Қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) дұрыс оқылуы үшін файлды әрқашан **UTF-8** кодтауымен ашамыз: `encoding="utf-8"`. Әйтпесе «Ð°Ò›» сияқты түсініксіз таңбалар шығуы мүмкін.

## 2. Мәтіндік файл мысалы

Мәтіндік файлды кез келген редакторда құруға болады (Thonny-де: **File → New**, содан кейін `.txt` кеңейтімімен сақтау). Төмендегі барлық мысалдарда `.py` бағдарламамен **бір папкада** тұрған `poem.txt` файлы қолданылады:

```text
Таң атады, күн шығады,
Компьютерім іске қосылады.
Python тілінде код жазамын,
Әр қатеден сабақ аламын.
```


## 3. open() функциясы және read() әдісі

```text
file = open("файл_атауы", "режим", encoding="utf-8")
```

- бірінші аргумент – файл атауы (жолы);
- екінші аргумент – **режим**: `"r"` – оқу (read). Бұл режим әдепкі, сондықтан оны жазбауға да болады;
- `encoding="utf-8"` – кодтау.

`open()` файлдың өзін емес, **файл объектісін** қайтарады – ол арқылы оқимыз.

```python
file = open("poem.txt", "r", encoding="utf-8")
text = file.read()      # бүкіл файлды бір жол ретінде оқу
file.close()            # файлды жабу
print(text)
print("Таңбалар саны:", len(text))
```

Нәтижесі:
```text
Таң атады, күн шығады,
Компьютерім іске қосылады.
Python тілінде код жазамын,
Әр қатеден сабақ аламын.

Таңбалар саны: 103
```

(Таңбалар саны файлдағы мәтінге байланысты өзгеруі мүмкін.)

`read()` нәтижесі – кәдімгі **жол (str)**. Демек, оған барлық жол әдістерін (`split`, `count`, `upper` т.б.) қолдануға болады:

```python
file = open("poem.txt", encoding="utf-8")
text = file.read()
file.close()

words = text.split()
print("Сөз саны:", len(words))
print("'а' әрпі", text.count("а"), "рет кездеседі")
print("Үлкен әріппен:", text.upper()[:20])
```

Нәтижесі:
```text
Сөз саны: 15
'а' әрпі 12 рет кездеседі
Үлкен әріппен: ТАҢ АТАДЫ, КҮН ШЫҒАД
```

`read(n)` – тек алғашқы `n` таңбаны оқиды: `file.read(10)`.

### Неліктен файлды жабу керек?

- Ашық файл жүйе ресурсын алып тұрады;
- жазу кезінде деректер дискіге файл жабылғаннан кейін ғана толық түседі (деректер алдымен буферде жиналады);
- кейбір операциялық жүйелер ашық файлды басқа бағдарламаға бермейді.

## 4. readline() және readlines()

`\n` – **жол соңы таңбасы** (жаңа жолға көшу). Файлда әр жолдың соңында көзге көрінбейтін `\n` тұрады.

| Әдіс | Не қайтарады | Мысал нәтижесі |
|---|---|---|
| `read()` | Бүкіл файл – бір жол | `"1-жол\n2-жол\n"` |
| `readline()` | Келесі бір жол | `"1-жол\n"` |
| `readlines()` | Барлық жолдардың тізімі | `["1-жол\n", "2-жол\n"]` |

```python
file = open("poem.txt", encoding="utf-8")
first = file.readline()
second = file.readline()
file.close()
print("1-жол:", first)
print("2-жол:", second)
```

Нәтижесі:
```text
1-жол: Таң атады, күн шығады,

2-жол: Компьютерім іске қосылады.

```

Арасында бос жол пайда болды – себебі жолдың өз ішінде `\n` бар, оған `print` тағы бір `\n` қосады. Емі – `strip()`:

```python
file = open("poem.txt", encoding="utf-8")
lines = file.readlines()
file.close()

print(lines[0])            # \n бар
print(len(lines), "жол")
for i in range(len(lines)):
    print(i + 1, lines[i].strip())
```

Нәтижесі:
```text
Таң атады, күн шығады,

4 жол
1 Таң атады, күн шығады,
2 Компьютерім іске қосылады.
3 Python тілінде код жазамын,
4 Әр қатеден сабақ аламын.
```

> **Файл курсоры.** Файл объектісі «қай жерге дейін оқығанын» есте сақтайды. `read()` бүкіл файлды оқығаннан кейін қайта `read()` шақырсаң, бос жол `""` аласың.

### Файл бойынша цикл

Ең қарапайым әрі тиімді тәсіл – файл объектісін тікелей `for` цикліне беру. Әр қадамда бір жол оқылады:

```python
file = open("poem.txt", encoding="utf-8")
number = 1
for line in file:
    print(f"{number:2}) {line.strip()}")
    number += 1
file.close()
```

Нәтижесі:
```text
 1) Таң атады, күн шығады,
 2) Компьютерім іске қосылады.
 3) Python тілінде код жазамын,
 4) Әр қатеден сабақ аламын.
```

Бұл тәсіл үлкен файлдар үшін тиімді: бүкіл файл жадқа бірден жүктелмейді.

## 5. with конструкциясы

`close()` жазуды ұмытып кету оңай. Ал файлды оқу кезінде қате шықса, `close()` мүлдем орындалмай қалуы мүмкін. Сондықтан Python-да **`with`** конструкциясы бар – ол блок аяқталғанда файлды **автоматты түрде** жабады (тіпті қате болса да).

```text
with open("файл", "r", encoding="utf-8") as file:
    # файлмен жұмыс (шегініспен)
# мұнда файл жабылған
```

```python
with open("poem.txt", encoding="utf-8") as file:
    lines = file.readlines()

print("Файл жабылды ма?", file.closed)
print("Жолдар саны:", len(lines))
print("Соңғы жол:", lines[-1].strip())
```

Нәтижесі:
```text
Файл жабылды ма? True
Жолдар саны: 4
Соңғы жол: Әр қатеден сабақ аламын.
```

**Аналогия.** `with` – автоматты есік: кірдің – ашылды, шықтың – өзі жабылды.

> **Әрқашан `with` қолдан.** Бұл – Python-да файлмен жұмыс істеудің стандартты, ұсынылатын тәсілі.

## 6. Сандар бар файлды оқу

Файлдан оқылғанның бәрі – **жол**. Санмен есептеу үшін оны `int()` немесе `float()` арқылы түрлендіру керек.

`scores.txt` файлы (әр жолда бір баға):

```text
85
92
78
100
64
```

```python
with open("scores.txt", encoding="utf-8") as f:
    scores = []
    for line in f:
        line = line.strip()
        if line != "":            # бос жолдарды өткізіп жібереміз
            scores.append(int(line))

print("Ұпайлар:", scores)
print("Орташа:", sum(scores) / len(scores))
print("Ең жоғары:", max(scores))
```

Нәтижесі:
```text
Ұпайлар: [85, 92, 78, 100, 64]
Орташа: 83.8
Ең жоғары: 100
```

### Бір жолда бірнеше дерек (бөлгішпен)

`cities.txt` – қала мен халық саны (мың адам) нүктелі үтірмен бөлінген:

```text
Алматы;2300
Астана;1500
Шымкент;1250
Қарағанды;500
```

```python
with open("cities.txt", encoding="utf-8") as f:
    for line in f:
        name, people = line.strip().split(";")
        people = int(people)
        print(f"{name:<10} – {people} мың адам")
```

Нәтижесі:
```text
Алматы     – 2300 мың адам
Астана     – 1500 мың адам
Шымкент    – 1250 мың адам
Қарағанды  – 500 мың адам
```

## 7. Файл табылмаса: FileNotFoundError

Файл атауы қате жазылса немесе ол басқа папкада тұрса, Python `FileNotFoundError` береді. Оны `try...except` арқылы ұстауға болады:

```python
name = input("Қай файлды ашу керек? ")
try:
    with open(name, encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print(f"'{name}' файлы табылмады. Атауын және папкасын тексер.")
else:
    print("Файлда", len(content.splitlines()), "жол бар.")
```

Нәтижесі (енгізу `poema.txt`):
```text
Қай файлды ашу керек? poema.txt
'poema.txt' файлы табылмады. Атауын және папкасын тексер.
```

Файл ішіндегі деректер бүлінген жағдайды да ұстауға болады:

```python
with open("scores.txt", encoding="utf-8") as f:
    good = []
    bad_count = 0
    for line in f:
        try:
            good.append(int(line))
        except ValueError:
            bad_count += 1
print("Дұрыс жолдар:", len(good), "| Бүлінген жолдар:", bad_count)
```

(`int()` жолдың басы мен соңындағы бос орындар мен `\n`-ді өзі елемейді.)

## Жиі кездесетін қателер

**1. Кодтауды көрсетпеу.** Windows-та `open("poem.txt")` қазақ әріптерін бұзып оқуы немесе `UnicodeDecodeError` беруі мүмкін.

```python
with open("poem.txt", encoding="utf-8") as f:   # дұрыс
    print(f.read())
```

**2. Файл басқа папкада тұр.** Файл `.py` бағдарламамен бір папкада болуы керек. Thonny-де бағдарламаны алдымен сақта, файлды да сол жерге қой.

**3. `\n`-ді ұмыту.** `if line == "Алматы":` ешқашан орындалмайды, өйткені `line` мәні – `"Алматы\n"`. Дұрысы: `if line.strip() == "Алматы":`.

**4. Санды түрлендірмеу.**

```python
with open("scores.txt", encoding="utf-8") as f:
    lines = f.readlines()
# sum(lines) -> TypeError, өйткені элементтер – жолдар
total = sum([int(x) for x in lines])
print(total)
```

**5. `with` блогынан тыс оқу.**

```python
with open("poem.txt", encoding="utf-8") as f:
    first = f.readline()
# f.read() мұнда -> ValueError: I/O operation on closed file
print(first.strip())
```

**6. Файлды екі рет оқуға тырысу.** Бірінші `read()`-тан кейін курсор файл соңында тұр; екінші `read()` бос жол қайтарады. Мәтінді айнымалыда сақтап, сонымен жұмыс істе.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Файл | Дискіде сақталатын атауы бар деректер |
| Мәтіндік файл | Таңбалардан тұратын файл (`.txt`, `.csv`, `.py`) |
| Файл жолы (path) | Файлдың орны: салыстырмалы немесе абсолюттік |
| Кодтау (encoding) | Таңбаларды санға айналдыру ережесі; бізде `utf-8` |
| `open()` | Файлды ашып, файл объектісін қайтарады |
| `read()` | Бүкіл файлды бір жол ретінде оқиды |
| `readline()` | Келесі бір жолды оқиды |
| `readlines()` | Барлық жолдарды тізім ретінде қайтарады |
| `close()` | Файлды жабады |
| `with` | Файлды автоматты жабатын конструкция |
| `\n` | Жол соңы (жаңа жолға көшу) таңбасы |
| `FileNotFoundError` | Файл табылмағанда туатын ерекше жағдай |

## Ескерту

- `encoding` көрсетілмесе, Python жүйенің әдепкі кодтауын алады (Windows-та көбіне `cp1251`), сондықтан бір код бір компьютерде жұмыс істеп, басқасында бұзылуы мүмкін. Python 3.15-те әдепкі UTF-8 болуы жоспарланған ([PEP 686](https://peps.python.org/pep-0686/)), бірақ `encoding="utf-8"` деп нақты жазу – ең дұрыс тәжірибе.
- Windows Блокнотында «UTF-8 BOM-мен» сақталған файлдар көрінбейтін `\ufeff` таңбасынан басталады. Ол бірінші жолға түспеуі үшін мұндай файлдарды `encoding="utf-8-sig"` арқылы аш.
- Салыстырмалы жол әрқашан скрипт папкасынан емес, **ағымдағы жұмыс папкасынан** есептеледі. Сенімді нұсқа – `pathlib`: `Path(__file__).parent / "poem.txt"`.
- `readlines()` пен `read()` бүкіл файлды жадқа жүктейді; үлкен файлдар үшін `for line in f` циклі жақсырақ.
- Қарапайым оқудың қысқа тәсілі бар: `from pathlib import Path; text = Path("poem.txt").read_text(encoding="utf-8")`.
- Құжаттама: [Reading and Writing Files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files), [open()](https://docs.python.org/3/library/functions.html#open).
