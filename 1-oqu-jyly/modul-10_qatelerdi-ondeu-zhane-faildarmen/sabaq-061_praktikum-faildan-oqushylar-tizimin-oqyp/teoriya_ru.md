## 1. Схема «чтение – обработка – запись»

Типичная задача обработки данных: оценки учеников выгружены из электронного журнала в текстовый файл. Программа читает файл, вычисляет среднюю оценку каждого ученика, определяет отличников и готовит **файл отчёта**.

Это схема работы большинства реальных программ:

```text
  +-----------------+     +-------------------+     +-----------------+
  |  1. ЧТЕНИЕ      | --> |  2. ОБРАБОТКА     | --> |  3. ЗАПИСЬ      |
  |  students.txt   |     |  список, словарь, |     |  report.txt     |
  |  (входной файл) |     |  расчёт, сортировка|    | (выходной файл) |
  +-----------------+     +-------------------+     +-----------------+
```

## 2. Структура файла данных

Файл `students.txt` (в одной папке с программой, UTF-8):

```text
Имя;Фамилия;Класс;Математика;Информатика;Казахский язык
Айгерим;Сейитова;7А;5;5;5
Нурлан;Жаксылыков;7А;4;5;3
Дана;Абилова;7Б;5;4;5
Ерасыл;Толегенов;7Б;3;4;4
Мадина;Ахметова;7А;4;4;5
Арман;Курманов;7Б;5;5;4
Алия;Бекова;7А;3;3;4
Санжар;Оразов;7Б;4;5;5
```

Пояснение:
- **Первая строка – строка заголовка**: названия столбцов. Её мы не обрабатываем как данные.
- **Разделитель** – `;`. Каждая строка делится с помощью `split(";")` на 6 частей.
- Каждая строка – одна **запись**, каждая часть – **поле**.

Такие табличные текстовые файлы называются **CSV** (Comma-Separated Values – «значения, разделённые запятыми»). Excel или Google Sheets умеют открывать их как таблицу. Для них в стандартной библиотеке есть модуль `csv`, но простые файлы легко разобрать и вручную, через `split()`.

## 3. Как хранить данные в памяти?

Каждого ученика удобно хранить как словарь, а всех учеников – в списке:

```python
student = {
    "name": "Айгерим",
    "surname": "Сейитова",
    "class": "7А",
    "grades": [5, 5, 5],
}
students = [student]
print(student["name"], "среднее:", sum(student["grades"]) / len(student["grades"]))
```

Результат:
```text
Айгерим среднее: 5.0
```

## 4. Структура программы: разбиение на функции

Если разбить большую программу на **маленькие функции**, её легче и писать, и проверять:

| Функция | Назначение | Возвращает |
|---|---|---|
| `read_students(file_name)` | Читает файл и создаёт список словарей | список |

```python
def read_students(file_name):
    students = []
    # чтение файла ...
    return students

def average(grades):
    return sum(grades) / len(grades)

def write_report(students, file_name):
    pass   # заглушка, тело функции пишется позже

students = read_students("students.txt")

```

> **Приём.** Сначала напиши «каркас», затем заполняй функции **по одной** и проверяй каждую. Так работают профессиональные программисты.

## 5. Функция чтения файла

```python
def read_students(file_name):
    students = []
    with open(file_name, encoding="utf-8") as f:
        f.readline()                      # пропускаем строку заголовка
        for line in f:
            parts = line.strip().split(";")
            if len(parts) != 6:
                continue                  # пустая или повреждённая строка
            grades = [int(parts[3]), int(parts[4]), int(parts[5])]
            students.append({
                "name": parts[0],
                "surname": parts[1],
                "class": parts[2],
                "grades": grades,
            })
    return students
```

Здесь:
- `f.readline()` – читаем первую строку и «выбрасываем» её;
- `len(parts) != 6` – игнорируем пустые и неполные строки;
- оценки превращаются в числа через `int()`.

## 6. Красивое оформление файла отчёта

Выравнивание в f-строках помогает строить таблицы:

| Запись | Значение |
|---|---|
| `{name:<12}` | 12 позиций, выравнивание влево |
| `{num:>5}` | 5 позиций, выравнивание вправо |
| `{avg:.2f}` | 2 знака после запятой |
| `{"=" * 30}` | символ, повторённый 30 раз |

```python
name = "Айгерим"
avg = 4.6667
print(f"|{name:<12}|{avg:>6.2f}|")
print(f"|{'Ерасыл':<12}|{3.6667:>6.2f}|")
```

Результат:
```text
|Айгерим     |  4.67|
|Ерасыл      |  3.67|
```

Функция записи отчёта, собранная из этих приёмов:

```python
def average(grades):
    return sum(grades) / len(grades)

def write_report(students, file_name):
    with open(file_name, "w", encoding="utf-8") as f:
        print("=" * 30, file=f)
        for s in sorted(students, key=lambda s: average(s["grades"]), reverse=True):
            print(f"{s['name']:<12}{s['class']:<5}{average(s['grades']):>6.2f}", file=f)
        print("=" * 30, file=f)

write_report([{"name": "Дана", "class": "7Б", "grades": [5, 4, 5]}], "report.txt")
```

## 7. Устойчивость к ошибкам

Реальные файлы данных часто бывают «грязными»: пустые строки, лишние пробелы, «н» (не был) вместо оценки, отсутствие самого файла. Надёжная программа должна:
- если файла нет – вывести понятное сообщение и завершить работу;
- повреждённую строку пропустить и сообщить её номер.

```python
line = "Алия;Бекова;7А;3;н;4"
parts = line.split(";")
try:
    grades = [int(parts[3]), int(parts[4]), int(parts[5])]
except ValueError:
    print("Пропущена повреждённая строка:", line)
```

Результат:
```text
Пропущена повреждённая строка: Алия;Бекова;7А;3;н;4
```

## 8. Проверка (тестирование) программы

Проверка программы обработки файлов:
1. Посчитай **вручную** среднюю оценку одного ученика и сравни с результатом программы.
2. Добавь в файл пустую строку и ошибочную строку и проверь, что программа не падает.
3. Намеренно неправильно напиши имя файла и проверь сообщение.
4. Открой файл `report.txt` в Блокноте и проверь, что русские и казахские буквы отображаются правильно.

## Частые ошибки

**1. Чтение строки заголовка как данных** → `int("Математика")` – `ValueError`. Решение: пропустить первую строку с помощью `f.readline()`.

**2. Забыли `strip()`** → последняя оценка будет `"5\n"`; `int()` это выдержит, но если последнее поле – текст (`"7А\n"`), сравнение будет работать неправильно.

**3. Целочисленное деление или ошибка округления.** Используй `/`, а не `//`; при выводе используй формат `:.2f`.

**4. Запись отчёта в режиме `a`** → при каждом запуске отчёт повторяется, и файл растёт. Для отчёта – `w`.

**5. Весь код в одном блоке.** Трудно найти, где ошибка. Разбивай на функции.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Входной файл | Файл данных, который читает программа |
| Выходной файл | Файл, в который программа записывает результат |
| Строка заголовка | Первая строка с названиями столбцов |
| Разделитель | Символ, разделяющий поля (`;`, `,`, `\t`) |
| Запись / поле | Одна строка файла / одна часть строки |
| CSV | Текстовый формат табличных данных |
| Фильтрация (фильтр) | Выбор записей, удовлетворяющих условию |
| Отчёт | Оформленный вид обработанных результатов |

## Примечание

- Для настоящих CSV-файлов используй модуль `csv`: `csv.reader(f, delimiter=";")` или `csv.DictReader` правильно обрабатывает поля в кавычках, внутри которых встречается разделитель. Файл для `csv` открывают с `newline=""`.
- Excel в русской/казахской локали сохраняет CSV с разделителем `;` и часто в кодировке `cp1251` или UTF-8 с BOM (`utf-8-sig`) – это нужно учитывать при чтении.
- `sorted(..., key=...)` не изменяет исходный список, а `list.sort(key=...)` сортирует на месте. Для сортировки по нескольким признакам ключ может возвращать кортеж: `key=lambda s: (s["class"], s["surname"])`.
- `round(2.675, 2)` даёт `2.67` из-за двоичного представления `float`; для вывода надёжнее формат `:.2f`, а для точных расчётов – модуль `decimal`.
- Защита от деления на ноль: у ученика без оценок `len(grades) == 0` – такую запись лучше пропускать заранее.
- Документация: [csv – чтение и запись CSV](https://docs.python.org/3/library/csv.html), [Format Specification Mini-Language](https://docs.python.org/3/library/string.html#formatspec).
