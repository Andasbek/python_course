## 1. «Оқу – өңдеу – жазу» сызбасы

Деректерді өңдеудің типтік міндеті: оқушылардың бағалары электрондық журналдан мәтіндік файлға жүктелген. Бағдарлама файлды оқып, әр оқушының орташа бағасын есептейді, үздіктерді анықтайды және **есеп файлын** дайындайды.

Бұл – нақты бағдарламалардың көпшілігінің жұмыс сызбасы:

```text
  +-----------------+     +------------------+     +-----------------+
  |  1. ОҚУ         | --> |  2. ӨҢДЕУ        | --> |  3. ЖАЗУ        |
  |  students.txt   |     |  тізім, сөздік,  |     |  report.txt     |
  |  (кіріс файлы)  |     |  есептеу, сұрыптау|    |  (шығыс файлы)  |
  +-----------------+     +------------------+     +-----------------+
```

## 2. Деректер файлының құрылымы

`students.txt` файлы (бағдарламамен бір папкада, UTF-8):

```text
Аты;Тегі;Сыныбы;Математика;Информатика;Қазақ тілі
Айгерім;Сейітова;7А;5;5;5
Нұрлан;Жақсылықов;7А;4;5;3
Дана;Әбілова;7Ә;5;4;5
Ерасыл;Төлегенов;7Ә;3;4;4
Мадина;Ахметова;7А;4;4;5
Арман;Құрманов;7Ә;5;5;4
Әлия;Бекова;7А;3;3;4
Санжар;Оразов;7Ә;4;5;5
```

Түсіндірме:
- **Бірінші жол – тақырып жолы (заголовок)**: бағандардың атаулары. Оны деректер ретінде өңдемейміз.
- **Бөлгіш (разделитель)** – `;`. Әр жол `split(";")` арқылы 6 бөлікке бөлінеді.
- Әр жол – бір **жазба** (запись), әр бөлік – **өріс** (поле).

Мұндай кестелік мәтіндік файлдар **CSV** (Comma-Separated Values – «үтірмен бөлінген мәндер») деп аталады. Excel немесе Google Sheets оларды кесте ретінде аша алады. Олар үшін стандартты кітапханада `csv` модулі бар, бірақ қарапайым файлдарды `split()` арқылы қолмен де оңай талдауға болады.

## 3. Деректерді жадта қалай сақтаймыз?

Әр оқушыны сөздік ретінде сақтау ыңғайлы, ал барлық оқушыларды – тізімге:

```python
student = {
    "name": "Айгерім",
    "surname": "Сейітова",
    "class": "7А",
    "grades": [5, 5, 5],
}
students = [student]
print(student["name"], "орташа:", sum(student["grades"]) / len(student["grades"]))
```

Нәтижесі:
```text
Айгерім орташа: 5.0
```

## 4. Бағдарлама құрылымы: функцияларға бөлу

Үлкен бағдарламаны **кішкентай функцияларға** бөлсек, оны жазу да, тексеру де оңай:

| Функция | Міндеті | Қайтарады |
|---|---|---|
| `read_students(file_name)` | Файлды оқып, сөздіктер тізімін жасайды | тізім |
| `average(grades)` | Бағалардың орташасын есептейді | сан |
| `best_students(students)` | Орташасы 4.5-тен жоғарыларды таңдайды | тізім |
| `write_report(students, file_name)` | Есепті файлға жазады | ештеңе |

Бағдарламаның «қаңқасы»:

```python
def read_students(file_name):
    students = []
    # файлды оқу ...
    return students

def average(grades):
    return sum(grades) / len(grades)

def write_report(students, file_name):
    pass   # бос орын, функция денесі кейін жазылады

students = read_students("students.txt")
write_report(students, "report.txt")
print("Дайын!")
```

> **Әдіс.** Алдымен «қаңқа» жаз, содан кейін әр функцияны **бір-бірден** толтырып, әрқайсысын тексер. Бұл – кәсіби бағдарламашылардың жұмыс тәсілі.

## 5. Файлды оқу функциясы

```python
def read_students(file_name):
    students = []
    with open(file_name, encoding="utf-8") as f:
        f.readline()                      # тақырып жолын өткізіп жібереміз
        for line in f:
            parts = line.strip().split(";")
            if len(parts) != 6:
                continue                  # бос немесе бүлінген жол
            grades = [int(parts[3]), int(parts[4]), int(parts[5])]
            students.append({
                "name": parts[0],
                "surname": parts[1],
                "class": parts[2],
                "grades": grades,
            })
    return students
```

Мұнда:
- `f.readline()` – бірінші жолды оқып, «лақтырып тастаймыз»;
- `len(parts) != 6` – бос жолдарды және толық емес жолдарды елемейміз;
- бағалар `int()` арқылы санға айналады.

## 6. Есеп файлын әдемі пішімдеу

f-жолдардағы туралау кесте жасауға көмектеседі:

| Жазылуы | Мағынасы |
|---|---|
| `{name:<12}` | 12 орын, сол жаққа туралау |
| `{num:>5}` | 5 орын, оң жаққа туралау |
| `{avg:.2f}` | 2 ондық белгі |
| `{"=" * 30}` | 30 рет қайталанған таңба |

```python
name = "Айгерім"
avg = 4.6667
print(f"|{name:<12}|{avg:>6.2f}|")
print(f"|{'Ерасыл':<12}|{3.6667:>6.2f}|")
```

Нәтижесі:
```text
|Айгерім     |  4.67|
|Ерасыл      |  3.67|
```

Осы тәсілдерден құралған есеп жазу функциясы:

```python
def average(grades):
    return sum(grades) / len(grades)

def write_report(students, file_name):
    with open(file_name, "w", encoding="utf-8") as f:
        print("=" * 30, file=f)
        for s in sorted(students, key=lambda s: average(s["grades"]), reverse=True):
            print(f"{s['name']:<12}{s['class']:<5}{average(s['grades']):>6.2f}", file=f)
        print("=" * 30, file=f)

write_report([{"name": "Дана", "class": "7Ә", "grades": [5, 4, 5]}], "report.txt")
```

## 7. Қателерге төзімділік

Нағыз деректер файлдары жиі «лас» болады: бос жолдар, артық бос орын, баға орнына «н» (келмеді), файлдың өзі жоқ болуы. Сенімді бағдарлама:
- файл жоқ болса – түсінікті хабарлама беріп, жұмысын тоқтатуы;
- бүлінген жолды өткізіп жіберіп, оның нөмірін хабарлауы тиіс.

```python
line = "Әлия;Бекова;7А;3;н;4"
parts = line.split(";")
try:
    grades = [int(parts[3]), int(parts[4]), int(parts[5])]
except ValueError:
    print("Бүлінген жол өткізілді:", line)
```

Нәтижесі:
```text
Бүлінген жол өткізілді: Әлия;Бекова;7А;3;н;4
```

## 8. Бағдарламаны тексеру (тестілеу)

Файлдарды өңдейтін бағдарламаны тексеру:
1. Бір оқушының орташа бағасын **қолмен** есептеп, бағдарлама нәтижесімен салыстыр.
2. Файлға бос жол және қате жол қосып, бағдарламаның құламайтынын тексер.
3. Файл атауын әдейі қате жазып, хабарламаны тексер.
4. `report.txt` файлын Блокнотта ашып, қазақ әріптерінің дұрыс көрінетінін тексер.

## Жиі кездесетін қателер

**1. Тақырып жолын деректер ретінде оқу** → `int("Математика")` – `ValueError`. Шешімі: `f.readline()` арқылы бірінші жолды өткізу.

**2. `strip()`-ті ұмыту** → соңғы баға `"5\n"` болады; `int()` мұны көтереді, бірақ соңғы өріс мәтін болса (`"7А\n"`), салыстыру дұрыс жұмыс істемейді.

**3. Бүтін бөлу немесе дөңгелектеу қатесі.** `//` емес, `/` қолдан; шығарғанда `:.2f` пішімін қолдан.

**4. Есепті `a` режимімен жазу** → әр іске қосқанда есеп қайталанып, файл ұзара береді. Есеп үшін – `w`.

**5. Барлық кодты бір блокқа жазу.** Қате қай жерде екенін табу қиын. Функцияларға бөл.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Кіріс файлы | Бағдарлама оқитын деректер файлы |
| Шығыс файлы | Бағдарлама нәтижені жазатын файл |
| Тақырып жолы | Бағандар атаулары жазылған бірінші жол |
| Бөлгіш | Өрістерді ажырататын таңба (`;`, `,`, `\t`) |
| Жазба / өріс | Файлдың бір жолы / жолдың бір бөлігі |
| CSV | Кестелік деректердің мәтіндік форматы |
| Сүзу (фильтр) | Шартқа сай жазбаларды таңдау |
| Есеп (отчёт) | Өңделген нәтижелердің пішімделген түрі |

## Ескерту

- Нағыз CSV файлдары үшін `csv` модулін қолдан: `csv.reader(f, delimiter=";")` немесе `csv.DictReader` ішінде бөлгіш кездесетін тырнақшадағы өрістерді дұрыс өңдейді. `csv` үшін файл `newline=""` арқылы ашылады.
- Орыс/қазақ локаліндегі Excel CSV-ді `;` бөлгішімен және көбіне `cp1251` немесе BOM-мен UTF-8 (`utf-8-sig`) кодтауында сақтайды – оқығанда мұны ескеру керек.
- `sorted(..., key=...)` бастапқы тізімді өзгертпейді, ал `list.sort(key=...)` орнында сұрыптайды. Бірнеше белгі бойынша сұрыптау үшін кілт кортеж қайтара алады: `key=lambda s: (s["class"], s["surname"])`.
- `float`-тың екілік көрінісіне байланысты `round(2.675, 2)` нәтижесі `2.67` болады; шығару үшін `:.2f` пішімі сенімдірек, ал дәл есептеулер үшін – `decimal` модулі.
- Нөлге бөлуден қорғау: бағасы жоқ оқушыда `len(grades) == 0` – мұндай жазбаны алдын ала өткізіп жіберген жөн.
- Құжаттама: [csv – CSV оқу және жазу](https://docs.python.org/3/library/csv.html), [Format Specification Mini-Language](https://docs.python.org/3/library/string.html#formatspec).
