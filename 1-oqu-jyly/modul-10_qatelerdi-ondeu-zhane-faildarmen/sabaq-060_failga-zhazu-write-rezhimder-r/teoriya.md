## 1. Файлды ашу режимдері

`open(атауы, режим, encoding="utf-8")` – екінші аргумент файлмен **не істейтінімізді** анықтайды.

| Режим | Атауы | Файл жоқ болса | Файл бар болса | Курсор |
|---|---|---|---|---|
| `"r"` | read – оқу (әдепкі) | `FileNotFoundError` | Оқиды | Басында |
| `"w"` | write – жазу | **Жаңасын құрады** | **Ескі мазмұнын өшіреді!** | Басында |
| `"a"` | append – қосып жазу | Жаңасын құрады | Соңына қосады | Соңында |
| `"x"` | exclusive – тек жаңа | Жаңасын құрады | `FileExistsError` | Басында |
| `"r+"` | оқу және жазу | `FileNotFoundError` | Оқиды да, жазады | Басында |

Ең жиі қолданылатын үш режим: **`r`, `w`, `a`**.

**Аналогия – дәптер.**
- `r` – дәптерді тек **оқу** үшін ашасың, ештеңе жазбайсың.
- `w` – дәптердің барлық бетін **жыртып тастап**, таза парақтан жаза бастайсың.
- `a` – дәптердің **соңғы жазуынан кейін** жалғастырып жазасың.

> **Абай бол!** `"w"` режимі файлдағы бұрынғы деректерді ескертусіз **өшіреді**. Маңызды файлды `w` режимімен ашпас бұрын ойлан.

## 2. write() әдісі

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Сәлем, файл!")
    f.write("Бұл – екінші сөйлем.")
print("Файл жазылды.")
```

Нәтижесі (экранда):
```text
Файл жазылды.
```

`hello.txt` файлының мазмұны:
```text
Сәлем, файл!Бұл – екінші сөйлем.
```

Байқадың ба? Сөйлемдер **жабысып қалды**. `print()`-тен айырмашылығы – `write()` жол соңына `\n` **қоймайды**. Оны өзіміз жазуымыз керек:

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Сәлем, файл!\n")
    f.write("Бұл – екінші сөйлем.\n")
```

`hello.txt`:
```text
Сәлем, файл!
Бұл – екінші сөйлем.
```

### write() тек жол қабылдайды

```python
score = 95
with open("score.txt", "w", encoding="utf-8") as f:
    # f.write(score)  -> TypeError: write() argument must be str, not int
    f.write(str(score) + "\n")
    f.write(f"Ойыншы: Әлихан, ұпай: {score}\n")
```

`score.txt`:
```text
95
Ойыншы: Әлихан, ұпай: 95
```

`write()` жазылған **таңбалар санын** қайтарады (әдетте оны елемейміз): `n = f.write("abc")` → `n = 3`.

### Тізімді файлға жазу

```python
fruits = ["алма", "өрік", "шие", "жүзім"]
with open("fruits.txt", "w", encoding="utf-8") as f:
    for fruit in fruits:
        f.write(fruit + "\n")
```

`fruits.txt`:
```text
алма
өрік
шие
жүзім
```

## 3. «w» режимі ескі мазмұнды өшіреді

```python
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Бірінші жазба\n")

with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Екінші жазба\n")

with open("test.txt", encoding="utf-8") as f:
    print(f.read())
```

Нәтижесі:
```text
Екінші жазба

```

«Бірінші жазба» жоғалды! Себебі екінші рет `w` режимімен ашқанда файл тазартылды.

## 4. «a» режимі – соңына қосу

```python
with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("Бүгін файлға жазуды үйрендім.\n")

with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("a режимі соңына қосып жазады.\n")

with open("diary.txt", encoding="utf-8") as f:
    print(f.read())
```

Нәтижесі (бағдарламаны бірінші рет іске қосқанда):
```text
Бүгін файлға жазуды үйрендім.
a режимі соңына қосып жазады.

```

Бағдарламаны **екінші рет** іске қоссаң, жолдар **қайталанып** қосылады – файл ұзара береді. Бұл журнал (лог), күнделік, тарих сақтау үшін өте ыңғайлы.

### Мысал: калькулятор тарихы

```python
a = float(input("a = "))
b = float(input("b = "))
result = a * b
print("Көбейтінді:", result)

with open("history.txt", "a", encoding="utf-8") as f:
    f.write(f"{a} * {b} = {result}\n")
print("Есептеу тарихқа сақталды.")
```

Нәтижесі:
```text
a = 2.5
b = 4
Көбейтінді: 10.0
Есептеу тарихқа сақталды.
```

## 5. writelines() және print(file=...)

`writelines(тізім)` – тізімдегі барлық жолдарды **қатарынан** жазады (бұл да `\n` қоспайды!):

```python
lines = ["Дүйсенбі – Python\n", "Сәрсенбі – Python\n", "Жұма – шахмат\n"]
with open("schedule.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

Егер тізімде `\n` жоқ болса, жолдың `join()` әдісі көмектеседі:

```python
days = ["Дүйсенбі", "Сейсенбі", "Сәрсенбі"]
with open("days.txt", "w", encoding="utf-8") as f:
    f.write("\n".join(days) + "\n")
```

**`print()` функциясы файлға да жаза алады!** `file=` параметрін көрсетсең болды. Бұл ең ыңғайлы тәсіл: сандарды өзі жолға айналдырады, `\n`-ді өзі қосады, `sep` және `end` жұмыс істейді.

```python
name = "Аружан"
math_grade = 5
with open("report.txt", "w", encoding="utf-8") as f:
    print("ОҚУШЫ ЕСЕБІ", file=f)
    print("Аты:", name, file=f)
    print("Математика:", math_grade, file=f)
    print("-" * 20, file=f)
```

`report.txt`:
```text
ОҚУШЫ ЕСЕБІ
Аты: Аружан
Математика: 5
--------------------
```

| Тәсіл | `\n` қосады ма? | Сан қабылдай ма? |
|---|---|---|
| `f.write(s)` | Жоқ | Жоқ (тек `str`) |
| `f.writelines(list)` | Жоқ | Жоқ (тек жолдар тізімі) |
| `print(..., file=f)` | Иә | Иә |

## 6. Сақтау және жүктеу (оқу + жазу бірге)

Нағыз бағдарламаларда деректер **іске қосқанда жүктеледі**, жұмыс соңында **сақталады**.

### Мысал: ойындағы рекорд

```python
# 1. Рекордты жүктеу
try:
    with open("record.txt", encoding="utf-8") as f:
        record = int(f.read())
except (FileNotFoundError, ValueError):
    record = 0          # файл әлі жоқ немесе бүлінген
print("Қазіргі рекорд:", record)

# 2. Ойын (қарапайым нұсқа)
score = int(input("Осы ойындағы ұпайың: "))

# 3. Жаңа рекорд болса – сақтау
if score > record:
    with open("record.txt", "w", encoding="utf-8") as f:
        f.write(str(score))
    print("Құттықтаймыз! Жаңа рекорд сақталды!")
else:
    print("Рекорд өзгерген жоқ.")
```

Нәтижесі (бірінші іске қосу):
```text
Қазіргі рекорд: 0
Осы ойындағы ұпайың: 120
Құттықтаймыз! Жаңа рекорд сақталды!
```

Нәтижесі (екінші іске қосу):
```text
Қазіргі рекорд: 120
Осы ойындағы ұпайың: 90
Рекорд өзгерген жоқ.
```

### Мысал: сөздікті файлға сақтау

Сөздікті «кілт;мән» түрінде сақтап, қайта оқимыз:

```python
phones = {"Анам": "+7 701 111 2233", "Әкем": "+7 777 444 5566"}

# Сақтау
with open("phones.txt", "w", encoding="utf-8") as f:
    for name, number in phones.items():
        f.write(f"{name};{number}\n")

# Жүктеу
loaded = {}
with open("phones.txt", encoding="utf-8") as f:
    for line in f:
        name, number = line.strip().split(";")
        loaded[name] = number
print(loaded)
```

Нәтижесі:
```text
{'Анам': '+7 701 111 2233', 'Әкем': '+7 777 444 5566'}
```

Бөлгіш ретінде мәтінде кездеспейтін таңбаны таңда (`;`, `|`, табуляция `\t`). Мұндай міндеттер үшін стандартты кітапханада «стандартты» форматтарға арналған дайын модульдер бар: `csv` және `json`.

## 7. Жазу кезіндегі қателерді өңдеу

Файлға жазу да сәтсіз болуы мүмкін: папка жоқ, файл тек оқуға арналған, диск толы. Мұндай жағдайлар `OSError` тобына жатады (`FileNotFoundError`, `PermissionError` т.б. – соның түрлері):

```python
try:
    with open("жоқ_папка/out.txt", "w", encoding="utf-8") as f:
        f.write("тест")
except OSError as e:
    print("Файлға жазу мүмкін болмады:", e)
```

Нәтижесі:
```text
Файлға жазу мүмкін болмады: [Errno 2] No such file or directory: 'жоқ_папка/out.txt'
```

## Жиі кездесетін қателер

**1. Санды тікелей жазу.**

```python
total = 1500
with open("sum.txt", "w", encoding="utf-8") as f:
    f.write(str(total))          # f.write(total) -> TypeError
```

**2. `\n`-ді ұмыту** – барлық деректер бір жолға жабысады. `write()` қолдансаң, соңына `"\n"` қос немесе `print(..., file=f)` пайдалан.

**3. `a` орнына `w` қолдану.** Тарих/журнал әр іске қосқанда өшіп отырады. Деректі **жинау** керек болса – `a`, **қайта жазу** керек болса – `w`.

**4. `r` режимімен ашып жазуға тырысу.**

```python
try:
    with open("hello.txt", "r", encoding="utf-8") as f:
        f.write("тест")
except Exception as e:
    print(type(e).__name__, e)   # UnsupportedOperation: not writable
```

**5. Бір файлды бір мезетте `r` және `w`-мен ашу.** `w` файлды бірден тазартады, сондықтан оқитын ештеңе қалмайды. Алдымен **толық оқып**, жабу, содан кейін ғана `w`-мен ашу керек.

**6. Файлды жаппау** (`with`-сіз жұмыс). `close()` шақырылмаса, деректердің бір бөлігі дискіге жазылмай қалуы мүмкін. Әрқашан `with` қолдан.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Режим (mode) | Файлмен не істейтінімізді анықтайтын жол: `r`, `w`, `a`, `x`, `r+` |
| `"r"` | Оқу; файл болуы міндетті |
| `"w"` | Жазу; файлды құрады немесе тазартады |
| `"a"` | Қосып жазу; файл соңына қосады |
| `write(s)` | Жолды файлға жазады, `\n` қоспайды |
| `writelines(list)` | Жолдар тізімін жазады |
| `print(..., file=f)` | Шығысты экранға емес, файлға бағыттайды |
| Сақтау / жүктеу | Деректі файлға жазу / файлдан қайта оқу |
| `OSError` | Файл жүйесімен байланысты қателердің жалпы түрі |

## Ескерту

- `write()`-қа берілген деректер алдымен буферге түседі де, файл жабылғанда немесе `f.flush()` шақырылғанда дискіге жазылады. Сондықтан `with`/`close()` болмаса, бағдарлама апатты аяқталғанда деректің бір бөлігі жоғалуы мүмкін.
- `"x"` режимі бар файлды кездейсоқ қайта жазып жібермеу үшін ыңғайлы: файл бұрыннан бар болса, `FileExistsError` шығады.
- Мәтіндік режимде Windows-та жазу кезінде `\n` автоматты түрде `\r\n`-ге айналады. Мұны `open()` функциясының `newline` параметрімен басқаруға болады (`csv` модулі үшін `newline=""` ұсынылады).
- Жолды бүтіндей жазудың қысқа тәсілі: `pathlib` модуліндегі `Path("out.txt").write_text(text, encoding="utf-8")` (файлды `"w"` режимі сияқты қайта жазады).
- Сөздіктер мен тізімдерді сақтау үшін `json` модулі ыңғайлырақ: `json.dump(data, f, ensure_ascii=False, indent=2)` – сонда кирилл әріптері оқылатын күйде сақталады.
- Құжаттама: [open() – режимдер](https://docs.python.org/3/library/functions.html#open), [io – ағындармен жұмыс](https://docs.python.org/3/library/io.html).
