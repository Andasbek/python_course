## 1. Режимы открытия файла

`open(имя, режим, encoding="utf-8")` – второй аргумент определяет, **что мы делаем** с файлом.

| Режим | Название | Если файла нет | Если файл есть | Курсор |
|---|---|---|---|---|
| `"r"` | read – чтение (по умолчанию) | `FileNotFoundError` | Читает | В начале |
| `"w"` | write – запись | **Создаёт новый** | **Стирает старое содержимое!** | В начале |
| `"a"` | append – дозапись | Создаёт новый | Добавляет в конец | В конце |
| `"x"` | exclusive – только новый | Создаёт новый | `FileExistsError` | В начале |
| `"r+"` | чтение и запись | `FileNotFoundError` | Читает и записывает | В начале |

Чаще всего используются три режима: **`r`, `w`, `a`**.

**Аналогия – тетрадь.**
- `r` – открываешь тетрадь только **почитать**, ничего не пишешь.
- `w` – **вырываешь** все страницы тетради и начинаешь писать с чистого листа.
- `a` – продолжаешь писать **после последней записи** в тетради.

> **Осторожно!** Режим `"w"` без предупреждения **стирает** прежние данные в файле. Подумай, прежде чем открывать важный файл в режиме `w`.

## 2. Метод write()

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Привет, файл!")
    f.write("Это – второе предложение.")
print("Файл записан.")
```

Результат (на экране):
```text
Файл записан.
```

Содержимое файла `hello.txt`:
```text
Привет, файл!Это – второе предложение.
```

Заметил? Предложения **слиплись**. В отличие от `print()`, `write()` **не ставит** `\n` в конце строки. Его нужно писать самим:

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Привет, файл!\n")
    f.write("Это – второе предложение.\n")
```

`hello.txt`:
```text
Привет, файл!
Это – второе предложение.
```

### write() принимает только строки

```python
score = 95
with open("score.txt", "w", encoding="utf-8") as f:
    # f.write(score)  -> TypeError: write() argument must be str, not int
    f.write(str(score) + "\n")
    f.write(f"Игрок: Алихан, баллы: {score}\n")
```

`score.txt`:
```text
95
Игрок: Алихан, баллы: 95
```

`write()` возвращает **количество записанных символов** (обычно мы это игнорируем): `n = f.write("abc")` → `n = 3`.

### Запись списка в файл

```python
fruits = ["яблоко", "урюк", "вишня", "виноград"]
with open("fruits.txt", "w", encoding="utf-8") as f:
    for fruit in fruits:
        f.write(fruit + "\n")
```

`fruits.txt`:
```text
яблоко
урюк
вишня
виноград
```

## 3. Режим «w» стирает старое содержимое

```python
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Первая запись\n")

with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Вторая запись\n")

with open("test.txt", encoding="utf-8") as f:
    print(f.read())
```

Результат:
```text
Вторая запись

```

«Первая запись» пропала! Потому что при втором открытии в режиме `w` файл был очищен.

## 4. Режим «a» – добавление в конец

```python
with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("Сегодня я научился записывать в файл.\n")

with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("Режим a дописывает в конец.\n")

with open("diary.txt", encoding="utf-8") as f:
    print(f.read())
```

Результат (при первом запуске программы):
```text
Сегодня я научился записывать в файл.
Режим a дописывает в конец.

```

Если запустить программу **второй раз**, строки добавятся **повторно** – файл будет расти. Это очень удобно для ведения журнала (лога), дневника, истории.

### Пример: история калькулятора

```python
a = float(input("a = "))
b = float(input("b = "))
result = a * b
print("Произведение:", result)

with open("history.txt", "a", encoding="utf-8") as f:
    f.write(f"{a} * {b} = {result}\n")
print("Вычисление сохранено в историю.")
```

Результат:
```text
a = 2.5
b = 4
Произведение: 10.0
Вычисление сохранено в историю.
```

## 5. writelines() и print(file=...)

`writelines(список)` – записывает все строки списка **подряд** (тоже не добавляет `\n`!):

```python
lines = ["Понедельник – Python\n", "Среда – Python\n", "Пятница – шахматы\n"]
with open("schedule.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

Если в списке нет `\n`, поможет метод строк `join()`:

```python
days = ["Понедельник", "Вторник", "Среда"]
with open("days.txt", "w", encoding="utf-8") as f:
    f.write("\n".join(days) + "\n")
```

**Функция `print()` тоже умеет писать в файл!** Достаточно указать параметр `file=`. Это самый удобный способ: числа сам превращает в строки, `\n` добавляет сам, работают `sep` и `end`.

```python
name = "Аружан"
math_grade = 5
with open("report.txt", "w", encoding="utf-8") as f:
    print("ОТЧЁТ ОБ УЧЕНИКЕ", file=f)
    print("Имя:", name, file=f)
    print("Математика:", math_grade, file=f)
    print("-" * 20, file=f)
```

`report.txt`:
```text
ОТЧЁТ ОБ УЧЕНИКЕ
Имя: Аружан
Математика: 5
--------------------
```

| Способ | Добавляет `\n`? | Принимает числа? |
|---|---|---|
| `f.write(s)` | Нет | Нет (только `str`) |
| `f.writelines(list)` | Нет | Нет (только список строк) |
| `print(..., file=f)` | Да | Да |

## 6. Сохранение и загрузка (чтение + запись вместе)

В настоящих программах данные **загружаются при запуске** и **сохраняются** в конце работы.

### Пример: рекорд в игре

```python
# 1. Загрузка рекорда
try:
    with open("record.txt", encoding="utf-8") as f:
        record = int(f.read())
except (FileNotFoundError, ValueError):
    record = 0          # файла ещё нет или он повреждён
print("Текущий рекорд:", record)

# 2. Игра (упрощённый вариант)
score = int(input("Твои баллы в этой игре: "))

# 3. Если новый рекорд – сохранить
if score > record:
    with open("record.txt", "w", encoding="utf-8") as f:
        f.write(str(score))
    print("Поздравляем! Новый рекорд сохранён!")
else:
    print("Рекорд не изменился.")
```

Результат (первый запуск):
```text
Текущий рекорд: 0
Твои баллы в этой игре: 120
Поздравляем! Новый рекорд сохранён!
```

Результат (второй запуск):
```text
Текущий рекорд: 120
Твои баллы в этой игре: 90
Рекорд не изменился.
```

### Пример: сохранение словаря в файл

Сохраняем словарь в виде «ключ;значение» и снова читаем:

```python
phones = {"Мама": "+7 701 111 2233", "Папа": "+7 777 444 5566"}

# Сохранение
with open("phones.txt", "w", encoding="utf-8") as f:
    for name, number in phones.items():
        f.write(f"{name};{number}\n")

# Загрузка
loaded = {}
with open("phones.txt", encoding="utf-8") as f:
    for line in f:
        name, number = line.strip().split(";")
        loaded[name] = number
print(loaded)
```

Результат:
```text
{'Мама': '+7 701 111 2233', 'Папа': '+7 777 444 5566'}
```

В качестве разделителя выбирай символ, который не встречается в тексте (`;`, `|`, табуляция `\t`). Для таких задач в стандартной библиотеке есть готовые модули для «стандартных» форматов: `csv` и `json`.

## 7. Обработка ошибок при записи

Запись в файл тоже может не удаться: папки нет, файл только для чтения, диск заполнен. Такие ситуации относятся к группе `OSError` (`FileNotFoundError`, `PermissionError` и др. – её разновидности):

```python
try:
    with open("нет_папки/out.txt", "w", encoding="utf-8") as f:
        f.write("тест")
except OSError as e:
    print("Не удалось записать в файл:", e)
```

Результат:
```text
Не удалось записать в файл: [Errno 2] No such file or directory: 'нет_папки/out.txt'
```

## Частые ошибки

**1. Запись числа напрямую.**

```python
total = 1500
with open("sum.txt", "w", encoding="utf-8") as f:
    f.write(str(total))          # f.write(total) -> TypeError
```

**2. Забыли `\n`** – все данные слипаются в одну строку. Если используешь `write()`, добавляй в конце `"\n"` или пользуйся `print(..., file=f)`.

**3. Использование `w` вместо `a`.** История/журнал стирается при каждом запуске. Если данные нужно **накапливать** – `a`, если **перезаписывать** – `w`.

**4. Попытка записи в файл, открытый в режиме `r`.**

```python
try:
    with open("hello.txt", "r", encoding="utf-8") as f:
        f.write("тест")
except Exception as e:
    print(type(e).__name__, e)   # UnsupportedOperation: not writable
```

**5. Открытие одного файла одновременно в `r` и `w`.** `w` сразу очищает файл, поэтому читать будет нечего. Сначала нужно **полностью прочитать** и закрыть, и только потом открывать в `w`.

**6. Файл не закрыт** (работа без `with`). Если не вызвать `close()`, часть данных может не записаться на диск. Всегда используй `with`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Режим (mode) | Строка, определяющая, что мы делаем с файлом: `r`, `w`, `a`, `x`, `r+` |
| `"r"` | Чтение; файл обязательно должен существовать |
| `"w"` | Запись; создаёт или очищает файл |
| `"a"` | Дозапись; добавляет в конец файла |
| `write(s)` | Записывает строку в файл, не добавляет `\n` |
| `writelines(list)` | Записывает список строк |
| `print(..., file=f)` | Направляет вывод не на экран, а в файл |
| Сохранение / загрузка | Запись данных в файл / повторное чтение из файла |
| `OSError` | Общий тип ошибок, связанных с файловой системой |

## Примечание

- Данные, переданные в `write()`, сначала попадают в буфер и записываются на диск при закрытии файла или вызове `f.flush()`. Поэтому без `with`/`close()` часть данных может потеряться при аварийном завершении.
- Режим `"x"` удобен, чтобы случайно не перезаписать существующий файл: если файл уже есть, будет `FileExistsError`.
- В текстовом режиме `\n` при записи в Windows автоматически превращается в `\r\n`. Управлять этим можно параметром `newline` функции `open()` (для модуля `csv` рекомендуется `newline=""`).
- Короткий способ записать строку целиком: `Path("out.txt").write_text(text, encoding="utf-8")` из модуля `pathlib` (перезаписывает файл, как режим `"w"`).
- Для сохранения словарей и списков удобнее модуль `json`: `json.dump(data, f, ensure_ascii=False, indent=2)` – тогда кириллица сохранится читаемой.
- Документация: [open() – режимы](https://docs.python.org/3/library/functions.html#open), [io – работа с потоками](https://docs.python.org/3/library/io.html).
