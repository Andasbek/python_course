## 1. Тармақталған алгоритм

**Тармақталған алгоритм** — шарттың орындалу-орындалмауына қарай әрекеттер әртүрлі жолмен жүретін алгоритм.

Өмірлік мысалдар:
- **Егер** жаңбыр жауса, **онда** қолшатыр ал.
- **Егер** телефон заряды 20%-дан аз болса, **онда** зарядқа қой.
- **Егер** бағдаршам қызыл болса, **онда** тоқта.

Бұл сөйлемдердің бәрінде тек бір әрекет бар: шарт орындалса — әрекет жасалады, орындалмаса — **ештеңе** жасалмайды, біз әрі қарай жүре береміз. Мұндай тармақталу **қысқа (толымсыз) тармақталу** деп аталады.

### Блок-схемасы

```text
            ┌──────────────┐
            │  Басы        │
            └──────┬───────┘
                   ▼
              ╱‾‾‾‾‾‾‾‾╲
   иә ◄──── ╱  Шарт?    ╲ ────► жоқ
   │         ╲          ╱        │
   ▼          ╲________╱         │
┌────────────┐                   │
│  Әрекет    │                   │
└─────┬──────┘                   │
      └─────────────┬────────────┘
                    ▼
            ┌──────────────┐
            │  Соңы        │
            └──────────────┘
```

## 2. if операторының синтаксисі

```text
if шарт:
    әрекет_1
    әрекет_2
келесі_команда
```

Ережелері:
1. `if` (ағылш. «егер») кілт сөзі — кіші әріппен.
2. Одан кейін — **шарт** (логикалық өрнек).
3. Шарттан кейін — **қос нүкте** `:` міндетті!
4. Шарт орындалғанда жасалатын командалар **шегініспен** (4 бос орын) жазылады. Бұл — `if` операторының **денесі (блогы)**.
5. Шегініссіз жазылған келесі жол — `if`-ке жатпайды, ол әрқашан орындалады.

```python
temp = int(input("Сыртта неше градус? "))
if temp < 0:
    print("Аяз! Жылы киін, қолғап ал.")
print("Күніңіз сәтті өтсін!")
```

Нәтижесі (−5 енгізсек):
```text
Сыртта неше градус? -5
Аяз! Жылы киін, қолғап ал.
Күніңіз сәтті өтсін!
```

Нәтижесі (12 енгізсек):
```text
Сыртта неше градус? 12
Күніңіз сәтті өтсін!
```

> Аналогия: `if` — есіктегі күзетші. Шарт `True` болса, есік ашылады да ішкі бөлмедегі (шегіністегі) командалар орындалады. `False` болса — бөлмеге кірмей, дәлізбен әрі қарай жүреміз.

## 3. Шегініс (отступ, indentation) — Python-ның ерекшелігі

Көп тілдерде блок `{ }` жақшаларымен белгіленеді. Python-да блокты **шегініс** анықтайды. Сондықтан шегініс — безендіру емес, **синтаксистің бөлігі**.

- Стандарт — **4 бос орын**. IDLE, Thonny, VS Code қос нүктеден кейін Enter басқанда шегіністі өздері қояды.
- Бір блоктағы барлық жолдардың шегінісі **бірдей** болуы керек.
- Блоктан шығу үшін шегіністі алып тастаймыз (Backspace).

```python
ball = int(input("Ойындағы ұпайыңыз: "))
if ball >= 100:
    print("Құттықтаймыз!")          # блок ішінде
    print("Сіз жаңа деңгейге өттіңіз!")  # блок ішінде
    ball = ball + 50                 # блок ішінде: бонус
print("Ұпайыңыз:", ball)             # блоктан тыс — әрқашан орындалады
```

Нәтижесі (120 енгізсек):
```text
Ойындағы ұпайыңыз: 120
Құттықтаймыз!
Сіз жаңа деңгейге өттіңіз!
Ұпайыңыз: 170
```

Нәтижесі (80 енгізсек):
```text
Ойындағы ұпайыңыз: 80
Ұпайыңыз: 80
```

## 4. Шарттар — кез келген логикалық өрнек

Шарт ретінде кез келген логикалық өрнекті — салыстыруды, бөлінгіштікті тексеруді, тізбекті салыстыруды қолдана аламыз:

```python
n = int(input("Сан енгізіңіз: "))
if n % 2 == 0:
    print(n, "— жұп сан")
if n > 0:
    print(n, "— оң сан")
if n == 0:
    print("Бұл — нөл")
if n % 5 == 0:
    print(n, "5-ке бөлінеді")
```

Нәтижесі (10 енгізсек):
```text
Сан енгізіңіз: 10
10 — жұп сан
10 — оң сан
10 5-ке бөлінеді
```

Бұл бағдарламада **төрт тәуелсіз** `if` бар: әрқайсысы өз бетінше тексеріледі, сондықтан бірнеше хабарлама шығуы мүмкін.

### Жолдармен шарт

```python
jauap = input("Қазақстанның астанасы қай қала? ")
if jauap == "Астана":
    print("Дұрыс! +1 ұпай")
```

### Логикалық айнымалы шарт ретінде

```python
jas = int(input("Жасыңыз: "))
eresek = jas >= 18
if eresek:
    print("Сіз сайлауға қатыса аласыз.")
```

`if eresek:` жазуы `if eresek == True:` дегенмен бірдей, бірақ қысқа әрі «Python стилінде».

### Тізбекті салыстыру шарт ретінде

```python
bal = int(input("Тесттен алған балыңыз (0–100): "))
if 85 <= bal <= 100:
    print("Керемет нәтиже!")
```

## 5. Шартқа байланысты мәнді өзгерту

`if` көбіне айнымалының мәнін өзгерту үшін қолданылады. Мысалы, **жеңілдік есептеу**:

```python
soma = int(input("Сатып алу сомасы (теңге): "))
if soma >= 10000:
    soma = soma - soma * 10 // 100   # 10% жеңілдік
    print("Сізге 10% жеңілдік берілді!")
print("Төлеуге:", soma, "теңге")
```

Нәтижесі (15000 енгізсек):
```text
Сатып алу сомасы (теңге): 15000
Сізге 10% жеңілдік берілді!
Төлеуге: 13500 теңге
```

Тағы бір классикалық мысал — **санның модулі** (абсолют шамасы):

```python
x = int(input("x = "))
if x < 0:
    x = -x
print("|x| =", x)
```

Нәтижесі (−7 енгізсек):
```text
x = -7
|x| = 7
```

### Екі санның үлкенін табу (тек if-пен)

```python
a = int(input("a = "))
b = int(input("b = "))
ulken = a           # әзірге a-ны үлкен деп есептейміз
if b > ulken:
    ulken = b       # b үлкен болса — ауыстырамыз
print("Үлкені:", ulken)
```

Бұл тәсіл — «**болжа да, тексер**» — бірнеше санның ең үлкенін табу үшін өте ыңғайлы: әр келесі санға тағы бір `if` қосылады.

## 6. Бір жолдық if

Блокта бір ғана қысқа команда болса, оны бір жолға жазуға болады:

```python
n = 7
if n > 0: print("оң")
```

Алайда PEP 8 стиль нұсқаулығы мұндай жазуды ұсынбайды: денені **әрқашан бөлек жолға** шегініспен жазған дұрыс — код оқуға жеңіл болады және оған команда қосу оңай.

## 7. if және turtle

```python
import turtle

tus = input("Қандай фигура саламыз? (шаршы/шеңбер): ")
t = turtle.Turtle()
if tus == "шаршы":
    t.forward(100)
    t.left(90)
    t.forward(100)
    t.left(90)
    t.forward(100)
    t.left(90)
    t.forward(100)
if tus == "шеңбер":
    t.circle(60)
turtle.done()
```

## Жиі кездесетін қателер

**1. Қос нүкте ұмытылады.**

```text
if n > 0
    print("оң")
# SyntaxError: expected ':'
```

**2. Шегініс жоқ.**

```text
if n > 0:
print("оң")
# IndentationError: expected an indented block after 'if' statement
```

**3. Бір блокта шегініс әртүрлі.**

```text
if n > 0:
    print("оң")
      print("сан")
# IndentationError: unexpected indent
```

**4. Шартта `=` жазу.**

```text
if n = 5:
    print("бес")
# SyntaxError: invalid syntax. Maybe you meant '==' ...
```

Дұрыс түрі:

```python
n = 5
if n > 0:
    print("оң")
    print("сан")
if n == 5:
    print("бес")
```

**5. Логикалық қате: шегіністен тыс қалған жол.** Синтаксис дұрыс, бірақ нәтиже қате:

```python
ball = 40
if ball >= 50:
    print("Сынақтан өттіңіз!")
print("Сертификат беріледі")   # ҚАТЕ ОЙ: бұл жол ball=40 болса да шығады!
```

Сертификат туралы жол да шегініспен жазылуы керек еді.

**6. Таб пен бос орынды араластыру.** Бір файлда тек бос орын қолданыңыз (редакторлар Tab-ты автоматты түрде 4 бос орынға айналдырады).

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Тармақталған алгоритм | Шартқа байланысты әртүрлі жолмен жүретін алгоритм |
| Қысқа (толымсыз) тармақталу | Шарт орындалса ғана әрекет жасалады, әйтпесе ештеңе |
| `if` | «Егер» — шартты оператор |
| Шарт | `if`-тен кейінгі логикалық өрнек |
| Блок (дене) | Шарт орындалғанда жасалатын командалар тобы |
| Шегініс (отступ) | Жол басындағы 4 бос орын, блокты анықтайды |
| `IndentationError` | Шегініс қатесі |

## Ескерту

- Шарт тек `bool` болуы міндетті емес: Python кез келген мәннің «ақиқаттығын» тексереді. `0`, `0.0`, бос жол `""`, `None`, бос жинақтар (`[]`, `{}`) жалған саналады; қалғанының бәрі — ақиқат. Мысалы, `if name:` тек `name` жолы бос болмаса ғана орындалады.
- `if` денесі бос бола алмайды. Код әлі жазылмаса, `pass` бітеуішін қолданыңыз: `if x > 0:` және келесі жолда шегініспен `pass`.
- PEP 8 әр деңгейге 4 бос орын шегініс талап етеді және таб пен бос орынды араластыруға тыйым салады; Python 3-те мұндай араластыру `TabError` тудырады.
- `if flag == True:` деп жазбаңыз — `if flag:` жеткілікті; `None`-ға тексеру үшін `if x is None:` қолданыңыз.
- Python 3.10+ нұсқаларында қате хабарламалары толығырақ: мысалы, `SyntaxError: expected ':'` қос нүктенің жоқ екенін тікелей көрсетеді.
- Құжаттама: https://docs.python.org/3/reference/compound_stmts.html#the-if-statement
