# Урок 20. Практические задания: оператор if

> На этом уроке используем только `if` (`else` — на следующем уроке). Проверяйте каждую программу хотя бы на двух разных значениях: когда условие выполняется и когда не выполняется.

## Базовый уровень

### Задание 1. «Отрицательное число»
Пользователь вводит число. Если число отрицательное, выведите «Вы ввели отрицательное число». В конце программы всегда должно выводиться «Программа завершена».

```text
Число: -4
Вы ввели отрицательное число
Программа завершена
```

### Задание 2. «Заряд телефона»
Вводится уровень заряда (0–100). Если ниже 20%: «Подключите зарядку!». Если 100%: «Полностью заряжено, отключите зарядное устройство». Используйте два независимых `if`.

### Задание 3. «Загадка»
Программа загадывает загадку: «Ног нет, а ходит; рук нет, а рисует. Что это?» (Ответ: «карандаш»). Если пользователь отвечает правильно: «Верно! Ты сообразительный!».

### Задание 4. «Скидка»
В кинотеатре билет стоит 2500 тенге. Если зрителю меньше 12 лет (12 лет не включается), цена — 1500 тенге. Введите возраст и выведите сумму к оплате (только с `if`: сначала `baga = 2500`, затем измените по условию).

```text
Ваш возраст: 9
Цена билета: 1500 тенге
```

### Задание 5. «Делимость»
Пользователь вводит целое число. Программа отдельно проверяет, делится ли число на 2, на 3, на 5, и выводит сообщения только о выполненных условиях.

```text
Число: 15
Число 15 делится на 3
Число 15 делится на 5
```

## Продвинутый уровень

### Задание 6. «Наибольшее из трёх чисел»
Вводятся три целых числа. Найдите наибольшее приёмом «предположи и проверь» (только `if`).

```text
a = 4
b = 11
c = 7
Наибольшее: 11
```

### Задание 7. «Стоимость доставки»
В интернет-магазине, если сумма заказа меньше 5000 тенге, добавляется плата за доставку 800 тенге. Если сумма заказа 20000 тенге и больше — предоставляется скидка 5%. Выведите итоговую сумму оплаты.

### Задание 8. «Два числа по возрастанию»
Вводятся два числа. Если первое число больше второго, поменяйте их местами (`a, b = b, a`). Затем выведите числа в порядке возрастания.

## ★ Олимпиадная / творческая задача

### Задание 9. «Часы»
Пользователь вводит количество секунд (например, 3725). Программа переводит его в часы, минуты, секунды. Но части, равные нулю, **не выводятся**:

```text
Секунды: 3725
1 ч
2 мин
5 сек
```

```text
Секунды: 120
2 мин
```

### Задание 10. «Светофор на turtle»
Пользователь вводит цвет (`красный`, `жёлтый`, `зелёный`). Черепашка рисует круг только этого цвета и с помощью `write` пишет под ним правило: «Стой!», «Приготовься!», «Иди!».

## Домашнее задание

1. Переведите на Python 3 жизненные ситуации вида «Если …, то …» (каждую с `input`).
2. Программа: в магазине 1 кг яблок стоит 650 тенге. Пользователь вводит, сколько кг он покупает. Если больше 5 кг, каждый кг считается по 550 тенге. Выведите сумму.

**Задание 10.**

```python
import turtle

tus = input("Цвет светофора (красный/жёлтый/зелёный): ").lower()
t = turtle.Turtle()
t.hideturtle()
t.penup()
t.goto(0, -60)
t.pendown()
if tus == "красный":
    t.color("red", "red")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Стой!", align="center", font=("Arial", 18, "bold"))
if tus == "жёлтый":
    t.color("gold", "yellow")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Приготовься!", align="center", font=("Arial", 18, "bold"))
if tus == "зелёный":
    t.color("green", "green")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Иди!", align="center", font=("Arial", 18, "bold"))
turtle.done()
```
