# Сабақ 20. Практикалық тапсырмалар: if операторы

> Бұл сабақта тек `if` қолданамыз (`else` — келесі сабақта). Әр бағдарламаны кемінде екі түрлі мәнмен тексеріңіз: шарт орындалатын және орындалмайтын.

## Базалық деңгей

### 1-тапсырма. «Теріс сан»
Пайдаланушы сан енгізеді. Егер сан теріс болса, «Сіз теріс сан енгіздіңіз» деп шығарыңыз. Бағдарлама соңында әрқашан «Бағдарлама аяқталды» деп шықсын.

```text
Сан: -4
Сіз теріс сан енгіздіңіз
Бағдарлама аяқталды
```

### 2-тапсырма. «Телефон заряды»
Заряд деңгейі (0–100) енгізіледі. 20%-дан төмен болса: «Зарядты қосыңыз!». 100% болса: «Толық зарядталды, зарядтағышты ажыратыңыз». Екі тәуелсіз `if` қолданыңыз.

### 3-тапсырма. «Жұмбақ»
Бағдарлама жұмбақ айтады: «Аяғы жоқ, жүреді; қолы жоқ, сызады. Бұл не?» (Жауабы: «қалам»). Пайдаланушы дұрыс жауап берсе: «Дұрыс! Тапқырсың!».

### 4-тапсырма. «Жеңілдік»
Кинотеатрда билет бағасы 2500 теңге. Егер көрермен 12 жасқа дейін болса (12 жасты қоспағанда), баға 1500 теңге болады. Жасты енгізіп, төлейтін соманы шығарыңыз (тек `if` арқылы: алдымен `baga = 2500`, сосын шартпен өзгертіңіз).

```text
Жасыңыз: 9
Билет бағасы: 1500 теңге
```

### 5-тапсырма. «Бөлінгіштік»
Пайдаланушы бүтін сан енгізеді. Бағдарлама сан 2-ге, 3-ке, 5-ке бөлінетінін жеке-жеке тексеріп, тек орындалған шарттар туралы хабарлама шығарады.

```text
Сан: 15
15 саны 3-ке бөлінеді
15 саны 5-ке бөлінеді
```

## Кеңейтілген деңгей

### 6-тапсырма. «Үш санның ең үлкені»
Үш бүтін сан енгізіледі. «Болжа да, тексер» тәсілімен (тек `if`) ең үлкенін табыңыз.

```text
a = 4
b = 11
c = 7
Ең үлкені: 11
```

### 7-тапсырма. «Жеткізу ақысы»
Интернет-дүкенде тапсырыс сомасы 5000 теңгеден аз болса, 800 теңге жеткізу ақысы қосылады. Тапсырыс сомасы 20000 теңге және одан көп болса — 5% жеңілдік беріледі. Соңғы төлем сомасын шығарыңыз.

### 8-тапсырма. «Екі санды өсу ретімен»
Екі сан енгізіледі. Егер бірінші сан екіншісінен үлкен болса, олардың орнын ауыстырыңыз (`a, b = b, a`). Сосын сандарды өсу ретімен шығарыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Сағат»
Пайдаланушы секунд санын енгізеді (мысалы, 3725). Бағдарлама оны сағат, минут, секундқа айналдырады. Бірақ нөлге тең бөліктер **шығарылмайды**:

```text
Секунд: 3725
1 сағат
2 минут
5 секунд
```

```text
Секунд: 120
2 минут
```

### 10-тапсырма. «Turtle бағдаршамы»
Пайдаланушы түсті енгізеді (`қызыл`, `сары`, `жасыл`). Тасбақа тек сол түсті шеңберді салып, астына `write` арқылы ережені жазады: «Тоқта!», «Дайындал!», «Жүр!».

## Үй тапсырмасы

1. «Егер … онда …» құрылымындағы 3 өмірлік жағдайды Python-ға аударыңыз (әрқайсысы `input`-пен).
2. Бағдарлама: дүкенде алма 1 кг — 650 теңге. Пайдаланушы неше кг алатынын енгізеді. 5 кг-нан көп алса, әр кг 550 теңгеден есептеледі. Соманы шығарыңыз.

**9-тапсырма.**

```python

if sagat > 0:
    print(sagat, "сағат")
if minut > 0:
    print(minut, "минут")
if sek > 0:
    print(sek, "секунд")
```

**10-тапсырма.**

```python
import turtle

tus = input("Бағдаршам түсі (қызыл/сары/жасыл): ").lower()
t = turtle.Turtle()
t.hideturtle()
t.penup()
t.goto(0, -60)
t.pendown()
if tus == "қызыл":
    t.color("red", "red")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Тоқта!", align="center", font=("Arial", 18, "bold"))
if tus == "сары":
    t.color("gold", "yellow")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Дайындал!", align="center", font=("Arial", 18, "bold"))
if tus == "жасыл":
    t.color("green", "green")
    t.begin_fill()
    t.circle(60)
    t.end_fill()
    t.penup()
    t.goto(0, -100)
    t.write("Жүр!", align="center", font=("Arial", 18, "bold"))
turtle.done()
```
