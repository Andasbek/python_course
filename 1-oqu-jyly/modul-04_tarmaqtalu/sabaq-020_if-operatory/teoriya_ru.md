## 1. Разветвляющийся алгоритм

**Разветвляющийся алгоритм** — алгоритм, в котором действия идут разными путями в зависимости от того, выполняется условие или нет.

Примеры из жизни:
- **Если** идёт дождь, **то** возьми зонт.
- **Если** заряд телефона меньше 20%, **то** поставь его на зарядку.
- **Если** горит красный свет светофора, **то** остановись.

Во всех этих предложениях только одно действие: если условие выполняется — действие совершается, если нет — **ничего** не делается, и мы идём дальше. Такое ветвление называется **сокращённым (неполным) ветвлением**.

### Блок-схема

```text
            ┌──────────────┐
            │  Начало      │
            └──────┬───────┘
                   ▼
              ╱‾‾‾‾‾‾‾‾╲
   да ◄──── ╱ Условие? ╲ ────► нет
   │         ╲          ╱        │
   ▼          ╲________╱         │
┌────────────┐                   │
│  Действие  │                   │
└─────┬──────┘                   │
      └─────────────┬────────────┘
                    ▼
            ┌──────────────┐
            │  Конец       │
            └──────────────┘
```

## 2. Синтаксис оператора if

```text
if условие:
    действие_1
    действие_2
следующая_команда
```

Правила:
1. Ключевое слово `if` (англ. «если») — строчными буквами.
2. После него — **условие** (логическое выражение).
3. После условия обязательно **двоеточие** `:`!
4. Команды, выполняемые при истинном условии, пишутся **с отступом** (4 пробела). Это **тело (блок)** оператора `if`.
5. Следующая строка без отступа к `if` не относится, она выполняется всегда.

```python
temp = int(input("Сколько градусов на улице? "))
if temp < 0:
    print("Мороз! Одевайся теплее, возьми перчатки.")
print("Хорошего дня!")
```

Результат (если ввести −5):
```text
Сколько градусов на улице? -5
Мороз! Одевайся теплее, возьми перчатки.
Хорошего дня!
```

Результат (если ввести 12):
```text
Сколько градусов на улице? 12
Хорошего дня!
```

> Аналогия: `if` — охранник у двери. Если условие `True`, дверь открывается и выполняются команды во внутренней комнате (с отступом). Если `False` — мы не заходим в комнату и идём дальше по коридору.

## 3. Отступ (indentation) — особенность Python

Во многих языках блок обозначается фигурными скобками `{ }`. В Python блок определяется **отступом**. Поэтому отступ — не украшение, а **часть синтаксиса**.

- Стандарт — **4 пробела**. IDLE, Thonny, VS Code сами ставят отступ, когда после двоеточия нажимаешь Enter.
- Все строки одного блока должны иметь **одинаковый** отступ.
- Чтобы выйти из блока, убираем отступ (Backspace).

```python
ball = int(input("Ваши очки в игре: "))
if ball >= 100:
    print("Поздравляем!")            # внутри блока
    print("Вы перешли на новый уровень!")  # внутри блока
    ball = ball + 50                 # внутри блока: бонус
print("Ваши очки:", ball)            # вне блока — выполняется всегда
```

Результат (если ввести 120):
```text
Ваши очки в игре: 120
Поздравляем!
Вы перешли на новый уровень!
Ваши очки: 170
```

Результат (если ввести 80):
```text
Ваши очки в игре: 80
Ваши очки: 80
```

## 4. Условие — любое логическое выражение

В качестве условия можно использовать любое логическое выражение — сравнение, проверку делимости, цепочку сравнений:

```python
n = int(input("Введите число: "))
if n % 2 == 0:
    print(n, "— чётное число")
if n > 0:
    print(n, "— положительное число")
if n == 0:
    print("Это — ноль")
if n % 5 == 0:
    print(n, "делится на 5")
```

Результат (если ввести 10):
```text
Введите число: 10
10 — чётное число
10 — положительное число
10 делится на 5
```

В этой программе **четыре независимых** `if`: каждый проверяется сам по себе, поэтому может появиться несколько сообщений.

### Условие со строками

```python
jauap = input("Какой город — столица Казахстана? ")
if jauap == "Астана":
    print("Верно! +1 очко")
```

### Логическая переменная как условие

```python
jas = int(input("Ваш возраст: "))
eresek = jas >= 18
if eresek:
    print("Вы можете участвовать в выборах.")
```

Запись `if eresek:` равносильна `if eresek == True:`, но короче и написана «в стиле Python».

### Цепочка сравнений как условие

```python
bal = int(input("Ваш балл за тест (0–100): "))
if 85 <= bal <= 100:
    print("Отличный результат!")
```

## 5. Изменение значения в зависимости от условия

`if` часто используется для изменения значения переменной. Например, **расчёт скидки**:

```python
soma = int(input("Сумма покупки (тенге): "))
if soma >= 10000:
    soma = soma - soma * 10 // 100   # скидка 10%
    print("Вам предоставлена скидка 10%!")
print("К оплате:", soma, "тенге")
```

Результат (если ввести 15000):
```text
Сумма покупки (тенге): 15000
Вам предоставлена скидка 10%!
К оплате: 13500 тенге
```

Ещё один классический пример — **модуль числа** (абсолютная величина):

```python
x = int(input("x = "))
if x < 0:
    x = -x
print("|x| =", x)
```

Результат (если ввести −7):
```text
x = -7
|x| = 7
```

### Поиск большего из двух чисел (только с if)

```python
a = int(input("a = "))
b = int(input("b = "))
ulken = a           # пока считаем большим a
if b > ulken:
    ulken = b       # если b больше — заменяем
print("Большее:", ulken)
```

Этот приём — «**предположи и проверь**» — очень удобен для поиска наибольшего из нескольких чисел: на каждое следующее число добавляется ещё один `if`.

## 6. if в одну строку

Если в блоке только одна короткая команда, её можно записать в одну строку:

```python
n = 7
if n > 0: print("положительное")
```

Однако руководство по стилю PEP 8 не рекомендует такую запись: тело лучше **всегда писать на отдельной строке** с отступом — так код легче читать и в него проще добавлять команды.

## 7. if и turtle

```python
import turtle

tus = input("Какую фигуру рисуем? (квадрат/круг): ")
t = turtle.Turtle()
if tus == "квадрат":
    t.forward(100)
    t.left(90)
    t.forward(100)
    t.left(90)
    t.forward(100)
    t.left(90)
    t.forward(100)
if tus == "круг":
    t.circle(60)
turtle.done()
```

## Частые ошибки

**1. Забыто двоеточие.**

```text
if n > 0
    print("положительное")
# SyntaxError: expected ':'
```

**2. Нет отступа.**

```text
if n > 0:
print("положительное")
# IndentationError: expected an indented block after 'if' statement
```

**3. Разные отступы в одном блоке.**

```text
if n > 0:
    print("положительное")
      print("число")
# IndentationError: unexpected indent
```

**4. `=` в условии.**

```text
if n = 5:
    print("пять")
# SyntaxError: invalid syntax. Maybe you meant '==' ...
```

Правильный вариант:

```python
n = 5
if n > 0:
    print("положительное")
    print("число")
if n == 5:
    print("пять")
```

**5. Логическая ошибка: строка оказалась вне отступа.** Синтаксис верный, но результат неправильный:

```python
ball = 40
if ball >= 50:
    print("Вы сдали зачёт!")
print("Выдаётся сертификат")   # ОШИБКА В ЛОГИКЕ: эта строка выводится даже при ball=40!
```

Строку о сертификате тоже нужно было написать с отступом.

**6. Смешивание табуляции и пробелов.** В одном файле используйте только пробелы (редакторы автоматически превращают Tab в 4 пробела).

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Разветвляющийся алгоритм | Алгоритм, идущий разными путями в зависимости от условия |
| Сокращённое (неполное) ветвление | Действие выполняется, только если условие истинно, иначе — ничего |
| `if` | «Если» — условный оператор |
| Условие | Логическое выражение после `if` |
| Блок (тело) | Группа команд, выполняемых при истинном условии |
| Отступ (indentation) | 4 пробела в начале строки, определяет блок |
| `IndentationError` | Ошибка отступа |

## Примечание

- Условием может быть не только `bool`: Python проверяет «истинность» любого значения. Ложными считаются `0`, `0.0`, пустая строка `""`, `None`, пустые коллекции (`[]`, `{}`); всё остальное — истинно. Например, `if name:` выполнится, только если строка `name` не пустая.
- Тело `if` не может быть пустым. Если код ещё не написан, используйте заглушку `pass`: `if x > 0:` и на следующей строке с отступом `pass`.
- PEP 8 требует 4 пробела на уровень отступа и запрещает смешивать табуляцию с пробелами; в Python 3 такое смешивание вызывает `TabError`.
- Не пишите `if flag == True:` — достаточно `if flag:`; для проверки на `None` используйте `if x is None:`.
- В Python 3.10+ сообщения об ошибках подробнее: например, `SyntaxError: expected ':'` прямо указывает на пропущенное двоеточие.
- Документация: https://docs.python.org/3/reference/compound_stmts.html#the-if-statement
