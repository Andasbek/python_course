# Сабақ 23. Практикалық тапсырмалар: and, or, not

## Базалық деңгей

### 1-тапсырма. «Есепте де тексер»
`a = 7`, `b = 0`, `c = -3` болсын. Әр өрнектің мәнін дәптерде есептеңіз, сосын Python-да тексеріңіз.

```text
1) a > 0 and c > 0
2) a > 0 or c > 0
3) not b == 0
4) a > b and b > c
5) a < 0 or b == 0 and c < 0
6) (a < 0 or b == 0) and c > 0
7) not (a > 5 and c < -5)
```

### 2-тапсырма. «Аралықта ма?»
Пайдаланушы бүтін сан енгізеді. Бағдарлама санның екі таңбалы екенін (10…99 немесе −99…−10 емес, тек оң екі таңбалы) `and` арқылы тексереді.

```text
Сан: 47
47 — екі таңбалы оң сан
```

### 3-тапсырма. «Демалыс күні»
Апта күнінің атауы енгізіледі. «сенбі» немесе «жексенбі» болса — «Демалыс!», әйтпесе — «Жұмыс күні». Енгізуді кіші әріпке келтіріңіз.

### 4-тапсырма. «Тегін жол»
Қоғамдық көлікте 7 жасқа дейінгі балалар және 63 жастан асқан зейнеткерлер тегін жүреді. Жасты енгізіп, жол ақысын шығарыңыз (тегін немесе 200 тг).

### 5-тапсырма. «Жеңімпаз»
Олимпиада кезеңінен өту шарты: теориядан кемінде 60 балл **және** практикадан кемінде 70 балл. Немесе екі балдың қосындысы 160-тан жоғары болса да өтеді. Екі балды енгізіп, нәтижені шығарыңыз.

## Кеңейтілген деңгей

### 6-тапсырма. «Кібісе жыл»
Жылды енгізіп, кібісе екенін бір құрама шартпен анықтаңыз. Сонымен қатар ақпан айында неше күн бар екенін шығарыңыз.

```text
Жыл: 2028
2028 — кібісе жыл, ақпанда 29 күн
```

### 7-тапсырма. «Үшбұрыш»
Үш қабырға енгізіледі. Бағдарлама алдымен мұндай үшбұрыш бар-жоғын тексереді, болса — оның түрін (тең қабырғалы, тең бүйірлі, әртүрлі қабырғалы) анықтайды. Қосымша: Пифагор теоремасы бойынша тікбұрышты екенін де тексеріңіз (кез келген қабырға гипотенуза болуы мүмкін).

### 8-тапсырма. «Шахмат: ат жүрісі»
Шахмат тақтасындағы аттың орны (x1, y1) және жүретін нүкте (x2, y2) енгізіледі (1…8). Ат бұл нүктеге бір жүріспен бара ала ма? Кеңес: `dx = abs(x2 - x1)`, `dy = abs(y2 - y1)`; ат жүрісі: (dx == 1 және dy == 2) немесе (dx == 2 және dy == 1). `abs()` — санның модулін беретін дайын функция.

```text
x1 = 2
y1 = 1
x2 = 3
y2 = 3
Иә, ат бара алады
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Сенімді құпиясөз»
Пайдаланушы құпиясөз ойлап табады. Бағдарлама оның сенімділігін тексереді:
- ұзындығы кемінде 8 таңба (`len()`);
- құрамында кемінде бір цифр бар (кеңес: `not s.isalpha()` — тек әріптерден тұрмайды);
- тек цифрлардан тұрмайды (`not s.isdigit()`);
- кіші әріптерден ғана тұрмайды (`s != s.lower()` — бас әріп бар).

Барлық шарт орындалса — «Сенімді құпиясөз», әйтпесе қай шарт орындалмағанын жеке-жеке шығарыңыз.

### 10-тапсырма. «Ферзь және піл»
Шахмат тақтасында (x1, y1) және (x2, y2) екі шаршы берілген. Бағдарлама анықтайды: (а) шаршылар бір түсті ме; (ә) ладья бір жүріспен бара ала ма; (б) піл бара ала ма; (в) ферзь бара ала ма. Кеңес: бір түсті — `(x1 + y1) % 2 == (x2 + y2) % 2`; піл — `abs(x1 - x2) == abs(y1 - y2)`.

## Үй тапсырмасы

1. Үш логикалық амалдың ақиқаттық кестелерін дәптерге жазып, әрқайсысына өмірден бір мысал келтіріңіз.
2. Бағдарлама: мектепке «үздік оқушы» стипендиясы беріледі, егер орташа баға 4.5-тен жоғары болса және сабақ жібермеген болса, немесе республикалық олимпиаданың жүлдегері болса. Деректерді `input` арқылы алыңыз («иә»/«жоқ» жауаптарын `== "иә"` арқылы `bool`-ға айналдырыңыз).

**9-тапсырма.**

```python
s = input("Құпиясөз ойлап табыңыз: ")
uzyn = len(s) >= 8
cifr_bar = not s.isalpha()
tek_cifr_emes = not s.isdigit()
bas_aripi_bar = s != s.lower()
if uzyn and cifr_bar and tek_cifr_emes and bas_aripi_bar:
    print("Сенімді құпиясөз")
else:
    if not uzyn:
        print("Кемінде 8 таңба болуы керек")
    if not cifr_bar:
        print("Кемінде бір цифр немесе белгі қосыңыз")
    if not tek_cifr_emes:
        print("Тек цифрлардан тұрмауы керек")
    if not bas_aripi_bar:
        print("Кемінде бір бас әріп қосыңыз")
```

Ескерту: `not s.isalpha()` «әріптен басқа таңба бар» дегенді білдіреді (цифр немесе белгі) — оқушыларға осы жеңілдетуді түсіндіріңіз; нақты цифрды тексеру циклді (26-сабақ) қажет етеді.
