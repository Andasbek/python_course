# Сабақ 23. Логикалық амалдар: and, or, not. Құрама шарттар.

## Тақырыптар

1. Құрама шарт деген не?
2. and — «және» (конъюнкция)
3. or — «немесе» (дизъюнкция)
4. not — «емес» (терістеу, инверсия)
5. Мысал: кібісе жыл — бір шартпен
6. Басымдық (приоритет) және жақшалар
7. Қысқаша есептеу (short-circuit)
8. Құрама шарттар және elif
9. Логикалық амалдардың нәтижесін айнымалыға сақтау
10. Жиі кездесетін қателер
11. Негізгі ұғымдар

## 1. Құрама шарт деген не?

**Қарапайым шарт** — бір салыстыру: `jas >= 18`.
**Құрама шарт** — логикалық амалдармен біріктірілген бірнеше қарапайым шарт: `jas >= 18 and azamat == "иә"`.

Өмірлік мысалдар:
- Аттракционға бойы 120 см-ден жоғары **және** жасы 7-ден үлкен балалар кіреді.
- Сенбі **немесе** жексенбі — демалыс күні.
- Егер жаңбыр жаумаса (жаңбыр **емес**) — далада ойнаймыз.

## 2. and — «және» (конъюнкция)

`A and B` — **екі шарт та** ақиқат болғанда ғана `True`.

| A | B | A and B |
|---|---|---|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

> Аналогия: тізбектей қосылған екі қосқыш. Шам жану үшін **екі** қосқыш та қосулы болуы керек.

```python
boy = int(input("Бойың (см): "))
jas = int(input("Жасың: "))
if boy >= 120 and jas >= 7:
    print("Аттракционға кіруге болады!")
else:
    print("Кешір, әзірге болмайды.")
```

Нәтижесі:
```text
Бойың (см): 130
Жасың: 6
Кешір, әзірге болмайды.
```

### Аралықты тексеру

```python
ball = int(input("Балл: "))
if ball >= 0 and ball <= 100:
    print("Балл дұрыс енгізілді")
else:
    print("Қате: балл 0–100 аралығында болуы керек")
```

`ball >= 0 and ball <= 100` жазуы — `0 <= ball <= 100` тізбекті салыстыруымен бірдей.

## 3. or — «немесе» (дизъюнкция)

`A or B` — шарттардың **ең болмағанда біреуі** ақиқат болса `True`.

| A | B | A or B |
|---|---|---|
| True | True | **True** |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

> Аналогия: параллель қосылған екі қосқыш. Шам жану үшін **кез келген біреуін** қосу жеткілікті.

```python
kun = input("Апта күні: ").lower()
if kun == "сенбі" or kun == "жексенбі":
    print("Демалыс!")
else:
    print("Жұмыс күні.")
```

### Аралықтан тыс

```python
t = int(input("Дене температурасы ×10 (мыс. 366): "))
if t < 360 or t > 370:
    print("Температура қалыпты емес, дәрігерге қаралыңыз")
else:
    print("Температура қалыпты")
```

> Есте сақтаңыз: **аралық ішінде** — `and`, **аралықтан тыс** — `or`.

```text
   аралық ішінде:  a <= x and x <= b        ———[■■■■■■■]———
   аралықтан тыс:  x < a or x > b           ■■■[       ]■■■
```

## 4. not — «емес» (терістеу, инверсия)

`not A` — шарттың мәнін **керісінше** өзгертеді.

| A | not A |
|---|---|
| True | False |
| False | True |

```python
janbyr = False
if not janbyr:
    print("Далаға ойнауға шығамыз!")
```

Нәтижесі:
```text
Далаға ойнауға шығамыз!
```

`not` көбіне `bool` айнымалылармен қолданылады. Салыстыруларда `not (a == b)` орнына `a != b` жазған ыңғайлы.

## 5. Мысал: кібісе жыл — бір шартпен

Жыл кібісе болады, егер: (4-ке бөлінсе **және** 100-ге бөлінбесе) **немесе** 400-ге бөлінсе.

```python
jyl = int(input("Жыл: "))
if (jyl % 4 == 0 and jyl % 100 != 0) or jyl % 400 == 0:
    print(jyl, "— кібісе жыл (366 күн)")
else:
    print(jyl, "— кібісе емес (365 күн)")
```

Нәтижесі:
```text
Жыл: 1900
1900 — кібісе емес (365 күн)
```

Үш деңгейлі кірістірілген шарттың (`if` ішінде `if` ішінде `if`) орнына — **бір** жол.

## 6. Басымдық (приоритет) және жақшалар

Бір өрнекте бірнеше амал болса, олар мына ретпен орындалады:

| Реті | Амалдар |
|---|---|
| 1 | жақшалар `( )` |
| 2 | арифметика: `**`, `* / // %`, `+ -` |
| 3 | салыстыру: `== != > < >= <=` |
| 4 | `not` |
| 5 | `and` |
| 6 | `or` |

```python
print(True or False and False)     # and бірінші: True or False
print((True or False) and False)   # жақша бірінші: True and False
print(not True or True)            # not бірінші: False or True
```

Нәтижесі:
```text
True
False
True
```

> Кеңес: ережені білсеңіз де, күрделі шарттарда **жақша қойыңыз** — код түсінікті болады, қате азаяды.

### Құрама шартты қолмен есептеу

`x = 5`, `y = 12` үшін `x > 3 and y < 10 or not x == 5`:
1. Салыстырулар: `True and False or not True`
2. `not`: `True and False or False`
3. `and`: `False or False`
4. `or`: `False`

## 7. Қысқаша есептеу (short-circuit)

Python құрама шартты солдан оңға есептейді және нәтиже белгілі болса — тоқтайды:
- `A and B`: егер `A` жалған болса, `B` **тексерілмейді** (нәтиже бәрібір `False`);
- `A or B`: егер `A` ақиқат болса, `B` **тексерілмейді** (нәтиже бәрібір `True`).

Бұл қасиет қатеден қорғауға көмектеседі:

```python
a = int(input("a = "))
b = int(input("b = "))
if b != 0 and a % b == 0:
    print(a, "саны", b, "санына қалдықсыз бөлінеді")
else:
    print("Бөлінбейді (немесе b = 0)")
```

`b = 0` болса, `b != 0` жалған, сондықтан `a % b` (нөлге бөлу қатесі) **есептелмейді**.

## 8. Құрама шарттар және elif

Құрама шарттар `elif` тізбектерін ықшамдайды:

```python
ai = int(input("Ай нөмірі: "))
if ai == 12 or ai == 1 or ai == 2:
    print("Қыс")
elif 3 <= ai <= 5:
    print("Көктем")
elif 6 <= ai <= 8:
    print("Жаз")
elif 9 <= ai <= 11:
    print("Күз")
else:
    print("Мұндай ай жоқ")
```

### Үшбұрыштың түрі

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
if a + b <= c or a + c <= b or b + c <= a:
    print("Мұндай үшбұрыш жоқ")
elif a == b and b == c:
    print("Тең қабырғалы үшбұрыш")
elif a == b or b == c or a == c:
    print("Тең бүйірлі үшбұрыш")
else:
    print("Әртүрлі қабырғалы үшбұрыш")
```

Нәтижесі:
```text
a = 5
b = 5
c = 8
Тең бүйірлі үшбұрыш
```

## 9. Логикалық амалдардың нәтижесін айнымалыға сақтау

Күрделі шартты бөліктерге бөліп, түсінікті атаулар берген дұрыс:

```python
jas = 15
baga = 5
qatysu = 95   # қатысу пайызы
jasy_saikes = 12 <= jas <= 17
ozat = baga == 5 and qatysu >= 90
if jasy_saikes and ozat:
    print("Сіз жазғы IT-лагерьге жолдамаға үміткерсіз!")
```

## Жиі кездесетін қателер

**1. Әр шартты толық жазбау.**

```text
if kun == "сенбі" or "жексенбі":
    print("Демалыс")   # ӘРҚАШАН орындалады! "жексенбі" — бос емес жол, ол True болып саналады
```

```python
kun = input("Күн: ")
if kun == "сенбі" or kun == "жексенбі":   # дұрыс
    print("Демалыс")
```

**2. `and` пен `or`-ды шатастыру.**

```text
if ball < 0 and ball > 100:    # ешқашан True болмайды: сан бір мезгілде <0 және >100 бола алмайды
```

Аралықтан тыс → `or`: `if ball < 0 or ball > 100:`

**3. Басқа тілдердегі белгілерді жазу.**

```text
if a > 0 && b > 0:    # SyntaxError — Python-да && жоқ
if a > 0 || b > 0:    # SyntaxError
if !janbyr:           # SyntaxError
```

Python-да тек сөздер: `and`, `or`, `not`.

**4. Жақшасыз күрделі шарт.**

```text
if jyl % 4 == 0 and jyl % 100 != 0 or jyl % 400 == 0:
```

Бұл жерде басымдық бойынша нәтиже дұрыс, бірақ оқуға қиын. Жақша қойыңыз.

**5. `not` орнын қате қою.** `not a == b` — бұл `not (a == b)`, бірақ түсінікті болу үшін `a != b` жазыңыз.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Құрама шарт | Логикалық амалдармен біріктірілген бірнеше шарт |
| `and` (конъюнкция) | Екі шарт та ақиқат болса — `True` |
| `or` (дизъюнкция) | Ең болмағанда біреуі ақиқат болса — `True` |
| `not` (инверсия) | Мәнді керісінше өзгерту |
| Ақиқаттық кестесі | Барлық мүмкін мәндер үшін нәтижелер кестесі |
| Басымдық | `not` → `and` → `or` |
| Қысқаша есептеу | Нәтиже белгілі болғанда қалған шарттарды тексермеу |

## Ескерту

- `and` пен `or` міндетті түрде `True`/`False` емес, **операндтардың бірін** қайтарады: `0 or 5` → `5`, `"" or "қонақ"` → `"қонақ"`, `3 and 7` → `7`. Әдепкі мән беру идиомасы осыдан шыққан: `name = input() or "Қонақ"`.
- «Мәндердің біріне тең бе» деген тексерісті `in` арқылы қысқа жазған дұрыс: `or` тізбегінің орнына `if kun in ("сенбі", "жексенбі"):`.
- `all(...)` және `any(...)` кіріктірілген функциялары көп шартты бірден тексереді: `all([a > 0, b > 0, c > 0])` — бәрі ақиқат, `any(...)` — ең болмағанда біреуі.
- Де Морган заңдары шарттарды ықшамдауға көмектеседі: `not (A and B)` == `not A or not B`, `not (A or B)` == `not A and not B`.
- Python-дағы `&`, `|`, `~` операторлары логикалық емес, разрядтық (побитовые); сандармен басқа нәтиже береді (`~True` → `-2`) және қысқаша есептеуді орындамайды.
- Кібісе жыл үшін дайын функция бар: `calendar.isleap(2024)` → `True`. Құжаттама: https://docs.python.org/3/reference/expressions.html#boolean-operations
