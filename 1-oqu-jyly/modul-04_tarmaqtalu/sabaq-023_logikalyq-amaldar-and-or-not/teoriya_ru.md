## 1. Что такое составное условие?

**Простое условие** — одно сравнение: `jas >= 18`.
**Составное условие** — несколько простых условий, объединённых логическими операциями: `jas >= 18 and azamat == "да"`.

Примеры из жизни:
- На аттракцион допускаются дети ростом выше 120 см **и** старше 7 лет.
- Суббота **или** воскресенье — выходной день.
- Если дождя нет (**не** дождь) — играем на улице.

## 2. and — «и» (конъюнкция)

`A and B` — `True` только тогда, когда **оба условия** истинны.

| A | B | A and B |
|---|---|---|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

> Аналогия: два выключателя, соединённых последовательно. Чтобы лампа загорелась, **оба** выключателя должны быть включены.

```python
boy = int(input("Твой рост (см): "))
jas = int(input("Твой возраст: "))
if boy >= 120 and jas >= 7:
    print("На аттракцион можно!")
else:
    print("Извини, пока нельзя.")
```

Результат:
```text
Твой рост (см): 130
Твой возраст: 6
Извини, пока нельзя.
```

### Проверка диапазона

```python
ball = int(input("Балл: "))
if ball >= 0 and ball <= 100:
    print("Балл введён правильно")
else:
    print("Ошибка: балл должен быть в диапазоне 0–100")
```

Запись `ball >= 0 and ball <= 100` равносильна цепочке сравнений `0 <= ball <= 100`.

## 3. or — «или» (дизъюнкция)

`A or B` — `True`, если **хотя бы одно** из условий истинно.

| A | B | A or B |
|---|---|---|
| True | True | **True** |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

> Аналогия: два выключателя, соединённых параллельно. Чтобы лампа загорелась, достаточно включить **любой** из них.

```python
kun = input("День недели: ").lower()
if kun == "суббота" or kun == "воскресенье":
    print("Выходной!")
else:
    print("Рабочий день.")
```

### Вне диапазона

```python
t = int(input("Температура тела ×10 (напр. 366): "))
if t < 360 or t > 370:
    print("Температура не в норме, обратитесь к врачу")
else:
    print("Температура в норме")
```

> Запомните: **внутри диапазона** — `and`, **вне диапазона** — `or`.

```text
   внутри диапазона:  a <= x and x <= b     ———[■■■■■■■]———
   вне диапазона:     x < a or x > b        ■■■[       ]■■■
```

## 4. not — «не» (отрицание, инверсия)

`not A` — меняет значение условия **на противоположное**.

| A | not A |
|---|---|
| True | False |
| False | True |

```python
janbyr = False
if not janbyr:
    print("Идём играть на улицу!")
```

Результат:
```text
Идём играть на улицу!
```

`not` чаще всего используется с переменными типа `bool`. В сравнениях вместо `not (a == b)` удобнее писать `a != b`.

## 5. Пример: високосный год — одним условием

Год високосный, если: (делится на 4 **и** не делится на 100) **или** делится на 400.

```python
jyl = int(input("Год: "))
if (jyl % 4 == 0 and jyl % 100 != 0) or jyl % 400 == 0:
    print(jyl, "— високосный год (366 дней)")
else:
    print(jyl, "— не високосный (365 дней)")
```

Результат:
```text
Год: 1900
1900 — не високосный (365 дней)
```

Вместо трёхуровневого вложенного условия (`if` внутри `if` внутри `if`) — **одна** строка.

## 6. Приоритет и скобки

Если в одном выражении несколько операций, они выполняются в таком порядке:

| Порядок | Операции |
|---|---|
| 1 | скобки `( )` |
| 2 | арифметика: `**`, `* / // %`, `+ -` |
| 3 | сравнение: `== != > < >= <=` |
| 4 | `not` |
| 5 | `and` |
| 6 | `or` |

```python
print(True or False and False)     # сначала and: True or False
print((True or False) and False)   # сначала скобки: True and False
print(not True or True)            # сначала not: False or True
```

Результат:
```text
True
False
True
```

> Подсказка: даже если знаете правило, в сложных условиях **ставьте скобки** — код станет понятнее, ошибок будет меньше.

### Вычисление составного условия вручную

Для `x = 5`, `y = 12`: `x > 3 and y < 10 or not x == 5`:
1. Сравнения: `True and False or not True`
2. `not`: `True and False or False`
3. `and`: `False or False`
4. `or`: `False`

## 7. Сокращённое вычисление (short-circuit)

Python вычисляет составное условие слева направо и останавливается, как только результат известен:
- `A and B`: если `A` ложно, `B` **не проверяется** (результат всё равно `False`);
- `A or B`: если `A` истинно, `B` **не проверяется** (результат всё равно `True`).

Это свойство помогает защититься от ошибок:

```python
a = int(input("a = "))
b = int(input("b = "))
if b != 0 and a % b == 0:
    print("Число", a, "делится на", b, "без остатка")
else:
    print("Не делится (или b = 0)")
```

Если `b = 0`, то `b != 0` ложно, поэтому `a % b` (ошибка деления на ноль) **не вычисляется**.

## 8. Составные условия и elif

Составные условия сокращают цепочки `elif`:

```python
ai = int(input("Номер месяца: "))
if ai == 12 or ai == 1 or ai == 2:
    print("Зима")
elif 3 <= ai <= 5:
    print("Весна")
elif 6 <= ai <= 8:
    print("Лето")
elif 9 <= ai <= 11:
    print("Осень")
else:
    print("Такого месяца нет")
```

### Вид треугольника

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
if a + b <= c or a + c <= b or b + c <= a:
    print("Такого треугольника не существует")
elif a == b and b == c:
    print("Равносторонний треугольник")
elif a == b or b == c or a == c:
    print("Равнобедренный треугольник")
else:
    print("Разносторонний треугольник")
```

Результат:
```text
a = 5
b = 5
c = 8
Равнобедренный треугольник
```

## 9. Сохранение результата логических операций в переменную

Сложное условие лучше разбить на части и дать им понятные имена:

```python
jas = 15
baga = 5
qatysu = 95   # процент посещаемости
jasy_saikes = 12 <= jas <= 17
ozat = baga == 5 and qatysu >= 90
if jasy_saikes and ozat:
    print("Вы претендуете на путёвку в летний IT-лагерь!")
```

## Частые ошибки

**1. Не каждое условие записано полностью.**

```text
if kun == "суббота" or "воскресенье":
    print("Выходной")   # выполняется ВСЕГДА! "воскресенье" — непустая строка, она считается True
```

```python
kun = input("День: ")
if kun == "суббота" or kun == "воскресенье":   # правильно
    print("Выходной")
```

**2. Путаница `and` и `or`.**

```text
if ball < 0 and ball > 100:    # никогда не будет True: число не может быть одновременно <0 и >100
```

Вне диапазона → `or`: `if ball < 0 or ball > 100:`

**3. Знаки из других языков.**

```text
if a > 0 && b > 0:    # SyntaxError — в Python нет &&
if a > 0 || b > 0:    # SyntaxError
if !janbyr:           # SyntaxError
```

В Python только слова: `and`, `or`, `not`.

**4. Сложное условие без скобок.**

```text
if jyl % 4 == 0 and jyl % 100 != 0 or jyl % 400 == 0:
```

Здесь по приоритету результат верный, но читать трудно. Ставьте скобки.

**5. `not` не на своём месте.** `not a == b` — это `not (a == b)`, но для понятности пишите `a != b`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Составное условие | Несколько условий, объединённых логическими операциями |
| `and` (конъюнкция) | `True`, если оба условия истинны |
| `or` (дизъюнкция) | `True`, если истинно хотя бы одно |
| `not` (инверсия) | Изменение значения на противоположное |
| Таблица истинности | Таблица результатов для всех возможных значений |
| Приоритет | `not` → `and` → `or` |
| Сокращённое вычисление | Остальные условия не проверяются, когда результат уже известен |

## Примечание

- `and` и `or` возвращают не обязательно `True`/`False`, а **один из операндов**: `0 or 5` → `5`, `"" or "гость"` → `"гость"`, `3 and 7` → `7`. Отсюда идиома значения по умолчанию: `name = input() or "Гость"`.
- Проверку «равно одному из значений» короче писать через `in`: `if kun in ("суббота", "воскресенье"):` вместо цепочки `or`.
- Встроенные функции `all(...)` и `any(...)` проверяют сразу много условий: `all([a > 0, b > 0, c > 0])` — все истинны, `any(...)` — хотя бы одно.
- Законы де Моргана помогают упрощать условия: `not (A and B)` == `not A or not B`, `not (A or B)` == `not A and not B`.
- Операторы `&`, `|`, `~` в Python — побитовые, а не логические; с числами они дают другой результат (`~True` → `-2`) и не выполняют сокращённое вычисление.
- Для високосного года есть готовая функция: `calendar.isleap(2024)` → `True`. Документация: https://docs.python.org/3/reference/expressions.html#boolean-operations
