# Урок 23. Практические задания: and, or, not

## Базовый уровень

### Задание 1. «Вычисли и проверь»
Пусть `a = 7`, `b = 0`, `c = -3`. Вычислите значение каждого выражения в тетради, затем проверьте в Python.

```text
1) a > 0 and c > 0
2) a > 0 or c > 0
3) not b == 0
4) a > b and b > c
5) a < 0 or b == 0 and c < 0
6) (a < 0 or b == 0) and c > 0
7) not (a > 5 and c < -5)
```

### Задание 2. «В диапазоне?»
Пользователь вводит целое число. Программа с помощью `and` проверяет, является ли число двузначным (не 10…99 или −99…−10, а только положительным двузначным).

```text
Число: 47
47 — двузначное положительное число
```

### Задание 3. «Выходной день»
Вводится название дня недели. Если «суббота» или «воскресенье» — «Выходной!», иначе — «Рабочий день». Приведите ввод к нижнему регистру.

### Задание 4. «Бесплатный проезд»
В общественном транспорте бесплатно ездят дети до 7 лет и пенсионеры старше 63 лет. Введите возраст и выведите стоимость проезда (бесплатно или 200 тг).

### Задание 5. «Победитель»
Условие прохождения этапа олимпиады: по теории не менее 60 баллов **и** по практике не менее 70 баллов. Или же проходит, если сумма двух баллов больше 160. Введите два балла и выведите результат.

## Продвинутый уровень

### Задание 6. «Високосный год»
Введите год и определите одним составным условием, високосный ли он. Также выведите, сколько дней в феврале.

```text
Год: 2028
2028 — високосный год, в феврале 29 дней
```

### Задание 7. «Треугольник»
Вводятся три стороны. Программа сначала проверяет, существует ли такой треугольник, и если да — определяет его вид (равносторонний, равнобедренный, разносторонний). Дополнительно: проверьте по теореме Пифагора, является ли он прямоугольным (гипотенузой может быть любая сторона).

### Задание 8. «Шахматы: ход коня»
Вводятся положение коня на шахматной доске (x1, y1) и клетка, куда он идёт (x2, y2) (1…8). Может ли конь попасть в эту клетку одним ходом? Подсказка: `dx = abs(x2 - x1)`, `dy = abs(y2 - y1)`; ход коня: (dx == 1 и dy == 2) или (dx == 2 и dy == 1). `abs()` — готовая функция, возвращающая модуль числа.

```text
x1 = 2
y1 = 1
x2 = 3
y2 = 3
Да, конь может пойти
```

## ★ Олимпиадная / творческая задача

### Задание 9. «Надёжный пароль»
Пользователь придумывает пароль. Программа проверяет его надёжность:
- длина не менее 8 символов (`len()`);
- содержит хотя бы одну цифру (подсказка: `not s.isalpha()` — состоит не только из букв);
- не состоит только из цифр (`not s.isdigit()`);
- не состоит только из строчных букв (`s != s.lower()` — есть заглавная буква).

Если все условия выполнены — «Надёжный пароль», иначе выведите отдельно, какие условия не выполнены.

### Задание 10. «Ферзь и слон»
На шахматной доске даны две клетки (x1, y1) и (x2, y2). Программа определяет: (а) одного ли цвета клетки; (б) может ли ладья дойти одним ходом; (в) может ли слон; (г) может ли ферзь. Подсказка: одного цвета — `(x1 + y1) % 2 == (x2 + y2) % 2`; слон — `abs(x1 - x2) == abs(y1 - y2)`.

**Задание 9.**

```python
s = input("Придумайте пароль: ")
uzyn = len(s) >= 8
cifr_bar = not s.isalpha()
tek_cifr_emes = not s.isdigit()
bas_aripi_bar = s != s.lower()
if uzyn and cifr_bar and tek_cifr_emes and bas_aripi_bar:
    print("Надёжный пароль")
else:
    if not uzyn:
        print("Должно быть не менее 8 символов")
    if not cifr_bar:
        print("Добавьте хотя бы одну цифру или знак")
```
