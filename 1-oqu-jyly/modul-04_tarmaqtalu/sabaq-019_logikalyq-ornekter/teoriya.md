## 1. Пікір және логикалық өрнек

Логикада **пікір (высказывание, statement)** — ақиқат немесе жалған екенін айтуға болатын сөйлем.

| Сөйлем | Пікір ме? | Мәні |
|---|---|---|
| «Қазақстанның астанасы — Астана» | иә | ақиқат |
| «7 саны 10-нан үлкен» | иә | жалған |
| «Бүгін ауа райы қандай?» | жоқ (сұрақ) | — |
| «Есікті жап!» | жоқ (бұйрық) | — |

Бағдарламалауда пікірдің рөлін **логикалық өрнек (логическое выражение, boolean expression)** атқарады. Оның нәтижесі әрдайым екі мәннің бірі:

- `True` — ақиқат (иә);
- `False` — жалған (жоқ).

Бұл мәндер — **`bool`** логикалық типіне жатады. Ағылшын математигі **Джордж Буль** (George Boole, XIX ғ.) құрметіне аталған.

```python
print(5 > 3)
print(5 < 3)
print(type(5 > 3))
```

Нәтижесі:
```text
True
False
<class 'bool'>
```

## 2. Салыстыру операторлары

| Оператор | Мағынасы | Мысал | Нәтиже |
|---|---|---|---|
| `==` | тең | `7 == 7` | `True` |
| `!=` | тең емес | `7 != 7` | `False` |
| `>` | үлкен | `10 > 3` | `True` |
| `<` | кіші | `10 < 3` | `False` |
| `>=` | үлкен немесе тең | `5 >= 5` | `True` |
| `<=` | кіші немесе тең | `4 <= 3` | `False` |

```python
a = 12
b = 20
print("a == b:", a == b)
print("a != b:", a != b)
print("a > b:", a > b)
print("a < b:", a < b)
print("a >= 12:", a >= 12)
print("b <= 19:", b <= 19)
```

Нәтижесі:
```text
a == b: False
a != b: True
a > b: False
a < b: True
a >= 12: True
b <= 19: False
```

> Есте сақтау тәсілі: `>=` және `<=` таңбаларында «тең» белгісі **әрқашан екінші** тұрады — «үлкен **немесе** тең» деп оқылатындай. `=>` және `=<` жазуы — қате.

## 3. `=` пен `==` — басты айырмашылық

| `=` | `==` |
|---|---|
| **меншіктеу**: «мәнді сақта» | **салыстыру**: «тең бе?» |
| `x = 5` — x-ке 5 жаз | `x == 5` — x 5-ке тең бе? |
| ештеңе қайтармайды | `True` немесе `False` қайтарады |

```python
x = 5            # меншіктеу
print(x == 5)    # салыстыру → True
print(x == 6)    # салыстыру → False
```

> Аналогия: `=` — қорапқа зат салу. `==` — «қорапта осы зат бар ма?» деп сұрау.

## 4. Өрнектің ішінде есептеу

Салыстыру операторларының **басымдығы** арифметикалық амалдардан төмен. Яғни алдымен есептеледі, сосын салыстырылады:

```python
print(2 + 3 == 5)        # (2 + 3) == 5
print(10 / 2 > 4 * 2)    # 5.0 > 8
print(7 * 2 != 15 - 1)   # 14 != 14
```

Нәтижесі:
```text
True
False
False
```

### Жұп/тақ және бөлінгіштікті тексеру

`%` операторы мен `==` бірге — ең жиі қолданылатын логикалық өрнектердің бірі:

```python
n = 14
print("Жұп па?", n % 2 == 0)
print("Тақ па?", n % 2 != 0)
print("5-ке бөліне ме?", n % 5 == 0)
print("7-ге бөліне ме?", n % 7 == 0)
```

Нәтижесі:
```text
Жұп па? True
Тақ па? False
5-ке бөліне ме? False
7-ге бөліне ме? True
```

## 5. Нәтижені айнымалыға сақтау

Логикалық өрнектің нәтижесін басқа мәндер сияқты айнымалыға сақтауға болады:

```python
jas = 15
eresek = jas >= 18
print("Ересек пе?", eresek)
print(type(eresek))
```

Нәтижесі:
```text
Ересек пе? False
<class 'bool'>
```

`input()`-пен бірге:

```python
baga = int(input("Тауардың бағасы (теңге): "))
aqsha = int(input("Сізде қанша ақша бар: "))
jetedi = aqsha >= baga
print("Ақша жете ме?", jetedi)
```

Нәтижесі (мысалы, 3500 және 5000 енгізсек):
```text
Тауардың бағасы (теңге): 3500
Сізде қанша ақша бар: 5000
Ақша жете ме? True
```

## 6. Тізбекті салыстыру

Python математикадағыдай **тізбекті салыстыруға** мүмкіндік береді:

```python
t = 22
print(18 <= t <= 25)   # температура қолайлы аралықта ма?
baga = 7
print(1 <= baga <= 5)  # баға 1…5 аралығында ма?
```

Нәтижесі:
```text
True
False
```

`18 <= t <= 25` — «t 18-ден кем емес **және** 25-тен аспайды» дегенді білдіреді, яғни `18 <= t and t <= 25` өрнегімен бірдей (`and` логикалық операторы).

## 7. Жолдарды (str) салыстыру

### Теңдік
Жолдар **әріптен әріпке дәл** сәйкес келсе ғана тең:

```python
print("Python" == "Python")
print("python" == "Python")   # кіші және бас әріп — әртүрлі!
print("Алма" != "алма")
print("Сәлем " == "Сәлем")    # соңындағы бос орын да маңызды
```

Нәтижесі:
```text
True
False
True
False
```

### Үлкен/кіші
Жолдар **әліпби (лексикографиялық) ретпен** салыстырылады: бірінші әріптер, тең болса — екінші әріптер және т.с.с. Әр таңбаның өз нөмірі (коды) бар, оны `ord()` функциясы көрсетеді.

```python
print("alma" < "anar")     # 'l' < 'n'
print("Abc" < "abc")       # бас әріптердің коды кішірек
print(ord("A"), ord("a"))
```

Нәтижесі:
```text
True
True
65 97
```

> Абайлаңыз: `"10" < "9"` → `True`, өйткені бұл **мәтіндер**, бірінші таңбалар салыстырылады: `"1"` < `"9"`. Сандарды салыстыру үшін алдымен `int()` арқылы түрлендіріңіз!

```python
print("10" < "9")
print(int("10") < int("9"))
```

Нәтижесі:
```text
True
False
```

### Әртүрлі типтер
- `5 == 5.0` → `True` (int пен float мәні тең);
- `5 == "5"` → `False` (сан мен мәтін ешқашан тең емес);
- `5 < "6"` → **қате** `TypeError`: санды мәтінмен «үлкен/кіші» деп салыстыруға болмайды.

## 8. Нақты (float) сандарды салыстыру

Компьютер бөлшек сандарды әрдайым дәл сақтай алмайды:

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2) == 0.3)
```

Нәтижесі:
```text
0.30000000000000004
False
True
```

Сондықтан `float` сандарды `==` арқылы салыстырғанда `round()` қолданған дұрыс.

## 9. Логикалық өрнектің нәтижесін анықтау тәсілі

Өрнекті «қолмен» есептеу алгоритмі:
1. Айнымалылардың орнына мәндерін қойыңыз.
2. Арифметикалық амалдарды орындаңыз.
3. Салыстыруды орындап, `True` немесе `False` жазыңыз.

Мысал: `a = 4`, `b = 9`, өрнек: `a * 2 + 1 >= b`
1. `4 * 2 + 1 >= 9`
2. `9 >= 9`
3. `True`

## Жиі кездесетін қателер

**1. Салыстырудың орнына меншіктеу.**

```text
print(x = 5)     # TypeError: 'x' is an invalid keyword argument for print()
```

```python
x = 5
print(x == 5)    # дұрыс
```

**2. Операторды керісінше немесе бос орынмен жазу.**

```text
print(5 => 3)    # SyntaxError
print(5 = < 3)   # SyntaxError
print(5 ! = 3)   # SyntaxError
```

```python
print(5 >= 3, 5 <= 3, 5 != 3)   # дұрыс
```

**3. `input()` нәтижесін түрлендірмей салыстыру.**

```text
jas = input("Жасыңыз: ")    # "9" — мәтін!
print(jas > 10)             # TypeError: '>' not supported between 'str' and 'int'
```

```python
jas = int(input("Жасыңыз: "))
print(jas > 10)             # дұрыс
```

**4. `True`/`False` кіші әріппен.** `true`, `false` — Python-да жоқ атаулар (`NameError`). Тек бас әріппен: `True`, `False`.

**5. Әріп регистрін ескермеу.** `"Астана" == "астана"` → `False`. Қажет болса, екеуін бір регистрге келтіріңіз: `"Астана".lower() == "астана"` → `True`.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Пікір | Ақиқат не жалған екенін айтуға болатын сөйлем |
| Логикалық өрнек | Нәтижесі `True` немесе `False` болатын өрнек |
| `bool` | Логикалық тип: `True`, `False` |
| Салыстыру операторлары | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| `=` | Меншіктеу |
| `==` | Теңдікке салыстыру |
| Тізбекті салыстыру | `a < x < b` түріндегі өрнек |
| Лексикографиялық рет | Жолдарды әріптердің кодтары бойынша салыстыру |
| `ord()` | Таңбаның кодын беретін функция |

## Ескерту

- `bool` — `int` типінің ішкі класы: `True == 1` және `False == 0`, сондықтан `True + True` нәтижесі `2`, ал `sum([5 > 3, 2 > 7, 1 < 4])` ақиқат шарттардың санын (`2`) есептейді.
- Бөлшек сандарды салыстыру үшін `round()`-тан гөрі `math.isclose(a, b)` дәлірек: `math.isclose(0.1 + 0.2, 0.3)` → `True` (`math` модулі).
- `a < b < c` тізбегі `b`-ны бір-ақ рет есептейді және әртүрлі операторларды қамти алады: `1 < x != 5`. Бірақ `a < b > c` жазуы рұқсат етілгенімен, қиын оқылады — одан аулақ болған жөн.
- Әртүрлі әліпби әріптері бар жолдарды регистрге тәуелсіз салыстыру үшін `lower()`-ден гөрі `s1.casefold() == s2.casefold()` сенімдірек (мысалы, неміс тіліндегі «ß» мен «ss»).
- `is` мәндердің теңдігін емес, бір объект екенін тексереді. Сандар мен жолдар үшін `==` қолданыңыз; `is` тек `None`-мен қолданылады (`x is None`).
- Құжаттама: https://docs.python.org/3/reference/expressions.html#comparisons
