## 1. Высказывание и логическое выражение

В логике **высказывание (statement)** — предложение, о котором можно сказать, истинно оно или ложно.

| Предложение | Высказывание? | Значение |
|---|---|---|
| «Столица Казахстана — Астана» | да | истина |
| «Число 7 больше 10» | да | ложь |
| «Какая сегодня погода?» | нет (вопрос) | — |
| «Закрой дверь!» | нет (приказ) | — |

В программировании роль высказывания играет **логическое выражение (boolean expression)**. Его результат всегда одно из двух значений:

- `True` — истина (да);
- `False` — ложь (нет).

Эти значения относятся к логическому типу **`bool`**. Он назван в честь английского математика **Джорджа Буля** (George Boole, XIX в.).

```python
print(5 > 3)
print(5 < 3)
print(type(5 > 3))
```

Результат:
```text
True
False
<class 'bool'>
```

## 2. Операторы сравнения

| Оператор | Значение | Пример | Результат |
|---|---|---|---|
| `==` | равно | `7 == 7` | `True` |
| `!=` | не равно | `7 != 7` | `False` |
| `>` | больше | `10 > 3` | `True` |
| `<` | меньше | `10 < 3` | `False` |
| `>=` | больше или равно | `5 >= 5` | `True` |
| `<=` | меньше или равно | `4 <= 3` | `False` |

```python
a = 12
b = 20
print("a == b:", a == b)
print("a != b:", a != b)
print("a > b:", a > b)
print("a < b:", a < b)
print("a >= 12:", a >= 12)
print("b <= 19:", b <= 19)
```

Результат:
```text
a == b: False
a != b: True
a > b: False
a < b: True
a >= 12: True
b <= 19: False
```

> Как запомнить: в знаках `>=` и `<=` знак «равно» **всегда стоит вторым** — так, как читается «больше **или** равно». Запись `=>` и `=<` — ошибка.

## 3. `=` и `==` — главное различие

| `=` | `==` |
|---|---|
| **присваивание**: «сохрани значение» | **сравнение**: «равно ли?» |
| `x = 5` — запиши 5 в x | `x == 5` — равно ли x пяти? |
| ничего не возвращает | возвращает `True` или `False` |

```python
x = 5            # присваивание
print(x == 5)    # сравнение → True
print(x == 6)    # сравнение → False
```

> Аналогия: `=` — положить предмет в коробку. `==` — спросить: «Есть ли в коробке этот предмет?»

## 4. Вычисления внутри выражения

**Приоритет** операторов сравнения ниже, чем у арифметических операций. То есть сначала выполняются вычисления, потом сравнение:

```python
print(2 + 3 == 5)        # (2 + 3) == 5
print(10 / 2 > 4 * 2)    # 5.0 > 8
print(7 * 2 != 15 - 1)   # 14 != 14
```

Результат:
```text
True
False
False
```

### Проверка чётности и делимости

Оператор `%` вместе с `==` — одно из самых часто используемых логических выражений:

```python
n = 14
print("Чётное?", n % 2 == 0)
print("Нечётное?", n % 2 != 0)
print("Делится на 5?", n % 5 == 0)
print("Делится на 7?", n % 7 == 0)
```

Результат:
```text
Чётное? True
Нечётное? False
Делится на 5? False
Делится на 7? True
```

## 5. Сохранение результата в переменную

Результат логического выражения, как и другие значения, можно сохранить в переменную:

```python
jas = 15
eresek = jas >= 18
print("Взрослый?", eresek)
print(type(eresek))
```

Результат:
```text
Взрослый? False
<class 'bool'>
```

Вместе с `input()`:

```python
baga = int(input("Цена товара (тенге): "))
aqsha = int(input("Сколько у вас денег: "))
jetedi = aqsha >= baga
print("Денег хватает?", jetedi)
```

Результат (например, если ввести 3500 и 5000):
```text
Цена товара (тенге): 3500
Сколько у вас денег: 5000
Денег хватает? True
```

## 6. Цепочки сравнений

Python, как и математика, позволяет **сравнивать цепочкой**:

```python
t = 22
print(18 <= t <= 25)   # температура в комфортном диапазоне?
baga = 7
print(1 <= baga <= 5)  # оценка в диапазоне 1…5?
```

Результат:
```text
True
False
```

`18 <= t <= 25` означает «t не меньше 18 **и** не больше 25», то есть то же самое, что `18 <= t and t <= 25` (логический оператор `and`).

## 7. Сравнение строк (str)

### Равенство
Строки равны, только если они **совпадают буква в букву**:

```python
print("Python" == "Python")
print("python" == "Python")   # строчная и заглавная буквы — разные!
print("Яблоко" != "яблоко")
print("Привет " == "Привет")  # пробел в конце тоже важен
```

Результат:
```text
True
False
True
False
```

### Больше/меньше
Строки сравниваются в **алфавитном (лексикографическом) порядке**: сначала первые буквы, если они равны — вторые и т. д. У каждого символа есть свой номер (код), его показывает функция `ord()`.

```python
print("alma" < "anar")     # 'l' < 'n'
print("Abc" < "abc")       # у заглавных букв код меньше
print(ord("A"), ord("a"))
```

Результат:
```text
True
True
65 97
```

> Осторожно: `"10" < "9"` → `True`, потому что это **тексты**, и сравниваются первые символы: `"1"` < `"9"`. Чтобы сравнивать числа, сначала преобразуйте их с помощью `int()`!

```python
print("10" < "9")
print(int("10") < int("9"))
```

Результат:
```text
True
False
```

### Разные типы
- `5 == 5.0` → `True` (значения int и float равны);
- `5 == "5"` → `False` (число и текст никогда не равны);
- `5 < "6"` → **ошибка** `TypeError`: число и текст нельзя сравнивать на «больше/меньше».

## 8. Сравнение вещественных (float) чисел

Компьютер не всегда может точно хранить дробные числа:

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2) == 0.3)
```

Результат:
```text
0.30000000000000004
False
True
```

Поэтому при сравнении чисел `float` через `==` лучше использовать `round()`.

## 9. Как определить результат логического выражения

Алгоритм вычисления выражения «вручную»:
1. Подставьте вместо переменных их значения.
2. Выполните арифметические операции.
3. Выполните сравнение и запишите `True` или `False`.

Пример: `a = 4`, `b = 9`, выражение: `a * 2 + 1 >= b`
1. `4 * 2 + 1 >= 9`
2. `9 >= 9`
3. `True`

## Частые ошибки

**1. Присваивание вместо сравнения.**

```text
print(x = 5)     # TypeError: 'x' is an invalid keyword argument for print()
```

```python
x = 5
print(x == 5)    # правильно
```

**2. Оператор написан наоборот или с пробелом.**

```text
print(5 => 3)    # SyntaxError
print(5 = < 3)   # SyntaxError
print(5 ! = 3)   # SyntaxError
```

```python
print(5 >= 3, 5 <= 3, 5 != 3)   # правильно
```

**3. Сравнение результата `input()` без преобразования.**

```text
jas = input("Ваш возраст: ")   # "9" — это текст!
print(jas > 10)                # TypeError: '>' not supported between 'str' and 'int'
```

```python
jas = int(input("Ваш возраст: "))
print(jas > 10)             # правильно
```

**4. `True`/`False` со строчной буквы.** `true`, `false` — несуществующие в Python имена (`NameError`). Только с заглавной: `True`, `False`.

**5. Не учтён регистр букв.** `"Астана" == "астана"` → `False`. При необходимости приведите обе строки к одному регистру: `"Астана".lower() == "астана"` → `True`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Высказывание | Предложение, о котором можно сказать, истинно оно или ложно |
| Логическое выражение | Выражение, результат которого `True` или `False` |
| `bool` | Логический тип: `True`, `False` |
| Операторы сравнения | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| `=` | Присваивание |
| `==` | Сравнение на равенство |
| Цепочка сравнений | Выражение вида `a < x < b` |
| Лексикографический порядок | Сравнение строк по кодам букв |
| `ord()` | Функция, возвращающая код символа |

## Примечание

- `bool` — подкласс `int`: `True == 1` и `False == 0`, поэтому `True + True` даёт `2`, а `sum([5 > 3, 2 > 7, 1 < 4])` считает количество истинных условий (`2`).
- Для сравнения дробных чисел точнее, чем `round()`, работает `math.isclose(a, b)`: `math.isclose(0.1 + 0.2, 0.3)` → `True` (модуль `math`).
- Цепочка `a < b < c` вычисляет `b` только один раз и может содержать разные операторы: `1 < x != 5`. Но запись `a < b > c` хоть и допустима, читается плохо — лучше её избегать.
- Для регистронезависимого сравнения строк с буквами разных алфавитов надёжнее `s1.casefold() == s2.casefold()`, чем `lower()` (например, немецкая «ß» и «ss»).
- `is` проверяет, один ли это объект, а не равенство значений. Для чисел и строк используйте `==`; `is` применяют только с `None` (`x is None`).
- Документация: https://docs.python.org/3/reference/expressions.html#comparisons
