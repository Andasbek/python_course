# Сабақ 19. Практикалық тапсырмалар: логикалық өрнектер

> `if` әлі өтілмеген: барлық жауаптарды `print()` арқылы `True`/`False` түрінде шығарыңыз. Алдымен нәтижені дәптерде **болжаңыз**, сосын бағдарламамен тексеріңіз.

## Базалық деңгей

### 1-тапсырма. «Болжа да тексер»
Әр өрнектің нәтижесін дәптерге жазыңыз, сосын Python-да тексеріңіз. Неше болжамыңыз дұрыс шықты?

```text
1)  8 > 12
2)  15 == 15.0
3)  3 * 4 != 12
4)  20 // 3 >= 6
5)  2 ** 5 < 30
6)  17 % 4 == 1
7)  "Python" == "python"
8)  "кітап" != "кітап "
9)  "abc" < "abd"
10) "100" < "25"
```

### 2-тапсырма. «Екі сан»
Пайдаланушы екі бүтін сан енгізеді. Бағдарлама алты салыстырудың бәрінің нәтижесін шығарады.

Мысал:
```text
a = 7
b = 3
7 == 3 : False
7 != 3 : True
7 > 3 : True
7 < 3 : False
7 >= 3 : True
7 <= 3 : False
```

### 3-тапсырма. «Жұп па?»
Пайдаланушы бүтін сан енгізеді. Бағдарлама оның жұп екенін, 3-ке бөлінетінін және 10-ға бөлінетінін тексереді.

Мысал:
```text
Сан: 30
Жұп: True
3-ке бөлінеді: True
10-ға бөлінеді: True
```

### 4-тапсырма. «Аттракцион»
Аттракционға бойы 120 см және одан жоғары балалар кіре алады. Бойды енгізіп, `Кіре алады: True/False` шығарыңыз.

### 5-тапсырма. «Құпиясөз»
Құпиясөз алдын ала бағдарламада сақталған: `qupiya = "Qazaq2026"`. Пайдаланушы құпиясөз енгізеді, бағдарлама `Құпиясөз дұрыс: True` немесе `False` шығарады.

## Кеңейтілген деңгей

### 6-тапсырма. «Сапарға ақша жете ме?»
Алматыдан Астанаға пойызбен бару билеті — `bilet` теңге, тамақ күніне — `tamaq` теңге, сапар — `kun` күн. Пайдаланушының ақшасы — `aqsha`. Барлық шығынды есептеп, ақшаның жететінін логикалық өрнекпен тексеріңіз. Сонымен қатар ақша **дәл** жетсе (артық та, кем де емес) ме — оны да шығарыңыз.

Мысал:
```text
Билет бағасы: 12000
Күнделікті тамақ: 4000
Неше күн: 3
Сіздің ақшаңыз: 25000
Барлық шығын: 24000 теңге
Ақша жетеді: True
Ақша дәл жетеді: False
```

### 7-тапсырма. «Қолайлы температура»
Бөлмедегі температура (бөлшек сан болуы мүмкін) енгізіледі. Тізбекті салыстыру арқылы оның 18-ден 24-ке дейінгі (шеттерін қоса) аралықта екенін тексеріңіз.

### 8-тапсырма. «Сөздердің реті»
Пайдаланушы екі сөз енгізеді. Бағдарлама сөздердің тең екенін және бірінші сөз сөздікте екіншісінен **бұрын** тұратынын тексереді. Сөздерді кіші әріпке келтіріп (`lower()`) салыстырыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Кібісе жыл»
Жыл кібісе болады, егер ол 4-ке бөлінсе, бірақ 100-ге бөлінбесе; немесе 400-ге бөлінсе. Әзірге `and`/`or` білмейміз, сондықтан үш логикалық айнымалы есептеңіз: `bol4`, `bol100`, `bol400` және әр шартты жеке шығарыңыз. 2024, 1900, 2000, 2026 жылдары үшін нәтижені кестеге жазып, қай жыл кібісе екенін өзіңіз анықтаңыз.

**Ойлан:** `True` мен `False` сан ретінде нені білдіреді? `print(True + True)`, `print(False * 10)`, `print(int(5 > 3))` нәтижелерін тексеріңіз. Осы қасиетті пайдаланып, бес тест сұрағының дұрыс жауаптарының санын `if`-сіз есептейтін бағдарлама жазыңыз (әр сұрақтың дұрыс жауабы бағдарламада сақталады, оқушының жауабымен `==` арқылы салыстырылады).

## Үй тапсырмасы

1. Өмірден 5 пікір жазып, оларды Python-ның логикалық өрнегіне айналдырыңыз. Мысалы: «Менің жасым 14-тен үлкен» → `jas > 14`.
2. Пайдаланушыдан екі пәннен алған бағасын (1–5) сұрап, бірінші бағаның екіншісінен жоғары екенін, бағалар тең екенін және екеуінің қосындысы 9-дан кем еместігін тексеретін бағдарлама жазыңыз.
