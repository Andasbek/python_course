## 1. Полное ветвление

**Полное ветвление** — алгоритм, в котором при выполнении условия совершается одно действие, а при невыполнении — **другое**. Обязательно выполняется **один и только один** из двух путей.

Примеры из жизни:
- **Если** идёт дождь, возьми зонт, **иначе** надень кепку от солнца.
- **Если** на экзамене набрал 50 баллов и больше — сдал, **иначе** — пересдаёшь.
- **Если** денег хватает — купи, **иначе** — продолжай копить.

### Блок-схема

```text
                ┌──────────┐
                │  Начало  │
                └────┬─────┘
                     ▼
                 ╱‾‾‾‾‾‾‾╲
      да ◄──── ╱ Условие? ╲ ────► нет
      │         ╲         ╱        │
      ▼          ╲_______╱         ▼
┌─────────────┐             ┌─────────────┐
│ Действие 1  │             │ Действие 2  │
└──────┬──────┘             └──────┬──────┘
       └────────────┬──────────────┘
                    ▼
              ┌──────────┐
              │  Конец   │
              └──────────┘
```

| | Сокращённое ветвление | Полное ветвление |
|---|---|---|
| Python | `if` | `if ... else` |
| Если условие `False` | ничего не делается | выполняется блок `else` |
| На блок-схеме | одна ветвь пустая | действия в обеих ветвях |

## 2. Синтаксис if...else

```text
if условие:
    блок 1 (если условие True)
else:
    блок 2 (если условие False)
следующая_команда
```

Правила:
1. `else` (англ. «иначе») пишется **на одном уровне** с `if` (без отступа).
2. После `else` **условие не пишется**, но **двоеточие** обязательно.
3. Блок `else` тоже пишется с отступом.
4. `else` не может стоять сам по себе, он всегда идёт после `if`.

```python
qupiya = "Qazaq2026"
engizildi = input("Пароль: ")
if engizildi == qupiya:
    print("Добро пожаловать!")
else:
    print("Неверный пароль! Попробуйте ещё раз.")
print("Программа завершена")
```

Результат (неверный пароль):
```text
Пароль: 12345
Неверный пароль! Попробуйте ещё раз.
Программа завершена
```

> Аналогия: развилка дороги. Путник (программа), глядя на условие, поворачивает **либо направо, либо налево**; он не может пойти по обеим дорогам сразу и не может остановиться. Потом обе дороги снова сходятся (следующая команда).

## 3. Классические примеры

### Чётное или нечётное

```python
n = int(input("Введите число: "))
if n % 2 == 0:
    print(n, "— чётное число")
else:
    print(n, "— нечётное число")
```

Результат:
```text
Введите число: 17
17 — нечётное число
```

### Большее из двух чисел

```python
a = int(input("a = "))
b = int(input("b = "))
if a > b:
    print("Большее:", a)
else:
    print("Большее:", b)
```

Если a = b, выполнится блок `else` — выведется `b`, которое равно a, то есть ответ верный. А если нужно отдельное сообщение «числа равны» — нужна третья ветвь (конструкция `elif`).

### Зачёт: сдал ли?

```python
ball = int(input("Балл за тест (0–100): "))
if ball >= 50:
    print("Поздравляем, вы сдали зачёт!")
    print("Выдаётся сертификат.")
else:
    print("К сожалению, вы не сдали зачёт.")
    print("Дата пересдачи: на следующей неделе.")
```

Строка «Выдаётся сертификат» находится внутри блока `if` и выводится только при сдаче, а сообщения о пересдаче — только в ветви `else`.

## 4. Вычисления внутри блока

В каждой ветви может быть не только `print`, а любые команды: вычисления, присваивание, даже `input`.

```python
# Стоимость такси: до 5 км — фиксированно 800 тенге,
# за каждый км сверх этого добавляется 150 тенге
km = float(input("Расстояние (км): "))
if km <= 5:
    baga = 800
else:
    baga = 800 + (km - 5) * 150
print(f"Стоимость поездки: {baga:.0f} тенге")
```

Результат:
```text
Расстояние (км): 12
Стоимость поездки: 1850 тенге
```

Обратите внимание: переменная `baga` получает значение **в обеих ветвях**, поэтому последний `print` всегда работает правильно.

### Защита от деления на ноль

```python
a = float(input("Делимое: "))
b = float(input("Делитель: "))
if b != 0:
    print("Частное:", a / b)
else:
    print("Ошибка: делить на ноль нельзя!")
```

## 5. Разница между двумя отдельными if и if...else

Две внешне похожие программы:

```python
# Вариант 1: два независимых if
n = 10
if n > 5:
    print("A")
    n = 0
if n <= 5:
    print("B")
```

Результат:
```text
A
B
```

```python
# Вариант 2: if...else
n = 10
if n > 5:
    print("A")
    n = 0
else:
    print("B")
```

Результат:
```text
A
```

В варианте 1 второй `if` проверяется **после** того, как первый блок изменил `n`, поэтому выполнились оба. В `if ... else` условие проверяется **один раз** и выполняется только одна ветвь. Кроме того, `if ... else` эффективнее: условие не проверяется дважды.

> Правило: если два варианта исключают друг друга («либо то, либо это») — пишите `if ... else`.

## 6. Условное выражение (тернарный оператор)

Для выбора значения есть краткая запись:

```text
значение_1 if условие else значение_2
```

```python
n = int(input("Число: "))
tur = "чётное" if n % 2 == 0 else "нечётное"
print(n, "—", tur)

a = 8
b = 13
ulken = a if a > b else b
print("Большее:", ulken)
```

Результат (n = 4):
```text
Число: 4
4 — чётное
Большее: 13
```

Это краткая запись только для **выбора значения**. Если в каждой ветви несколько действий, используйте обычный `if ... else`.

## 7. От блок-схемы к коду

Задача: «Если возраст меньше 16, вывести "Группа подростков", иначе — "Группа взрослых"».

1. Ввод: `jas`.
2. Ромб: `jas < 16`?
3. Ветвь «Да» → `print("Группа подростков")`.
4. Ветвь «Нет» → `print("Группа взрослых")`.

```python
jas = int(input("Ваш возраст: "))
if jas < 16:
    print("Группа подростков")
else:
    print("Группа взрослых")
```

## Частые ошибки

**1. Условие после `else`.**

```text
if n > 0:
    print("положительное")
else n <= 0:
    print("не положительное")
# SyntaxError: expected ':'
```

**2. `else` написан с отступом.**

```text
if n > 0:
    print("положительное")
    else:
    print("не положительное")
# SyntaxError: invalid syntax
```

**3. Нет двоеточия после `else`.**

```text
else
    print("не положительное")
# SyntaxError: expected ':'
```

**4. Строка вне блока между `if` и `else`.**

```text
if n > 0:
    print("положительное")
print("проверено")
else:
    print("не положительное")
# SyntaxError: invalid syntax — else «потерял» свой if
```

Правильно:

```python
n = int(input("n = "))
if n > 0:
    print("положительное")
else:
    print("не положительное")
print("проверено")
```

**5. Переменная определена только в одной ветви.**

```text
if km > 5:
    baga = 800 + (km - 5) * 150
print(baga)   # если km <= 5 — NameError: name 'baga' is not defined
```

Решение: задайте значение и в ветви `else` или задайте начальное значение до `if`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Полное ветвление | Если условие `True` — одно действие, если `False` — другое |
| `else` | «Иначе» — блок на случай, когда условие не выполнено |
| Ветвь | Группа команд, соответствующая одному варианту условия |
| Условное выражение | `x if условие else y` — выбор значения в зависимости от условия |
| Взаимоисключающие случаи | Условия, которые не могут быть истинными одновременно (чётное/нечётное) |

## Примечание

- Условное выражение `a if cond else b` вычисляет только одну из двух ветвей: в `x / y if y != 0 else 0` деления на ноль не будет.
- Вложенные тернарные выражения (`a if c1 else b if c2 else d`) допустимы, но читаются плохо — в таких случаях лучше обычный `if ... elif ... else`.
- Для выбора большего/меньшего значения есть встроенные функции: `max(a, b)` и `min(a, b)` — они короче, чем `a if a > b else b`.
- Вместо проверки `if b != 0` перед делением можно использовать обработку исключений `try ... except ZeroDivisionError` — этот подход называют EAFP («проще попросить прощения, чем разрешения»).
- Если одна ветвь заканчивается `return` (внутри функции), `else` часто можно опустить — так код получается менее вложенным.
- Документация: https://docs.python.org/3/reference/expressions.html#conditional-expressions
