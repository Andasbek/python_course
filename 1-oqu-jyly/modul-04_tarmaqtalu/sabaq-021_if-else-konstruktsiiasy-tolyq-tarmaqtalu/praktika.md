# Сабақ 21. Практикалық тапсырмалар: if...else

> Әр бағдарламаны екі тармақты да тексеретіндей кемінде екі мәнмен іске қосыңыз. `elif` әлі өтілмеген.

## Базалық деңгей

### 1-тапсырма. «Жұп немесе тақ»
Сан енгізіледі, бағдарлама оның жұп немесе тақ екенін шығарады.

```text
Сан: 27
27 — тақ сан
```

### 2-тапсырма. «Құпиясөз»
Сақталған құпиясөзбен салыстырып, «Кіру рұқсат етілді» немесе «Кіру тыйым салынған» шығарыңыз.

### 3-тапсырма. «Оң немесе оң емес»
Сан енгізіледі. Сан 0-ден үлкен болса — «Оң сан», әйтпесе — «Оң сан емес».

### 4-тапсырма. «Сайлау»
Азаматтың жасын енгізіңіз. 18 және одан үлкен болса — «Сайлауға қатыса алады», әйтпесе — «Сайлауға дейін ... жыл қалды» (қалған жылды есептеңіз).

```text
Жасыңыз: 14
Сайлауға дейін 4 жыл қалды
```

### 5-тапсырма. «Ақша жете ме?»
Смартфонның бағасы мен пайдаланушының ақшасы енгізіледі. Жетсе — «Сатып алуға болады, қалдық: ... теңге», жетпесе — «Тағы ... теңге жинау керек».

## Кеңейтілген деңгей

### 6-тапсырма. «Мобильдік тариф»
Тариф: айына 3000 теңге, оған 10 ГБ интернет кіреді. Пайдаланушы осы айда неше ГБ жұмсағанын енгізеді. Егер 10 ГБ-тан асса, әр артық ГБ үшін 250 теңге қосылады. Айлық төлемді шығарыңыз.

```text
Жұмсалған интернет (ГБ): 13
Төлем: 3750 теңге
```

### 7-тапсырма. «Кібісе жыл»
Жыл енгізіледі. Әзірге `and`/`or` білмейміз, сондықтан алдымен `if ... else` арқылы ақпаратты бөлек айнымалыларға жинаңыз немесе шартты өрнекті қолданыңыз. Кеңес: `jyl % 400 == 0` — кібісе; әйтпесе `jyl % 100 == 0` — кібісе емес; әйтпесе `jyl % 4 == 0` — кібісе. Бұл үшін `else` ішіне тағы `if ... else` жазуға болады (кірістірілген шарт — алдағы сабақтардың тақырыбы, бірақ сынап көріңіз).

### 8-тапсырма. «Шартты өрнек»
Екі санды енгізіп, олардың кішісін **бір жолда** шартты өрнекпен (`... if ... else ...`) табыңыз. Сосын санның модулін де шартты өрнекпен табыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Автобус орындары»
Автобуста 45 орын бар. Пайдаланушы мектептің экскурсияға баратын оқушылар санын енгізеді. Бағдарлама неше автобус керек екенін есептейді (бүтін санға жоғары дөңгелектеу!) және соңғы автобуста неше бос орын қалатынын шығарады. Кеңес: `oqushy % 45 == 0` болса, автобус саны `oqushy // 45`, әйтпесе `oqushy // 45 + 1`.

```text
Оқушылар саны: 100
Автобус саны: 3
Соңғы автобуста бос орын: 35
```

### 10-тапсырма. «Turtle: жұп/тақ»
Сан енгізіледі. Жұп болса — тасбақа көк шаршы салады, тақ болса — қызыл үшбұрыш салады. Фигураның астына санды және оның түрін `write` арқылы жазыңыз.

## Үй тапсырмасы

1. Үш өмірлік «егер … әйтпесе …» жағдайын бағдарламаға айналдырыңыз.
2. «Екі санның қайсысы үлкен» бағдарламасын шартты өрнекпен (бір `print`-пен) жазыңыз.
3. Ойланыңыз: бағдарлама «оң», «теріс» және «нөл» деген **үш** жауаптың бірін беруі керек. Мұны `if ... else` арқылы қалай жасауға болады? Келесі сабақта тексереміз.

**7-тапсырма** (кірістірілген `if ... else` арқылы).

```python
jyl = int(input("Жыл: "))
if jyl % 400 == 0:
    print(jyl, "— кібісе жыл")
else:
    if jyl % 100 == 0:
        print(jyl, "— кібісе жыл емес")
    else:
        if jyl % 4 == 0:
            print(jyl, "— кібісе жыл")
        else:
            print(jyl, "— кібісе жыл емес")
```

Ескерту: бұл кодты 22-сабақта `elif`, 23-сабақта `and`/`or` арқылы ықшамдаймыз — оқушыларға осыны айтыңыз.

**8-тапсырма.**

```python
a = int(input("a = "))

kishi = a if a < b else b
print("Кішісі:", kishi)
x = int(input("x = "))
modul = x if x >= 0 else -x
print("|x| =", modul)
```

**9-тапсырма.**

```python
oqushy = int(input("Оқушылар саны: "))
if oqushy % 45 == 0:
    avtobus = oqushy // 45
```
