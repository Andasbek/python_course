## 1. Толық тармақталу

**Толық тармақталу** — шарт орындалса бір әрекет, орындалмаса **басқа** әрекет жасалатын алгоритм. Екі жолдың **біреуі және тек біреуі** міндетті түрде орындалады.

Өмірлік мысалдар:
- **Егер** жаңбыр жауса, қолшатыр ал, **әйтпесе** күннен қорғайтын кепка ки.
- **Егер** емтиханнан 50 балл және одан көп алсаң — өттің, **әйтпесе** — қайта тапсырасың.
- **Егер** ақша жетсе — сатып ал, **әйтпесе** — жинай бер.

### Блок-схемасы

```text
                ┌──────────┐
                │   Басы   │
                └────┬─────┘
                     ▼
                 ╱‾‾‾‾‾‾‾╲
      иә ◄──── ╱  Шарт?   ╲ ────► жоқ
      │         ╲         ╱        │
      ▼          ╲_______╱         ▼
┌─────────────┐             ┌─────────────┐
│  1-әрекет   │             │  2-әрекет   │
└──────┬──────┘             └──────┬──────┘
       └────────────┬──────────────┘
                    ▼
              ┌──────────┐
              │   Соңы   │
              └──────────┘
```

| | Қысқа тармақталу | Толық тармақталу |
|---|---|---|
| Python | `if` | `if ... else` |
| Шарт `False` болса | ештеңе жасалмайды | `else` блогы орындалады |
| Блок-схемада | бір тармақ бос | екі тармақта да әрекет |

## 2. if...else синтаксисі

```text
if шарт:
    1-блок (шарт True болса)
else:
    2-блок (шарт False болса)
келесі_команда
```

Ережелері:
1. `else` (ағылш. «әйтпесе») — `if`-пен **бір деңгейде** (шегініссіз) жазылады.
2. `else`-тен кейін **шарт жазылмайды**, бірақ **қос нүкте** міндетті.
3. `else` блогы да шегініспен жазылады.
4. `else` өздігінен тұра алмайды, ол әрқашан `if`-тен кейін келеді.

```python
qupiya = "Qazaq2026"
engizildi = input("Құпиясөз: ")
if engizildi == qupiya:
    print("Қош келдіңіз!")
else:
    print("Құпиясөз қате! Қайта көріңіз.")
print("Бағдарлама аяқталды")
```

Нәтижесі (қате құпиясөз):
```text
Құпиясөз: 12345
Құпиясөз қате! Қайта көріңіз.
Бағдарлама аяқталды
```

> Аналогия: жол айырығы. Жолаушы (бағдарлама) шартқа қарап **не оңға, не солға** бұрылады; екі жолға бірдей бара алмайды және тоқтап та қалмайды. Екі жол кейін қайта қосылады (келесі команда).

## 3. Классикалық мысалдар

### Жұп немесе тақ

```python
n = int(input("Сан енгізіңіз: "))
if n % 2 == 0:
    print(n, "— жұп сан")
else:
    print(n, "— тақ сан")
```

Нәтижесі:
```text
Сан енгізіңіз: 17
17 — тақ сан
```

### Екі санның үлкені

```python
a = int(input("a = "))
b = int(input("b = "))
if a > b:
    print("Үлкені:", a)
else:
    print("Үлкені:", b)
```

a = b болса, `else` блогы орындалады — `b` шығады, ол a-ға тең, яғни жауап дұрыс. Ал «сандар тең» деген бөлек хабарлама керек болса — үшінші тармақ қажет (`elif` конструкциясы).

### Сынақ: өтті ме?

```python
ball = int(input("Тест балы (0–100): "))
if ball >= 50:
    print("Құттықтаймыз, сынақтан өттіңіз!")
    print("Сертификат беріледі.")
else:
    print("Өкінішке орай, сынақтан өтпедіңіз.")
    print("Қайта тапсыру күні: келесі аптада.")
```

«Сертификат беріледі» жолы `if` блогының ішінде, сондықтан тек өткенде ғана шығады, ал қайта тапсыру туралы хабарламалар — тек `else` тармағында.

## 4. Блок ішінде есептеу

Әр тармақта тек `print` емес, кез келген командалар болуы мүмкін: есептеу, меншіктеу, тіпті `input`.

```python
# Такси бағасы: 5 км-ге дейін — тұрақты 800 теңге,
# одан артық әр км үшін — 150 теңге қосылады
km = float(input("Қашықтық (км): "))
if km <= 5:
    baga = 800
else:
    baga = 800 + (km - 5) * 150
print(f"Жол ақысы: {baga:.0f} теңге")
```

Нәтижесі:
```text
Қашықтық (км): 12
Жол ақысы: 1850 теңге
```

Байқаңыз: `baga` айнымалысы **екі тармақта да** мән алады, сондықтан соңғы `print` әрқашан дұрыс жұмыс істейді.

### Нөлге бөлуден қорғау

```python
a = float(input("Бөлінгіш: "))
b = float(input("Бөлгіш: "))
if b != 0:
    print("Бөлінді:", a / b)
else:
    print("Қате: нөлге бөлуге болмайды!")
```

## 5. Екі бөлек if пен if...else айырмашылығы

Сырттай ұқсас екі бағдарлама:

```python
# 1-нұсқа: екі тәуелсіз if
n = 10
if n > 5:
    print("A")
    n = 0
if n <= 5:
    print("B")
```

Нәтижесі:
```text
A
B
```

```python
# 2-нұсқа: if...else
n = 10
if n > 5:
    print("A")
    n = 0
else:
    print("B")
```

Нәтижесі:
```text
A
```

1-нұсқада екінші `if` бірінші блок `n`-ді өзгерткеннен **кейін** тексеріледі, сондықтан екеуі де орындалды. `if ... else`-те шарт **бір рет** тексеріледі және тек бір тармақ орындалады. Сонымен қатар `if ... else` тиімдірек: шарт екі рет тексерілмейді.

> Ереже: екі нұсқа бір-бірін жоққа шығарса («не ол, не бұл») — `if ... else` жазыңыз.

## 6. Шартты өрнек (тернарлы оператор)

Мәнді таңдау үшін қысқа жазу бар:

```text
мән_1 if шарт else мән_2
```

```python
n = int(input("Сан: "))
tur = "жұп" if n % 2 == 0 else "тақ"
print(n, "—", tur)

a = 8
b = 13
ulken = a if a > b else b
print("Үлкені:", ulken)
```

Нәтижесі (n = 4):
```text
Сан: 4
4 — жұп
Үлкені: 13
```

Бұл — тек **мәнді таңдауға** арналған қысқа жазба. Әр тармақта бірнеше әрекет болса, кәдімгі `if ... else` қолданыңыз.

## 7. Блок-схемадан кодқа

Есеп: «Жасы 16-дан кіші болса, "Жасөспірімдер тобы", әйтпесе "Ересектер тобы" деп шығар».

1. Енгізу: `jas`.
2. Ромб: `jas < 16`?
3. «Иә» тармағы → `print("Жасөспірімдер тобы")`.
4. «Жоқ» тармағы → `print("Ересектер тобы")`.

```python
jas = int(input("Жасыңыз: "))
if jas < 16:
    print("Жасөспірімдер тобы")
else:
    print("Ересектер тобы")
```

## Жиі кездесетін қателер

**1. `else`-ке шарт жазу.**

```text
if n > 0:
    print("оң")
else n <= 0:
    print("оң емес")
# SyntaxError: expected ':'
```

**2. `else` шегініспен жазылған.**

```text
if n > 0:
    print("оң")
    else:
    print("оң емес")
# SyntaxError: invalid syntax
```

**3. `else`-тен кейін қос нүкте жоқ.**

```text
else
    print("оң емес")
# SyntaxError: expected ':'
```

**4. `if` пен `else` арасына блоктан тыс жол кірістіру.**

```text
if n > 0:
    print("оң")
print("тексерілді")
else:
    print("оң емес")
# SyntaxError: invalid syntax — else өз if-ін «жоғалтты»
```

Дұрысы:

```python
n = int(input("n = "))
if n > 0:
    print("оң")
else:
    print("оң емес")
print("тексерілді")
```

**5. Айнымалы тек бір тармақта анықталған.**

```text
if km > 5:
    baga = 800 + (km - 5) * 150
print(baga)   # km <= 5 болса — NameError: name 'baga' is not defined
```

Шешімі: `else` тармағында да мән беріңіз немесе `if`-ке дейін бастапқы мән беріңіз.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Толық тармақталу | Шарт `True` болса бір әрекет, `False` болса басқа әрекет |
| `else` | «Әйтпесе» — шарт орындалмаған жағдайдағы блок |
| Тармақ | Шарттың бір нұсқасына сәйкес командалар тобы |
| Шартты өрнек | `x if шарт else y` — шартқа қарай мән таңдау |
| Өзара жоққа шығаратын жағдайлар | Бір мезгілде ақиқат бола алмайтын шарттар (жұп/тақ) |

## Ескерту

- `a if cond else b` шартты өрнегі екі тармақтың біреуін ғана есептейді: `x / y if y != 0 else 0` өрнегінде нөлге бөлу болмайды.
- Кірістірілген тернарлы өрнектер (`a if c1 else b if c2 else d`) рұқсат етілген, бірақ қиын оқылады — мұндай жағдайда кәдімгі `if ... elif ... else` жақсырақ.
- Үлкен/кіші мәнді таңдау үшін кіріктірілген функциялар бар: `max(a, b)` және `min(a, b)` — олар `a if a > b else b` жазуынан қысқа.
- Бөлу алдында `if b != 0` тексерудің орнына `try ... except ZeroDivisionError` ерекшеліктерді өңдеуді қолдануға болады — бұл тәсіл EAFP («рұқсат сұрағаннан гөрі кешірім сұраған оңай») деп аталады.
- Егер бір тармақ (функция ішінде) `return`-мен аяқталса, `else`-ті жиі алып тастауға болады — код аз кірістірілген болады.
- Құжаттама: https://docs.python.org/3/reference/expressions.html#conditional-expressions
