# Урок 21. Практические задания: if...else

> Запускайте каждую программу хотя бы с двумя значениями так, чтобы проверить обе ветви. `elif` ещё не изучен.

## Базовый уровень

### Задание 1. «Чётное или нечётное»
Вводится число, программа выводит, чётное оно или нечётное.

```text
Число: 27
27 — нечётное число
```

### Задание 2. «Пароль»
Сравните с сохранённым паролем и выведите «Доступ разрешён» или «Доступ запрещён».

### Задание 3. «Положительное или нет»
Вводится число. Если число больше 0 — «Положительное число», иначе — «Не положительное число».

### Задание 4. «Выборы»
Введите возраст гражданина. Если 18 и больше — «Может участвовать в выборах», иначе — «До выборов осталось ... лет» (вычислите оставшиеся годы).

```text
Ваш возраст: 14
До выборов осталось 4 лет
```

### Задание 5. «Хватит ли денег?»
Вводятся цена смартфона и деньги пользователя. Если хватает — «Можно купить, остаток: ... тенге», если не хватает — «Нужно накопить ещё ... тенге».

## Продвинутый уровень

### Задание 6. «Мобильный тариф»
Тариф: 3000 тенге в месяц, в него входит 10 ГБ интернета. Пользователь вводит, сколько ГБ он израсходовал в этом месяце. Если больше 10 ГБ, за каждый лишний ГБ добавляется 250 тенге. Выведите месячную оплату.

```text
Израсходовано интернета (ГБ): 13
Оплата: 3750 тенге
```

### Задание 7. «Високосный год»
Вводится год. Пока мы не знаем `and`/`or`, поэтому сначала соберите информацию в отдельные переменные с помощью `if ... else` или используйте условное выражение. Подсказка: `jyl % 400 == 0` — високосный; иначе `jyl % 100 == 0` — не високосный; иначе `jyl % 4 == 0` — високосный. Для этого внутри `else` можно написать ещё один `if ... else` (вложенные условия — тема следующих уроков, но попробуйте).

### Задание 8. «Условное выражение»
Введите два числа и найдите меньшее из них **в одной строке** с помощью условного выражения (`... if ... else ...`). Затем найдите модуль числа тоже с помощью условного выражения.

## ★ Олимпиадная / творческая задача

### Задание 9. «Места в автобусе»
В автобусе 45 мест. Пользователь вводит число учеников школы, едущих на экскурсию. Программа вычисляет, сколько нужно автобусов (округление вверх до целого!), и выводит, сколько свободных мест останется в последнем автобусе. Подсказка: если `oqushy % 45 == 0`, число автобусов `oqushy // 45`, иначе `oqushy // 45 + 1`.

```text
Количество учеников: 100
Количество автобусов: 3
Свободных мест в последнем автобусе: 35
```

### Задание 10. «Turtle: чётное/нечётное»
Вводится число. Если оно чётное — черепашка рисует синий квадрат, если нечётное — красный треугольник. Под фигурой с помощью `write` напишите число и его вид.

**Задание 7** (с помощью вложенных `if ... else`).

```python
jyl = int(input("Год: "))
if jyl % 400 == 0:
    print(jyl, "— високосный год")
else:
    if jyl % 100 == 0:
        print(jyl, "— не високосный год")
    else:
        if jyl % 4 == 0:
            print(jyl, "— високосный год")
        else:
            print(jyl, "— не високосный год")
```

Примечание: этот код мы упростим на 22-м уроке с помощью `elif`, а на 23-м — с помощью `and`/`or`; скажите об этом ученикам.

    t.color("blue", "lightblue")
