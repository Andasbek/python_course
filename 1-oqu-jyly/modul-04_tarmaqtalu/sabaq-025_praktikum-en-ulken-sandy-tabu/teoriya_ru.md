## 1. Шпаргалка по ветвлению

### Сравнение и логические операции

| Оператор | Значение | Оператор | Значение |
|---|---|---|---|
| `==` | равно | `!=` | не равно |
| `>` / `<` | больше / меньше | `>=` / `<=` | больше или равно / меньше или равно |
| `and` | и (оба) | `or` | или (достаточно одного) |
| `not` | не (наоборот) | `a <= x <= b` | цепочка сравнений |

Приоритет: арифметика → сравнение → `not` → `and` → `or`.

### Виды условных операторов

```text
# Сокращённое      # Полное            # Множественное         # Вложенное
if условие:        if условие:         if условие1:            if условие1:
    действие           действие1           действие1               if условие2:
                   else:               elif условие2:                  действие
                       действие2           действие2               else:
                                       else:                           действие
                                           действие3
```

### Условное выражение

```python
n = 7
tur = "чётное" if n % 2 == 0 else "нечётное"
print(tur)
```

### Частые ошибки — список

- забыто `:`; нет отступа или он разный;
- путаница `=` и `==`;
- `else if` (правильно `elif`); условие после `else`;
- результат `input()` не преобразован в `int()`;
- `x == 1 or 2` (правильно `x == 1 or x == 2`);
- неверный порядок условий `elif`; не учтены граничные значения (`>` вместо `>=`).

## 2. Алгоритм решения задачи на ветвление

1. **Прочитать условие.** Что вводится? Что нужно вывести?
2. **Определить случаи.** Сколько вариантов? Какими условиями они различаются? Нанесите диапазоны на числовую ось.
3. **Выбрать конструкцию.**
   - один вариант → `if`; два варианта → `if ... else`; много вариантов → `if/elif/else`;
   - условия независимы → несколько `if`;
   - внутренняя проверка имеет смысл только в определённом случае → вложенное условие.
4. **Написать код.** Понятные имена переменных; при вводе `int()`/`float()`.
5. **Тестирование.** Хотя бы один тест на каждую ветвь + граничные значения + неверный ввод.

### Образец тестовой таблицы

| № | Ввод | Ожидаемый вывод | Полученный вывод | ✓/✗ |
|---|---|---|---|---|
| 1 | ... | ... | ... | |

## 3. Задача 1: «Поиск наибольшего числа»

**Условие:** вводятся три числа. Нужно найти наибольшее.

### Способ 1: сравнение (and)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
if a >= b and a >= c:
    ulken = a
elif b >= a and b >= c:
    ulken = b
else:
    ulken = c
print("Наибольшее:", ulken)
```

Почему `>=`, а не `>`? Если `a = b = 5`, `c = 2`, то с `>` оба первых условия окажутся ложными, и будет ошибочно выбрано `c`!

### Способ 2: «предположи и проверь» (самый универсальный)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
ulken = a
if b > ulken:
    ulken = b
if c > ulken:
    ulken = c
print("Наибольшее:", ulken)
```

Этот способ легко расширяется при увеличении количества чисел: на каждое новое число — ещё один `if`, а в цикле — одна и та же проверка для каждого элемента. В Python есть и готовая функция `max(a, b, c)`, но понимание самого алгоритма нужно, когда готовой функции нет (например, при поиске по особому правилу).

### Тестовая таблица

| № | a, b, c | Ожидается | Что проверяет |
|---|---|---|---|
| 1 | 9, 4, 1 | 9 | наибольшее первое |
| 2 | 2, 8, 5 | 8 | в середине |
| 3 | 1, 3, 7 | 7 | в конце |
| 4 | 5, 5, 2 | 5 | равные числа |
| 5 | −4, −9, −1 | −1 | отрицательные числа |

## 4. Задача 2: «Цена билета»

**Условие:** базовая цена билета в кинотеатр — 2500 тг. Скидки:
- до 7 лет — бесплатно;
- 7–17 лет — скидка 50%;
- 65 лет и старше — скидка 30%;
- если сеанс в среду — дополнительная скидка 500 тг **для всех** (цена не должна быть отрицательной);
- возраст меньше 0 или больше 120 — «Ошибка ввода».

**Анализ:** по возрасту — множественный выбор (`elif`); по дню — независимое условие (отдельный `if`); ошибочный ввод — сторожевое условие.

```python
negizgi = 2500
jas = int(input("Ваш возраст: "))
kun = input("День недели: ").lower()

if jas < 0 or jas > 120:
    print("Ошибка ввода")
else:
    if jas < 7:
        baga = 0
    elif jas <= 17:
        baga = negizgi * 50 // 100
    elif jas >= 65:
        baga = negizgi * 70 // 100
    else:
        baga = negizgi
    if kun == "среда":
        baga = baga - 500
        if baga < 0:
            baga = 0
    print("Цена билета:", baga, "тг")
```

Результат:
```text
Ваш возраст: 12
День недели: среда
Цена билета: 750 тг
```

Граничные значения для тестовой таблицы: 6, 7, 17, 18, 64, 65, −1, 121; день — «среда» и другой день.

## 5. Задача 3: «Программа-тест»

**Условие:** программа задаёт 5 вопросов по Python, каждый правильный ответ — 1 балл. В конце выводятся количество баллов, процент и оценка (5 баллов → «5», 4 → «4», 3 → «3», остальное → «2»).

**Анализ:** каждый вопрос — независимый `if` (накопление баллов, то есть переменная-**накопитель**); оценивание — `elif`.

```python
upai = 0
print("=== Тест по Python ===")

j = input("1. Как называется тип целого числа? ").lower()
if j == "int":
    upai = upai + 1
    print("Верно!")
else:
    print("Неверно. Правильный ответ: int")

j = input("2. Чему равно 17 % 5? ")
if j == "2":
    upai = upai + 1
    print("Верно!")
else:
    print("Неверно. Правильный ответ: 2")

j = input("3. Как в Python записывается «иначе, если»? ").lower()
if j == "elif":
    upai = upai + 1
    print("Верно!")
else:
    print("Неверно. Правильный ответ: elif")

j = input("4. True and False = ? ").lower()
if j == "false":
    upai = upai + 1
    print("Верно!")
else:
    print("Неверно. Правильный ответ: False")

j = input("5. Команда, которая двигает черепашку вперёд? ").lower()
if j == "forward" or j == "fd":
    upai = upai + 1
    print("Верно!")
else:
    print("Неверно. Правильный ответ: forward")

paiyz = upai * 100 // 5
if upai == 5:
    baga = 5
elif upai == 4:
    baga = 4
elif upai == 3:
    baga = 3
else:
    baga = 2
print(f"Результат: {upai}/5 ({paiyz}%), ваша оценка: {baga}")
```

Примечание: `.lower()` использован для того, чтобы ответы не зависели от регистра букв (`False`, `false`, `FALSE` — все верны).

## Частые ошибки

**1. Не задано начальное значение накопителя.**

```text
if j == "int":
    upai = upai + 1    # NameError: name 'upai' is not defined
```

Решение: в начале программы `upai = 0`.

**2. Сравнение введённого ответа с числом.**

```text
j = input("17 % 5 = ? ")
if j == 2:           # всегда False: "2" (str) != 2 (int)
```

Решение: `j == "2"` или `int(j) == 2`.

**3. В задаче о билете скидка записана внутри ветви возраста.** Скидка среды должна применяться ко **всем** возрастным группам — это отдельный `if` **после** цепочки `elif`.

**4. Использование `>` в задаче о наибольшем числе** (ошибка при равных числах, см. раздел 3).

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Тестовый случай | Набор входных данных и ожидаемый результат для проверки программы |
| Тестовая таблица | Таблица вводимых данных, ожидаемых и полученных результатов |
| Граничное значение | Значение на краю диапазона, там чаще всего бывают ошибки |
| Сторожевое условие | Проверка неверного ввода в первую очередь |
| Накопитель | Переменная, значение которой постепенно увеличивается (`upai = upai + 1`) |

## Примечание

- `max()` и `min()` принимают любое число аргументов (`max(a, b, c, d)`) и имеют параметр `key`: `max("кот", "собака", key=len)` вернёт самую длинную строку.
- Если пользователь введёт не число, `int(input())` вызовет `ValueError`. Проверить строку заранее можно методом `s.isdigit()` (только для неотрицательных целых) или обработать ошибку через `try ... except ValueError`.
- Запись `upai = upai + 1` можно сократить до `upai += 1` — это составное присваивание (также `-=`, `*=`, `//=`).
- Для расчётов с деньгами `//` отбрасывает дробную часть; если нужны копейки/тиыны, используйте `round(x, 2)` или модуль `decimal`, а не `float` для точных сумм.
- Тестовые таблицы можно превратить в автоматические проверки: вынесите расчёт в функцию и проверяйте её через `assert bilet_baga(12, "среда") == 750`.
- Документация по встроенным функциям: https://docs.python.org/3/library/functions.html
