## 1. Тармақталу бойынша шпаргалка

### Салыстыру және логикалық амалдар

| Оператор | Мағынасы | Оператор | Мағынасы |
|---|---|---|---|
| `==` | тең | `!=` | тең емес |
| `>` / `<` | үлкен / кіші | `>=` / `<=` | үлкен-тең / кіші-тең |
| `and` | және (екеуі де) | `or` | немесе (біреуі жеткілікті) |
| `not` | емес (керісінше) | `a <= x <= b` | тізбекті салыстыру |

Басымдық: арифметика → салыстыру → `not` → `and` → `or`.

### Шартты операторлардың түрлері

```text
# Қысқа            # Толық             # Көп тармақты           # Кірістірілген
if шарт:           if шарт:            if шарт1:                if шарт1:
    әрекет             әрекет1             әрекет1                  if шарт2:
                   else:               elif шарт2:                      әрекет
                       әрекет2             әрекет2                  else:
                                       else:                            әрекет
                                           әрекет3
```

### Шартты өрнек

```python
n = 7
tur = "жұп" if n % 2 == 0 else "тақ"
print(tur)
```

### Жиі қателер — тізім

- `:` ұмыту; шегініс жоқ немесе әртүрлі;
- `=` мен `==` шатастыру;
- `else if` (дұрысы `elif`); `else`-ке шарт жазу;
- `input()` нәтижесін `int()`-ке айналдырмау;
- `x == 1 or 2` (дұрысы `x == 1 or x == 2`);
- `elif` шарттарының қате реті; шекаралық мәндерді (`>` орнына `>=`) ескермеу.

## 2. Тармақталу есебін шығару алгоритмі

1. **Шартты оқу.** Не енгізіледі? Не шығарылуы керек?
2. **Жағдайларды анықтау.** Неше нұсқа бар? Қандай шарттармен ажыратылады? Аралықтарды сан осіне салыңыз.
3. **Конструкцияны таңдау.**
   - бір нұсқа → `if`; екі нұсқа → `if ... else`; көп нұсқа → `if/elif/else`;
   - шарттар тәуелсіз → бірнеше `if`;
   - ішкі тексеру тек белгілі жағдайда мағыналы → кірістірілген шарт.
4. **Код жазу.** Айнымалыларға түсінікті атаулар; енгізуде `int()`/`float()`.
5. **Тестілеу.** Әр тармаққа кемінде бір тест + шекаралық мәндер + қате енгізу.

### Тест-кесте үлгісі

| № | Енгізу | Күтілетін шығыс | Алынған шығыс | ✓/✗ |
|---|---|---|---|---|
| 1 | ... | ... | ... | |

## 3. 1-есеп: «Ең үлкен санды табу»

**Шарты:** үш сан енгізіледі. Ең үлкенін табу керек.

### 1-тәсіл: салыстыру (and)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
if a >= b and a >= c:
    ulken = a
elif b >= a and b >= c:
    ulken = b
else:
    ulken = c
print("Ең үлкені:", ulken)
```

Неге `>=`, `>` емес? Егер `a = b = 5`, `c = 2` болса, `>` қолдансақ бірінші екі шарт та жалған болып, қате түрде `c` таңдалады!

### 2-тәсіл: «болжа да, тексер» (ең әмбебап)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))
ulken = a
if b > ulken:
    ulken = b
if c > ulken:
    ulken = c
print("Ең үлкені:", ulken)
```

Бұл тәсіл сандар саны көбейгенде де оңай кеңейеді: әр жаңа санға — тағы бір `if`, ал циклде — әр элемент үшін бір ғана тексеру. Python-да дайын `max(a, b, c)` функциясы да бар, бірақ алгоритмнің өзін түсіну дайын функция жоқ кезде керек (мысалы, ерекше ереже бойынша іздегенде).

### Тест-кесте

| № | a, b, c | Күтілетін | Не тексереді |
|---|---|---|---|
| 1 | 9, 4, 1 | 9 | ең үлкені бірінші |
| 2 | 2, 8, 5 | 8 | ортада |
| 3 | 1, 3, 7 | 7 | соңында |
| 4 | 5, 5, 2 | 5 | тең сандар |
| 5 | −4, −9, −1 | −1 | теріс сандар |

## 4. 2-есеп: «Билет бағасы»

**Шарты:** кинотеатрдағы билеттің негізгі бағасы — 2500 тг. Жеңілдіктер:
- 7 жасқа дейін — тегін;
- 7–17 жас — 50% жеңілдік;
- 65 және одан жоғары — 30% жеңілдік;
- сеанс сәрсенбіде болса — **барлығына** қосымша 500 тг жеңілдік (баға теріс болмауы керек);
- жас 0-ден кіші немесе 120-дан үлкен — «Қате енгізу».

**Талдау:** жас бойынша — көп тармақты таңдау (`elif`); күн бойынша — тәуелсіз шарт (бөлек `if`); қате енгізу — күзетші шарт.

```python
negizgi = 2500
jas = int(input("Жасыңыз: "))
kun = input("Апта күні: ").lower()

if jas < 0 or jas > 120:
    print("Қате енгізу")
else:
    if jas < 7:
        baga = 0
    elif jas <= 17:
        baga = negizgi * 50 // 100
    elif jas >= 65:
        baga = negizgi * 70 // 100
    else:
        baga = negizgi
    if kun == "сәрсенбі":
        baga = baga - 500
        if baga < 0:
            baga = 0
    print("Билет бағасы:", baga, "тг")
```

Нәтижесі:
```text
Жасыңыз: 12
Апта күні: сәрсенбі
Билет бағасы: 750 тг
```

Тест-кесте үшін шекаралық мәндер: 6, 7, 17, 18, 64, 65, −1, 121; күн — «сәрсенбі» және басқа күн.

## 5. 3-есеп: «Тест бағдарламасы»

**Шарты:** бағдарлама Python бойынша 5 сұрақ қояды, әр дұрыс жауап — 1 ұпай. Соңында ұпай саны, пайызы және бағасы шығады (5 ұпай → «5», 4 → «4», 3 → «3», қалғаны → «2»).

**Талдау:** әр сұрақ — тәуелсіз `if` (ұпайды жинау, яғни **жинауыш** айнымалы); бағалау — `elif`.

```python
upai = 0
print("=== Python бойынша тест ===")

j = input("1. Бүтін сан типі қалай аталады? ").lower()
if j == "int":
    upai = upai + 1
    print("Дұрыс!")
else:
    print("Қате. Дұрыс жауап: int")

j = input("2. 17 % 5 неге тең? ")
if j == "2":
    upai = upai + 1
    print("Дұрыс!")
else:
    print("Қате. Дұрыс жауап: 2")

j = input("3. «Әйтпесе, егер» Python-да қалай жазылады? ").lower()
if j == "elif":
    upai = upai + 1
    print("Дұрыс!")
else:
    print("Қате. Дұрыс жауап: elif")

j = input("4. True and False = ? ").lower()
if j == "false":
    upai = upai + 1
    print("Дұрыс!")
else:
    print("Қате. Дұрыс жауап: False")

j = input("5. Тасбақаны алға жүргізетін команда? ").lower()
if j == "forward" or j == "fd":
    upai = upai + 1
    print("Дұрыс!")
else:
    print("Қате. Дұрыс жауап: forward")

paiyz = upai * 100 // 5
if upai == 5:
    baga = 5
elif upai == 4:
    baga = 4
elif upai == 3:
    baga = 3
else:
    baga = 2
print(f"Нәтиже: {upai}/5 ({paiyz}%), бағаңыз: {baga}")
```

Ескерту: `.lower()` жауаптардың бас/кіші әріппен жазылуына тәуелсіз болуы үшін қолданылды (`False`, `false`, `FALSE` — бәрі дұрыс).

## Жиі кездесетін қателер

**1. Жинауыштың бастапқы мәнін бермеу.**

```text
if j == "int":
    upai = upai + 1    # NameError: name 'upai' is not defined
```

Шешімі: бағдарлама басында `upai = 0`.

**2. Енгізілген жауапты санмен салыстыру.**

```text
j = input("17 % 5 = ? ")
if j == 2:           # әрқашан False: "2" (str) != 2 (int)
```

Шешімі: `j == "2"` немесе `int(j) == 2`.

**3. Билет есебінде жеңілдікті жас тармағының ішіне жазу.** Сәрсенбі жеңілдігі **барлық** жас тобына қолданылуы керек — ол `elif` тізбегінен **кейін**, бөлек `if`.

**4. Ең үлкен сан есебінде `>` қолдану** (тең сандарда қате, 3-бөлімді қараңыз).

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Тест жағдайы | Бағдарламаны тексеруге арналған кіріс деректер мен күтілетін нәтиже |
| Тест-кесте | Енгізу, күтілетін және алынған нәтижелер кестесі |
| Шекаралық мән | Аралықтың шетіндегі мән, қателер жиі сонда болады |
| Күзетші шарт | Қате енгізуді ең алдымен тексеру |
| Жинауыш | Мәні біртіндеп қосылып отыратын айнымалы (`upai = upai + 1`) |

## Ескерту

- `max()` пен `min()` кез келген санды аргумент қабылдайды (`max(a, b, c, d)`) және `key` параметрі бар: `max("мысық", "ит", key=len)` ең ұзын жолды қайтарады.
- Пайдаланушы сан емес мән енгізсе, `int(input())` `ValueError` тудырады. Жолды алдын ала `s.isdigit()` әдісімен (тек теріс емес бүтін сандар үшін) тексеруге немесе қатені `try ... except ValueError` арқылы өңдеуге болады.
- `upai = upai + 1` жазуын `upai += 1` деп қысқартуға болады — бұл құрама меншіктеу (сондай-ақ `-=`, `*=`, `//=`).
- Ақшаға қатысты есептеулерде `//` бөлшек бөлігін алып тастайды; тиындар керек болса, `round(x, 2)` немесе `decimal` модулін қолданыңыз, дәл сомалар үшін `float` қолданбаған жөн.
- Тест-кестелерді автоматты тексеруге айналдыруға болады: есептеуді функцияға шығарып, оны `assert bilet_baga(12, "сәрсенбі") == 750` арқылы тексеріңіз.
- Кіріктірілген функциялар құжаттамасы: https://docs.python.org/3/library/functions.html
