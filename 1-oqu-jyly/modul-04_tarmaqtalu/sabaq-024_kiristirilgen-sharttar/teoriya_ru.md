## 1. Что такое вложенное условие?

**Вложенное (внутреннее) условие** — условный оператор, записанный **внутри** блока другого условного оператора.

Пример из жизни — **дерево решений**:

```text
                   Сегодня выходной?
                   /              \
                да                  нет
                /                     \
      Погода хорошая?             Иди в школу
        /          \
      да            нет
      /               \
 Иди в горы       Читай книгу
```

Внутренний вопрос («Погода хорошая?») задаётся только тогда, когда на внешний вопрос ответили «да».

```python
demalys = input("Сегодня выходной? (да/нет): ") == "да"
if demalys:
    aua_jaqsy = input("Погода хорошая? (да/нет): ") == "да"
    if aua_jaqsy:
        print("Идём в горы! Поедем на Медеу.")
    else:
        print("Читаем книгу дома.")
else:
    print("Идём в школу.")
```

Результат:
```text
Сегодня выходной? (да/нет): да
Погода хорошая? (да/нет): нет
Читаем книгу дома.
```

Обратите внимание: если не выходной, программа **даже не спрашивает** о погоде. Это главное преимущество вложенного условия: внутренняя проверка выполняется только при необходимости.

## 2. Уровни отступа

Каждый уровень вложенности — ещё **4 пробела**:

```text
if условие_1:              ← уровень 0
    if условие_2:          ← уровень 1 (4 пробела)
        действие_А         ← уровень 2 (8 пробелов)
    else:                  ← уровень 1 — else условия 2!
        действие_Б
else:                      ← уровень 0 — else условия 1
    действие_В
```

К какому `if` относится `else`, определяет **отступ**: он принадлежит ближайшему `if` на том же уровне.

### Отступ меняет смысл

```python
x = 5
y = -3
# Вариант 1: else относится к внутреннему if
if x > 0:
    if y > 0:
        print("1-я четверть")
    else:
        print("x положительный, y не положительный")
```

Результат:
```text
x положительный, y не положительный
```

```python
x = 5
y = -3
# Вариант 2: else относится к внешнему if
if x > 0:
    if y > 0:
        print("1-я четверть")
else:
    print("x не положительный")
```

Результат: ничего не выводится! (x > 0 истинно, внутреннее условие ложно, у внутреннего `if` нет `else`.)

## 3. Трассировка: координатная четверть

```python
x = int(input("x = "))
y = int(input("y = "))
if x > 0:
    if y > 0:
        print("I четверть")
    else:
        print("IV четверть")
else:
    if y > 0:
        print("II четверть")
    else:
        print("III четверть")
```

Трассировка (`x = -2`, `y = 7`):

| Шаг | Проверка | Результат | Куда идём |
|---|---|---|---|
| 1 | `x > 0` → `-2 > 0` | False | внешний `else` |
| 2 | `y > 0` → `7 > 0` | True | `print("II четверть")` |

Результат:
```text
x = -2
y = 7
II четверть
```

Этот упрощённый вариант не учитывает точки на осях: например, при x = 0 он выведет «II» или «III четверть». Полный вариант сначала проверяет оси (сторожевое условие):

```python
x = int(input("x = "))
y = int(input("y = "))
if x == 0 or y == 0:
    print("Точка лежит на оси")
elif x > 0:
    if y > 0:
        print("I четверть")
    else:
        print("IV четверть")
else:
    if y > 0:
        print("II четверть")
    else:
        print("III четверть")
```

## 4. Когда нужно вложенное условие?

| Ситуация | Пример |
|---|---|
| Внутренняя проверка **имеет смысл** только при выполнении внешнего условия | «Зарегистрирован?» → да → «Пароль верный?» |
| Внутренняя проверка **защищает от ошибки** | «Делитель не ноль?» → да → «Делится без остатка?» |
| У **каждой** внешней ветви свой выбор | четверти, дерево решений |
| При выполнении внешнего условия есть **общее действие**, затем разветвление | «Логин верный» → «Привет!», затем меню в зависимости от роли |

## 5. Оптимизация условий

**Оптимизация** — сделать код **короче, понятнее, эффективнее**, не меняя результат программы.

### 5.1. Вложенный if → and

Если у внутреннего `if` нет `else` и во внешнем `if` нет других действий:

```python
jas = 15
boy = 140
# Длинный вариант
if jas >= 12:
    if boy >= 130:
        print("Можно пройти")
# Краткий вариант — результат тот же
if jas >= 12 and boy >= 130:
    print("Можно пройти")
```

### 5.2. if внутри else → elif

```python
ball = 70
# Длинный вариант: код-«лесенка»
if ball >= 85:
    print(5)
else:
    if ball >= 65:
        print(4)
    else:
        if ball >= 40:
            print(3)
        else:
            print(2)
# Краткий вариант
if ball >= 85:
    print(5)
elif ball >= 65:
    print(4)
elif ball >= 40:
    print(3)
else:
    print(2)
```

### 5.3. Удаление лишних проверок

```python
t = 18
# Лишнее: раз дошли до elif — t < 0 ложно, значит проверять t >= 0 не нужно
if t < 0:
    print("Мороз")
elif t >= 0 and t < 20:
    print("Прохладно")
elif t >= 20:
    print("Тепло")
# Оптимально
if t < 0:
    print("Мороз")
elif t < 20:
    print("Прохладно")
else:
    print("Тепло")
```

### 5.4. Прямое присваивание логического значения

```python
n = 10
# Длинно
if n % 2 == 0:
    jup = True
else:
    jup = False
# Кратко — сравнение само даёт True/False
jup = n % 2 == 0
print(jup)
```

Аналогично `if jup == True:` → `if jup:`, а `if jup == False:` → `if not jup:`.

### 5.5. Вынос повторяющегося кода из ветвей

```python
jas = 10
# Повтор: print("Билет продан") одинаков в двух ветвях
if jas < 12:
    baga = 1500
    print("Билет продан")
else:
    baga = 2500
    print("Билет продан")
# Оптимально: общее действие — после условия
if jas < 12:
    baga = 1500
else:
    baga = 2500
print("Билет продан. Цена:", baga)
```

### 5.6. Ранняя проверка (сторожевое условие)

Сначала проверяем **ошибочные ситуации**, а остальной код оставляем чистым:

```python
ball = int(input("Балл (0–100): "))
if ball < 0 or ball > 100:
    print("Ошибка ввода!")
elif ball >= 50:
    print("Сдал")
else:
    print("Не сдал")
```

### 5.7. Законы де Моргана

При внесении `not` в скобки `and` ↔ `or` меняются местами:

| Выражение | Равносильно |
|---|---|
| `not (A and B)` | `not A or not B` |
| `not (A or B)` | `not A and not B` |

```python
ball = 120
# вариант с not
if not (0 <= ball and ball <= 100):
    print("Вне диапазона")
# по де Моргану — понятнее
if ball < 0 or ball > 100:
    print("Вне диапазона")
```

> Аналогия: «Неверно, что нет ни дождя, ни ветра» — запутывает. «Есть дождь или есть ветер» — понятно.

## 6. Какой вариант лучше? Критерии выбора

1. **Правильность** — самое главное: работает верно во всех случаях (и на граничных значениях).
2. **Читаемость** — другой человек (и вы сами через месяц) быстро поймёт код.
3. **Краткость** — нет лишних проверок и повторов.
4. **Эффективность** — нет ненужных вычислений и запросов `input()`.

Если глубина вложенности превышает 3 уровня — подумайте о том, чтобы «выпрямить» код с помощью `and`/`elif`.

## Частые ошибки

**1. `else` на неверном уровне** (см. раздел 2) — синтаксис верный, но смысл другой. Проверяйте пошаговым режимом Thonny.

**2. Нет отступа во внутреннем блоке.**

```text
if x > 0:
    if y > 0:
    print("I четверть")
# IndentationError: expected an indented block after 'if' statement
```

**3. Нарушение смысла при оптимизации.** Конструкцию `if A: if B: X else: Y` **нельзя** записать как `if A and B: X else: Y`: в первом варианте при ложном A ничего не происходит, во втором — выполняется Y!

```python
A = False
B = True
if A:
    if B:
        print("X")
    else:
        print("Y")
# ничего не выводится
if A and B:
    print("X")
else:
    print("Y")
# выводится Y — смысл изменился!
```

**4. Неверное применение де Моргана.** `not (A and B)` ≠ `not A and not B`. Чтобы проверить правило, составьте таблицу истинности.

**5. Слишком глубокая вложенность.** В коде-«лесенке» из 4–5 уровней трудно найти ошибку — используйте `elif` и `and`.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Вложенное условие | Условный оператор внутри блока другого условия |
| Дерево решений | Схема принятия решения через последовательные вопросы |
| Уровень вложенности | Глубина внутреннего блока, показываемая отступом |
| Оптимизация | Улучшение кода без изменения результата |
| Сторожевое условие | Проверка ошибочной ситуации в первую очередь |
| Законы де Моргана | `not (A and B) = not A or not B`, `not (A or B) = not A and not B` |
| Трассировка | Пошаговое отслеживание выполнения с помощью таблицы |

## Примечание

- В Python нет проблемы «висящего else», как в C или Java: принадлежность `else` однозначно задаётся отступом.
- Глубину вложенности удобно уменьшать «ранним выходом»: внутри функции — `return`, в цикле — `continue`/`break`. Так основной код остаётся на верхнем уровне.
- Линтеры (например, `pylint`, `flake8` с плагином `mccabe`) умеют измерять **цикломатическую сложность** — число независимых путей в коде — и предупреждать о слишком разветвлённых участках.
- Упрощения вида `if x: return True else: return False` → `return bool(x)` и `jup = n % 2 == 0` делают код короче без потери смысла.
- Проверять равносильность двух вариантов условия удобно перебором: составьте таблицу истинности или переберите все комбинации `True`/`False` с помощью `itertools.product([True, False], repeat=2)`.
- Руководство по стилю: https://peps.python.org/pep-0008/ (раздел «Programming Recommendations»).
