# Сабақ 24. Практикалық тапсырмалар: кірістірілген шарттар және оңтайландыру

## Базалық деңгей

### 1-тапсырма. «Трассировка»
Кодты іске қоспай, `a` мен `b`-нің әр жұбы үшін не шығатынын дәптерге жазыңыз. Сосын тексеріңіз.

```text
if a > 10:
    if b > 10:
        print("A")
    else:
        print("B")
else:
    if b > a:
        print("C")
print("D")
```

Жұптар: (15; 20), (15; 5), (3; 8), (8; 3).

### 2-тапсырма. «Координаталық ширек»
Нүктенің x, y координаталары енгізіледі. Кірістірілген шарттар арқылы нүктенің қай ширекте екенін анықтаңыз. Нүкте осьте жатса — «Нүкте X осінде», «Нүкте Y осінде» немесе «Бас нүкте» деп шығарыңыз.

### 3-тапсырма. «Банкомат»
PIN-код `2468` деп сақталған, картадағы баланс — 50000 тг. Пайдаланушы PIN енгізеді. Қате болса — «PIN қате». Дұрыс болса — шешілетін соманы сұрайды; сома баланстан аспаса және 1000-ға еселік болса — «Ақшаңызды алыңыз, қалдық: ...», әйтпесе тиісті қате хабарламасы.

```text
PIN: 2468
Сома: 15500
Сома 1000-ға еселік болуы керек
```

### 4-тапсырма. «Кодты ықшамда — 1»
Төмендегі кодты нәтижесін өзгертпей `and` арқылы ықшамдаңыз:

```python
jas = int(input("Жасы: "))
if jas >= 14:
    if jas <= 17:
        print("Жасөспірімдер командасына қабылданады")
```

### 5-тапсырма. «Кодты ықшамда — 2»
Төмендегі «баспалдақ» кодты `elif` арқылы қайта жазыңыз:

```python
kun = int(input("Апта күні (1–7): "))
if kun == 6:
    print("Сенбі — демалыс")
else:
    if kun == 7:
        print("Жексенбі — демалыс")
    else:
        if kun >= 1:
            if kun <= 5:
                print("Жұмыс күні")
            else:
                print("Қате")
        else:
            print("Қате")
```

## Кеңейтілген деңгей

### 6-тапсырма. «Артық кодты тап»
Кодтағы барлық артық тексерулер мен қайталанатын жолдарды тауып, оңтайлы нұсқасын жазыңыз:

```python
ball = int(input("Балл: "))
if ball >= 90:
    otti = True
    print("Нәтиже есептелді")
elif ball >= 50 and ball < 90:
    otti = True
    print("Нәтиже есептелді")
elif ball < 50:
    otti = False
    print("Нәтиже есептелді")
if otti == True:
    print("Өтті")
if otti == False:
    print("Өтпеді")
```

### 7-тапсырма. «Тіркелу формасы»
Үйірмеге тіркелу: бағдарлама жасты сұрайды. 10-нан кіші немесе 17-ден үлкен болса — «Жасыңыз сәйкес келмейді» (күзетші шарт). Сәйкес болса — Python-мен бұрын айналысқанын сұрайды (иә/жоқ). «иә» болса — тест балын сұрайды: 70 және жоғары — «2-жыл тобы», әйтпесе — «1-жыл тобы». «жоқ» болса — «1-жыл тобы».

### 8-тапсырма. «Де Морган»
Әр шартты `not`-сыз, баламалы түрде жазыңыз және екі нұсқа бірдей нәтиже беретінін 3 түрлі мәнмен тексеріңіз:

```text
1) not (x > 0 and y > 0)
2) not (jas < 7 or jas > 63)
3) not (kun == "сенбі" or kun == "жексенбі")
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Тас-қайшы-қағаз»
Екі ойыншы кезекпен таңдау енгізеді («тас», «қайшы», «қағаз»). Бағдарлама жеңімпазды анықтайды. Алдымен күзетші шарт — екі енгізу дұрыс па? Сосын тең бе? Сосын бірінші ойыншының жеңісін **бір құрама шартпен** тексеріңіз. Кірістіру деңгейі 2-ден аспасын.

### 10-тапсырма. «Күн мен айдың дұрыстығы»
Күн (d), ай (m), жыл (y) енгізіледі. Бағдарлама мұндай күн бар-жоғын тексереді (31 күнді айлар, 30 күнді айлар, ақпан және кібісе жыл). Ең оңтайлы нұсқаны жазуға тырысыңыз: алдымен айдағы күндер санын `max_kun` айнымалысына анықтап, соңында бір ғана салыстыру жасаңыз.

```text
Күн: 29
Ай: 2
Жыл: 2027
Мұндай күн жоқ (2027 жылы 2-айда 28 күн)
```

## Үй тапсырмасы

1. Өзіндік жұмыс №2-ге дайындалу: 19–24-сабақтардағы теорияны қайталаңыз (салыстыру операторлары, `if`, `else`, `elif`, `and`/`or`/`not`, кірістірілген шарттар).
2. Өзіңіз жазған кез келген бұрынғы бағдарламаны (20–23-сабақтардан) тауып, оны оңтайландырыңыз. Не өзгерткеніңізді түсініктемемен жазыңыз.
