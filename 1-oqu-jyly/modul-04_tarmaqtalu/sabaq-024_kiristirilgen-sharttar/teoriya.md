## 1. Кірістірілген шарт деген не?

**Кірістірілген (ішкі) шарт** — бір шартты оператордың блогының **ішінде** жазылған басқа шартты оператор.

Өмірлік мысал — **шешім ағашы**:

```text
                   Демалыс күні ме?
                   /              \
                иә                  жоқ
                /                     \
      Ауа райы жақсы ма?          Мектепке бар
        /          \
      иә            жоқ
      /               \
 Тауға шық        Кітап оқы
```

Ішкі сұрақ («Ауа райы жақсы ма?») тек сыртқы сұраққа «иә» деп жауап бергенде ғана қойылады.

```python
demalys = input("Бүгін демалыс па? (иә/жоқ): ") == "иә"
if demalys:
    aua_jaqsy = input("Ауа райы жақсы ма? (иә/жоқ): ") == "иә"
    if aua_jaqsy:
        print("Тауға шығамыз! Медеуге барайық.")
    else:
        print("Үйде кітап оқимыз.")
else:
    print("Мектепке барамыз.")
```

Нәтижесі:
```text
Бүгін демалыс па? (иә/жоқ): иә
Ауа райы жақсы ма? (иә/жоқ): жоқ
Үйде кітап оқимыз.
```

Байқаңыз: демалыс болмаса, бағдарлама ауа райын **сұрамайды да**. Бұл — кірістірілген шарттың басты артықшылығы: ішкі тексеру тек қажет кезде орындалады.

## 2. Шегініс деңгейлері

Әр кірістіру деңгейі — тағы **4 бос орын**:

```text
if 1-шарт:                 ← 0 деңгей
    if 2-шарт:             ← 1 деңгей (4 бос орын)
        әрекет_А           ← 2 деңгей (8 бос орын)
    else:                  ← 1 деңгей — 2-шарттың else-і!
        әрекет_Б
else:                      ← 0 деңгей — 1-шарттың else-і
    әрекет_В
```

`else` қай `if`-ке жататынын **шегініс** анықтайды: ол өзімен бір деңгейдегі ең жақын `if`-ке тиесілі.

### Шегініс мағынаны өзгертеді

```python
x = 5
y = -3
# 1-нұсқа: else ішкі if-ке тиесілі
if x > 0:
    if y > 0:
        print("1-ширек")
    else:
        print("x оң, y оң емес")
```

Нәтижесі:
```text
x оң, y оң емес
```

```python
x = 5
y = -3
# 2-нұсқа: else сыртқы if-ке тиесілі
if x > 0:
    if y > 0:
        print("1-ширек")
else:
    print("x оң емес")
```

Нәтижесі: ештеңе шықпайды! (x > 0 ақиқат, ішкі шарт жалған, ішкі `if`-тің `else`-і жоқ.)

## 3. Трассировка: координаталық ширек

```python
x = int(input("x = "))
y = int(input("y = "))
if x > 0:
    if y > 0:
        print("I ширек")
    else:
        print("IV ширек")
else:
    if y > 0:
        print("II ширек")
    else:
        print("III ширек")
```

Трассировка (`x = -2`, `y = 7`):

| Қадам | Тексеру | Нәтиже | Қайда барамыз |
|---|---|---|---|
| 1 | `x > 0` → `-2 > 0` | False | сыртқы `else` |
| 2 | `y > 0` → `7 > 0` | True | `print("II ширек")` |

Нәтижесі:
```text
x = -2
y = 7
II ширек
```

Бұл жеңілдетілген нұсқа ось үстіндегі нүктелерді ескермейді: мысалы, x = 0 болса, ол «II» немесе «III ширек» деп шығарады. Толық нұсқа алдымен осьтерді тексереді (күзетші шарт):

```python
x = int(input("x = "))
y = int(input("y = "))
if x == 0 or y == 0:
    print("Нүкте ось үстінде жатыр")
elif x > 0:
    if y > 0:
        print("I ширек")
    else:
        print("IV ширек")
else:
    if y > 0:
        print("II ширек")
    else:
        print("III ширек")
```

## 4. Қашан кірістірілген шарт қажет?

| Жағдай | Мысал |
|---|---|
| Ішкі тексеру тек сыртқы шарт орындалғанда **мағыналы** | «Тіркелген бе?» → иә → «Құпиясөз дұрыс па?» |
| Ішкі тексеру **қатеден** қорғайды | «Бөлгіш нөл емес пе?» → иә → «Қалдықсыз бөліне ме?» |
| Сыртқы тармақтың **әрқайсысында** өз таңдауы бар | ширектер, шешім ағашы |
| Сыртқы шарт орындалғанда **ортақ әрекет** бар, сосын бөлінеді | «Логин дұрыс» → «Сәлем!» деп, сосын рөлге қарай мәзір |

## 5. Шарттарды оңтайландыру

**Оңтайландыру (оптимизация)** — бағдарламаның нәтижесін өзгертпей, кодты **қысқа, түсінікті, тиімді** ету.

### 5.1. Кірістірілген if → and

Ішкі `if`-тің `else`-і жоқ және сыртқы `if`-те басқа әрекет жоқ болса:

```python
jas = 15
boy = 140
# Ұзын нұсқа
if jas >= 12:
    if boy >= 130:
        print("Кіруге болады")
# Ықшам нұсқа — нәтижесі бірдей
if jas >= 12 and boy >= 130:
    print("Кіруге болады")
```

### 5.2. else ішіндегі if → elif

```python
ball = 70
# Ұзын нұсқа: «баспалдақ» код
if ball >= 85:
    print(5)
else:
    if ball >= 65:
        print(4)
    else:
        if ball >= 40:
            print(3)
        else:
            print(2)
# Ықшам нұсқа
if ball >= 85:
    print(5)
elif ball >= 65:
    print(4)
elif ball >= 40:
    print(3)
else:
    print(2)
```

### 5.3. Артық тексерулерді алып тастау

```python
t = 18
# Артық: elif-ке жеттік — демек t < 0 жалған, яғни t >= 0 тексерудің қажеті жоқ
if t < 0:
    print("Аяз")
elif t >= 0 and t < 20:
    print("Салқын")
elif t >= 20:
    print("Жылы")
# Оңтайлы
if t < 0:
    print("Аяз")
elif t < 20:
    print("Салқын")
else:
    print("Жылы")
```

### 5.4. Логикалық мәнді тікелей меншіктеу

```python
n = 10
# Ұзын
if n % 2 == 0:
    jup = True
else:
    jup = False
# Ықшам — салыстыру өзі True/False береді
jup = n % 2 == 0
print(jup)
```

Сол сияқты `if jup == True:` → `if jup:`, ал `if jup == False:` → `if not jup:`.

### 5.5. Қайталанатын кодты тармақтан шығару

```python
jas = 10
# Қайталау: print("Билет сатылды") екі тармақта бірдей
if jas < 12:
    baga = 1500
    print("Билет сатылды")
else:
    baga = 2500
    print("Билет сатылды")
# Оңтайлы: ортақ әрекет — шарттан кейін
if jas < 12:
    baga = 1500
else:
    baga = 2500
print("Билет сатылды. Бағасы:", baga)
```

### 5.6. Ерте тексеру (күзетші шарт)

Алдымен **қате жағдайларды** тексеріп, қалған кодты таза қалдырамыз:

```python
ball = int(input("Балл (0–100): "))
if ball < 0 or ball > 100:
    print("Қате енгізу!")
elif ball >= 50:
    print("Өтті")
else:
    print("Өтпеді")
```

### 5.7. Де Морган заңдары

`not` жақшаға енгізілгенде `and` ↔ `or` орын ауыстырады:

| Өрнек | Баламасы |
|---|---|
| `not (A and B)` | `not A or not B` |
| `not (A or B)` | `not A and not B` |

```python
ball = 120
# not бар нұсқа
if not (0 <= ball and ball <= 100):
    print("Аралықтан тыс")
# Де Морган бойынша — түсініктірек
if ball < 0 or ball > 100:
    print("Аралықтан тыс")
```

> Аналогия: «Жаңбыр да жоқ, жел де жоқ емес» — шатастырады. «Не жаңбыр бар, не жел бар» — түсінікті.

## 6. Қай нұсқа жақсы? Таңдау критерийлері

1. **Дұрыстық** — ең бастысы: барлық жағдайда (шекаралық мәндерде де) дұрыс жұмыс істейді.
2. **Оқылымдылық** — басқа адам (және бір айдан кейін сіздің өзіңіз) кодты тез түсінеді.
3. **Қысқалық** — артық тексерулер мен қайталаулар жоқ.
4. **Тиімділік** — қажетсіз есептеулер мен `input()` сұраулары жоқ.

Кірістіру тереңдігі 3 деңгейден асса — кодты `and`/`elif` арқылы «тегістеуді» ойланыңыз.

## Жиі кездесетін қателер

**1. `else` қате деңгейде** (2-бөлімді қараңыз) — синтаксис дұрыс, бірақ мағына басқа. Thonny-дің қадамдық режимімен тексеріңіз.

**2. Ішкі блоктың шегінісі жоқ.**

```text
if x > 0:
    if y > 0:
    print("I ширек")
# IndentationError: expected an indented block after 'if' statement
```

**3. Оңтайландыру кезінде мағынаны бұзу.** `if A: if B: X else: Y` құрылымын `if A and B: X else: Y` деп жазуға **болмайды**: бірінші нұсқада A жалған болса — ештеңе болмайды, екіншісінде — Y орындалады!

```python
A = False
B = True
if A:
    if B:
        print("X")
    else:
        print("Y")
# ештеңе шықпайды
if A and B:
    print("X")
else:
    print("Y")
# Y шығады — мағына өзгерді!
```

**4. Де Морганды қате қолдану.** `not (A and B)` ≠ `not A and not B`. Ережені тексеру үшін ақиқаттық кестесін құрыңыз.

**5. Тым терең кірістіру.** 4–5 деңгейлі «баспалдақ» кодта қате табу қиын — `elif` пен `and` қолданыңыз.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Кірістірілген шарт | Басқа шарттың блогы ішіндегі шартты оператор |
| Шешім ағашы | Тізбекті сұрақтар арқылы шешім қабылдау сызбасы |
| Кірістіру деңгейі | Шегініс арқылы көрсетілетін ішкі блок тереңдігі |
| Оңтайландыру | Нәтижені өзгертпей кодты жақсарту |
| Күзетші шарт | Қате жағдайды ең алдымен тексеру |
| Де Морган заңдары | `not (A and B) = not A or not B`, `not (A or B) = not A and not B` |
| Трассировка | Орындалуды кестемен қадамдап бақылау |

## Ескерту

- Python-да C немесе Java тілдеріндегідей «салбыраған else» мәселесі жоқ: `else`-тің қай `if`-ке тиесілі екенін шегініс бірмәнді анықтайды.
- Кірістіру тереңдігін «ерте шығу» арқылы азайтқан ыңғайлы: функция ішінде — `return`, циклде — `continue`/`break`. Сонда негізгі код жоғарғы деңгейде қалады.
- Линтерлер (мысалы, `pylint`, `mccabe` плагині бар `flake8`) **цикломатикалық күрделілікті** — кодтағы тәуелсіз жолдар санын — өлшеп, тым тармақталған бөліктер туралы ескерте алады.
- `if x: return True else: return False` → `return bool(x)` және `jup = n % 2 == 0` сияқты ықшамдаулар мағынаны жоғалтпай кодты қысқартады.
- Шарттың екі нұсқасының баламалылығын сұрыптау арқылы тексерген ыңғайлы: ақиқаттық кестесін құрыңыз немесе `itertools.product([True, False], repeat=2)` арқылы `True`/`False`-тың барлық комбинацияларын өткізіңіз.
- Стиль нұсқаулығы: https://peps.python.org/pep-0008/ («Programming Recommendations» бөлімі).
