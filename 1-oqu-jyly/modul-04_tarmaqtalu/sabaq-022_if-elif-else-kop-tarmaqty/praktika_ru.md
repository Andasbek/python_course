# Урок 22. Практические задания: if...elif...else

> Проверяйте каждую программу на всех ветвях и на **граничных значениях**. `and`/`or` ещё не изучены — решайте, правильно выстраивая порядок `elif`.

## Базовый уровень

### Задание 1. «Положительное, отрицательное, ноль»
Введите число и выведите, положительное оно, отрицательное или ноль.

### Задание 2. «Оценка»
Вводится балл за тест (0–100). Оценка: 85–100 → 5, 65–84 → 4, 40–64 → 3, 0–39 → 2. Выведите оценку и её словесное описание («отлично», «хорошо», «удовлетворительно», «неудовлетворительно»).

```text
Балл: 65
Оценка: 4 (хорошо)
```

### Задание 3. «День недели»
Вводится число от 1 до 7, программа выводит название дня недели (1 — понедельник, …, 7 — воскресенье). Если введено другое число — «Такого дня нет».

### Задание 4. «Погодный советник»
Вводится температура:
- ниже −10: «Сильный мороз, оставайтесь дома»;
- −10…−1: «Мороз, одевайтесь теплее»;
- 0…14: «Прохладно, наденьте куртку»;
- 15…24: «Тепло, одевайтесь легко»;
- 25 и выше: «Жарко, не забывайте пить воду».

### Задание 5. «Калькулятор»
Вводятся два числа и знак операции (`+`, `-`, `*`, `/`). Программа выводит результат. Если введена неизвестная операция — «Неизвестная операция». Учтите и деление на ноль (`if ... else` внутри ветви `/`).

```text
Первое число: 12
Операция: /
Второе число: 4
12.0 / 4.0 = 3.0
```

## Продвинутый уровень

### Задание 6. «Система скидок»
Скидка в магазине зависит от суммы покупки: до 5000 тг — 0%; 5000–14999 — 3%; 15000–49999 — 7%; 50000 и выше — 12%. Выведите процент скидки, сумму скидки и сумму к оплате.

```text
Сумма: 20000
Скидка: 7% (1400.0 тенге)
К оплате: 18600.0 тенге
```

### Задание 7. «Коммунальный платёж»
Ступенчатый тариф на электроэнергию (для примера): 0–100 кВт·ч — 25 тг/кВт·ч; 101–200 — первые 100 по 25 тг, остальные по 35 тг; свыше 200 — первые 100 по 25 тг, следующие 100 по 35 тг, остальные по 45 тг. Вычислите месячный платёж.

```text
Израсходовано электроэнергии (кВт·ч): 250
Оплата: 8250 тенге
```

### Задание 8. «Время года»
Вводится номер месяца (1–12). Программа выводит время года (12, 1, 2 — зима; 3–5 — весна; 6–8 — лето; 9–11 — осень). Используйте только `elif` и операторы сравнения (без `and`/`or`). Подсказка: сначала отдельно проверьте 12.

## ★ Олимпиадная / творческая задача

### Задание 9. «Восточный календарь»
Вводится год рождения. Программа определяет животное по 12-летнему циклу мушель. 2020 — год мыши. Порядок: мышь, корова, барс, заяц, дракон (улу), змея, лошадь, овца, обезьяна, курица, собака, свинья. Подсказка: `qaldyq = (jyl - 2020) % 12` (в Python остаток от деления отрицательного числа тоже находится в диапазоне 0…11!).

```text
Ваш год рождения: 2013
Ваш год по восточному календарю: змея
```

### Задание 10. «Квадратное уравнение»
Вводятся коэффициенты `a`, `b`, `c` (a ≠ 0). По дискриминанту `D = b² − 4ac`: D > 0 — два корня, D = 0 — один корень, D < 0 — корней нет. Вычислите и выведите корни (`** 0.5` — квадратный корень).

```text
a = 1
b = -5
c = 6
D = 1
x1 = 3.0, x2 = 2.0
```

```python
a = float(input("a = "))
b = float(input("b = "))
c = float(input("c = "))
D = b ** 2 - 4 * a * c
print("D =", D)
if D > 0:
    x1 = (-b + D ** 0.5) / (2 * a)
    x2 = (-b - D ** 0.5) / (2 * a)
    print(f"x1 = {x1}, x2 = {x2}")
elif D == 0:
    x = -b / (2 * a)
    print("x =", x)
else:
    print("Действительных корней нет")
```
