# Сабақ 22. Практикалық тапсырмалар: if...elif...else

> Әр бағдарламаны барлық тармақтарға және **шекаралық мәндерге** тексеріңіз. `and`/`or` әлі өтілмеген — `elif` ретін дұрыс құру арқылы шешіңіз.

## Базалық деңгей

### 1-тапсырма. «Оң, теріс, нөл»
Санды енгізіп, оның оң, теріс немесе нөл екенін шығарыңыз.

### 2-тапсырма. «Баға»
Тест балы (0–100) енгізіледі. Баға: 85–100 → 5, 65–84 → 4, 40–64 → 3, 0–39 → 2. Бағаны және сөзбен сипаттамасын шығарыңыз («өте жақсы», «жақсы», «қанағаттанарлық», «қанағаттанарлықсыз»).

```text
Балл: 65
Баға: 4 (жақсы)
```

### 3-тапсырма. «Апта күні»
1-ден 7-ге дейінгі сан енгізіледі, бағдарлама апта күнінің атауын шығарады (1 — дүйсенбі, …, 7 — жексенбі). Басқа сан енгізілсе — «Мұндай күн жоқ».

### 4-тапсырма. «Ауа райы кеңесшісі»
Температура енгізіледі:
- −10-нан төмен: «Қатты аяз, үйде отырыңыз»;
- −10…−1: «Аяз, жылы киініңіз»;
- 0…14: «Салқын, күртеше киіңіз»;
- 15…24: «Жылы, жеңіл киініңіз»;
- 25 және жоғары: «Ыстық, су ішуді ұмытпаңыз».

### 5-тапсырма. «Калькулятор»
Екі сан және амал белгісі (`+`, `-`, `*`, `/`) енгізіледі. Бағдарлама нәтижені шығарады. Белгісіз амал енгізілсе — «Белгісіз амал». Нөлге бөлуді де ескеріңіз (`/` тармағының ішінде `if ... else`).

```text
Бірінші сан: 12
Амал: /
Екінші сан: 4
12.0 / 4.0 = 3.0
```

## Кеңейтілген деңгей

### 6-тапсырма. «Жеңілдік жүйесі»
Дүкенде сатып алу сомасына қарай жеңілдік: 5000 тг-ге дейін — 0%; 5000–14999 — 3%; 15000–49999 — 7%; 50000 және жоғары — 12%. Жеңілдік пайызын, жеңілдік сомасын және төлем сомасын шығарыңыз.

```text
Сома: 20000
Жеңілдік: 7% (1400.0 теңге)
Төлеуге: 18600.0 теңге
```

### 7-тапсырма. «Коммуналдық төлем»
Электр энергиясына сатылы тариф (мысал ретінде): 0–100 кВт·сағ — 25 тг/кВт·сағ; 101–200 — алғашқы 100-і 25 тг, қалғаны 35 тг; 200-ден жоғары — алғашқы 100-і 25 тг, келесі 100-і 35 тг, қалғаны 45 тг. Айлық төлемді есептеңіз.

```text
Жұмсалған электр (кВт·сағ): 250
Төлем: 8250 теңге
```

### 8-тапсырма. «Жыл мезгілі»
Ай нөмірі (1–12) енгізіледі. Бағдарлама жыл мезгілін шығарады (12, 1, 2 — қыс; 3–5 — көктем; 6–8 — жаз; 9–11 — күз). Тек `elif` және салыстыру операторларын қолданыңыз (`and`/`or`-сыз). Кеңес: алдымен 12-ні бөлек тексеріңіз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Шығыс күнтізбесі»
Туған жылы енгізіледі. Бағдарлама 12 жылдық мүшел бойынша жануарды анықтайды. 2020 — тышқан жылы. Реті: тышқан, сиыр, барыс, қоян, ұлу, жылан, жылқы, қой, мешін, тауық, ит, доңыз. Кеңес: `qaldyq = (jyl - 2020) % 12` (Python-да теріс санның қалдығы да 0…11 аралығында болады!).

```text
Туған жылыңыз: 2013
Сіз жылан жылы туғансыз
```

### 10-тапсырма. «Квадрат теңдеу»
`a`, `b`, `c` коэффициенттері енгізіледі (a ≠ 0). Дискриминант `D = b² − 4ac` бойынша: D > 0 — екі түбір, D = 0 — бір түбір, D < 0 — түбір жоқ. Түбірлерді есептеп шығарыңыз (`** 0.5` — квадрат түбір).

```text
a = 1
b = -5
c = 6
D = 1
x1 = 3.0, x2 = 2.0
```

## Үй тапсырмасы

1. Өз үйірме/мектеп өміріңізден көп тармақты таңдауға 1 бағдарлама ойлап жазыңыз (кемінде 4 тармақ).
2. 4-тапсырманы `<` арқылы (кішіден үлкенге) және `>=` арқылы (үлкеннен кішіге) — екі түрлі жазыңыз. Екеуін де −10, 0, 15, 25 мәндерімен тексеріңіз.

```python
a = float(input("a = "))

c = float(input("c = "))
D = b ** 2 - 4 * a * c
print("D =", D)
if D > 0:
    x1 = (-b + D ** 0.5) / (2 * a)
    x2 = (-b - D ** 0.5) / (2 * a)
    print(f"x1 = {x1}, x2 = {x2}")

```

Ескерту: `float` енгізілгенде `D = 1.0` болып шығады; мысалдағы шығыс `int` енгізгендегі түрі.
