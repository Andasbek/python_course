## 1. Көп тармақты таңдау

**Көп тармақты таңдау** — екіден көп нұсқаның ішінен шарттарға сәйкес **біреуін** таңдау.

Өмірлік мысалдар:
- Бағдаршам: қызыл — тоқта, сары — дайындал, жасыл — жүр.
- Мектеп бағасы: 85–100 балл — «5», 65–84 — «4», 40–64 — «3», 0–39 — «2».
- Ауа райы: −10-нан төмен — «қатты аяз», 0-ден төмен — «салқын», 20-дан төмен — «жылы», әйтпесе — «ыстық».

### Блок-схемасы

```text
            ╱‾‾‾‾‾‾‾‾‾╲  иә    ┌──────────┐
 ─────────►  1-шарт?    ─────► │ 1-әрекет │ ──────────┐
            ╲_________╱        └──────────┘           │
                 │ жоқ                                │
            ╱‾‾‾‾‾‾‾‾‾╲  иә    ┌──────────┐           │
             2-шарт?    ─────► │ 2-әрекет │ ──────────┤
            ╲_________╱        └──────────┘           │
                 │ жоқ                                │
            ╱‾‾‾‾‾‾‾‾‾╲  иә    ┌──────────┐           │
             3-шарт?    ─────► │ 3-әрекет │ ──────────┤
            ╲_________╱        └──────────┘           │
                 │ жоқ                                │
            ┌──────────────┐                          │
            │ else-әрекет  │ ─────────────────────────┤
            └──────────────┘                          ▼
                                                 келесі команда
```

Шарттар **жоғарыдан төмен** тексеріледі. Бірінші `True` болған шарттың блогы орындалады да, қалғандары **тексерілмейді**.

## 2. Синтаксис

```text
if 1-шарт:
    1-блок
elif 2-шарт:
    2-блок
elif 3-шарт:
    3-блок
else:
    барлық шарттар жалған болғандағы блок
```

- `elif` — «else if» (әйтпесе, егер) сөздерінің қысқартылуы.
- `elif` саны шектелмейді: бір, екі, он…
- `elif` пен `else` — `if`-пен бір деңгейде, қос нүктемен.
- `else` — міндетті емес, бірақ болса, **ең соңында** және біреу ғана.

«Оң/теріс/нөл» есебі `elif` арқылы:

```python
n = int(input("Сан: "))
if n > 0:
    print("Оң")
elif n < 0:
    print("Теріс")
else:
    print("Нөл")
```

Нәтижесі:
```text
Сан: 0
Нөл
```

Шегініс деңгейі бірдей, код оқуға оңай!

## 3. Мысал: баллды бағаға айналдыру

```python
ball = int(input("Балл (0–100): "))
if ball >= 85:
    baga = 5
elif ball >= 65:
    baga = 4
elif ball >= 40:
    baga = 3
else:
    baga = 2
print("Бағаңыз:", baga)
```

Нәтижесі:
```text
Балл (0–100): 72
Бағаңыз: 4
```

**Неге `elif ball >= 65` жеткілікті, `65 <= ball < 85` жазу керек емес?** Өйткені екінші шартқа тек бірінші шарт **жалған** болғанда ғана жетеміз. Яғни ол жерде `ball < 85` екені белгілі. `elif` өзінен бұрынғы шарттардың жалған екенін «біледі».

### Орындалу трассировкасы (ball = 72)

| Қадам | Шарт | Нәтиже | Әрекет |
|---|---|---|---|
| 1 | `72 >= 85` | False | келесі шартқа |
| 2 | `72 >= 65` | True | `baga = 4`, тізбектен шығу |
| 3 | `72 >= 40` | — | тексерілмейді |
| 4 | `else` | — | орындалмайды |

## 4. Шарттардың реті маңызды!

Шарттарды қате ретпен жазсақ:

```python
ball = 95
if ball >= 40:
    baga = 3
elif ball >= 65:
    baga = 4
elif ball >= 85:
    baga = 5
else:
    baga = 2
print("Бағаңыз:", baga)
```

Нәтижесі:
```text
Бағаңыз: 3
```

95 балл `ball >= 40` шартына да сәйкес, ол бірінші тексерілді, сондықтан қалғандарына кезек келмеді.

> Ереже: аралықтарды «**>=**» арқылы тексерсеңіз — **үлкеннен кішіге**, «**<**» арқылы тексерсеңіз — **кішіден үлкенге** қарай жазыңыз.

Дәл сол есеп «кішіден үлкенге» ретімен:

```python
ball = 95
if ball < 40:
    baga = 2
elif ball < 65:
    baga = 3
elif ball < 85:
    baga = 4
else:
    baga = 5
print("Бағаңыз:", baga)
```

Нәтижесі:
```text
Бағаңыз: 5
```

## 5. if/elif тізбегі мен бірнеше if айырмашылығы

```python
temp = 30
# Бірнеше тәуелсіз if — бірнеше хабар шығуы мүмкін
if temp > 25:
    print("if: Ыстық")
if temp > 15:
    print("if: Жылы")
if temp > 0:
    print("if: Салқын")
```

Нәтижесі:
```text
if: Ыстық
if: Жылы
if: Салқын
```

```python
temp = 30
# if/elif — тек бір хабар
if temp > 25:
    print("Ыстық")
elif temp > 15:
    print("Жылы")
elif temp > 0:
    print("Салқын")
else:
    print("Аяз")
```

Нәтижесі:
```text
Ыстық
```

| | Бірнеше `if` | `if/elif/else` |
|---|---|---|
| Неше шарт тексеріледі | **барлығы** | бірінші `True`-ға дейін |
| Неше блок орындалады | 0-ден бәріне дейін | 0 немесе 1 (`else` болса — дәл 1) |
| Қашан қолданамыз | шарттар тәуелсіз | нұсқалар бір-бірін жоққа шығарады |

## 6. Мәтіндік таңдау: меню

```python
print("1 — Шай, 300 тг")
print("2 — Кофе, 600 тг")
print("3 — Шырын, 450 тг")
tandau = input("Таңдауыңыз: ")
if tandau == "1":
    print("Сіз шай таңдадыңыз. Төлеуге: 300 тг")
elif tandau == "2":
    print("Сіз кофе таңдадыңыз. Төлеуге: 600 тг")
elif tandau == "3":
    print("Сіз шырын таңдадыңыз. Төлеуге: 450 тг")
else:
    print("Мұндай нөмір жоқ!")
```

`else` мұнда **қате енгізуді** өңдейді — бұл жақсы бағдарламаның белгісі.

## 7. else-сіз elif

`else` міндетті емес. Ол болмаса және ешбір шарт орындалмаса — ештеңе орындалмайды:

```python
kun = input("Апта күні: ").lower()
if kun == "сенбі":
    print("Демалыс! Үйірме жоқ.")
elif kun == "жексенбі":
    print("Демалыс!")
```

## 8. Блок ішінде есептеу: дене салмағының индексі

```python
massa = float(input("Салмағыңыз (кг): "))
boy = float(input("Бойыңыз (м, мысалы 1.65): "))
dsi = massa / boy ** 2
print(f"ДСИ = {dsi:.1f}")
if dsi < 18.5:
    print("Салмақ жеткіліксіз")
elif dsi < 25:
    print("Қалыпты салмақ")
elif dsi < 30:
    print("Артық салмақ")
else:
    print("Семіздік")
```

Нәтижесі:
```text
Салмағыңыз (кг): 55
Бойыңыз (м, мысалы 1.65): 1.65
ДСИ = 20.2
Қалыпты салмақ
```

## 9. Қосымша: match-case (Python 3.10+)

Бір айнымалыны **нақты мәндермен** салыстырғанда Python 3.10-нан бастап `match` операторын қолдануға болады:

```python
tus = input("Бағдаршам түсі: ").lower()
match tus:
    case "қызыл":
        print("Тоқта!")
    case "сары":
        print("Дайындал!")
    case "жасыл":
        print("Жүр!")
    case _:
        print("Мұндай түс жоқ")
```

`case _:` — `else` рөлін атқарады. Бірақ аралықтар (`ball >= 85`) үшін `if/elif` қолайлырақ, сондықтан негізгі құрал — `elif`.

## Жиі кездесетін қателер

**1. `else if` деп жазу.**

```text
if n > 0:
    print("оң")
else if n < 0:
    print("теріс")
# SyntaxError: expected ':'
```

Python-да `elif` — бір сөз.

**2. `else`-тен кейін `elif` жазу.**

```text
if n > 0:
    print("оң")
else:
    print("басқа")
elif n < 0:
    print("теріс")
# SyntaxError: invalid syntax
```

`else` әрқашан соңғы.

**3. `if`-сіз `elif`.** `elif` тізбегі әрқашан `if`-пен басталады.

**4. Шарттардың қате реті** (4-бөлімді қараңыз) — синтаксистік қате жоқ, бірақ нәтиже қате. Бұл **логикалық қате** — оны табу үшін шекаралық мәндермен тексеріңіз.

**5. Шекаралық мәндерді ұмыту.** «85 және одан жоғары — 5» десе, `ball > 85` емес, `ball >= 85` жазу керек. Тексеру үшін **шекаралық мәндерді** енгізіп көріңіз: 84, 85, 64, 65, 39, 40.

## Негізгі ұғымдар

| Ұғым | Түсініктеме |
|---|---|
| Көп тармақты таңдау | Бірнеше нұсқаның ішінен біреуін таңдау |
| `elif` | «Әйтпесе, егер» — келесі шартты тексеру |
| Шарттар реті | Жоғарыдан төмен; бірінші `True` блогы орындалады |
| Шекаралық мән | Аралықтың шетіндегі мән (мыс. 85) |
| Трассировка | Бағдарламаның орындалуын қадамдап кестемен бақылау |
| `match-case` | Мәнді үлгілермен салыстыру (Python 3.10+) |

## Ескерту

- `match-case` тек Python 3.10-да пайда болды: ескі нұсқаларда `match` бар код `SyntaxError` береді. Нұсқаны `python --version` командасымен тексеруге болады.
- `match` ішінде бірнеше мәнді `|` арқылы біріктіруге болады: `case "сенбі" | "жексенбі":`, сондай-ақ күзетші-шарт қосуға болады: `case x if x > 100:`.
- Егер `elif` тармақтары өте көп болса және әрқайсысы мәнді нәтижемен ғана сәйкестендірсе, сөздік ыңғайлырақ: `bagalar = {"1": 300, "2": 600, "3": 450}` және `bagalar.get(tandau, "мұндай нөмір жоқ")`.
- Жолдарды салыстыру алдында `.lower()` (немесе `.strip().lower()`) әдісі пайдаланушы енгізгендегі артық бос орындар мен әртүрлі регистрден қорғайды.
- `elif` тізбегін тексеру үшін әр тармақты және барлық шекаралық мәндерді тестілеңіз; автоматты тексеру үшін `assert` немесе `unittest` модулі қолданылады.
- Құжаттама: https://docs.python.org/3/tutorial/controlflow.html#if-statements және https://docs.python.org/3/tutorial/controlflow.html#match-statements
