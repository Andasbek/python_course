## 1. Множественный выбор

**Множественный выбор** — выбор **одного** варианта из более чем двух в соответствии с условиями.

Примеры из жизни:
- Светофор: красный — стой, жёлтый — приготовься, зелёный — иди.
- Школьная оценка: 85–100 баллов — «5», 65–84 — «4», 40–64 — «3», 0–39 — «2».
- Погода: ниже −10 — «сильный мороз», ниже 0 — «холодно», ниже 20 — «тепло», иначе — «жарко».

### Блок-схема

```text
            ╱‾‾‾‾‾‾‾‾‾╲  да     ┌─────────────┐
 ─────────► Условие 1?  ─────► │ Действие 1  │ ───────┐
            ╲_________╱        └─────────────┘        │
                 │ нет                                │
            ╱‾‾‾‾‾‾‾‾‾╲  да     ┌─────────────┐        │
            Условие 2?  ─────► │ Действие 2  │ ───────┤
            ╲_________╱        └─────────────┘        │
                 │ нет                                │
            ╱‾‾‾‾‾‾‾‾‾╲  да     ┌─────────────┐        │
            Условие 3?  ─────► │ Действие 3  │ ───────┤
            ╲_________╱        └─────────────┘        │
                 │ нет                                │
            ┌───────────────┐                         │
            │ действие else │ ────────────────────────┤
            └───────────────┘                         ▼
                                               следующая команда
```

Условия проверяются **сверху вниз**. Выполняется блок первого условия, оказавшегося `True`, а остальные **не проверяются**.

## 2. Синтаксис

```text
if условие_1:
    блок_1
elif условие_2:
    блок_2
elif условие_3:
    блок_3
else:
    блок на случай, когда все условия ложны
```

- `elif` — сокращение от слов «else if» (иначе, если).
- Количество `elif` не ограничено: один, два, десять…
- `elif` и `else` — на одном уровне с `if`, с двоеточием.
- `else` — не обязателен, но если он есть, то **в самом конце** и только один.

Задача «положительное/отрицательное/ноль» с помощью `elif`:

```python
n = int(input("Число: "))
if n > 0:
    print("Положительное")
elif n < 0:
    print("Отрицательное")
else:
    print("Ноль")
```

Результат:
```text
Число: 0
Ноль
```

Уровень отступа одинаковый, код легко читать!

## 3. Пример: перевод балла в оценку

```python
ball = int(input("Балл (0–100): "))
if ball >= 85:
    baga = 5
elif ball >= 65:
    baga = 4
elif ball >= 40:
    baga = 3
else:
    baga = 2
print("Ваша оценка:", baga)
```

Результат:
```text
Балл (0–100): 72
Ваша оценка: 4
```

**Почему достаточно `elif ball >= 65` и не нужно писать `65 <= ball < 85`?** Потому что до второго условия мы доходим, только если первое условие **ложно**. То есть там уже известно, что `ball < 85`. `elif` «знает», что все предыдущие условия ложны.

### Трассировка выполнения (ball = 72)

| Шаг | Условие | Результат | Действие |
|---|---|---|---|
| 1 | `72 >= 85` | False | к следующему условию |
| 2 | `72 >= 65` | True | `baga = 4`, выход из цепочки |
| 3 | `72 >= 40` | — | не проверяется |
| 4 | `else` | — | не выполняется |

## 4. Порядок условий важен!

Если записать условия в неверном порядке:

```python
ball = 95
if ball >= 40:
    baga = 3
elif ball >= 65:
    baga = 4
elif ball >= 85:
    baga = 5
else:
    baga = 2
print("Ваша оценка:", baga)
```

Результат:
```text
Ваша оценка: 3
```

95 баллов подходят и под условие `ball >= 40`, оно проверено первым, поэтому до остальных очередь не дошла.

> Правило: если проверяете диапазоны через «**>=**» — пишите **от большего к меньшему**, если через «**<**» — **от меньшего к большему**.

Та же задача в порядке «от меньшего к большему»:

```python
ball = 95
if ball < 40:
    baga = 2
elif ball < 65:
    baga = 3
elif ball < 85:
    baga = 4
else:
    baga = 5
print("Ваша оценка:", baga)
```

Результат:
```text
Ваша оценка: 5
```

## 5. Разница между цепочкой if/elif и несколькими if

```python
temp = 30
# Несколько независимых if — может появиться несколько сообщений
if temp > 25:
    print("if: Жарко")
if temp > 15:
    print("if: Тепло")
if temp > 0:
    print("if: Прохладно")
```

Результат:
```text
if: Жарко
if: Тепло
if: Прохладно
```

```python
temp = 30
# if/elif — только одно сообщение
if temp > 25:
    print("Жарко")
elif temp > 15:
    print("Тепло")
elif temp > 0:
    print("Прохладно")
else:
    print("Мороз")
```

Результат:
```text
Жарко
```

| | Несколько `if` | `if/elif/else` |
|---|---|---|
| Сколько условий проверяется | **все** | до первого `True` |
| Сколько блоков выполняется | от 0 до всех | 0 или 1 (если есть `else` — ровно 1) |
| Когда используем | условия независимы | варианты исключают друг друга |

## 6. Текстовый выбор: меню

```python
print("1 — Чай, 300 тг")
print("2 — Кофе, 600 тг")
print("3 — Сок, 450 тг")
tandau = input("Ваш выбор: ")
if tandau == "1":
    print("Вы выбрали чай. К оплате: 300 тг")
elif tandau == "2":
    print("Вы выбрали кофе. К оплате: 600 тг")
elif tandau == "3":
    print("Вы выбрали сок. К оплате: 450 тг")
else:
    print("Такого номера нет!")
```

Здесь `else` обрабатывает **неверный ввод** — это признак хорошей программы.

## 7. elif без else

`else` не обязателен. Если его нет и ни одно условие не выполнилось — ничего не выполняется:

```python
kun = input("День недели: ").lower()
if kun == "суббота":
    print("Выходной! Кружка нет.")
elif kun == "воскресенье":
    print("Выходной!")
```

## 8. Вычисления в блоке: индекс массы тела

```python
massa = float(input("Ваш вес (кг): "))
boy = float(input("Ваш рост (м, например 1.65): "))
dsi = massa / boy ** 2
print(f"ИМТ = {dsi:.1f}")
if dsi < 18.5:
    print("Недостаточный вес")
elif dsi < 25:
    print("Нормальный вес")
elif dsi < 30:
    print("Избыточный вес")
else:
    print("Ожирение")
```

Результат:
```text
Ваш вес (кг): 55
Ваш рост (м, например 1.65): 1.65
ИМТ = 20.2
Нормальный вес
```

## 9. Дополнительно: match-case (Python 3.10+)

При сравнении одной переменной с **конкретными значениями** начиная с Python 3.10 можно использовать оператор `match`:

```python
tus = input("Цвет светофора: ").lower()
match tus:
    case "красный":
        print("Стой!")
    case "жёлтый":
        print("Приготовься!")
    case "зелёный":
        print("Иди!")
    case _:
        print("Такого цвета нет")
```

`case _:` играет роль `else`. Но для диапазонов (`ball >= 85`) удобнее `if/elif`, поэтому основной инструмент — `elif`.

## Частые ошибки

**1. Запись `else if`.**

```text
if n > 0:
    print("положительное")
else if n < 0:
    print("отрицательное")
# SyntaxError: expected ':'
```

В Python `elif` — одно слово.

**2. `elif` после `else`.**

```text
if n > 0:
    print("положительное")
else:
    print("другое")
elif n < 0:
    print("отрицательное")
# SyntaxError: invalid syntax
```

`else` всегда последний.

**3. `elif` без `if`.** Цепочка `elif` всегда начинается с `if`.

**4. Неверный порядок условий** (см. раздел 4) — синтаксической ошибки нет, но результат неверный. Это **логическая ошибка** — чтобы её найти, проверяйте граничными значениями.

**5. Забытые граничные значения.** Если сказано «85 и выше — 5», нужно писать `ball >= 85`, а не `ball > 85`. Для проверки введите **граничные значения**: 84, 85, 64, 65, 39, 40.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Множественный выбор | Выбор одного из нескольких вариантов |
| `elif` | «Иначе, если» — проверка следующего условия |
| Порядок условий | Сверху вниз; выполняется блок первого `True` |
| Граничное значение | Значение на краю диапазона (напр. 85) |
| Трассировка | Пошаговое отслеживание выполнения программы с помощью таблицы |
| `match-case` | Сравнение значения с образцами (Python 3.10+) |

## Примечание

- `match-case` появился только в Python 3.10: в более старых версиях код с `match` вызовет `SyntaxError`. Проверить версию можно командой `python --version`.
- В `match` можно объединять несколько значений через `|`: `case "суббота" | "воскресенье":`, а также добавлять условие-охранник: `case x if x > 100:`.
- Если `elif`-веток очень много и каждая лишь сопоставляет значение с результатом, удобнее словарь: `ceny = {"1": 300, "2": 600, "3": 450}` и `ceny.get(tandau, "нет такого номера")`.
- Метод `.lower()` (или `.strip().lower()`) перед сравнением строк защищает от лишних пробелов и разного регистра при вводе пользователя.
- Для проверки цепочки `elif` тестируйте каждую ветвь и все граничные значения; для автоматической проверки используют `assert` или модуль `unittest`.
- Документация: https://docs.python.org/3/tutorial/controlflow.html#if-statements и https://docs.python.org/3/tutorial/controlflow.html#match-statements
