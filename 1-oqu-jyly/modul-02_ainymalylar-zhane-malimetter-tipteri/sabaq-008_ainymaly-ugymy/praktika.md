### 2-тапсырма. Менің айнымалыларым
Өзіңіз туралы 5 айнымалы құрыңыз (`name`, `age`, `city`, `school`, `hobby`) және оларды мына түрде шығарыңыз:

Мысал шығыс:
```text
Аты: Ерлан
Жасы: 13
Қаласы: Алматы
Мектебі: №54
Хоббиі: футбол
```

### 3-тапсырма. Дүкенде
Айнымалылар құрыңыз: `bread_price = 180`, `milk_price = 520`, `bread_count = 2`, `milk_count = 3`. Әр тауардың құнын және жалпы соманы айнымалылар арқылы есептеп шығарыңыз.

Мысал шығыс:
```text
Нан: 360 теңге
Сүт: 1560 теңге
Барлығы: 1920 теңге
```
*Кеңес:* `bread_total = bread_price * bread_count`.

### 4-тапсырма. Трассировка
Бағдарламаны компьютерсіз орындап, трассировка кестесін толтырыңыз. Содан кейін Thonny-де (View → Variables, Debug) тексеріңіз.

```python
x = 4
y = x * 3
x = y - x
y = y + x
x += 1
print(x, y)
```

| Жол | x | y |
|---|---|---|
| `x = 4` | | |
| ... | | |

### 5-тапсырма. Әмиян
Әмиянда 5000 теңге бар. Құрама меншіктеу (`+=`, `-=`) арқылы мына оқиғаларды бағдарламаға жазыңыз да, әр қадамнан кейін қалдықты шығарыңыз:
1. Кітап сатып алдың — 1800 теңге.
2. Әжең берді — 2000 теңге.
3. Досыңа сыйлық — 1500 теңге.

Мысал шығыс:
```text
Бастапқы: 5000
Кітаптан кейін: 3200
Әжем бергеннен кейін: 5200
Сыйлықтан кейін: 3700
```

## Кеңейтілген деңгей

### 6-тапсырма. Алмастыру
`left = "Алма"`, `right = "Алмұрт"`. Мәндерді:
1. үшінші айнымалы арқылы;
2. Python-ның бір жолдық тәсілімен алмастырыңыз.
Әр тәсілден кейін нәтижені шығарыңыз.

### 7-тапсырма. Үш айнымалыны «айналдыру»
`a = 1`, `b = 2`, `c = 3`. Мәндерді «шеңбер бойымен» жылжытыңыз: `a`-ға `b`-ның мәні, `b`-ға `c`-ның мәні, `c`-ға `a`-ның (бастапқы) мәні. Нәтиже: `2 3 1`.

### 8-тапсырма. «Мен туралы 2.0»
7-сабақтағы «Мен туралы» бағдарламасын айнымалылармен қайта жазыңыз: атыңыз, жасыңыз, қалаңыз бір-бір рет қана айнымалыға жазылсын, ал бағдарламада олар кемінде екі рет қолданылсын. Атыңызды өзгерткенде тек бір жол түзетілетініне көз жеткізіңіз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Үшінші айнымалысыз
Екі сандық айнымалының (`a = 15`, `b = 40`) мәнін үшінші айнымалыны да, `a, b = b, a` тәсілін де қолданбай, тек қосу мен азайту арқылы алмастырыңыз.

### 10-тапсырма. Бактерия
Бір ыдыста 1 бактерия бар. Әр сағат сайын бактериялар саны екі есе артады. Бір ғана `bacteria` айнымалысын және `*=` амалын қолданып, 1, 2, 3, 4, 5-сағаттағы санды шығарыңыз. Содан кейін ойланыңыз: 24 сағаттан кейін неше бактерия болады? (Есептеу үшін `**` амалын келесі сабақтарда өтеміз; әзірге `*=` арқылы көріңіз.)

## Үй тапсырмасы
1. «Менің мектеп күнім» бағдарламасы: сабақ саны, бір сабақтың ұзақтығы (мин), үзіліс саны мен ұзақтығы айнымалыларда сақталсын. Мектепте өткізетін жалпы уақытты минутпен есептеп шығарыңыз.
2. 1-тапсырмадағы қате атауларды дұрыс атауларға айналдырып жазыңыз.
3. Үйдегі 3 затты (мысалы, теледидар, тоңазытқыш, ноутбук) таңдап, әрқайсысы үшін «бағасы» мен «саны» айнымалыларын құрып, жалпы құнын есептеңіз.
