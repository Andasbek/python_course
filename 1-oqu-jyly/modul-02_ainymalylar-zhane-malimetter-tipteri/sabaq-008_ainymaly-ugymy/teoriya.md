## 1. Айнымалы деген не?

**Айнымалы** (переменная, variable) — бағдарламада мәліметті сақтайтын, **аты бар** жады аймағы. Айнымалының мәні бағдарлама барысында өзгере алады — сондықтан «айнымалы» деп аталады.

**Аналогия — қорап.** Айнымалыны сыртына жапсырма (аты) жабыстырылған қорап деп елестетіңіз. Қораптың ішінде бір ғана зат (мән) жатады.

```text
   +----------+      +----------+      +----------+
   |    12    |      | "Айдана" |      |   650    |
   +----------+      +----------+      +----------+
       age              name              price
```

- `age` (жасы) қорабында — `12`;
- `name` (аты) қорабында — `"Айдана"`;
- `price` (бағасы) қорабында — `650`.

Басқа аналогия — мектептегі шкафтар: әр шкафтың нөмірі (аты) бар, ішіндегі заттар өзгеруі мүмкін.

## 2. Мән меншіктеу

Айнымалыға мән беру — **меншіктеу** (присваивание, assignment). Ол `=` таңбасымен жазылады:

```text
айнымалының_аты = мән
```

```python
name = "Айдана"
age = 12
city = "Алматы"

print(name)
print(age)
print("Қаласы:", city)
```

Нәтижесі:
```text
Айдана
12
Қаласы: Алматы
```

**Маңызды!** Бағдарламалаудағы `=` таңбасы математикадағы «тең» емес. Ол «**оң жақтағы мәнді сол жақтағы айнымалыға сал**» дегенді білдіреді. Сондықтан ол оңнан солға қарай оқылады: `age = 12` — «12 мәнін age айнымалысына сал».

Python-да айнымалы алдын ала «жарияланбайды»: оған бірінші рет мән берген сәтте ол **құрылады**.

### 2.1. Айнымалыны қолдану
Айнымалының атын жазсақ, Python оның орнына мәнін қояды:

```python
price = 650
count = 3
total = price * count
print("Төлеуге:", total, "теңге")
```

Нәтижесі:
```text
Төлеуге: 1950 теңге
```

Енді бағаны өзгерту үшін тек бір жолды (`price = 700`) түзету жеткілікті — бұл айнымалының басты пайдасы.

### 2.2. Айнымалы мен мәтіннің айырмашылығы
```python
city = "Шымкент"
print(city)
print("city")
```

Нәтижесі:
```text
Шымкент
city
```

Тырнақшасыз `city` — айнымалы (оның мәні шығады), тырнақшадағы `"city"` — жай мәтін.

## 3. Айнымалыға ат қою ережелері

### 3.1. Міндетті ережелер (бұзылса — қате)
1. Атау тек **әріптерден, цифрлардан және астын сызу таңбасынан** `_` тұрады.
2. Атау **цифрдан басталмайды**: `1place` — қате, `place1` — дұрыс.
3. Атауда **бос орын**, сызықша `-`, нүкте, `!`, `@`, `$` т.б. таңбалар болмайды.
4. Python-ның **кілт сөздерін** (зарезервированные слова) атау ретінде қолдануға болмайды.
5. Python **үлкен және кіші әріптерді ажыратады**: `age`, `Age`, `AGE` — үш түрлі айнымалы.

Python кілт сөздері:

```text
False   None    True    and     as      assert  async   await
break   class   continue def    del     elif    else    except
finally for     from    global  if      import  in      is
lambda  nonlocal not    or      pass    raise   return  try
while   with    yield
```

Оларды Python-ның өзінен көруге болады:

```python
import keyword
print(keyword.kwlist)
```

### 3.2. Ұсынылатын ережелер (PEP 8 — «жақсы әдет»)
1. Атау **мағыналы** болсын: `a` емес, `price`; `x` емес, `student_name`.
2. **Кіші әріппен**, сөздерді `_` арқылы бөліп жазамыз (snake_case — «жылан стилі»): `total_price`, `birth_year`.
3. Атауларды **латынша** жазамыз (ағылшынша немесе түсінікті транслит): `baga` немесе `price`, `aty` немесе `name`. Python кирилл әріптерін де қабылдайды (`баға = 100` жұмыс істейді), бірақ бұл кәсіби ортада қабылданбаған және раскладка ауыстыруда қате тудырады.
4. Python-ның дайын функцияларының атын қоймаймыз: `print`, `input`, `sum`, `max`, `list`, `str`, `int` — әйтпесе олар «бұзылады».
5. Тым ұзын емес: `the_number_of_students_in_our_class` орнына `student_count`.

### 3.3. Мысалдар кестесі

| Атау | Дұрыс па? | Түсіндірме |
|---|---|---|
| `age` | ✓ | Қысқа, мағыналы |
| `student_name` | ✓ | snake_case |
| `score2` | ✓ | Цифр соңында — рұқсат |
| `_temp` | ✓ | `_`-тен басталуға болады |
| `2score` | ✗ | Цифрдан басталады |
| `student name` | ✗ | Бос орын |
| `student-name` | ✗ | Сызықша — бұл азайту белгісі |
| `class` | ✗ | Кілт сөз |
| `print` | ⚠ | Қате бермейді, бірақ `print()` функциясын «бұзады» |
| `a` | ⚠ | Рұқсат, бірақ мағынасыз |
| `StudentName` | ⚠ | Рұқсат, бірақ айнымалы үшін PEP 8 бойынша `student_name` |

## 4. Айнымалының мәнін өзгерту

Айнымалыға жаңа мән берсек, **ескі мән жойылады** (қорапқа жаңа зат салсақ, ескісі шығарылады):

```python
weather = "күн ашық"
print("Таңертең:", weather)
weather = "жаңбыр"
print("Түсте:", weather)
```

Нәтижесі:
```text
Таңертең: күн ашық
Түсте: жаңбыр
```

### 4.1. Айнымалының өз мәнін пайдаланып өзгерту
```python
score = 10
score = score + 5
print(score)
```

Нәтижесі:
```text
15
```

Бұл математикада мағынасыз («10 = 15»?), бірақ бағдарламада ол былай орындалады:
1. Оң жақ есептеледі: `score + 5` → `10 + 5` → `15`.
2. Нәтиже сол жақтағы айнымалыға жазылады: `score` енді `15`.

Қысқаша жазылуы (құрама меншіктеу): `score += 5`. Сол сияқты: `-=`, `*=`, `/=`.

```python
balance = 5000      # картадағы ақша
balance -= 1200     # түскі ас
balance -= 200      # автобус
balance += 3000     # ата-анам салды
print("Қалдық:", balance, "теңге")
```

Нәтижесі:
```text
Қалдық: 6600 теңге
```

## 5. Мәнді көшіру, көп меншіктеу, алмастыру

### 5.1. Бір айнымалыдан екіншісіне көшіру
```python
a = 7
b = a       # b-ға a-ның мәні көшірілді
a = 100     # a өзгерді, b өзгермейді
print(a, b)
```

Нәтижесі:
```text
100 7
```

### 5.2. Бірнеше айнымалыға бір жолда мән беру
```python
x, y, z = 1, 2, 3
print(x, y, z)

a = b = c = 0       # үшеуіне бірдей мән
print(a, b, c)
```

Нәтижесі:
```text
1 2 3
0 0 0
```

### 5.3. Екі айнымалының мәнін алмастыру
Есеп: стақанда сүт, кеседе шырын. Оларды қалай ауыстыруға болады? Үшінші бос ыдыс керек!

```python
glass = "сүт"
cup = "шырын"

temp = glass    # 1) сүтті уақытша ыдысқа құйдық
glass = cup     # 2) шырынды стақанға құйдық
cup = temp      # 3) сүтті кесеге құйдық

print("Стақанда:", glass)
print("Кеседе:", cup)
```

Нәтижесі:
```text
Стақанда: шырын
Кеседе: сүт
```

Python-да мұны бір жолмен жасауға болады:

```python
glass = "сүт"
cup = "шырын"
glass, cup = cup, glass
print(glass, cup)
```

Нәтижесі:
```text
шырын сүт
```

## 6. Айнымалыларды Thonny-де бақылау

Thonny-де **View → Variables** мәзірін қосыңыз. Бағдарламаны 🐞 (Debug) батырмасымен іске қосып, **F7** (Step into) немесе **F6** (Step over) арқылы қадамдап жүріңіз. Оң жақ терезеде әр айнымалының аты мен ағымдағы мәні көрінеді — бұл **трассировка кестесінің** автоматты нұсқасы.

Трассировка (қолмен):

```python
a = 5
b = a + 3
a = b * 2
b = a - b
print(a, b)
```

| Жол | a | b |
|---|---|---|
| `a = 5` | 5 | — |
| `b = a + 3` | 5 | 8 |
| `a = b * 2` | 16 | 8 |
| `b = a - b` | 16 | 8 |
| `print(a, b)` | 16 | 8 |

Нәтижесі:
```text
16 8
```

## Жиі кездесетін қателер

**1. Мән берілмеген айнымалыны қолдану.**
```python
# print(total)  # NameError: name 'total' is not defined
total = 100
print(total)
```
Айнымалыны алдымен құрып (мән беріп), сосын қолданамыз. Бағдарлама жоғарыдан төмен орындалады!

**2. Атаудағы әріп қатесі немесе үлкен/кіші әріп.**
```text
name = "Дана"
print(Name)
NameError: name 'Name' is not defined. Did you mean: 'name'?
```

**3. `=` таңбасының бағытын шатастыру.**
```text
12 = age
SyntaxError: cannot assign to literal here. Maybe you meant '==' instead of '='?
```
Дұрысы: айнымалы әрқашан сол жақта.
```python
age = 12
```

**4. Ережеге қайшы атау.**
```text
1st_place = "Алтын"
SyntaxError: invalid decimal literal

my name = "Арман"
SyntaxError: invalid syntax
```
Дұрысы:
```python
first_place = "Алтын"
my_name = "Арман"
```

**5. Дайын функцияның атын айнымалыға беру.**
```python
print = "Сәлем"
# print("Тест")  # TypeError: 'str' object is not callable
```
Мұндайда `print` енді функция емес, мәтін болып қалады. Shell-ді қайта іске қосу керек (Thonny: Stop/Restart). Мұндай атауларды қолданбаңыз!

**6. Айнымалыны тырнақшаға алу.**
```python
name = "Ержан"
print("name")   # name деп шығады, Ержан емес
print(name)     # Ержан
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Айнымалы (variable) | Мәліметті сақтайтын, аты бар жады аймағы |
| Мән (value) | Айнымалыда сақталған дерек |
| Меншіктеу (assignment) | `=` арқылы айнымалыға мән беру |
| Идентификатор | Айнымалының (функцияның) аты |
| Кілт сөз (keyword) | Python-да арнайы мағынасы бар, атау ретінде қолдануға болмайтын сөз |
| snake_case | Сөздерді кіші әріппен, `_` арқылы бөліп жазу стилі |
| Құрама меншіктеу | `+=`, `-=`, `*=`, `/=` — айнымалыны өз мәні негізінде өзгерту |
| Алмастыру (swap) | Екі айнымалының мәнін орын ауыстыру |

## Ескерту

- Python-да айнымалы — «қораптың» өзі емес, **объектіге сілтейтін атау**. `b = a` орындалғаннан кейін екі атау да бір объектіге сілтейді; сандар мен жолдар үшін бұл байқалмайды, бірақ тізімдер үшін маңызды (тізімді бір атау арқылы өзгертсеңіз, ол екінші атау арқылы да көрінеді).
- `id(x)` функциясы объектінің «мекенжайын» көрсетеді, ал `del x` атауды жояды: осыдан кейін `x`-ке жүгіну `NameError` береді.
- Кілт сөздерден бөлек «жұмсақ» кілт сөздер бар (`match`, `case`, `_`, 3.12-ден бастап — `type`): олар тек белгілі бір құрылымдарда ерекше мағынаға ие. Тізімі: `keyword.softkwlist`.
- БАС әріптермен жазылған атаулар (`MAX_SCORE = 100`) PEP 8 бойынша тұрақтыларды — өзгертілмейтін мәндерді білдіреді. Python мұны тексермейді, бұл — келісім.
- Python 3.8+ нұсқасында мәнді өрнектің ішінде меншіктейтін `:=` («морж») операторы бар — оны қарапайым `=` белгісімен шатастырмаңыз.
- Атау беру ережелері — PEP 8-дегі «Naming Conventions» бөлімі: https://peps.python.org/pep-0008/#naming-conventions
