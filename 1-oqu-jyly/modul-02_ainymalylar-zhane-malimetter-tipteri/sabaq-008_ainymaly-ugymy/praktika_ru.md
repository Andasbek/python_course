# Урок 8. Практические задания: переменные и присваивание значения

## Базовый уровень

### Задание 1. Проверь имя
Какое имя правильное (✓), какое ошибочное (✗), а какое допустимое, но плохое (⚠)? Напишите причину.

`school_number`, `5klass`, `my-city`, `Temperature`, `if`, `total_sum`, `x`, `student age`, `_count`, `price$`, `input`, `max_speed_kmh`

### Задание 2. Мои переменные
Создайте 5 переменных о себе (`name`, `age`, `city`, `school`, `hobby`) и выведите их в таком виде:

Пример вывода:
```text
Имя: Ерлан
Возраст: 13
Город: Алматы
Школа: №54
Хобби: футбол
```

### Задание 3. В магазине
Создайте переменные: `bread_price = 180`, `milk_price = 520`, `bread_count = 2`, `milk_count = 3`. Вычислите с помощью переменных стоимость каждого товара и общую сумму и выведите их.

Пример вывода:
```text
Хлеб: 360 тенге
Молоко: 1560 тенге
Итого: 1920 тенге
```
*Подсказка:* `bread_total = bread_price * bread_count`.

### Задание 4. Трассировка
Выполните программу без компьютера и заполните таблицу трассировки. Затем проверьте в Thonny (View → Variables, Debug).

```python
x = 4
y = x * 3
x = y - x
y = y + x
x += 1
print(x, y)
```

| Строка | x | y |
|---|---|---|
| `x = 4` | | |
| ... | | |

### Задание 5. Кошелёк
В кошельке 5000 тенге. Запишите в программу следующие события с помощью составного присваивания (`+=`, `-=`) и после каждого шага выводите остаток:
1. Купил(а) книгу — 1800 тенге.
2. Бабушка дала — 2000 тенге.
3. Подарок другу — 1500 тенге.

Пример вывода:
```text
Сначала: 5000
После книги: 3200
После подарка бабушки: 5200
После подарка другу: 3700
```

## Продвинутый уровень

### Задание 6. Обмен
`left = "Яблоко"`, `right = "Груша"`. Поменяйте значения местами:
1. с помощью третьей переменной;
2. однострочным способом Python.
После каждого способа выведите результат.

### Задание 7. «Прокрутка» трёх переменных
`a = 1`, `b = 2`, `c = 3`. Сдвиньте значения «по кругу»: в `a` — значение `b`, в `b` — значение `c`, в `c` — (исходное) значение `a`. Результат: `2 3 1`.

### Задание 8. «Обо мне 2.0»
Перепишите программу «Обо мне» с 7-го урока с использованием переменных: ваше имя, возраст, город пусть записываются в переменную только по одному разу, а в программе используются не менее двух раз. Убедитесь, что при изменении имени исправляется только одна строка.

## ★ Олимпиадная / творческая задача

### Задание 9. Без третьей переменной
Поменяйте местами значения двух числовых переменных (`a = 15`, `b = 40`), не используя ни третью переменную, ни способ `a, b = b, a`, — только сложение и вычитание.

### Задание 10. Бактерии
В сосуде 1 бактерия. Каждый час количество бактерий удваивается. Используя только одну переменную `bacteria` и операцию `*=`, выведите количество в 1, 2, 3, 4, 5-й час. Затем подумайте: сколько бактерий будет через 24 часа? (Операцию `**` для вычисления пройдём на следующих уроках; пока попробуйте через `*=`.)
