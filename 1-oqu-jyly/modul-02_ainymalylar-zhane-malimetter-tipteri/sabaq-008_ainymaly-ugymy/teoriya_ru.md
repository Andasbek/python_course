## 1. Что такое переменная?

**Переменная** (айнымалы, variable) — **именованная** область памяти, в которой программа хранит информацию. Значение переменной может меняться в ходе выполнения программы — поэтому она и называется «переменной».

**Аналогия — коробка.** Представьте переменную как коробку с наклеенной снаружи этикеткой (именем). Внутри коробки лежит только один предмет (значение).

```text
   +----------+      +----------+      +----------+
   |    12    |      | "Айдана" |      |   650    |
   +----------+      +----------+      +----------+
       age              name              price
```

- в коробке `age` (возраст) — `12`;
- в коробке `name` (имя) — `"Айдана"`;
- в коробке `price` (цена) — `650`.

Другая аналогия — школьные шкафчики: у каждого шкафчика есть номер (имя), а вещи внутри могут меняться.

## 2. Присваивание значения

Задание значения переменной — это **присваивание** (меншіктеу, assignment). Оно записывается знаком `=`:

```text
имя_переменной = значение
```

```python
name = "Айдана"
age = 12
city = "Алматы"

print(name)
print(age)
print("Город:", city)
```

Результат:
```text
Айдана
12
Город: Алматы
```

**Важно!** Знак `=` в программировании — это не математическое «равно». Он означает «**положи значение справа в переменную слева**». Поэтому он читается справа налево: `age = 12` — «положи значение 12 в переменную age».

В Python переменная не «объявляется» заранее: она **создаётся** в момент первого присваивания ей значения.

### 2.1. Использование переменной
Если написать имя переменной, Python подставит вместо него её значение:

```python
price = 650
count = 3
total = price * count
print("К оплате:", total, "тенге")
```

Результат:
```text
К оплате: 1950 тенге
```

Теперь, чтобы изменить цену, достаточно исправить всего одну строку (`price = 700`) — в этом главная польза переменной.

### 2.2. Разница между переменной и текстом
```python
city = "Шымкент"
print(city)
print("city")
```

Результат:
```text
Шымкент
city
```

`city` без кавычек — переменная (выводится её значение), `"city"` в кавычках — просто текст.

## 3. Правила именования переменных

### 3.1. Обязательные правила (при нарушении — ошибка)
1. Имя состоит только из **букв, цифр и символа подчёркивания** `_`.
2. Имя **не начинается с цифры**: `1place` — ошибка, `place1` — правильно.
3. В имени нет **пробелов**, дефиса `-`, точки, `!`, `@`, `$` и других символов.
4. Нельзя использовать в качестве имени **ключевые слова** Python (зарезервированные слова).
5. Python **различает заглавные и строчные буквы**: `age`, `Age`, `AGE` — три разные переменные.

Ключевые слова Python:

```text
False   None    True    and     as      assert  async   await
break   class   continue def    del     elif    else    except
finally for     from    global  if      import  in      is
lambda  nonlocal not    or      pass    raise   return  try
while   with    yield
```

Их можно посмотреть в самом Python:

```python
import keyword
print(keyword.kwlist)
```

### 3.2. Рекомендуемые правила (PEP 8 — «хорошая привычка»)
1. Имя должно быть **осмысленным**: не `a`, а `price`; не `x`, а `student_name`.
2. Пишем **строчными буквами**, разделяя слова символом `_` (snake_case — «змеиный стиль»): `total_price`, `birth_year`.
3. Имена пишем **латиницей** (по-английски или понятным транслитом): `baga` или `price`, `aty` или `name`. Python принимает и кириллицу (`цена = 100` работает), но в профессиональной среде так не принято, и при переключении раскладки это приводит к ошибкам.
4. Не используем имена готовых функций Python: `print`, `input`, `sum`, `max`, `list`, `str`, `int` — иначе они «сломаются».
5. Не слишком длинно: вместо `the_number_of_students_in_our_class` — `student_count`.

### 3.3. Таблица примеров

| Имя | Правильно? | Пояснение |
|---|---|---|
| `age` | ✓ | Короткое, осмысленное |
| `student_name` | ✓ | snake_case |
| `score2` | ✓ | Цифра в конце — разрешено |
| `_temp` | ✓ | Можно начинать с `_` |
| `2score` | ✗ | Начинается с цифры |
| `student name` | ✗ | Пробел |
| `student-name` | ✗ | Дефис — это знак вычитания |
| `class` | ✗ | Ключевое слово |
| `print` | ⚠ | Ошибки не будет, но функция `print()` «сломается» |
| `a` | ⚠ | Разрешено, но бессмысленно |
| `StudentName` | ⚠ | Разрешено, но для переменной по PEP 8 — `student_name` |

## 4. Изменение значения переменной

Если присвоить переменной новое значение, **старое значение удаляется** (если положить в коробку новый предмет, старый вынимается):

```python
weather = "солнечно"
print("Утром:", weather)
weather = "дождь"
print("Днём:", weather)
```

Результат:
```text
Утром: солнечно
Днём: дождь
```

### 4.1. Изменение переменной с использованием её собственного значения
```python
score = 10
score = score + 5
print(score)
```

Результат:
```text
15
```

В математике это бессмысленно («10 = 15»?), но в программе выполняется так:
1. Вычисляется правая часть: `score + 5` → `10 + 5` → `15`.
2. Результат записывается в переменную слева: теперь `score` равно `15`.

Краткая запись (составное присваивание): `score += 5`. Аналогично: `-=`, `*=`, `/=`.

```python
balance = 5000      # деньги на карте
balance -= 1200     # обед
balance -= 200      # автобус
balance += 3000     # родители пополнили
print("Остаток:", balance, "тенге")
```

Результат:
```text
Остаток: 6600 тенге
```

## 5. Копирование значения, множественное присваивание, обмен

### 5.1. Копирование из одной переменной в другую
```python
a = 7
b = a       # в b скопировано значение a
a = 100     # a изменилась, b не меняется
print(a, b)
```

Результат:
```text
100 7
```

### 5.2. Присваивание значений нескольким переменным в одной строке
```python
x, y, z = 1, 2, 3
print(x, y, z)

a = b = c = 0       # всем трём одинаковое значение
print(a, b, c)
```

Результат:
```text
1 2 3
0 0 0
```

### 5.3. Обмен значений двух переменных
Задача: в стакане молоко, в чашке сок. Как поменять их местами? Нужен третий, пустой сосуд!

```python
glass = "молоко"
cup = "сок"

temp = glass    # 1) перелили молоко во временный сосуд
glass = cup     # 2) перелили сок в стакан
cup = temp      # 3) перелили молоко в чашку

print("В стакане:", glass)
print("В чашке:", cup)
```

Результат:
```text
В стакане: сок
В чашке: молоко
```

В Python это можно сделать одной строкой:

```python
glass = "молоко"
cup = "сок"
glass, cup = cup, glass
print(glass, cup)
```

Результат:
```text
сок молоко
```

## 6. Отслеживание переменных в Thonny

Включите в Thonny меню **View → Variables**. Запустите программу кнопкой 🐞 (Debug) и выполняйте её по шагам с помощью **F7** (Step into) или **F6** (Step over). В правом окне видно имя каждой переменной и её текущее значение — это автоматический вариант **таблицы трассировки**.

Трассировка (вручную):

```python
a = 5
b = a + 3
a = b * 2
b = a - b
print(a, b)
```

| Строка | a | b |
|---|---|---|
| `a = 5` | 5 | — |
| `b = a + 3` | 5 | 8 |
| `a = b * 2` | 16 | 8 |
| `b = a - b` | 16 | 8 |
| `print(a, b)` | 16 | 8 |

Результат:
```text
16 8
```

## Частые ошибки
**1. Использование переменной, которой не присвоено значение.**
```python
# print(total)  # NameError: name 'total' is not defined
total = 100
print(total)
```
Сначала создаём переменную (присваиваем значение), потом используем. Программа выполняется сверху вниз!

**2. Опечатка в имени или заглавная/строчная буква.**
```text
name = "Дана"
print(Name)
NameError: name 'Name' is not defined. Did you mean: 'name'?
```

**3. Путаница с направлением знака `=`.**
```text
12 = age
SyntaxError: cannot assign to literal here. Maybe you meant '==' instead of '='?
```
Правильно: переменная всегда слева.
```python
age = 12
```

**4. Имя, нарушающее правила.**
```text
1st_place = "Золото"
SyntaxError: invalid decimal literal

my name = "Арман"
SyntaxError: invalid syntax
```
Правильно:
```python
first_place = "Золото"
my_name = "Арман"
```

**5. Присвоение переменной имени готовой функции.**
```python
print = "Привет"
# print("Тест")  # TypeError: 'str' object is not callable
```
В этом случае `print` уже не функция, а текст. Нужно перезапустить Shell (Thonny: Stop/Restart). Не используйте такие имена!

**6. Переменная в кавычках.**
```python
name = "Ержан"
print("name")   # выведется name, а не Ержан
print(name)     # Ержан
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Переменная (айнымалы, variable) | Именованная область памяти, в которой хранится информация |
| Значение (value) | Данные, хранящиеся в переменной |
| Присваивание (assignment) | Задание значения переменной с помощью `=` |
| Идентификатор | Имя переменной (функции) |
| Ключевое слово (keyword) | Слово, имеющее в Python особое значение; его нельзя использовать как имя |
| snake_case | Стиль записи слов строчными буквами через `_` |
| Составное присваивание | `+=`, `-=`, `*=`, `/=` — изменение переменной на основе её собственного значения |
| Обмен (swap) | Перестановка значений двух переменных |

## Примечание

- В Python переменная — это **имя, ссылающееся на объект**, а не сама «коробка». После `b = a` оба имени ссылаются на один объект; для чисел и строк это незаметно, но для списков важно (изменение списка через одно имя видно через другое).
- Функция `id(x)` показывает «адрес» объекта, а `del x` удаляет имя: после этого обращение к `x` даёт `NameError`.
- Помимо ключевых слов есть «мягкие» ключевые слова (`match`, `case`, `_`, с 3.12 — `type`): они особые только в определённых конструкциях. Список: `keyword.softkwlist`.
- Имена, написанные ПРОПИСНЫМИ буквами (`MAX_SCORE = 100`), по PEP 8 обозначают константы — значения, которые не принято менять. Python это не проверяет, это соглашение.
- В Python 3.8+ есть оператор `:=` («морж»), который присваивает значение внутри выражения, — не путайте его с обычным `=`.
- Правила именования — раздел «Naming Conventions» в PEP 8: https://peps.python.org/pep-0008/#naming-conventions
