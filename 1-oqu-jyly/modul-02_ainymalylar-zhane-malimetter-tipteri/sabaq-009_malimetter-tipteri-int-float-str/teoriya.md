## 1. Мәліметтер типі деген не?

Өмірде біз әртүрлі деректермен жұмыс істейміз: жас (12), бой (1.55 м), аты («Дана»), «үй тапсырмасы орындалды ма?» (иә/жоқ). Олармен әртүрлі әрекет жасауға болады: жасты қосуға болады, ал атты — жоқ.

**Мәліметтер типі** (тип данных, data type) — мәннің қандай түрге жататынын және онымен қандай амалдар орындауға болатынын анықтайтын сипаттама.

Аналогия: дүкендегі сөрелер. Сүт — сүт сөресінде, нан — нан сөресінде. Әр сөреде өз ережесі бар: сүт тоңазытқышта сақталады, нан — қағаз пакетте.

Python-ның 4 негізгі қарапайым типі:

| Тип | Толық атауы | Мағынасы | Мысалдар |
|---|---|---|---|
| `int` | integer | Бүтін сан | `12`, `-5`, `0`, `2026`, `1000000` |
| `float` | floating point | Нақты (бөлшек) сан | `3.14`, `-0.5`, `1.55`, `36.6`, `2.0` |
| `str` | string | Жол (мәтін) | `"Сәлем"`, `'Алматы'`, `"123"`, `""` |
| `bool` | boolean | Логикалық мән | `True`, `False` |

## 2. type() функциясы

`type()` — мәннің немесе айнымалының типін көрсететін функция.

```python
print(type(12))
print(type(3.14))
print(type("Сәлем"))
print(type(True))
```

Нәтижесі:
```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

(`class` сөзі «класс, түр» дегенді білдіреді: Python-да әр мәліметтер типі — класс, ал әр мән — сол кластың объектісі.)

Айнымалымен:

```python
age = 13
height = 1.58
name = "Арман"
is_student = True

print(name, type(name))
print(age, type(age))
print(height, type(height))
print(is_student, type(is_student))
```

Нәтижесі:
```text
Арман <class 'str'>
13 <class 'int'>
1.58 <class 'float'>
True <class 'bool'>
```

Python-да айнымалының типін алдын ала жазу қажет емес — Python оны **мәніне қарап өзі анықтайды**. Мұны **динамикалық типтеу** дейді. Сондықтан бір айнымалы әр сәтте әр типті мән сақтай алады:

```python
data = 100
print(type(data))
data = "жүз"
print(type(data))
```

Нәтижесі:
```text
<class 'int'>
<class 'str'>
```

## 3. int — бүтін сандар

- Оң, теріс және нөл: `5`, `-17`, `0`.
- Python-да бүтін сандардың өлшемі шектелмеген: өте үлкен сандармен де жұмыс істейді.
- Үлкен сандарды оқуға жеңіл болу үшін `_` қоюға болады: `1_000_000` = `1000000`.

```python
population = 2_200_000     # Алматы халқы (шамамен)
print(population)
print(type(population))
```

Нәтижесі:
```text
2200000
<class 'int'>
```

Мысалдар: оқушылар саны, жыл, қабат, ұпай, теңге (тиынсыз).

## 4. float — нақты сандар

- Бөлшек бөлігі **нүкте** арқылы жазылады (үтір емес!): `3.14`, ал `3,14` — бұл екі сан.
- `2.0` — бұл `float`, ал `2` — `int`. Мәні тең, бірақ типі әртүрлі.
- Өте үлкен/кіші сандар үшін экспоненциалды жазу: `1.5e6` = 1 500 000.0.

```python
temperature = 36.6
price_usd = 4.99
print(temperature, type(temperature))
print(2.0, type(2.0))
print(1.5e6)
```

Нәтижесі:
```text
36.6 <class 'float'>
2.0 <class 'float'>
1500000.0
```

Мысалдар: бой, салмақ, температура, орташа баға, валюта бағамы.

**Қызықты дерек:** компьютер нақты сандарды екілік жүйеде жуықтап сақтайды, сондықтан кейде кішкене дәлсіздік болады:

```python
print(0.1 + 0.2)
```

Нәтижесі:
```text
0.30000000000000004
```

Бұл Python-ның қатесі емес — IEEE 754 стандартын қолданатын барлық тілдерде солай. Шығару үшін нәтижені дөңгелектейді: `round(0.1 + 0.2, 2)` немесе `f"{0.1 + 0.2:.2f}"`.

## 5. str — жолдар (мәтін)

- Тырнақшаға алынған кез келген таңбалар тізбегі: `"Сәлем"`, `'Python'`, `"Алматы, 2026"`.
- Тырнақшаға алынған сан да — жол: `"123"` — бұл `str`, `123` — бұл `int`.
- Бос жол: `""`.

```python
print(type("123"))
print(type(123))
```

Нәтижесі:
```text
<class 'str'>
<class 'int'>
```

### 5.1. Жолдарды біріктіру (конкатенация) — `+`
```python
first_name = "Әлия"
last_name = "Нұрланова"
full_name = first_name + " " + last_name
print(full_name)
```

Нәтижесі:
```text
Әлия Нұрланова
```

Бос орынды өзіміз қосуымыз керек — `+` оны автоматты қоймайды.

### 5.2. Жолды қайталау — `*`
```python
print("Ура! " * 3)
print("-" * 25)
```

Нәтижесі:
```text
Ура! Ура! Ура! 
-------------------------
```

### 5.3. Жолдың ұзындығы — `len()`
`len()` жолдағы таңбалар санын (бос орын мен тыныс белгілерін қоса) береді:

```python
city = "Алматы"
print(len(city))
print(len("Сәлем, әлем!"))
print(len(""))
```

Нәтижесі:
```text
6
12
0
```

### 5.4. Санды «қосу» мен жолды «қосудың» айырмашылығы
```python
print(5 + 5)
print("5" + "5")
print(5 * 3)
print("5" * 3)
```

Нәтижесі:
```text
10
55
15
555
```

Бір таңба (`+`) типке байланысты әртүрлі жұмыс істейді: сандарды қосады, жолдарды біріктіреді.

## 6. bool — логикалық тип

Тек **екі** мәні бар: `True` (ақиқат, иә) және `False` (жалған, жоқ). Бас әріппен жазылады!

```python
is_raining = False
has_homework = True
print("Жаңбыр жауып тұр ма?", is_raining)
print("Үй тапсырмасы бар ма?", has_homework)
print(type(has_homework))
```

Нәтижесі:
```text
Жаңбыр жауып тұр ма? False
Үй тапсырмасы бар ма? True
<class 'bool'>
```

`bool` мәндері **салыстыру** (`>`, `<`, `==`, `!=`, `>=`, `<=`) нәтижесінде пайда болады:

```python
age = 13
print(age > 10)
print(age == 18)
```

Нәтижесі:
```text
True
False
```

`bool` блок-схеманың **ромбына** (шартына) сәйкес келеді: «Иә» = `True`, «Жоқ» = `False`. `if` операторы дәл осындай мәндерді тексереді.

Атау кеңесі: логикалық айнымалыларды `is_`, `has_`, `can_` деп бастау ыңғайлы: `is_student`, `has_ticket`, `can_vote`.

## 7. Тағы бір ерекше мән: None

`None` — «мән жоқ», «бос» дегенді білдіретін ерекше мән (типі `NoneType`). Мысалы, әлі белгісіз деректі сақтау үшін.

```python
phone = None
print(phone, type(phone))
```

Нәтижесі:
```text
None <class 'NoneType'>
```

## 8. Типтерді салыстыру кестесі

| Мән | Типі | Неге? |
|---|---|---|
| `42` | `int` | Бүтін сан |
| `42.0` | `float` | Нүктесі бар |
| `"42"` | `str` | Тырнақшада |
| `-7` | `int` | Теріс бүтін сан |
| `0.5` | `float` | Бөлшек сан |
| `"True"` | `str` | Тырнақшада |
| `True` | `bool` | Логикалық мән |
| `""` | `str` | Бос жол |
| `3e2` | `float` | Экспоненциалды жазу (300.0) |

## Жиі кездесетін қателер

**1. Жол мен санды `+` арқылы біріктіру.**
```python
age = 13
# print("Менің жасым " + age)
# TypeError: can only concatenate str (not "int") to str
```
Себебі: Python жол мен санды «қоса» алмайды — қосу керек пе, әлде біріктіру керек пе, белгісіз. Шешімдері:
```python
age = 13
print("Менің жасым", age)          # үтір арқылы
print("Менің жасым " + str(age))   # санды жолға айналдыру
```
Нәтижесі:
```text
Менің жасым 13
Менің жасым 13
```

**2. Ондық бөлшекті үтірмен жазу.**
```python
height = 1,58
print(height)
print(type(height))
```
Нәтижесі:
```text
(1, 58)
<class 'tuple'>
```
Бұл сан емес, екі саннан тұратын жинақ (кортеж, `tuple`). Дұрысы: `height = 1.58`.

**3. `True`/`False`-ты кіші әріппен жазу.**
```text
is_ready = true
NameError: name 'true' is not defined. Did you mean: 'True'?
```
Дұрысы: `is_ready = True`.

**4. `"True"` пен `True`-ды шатастыру.** `"True"` — жол (4 әріп), `True` — логикалық мән.

**5. Санды тырнақшаға алып, есептей алмау.**
```python
a = "10"
b = "20"
print(a + b)
```
Нәтижесі:
```text
1020
```
Күткеніміз `30` еді! Есептеу үшін сандар тырнақшасыз болуы керек.

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Мәліметтер типі | Мәннің түрін және онымен орындалатын амалдарды анықтайтын сипаттама |
| `int` | Бүтін сан |
| `float` | Нақты (бөлшек) сан, нүктемен жазылады |
| `str` | Жол — тырнақшадағы мәтін |
| `bool` | Логикалық тип: `True` немесе `False` |
| `None` | «Мән жоқ» дегенді білдіретін ерекше мән |
| `type()` | Мәннің типін көрсететін функция |
| `len()` | Жолдың ұзындығын (таңбалар санын) беретін функция |
| Конкатенация | Жолдарды `+` арқылы біріктіру |
| Динамикалық типтеу | Айнымалының типін Python мәніне қарап өзі анықтауы |

## Ескерту

- `bool` — `int` типінің ішкі түрі: `True == 1` және `False == 0`, сондықтан `True + True` нәтижесі `2`. Мұны былай тексеруге болады: `isinstance(True, int)` → `True`.
- Бағдарламаларда типті тексеру үшін `type(x) == int` емес, көбіне `isinstance(x, int)` қолданылады: `isinstance` ішкі типтерді де ескереді.
- Кез келген мәннің `bool()` мәні: `0`, `0.0`, `""`, `None` — `False`, қалғандарының дерлік бәрі — `True`. Сондықтан `bool("False")` — `True` (бос емес жол!).
- `float` сандарын дәл теңдікке салыстыру қауіпті (`0.1 + 0.2 == 0.3` → `False`); `math.isclose(a, b)` қолданыңыз. Ақшалай есептеулер үшін `decimal` модулі бар.
- Python-да жолдар **өзгермейді**: `s[0] = "A"` `TypeError` береді; кез келген «өзгерту» жаңа жол жасайды.
- Кіріктірілген типтер туралы толығырақ: https://docs.python.org/3/library/stdtypes.html
