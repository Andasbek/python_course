## 1. Что такое тип данных?

В жизни мы работаем с разными данными: возраст (12), рост (1.55 м), имя («Дана»), «выполнено ли домашнее задание?» (да/нет). С ними можно выполнять разные действия: возраст можно складывать, а имя — нет.

**Тип данных** (мәліметтер типі, data type) — характеристика, определяющая, к какому виду относится значение и какие операции с ним можно выполнять.

Аналогия: полки в магазине. Молоко — на молочной полке, хлеб — на хлебной. У каждой полки свои правила: молоко хранится в холодильнике, хлеб — в бумажном пакете.

4 основных простых типа Python:

| Тип | Полное название | Значение | Примеры |
|---|---|---|---|
| `int` | integer | Целое число | `12`, `-5`, `0`, `2026`, `1000000` |
| `float` | floating point | Вещественное (дробное) число | `3.14`, `-0.5`, `1.55`, `36.6`, `2.0` |
| `str` | string | Строка (текст) | `"Привет"`, `'Алматы'`, `"123"`, `""` |
| `bool` | boolean | Логическое значение | `True`, `False` |

## 2. Функция type()

`type()` — функция, показывающая тип значения или переменной.

```python
print(type(12))
print(type(3.14))
print(type("Привет"))
print(type(True))
```

Результат:
```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

(Слово `class` означает «класс, вид»: в Python каждый тип данных — это класс, а каждое значение — объект этого класса.)

С переменной:

```python
age = 13
height = 1.58
name = "Арман"
is_student = True

print(name, type(name))
print(age, type(age))
print(height, type(height))
print(is_student, type(is_student))
```

Результат:
```text
Арман <class 'str'>
13 <class 'int'>
1.58 <class 'float'>
True <class 'bool'>
```

В Python не нужно заранее указывать тип переменной — Python **сам определяет его по значению**. Это называется **динамической типизацией**. Поэтому одна переменная в разные моменты может хранить значения разных типов:

```python
data = 100
print(type(data))
data = "сто"
print(type(data))
```

Результат:
```text
<class 'int'>
<class 'str'>
```

## 3. int — целые числа

- Положительные, отрицательные и ноль: `5`, `-17`, `0`.
- В Python размер целых чисел не ограничен: можно работать даже с очень большими числами.
- Для удобства чтения больших чисел можно ставить `_`: `1_000_000` = `1000000`.

```python
population = 2_200_000     # население Алматы (примерно)
print(population)
print(type(population))
```

Результат:
```text
2200000
<class 'int'>
```

Примеры: количество учеников, год, этаж, баллы, тенге (без тиынов).

## 4. float — вещественные числа

- Дробная часть пишется через **точку** (не запятую!): `3.14`, а `3,14` — это два числа.
- `2.0` — это `float`, а `2` — `int`. Значения равны, но типы разные.
- Для очень больших/малых чисел — экспоненциальная запись: `1.5e6` = 1 500 000.0.

```python
temperature = 36.6
price_usd = 4.99
print(temperature, type(temperature))
print(2.0, type(2.0))
print(1.5e6)
```

Результат:
```text
36.6 <class 'float'>
2.0 <class 'float'>
1500000.0
```

Примеры: рост, вес, температура, средняя оценка, курс валют.

**Интересный факт:** компьютер хранит вещественные числа в двоичной системе приближённо, поэтому иногда возникает небольшая неточность:

```python
print(0.1 + 0.2)
```

Результат:
```text
0.30000000000000004
```

Это не ошибка Python — так во всех языках, использующих стандарт IEEE 754. Для вывода результат округляют: `round(0.1 + 0.2, 2)` или `f"{0.1 + 0.2:.2f}"`.

## 5. str — строки (текст)

- Любая последовательность символов в кавычках: `"Привет"`, `'Python'`, `"Алматы, 2026"`.
- Число в кавычках — тоже строка: `"123"` — это `str`, `123` — это `int`.
- Пустая строка: `""`.

```python
print(type("123"))
print(type(123))
```

Результат:
```text
<class 'str'>
<class 'int'>
```

### 5.1. Объединение строк (конкатенация) — `+`
```python
first_name = "Алия"
last_name = "Нурланова"
full_name = first_name + " " + last_name
print(full_name)
```

Результат:
```text
Алия Нурланова
```

Пробел нужно добавить самим — `+` не ставит его автоматически.

### 5.2. Повторение строки — `*`
```python
print("Ура! " * 3)
print("-" * 25)
```

Результат:
```text
Ура! Ура! Ура! 
-------------------------
```

### 5.3. Длина строки — `len()`
`len()` возвращает количество символов в строке (включая пробелы и знаки препинания):

```python
city = "Алматы"
print(len(city))
print(len("Привет, мир!"))
print(len(""))
```

Результат:
```text
6
12
0
```

### 5.4. Разница между «сложением» чисел и «сложением» строк
```python
print(5 + 5)
print("5" + "5")
print(5 * 3)
print("5" * 3)
```

Результат:
```text
10
55
15
555
```

Один и тот же знак (`+`) работает по-разному в зависимости от типа: числа складывает, строки объединяет.

## 6. bool — логический тип

Имеет только **два** значения: `True` (истина, да) и `False` (ложь, нет). Пишутся с заглавной буквы!

```python
is_raining = False
has_homework = True
print("Идёт дождь?", is_raining)
print("Есть домашнее задание?", has_homework)
print(type(has_homework))
```

Результат:
```text
Идёт дождь? False
Есть домашнее задание? True
<class 'bool'>
```

Значения `bool` появляются в результате **сравнения** (`>`, `<`, `==`, `!=`, `>=`, `<=`):

```python
age = 13
print(age > 10)
print(age == 18)
```

Результат:
```text
True
False
```

`bool` соответствует **ромбу** (условию) блок-схемы: «Да» = `True`, «Нет» = `False`. Именно такие значения проверяет оператор `if`.

Совет по именам: логические переменные удобно начинать с `is_`, `has_`, `can_`: `is_student`, `has_ticket`, `can_vote`.

## 7. Ещё одно особое значение: None

`None` — особое значение, означающее «значения нет», «пусто» (тип `NoneType`). Например, для хранения пока неизвестных данных.

```python
phone = None
print(phone, type(phone))
```

Результат:
```text
None <class 'NoneType'>
```

## 8. Сравнительная таблица типов

| Значение | Тип | Почему? |
|---|---|---|
| `42` | `int` | Целое число |
| `42.0` | `float` | Есть точка |
| `"42"` | `str` | В кавычках |
| `-7` | `int` | Отрицательное целое число |
| `0.5` | `float` | Дробное число |
| `"True"` | `str` | В кавычках |
| `True` | `bool` | Логическое значение |
| `""` | `str` | Пустая строка |
| `3e2` | `float` | Экспоненциальная запись (300.0) |

## Частые ошибки
**1. Объединение строки и числа через `+`.**
```python
age = 13
# print("Мой возраст " + age)
# TypeError: can only concatenate str (not "int") to str
```
Причина: Python не может «сложить» строку и число — непонятно, складывать или объединять. Решения:
```python
age = 13
print("Мой возраст", age)          # через запятую
print("Мой возраст " + str(age))   # превращение числа в строку
```
Результат:
```text
Мой возраст 13
Мой возраст 13
```

**2. Запись десятичной дроби через запятую.**
```python
height = 1,58
print(height)
print(type(height))
```
Результат:
```text
(1, 58)
<class 'tuple'>
```
Это не число, а набор из двух чисел (кортеж, `tuple`). Правильно: `height = 1.58`.

**3. `True`/`False` со строчной буквы.**
```text
is_ready = true
NameError: name 'true' is not defined. Did you mean: 'True'?
```
Правильно: `is_ready = True`.

**4. Путаница `"True"` и `True`.** `"True"` — строка (4 буквы), `True` — логическое значение.

**5. Число в кавычках не получается вычислить.**
```python
a = "10"
b = "20"
print(a + b)
```
Результат:
```text
1020
```
А мы ожидали `30`! Для вычислений числа должны быть без кавычек.

## Основные понятия

| Понятие | Определение |
|---|---|
| Тип данных | Характеристика, определяющая вид значения и выполнимые с ним операции |
| `int` | Целое число |
| `float` | Вещественное (дробное) число, пишется через точку |
| `str` | Строка — текст в кавычках |
| `bool` | Логический тип: `True` или `False` |
| `None` | Особое значение, означающее «значения нет» |
| `type()` | Функция, показывающая тип значения |
| `len()` | Функция, возвращающая длину строки (количество символов) |
| Конкатенация | Объединение строк с помощью `+` |
| Динамическая типизация | Автоматическое определение Python типа переменной по её значению |

## Примечание

- `bool` — подтип `int`: `True == 1` и `False == 0`, поэтому `True + True` даёт `2`. Проверить это можно так: `isinstance(True, int)` → `True`.
- Для проверки типа в программах чаще используют `isinstance(x, int)`, а не `type(x) == int`: `isinstance` учитывает подтипы.
- `bool()` любого значения: `0`, `0.0`, `""`, `None` дают `False`, почти всё остальное — `True`. Поэтому `bool("False")` — это `True` (непустая строка!).
- Сравнивать `float` на точное равенство опасно (`0.1 + 0.2 == 0.3` → `False`); используйте `math.isclose(a, b)`. Для денежных расчётов есть модуль `decimal`.
- Строки в Python **неизменяемые**: `s[0] = "A"` вызывает `TypeError`; любые «изменения» создают новую строку.
- Подробно о встроенных типах: https://docs.python.org/3/library/stdtypes.html
