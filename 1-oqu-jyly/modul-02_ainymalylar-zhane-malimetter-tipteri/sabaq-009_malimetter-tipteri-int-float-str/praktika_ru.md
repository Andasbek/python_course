# Урок 9. Практические задания: типы данных и type()

## Базовый уровень

### Задание 1. «Рассортируй типы» (сначала на бумаге, потом проверь в Python)
Запишите тип каждого значения (`int`, `float`, `str`, `bool`):

`25`, `25.0`, `"25"`, `-3`, `0.001`, `"Алматы"`, `True`, `"False"`, `""`, `1_000`, `2e3`, `" "`

Затем проверьте каждое с помощью `print(type(...))`. Сколько ваших ответов оказались верными?

### Задание 2. Карточка учащегося
Создайте следующие переменные и выведите значение и тип каждой:
- `name` — ваше имя;
- `age` — ваш возраст;
- `height` — ваш рост (в метрах, например 1.52);
- `is_club_member` — являетесь ли вы членом кружка (`True`).

Пример вывода:
```text
Имя: Дана <class 'str'>
Возраст: 12 <class 'int'>
Рост: 1.52 <class 'float'>
Член кружка: True <class 'bool'>
```

### Задание 3. Игра со строками
Создайте переменные `first_name` и `last_name` и:
1. выведите своё полное имя, объединив их через `+` (между ними должен быть пробел);
2. выведите количество символов в полном имени с помощью `len()`;
3. выведите своё имя 3 раза подряд (`*`).

Пример вывода:
```text
Айдар Сериков
Количество символов: 13
АйдарАйдарАйдар
```

### Задание 4. Предскажи, потом проверь
Сначала запишите в тетрадь результат каждой строки, затем проверьте в Python:

```python
print(3 + 4)
print("3" + "4")
print("3" * 4)
print(3 * 4)
print(len("3 + 4"))
print(type(3 + 4.0))
print(type("3" + "4"))
```
