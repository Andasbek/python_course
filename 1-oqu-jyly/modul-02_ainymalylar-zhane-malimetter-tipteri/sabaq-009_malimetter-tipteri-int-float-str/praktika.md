# Сабақ 9. Практикалық тапсырмалар: Мәліметтер типтері және type()

## Базалық деңгей

### 1-тапсырма. «Типтерді сұрыпта» (алдымен қағазда, сосын Python-да тексер)
Әр мәннің типін жазыңыз (`int`, `float`, `str`, `bool`):

`25`, `25.0`, `"25"`, `-3`, `0.001`, `"Алматы"`, `True`, `"False"`, `""`, `1_000`, `2e3`, `" "`

Содан кейін әрқайсысын `print(type(...))` арқылы тексеріңіз. Неше жауабыңыз дұрыс шықты?

### 2-тапсырма. Оқушы картасы
Мына айнымалыларды құрыңыз және әрқайсысының мәні мен типін шығарыңыз:
- `name` — атыңыз;
- `age` — жасыңыз;
- `height` — бойыңыз (метрмен, мысалы 1.52);
- `is_club_member` — үйірме мүшесісіз бе (`True`).

Мысал шығыс:
```text
Аты: Дана <class 'str'>
Жасы: 12 <class 'int'>
Бойы: 1.52 <class 'float'>
Үйірме мүшесі: True <class 'bool'>
```

### 3-тапсырма. Жолдармен ойын
`first_name` және `last_name` айнымалыларын құрып:
1. толық атыңызды `+` арқылы біріктіріп шығарыңыз (арасында бос орын болсын);
2. толық атыңыздағы таңбалар санын `len()` арқылы шығарыңыз;
3. атыңызды 3 рет қатарынан шығарыңыз (`*`).

Мысал шығыс:
```text
Айдар Серіков
Таңбалар саны: 13
АйдарАйдарАйдар
```

### 4-тапсырма. Болжа, сосын тексер
Әр жолдың нәтижесін алдымен дәптерге жазыңыз, содан кейін Python-да тексеріңіз:

```python
print(3 + 4)
print("3" + "4")
print("3" * 4)
print(3 * 4)
print(len("3 + 4"))
print(type(3 + 4.0))
print(type("3" + "4"))
```

## Кеңейтілген деңгей

### 5-тапсырма. Қатені түзет
Бағдарлама қате береді. Неге? Екі түрлі тәсілмен түзетіңіз.

```python

```

Күтілетін нәтиже:


### 6-тапсырма. Жақтау
Кез келген сөзді `word` айнымалысына сақтап, оны `*` таңбасынан жасалған жақтаумен шығарыңыз. Жақтаудың ұзындығы сөздің ұзындығына байланысты автоматты түрде өзгеруі керек (`len()` қолданыңыз).

Мысал (`word = "Python"`):
```text
**********
* Python *
**********
```

Мысал (`word = "Алматы — алма қала"`):
```text
**********************
* Алматы — алма қала *
**********************
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 7-тапсырма. bool — бұл сан ба?
Мына кодты орындап, нәтижесін түсіндіріңіз:

```python
print(True + True)
print(True * 10)
print(False + 5)
print(type(True + 1))
```

Неліктен осылай шықты деп ойлайсыз?

### 8-тапсырма. Дәлсіздік
`print(0.1 + 0.2)` нәтижесі неге `0.3` емес? `print(0.1 + 0.2 == 0.3)` не шығарады? Интернеттен (педагог рұқсат еткен) «floating point» ұғымы туралы 2–3 сөйлем жазыңыз. Нәтижені `round()` функциясымен қалай «түзетуге» болады? (`round(0.1 + 0.2, 2)` көріңіз.)
