## 1. Шпаргалка: айнымалылар, типтер, арифметика, енгізу-шығару

### Айнымалы және меншіктеу
```python
name = "Айдана"     # жаңа айнымалы
score = 10
score += 5          # score = score + 5
a, b = 3, 4         # көп меншіктеу
a, b = b, a         # алмастыру
```

### Мәліметтер типтері
| Тип | Мысал | Түрлендіру |
|---|---|---|
| `int` | `12`, `-5` | `int("12")`, `int(3.9)` → 3 |
| `float` | `3.14`, `2.0` | `float("3.14")`, `float(5)` → 5.0 |
| `str` | `"Сәлем"`, `"12"` | `str(12)` → `"12"` |
| `bool` | `True`, `False` | `bool(0)` → `False` |

### Арифметика
| `+` | `-` | `*` | `/` | `//` | `%` | `**` |
|---|---|---|---|---|---|---|
| қосу | азайту | көбейту | бөлу (float) | бүтін бөлу | қалдық | дәреже |

Реті: `( )` → `**` → `* / // %` → `+ -`.

### Енгізу және шығару
```python
name = input("Атыңыз: ")                # мәтін
age = int(input("Жасыңыз: "))           # бүтін сан
price = float(input("Бағасы: "))        # бөлшек сан
print(f"{name}, {age} жас, {price:.2f} теңге")
```

### f-жол пішімдері
| Пішім | Мағынасы |
|---|---|
| `{x:.2f}` | 2 таңба үтірден кейін |
| `{x:,}` | мыңдықтар |
| `{x:.0%}` | пайыз |
| `{x:02d}` | алдыңғы нөлдер |
| `{x:<10}`, `{x:>10}`, `{x:^10}` | туралау |

## 2. Қолданбалы есепті шешу реті

Код жазбас бұрын мына сұрақтарға жауап береміз (бұл — «енгізу → өңдеу → шығару» сызбасы және тексеру):

| Қадам | Сұрақ | «Дүкен чегі» мысалында |
|---|---|---|
| 1. Кіріс | Пайдаланушыдан не сұраймыз? Қай типте? | Тауар атауы (`str`), бағасы (`float`), саны (`int`) |
| 2. Өңдеу | Қандай формулалар керек? | құн = баға × сан; жалпы = қосынды; жеңілдік = жалпы × % |
| 3. Шығыс | Не шығарамыз? Қандай пішімде? | Чек: тураланған бағандар, `.2f` |
| 4. Тест | Қандай деректермен тексереміз? | Қарапайым сандар (нәтижесін ойша есептеуге болатын) |

## 3. «Калькулятор» есебі

**Есеп:** екі санды енгізіп, олармен барлық арифметикалық амалдардың нәтижесін шығаратын калькулятор жасау.

Бұл — сызықтық бағдарлама: `if` шартты операторынсыз калькулятор **бір** амалды таңдай алмайды, сондықтан **барлық** амалдарды бірден есептейді. Пайдаланушының амалды таңдауы `if`/`elif` арқылы жүзеге асырылады.

### Талдау
- Кіріс: `a`, `b` — бөлшек сандар болуы мүмкін → `float(input())`.
- Өңдеу: `a + b`, `a - b`, `a * b`, `a / b`, `a // b`, `a % b`, `a ** b`.
- Шығыс: әр амал жеке жолда, тураланған, 2 таңбамен.
- Шектеу: `b` нөлге тең болмауы керек (сызықтық бағдарламада — prompt-тағы ескерту).

### Шешім
```python
"""
Бағдарлама: Калькулятор
Сипаттамасы: екі санмен барлық арифметикалық амалдарды орындайды.
"""

print(f"{' КАЛЬКУЛЯТОР ':=^34}")
a = float(input("Бірінші сан (a): "))
b = float(input("Екінші сан (b, 0 емес): "))

print("-" * 34)
print(f"{'a + b':<10} = {a + b:>15.2f}")
print(f"{'a - b':<10} = {a - b:>15.2f}")
print(f"{'a * b':<10} = {a * b:>15.2f}")
print(f"{'a / b':<10} = {a / b:>15.2f}")
print(f"{'a // b':<10} = {a // b:>15.2f}")
print(f"{'a % b':<10} = {a % b:>15.2f}")
print(f"{'a ** 2':<10} = {a ** 2:>15.2f}")
print(f"{'a ** 0.5':<10} = {a ** 0.5:>15.2f}")
print("=" * 34)
```

Нәтижесі:
```text
========== КАЛЬКУЛЯТОР ===========
Бірінші сан (a): 17
Екінші сан (b, 0 емес): 5
----------------------------------
a + b      =           22.00
a - b      =           12.00
a * b      =           85.00
a / b      =            3.40
a // b     =            3.00
a % b      =            2.00
a ** 2     =          289.00
a ** 0.5   =            4.12
==================================
```

## 4. «Дүкен чегі» есебі

**Есеп:** үш тауардың атауын, бағасын және санын енгізіп, жеңілдік пен ҚҚС-ты ескеріп, дүкен чегін шығару.

### Талдау
- Кіріс: 3 × (атауы `str`, бағасы `float`, саны `int`), жеңілдік пайызы (`int`).
- Өңдеу:
  - әр тауардың құны = баға × сан;
  - жиыны = құндардың қосындысы;
  - жеңілдік = жиыны × пайыз / 100;
  - төлеуге = жиыны − жеңілдік;
  - ҚҚС (12%) — бағаның ішінде: ҚҚС = төлеуге × 12 / 112.
- Шығыс: тураланған чек.

### Шешім
```python
"""
Бағдарлама: Дүкен чегі
Сипаттамасы: үш тауардың чегін жеңілдік пен ҚҚС-ты ескеріп шығарады.
"""

shop = "«Береке» дүкені"

name1 = input("1-тауар атауы: ")
price1 = float(input("  бағасы: "))
qty1 = int(input("  саны: "))
name2 = input("2-тауар атауы: ")
price2 = float(input("  бағасы: "))
qty2 = int(input("  саны: "))
name3 = input("3-тауар атауы: ")
price3 = float(input("  бағасы: "))
qty3 = int(input("  саны: "))
discount_percent = int(input("Жеңілдік (%): "))

cost1 = price1 * qty1
cost2 = price2 * qty2
cost3 = price3 * qty3
subtotal = cost1 + cost2 + cost3
discount = subtotal * discount_percent / 100
total = subtotal - discount
vat = total * 12 / 112          # ҚҚС бағаның ішінде

width = 40
print()
print("=" * width)
print(f"{shop:^{width}}")
print(f"{'Алматы қ., Абай даңғылы, 10':^{width}}")
print("-" * width)
print(f"{name1:<14}{qty1:>3} x {price1:>8.2f} = {cost1:>9.2f}")
print(f"{name2:<14}{qty2:>3} x {price2:>8.2f} = {cost2:>9.2f}")
print(f"{name3:<14}{qty3:>3} x {price3:>8.2f} = {cost3:>9.2f}")
print("-" * width)
print(f"{'Жиыны:':<28}{subtotal:>12,.2f}")
print(f"{'Жеңілдік ' + str(discount_percent) + '%:':<28}{-discount:>12,.2f}")
print(f"{'ТӨЛЕУГЕ:':<28}{total:>12,.2f}")
print(f"{'оның ішінде ҚҚС 12%:':<28}{vat:>12,.2f}")
print("=" * width)
print(f"{'Сатып алғаныңызға рақмет!':^{width}}")
```

**Жаңа тәсіл:** `{shop:^{width}}` — ені де айнымалыдан алынады (кірістірілген фигуралық жақша). Бұл чектің енін бір жерден өзгертуге мүмкіндік береді.

## Жиі кездесетін қателер

**1. Енгізуді дұрыс типке түрлендірмеу.**
```python
price = input("Бағасы: ")
qty = int(input("Саны: "))
# cost = price * qty   # "180" * 2 = "180180" — логикалық қате!
cost = float(price) * qty
```

**2. Жеңілдікті пайыз ретінде емес, сан ретінде азайту.**
```python
subtotal = 3220
discount_percent = 5
wrong = subtotal - discount_percent                       # 3215 — қате
right = subtotal - subtotal * discount_percent / 100      # 3059.0 — дұрыс
print(wrong, right)
```

**3. Ұзын атаулар бағанды «бұзады».** `{name:<14}` — атау 14 таңбадан ұзын болса, баған жылжиды. Ұзын атаулар үшін енді үлкейтіңіз немесе атауды қысқартып енгізіңіз.

**4. Нөлге бөлу.** Калькуляторда `b = 0` енгізілсе — `ZeroDivisionError`. Сенімді қорғаныс — бөлер алдында `if b != 0:` тексеруі немесе қатені `try...except ZeroDivisionError` арқылы ұстау.

**5. f-жолда ішкі тырнақша.** `f"{'Жиыны:':<28}"` — сыртқы `"`, ішкі `'`.

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Есепті талдау | Кіріс, өңдеу, шығыс және тест деректерін анықтау |
| ҚҚС (қосылған құн салығы) | Тауар бағасына кіретін салық; мөлшерлемесін Салық кодексі белгілейді |
| Тест деректері | Бағдарламаны тексеруге арналған, нәтижесі алдын ала белгілі деректер |
| Кірістірілген спецификатор | Айнымалыдан алынатын пішім параметрі: `{x:^{width}}` |

## Ескерту

- Салық пен жеңілдік мөлшерлемелерін бағдарламаның басындағы тұрақты-айнымалыларға шығарыңыз (`VAT_RATE = 12`): ҚҚС мөлшерлемесін заң белгілейді және ол өзгереді (Қазақстанда 2026 жылдың 1 қаңтарынан — 16%), сонда тек бір жолды түзету жеткілікті.
- Нақты бағдарламаларда дәл ақшалай есептеулер үшін `float` орнына `decimal.Decimal` қолданылады, ал сомалар тиынға дейін дөңгелектенеді: `Decimal("3059.00")`.
- `,` пішіміндегі мыңдық бөлгіш әрқашан үтір қояды (ағылшынша стиль). Бос орын алу үшін оны ауыстыруға болады: `f"{x:,.2f}".replace(",", " ")`.
- `a // b` және `a % b` `float` сандарымен де жұмыс істейді: `17.5 // 5` → `3.0`, `17.5 % 5` → `2.5`.
- Үш тауарға арналған қайталанатын код (`name1`, `name2`, `name3`) — деректерді тізімде сақтап, `for` циклімен өңдеген ыңғайлы екенінің белгісі.
