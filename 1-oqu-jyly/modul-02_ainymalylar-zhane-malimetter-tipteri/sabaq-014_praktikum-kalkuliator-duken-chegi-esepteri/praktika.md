## Базалық деңгей (практикум, 1-бөлім — 30 мин)

### 1-тапсырма. «Калькулятор» (бірге жазамыз)
Педагогпен бірге теориядағы калькуляторды жазыңыз (`kalkulyator.py`). Содан кейін мына деректермен тестілеп, кестені толтырыңыз:

| № | a | b | a + b | a / b | a // b | a % b |
|---|---|---|---|---|---|---|
| 1 | 17 | 5 | | | | |
| 2 | 10 | 4 | | | | |
| 3 | 7.5 | 2 | | | | |
| 4 | -7 | 2 | | | | |

### 2-тапсырма. Калькуляторды кеңейт
Калькуляторға қосыңыз:
1. Екі санның орташа арифметикалығы.
2. `a` саны `b` санының неше пайызын құрайды (`.1%` пішімі).
3. Бағдарламаның басында және соңында жақтау.

Мысал (a = 17, b = 5):
```text
Орташа         =           11.00
a / b пайызбен =          340.0%
```

### 3-тапсырма. «Дүкен чегі» (өз бетінше)
Теориядағы үлгіге сүйеніп, **өз дүкеніңіздің** чегін жасаңыз (`chek.py`):
- дүкен атауы мен мекенжайы — өзіңіз ойлап табыңыз;
- 3 тауар (атауы, бағасы, саны пайдаланушыдан енгізіледі);
- жиыны, жеңілдік (%), төлеуге, ҚҚС 12%;
- бағандар тураланған, ақша `.2f` пішімінде.

## Өзіндік жұмыс №1 (35 минут)

**Нұсқаулық:** әр тапсырманы бөлек файлға сақтаңыз (`oz1_t1.py` ...). Файлдың бірінші жолына түсініктеме ретінде аты-жөніңізді және нұсқаңызды жазыңыз. 1–3 тапсырмалар міндетті, 4-тапсырма — қосымша ұпай.

### 1-нұсқа

**1-тапсырма (20 ұпай). Типтер мен амалдар.** Бағдарлама не шығарады? Алдымен дәптерге жазыңыз, содан кейін тексеріңіз. Нәтижені `oz1_t1.py` файлына түсініктеме ретінде жазыңыз.
```python
a = 23
b = 4
print(a // b, a % b)
print(a / b)
print(type(a / b))
print(str(a) + str(b))
print(2 + 3 * b ** 2)
```

**2-тапсырма (25 ұпай). Кинотеатр.** Ересек билеттің бағасы (`float`), ересектер саны және балалар саны (`int`) енгізіледі. Бала билеті ересек билеттен 40% арзан. Жалпы соманы 2 таңбамен шығарыңыз.

Мысал:

**3-тапсырма (30 ұпай). Жол уақыты.** Автобус жүрген қашықтық (км, `float`) және орташа жылдамдық (км/сағ, `float`) енгізіледі. Жол уақытын **сағат пен минутпен** (бүтін минутқа дейін) шығарыңыз.

Мысал:
```text

Жылдамдық (км/сағ): 60

```
*Кеңес:* алдымен жалпы минутты есептеңіз: `int(қашықтық / жылдамдық * 60)`.

**4-тапсырма (25 ұпай, қосымша). Электр энергиясы.** Есептегіштің өткен айдағы және осы айдағы көрсеткіштері (`int`), 1 кВт·сағ бағасы (`float`) енгізіледі. Тұтыну мөлшерін, төлем сомасын және төлемді тураланған «түбіртек» түрінде шығарыңыз (тақырып ортада, сандар оңға тураланған, мыңдықтар бөлінген).

Мысал:


### 2-нұсқа

**1-тапсырма (20 ұпай). Типтер мен амалдар.** Бағдарлама не шығарады? Алдымен дәптерге жазыңыз, содан кейін тексеріңіз. Нәтижені `oz1_t1.py` файлына түсініктеме ретінде жазыңыз.

| Критерий | Сипаттамасы | Ұпай |
|---|---|---|
| Дұрыс жұмыс істеуі (40%) | Калькулятор барлық амалдарды дұрыс есептейді; чек дұрыс жиын, жеңілдік, ҚҚС шығарады | 40 |
| Шешімнің ұтымдылығы (25%) | Типтер дұрыс таңдалған (`int`/`float`), формулалар дұрыс, айнымалылар орынды | 25 |

**Өзіндік жұмыс №1:**

| Тапсырма | Ұпай | Не бағаланады |
|---|---|---|
| 1 | 20 | Әр жол — 4 ұпай (дұрыс болжам) |
| 2 | 25 | Енгізу типтері (5), формула (10), пішімдеу (5), атаулар мен түсініктеме (5) |
| 3 | 30 | Енгізу (5), минутқа түрлендіру (10), `//` және `%` дұрыс (10), шығыс пішімі (5) |

Қорытынды пайыз = (жиналған ұпай / 75) × 100%, 100%-дан аспайды. Меңгеру деңгейі: 85–100% — жоғары; 60–84% — орта; 40–59% — бастапқы.

Бағдарламадағы жалпы критерийлермен сәйкестігі: дұрыс жұмыс — 40%, тиімділік пен ұтымдылық — 25%, оқылымдылық — 20%, дербестік пен мерзім — 15% (әр тапсырманың ішкі ұпайлары осы үлестерге сай бөлінген).
