### Задание 1. «Калькулятор» (пишем вместе)
Вместе с педагогом напишите калькулятор из теории (`kalkulyator.py`). Затем протестируйте его на следующих данных и заполните таблицу:

| № | a | b | a + b | a / b | a // b | a % b |
|---|---|---|---|---|---|---|
| 1 | 17 | 5 | | | | |
| 2 | 10 | 4 | | | | |
| 3 | 7.5 | 2 | | | | |
| 4 | -7 | 2 | | | | |

### Задание 2. Расширь калькулятор
Добавьте в калькулятор:
1. Среднее арифметическое двух чисел.
2. Сколько процентов число `a` составляет от числа `b` (формат `.1%`).
3. Рамку в начале и в конце программы.

Пример (a = 17, b = 5):
```text
Среднее        =           11.00
a / b в %      =          340.0%
```

### Задание 3. «Чек магазина» (самостоятельно)
Опираясь на образец из теории, создайте чек **своего магазина** (`chek.py`):
- название и адрес магазина — придумайте сами;
- 3 товара (название, цена, количество вводятся пользователем);
- итого, скидка (%), к оплате, НДС 12%;
- столбцы выровнены, деньги в формате `.2f`.
