## 1. Шпаргалка: переменные, типы, арифметика, ввод-вывод

### Переменная и присваивание
```python
name = "Айдана"     # новая переменная
score = 10
score += 5          # score = score + 5
a, b = 3, 4         # множественное присваивание
a, b = b, a         # обмен
```

### Типы данных
| Тип | Пример | Преобразование |
|---|---|---|
| `int` | `12`, `-5` | `int("12")`, `int(3.9)` → 3 |
| `float` | `3.14`, `2.0` | `float("3.14")`, `float(5)` → 5.0 |
| `str` | `"Привет"`, `"12"` | `str(12)` → `"12"` |
| `bool` | `True`, `False` | `bool(0)` → `False` |

### Арифметика
| `+` | `-` | `*` | `/` | `//` | `%` | `**` |
|---|---|---|---|---|---|---|
| сложение | вычитание | умножение | деление (float) | целочисленное деление | остаток | степень |

Порядок: `( )` → `**` → `* / // %` → `+ -`.

### Ввод и вывод
```python
name = input("Имя: ")                   # текст
age = int(input("Возраст: "))           # целое число
price = float(input("Цена: "))          # дробное число
print(f"{name}, {age} лет, {price:.2f} тенге")
```

### Форматы f-строк
| Формат | Значение |
|---|---|
| `{x:.2f}` | 2 знака после запятой |
| `{x:,}` | тысячи |
| `{x:.0%}` | проценты |
| `{x:02d}` | ведущие нули |
| `{x:<10}`, `{x:>10}`, `{x:^10}` | выравнивание |

## 2. Порядок решения прикладной задачи

Перед написанием кода отвечаем на следующие вопросы (это схема «ввод → обработка → вывод» плюс проверка):

| Шаг | Вопрос | На примере «Чека магазина» |
|---|---|---|
| 1. Вход | Что спрашиваем у пользователя? В каком типе? | Название товара (`str`), цена (`float`), количество (`int`) |
| 2. Обработка | Какие нужны формулы? | стоимость = цена × количество; итого = сумма; скидка = итого × % |
| 3. Выход | Что выводим? В каком формате? | Чек: выровненные столбцы, `.2f` |
| 4. Тест | На каких данных проверяем? | Простые числа (результат которых можно посчитать в уме) |

## 3. Задача «Калькулятор»

**Задача:** создать калькулятор, который вводит два числа и выводит результаты всех арифметических операций над ними.

Это линейная программа: без условного оператора `if` калькулятор не может выбрать **одну** операцию, поэтому вычисляет **все** сразу. Выбор операции пользователем реализуется через `if`/`elif`.

### Анализ
- Вход: `a`, `b` — могут быть дробными числами → `float(input())`.
- Обработка: `a + b`, `a - b`, `a * b`, `a / b`, `a // b`, `a % b`, `a ** b`.
- Выход: каждая операция на отдельной строке, выровнено, с 2 знаками.
- Ограничение: `b` не должно быть равно нулю (в линейной программе — предупреждение в prompt).

### Решение
```python
"""
Программа: Калькулятор
Описание: выполняет все арифметические операции над двумя числами.
"""

print(f"{' КАЛЬКУЛЯТОР ':=^34}")
a = float(input("Первое число (a): "))
b = float(input("Второе число (b, не 0): "))

print("-" * 34)
print(f"{'a + b':<10} = {a + b:>15.2f}")
print(f"{'a - b':<10} = {a - b:>15.2f}")
print(f"{'a * b':<10} = {a * b:>15.2f}")
print(f"{'a / b':<10} = {a / b:>15.2f}")
print(f"{'a // b':<10} = {a // b:>15.2f}")
print(f"{'a % b':<10} = {a % b:>15.2f}")
print(f"{'a ** 2':<10} = {a ** 2:>15.2f}")
print(f"{'a ** 0.5':<10} = {a ** 0.5:>15.2f}")
print("=" * 34)
```

Результат:
```text
========== КАЛЬКУЛЯТОР ===========
Первое число (a): 17
Второе число (b, не 0): 5
----------------------------------
a + b      =           22.00
a - b      =           12.00
a * b      =           85.00
a / b      =            3.40
a // b     =            3.00
a % b      =            2.00
a ** 2     =          289.00
a ** 0.5   =            4.12
==================================
```

## 4. Задача «Чек магазина»

**Задача:** ввести название, цену и количество трёх товаров и вывести чек магазина с учётом скидки и НДС.

### Анализ
- Вход: 3 × (название `str`, цена `float`, количество `int`), процент скидки (`int`).
- Обработка:
  - стоимость каждого товара = цена × количество;
  - итого = сумма стоимостей;
  - скидка = итого × процент / 100;
  - к оплате = итого − скидка;
  - НДС (12%) — включён в цену: НДС = к оплате × 12 / 112.
- Выход: выровненный чек.

### Решение
```python
"""
Программа: Чек магазина
Описание: выводит чек на три товара с учётом скидки и НДС.
"""

shop = "Магазин «Береке»"

name1 = input("Товар 1, название: ")
price1 = float(input("  цена: "))
qty1 = int(input("  количество: "))
name2 = input("Товар 2, название: ")
price2 = float(input("  цена: "))
qty2 = int(input("  количество: "))
name3 = input("Товар 3, название: ")
price3 = float(input("  цена: "))
qty3 = int(input("  количество: "))
discount_percent = int(input("Скидка (%): "))

cost1 = price1 * qty1
cost2 = price2 * qty2
cost3 = price3 * qty3
subtotal = cost1 + cost2 + cost3
discount = subtotal * discount_percent / 100
total = subtotal - discount
vat = total * 12 / 112          # НДС включён в цену

width = 40
print()
print("=" * width)
print(f"{shop:^{width}}")
print(f"{'г. Алматы, пр. Абая, 10':^{width}}")
print("-" * width)
print(f"{name1:<14}{qty1:>3} x {price1:>8.2f} = {cost1:>9.2f}")
print(f"{name2:<14}{qty2:>3} x {price2:>8.2f} = {cost2:>9.2f}")
print(f"{name3:<14}{qty3:>3} x {price3:>8.2f} = {cost3:>9.2f}")
print("-" * width)
print(f"{'Итого:':<28}{subtotal:>12,.2f}")
print(f"{'Скидка ' + str(discount_percent) + '%:':<28}{-discount:>12,.2f}")
print(f"{'К ОПЛАТЕ:':<28}{total:>12,.2f}")
print(f"{'в т.ч. НДС 12%:':<28}{vat:>12,.2f}")
print("=" * width)
print(f"{'Спасибо за покупку!':^{width}}")
```

Результат:

**Новый приём:** `{shop:^{width}}` — ширина тоже берётся из переменной (вложенные фигурные скобки). Это позволяет менять ширину чека в одном месте.

## Частые ошибки
**1. Ввод не преобразован в нужный тип.**
```python
price = input("Цена: ")
qty = int(input("Количество: "))
# cost = price * qty   # "180" * 2 = "180180" — логическая ошибка!
cost = float(price) * qty
```

**2. Вычитание скидки как числа, а не как процента.**
```python
subtotal = 3220
discount_percent = 5
wrong = subtotal - discount_percent                       # 3215 — неверно
right = subtotal - subtotal * discount_percent / 100      # 3059.0 — верно
print(wrong, right)
```

**3. Длинные названия «ломают» столбец.** `{name:<14}` — если название длиннее 14 символов, столбец сдвигается. Для длинных названий увеличьте ширину или вводите название сокращённо.

**4. Деление на ноль.** Если в калькуляторе ввести `b = 0` — `ZeroDivisionError`. Надёжная защита — проверка `if b != 0:` перед делением или перехват ошибки через `try...except ZeroDivisionError`.

**5. Внутренние кавычки в f-строке.** `f"{'Итого:':<28}"` — внешние `"`, внутренние `'`.

## Основные понятия

| Понятие | Определение |
|---|---|
| Анализ задачи | Определение входа, обработки, выхода и тестовых данных |
| НДС (налог на добавленную стоимость, ҚҚС) | Налог, входящий в цену товара; ставка устанавливается Налоговым кодексом |
| Тестовые данные | Данные для проверки программы, результат которых известен заранее |
| Вложенный спецификатор | Параметр формата, взятый из переменной: `{x:^{width}}` |

## Примечание

- Ставки налогов и скидок выносите в переменные-константы в начале программы (`VAT_RATE = 12`): ставка НДС задаётся законом и меняется (в Казахстане с 1 января 2026 года — 16%), и тогда исправлять нужно одну строку.
- Для точных денежных расчётов в реальных программах используют `decimal.Decimal` вместо `float`, а суммы округляют до тиынов: `Decimal("3059.00")`.
- Разделитель тысяч в формате `,` всегда ставит запятую (англоязычный стиль). Чтобы получить пробел, можно заменить её: `f"{x:,.2f}".replace(",", " ")`.
- `a // b` и `a % b` работают и с `float`: `17.5 // 5` → `3.0`, `17.5 % 5` → `2.5`.
- Повторяющийся код для трёх товаров (`name1`, `name2`, `name3`) — признак того, что данные удобнее хранить в списке и обрабатывать циклом `for`.
