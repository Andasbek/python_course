# Сабақ 10. Практикалық тапсырмалар: Арифметикалық амалдар

Бұл сабақта деректерді айнымалыларға тікелей жазамыз (пернетақтадан енгізуді келесі сабақта үйренеміз). Айнымалының мәнін өзгертіп, бағдарламаны бірнеше рет тексеріңіз.

## Базалық деңгей

### 1-тапсырма. Есептемей тұрып болжа
Әр өрнектің мәнін алдымен дәптерде есептеңіз, содан кейін Python-да тексеріңіз:

```python
print(15 // 4)
print(15 % 4)
print(15 / 4)
print(2 ** 5)
print(10 - 2 * 3)
print((10 - 2) * 3)
print(100 // 7 % 3)
print(3 + 4 ** 2 // 5)
```

### 2-тапсырма. Тіктөртбұрыш бөлме
Бөлменің ұзындығы `length = 6` м, ені `width = 4` м. Есептеңіз:
1. Еденнің ауданын.
2. Периметрін (плинтус ұзындығы).
3. Ламинат 1 м² бағасы 4500 теңге — жалпы құнын.

Мысал шығыс:
```text
Ауданы: 24 м²
Периметрі: 20 м
Ламинат құны: 108000 теңге
```

### 3-тапсырма. Уақыт
`minutes = 135` (фильмнің ұзақтығы). Оны сағат пен минутқа айналдырыңыз.

Мысал шығыс:
```text
135 минут = 2 сағат 15 минут
```

### 4-тапсырма. Орташа баға
Тоқсандағы төрт баға: `5`, `4`, `5`, `3`. Орташа бағаны есептеп, 2 таңбаға дейін дөңгелектеп шығарыңыз.

Мысал шығыс:
```text
Орташа баға: 4.25
```

### 5-тапсырма. Жұп па, тақ па?
`n = 37`. `n % 2` мәнін шығарыңыз. Нәтиже 0 болса — жұп, 1 болса — тақ (әзірге нәтижені өзіңіз түсіндіресіз; автоматты түрде «жұп/тақ» деп жазуды IV модульде үйренеміз).

## Кеңейтілген деңгей

### 6-тапсырма. Цифрлар
`n = 2026`. Санның әр цифрын бөлек шығарыңыз және цифрлар қосындысын табыңыз (тек `//` және `%` арқылы).

```text
Жүздік: 0

```

### 7-тапсырма. Банкомат
Банкомат 20 000, 5 000, 1 000 теңгелік купюралар береді. `amount = 47000` теңгені ең аз купюрамен беру үшін әр купюрадан неше дана керек?

Мысал шығыс:
```text
20000 теңгелік: 2
5000 теңгелік: 1
1000 теңгелік: 2
```

### 8-тапсырма. Формуланы аудар
Мына формулаларды Python-ға аударып, `a = 3`, `b = 4`, `c = 5` мәндерімен есептеңіз:
1. Пифагор: √(a² + b²)
2. Үшбұрыштың периметрінің жартысы: p = (a + b + c) / 2
3. Герон формуласы: S = √(p · (p − a) · (p − b) · (p − c))

Күтілетін нәтиже:
```text
Гипотенуза: 5.0
Жарты периметр: 6.0
Ауданы: 6.0
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Санды кері жазу
`n = 375`. Тек арифметикалық амалдар арқылы цифрларын кері ретпен жазылған санды (`573`) **сан ретінде** алыңыз (жол емес!). `print(reversed_n + 1)` → `574` шығуы керек.

### 10-тапсырма. Апта күні
Бүгін — дүйсенбі (апта күнінің нөмірі 0: 0 — дүйсенбі, 1 — сейсенбі, ..., 6 — жексенбі). 100 күннен кейін аптаның қай күні болады? 1000 күннен кейін ше? Бір өрнекпен есептеңіз.

### 11-тапсырма. Шахмат тақтасындағы бидай
Аңыз бойынша шахматты ойлап тапқан адам сыйлық ретінде тақтаның 1-ұяшығына 1 бидай, 2-сіне 2, 3-іне 4, ... әр келесі ұяшыққа екі есе көп бидай сұрапты. 64-ұяшықта неше дән бар? Барлық ұяшықтағы дәндердің қосындысы неше? (Кеңес: 1 + 2 + 4 + ... + 2⁶³ = 2⁶⁴ − 1.)

## Үй тапсырмасы
1. «Менің жасым» бағдарламасы: туған жылыңызды айнымалыға жазып, жасыңызды, өмір сүрген айларды, апталарды, күндерді (шамамен, 365 күн), сағаттарды есептеп шығарыңыз.
2. 3 есеп құрастырыңыз (өмірлік, Қазақстан контекстінде), олардың шешімінде `//` және `%` қолданылсын. Шешімін Python-да жазыңыз.
3. `print(2 ** 3 ** 2)` пен `print((2 ** 3) ** 2)` нәтижелері неге әртүрлі? Түсіндіріп жазыңыз.
