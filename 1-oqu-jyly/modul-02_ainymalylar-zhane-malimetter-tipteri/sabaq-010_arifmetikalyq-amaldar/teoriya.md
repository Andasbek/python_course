## 1. Арифметикалық амалдар

| Амал | Белгісі | Мысал | Нәтижесі | Нәтиже типі |
|---|---|---|---|---|
| Қосу | `+` | `7 + 3` | `10` | int |
| Азайту | `-` | `7 - 3` | `4` | int |
| Көбейту | `*` | `7 * 3` | `21` | int |
| Бөлу | `/` | `7 / 2` | `3.5` | **әрқашан float** |
| Бүтін бөлу | `//` | `7 // 2` | `3` | int (егер екеуі де int) |
| Бөлгендегі қалдық | `%` | `7 % 2` | `1` | int (егер екеуі де int) |
| Дәрежеге шығару | `**` | `7 ** 2` | `49` | int |

```python
a = 17
b = 5
print("a + b =", a + b)
print("a - b =", a - b)
print("a * b =", a * b)
print("a / b =", a / b)
print("a // b =", a // b)
print("a % b =", a % b)
print("a ** b =", a ** b)
```

Нәтижесі:
```text
a + b = 22
a - b = 12
a * b = 85
a / b = 3.4
a // b = 3
a % b = 2
a ** b = 1419857
```

### 1.1. Бөлу `/` — әрқашан float
```python
print(10 / 2)
print(type(10 / 2))
```

Нәтижесі:
```text
5.0
<class 'float'>
```

Сандар бөлінсе де, нәтиже `5.0` (float) болады.

### 1.2. Бүтін бөлу `//` және қалдық `%`

Аналогия: 17 кәмпитті 5 баланың арасында тең бөлеміз.
- Әр балаға **3** кәмпиттен тиеді → `17 // 5 = 3`
- **2** кәмпит артылып қалады → `17 % 5 = 2`

Тексеру: `5 · 3 + 2 = 17`. Жалпы ереже: `a == b * (a // b) + a % b`.

```text
  17 кәмпит:  ●●●●● ●●●●● ●●●●● ●●
              ↓↓↓↓↓ ↓↓↓↓↓ ↓↓↓↓↓
             5 балаға 3-тен     қалдық 2
```

`%` амалының пайдалы қолданыстары:

| Есеп | Өрнек | Түсіндірме |
|---|---|---|
| Сан жұп па? | `n % 2` | 0 болса — жұп, 1 болса — тақ |
| Сан 3-ке бөліне ме? | `n % 3` | 0 болса — бөлінеді |
| Санның соңғы цифры | `n % 10` | `1234 % 10 = 4` |
| Соңғы екі цифр | `n % 100` | `1234 % 100 = 34` |
| Соңғы цифрсыз сан | `n // 10` | `1234 // 10 = 123` |

### 1.3. Дәрежеге шығару `**`
```python
print(2 ** 10)
print(5 ** 2)
print(9 ** 0.5)     # 0.5 дәрежесі — квадрат түбір
print(2 ** -1)      # теріс дәреже — бөлшек
```

Нәтижесі:
```text
1024
25
3.0
0.5
```

## 2. Нәтиженің типі

| Операндтар | Нәтиже типі | Мысал |
|---|---|---|
| int және int (`+ - * // % **`) | int | `7 * 2 = 14` |
| int және int (`/`) | float | `8 / 2 = 4.0` |
| int және float | float | `3 + 0.5 = 3.5`, `7 // 2.0 = 3.0` |
| float және float | float | `1.5 * 2.0 = 3.0` |

## 3. Амалдардың орындалу реті (басымдық)

Python математикадағы ережелерді сақтайды:

| Басымдық | Амал | Ескерту |
|---|---|---|
| 1 (ең жоғары) | `( )` — жақша | Әрқашан бірінші |
| 2 | `**` — дәреже | **Оңнан солға**: `2 ** 3 ** 2 = 2 ** 9 = 512` |
| 3 | `-x` — унарлы минус | `-2 ** 2 = -4` (алдымен дәреже!) |
| 4 | `*`, `/`, `//`, `%` | Солдан оңға |
| 5 (ең төмен) | `+`, `-` | Солдан оңға |

Мысалдар:

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(10 - 4 - 3)
print(20 / 4 * 2)
print(2 ** 3 ** 2)
print(-2 ** 2)
print((-2) ** 2)
print(7 + 10 % 4 * 2)
```

Нәтижесі:
```text
14
20
3
10.0
512
-4
4
11
```

Соңғы өрнекті қадамдап талдайық: `7 + 10 % 4 * 2`
1. `10 % 4` = `2` (`%` пен `*` бір деңгейде, солдан оңға)
2. `2 * 2` = `4`
3. `7 + 4` = `11`

**Кеңес:** күмәндансаңыз — жақша қойыңыз. Артық жақша қате емес, ол кодты түсінікті етеді.

## 4. Математикалық формуланы Python-ға аудару

| Математика | Python | Ескерту |
|---|---|---|
| a · b | `a * b` | Көбейту белгісі міндетті: `2a` емес, `2 * a` |
| (a + b) / 2 | `(a + b) / 2` | Жақшасыз: `a + b / 2` — басқа өрнек! |
| a² | `a ** 2` | `^` емес! |
| √x | `x ** 0.5` | (немесе `math` модуліндегі `math.sqrt(x)`) |
| (a + b) / (c − d) | `(a + b) / (c - d)` | Алымы мен бөлімі жақшада |
| v = s / t | `v = s / t` | |
| S = π r² | `S = 3.14 * r ** 2` | |

```python
# Орташа арифметикалық
a = 4
b = 5
c = 9
average = (a + b + c) / 3
print("Орташа баға:", average)

# Шеңбердің ауданы
r = 10
area = 3.14159 * r ** 2
print("Шеңбердің ауданы:", area)
```

Нәтижесі:
```text
Орташа баға: 6.0
Шеңбердің ауданы: 314.159
```

## 5. Пайдалы функциялар: round() және abs()

`round(x)` — бүтінге дөңгелектеу; `round(x, n)` — үтірден кейін n таңбаға дейін.
`abs(x)` — абсолют шама (модуль).

```python
print(round(3.14159, 2))
print(round(7.6))
print(round(2 / 3, 3))
print(abs(-15))
print(abs(4 - 10))
```

Нәтижесі:
```text
3.14
8
0.667
15
6
```

**Ескерту:** `round()` «банктік» дөңгелектеуді қолданады: `round(2.5)` = `2`, `round(3.5)` = `4` (дәл ортасы болса, жұп санға қарай дөңгелектейді).

### 6.3. Автобус орындары
45 оқушы экскурсияға барады, бір шағын автобусқа 18 адам сияды. Неше автобус керек?

```python
students = 45
seats = 18
full_buses = students // seats
remaining = students % seats
print("Толық автобустар:", full_buses)
print("Қалған оқушылар:", remaining)
print("Барлық керек автобус:", (students + seats - 1) // seats)
```

Нәтижесі:
```text
Толық автобустар: 2
Қалған оқушылар: 9
Барлық керек автобус: 3
```

(`(a + b - 1) // b` — оң сандар үшін жоғары қарай дөңгелектеп бүтін бөлу тәсілі; дәл осыны `-(-a // b)` немесе `math.ceil(a / b)` береді.)

## Жиі кездесетін қателер

**1. Нөлге бөлу.**
```python
a = 10
b = 0
# print(a / b)   # ZeroDivisionError: division by zero
```
Нөлге бөлуге болмайды (`/`, `//`, `%` барлығында). Бөлер алдында бөлгіштің нөлге тең емес екеніне көз жеткізу керек (`if b != 0:` шарты арқылы).

**2. Жақшаны ұмыту.**
```python
a = 4
b = 6
print(a + b / 2)    # 7.0 — орташа емес!
print((a + b) / 2)  # 5.0 — дұрыс орташа
```

**3. Көбейту белгісін жазбау.**
```text
x = 3
y = 2x + 1
SyntaxError: invalid decimal literal
```
Дұрысы:
```python
x = 3
y = 2 * x + 1
print(y)
```

**4. Дәрежені `^` арқылы жазу.**
```python
print(2 ^ 3)    # 1 — бұл дәреже емес, басқа (биттік) амал!
print(2 ** 3)   # 8 — дұрыс
```

**5. `/` нәтижесі float екенін ұмыту.**
```python
pages = 120
days = 4
per_day = pages / days
print(per_day)          # 30.0
print(pages // days)    # 30
```

**6. Теріс сандармен `//` және `%`.** Python `//` нәтижесін **төменге** (кіші жаққа) дөңгелектейді:
```python
print(-7 // 2)   # -4 (−3.5 төменге дөңгелектенді)
print(-7 % 2)    # 1
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Операнд | Амал орындалатын мән (`3 + 4`-тегі 3 және 4) |
| Оператор | Амалдың белгісі (`+`, `*`, `//` ...) |
| Өрнек | Операндтар мен операторлардан құралған, мәні есептелетін жазба |
| Бүтін бөлу (`//`) | Бөліндінің бүтін бөлігін беретін амал |
| Қалдық (`%`) | Бүтін бөлгендегі қалдықты беретін амал |
| Дәреже (`**`) | Санды дәрежеге шығару |
| Басымдық (приоритет) | Амалдардың орындалу реті |
| `round()` | Санды дөңгелектейтін функция |
| `abs()` | Санның абсолют шамасын (модулін) беретін функция |

## Ескерту

- `divmod(a, b)` функциясы бірден `(a // b, a % b)` жұбын қайтарады: `divmod(500, 60)` → `(8, 20)`.
- Кіріктірілген `pow(a, b, m)` функциясы `a ** b % m` мәнін жылдам есептейді — бұл өте үлкен дәрежелер үшін пайдалы.
- Python-да бүтін сандар толып кетпейді (`2 ** 1000` дәл есептеледі), ал `float` шектеулі: `10.0 ** 400` `OverflowError` береді.
- Python-да `%` қалдығы бөлгіштің таңбасын алады: `-7 % 3` = `2`, `7 % -3` = `-2` (C/Java-да нәтиже басқаша болар еді). Бұл `//` төмен қарай дөңгелектеуімен үйлесімді.
- PEP 8 бойынша басымдығы төмен операторлардың айналасына бос орын қойып, басымдығы жоғарыларынан алып тастауға болады — ретті көрсету үшін: `x = a*b + c*d`. Ең бастысы — бірізділік.
- Барлық операторлардың басымдық кестесі: https://docs.python.org/3/reference/expressions.html#operator-precedence
