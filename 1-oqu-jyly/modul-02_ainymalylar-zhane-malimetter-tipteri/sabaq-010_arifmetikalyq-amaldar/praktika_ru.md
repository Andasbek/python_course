На этом уроке записываем данные прямо в переменные (ввод с клавиатуры изучим на следующем уроке). Меняйте значения переменных и проверяйте программу несколько раз.

## Базовый уровень

### Задание 1. Предскажи, не вычисляя
Сначала вычислите значение каждого выражения в тетради, затем проверьте в Python:

```python
print(15 // 4)
print(15 % 4)
print(15 / 4)
print(2 ** 5)
print(10 - 2 * 3)
print((10 - 2) * 3)
print(100 // 7 % 3)
print(3 + 4 ** 2 // 5)
```

### Задание 2. Прямоугольная комната
Длина комнаты `length = 6` м, ширина `width = 4` м. Вычислите:
1. Площадь пола.
2. Периметр (длину плинтуса).
3. Цена ламината за 1 м² — 4500 тенге; общую стоимость.

Пример вывода:
```text

Периметр: 20 м
Стоимость ламината: 108000 тенге
```

### Задание 4. Средняя оценка
Четыре оценки за четверть: `5`, `4`, `5`, `3`. Вычислите среднюю оценку и выведите её, округлив до 2 знаков.

### Задание 5. Чётное или нечётное?

Банкомат выдаёт купюры по 20 000, 5 000, 1 000 тенге. Сколько купюр каждого номинала нужно, чтобы выдать `amount = 47000` тенге наименьшим числом купюр?

### Задание 8. Переведи формулу
Переведите следующие формулы на Python и вычислите их при `a = 3`, `b = 4`, `c = 5`:
1. Пифагор: √(a² + b²)
2. Полупериметр треугольника: p = (a + b + c) / 2
3. Формула Герона: S = √(p · (p − a) · (p − b) · (p − c))

Ожидаемый результат:
```text
Гипотенуза: 5.0
Полупериметр: 6.0
Площадь: 6.0
```
