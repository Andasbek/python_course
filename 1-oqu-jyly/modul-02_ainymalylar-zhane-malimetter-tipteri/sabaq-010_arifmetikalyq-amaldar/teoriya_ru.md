## 1. Арифметические операции

| Операция | Знак | Пример | Результат | Тип результата |
|---|---|---|---|---|
| Сложение | `+` | `7 + 3` | `10` | int |
| Вычитание | `-` | `7 - 3` | `4` | int |
| Умножение | `*` | `7 * 3` | `21` | int |
| Деление | `/` | `7 / 2` | `3.5` | **всегда float** |
| Целочисленное деление | `//` | `7 // 2` | `3` | int (если оба int) |
| Остаток от деления | `%` | `7 % 2` | `1` | int (если оба int) |
| Возведение в степень | `**` | `7 ** 2` | `49` | int |

```python
a = 17
b = 5
print("a + b =", a + b)
print("a - b =", a - b)
print("a * b =", a * b)
print("a / b =", a / b)
print("a // b =", a // b)
print("a % b =", a % b)
print("a ** b =", a ** b)
```

Результат:
```text
a + b = 22
a - b = 12
a * b = 85
a / b = 3.4
a // b = 3
a % b = 2
a ** b = 1419857
```

### 1.1. Деление `/` — всегда float
```python
print(10 / 2)
print(type(10 / 2))
```

Результат:
```text
5.0
<class 'float'>
```

Даже если числа делятся нацело, результат будет `5.0` (float).

### 1.2. Целочисленное деление `//` и остаток `%`

Аналогия: делим 17 конфет поровну между 5 детьми.
- Каждому ребёнку достаётся по **3** конфеты → `17 // 5 = 3`
- **2** конфеты остаются лишними → `17 % 5 = 2`

Проверка: `5 · 3 + 2 = 17`. Общее правило: `a == b * (a // b) + a % b`.

```text
  17 конфет:  ●●●●● ●●●●● ●●●●● ●●
              ↓↓↓↓↓ ↓↓↓↓↓ ↓↓↓↓↓
             5 детям по 3        остаток 2
```

Полезные применения операции `%`:

| Задача | Выражение | Пояснение |
|---|---|---|
| Число чётное? | `n % 2` | если 0 — чётное, если 1 — нечётное |
| Делится ли число на 3? | `n % 3` | если 0 — делится |
| Последняя цифра числа | `n % 10` | `1234 % 10 = 4` |
| Две последние цифры | `n % 100` | `1234 % 100 = 34` |
| Число без последней цифры | `n // 10` | `1234 // 10 = 123` |

### 1.3. Возведение в степень `**`
```python
print(2 ** 10)
print(5 ** 2)
print(9 ** 0.5)     # степень 0.5 — квадратный корень
print(2 ** -1)      # отрицательная степень — дробь
```

Результат:
```text
1024
25
3.0
0.5
```

## 2. Тип результата

|---|---|---|
| int и int (`+ - * // % **`) | int | `7 * 2 = 14` |
| int и int (`/`) | float | `8 / 2 = 4.0` |
| int и float | float | `3 + 0.5 = 3.5`, `7 // 2.0 = 3.0` |

## 3. Порядок выполнения операций (приоритет)

Python соблюдает правила математики:

| Приоритет | Операция | Примечание |
|---|---|---|
| 1 (самый высокий) | `( )` — скобки | Всегда первыми |
| 2 | `**` — степень | **Справа налево**: `2 ** 3 ** 2 = 2 ** 9 = 512` |
| 3 | `-x` — унарный минус | `-2 ** 2 = -4` (сначала степень!) |
| 4 | `*`, `/`, `//`, `%` | Слева направо |
| 5 (самый низкий) | `+`, `-` | Слева направо |

Примеры:

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(10 - 4 - 3)
print(20 / 4 * 2)
print(2 ** 3 ** 2)
print(-2 ** 2)
print((-2) ** 2)
print(7 + 10 % 4 * 2)
```

Результат:
```text
14
20
3
10.0
512
-4
4
11
```

Разберём последнее выражение по шагам: `7 + 10 % 4 * 2`
1. `10 % 4` = `2` (`%` и `*` на одном уровне, слева направо)
2. `2 * 2` = `4`
3. `7 + 4` = `11`

**Совет:** если сомневаетесь — ставьте скобки. Лишние скобки — не ошибка, они делают код понятнее.

## 4. Перевод математической формулы на Python

| Математика | Python | Примечание |
|---|---|---|
| a · b | `a * b` | Знак умножения обязателен: не `2a`, а `2 * a` |
| (a + b) / 2 | `(a + b) / 2` | Без скобок: `a + b / 2` — другое выражение! |
| a² | `a ** 2` | Не `^`! |
| √x | `x ** 0.5` | (или `math.sqrt(x)` из модуля `math`) |
| (a + b) / (c − d) | `(a + b) / (c - d)` | Числитель и знаменатель в скобках |
| v = s / t | `v = s / t` | |
| S = π r² | `S = 3.14 * r ** 2` | |

```python
# Среднее арифметическое
a = 4
b = 5
c = 9
average = (a + b + c) / 3
print("Средняя оценка:", average)

# Площадь круга
r = 10
area = 3.14159 * r ** 2
print("Площадь круга:", area)
```

Результат:
```text
Средняя оценка: 6.0
Площадь круга: 314.159
```

## 5. Полезные функции: round() и abs()

`round(x)` — округление до целого; `round(x, n)` — до n знаков после запятой.
`abs(x)` — абсолютная величина (модуль).

```python
print(round(3.14159, 2))
print(round(7.6))
print(round(2 / 3, 3))
print(abs(-15))
print(abs(4 - 10))
```

Результат:
```text
3.14
8
0.667
15
6
```

**Примечание:** `round()` использует «банковское» округление: `round(2.5)` = `2`, `round(3.5)` = `4` (если число ровно посередине, округляет к чётному).

### 6.3. Места в автобусе
45 учащихся едут на экскурсию, в один микроавтобус помещается 18 человек. Сколько нужно автобусов?

```python
students = 45
seats = 18
full_buses = students // seats
remaining = students % seats
print("Полных автобусов:", full_buses)
print("Оставшихся учащихся:", remaining)
print("Всего нужно автобусов:", (students + seats - 1) // seats)
```

Результат:
```text
Полных автобусов: 2
Оставшихся учащихся: 9
Всего нужно автобусов: 3
```

(`(a + b - 1) // b` — способ целочисленного деления с округлением вверх для положительных чисел; то же даёт `-(-a // b)` или `math.ceil(a / b)`.)

## Частые ошибки
**1. Деление на ноль.**
```python
a = 10
b = 0
# print(a / b)   # ZeroDivisionError: division by zero
```
Делить на ноль нельзя (во всех операциях `/`, `//`, `%`). Перед делением нужно убедиться, что делитель не равен нулю (с помощью условия `if b != 0:`).

**2. Забытые скобки.**
```python
a = 4
b = 6
print(a + b / 2)    # 7.0 — это не среднее!
print((a + b) / 2)  # 5.0 — правильное среднее
```

**3. Пропущен знак умножения.**
```text
x = 3
y = 2x + 1
SyntaxError: invalid decimal literal
```
Правильно:
```python
x = 3
y = 2 * x + 1
print(y)
```

**4. Степень через `^`.**
```python
print(2 ^ 3)    # 1 — это не степень, а другая (побитовая) операция!
print(2 ** 3)   # 8 — правильно
```

**5. Забыли, что результат `/` — float.**
```python
pages = 120
days = 4
per_day = pages / days
print(per_day)          # 30.0
print(pages // days)    # 30
```

**6. `//` и `%` с отрицательными числами.** Python округляет результат `//` **вниз** (в меньшую сторону):
```python
print(-7 // 2)   # -4 (−3.5 округлено вниз)
print(-7 % 2)    # 1
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Операнд | Значение, над которым выполняется операция (3 и 4 в `3 + 4`) |
| Оператор | Знак операции (`+`, `*`, `//` ...) |
| Выражение | Запись из операндов и операторов, значение которой вычисляется |
| Целочисленное деление (`//`) | Операция, дающая целую часть частного |
| Остаток (`%`) | Операция, дающая остаток от целочисленного деления |
| Степень (`**`) | Возведение числа в степень |
| Приоритет | Порядок выполнения операций |
| `round()` | Функция округления числа |
| `abs()` | Функция, возвращающая абсолютную величину (модуль) числа |

## Примечание

- Функция `divmod(a, b)` возвращает сразу пару `(a // b, a % b)`: `divmod(500, 60)` → `(8, 20)`.
- Встроенная `pow(a, b, m)` быстро вычисляет `a ** b % m` — это полезно для очень больших степеней.
- Целые числа в Python не переполняются (`2 ** 1000` вычисляется точно), а `float` ограничен: `10.0 ** 400` вызывает `OverflowError`.
- Остаток `%` в Python имеет знак делителя: `-7 % 3` = `2`, `7 % -3` = `-2` (в C/Java результат был бы другим). Это согласовано с округлением `//` вниз.
- По PEP 8 вокруг операторов с низким приоритетом можно ставить пробелы, а у операторов с высоким — опускать, чтобы показать порядок: `x = a*b + c*d`. Главное — единообразие.
- Таблица приоритетов всех операторов: https://docs.python.org/3/reference/expressions.html#operator-precedence
