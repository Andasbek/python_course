# Сабақ 13. Практикалық тапсырмалар: f-жолдар және format()

## Базалық деңгей

### 1-тапсырма. f-жолға аудар
Мына бағдарламаларды f-жолдарды қолданып қайта жазыңыз (нәтиже бірдей болуы керек):

```python
name = "Әсел"
grade = 7
print("Менің атым " + name + ", мен " + str(grade) + "-сыныпта оқимын.")
print("Келесі жылы", grade + 1, "-сыныпта боламын.")
```

Күтілетін нәтиже:
```text
Менің атым Әсел, мен 7-сыныпта оқимын.
Келесі жылы 8-сыныпта боламын.
```

### 2-тапсырма. Дөңгелектеу
Шеңбердің радиусын (`float`) енгізіп, ұзындығын (L = 2πr) және ауданын (S = πr²) үтірден кейін 2 таңбамен шығарыңыз. π = 3.14159.

Мысал:
```text
Радиус: 5
Шеңбер ұзындығы: 31.42
Шеңбер ауданы: 78.54
```

### 3-тапсырма. Электронды сағат
Сағат, минут, секундты (бүтін сандар) бөлек енгізіп, оларды `ЧЧ:ММ:СС` пішімінде шығарыңыз.

Мысал:
```text
Сағат: 8
Минут: 5
Секунд: 9
08:05:09
```

### 4-тапсырма. Тест нәтижесі
Тест сұрақтарының жалпы санын және дұрыс жауаптар санын енгізіп, нәтижені пайызбен (бүтін пайыз) шығарыңыз.

Мысал:
```text
Барлық сұрақ: 25
Дұрыс жауап: 19
Нәтиже: 19/25 (76%)
```

### 5-тапсырма. format() әдісі
`format()` әдісін қолданып (f-жолсыз!), мына шығысты алыңыз. Қала мен температура айнымалыларда сақталсын.

```text
Ауа райы: Алматы +18°C, Астана -3°C
```
*Кеңес:* `{:+d}` пішімі санның алдына әрқашан таңбасын (`+` немесе `-`) қояды.

## Кеңейтілген деңгей

### 6-тапсырма. Сабақ кестесі
f-жолдармен тураланған кесте шығарыңыз (бағандардың ені: 4, 15, 8):

```text
№   Пән              Уақыты
---------------------------
1   Математика        08:30
2   Қазақ тілі        09:25
3   Python            10:20
```

### 7-тапсырма. Мыңдықтар
Қазақстан халқының санын (мысалы, 20 300 000) және Алматы халқын (2 300 000) айнымалыларда сақтаңыз. Мыңдықтар бөлінген түрде шығарыңыз және Алматы халқының үлесін пайызбен (1 таңба) есептеңіз.

Мысал:
```text
Қазақстан: 20,300,000 адам
Алматы: 2,300,000 адам
Алматы үлесі: 11.3%
```

### 8-тапсырма. Мәзір
Үш тағамның атауы мен бағасы айнымалыларда. Нүктелермен толтырылған мәзір шығарыңыз (жалпы ені 30):

```text
*********** МӘЗІР ************
Палау.....................1800
Манты.....................1500
Шай........................300
==============================
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Көбейту кестесінің жолы
Пайдаланушы бір сан (n) енгізеді. f-жолдармен n-ге көбейту кестесінің 1-ден 5-ке дейінгі жолдарын әдемі туралап шығарыңыз (сандар оңға тураланған, ені 3). Цикл әлі өтілмеген — 5 жол жазуға болады, бірақ бір `print()` және `\n` арқылы жасап көріңіз.

Мысал (n = 7):
```text
  7 x   1 =  7
  7 x   2 = 14
  7 x   3 = 21
  7 x   4 = 28
  7 x   5 = 35
```

### 10-тапсырма. Прогресс-жолақ
Пайдаланушы жүктелу пайызын енгізеді (0–100). Ені 20 таңбалы прогресс-жолақ шығарыңыз.

Мысал:
```text
Пайыз: 35
[#######-------------] 35%
```
*Кеңес:* `#` саны = `пайыз * 20 // 100`.
