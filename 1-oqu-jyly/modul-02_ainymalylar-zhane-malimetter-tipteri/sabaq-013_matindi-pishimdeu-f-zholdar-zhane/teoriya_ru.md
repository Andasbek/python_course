## 1. Зачем нужно форматирование?

Простой вывод через `print()` с запятыми:
```text
Хлеб 2 180 360
Молоко 3 520.5 1561.5
Итого 1921.5
```

Чек из магазина:
```text
Хлеб             2 x   180.00 =    360.00
Молоко           3 x   520.50 =   1561.50
-----------------------------------------
ИТОГО:                           1921.50
```

Второй читать гораздо легче: столбцы выровнены, у чисел одинаковое количество знаков после запятой. Такой вывод получают с помощью **форматирования строк**.

## 2. Уже известные нам способы вывода

```python
name = "Дана"
age = 12

print("Имя:", name, "возраст:", age)             # через запятую
print("Имя: " + name + " возраст: " + str(age))  # через + и str()
```

Результат:
```text
Имя: Дана возраст: 12
Имя: Дана возраст: 12
```

Недостатки: через запятую — трудно управлять пробелами; через `+` — неудобно писать `str()`, следить за кавычками и пробелами.

## 3. f-строки (f-strings)

**f-строка** (форматированная строка, formatted string literal) — строка, перед которой написана буква `f`. Внутри неё вместо переменных и выражений, заключённых в **фигурные скобки** `{ }`, подставляются их значения. Есть начиная с Python 3.6 — самый удобный и самый распространённый способ на сегодня.

```python
name = "Дана"
age = 12
print(f"Имя: {name}, возраст: {age}")
```

Результат:
```text
Имя: Дана, возраст: 12
```

`str()` не нужен, пробелы — ровно такие, как мы написали.

### 3.1. Внутри фигурных скобок — любое выражение
```python
a = 7
b = 3
print(f"{a} + {b} = {a + b}")
print(f"{a} / {b} = {a / b}")
print(f"В следующем году мне будет {age + 1} лет")
print(f"В моём имени {len(name)} буквы")
```

Результат:
```text
7 + 3 = 10
7 / 3 = 2.3333333333333335
В следующем году мне будет 13 лет
В моём имени 4 буквы
```

### 3.2. Самодокументирующее выражение `=` (Python 3.8+)
Очень удобно для проверки (отладки):

```python
x = 15
y = 4
print(f"{x=}, {y=}, {x // y=}")
```

Результат:
```text
x=15, y=4, x // y=3
```

## 4. Форматирование чисел

Формат пишется после **двоеточия**: `{значение:формат}`.

### 4.1. Количество знаков после запятой — `.nf`
```python
pi = 3.14159265
price = 1500
print(f"{pi:.2f}")
print(f"{pi:.4f}")
print(f"{price:.2f}")
print(f"{7 / 3:.1f}")
```

Результат:
```text
3.14
3.1416
1500.00
2.3
```

`f` — fixed (фиксированная точка). Отличие от `round()`: `.2f` всегда показывает ровно 2 знака (`1500.00`), а `round(1500, 2)` → `1500`.

### 4.2. Разделение тысяч — `,` или `_`
```python
salary = 350000
population = 20_000_000
print(f"{salary:,}")
print(f"{population:_}")
print(f"{1234567.891:,.2f}")
```

Результат:
```text
350,000
20_000_000
1,234,567.89
```

### 4.3. Проценты — `%`
Число умножается на 100, и добавляется знак `%`:
```python
correct = 17
total = 20
ratio = correct / total
print(f"Правильные ответы: {ratio:.0%}")
print(f"Правильные ответы: {ratio:.1%}")
```

Результат:
```text
Правильные ответы: 85%
Правильные ответы: 85.0%
```

### 4.4. Ведущие нули — `0nd`
Для часов, дней, месяцев, номеров:
```python
h = 9
m = 5
s = 3
print(f"{h:02d}:{m:02d}:{s:02d}")
print(f"Билет №{42:05d}")
```

Результат:
```text
09:05:03
Билет №00042
```

`d` — decimal (целое число). `02d` — «не менее 2 символов, если не хватает — поставить впереди 0».

## 5. Ширина и выравнивание

`{значение:ширина}` — под значение отводится не менее **ширина** символов.

| Знак | Выравнивание | Пример | Результат (ширина 10, `|` — граница) |
|---|---|---|---|
| `<` | Влево | `f"|{'Яблоко':<10}|"` | `|Яблоко    |` |
| `>` | Вправо | `f"|{'Яблоко':>10}|"` | `|    Яблоко|` |
| `^` | По центру | `f"|{'Яблоко':^10}|"` | `|  Яблоко  |` |

По умолчанию строки выравниваются влево, числа — вправо.

```python
print(f"|{'Название':<10}|{'Цена':>8}|")
print(f"|{'Хлеб':<10}|{180:>8}|")
print(f"|{'Молоко':<10}|{520.5:>8.2f}|")
```

Результат:
```text
|Название  |    Цена|
|Хлеб      |     180|
|Молоко    |  520.50|
```

### 5.1. Символ-заполнитель
Перед знаком выравнивания можно написать любой символ:
```python
print(f"{'МЕНЮ':*^30}")
print(f"{'Плов':.<20}{1800:.>10}")
print(f"{'Манты':.<20}{1500:.>10}")
print(f"{'':=^30}")
```

Результат:
```text
*************МЕНЮ*************
Плов......................1800
Манты.....................1500
==============================
```

### 5.2. Шпаргалка по форматам

| Формат | Значение | Пример | Результат |
|---|---|---|---|
| `{x}` | Значение | `f"{5}"` | `5` |
| `{x:.2f}` | 2 знака после запятой | `f"{3.14159:.2f}"` | `3.14` |
| `{x:,}` | Тысячи | `f"{1000000:,}"` | `1,000,000` |
| `{x:.0%}` | Проценты | `f"{0.256:.0%}"` | `26%` |
| `{x:02d}` | Ведущие нули | `f"{7:02d}"` | `07` |
| `{x:<10}` | Влево, ширина 10 | `f"{'ab':<5}|"` | `ab   |` |
| `{x:>10}` | Вправо, ширина 10 | `f"{'ab':>5}"` | `   ab` |
| `{x:^10}` | По центру | `f"{'ab':^6}"` | `  ab  ` |
| `{x:*^10}` | По центру, заполнитель `*` | `f"{'ab':*^6}"` | `**ab**` |
| `{x:>10.2f}` | Вправо, ширина 10, 2 знака | `f"{3.5:>8.2f}"` | `    3.50` |

## 6. Метод format()

До появления f-строк (Python 3.6) основным способом был **метод строки `format()`**. Он до сих пор широко используется, особенно когда шаблон нужно подготовить заранее, а заполнить позже.

### 6.1. Позиционные аргументы
```python
print("Имя: {}, возраст: {}".format("Дана", 12))
print("{0} + {1} = {2}".format(2, 3, 2 + 3))
print("{1} {0}".format("мир", "Привет"))
```

Результат:
```text
Имя: Дана, возраст: 12
2 + 3 = 5
Привет мир
```

`{}` — заполняются по порядку; `{0}`, `{1}` — номер аргумента (счёт начинается **с 0**).

### 6.2. Именованные аргументы
```python
text = "В городе {city} сегодня {temp}°C".format(city="Астана", temp=-12)
print(text)
```

Результат:
```text
В городе Астана сегодня -12°C
```

### 6.3. Знаки формата — как в f-строке
```python
print("Цена: {:.2f} тенге".format(1234.5))
print("{:>10}|{:^10}|{:<10}".format("право", "центр", "лево"))
```

Результат:
```text
Цена: 1234.50 тенге
     право|  центр   |лево      
```

### 6.4. Повторное использование шаблона
```python
template = "{} — {} тенге"
print(template.format("Хлеб", 180))
print(template.format("Молоко", 520))
```

Результат:
```text
Хлеб — 180 тенге
Молоко — 520 тенге
```

### 6.5. Функция format()
Для форматирования одного значения есть и встроенная функция `format()`:
```python
print(format(3.14159, ".3f"))
print(format(5000000, ","))
```

Результат:
```text
3.142
5,000,000
```

## 7. Сравнение способов

| Способ | Пример | Преимущество | Недостаток |
|---|---|---|---|
| Запятая | `print("Имя:", name)` | Самый простой | Нет возможностей форматирования |
| Объединение `+` | `"Имя: " + name` | Понятно | Нужен `str()`, неудобно |
| `format()` | `"Имя: {}".format(name)` | Повторное использование шаблона | Длиннее |
| **f-строка** | `f"Имя: {name}"` | Коротко, читаемо, быстро | Требует Python 3.6+ |

**Рекомендация:** в повседневной работе используйте **f-строки**.

## 8. Полный пример: квитанция

```python
name = input("Товар: ")
price = float(input("Цена (тенге): "))
qty = int(input("Количество: "))
discount = 0.05                       # скидка 5%

subtotal = price * qty
saving = subtotal * discount
total = subtotal - saving

print()
print(f"{' КВИТАНЦИЯ ':=^36}")
print(f"{name:<14}{qty:>4} x {price:>10.2f}")
print(f"{'Сумма:':<20}{subtotal:>16,.2f}")
print(f"{'Скидка ' + format(discount, '.0%') + ':':<20}{-saving:>16,.2f}")
print("-" * 36)
print(f"{'К ОПЛАТЕ:':<20}{total:>16,.2f}")
print("=" * 36)
```

Результат:
```text
Товар: Книга
Цена (тенге): 3450
Количество: 3

============ КВИТАНЦИЯ =============
Книга            3 x    3450.00
Сумма:                     10,350.00
Скидка 5%:                   -517.50
------------------------------------
К ОПЛАТЕ:                   9,832.50
====================================
```

## Частые ошибки
**1. Забыли букву `f`.**
```python
name = "Дана"
print("Привет, {name}!")    # Привет, {name}! — значение не подставлено
print(f"Привет, {name}!")   # Привет, Дана!
```

**2. Числовой формат применён к строке.**
```python
price = input("Цена: ")           # str!
# print(f"{price:.2f}")           # ValueError: Unknown format code 'f' for object of type 'str'
price = float(price)
print(f"{price:.2f}")
```

**3. Такие же кавычки внутри f-строки.**
```text
print(f"{"Яблоко":<10}|")    # до Python 3.12: SyntaxError
```
Правильно — сменить вид внутренних кавычек:
```python
print(f"{'Яблоко':<10}|")
```

**4. Путаница `.2f` и `round()`.** `round(5.0, 2)` → `5.0`, а `f"{5.0:.2f}"` → `5.00`. Для денежных сумм — `.2f`.

**5. Вывод самих фигурных скобок в тексте.** Пишем их дважды:
```python
x = 5
print(f"{{x}} = {x}")
```
Результат:
```text
{x} = 5
```

**6. Не хватает аргументов в `format()`.**
```python
# print("{} и {}".format("Яблоко"))   # IndexError: Replacement index 1 out of range
print("{} и {}".format("Яблоко", "Груша"))
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Форматирование (пішімдеу) | Вставка значений в текст в определённом виде (ширина, точность, выравнивание) |
| f-строка | `f"...{выражение}..."` — строка, в которую подставляется значение выражения |
| Спецификатор формата | Правило форматирования после двоеточия внутри `{x:...}` |
| `.nf` | n знаков после запятой (вещественное число) |
| `,` | Разделение тысяч |
| `%` (в формате) | Отображение числа в процентах |
| Ширина, выравнивание | `<` влево, `>` вправо, `^` по центру |
| Заполнитель | Символ, заполняющий пустое место (`*^20`) |
| Метод `format()` | `"...{}...".format(значения)` — заполнение шаблона |

## Примечание

- Начиная с Python 3.12 (PEP 701) внутри f-строки можно использовать те же кавычки, что и снаружи, переносить выражения на несколько строк и писать в них `#`-комментарии; в более старых версиях это `SyntaxError`.
- Флаги преобразования: `{x!r}` выводит `repr(x)` (строки — в кавычках), `{x!s}` — `str(x)`. Это удобно при отладке: `f"{name!r}"` → `'Дана'`.
- Спецификаторы можно задавать переменными: `f"{value:{width}.{digits}f}"`.
- Существует ещё старый способ форматирования через `%`: `"%s — %d тенге" % ("Хлеб", 180)`; его можно встретить в старом коде и в модуле `logging`.
- Форматирование `.2f` использует то же «банковское» округление половин, что и `round()`, а сами `float` хранятся приближённо: `f"{2.675:.2f}"` даёт `2.67`.
- Полный синтаксис спецификаторов (Format Specification Mini-Language): https://docs.python.org/3/library/string.html#formatspec
