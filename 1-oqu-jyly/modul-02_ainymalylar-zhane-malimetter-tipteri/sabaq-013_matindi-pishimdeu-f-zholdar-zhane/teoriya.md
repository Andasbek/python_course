## 1. Пішімдеу не үшін керек?

`print()` арқылы үтірмен қарапайым шығару:
```text
Нан 2 180 360
Сүт 3 520.5 1561.5
Барлығы 1921.5
```

Дүкен чегі:
```text
Нан              2 x   180.00 =    360.00
Сүт              3 x   520.50 =   1561.50
-----------------------------------------
БАРЛЫҒЫ:                         1921.50
```

Екіншісі оқуға әлдеқайда жеңіл: бағандар тураланған, сандардың үтірден кейінгі таңба саны бірдей. Мұндай шығару **жолдарды пішімдеу** арқылы алынады.

## 2. Шығарудың бізге белгілі тәсілдері

```python
name = "Дана"
age = 12

print("Аты:", name, "жасы:", age)             # үтір арқылы
print("Аты: " + name + " жасы: " + str(age))  # + және str() арқылы
```

Нәтижесі:
```text
Аты: Дана жасы: 12
Аты: Дана жасы: 12
```

Кемшіліктері: үтір арқылы — бос орындарды басқару қиын; `+` арқылы — `str()` жазу, тырнақша мен бос орындарды қадағалау ыңғайсыз.

## 3. f-жолдар (f-strings)

**f-жол** (форматированная строка, formatted string literal) — алдына `f` әрпі жазылған жол. Оның ішінде **фигуралық жақшаға** `{ }` алынған айнымалылар мен өрнектердің орнына олардың мәні қойылады. Python 3.6-дан бастап бар — қазіргі ең ыңғайлы әрі ең көп қолданылатын тәсіл.

```python
name = "Дана"
age = 12
print(f"Аты: {name}, жасы: {age}")
```

Нәтижесі:
```text
Аты: Дана, жасы: 12
```

`str()` қажет емес, бос орындар — дәл біз жазғандай.

### 3.1. Фигуралық жақшаның ішінде — кез келген өрнек
```python
a = 7
b = 3
print(f"{a} + {b} = {a + b}")
print(f"{a} / {b} = {a / b}")
print(f"Келесі жылы маған {age + 1} жас болады")
print(f"Атымда {len(name)} әріп бар")
```

Нәтижесі:
```text
7 + 3 = 10
7 / 3 = 2.3333333333333335
Келесі жылы маған 13 жас болады
Атымда 4 әріп бар
```

### 3.2. Өзін-өзі құжаттайтын өрнек `=` (Python 3.8+)
Тексеру (отладка) үшін өте ыңғайлы:

```python
x = 15
y = 4
print(f"{x=}, {y=}, {x // y=}")
```

Нәтижесі:
```text
x=15, y=4, x // y=3
```

## 4. Сандарды пішімдеу

Пішім **қос нүктеден** кейін жазылады: `{мән:пішім}`.

### 4.1. Үтірден кейінгі таңбалар саны — `.nf`
```python
pi = 3.14159265
price = 1500
print(f"{pi:.2f}")
print(f"{pi:.4f}")
print(f"{price:.2f}")
print(f"{7 / 3:.1f}")
```

Нәтижесі:
```text
3.14
3.1416
1500.00
2.3
```

`f` — fixed (бекітілген нүкте). `round()`-тан айырмашылығы: `.2f` әрқашан дәл 2 таңба көрсетеді (`1500.00`), ал `round(1500, 2)` → `1500`.

### 4.2. Мыңдықтарды бөлу — `,` немесе `_`
```python
salary = 350000
population = 20_000_000
print(f"{salary:,}")
print(f"{population:_}")
print(f"{1234567.891:,.2f}")
```

Нәтижесі:
```text
350,000
20_000_000
1,234,567.89
```

### 4.3. Пайыз — `%`
Сан 100-ге көбейтіліп, `%` белгісі қосылады:
```python
correct = 17
total = 20
ratio = correct / total
print(f"Дұрыс жауаптар: {ratio:.0%}")
print(f"Дұрыс жауаптар: {ratio:.1%}")
```

Нәтижесі:
```text
Дұрыс жауаптар: 85%
Дұрыс жауаптар: 85.0%
```

### 4.4. Алдыңғы нөлдер — `0nd`
Сағат, күн, ай, нөмірлер үшін:
```python
h = 9
m = 5
s = 3
print(f"{h:02d}:{m:02d}:{s:02d}")
print(f"Билет №{42:05d}")
```

Нәтижесі:
```text
09:05:03
Билет №00042
```

`d` — decimal (бүтін сан). `02d` — «кемінде 2 таңба, жетпесе алдына 0 қой».

## 5. Ені және туралау

`{мән:ен}` — мәнге кемінде **ен** таңба орын беріледі.

| Белгі | Туралау | Мысал | Нәтиже (ені 10, `|` — шекара) |
|---|---|---|---|
| `<` | Солға | `f"|{'Алма':<10}|"` | `|Алма      |` |
| `>` | Оңға | `f"|{'Алма':>10}|"` | `|      Алма|` |
| `^` | Ортаға | `f"|{'Алма':^10}|"` | `|   Алма   |` |

Әдепкіде: жолдар — солға, сандар — оңға тураланады.

```python
print(f"|{'Атауы':<10}|{'Бағасы':>8}|")
print(f"|{'Нан':<10}|{180:>8}|")
print(f"|{'Сүт':<10}|{520.5:>8.2f}|")
```

Нәтижесі:
```text
|Атауы     |  Бағасы|
|Нан       |     180|
|Сүт       |  520.50|
```

### 5.1. Толтырғыш таңба
Туралау белгісінің алдына кез келген таңба жазуға болады:
```python
print(f"{'МӘЗІР':*^30}")
print(f"{'Палау':.<20}{1800:.>10}")
print(f"{'Манты':.<20}{1500:.>10}")
print(f"{'':=^30}")
```

Нәтижесі:
```text
************МӘЗІР*************
Палау.....................1800
Манты.....................1500
==============================
```

### 5.2. Пішімдер шпаргалкасы

| Пішім | Мағынасы | Мысал | Нәтиже |
|---|---|---|---|
| `{x}` | Мәні | `f"{5}"` | `5` |
| `{x:.2f}` | 2 таңба үтірден кейін | `f"{3.14159:.2f}"` | `3.14` |
| `{x:,}` | Мыңдықтар | `f"{1000000:,}"` | `1,000,000` |
| `{x:.0%}` | Пайыз | `f"{0.256:.0%}"` | `26%` |
| `{x:02d}` | Алдыңғы нөлдер | `f"{7:02d}"` | `07` |
| `{x:<10}` | Солға, ені 10 | `f"{'ab':<5}|"` | `ab   |` |
| `{x:>10}` | Оңға, ені 10 | `f"{'ab':>5}"` | `   ab` |
| `{x:^10}` | Ортаға | `f"{'ab':^6}"` | `  ab  ` |
| `{x:*^10}` | Ортаға, `*` толтырғыш | `f"{'ab':*^6}"` | `**ab**` |
| `{x:>10.2f}` | Оңға, ені 10, 2 таңба | `f"{3.5:>8.2f}"` | `    3.50` |

## 6. format() әдісі

f-жолдар пайда болғанға дейін (Python 3.6) негізгі тәсіл — жолдың **`format()` әдісі** болды. Ол әлі де кең қолданылады, әсіресе үлгіні (шаблонды) алдын ала дайындап, кейін толтыру керек болғанда.

### 6.1. Позициялық аргументтер
```python
print("Аты: {}, жасы: {}".format("Дана", 12))
print("{0} + {1} = {2}".format(2, 3, 2 + 3))
print("{1} {0}".format("әлем", "Сәлем"))
```

Нәтижесі:
```text
Аты: Дана, жасы: 12
2 + 3 = 5
Сәлем әлем
```

`{}` — кезекпен толтырылады; `{0}`, `{1}` — аргументтің нөмірі (санау **0-ден** басталады).

### 6.2. Атаулы аргументтер
```python
text = "{city} қаласында бүгін {temp}°C".format(city="Астана", temp=-12)
print(text)
```

Нәтижесі:
```text
Астана қаласында бүгін -12°C
```

### 6.3. Пішім белгілері — f-жолдағыдай
```python
print("Бағасы: {:.2f} теңге".format(1234.5))
print("{:>10}|{:^10}|{:<10}".format("оң", "орта", "сол"))
```

Нәтижесі:
```text
Бағасы: 1234.50 теңге
        оң|   орта   |сол       
```

### 6.4. Үлгіні қайта қолдану
```python
template = "{} — {} теңге"
print(template.format("Нан", 180))
print(template.format("Сүт", 520))
```

Нәтижесі:
```text
Нан — 180 теңге
Сүт — 520 теңге
```

### 6.5. format() функциясы
Бір мәнді пішімдеу үшін кіріктірілген `format()` функциясы да бар:
```python
print(format(3.14159, ".3f"))
print(format(5000000, ","))
```

Нәтижесі:
```text
3.142
5,000,000
```

## 7. Тәсілдерді салыстыру

| Тәсіл | Мысал | Артықшылығы | Кемшілігі |
|---|---|---|---|
| Үтір | `print("Аты:", name)` | Ең қарапайым | Пішімдеу мүмкіндігі жоқ |
| `+` біріктіру | `"Аты: " + name` | Түсінікті | `str()` керек, ыңғайсыз |
| `format()` | `"Аты: {}".format(name)` | Үлгіні қайта қолдану | Ұзынырақ |
| **f-жол** | `f"Аты: {name}"` | Қысқа, оқылымды, жылдам | Python 3.6+ қажет |

**Ұсыныс:** күнделікті жұмыста **f-жолдарды** қолданыңыз.

## 8. Толық мысал: түбіртек (квитанция)

```python
name = input("Тауар: ")
price = float(input("Бағасы (теңге): "))
qty = int(input("Саны: "))
discount = 0.05                       # 5% жеңілдік

subtotal = price * qty
saving = subtotal * discount
total = subtotal - saving

print()
print(f"{' ТҮБІРТЕК ':=^36}")
print(f"{name:<14}{qty:>4} x {price:>10.2f}")
print(f"{'Сомасы:':<20}{subtotal:>16,.2f}")
print(f"{'Жеңілдік ' + format(discount, '.0%') + ':':<20}{-saving:>16,.2f}")
print("-" * 36)
print(f"{'ТӨЛЕУГЕ:':<20}{total:>16,.2f}")
print("=" * 36)
```

Нәтижесі:
```text
Тауар: Кітап
Бағасы (теңге): 3450
Саны: 3

============= ТҮБІРТЕК =============
Кітап            3 x    3450.00
Сомасы:                    10,350.00
Жеңілдік 5%:                 -517.50
------------------------------------
ТӨЛЕУГЕ:                    9,832.50
====================================
```

## Жиі кездесетін қателер

**1. `f` әрпін ұмыту.**
```python
name = "Дана"
print("Сәлем, {name}!")    # Сәлем, {name}! — мән қойылмады
print(f"Сәлем, {name}!")   # Сәлем, Дана!
```

**2. Сандық пішімді жолға қолдану.**
```python
price = input("Баға: ")           # str!
# print(f"{price:.2f}")           # ValueError: Unknown format code 'f' for object of type 'str'
price = float(price)
print(f"{price:.2f}")
```

**3. f-жол ішінде дәл сондай тырнақшаны қолдану.**
```text
print(f"{"Алма":<10}|")    # Python 3.12-ден бұрын: SyntaxError
```
Дұрысы — ішкі тырнақшаның түрін өзгерту:
```python
print(f"{'Алма':<10}|")
```

**4. `.2f` пен `round()` шатастыру.** `round(5.0, 2)` → `5.0`, ал `f"{5.0:.2f}"` → `5.00`. Ақшаны көрсеткенде — `.2f`.

**5. Мәтінде фигуралық жақшаның өзін шығару.** Екі рет жазамыз:
```python
x = 5
print(f"{{x}} = {x}")
```
Нәтижесі:
```text
{x} = 5
```

**6. `format()`-та аргумент жетіспеуі.**
```python
# print("{} және {}".format("Алма"))   # IndexError: Replacement index 1 out of range
print("{} және {}".format("Алма", "Алмұрт"))
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Пішімдеу (форматирование) | Мәндерді мәтінге белгілі бір түрде (ені, дәлдігі, туралауы) қою |
| f-жол | `f"...{өрнек}..."` — өрнектің мәні жолға қойылатын жол |
| Пішім спецификаторы | `{x:...}` ішіндегі қос нүктеден кейінгі пішімдеу ережесі |
| `.nf` | Үтірден кейін n таңба (нақты сан) |
| `,` | Мыңдықтарды бөлу |
| `%` (пішімде) | Санды пайызбен көрсету |
| Ені, туралау | `<` солға, `>` оңға, `^` ортаға |
| Толтырғыш | Бос орынды толтыратын таңба (`*^20`) |
| `format()` әдісі | `"...{}...".format(мәндер)` — үлгіні толтыру |

## Ескерту

- Python 3.12-ден бастап (PEP 701) f-жолдың ішінде сыртындағыдай тырнақшаларды қолдануға, өрнектерді бірнеше жолға тасымалдауға және оларға `#`-түсініктемелер жазуға болады; ескі нұсқаларда бұл — `SyntaxError`.
- Түрлендіру жалаушалары: `{x!r}` `repr(x)` шығарады (жолдар — тырнақшамен), `{x!s}` — `str(x)`. Бұл жөндеу кезінде ыңғайлы: `f"{name!r}"` → `'Дана'`.
- Спецификаторларды айнымалылармен беруге болады: `f"{value:{width}.{digits}f}"`.
- `%` арқылы пішімдеудің ескі тәсілі де бар: `"%s — %d теңге" % ("Нан", 180)`; оны ескі кодта және `logging` модулінде кездестіруге болады.
- `.2f` пішімдеуі `round()` сияқты жартыларды «банктік» дөңгелектеуді қолданады, ал `float` сандары жуықтап сақталады: `f"{2.675:.2f}"` нәтижесі `2.67`.
- Спецификаторлардың толық синтаксисі (Format Specification Mini-Language): https://docs.python.org/3/library/string.html#formatspec
