## 1. Зачем нужен ввод данных

Если данные «зашиты» в код (`length = 6`), то для других данных приходится менять сам код. А настоящие программы (калькулятор, игра, приложение Kaspi) запрашивают данные **у пользователя**.

В блок-схеме это блок **ввода** (параллелограмм). В Python — функция `input()`.

## 2. Функция input()

`input()` — функция, считывающая текст, введённый с клавиатуры. Она работает так:
1. Программа **останавливается** и ждёт ввода пользователя (мигает курсор).
2. Пользователь набирает текст и нажимает **Enter**.
3. `input()` **возвращает** набранный текст — сохраняем его в переменную.

```python
name = input()
print("Привет,", name)
```

Выполнение (пользователь ввёл `Арман`):
```text
Арман
Привет, Арман
```

### 2.1. Текст-вопрос (prompt)
Чтобы пользователь знал, что нужно ввести, пишем в скобках **вопрос**:

```python
name = input("Как тебя зовут? ")
print("Привет,", name + "!")
```

Результат:
```text
Как тебя зовут? Арман
Привет, Арман!
```

**Совет:** в конце prompt ставьте пробел или `: ` — иначе ответ пользователя прилипнет к вопросу: `Как тебя зовут?Арман`.

### 2.2. Несколько вводов
```python
name = input("Имя: ")
city = input("Из какого ты города? ")
hobby = input("Твоё хобби: ")

print()
print("Рад знакомству,", name + "!")
print(city, "— замечательный город!")
print("Я тоже люблю", hobby + ".")
```

Результат:
```text
Имя: Дана
Из какого ты города? Шымкент
Твоё хобби: шахматы

Рад знакомству, Дана!
Шымкент — замечательный город!
Я тоже люблю шахматы.
```

## 3. Ввод → обработка → вывод

Классическая структура любой программы (IPO — Input, Process, Output):

```text
      ( Начало )
          |
   /  Ввод данных   /        <- input()
          |
   [ Обработка, вычисление ] <- переменные, операции
          |
   / Вывод результата /      <- print()
          |
      ( Конец  )
```

Пример — работа со строками:

```python
word = input("Введите любое слово: ")
length = len(word)
print("В вашем слове", length, "символов.")
print("Если повторить его три раза:", word * 3)
```

Результат:
```text
Введите любое слово: Python
В вашем слове 6 символов.
Если повторить его три раза: PythonPythonPython
```

## 4. Важная особенность: input() всегда возвращает str

Даже если пользователь вводит число, `input()` возвращает его как **текст**.

```python
age = input("Ваш возраст: ")
print(type(age))
```

Результат:
```text
Ваш возраст: 12
<class 'str'>
```

Поэтому при вычислениях получается неожиданный результат:

```python
a = input("Первое число: ")
b = input("Второе число: ")
print("Сумма:", a + b)
```

Результат:
```text
Первое число: 5
Второе число: 7
Сумма: 57
```

`"5" + "7"` = `"57"` — строки объединились! А если попытаться вычесть — ошибка:

```text
print(a - b)
TypeError: unsupported operand type(s) for -: 'str' and 'str'
```

### 4.1. Решение — int() и float()
Чтобы превратить введённый текст в число, «оборачиваем» его в функцию `int()` (целое число) или `float()` (дробное число):

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
print("Сумма:", a + b)
print("Разность:", a - b)
```

Результат:
```text
Первое число: 5
Второе число: 7
Сумма: 12
Разность: -2
```

Как выполняется эта строка: сначала выполняется внутренний `input()` (пользователь вводит `"5"`), затем `int("5")` превращает его в число `5`, после чего оно записывается в `a`.

```text
int(input("..."))
      └── "5" ──> int("5") ──> 5 ──> a
```

Шаблоны ввода:
- если нужно целое число: `x = int(input("..."))`
- если нужно дробное число: `x = float(input("..."))`
- если нужен текст: `x = input("...")`

## 5. Пример диалоговой программы: «Чат-бот»

```python
"""
Программа: Простой чат-бот «Бота»
Описание: знакомится с пользователем и выполняет небольшие вычисления с его данными.
"""

print("Привет! Я — чат-бот Бота.")
name = input("Как тебя зовут? ")
print("Рада знакомству,", name + "!")

age = int(input("Сколько тебе лет? "))
print("Получается, ты прожил(а) примерно", age * 365, "дней!")
print("Через 5 лет тебе будет", age + 5, "лет.")

food = input("Какое у тебя любимое блюдо? ")
print("Ммм,", food, "— и моё любимое блюдо! (Только я не ем...)")

print("Пока,", name + "! Приходи ещё поболтать.")
```

Результат:
```text
Привет! Я — чат-бот Бота.
Как тебя зовут? Алихан
Рада знакомству, Алихан!
Сколько тебе лет? 11
Получается, ты прожил(а) примерно 4015 дней!
Через 5 лет тебе будет 16 лет.
Какое у тебя любимое блюдо? бешбармак
Ммм, бешбармак — и моё любимое блюдо! (Только я не ем...)
Пока, Алихан! Приходи ещё поболтать.
```

## 6. Тестирование программы

Программу с вводом нужно проверять не один раз, а **с разными данными**. Заполнение таблицы тестирования — профессиональная привычка:

| № | Ввод | Ожидаемый вывод | Фактический вывод | Верно? |
|---|---|---|---|---|
| 1 | `5`, `7` | `12` | `12` | ✓ |
| 2 | `-3`, `3` | `0` | `0` | ✓ |
| 3 | `0`, `0` | `0` | `0` | ✓ |
| 4 | `5.5`, `1` | ? | `ValueError` | ✗ — для дробного числа нужен `float()` |
| 5 | `пять`, `7` | ? | `ValueError` | ✗ — текст не является числом |

Случаи 4–5 обрабатываются проверкой введённой строки (например, `s.isdigit()`) или перехватом исключения с помощью `try...except ValueError`.

## 7. Культура ввода (чтобы пользователю было удобно)

1. Пишите вопрос точно: `"Ваш вес (кг): "` — указывайте единицу измерения.
2. Приводите пример: `"Дата рождения (например, 14.03.2013): "`.
3. Сообщайте пользователю, что происходит: в начале программы — приветствие, в конце — итог.
4. После ввода чётко выводите результат — пишите, что было вычислено.

## Частые ошибки
**1. Введённое значение не сохранено в переменную.**
```python
input("Имя: ")
# print("Привет,", name)   # NameError: name 'name' is not defined
```
Правильно:
```python
name = input("Имя: ")
print("Привет,", name)
```

**2. Сложение чисел без `int()`.**
```python
a = input("a = ")
b = input("b = ")
print(a + b)            # если ввести 3 и 4 -> 34
```
Правильно:
```python
a = int(input("a = "))
b = int(input("b = "))
print(a + b)            # 7
```

**3. Неправильно закрытые скобки.**
```text
age = int(input("Ваш возраст: ")
SyntaxError: '(' was never closed
```
Количество открытых скобок должно равняться количеству закрытых: `int(input("..."))` — две `(`, две `)`.

**4. Нет пробела в prompt.**
```python
name = input("Имя:")     # Имя:Арман — прилипает
name = input("Имя: ")    # Имя: Арман — правильно
```

**5. Думать, что программа «зависла».** `input()` ждёт пользователя — щёлкните в окне Shell, наберите значение и нажмите Enter.

**6. Использование `input` в качестве имени переменной.**
```python
input = "текст"
# name = input("Имя: ")  # TypeError: 'str' object is not callable
```

## Основные понятия

| Понятие | Определение |
|---|---|
| `input()` | Функция, считывающая текст, введённый с клавиатуры |
| Prompt (текст-вопрос) | Пояснение, которое `input()` выводит на экран перед вводом |
| Ввод–обработка–вывод (IPO) | Классическая структура программы |
| Диалоговая программа | Программа, взаимодействующая с пользователем в форме вопрос-ответ |
| Возвращаемое значение | Результат работы функции (для input() — str) |
| Тестирование | Проверка программы на разных данных |

## Примечание

- `input()` возвращает строку **без** символа перевода строки `\n` в конце, но с пробелами, если пользователь их ввёл. Лишние пробелы по краям убирает `input().strip()`.
- Несколько значений в одной строке читают так: `a, b = input().split()` — строка делится по пробелам; для чисел: `a, b = map(int, input().split())`.
- Если ввод закончился (например, нажато Ctrl+D в Linux/macOS или Ctrl+Z, Enter в Windows), `input()` вызывает `EOFError`.
- Не используйте `eval(input())` для «удобного» ввода чисел: так пользователь может выполнить произвольный код. Безопасно — `int()`/`float()`.
- В Python 2 функция `input()` вычисляла введённое выражение, а текст читала `raw_input()`; в Python 3 осталась только `input()`, всегда возвращающая `str`.
- Документация: https://docs.python.org/3/library/functions.html#input
