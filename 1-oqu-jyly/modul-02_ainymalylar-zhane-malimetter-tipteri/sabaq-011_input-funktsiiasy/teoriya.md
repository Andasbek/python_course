## 1. Деректерді енгізу не үшін керек

Егер деректер кодтың ішіне «қатырылып» жазылса (`length = 6`), басқа деректер үшін кодтың өзін өзгертуге тура келеді. Ал нағыз бағдарламалар (калькулятор, ойын, Kaspi қосымшасы) деректерді **пайдаланушыдан** сұрайды.

Блок-схемада бұл — **енгізу** блогы (параллелограмм). Python-да — `input()` функциясы.

## 2. input() функциясы

`input()` — пернетақтадан енгізілген мәтінді оқитын функция. Ол былай жұмыс істейді:
1. Бағдарлама **тоқтап**, пайдаланушының енгізуін күтеді (курсор жыпылықтайды).
2. Пайдаланушы мәтін теріп, **Enter** басады.
3. `input()` терілген мәтінді **қайтарады** — оны айнымалыға сақтаймыз.

```python
name = input()
print("Сәлем,", name)
```

Орындалуы (пайдаланушы `Арман` деп енгізді):
```text
Арман
Сәлем, Арман
```

### 2.1. Сұрақ-мәтін (prompt)
Пайдаланушы не енгізу керектігін білуі үшін жақша ішіне **сұрақ** жазамыз:

```python
name = input("Атыңыз кім? ")
print("Сәлем,", name + "!")
```

Нәтижесі:
```text
Атыңыз кім? Арман
Сәлем, Арман!
```

**Кеңес:** prompt соңына бос орын немесе `: ` қойыңыз — әйтпесе пайдаланушының жауабы сұраққа жабысып қалады: `Атыңыз кім?Арман`.

### 2.2. Бірнеше енгізу
```python
name = input("Атыңыз: ")
city = input("Қай қаладансыз? ")
hobby = input("Хоббиіңіз: ")

print()
print("Танысқаныма қуаныштымын,", name + "!")
print(city, "— керемет қала!")
print("Мен де", hobby, "ұнатамын.")
```

Нәтижесі:
```text
Атыңыз: Дана
Қай қаладансыз? Шымкент
Хоббиіңіз: шахмат

Танысқаныма қуаныштымын, Дана!
Шымкент — керемет қала!
Мен де шахмат ұнатамын.
```

## 3. Енгізу → өңдеу → шығару

Кез келген бағдарламаның классикалық құрылымы (IPO — Input, Process, Output):

```text
      ( Басы )
          |
   / Деректерді енгізу /     <- input()
          |
   [ Өңдеу, есептеу ]        <- айнымалылар, амалдар
          |
   / Нәтижені шығару /       <- print()
          |
      ( Соңы )
```

Мысал — жолдармен жұмыс:

```python
word = input("Кез келген сөз енгізіңіз: ")
length = len(word)
print("Сіздің сөзіңізде", length, "таңба бар.")
print("Оны үш рет қайталасақ:", word * 3)
```

Нәтижесі:
```text
Кез келген сөз енгізіңіз: Python
Сіздің сөзіңізде 6 таңба бар.
Оны үш рет қайталасақ: PythonPythonPython
```

## 4. Маңызды ерекшелік: input() әрқашан str қайтарады

Пайдаланушы сан енгізсе де, `input()` оны **мәтін** ретінде қайтарады.

```python
age = input("Жасыңыз: ")
print(type(age))
```

Нәтижесі:
```text
Жасыңыз: 12
<class 'str'>
```

Сондықтан есептеу кезінде күтпеген нәтиже шығады:

```python
a = input("Бірінші сан: ")
b = input("Екінші сан: ")
print("Қосындысы:", a + b)
```

Нәтижесі:
```text
Бірінші сан: 5
Екінші сан: 7
Қосындысы: 57
```

`"5" + "7"` = `"57"` — жолдар біріктірілді! Ал азайтуға тырыссақ — қате:

```text
print(a - b)
TypeError: unsupported operand type(s) for -: 'str' and 'str'
```

### 4.1. Шешімі — int() және float()
Енгізілген мәтінді санға айналдыру үшін оны `int()` (бүтін сан) немесе `float()` (бөлшек сан) функциясына «орап» аламыз:

```python
a = int(input("Бірінші сан: "))
b = int(input("Екінші сан: "))
print("Қосындысы:", a + b)
print("Айырмасы:", a - b)
```

Нәтижесі:
```text
Бірінші сан: 5
Екінші сан: 7
Қосындысы: 12
Айырмасы: -2
```

Бұл жол қалай орындалады: алдымен ішкі `input()` орындалады (пайдаланушы `"5"` енгізеді), содан кейін `int("5")` оны `5` санына айналдырады, сосын `a`-ға жазылады.

```text
int(input("..."))
      └── "5" ──> int("5") ──> 5 ──> a
```

Енгізу үлгілері:
- бүтін сан керек болса: `x = int(input("..."))`
- бөлшек сан керек болса: `x = float(input("..."))`
- мәтін керек болса: `x = input("...")`

## 5. Диалогтық бағдарлама мысалы: «Чат-бот»

```python
"""
Бағдарлама: Қарапайым чат-бот «Бота»
Сипаттамасы: пайдаланушымен танысып, оның деректерімен шағын есептеулер жасайды.
"""

print("Сәлем! Мен — чат-бот Бота.")
name = input("Сенің атың кім? ")
print("Танысқаныма қуаныштымын,", name + "!")

age = int(input("Жасың нешеде? "))
print("Сен шамамен", age * 365, "күн өмір сүрдің екен!")
print("5 жылдан кейін саған", age + 5, "жас болады.")

food = input("Сүйікті тағамың қандай? ")
print("Ммм,", food, "— менің де сүйікті тағамым! (Тек мен тамақ жемеймін...)")

print("Сау бол,", name + "! Тағы әңгімелесейік.")
```

Нәтижесі:
```text
Сәлем! Мен — чат-бот Бота.
Сенің атың кім? Әлихан
Танысқаныма қуаныштымын, Әлихан!
Жасың нешеде? 11
Сен шамамен 4015 күн өмір сүрдің екен!
5 жылдан кейін саған 16 жас болады.
Сүйікті тағамың қандай? бешбармақ
Ммм, бешбармақ — менің де сүйікті тағамым! (Тек мен тамақ жемеймін...)
Сау бол, Әлихан! Тағы әңгімелесейік.
```

## 6. Бағдарламаны тестілеу

Енгізуі бар бағдарламаны бір рет қана емес, **әртүрлі деректермен** тексеру керек. Тестілеу кестесін толтыру — кәсіби әдет:

| № | Енгізу | Күтілген нәтиже | Алынған нәтиже | Дұрыс па? |
|---|---|---|---|---|
| 1 | `5`, `7` | `12` | `12` | ✓ |
| 2 | `-3`, `3` | `0` | `0` | ✓ |
| 3 | `0`, `0` | `0` | `0` | ✓ |
| 4 | `5.5`, `1` | ? | `ValueError` | ✗ — бөлшек санға `float()` керек |
| 5 | `бес`, `7` | ? | `ValueError` | ✗ — мәтін сан емес |

4–5 жағдайлар енгізілген жолды тексеру (мысалы, `s.isdigit()`) немесе `try...except ValueError` арқылы ерекше жағдайды ұстау арқылы өңделеді.

## 7. Енгізу мәдениеті (пайдаланушыға ыңғайлы болу үшін)

1. Сұрақты нақты жазыңыз: `"Салмағыңыз (кг): "` — өлшем бірлігін көрсетіңіз.
2. Мысал беріңіз: `"Туған күніңіз (мысалы, 14.03.2013): "`.
3. Пайдаланушыға не болып жатқанын хабарлаңыз: бағдарлама басында сәлемдесу, соңында қорытынды.
4. Енгізуден кейін нәтижені анық шығарыңыз — не есептелгенін жазыңыз.

## Жиі кездесетін қателер

**1. Енгізілген мәнді айнымалыға сақтамау.**
```python
input("Атыңыз: ")
# print("Сәлем,", name)   # NameError: name 'name' is not defined
```
Дұрысы:
```python
name = input("Атыңыз: ")
print("Сәлем,", name)
```

**2. Сандарды `int()`-сіз қосу.**
```python
a = input("a = ")
b = input("b = ")
print(a + b)            # 3 және 4 енгізсе -> 34
```
Дұрысы:
```python
a = int(input("a = "))
b = int(input("b = "))
print(a + b)            # 7
```

**3. Жақшаларды дұрыс жаппау.**
```text
age = int(input("Жасыңыз: ")
SyntaxError: '(' was never closed
```
Ашылған жақша саны жабылғанына тең болуы керек: `int(input("..."))` — екі `(`, екі `)`.

**4. Prompt-та бос орын жоқ.**
```python
name = input("Атыңыз:")     # Атыңыз:Арман — жабысып қалады
name = input("Атыңыз: ")    # Атыңыз: Арман — дұрыс
```

**5. Бағдарлама «қатып қалды» деп ойлау.** `input()` пайдаланушыны күтіп тұр — Shell терезесіне басып, мәнді теріп, Enter басыңыз.

**6. `input`-ты айнымалы аты ретінде қолдану.**
```python
input = "мәтін"
# name = input("Атыңыз: ")  # TypeError: 'str' object is not callable
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| `input()` | Пернетақтадан енгізілген мәтінді оқитын функция |
| Prompt (сұрақ-мәтін) | `input()` енгізу алдында экранға шығаратын түсіндірме |
| Енгізу–өңдеу–шығару (IPO) | Бағдарламаның классикалық құрылымы |
| Диалогтық бағдарлама | Пайдаланушымен сұрақ-жауап арқылы әрекеттесетін бағдарлама |
| Қайтарылатын мән | Функция жұмысының нәтижесі (input() үшін — str) |
| Тестілеу | Бағдарламаны әртүрлі деректермен тексеру |

## Ескерту

- `input()` жолды соңындағы `\n` жол ауыстыру таңбасын **қоспай** қайтарады, бірақ пайдаланушы енгізген бос орындар сақталады. Шеттердегі артық бос орындарды `input().strip()` алып тастайды.
- Бір жолдағы бірнеше мәнді былай оқиды: `a, b = input().split()` — жол бос орындар бойынша бөлінеді; сандар үшін: `a, b = map(int, input().split())`.
- Енгізу аяқталса (мысалы, Linux/macOS-та Ctrl+D немесе Windows-та Ctrl+Z, Enter басылса), `input()` `EOFError` береді.
- Сандарды «ыңғайлы» енгізу үшін `eval(input())` қолданбаңыз: бұлай пайдаланушы кез келген кодты орындай алады. Қауіпсізі — `int()`/`float()`.
- Python 2-де `input()` функциясы енгізілген өрнекті есептейтін, ал мәтінді `raw_input()` оқитын; Python 3-те әрқашан `str` қайтаратын `input()` ғана қалды.
- Құжаттама: https://docs.python.org/3/library/functions.html#input
