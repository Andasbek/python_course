# Сабақ 11. Практикалық тапсырмалар: input() — пернетақтадан енгізу

Еске салу: мәтін үшін — `x = input("...")`, бүтін сан үшін — `x = int(input("..."))`, бөлшек сан үшін — `x = float(input("..."))`.

## Базалық деңгей

### 1-тапсырма. Сәлемдесу
Пайдаланушының атын және тегін сұрап, оған сәлем беретін бағдарлама жазыңыз.

Мысал:
```text
Атыңыз: Айгерім
Тегіңіз: Болатова
Сәлем, Айгерім Болатова! Python үйірмесіне қош келдіңіз!
```

### 2-тапсырма. Ертегі генераторы
Пайдаланушыдан 4 сөз сұраңыз: батырдың аты, жануар, қала, зат. Осы сөздерден 3–4 сөйлемдік шағын ертегі құрастырып шығарыңыз.

Мысал:
```text
Батырдың аты: Ер Төстік
Жануар: тұлпар
Қала: Түркістан
Зат: сиқырлы қамшы
---
Ертеде Ер Төстік деген батыр өмір сүріпті.
Оның тұлпар деген адал серігі болыпты.
Бір күні олар Түркістан қаласына сапар шегіп,
жолда сиқырлы қамшы тауып алыпты...
```

### 3-тапсырма. Сөз анализаторы
Пайдаланушыдан бір сөз сұраңыз. Сөздің ұзындығын және сөзді `-` таңбасынан жасалған, сөзбен бірдей ұзындықтағы сызықпен астын сызып шығарыңыз.

Мысал:
```text
Сөз енгізіңіз: Алматы
Алматы
------
Ұзындығы: 6
```

### 4-тапсырма. Екі санның қосындысы
Екі бүтін санды енгізіп, олардың қосындысын, айырмасын, көбейтіндісін шығарыңыз.

Мысал:
```text
Бірінші сан: 12
Екінші сан: 5
12 + 5 = 17
12 - 5 = 7
12 * 5 = 60
```

### 5-тапсырма. Тестілеу кестесі
4-тапсырмадағы бағдарламаны мына деректермен тестілеп, кестені толтырыңыз:

| № | Енгізу | Күтілген нәтиже | Алынған нәтиже | Дұрыс па? |
|---|---|---|---|---|
| 1 | 12, 5 | | | |
| 2 | -4, 4 | | | |
| 3 | 0, 100 | | | |
| 4 | 2.5, 1 | | | |
| 5 | он, 5 | | | |

## Кеңейтілген деңгей

### 6-тапсырма. Туған жыл
Пайдаланушының атын және туған жылын сұраңыз. Ағымдағы жылды айнымалыда сақтаңыз (`current_year = 2026`). Оның жасын және 18 жасқа (кәмелетке) толатын жылын есептеңіз.

Мысал:
```text
Атыңыз: Нұрлан
Туған жылыңыз: 2014
Нұрлан, сен биыл 12 жасқа толасың.
Сен 2032 жылы кәмелетке толасың.
```

### 7-тапсырма. Пицца
Пиццаның бағасын (теңге) және достар санын енгізіп, әр адамның қанша төлейтінін (бүтін теңге) және қанша теңге артық төленетінін есептеңіз (егер біреуі қалдықты төлесе).

Мысал:
```text
Пиццаның бағасы: 5900
Достар саны: 4
Әркім төлейді: 1475 теңге
Қалдық: 0 теңге
```
```text
Пиццаның бағасы: 6100
Достар саны: 4
Әркім төлейді: 1525 теңге
Қалдық: 0 теңге
```
```text
Пиццаның бағасы: 5000
Достар саны: 3
Әркім төлейді: 1666 теңге
Қалдық: 2 теңге
```

### 8-тапсырма. «Мен туралы 3.0»
«Мен туралы» бағдарламасын кез келген адам туралы «визитка» шығаратын бағдарламаға айналдырыңыз: аты, жасы, қаласы, хоббиі пайдаланушыдан сұралсын, нәтиже жақтаумен шығарылсын.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Үш таңбалы сан
Пайдаланушы үш таңбалы сан енгізеді. Бағдарлама оның цифрларын, цифрлар қосындысын, көбейтіндісін және кері санды шығарсын.

Мысал:
```text
Үш таңбалы сан: 538
Цифрлары: 5 3 8
Қосындысы: 16
Көбейтіндісі: 120
Кері сан: 835
```

### 10-тапсырма. Сағат
Тәулік басынан бері өткен секунд саны енгізіледі (0-ден 86399-ға дейін). Сағатты `сағ:мин:сек` түрінде шығарыңыз.

Мысал:
```text
Секунд: 45296
Уақыт: 12 : 34 : 56
```
(Минут пен секундтың алдына 0 қою — `12:04:05` — келесі сабақтардағы пішімдеу тақырыбы.)

## Үй тапсырмасы
1. «Сауалнама» бағдарламасы: пайдаланушыдан 5 сұрақ сұрап (аты, сыныбы, сүйікті пәні, сүйікті ойыны, болашақ мамандығы), жауаптарды әдемі «анкета» түрінде шығарыңыз.
2. «Жол ақысы» бағдарламасы: бір жол бағасын және айына жүру санын енгізіп, айлық және жылдық шығынды есептеңіз.
3. Ата-анаңызды немесе бауырыңызды «пайдаланушы» ретінде отырғызып, бағдарламаңызды сынатыңыз. Олар не айтты? Бағдарламаға қандай өзгеріс енгізер едіңіз?
