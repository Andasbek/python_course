## 1. Тип түрлендіру деген не?

**Тип түрлендіру** (приведение типов, type conversion / casting) — мәнді бір типтен екінші типке айналдыру.

Аналогия — валюта айырбастау: 100 доллар мен 50 000 теңге тікелей қосылмайды; алдымен бір валютаға айырбастау керек. Сол сияқты `"5"` (жол) мен `7` (сан) қосылмайды — алдымен бір типке келтіру керек.

| Функция | Не істейді | Мысал | Нәтиже |
|---|---|---|---|
| `int(x)` | Бүтін санға айналдырады | `int("42")` | `42` |
| `float(x)` | Нақты санға айналдырады | `float("3.5")` | `3.5` |
| `str(x)` | Жолға (мәтінге) айналдырады | `str(42)` | `"42"` |
| `bool(x)` | Логикалық мәнге айналдырады | `bool(0)` | `False` |

## 2. int() — бүтін санға түрлендіру

### 2.1. Жолдан бүтін санға
```python
text = "2026"
year = int(text)
print(year + 1)
print(type(year))
```

Нәтижесі:
```text
2027
<class 'int'>
```

Жолдың басы мен соңындағы бос орындарға рұқсат, ішінде — жоқ:

```python
print(int("  15  "))
print(int("-8"))
```

Нәтижесі:
```text
15
-8
```

### 2.2. Нақты саннан бүтін санға — бөлшек бөлігі **кесіліп тасталады**
```python
print(int(3.99))
print(int(7.1))
print(int(-2.8))
```

Нәтижесі:
```text
3
7
-2
```

`int()` **дөңгелектемейді**, тек бөлшек бөлігін алып тастайды (нөлге қарай). Дөңгелектеу үшін — `round()`:

| x | `int(x)` | `round(x)` |
|---|---|---|
| 3.2 | 3 | 3 |
| 3.9 | 3 | 4 |
| -2.8 | -2 | -3 |
| 7.5 | 7 | 8 |

### 2.3. int() қате беретін жағдайлар
```text
int("3.5")     -> ValueError: invalid literal for int() with base 10: '3.5'
int("он")      -> ValueError: invalid literal for int() with base 10: 'он'
int("12a")     -> ValueError: invalid literal for int() with base 10: '12a'
int("")        -> ValueError: invalid literal for int() with base 10: ''
int("1 000")   -> ValueError: invalid literal for int() with base 10: '1 000'
```

Нүктесі бар жолды бүтінге айналдыру керек болса — екі қадаммен: `int(float("3.5"))` → `3`.

## 3. float() — нақты санға түрлендіру

```python
print(float("3.14"))
print(float("10"))
print(float(7))
print(float("  -0.5 "))
print(float("1e3"))
```

Нәтижесі:
```text
3.14
10.0
7.0
-0.5
1000.0
```

`float()` бүтін сан жазылған жолды да қабылдайды (`"10"` → `10.0`). Сондықтан пайдаланушы бөлшек сан енгізуі мүмкін болса (бой, салмақ, баға, температура) — **`float(input())`** қолданамыз.

```text
float("3,5")   -> ValueError: could not convert string to float: '3,5'
```

Бөлшек бөлік — тек **нүктемен**! Пайдаланушыға prompt-та ескертіңіз: `"Бойыңыз (метр, мысалы 1.55): "`.

## 4. str() — жолға түрлендіру

```python
age = 13
height = 1.58
text = "Жасым " + str(age) + ", бойым " + str(height) + " м"
print(text)
print(len(str(123456)))
```

Нәтижесі:
```text
Жасым 13, бойым 1.58 м
6
```

`str()` ешқашан қате бермейді — кез келген мәнді мәтінге айналдыра алады. Қолданылуы:
- мәтін мен санды `+` арқылы біріктіру;
- санның цифрлар санын `len(str(n))` арқылы табу;
- санды мәтін ретінде қайталау: `str(7) * 3` → `"777"`.

## 5. bool() — логикалық түрлендіру

Ереже: «бос» немесе «нөл» мәндер → `False`, қалғанының бәрі → `True`.

```python
print(bool(0))
print(bool(15))
print(bool(-3))
print(bool(0.0))
print(bool(""))
print(bool("Сәлем"))
print(bool(" "))
print(bool("False"))
```

Нәтижесі:
```text
False
True
True
False
False
True
True
True
```

Назар аударыңыз: `bool("False")` → `True`, себебі бұл бос емес жол! `if` операторы кез келген мәнді дәл осылай тексереді: жол бос болмаса, `if name:` ақиқат.

## 6. Айқын және айқын емес түрлендіру

**Айқын түрлендіру** (явное) — бағдарламашы өзі `int()`, `float()`, `str()` жазады.

**Айқын емес түрлендіру** (неявное) — Python өзі автоматты түрде жасайды. Бұл тек сандар арасында болады: `int` + `float` → `float`.

```python
a = 5          # int
b = 2.5        # float
c = a + b      # Python a-ны 5.0-ге айналдырды
print(c, type(c))
print(10 / 5, type(10 / 5))
print(True + 1)
```

Нәтижесі:
```text
7.5 <class 'float'>
2.0 <class 'float'>
2
```

Бірақ жол мен сан арасында Python **ешқашан өзі түрлендірмейді** — бағдарламашы өзі шешуі керек: «қосу» ма, әлде «біріктіру» ме?

```python
x = "10"
y = 5
print(int(x) + y)      # қосу
print(x + str(y))      # біріктіру
```

Нәтижесі:
```text
15
105
```

## 7. Түрлендіру картасы

```text
              int("42")             float("4.2")
   "42" -------------------> 42      "4.2" ----------> 4.2
   "42" <------------------- 42      "4.2" <---------- 4.2
              str(42)               str(4.2)

              float(42)
     42 -------------------> 42.0
     42 <------------------- 42.0  (int кеседі: int(4.9) = 4)
              int(42.0)

   "4.2" --X--> int     (ValueError)   -> int(float("4.2")) = 4
```

## 8. Енгізуге сай функцияны таңдау

| Енгізілетін дерек | Функция | Мысал |
|---|---|---|
| Аты, қала, сөз | `input()` | `name = input("Атыңыз: ")` |
| Жас, саны, жыл, қабат | `int(input())` | `count = int(input("Саны: "))` |
| Баға, бой, салмақ, температура, бағам | `float(input())` | `weight = float(input("Салмағы (кг): "))` |
| Телефон нөмірі, пошта индексі, ЖСН | `input()` (жол!) | Олармен есептеу жасалмайды; `int` басындағы нөлдерді жояды: `int("050000")` → `50000` |

Мысал — Дене салмағының индексі (ДСИ / BMI):

```python
weight = float(input("Салмағыңыз (кг): "))
height = float(input("Бойыңыз (м, мысалы 1.55): "))
bmi = weight / height ** 2
print("Дене салмағының индексі:", round(bmi, 1))
```

Нәтижесі:
```text
Салмағыңыз (кг): 45
Бойыңыз (м, мысалы 1.55): 1.55
Дене салмағының индексі: 18.7
```

Мысал — валюта айырбастау:

```python
rate = float(input("1 доллар бағамы (теңге): "))
tenge = int(input("Неше теңге айырбастайсыз? "))
dollars = tenge / rate
print("Сіз", round(dollars, 2), "доллар аласыз")
```

Нәтижесі:
```text
1 доллар бағамы (теңге): 505.5
Неше теңге айырбастайсыз? 100000
Сіз 197.82 доллар аласыз
```

## Жиі кездесетін қателер

**1. `int()` арқылы бөлшек санды енгізу.**
```python
# height = int(input("Бойыңыз: "))   # 1.55 енгізсе -> ValueError
height = float(input("Бойыңыз: "))
```

**2. Түрлендірудің нәтижесін сақтамау.**
```python
age = input("Жасыңыз: ")
int(age)                 # нәтиже ешқайда сақталмады!
print(type(age))         # бәрібір <class 'str'>
```
Дұрысы:
```python
age = input("Жасыңыз: ")
age = int(age)           # немесе бірден: age = int(input(...))
print(type(age))
```

**3. Жақшалар саны.**
```text
x = int(input("x = ")
SyntaxError: '(' was never closed
```
Дұрысы: `x = int(input("x = "))`.

**4. `int()` дөңгелектейді деп ойлау.**
```python
price = 999.99
print(int(price))     # 999, 1000 емес!
print(round(price))   # 1000
```

**5. Үтірді нүктенің орнына енгізу (`3,5`).** Prompt-та мысал беріңіз.

**6. Сан мен жолды `+` арқылы біріктіру.**
```python
score = 95
# print("Ұпай: " + score)   # TypeError: can only concatenate str (not "int") to str
print("Ұпай: " + str(score))
print("Ұпай:", score)
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Тип түрлендіру (casting) | Мәнді бір типтен басқа типке айналдыру |
| `int()` | Бүтін санға түрлендіру (бөлшек бөлігін кесіп тастайды) |
| `float()` | Нақты санға түрлендіру |
| `str()` | Жолға түрлендіру |
| `bool()` | Логикалық мәнге түрлендіру: нөл/бос → `False` |
| Айқын түрлендіру | Бағдарламашы функция арқылы өзі түрлендіреді |
| Айқын емес түрлендіру | Python өзі автоматты түрлендіреді (int → float) |
| `ValueError` | Мәнді сұралған типке айналдыру мүмкін болмағанда шығатын қате |
| `TypeError` | Сәйкес емес типтермен амал орындағанда шығатын қате |

## Ескерту

- `int()` басқа санау жүйелеріндегі сандарды да оқи алады: `int("ff", 16)` → `255`, `int("1010", 2)` → `10`. Кері түрлендіру: `bin(10)`, `hex(255)`.
- `int()` және `float()` кодтағыдай цифрлар арасындағы `_` таңбасын қабылдайды: `int("1_000")` → `1000`, бірақ сан ішіндегі бос орынды қабылдамайды.
- `float()` ерекше `"inf"`, `"-inf"` және `"nan"` («сан емес») жолдарын түсінеді: `float("nan") == float("nan")` нәтижесі `False`.
- Түрлендірер алдында енгізуді тексеруге болады: `"123".isdigit()` → `True`, бірақ `"-5"` және `"3.5"` үшін бұл `False`, сондықтан `ValueError`-ды `try...except` арқылы ұстаған сенімдірек.
- Цифрлардан тұратын өте ұзын жолдар үшін (4300 таңбадан көп) Python 3.11+ нұсқасында `int()` әдепкі бойынша `ValueError` береді — бұл баяу есептеулерден қорғаныс; шекті `sys.set_int_max_str_digits()` арқылы өзгертуге болады.
- Кіріктірілген функциялар құжаттамасы: https://docs.python.org/3/library/functions.html
