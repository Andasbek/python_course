# Сабақ 12. Практикалық тапсырмалар: Тип түрлендіру

## Базалық деңгей

### 1-тапсырма. Болжа — тексер
Әр жолдың нәтижесін (немесе қате түрін) алдымен дәптерге жазыңыз, содан кейін Python-да тексеріңіз.

```python
print(int("7") + 3)
print("7" + str(3))
print(float("7") + 3)
print(int(7.99))
print(round(7.99))
print(int(float("2.5")))
print(str(2) * 3)
print(len(str(2 ** 10)))
print(bool(0), bool(-1), bool(""))
```

Ал мына жолдар қандай қате береді? (Әрқайсысын бөлек тексеріңіз.)

```text
int("7.5")
float("7,5")
"Баға: " + 500
int("жеті")
```

### 2-тапсырма. Тауар бағасы
Тауардың атауын (`str`), бағасын (`float`) және санын (`int`) енгізіп, жалпы құнын шығарыңыз.

Мысал:
```text
Тауар: дәптер
Бағасы: 149.5
Саны: 4
дәптер x 4 = 598.0 теңге
```

### 3-тапсырма. Температура
Цельсий бойынша температураны (`float`) енгізіп, Фаренгейтке айналдырыңыз: F = C · 9/5 + 32.

Мысал:
```text
Температура (°C): 36.6
Фаренгейт бойынша: 97.88
```

### 4-тапсырма. Ұпай
Пайдаланушы үш тапсырманың ұпайын енгізеді (бүтін сандар). Жалпы ұпайды және орташа ұпайды (1 таңбаға дейін дөңгелектеп) шығарыңыз. Нәтижені **`+` арқылы біріктірілген бір жолмен** шығарыңыз (`str()` қолданыңыз).

Мысал:
```text
1-тапсырма: 8
2-тапсырма: 10
3-тапсырма: 7
Жалпы: 25, орташа: 8.3
```

### 5-тапсырма. Қатені түзет
Әр бағдарламада қате бар. Іске қосып, қатенің түрін анықтап, түзетіңіз.

**А)**
```python
apples = input("Алма саны: ")
pears = input("Алмұрт саны: ")
print("Барлығы:", apples + pears)
```

**Б)**
```python
weight = int(input("Салмағыңыз (кг, мысалы 42.5): "))
print("Айдағы салмағыңыз:", weight * 0.165)
```

**В)**
```python
year = int(input("Туған жылыңыз: "))
print("Сіз " + 2026 - year + " жастасыз")
```

## Кеңейтілген деңгей

### 6-тапсырма. Дене салмағының индексі
Салмақ (кг) пен бойды (см!) енгізіңіз. Бойды метрге айналдырып, ДСИ есептеңіз: ДСИ = салмақ / бой². Нәтижені 1 таңбаға дейін дөңгелектеңіз.

Мысал:
```text
Салмағыңыз (кг): 50
Бойыңыз (см): 160
ДСИ: 19.5
```

### 7-тапсырма. Валюта айырбастау
Доллар бағамын және теңге сомасын енгізіп, неше доллар алатынын (2 таңбаға дейін), сондай-ақ тек бүтін доллар алса (тиынсыз), неше теңге «қалатынын» есептеңіз.

Мысал:
```text
1 доллар (теңге): 505.5
Теңге: 10000
Доллар: 19.78
Бүтін доллар: 19
Қалған теңге: 395.5
```

### 8-тапсырма. Цифрлар саны
Пайдаланушы кез келген бүтін сан енгізеді (оң). Санның неше цифрдан тұратынын және бірінші цифрын `str()` және `len()` көмегімен табыңыз.

Мысал:
```text
Сан: 2026
Цифрлар саны: 4
Ең үлкен разряд бірлігі: 1000
```
*Кеңес:* ең үлкен разряд бірлігі = `10 ** (цифрлар саны - 1)`.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Цифрлар қосындысы (кез келген ұзындықтағы сан)
Пайдаланушы **төрт таңбалы** сан енгізеді. Цифрлар қосындысын **екі тәсілмен** есептеңіз:
1. `//` және `%` арқылы;
2. санды жолға айналдырып, `int(s[0])` түріндегі индекстеу арқылы (индекстеу — 42-сабақтың тақырыбы; `s[0]` — жолдың бірінші таңбасы, `s[1]` — екіншісі).

### 10-тапсырма. Дөңгелектеу шеберлері
Пайдаланушы оң бөлшек сан енгізеді. Шығарыңыз:
1. бөлшек бөлігін кесіп тастағандағы мәнін (`int`);
2. математикалық дөңгелектеуді (0.5 әрқашан жоғары): `int(x + 0.5)`;
3. жоғары қарай дөңгелектеуді (ceil) — `if`-сіз және `math` модулінсіз! (Кеңес: `-int(-x // 1)` немесе `int(-(-x // 1))`.)

Мысал:
```text
Сан: 4.3
Кесілген: 4
Дөңгелектелген: 4
Жоғары қарай: 5
```

## Үй тапсырмасы
1. «Ұялы байланыс тарифі» бағдарламасы: айлық абоненттік төлем (`float`), қосымша минут саны (`int`), бір минут бағасы (`float`) енгізіледі. Айлық төлемді есептеңіз.
2. Өзіңізге 5 «Болжа — тексер» сұрағын құрастырыңыз (`int`, `float`, `str`, `bool` түрлендірулерімен) және жауаптарын жазыңыз. Келесі сабақта сыныптастарыңызға қоясыз.
3. Кестені толтырыңыз: «Енгізілетін дерек | Қай функция | Неге» — 8 түрлі дерек үшін (жас, баға, телефон нөмірі, температура, қабат, ЖСН, бағам, оқушылар саны).
