## 1. Что такое преобразование типов?

**Преобразование типов** (тип түрлендіру, type conversion / casting) — превращение значения одного типа в другой тип.

Аналогия — обмен валюты: 100 долларов и 50 000 тенге напрямую не складываются; сначала их нужно перевести в одну валюту. Так же `"5"` (строка) и `7` (число) не складываются — сначала их нужно привести к одному типу.

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `int(x)` | Превращает в целое число | `int("42")` | `42` |
| `float(x)` | Превращает в вещественное число | `float("3.5")` | `3.5` |
| `str(x)` | Превращает в строку (текст) | `str(42)` | `"42"` |
| `bool(x)` | Превращает в логическое значение | `bool(0)` | `False` |

## 2. int() — преобразование в целое число

### 2.1. Из строки в целое число
```python
text = "2026"
year = int(text)
print(year + 1)
print(type(year))
```

Результат:
```text
2027
<class 'int'>
```

Пробелы в начале и конце строки допустимы, внутри — нет:

```python
print(int("  15  "))
print(int("-8"))
```

Результат:
```text
15
-8
```

### 2.2. Из вещественного числа в целое — дробная часть **отбрасывается**
```python
print(int(3.99))
print(int(7.1))
print(int(-2.8))
```

Результат:
```text
3
7
-2
```

`int()` **не округляет**, а только отбрасывает дробную часть (в сторону нуля). Для округления — `round()`:

| x | `int(x)` | `round(x)` |
|---|---|---|
| 3.2 | 3 | 3 |
| 3.9 | 3 | 4 |
| -2.8 | -2 | -3 |
| 7.5 | 7 | 8 |

### 2.3. Случаи, когда int() выдаёт ошибку
```text
int("3.5")     -> ValueError: invalid literal for int() with base 10: '3.5'
int("десять")  -> ValueError: invalid literal for int() with base 10: 'десять'
int("12a")     -> ValueError: invalid literal for int() with base 10: '12a'
int("")        -> ValueError: invalid literal for int() with base 10: ''
int("1 000")   -> ValueError: invalid literal for int() with base 10: '1 000'
```

Если нужно превратить в целое число строку с точкой — в два шага: `int(float("3.5"))` → `3`.

## 3. float() — преобразование в вещественное число

```python
print(float("3.14"))
print(float("10"))
print(float(7))
print(float("  -0.5 "))
print(float("1e3"))
```

Результат:
```text
3.14
10.0
7.0
-0.5
1000.0
```

`float()` принимает и строку с целым числом (`"10"` → `10.0`). Поэтому, если пользователь может ввести дробное число (рост, вес, цена, температура), используем **`float(input())`**.

```text
float("3,5")   -> ValueError: could not convert string to float: '3,5'
```

Дробная часть — только через **точку**! Предупредите пользователя в prompt: `"Ваш рост (в метрах, например 1.55): "`.

## 4. str() — преобразование в строку

```python
age = 13
height = 1.58
text = "Мне " + str(age) + " лет, мой рост " + str(height) + " м"
print(text)
print(len(str(123456)))
```

Результат:
```text
Мне 13 лет, мой рост 1.58 м
6
```

`str()` никогда не выдаёт ошибку — может превратить в текст любое значение. Применение:
- объединение текста и числа через `+`;
- нахождение количества цифр числа через `len(str(n))`;
- повторение числа как текста: `str(7) * 3` → `"777"`.

## 5. bool() — логическое преобразование

Правило: «пустые» или «нулевые» значения → `False`, всё остальное → `True`.

```python
print(bool(0))
print(bool(15))
print(bool(-3))
print(bool(0.0))
print(bool(""))
print(bool("Привет"))
print(bool(" "))
print(bool("False"))
```

Результат:
```text
False
True
True
False
False
True
True
True
```

Обратите внимание: `bool("False")` → `True`, потому что это непустая строка! Именно так оператор `if` проверяет любые значения: `if name:` истинно, если строка не пустая.

## 6. Явное и неявное преобразование

**Явное преобразование** — программист сам пишет `int()`, `float()`, `str()`.

**Неявное преобразование** — Python выполняет его сам, автоматически. Это происходит только между числами: `int` + `float` → `float`.

```python
a = 5          # int
b = 2.5        # float
c = a + b      # Python превратил a в 5.0
print(c, type(c))
print(10 / 5, type(10 / 5))
print(True + 1)
```

Результат:
```text
7.5 <class 'float'>
2.0 <class 'float'>
2
```

Но между строкой и числом Python **никогда не преобразует сам** — программист должен решить: «сложить» или «объединить»?

```python
x = "10"
y = 5
print(int(x) + y)      # сложение
print(x + str(y))      # объединение
```

Результат:
```text
15
105
```

## 7. Карта преобразований

```text
              int("42")             float("4.2")
   "42" -------------------> 42      "4.2" ----------> 4.2
   "42" <------------------- 42      "4.2" <---------- 4.2
              str(42)               str(4.2)

              float(42)
     42 -------------------> 42.0
     42 <------------------- 42.0  (int отбрасывает: int(4.9) = 4)
              int(42.0)

   "4.2" --X--> int     (ValueError)   -> int(float("4.2")) = 4
```

## 8. Выбор функции в зависимости от вводимых данных

| Вводимые данные | Функция | Пример |
|---|---|---|
| Имя, город, слово | `input()` | `name = input("Имя: ")` |
| Возраст, количество, год, этаж | `int(input())` | `count = int(input("Количество: "))` |
| Цена, рост, вес, температура, курс | `float(input())` | `weight = float(input("Вес (кг): "))` |
| Номер телефона, почтовый индекс, ИИН | `input()` (строка!) | С ними не выполняют вычислений; `int` удаляет ведущие нули: `int("050000")` → `50000` |

Пример — индекс массы тела (ИМТ / BMI):

```python
weight = float(input("Ваш вес (кг): "))
height = float(input("Ваш рост (м, например 1.55): "))
bmi = weight / height ** 2
print("Индекс массы тела:", round(bmi, 1))
```

Результат:
```text
Ваш вес (кг): 45
Ваш рост (м, например 1.55): 1.55
Индекс массы тела: 18.7
```

Пример — обмен валюты:

```python
rate = float(input("Курс 1 доллара (тенге): "))
tenge = int(input("Сколько тенге обмениваете? "))
dollars = tenge / rate
print("Вы получите", round(dollars, 2), "долл.")
```

Результат:
```text
Курс 1 доллара (тенге): 505.5
Сколько тенге обмениваете? 100000
Вы получите 197.82 долл.
```

## Частые ошибки
**1. Ввод дробного числа через `int()`.**
```python
# height = int(input("Ваш рост: "))   # если ввести 1.55 -> ValueError
height = float(input("Ваш рост: "))
```

**2. Результат преобразования не сохранён.**
```python
age = input("Ваш возраст: ")
int(age)                 # результат никуда не сохранён!
print(type(age))         # всё равно <class 'str'>
```
Правильно:
```python
age = input("Ваш возраст: ")
age = int(age)           # или сразу: age = int(input(...))
print(type(age))
```

**3. Количество скобок.**
```text
x = int(input("x = ")
SyntaxError: '(' was never closed
```
Правильно: `x = int(input("x = "))`.

**4. Думать, что `int()` округляет.**
```python
price = 999.99
print(int(price))     # 999, а не 1000!
print(round(price))   # 1000
```

**5. Ввод запятой вместо точки (`3,5`).** Приводите пример в prompt.

**6. Объединение числа и строки через `+`.**
```python
score = 95
# print("Баллы: " + score)   # TypeError: can only concatenate str (not "int") to str
print("Баллы: " + str(score))
print("Баллы:", score)
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Преобразование типов (casting) | Превращение значения одного типа в другой тип |
| `int()` | Преобразование в целое число (отбрасывает дробную часть) |
| `float()` | Преобразование в вещественное число |
| `str()` | Преобразование в строку |
| `bool()` | Преобразование в логическое значение: ноль/пусто → `False` |
| Явное преобразование | Программист сам выполняет преобразование с помощью функции |
| Неявное преобразование | Python выполняет преобразование автоматически (int → float) |
| `ValueError` | Ошибка, возникающая, когда значение невозможно превратить в нужный тип |
| `TypeError` | Ошибка, возникающая при операции над несовместимыми типами |

## Примечание

- `int()` умеет читать числа в других системах счисления: `int("ff", 16)` → `255`, `int("1010", 2)` → `10`. Обратно: `bin(10)`, `hex(255)`.
- `int()` и `float()` допускают `_` между цифрами, как в коде: `int("1_000")` → `1000`, но не пробелы внутри числа.
- `float()` понимает особые строки `"inf"`, `"-inf"` и `"nan"` («не число»): `float("nan") == float("nan")` даёт `False`.
- Перед преобразованием ввод можно проверить: `"123".isdigit()` → `True`, но для `"-5"` и `"3.5"` это `False`, поэтому надёжнее перехватывать `ValueError` через `try...except`.
- Для очень длинных строк из цифр (более 4300 знаков) `int()` в Python 3.11+ по умолчанию выдаёт `ValueError` — это защита от медленных вычислений; лимит меняется через `sys.set_int_max_str_digits()`.
- Документация по встроенным функциям: https://docs.python.org/3/library/functions.html
