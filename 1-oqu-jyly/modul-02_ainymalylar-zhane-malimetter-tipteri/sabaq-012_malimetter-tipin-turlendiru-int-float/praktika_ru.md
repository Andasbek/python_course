## Базовый уровень

### Задание 1. Предскажи — проверь
Сначала запишите в тетрадь результат (или вид ошибки) каждой строки, затем проверьте в Python.

```python
print(int("7") + 3)
print("7" + str(3))
print(float("7") + 3)
print(int(7.99))
print(round(7.99))
print(int(float("2.5")))
print(str(2) * 3)
print(len(str(2 ** 10)))
print(bool(0), bool(-1), bool(""))
```

А какие ошибки выдадут эти строки? (Проверьте каждую отдельно.)

```text
int("7.5")
float("7,5")
"Цена: " + 500
int("семь")
```

### Задание 2. Стоимость товара
Введите название товара (`str`), его цену (`float`) и количество (`int`) и выведите общую стоимость.

Пример:
```text
Товар: тетрадь
Цена: 149.5
Количество: 4
тетрадь x 4 = 598.0 тенге
```

### Задание 3. Температура
Введите температуру по Цельсию (`float`) и переведите её в градусы Фаренгейта: F = C · 9/5 + 32.

Пример:
```text
Температура (°C): 36.6
По Фаренгейту: 97.88
```

### Задание 4. Баллы
Пользователь вводит баллы за три задания (целые числа). Выведите общий и средний балл (округлённый до 1 знака). Выведите результат **одной строкой, собранной через `+`** (используйте `str()`).

Пример:
```text
Задание 1: 8
Задание 2: 10
Задание 3: 7
Всего: 25, среднее: 8.3
```

### Задание 5. Исправь ошибку
В каждой программе есть ошибка. Запустите, определите вид ошибки и исправьте.

**А)**
```python
apples = input("Количество яблок: ")
pears = input("Количество груш: ")
print("Всего:", apples + pears)
```

**Б)**
```python
weight = int(input("Ваш вес (кг, например 42.5): "))

```

**В)**


## Продвинутый уровень

### Задание 6. Индекс массы тела
Введите вес (кг) и рост (в см!). Переведите рост в метры и вычислите ИМТ: ИМТ = вес / рост². Округлите результат до 1 знака.

Пример:
```text
Ваш вес (кг): 50
Ваш рост (см): 160
ИМТ: 19.5
```

### Задание 7. Обмен валюты
Введите курс доллара и сумму в тенге и вычислите, сколько долларов получится (до 2 знаков), а также сколько тенге «останется», если брать только целые доллары (без центов).

Пример:
```text
1 доллар (тенге): 505.5
Тенге: 10000
Долларов: 19.78
Целых долларов: 19
Осталось тенге: 395.5
```

### Задание 8. Количество цифр
Пользователь вводит любое целое (положительное) число. С помощью `str()` и `len()` найдите, из скольких цифр состоит число, и его старшую разрядную единицу.

Пример:
```text
Число: 2026
Количество цифр: 4
Старшая разрядная единица: 1000
```
*Подсказка:* старшая разрядная единица = `10 ** (количество цифр - 1)`.

## ★ Олимпиадная / творческая задача

### Задание 9. Сумма цифр (число любой длины)
Пользователь вводит **четырёхзначное** число. Вычислите сумму цифр **двумя способами**:
1. с помощью `//` и `%`;
2. превратив число в строку и используя индексацию вида `int(s[0])` (индексация — тема 42-го урока; `s[0]` — первый символ строки, `s[1]` — второй).

### Задание 10. Мастера округления
Пользователь вводит положительное дробное число. Выведите:
1. значение с отброшенной дробной частью (`int`);
2. математическое округление (0.5 всегда вверх): `int(x + 0.5)`;
3. округление вверх (ceil) — без `if` и без модуля `math`! (Подсказка: `-int(-x // 1)` или `int(-(-x // 1))`.)

Пример:
```text
Число: 4.3
Отброшено: 4
Округлено: 4
Вверх: 5
```
