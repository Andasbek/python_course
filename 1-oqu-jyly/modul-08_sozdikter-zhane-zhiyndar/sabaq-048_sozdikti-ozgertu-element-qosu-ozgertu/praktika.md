# Сабақ 48. Практикалық тапсырмалар: сөздікті өзгерту

## Базалық деңгей

### 1-тапсырма. Асхана мәзірі
Сөздік берілген: `menu = {"палау": 900, "лағман": 850, "шай": 100}`. Бағдарлама кезекпен:
1. `"самса": 300` қоссын;
2. палаудың бағасын 50 теңгеге көтерсін;
3. шайды мәзірден алып тастасын;
4. әр қадамнан кейін мәзірді шығарсын.

### 2-тапсырма. Телефон кітапшасын толтыру
Бос сөздіктен бастап, пайдаланушыдан 3 рет есім мен телефон нөмірін сұрап, сөздікке қосыңыз. Соңында сөздікті және контактілер санын шығарыңыз.

### 3-тапсырма. Әріптер жиілігі
Сөз енгізіледі. Санауыш-сөздік арқылы әр әріптің неше рет кездесетінін есептеп, сөздікті шығарыңыз.

Мысал:
```text
Сөз: қазақстан
{'қ': 2, 'а': 3, 'з': 1, 'с': 1, 'т': 1, 'н': 1}
```

### 4-тапсырма. Қаржы әмияны
`wallet = {"Арман": 5000, "Сәуле": 3000}`. Пайдаланушы есім мен сома енгізеді (оң сан — толтыру, теріс — шығын). Егер есім жоқ болса, жаңа әмиян ашылсын (бастапқы баланс 0). Әрекеттен кейін сөздікті шығарыңыз.

### 5-тапсырма. Себеттен жою
`cart = {"нан": 2, "сүт": 1, "алма": 5, "ірімшік": 1}`. Пайдаланушы тауар атауын енгізеді. Тауар себетте болса — `pop()` арқылы жойып, «нан (2 дана) жойылды» түрінде хабар беріңіз; болмаса — «Себетте мұндай тауар жоқ».

## Кеңейтілген деңгей

### 6-тапсырма. Сөздер жиілігі
Мәтін енгізіледі. Тыныс белгілерін алып тастап, кіші әріпке айналдырып, әр сөздің неше рет кездесетінін сөздікке жинаңыз.

Мысал:
```text
Мәтін: Бала, бала, балапан! Бала ойнайды.
{'бала': 3, 'балапан': 1, 'ойнайды': 1}
```

### 7-тапсырма. Қойма
Қойма сөздігі: `stock = {"дәптер": 50, "қалам": 120, "сызғыш": 30}`. Мәзірлі бағдарлама (while цикл) жазыңыз:
- `1` — тауар келді (атауы, саны → көбейту немесе жаңа тауар қосу);
- `2` — тауар сатылды (атауы, саны → азайту; қалдық жеткіліксіз болса — ескерту; 0 болса — тауарды жою);
- `3` — қойманы көрсету;
- `0` — шығу.

### 8-тапсырма. Кілт атауын өзгерту
`student = {"name": "Дана", "age": 14, "city": "Тараз"}`. Барлық ағылшынша кілттерді қазақшаға (`аты`, `жасы`, `қала`) ауыстырыңыз. Кеңес: аударма сөздігін құрып, `pop()` қолданыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Анаграммалар
Екі сөз енгізіледі. Олар анаграмма ба (бірдей әріптерден тұра ма)? Әр сөз үшін әріптер жиілігінің сөздігін құрып, сөздіктерді `==` арқылы салыстырыңыз.

Мысал: `қамыр` және `қырма` → анаграмма; `алма` және `алым` → анаграмма емес.

### 10-тапсырма. Ең жиі сөз
Мәтіндегі ең жиі кездесетін сөзді және оның санын табыңыз. Бірнеше сөздің саны бірдей болса — мәтінде бірінші кездескенін шығарыңыз. (Кеңес: сөздерді сөздікке қосқанда, бір мезгілде ең үлкен санды да жаңартып отырыңыз.)

## Үй тапсырмасы

1. «Менің кітапханам» сөздігі: кітап атауы → авторы. Кемінде 5 кітап қосыңыз, 1-еуін өзгертіңіз, 1-еуін жойыңыз.
2. Аптаның әр күнінде неше сағат ұйықтағаныңызды сөздікке жазыңыз, кейін бір күннің мәнін түзетіңіз.
3. Өткен сабақтағы қазақша-ағылшынша сөздікке тағы 5 сөз қосыңыз.

**7-тапсырма**
```python
stock = {"дәптер": 50, "қалам": 120, "сызғыш": 30}
while True:
    choice = input("1-келді, 2-сатылды, 3-көрсету, 0-шығу: ")
    if choice == "0":
        break
    elif choice == "1":
        item = input("Тауар: ")
        n = int(input("Саны: "))
        stock[item] = stock.get(item, 0) + n
    elif choice == "2":
        item = input("Тауар: ")
        n = int(input("Саны: "))
        if item not in stock:
            print("Мұндай тауар жоқ")
        elif stock[item] < n:
            print("Қалдық жеткіліксіз! Қоймада:", stock[item])
        else:
            stock[item] -= n
            if stock[item] == 0:
                del stock[item]
                print(item, "таусылды")
    elif choice == "3":
        print(stock)
    else:
        print("Қате таңдау")
```

**10-тапсырма**
```python
text = input("Мәтін: ").lower()
for mark in ".,!?;:—-":
    text = text.replace(mark, " ")
freq = {}
best_word = ""
best_count = 0
for word in text.split():
    freq[word] = freq.get(word, 0) + 1
    if freq[word] > best_count:
        best_count = freq[word]
        best_word = word
print(best_word, best_count)
```
Ескерту: бұл шешімде тең жағдайда санды бірінші жеткен сөз таңдалады — оқушылармен «бірінші кездескен» мен «санды бірінші жеткен» айырмашылығын талқылауға болады (49-сабақтан кейін сөздік бойынша цикл арқылы дәл шешіледі).
