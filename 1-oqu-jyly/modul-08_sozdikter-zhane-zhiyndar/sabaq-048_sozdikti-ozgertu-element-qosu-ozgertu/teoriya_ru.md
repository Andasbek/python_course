## 1. Словарь — изменяемый тип

Как и список, словарь является **изменяемым (mutable)**: после создания в него можно добавлять пары, изменять значения, удалять их. В этом главное отличие от строки (str).

## 2. Добавление и изменение элемента

Один и тот же синтаксис выполняет два действия:

```
d[ключ] = значение
```

- если ключа **нет** — новая пара **добавляется**;
- если ключ **есть** — значение **заменяется**.

```python
menu = {"плов": 900, "лагман": 850}
menu["баурсак"] = 150      # добавление
menu["плов"] = 950         # изменение
print(menu)
print(len(menu))
```

Результат:
```text
{'плов': 950, 'лагман': 850, 'баурсак': 150}
3
```

### Изменение значения через старое значение

```python
balance = {"Арман": 2000, "Сауле": 3500}
balance["Арман"] += 500        # добавлено 500 тенге
balance["Сауле"] -= 1200       # купила обед в столовой
print(balance)
```

Результат:
```text
{'Арман': 2500, 'Сауле': 2300}
```

**Будьте внимательны:** `+=` работает только с существующим ключом. Для несуществующего ключа `d["новый"] += 1` → `KeyError`.

### Постепенное заполнение словаря

Часто словарь начинается пустым и заполняется в цикле:

```python
phonebook = {}
names = ["Айгерим", "Бекзат", "Дана"]
numbers = ["87011112233", "87772223344", "87053334455"]
for i in range(len(names)):
    phonebook[names[i]] = numbers[i]
print(phonebook)
```

Результат:
```text
{'Айгерим': '87011112233', 'Бекзат': '87772223344', 'Дана': '87053334455'}
```

Заполнение пользователем (пример, работает с `input()`):

```python
grades = {}
for i in range(3):
    name = input("Имя ученика: ")
    grade = int(input("Оценка: "))
    grades[name] = grade
print(grades)
```

### update() — сразу несколько пар

```python
menu = {"плов": 950, "лагман": 850}
menu.update({"манты": 800, "лагман": 900})   # одна пара новая, одна изменяется
print(menu)
```

Результат:
```text
{'плов': 950, 'лагман': 900, 'манты': 800}
```

### setdefault() — добавить, только если нет

```python
settings = {"язык": "казахский"}
settings.setdefault("язык", "русский")     # есть — не изменяется
settings.setdefault("тема", "тёмная")      # нет — добавляется
print(settings)
```

Результат:
```text
{'язык': 'казахский', 'тема': 'тёмная'}
```

## 3. Удаление элементов

| Способ | Что делает | Если ключа нет |
|---|---|---|
| `del d[k]` | удаляет пару `k` | `KeyError` |
| `d.pop(k)` | удаляет и **возвращает значение** | `KeyError` |
| `d.pop(k, x)` | удаляет, возвращает значение | возвращает `x`, ошибки нет |
| `d.popitem()` | удаляет **последнюю добавленную** пару, возвращает `(ключ, значение)` | в пустом словаре `KeyError` |
| `d.clear()` | полностью очищает словарь | — |

```python
menu = {"плов": 950, "лагман": 900, "манты": 800, "баурсак": 150, "чай": 100}

del menu["лагман"]
print(menu)

price = menu.pop("манты")
print("Манты удалены, их цена была:", price)

print(menu.pop("бешбармак", "нет такого блюда"))

last = menu.popitem()
print("Последний удалённый:", last)
print(menu)

menu.clear()
print(menu, len(menu))
```

Результат:
```text
{'плов': 950, 'манты': 800, 'баурсак': 150, 'чай': 100}
Манты удалены, их цена была: 800
нет такого блюда
Последний удалённый: ('чай', 100)
{'плов': 950, 'баурсак': 150}
{} 0
```

### Безопасное удаление

```python
cart = {"хлеб": 2, "молоко": 1}
item = "сыр"
if item in cart:
    del cart[item]
    print(item, "удалён")
else:
    print(item, "нет в корзине")
```

Результат:
```text
сыр нет в корзине
```

## 4. «Переименование» ключа

Изменить ключ в словаре напрямую нельзя. Удаляем старую пару и добавляем с новым ключом:

```python
student = {"фио": "Дана Сеитова", "класс": 8}
student["имя"] = student.pop("фио")
print(student)
```

Результат:
```text
{'класс': 8, 'имя': 'Дана Сеитова'}
```

## 5. Словарь-счётчик: самый важный шаблон

Для поиска частоты букв не нужно вызывать `count()` для всего алфавита — со словарём это гораздо проще и быстрее (текст просматривается только один раз):

```python
text = "мама и папа"
freq = {}
for ch in text:
    if ch != " ":
        freq[ch] = freq.get(ch, 0) + 1
print(freq)
```

Результат:
```text
{'м': 2, 'а': 4, 'и': 1, 'п': 2}
```

Как это работает: `freq.get(ch, 0)` даёт старое количество, если буква уже встречалась, или 0, если нет; прибавляем к нему 1 и сохраняем.

Альтернатива (через `if`):

```python
votes = ["Яблоко", "Банан", "Яблоко", "Яблоко", "Банан", "Абрикос"]
result = {}
for v in votes:
    if v in result:
        result[v] += 1
    else:
        result[v] = 1
print(result)
```

Результат:
```text
{'Яблоко': 3, 'Банан': 2, 'Абрикос': 1}
```

Этот шаблон применяется для подсчёта голосов, слов, продаж и т.п.

## 6. Копия и ссылка

```python
original = {"а": 1}
link = original          # это НЕ копия, а второе имя того же словаря
copy = original.copy()   # настоящая копия
link["б"] = 2
print(original)
print(copy)
```

Результат:
```text
{'а': 1, 'б': 2}
{'а': 1}
```

Как и у списка: `=` не создаёт новый словарь. Если нужна отдельная копия — `copy()`.

## Частые ошибки

**1. Использование += для несуществующего ключа**

```python
count = {}
# count["а"] += 1                    # KeyError
count["а"] = count.get("а", 0) + 1
print(count)
```

**2. Ключа нет при удалении**

```python
d = {"x": 1}
# del d["y"]           # KeyError
d.pop("y", None)       # без ошибки
print(d)
```

**3. Применение методов списка к словарю**

```python
d = {"хлеб": 250}
# d.append("молоко")      # AttributeError: у словаря нет append
d["молоко"] = 520
print(d)
```

**4. Не учитывают регистр и пробелы**

```python
d = {"хлеб": 250}
key = "  Хлеб ".strip().lower()
print(d.get(key))      # 250
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Изменяемый тип (mutable) | объект, который можно изменить после создания (list, dict) |
| `d[k] = v` | добавление новой пары или изменение существующего значения |
| `update()` | добавление/обновление пар из другого словаря |
| `del d[k]` | удаление пары |
| `pop(k)` | удаление с возвратом значения |
| `popitem()` | удаление и возврат последней пары |
| `clear()` | очистка словаря |
| Словарь-счётчик | `d[k] = d.get(k, 0) + 1` — шаблон подсчёта частоты |

## Примечание

- Во время обхода словаря циклом `for` нельзя добавлять или удалять ключи — будет `RuntimeError`. Сначала возьмите копию ключей: `for k in list(d):`.
- `copy()` — «поверхностная» копия: если значения — списки или словари, они останутся общими. Для полностью независимой копии используется `copy.deepcopy()`.
- С Python 3.9 есть операторы объединения словарей: `d1 | d2` создаёт новый словарь, `d1 |= d2` работает как `update()`.
- Готовые структуры для подсчёта: `collections.Counter` и `collections.defaultdict(int)` — позволяют писать `d[k] += 1` без `KeyError`.
- `popitem()` начиная с Python 3.7 всегда удаляет последнюю добавленную пару (LIFO); в более ранних версиях могла удаляться произвольная пара.
- Документация: https://docs.python.org/3/library/stdtypes.html#dict
