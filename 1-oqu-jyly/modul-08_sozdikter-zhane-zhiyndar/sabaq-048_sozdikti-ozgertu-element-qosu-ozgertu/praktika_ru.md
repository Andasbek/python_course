# Урок 48. Практические задания: изменение словаря

## Базовый уровень

### Задание 1. Меню столовой
Дан словарь: `menu = {"плов": 900, "лагман": 850, "чай": 100}`. Программа должна по очереди:
1. добавить `"самса": 300`;
2. повысить цену плова на 50 тенге;
3. убрать чай из меню;
4. выводить меню после каждого шага.

### Задание 2. Заполнение телефонной книжки
Начиная с пустого словаря, 3 раза спросите у пользователя имя и номер телефона и добавьте их в словарь. В конце выведите словарь и количество контактов.

### Задание 3. Частота букв
Вводится слово. С помощью словаря-счётчика подсчитайте, сколько раз встречается каждая буква, и выведите словарь.

Пример:
```text
Слово: казахстан
{'к': 1, 'а': 3, 'з': 1, 'х': 1, 'с': 1, 'т': 1, 'н': 1}
```

### Задание 4. Кошелёк
`wallet = {"Арман": 5000, "Сауле": 3000}`. Пользователь вводит имя и сумму (положительное число — пополнение, отрицательное — расход). Если такого имени нет, открывается новый кошелёк (начальный баланс 0). После операции выведите словарь.

### Задание 5. Удаление из корзины
`cart = {"хлеб": 2, "молоко": 1, "яблоко": 5, "сыр": 1}`. Пользователь вводит название товара. Если товар есть в корзине — удалите его с помощью `pop()` и выведите сообщение вида «хлеб (2 шт.) удалён»; если нет — «В корзине нет такого товара».

## Продвинутый уровень

### Задание 6. Частота слов
Вводится текст. Удалите знаки препинания, переведите в строчные буквы и соберите в словарь, сколько раз встречается каждое слово.

Пример:
```text
Текст: Мама, мама, мамочка! Мама спит.
{'мама': 3, 'мамочка': 1, 'спит': 1}
```

### Задание 7. Склад
Словарь склада: `stock = {"тетрадь": 50, "ручка": 120, "линейка": 30}`. Напишите программу с меню (цикл while):
- `1` — поступил товар (название, количество → увеличить или добавить новый товар);
- `2` — товар продан (название, количество → уменьшить; если остатка недостаточно — предупреждение; если стало 0 — удалить товар);
- `3` — показать склад;
- `0` — выход.

### Задание 8. Переименование ключей
`student = {"name": "Дана", "age": 14, "city": "Тараз"}`. Замените все английские ключи на русские (`имя`, `возраст`, `город`). Подсказка: создайте словарь перевода и используйте `pop()`.

## ★ Олимпиадная / творческая задача

### Задание 9. Анаграммы
Вводятся два слова. Являются ли они анаграммами (состоят ли из одних и тех же букв)? Для каждого слова создайте словарь частоты букв и сравните словари с помощью `==`.

Пример: `лето` и `тело` → анаграмма; `кот` и `кит` → не анаграмма.

### Задание 10. Самое частое слово
Найдите самое часто встречающееся слово в тексте и количество его повторений. Если у нескольких слов одинаковое количество — выведите то, которое встретилось в тексте первым. (Подсказка: добавляя слова в словарь, одновременно обновляйте и наибольшее количество.)

## Домашнее задание

1. Словарь «Моя библиотека»: название книги → автор. Добавьте не менее 5 книг, измените 1, удалите 1.
2. Запишите в словарь, сколько часов вы спали в каждый день недели, затем исправьте значение для одного дня.
3. Добавьте ещё 5 слов в казахско-английский словарь с прошлого урока.

**Задание 7**
```python
stock = {"тетрадь": 50, "ручка": 120, "линейка": 30}
while True:
    choice = input("1-поступил, 2-продан, 3-показать, 0-выход: ")
    if choice == "0":
        break
    elif choice == "1":
        item = input("Товар: ")
        n = int(input("Количество: "))
        stock[item] = stock.get(item, 0) + n
    elif choice == "2":
        item = input("Товар: ")
        n = int(input("Количество: "))
        if item not in stock:
            print("Такого товара нет")
        elif stock[item] < n:
            print("Недостаточно остатка! На складе:", stock[item])
        else:
            stock[item] -= n
            if stock[item] == 0:
                del stock[item]
                print(item, "закончился")
    elif choice == "3":
        print(stock)
    else:
        print("Неверный выбор")
```

**Задание 10**
```python
text = input("Текст: ").lower()
for mark in ".,!?;:—-":
    text = text.replace(mark, " ")
freq = {}
best_word = ""
best_count = 0
for word in text.split():
    freq[word] = freq.get(word, 0) + 1
    if freq[word] > best_count:
        best_count = freq[word]
        best_word = word
print(best_word, best_count)
```
Примечание: в этом решении при равенстве выбирается слово, которое первым достигло этого количества — с учениками можно обсудить разницу между «встретилось первым» и «первым достигло количества» (после 49-го урока задача точно решается с помощью цикла по словарю).
