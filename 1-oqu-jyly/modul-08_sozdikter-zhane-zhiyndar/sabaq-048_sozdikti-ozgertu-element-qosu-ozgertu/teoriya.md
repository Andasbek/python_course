## 1. Сөздік — өзгермелі тип

Тізім сияқты, сөздік те **өзгермелі (mutable)**: оны құрғаннан кейін жұп қосуға, мәнді өзгертуге, жоюға болады. Бұл жолдан (str) басты айырмашылық.

## 2. Элемент қосу және өзгерту

Бір ғана синтаксис екі жұмыс істейді:

```
d[кілт] = мән
```

- кілт **жоқ** болса — жаңа жұп **қосылады**;
- кілт **бар** болса — мәні **ауыстырылады**.

```python
menu = {"палау": 900, "лағман": 850}
menu["бауырсақ"] = 150      # қосу
menu["палау"] = 950         # өзгерту
print(menu)
print(len(menu))
```

Нәтижесі:
```text
{'палау': 950, 'лағман': 850, 'бауырсақ': 150}
3
```

### Мәнді ескі мәні арқылы өзгерту

```python
balance = {"Арман": 2000, "Сәуле": 3500}
balance["Арман"] += 500        # 500 теңге қосылды
balance["Сәуле"] -= 1200       # асханада түскі ас алды
print(balance)
```

Нәтижесі:
```text
{'Арман': 2500, 'Сәуле': 2300}
```

**Абай болыңыз:** `+=` тек бар кілтке жұмыс істейді. Жоқ кілтке `d["жаңа"] += 1` → `KeyError`.

### Сөздікті біртіндеп толтыру

Көп жағдайда сөздік бос күйден басталып, цикл ішінде толтырылады:

```python
phonebook = {}
names = ["Айгерім", "Бекзат", "Дана"]
numbers = ["87011112233", "87772223344", "87053334455"]
for i in range(len(names)):
    phonebook[names[i]] = numbers[i]
print(phonebook)
```

Нәтижесі:
```text
{'Айгерім': '87011112233', 'Бекзат': '87772223344', 'Дана': '87053334455'}
```

Пайдаланушыдан толтыру (мысал, `input()`-пен жұмыс істейді):

```python
grades = {}
for i in range(3):
    name = input("Оқушы аты: ")
    grade = int(input("Бағасы: "))
    grades[name] = grade
print(grades)
```

### update() — бірнеше жұпты бірден

```python
menu = {"палау": 950, "лағман": 850}
menu.update({"манты": 800, "лағман": 900})   # біреуі жаңа, біреуі өзгереді
print(menu)
```

Нәтижесі:
```text
{'палау': 950, 'лағман': 900, 'манты': 800}
```

### setdefault() — тек жоқ болса қосу

```python
settings = {"тіл": "қазақша"}
settings.setdefault("тіл", "орысша")       # бар — өзгермейді
settings.setdefault("тақырып", "қараңғы")  # жоқ — қосылады
print(settings)
```

Нәтижесі:
```text
{'тіл': 'қазақша', 'тақырып': 'қараңғы'}
```

## 3. Элементтерді жою

| Тәсіл | Не істейді | Кілт жоқ болса |
|---|---|---|
| `del d[k]` | `k` жұбын жояды | `KeyError` |
| `d.pop(k)` | жояды және **мәнін қайтарады** | `KeyError` |
| `d.pop(k, x)` | жояды, мәнін қайтарады | `x` қайтарады, қате жоқ |
| `d.popitem()` | **соңғы қосылған** жұпты жояды, `(кілт, мән)` қайтарады | бос сөздікте `KeyError` |
| `d.clear()` | сөздікті толығымен тазалайды | — |

```python
menu = {"палау": 950, "лағман": 900, "манты": 800, "бауырсақ": 150, "шай": 100}

del menu["лағман"]
print(menu)

price = menu.pop("манты")
print("Манты жойылды, бағасы еді:", price)

print(menu.pop("бешбармақ", "жоқ тағам"))

last = menu.popitem()
print("Соңғы жойылған:", last)
print(menu)

menu.clear()
print(menu, len(menu))
```

Нәтижесі:
```text
{'палау': 950, 'манты': 800, 'бауырсақ': 150, 'шай': 100}
Манты жойылды, бағасы еді: 800
жоқ тағам
Соңғы жойылған: ('шай', 100)
{'палау': 950, 'бауырсақ': 150}
{} 0
```

### Қауіпсіз жою

```python
cart = {"нан": 2, "сүт": 1}
item = "ірімшік"
if item in cart:
    del cart[item]
    print(item, "жойылды")
else:
    print(item, "себетте жоқ")
```

Нәтижесі:
```text
ірімшік себетте жоқ
```

## 4. Кілтті «қайта атау»

Сөздікте кілтті тікелей өзгертуге болмайды. Ескі жұпты жойып, жаңа кілтпен қосамыз:

```python
student = {"атыжөні": "Дана Сейітова", "сынып": 8}
student["аты"] = student.pop("атыжөні")
print(student)
```

Нәтижесі:
```text
{'сынып': 8, 'аты': 'Дана Сейітова'}
```

## 5. Санауыш-сөздік: ең маңызды үлгі

Әріптер жиілігін табу үшін бүкіл әліппе бойынша `count()` шақырудың қажеті жоқ — сөздікпен бұл әлдеқайда жеңіл әрі жылдам (мәтін бір рет қана қаралады):

```python
text = "мама мен папа"
freq = {}
for ch in text:
    if ch != " ":
        freq[ch] = freq.get(ch, 0) + 1
print(freq)
```

Нәтижесі:
```text
{'м': 3, 'а': 4, 'е': 1, 'н': 1, 'п': 2}
```

Қалай жұмыс істейді: `freq.get(ch, 0)` — әріп бұрын кездессе, ескі санын, кездеспесе 0 береді; оған 1 қосып, сақтаймыз.

Баламасы (`if` арқылы):

```python
votes = ["Алма", "Банан", "Алма", "Алма", "Банан", "Өрік"]
result = {}
for v in votes:
    if v in result:
        result[v] += 1
    else:
        result[v] = 1
print(result)
```

Нәтижесі:
```text
{'Алма': 3, 'Банан': 2, 'Өрік': 1}
```

Бұл үлгі дауыстарды, сөздерді, сатылымдарды және т.б. санауға қолданылады.

## 6. Көшірме мен сілтеме

```python
original = {"а": 1}
link = original          # бұл көшірме ЕМЕС, сол сөздікке екінші атау
copy = original.copy()   # нағыз көшірме
link["б"] = 2
print(original)
print(copy)
```

Нәтижесі:
```text
{'а': 1, 'б': 2}
{'а': 1}
```

Тізімдегідей: `=` жаңа сөздік жасамайды. Бөлек көшірме керек болса — `copy()`.

## Жиі кездесетін қателер

**1. Жоқ кілтке += қолдану**

```python
count = {}
# count["а"] += 1                    # KeyError
count["а"] = count.get("а", 0) + 1
print(count)
```

**2. Жою кезінде кілт жоқ болуы**

```python
d = {"x": 1}
# del d["y"]           # KeyError
d.pop("y", None)       # қатесіз
print(d)
```

**3. Тізім әдістерін сөздікке қолдану**

```python
d = {"нан": 250}
# d.append("сүт")      # AttributeError: сөздікте append жоқ
d["сүт"] = 520
print(d)
```

**4. Регистр мен бос орындарды ескермеу**

```python
d = {"нан": 250}
key = "  Нан ".strip().lower()
print(d.get(key))      # 250
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Өзгермелі тип (mutable) | құрылғаннан кейін өзгертуге болатын объект (list, dict) |
| `d[k] = v` | жаңа жұп қосу немесе бар мәнді өзгерту |
| `update()` | басқа сөздіктің жұптарын қосу/жаңарту |
| `del d[k]` | жұпты жою |
| `pop(k)` | жою және мәнін қайтару |
| `popitem()` | соңғы жұпты жою және қайтару |
| `clear()` | сөздікті тазалау |
| Санауыш-сөздік | `d[k] = d.get(k, 0) + 1` — жиілікті санау үлгісі |

## Ескерту

- Сөздікті `for` циклімен аралап жүргенде оған кілт қосуға немесе жоюға болмайды — `RuntimeError` шығады. Алдымен кілттердің көшірмесін алыңыз: `for k in list(d):`.
- `copy()` — «таяз» көшірме: егер мәндер тізім немесе сөздік болса, олар ортақ болып қалады. Толық тәуелсіз көшірме үшін `copy.deepcopy()` қолданылады.
- Python 3.9-дан бастап сөздіктерді біріктіру операторлары бар: `d1 | d2` жаңа сөздік береді, `d1 |= d2` — `update()` сияқты.
- Санауға арналған дайын құрылымдар: `collections.Counter` және `collections.defaultdict(int)` — `d[k] += 1` жазбасын `KeyError`-сыз қолдануға мүмкіндік береді.
- `popitem()` Python 3.7-ден бастап әрқашан соңғы қосылған жұпты жояды (LIFO); ертерек нұсқаларда кездейсоқ жұпты жоюы мүмкін еді.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#dict
