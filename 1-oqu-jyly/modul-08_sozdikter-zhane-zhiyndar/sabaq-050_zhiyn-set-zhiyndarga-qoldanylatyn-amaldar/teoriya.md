## 1. Жиын дегеніміз не?

**Жиын (множество, set)** — **қайталанбайтын** элементтердің **ретсіз** жиынтығы.

Негізгі қасиеттері:
1. **Қайталанбайды** — бір элемент тек бір рет кездеседі.
2. **Ретсіз** — индекс жоқ, `s[0]` жазуға болмайды; шығару реті кез келген болуы мүмкін.
3. **Өзгермелі** — элемент қосуға, жоюға болады.
4. Элементтері тек **өзгермейтін** типтерде болады (сан, жол, кортеж) — сөздік кілттері сияқты.

Аналогия: мектеп кітапханасының оқырмандар тізімі — бір оқушы 10 кітап алса да, оқырман ретінде бір рет тіркеледі.

## 2. Жиын құру

```python
colors = {"қызыл", "жасыл", "көк", "қызыл"}
print(colors)
print(len(colors))

numbers = set([1, 2, 2, 3, 3, 3])
print(numbers)

letters = set("алматы")
print(sorted(letters))

empty = set()          # бос жиын
print(type(empty), type({}))
```

Нәтижесі (жиын элементтерінің реті әр іске қосуда өзгеше болуы мүмкін):
```text
{'көк', 'қызыл', 'жасыл'}
3
{1, 2, 3}
['а', 'л', 'м', 'т', 'ы']
<class 'set'> <class 'dict'>
```

**Маңызды:** `{}` — бос **сөздік**, бос жиын тек `set()` арқылы құрылады.

## 3. Қайталанатын элементтерді жою

Жиынның ең танымал қолданылуы:

```python
visitors = ["Айгерім", "Бекзат", "Айгерім", "Дана", "Бекзат", "Айгерім"]
unique = set(visitors)
print("Барлық келу:", len(visitors))
print("Әр түрлі адам:", len(unique))
print(sorted(unique))
```

Нәтижесі:
```text
Барлық келу: 6
Әр түрлі адам: 3
['Айгерім', 'Бекзат', 'Дана']
```

Мәтіндегі әр түрлі сөздер саны:

```python
text = "бала бала балапан бала ойнайды"
print(len(set(text.split())))
```

Нәтижесі:
```text
3
```

## 4. Жиынның әдістері

| Әдіс | Не істейді | Элемент жоқ болса |
|---|---|---|
| `s.add(x)` | `x` қосады (бар болса — ештеңе болмайды) | — |
| `s.remove(x)` | `x` жояды | `KeyError` |
| `s.discard(x)` | `x` жояды | қате жоқ |
| `s.pop()` | кез келген бір элементті жояды және қайтарады | бос жиында `KeyError` |
| `s.clear()` | жиынды тазалайды | — |
| `s.update(t)` | `t` элементтерін қосады | — |
| `x in s` | `x` бар ма? (өте жылдам) | — |

```python
club = {"Айгерім", "Бекзат"}
club.add("Дана")
club.add("Айгерім")          # бар — өзгеріс жоқ
print(sorted(club))

club.remove("Бекзат")
club.discard("Тимур")        # жоқ, бірақ қате жоқ
print(sorted(club))

club.update(["Ерлан", "Жансая"])
print(len(club), "Ерлан" in club)
```

Нәтижесі:
```text
['Айгерім', 'Бекзат', 'Дана']
['Айгерім', 'Дана']
4 True
```

Жиын бойынша цикл (ретсіз болғандықтан, көбіне `sorted()` арқылы):

```python
for name in sorted({"Дана", "Айгерім", "Ерлан"}):
    print(name)
```

Нәтижесі:
```text
Айгерім
Дана
Ерлан
```

## 5. Жиындарға қолданылатын амалдар

Мысал жиындар:

```
A = Python үйірмесі     = {Айгерім, Бекзат, Дана, Ерлан}
B = Робототехника       = {Дана, Ерлан, Жансая, Тимур}
```

Эйлер–Венн диаграммасы:

```
        A                     B
   ┌─────────────┬─────┬─────────────┐
   │  Айгерім    │Дана │  Жансая     │
   │  Бекзат     │Ерлан│  Тимур      │
   └─────────────┴─────┴─────────────┘
      тек A        A∩B     тек B
```

| Амал | Белгі | Әдіс | Мағынасы |
|---|---|---|---|
| Бірігу | `A \| B` | `A.union(B)` | екеуіндегі барлық элементтер |
| Қиылысу | `A & B` | `A.intersection(B)` | екеуіне де ортақ |
| Айырма | `A - B` | `A.difference(B)` | A-да бар, B-да жоқ |
| Симметриялық айырма | `A ^ B` | `A.symmetric_difference(B)` | тек біреуінде ғана бар |

```python
python_club = {"Айгерім", "Бекзат", "Дана", "Ерлан"}
robot_club = {"Дана", "Ерлан", "Жансая", "Тимур"}

print("Барлығы:", sorted(python_club | robot_club))
print("Екеуіне де:", sorted(python_club & robot_club))
print("Тек Python:", sorted(python_club - robot_club))
print("Тек робототехника:", sorted(robot_club - python_club))
print("Тек біреуіне:", sorted(python_club ^ robot_club))
```

Нәтижесі:
```text
Барлығы: ['Айгерім', 'Бекзат', 'Дана', 'Ерлан', 'Жансая', 'Тимур']
Екеуіне де: ['Дана', 'Ерлан']
Тек Python: ['Айгерім', 'Бекзат']
Тек робототехника: ['Жансая', 'Тимур']
Тек біреуіне: ['Айгерім', 'Бекзат', 'Жансая', 'Тимур']
```

**Ескерту:** `A - B` және `B - A` — әр түрлі нәтиже береді!

## 6. Жиындарды салыстыру

| Өрнек | Мағынасы |
|---|---|
| `A == B` | элементтері бірдей ме (ретке қарамай) |
| `A <= B` немесе `A.issubset(B)` | A — B-ның ішкі жиыны ма |
| `A >= B` немесе `A.issuperset(B)` | A B-ны толық қамти ма |
| `A.isdisjoint(B)` | ортақ элементтері жоқ па |

```python
required = {"дәптер", "қалам", "сызғыш"}
bag = {"қалам", "дәптер", "сызғыш", "өшіргіш"}
print(required <= bag)
print("Жетіспейді:", sorted(required - {"қалам"}))
print({1, 2} == {2, 1})
print({1, 2}.isdisjoint({3, 4}))
```

Нәтижесі:
```text
True
Жетіспейді: ['дәптер', 'сызғыш']
True
True
```


## 7. Өмірлік мысал: екі сөйлемнің ортақ сөздері

```python
s1 = "мен python тілін үйренемін"
s2 = "досым да python тілін үйренеді"
common = set(s1.split()) & set(s2.split())
print(sorted(common))
```

Нәтижесі:
```text
['python', 'тілін']
```

## 8. Тізім, кортеж, сөздік, жиын — салыстыру

| Қасиет | list | tuple | dict | set |
|---|---|---|---|---|
| Жазылуы | `[1, 2]` | `(1, 2)` | `{"а": 1}` | `{1, 2}` |
| Реттелген, индекс бар | иә | иә | кілт арқылы | жоқ |
| Қайталану | болады | болады | кілттер — жоқ | жоқ |
| Өзгермелі | иә | жоқ | иә | иә |
| Негізгі қолданылуы | элементтер тізбегі | тұрақты мәліметтер | кілт → мән | бірегейлік, жиын амалдары |

## Жиі кездесетін қателер

**1. Бос жиынды {} арқылы құру**

```python
s = {}
print(type(s))      # <class 'dict'> — бұл сөздік!
s = set()
s.add(5)
print(s)
```

**2. Жиынға индекс арқылы қатынау**

```python
s = {10, 20, 30}
# print(s[0])        # TypeError: 'set' object is not subscriptable
print(sorted(s)[0])  # 10
```

**3. Жоқ элементті remove() арқылы жою**

```python
s = {1, 2}
# s.remove(5)        # KeyError
s.discard(5)
print(s)
```

**4. Тізімді жиынға элемент ретінде қосу**

```python
s = set()
# s.add([1, 2])      # TypeError: unhashable type: 'list'
s.add((1, 2))
print(s)
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Жиын (set) | қайталанбайтын, ретсіз элементтер жиынтығы |
| Бірігу `\|` | екі жиынның барлық элементтері |
| Қиылысу `&` | ортақ элементтер |
| Айырма `-` | бірінші жиында бар, екіншісінде жоқ элементтер |
| Симметриялық айырма `^` | тек бір жиында ғана бар элементтер |
| Ішкі жиын `<=` | бір жиынның барлық элементі екіншісінде бар |
| Эйлер–Венн диаграммасы | жиындарды шеңберлермен бейнелеу |

## Ескерту

- `set(lst)` қайталауларды жояды, бірақ элементтердің ретін сақтамайды. Ретті сақтап қайталауларды жою үшін: `list(dict.fromkeys(lst))`.
- `x in s` тексеруі жиында орташа есеппен бірден орындалады (O(1)), ал тізімде барлық элементті қарап шығады (O(n)) — үлкен мәліметте айырмашылық өте үлкен.
- Операторлар (`|`, `&`, `-`, `^`) тек жиындармен жұмыс істейді, ал әдістер (`union()`, `intersection()` т.б.) кез келген итерацияланатын объектіні қабылдайды: `{1, 2}.union([3, 4])`.
- `frozenset` — өзгермейтін жиын; оны сөздік кілті немесе басқа жиынның элементі ретінде қолдануға болады.
- Жиынды шығарғанда элементтердің реті әр іске қосуда өзгеруі мүмкін (әсіресе жолдар үшін), сондықтан тұрақты нәтиже керек болса `sorted()` қолданыңыз.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#set-types-set-frozenset
