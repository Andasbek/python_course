## 1. Что такое множество?

**Множество (set)** — **неупорядоченный** набор **неповторяющихся** элементов.

Основные свойства:
1. **Не повторяются** — каждый элемент встречается только один раз.
2. **Неупорядочено** — индексов нет, писать `s[0]` нельзя; порядок вывода может быть любым.
3. **Изменяемое** — элементы можно добавлять и удалять.
4. Элементы могут быть только **неизменяемых** типов (число, строка, кортеж) — как ключи словаря.

Аналогия: список читателей школьной библиотеки — даже если ученик взял 10 книг, как читатель он зарегистрирован один раз.

## 2. Создание множества

```python
colors = {"красный", "зелёный", "синий", "красный"}
print(colors)
print(len(colors))

numbers = set([1, 2, 2, 3, 3, 3])
print(numbers)

letters = set("алматы")
print(sorted(letters))

empty = set()          # пустое множество
print(type(empty), type({}))
```

Результат (порядок элементов множества может отличаться при каждом запуске):
```text
{'синий', 'красный', 'зелёный'}
3
{1, 2, 3}
['а', 'л', 'м', 'т', 'ы']
<class 'set'> <class 'dict'>
```

**Важно:** `{}` — это пустой **словарь**, пустое множество создаётся только через `set()`.

## 3. Удаление повторяющихся элементов

Самое известное применение множества:

```python
visitors = ["Айгерим", "Бекзат", "Айгерим", "Дана", "Бекзат", "Айгерим"]
unique = set(visitors)
print("Всего посещений:", len(visitors))
print("Разных людей:", len(unique))
print(sorted(unique))
```

Результат:
```text
Всего посещений: 6
Разных людей: 3
['Айгерим', 'Бекзат', 'Дана']
```

Количество разных слов в тексте:

```python
text = "мама мама мамочка мама спит"
print(len(set(text.split())))
```

Результат:
```text
3
```

## 4. Методы множества

| Метод | Что делает | Если элемента нет |
|---|---|---|
| `s.add(x)` | добавляет `x` (если уже есть — ничего не происходит) | — |
| `s.remove(x)` | удаляет `x` | `KeyError` |
| `s.discard(x)` | удаляет `x` | ошибки нет |
| `s.pop()` | удаляет и возвращает произвольный элемент | в пустом множестве `KeyError` |
| `s.clear()` | очищает множество | — |
| `s.update(t)` | добавляет элементы `t` | — |
| `x in s` | есть ли `x`? (очень быстро) | — |

```python
club = {"Айгерим", "Бекзат"}
club.add("Дана")
club.add("Айгерим")          # уже есть — без изменений
print(sorted(club))

club.remove("Бекзат")
club.discard("Тимур")        # нет, но ошибки нет
print(sorted(club))

club.update(["Ерлан", "Жансая"])
print(len(club), "Ерлан" in club)
```

Результат:
```text
['Айгерим', 'Бекзат', 'Дана']
['Айгерим', 'Дана']
4 True
```

Цикл по множеству (так как оно неупорядочено, чаще через `sorted()`):

```python
for name in sorted({"Дана", "Айгерим", "Ерлан"}):
    print(name)
```

Результат:
```text
Айгерим
Дана
Ерлан
```

## 5. Операции над множествами

Примеры множеств:

```
A = Кружок Python       = {Айгерим, Бекзат, Дана, Ерлан}
B = Робототехника       = {Дана, Ерлан, Жансая, Тимур}
```

Диаграмма Эйлера–Венна:

```
        A                     B
   ┌─────────────┬─────┬─────────────┐
   │  Айгерим    │Дана │  Жансая     │
   │  Бекзат     │Ерлан│  Тимур      │
   └─────────────┴─────┴─────────────┘
      только A     A∩B    только B
```

| Операция | Знак | Метод | Значение |
|---|---|---|---|
| Объединение | `A \| B` | `A.union(B)` | все элементы обоих множеств |
| Пересечение | `A & B` | `A.intersection(B)` | общие для обоих |
| Разность | `A - B` | `A.difference(B)` | есть в A, нет в B |
| Симметрическая разность | `A ^ B` | `A.symmetric_difference(B)` | есть только в одном из них |

```python
python_club = {"Айгерим", "Бекзат", "Дана", "Ерлан"}
robot_club = {"Дана", "Ерлан", "Жансая", "Тимур"}

print("Все:", sorted(python_club | robot_club))
print("В обоих:", sorted(python_club & robot_club))
print("Только Python:", sorted(python_club - robot_club))
print("Только робототехника:", sorted(robot_club - python_club))
print("Только в одном:", sorted(python_club ^ robot_club))
```

Результат:
```text
Все: ['Айгерим', 'Бекзат', 'Дана', 'Ерлан', 'Жансая', 'Тимур']
В обоих: ['Дана', 'Ерлан']
Только Python: ['Айгерим', 'Бекзат']
Только робототехника: ['Жансая', 'Тимур']
Только в одном: ['Айгерим', 'Бекзат', 'Жансая', 'Тимур']
```

**Примечание:** `A - B` и `B - A` дают разные результаты!

## 6. Сравнение множеств

| Выражение | Значение |
|---|---|
| `A == B` | одинаковы ли элементы (без учёта порядка) |
| `A <= B` или `A.issubset(B)` | является ли A подмножеством B |
| `A >= B` или `A.issuperset(B)` | содержит ли A множество B полностью |
| `A.isdisjoint(B)` | нет ли общих элементов |

```python
required = {"тетрадь", "ручка", "линейка"}
bag = {"ручка", "тетрадь", "линейка", "ластик"}
print(required <= bag)
print("Не хватает:", sorted(required - {"ручка"}))
print({1, 2} == {2, 1})
print({1, 2}.isdisjoint({3, 4}))
```

Результат:
```text
True
Не хватает: ['линейка', 'тетрадь']
True
True
```


## 7. Пример из жизни: общие слова двух предложений

```python
s1 = "я изучаю язык python"
s2 = "мой друг тоже изучает язык python"
common = set(s1.split()) & set(s2.split())
print(sorted(common))
```

Результат:
```text
['python', 'язык']
```

## 8. Список, кортеж, словарь, множество — сравнение

| Свойство | list | tuple | dict | set |
|---|---|---|---|---|
| Запись | `[1, 2]` | `(1, 2)` | `{"а": 1}` | `{1, 2}` |
| Упорядочен, есть индекс | да | да | по ключу | нет |
| Повторы | возможны | возможны | ключи — нет | нет |
| Изменяемый | да | нет | да | да |
| Основное применение | последовательность элементов | постоянные данные | ключ → значение | уникальность, операции над множествами |

## Частые ошибки

**1. Создание пустого множества через {}**

```python
s = {}
print(type(s))      # <class 'dict'> — это словарь!
s = set()
s.add(5)
print(s)
```

**2. Обращение к множеству по индексу**

```python
s = {10, 20, 30}
# print(s[0])        # TypeError: 'set' object is not subscriptable
print(sorted(s)[0])  # 10
```

**3. Удаление отсутствующего элемента через remove()**

```python
s = {1, 2}
# s.remove(5)        # KeyError
s.discard(5)
print(s)
```

**4. Добавление списка в множество как элемента**

```python
s = set()
# s.add([1, 2])      # TypeError: unhashable type: 'list'
s.add((1, 2))
print(s)
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Множество (set) | неупорядоченный набор неповторяющихся элементов |
| Объединение `\|` | все элементы двух множеств |
| Пересечение `&` | общие элементы |
| Разность `-` | элементы, которые есть в первом множестве и отсутствуют во втором |
| Симметрическая разность `^` | элементы, которые есть только в одном из множеств |
| Подмножество `<=` | все элементы одного множества есть в другом |
| Диаграмма Эйлера–Венна | изображение множеств в виде кругов |

## Примечание

- `set(lst)` удаляет повторы, но не сохраняет порядок элементов. Чтобы удалить повторы с сохранением порядка: `list(dict.fromkeys(lst))`.
- Проверка `x in s` во множестве в среднем выполняется сразу (O(1)), а в списке просматриваются все элементы (O(n)) — на больших данных разница огромна.
- Операторы (`|`, `&`, `-`, `^`) работают только с множествами, а методы (`union()`, `intersection()` и др.) принимают любой итерируемый объект: `{1, 2}.union([3, 4])`.
- `frozenset` — неизменяемое множество; его можно использовать как ключ словаря или элемент другого множества.
- Порядок элементов при выводе множества может меняться от запуска к запуску (особенно для строк), поэтому для стабильного результата используйте `sorted()`.
- Документация: https://docs.python.org/3/library/stdtypes.html#set-types-set-frozenset
