# Сабақ 50. Практикалық тапсырмалар: жиындар

## Базалық деңгей

### 1-тапсырма. Әр түрлі сандар
Бір жолға бос орын арқылы бірнеше сан енгізіледі. Неше **әр түрлі** сан енгізілгенін және оларды өсу ретімен шығарыңыз.

Мысал:
```text
Сандар: 5 3 5 1 3 5 7
Әр түрлі сандар саны: 4
1 3 5 7
```

### 2-тапсырма. Әр түрлі әріптер
Сөз енгізіледі. Онда неше әр түрлі әріп бар? Әріптерді әліппе бойынша шығарыңыз. Барлық әріптері әр түрлі болса, «Барлық әріп қайталанбайды!» деп жазыңыз.

Мысал: `Қарағанды` → 7 әр түрлі әріп (регистрді ескермей: `қ, а, р, ғ, н, д, ы`).

### 3-тапсырма. Үйірмелер
```python
python_club = {"Айгерім", "Бекзат", "Дана", "Ерлан", "Мадина"}
chess_club = {"Дана", "Тимур", "Мадина", "Нұрлан"}
```
Шығарыңыз: екі үйірмеге де баратындар; тек Python-ға баратындар; кемінде бір үйірмеге баратындардың жалпы саны.

### 4-тапсырма. Үй тапсырмасын кім тапсырмады?
```python
class_list = {"Айгерім", "Бекзат", "Дана", "Ерлан", "Жансая", "Тимур"}
submitted = ["Дана", "Айгерім", "Тимур", "Дана"]
```
Тапсырмағандарды әліппе бойынша шығарыңыз.

### 5-тапсырма. Келушілер есебі
Пайдаланушы кітапханаға келушілердің аттарын бір-бірден енгізеді (`бітті` деп жазғанша). Бір адам бірнеше рет келуі мүмкін. Соңында барлық келу саны мен әр түрлі келушілер санын шығарыңыз.

## Кеңейтілген деңгей

### 6-тапсырма. Ортақ сөздер
Екі сөйлем енгізіледі. Тыныс белгілерін алып тастап, кіші әріпке айналдырып:
- екеуіне ортақ сөздерді;
- тек бірінші сөйлемде бар сөздерді;
- екі сөйлемдегі барлық әр түрлі сөздер санын шығарыңыз.

### 7-тапсырма. Панграмма
Ағылшынша сөйлем барлық 26 латын әрпін қамти ма? (Мысалы: `The quick brown fox jumps over the lazy dog` — иә.) Жоқ болса, жетіспейтін әріптерді шығарыңыз. Кеңес: `set("abcdefghijklmnopqrstuvwxyz")`.

### 8-тапсырма. Дауысты дыбыстар
Сөз енгізіледі. Онда қазақ тілінің қандай дауысты дыбыстары кездеседі (`set(word) & vowels`), қандайлары кездеспейді?

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Лото
Пайдаланушы 1-ден 36-ға дейінгі 6 әр түрлі сан енгізеді (бір жолға). Ұтыс сандары: `{3, 11, 17, 22, 29, 34}`. Неше сан сәйкес келгенін және қайсылары екенін шығарыңыз. Пайдаланушы бірдей сандар немесе ауқымнан тыс сан енгізсе — қате туралы хабарлаңыз.

### 10-тапсырма. Бірегей бірінші символ
Жолдағы **бірінші** қайталанбайтын символды табыңыз (тек бір рет кездесетін). Мысалы: `алмалы` → `м`, `аабб` → `жоқ`. Кеңес: жиынмен «көрген» символдарды, сөздікпен санын сақтауға болады.

## Үй тапсырмасы

1. Өзіңіздің және досыңыздың сүйікті 5 тағамының жиынын құрыңыз. Ортақ тағамдарды, тек сізге ұнайтындарды шығарыңыз.
2. 1-ден 50-ге дейінгі сандардың ішінен 3-ке бөлінетіндер жиыны мен 5-ке бөлінетіндер жиынын құрып, олардың қиылысын табыңыз. Нәтиже неге 15-ке еселі сандар болды?
3. Келесі сабақта өзіндік жұмыс болады: сөздік пен жиын тақырыптарын қайталаңыз.

**9-тапсырма**
```python
win = {3, 11, 17, 22, 29, 34}
parts = input("6 сан: ").split()
ticket = set()
ok = True
for p in parts:
    n = int(p)
    if n < 1 or n > 36:
        ok = False
    ticket.add(n)
if len(parts) != 6 or len(ticket) != 6 or not ok:
    print("Қате: 1–36 аралығындағы 6 әр түрлі сан енгізіңіз")
else:
    match = ticket & win
    print("Сәйкес келді:", len(match), sorted(match))
```
