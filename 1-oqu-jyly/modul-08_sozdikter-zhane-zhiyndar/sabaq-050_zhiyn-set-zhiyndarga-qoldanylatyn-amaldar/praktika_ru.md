# Урок 50. Практические задания: множества

## Базовый уровень

### Задание 1. Разные числа
В одну строку через пробел вводится несколько чисел. Выведите, сколько **разных** чисел введено, и сами эти числа в порядке возрастания.

Пример:
```text
Числа: 5 3 5 1 3 5 7
Количество разных чисел: 4
1 3 5 7
```

### Задание 2. Разные буквы
Вводится слово. Сколько в нём разных букв? Выведите буквы в алфавитном порядке. Если все буквы разные, напишите «Ни одна буква не повторяется!».

Пример: `Караганда` → 6 разных букв (без учёта регистра: `к, а, р, г, н, д`).

### Задание 3. Кружки
```python
python_club = {"Айгерим", "Бекзат", "Дана", "Ерлан", "Мадина"}
chess_club = {"Дана", "Тимур", "Мадина", "Нурлан"}
```
Выведите: тех, кто ходит в оба кружка; тех, кто ходит только в Python; общее количество тех, кто ходит хотя бы в один кружок.

### Задание 4. Кто не сдал домашнее задание?
```python
class_list = {"Айгерим", "Бекзат", "Дана", "Ерлан", "Жансая", "Тимур"}
submitted = ["Дана", "Айгерим", "Тимур", "Дана"]
```
Выведите не сдавших в алфавитном порядке.

### Задание 5. Учёт посетителей
Пользователь по одному вводит имена посетителей библиотеки (пока не напишет `готово`). Один человек может прийти несколько раз. В конце выведите общее количество посещений и количество разных посетителей.

## Продвинутый уровень

### Задание 6. Общие слова
Вводятся два предложения. Удалив знаки препинания и переведя в строчные буквы, выведите:
- слова, общие для обоих;
- слова, которые есть только в первом предложении;
- общее количество разных слов в двух предложениях.

### Задание 7. Панграмма
Содержит ли предложение на английском все 26 латинских букв? (Например: `The quick brown fox jumps over the lazy dog` — да.) Если нет, выведите недостающие буквы. Подсказка: `set("abcdefghijklmnopqrstuvwxyz")`.

### Задание 8. Гласные
Вводится слово. Какие гласные русского языка в нём встречаются (`set(word) & vowels`), а какие — нет?

## ★ Олимпиадная / творческая задача

### Задание 9. Лото
Пользователь вводит 6 разных чисел от 1 до 36 (в одну строку). Выигрышные числа: `{3, 11, 17, 22, 29, 34}`. Выведите, сколько чисел совпало и какие именно. Если пользователь ввёл одинаковые числа или число вне диапазона — сообщите об ошибке.

### Задание 10. Первый уникальный символ
Найдите **первый** неповторяющийся символ строки (встречающийся только один раз). Например: `банан` → `б`, `аабб` → `нет`. Подсказка: «увиденные» символы можно хранить во множестве, а их количество — в словаре.

1. Составьте множества из 5 любимых блюд — своих и друга. Выведите общие блюда и те, что нравятся только вам.

3. На следующем уроке будет самостоятельная работа: повторите темы «Словарь» и «Множество».

**Задание 9**
```python
win = {3, 11, 17, 22, 29, 34}
parts = input("6 чисел: ").split()
ticket = set()
ok = True
for p in parts:
    n = int(p)
    if n < 1 or n > 36:
        ok = False
    ticket.add(n)
if len(parts) != 6 or len(ticket) != 6 or not ok:
    print("Ошибка: введите 6 разных чисел от 1 до 36")
else:
    match = ticket & win
    print("Совпало:", len(match), sorted(match))
```
