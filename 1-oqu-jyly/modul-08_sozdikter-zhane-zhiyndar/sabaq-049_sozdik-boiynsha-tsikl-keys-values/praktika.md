# Сабақ 49. Практикалық тапсырмалар: сөздік бойынша цикл

## Базалық деңгей

### 1-тапсырма. Қалалар және халық
```python
cities = {"Алматы": 2200, "Астана": 1400, "Шымкент": 1200, "Ақтөбе": 600, "Қарағанды": 500}
```
(мың адам). `items()` арқылы әр қаланы `Алматы — 2200 мың адам` түрінде шығарыңыз. Соңында барлық қалалардың жалпы халық санын шығарыңыз.

### 2-тапсырма. Үздік оқушы
```python
scores = {"Әлихан": 87, "Нұрай": 95, "Тимур": 78, "Жансая": 91, "Ернұр": 66}
```
Ең жоғары және ең төмен ұпай жинаған оқушылардың аттарын, сондай-ақ орташа ұпайды шығарыңыз.

### 3-тапсырма. Сүзгі
Сол `scores` сөздігінен 80 ұпайдан жоғары жинағандарды жаңа сөздікке жинап шығарыңыз және олардың санын көрсетіңіз.

### 4-тапсырма. Әліппе бойынша
```python
phonebook = {"Дана": "87053334455", "Айгерім": "87011112233", "Ерлан": "87475556677", "Бекзат": "87772223344"}
```
Контактілерді есім бойынша әліппе ретімен нөмірлеп шығарыңыз:
```text
1. Айгерім: 87011112233
2. Бекзат: 87772223344
...
```

### 5-тапсырма. Чек
```python
cart = {"нан": (250, 2), "сүт": (520, 1), "алма": (450, 3)}   # тауар: (бағасы, саны)
```
Кесте түрінде чек шығарыңыз: тауар, бағасы, саны, сомасы; соңында жалпы сома.

## Кеңейтілген деңгей

### 6-тапсырма. Рейтинг
Мәтін енгізіледі. Сөздер жиілігінің сөздігін құрып, ең жиі кездесетін 3 сөзді (мәндер бойынша сұрыптап) шығарыңыз.

### 7-тапсырма. Кері сөздік
`eng_kaz = {"apple": "алма", "cat": "мысық", "book": "кітап", "sun": "күн"}` сөздігінен кері сөздік (`kaz_eng`) құрыңыз: мәндер — кілт, кілттер — мән. Кейін пайдаланушы енгізген қазақша сөздің аудармасын шығарыңыз.

### 8-тапсырма. Сынып журналы
```python
journal = {
    "Айгерім": [5, 5, 4, 5],
    "Бекзат": [4, 3, 3, 4],
    "Дана": [5, 4, 5, 5],
    "Ерлан": [3, 3, 2, 4],
}
```
Әр оқушының орташа бағасын (2 ондық белгі) есептеп шығарыңыз; орташасы 4.5-тен жоғары оқушыларды «үздік», 3.0-ден төмендерді «назар аудару керек» деп белгілеңіз. Соңында сыныптың жалпы орташасын шығарыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Топтастыру
Сөздер тізімі берілген: `["алма", "анар", "банан", "бал", "алмұрт", "қияр", "қарбыз"]`. Бірінші әрпі бойынша топтастырыңыз: кілт — әріп, мән — сөздер тізімі. Нәтижені әліппе бойынша шығарыңыз.
```text
а: алма, анар, алмұрт
б: банан, бал
қ: қияр, қарбыз
```

### 10-тапсырма. Гистограмма
Әріптер жиілігінің сөздігі бойынша мәтіндік гистограмма салыңыз (әр әріп үшін сонша `█` символы), жиілігі бойынша кему ретімен.
```text
а ████████
л ████
...
```

2. 47-сабақта құрған қазақша-ағылшынша сөздігіңізді әліппе бойынша кесте түрінде шығаратын бағдарлама жазыңыз.

**2-тапсырма**
```python
scores = {"Әлихан": 87, "Нұрай": 95, "Тимур": 78, "Жансая": 91, "Ернұр": 66}
best = ""
worst = ""
for name, s in scores.items():
    if best == "" or s > scores[best]:
        best = name
    if worst == "" or s < scores[worst]:
        worst = name
print("Ең жоғары:", best, scores[best])
print("Ең төмен:", worst, scores[worst])
print("Орташа:", sum(scores.values()) / len(scores))
```
Нәтижесі:
```text
Ең жоғары: Нұрай 95
Ең төмен: Ернұр 66
Орташа: 83.4
```

**8-тапсырма**
```python
journal = {
    "Айгерім": [5, 5, 4, 5],
    "Бекзат": [4, 3, 3, 4],
    "Дана": [5, 4, 5, 5],
    "Ерлан": [3, 3, 2, 4],
}
all_marks = []
for name, marks in journal.items():
    avg = sum(marks) / len(marks)
    note = ""
    if avg > 4.5:
        note = " — үздік"
    elif avg < 3.0:
        note = " — назар аудару керек"
    print(f"{name}: {avg:.2f}{note}")
    all_marks += marks
print(f"Сынып орташасы: {sum(all_marks) / len(all_marks):.2f}")
```

words = ["алма", "анар", "банан", "бал", "алмұрт", "қияр", "қарбыз"]
groups = {}
for w in words:
    first = w[0]
    if first not in groups:
        groups[first] = []
    groups[first].append(w)
for letter in sorted(groups):
    print(f"{letter}: {', '.join(groups[letter])}")
