## 1. Цикл for по словарю

При переборе словаря циклом `for` переменная получает **ключи**:

```python
capitals = {"Казахстан": "Астана", "Кыргызстан": "Бишкек", "Узбекистан": "Ташкент"}
for country in capitals:
    print(country, "→", capitals[country])
```

Результат:
```text
Казахстан → Астана
Кыргызстан → Бишкек
Узбекистан → Ташкент
```

Ключи выводятся **в порядке добавления**.

## 2. Три метода: keys(), values(), items()

| Метод | Что возвращает | Пример результата |
|---|---|---|
| `d.keys()` | все ключи | `dict_keys(['а', 'б'])` |
| `d.values()` | все значения | `dict_values([1, 2])` |
| `d.items()` | пары (ключ, значение) | `dict_items([('а', 1), ('б', 2)])` |

Аналогия: словарь — классный журнал. `keys()` — столбец с именами учеников, `values()` — столбец с оценками, `items()` — полные строки журнала.

```python
grades = {"Айгерим": 5, "Бекзат": 4, "Дана": 5, "Ерлан": 3}
print(grades.keys())
print(grades.values())
print(grades.items())
print(list(grades.keys()))
```

Результат:
```text
dict_keys(['Айгерим', 'Бекзат', 'Дана', 'Ерлан'])
dict_values([5, 4, 5, 3])
dict_items([('Айгерим', 5), ('Бекзат', 4), ('Дана', 5), ('Ерлан', 3)])
['Айгерим', 'Бекзат', 'Дана', 'Ерлан']
```

Эти объекты можно превратить в список через `list()` и применять к ним `for`, `in`, `len()`, `sum()`, `max()` и т.д.

### keys()

```python
grades = {"Айгерим": 5, "Бекзат": 4, "Дана": 5}
for name in grades.keys():      # for name in grades: — то же самое
    print(name)
```

Результат:
```text
Айгерим
Бекзат
Дана
```

### values()

Когда нужны только значения — например, сумма или среднее:

```python
grades = {"Айгерим": 5, "Бекзат": 4, "Дана": 5, "Ерлан": 3}
print("Сумма:", sum(grades.values()))
print("Среднее:", sum(grades.values()) / len(grades))
print("Наивысшая:", max(grades.values()))
print("Есть ли оценка 5?", 5 in grades.values())

count5 = 0
for g in grades.values():
    if g == 5:
        count5 += 1
print("Отличников:", count5)
```

Результат:
```text
Сумма: 17
Среднее: 4.25
Наивысшая: 5
Есть ли оценка 5? True
Отличников: 2
```

### items() — самый часто используемый

`items()` на каждом шаге даёт кортеж `(ключ, значение)`. Сразу «распаковываем» его в две переменные:

```python
prices = {"хлеб": 250, "молоко": 520, "сыр": 2400}
for item, price in prices.items():
    print(f"{item}: {price} тенге")
```

Результат:
```text
хлеб: 250 тенге
молоко: 520 тенге
сыр: 2400 тенге
```

## 3. Типовые алгоритмы

### Поиск ключа с максимальным значением

`max(d.values())` даёт наибольшее значение, но мы не знаем, **чьё** оно. Поэтому — цикл:

```python
scores = {"Алихан": 87, "Нурай": 95, "Тимур": 78, "Жансая": 91}
best_name = ""
best_score = -1
for name, score in scores.items():
    if score > best_score:
        best_score = score
        best_name = name
print(f"Победитель: {best_name} ({best_score} баллов)")
```

Результат:
```text
Победитель: Нурай (95 баллов)
```

### Фильтрация по условию

```python
scores = {"Алихан": 87, "Нурай": 95, "Тимур": 78, "Жансая": 91}
print("Выше 90:")
for name, score in scores.items():
    if score >= 90:
        print("-", name)

passed = {}
for name, score in scores.items():
    if score >= 80:
        passed[name] = score
print(passed)
```

Результат:
```text
Выше 90:
- Нурай
- Жансая
{'Алихан': 87, 'Нурай': 95, 'Жансая': 91}
```

### Поиск по значению (обратный поиск)

```python
capitals = {"Казахстан": "Астана", "Япония": "Токио", "Франция": "Париж"}
city = "Токио"
for country, capital in capitals.items():
    if capital == city:
        print(city, "— столица страны", country)
```

Результат:
```text
Токио — столица страны Япония
```

### Изменение всех значений

```python
prices = {"хлеб": 250, "молоко": 520, "сыр": 2400}
for item in prices:
    prices[item] = round(prices[item] * 1.1)   # подорожание на 10%
print(prices)
```

Результат:
```text
{'хлеб': 275, 'молоко': 572, 'сыр': 2640}
```

**Правило:** во время цикла можно изменять значения, но **добавлять** новые ключи в словарь или **удалять** их нельзя (`RuntimeError`). Если нужно удаление — перебираем копию ключей: `for k in list(d.keys()):`.

```python
stock = {"тетрадь": 0, "ручка": 15, "ластик": 0}
for item in list(stock.keys()):
    if stock[item] == 0:
        del stock[item]
print(stock)
```

Результат:
```text
{'ручка': 15}
```

## 4. Сортировка

### По ключам

`sorted(d)` даёт отсортированный **список ключей**:

```python
grades = {"Дана": 5, "Айгерим": 4, "Ерлан": 3, "Бекзат": 5}
for name in sorted(grades):
    print(name, grades[name])
```

Результат:
```text
Айгерим 4
Бекзат 5
Дана 5
Ерлан 3
```

### По значениям

Собираем пары в список в порядке `(значение, ключ)` и сортируем — кортежи сравниваются по первому элементу:

```python
scores = {"Алихан": 87, "Нурай": 95, "Тимур": 78, "Жансая": 91}
pairs = []
for name, score in scores.items():
    pairs.append((score, name))
pairs.sort(reverse=True)
place = 1
for score, name in pairs:
    print(f"{place}. {name} — {score}")
    place += 1
```

Результат:
```text
1. Нурай — 95
2. Жансая — 91
3. Алихан — 87
4. Тимур — 78
```

## 5. Красивый вывод в виде таблицы

С помощью ширины в f-строке (`:<12` — выравнивание влево, `:>6` — выравнивание вправо):

```python
prices = {"хлеб": 250, "молоко": 520, "сыр": 2400, "чай": 1300}
print(f"{'Товар':<10}{'Цена':>8}")
print("-" * 18)
for item, price in prices.items():
    print(f"{item:<10}{price:>8}")
print("-" * 18)
print(f"{'Итого':<10}{sum(prices.values()):>8}")
```

Результат:
```text
Товар         Цена
------------------
хлеб           250
молоко         520
сыр           2400
чай           1300
------------------
Итого         4470
```

## 6. Если значение — список или словарь

```python
journal = {
    "Айгерим": [5, 5, 4],
    "Бекзат": [4, 3, 5, 4],
    "Дана": [5, 5, 5],
}
for name, marks in journal.items():
    avg = sum(marks) / len(marks)
    print(f"{name}: {marks}, среднее {avg:.2f}")
```

Результат:
```text
Айгерим: [5, 5, 4], среднее 4.67
Бекзат: [4, 3, 5, 4], среднее 4.00
Дана: [5, 5, 5], среднее 5.00
```

Словарь внутри словаря:

```python
students = {
    "Айгерим": {"класс": 8, "город": "Алматы"},
    "Бекзат": {"класс": 7, "город": "Конаев"},
}
for name, info in students.items():
    print(f"{name}: {info['класс']} класс, {info['город']}")
```

Результат:
```text
Айгерим: 8 класс, Алматы
Бекзат: 7 класс, Конаев
```

## Частые ошибки

**1. Получение двух переменных без items()**

```python
d = {"а": 1, "б": 2}
# for k, v in d:           # ValueError — ключ это одна строка
for k, v in d.items():
    print(k, v)
```

**2. Перебор values() и поиск ключа**

```python
d = {"Нурай": 95}
for v in d.values():
    print(v)               # ключ недоступен — нужен items()
```

**3. Удаление из словаря во время цикла**

```python
d = {"а": 0, "б": 1}
# for k in d:
#     if d[k] == 0:
#         del d[k]         # RuntimeError: dictionary changed size during iteration
for k in list(d):
    if d[k] == 0:
        del d[k]
print(d)
```

**4. Думают, что sorted(d) возвращает словарь**

```python
d = {"б": 2, "а": 1}
print(sorted(d))          # ['а', 'б'] — это список ключей
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| `for k in d` | цикл по ключам словаря |
| `keys()` | все ключи |
| `values()` | все значения |
| `items()` | все пары (ключ, значение) |
| Распаковка кортежа | `for k, v in d.items()` — разделение пары на две переменные |
| Фильтрация | выбор пар, удовлетворяющих условию |
| `sorted(d)` | отсортированный список ключей |

## Примечание

- `keys()`, `values()`, `items()` возвращают не списки, а «представления» (view) словаря: если словарь изменится, представление изменится вместе с ним. Если нужна неизменная копия — `list(d.items())`.
- Ключ с максимальным значением можно найти без цикла: `max(scores, key=scores.get)`.
- Короткая запись сортировки по значениям: `sorted(scores.items(), key=lambda p: p[1], reverse=True)` — результат: список пар `(ключ, значение)`.
- Из отсортированных пар можно снова собрать словарь: `dict(sorted(d.items()))` — в Python 3.7+ порядок сохранится.
- Вместо ручного подсчёта места удобнее `enumerate(pairs, start=1)`.
- Документация: https://docs.python.org/3/library/stdtypes.html#dictionary-view-objects
