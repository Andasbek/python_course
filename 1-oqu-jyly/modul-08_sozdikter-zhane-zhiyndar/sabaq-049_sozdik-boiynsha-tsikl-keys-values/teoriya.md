## 1. for циклі сөздік бойынша

Сөздікті `for` циклімен аралағанда, айнымалыға **кілттер** беріледі:

```python
capitals = {"Қазақстан": "Астана", "Қырғызстан": "Бішкек", "Өзбекстан": "Ташкент"}
for country in capitals:
    print(country, "→", capitals[country])
```

Нәтижесі:
```text
Қазақстан → Астана
Қырғызстан → Бішкек
Өзбекстан → Ташкент
```

Кілттер **қосылған ретімен** шығады.

## 2. Үш әдіс: keys(), values(), items()

| Әдіс | Не қайтарады | Мысал нәтиже |
|---|---|---|
| `d.keys()` | барлық кілттер | `dict_keys(['а', 'б'])` |
| `d.values()` | барлық мәндер | `dict_values([1, 2])` |
| `d.items()` | (кілт, мән) жұптары | `dict_items([('а', 1), ('б', 2)])` |

Аналогия: сөздік — сынып журналы. `keys()` — оқушылардың аттары бағаны, `values()` — бағалар бағаны, `items()` — журналдың толық жолдары.

```python
grades = {"Айгерім": 5, "Бекзат": 4, "Дана": 5, "Ерлан": 3}
print(grades.keys())
print(grades.values())
print(grades.items())
print(list(grades.keys()))
```

Нәтижесі:
```text
dict_keys(['Айгерім', 'Бекзат', 'Дана', 'Ерлан'])
dict_values([5, 4, 5, 3])
dict_items([('Айгерім', 5), ('Бекзат', 4), ('Дана', 5), ('Ерлан', 3)])
['Айгерім', 'Бекзат', 'Дана', 'Ерлан']
```

Бұл объектілерді `list()` арқылы тізімге айналдыруға және `for`, `in`, `len()`, `sum()`, `max()` т.б. қолдануға болады.

### keys()

```python
grades = {"Айгерім": 5, "Бекзат": 4, "Дана": 5}
for name in grades.keys():      # for name in grades: — дәл осындай
    print(name)
```

Нәтижесі:
```text
Айгерім
Бекзат
Дана
```

### values()

Тек мәндер керек болғанда — мысалы, қосынды немесе орташа:

```python
grades = {"Айгерім": 5, "Бекзат": 4, "Дана": 5, "Ерлан": 3}
print("Қосынды:", sum(grades.values()))
print("Орташа:", sum(grades.values()) / len(grades))
print("Ең жоғары:", max(grades.values()))
print("5 бағасы бар ма?", 5 in grades.values())

count5 = 0
for g in grades.values():
    if g == 5:
        count5 += 1
print("Беске оқитындар:", count5)
```

Нәтижесі:
```text
Қосынды: 17
Орташа: 4.25
Ең жоғары: 5
5 бағасы бар ма? True
Беске оқитындар: 2
```

### items() — ең жиі қолданылатыны

`items()` әр қадамда `(кілт, мән)` кортежін береді. Оны бірден екі айнымалыға «ашамыз»:

```python
prices = {"нан": 250, "сүт": 520, "ірімшік": 2400}
for item, price in prices.items():
    print(f"{item}: {price} теңге")
```

Нәтижесі:
```text
нан: 250 теңге
сүт: 520 теңге
ірімшік: 2400 теңге
```

## 3. Типтік алгоритмдер

### Максимум мәні бар кілтті табу

`max(d.values())` ең үлкен мәнді береді, бірақ оның **кімдікі** екенін білмейміз. Сондықтан цикл:

```python
scores = {"Әлихан": 87, "Нұрай": 95, "Тимур": 78, "Жансая": 91}
best_name = ""
best_score = -1
for name, score in scores.items():
    if score > best_score:
        best_score = score
        best_name = name
print(f"Жеңімпаз: {best_name} ({best_score} ұпай)")
```

Нәтижесі:
```text
Жеңімпаз: Нұрай (95 ұпай)
```

### Шарт бойынша сүзу

```python
scores = {"Әлихан": 87, "Нұрай": 95, "Тимур": 78, "Жансая": 91}
print("90-нан жоғары:")
for name, score in scores.items():
    if score >= 90:
        print("-", name)

passed = {}
for name, score in scores.items():
    if score >= 80:
        passed[name] = score
print(passed)
```

Нәтижесі:
```text
90-нан жоғары:
- Нұрай
- Жансая
{'Әлихан': 87, 'Нұрай': 95, 'Жансая': 91}
```

### Мәнді іздеу (кері іздеу)

```python
capitals = {"Қазақстан": "Астана", "Жапония": "Токио", "Франция": "Париж"}
city = "Токио"
for country, capital in capitals.items():
    if capital == city:
        print(city, "—", country, "елінің астанасы")
```

Нәтижесі:
```text
Токио — Жапония елінің астанасы
```

### Барлық мәндерді өзгерту

```python
prices = {"нан": 250, "сүт": 520, "ірімшік": 2400}
for item in prices:
    prices[item] = round(prices[item] * 1.1)   # 10% қымбаттау
print(prices)
```

Нәтижесі:
```text
{'нан': 275, 'сүт': 572, 'ірімшік': 2640}
```

**Ереже:** цикл кезінде мәндерді өзгертуге болады, бірақ сөздікке жаңа кілт **қосуға** немесе **жоюға** болмайды (`RuntimeError`). Жою керек болса — кілттердің көшірмесі бойынша аралаймыз: `for k in list(d.keys()):`.

```python
stock = {"дәптер": 0, "қалам": 15, "өшіргіш": 0}
for item in list(stock.keys()):
    if stock[item] == 0:
        del stock[item]
print(stock)
```

Нәтижесі:
```text
{'қалам': 15}
```

## 4. Сұрыптау

### Кілттер бойынша

`sorted(d)` — сұрыпталған **кілттер тізімін** береді:

```python
grades = {"Дана": 5, "Айгерім": 4, "Ерлан": 3, "Бекзат": 5}
for name in sorted(grades):
    print(name, grades[name])
```

Нәтижесі:
```text
Айгерім 4
Бекзат 5
Дана 5
Ерлан 3
```

### Мәндер бойынша

Жұптарды `(мән, кілт)` ретімен тізімге жинап, сұрыптаймыз — кортеждер бірінші элементі бойынша салыстырылады:

```python
scores = {"Әлихан": 87, "Нұрай": 95, "Тимур": 78, "Жансая": 91}
pairs = []
for name, score in scores.items():
    pairs.append((score, name))
pairs.sort(reverse=True)
place = 1
for score, name in pairs:
    print(f"{place}. {name} — {score}")
    place += 1
```

Нәтижесі:
```text
1. Нұрай — 95
2. Жансая — 91
3. Әлихан — 87
4. Тимур — 78
```

## 5. Кесте түрінде әдемі шығару

f-жолдағы ені (`:<12` — солға туралау, `:>6` — оңға туралау) арқылы:

```python
prices = {"нан": 250, "сүт": 520, "ірімшік": 2400, "шай": 1300}
print(f"{'Тауар':<10}{'Бағасы':>8}")
print("-" * 18)
for item, price in prices.items():
    print(f"{item:<10}{price:>8}")
print("-" * 18)
print(f"{'Барлығы':<10}{sum(prices.values()):>8}")
```

Нәтижесі:
```text
Тауар       Бағасы
------------------
нан            250
сүт            520
ірімшік       2400
шай           1300
------------------
Барлығы       4470
```

## 6. Мәні тізім немесе сөздік болса

```python
journal = {
    "Айгерім": [5, 5, 4],
    "Бекзат": [4, 3, 5, 4],
    "Дана": [5, 5, 5],
}
for name, marks in journal.items():
    avg = sum(marks) / len(marks)
    print(f"{name}: {marks}, орташа {avg:.2f}")
```

Нәтижесі:
```text
Айгерім: [5, 5, 4], орташа 4.67
Бекзат: [4, 3, 5, 4], орташа 4.00
Дана: [5, 5, 5], орташа 5.00
```

Сөздік ішіндегі сөздік:

```python
students = {
    "Айгерім": {"сынып": 8, "қала": "Алматы"},
    "Бекзат": {"сынып": 7, "қала": "Қонаев"},
}
for name, info in students.items():
    print(f"{name}: {info['сынып']}-сынып, {info['қала']}")
```

Нәтижесі:
```text
Айгерім: 8-сынып, Алматы
Бекзат: 7-сынып, Қонаев
```

## Жиі кездесетін қателер

**1. items() жазбай екі айнымалы алу**

```python
d = {"а": 1, "б": 2}
# for k, v in d:           # ValueError — кілт бір ғана жол
for k, v in d.items():
    print(k, v)
```

**2. values() бойынша аралап, кілтті іздеу**

```python
d = {"Нұрай": 95}
for v in d.values():
    print(v)               # кілт қолжетімсіз — items() керек
```

**3. Цикл кезінде сөздіктен жою**

```python
d = {"а": 0, "б": 1}
# for k in d:
#     if d[k] == 0:
#         del d[k]         # RuntimeError: dictionary changed size during iteration
for k in list(d):
    if d[k] == 0:
        del d[k]
print(d)
```

**4. sorted(d) сөздік қайтарады деп ойлау**

```python
d = {"б": 2, "а": 1}
print(sorted(d))          # ['а', 'б'] — бұл кілттер тізімі
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `for k in d` | сөздіктің кілттері бойынша цикл |
| `keys()` | барлық кілттер |
| `values()` | барлық мәндер |
| `items()` | барлық (кілт, мән) жұптары |
| Кортежді ашу | `for k, v in d.items()` — жұпты екі айнымалыға бөлу |
| Сүзу | шартқа сай жұптарды таңдау |
| `sorted(d)` | кілттердің сұрыпталған тізімі |

## Ескерту

- `keys()`, `values()`, `items()` тізім емес, сөздіктің «көріністерін» (view) қайтарады: сөздік өзгерсе, көрініс те бірге өзгереді. Тұрақты көшірме керек болса — `list(d.items())`.
- Ең үлкен мәні бар кілтті циклсіз табуға болады: `max(scores, key=scores.get)`.
- Мәндер бойынша сұрыптаудың қысқа жазбасы: `sorted(scores.items(), key=lambda p: p[1], reverse=True)` — нәтиже `(кілт, мән)` жұптарының тізімі.
- Сұрыпталған жұптардан қайтадан сөздік құруға болады: `dict(sorted(d.items()))` — Python 3.7+ нұсқасында рет сақталады.
- Орын нөмірін қолмен санаудың орнына `enumerate(pairs, start=1)` қолданған ыңғайлы.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#dictionary-view-objects
