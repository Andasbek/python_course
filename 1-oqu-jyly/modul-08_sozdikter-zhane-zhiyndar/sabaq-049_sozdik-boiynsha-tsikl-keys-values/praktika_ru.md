**Задание 2**
```python
scores = {"Алихан": 87, "Нурай": 95, "Тимур": 78, "Жансая": 91, "Ернур": 66}
best = ""
worst = ""
for name, s in scores.items():
    if best == "" or s > scores[best]:
        best = name
    if worst == "" or s < scores[worst]:
        worst = name
print("Наибольший:", best, scores[best])
print("Наименьший:", worst, scores[worst])
print("Средний:", sum(scores.values()) / len(scores))
```
Результат:
```text

Наименьший: Ернур 66
Средний: 83.4
```

```python
freq = {}
for w in text.split():
    freq[w] = freq.get(w, 0) + 1
pairs = []
for w, c in freq.items():
```

**Задание 8**
```python
journal = {
    "Айгерим": [5, 5, 4, 5],
    "Бекзат": [4, 3, 3, 4],
    "Дана": [5, 4, 5, 5],
    "Ерлан": [3, 3, 2, 4],
}
all_marks = []
for name, marks in journal.items():
    avg = sum(marks) / len(marks)
    note = ""
    if avg > 4.5:
        note = " — отличник"
    elif avg < 3.0:
        note = " — требует внимания"
    print(f"{name}: {avg:.2f}{note}")
    all_marks += marks
print(f"Средний балл класса: {sum(all_marks) / len(all_marks):.2f}")
```


**Задание 9**
```python
words = ["арбуз", "абрикос", "банан", "брусника", "айва", "груша", "гранат"]
groups = {}
for w in words:
    first = w[0]
    if first not in groups:
        groups[first] = []
    groups[first].append(w)
for letter in sorted(groups):
    print(f"{letter}: {', '.join(groups[letter])}")
```
Результат:
```text
а: арбуз, абрикос, айва
б: банан, брусника
г: груша, гранат
```
