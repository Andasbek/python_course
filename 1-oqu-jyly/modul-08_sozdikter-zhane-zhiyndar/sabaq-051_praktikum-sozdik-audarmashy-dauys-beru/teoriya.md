## 1. Шпаргалка: сөздіктер мен жиындар

### Сөздік (dict)

| Әрекет | Код |
|---|---|
| Құру | `d = {"алма": "apple"}`, `d = {}`, `dict(zip(keys, values))` |
| Мәнді алу | `d[k]`, `d.get(k, әдепкі)` |
| Қосу / өзгерту | `d[k] = v`, `d.update(басқа)` |
| Жою | `del d[k]`, `d.pop(k)`, `d.popitem()`, `d.clear()` |
| Тексеру | `k in d`, `v in d.values()` |
| Цикл | `for k in d`, `for v in d.values()`, `for k, v in d.items()` |
| Санау үлгісі | `d[x] = d.get(x, 0) + 1` |
| Сұрыптау | `sorted(d)` — кілттер; `(мән, кілт)` жұптарының тізімі — мән бойынша |

### Жиын (set)

| Әрекет | Код |
|---|---|
| Құру | `s = {1, 2}`, `s = set()`, `set(тізім)` |
| Қосу / жою | `s.add(x)`, `s.remove(x)`, `s.discard(x)` |
| Амалдар | `A \| B`, `A & B`, `A - B`, `A ^ B` |
| Тексеру | `x in s`, `A <= B` |

## 2. «Сөздік-аудармашы» жобасының идеясы

Аудармашы бағдарламаның «жүрегі» — сөздік: **кілт** — қазақша сөз, **мән** — ағылшынша аудармасы.

```python
kaz_eng = {"сәлем": "hello", "мектеп": "school", "кітап": "book", "дос": "friend"}
word = "кітап"
print(kaz_eng.get(word, "сөздікте жоқ"))
```

Нәтижесі:
```text
book
```

### Мәзірлі бағдарламаның құрылымы

```
┌──────────────────────────────┐
│ while True:                  │
│   мәзірді шығару             │
│   таңдауды оқу               │
│   if 1 → аудару              │
│   elif 2 → жаңа сөз қосу     │
│   elif 3 → сөз жою           │
│   elif 4 → барлық сөздер     │
│   elif 0 → break             │
└──────────────────────────────┘
```

Бұл — `while True` және `break` негізіндегі әдеттегі меню құрылымы; мұнда ол сөздікпен біріктіріледі.

### Сөйлемді аудару

Сөйлемді `split()` арқылы сөздерге бөліп, әр сөзді сөздіктен іздейміз; табылмаған сөзді `[?сөз]` түрінде белгілейміз:

```python
kaz_eng = {"мен": "i", "мектепке": "to school", "барамын": "go"}
sentence = "мен мектепке барамын"
result = []
for w in sentence.split():
    result.append(kaz_eng.get(w, "[?" + w + "]"))
print(" ".join(result))
```

Нәтижесі:
```text
i to school go
```

Ескерту: бұл «сөзбе-сөз» аударма — нағыз аудармашылар (мысалы, Google Translate) грамматиканы, сөз ретін және мағынаны ескереді.

### Кері аударма

Ағылшынша → қазақша аудару үшін кері сөздік құрамыз:

```python
kaz_eng = {"сәлем": "hello", "мектеп": "school"}
eng_kaz = {}
for kaz, eng in kaz_eng.items():
    eng_kaz[eng] = kaz
print(eng_kaz)
```

Нәтижесі:
```text
{'hello': 'сәлем', 'school': 'мектеп'}
```

## 3. «Дауыс беру жүйесі» жобасының идеясы

Мектепте «Жыл оқушысы» сайлауы өтеді. Әр оқушы бір рет қана дауыс бере алады.

Қажетті құрылымдар:
- `candidates` — үміткерлер тізімі немесе жиыны;
- `votes` — **сөздік**: үміткер → дауыс саны;
- `voted` — **жиын**: дауыс берген оқушылар (қайталап дауыс беруді болдырмау үшін).

```python
candidates = {"Айгерім", "Бекзат", "Дана"}
votes = {}
for c in candidates:
    votes[c] = 0
voted = set()

ballots = [("Ерлан", "Дана"), ("Жансая", "Айгерім"), ("Ерлан", "Бекзат"),
           ("Тимур", "Дана"), ("Мадина", "Асқар")]

for voter, choice in ballots:
    if voter in voted:
        print(voter, "— қайта дауыс беруге болмайды!")
    elif choice not in candidates:
        print(choice, "— мұндай үміткер жоқ")
    else:
        votes[choice] += 1
        voted.add(voter)

for name in sorted(votes):
    print(name, votes[name])
```

Нәтижесі:
```text
Ерлан — қайта дауыс беруге болмайды!
Асқар — мұндай үміткер жоқ
Айгерім 1
Бекзат 0
Дана 2
```

### Жеңімпазды анықтау және тең дауыс

```python
votes = {"Айгерім": 5, "Бекзат": 7, "Дана": 7}
max_votes = max(votes.values())
winners = []
for name, v in votes.items():
    if v == max_votes:
        winners.append(name)
if len(winners) == 1:
    print("Жеңімпаз:", winners[0])
else:
    print("Тең дауыс:", ", ".join(winners), "— екінші тур қажет")
```

Нәтижесі:
```text
Тең дауыс: Бекзат, Дана — екінші тур қажет
```

### Пайыз және мәтіндік диаграмма

```python
votes = {"Айгерім": 5, "Бекзат": 8, "Дана": 7}
total = sum(votes.values())
for name, v in votes.items():
    percent = v / total * 100
    print(f"{name:<10}{v:>3} {percent:5.1f}% " + "█" * v)
```

Нәтижесі:
```text
Айгерім     5  25.0% █████
Бекзат      8  40.0% ████████
Дана        7  35.0% ███████
```

## Жиі кездесетін қателер

**1. Санауышты бастапқы мәнсіз арттыру**

```python
votes = {}
# votes["Дана"] += 1                  # KeyError
votes["Дана"] = votes.get("Дана", 0) + 1
print(votes)
```

**2. Қайта дауыс беруді тексермеу** — `voted` жиынын қолданбаса, бір адам бірнеше рет дауыс бере алады.

**3. Регистр мен бос орындар**

```python
kaz_eng = {"мектеп": "school"}
word = "  Мектеп "
print(kaz_eng.get(word, "жоқ"))                   # жоқ
print(kaz_eng.get(word.strip().lower(), "жоқ"))   # school
```

**4. max(votes) жеңімпазды береді деп ойлау**

```python
votes = {"Айгерім": 9, "Бекзат": 2}
print(max(votes))      # Бекзат — әліппе бойынша ең «үлкен» кілт, дауыс емес!
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Мәзір (меню) | пайдаланушы әрекетті таңдайтын қайталанатын цикл |
| Кері сөздік | кілттер мен мәндердің орындары ауыстырылған сөздік |
| Бюллетень | бір дауыс туралы жазба (кім → кімге) |
| Санауыш-сөздік | нысан → кездесу саны |
| Бірегейлікті тексеру | жиын арқылы қайталануды болдырмау |

## Ескерту

- Кері сөздік құрғанда мәндер қайталанса, ақпарат жоғалады: бірдей мәні бар бірнеше кілттің тек соңғысы сақталады. Мысалы, `{"кітап": "book", "кітапша": "book"}` кері сөздікте бір ғана жұп береді.
- Кері сөздікті бір жолмен құруға болады (dict comprehension): `eng_kaz = {v: k for k, v in kaz_eng.items()}`.
- `max(votes)` кілттер бойынша салыстырады; ең көп дауыс алған кандидатты табу үшін `max(votes, key=votes.get)` жазылады (тең дауыстар болса, бірінші кездескені қайтарылады).
- Дауыстарды санау үшін `collections.Counter` ыңғайлы: `Counter(choices).most_common()` нәтижені кему ретімен береді.
- Пайызды есептегенде жалпы сан нөлге тең болуы мүмкін екенін ескеріңіз (`ZeroDivisionError`).
- Құжаттама: https://docs.python.org/3/tutorial/datastructures.html#dictionaries
