## 1. Шпаргалка: словари и множества

### Словарь (dict)

| Действие | Код |
|---|---|
| Создание | `d = {"алма": "apple"}`, `d = {}`, `dict(zip(keys, values))` |
| Получение значения | `d[k]`, `d.get(k, по_умолчанию)` |
| Добавление / изменение | `d[k] = v`, `d.update(другой)` |
| Удаление | `del d[k]`, `d.pop(k)`, `d.popitem()`, `d.clear()` |
| Проверка | `k in d`, `v in d.values()` |
| Цикл | `for k in d`, `for v in d.values()`, `for k, v in d.items()` |
| Шаблон подсчёта | `d[x] = d.get(x, 0) + 1` |
| Сортировка | `sorted(d)` — ключи; список пар `(значение, ключ)` — по значению |

### Множество (set)

| Действие | Код |
|---|---|
| Создание | `s = {1, 2}`, `s = set()`, `set(список)` |
| Добавление / удаление | `s.add(x)`, `s.remove(x)`, `s.discard(x)` |
| Операции | `A \| B`, `A & B`, `A - B`, `A ^ B` |
| Проверка | `x in s`, `A <= B` |

## 2. Идея проекта «Словарь-переводчик»

«Сердце» программы-переводчика — словарь: **ключ** — казахское слово, **значение** — его перевод на английский.

```python
kaz_eng = {"сәлем": "hello", "мектеп": "school", "кітап": "book", "дос": "friend"}
word = "кітап"
print(kaz_eng.get(word, "нет в словаре"))
```

Результат:
```text
book
```

### Структура программы с меню

```
┌──────────────────────────────┐
│ while True:                  │
│   вывести меню               │
│   прочитать выбор            │
│   if 1 → перевести           │
│   elif 2 → добавить слово    │
│   elif 3 → удалить слово     │
│   elif 4 → все слова         │
│   elif 0 → break             │
└──────────────────────────────┘
```

Это обычная структура меню на основе `while True` и `break`; здесь она объединяется со словарём.

### Перевод предложения

Разбиваем предложение на слова с помощью `split()` и ищем каждое слово в словаре; ненайденное слово помечаем в виде `[?слово]`:

```python
kaz_eng = {"мен": "i", "мектепке": "to school", "барамын": "go"}
sentence = "мен мектепке барамын"
result = []
for w in sentence.split():
    result.append(kaz_eng.get(w, "[?" + w + "]"))
print(" ".join(result))
```

Результат:
```text
i to school go
```

Примечание: это «дословный» перевод — настоящие переводчики (например, Google Translate) учитывают грамматику, порядок слов и смысл.

### Обратный перевод

Для перевода с английского на казахский создаём обратный словарь:

```python
kaz_eng = {"сәлем": "hello", "мектеп": "school"}
eng_kaz = {}
for kaz, eng in kaz_eng.items():
    eng_kaz[eng] = kaz
print(eng_kaz)
```

Результат:
```text
{'hello': 'сәлем', 'school': 'мектеп'}
```

## 3. Идея проекта «Система голосования»

В школе проходят выборы «Ученик года». Каждый ученик может проголосовать только один раз.

Необходимые структуры:
- `candidates` — список или множество кандидатов;
- `votes` — **словарь**: кандидат → количество голосов;
- `voted` — **множество**: проголосовавшие ученики (чтобы не допустить повторного голосования).

```python
candidates = {"Айгерим", "Бекзат", "Дана"}
votes = {}
for c in candidates:
    votes[c] = 0
voted = set()

ballots = [("Ерлан", "Дана"), ("Жансая", "Айгерим"), ("Ерлан", "Бекзат"),
           ("Тимур", "Дана"), ("Мадина", "Аскар")]

for voter, choice in ballots:
    if voter in voted:
        print(voter, "— повторно голосовать нельзя!")
    elif choice not in candidates:
        print(choice, "— такого кандидата нет")
    else:
        votes[choice] += 1
        voted.add(voter)

for name in sorted(votes):
    print(name, votes[name])
```

Результат:
```text
Ерлан — повторно голосовать нельзя!
Аскар — такого кандидата нет
Айгерим 1
Бекзат 0
Дана 2
```

### Определение победителя и равенство голосов

```python
votes = {"Айгерим": 5, "Бекзат": 7, "Дана": 7}
max_votes = max(votes.values())
winners = []
for name, v in votes.items():
    if v == max_votes:
        winners.append(name)
if len(winners) == 1:
    print("Победитель:", winners[0])
else:
    print("Равенство голосов:", ", ".join(winners), "— нужен второй тур")
```

Результат:
```text
Равенство голосов: Бекзат, Дана — нужен второй тур
```

### Проценты и текстовая диаграмма

```python
votes = {"Айгерим": 5, "Бекзат": 8, "Дана": 7}
total = sum(votes.values())
for name, v in votes.items():
    percent = v / total * 100
    print(f"{name:<10}{v:>3} {percent:5.1f}% " + "█" * v)
```

Результат:
```text
Айгерим     5  25.0% █████
Бекзат      8  40.0% ████████
Дана        7  35.0% ███████
```

## Частые ошибки

**1. Увеличение счётчика без начального значения**

```python
votes = {}
# votes["Дана"] += 1                  # KeyError
votes["Дана"] = votes.get("Дана", 0) + 1
print(votes)
```

**2. Нет проверки повторного голосования** — если не использовать множество `voted`, один человек сможет проголосовать несколько раз.

**3. Регистр и пробелы**

```python
kaz_eng = {"мектеп": "school"}
word = "  Мектеп "
print(kaz_eng.get(word, "нет"))                   # нет
print(kaz_eng.get(word.strip().lower(), "нет"))   # school
```

**4. Думают, что max(votes) даёт победителя**

```python
votes = {"Айгерим": 9, "Бекзат": 2}
print(max(votes))      # Бекзат — наибольший ключ по алфавиту, а не по голосам!
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Меню | повторяющийся цикл, в котором пользователь выбирает действие |
| Обратный словарь | словарь, в котором ключи и значения поменялись местами |
| Бюллетень | запись об одном голосе (кто → за кого) |
| Словарь-счётчик | объект → количество появлений |
| Проверка уникальности | предотвращение повторов с помощью множества |

## Примечание

- При построении обратного словаря повторяющиеся значения приводят к потере данных: из нескольких ключей с одинаковым значением сохранится только последний. Например, `{"кітап": "book", "кітапша": "book"}` в обратном словаре даст одну пару.
- Обратный словарь можно создать одной строкой (dict comprehension): `eng_kaz = {v: k for k, v in kaz_eng.items()}`.
- `max(votes)` сравнивает ключи; чтобы найти кандидата с наибольшим числом голосов, пишут `max(votes, key=votes.get)` (при равенстве вернётся первый встретившийся).
- Для подсчёта голосов удобен `collections.Counter`: `Counter(choices).most_common()` выдаёт результат по убыванию.
- При вычислении процентов учитывайте, что общее количество может быть равно нулю (`ZeroDivisionError`).
- Документация: https://docs.python.org/3/tutorial/datastructures.html#dictionaries
