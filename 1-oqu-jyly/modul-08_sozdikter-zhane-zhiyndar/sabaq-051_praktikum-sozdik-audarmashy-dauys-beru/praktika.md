# Сабақ 51. Практикалық тапсырмалар: «Сөздік-аудармашы», «Дауыс беру жүйесі», Өзіндік жұмыс №5

## Базалық деңгей

### 1-жоба. «Сөздік-аудармашы»

**1-қадам. Сөздік.** Кемінде 10 қазақша-ағылшынша сөз жұбынан тұратын `kaz_eng` сөздігін құрыңыз (47-сабақтағы үй тапсырмасын қолдануға болады).

**2-қадам. Бір сөзді аудару.** Пайдаланушы сөз енгізеді (бос орын мен регистр ескерілмейді), бағдарлама аудармасын шығарады немесе «Бұл сөз сөздікте жоқ» дейді.

**3-қадам. Мәзір.** `while True` циклімен мәзір жасаңыз:
```text
===== СӨЗДІК-АУДАРМАШЫ =====
1 — Қазақша → ағылшынша
2 — Ағылшынша → қазақша
3 — Жаңа сөз қосу
4 — Сөзді жою
5 — Барлық сөздер (әліппе бойынша)
0 — Шығу
Таңдаңыз:
```

**4-қадам. Кері аударма.** 2-пункт үшін кері сөздік құрыңыз (немесе `items()` бойынша іздеңіз).

**5-қадам. Сөз қосу және жою.** 3-пунктте сөз бұрыннан бар болса, «Ауыстырайын ба? (иә/жоқ)» деп сұраңыз. 4-пунктте `pop()` қолданыңыз.

**6-қадам. Сөйлемді аудару (қосымша).** `6 — Сөйлемді аудару` пунктін қосыңыз: әр сөз аударылады, табылмағандары `[?сөз]` түрінде белгіленеді.

### 2-жоба. «Дауыс беру жүйесі»

**1-қадам.** Үміткерлер тізімін енгізіңіз (бір жолға үтір арқылы): `Айгерім, Бекзат, Дана`. `votes` сөздігін әр үміткерге 0 мәнімен толтырыңыз.

**2-қадам.** Цикл: сайлаушы өз атын, кейін үміткерді енгізеді. `стоп` енгізілгенде дауыс беру аяқталады.

**3-қадам.** Тексерулер: сайлаушы бұрын дауыс берген болса (`voted` жиыны) — бас тарту; үміткер жоқ болса — ескерту.

**4-қадам.** Нәтижелер: әр үміткердің дауыс саны, пайызы және мәтіндік диаграммасы — дауыс саны бойынша кему ретімен.
```text
===== НӘТИЖЕЛЕР =====
Бекзат      4  50.0% ████
Дана        3  37.5% ███
Айгерім     1  12.5% █
Барлық дауыс: 8
Жеңімпаз: Бекзат
```

**5-қадам.** Тең дауыс жағдайын өңдеңіз: «Тең дауыс: ... — екінші тур қажет».

## Кеңейтілген деңгей

### 3-тапсырма. Аудармашыға викторина режимі
Аудармашыға `7 — Тест` пунктін қосыңыз: бағдарлама сөздіктегі әр сөзді кезекпен сұрайды, пайдаланушы аудармасын жазады, соңында дұрыс жауаптар саны мен пайызы шығады. Қате жауап берілген сөздерді жиынға жинап, соңында «Қайталау керек сөздер» деп шығарыңыз.

### 4-тапсырма. Бірнеше номинация
Дауыс беру жүйесін кеңейтіңіз: екі номинация бар («Жыл оқушысы», «Жыл спортшысы»). Әр номинацияның өз `votes` сөздігі болсын (сөздік ішіндегі сөздік: `{"Жыл оқушысы": {...}, "Жыл спортшысы": {...}}`). Бір сайлаушы әр номинацияда бір реттен дауыс бере алады.

## ★ Олимпиадалық / шығармашылық тапсырма

### 5-тапсырма. Рейтингтік дауыс беру
Әр сайлаушы 3 үміткерді ұнату реті бойынша атайды. 1-орын — 3 ұпай, 2-орын — 2 ұпай, 3-орын — 1 ұпай (Борда әдісі). Бюллетеньдер тізімі берілген:
```python
ballots = [
    ["Дана", "Айгерім", "Бекзат"],
    ["Бекзат", "Дана", "Айгерім"],
    ["Дана", "Бекзат", "Айгерім"],
    ["Айгерім", "Бекзат", "Дана"],
]
```
Әр үміткердің жалпы ұпайын есептеп, жеңімпазды анықтаңыз.

**1-жоба «Сөздік-аудармашы» (толық нұсқа)**
```python
kaz_eng = {
    "сәлем": "hello", "мектеп": "school", "кітап": "book", "дос": "friend",
    "алма": "apple", "су": "water", "күн": "sun", "ай": "moon",
    "үй": "house", "мысық": "cat",
}
while True:
    print("===== СӨЗДІК-АУДАРМАШЫ =====")
    print("1 — Қазақша → ағылшынша")
    print("2 — Ағылшынша → қазақша")
    print("3 — Жаңа сөз қосу")
    print("4 — Сөзді жою")
    print("5 — Барлық сөздер")
    print("6 — Сөйлемді аудару")
    print("0 — Шығу")
    choice = input("Таңдаңыз: ").strip()

    if choice == "0":
        print("Сау болыңыз!")
        break
    elif choice == "1":
        word = input("Қазақша сөз: ").strip().lower()
        print(kaz_eng.get(word, "Бұл сөз сөздікте жоқ"))
    elif choice == "2":
        word = input("Ағылшынша сөз: ").strip().lower()
        found = False
        for kaz, eng in kaz_eng.items():
            if eng == word:
                print(kaz)
                found = True
        if not found:
            print("Бұл сөз сөздікте жоқ")
    elif choice == "3":
        kaz = input("Қазақша: ").strip().lower()
        eng = input("Ағылшынша: ").strip().lower()
        if kaz in kaz_eng:
            answer = input(f"«{kaz}» бар ({kaz_eng[kaz]}). Ауыстырайын ба? (иә/жоқ): ")
            if answer.lower() != "иә":
                continue
        kaz_eng[kaz] = eng
        print("Сақталды")
    elif choice == "4":
        kaz = input("Жойылатын сөз: ").strip().lower()
        removed = kaz_eng.pop(kaz, None)
        if removed is None:
            print("Мұндай сөз жоқ")
        else:
            print(f"«{kaz} — {removed}» жойылды")
    elif choice == "5":
        for kaz in sorted(kaz_eng):
            print(f"{kaz:<12} {kaz_eng[kaz]}")
        print("Барлығы:", len(kaz_eng), "сөз")
    elif choice == "6":
        sentence = input("Сөйлем: ").lower()
        result = []
        for w in sentence.split():
            result.append(kaz_eng.get(w, "[?" + w + "]"))
        print(" ".join(result))
    else:
        print("Қате таңдау")
```

**2-жоба «Дауыс беру жүйесі» (толық нұсқа)**
```python
names = input("Үміткерлер (үтір арқылы): ").split(",")
votes = {}
for n in names:
    votes[n.strip()] = 0
voted = set()

while True:
    voter = input("Сайлаушының аты (стоп — аяқтау): ").strip()
    if voter.lower() == "стоп":
        break
    if voter in voted:
        print("Сіз дауыс беріп қойғансыз!")
        continue
    choice = input("Үміткер: ").strip()
    if choice not in votes:
        print("Мұндай үміткер жоқ")
        continue
    votes[choice] += 1
    voted.add(voter)
    print("Дауысыңыз қабылданды")

total = sum(votes.values())
print("===== НӘТИЖЕЛЕР =====")
pairs = []
for name, v in votes.items():
    pairs.append((v, name))
pairs.sort(reverse=True)
for v, name in pairs:
    percent = 0
    if total > 0:
        percent = v / total * 100
    print(f"{name:<10}{v:>3} {percent:5.1f}% " + "█" * v)
print("Барлық дауыс:", total)

if total > 0:
    max_v = pairs[0][0]
    winners = []
    for v, name in pairs:
        if v == max_v:
            winners.append(name)
    if len(winners) == 1:
        print("Жеңімпаз:", winners[0])
    else:
        print("Тең дауыс:", ", ".join(winners), "— екінші тур қажет")
```

**4-тапсырма (құрылымы)**
```python
candidates = {
    "Жыл оқушысы": ["Айгерім", "Бекзат"],
    "Жыл спортшысы": ["Дана", "Ерлан"],
}
votes = {}
voted = {}
for nom, people in candidates.items():
    votes[nom] = {}
    voted[nom] = set()
    for p in people:
        votes[nom][p] = 0

while True:
    voter = input("Сайлаушы (стоп): ").strip()
    if voter.lower() == "стоп":
        break
    for nom in candidates:
        if voter in voted[nom]:
            print(nom, "— дауыс берілген")
            continue
        choice = input(f"{nom} {candidates[nom]}: ").strip()
        if choice in votes[nom]:
            votes[nom][choice] += 1
            voted[nom].add(voter)
for nom, result in votes.items():
    print(nom, result)
```

```python
ballots = [
    ["Дана", "Айгерім", "Бекзат"],
    ["Бекзат", "Дана", "Айгерім"],
    ["Дана", "Бекзат", "Айгерім"],

]
points = {}
for ballot in ballots:
    for place in range(len(ballot)):
        name = ballot[place]
        points[name] = points.get(name, 0) + (3 - place)
for name in sorted(points):
    print(name, points[name])
best = ""
for name, p in points.items():
    if best == "" or p > points[best]:
        best = name
print("Жеңімпаз:", best)
```

```python
word = input("Сөз: ").lower()
freq = {}
for ch in word:
    freq[ch] = freq.get(ch, 0) + 1
for ch, c in freq.items():
    if c > 1:
        print(ch, c)
```
