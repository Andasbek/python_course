# Сабақ 47. Практикалық тапсырмалар: сөздік құру

## Базалық деңгей

### 1-тапсырма. Мен туралы сөздік
Өзіңіз туралы сөздік құрыңыз: `аты`, `жасы`, `қала`, `мектеп`, `хобби` кілттерімен. Сөздіктен мәліметтерді алып, сөйлем түрінде шығарыңыз.

Мысал:
```text
Менің атым Ерасыл, 13 жастамын. Мен Алматы қаласындағы №120 мектепте оқимын. Хоббиім — шахмат.
```

### 2-тапсырма. Астаналар
Кемінде 5 мемлекет пен астанасының сөздігін құрыңыз. Пайдаланушы ел атауын енгізеді, бағдарлама астанасын шығарады. Ел сөздікте жоқ болса — «Бұл ел туралы мәлімет жоқ».

```text
Ел: Түркия
Астанасы: Анкара
```

### 3-тапсырма. Дүкен
Тауарлар мен бағалардың сөздігі берілген:
```python
prices = {"нан": 250, "сүт": 520, "ірімшік": 2400, "алма": 450, "шай": 1300}
```
Пайдаланушы тауар атауы мен санын енгізеді. Бағдарлама жалпы құнын шығарады. Тауар жоқ болса, `get()` арқылы хабар беріңіз.

### 4-тапсырма. Апта күндері
Нөмір → күн атауы сөздігін құрыңыз (`1: "Дүйсенбі"`, ..., `7: "Жексенбі"`). Пайдаланушы 1–7 аралығындағы сан енгізеді, бағдарлама күн атауын шығарады.

### 5-тапсырма. Екі тізімнен сөздік
```python
cities = ["Алматы", "Астана", "Шымкент", "Ақтөбе"]
population = [2200, 1400, 1200, 600]   # мың адам
```
`zip()` арқылы сөздік құрыңыз және Шымкенттің халық санын шығарыңыз.

## Кеңейтілген деңгей

### 6-тапсырма. Оқушы карточкасы
Мәні тізім болатын сөздік құрыңыз:
```python
student = {"аты": "Мадина", "бағалар": [5, 4, 5, 5, 3], "үйірмелер": ["Python", "робототехника"]}
```
Шығарыңыз: аты, бағалар саны, орташа бағасы (1 ондық белгі), ең жоғары бағасы, бірінші үйірмесі.

### 7-тапсырма. Морзе әліппесі
Латын әріптерінің бір бөлігі үшін Морзе сөздігін құрыңыз (кемінде `a, e, i, o, s, t, m, n`):
```python
morse = {"a": ".-", "e": ".", "i": "..", "o": "---", "s": "...", "t": "-", "m": "--", "n": "-."}
```
Пайдаланушы енгізген сөзді (осы әріптерден) Морзе кодына аударыңыз, кодтарды бос орынмен бөліңіз. Мысалы: `sos` → `... --- ...`.

### 8-тапсырма. Бағаны сөзбен
Сөздік арқылы бағаны сөзге айналдырыңыз: `5 → "өте жақсы"`, `4 → "жақсы"`, `3 → "қанағаттанарлық"`, `2 → "нашар"`. Бір жолға енгізілген бағалардың әрқайсысын сөзбен шығарыңыз.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Рим цифрлары
Сөздік `{"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}` арқылы рим цифрымен жазылған санды ондық санға айналдырыңыз. Ереже: егер символдың мәні келесі символдың мәнінен кіші болса — ол азайтылады (`IV = 4`, `XC = 90`).

Мысал: `MMXXVII` → `2027`, `XIV` → `14`.

### 10-тапсырма. Телефон пернелері
Ескі телефон пернетақтасының сөздігін құрыңыз: `"2": "abc"`, `"3": "def"`, ..., `"9": "wxyz"`. Цифрлар тізбегі енгізіледі (мысалы `44 33 555 555 666`), әр топтағы цифр санына қарай әріпті анықтап, сөзді шығарыңыз (`hello`).

## Үй тапсырмасы

1. Отбасы мүшелерінің аттары мен туған жылдарының сөздігін құрыңыз. Пайдаланушы есімді енгізгенде, ол адамның жасын есептеп шығарыңыз.
2. Қазақша-ағылшынша 10 сөзден тұратын сөздік құрыңыз (келесі сабақтарда «Сөздік-аудармашы» жобасында қолданамыз!).
3. Ойланыңыз: сынып журналын сөздік түрінде қалай сақтауға болады? Құрылымын дәптерге сызыңыз.

**9-тапсырма**
```python
roman = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
s = input("Рим саны: ").upper()
total = 0
for i in range(len(s)):
    value = roman[s[i]]
    if i + 1 < len(s) and value < roman[s[i + 1]]:
        total -= value
    else:
        total += value
print(total)
```
