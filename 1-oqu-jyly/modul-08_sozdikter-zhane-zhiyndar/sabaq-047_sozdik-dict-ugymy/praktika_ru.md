# Урок 47. Практические задания: создание словаря

## Базовый уровень

### Задание 1. Словарь обо мне
Создайте словарь о себе с ключами `имя`, `возраст`, `город`, `школа`, `хобби`. Извлеките из словаря данные и выведите их в виде предложения.

Пример:
```text
Меня зовут Ерасыл, мне 13 лет. Я учусь в школе №120 города Алматы. Моё хобби — шахматы.
```

### Задание 2. Столицы
Создайте словарь минимум из 5 государств и их столиц. Пользователь вводит название страны, программа выводит столицу. Если страны нет в словаре — «Нет данных об этой стране».

```text
Страна: Турция
Столица: Анкара
```

### Задание 3. Магазин
Дан словарь товаров и цен:
```python
prices = {"хлеб": 250, "молоко": 520, "сыр": 2400, "яблоко": 450, "чай": 1300}
```
Пользователь вводит название товара и количество. Программа выводит общую стоимость. Если товара нет, сообщите об этом с помощью `get()`.

### Задание 4. Дни недели
Создайте словарь номер → название дня (`1: "Понедельник"`, ..., `7: "Воскресенье"`). Пользователь вводит число от 1 до 7, программа выводит название дня.

### Задание 5. Словарь из двух списков
```python
cities = ["Алматы", "Астана", "Шымкент", "Актобе"]
population = [2200, 1400, 1200, 600]   # тысяч человек
```
Создайте словарь с помощью `zip()` и выведите численность населения Шымкента.

## Продвинутый уровень

### Задание 6. Карточка ученика
Создайте словарь, значения которого — списки:
```python
student = {"имя": "Мадина", "оценки": [5, 4, 5, 5, 3], "кружки": ["Python", "робототехника"]}
```
Выведите: имя, количество оценок, средний балл (1 знак после запятой), самую высокую оценку, первый кружок.

### Задание 7. Азбука Морзе
Создайте словарь Морзе для части латинских букв (как минимум `a, e, i, o, s, t, m, n`):
```python
morse = {"a": ".-", "e": ".", "i": "..", "o": "---", "s": "...", "t": "-", "m": "--", "n": "-."}
```
Переведите введённое пользователем слово (из этих букв) в код Морзе, разделяя коды пробелом. Например: `sos` → `... --- ...`.

### Задание 8. Оценка словами
С помощью словаря преобразуйте оценку в слово: `5 → "отлично"`, `4 → "хорошо"`, `3 → "удовлетворительно"`, `2 → "плохо"`. Выведите словами каждую из оценок, введённых в одну строку.

## ★ Олимпиадная / творческая задача

### Задание 9. Римские цифры
С помощью словаря `{"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}` переведите число, записанное римскими цифрами, в десятичное. Правило: если значение символа меньше значения следующего символа — оно вычитается (`IV = 4`, `XC = 90`).

Пример: `MMXXVII` → `2027`, `XIV` → `14`.

### Задание 10. Кнопки телефона
Создайте словарь клавиатуры старого телефона: `"2": "abc"`, `"3": "def"`, ..., `"9": "wxyz"`. Вводится последовательность цифр (например, `44 33 555 555 666`); по количеству цифр в каждой группе определите букву и выведите слово (`hello`).

**Задание 9**
```python
roman = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
s = input("Римское число: ").upper()
total = 0
for i in range(len(s)):
    value = roman[s[i]]
    if i + 1 < len(s) and value < roman[s[i + 1]]:
        total -= value
    else:
        total += value
print(total)
```
