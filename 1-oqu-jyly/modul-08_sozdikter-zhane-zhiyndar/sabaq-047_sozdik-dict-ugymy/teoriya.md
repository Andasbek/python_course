## 1. Сөздік дегеніміз не?

**Сөздік (словарь, dictionary, dict)** — **кілт → мән** (key → value) жұптарының жиынтығы. Әр мәнге индекс арқылы емес, **кілт** арқылы қатынаймыз.

Өмірлік аналогиялар:

| Өмірдегі «сөздік» | Кілт | Мән |
|---|---|---|
| Қазақша-ағылшынша сөздік | `алма` | `apple` |
| Телефон кітапшасы | `Айгерім` | `87011112233` |
| Сынып журналы | оқушы аты | баға |
| Гардероб | номерок | пальто |
| Мемлекеттер | ел | астанасы |

## 2. Сөздік құру

### Фигуралық жақшалар арқылы

```python
phones = {
    "Айгерім": "87011112233",
    "Бекзат": "87772223344",
    "Дана": "87053334455",
}
print(phones)
print(type(phones))
```

Нәтижесі:
```text
{'Айгерім': '87011112233', 'Бекзат': '87772223344', 'Дана': '87053334455'}
<class 'dict'>
```

Жазылу ережесі:
- сөздік `{` `}` фигуралық жақшаларға алынады;
- кілт пен мән `:` (қос нүкте) арқылы жазылады;
- жұптар `,` арқылы бөлінеді.

### Бос сөздік

```python
empty1 = {}
empty2 = dict()
print(empty1, empty2, len(empty1))
```

Нәтижесі:
```text
{} {} 0
```

### dict() функциясы арқылы

```python
capitals = dict(Kazakhstan="Астана", Russia="Мәскеу", Turkey="Анкара")
print(capitals)

pairs = [("алма", "apple"), ("мысық", "cat"), ("кітап", "book")]
translator = dict(pairs)
print(translator)
```

Нәтижесі:
```text
{'Kazakhstan': 'Астана', 'Russia': 'Мәскеу', 'Turkey': 'Анкара'}
{'алма': 'apple', 'мысық': 'cat', 'кітап': 'book'}
```

`dict(кілт=мән)` түрінде кілттер латынша айнымалы атауы сияқты болуы керек. Кортеждер тізімінен құру кез келген кілтпен жұмыс істейді.

### Екі тізімнен: zip()

```python
subjects = ["математика", "физика", "информатика"]
grades = [5, 4, 5]
journal = dict(zip(subjects, grades))
print(journal)
```

Нәтижесі:
```text
{'математика': 5, 'физика': 4, 'информатика': 5}
```

`zip()` екі тізімнің элементтерін жұптап береді — бірінші бірінші мен, екінші екінші мен т.с.с.

## 3. Мәнге кілт арқылы қатынау

```python
student = {"аты": "Әлихан", "жасы": 13, "сынып": 7, "қала": "Алматы"}
print(student["аты"])
print(student["жасы"] + 1)
print(f"{student['аты']} {student['сынып']}-сыныпта оқиды")
```

Нәтижесі:
```text
Әлихан
14
Әлихан 7-сыныпта оқиды
```

Ескерту: f-жол ішінде қос тырнақша қолданылса, кілтті дара тырнақшамен жазамыз.

### Жоқ кілт → қате

```python
student = {"аты": "Әлихан"}
# print(student["тегі"])    # KeyError: 'тегі'
```

### Қауіпсіз тәсіл: get()

`d.get(кілт)` — кілт болса мәнін, болмаса `None` қайтарады. Екінші аргумент — үнсіз келісім бойынша мән.

```python
student = {"аты": "Әлихан", "жасы": 13}
print(student.get("аты"))
print(student.get("тегі"))
print(student.get("тегі", "белгісіз"))
```

Нәтижесі:
```text
Әлихан
None
белгісіз
```

### Кілт бар ма? — in

`in` операторы сөздікте **кілттерді** тексереді (мәндерді емес!):

```python
capitals = {"Қазақстан": "Астана", "Қырғызстан": "Бішкек"}
print("Қазақстан" in capitals)
print("Астана" in capitals)
country = "Өзбекстан"
if country in capitals:
    print(capitals[country])
else:
    print(country, "сөздікте жоқ")
```

Нәтижесі:
```text
True
False
Өзбекстан сөздікте жоқ
```

## 4. Кілттер мен мәндерге қойылатын талаптар

**Кілттер:**
- **бірегей** болуы керек: бір кілт екі рет кездессе, соңғы мәні сақталады;
- **өзгермейтін** типте болуы керек: `str`, `int`, `float`, `bool`, `tuple`. Тізім кілт бола **алмайды**.

**Мәндер:** кез келген тип — сан, жол, тізім, тіпті басқа сөздік; мәндер қайталана береді.

```python
d = {"а": 1, "б": 2, "а": 100}
print(d)

points = {(0, 0): "бастау", (3, 4): "мектеп"}   # кортеж — кілт
print(points[(3, 4)])

numbers = {1: "бір", 2: "екі", 10: "он"}       # сан — кілт
print(numbers[10])

# bad = {[1, 2]: "тізім"}   # TypeError: unhashable type: 'list'
```

Нәтижесі:
```text
{'а': 100, 'б': 2}
мектеп
он
```

### Мән ретінде тізім

```python
grades = {
    "Айгерім": [5, 5, 4],
    "Бекзат": [4, 3, 5],
}
print(grades["Айгерім"])
print(grades["Бекзат"][2])
print("Айгерімнің орташа бағасы:", sum(grades["Айгерім"]) / len(grades["Айгерім"]))
```

Нәтижесі:
```text
[5, 5, 4]
5
Айгерімнің орташа бағасы: 4.666666666666667
```

## 5. len() және ретпен сақтау

`len(d)` — сөздіктегі **жұптар** саны. Python 3.7-ден бастап сөздік жұптарды **қосылған ретімен** сақтайды, бірақ сөздікте индекс жоқ: `d[0]` — бұл «0 кілтінің мәні», бірінші элемент емес!

```python
fruits = {"алма": 450, "банан": 780, "анар": 1200}
print(len(fruits))
# print(fruits[0])     # KeyError: 0
```

Нәтижесі:
```text
3
```

## 6. Тізім немесе сөздік?

| Сұрақ | Тізім (list) | Сөздік (dict) |
|---|---|---|
| Элементке қалай қатынаймыз? | индекс бойынша `a[0]` | кілт бойынша `d["аты"]` |
| Жазылуы | `[ ]` | `{ кілт: мән }` |
| Рет маңызды ма? | иә, негізгі қасиет | қосылу реті сақталады, бірақ индекс жоқ |
| Іздеу жылдамдығы | баяу (бәрін қарап шығады) | өте жылдам (кілт бойынша бірден) |
| Қашан қолданамыз? | біртекті элементтер қатары (бағалар, сандар) | атау → ақпарат сәйкестігі (контактілер, бағалар журналы) |

### Өмірлік мысал: дүкен бағалары

```python
prices = {"нан": 250, "сүт": 520, "жұмыртқа": 900, "алма": 450}
item = "сүт"
count = 2
print(f"{count} {item}: {prices[item] * count} теңге")
```

Нәтижесі:
```text
2 сүт: 1040 теңге
```

## Жиі кездесетін қателер

**1. Жоқ кілтке қатынау**

```python
prices = {"нан": 250}
# print(prices["Нан"])          # KeyError — регистр маңызды!
print(prices.get("Нан", 0))     # 0
```

**2. Қос нүкте орнына үтір немесе теңдік**

```python
# d = {"аты", "Дана"}     # бұл сөздік емес, жиын болып шығады!
# d = {"аты" = "Дана"}    # SyntaxError
d = {"аты": "Дана"}
print(type(d))
```

**3. Мән бойынша іздеу**

```python
capitals = {"Қазақстан": "Астана"}
print("Астана" in capitals)            # False — in кілттерді тексереді
print("Астана" in capitals.values())   # True — values() мәндерді береді
```

**4. Тізімді кілт ету**

```python
# d = {["a", "b"]: 1}    # TypeError
d = {("a", "b"): 1}      # кортеж — болады
print(d)
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Сөздік (dict) | кілт → мән жұптарының жиынтығы |
| Кілт (key) | мәнді табуға арналған бірегей, өзгермейтін «атау» |
| Мән (value) | кілтпен байланысқан кез келген мәлімет |
| `d[key]` | мәнді алу (кілт жоқ болса — KeyError) |
| `d.get(key, x)` | мәнді қауіпсіз алу (жоқ болса — x немесе None) |
| `key in d` | кілттің бар-жоғын тексеру |
| `zip()` | екі тізімді жұптастыру |

## Ескерту

- Python 3.7-ден бастап сөздік жұптардың қосылу ретін сақтайды (3.6-да бұл CPython-ның ішкі ерекшелігі ғана болған). Ескі нұсқаларда ретке сенуге болмайды.
- Кілт ретінде `1`, `1.0` және `True` бір кілт болып саналады, өйткені олар тең (`1 == 1.0 == True`): `{1: "a", True: "b"}` → `{1: 'b'}`.
- `{}` — бос сөздік, бос жиын емес. Бос жиын тек `set()` арқылы құрылады.
- `zip()` ұзындығы әртүрлі тізімдерде ең қысқасы бойынша тоқтайды; Python 3.10-нан бастап `zip(a, b, strict=True)` ұзындықтар сәйкес келмесе қате береді.
- PEP 8 бойынша сөздік бірнеше жолға жазылса, әр жұпты жеке жолға шегініспен жазып, соңғы жұптан кейін де үтір қою ыңғайлы.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#mapping-types-dict
