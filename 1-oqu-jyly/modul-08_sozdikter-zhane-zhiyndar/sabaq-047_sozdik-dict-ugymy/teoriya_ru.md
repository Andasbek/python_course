## 1. Что такое словарь?

**Словарь (dictionary, dict)** — набор пар **ключ → значение** (key → value). К каждому значению обращаемся не по индексу, а по **ключу**.

Аналогии из жизни:

| «Словарь» в жизни | Ключ | Значение |
|---|---|---|
| Русско-английский словарь | `яблоко` | `apple` |
| Телефонная книжка | `Айгерим` | `87011112233` |
| Классный журнал | имя ученика | оценка |
| Гардероб | номерок | пальто |
| Государства | страна | столица |

## 2. Создание словаря

### С помощью фигурных скобок

```python
phones = {
    "Айгерим": "87011112233",
    "Бекзат": "87772223344",
    "Дана": "87053334455",
}
print(phones)
print(type(phones))
```

Результат:
```text
{'Айгерим': '87011112233', 'Бекзат': '87772223344', 'Дана': '87053334455'}
<class 'dict'>
```

Правила записи:
- словарь заключается в фигурные скобки `{` `}`;
- ключ и значение записываются через `:` (двоеточие);
- пары разделяются `,`.

### Пустой словарь

```python
empty1 = {}
empty2 = dict()
print(empty1, empty2, len(empty1))
```

Результат:
```text
{} {} 0
```

### С помощью функции dict()

```python
capitals = dict(Kazakhstan="Астана", Russia="Москва", Turkey="Анкара")
print(capitals)

pairs = [("яблоко", "apple"), ("кошка", "cat"), ("книга", "book")]
translator = dict(pairs)
print(translator)
```

Результат:
```text
{'Kazakhstan': 'Астана', 'Russia': 'Москва', 'Turkey': 'Анкара'}
{'яблоко': 'apple', 'кошка': 'cat', 'книга': 'book'}
```

В форме `dict(ключ=значение)` ключи должны быть похожи на латинские имена переменных. Создание из списка кортежей работает с любыми ключами.

### Из двух списков: zip()

```python
subjects = ["математика", "физика", "информатика"]
grades = [5, 4, 5]
journal = dict(zip(subjects, grades))
print(journal)
```

Результат:
```text
{'математика': 5, 'физика': 4, 'информатика': 5}
```

`zip()` соединяет элементы двух списков в пары — первый с первым, второй со вторым и т.д.

## 3. Обращение к значению по ключу

```python
student = {"имя": "Алихан", "возраст": 13, "класс": 7, "город": "Алматы"}
print(student["имя"])
print(student["возраст"] + 1)
print(f"{student['имя']} учится в {student['класс']} классе")
```

Результат:
```text
Алихан
14
Алихан учится в 7 классе
```

Примечание: если внутри f-строки используются двойные кавычки, ключ записываем в одинарных кавычках.

### Несуществующий ключ → ошибка

```python
student = {"имя": "Алихан"}
# print(student["фамилия"])    # KeyError: 'фамилия'
```

### Безопасный способ: get()

`d.get(ключ)` возвращает значение, если ключ есть, иначе — `None`. Второй аргумент — значение по умолчанию.

```python
student = {"имя": "Алихан", "возраст": 13}
print(student.get("имя"))
print(student.get("фамилия"))
print(student.get("фамилия", "неизвестно"))
```

Результат:
```text
Алихан
None
неизвестно
```

### Есть ли ключ? — in

Оператор `in` проверяет в словаре **ключи** (а не значения!):

```python
capitals = {"Казахстан": "Астана", "Кыргызстан": "Бишкек"}
print("Казахстан" in capitals)
print("Астана" in capitals)
country = "Узбекистан"
if country in capitals:
    print(capitals[country])
else:
    print(country, "нет в словаре")
```

Результат:
```text
True
False
Узбекистан нет в словаре
```

## 4. Требования к ключам и значениям

**Ключи:**
- должны быть **уникальными**: если один ключ встречается дважды, сохраняется последнее значение;
- должны быть **неизменяемого** типа: `str`, `int`, `float`, `bool`, `tuple`. Список **не может** быть ключом.

**Значения:** любого типа — число, строка, список, даже другой словарь; значения могут повторяться.

```python
d = {"а": 1, "б": 2, "а": 100}
print(d)

points = {(0, 0): "старт", (3, 4): "школа"}   # кортеж — ключ
print(points[(3, 4)])

numbers = {1: "один", 2: "два", 10: "десять"}       # число — ключ
print(numbers[10])

# bad = {[1, 2]: "список"}   # TypeError: unhashable type: 'list'
```

Результат:
```text
{'а': 100, 'б': 2}
школа
десять
```

### Список в качестве значения

```python
grades = {
    "Айгерим": [5, 5, 4],
    "Бекзат": [4, 3, 5],
}
print(grades["Айгерим"])
print(grades["Бекзат"][2])
print("Средний балл Айгерим:", sum(grades["Айгерим"]) / len(grades["Айгерим"]))
```

Результат:
```text
[5, 5, 4]
5
Средний балл Айгерим: 4.666666666666667
```

## 5. len() и порядок хранения

`len(d)` — количество **пар** в словаре. Начиная с Python 3.7 словарь хранит пары **в порядке добавления**, но индексов в словаре нет: `d[0]` — это «значение ключа 0», а не первый элемент!

```python
fruits = {"яблоко": 450, "банан": 780, "гранат": 1200}
print(len(fruits))
# print(fruits[0])     # KeyError: 0
```

Результат:
```text
3
```

## 6. Список или словарь?

| Вопрос | Список (list) | Словарь (dict) |
|---|---|---|
| Как обратиться к элементу? | по индексу `a[0]` | по ключу `d["имя"]` |
| Запись | `[ ]` | `{ ключ: значение }` |
| Важен ли порядок? | да, основное свойство | порядок добавления сохраняется, но индексов нет |
| Скорость поиска | медленно (просматривает всё) | очень быстро (сразу по ключу) |
| Когда используем? | ряд однородных элементов (оценки, числа) | соответствие «название → информация» (контакты, журнал оценок) |

### Пример из жизни: цены в магазине

```python
prices = {"хлеб": 250, "молоко": 520, "яйца": 900, "яблоко": 450}
item = "молоко"
count = 2
print(f"{item} × {count}: {prices[item] * count} тенге")
```

Результат:
```text
молоко × 2: 1040 тенге
```

## Частые ошибки

**1. Обращение к несуществующему ключу**

```python
prices = {"хлеб": 250}
# print(prices["Хлеб"])          # KeyError — регистр важен!
print(prices.get("Хлеб", 0))     # 0
```

**2. Запятая или знак равенства вместо двоеточия**

```python
# d = {"имя", "Дана"}     # это не словарь, получится множество!
# d = {"имя" = "Дана"}    # SyntaxError
d = {"имя": "Дана"}
print(type(d))
```

**3. Поиск по значению**

```python
capitals = {"Казахстан": "Астана"}
print("Астана" in capitals)            # False — in проверяет ключи
print("Астана" in capitals.values())   # True — values() возвращает значения
```

**4. Список в качестве ключа**

```python
# d = {["a", "b"]: 1}    # TypeError
d = {("a", "b"): 1}      # кортеж — можно
print(d)
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Словарь (dict) | набор пар ключ → значение |
| Ключ (key) | уникальное неизменяемое «название» для поиска значения |
| Значение (value) | любые данные, связанные с ключом |
| `d[key]` | получение значения (если ключа нет — KeyError) |
| `d.get(key, x)` | безопасное получение значения (если нет — x или None) |
| `key in d` | проверка наличия ключа |
| `zip()` | соединение двух списков в пары |

## Примечание

- Начиная с Python 3.7 словарь гарантированно сохраняет порядок добавления пар (в 3.6 это было лишь внутренней особенностью CPython). В старых версиях на порядок полагаться нельзя.
- Ключи `1`, `1.0` и `True` считаются одним ключом, так как они равны (`1 == 1.0 == True`): `{1: "a", True: "b"}` → `{1: 'b'}`.
- `{}` — это пустой словарь, а не пустое множество. Пустое множество создаётся только через `set()`.
- `zip()` для списков разной длины останавливается по самому короткому; с Python 3.10 `zip(a, b, strict=True)` вызывает ошибку при несовпадении длин.
- По PEP 8 многострочный словарь удобно записывать по одной паре на строку с отступом и ставить запятую и после последней пары.
- Документация: https://docs.python.org/3/library/stdtypes.html#mapping-types-dict
