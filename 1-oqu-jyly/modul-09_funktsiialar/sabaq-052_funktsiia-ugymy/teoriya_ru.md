## 1. Что такое функция?

**Функция (function)** — часть кода, **имеющая имя** и выполняющая определённую задачу. Её можно написать один раз и **вызывать** по имени из любого места.

Аналогии:
- **Рецепт:** рецепт «как испечь баурсаки» записывается один раз, а «выполняете рецепт» вы столько раз, сколько захотите испечь баурсаки.
- **Кнопка на пульте:** нажимая кнопку «громче», мы получаем результат, даже не зная, что происходит внутри.
- **Кухонный робот:** одна команда «приготовь чай» содержит внутри много действий.

### Преимущества функций

| Преимущество | Пояснение |
|---|---|
| Отсутствие повторов (DRY — Don't Repeat Yourself) | не копируем один и тот же код много раз |
| Понятность | имя `print_menu()` говорит о том, что делает код |
| Лёгкость изменения | исправление делается только в одном месте |
| Разбиение на части | большую задачу делим на маленькие части |
| Командная работа | каждый программист может писать свою функцию |

## 2. Встроенные и пользовательские функции

**Встроенные (built-in) функции** — функции, уже готовые в Python:

```python
print(len("Казахстан"))
print(max(3, 9, 4))
print(abs(-7))
print(round(3.14159, 2))
```

Результат:
```text
9
9
7
3.14
```

Мы пользуемся ими, не зная их внутреннего устройства. Кроме того, программист может создавать **свои (пользовательские) функции**.

## 3. Создание функции с помощью def

Синтаксис:

```
def имя_функции():
    """Краткое описание того, что делает функция."""
    действие 1
    действие 2
```

- `def` (англ. *define* — определить) — ключевое слово, создающее функцию;
- имя функции — по тем же правилам, что и имя переменной (латинские буквы, цифры, `_`; не начинается с цифры);
- `()` — круглые скобки (в них записываются параметры, если они нужны);
- `:` — двоеточие обязательно;
- **тело** функции записывается с отступом в 4 пробела (как у `if`, `for`).

Пример: заголовок, который выводится несколько раз, выносим в функцию:

```python
def print_header():
    print("=" * 30)
    print("  Кружок «Python»")
    print("=" * 30)


print_header()
print("Раздел 1: функции")
print_header()
print("Раздел 2: параметры")
```

Результат:
```text
==============================
  Кружок «Python»
==============================
Раздел 1: функции
==============================
  Кружок «Python»
==============================
Раздел 2: параметры
```

Теперь, чтобы изменить слово «Кружок», исправляем только **одно** место.

### Выбор имени функции

- Имя должно говорить, **что делает** функция: лучше начинать с глагола — `print_menu`, `show_rules`, `draw_line`.
- Слова разделяем знаком `_` (snake_case).
- Не используйте имена встроенных функций (`print`, `len`, `sum`, `list`...).

| Плохое имя | Хорошее имя |
|---|---|
| `f()` | `show_greeting()` |
| `a1()` | `print_rules()` |
| `Menu()` | `print_menu()` |

## 4. Определение и вызов

**Определение** функции (`def ...`) — это только «запись рецепта». При этом код внутри **не выполняется**!

**Вызов** функции — запись её имени со скобками: `print_header()`. Только тогда выполняется её тело.

```python
def say_hello():
    print("Привет!")

print("Программа началась")
say_hello()
say_hello()
print("Программа завершилась")
```

Результат:
```text
Программа началась
Привет!
Привет!
Программа завершилась
```

### Порядок выполнения

1. Python видит строку `def` — «запоминает» функцию, но не выполняет её.
2. Выполняет основную программу сверху вниз.
3. Встретив вызов `say_hello()`, «прыгает» внутрь функции и выполняет её тело.
4. Когда функция завершается, **возвращается** в место вызова и продолжает со следующей строки.

```
Основная программа            Функция
──────────────────            ─────────────────
print("началась")
say_hello()  ───────────────► print("Привет!")
             ◄─────────────── (завершилась)
say_hello()  ───────────────► print("Привет!")
             ◄───────────────
print("завершилась")
```

Эти «прыжки» наглядно видны в пошаговом режиме отладчика (debugger), например в Thonny по клавише F7.

### Сначала определи, потом вызывай

```python
# greet()            # NameError: name 'greet' is not defined
def greet():
    print("Добро пожаловать!")

greet()              # правильно — после определения функции
```

Поэтому обычно все функции пишут в **начале** файла, а основную программу — в **конце**.

## 5. Вызов в цикле

Функцию можно вызывать и в цикле, и в условии:

```python
def draw_star_line():
    print("* " * 5)

for i in range(3):
    draw_star_line()
```

Результат:
```text
* * * * * 
* * * * * 
* * * * * 
```

## 6. Вызов функции из функции

Делим большую задачу на маленькие функции:

```python
def print_line():
    print("-" * 25)


def print_steps():
    print("1. Вскипяти воду")
    print("2. Засыпь чай в заварник")
    print("3. Добавь молоко")


def show_recipe():
    print_line()
    print("ПРИГОТОВЛЕНИЕ ЧАЯ")
    print_line()
    print_steps()
    print_line()


show_recipe()
```

Результат:
```text
-------------------------
ПРИГОТОВЛЕНИЕ ЧАЯ
-------------------------
1. Вскипяти воду
2. Засыпь чай в заварник
3. Добавь молоко
-------------------------
```

Это **проектирование сверху вниз** (декомпозиция): сначала называем большое действие, затем делим его на более мелкие части.

## 7. Docstring — документация функции

В первой строке функции в тройных кавычках можно написать, что она делает. Это называется **docstring**. Функция `help()` показывает его.

```python
def show_menu():
    """Выводит на экран главное меню программы."""
    print("1 — Играть")
    print("2 — Правила")
    print("0 — Выход")


help(show_menu)
```

Результат (сокращённый):
```text
Help on function show_menu in module __main__:

show_menu()
    Выводит на экран главное меню программы.
```

## 8. Пустая функция: pass

Планируя программу, можно заранее написать «каркас» функции. Тело не может быть пустым, поэтому пишем `pass` (ничего не делать):

```python
def play_game():
    pass    # напишем позже


play_game()
print("Игры пока нет :)")
```

Результат:
```text
Игры пока нет :)
```

## 9. Пример: программа с меню на функциях

```python
def show_menu():
    """Показывает меню."""
    print("1 — Приветствие")
    print("2 — Забавный факт")
    print("0 — Выход")


def greet():
    print("Привет, добро пожаловать в мир Python!")


def fun_fact():
    print("Название Python взято не от змеи, а от комедийной группы «Monty Python».")


while True:
    show_menu()
    choice = input("Выбор: ")
    if choice == "1":
        greet()
    elif choice == "2":
        fun_fact()
    elif choice == "0":
        break
    else:
        print("Неверный выбор")
```

Основной цикл стал коротким и понятным: «внутренняя работа» каждого пункта — в отдельной функции.

## Частые ошибки

**1. Забывают скобки**

```python
def hello():
    print("Привет")

hello        # ничего не происходит — функция не вызвана
hello()      # Привет
```

**2. Забывают отступ или не ставят двоеточие**

```python
# def hello()            # SyntaxError: нет двоеточия
# print("Привет")        # IndentationError: нет отступа
def hello():
    print("Привет")
```

**3. Вызов до определения**

```python
# show()                 # NameError
def show():
    print("Показано")

show()
```

**4. Имя функции отдают переменной**

```python
def menu():
    print("Меню")

# menu = "главное"       # теперь menu — строка, menu() → TypeError
menu()
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Функция | часть кода с именем, которую можно использовать повторно |
| `def` | ключевое слово, определяющее функцию |
| Тело функции | команды внутри функции, записанные с отступом |
| Вызов | `имя()` — выполнение функции |
| Встроенная функция | функция, уже готовая в Python (`print`, `len` и др.) |
| Docstring | описание функции, `"""..."""` |
| Декомпозиция | разбиение большой задачи на маленькие части |
| `pass` | «пустая» команда, заполнитель |

## Примечание

- По PEP 8 имена функций пишутся строчными буквами, слова разделяются `_` (`print_menu`), а определения функций отделяются двумя пустыми строками сверху и снизу.
- Функция в Python — обычный объект: `say_hello` (без скобок) обозначает саму функцию, её можно присвоить переменной или передать в другую функцию; а `say_hello()` — это её вызов.
- Docstring по PEP 257 записывают в тройных двойных кавычках и начинают с короткого предложения в первой строке. Его можно прочитать и через `show_menu.__doc__`.
- В больших программах основной код принято помещать в блок `if __name__ == "__main__":` — тогда при импорте файла как модуля он не выполняется автоматически.
- Вместо `pass` можно написать `...` (Ellipsis) — это тоже работает как «пустое» тело.
- Документация: https://docs.python.org/3/tutorial/controlflow.html#defining-functions
