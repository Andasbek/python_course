# Сабақ 52. Практикалық тапсырмалар: функция құру және шақыру

## Базалық деңгей

### 1-тапсырма. Визит карточкасы
`print_card()` функциясын жазыңыз. Ол сіздің атыңызды, мектебіңізді және үйірме атауын рамкада шығарсын. Функцияны 2 рет шақырыңыз.

```text
+------------------------------+
| Аты: Ерасыл                  |
| Мектеп: №120                 |
| Үйірме: Python               |
+------------------------------+
```

### 2-тапсырма. Әнұран жолы
`print_chorus()` функциясы Қазақстан Республикасының Мемлекеттік Әнұранының қайырмасын шығарсын. Бағдарлама екі шумақ арасында қайырманы шақырсын (шумақтарды `print` арқылы жазыңыз немесе мұғалім берген мәтінді қолданыңыз).

### 3-тапсырма. Сызықтар
Үш функция жазыңыз: `line_stars()` (20 жұлдызша), `line_dashes()` (20 сызықша), `line_equals()` (20 теңдік белгісі). Оларды кезекпен шақырып, «жалауша» салыңыз:
```text
********************
--------------------
====================
--------------------
********************
```

### 4-тапсырма. Қауіпсіздік ережелері
`show_rules()` функциясы компьютер кабинетіндегі 5 ережені нөмірлеп шығарсын. Функцияға docstring жазыңыз және `help(show_rules)` арқылы оны көрсетіңіз.

### 5-тапсырма. Цикл ішінде
`print_smile()` функциясы `:-)` белгісін шығарады. Пайдаланушы сан енгізеді, бағдарлама функцияны сонша рет шақырады.

## Кеңейтілген деңгей

### 6-тапсырма. Декомпозиция: үй суреті
Символдармен үй суретін салыңыз. Әр бөлікке жеке функция: `draw_roof()`, `draw_walls()`, `draw_door()`, `draw_ground()`. Ең соңында `draw_house()` функциясы барлығын шақырсын.
```text
    /\
   /  \
  /____\
  |    |
  | [] |
  |____|
~~~~~~~~~~
```

### 7-тапсырма. Мәзірлі калькулятор
Мәзірлі бағдарлама: `1 — қосу`, `2 — көбейту`, `3 — квадратқа шығару`, `0 — шығу`. Әр пункт жеке параметрсіз функция: функция ішінде сандарды `input()` арқылы сұрап, нәтижені шығарады. Мәзірдің өзі де `show_menu()` функциясы болсын.

### 8-тапсырма. Қате табу
Төмендегі кодта 4 қате бар. Тауып, түзетіңіз:
```text
def greeting()
print("Қайырлы таң!")

greeting
Greeting()
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Мәтіндік квест
Шағын мәтіндік ойын жазыңыз: әр «бөлме» — жеке функция (`room_start()`, `room_forest()`, `room_cave()`, `room_treasure()`). Әр бөлмеде ойыншыға таңдау беріледі де, таңдауға қарай келесі бөлменің функциясы шақырылады. Ойын «қазына табылды» немесе «жол адасты» деп аяқталады.

### 10-тапсырма. Кім шақырды?
Келесі бағдарлама не шығарады? Алдымен дәптерге жазыңыз, кейін тексеріңіз.
```python
def a():
    print("A басталды")
    b()
    print("A аяқталды")


def b():
    print("  B")
    c()


def c():
    print("    C")


print("Басы")
a()
c()
print("Соңы")
```

**7-тапсырма**
```python
def show_menu():
    print("1 — қосу, 2 — көбейту, 3 — квадрат, 0 — шығу")


def add_numbers():
    a = float(input("a = "))
    b = float(input("b = "))
    print("Қосынды:", a + b)


def multiply_numbers():
    a = float(input("a = "))
    b = float(input("b = "))
    print("Көбейтінді:", a * b)


def square_number():
    a = float(input("a = "))
    print("Квадраты:", a ** 2)


while True:
    show_menu()
    choice = input("Таңдау: ")
    if choice == "1":
        add_numbers()
    elif choice == "2":
        multiply_numbers()
    elif choice == "3":
        square_number()
    elif choice == "0":
        break
    else:
        print("Қате таңдау")
```

**9-тапсырма (үлгі)**
```python
def room_treasure():
    print("Сандық ашылды — қазына табылды! Жеңіс!")


def room_lost():
    print("Сіз адасып кеттіңіз... Ойын аяқталды.")


def room_cave():
    print("Үңгірдесіз. Алдыңызда екі есік: алтын (1) немесе темір (2).")
    if input("> ") == "1":
        room_treasure()
    else:
        room_lost()


def room_forest():
    print("Орманға кірдіңіз. Сұңқар ұшып барады. Соңынан ересіз бе? (иә/жоқ)")
    if input("> ").lower() == "иә":
        room_cave()
    else:
        room_lost()


def room_start():
    print("Сіз Алатау баурайындасыз. Орманға (1) әлде өзенге (2)?")
    if input("> ") == "1":
        room_forest()
    else:
        room_lost()


room_start()
```
