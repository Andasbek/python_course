## 1. Функция дегеніміз не?

**Функция (функция, function)** — белгілі бір міндетті орындайтын, **атауы бар** код бөлігі. Оны бір рет жазып, кез келген жерден атымен **шақыруға** болады.

Аналогиялар:
- **Рецепт:** «бауырсақ пісіру» рецепті бір рет жазылады, ал бауырсақты қанша рет пісіргіңіз келсе, сонша рет «рецептті орындайсыз».
- **Пульттегі батырма:** «дыбысты көтеру» батырмасын басқанда іште не болатынын білмесек те, нәтижесін аламыз.
- **Ас үй роботы:** «шай дайында» деген бір команда ішінде көп әрекеттер бар.

### Функцияның артықшылықтары

| Артықшылық | Түсіндірме |
|---|---|
| Қайталанбау (DRY — Don't Repeat Yourself) | бір кодты көп рет көшірмейміз |
| Түсініктілік | `print_menu()` деген атау кодтың не істейтінін айтып тұр |
| Өзгертуге оңай | түзету бір ғана жерде жасалады |
| Бөлшектеу | үлкен есепті кішкентай бөліктерге бөлеміз |
| Командалық жұмыс | әр бағдарламашы өз функциясын жаза алады |

## 2. Кірістірілген және пайдаланушы функциялары

**Кірістірілген (встроенные, built-in) функциялар** — Python-да дайын тұрған функциялар:

```python
print(len("Қазақстан"))
print(max(3, 9, 4))
print(abs(-7))
print(round(3.14159, 2))
```

Нәтижесі:
```text
9
9
7
3.14
```

Біз оларды ішкі құрылысын білмей-ақ қолданамыз. Сонымен қатар бағдарламашы **өз функцияларын** (пайдаланушы функцияларын) құра алады.

## 3. def арқылы функция құру

Синтаксис:

```
def функция_аты():
    """Функция не істейтіні туралы қысқаша сипаттама."""
    әрекет 1
    әрекет 2
```

- `def` (ағылш. *define* — анықтау) — функция құратын кілт сөз;
- функция аты — айнымалы атауы сияқты ережелермен (латын әріптері, цифр, `_`; цифрдан басталмайды);
- `()` — жай жақшалар (қажет болса, оларға параметрлер жазылады);
- `:` — қос нүкте міндетті;
- функция **денесі** — 4 бос орын шегініспен жазылады (`if`, `for` сияқты).

Мысал: бірнеше рет шығарылатын тақырыпты функцияға бөлеміз:

```python
def print_header():
    print("=" * 30)
    print("  «Python» үйірмесі")
    print("=" * 30)


print_header()
print("1-бөлім: функциялар")
print_header()
print("2-бөлім: параметрлер")
```

Нәтижесі:
```text
==============================
  «Python» үйірмесі
==============================
1-бөлім: функциялар
==============================
  «Python» үйірмесі
==============================
2-бөлім: параметрлер
```

Енді «үйірмесі» сөзін өзгерту үшін тек **бір** жерді түзетеміз.

### Функция атауын таңдау

- Атау функцияның **не істейтінін** айтсын: етістіктен басталғаны жөн — `print_menu`, `show_rules`, `draw_line`.
- Сөздерді `_` арқылы бөлеміз (snake_case).
- Кірістірілген функциялардың атын қолданбаңыз (`print`, `len`, `sum`, `list`...).

| Жаман атау | Жақсы атау |
|---|---|
| `f()` | `show_greeting()` |
| `a1()` | `print_rules()` |
| `Menu()` | `print_menu()` |

## 4. Анықтау мен шақыру

Функцияны **анықтау** (`def ...`) — тек «рецептті жазу». Бұл кезде ішіндегі код **орындалмайды**!

Функцияны **шақыру** — оның атын жақшамен жазу: `print_header()`. Тек сонда денесі орындалады.

```python
def say_hello():
    print("Сәлем!")

print("Бағдарлама басталды")
say_hello()
say_hello()
print("Бағдарлама аяқталды")
```

Нәтижесі:
```text
Бағдарлама басталды
Сәлем!
Сәлем!
Бағдарлама аяқталды
```

### Орындалу реті

1. Python `def` жолын көреді — функцияны «есте сақтайды», бірақ орындамайды.
2. Негізгі бағдарламаны жоғарыдан төмен қарай орындайды.
3. `say_hello()` шақыруын кездестіргенде — функцияның ішіне «секіреді», денесін орындайды.
4. Функция аяқталғанда, шақырылған жерге **қайтып**, келесі жолдан жалғастырады.

```
Негізгі бағдарлама            Функция
──────────────────            ─────────────────
print("басталды")
say_hello()  ───────────────► print("Сәлем!")
             ◄─────────────── (аяқталды)
say_hello()  ───────────────► print("Сәлем!")
             ◄───────────────
print("аяқталды")
```

Бұл «секірулерді» жөндеушінің (debugger) қадамдық режимінде анық көруге болады, мысалы, Thonny-де F7 пернесімен.

### Алдымен анықта, сосын шақыр

```python
# greet()            # NameError: name 'greet' is not defined
def greet():
    print("Қош келдіңіз!")

greet()              # дұрыс — функция анықталғаннан кейін
```

Сондықтан әдетте барлық функциялар файлдың **басында**, негізгі бағдарлама **соңында** жазылады.

## 5. Цикл ішінде шақыру

Функцияны циклде де, шартта да шақыруға болады:

```python
def draw_star_line():
    print("* " * 5)

for i in range(3):
    draw_star_line()
```

Нәтижесі:
```text
* * * * * 
* * * * * 
* * * * * 
```

## 6. Функциядан функцияны шақыру

Үлкен міндетті кішкене функцияларға бөлеміз:

```python
def print_line():
    print("-" * 25)


def print_steps():
    print("1. Суды қайнат")
    print("2. Шәйнекке шай сал")
    print("3. Сүт қос")


def show_recipe():
    print_line()
    print("ШАЙ ДАЙЫНДАУ")
    print_line()
    print_steps()
    print_line()


show_recipe()
```

Нәтижесі:
```text
-------------------------
ШАЙ ДАЙЫНДАУ
-------------------------
1. Суды қайнат
2. Шәйнекке шай сал
3. Сүт қос
-------------------------
```

Бұл — **жоғарыдан төмен жобалау** (декомпозиция): алдымен үлкен әрекетті атаймыз, кейін оны кішірек бөліктерге бөлеміз.

## 7. Docstring — функцияның құжаттамасы

Функцияның бірінші жолына үш тырнақшамен оның не істейтінін жазуға болады. Бұл **docstring** деп аталады. `help()` функциясы оны көрсетеді.

```python
def show_menu():
    """Бағдарламаның басты мәзірін экранға шығарады."""
    print("1 — Ойнау")
    print("2 — Ережелер")
    print("0 — Шығу")


help(show_menu)
```

Нәтижесі (қысқартылған):
```text
Help on function show_menu in module __main__:

show_menu()
    Бағдарламаның басты мәзірін экранға шығарады.
```

## 8. Бос функция: pass

Бағдарламаны жоспарлағанда функцияның «қаңқасын» алдын ала жазып қоюға болады. Денесі бос болмауы тиіс, сондықтан `pass` (ештеңе істеме) жазамыз:

```python
def play_game():
    pass    # кейін жазамыз


play_game()
print("Әзірге ойын жоқ :)")
```

Нәтижесі:
```text
Әзірге ойын жоқ :)
```

## 9. Мысал: мәзірлі бағдарлама функциялармен

```python
def show_menu():
    """Мәзірді көрсетеді."""
    print("1 — Сәлемдесу")
    print("2 — Күлкілі факт")
    print("0 — Шығу")


def greet():
    print("Сәлем, Python әлеміне қош келдіңіз!")


def fun_fact():
    print("Python атауы жыланнан емес, «Monty Python» комедиялық тобынан алынған.")


while True:
    show_menu()
    choice = input("Таңдау: ")
    if choice == "1":
        greet()
    elif choice == "2":
        fun_fact()
    elif choice == "0":
        break
    else:
        print("Қате таңдау")
```

Негізгі цикл қысқа әрі түсінікті болды: әр пункттің «ішкі жұмысы» жеке функцияда.

## Жиі кездесетін қателер

**1. Жақшаны ұмыту**

```python
def hello():
    print("Сәлем")

hello        # ештеңе болмайды — функция шақырылмады
hello()      # Сәлем
```

**2. Шегіністі ұмыту немесе қос нүктені жазбау**

```python
# def hello()            # SyntaxError: қос нүкте жоқ
# print("Сәлем")         # IndentationError: шегініс жоқ
def hello():
    print("Сәлем")
```

**3. Анықтамас бұрын шақыру**

```python
# show()                 # NameError
def show():
    print("Көрсетілді")

show()
```

**4. Функцияның атын айнымалыға беріп қою**

```python
def menu():
    print("Мәзір")

# menu = "басты"         # енді menu — жол, menu() → TypeError
menu()
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Функция | атауы бар, қайта қолдануға болатын код бөлігі |
| `def` | функцияны анықтайтын кілт сөз |
| Функция денесі | шегініспен жазылған функция ішіндегі командалар |
| Шақыру | `атауы()` — функцияны орындау |
| Кірістірілген функция | Python-да дайын тұрған функция (`print`, `len` т.б.) |
| Docstring | функцияның сипаттамасы, `"""..."""` |
| Декомпозиция | үлкен есепті кіші бөліктерге бөлу |
| `pass` | «бос» команда, орын толтырғыш |

## Ескерту

- PEP 8 бойынша функция атаулары кіші әріптермен, сөздер `_` арқылы жазылады (`print_menu`), ал функция анықтамаларының алдынан және артынан екі бос жол қалдырылады.
- Функция — Python-да кәдімгі объект: `say_hello` (жақшасыз) функцияның өзін білдіреді, оны айнымалыға меншіктеуге немесе басқа функцияға беруге болады; ал `say_hello()` — оны шақыру.
- Docstring-ті PEP 257 бойынша үш қос тырнақпен жазып, бірінші жолын қысқа сөйлеммен бастайды. Оны `show_menu.__doc__` арқылы да оқуға болады.
- Ірі бағдарламада негізгі кодты `if __name__ == "__main__":` блогына жазу әдетке айналған — сонда файлды модуль ретінде импорттағанда ол автоматты түрде орындалмайды.
- `pass` орнына `...` (Ellipsis) жазуға да болады — бұл да «бос» дене ретінде жұмыс істейді.
- Құжаттама: https://docs.python.org/3/tutorial/controlflow.html#defining-functions
