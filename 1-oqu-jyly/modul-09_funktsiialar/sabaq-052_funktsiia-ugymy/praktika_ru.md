# Урок 52. Практические задания: создание и вызов функции

## Базовый уровень

### Задание 1. Визитная карточка
Напишите функцию `print_card()`. Она должна выводить в рамке ваше имя, школу и название кружка. Вызовите функцию 2 раза.

```text
+------------------------------+
| Имя: Ерасыл                  |
| Школа: №120                  |
| Кружок: Python               |
+------------------------------+
```

### Задание 2. Строки гимна
Функция `print_chorus()` должна выводить припев Государственного гимна Республики Казахстан (на государственном языке). Программа должна вызывать припев между двумя куплетами (запишите куплеты с помощью `print` или используйте текст, выданный учителем).

### Задание 3. Линии
Напишите три функции: `line_stars()` (20 звёздочек), `line_dashes()` (20 дефисов), `line_equals()` (20 знаков равенства). Вызывая их по очереди, нарисуйте «флажок»:
```text
********************
--------------------
====================
--------------------
********************
```

### Задание 4. Правила безопасности
Функция `show_rules()` должна выводить 5 пронумерованных правил поведения в компьютерном классе. Напишите для функции docstring и покажите его с помощью `help(show_rules)`.

### Задание 5. В цикле
Функция `print_smile()` выводит смайлик `:-)`. Пользователь вводит число, программа вызывает функцию столько раз.

## Продвинутый уровень

### Задание 6. Декомпозиция: рисунок дома

```text
    /\
   /  \
  /____\
  |    |

  |____|
~~~~~~~~~~
```

### Задание 7. Калькулятор с меню
Программа с меню: `1 — сложение`, `2 — умножение`, `3 — возведение в квадрат`, `0 — выход`. Каждый пункт — отдельная функция без параметров: внутри функции числа запрашиваются через `input()`, и выводится результат. Само меню тоже должно быть функцией `show_menu()`.

## ★ Олимпиадная / творческая задача

### Задание 9. Текстовый квест
Напишите небольшую текстовую игру: каждая «комната» — отдельная функция (`room_start()`, `room_forest()`, `room_cave()`, `room_treasure()`). В каждой комнате игроку даётся выбор, и в зависимости от выбора вызывается функция следующей комнаты. Игра заканчивается словами «сокровище найдено» или «вы заблудились».

### Задание 10. Кто вызвал?
Что выведет следующая программа? Сначала запишите в тетрадь, потом проверьте.
```python
def a():
    print("A начата")
    b()
    print("A завершена")


def b():
    print("  B")
    c()


def c():
    print("    C")


print("Начало")
a()
c()
print("Конец")
```

**Задание 7**
```python
def show_menu():
    print("1 — сложение, 2 — умножение, 3 — квадрат, 0 — выход")


def add_numbers():
    a = float(input("a = "))
    b = float(input("b = "))
    print("Сумма:", a + b)


def multiply_numbers():
    a = float(input("a = "))
    b = float(input("b = "))
    print("Произведение:", a * b)


def square_number():
    a = float(input("a = "))
    print("Квадрат:", a ** 2)


while True:
    show_menu()
    choice = input("Выбор: ")
    if choice == "1":
        add_numbers()
    elif choice == "2":
        multiply_numbers()
    elif choice == "3":
        square_number()
    elif choice == "0":
        break
    else:
        print("Неверный выбор")
```

```python
def room_treasure():
    print("Сундук открыт — сокровище найдено! Победа!")


def room_lost():
    print("Вы заблудились... Игра окончена.")


def room_cave():
    print("Вы в пещере. Перед вами две двери: золотая (1) или железная (2).")
    if input("> ") == "1":
        room_treasure()
    else:
        room_lost()


def room_forest():
    print("Вы вошли в лес. Пролетает сокол. Последуете за ним? (да/нет)")
    if input("> ").lower() == "да":
        room_cave()
    else:
        room_lost()


def room_start():
    print("Вы у подножия Алатау. В лес (1) или к реке (2)?")
    if input("> ") == "1":
        room_forest()
    else:
        room_lost()


room_start()
```
