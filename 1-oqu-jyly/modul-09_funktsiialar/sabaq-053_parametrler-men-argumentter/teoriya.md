## 1. Параметр және аргумент

```python
def greet(name):          # name — ПАРАМЕТР
    print(f"Сәлем, {name}!")


greet("Айгерім")          # "Айгерім" — АРГУМЕНТ
greet("Бекзат")
```

Нәтижесі:
```text
Сәлем, Айгерім!
Сәлем, Бекзат!
```

| Ұғым | Қайда жазылады | Мағынасы |
|---|---|---|
| **Параметр** | `def` жолында, жақша ішінде | функция ішіндегі «бос ұяшық», айнымалы |
| **Аргумент** | шақыру кезінде, жақша ішінде | ұяшыққа салынатын нақты мән |

Аналогия: бланкідегі «Аты: ______» жолы — параметр, ал оған жазылған «Айгерім» — аргумент.

Шақыру кезінде Python шын мәнінде `name = "Айгерім"` меншіктеуін орындайды, кейін функция денесін іске қосады.

Аргумент ретінде кез келген өрнек беруге болады — айнымалы, есептеу, басқа функцияның нәтижесі:

```python
def show_square(n):
    print(f"{n} санының квадраты = {n * n}")


x = 7
show_square(x)
show_square(x + 3)
show_square(len("Абай"))
```

Нәтижесі:
```text
7 санының квадраты = 49
10 санының квадраты = 100
4 санының квадраты = 16
```

## 2. Бірнеше параметр

Параметрлер үтір арқылы жазылады:

```python
def draw_line(symbol, length):
    print(symbol * length)


draw_line("*", 20)
draw_line("-", 10)
draw_line("=", 15)
```

Нәтижесі:
```text
********************
----------
===============
```

Әр символға жеке функция (`draw_star_line`, `draw_dash_line`, …) жазудың орнына **бір** әмбебап функция жеткілікті.

### Позициялық аргументтер

Аргументтер параметрлерге **ретімен** сәйкестендіріледі: бірінші аргумент → бірінші параметр, екіншісі → екінші параметр.

```python
def introduce(name, age, city):
    print(f"Менің атым {name}, {age} жастамын, {city} қаласынанмын.")


introduce("Дана", 13, "Тараз")
introduce(13, "Дана", "Тараз")     # рет шатасты!
```

Нәтижесі:
```text
Менің атым Дана, 13 жастамын, Тараз қаласынанмын.
Менің атым 13, Дана жастамын, Тараз қаласынанмын.
```

Аргументтер саны параметрлер санына **сәйкес** болуы керек:

```python
def introduce(name, age):
    print(name, age)

# introduce("Дана")    # TypeError: introduce() missing 1 required positional argument: 'age'
# introduce("Дана", 13, "Тараз")   # TypeError: takes 2 positional arguments but 3 were given
introduce("Дана", 13)
```

## 3. Атаулы (кілттік) аргументтер

Аргументті параметрдің **атымен** беруге болады — сонда рет маңызды емес:

```python
def introduce(name, age, city):
    print(f"{name}, {age} жас, {city}")


introduce(city="Ақтау", name="Ерлан", age=14)
introduce("Мадина", city="Семей", age=12)
```

Нәтижесі:
```text
Ерлан, 14 жас, Ақтау
Мадина, 12 жас, Семей
```

**Ереже:** позициялық аргументтер атаулы аргументтерден **бұрын** жазылады: `introduce(name="Мадина", 12, "Семей")` — қате.

Атаулы аргументтер кірістірілген функцияларда да жиі кездеседі: `print("a", "b", sep="-", end="!")`, `sorted(lst, reverse=True)`.

## 4. Үнсіз келісім бойынша параметрлер

Параметрге **әдепкі мән** (значение по умолчанию, default value) беруге болады. Шақыруда аргумент берілмесе — әдепкі мән қолданылады.

```python
def greet(name, greeting="Сәлем"):
    print(f"{greeting}, {name}!")


greet("Айгерім")
greet("Бекзат", "Қайырлы таң")
greet("Дана", greeting="Қош келдіңіз")
```

Нәтижесі:
```text
Сәлем, Айгерім!
Қайырлы таң, Бекзат!
Қош келдіңіз, Дана!
```

Кофе аппараты аналогиясы: көлемін таңдамасаңыз — «орташа» құяды.

```python
def draw_line(length=20, symbol="-"):
    print(symbol * length)


draw_line()                 # екеуі де әдепкі
draw_line(10)               # length=10
draw_line(5, "*")
draw_line(symbol="~")       # тек symbol береміз
```

Нәтижесі:
```text
--------------------
----------
*****
~~~~~~~~~~~~~~~~~~~~
```

### Жазылу ережесі

Әдепкі мәні бар параметрлер міндетті параметрлерден **кейін** жазылады:

```python
# def order(size="орташа", drink):       # SyntaxError: non-default argument follows default argument
def order(drink, size="орташа", sugar=True):
    text = f"{drink} ({size})"
    if not sugar:
        text += ", қантсыз"
    print("Тапсырыс:", text)


order("капучино")
order("латте", "үлкен")
order("шай", sugar=False)
```

Нәтижесі:
```text
Тапсырыс: капучино (орташа)
Тапсырыс: латте (үлкен)
Тапсырыс: шай (орташа), қантсыз
```

## 5. Функцияға тізім мен сөздік беру

Параметр кез келген типтегі мәнді қабылдай алады:

```python
def print_list(items, title="Тізім"):
    print(f"--- {title} ---")
    for i in range(len(items)):
        print(f"{i + 1}. {items[i]}")


print_list(["нан", "сүт", "алма"], "Сатып алу")
print_list(["Python", "Шахмат"])
```

Нәтижесі:
```text
--- Сатып алу ---
1. нан
2. сүт
3. алма
--- Тізім ---
1. Python
2. Шахмат
```

```python
def print_report(grades):
    for name, mark in grades.items():
        print(f"{name:<10}{mark}")
    print("Орташа:", sum(grades.values()) / len(grades))


print_report({"Айгерім": 5, "Бекзат": 4, "Дана": 5})
```

Нәтижесі:
```text
Айгерім   5
Бекзат    4
Дана      5
Орташа: 4.666666666666667
```

**Абай болыңыз:** функция ішінде тізімді немесе сөздікті **өзгертсек** (`append`, `d[k] = v`), өзгеріс функциядан тыс та көрінеді — себебі функцияға сол объектінің өзі беріледі, көшірмесі емес.

```python
def add_bonus(scores):
    for name in scores:
        scores[name] += 5


results = {"Әлихан": 80, "Нұрай": 90}
add_bonus(results)
print(results)
```

Нәтижесі:
```text
{'Әлихан': 85, 'Нұрай': 95}
```

### Әдепкі мән ретінде тізім бермеңіз!

```python
def add_item(item, basket=None):
    if basket is None:      # әр шақыруда жаңа тізім
        basket = []
    basket.append(item)
    print(basket)


add_item("алма")
add_item("нан")
```

Нәтижесі:
```text
['алма']
['нан']
```

`def add_item(item, basket=[])` деп жазсақ, бір ғана тізім барлық шақыруларда ортақ болып қалады — бұл тәжірибелі бағдарламашылардың да жиі қатесі.

## 6. Мысал: чек шығару функциясы

```python
def print_receipt(item, price, count=1, discount=0):
    """Тауар чегін шығарады. discount — пайызбен."""
    total = price * count
    total = total - total * discount / 100
    print(f"{item}: {count} × {price} тг")
    if discount > 0:
        print(f"Жеңілдік: {discount}%")
    print(f"Төлеуге: {total:.0f} тг")
    print("-" * 20)


print_receipt("Дәптер", 150, 10)
print_receipt("Рюкзак", 12000, discount=15)
```

Нәтижесі:
```text
Дәптер: 10 × 150 тг
Төлеуге: 1500 тг
--------------------
Рюкзак: 1 × 12000 тг
Жеңілдік: 15%
Төлеуге: 10200 тг
--------------------
```

## Жиі кездесетін қателер

**1. Аргументтер саны сәйкес емес**

```python
def area(a, b):
    print(a * b)

# area(5)        # TypeError: missing 1 required positional argument
area(5, 3)
```

**2. Аргументтер ретін шатастыру**

```python
def divide(a, b):
    print(a / b)

divide(10, 2)        # 5.0
divide(2, 10)        # 0.2 — басқа нәтиже!
divide(b=2, a=10)    # 5.0 — атаулы аргументтермен қауіпсіз
```

**3. Әдепкі параметрді міндеттіден бұрын жазу**

```python
# def f(a=1, b):     # SyntaxError
def f(b, a=1):
    print(a, b)

f(5)
```

**4. Параметрді функция ішінде input()-пен «жою»**

```python
def greet(name):
    # name = input("Атың? ")   # қате ой: берілген аргумент жойылады
    print("Сәлем,", name)

greet("Дана")
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Параметр | функция анықтамасындағы айнымалы: `def f(x):` |
| Аргумент | шақыру кезінде берілетін нақты мән: `f(5)` |
| Позициялық аргумент | ретімен сәйкестендірілетін аргумент |
| Атаулы аргумент | `атау=мән` түрінде берілетін аргумент |
| Әдепкі мән (default) | аргумент берілмесе қолданылатын мән: `def f(x=10):` |
| `None` | «мән жоқ» дегенді білдіретін арнайы мән |

## Ескерту

- PEP 8 бойынша атаулы аргументте және әдепкі мәнде `=` белгісінің айналасына бос орын қойылмайды: `greet("Дана", greeting="Сәлем")`, `def f(x=10):`.
- Әдепкі мән функция **анықталған кезде бір рет** есептеледі. Сондықтан өзгермелі объектіні (`[]`, `{}`) әдепкі мән етпей, `None` қолданылады.
- Тек атаулы түрде берілетін параметрлерді `*` арқылы белгілеуге болады: `def order(drink, *, sugar=True):` — енді `order("шай", False)` қате береді, `order("шай", sugar=False)` дұрыс.
- Аргументтер саны алдын ала белгісіз болса, `*args` (позициялық аргументтер кортежі) және `**kwargs` (атаулы аргументтер сөздігі) қолданылады: `def total(*args): return sum(args)`.
- Python 3.8-ден бастап `/` белгісі тек позициялық параметрлерді көрсетеді: `def f(a, b, /):`.
- Құжаттама: https://docs.python.org/3/tutorial/controlflow.html#more-on-defining-functions
