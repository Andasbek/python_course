## 1. Параметр и аргумент

```python
def greet(name):          # name — ПАРАМЕТР
    print(f"Привет, {name}!")


greet("Айгерим")          # "Айгерим" — АРГУМЕНТ
greet("Бекзат")
```

Результат:
```text
Привет, Айгерим!
Привет, Бекзат!
```

| Понятие | Где записывается | Значение |
|---|---|---|
| **Параметр** | в строке `def`, в скобках | «пустая ячейка» внутри функции, переменная |
| **Аргумент** | при вызове, в скобках | конкретное значение, помещаемое в ячейку |

Аналогия: строка «Имя: ______» на бланке — параметр, а вписанное в неё «Айгерим» — аргумент.

При вызове Python на самом деле выполняет присваивание `name = "Айгерим"`, а затем запускает тело функции.

В качестве аргумента можно передать любое выражение — переменную, вычисление, результат другой функции:

```python
def show_square(n):
    print(f"Квадрат числа {n} = {n * n}")


x = 7
show_square(x)
show_square(x + 3)
show_square(len("Абай"))
```

Результат:
```text
Квадрат числа 7 = 49
Квадрат числа 10 = 100
Квадрат числа 4 = 16
```

## 2. Несколько параметров

Параметры записываются через запятую:

```python
def draw_line(symbol, length):
    print(symbol * length)


draw_line("*", 20)
draw_line("-", 10)
draw_line("=", 15)
```

Результат:
```text
********************
----------
===============
```

Вместо отдельной функции для каждого символа (`draw_star_line`, `draw_dash_line`, …) достаточно **одной** универсальной функции.

### Позиционные аргументы

Аргументы сопоставляются с параметрами **по порядку**: первый аргумент → первый параметр, второй → второй параметр.

```python
def introduce(name, age, city):
    print(f"Меня зовут {name}, мне {age} лет, я из города {city}.")


introduce("Дана", 13, "Тараз")
introduce(13, "Дана", "Тараз")     # порядок перепутан!
```

Результат:
```text
Меня зовут Дана, мне 13 лет, я из города Тараз.
Меня зовут 13, мне Дана лет, я из города Тараз.
```

Количество аргументов должно **совпадать** с количеством параметров:

```python
def introduce(name, age):
    print(name, age)

# introduce("Дана")    # TypeError: introduce() missing 1 required positional argument: 'age'
# introduce("Дана", 13, "Тараз")   # TypeError: takes 2 positional arguments but 3 were given
introduce("Дана", 13)
```

## 3. Именованные (ключевые) аргументы

Аргумент можно передать по **имени** параметра — тогда порядок не важен:

```python
def introduce(name, age, city):
    print(f"{name}, {age} лет, {city}")


introduce(city="Актау", name="Ерлан", age=14)
introduce("Мадина", city="Семей", age=12)
```

Результат:
```text
Ерлан, 14 лет, Актау
Мадина, 12 лет, Семей
```

**Правило:** позиционные аргументы записываются **перед** именованными: `introduce(name="Мадина", 12, "Семей")` — ошибка.

Именованные аргументы часто встречаются и у встроенных функций: `print("a", "b", sep="-", end="!")`, `sorted(lst, reverse=True)`.

## 4. Параметры по умолчанию

Параметру можно задать **значение по умолчанию** (default value). Если при вызове аргумент не передан — используется значение по умолчанию.

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")


greet("Айгерим")
greet("Бекзат", "Доброе утро")
greet("Дана", greeting="Добро пожаловать")
```

Результат:
```text
Привет, Айгерим!
Доброе утро, Бекзат!
Добро пожаловать, Дана!
```

Аналогия с кофейным автоматом: если не выбрать объём — нальёт «средний».

```python
def draw_line(length=20, symbol="-"):
    print(symbol * length)


draw_line()                 # оба по умолчанию
draw_line(10)               # length=10
draw_line(5, "*")
draw_line(symbol="~")       # передаём только symbol
```

Результат:
```text
--------------------
----------
*****
~~~~~~~~~~~~~~~~~~~~
```

### Правило записи

Параметры со значением по умолчанию записываются **после** обязательных параметров:

```python
# def order(size="средний", drink):       # SyntaxError: non-default argument follows default argument
def order(drink, size="средний", sugar=True):
    text = f"{drink} ({size})"
    if not sugar:
        text += ", без сахара"
    print("Заказ:", text)


order("капучино")
order("латте", "большой")
order("чай", sugar=False)
```

Результат:
```text
Заказ: капучино (средний)
Заказ: латте (большой)
Заказ: чай (средний), без сахара
```

## 5. Передача списка и словаря в функцию

Параметр может принимать значение любого типа:

```python
def print_list(items, title="Список"):
    print(f"--- {title} ---")
    for i in range(len(items)):
        print(f"{i + 1}. {items[i]}")


print_list(["хлеб", "молоко", "яблоко"], "Покупки")
print_list(["Python", "Шахматы"])
```

Результат:
```text
--- Покупки ---
1. хлеб
2. молоко
3. яблоко
--- Список ---
1. Python
2. Шахматы
```

```python
def print_report(grades):
    for name, mark in grades.items():
        print(f"{name:<10}{mark}")
    print("Среднее:", sum(grades.values()) / len(grades))


print_report({"Айгерим": 5, "Бекзат": 4, "Дана": 5})
```

Результат:
```text
Айгерим   5
Бекзат    4
Дана      5
Среднее: 4.666666666666667
```

**Будьте внимательны:** если внутри функции **изменить** список или словарь (`append`, `d[k] = v`), изменение будет видно и вне функции — потому что в функцию передаётся сам объект, а не его копия.

```python
def add_bonus(scores):
    for name in scores:
        scores[name] += 5


results = {"Алихан": 80, "Нурай": 90}
add_bonus(results)
print(results)
```

Результат:
```text
{'Алихан': 85, 'Нурай': 95}
```

### Не задавайте список значением по умолчанию!

```python
def add_item(item, basket=None):
    if basket is None:      # при каждом вызове новый список
        basket = []
    basket.append(item)
    print(basket)


add_item("яблоко")
add_item("хлеб")
```

Результат:
```text
['яблоко']
['хлеб']
```

Если написать `def add_item(item, basket=[])`, один и тот же список будет общим для всех вызовов — это частая ошибка даже у опытных программистов.

## 6. Пример: функция печати чека

```python
def print_receipt(item, price, count=1, discount=0):
    """Выводит чек за товар. discount — в процентах."""
    total = price * count
    total = total - total * discount / 100
    print(f"{item}: {count} × {price} тг")
    if discount > 0:
        print(f"Скидка: {discount}%")
    print(f"К оплате: {total:.0f} тг")
    print("-" * 20)


print_receipt("Тетрадь", 150, 10)
print_receipt("Рюкзак", 12000, discount=15)
```

Результат:
```text
Тетрадь: 10 × 150 тг
К оплате: 1500 тг
--------------------
Рюкзак: 1 × 12000 тг
Скидка: 15%
К оплате: 10200 тг
--------------------
```

## Частые ошибки

**1. Количество аргументов не совпадает**

```python
def area(a, b):
    print(a * b)

# area(5)        # TypeError: missing 1 required positional argument
area(5, 3)
```

**2. Путают порядок аргументов**

```python
def divide(a, b):
    print(a / b)

divide(10, 2)        # 5.0
divide(2, 10)        # 0.2 — другой результат!
divide(b=2, a=10)    # 5.0 — с именованными аргументами безопасно
```

**3. Параметр по умолчанию записан перед обязательным**

```python
# def f(a=1, b):     # SyntaxError
def f(b, a=1):
    print(a, b)

f(5)
```

**4. «Затирание» параметра с помощью input() внутри функции**

```python
def greet(name):
    # name = input("Как тебя зовут? ")   # неверная идея: переданный аргумент теряется
    print("Привет,", name)

greet("Дана")
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Параметр | переменная в определении функции: `def f(x):` |
| Аргумент | конкретное значение, передаваемое при вызове: `f(5)` |
| Позиционный аргумент | аргумент, сопоставляемый по порядку |
| Именованный аргумент | аргумент, передаваемый в виде `имя=значение` |
| Значение по умолчанию (default) | значение, используемое, если аргумент не передан: `def f(x=10):` |
| `None` | специальное значение, означающее «нет значения» |

## Примечание

- По PEP 8 вокруг `=` в именованном аргументе и значении по умолчанию пробелы не ставятся: `greet("Дана", greeting="Привет")`, `def f(x=10):`.
- Значение по умолчанию вычисляется **один раз — при определении функции**. Поэтому изменяемые объекты (`[]`, `{}`) не делают значением по умолчанию, а используют `None`.
- Параметры, передаваемые только по имени, отмечаются `*`: `def order(drink, *, sugar=True):` — теперь `order("чай", False)` даст ошибку, а `order("чай", sugar=False)` сработает.
- Если число аргументов заранее неизвестно, используют `*args` (кортеж позиционных аргументов) и `**kwargs` (словарь именованных аргументов): `def total(*args): return sum(args)`.
- С Python 3.8 знак `/` обозначает параметры, передаваемые только по позиции: `def f(a, b, /):`.
- Документация: https://docs.python.org/3/tutorial/controlflow.html#more-on-defining-functions
