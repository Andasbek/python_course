## 1. Рекурсия дегеніміз не?

**Рекурсия (рекурсия, recursion)** — функцияның **өзін-өзі** шақыруы.

Рекурсивті функцияның **екі міндетті бөлігі** бар:

| Бөлік | Мағынасы | Мысал: кезектегі өз нөміріңді табу |
|---|---|---|
| **Базалық жағдай** (база рекурсии, base case) | жауабы бірден белгілі, рекурсия **тоқтайды** | «Алдымда ешкім жоқ, мен — 1-мін» |
| **Рекурсивті қадам** (recursive case) | есеп **кішірек** сол есепке келтіріледі | «Алдымдағының нөмірі + 1» |

**Алтын ереже:** әр рекурсивті шақыру есепті базалық жағдайға **жақындатуы** керек. Әйтпесе рекурсия ешқашан тоқтамайды.

## 2. Алғашқы мысал: кері санау

```python
def countdown(n):
    if n == 0:                 # базалық жағдай
        print("Старт!")
        return
    print(n)
    countdown(n - 1)           # рекурсивті қадам: n кішірейеді


countdown(3)
```

Нәтижесі:
```text
3
2
1
Старт!
```

Қалай жұмыс істейді:

```
countdown(3) → 3 шығарады, countdown(2) шақырады
  countdown(2) → 2 шығарады, countdown(1) шақырады
    countdown(1) → 1 шығарады, countdown(0) шақырады
      countdown(0) → «Старт!» — базалық жағдай, тоқтайды
```

Бұл есепті цикл арқылы да шешуге болады (`while n > 0`). Рекурсия — қайталауды ұйымдастырудың **басқа тәсілі**.

## 3. Факториал

**Факториал** `n!` — 1-ден `n`-ге дейінгі натурал сандардың көбейтіндісі:

```
5! = 1 · 2 · 3 · 4 · 5 = 120
0! = 1  (келісім бойынша)
```

Қолданылуы: `n` затты неше тәсілмен ретпен орналастыруға болады? Мысалы, 4 кітапты сөреге `4! = 24` тәсілмен қоюға болады.

### Факториалдың рекурсивті анықтамасы

Байқаңыз: `5! = 5 · (1 · 2 · 3 · 4) = 5 · 4!`

```
n! = 1            , егер n == 0 немесе n == 1   ← базалық жағдай
n! = n · (n - 1)! , егер n > 1                  ← рекурсивті қадам
```

Математикалық анықтама кодқа тікелей аударылады:

```python
def factorial(n):
    if n <= 1:                        # базалық жағдай
        return 1
    return n * factorial(n - 1)       # рекурсивті қадам


print(factorial(5))
print(factorial(0))
print(factorial(10))
```

Нәтижесі:
```text
120
1
3628800
```

### Шақыруларды қадағалау

`factorial(4)` қалай есептеледі:

```
factorial(4) = 4 * factorial(3)                  ↓ «төмен түсу»
               factorial(3) = 3 * factorial(2)
                              factorial(2) = 2 * factorial(1)
                                             factorial(1) = 1   ← база
                              factorial(2) = 2 * 1 = 2          ↑ «жоғары көтерілу»
               factorial(3) = 3 * 2 = 6
factorial(4) = 4 * 6 = 24
```

Рекурсия екі кезеңнен тұрады:
1. **Төмен түсу** — шақырулар базалық жағдайға жеткенше «тереңдейді», әрқайсысы нәтижені күтіп тұрады.
2. **Жоғары көтерілу** — базалық жағдайдан бастап нәтижелер кері қарай қайтарылып, көбейтіледі.

Мұны экранда көрейік — әр деңгейде шегініс береміз:

```python
def factorial_trace(n, depth=0):
    indent = "  " * depth
    print(f"{indent}factorial({n}) шақырылды")
    if n <= 1:
        print(f"{indent}база: 1 қайтарамыз")
        return 1
    result = n * factorial_trace(n - 1, depth + 1)
    print(f"{indent}{n}! = {result} қайтарамыз")
    return result


factorial_trace(3)
```

Нәтижесі:
```text
factorial(3) шақырылды
  factorial(2) шақырылды
    factorial(1) шақырылды
    база: 1 қайтарамыз
  2! = 2 қайтарамыз
3! = 6 қайтарамыз
```

## 4. Шақырулар стегі

Әр шақыру өзінің **жергілікті айнымалыларымен** жеке «қорапта» сақталады. Бұл қораптар бірінің үстіне бірі қойылады — бұл **шақырулар стегі** (стек вызовов, call stack) деп аталады.

```
┌───────────────┐
│ factorial(1)  │  n = 1   ← ең үстіңгі, бірінші аяқталады
├───────────────┤
│ factorial(2)  │  n = 2
├───────────────┤
│ factorial(3)  │  n = 3
├───────────────┤
│ factorial(4)  │  n = 4   ← бірінші шақырылған, соңғы аяқталады
└───────────────┘
```

Аналогия: тарелкалар үйіндісі — соңғы қойылған тарелка бірінші алынады.

Жөндеушіде (мысалы, Thonny-дің қадамдық режимінде, F7) `factorial(4)` орындалғанда әр шақыру жеке терезеде ашылып, өз `n` мәнін көрсетеді.

## 5. Шексіз рекурсия

Базалық жағдайды ұмытсақ немесе есеп кішіреймесе:

```python
def bad_factorial(n):
    return n * bad_factorial(n - 1)      # базалық жағдай жоқ!

# bad_factorial(5)
# RecursionError: maximum recursion depth exceeded
```

Python шақырулар стегінің тереңдігін шектейді (әдетте шамамен 1000). Бұл шектен асса — `RecursionError`.

Тағы бір жиі қате — есепті кішірейтпеу:

```python
def wrong(n):
    if n == 0:
        return 0
    return wrong(n)        # n өзгермейді — базаға жақындамаймыз!
```

## 6. Рекурсия мен цикл

Факториалды цикл арқылы да есептеуге болады (бұл **итеративті** тәсіл):

```python
def factorial_loop(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result


print(factorial_loop(5))
print(factorial_loop(5) == 120)
```

Нәтижесі:
```text
120
True
```

| | Рекурсия | Цикл |
|---|---|---|
| Код | қысқа, математикалық анықтамаға ұқсас | сәл ұзынырақ |
| Жад | әр шақыру стекте орын алады | бір-екі айнымалы жеткілікті |
| Шек | тереңдік ~1000 | шек жоқ |
| Қашан ыңғайлы | «өзіне ұқсас» құрылымдар: ағаштар, бумалар, фракталдар | қарапайым қайталаулар |

Рекурсивті шешімді цикл арқылы, ал цикл шешімін рекурсия арқылы әрдайым жазуға болады. Рекурсия есеп **өзіне ұқсас кішірек есепке** табиғи түрде бөлінетін жағдайларда ыңғайлы.

## 7. Тағы бірнеше рекурсивті мысал

### 1-ден n-ге дейінгі қосынды

```
sum(n) = 0            , егер n == 0
sum(n) = n + sum(n-1) , егер n > 0
```

```python
def sum_to(n):
    if n == 0:
        return 0
    return n + sum_to(n - 1)


print(sum_to(100))
```

Нәтижесі:
```text
5050
```

### Дәрежеге шығару

```python
def power(a, n):
    if n == 0:
        return 1
    return a * power(a, n - 1)


print(power(2, 10))
```

Нәтижесі:
```text
1024
```

### Жолды кері аудару

```python
def reverse(s):
    if len(s) <= 1:
        return s
    return reverse(s[1:]) + s[0]


print(reverse("Қазақстан"))
```

Нәтижесі:
```text
натсқазаҚ
```

### Цифрлар қосындысы

```python
def digit_sum(n):
    if n < 10:
        return n
    return n % 10 + digit_sum(n // 10)


print(digit_sum(2027))
```

Нәтижесі:
```text
11
```

### Рекурсивті ойлау үлгісі

Кез келген рекурсивті есепті шешкенде үш сұрақ қойыңыз:
1. **Ең қарапайым жағдай қандай?** (бос жол, 0, 1) — бұл база.
2. **Есепті қалай бір қадам кішірейтемін?** (`n - 1`, `s[1:]`, `n // 10`)
3. **Кішірек есептің жауабы белгілі болса, үлкенінің жауабын қалай құрамын?** (`n * ...`, `... + s[0]`)

## Жиі кездесетін қателер

**1. Базалық жағдай жоқ** → `RecursionError` (жоғарыдағы мысал).

**2. Рекурсивті шақыру нәтижесін return етпеу**

```python
def factorial(n):
    if n <= 1:
        return 1
    # n * factorial(n - 1)        # қате: нәтиже қайтарылмайды → None
    return n * factorial(n - 1)

print(factorial(4))   # 24
```

**3. Базаға жақындамау немесе «секіріп өту»**

```python
def countdown(n):
    if n == 0:               # n = 5 болса: 5, 3, 1, -1, ... ешқашан 0 болмайды
        return
    # countdown(n - 2)
    countdown(n - 1)         # дұрыс

countdown(5)
```

**4. Теріс аргументті ескермеу**

```python
def factorial(n):
    if n < 0:
        return None          # теріс сандарға факториал анықталмаған
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(-3))   # None
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Рекурсия | функцияның өзін-өзі шақыруы |
| Базалық жағдай | рекурсияны тоқтататын, жауабы бірден белгілі жағдай |
| Рекурсивті қадам | есепті кішірек сол есепке келтіру |
| Факториал `n!` | 1·2·…·n көбейтіндісі; 0! = 1 |
| Шақырулар стегі | аяқталмаған шақырулардың «үйіндісі» |
| Рекурсия тереңдігі | бір мезгілде ашық тұрған шақырулар саны |
| Итерация | цикл арқылы қайталау |
| `RecursionError` | рекурсия тереңдігі шектен асқандағы қате |

## Ескерту

- Рекурсия тереңдігінің шегін `sys.getrecursionlimit()` арқылы білуге, `sys.setrecursionlimit()` арқылы өзгертуге болады, бірақ шекті тым үлкейту бағдарламаның апатты тоқтауына әкелуі мүмкін.
- Python «құйрықты рекурсияны» (tail recursion) оңтайландырмайды, сондықтан тереңдігі үлкен есептерде цикл тиімдірек.
- Дайын факториал функциясы бар: `math.factorial(n)` — ол жылдам және теріс сан берілсе `ValueError` шығарады.
- Python-дағы бүтін сандардың шегі жоқ, сондықтан `factorial(100)` да дәл есептеледі (158 цифрлы сан).
- Бір мәнді қайта-қайта есептейтін рекурсияны (мысалы, Фибоначчи сандары) `functools.lru_cache` (Python 3.9+ — `functools.cache`) декораторымен жылдамдатуға болады.
- Құжаттама: https://docs.python.org/3/library/sys.html#sys.setrecursionlimit
