## 1. Что такое рекурсия?

**Рекурсия (recursion)** — вызов функцией **самой себя**.

У рекурсивной функции есть **две обязательные части**:

| Часть | Значение | Пример: узнать свой номер в очереди |
|---|---|---|
| **Базовый случай** (база рекурсии, base case) | ответ известен сразу, рекурсия **останавливается** | «Передо мной никого нет, я — 1-й» |
| **Рекурсивный шаг** (recursive case) | задача сводится к **меньшей** такой же задаче | «Номер впереди стоящего + 1» |

**Золотое правило:** каждый рекурсивный вызов должен **приближать** задачу к базовому случаю. Иначе рекурсия никогда не остановится.

## 2. Первый пример: обратный отсчёт

```python
def countdown(n):
    if n == 0:                 # базовый случай
        print("Старт!")
        return
    print(n)
    countdown(n - 1)           # рекурсивный шаг: n уменьшается


countdown(3)
```

Результат:
```text
3
2
1
Старт!
```

Как это работает:

```
countdown(3) → выводит 3, вызывает countdown(2)
  countdown(2) → выводит 2, вызывает countdown(1)
    countdown(1) → выводит 1, вызывает countdown(0)
      countdown(0) → «Старт!» — базовый случай, остановка
```

Эту же задачу можно решить и с помощью цикла (`while n > 0`). Рекурсия — **другой способ** организации повторения.

## 3. Факториал

**Факториал** `n!` — произведение натуральных чисел от 1 до `n`:

```
5! = 1 · 2 · 3 · 4 · 5 = 120
0! = 1  (по определению)
```

Применение: сколькими способами можно расставить по порядку `n` предметов? Например, 4 книги на полке можно расставить `4! = 24` способами.

### Рекурсивное определение факториала

Заметьте: `5! = 5 · (1 · 2 · 3 · 4) = 5 · 4!`

```
n! = 1            , если n == 0 или n == 1   ← базовый случай
n! = n · (n - 1)! , если n > 1               ← рекурсивный шаг
```

Математическое определение напрямую переводится в код:

```python
def factorial(n):
    if n <= 1:                        # базовый случай
        return 1
    return n * factorial(n - 1)       # рекурсивный шаг


print(factorial(5))
print(factorial(0))
print(factorial(10))
```

Результат:
```text
120
1
3628800
```

### Отслеживание вызовов

Как вычисляется `factorial(4)`:

```
factorial(4) = 4 * factorial(3)                  ↓ «спуск»
               factorial(3) = 3 * factorial(2)
                              factorial(2) = 2 * factorial(1)
                                             factorial(1) = 1   ← база
                              factorial(2) = 2 * 1 = 2          ↑ «подъём»
               factorial(3) = 3 * 2 = 6
factorial(4) = 4 * 6 = 24
```

Рекурсия состоит из двух этапов:
1. **Спуск** — вызовы «углубляются», пока не дойдут до базового случая, каждый ждёт результата.
2. **Подъём** — начиная с базового случая, результаты возвращаются в обратном порядке и перемножаются.

Посмотрим это на экране — на каждом уровне делаем отступ:

```python
def factorial_trace(n, depth=0):
    indent = "  " * depth
    print(f"{indent}вызвана factorial({n})")
    if n <= 1:
        print(f"{indent}база: возвращаем 1")
        return 1
    result = n * factorial_trace(n - 1, depth + 1)
    print(f"{indent}{n}! = {result}, возвращаем")
    return result


factorial_trace(3)
```

Результат:
```text
вызвана factorial(3)
  вызвана factorial(2)
    вызвана factorial(1)
    база: возвращаем 1
  2! = 2, возвращаем
3! = 6, возвращаем
```

## 4. Стек вызовов

Каждый вызов хранится в отдельной «коробке» со своими **локальными переменными**. Эти коробки ставятся одна на другую — это называется **стеком вызовов** (call stack).

```
┌───────────────┐
│ factorial(1)  │  n = 1   ← самый верхний, завершается первым
├───────────────┤
│ factorial(2)  │  n = 2
├───────────────┤
│ factorial(3)  │  n = 3
├───────────────┤
│ factorial(4)  │  n = 4   ← вызван первым, завершается последним
└───────────────┘
```

Аналогия: стопка тарелок — последнюю поставленную тарелку берут первой.

В отладчике (например, в пошаговом режиме Thonny, F7) при выполнении `factorial(4)` каждый вызов открывается в отдельном окне и показывает своё значение `n`.

## 5. Бесконечная рекурсия

Если забыть базовый случай или задача не уменьшается:

```python
def bad_factorial(n):
    return n * bad_factorial(n - 1)      # нет базового случая!

# bad_factorial(5)
# RecursionError: maximum recursion depth exceeded
```

Python ограничивает глубину стека вызовов (обычно примерно 1000). При превышении этого предела — `RecursionError`.

Ещё одна частая ошибка — задача не уменьшается:

```python
def wrong(n):
    if n == 0:
        return 0
    return wrong(n)        # n не меняется — к базе не приближаемся!
```

## 6. Рекурсия и цикл

Факториал можно вычислить и с помощью цикла (это **итеративный** способ):

```python
def factorial_loop(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result


print(factorial_loop(5))
print(factorial_loop(5) == 120)
```

Результат:
```text
120
True
```

| | Рекурсия | Цикл |
|---|---|---|
| Код | короткий, похож на математическое определение | немного длиннее |
| Память | каждый вызов занимает место в стеке | достаточно одной-двух переменных |
| Ограничение | глубина ~1000 | ограничения нет |
| Когда удобно | «самоподобные» структуры: деревья, папки, фракталы | простые повторения |

Рекурсивное решение всегда можно записать циклом, а циклическое — рекурсией. Рекурсия удобна там, где задача естественно разбивается **на меньшую подобную ей задачу**.

## 7. Ещё несколько рекурсивных примеров

### Сумма от 1 до n

```
sum(n) = 0            , если n == 0
sum(n) = n + sum(n-1) , если n > 0
```

```python
def sum_to(n):
    if n == 0:
        return 0
    return n + sum_to(n - 1)


print(sum_to(100))
```

Результат:
```text
5050
```

### Возведение в степень

```python
def power(a, n):
    if n == 0:
        return 1
    return a * power(a, n - 1)


print(power(2, 10))
```

Результат:
```text
1024
```

### Разворот строки

```python
def reverse(s):
    if len(s) <= 1:
        return s
    return reverse(s[1:]) + s[0]


print(reverse("Казахстан"))
```

Результат:
```text
натсхазаК
```

### Сумма цифр

```python
def digit_sum(n):
    if n < 10:
        return n
    return n % 10 + digit_sum(n // 10)


print(digit_sum(2027))
```

Результат:
```text
11
```

### Шаблон рекурсивного мышления

Решая любую рекурсивную задачу, задайте себе три вопроса:
1. **Какой случай самый простой?** (пустая строка, 0, 1) — это база.
2. **Как уменьшить задачу на один шаг?** (`n - 1`, `s[1:]`, `n // 10`)
3. **Если ответ меньшей задачи известен, как построить ответ большей?** (`n * ...`, `... + s[0]`)

## Частые ошибки

**1. Нет базового случая** → `RecursionError` (пример выше).

**2. Результат рекурсивного вызова не возвращается через return**

```python
def factorial(n):
    if n <= 1:
        return 1
    # n * factorial(n - 1)        # ошибка: результат не возвращается → None
    return n * factorial(n - 1)

print(factorial(4))   # 24
```

**3. Не приближаются к базе или «перепрыгивают» её**

```python
def countdown(n):
    if n == 0:               # если n = 5: 5, 3, 1, -1, ... никогда не станет 0
        return
    # countdown(n - 2)
    countdown(n - 1)         # правильно

countdown(5)
```

**4. Не учитывают отрицательный аргумент**

```python
def factorial(n):
    if n < 0:
        return None          # для отрицательных чисел факториал не определён
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(-3))   # None
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Рекурсия | вызов функцией самой себя |
| Базовый случай | случай, останавливающий рекурсию, ответ на который известен сразу |
| Рекурсивный шаг | сведение задачи к меньшей такой же задаче |
| Факториал `n!` | произведение 1·2·…·n; 0! = 1 |
| Стек вызовов | «стопка» незавершённых вызовов |
| Глубина рекурсии | количество одновременно открытых вызовов |
| Итерация | повторение с помощью цикла |
| `RecursionError` | ошибка превышения глубины рекурсии |

## Примечание

- Предел глубины рекурсии можно узнать через `sys.getrecursionlimit()` и изменить через `sys.setrecursionlimit()`, но слишком большой предел может привести к аварийному завершению программы.
- Python не оптимизирует «хвостовую рекурсию» (tail recursion), поэтому для задач большой глубины эффективнее цикл.
- Есть готовая функция факториала: `math.factorial(n)` — она быстрая и при отрицательном аргументе вызывает `ValueError`.
- Целые числа в Python не имеют предела, поэтому даже `factorial(100)` вычисляется точно (число из 158 цифр).
- Рекурсию, которая многократно пересчитывает одни и те же значения (например, числа Фибоначчи), можно ускорить декоратором `functools.lru_cache` (в Python 3.9+ — `functools.cache`).
- Документация: https://docs.python.org/3/library/sys.html#sys.setrecursionlimit
