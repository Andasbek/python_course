## 1. Шпаргалка: функциялар

```python
def function_name(required, optional="әдепкі"):
    """Функция не істейтінін қысқаша сипаттайды."""
    local_var = required          # жергілікті айнымалы
    return local_var              # нәтижені қайтару


result = function_name(5)                     # позициялық аргумент
result = function_name(5, optional="басқа")   # атаулы аргумент
```

| Тақырып | Негізгісі |
|---|---|
| `def` | анықтау кезінде код орындалмайды, тек шақырғанда |
| Параметрлер | әдепкі мәні барлары — міндеттілерден кейін |
| `return` | мәнді қайтарады және функцияны аяқтайды; жоқ болса → `None` |
| Бірнеше мән | `return a, b` → `x, y = f()` |
| Көріну аймағы | функция ішіндегі айнымалылар сыртта көрінбейді |
| `global` | мүмкіндігінше қолданба — параметр + `return` жақсы |
| Рекурсия | базалық жағдай + кішірейетін рекурсивті қадам |

## 2. Функциялар жинағы (кітапхана) дегеніміз не?

**Функциялар жинағы** — бір тақырыпқа арналған, бір-бірімен үйлесетін функциялар топтамасы. Мысалы, Python-ның `math` кітапханасында `sqrt()`, `sin()`, `factorial()` т.б. бар. Осындай кітапхананы өз бетіңізше де құруға болады.

Жақсы кітапхананың белгілері:

| Белгі | Түсіндірме |
|---|---|
| Бір тақырып | мысалы, тек мәтінмен немесе тек геометриямен жұмыс |
| Бір функция — бір міндет | `circle_area()` тек ауданды есептейді, экранға шығармайды |
| Түсінікті атаулар | `is_prime`, `count_words`, `to_binary` |
| Docstring | әр функцияның не қабылдап, не қайтаратыны жазылған |
| `return` | есептеу нәтижесі қайтарылады, `print` — тек негізгі бағдарламада |
| Тестілеу | әр функция бірнеше мәліметпен тексерілген |
| Қайта қолдану | күрделі функциялар қарапайымдарын шақырады |

## 3. Функциялар жинағын құру кезеңдері

**1-қадам. Тақырып таңдау.** Мысалдар: «Математика көмекшісі», «Мәтін өңдегіш», «Мектеп журналы», «Геометрия», «Ойын құралдары», «Қаржы калькуляторы».

**2-қадам. Функциялар тізімін жоспарлау.** Кестемен:

| № | Атауы | Параметрлер | Қайтарады | Мысал |
|---|---|---|---|---|
| 1 | `is_even` | `n` (int) | bool | `is_even(4)` → `True` |
| 2 | `factorial` | `n` (int ≥ 0) | int | `factorial(5)` → `120` |
| 3 | `gcd` | `a`, `b` (int) | int | `gcd(12, 18)` → `6` |
| 4 | `average` | `numbers` (list) | float | `average([4, 5])` → `4.5` |

**3-қадам. Қаңқа жазу** — алдымен барлық функциялардың тақырыбы мен docstring-і, денесі `pass`:

```python
def is_even(n):
    """n жұп болса True қайтарады."""
    pass


def factorial(n):
    """n! мәнін қайтарады (n >= 0)."""
    pass
```

**4-қадам. Әр функцияны жеке жазып, бірден тексеру.**

**5-қадам. Тестілеу.** Әр функцияға кемінде 3 тексеру: қалыпты жағдай, шекаралық жағдай (0, бос тізім, 1), «ерекше» жағдай.

**6-қадам. Біріктіру** — функцияларды мәзірлі негізгі бағдарламаға қосу.

## 4. Функцияларды тестілеу

Қарапайым тәсіл — күтілетін нәтижемен салыстыру:

```python
def is_even(n):
    """n жұп болса True қайтарады."""
    return n % 2 == 0


def average(numbers):
    """Тізімнің орташа мәнін қайтарады; бос тізім үшін 0."""
    if len(numbers) == 0:
        return 0
    return sum(numbers) / len(numbers)


print("is_even(4):", is_even(4) == True)
print("is_even(7):", is_even(7) == False)
print("is_even(0):", is_even(0) == True)
print("average([4, 5]):", average([4, 5]) == 4.5)
print("average([]):", average([]) == 0)
```

Нәтижесі:
```text
is_even(4): True
is_even(7): True
is_even(0): True
average([4, 5]): True
average([]): True
```

Барлығы `True` болса — тесттер өтті.

### assert операторы

Python-да тексеруге арналған арнайы `assert` операторы бар: шарт `True` болса — ештеңе болмайды, `False` болса — `AssertionError` қатесі шығады.

```python
def square(n):
    return n * n


assert square(3) == 9
assert square(0) == 0
assert square(-2) == 4
print("Барлық тест өтті!")
```

Нәтижесі:
```text
Барлық тест өтті!
```

Кәсіби бағдарламашылар осылай жүздеген тест жазады. Бұл — **автоматты тестілеудің** бастамасы.

## 5. Функцияларды қайта қолдану

Күрделі функцияны қарапайымдарынан «құрастырамыз»:

```python
def clean_text(text):
    """Мәтінді кіші әріпке айналдырып, тыныс белгілерін алып тастайды."""
    text = text.lower()
    for mark in ".,!?;:—-":
        text = text.replace(mark, " ")
    return text


def count_words(text):
    """Мәтіндегі сөздер санын қайтарады."""
    return len(clean_text(text).split())


def word_frequency(text):
    """Әр сөздің кездесу санының сөздігін қайтарады."""
    freq = {}
    for w in clean_text(text).split():
        freq[w] = freq.get(w, 0) + 1
    return freq


def most_common_word(text):
    """Ең жиі сөз бен оның санын қайтарады."""
    freq = word_frequency(text)
    best = ""
    for w, c in freq.items():
        if best == "" or c > freq[best]:
            best = w
    return best, freq.get(best, 0)


sample = "Бала, бала, балапан! Бала ойнайды, балапан ұшады."
print(count_words(sample))
print(word_frequency(sample))
print(most_common_word(sample))
```

Нәтижесі:
```text
7
{'бала': 3, 'балапан': 2, 'ойнайды': 1, 'ұшады': 1}
('бала', 3)
```

`clean_text` бір рет жазылды, бірақ үш функцияда қолданылды. Тыныс белгілерінің тізімін өзгерту керек болса — тек бір жерде түзетеміз.

## 6. Бағдарламаның құрылымы

```python
# ===== 1. Функциялар =====
def menu():
    """Мәзірді шығарады."""
    print("1 — Факториал")
    print("0 — Шығу")


def factorial(n):
    """n! мәнін қайтарады."""
    if n <= 1:
        return 1
    return n * factorial(n - 1)


# ===== 2. Негізгі бағдарлама =====
while True:
    menu()
    choice = input("Таңдау: ")
    if choice == "1":
        n = int(input("n = "))
        print(f"{n}! = {factorial(n)}")
    elif choice == "0":
        break
```

Ереже: алдымен **барлық функциялар**, кейін **негізгі бағдарлама**. Функциялар ішінде `input()`/`print()` аз болсын — мәліметті енгізу мен шығару негізгі бағдарламада.

## 7. Функциялар жинағы бөлек файлда (модуль)

Жинақтың функцияларын бөлек файлға, мысалы `mytools.py`-ға сақтап, басқа бағдарламаларда `import` командасымен қосуға болады. Мұндай файл **модуль** деп аталады.

```python
# mytools.py файлы
def is_even(n):
    """n жұп болса, True қайтарады."""
    return n % 2 == 0
```

```python
# main.py файлы (сол папкада)
import mytools
from mytools import is_even

print(mytools.is_even(10))
print(is_even(7))
```

Нәтиже:
```text
True
False
```

Модуль ішіндегі тесттерді `if __name__ == "__main__":` блогына жазады: бұл блок файл тікелей іске қосылғанда ғана орындалады, ал импорттағанда орындалмайды.

```python
def is_even(n):
    """n жұп болса, True қайтарады."""
    return n % 2 == 0


if __name__ == "__main__":
    assert is_even(4)
    assert not is_even(7)
    print("Барлық тест өтті!")
```

## Жиі кездесетін қателер

**1. Функция ішінде input() қолдану** — функцияны қайта қолдану мүмкін болмай қалады:

```python
# def area(): a = int(input()); ...   # тек пернетақтадан ғана жұмыс істейді
def area(a, b):                         # кез келген мәліметпен жұмыс істейді
    return a * b

print(area(3, 4))
```

**2. Docstring-ті функция денесінен кейін жазу** — docstring функцияның **бірінші** жолы болуы керек.

**3. Тестілемеу** — функция «қалыпты» мәліметпен жұмыс істеп, бос тізімде немесе 0-де қате беруі мүмкін:

```python
def average(numbers):
    if len(numbers) == 0:      # бұл тексеру болмаса — ZeroDivisionError
        return 0
    return sum(numbers) / len(numbers)

print(average([]))
```

**4. Бір функцияда тым көп міндет** — `calculate_and_print_and_save()` сияқты функцияны бірнешеуге бөліңіз.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Функциялар жинағы (кітапхана) | бір тақырыптағы функциялар топтамасы |
| Қаңқа (заготовка) | `pass` арқылы жазылған функциялар тақырыптары |
| Тестілеу | функцияны белгілі нәтижесі бар мәліметтермен тексеру |
| `assert` | шарт жалған болса қате шығаратын тексеру операторы |
| Шекаралық жағдай | 0, бос тізім, бір элемент сияқты «шеттегі» мәліметтер |
| Қайта қолдану | бір функцияны басқа функциялардың ішінде шақыру |

## Ескерту

- Модуль файлының атауы Python-ның стандартты модульдерімен сәйкес келмеуі керек: өз файлыңызды `math.py` немесе `random.py` деп атасаңыз, стандартты модуль «жабылып» қалады.
- PEP 8 бойынша модуль атаулары қысқа, кіші әріптермен жазылады (`mytools.py`, `text_utils.py`), ал `import` жолдары файлдың басында тұрады.
- `assert` тек жөндеуге арналған: Python `-O` кілтімен іске қосылса, барлық `assert` өшіріледі. Сондықтан пайдаланушы енгізген мәліметті тексеру үшін `if` қолданылады.
- Тесттер көбейгенде стандартты `unittest` модулі немесе танымал `pytest` кітапханасы қолданылады; docstring ішіндегі мысалдарды `doctest` модулі тексере алады.
- Модульді импорттағанда оның коды бір рет қана орындалады; модульді өзгерткеннен кейін интерактивті сессияны қайта іске қосу керек.
