## 1. Шпаргалка: функции

```python
def function_name(required, optional="по умолчанию"):
    """Кратко описывает, что делает функция."""
    local_var = required          # локальная переменная
    return local_var              # возврат результата


result = function_name(5)                     # позиционный аргумент
result = function_name(5, optional="другое")  # именованный аргумент
```

| Тема | Главное |
|---|---|
| `def` | при определении код не выполняется, только при вызове |
| Параметры | параметры со значением по умолчанию — после обязательных |
| `return` | возвращает значение и завершает функцию; если его нет → `None` |
| Несколько значений | `return a, b` → `x, y = f()` |
| Область видимости | переменные внутри функции не видны снаружи |
| `global` | по возможности не используй — лучше параметр + `return` |
| Рекурсия | базовый случай + уменьшающийся рекурсивный шаг |

## 2. Что такое сборник (библиотека) функций?

**Сборник функций** — группа согласованных друг с другом функций, посвящённых одной теме. Например, в библиотеке Python `math` есть `sqrt()`, `sin()`, `factorial()` и др. Такую библиотеку можно создать и самостоятельно.

Признаки хорошей библиотеки:

| Признак | Пояснение |
|---|---|
| Одна тема | например, работа только с текстом или только с геометрией |
| Одна функция — одна задача | `circle_area()` только вычисляет площадь, не выводит её на экран |
| Понятные имена | `is_prime`, `count_words`, `to_binary` |
| Docstring | для каждой функции записано, что она принимает и что возвращает |
| `return` | результат вычисления возвращается, `print` — только в основной программе |
| Тестирование | каждая функция проверена на нескольких наборах данных |
| Повторное использование | сложные функции вызывают более простые |

## 3. Этапы создания сборника функций

**Шаг 1. Выбор темы.** Примеры: «Помощник по математике», «Обработчик текста», «Школьный журнал», «Геометрия», «Игровые инструменты», «Финансовый калькулятор».

**Шаг 2. Планирование списка функций.** В виде таблицы:

| № | Имя | Параметры | Возвращает | Пример |
|---|---|---|---|---|
| 1 | `is_even` | `n` (int) | bool | `is_even(4)` → `True` |
| 2 | `factorial` | `n` (int ≥ 0) | int | `factorial(5)` → `120` |
| 3 | `gcd` | `a`, `b` (int) | int | `gcd(12, 18)` → `6` |
| 4 | `average` | `numbers` (list) | float | `average([4, 5])` → `4.5` |

**Шаг 3. Написание каркаса** — сначала заголовки и docstring всех функций, тело — `pass`:

```python
def is_even(n):
    """Возвращает True, если n чётное."""
    pass


def factorial(n):
    """Возвращает значение n! (n >= 0)."""
    pass
```

**Шаг 4. Написание каждой функции по отдельности с немедленной проверкой.**

**Шаг 5. Тестирование.** Для каждой функции не менее 3 проверок: обычный случай, граничный случай (0, пустой список, 1), «особый» случай.

**Шаг 6. Объединение** — подключение функций к основной программе с меню.

## 4. Тестирование функций

Простой способ — сравнение с ожидаемым результатом:

```python
def is_even(n):
    """Возвращает True, если n чётное."""
    return n % 2 == 0


def average(numbers):
    """Возвращает среднее значение списка; для пустого списка — 0."""
    if len(numbers) == 0:
        return 0
    return sum(numbers) / len(numbers)


print("is_even(4):", is_even(4) == True)
print("is_even(7):", is_even(7) == False)
print("is_even(0):", is_even(0) == True)
print("average([4, 5]):", average([4, 5]) == 4.5)
print("average([]):", average([]) == 0)
```

Результат:
```text
is_even(4): True
is_even(7): True
is_even(0): True
average([4, 5]): True
average([]): True
```

Если везде `True` — тесты пройдены.

### Оператор assert

В Python есть специальный оператор для проверок `assert`: если условие `True` — ничего не происходит, если `False` — возникает ошибка `AssertionError`.

```python
def square(n):
    return n * n


assert square(3) == 9
assert square(0) == 0
assert square(-2) == 4
print("Все тесты пройдены!")
```

Результат:
```text
Все тесты пройдены!
```

Профессиональные программисты пишут так сотни тестов. Это начало **автоматического тестирования**.

## 5. Повторное использование функций

Сложную функцию «собираем» из простых:

```python
def clean_text(text):
    """Переводит текст в строчные буквы и удаляет знаки препинания."""
    text = text.lower()
    for mark in ".,!?;:—-":
        text = text.replace(mark, " ")
    return text


def count_words(text):
    """Возвращает количество слов в тексте."""
    return len(clean_text(text).split())


def word_frequency(text):
    """Возвращает словарь частоты каждого слова."""
    freq = {}
    for w in clean_text(text).split():
        freq[w] = freq.get(w, 0) + 1
    return freq


def most_common_word(text):
    """Возвращает самое частое слово и его количество."""
    freq = word_frequency(text)
    best = ""
    for w, c in freq.items():
        if best == "" or c > freq[best]:
            best = w
    return best, freq.get(best, 0)


sample = "Мама, мама, мамочка! Мама спит, мамочка поёт."
print(count_words(sample))
print(word_frequency(sample))
print(most_common_word(sample))
```

Результат:
```text
7
{'мама': 3, 'мамочка': 2, 'спит': 1, 'поёт': 1}
('мама', 3)
```

`clean_text` написана один раз, но использована в трёх функциях. Если нужно изменить список знаков препинания — исправляем только в одном месте.

## 6. Структура программы

```python
# ===== 1. Функции =====
def menu():
    """Выводит меню."""
    print("1 — Факториал")
    print("0 — Выход")


def factorial(n):
    """Возвращает значение n!."""
    if n <= 1:
        return 1
    return n * factorial(n - 1)


# ===== 2. Основная программа =====
while True:
    menu()
    choice = input("Выбор: ")
    if choice == "1":
        n = int(input("n = "))
        print(f"{n}! = {factorial(n)}")
    elif choice == "0":
        break
```

Правило: сначала **все функции**, затем **основная программа**. Внутри функций должно быть мало `input()`/`print()` — ввод и вывод данных в основной программе.

## 7. Сборник функций в отдельном файле (модуль)

Функции сборника можно сохранить в отдельный файл, например `mytools.py`, и подключать в других программах командой `import`. Такой файл называется **модулем**.

```python
# файл mytools.py
def is_even(n):
    """Возвращает True, если n чётное."""
    return n % 2 == 0
```

```python
# файл main.py (в той же папке)
import mytools
from mytools import is_even

print(mytools.is_even(10))
print(is_even(7))
```

Результат:
```text
True
False
```

Тесты внутри модуля записывают в блок `if __name__ == "__main__":` — он выполняется только при прямом запуске файла, а при импорте — нет.

```python
def is_even(n):
    """Возвращает True, если n чётное."""
    return n % 2 == 0


if __name__ == "__main__":
    assert is_even(4)
    assert not is_even(7)
    print("Все тесты пройдены!")
```

## Частые ошибки

**1. Использование input() внутри функции** — функцию невозможно использовать повторно:

```python
# def area(): a = int(input()); ...   # работает только с клавиатуры
def area(a, b):                         # работает с любыми данными
    return a * b

print(area(3, 4))
```

**2. Docstring пишут после тела функции** — docstring должен быть **первой** строкой функции.

**3. Нет тестирования** — функция может работать с «обычными» данными и выдавать ошибку на пустом списке или 0:

```python
def average(numbers):
    if len(numbers) == 0:      # без этой проверки — ZeroDivisionError
        return 0
    return sum(numbers) / len(numbers)

print(average([]))
```

**4. Слишком много задач в одной функции** — функцию вроде `calculate_and_print_and_save()` разделите на несколько.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Сборник функций (библиотека) | группа функций на одну тему |
| Каркас (заготовка) | заголовки функций, записанные с `pass` |
| Тестирование | проверка функции на данных с известным результатом |
| `assert` | оператор проверки, вызывающий ошибку, если условие ложно |
| Граничный случай | «крайние» данные, такие как 0, пустой список, один элемент |
| Повторное использование | вызов одной функции внутри других функций |

## Примечание

- Имя файла модуля не должно совпадать со стандартными модулями Python: если назвать свой файл `math.py` или `random.py`, стандартный модуль окажется «закрыт».
- По PEP 8 имена модулей короткие, строчными буквами (`mytools.py`, `text_utils.py`), а строки `import` располагаются в начале файла.
- `assert` предназначен только для отладки: при запуске Python с ключом `-O` все `assert` отключаются. Поэтому для проверки данных, введённых пользователем, используют `if`.
- Когда тестов становится много, используют стандартный модуль `unittest` или популярную библиотеку `pytest`; примеры внутри docstring умеет проверять модуль `doctest`.
- При импорте код модуля выполняется только один раз; после изменения модуля интерактивную сессию нужно перезапустить.
- Документация: https://docs.python.org/3/tutorial/modules.html
