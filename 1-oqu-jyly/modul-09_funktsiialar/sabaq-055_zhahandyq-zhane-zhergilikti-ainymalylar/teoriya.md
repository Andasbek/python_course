## 1. Көріну аймағы дегеніміз не?

**Көріну аймағы (область видимости, scope)** — бағдарламаның айнымалыға **қол жеткізуге болатын** бөлігі.

Аналогия: **мектеп пен сынып**.
- Мектеп фойесіндегі хабарландыру тақтасы — **жаһандық**: оны кез келген сыныптан шыққан оқушы көре алады.
- Сыныптың ішіндегі тақтаға жазылған жазу — **жергілікті**: оны тек сол сыныптағылар көреді, сабақ біткенде өшіріледі.

| Аймақ | Қайда құрылады | Қайда көрінеді | Қашан жойылады |
|---|---|---|---|
| **Жергілікті (local)** | функция ішінде | тек сол функцияның ішінде | функция аяқталғанда |
| **Жаһандық (global)** | файлдың негізгі бөлігінде (функциялардан тыс) | бүкіл файлда, функциялардың ішінде де (оқу үшін) | бағдарлама аяқталғанда |
| **Кірістірілген (built-in)** | Python-ның өзінде | барлық жерде | — (`print`, `len`, `sum` ...) |

## 2. Жергілікті айнымалылар

Функция ішінде меншіктелген әр айнымалы — **жергілікті**. Ол функция шақырылғанда құрылады және функция аяқталғанда жойылады.

```python
def make_tea():
    water = 250        # жергілікті
    sugar = 2          # жергілікті
    print(f"Шай: {water} мл су, {sugar} қасық қант")


make_tea()
make_tea()             # әр шақыруда айнымалылар жаңадан құрылады
```

Нәтижесі:
```text
Шай: 250 мл су, 2 қасық қант
Шай: 250 мл су, 2 қасық қант
```

### Параметрлер де — жергілікті

```python
def double(n):         # n — жергілікті айнымалы
    n = n * 2
    return n


x = 10
print(double(x))
print(x)               # x өзгерген жоқ!
# print(n)             # NameError: n тек функция ішінде бар
```

Нәтижесі:
```text
20
10
```

Шақыру кезінде `n = x` сияқты меншіктеу болады: `n` — бөлек айнымалы, оны өзгерту `x`-ке әсер етпейді (сандар мен жолдар үшін).

### Әр функцияның өз «бөлмесі»

Екі түрлі функциядағы аттас айнымалылар бір-біріне кедергі келтірмейді:

```python
def morning():
    message = "Қайырлы таң!"
    print(message)


def evening():
    message = "Қайырлы кеш!"
    print(message)


morning()
evening()
```

Нәтижесі:
```text
Қайырлы таң!
Қайырлы кеш!
```

Бұл — функциялардың басты артықшылығының бірі: әр функция өз ішінде **оқшауланған**, басқалардың айнымалыларын байқаусызда бүлдірмейді.

## 3. Жаһандық айнымалылар

Функциялардан тыс құрылған айнымалы — **жаһандық**. Функция оны **оқи** алады:

```python
school = "№120 мектеп"     # жаһандық
year = 2027                # жаһандық


def print_badge(name):
    print(f"{name} | {school} | {year}")


print_badge("Айгерім")
print_badge("Бекзат")
```

Нәтижесі:
```text
Айгерім | №120 мектеп | 2027
Бекзат | №120 мектеп | 2027
```

Тұрақты мәндер (тұрақтылар, константы) үшін бұл ыңғайлы. Келісім бойынша оларды **БАС ӘРІППЕН** жазады: `PI = 3.14159`, `MAX_SCORE = 100`.

## 4. Айнымалыны іздеу реті

Python айнымалы атауын кездестіргенде, оны мына ретпен іздейді:

```
1. Жергілікті (Local)   — функцияның өз ішінен
2. Жаһандық (Global)    — файлдың негізгі бөлігінен
3. Кірістірілген (Built-in) — Python-ның дайын атауларынан
Табылмаса → NameError
```

```python
x = "жаһандық"


def show():
    x = "жергілікті"
    print("Функция ішінде:", x)


show()
print("Функция сыртында:", x)
```

Нәтижесі:
```text
Функция ішінде: жергілікті
Функция сыртында: жаһандық
```

Функция ішіндегі `x = ...` **жаңа жергілікті** айнымалы құрды, ол жаһандық `x`-ті «бүркеп» (shadowing) тұр, бірақ оны өзгертпеді.

### Кірістірілген атауларды бүркеу — қауіпті!

```python
numbers = [3, 5, 7]
# sum = 0                      # енді sum — сан, кірістірілген функция «жабылды»
# print(sum(numbers))          # TypeError: 'int' object is not callable
total = 0                      # дұрыс: басқа атау
print(sum(numbers))
```

Нәтижесі:
```text
15
```

## 5. Жаһандық айнымалыны функция ішінде өзгерту

```python
counter = 0


def add_one():
    # counter = counter + 1   # UnboundLocalError: cannot access local variable 'counter'
    pass
```

Неге қате? Функция ішінде `counter = ...` меншіктеуі бар, сондықтан Python `counter`-ді **жергілікті** деп санайды. Ал оң жақтағы `counter + 1` есептелгенде, жергілікті `counter` әлі мәнсіз.

### global кілт сөзі

`global` — «бұл айнымалы жаһандық, жаңасын құрма» деп Python-ға айтады:

```python
counter = 0


def add_one():
    global counter
    counter = counter + 1


add_one()
add_one()
add_one()
print("Санауыш:", counter)
```

Нәтижесі:
```text
Санауыш: 3
```

### Неге global-ды аз қолдану керек?

`global` қолданылған функцияның нәтижесі тек параметрлерге ғана емес, **сыртқы күйге** де байланысты болады. Бағдарлама үлкейгенде, айнымалыны «кім, қашан өзгертті?» деп іздеу өте қиын. Сондықтан ұсыныс: **мәлімет функцияға параметр арқылы кірсін, нәтиже `return` арқылы шықсын.**

Жоғарыдағы мысал — дұрыс тәсілмен:

```python
def add_one(value):
    return value + 1


counter = 0
counter = add_one(counter)
counter = add_one(counter)
counter = add_one(counter)
print("Санауыш:", counter)
```

Нәтижесі:
```text
Санауыш: 3
```

| | `global` арқылы | параметр + `return` арқылы |
|---|---|---|
| Функция неге тәуелді | сыртқы айнымалыға | тек аргументтерге |
| Тестілеу | қиын | оңай: кіріс → шығыс |
| Қайта қолдану | тек сол айнымалымен | кез келген мәнмен |
| Қателерді іздеу | қиын | оңай |

## 6. Өзгермелі объектілер туралы ескерту

Тізім мен сөздікті функция ішінде **әдістер арқылы өзгерту** үшін `global` қажет емес — себебі айнымалыны қайта меншіктемейміз, объектінің ішін өзгертеміз:

```python
cart = []


def add_to_cart(item):
    cart.append(item)       # global қажет емес


add_to_cart("нан")
add_to_cart("сүт")
print(cart)
```

Нәтижесі:
```text
['нан', 'сүт']
```

Бірақ бұл да жаһандық күйге тәуелділік. Таза тәсіл — тізімді параметр ретінде беру: `def add_to_cart(cart, item):`.

## 7. Көріну аймағын жөндеушіде бақылау

Жөндеушіде (debugger) бағдарламаны қадамдап орындағанда көріну аймақтары анық көрінеді. Мысалы, Thonny-де **View → Variables** терезесі ашық тұрса, қадамдық режимде (F7) функцияға кірген кезде жаңа терезе — функцияның **жергілікті аймағы** пайда болады, ал функциядан шыққанда ол жабылады.

Кодтың өзінен де аймақтарды көруге болады: `locals()` жергілікті айнымалылар сөздігін, `globals()` — жаһандық айнымалылар сөздігін қайтарады.

```python
def demo(a):
    b = a * 2
    print(locals())


demo(5)
```

Нәтиже:
```text
{'a': 5, 'b': 10}
```

## Жиі кездесетін қателер

**1. Жергілікті айнымалыны сырттан оқу**

```python
def get_name():
    name = "Дана"
    return name

# print(name)          # NameError
name = get_name()      # дұрыс: return арқылы алу
print(name)
```

**2. Жаһандық айнымалыны global-сыз өзгертуге тырысу**

```python
score = 10

def bonus():
    # score += 5       # UnboundLocalError
    return 5

score += bonus()
print(score)           # 15
```

**3. Параметрді өзгертіп, сыртқы айнымалы өзгерді деп ойлау**

```python
def reset(x):
    x = 0

a = 100
reset(a)
print(a)               # 100 — өзгермеді
```

**4. Кірістірілген атауды айнымалыға беру**

```python
# list = [1, 2, 3]     # list() функциясы енді қолжетімсіз
items = [1, 2, 3]
print(list("абв"))
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Көріну аймағы (scope) | айнымалыға қол жеткізуге болатын бағдарлама бөлігі |
| Жергілікті айнымалы | функция ішінде құрылып, тек сонда көрінетін айнымалы |
| Жаһандық айнымалы | функциялардан тыс құрылған, бүкіл файлда көрінетін айнымалы |
| Кірістірілген атаулар | `print`, `len`, `sum` сияқты Python атаулары |
| Бүркеу (shadowing) | ішкі аймақтағы аттас айнымалы сыртқысын «жабуы» |
| `global` | функция ішінде жаһандық айнымалыны өзгертуге рұқсат беретін кілт сөз |
| Тұрақты (константа) | өзгермейтін мән, атауы бас әріппен: `MAX_SCORE` |

## Ескерту

- Python-да `if`, `for`, `while` блоктары жаңа көріну аймағын құрмайды: цикл ішінде құрылған айнымалы циклден кейін де қолжетімді (C, Java тілдерінен айырмашылығы).
- Толық іздеу тәртібі — **LEGB**: Local → Enclosing (сыртқы функция) → Global → Built-in. Ішкі функциядан сыртқы функцияның айнымалысын өзгерту үшін `nonlocal` қолданылады.
- `UnboundLocalError` — `NameError`-дың ішкі түрі; ол функцияда айнымалыға кез келген жерде мән меншіктелсе, бүкіл функция бойы оның жергілікті саналатынынан туындайды.
- PEP 8 бойынша тұрақтылар (константалар) модуль деңгейінде `UPPER_CASE` түрінде жазылады; Python оларды өзгертуге тыйым салмайды — бұл тек келісім.
- Кірістірілген атауды байқамай жауып тастасаңыз, `del sum` арқылы айнымалыны жойып, кірістірілген функцияны қайтаруға болады.
- Құжаттама: https://docs.python.org/3/tutorial/classes.html#python-scopes-and-namespaces
