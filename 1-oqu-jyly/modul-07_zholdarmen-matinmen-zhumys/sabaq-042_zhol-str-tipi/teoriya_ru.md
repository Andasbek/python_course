## 1. Что такое строка?

**Строка (string)** — упорядоченная последовательность символов. Символ — это буква, цифра, пробел, знак препинания и даже эмодзи.

Аналогия: представьте строку как **поезд**. В каждом вагоне сидит только один символ, вагоны пронумерованы, а состав поезда менять нельзя — можно только собрать новый поезд.

### Способы создания строк

```python
name = "Айгерим"          # двойные кавычки
city = 'Алматы'           # одинарные кавычки
quote = "Он сказал: 'Привет!'"   # внутри одинарные кавычки
poem = """Родина,
родная земля,
Казахстан!"""             # тройные кавычки — многострочный текст
empty = ""                # пустая строка

print(name, city)
print(quote)
print(poem)
print(type(name))
print(len(empty))
```

Результат:
```text
Айгерим Алматы
Он сказал: 'Привет!'
Родина,
родная земля,
Казахстан!
<class 'str'>
0
```

### Специальные (экранированные) символы

С помощью обратной косой черты `\` записываются специальные символы:

| Запись | Значение |
|---|---|
| `\n` | переход на новую строку |
| `\t` | табуляция (широкий пробел) |
| `\\` | сама обратная косая черта |
| `\"`, `\'` | кавычка |

```python
print("Имя:\tДаулет\nВозраст:\t14")
print("Путь к файлу: C:\\Users\\Daulet")
```

Результат:
```text
Имя:	Даулет
Возраст:	14
Путь к файлу: C:\Users\Daulet
```

## 2. Длина строки: len()

Функция `len()` возвращает **количество символов** в строке. Пробел и знак препинания тоже считаются символами.

```python
text = "Привет, мир!"
print(len(text))
```

Результат:
```text
12
```

## 3. Индексы

У каждого символа строки есть свой **индекс** (номер). Как и в списке, нумерация начинается **с 0**. Кроме того, есть **отрицательные индексы**: `-1` — последний символ, `-2` — второй с конца.

Слово: `"PYTHON"`

| Символ | P | Y | T | H | O | N |
|---|---|---|---|---|---|---|
| Положительный индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| Отрицательный индекс | -6 | -5 | -4 | -3 | -2 | -1 |

```python
word = "PYTHON"
print(word[0])     # первый символ
print(word[3])
print(word[-1])    # последний символ
print(word[-2])
print(word[len(word) - 1])  # последний символ, другим способом
```

Результат:
```text
P
H
N
O
N
```

**Правило:** индексы строки длины `n` — от `0` до `n-1` или от `-n` до `-1`. Индекс за этими пределами — ошибка (`IndexError`).

## 4. Срезы (slice)

Срез возвращает **часть** строки в виде новой строки:

```
s[start:stop:step]
```

- `start` — начальный индекс (входит), если не указан — с начала;
- `stop` — конечный индекс (**не входит**), если не указан — до конца;
- `step` — шаг, если не указан — 1.

Аналогия: нарезка хлеба. Если сказать «со 2-го ломтика до 5-го», мы остановимся перед 5-м ломтиком.

```python
s = "Казахстан"
print(s[0:5])     # индексы 0,1,2,3,4
print(s[5:])      # с 5-го до конца
print(s[:3])      # с начала до 3-го
print(s[-4:])     # последние 4 символа
print(s[:])       # полная копия
```

Результат:
```text
Казах
стан
Каз
стан
Казахстан
```

### Срез с шагом

```python
digits = "0123456789"
print(digits[::2])     # стоящие на чётных местах
print(digits[1::2])    # стоящие на нечётных местах
print(digits[2:8:3])
print(digits[::-1])    # разворот строки
```

Результат:
```text
02468
13579
25
9876543210
```

`s[::-1]` — самый короткий способ развернуть строку. Его удобно использовать, например, для проверки палиндрома.

**Важно:** срез не вызывает ошибку, даже если выходит за границы индексов:

```python
s = "Abai"
print(s[2:100])
print(s[10:20] == "")
```

Результат:
```text
ai
True
```

### Пример из жизни: дата рождения по ИИН

ИИН состоит из 12 цифр, первые 6 цифр — ГГММДД (год, месяц, день).

```python
iin = "100315500123"
year = iin[0:2]
month = iin[2:4]
day = iin[4:6]
print(f"Дата рождения: {day}.{month}.20{year}")
```

Результат:
```text
Дата рождения: 15.03.2010
```

## 5. Операции над строками

| Операция | Пример | Результат |
|---|---|---|
| `+` объединение (конкатенация) | `"Кара" + "ганда"` | `"Караганда"` |
| `*` повторение | `"ха" * 3` | `"хахаха"` |
| `in` есть ли? | `"аз" in "Казах"` | `True` |
| `not in` нет ли? | `"z" not in "Абай"` | `True` |
| `==`, `<` сравнение | `"апельсин" < "банан"` | `True` |

```python
line = "-" * 20
print(line)
print("Привет, " + "Нурсултан" + "!")
print(line)
email = "aru@mail.kz"
print("@" in email)
```

Результат:
```text
--------------------
Привет, Нурсултан!
--------------------
True
```

## 6. Строка — неизменяемый тип

Элемент списка мы можем изменить: `lst[0] = 5`. А со строкой так **нельзя**:

```python
s = "кот"
# s[0] = "р"   # TypeError: 'str' object does not support item assignment
s = "р" + s[1:]   # создаём новую строку
print(s)
```

Результат:
```text
рот
```

Строка — **неизменяемый (immutable)** тип, как и кортеж. Если нужно изменение, мы с помощью среза и `+` создаём **новую строку** и заново присваиваем её переменной.

## 7. Сравнение списка и строки

| Свойство | list | str |
|---|---|---|
| Элементы | любого типа | только символы |
| Индекс, срез | есть | есть |
| `len()`, `in` | есть | есть |
| Изменение `x[i] = ...` | можно | нельзя |
| Запись | `[1, 2, 3]` | `"123"` |

Функция `list()` превращает строку в список символов:

```python
print(list("Абай"))
```

Результат:
```text
['А', 'б', 'а', 'й']
```

## Частые ошибки

**1. Выход за границы индекса**

```python
s = "Каша"
# print(s[4])   # IndexError: string index out of range
print(s[3])     # правильно: последний индекс = len(s) - 1
```

**2. Забывают, что индекс stop не входит**

```python
s = "Python"
print(s[0:3])   # 'Pyt' — 'h' с индексом 3 не входит
print(s[0:4])   # 'Pyth' — если нужно 4 символа
```

**3. Попытка изменить символ строки**

```python
s = "сон"
# s[-1] = "к"   # TypeError
s = s[:-1] + "к"
print(s)        # сок
```

**4. Объединение числа со строкой**

```python
age = 14
# print("Мой возраст: " + age)   # TypeError
print("Мой возраст: " + str(age))
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Строка (str) | упорядоченная неизменяемая последовательность символов |
| Индекс | порядковый номер символа, начинается с 0 |
| Отрицательный индекс | отсчёт с конца: -1 — последний символ |
| Срез (slice) | `s[start:stop:step]` — часть строки |
| Конкатенация | объединение строк с помощью `+` |
| Неизменяемый (immutable) | объект, содержимое которого нельзя изменить после создания |
| Экранирование | специальные символы вида `\n`, `\t` |

## Примечание

- В Python 3 `str` — строка Unicode, поэтому казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) и эмодзи индексируются как один символ: `len("Қазақ") == 5`.
- Индекс за пределами строки — `IndexError`, а срез никогда не вызывает ошибку: часть за границами просто не учитывается.
- `s[:]` даёт «копию» строки, но так как строка неизменяема, Python обычно возвращает тот же объект — это безопасно.
- Если неудобно удваивать `\` в путях Windows, используйте «сырую» строку: `r"C:\Users\Daulet"`.
- Многократное объединение строк через `+` в цикле работает медленно; для сборки большого текста эффективнее список и `"".join(...)`.
- Подробнее: https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str
