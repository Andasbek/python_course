## 1. Жол дегеніміз не?

**Жол (строка, string)** — символдардың реттелген тізбегі. Символ дегеніміз — әріп, цифр, бос орын, тыныс белгісі, тіпті эмодзи.

Аналогия: жолды **пойыз** ретінде елестетіңіз. Әр вагонда бір ғана символ отырады, вагондар нөмірленген, ал пойыздың құрамын ауыстыруға болмайды — тек жаңа пойыз жинауға болады.

### Жол құру тәсілдері

```python
name = "Айгерім"          # қос тырнақша
city = 'Алматы'           # дара тырнақша
quote = "Ол: 'Сәлем!' деді"   # ішінде дара тырнақша
poem = """Атамекен,
туған жер,
Қазақстан!"""             # үш тырнақша — көп жолды мәтін
empty = ""                # бос жол

print(name, city)
print(quote)
print(poem)
print(type(name))
print(len(empty))
```

Нәтижесі:
```text
Айгерім Алматы
Ол: 'Сәлем!' деді
Атамекен,
туған жер,
Қазақстан!
<class 'str'>
0
```

### Арнайы (экрандалған) символдар

Кері қиғаш сызық `\` арқылы арнайы символдар жазылады:

| Жазылуы | Мағынасы |
|---|---|
| `\n` | жаңа жолға көшу |
| `\t` | табуляция (кең бос орын) |
| `\\` | кері қиғаш сызықтың өзі |
| `\"`, `\'` | тырнақша |

```python
print("Аты:\tДәулет\nЖасы:\t14")
print("Файл жолы: C:\\Users\\Daulet")
```

Нәтижесі:
```text
Аты:	Дәулет
Жасы:	14
Файл жолы: C:\Users\Daulet
```

## 2. Жолдың ұзындығы: len()

`len()` функциясы жолдағы **символдар санын** қайтарады. Бос орын да, тыныс белгісі де символ болып саналады.

```python
text = "Сәлем, әлем!"
print(len(text))
```

Нәтижесі:
```text
12
```

## 3. Индекстер

Жолдың әр символының өз **индексі** (нөмірі) бар. Тізімдегідей, нөмірлеу **0-ден** басталады. Сонымен қатар **теріс индекстер** бар: `-1` — соңғы символ, `-2` — соңынан екіншісі.

Сөз: `"PYTHON"`

| Символ | P | Y | T | H | O | N |
|---|---|---|---|---|---|---|
| Оң индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| Теріс индекс | -6 | -5 | -4 | -3 | -2 | -1 |

```python
word = "PYTHON"
print(word[0])     # бірінші символ
print(word[3])
print(word[-1])    # соңғы символ
print(word[-2])
print(word[len(word) - 1])  # соңғы символ, басқаша жолмен
```

Нәтижесі:
```text
P
H
N
O
N
```

**Ереже:** ұзындығы `n` жолдың индекстері `0`-ден `n-1`-ге дейін немесе `-n`-нен `-1`-ге дейін. Одан тыс индекс — қате (`IndexError`).

## 4. Кесінділер (срез, slice)

Кесінді жолдың **бір бөлігін** жаңа жол ретінде қайтарады:

```
s[start:stop:step]
```

- `start` — басталатын индекс (кіреді), жазылмаса — басынан;
- `stop` — аяқталатын индекс (**кірмейді**), жазылмаса — соңына дейін;
- `step` — қадам, жазылмаса — 1.

Аналогия: нан кесу. «2-тілімнен 5-тілімге дейін» десек, 5-тілімнің алдында тоқтаймыз.

```python
s = "Қазақстан"
print(s[0:5])     # 0,1,2,3,4 индекстер
print(s[5:])      # 5-тен соңына дейін
print(s[:3])      # басынан 3-ке дейін
print(s[-4:])     # соңғы 4 символ
print(s[:])       # толық көшірме
```

Нәтижесі:
```text
Қазақ
стан
Қаз
стан
Қазақстан
```

### Қадаммен кесу

```python
digits = "0123456789"
print(digits[::2])     # жұп орындағылар
print(digits[1::2])    # тақ орындағылар
print(digits[2:8:3])
print(digits[::-1])    # жолды кері аудару
```

Нәтижесі:
```text
02468
13579
25
9876543210
```

`s[::-1]` — жолды кері аударудың ең қысқа тәсілі. Оны, мысалы, палиндромды тексеруге қолдануға болады.

**Маңызды:** кесінді индекс шегінен шықса да қате бермейді:

```python
s = "Abai"
print(s[2:100])
print(s[10:20] == "")
```

Нәтижесі:
```text
ai
True
```

### Өмірлік мысал: ЖСН-нен туған күнді алу

ЖСН (ИИН) 12 цифрдан тұрады, алғашқы 6 цифры — ЖЖААКК (жыл, ай, күн).

```python
iin = "100315500123"
year = iin[0:2]
month = iin[2:4]
day = iin[4:6]
print(f"Туған күні: {day}.{month}.20{year}")
```

Нәтижесі:
```text
Туған күні: 15.03.2010
```

## 5. Жолдарға арналған амалдар

| Амал | Мысал | Нәтиже |
|---|---|---|
| `+` біріктіру (конкатенация) | `"Қош" + "кел"` | `"Қошкел"` |
| `*` қайталау | `"ха" * 3` | `"хахаха"` |
| `in` бар ма? | `"ақ" in "Қазақ"` | `True` |
| `not in` жоқ па? | `"z" not in "Абай"` | `True` |
| `==`, `<` салыстыру | `"алма" < "анар"` | `True` |

```python
line = "-" * 20
print(line)
print("Сәлем, " + "Нұрсұлтан" + "!")
print(line)
email = "aru@mail.kz"
print("@" in email)
```

Нәтижесі:
```text
--------------------
Сәлем, Нұрсұлтан!
--------------------
True
```

## 6. Жол — өзгермейтін тип

Тізімнің элементін өзгерте аламыз: `lst[0] = 5`. Ал жолда бұлай **болмайды**:

```python
s = "мысық"
# s[0] = "б"   # TypeError: 'str' object does not support item assignment
s = "б" + s[1:]   # жаңа жол құрамыз
print(s)
```

Нәтижесі:
```text
бысық
```

Жол — **өзгермейтін (immutable)** тип, кортеж сияқты. Өзгерту керек болса, кесінді мен `+` арқылы **жаңа жол** құрамыз да, айнымалыға қайта меншіктейміз.

## 7. Тізім мен жолды салыстыру

| Қасиеті | list | str |
|---|---|---|
| Элементтері | кез келген тип | тек символдар |
| Индекс, кесінді | бар | бар |
| `len()`, `in` | бар | бар |
| Өзгерту `x[i] = ...` | болады | болмайды |
| Жазылуы | `[1, 2, 3]` | `"123"` |

`list()` функциясы жолды символдар тізіміне айналдырады:

```python
print(list("Абай"))
```

Нәтижесі:
```text
['А', 'б', 'а', 'й']
```

## Жиі кездесетін қателер

**1. Индекс шегінен шығу**

```python
s = "Алма"
# print(s[4])   # IndexError: string index out of range
print(s[3])     # дұрысы: соңғы индекс = len(s) - 1
```

**2. stop индексі кірмейтінін ұмыту**

```python
s = "Python"
print(s[0:3])   # 'Pyt' — 3-индекстегі 'h' кірмейді
print(s[0:4])   # 'Pyth' — 4 символ керек болса
```

**3. Жолдың символын өзгертуге тырысу**

```python
s = "кітап"
# s[-1] = "р"   # TypeError
s = s[:-1] + "р"
print(s)        # кітар
```

**4. Санды жолмен біріктіру**

```python
age = 14
# print("Жасым: " + age)   # TypeError
print("Жасым: " + str(age))
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Жол (str) | символдардың реттелген, өзгермейтін тізбегі |
| Индекс | символдың реттік нөмірі, 0-ден басталады |
| Теріс индекс | соңынан санау: -1 — соңғы символ |
| Кесінді (slice) | `s[start:stop:step]` — жолдың бөлігі |
| Конкатенация | жолдарды `+` арқылы біріктіру |
| Өзгермейтін (immutable) | құрылғаннан кейін ішін өзгертуге болмайтын объект |
| Экрандау | `\n`, `\t` сияқты арнайы символдар |

## Ескерту

- Python 3-те `str` — Unicode жолы, сондықтан қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) мен эмодзи де бір символ ретінде индекстеледі: `len("Қазақ") == 5`.
- Индекс шектен шықса — `IndexError`, ал кесінді ешқашан қате бермейді: шектен тыс бөлік жай ғана ескерілмейді.
- `s[:]` жолдың «көшірмесін» береді, бірақ жол өзгермейтін болғандықтан, Python көбіне сол объектінің өзін қайтарады — бұл қауіпсіз.
- Windows жолдарындағы `\` белгісін екі еселеу ыңғайсыз болса, «шикі» жолды қолданыңыз: `r"C:\Users\Daulet"`.
- Жолдарды цикл ішінде `+` арқылы көп рет біріктіру баяу жұмыс істейді; үлкен мәтін құру үшін тізім мен `"".join(...)` тиімдірек.
- Толығырақ: https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str
