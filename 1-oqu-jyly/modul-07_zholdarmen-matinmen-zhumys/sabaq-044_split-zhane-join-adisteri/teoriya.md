## 1. split() — жолды бөлшектеу

`split()` жолды бөліктерге бөліп, **жолдар тізімін** қайтарады.

Аналогия: бір бөлке нанды тілімдерге кесу. Бөлке — жол, тілімдер — тізім элементтері, пышақ — бөлгіш.

### Бөлгішсіз split()

Аргументсіз шақырылса, жолды **кез келген бос орындар** (бос орын, `\t`, `\n`, бірнеше бос орын қатар) бойынша бөледі және бос элементтер шығармайды:

```python
sentence = "Адам   болам десеңіз\tбілім керек"
words = sentence.split()
print(words)
print("Сөздер саны:", len(words))
```

Нәтижесі:
```text
['Адам', 'болам', 'десеңіз', 'білім', 'керек']
Сөздер саны: 5
```

### Бөлгішпен split(sep)

```python
data = "Алматы,Астана,Шымкент,Қарағанды"
cities = data.split(",")
print(cities)
print(cities[2])

date = "08.02.2027"
parts = date.split(".")
print(parts)
```

Нәтижесі:
```text
['Алматы', 'Астана', 'Шымкент', 'Қарағанды']
Шымкент
['08', '02', '2027']
```

**Назар аударыңыз:** бөлгішпен бөлгенде бос орындар сақталады және бос жолдар пайда болуы мүмкін:

```python
print("а, б, в".split(","))
print("а,,б".split(","))
print("а,,б".split())
```

Нәтижесі:
```text
['а', ' б', ' в']
['а', '', 'б']
['а,,б']
```

Бірінші жағдайда `", "` (үтір + бос орын) бойынша бөлу дұрыс: `"а, б, в".split(", ")`.

### Бөліктер санын шектеу

`split(sep, maxsplit)` — ең көп дегенде `maxsplit` рет бөледі:

```python
line = "Абай Құнанбайұлы ақын, ағартушы, философ"
print(line.split(" ", 1))
```

Нәтижесі:
```text
['Абай', 'Құнанбайұлы ақын, ағартушы, философ']
```

## 2. Бір жолға енгізілген сандар

Олимпиадалық есептерде сандар жиі бір жолда беріледі: `5 12 7`. Оларды оқу үлгісі:

```python
line = "5 12 7"            # input() орнына мысал
parts = line.split()       # ['5', '12', '7']
numbers = []
for p in parts:
    numbers.append(int(p))
print(numbers)
print("Қосындысы:", sum(numbers))
```

Нәтижесі:
```text
[5, 12, 7]
Қосындысы: 24
```

Тізім генераторымен (list comprehension) қысқарақ:

```python
numbers = [int(x) for x in "5 12 7".split()]
print(max(numbers))
```

Нәтижесі:
```text
12
```

Екі немесе үш айнымалыға бірден орау (кортеж тәрізді меншіктеу):

```python
a, b = "17 25".split()
a = int(a)
b = int(b)
print(a + b)
```

Нәтижесі:
```text
42
```

## 3. join() — тізімді жолға жинау

`join()` — `split()`-ке **кері** әрекет. Жазылуы ерекше: бөлгіш жол алдында тұрады:

```
бөлгіш.join(жолдар_тізімі)
```

```python
words = ["Білім", "инемен", "құдық", "қазғандай"]
print(" ".join(words))
print("-".join(words))
print("".join(words))
print(", ".join(["Алма", "Алмұрт", "Өрік"]))
```

Нәтижесі:
```text
Білім инемен құдық қазғандай
Білім-инемен-құдық-қазғандай
Біліминеменқұдыққазғандай
Алма, Алмұрт, Өрік
```

**Маңызды:** `join()` тек **жолдар** тізімін біріктіреді. Сандар болса, алдымен `str()`-ге түрлендіру керек:

```python
nums = [1, 2, 3]
# print("+".join(nums))   # TypeError
print("+".join([str(n) for n in nums]), "=", sum(nums))
```

Нәтижесі:
```text
1+2+3 = 6
```

## 4. split() + join() бірге: типтік үлгілер

### Артық бос орындарды жою
```python
messy = "  Ұстаздан   шәкірт    озар  "
print(" ".join(messy.split()))
```

Нәтижесі:
```text
Ұстаздан шәкірт озар
```

### Сөздердің ретін кері ауыстыру
```python
s = "мен бүгін мектепке барамын"
print(" ".join(s.split()[::-1]))
```

Нәтижесі:
```text
барамын мектепке бүгін мен
```

### Аббревиатура құру
```python
name = "Қазақ ұлттық университеті"
abbr = ""
for word in name.split():
    abbr = abbr + word[0].upper()
print(abbr)
```

Нәтижесі:
```text
ҚҰУ
```

## 5. Мәтінді талдау

Сөздерге бөлгеннен кейін тізіммен жұмыс істейтін барлық құралдар қолжетімді: цикл, `len()`, `max()`, `sorted()`, `count()`.

```python
text = "Еңбек етсең ерінбей тояды қарның тіленбей"
words = text.lower().split()

print("Сөз саны:", len(words))

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w
print("Ең ұзын сөз:", longest)

print("Әліппе бойынша:", sorted(words))

count_e = 0
for w in words:
    if w[0] == "е":
        count_e += 1
print("«е» әрпінен басталатын сөздер:", count_e)
```

Нәтижесі:
```text
Сөз саны: 6
Ең ұзын сөз: тіленбей
Әліппе бойынша: ['ерінбей', 'етсең', 'еңбек', 'тояды', 'тіленбей', 'қарның']
«е» әрпінен басталатын сөздер: 3
```

Ескерту: Python қазақ әріптерін Юникод кодтары бойынша сұрыптайды, сондықтан `ң`, `қ`, `і` сияқты әріптер әліппедегі орнынан басқаша орналасуы мүмкін.

### Тыныс белгілерін алып тастау

Сөздерге бөлмес бұрын үтір, нүкте сияқты белгілерді алып тастаған дұрыс:

```python
text = "Сәлем, достар! Бүгін, ертең, әрдайым."
for mark in ",.!?":
    text = text.replace(mark, "")
print(text.split())
```

Нәтижесі:
```text
['Сәлем', 'достар', 'Бүгін', 'ертең', 'әрдайым']
```

## Жиі кездесетін қателер

**1. join() жазылуын шатастыру**

```python
words = ["а", "б"]
# words.join(" ")      # AttributeError: тізімде join жоқ
print(" ".join(words))
```

**2. split() нәтижесі — жолдар тізімі, сандар емес**

```python
parts = "3 4".split()
print(parts[0] + parts[1])             # 34 — жолдар біріктірілді
print(int(parts[0]) + int(parts[1]))   # 7
```

**3. split() жолды өзгертеді деп ойлау**

```python
s = "a b c"
s.split()
print(s)            # 'a b c' — өзгерген жоқ
lst = s.split()
print(lst)          # ['a', 'b', 'c']
```

**4. Бөлгіштегі бос орынды ескермеу**

```python
print("Алма, Анар".split(","))    # ['Алма', ' Анар']
print("Алма, Анар".split(", "))   # ['Алма', 'Анар']
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `split()` | жолды бос орындар бойынша бөліп, тізім қайтарады |
| `split(sep)` | жолды `sep` бөлгіші бойынша бөледі |
| `join()` | `бөлгіш.join(тізім)` — жолдар тізімін бір жолға біріктіреді |
| Бөлгіш (разделитель, separator) | бөліктерді ажырататын символ/жол |
| Токен | мәтінді бөлгеннен кейінгі жеке бөлік (сөз) |
| Мәтінді талдау (парсинг) | мәтінді бөлшектеп, мәлімет алу |

## Ескерту

- `split()` (аргументсіз) пен `split(" ")` әртүрлі жұмыс істейді: біріншісі бірнеше бос орынды бір бөлгіш деп санайды, екіншісі әр бос орынды бөлек бөлгіш деп санап, бос жолдар (`''`) береді.
- `split()` бос жолға `[]` қайтарады, ал `"".split(",")` нәтижесі — `['']` (бір бос жолы бар тізім).
- `rsplit(sep, maxsplit)` жолды оң жағынан бөледі: `"a.b.c".rsplit(".", 1)` → `['a.b', 'c']`. Жолдарды бөлу үшін `splitlines()` бар.
- Сандарды бір жолдан оқудың қысқа жазбасы: `a, b = map(int, input().split())`. Айнымалылар саны мен бөліктер саны сәйкес болмаса, `ValueError` шығады.
- `join()` тек жолдармен жұмыс істейді: `", ".join(map(str, numbers))` — сандар тізімін біріктірудің ықшам тәсілі.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#str.split
