# Урок 44. Практические задания: split() и join()

## Базовый уровень

### Задание 1. Подсчёт слов
Пользователь вводит предложение. Выведите количество слов и каждое слово на отдельной строке.

Пример:
```text
Предложение: Родина начинается с семьи
Количество слов: 4
Родина
начинается
с
семьи
```

### Задание 2. Сумма трёх чисел
В одну строку через пробел вводятся три целых числа. Выведите их сумму и среднее значение.

Пример:
```text
Числа: 12 7 20
Сумма: 39
Среднее значение: 13.0
```

### Задание 3. Разбор ФИО
Вводится `Фамилия Имя Отчество`. Программа должна вывести `Имя Фамилия` и вариант с инициалами.

Пример:
```text
ФИО: Кунанбаев Абай Кунанбайулы
Абай Кунанбаев
Кунанбаев А. К.
```

### Задание 4. Список городов
Через запятую и пробел вводятся города: `Алматы, Тараз, Актобе, Уральск`. Отсортируйте города по алфавиту и выведите, объединив их разделителем ` → `.

### Задание 5. Хештег
Вводится предложение. Объедините все слова без пробелов, начиная каждое с заглавной буквы, и поставьте перед ними `#`.

Пример: `проект зелёная страна` → `#ПроектЗелёнаяСтрана`

## Продвинутый уровень

### Задание 6. Самое длинное и самое короткое слово
Удалите из предложения знаки препинания (`, . ! ?`) и выведите самое длинное и самое короткое слово, а также среднюю длину слов (с точностью до 1 знака после запятой).

### Задание 7. Журнал оценок
В одну строку вводятся имя ученика и его оценки: `Айдос 5 4 5 3 5`. Программа должна вывести имя и средний балл, а также количество оценок «5».

Пример:
```text
Айдос: средний 4.4, количество «5» — 3
```

### Задание 8. Разворот каждого слова
Сохраняя порядок слов в предложении, разверните **буквы каждого слова** в обратном порядке.

Пример: `Привет друг` → `тевирП гурд`

## ★ Олимпиадная / творческая задача

### Задание 9. Сложение времени
В одну строку вводятся два промежутка времени в формате `ЧЧ:ММ`: `01:45 02:30`. Выведите их сумму в виде `ЧЧ:ММ` (если минут больше 60, они переходят в часы; перед однозначными числами ставится 0).

Пример: `01:45 02:30` → `04:15`

### Задание 10. Разбор CSV-строки
Дано несколько строк (в списке):
```text
Айгерим;9;Алматы
Бекзат;10;Астана
Дана;9;Алматы
Ерлан;11;Шымкент
```
Разбейте каждую строку по `;`, выведите имена учеников из Алматы, объединив их через `, `, и найдите средний номер класса учеников.

## Домашнее задание

1. Вводится пословица. Составьте «аббревиатуру» из первых букв всех её слов.
2. В одну строку вводятся 5 чисел. Выведите в одну строку через пробел только чётные числа (с помощью `join()`).
3. Введите через запятую своё имя и имена друзей и выведите пронумерованный список по алфавиту.

**Задание 6**
```python
text = input("Предложение: ")
for mark in ",.!?":
    text = text.replace(mark, "")
words = text.split()
longest = words[0]
shortest = words[0]
total = 0
for w in words:
    if len(w) > len(longest):
        longest = w
    if len(w) < len(shortest):
        shortest = w
    total += len(w)
print("Самое длинное:", longest)
print("Самое короткое:", shortest)
print("Средняя длина:", round(total / len(words), 1))
```

**Задание 10**
```python
rows = ["Айгерим;9;Алматы", "Бекзат;10;Астана", "Дана;9;Алматы", "Ерлан;11;Шымкент"]
almaty = []
grades_sum = 0
for row in rows:
    name, grade, city = row.split(";")
    grades_sum += int(grade)
    if city == "Алматы":
        almaty.append(name)
print("Из Алматы:", ", ".join(almaty))
print("Средний номер класса:", grades_sum / len(rows))
```
Результат:
```text
Из Алматы: Айгерим, Дана
Средний номер класса: 9.75
```
