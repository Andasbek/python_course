## 1. split() — разбиение строки

`split()` разбивает строку на части и возвращает **список строк**.

Аналогия: нарезка буханки хлеба на ломтики. Буханка — строка, ломтики — элементы списка, нож — разделитель.

### split() без разделителя

При вызове без аргумента строка разбивается **по любым пробельным символам** (пробел, `\t`, `\n`, несколько пробелов подряд), и пустые элементы не появляются:

```python
sentence = "Без   труда не\tвытащишь рыбку"
words = sentence.split()
print(words)
print("Количество слов:", len(words))
```

Результат:
```text
['Без', 'труда', 'не', 'вытащишь', 'рыбку']
Количество слов: 5
```

### split(sep) с разделителем

```python
data = "Алматы,Астана,Шымкент,Караганда"
cities = data.split(",")
print(cities)
print(cities[2])

date = "08.02.2027"
parts = date.split(".")
print(parts)
```

Результат:
```text
['Алматы', 'Астана', 'Шымкент', 'Караганда']
Шымкент
['08', '02', '2027']
```

**Обратите внимание:** при разбиении с разделителем пробелы сохраняются и могут появиться пустые строки:

```python
print("а, б, в".split(","))
print("а,,б".split(","))
print("а,,б".split())
```

Результат:
```text
['а', ' б', ' в']
['а', '', 'б']
['а,,б']
```

В первом случае правильно разбивать по `", "` (запятая + пробел): `"а, б, в".split(", ")`.

### Ограничение количества частей

`split(sep, maxsplit)` — выполняет разбиение не более `maxsplit` раз:

```python
line = "Абай Кунанбайулы поэт, просветитель, философ"
print(line.split(" ", 1))
```

Результат:
```text
['Абай', 'Кунанбайулы поэт, просветитель, философ']
```

## 2. Числа, введённые в одну строку

В олимпиадных задачах числа часто даются в одной строке: `5 12 7`. Шаблон их считывания:

```python
line = "5 12 7"            # пример вместо input()
parts = line.split()       # ['5', '12', '7']
numbers = []
for p in parts:
    numbers.append(int(p))
print(numbers)
print("Сумма:", sum(numbers))
```

Результат:
```text
[5, 12, 7]
Сумма: 24
```

Короче — с помощью генератора списка (list comprehension):

```python
numbers = [int(x) for x in "5 12 7".split()]
print(max(numbers))
```

Результат:
```text
12
```

Распаковка сразу в две или три переменные (присваивание как у кортежа):

```python
a, b = "17 25".split()
a = int(a)
b = int(b)
print(a + b)
```

Результат:
```text
42
```

## 3. join() — сборка списка в строку

`join()` — действие, **обратное** `split()`. Запись необычная: строка-разделитель стоит впереди:

```
разделитель.join(список_строк)
```

```python
words = ["Учиться", "всегда", "пригодится"]
print(" ".join(words))
print("-".join(words))
print("".join(words))
print(", ".join(["Яблоко", "Груша", "Абрикос"]))
```

Результат:
```text
Учиться всегда пригодится
Учиться-всегда-пригодится
Учитьсявсегдапригодится
Яблоко, Груша, Абрикос
```

**Важно:** `join()` объединяет только список **строк**. Если там числа, их сначала нужно преобразовать через `str()`:

```python
nums = [1, 2, 3]
# print("+".join(nums))   # TypeError
print("+".join([str(n) for n in nums]), "=", sum(nums))
```

Результат:
```text
1+2+3 = 6
```

## 4. split() + join() вместе: типовые шаблоны

### Удаление лишних пробелов
```python
messy = "  Тише   едешь —    дальше будешь  "
print(" ".join(messy.split()))
```

Результат:
```text
Тише едешь — дальше будешь
```

### Обратный порядок слов
```python
s = "я сегодня иду в школу"
print(" ".join(s.split()[::-1]))
```

Результат:
```text
школу в иду сегодня я
```

### Создание аббревиатуры
```python
name = "Казахский национальный университет"
abbr = ""
for word in name.split():
    abbr = abbr + word[0].upper()
print(abbr)
```

Результат:
```text
КНУ
```

## 5. Анализ текста

После разбиения на слова доступны все инструменты работы со списками: цикл, `len()`, `max()`, `sorted()`, `count()`.

```python
text = "Едет Емеля на печи ест калачи"
words = text.lower().split()

print("Количество слов:", len(words))

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w
print("Самое длинное слово:", longest)

print("По алфавиту:", sorted(words))

count_e = 0
for w in words:
    if w[0] == "е":
        count_e += 1
print("Слов на букву «е»:", count_e)
```

Результат:
```text
Количество слов: 6
Самое длинное слово: калачи
По алфавиту: ['едет', 'емеля', 'ест', 'калачи', 'на', 'печи']
Слов на букву «е»: 3
```

Примечание: Python сортирует буквы по их кодам Юникода, поэтому буква `ё`, а также казахские буквы `ң`, `қ`, `і` могут оказаться не на том месте, где они стоят в алфавите.

### Удаление знаков препинания

Перед разбиением на слова лучше удалить запятые, точки и подобные знаки:

```python
text = "Привет, друзья! Сегодня, завтра, всегда."
for mark in ",.!?":
    text = text.replace(mark, "")
print(text.split())
```

Результат:
```text
['Привет', 'друзья', 'Сегодня', 'завтра', 'всегда']
```

## Частые ошибки

**1. Путают запись join()**

```python
words = ["а", "б"]
# words.join(" ")      # AttributeError: у списка нет join
print(" ".join(words))
```

**2. Результат split() — список строк, а не чисел**

```python
parts = "3 4".split()
print(parts[0] + parts[1])             # 34 — строки склеились
print(int(parts[0]) + int(parts[1]))   # 7
```

**3. Думают, что split() изменяет строку**

```python
s = "a b c"
s.split()
print(s)            # 'a b c' — не изменилась
lst = s.split()
print(lst)          # ['a', 'b', 'c']
```

**4. Не учитывают пробел в разделителе**

```python
print("Яблоко, Гранат".split(","))    # ['Яблоко', ' Гранат']
print("Яблоко, Гранат".split(", "))   # ['Яблоко', 'Гранат']
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| `split()` | разбивает строку по пробельным символам и возвращает список |
| `split(sep)` | разбивает строку по разделителю `sep` |
| `join()` | `разделитель.join(список)` — объединяет список строк в одну строку |
| Разделитель (separator) | символ/строка, отделяющая части друг от друга |
| Токен | отдельная часть (слово) после разбиения текста |
| Анализ текста (парсинг) | разбор текста на части для получения данных |

## Примечание

- `split()` (без аргумента) и `split(" ")` работают по-разному: первый считает несколько пробелов подряд одним разделителем, второй — каждый пробел отдельным разделителем и даёт пустые строки (`''`).
- `split()` для пустой строки возвращает `[]`, а `"".split(",")` — `['']` (список с одной пустой строкой).
- `rsplit(sep, maxsplit)` разбивает строку справа: `"a.b.c".rsplit(".", 1)` → `['a.b', 'c']`. Для разбиения по строкам есть `splitlines()`.
- Короткая запись чтения чисел из одной строки: `a, b = map(int, input().split())`. Если число переменных не совпадает с числом частей — `ValueError`.
- `join()` работает только со строками: `", ".join(map(str, numbers))` — компактный способ объединить список чисел.
- Документация: https://docs.python.org/3/library/stdtypes.html#str.split
