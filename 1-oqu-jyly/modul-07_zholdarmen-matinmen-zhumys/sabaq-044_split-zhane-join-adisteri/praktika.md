# Сабақ 44. Практикалық тапсырмалар: split() және join()

## Базалық деңгей

### 1-тапсырма. Сөздерді санау
Пайдаланушы сөйлем енгізеді. Сөздер санын және әр сөзді жеке жолда шығарыңыз.

Мысал:
```text
Сөйлем: Отан отбасынан басталады
Сөздер саны: 3
Отан
отбасынан
басталады
```

### 2-тапсырма. Үш санның қосындысы
Бір жолға бос орын арқылы үш бүтін сан енгізіледі. Олардың қосындысын және орта мәнін шығарыңыз.

Мысал:
```text
Сандар: 12 7 20
Қосындысы: 39
Орта мәні: 13.0
```

### 3-тапсырма. Аты-жөнді бөлу
`Тегі Аты Әкесінің аты` енгізіледі. Бағдарлама `Аты Тегі` түрінде және инициалдармен шығарсын.

Мысал:
```text
Аты-жөні: Құнанбаев Абай Құнанбайұлы
Абай Құнанбаев
Құнанбаев А. Қ.
```

### 4-тапсырма. Қалалар тізімі
Үтір мен бос орын арқылы қалалар енгізіледі: `Алматы, Тараз, Ақтөбе, Орал`. Қалаларды әліппе бойынша сұрыптап, ` → ` бөлгішімен біріктіріп шығарыңыз.

### 5-тапсырма. Хэштег
Сөйлем енгізіледі. Барлық сөздерді бас әріптен бастап, бос орынсыз біріктіріп, алдына `#` қойыңыз.

Мысал: `жасыл ел жобасы` → `#ЖасылЕлЖобасы`

## Кеңейтілген деңгей

### 6-тапсырма. Ең ұзын және ең қысқа сөз
Сөйлемдегі тыныс белгілерін (`, . ! ?`) алып тастап, ең ұзын және ең қысқа сөзді, сондай-ақ сөздердің орташа ұзындығын (1 ондық белгіге дейін) шығарыңыз.

### 7-тапсырма. Бағалар журналы
Бір жолға оқушы аты мен бағалары енгізіледі: `Айдос 5 4 5 3 5`. Бағдарлама аты мен орташа бағасын, сондай-ақ «5» бағасының санын шығарсын.

Мысал:
```text
Айдос: орташа 4.4, «5» саны — 3
```

### 8-тапсырма. Әр сөзді аудару
Сөйлемдегі сөздердің ретін сақтап, **әр сөздің әріптерін** кері аударыңыз.

Мысал: `Сәлем досым` → `меләС мысод`

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Уақытты қосу
Екі уақыт аралығы `ЧЧ:ММ` форматында бір жолда енгізіледі: `01:45 02:30`. Олардың қосындысын `ЧЧ:ММ` түрінде шығарыңыз (минут 60-тан асса, сағатқа ауыссын; бір таңбалы сандардың алдына 0 қойылсын).

Мысал: `01:45 02:30` → `04:15`

### 10-тапсырма. CSV жолын талдау
Бірнеше жол берілген (тізімде):
```text
Айгерім;9;Алматы
Бекзат;10;Астана
Дана;9;Алматы
Ерлан;11;Шымкент
```
Әр жолды `;` бойынша бөліп, Алматыдан келген оқушылардың аттарын `, ` арқылы біріктіріп шығарыңыз және оқушылардың сыныптарының орташасын табыңыз.

## Үй тапсырмасы

1. Мақал-мәтел енгізіледі. Әр сөзінің бірінші әрпінен «аббревиатура» құрыңыз.
2. Бір жолға 5 сан енгізіледі. Тек жұп сандарды бос орын арқылы бір жолға шығарыңыз (`join()` қолданып).
3. Өз есімдеріңізді, достарыңыздың есімдерін үтір арқылы енгізіп, әліппе бойынша нөмірленген тізім шығарыңыз.

**6-тапсырма**
```python
text = input("Сөйлем: ")
for mark in ",.!?":
    text = text.replace(mark, "")
words = text.split()
longest = words[0]
shortest = words[0]
total = 0
for w in words:
    if len(w) > len(longest):
        longest = w
    if len(w) < len(shortest):
        shortest = w
    total += len(w)
print("Ең ұзын:", longest)
print("Ең қысқа:", shortest)
print("Орташа ұзындық:", round(total / len(words), 1))
```

**10-тапсырма**
```python
rows = ["Айгерім;9;Алматы", "Бекзат;10;Астана", "Дана;9;Алматы", "Ерлан;11;Шымкент"]
almaty = []
grades_sum = 0
for row in rows:
    name, grade, city = row.split(";")
    grades_sum += int(grade)
    if city == "Алматы":
        almaty.append(name)
print("Алматыдан:", ", ".join(almaty))
print("Орташа сынып:", grades_sum / len(rows))
```

```text

Орташа сынып: 9.75
```
