# Сабақ 46. Практикалық тапсырмалар: «Палиндром», «Қарапайым шифр», «Мәтін статистикасы»

Практикум үш мини-жобадан тұрады. Әр жобаны қадам бойынша орындаңыз: әр қадамнан кейін бағдарламаны іске қосып, тексеріңіз.

## Базалық деңгей

### 1-жоба. «Палиндром»

**1-қадам.** Пайдаланушыдан сөз енгізуді сұраңыз және оны кіші әріпке айналдырыңыз.

**2-қадам.** Сөзді кесінді арқылы кері аударып, салыстырыңыз. Нәтижені шығарыңыз.
```text
Сөз енгізіңіз: Қазақ
«Қазақ» — палиндром!
```

**3-қадам.** Бағдарламаны сөйлемге бейімдеңіз: бос орындар мен тыныс белгілерін алып тастап тексеріңіз.
```text
Сөйлем: Was it a car or a cat I saw?
Палиндром!
```
Тест ретінде мына сөйлемді де тексеріңіз: `Ақ серек, кере сақ!` — бағдарламаңыз не дейді? Неге? (Тазаланған жолды және оның кері түрін экранға шығарып, салыстырыңыз.)

**4-қадам.** Сандарға арналған нұсқа: пайдаланушы бүтін сан енгізеді, бағдарлама ол палиндром-сан ба екенін айтады (`12321` → иә, `1231` → жоқ).

**5-қадам.** `while True` циклімен бағдарламаны қайталанатын етіңіз: `стоп` сөзі енгізілгенде тоқтасын.

### 2-жоба. «Қарапайым шифр» (Цезарь шифрі)

**1-қадам.** Ағылшынша мәтін мен `k` кілтін енгізіңіз.

**2-қадам.** Тек кіші латын әріптерін шифрлаңыз, қалған символдар өзгермесін.

**3-қадам.** Бас әріптерді де шифрлауды қосыңыз.
```text
Мәтін: Hello, Python!
Кілт: 3
Шифр: Khoor, Sbwkrq!
```

**4-қадам.** Мәзір қосыңыз: `1 — шифрлау`, `2 — дешифрлау`. Дешифрлауда кілт `-k` болады.
```text
1 — шифрлау, 2 — дешифрлау: 2
Мәтін: Khoor, Sbwkrq!
Кілт: 3
Нәтиже: Hello, Python!
```

**5-қадам.** Жұбыңызға шифрланған хабар мен кілтті жіберіңіз, оның хабарын ашыңыз.

### 3-жоба. «Мәтін статистикасы»

Бағдарлама көп жолды мәтінмен жұмыс істейді (мәтінді бағдарлама ішінде `"""..."""` арқылы беріңіз немесе `input()` арқылы бір абзац енгізіңіз).

**1-қадам.** Символдар саны және бос орынсыз символдар саны.

**2-қадам.** Әріптер, цифрлар, бос орындар саны.

**3-қадам.** Сөздер саны (тыныс белгілері алынып тасталғаннан кейін) және сөйлемдер саны.

**4-қадам.** Ең ұзын сөз және сөздердің орташа ұзындығы.

**5-қадам.** Ең жиі кездесетін әріп.

Шығару үлгісі:
```text
===== МӘТІН СТАТИСТИКАСЫ =====
Символдар:            120
Бос орынсыз:          102
Әріптер:              95
Сөздер:               18
Сөйлемдер:            3
Ең ұзын сөз:          бағдарламалау
Орташа сөз ұзындығы:  5.3
Ең жиі әріп:          а (14 рет)
```

## Кеңейтілген деңгей

### 4-тапсырма. Ең ұзын палиндром-сөз
Мәтіндегі сөздердің ішінен палиндром болатындарын (ұзындығы ≥ 3) тауып, тізімін шығарыңыз. Мысалы: `Ата мен ана қазақ тілінде сөйлейді` → `ата, ана, қазақ`.

### 5-тапсырма. Қазақша Цезарь шифрі
Қазақ әліппесін (`"аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"`) қолданып, қазақша мәтінді шифрлайтын және дешифрлайтын бағдарлама жазыңыз.

### 6-тапсырма. Сөздердің ұзындығы бойынша статистика
Мәтіндегі сөздерді ұзындығы бойынша топтастырып шығарыңыз: «1 әріпті сөздер: 2», «2 әріпті сөздер: 5» және т.с.с. (кірістірілген цикл қолданыңыз).

## ★ Олимпиадалық / шығармашылық тапсырма

### 7-тапсырма. Шифрды бұзу (brute force)
Шифрланған ағылшынша мәтін берілген: `Wkh txlfn eurzq ira mxpsv ryhu wkh odcb grj`. Кілт белгісіз. Бағдарлама 1-ден 25-ке дейінгі барлық кілттермен дешифрлап, нәтижелерді шығарсын. Қайсысы мағыналы? Қосымша: `the` сөзі кездесетін нұсқаны автоматты түрде тауып көрсетіңіз.

### 8-тапсырма. Виженер шифрі
Цезарь шифрінде барлық әріп бірдей ығысады. Виженер шифрінде ығысу кілт-сөзден алынады: кілт `key` болса, 1-әріп `k` (10) позицияға, 2-әріп `e` (4), 3-әріп `y` (24), 4-әріп қайтадан `k`... Тек кіші латын әріптерінен тұратын мәтінді Виженер шифрімен шифрлаңыз.

Мысал: мәтін `attack`, кілт `lemon` → `lxfopv`.

## Үй тапсырмасы

1. Жақындарыңызға арналған қысқа құттықтауды Цезарь шифрімен шифрлап, келесі сабаққа әкеліңіз — сыныптастарыңыз ашып көрсін.
2. Сүйікті кітабыңыздан бір абзацты «Мәтін статистикасы» бағдарламасына енгізіп, нәтижесін дәптерге жазыңыз.
3. 5 қазақша палиндром-сөз тауып, бағдарламаңызбен тексеріңіз.

## Бағалау критерийлері

| Критерий | Ұпай |
|---|---|
| 1-жоба «Палиндром»: сөзді дұрыс тексереді (2), сөйлемді тазалап тексереді (2), сандар нұсқасы және қайталау циклі (1) | 5 |
| 2-жоба «Шифр»: кіші әріптерді шифрлайды (2), бас әріптер мен басқа символдарды дұрыс өңдейді (2), шифрлау/дешифрлау мәзірі (1) | 5 |
| 3-жоба «Статистика»: символдар, әріптер, сөздер, сөйлемдер (3), ең ұзын сөз және орташа ұзындық (1), ең жиі әріп (1) | 5 |
| Код мәдениеті: түсінікті айнымалы атаулары, түсініктемелер, әдемі шығару | 3 |
| Тестілеу: әр жобаны кемінде 3 түрлі мәліметпен тексерген | 2 |
| **Барлығы** | **20** |

Бағалау шкаласы: 18–20 ұпай — «өте жақсы», 14–17 — «жақсы», 10–13 — «қанағаттанарлық», 10-нан төмен — қосымша консультация. Кеңейтілген және ★ тапсырмалар үшін қосымша 1–3 бонус ұпай беріледі.

**1-жоба (толық нұсқа)**
```python
# «Палиндром» бағдарламасы
while True:
    text = input("Сөз, сөйлем немесе сан (стоп — шығу): ")
    if text.lower() == "стоп":
        print("Сау болыңыз!")
        break
    clean = ""
    for ch in text.lower():
        if ch.isalnum():
            clean += ch
    if clean == "":
        print("Бос енгізу")
    elif clean == clean[::-1]:
        print(f"«{text}» — палиндром!")
    else:
        print(f"«{text}» — палиндром емес.")
```
Ескерту: 3-қадамдағы «Ақ серек, кере сақ!» — палиндром ЕМЕС (`ақсереккересақ` ≠ `қасереккересқа`), тексеру үшін әдейі берілген «тұзақ». Нақты палиндром-сөйлемдер: `Was it a car or a cat I saw?`, `Never odd or even`.

**2-жоба (толық нұсқа)**
```python
# Цезарь шифрі
mode = input("1 — шифрлау, 2 — дешифрлау: ")
text = input("Мәтін: ")
k = int(input("Кілт: "))
if mode == "2":
    k = -k
result = ""
for ch in text:
    if "a" <= ch <= "z":
        result += chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    elif "A" <= ch <= "Z":
        result += chr((ord(ch) - ord("A") + k) % 26 + ord("A"))
    else:
        result += ch
print("Нәтиже:", result)
```

**3-жоба (толық нұсқа)**
```python
text = """Python — бағдарламалау тілі. Оны 1991 жылы Гвидо ван Россум жасады!
Бүгін Python тілін мектеп оқушылары да, ғалымдар да үйренеді."""

alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюяabcdefghijklmnopqrstuvwxyz"

letters = 0
digits = 0
spaces = 0
for ch in text:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1

clean = text
for mark in ".,!?—-:;\"()":
    clean = clean.replace(mark, " ")
words = clean.lower().split()

sentences = text.count(".") + text.count("!") + text.count("?")

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w

best = ""
best_count = 0
lower_text = text.lower()
for letter in alphabet:
    c = lower_text.count(letter)
    if c > best_count:
        best_count = c
        best = letter

print("===== МӘТІН СТАТИСТИКАСЫ =====")
print(f"{'Символдар:':22}{len(text)}")
print(f"{'Бос орынсыз:':22}{len(text) - spaces}")
print(f"{'Әріптер:':22}{letters}")
print(f"{'Цифрлар:':22}{digits}")
print(f"{'Сөздер:':22}{len(words)}")
print(f"{'Сөйлемдер:':22}{sentences}")
print(f"{'Ең ұзын сөз:':22}{longest}")
if len(words) > 0:
    print(f"{'Орташа сөз ұзындығы:':22}{letters / len(words):.1f}")
print(f"{'Ең жиі әріп:':22}{best} ({best_count} рет)")
```

**5-тапсырма**
```python
alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"
n = len(alphabet)
mode = input("1 — шифрлау, 2 — дешифрлау: ")
text = input("Мәтін: ")
k = int(input("Кілт: "))
if mode == "2":
    k = -k
result = ""
for ch in text:
    low = ch.lower()
    pos = alphabet.find(low)
    if pos == -1:
        result += ch
    else:
        new = alphabet[(pos + k) % n]
        if ch.isupper():
            new = new.upper()
        result += new
print("Нәтиже:", result)
```

**6-тапсырма**

```python
text = input("Мәтін: ")
for mark in ".,!?—-":
    text = text.replace(mark, " ")
words = text.split()
max_len = 0
for w in words:
    if len(w) > max_len:
        max_len = len(w)
for length in range(1, max_len + 1):
    count = 0
    for w in words:
        if len(w) == length:
            count += 1
    if count > 0:
        print(f"{length} әріпті сөздер: {count}")
```
