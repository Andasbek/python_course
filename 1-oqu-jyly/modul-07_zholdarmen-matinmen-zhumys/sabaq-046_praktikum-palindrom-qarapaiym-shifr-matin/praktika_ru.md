## Базовый уровень

### Проект 1. «Палиндром»

**Шаг 1.** Попросите пользователя ввести слово и переведите его в строчные буквы.

**Шаг 2.** Разверните слово с помощью среза и сравните. Выведите результат.
```text
Введите слово: Казак
«Казак» — палиндром!
```

**Шаг 3.** Адаптируйте программу для предложений: удалите пробелы и знаки препинания и проверьте.
```text
Предложение: Was it a car or a cat I saw?
Палиндром!
```
В качестве теста проверьте и такое предложение: `Леша на полке клопа нашёл` — что скажет ваша программа? Почему? (Выведите на экран очищенную строку и её развёрнутый вариант и сравните.)

**Шаг 4.** Вариант для чисел: пользователь вводит целое число, программа сообщает, является ли оно числом-палиндромом (`12321` → да, `1231` → нет).

**Шаг 5.** С помощью цикла `while True` сделайте программу повторяющейся: при вводе слова `стоп` она должна завершаться.

### Проект 2. «Простой шифр» (шифр Цезаря)

**Шаг 1.** Введите текст на английском языке и ключ `k`.

**Шаг 2.** Шифруйте только строчные латинские буквы, остальные символы не должны меняться.

**Шаг 3.** Добавьте шифрование заглавных букв.
```text
Текст: Hello, Python!
Ключ: 3
Шифр: Khoor, Sbwkrq!
```

**Шаг 4.** Добавьте меню: `1 — шифрование`, `2 — дешифрование`. При дешифровании ключ равен `-k`.
```text
1 — шифрование, 2 — дешифрование: 2
Текст: Khoor, Sbwkrq!
Ключ: 3
Результат: Hello, Python!
```

**Шаг 5.** Отправьте напарнику зашифрованное сообщение и ключ, разгадайте его сообщение.

### Проект 3. «Статистика текста»

Программа работает с многострочным текстом (задайте текст внутри программы с помощью `"""..."""` или введите один абзац через `input()`).

**Шаг 1.** Количество символов и количество символов без пробелов.

**Шаг 2.** Количество букв, цифр, пробелов.

**Шаг 3.** Количество слов (после удаления знаков препинания) и количество предложений.

**Шаг 4.** Самое длинное слово и средняя длина слов.

**Шаг 5.** Самая часто встречающаяся буква.

## ★ Олимпиадная / творческая задача

### Задание 7. Взлом шифра (brute force)

Какой из них осмысленный? Дополнительно: автоматически найдите и отметьте вариант, в котором встречается слово `the`.

### Задание 8. Шифр Виженера
В шифре Цезаря все буквы сдвигаются одинаково. В шифре Виженера сдвиг берётся из ключевого слова: если ключ `key`, то 1-я буква сдвигается на `k` (10) позиций, 2-я — на `e` (4), 3-я — на `y` (24), 4-я — снова на `k`... Зашифруйте шифром Виженера текст, состоящий только из строчных латинских букв.

Пример: текст `attack`, ключ `lemon` → `lxfopv`.

**Проект 1 (полная версия)**
```python
# Программа «Палиндром»
while True:
    text = input("Слово, предложение или число (стоп — выход): ")
    if text.lower() == "стоп":
        print("До свидания!")
        break
    clean = ""
    for ch in text.lower():
        if ch.isalnum():
            clean += ch
    if clean == "":
        print("Пустой ввод")
    elif clean == clean[::-1]:
        print(f"«{text}» — палиндром!")
    else:
        print(f"«{text}» — не палиндром.")
```
Примечание: предложение «Леша на полке клопа нашёл» из шага 3 НЕ является палиндромом для программы (`лешанаполкеклопанашёл` ≠ `лёшанаполкеклопанашел`, так как «е» и «ё» — разные символы) — это специально поставленная «ловушка». Если написать «Лёша на полке клопа нашёл», получится палиндром. Настоящие предложения-палиндромы: `Was it a car or a cat I saw?`, `Never odd or even`, «А роза упала на лапу Азора».

text = """Python — язык программирования. Его создал Гвидо ван Россум в 1991 году!
Сегодня язык Python изучают и школьники, и учёные."""

alphabet = "абвгдеёжзийклмнопрстуфхцчшщъыьэюяabcdefghijklmnopqrstuvwxyz"

letters = 0
digits = 0
spaces = 0
for ch in text:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1

clean = text
for mark in ".,!?—-:;\"()":
    clean = clean.replace(mark, " ")
words = clean.lower().split()

sentences = text.count(".") + text.count("!") + text.count("?")

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w

best = ""
best_count = 0
lower_text = text.lower()
for letter in alphabet:
    c = lower_text.count(letter)
    if c > best_count:
        best_count = c
        best = letter

print("===== СТАТИСТИКА ТЕКСТА =====")
print(f"{'Символов:':22}{len(text)}")
print(f"{'Без пробелов:':22}{len(text) - spaces}")
print(f"{'Букв:':22}{letters}")
print(f"{'Цифр:':22}{digits}")
print(f"{'Слов:':22}{len(words)}")
print(f"{'Предложений:':22}{sentences}")
print(f"{'Самое длинное слово:':22}{longest}")
if len(words) > 0:
    print(f"{'Средняя длина слова:':22}{letters / len(words):.1f}")
print(f"{'Самая частая буква:':22}{best} ({best_count} раз)")

alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"

        result += ch
