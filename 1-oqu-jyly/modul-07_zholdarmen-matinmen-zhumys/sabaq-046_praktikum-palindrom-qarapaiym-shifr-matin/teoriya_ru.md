## 1. Палиндром

**Палиндром** — слово, число или предложение, которое одинаково читается слева направо и справа налево.

Примеры: `шалаш`, `казак`, `потоп`, `121`, `12321`, по-казахски `қазақ`, `қайық`, по-английски `level`, `radar`. В предложениях-палиндромах пробелы, знаки препинания и регистр не учитываются: «А роза упала на лапу Азора».

### Алгоритм
1. Ввести текст.
2. Очистить: перевести в строчные буквы, оставить только буквы и цифры.
3. Сравнить очищенную строку с её развёрнутым вариантом.

```python
text = "Казак"
clean = ""
for ch in text.lower():
    if ch.isalnum():
        clean += ch
if clean == clean[::-1]:
    print("Палиндром")
else:
    print("Не палиндром")
```

Результат:
```text
Палиндром
```

### Способ без среза: два «указателя»

Сравниваем первый символ с последним, второй — со вторым с конца... Если хотя бы одна пара не совпала — не палиндром.

```python
s = "level"
is_pal = True
for i in range(len(s) // 2):
    if s[i] != s[len(s) - 1 - i]:
        is_pal = False
        break
print(is_pal)
```

Результат:
```text
True
```

Этот способ эффективнее: он проверяет только половину строки и сразу останавливается при обнаружении несовпадения.

## 2. Простой шифр: шифр Цезаря

**Криптография** — наука о защите информации от посторонних. **Шифрование** — приведение открытого текста к непонятному виду, **дешифрование** — обратный процесс. **Ключ** — секретный параметр правила шифрования.

**Шифр Цезаря:** каждая буква сдвигается по алфавиту на `k` позиций. При `k = 3`: `a → d`, `b → e`, ..., `x → a`, `y → b`, `z → c` (с конца алфавита переходим в начало).

| Открытый | a | b | c | ... | x | y | z |
|---|---|---|---|---|---|---|---|
| Шифр (k=3) | d | e | f | ... | a | b | c |

### Формула
Номер буквы в алфавите `p = ord(ch) - ord("a")` (от 0 до 25).
Новый номер: `(p + k) % 26`. Новая буква: `chr(новый_номер + ord("a"))`.

`% 26` (остаток) обеспечивает «переход» с конца алфавита в начало (как часовая стрелка после 12 возвращается к 1).

```python
text = "Hello, World!"
k = 3
result = ""
for ch in text:
    if "a" <= ch <= "z":
        result += chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    elif "A" <= ch <= "Z":
        result += chr((ord(ch) - ord("A") + k) % 26 + ord("A"))
    else:
        result += ch          # остальные символы не меняются
print(result)
```

Результат:
```text
Khoor, Zruog!
```

**Дешифрование** — та же программа, только вместо `k` берём `-k` (или `26 - k`). В Python остаток от деления отрицательного числа по `%` положителен: `(-2) % 26 = 24`, поэтому формула работает правильно.

### Шифрование с казахским алфавитом

Коды Юникода казахских букв идут не подряд (например, `ә`, `ғ`, `қ` расположены отдельно; то же касается и русской буквы `ё`). Поэтому задаём алфавит строкой и находим номер буквы с помощью `find()`:

```python
alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"
n = len(alphabet)
k = 2
text = "сәлем"
result = ""
for ch in text:
    pos = alphabet.find(ch)
    if pos == -1:
        result += ch
    else:
        result += alphabet[(pos + k) % n]
print(n, result)
```

Результат:
```text
42 увнжң
```

### Слабость шифра
В шифре Цезаря всего 25 возможных ключей (для латиницы), поэтому его легко взломать **перебором** всех ключей (brute force). Современные шифры (например, в банковских приложениях) основаны на гораздо более сложной математике.

## 3. Статистика текста

Анализ текста — метод, который используют редакторы, поисковые системы и сервисы «проверки на плагиат».

| Показатель | Как вычисляем |
|---|---|
| Количество символов | `len(text)` |
| Символы без пробелов | `len(text) - text.count(" ")` |
| Количество слов | очистив от знаков препинания, `len(text.split())` |
| Количество предложений | подсчёт знаков `.`, `!`, `?` |
| Буквы / цифры | цикл с `isalpha()`, `isdigit()` |
| Самое длинное слово | цикл по словам, сравнение длины |
| Средняя длина слова | количество букв / количество слов |
| Самая частая буква | цикл по алфавиту + `count()` |

```python
text = "Знание – неисчерпаемое богатство. Ученье – свет, а неученье – тьма!"
clean = text
for mark in ".,!?–-":
    clean = clean.replace(mark, " ")
words = clean.lower().split()

sentences = text.count(".") + text.count("!") + text.count("?")
letters = 0
for ch in text:
    if ch.isalpha():
        letters += 1

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w

print("Символов:", len(text))
print("Слов:", len(words))
print("Предложений:", sentences)
print("Букв:", letters)
print("Самое длинное слово:", longest)
print("Средняя длина слова:", round(letters / len(words), 1))
```

Результат:
```text
Символов: 67
Слов: 8
Предложений: 2
Букв: 51
Самое длинное слово: неисчерпаемое
Средняя длина слова: 6.4
```

### Самая частая буква

```python
text = "на дворе трава на траве дрова"
alphabet = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"
best = ""
best_count = 0
for letter in alphabet:
    c = text.count(letter)
    if c > best_count:
        best_count = c
        best = letter
print("Самая частая буква:", best, "-", best_count, "раз")
```

Результат:
```text
Самая частая буква: а - 6 раз
```

Интересный факт: в любом языке частота букв почти постоянна. Пользуясь этим свойством, шифр Цезаря можно взломать и без ключа — самой частой буквой шифра, скорее всего, окажется «о» (в русском), «а» (в казахском) или «e» (в английском). Это называется **частотным анализом**.

## 4. Проверка на граничных случаях

Программы обработки текста стоит проверять не только на обычных данных, но и на граничных случаях: пустая строка, строка из одного символа, только цифры или только знаки препинания, смешанный регистр.

```python
tests = ["А роза упала на лапу Азора", "", "!!!", "Abc"]
for text in tests:
    clean = ""
    for ch in text.lower():
        if ch.isalnum():
            clean += ch
    print(repr(text), clean == clean[::-1])
```

Результат:
```text
'А роза упала на лапу Азора' True
'' True
'!!!' True
'Abc' False
```

Пустая строка и строка без букв после очистки становятся пустыми и поэтому считаются палиндромами. Заранее решите, какой ответ нужен в вашей программе в таком случае.

## Частые ошибки

**1. Не очищают текст при проверке палиндрома**

```python
s = "Казак"
print(s == s[::-1])               # False — «К» и «к» разные
print(s.lower() == s.lower()[::-1])   # True
```

**2. Забывают % 26 при шифровании**

```python
ch = "y"
# print(chr(ord(ch) + 3))           # '|' — вышли за пределы алфавита
print(chr((ord(ch) - ord("a") + 3) % 26 + ord("a")))   # b
```

**3. Шифруют и не-буквенные символы**

Пробелы и знаки препинания нужно оставлять без изменений — поэтому проверяем через `if`.

**4. Деление на ноль при пустом тексте**

```python
words = "".split()
if len(words) > 0:
    print(10 / len(words))
else:
    print("Текст пуст")
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Палиндром | слово/число/предложение, одинаково читающееся с обеих сторон |
| Криптография | наука о защите информации путём шифрования |
| Шифрование / дешифрование | приведение открытого текста к секретному виду / обратное преобразование |
| Ключ | параметр правила шифрования (в шифре Цезаря — величина сдвига) |
| Шифр Цезаря | сдвиг каждой буквы по алфавиту на k позиций |
| Частотный анализ | исследование текста по частоте встречаемости букв |

## Примечание

- Проверка палиндрома через `s[::-1]` создаёт полную копию строки; для очень длинных текстов способ двух «указателей» экономит память.
- Оператор `%` в Python даёт неотрицательный остаток и для отрицательных чисел (`(-3) % 26 == 23`), поэтому при дешифровании шифра Цезаря можно смело использовать сдвиг `-k`. В C и Java это работает иначе.
- Методы `str.maketrans()` и `translate()` позволяют один раз построить таблицу замен и зашифровать весь текст за один шаг: `text.translate(str.maketrans("abc", "bcd"))`.
- Для подсчёта частоты букв удобен `collections.Counter`: `Counter(text).most_common(3)` — три самых частых символа.
- Шифр Цезаря — учебный пример; для реальной защиты данных используют модули `hashlib`, `secrets` или специальные криптографические библиотеки.
- Документация: https://docs.python.org/3/library/stdtypes.html#str.translate
