## 1. Палиндром

**Палиндром** — солдан оңға және оңнан солға бірдей оқылатын сөз, сан немесе сөйлем.

Мысалдар: `қазақ`, `қайық`, `ата`, `ана`, `121`, `12321`, ағылшынша `level`, `radar`. Сөйлем-палиндромдарда бос орын, тыныс белгілері мен регистр ескерілмейді: «А роза упала на лапу Азора» (орысша).

### Алгоритм
1. Мәтінді енгізу.
2. Тазалау: кіші әріпке айналдыру, тек әріптер мен цифрларды қалдыру.
3. Тазаланған жолды оның кері аударылған түрімен салыстыру.

```python
text = "Қазақ"
clean = ""
for ch in text.lower():
    if ch.isalnum():
        clean += ch
if clean == clean[::-1]:
    print("Палиндром")
else:
    print("Палиндром емес")
```

Нәтижесі:
```text
Палиндром
```

### Кесіндісіз тәсіл: екі «көрсеткіш»

Бірінші символды соңғысымен, екіншісін соңынан екіншімен салыстырамыз... Бір жұп сәйкес келмесе — палиндром емес.

```python
s = "level"
is_pal = True
for i in range(len(s) // 2):
    if s[i] != s[len(s) - 1 - i]:
        is_pal = False
        break
print(is_pal)
```

Нәтижесі:
```text
True
```

Бұл тәсіл тиімдірек: жолдың тек жартысын тексереді және сәйкессіздік табылса, бірден тоқтайды.

## 2. Қарапайым шифр: Цезарь шифрі

**Криптография** — ақпаратты бөгде адамдардан қорғау ғылымы. **Шифрлау** — ашық мәтінді түсініксіз түрге келтіру, **дешифрлау** — кері процесс. **Кілт** — шифрлау ережесінің құпия параметрі.

**Цезарь шифрі:** әр әріп әліппе бойынша `k` позицияға ығыстырылады. `k = 3` болса: `a → d`, `b → e`, ..., `x → a`, `y → b`, `z → c` (соңынан басына айналады).

| Ашық | a | b | c | ... | x | y | z |
|---|---|---|---|---|---|---|---|
| Шифр (k=3) | d | e | f | ... | a | b | c |

### Формула
Әріптің әліппедегі нөмірі `p = ord(ch) - ord("a")` (0-ден 25-ке дейін).
Жаңа нөмір: `(p + k) % 26`. Жаңа әріп: `chr(жаңа_нөмір + ord("a"))`.

`% 26` (қалдық) — әліппенің соңынан басына «айналуды» қамтамасыз етеді (сағат тілі 12-ден кейін 1-ге оралатыны сияқты).

```python
text = "Hello, World!"
k = 3
result = ""
for ch in text:
    if "a" <= ch <= "z":
        result += chr((ord(ch) - ord("a") + k) % 26 + ord("a"))
    elif "A" <= ch <= "Z":
        result += chr((ord(ch) - ord("A") + k) % 26 + ord("A"))
    else:
        result += ch          # басқа символдар өзгермейді
print(result)
```

Нәтижесі:
```text
Khoor, Zruog!
```

**Дешифрлау** — сол бағдарлама, тек `k` орнына `-k` (немесе `26 - k`) аламыз. Python-да теріс санның `%` бойынша қалдығы оң болады: `(-2) % 26 = 24`, сондықтан формула дұрыс жұмыс істейді.

### Қазақ әліппесімен шифрлау

Қазақ әріптерінің Юникод кодтары қатар тұрмайды (мысалы, `ә`, `ғ`, `қ` бөлек орналасқан). Сондықтан әліппені жол ретінде береміз де, `find()` арқылы нөмірін табамыз:

```python
alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"
n = len(alphabet)
k = 2
text = "сәлем"
result = ""
for ch in text:
    pos = alphabet.find(ch)
    if pos == -1:
        result += ch
    else:
        result += alphabet[(pos + k) % n]
print(n, result)
```

Нәтижесі:
```text
42 увнжң
```

### Шифрдің әлсіздігі
Цезарь шифрінде тек 25 мүмкін кілт бар (латын үшін), сондықтан оны барлық кілттерді **тексеріп шығу** (brute force) арқылы оңай ашуға болады. Қазіргі шифрлар (мысалы, банк қосымшаларындағы) әлдеқайда күрделі математикаға негізделген.

## 3. Мәтін статистикасы

Мәтінді талдау — редакторлар, іздеу жүйелері және «плагиатқа тексеру» сервистері қолданатын әдіс.

| Көрсеткіш | Қалай есептейміз |
|---|---|
| Символдар саны | `len(text)` |
| Бос орынсыз символдар | `len(text) - text.count(" ")` |
| Сөздер саны | тыныс белгілерін тазалап, `len(text.split())` |
| Сөйлемдер саны | `.`, `!`, `?` белгілерін санау |
| Әріптер / цифрлар | `isalpha()`, `isdigit()` арқылы цикл |
| Ең ұзын сөз | сөздер бойынша цикл, ұзындықты салыстыру |
| Орташа сөз ұзындығы | әріптер саны / сөздер саны |
| Ең жиі әріп | әліппе бойынша цикл + `count()` |

```python
text = "Білім – таусылмас қазына. Оқу – инемен құдық қазғандай!"
clean = text
for mark in ".,!?–-":
    clean = clean.replace(mark, " ")
words = clean.lower().split()

sentences = text.count(".") + text.count("!") + text.count("?")
letters = 0
for ch in text:
    if ch.isalpha():
        letters += 1

longest = ""
for w in words:
    if len(w) > len(longest):
        longest = w

print("Символдар:", len(text))
print("Сөздер:", len(words))
print("Сөйлемдер:", sentences)
print("Әріптер:", letters)
print("Ең ұзын сөз:", longest)
print("Орташа сөз ұзындығы:", round(letters / len(words), 1))
```

Нәтижесі:
```text
Символдар: 55
Сөздер: 7
Сөйлемдер: 2
Әріптер: 43
Ең ұзын сөз: таусылмас
Орташа сөз ұзындығы: 6.1
```

### Ең жиі кездесетін әріп

```python
text = "ата анаға қарап бала өсер"
alphabet = "аәбвгғдеёжзийкқлмнңоөпрстуұүфхһцчшщъыіьэюя"
best = ""
best_count = 0
for letter in alphabet:
    c = text.count(letter)
    if c > best_count:
        best_count = c
        best = letter
print("Ең жиі әріп:", best, "-", best_count, "рет")
```

Нәтижесі:
```text
Ең жиі әріп: а - 9 рет
```

Қызықты дерек: кез келген тілде әріптердің жиілігі тұрақты дерлік. Осы қасиетті пайдаланып, Цезарь шифрін кілтсіз-ақ ашуға болады — ең жиі шифр-әріп, сірә, «а» (қазақшада) немесе «e» (ағылшынша) болып шығады. Бұл **жиіліктік талдау** деп аталады.

## 4. Шекаралық жағдайларда тексеру

Мәтінді өңдейтін бағдарламаны тек қалыпты мәліметпен емес, шекаралық жағдайлармен де тексерген жөн: бос жол, бір символдан тұратын жол, тек цифрлар немесе тек тыныс белгілері, аралас регистр.

```python
tests = ["А роза упала на лапу Азора", "", "!!!", "Abc"]
for text in tests:
    clean = ""
    for ch in text.lower():
        if ch.isalnum():
            clean += ch
    print(repr(text), clean == clean[::-1])
```

Нәтиже:
```text
'А роза упала на лапу Азора' True
'' True
'!!!' True
'Abc' False
```

Бос жол мен әріпсіз жол тазартудан кейін бос болып қалады, сондықтан палиндром болып саналады. Бағдарламада мұндай жағдайда қандай жауап керек екенін алдын ала шешіп қойыңыз.

## Жиі кездесетін қателер

**1. Палиндромды тексергенде тазаламау**

```python
s = "Қазақ"
print(s == s[::-1])               # False — «Қ» мен «қ» әртүрлі
print(s.lower() == s.lower()[::-1])   # True
```

**2. Шифрлауда % 26 ұмыту**

```python
ch = "y"
# print(chr(ord(ch) + 3))           # '|' — әліппеден шығып кетті
print(chr((ord(ch) - ord("a") + 3) % 26 + ord("a")))   # b
```

**3. Әріп емес символдарды да шифрлау**

Бос орын мен тыныс белгілерін өзгертпей қалдыру керек — сондықтан `if` арқылы тексереміз.

**4. Бос мәтінде нөлге бөлу**

```python
words = "".split()
if len(words) > 0:
    print(10 / len(words))
else:
    print("Мәтін бос")
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Палиндром | екі жақтан бірдей оқылатын сөз/сан/сөйлем |
| Криптография | ақпаратты шифрлау арқылы қорғау ғылымы |
| Шифрлау / дешифрлау | ашық мәтінді құпия түрге келтіру / кері қайтару |
| Кілт | шифрлау ережесінің параметрі (Цезарь шифрінде — ығысу саны) |
| Цезарь шифрі | әр әріпті әліппе бойынша k позицияға ығыстыру |
| Жиіліктік талдау | әріптердің кездесу жиілігі арқылы мәтінді зерттеу |

## Ескерту

- `s[::-1]` арқылы палиндромды тексеру жолдың толық көшірмесін жасайды; өте ұзын мәтіндер үшін екі «көрсеткіш» тәсілі жадты үнемдейді.
- Python-дағы `%` операторы теріс санға да оң қалдық береді (`(-3) % 26 == 23`), сондықтан Цезарь шифрін ашуда `-k` ығысуын еркін қолдануға болады. Бұл C, Java тілдерінен өзгеше.
- `str.maketrans()` және `translate()` әдістері ауыстыру кестесін бір рет құрып, бүкіл мәтінді бір қадамда шифрлауға мүмкіндік береді: `text.translate(str.maketrans("abc", "bcd"))`.
- Әріптердің жиілігін санау үшін `collections.Counter` ыңғайлы: `Counter(text).most_common(3)` — ең жиі үш символ.
- Цезарь шифры тек оқу мақсатындағы мысал; нақты деректерді қорғау үшін `hashlib`, `secrets` модульдері немесе арнайы криптографиялық кітапханалар қолданылады.
- Құжаттама: https://docs.python.org/3/library/stdtypes.html#str.translate
