## 1. Әдіс дегеніміз не?

**Әдіс (метод, method)** — белгілі бір типке «тиесілі» функция. Ол нүкте арқылы шақырылады:

```
жол.әдіс(аргументтер)
```

Аналогия: смартфонның «камера», «қоңырау» деген мүмкіндіктері бар — олар телефонның өзіне тиесілі. Сол сияқты жолдың да өз «мүмкіндіктері» — әдістері бар.

**Ең маңызды ереже:** жол өзгермейтін болғандықтан, жол әдістері бастапқы жолды **өзгертпейді**, олар **жаңа жол қайтарады**.

```python
name = "абай"
name.upper()          # нәтиже ешқайда сақталмады
print(name)
name = name.upper()   # нәтижені қайта меншіктейміз
print(name)
```

Нәтижесі:
```text
абай
АБАЙ
```

## 2. Регистрді өзгерту әдістері

| Әдіс | Не істейді | Мысал | Нәтиже |
|---|---|---|---|
| `upper()` | бәрін бас әріпке | `"Алматы".upper()` | `"АЛМАТЫ"` |
| `lower()` | бәрін кіші әріпке | `"АЛМАТЫ".lower()` | `"алматы"` |
| `capitalize()` | тек бірінші әріп бас | `"қазақ ТІЛІ".capitalize()` | `"Қазақ тілі"` |
| `title()` | әр сөз бас әріптен | `"қаныш сәтбаев".title()` | `"Қаныш Сәтбаев"` |
| `swapcase()` | регистрді ауыстырады | `"PyThOn".swapcase()` | `"pYtHoN"` |

Қазақ әріптері (`ә, ғ, қ, ң, ө, ұ, ү, һ, і`) де дұрыс түрленеді:

```python
print("өнер, ғылым, ұлт".upper())
print("ҚАЗАҚСТАН".lower())
print("мұхтар әуезов".title())
```

Нәтижесі:
```text
ӨНЕР, ҒЫЛЫМ, ҰЛТ
қазақстан
Мұхтар Әуезов
```

### Тексеру әдістері (True/False қайтарады)

| Әдіс | Сұрақ |
|---|---|
| `isupper()` / `islower()` | бәрі бас / кіші әріп пе? |
| `isdigit()` | тек цифрлардан тұра ма? |
| `isalpha()` | тек әріптерден тұра ма? |
| `startswith(x)` / `endswith(x)` | x-пен басталады / аяқталады ма? |

```python
print("2027".isdigit())
print("Абай".isalpha())
print("photo.png".endswith(".png"))
```

Нәтижесі:
```text
True
True
True
```

### Қолданылуы: регистрге тәуелсіз салыстыру

```python
answer = input("Қазақстанның астанасы? ")
if answer.lower() == "астана":
    print("Дұрыс!")
else:
    print("Қате")
```

Пайдаланушы `АСТАНА`, `Астана`, `астана` деп жазса да — бәрі дұрыс деп есептеледі.

## 3. strip() — бос орындарды тазалау

| Әдіс | Не істейді |
|---|---|
| `strip()` | екі жағындағы бос орындар мен `\n`, `\t` таңбаларын алып тастайды |
| `lstrip()` | тек сол жағынан |
| `rstrip()` | тек оң жағынан |
| `strip("x.")` | көрсетілген символдарды екі жағынан алып тастайды |

```python
login = "   aidana_07   "
print("[" + login + "]")
print("[" + login.strip() + "]")
print("[" + login.lstrip() + "]")
print("[" + login.rstrip() + "]")
print("...Сәлем!!!".strip(".!"))
```

Нәтижесі:
```text
[   aidana_07   ]
[aidana_07]
[aidana_07   ]
[   aidana_07]
Сәлем
```

**Маңызды:** `strip()` сөздің **ортасындағы** бос орындарға тимейді: `"  Нұр  Сұлтан  ".strip()` → `"Нұр  Сұлтан"`.

Тәжірибеде `input()` нәтижесін бірден тазалайды:

```python
city = input("Қалаңыз: ").strip().title()
print("Сіз", city, "қаласынансыз")
```

## 4. replace() — ауыстыру

```
жол.replace(ескі, жаңа)           # бәрін ауыстырады
жол.replace(ескі, жаңа, саны)     # тек алғашқы «саны» данасын
```

```python
text = "Мен мектепке барамын. Мектеп үлкен."
print(text.replace("Мектеп", "Лицей"))
print("2027-02-03".replace("-", "."))
print("бала-бала-бала".replace("бала", "қала", 2))
print("Бос   орын   көп".replace(" ", ""))
```

Нәтижесі:
```text
Мен мектепке барамын. Лицей үлкен.
2027.02.03
қала-қала-бала
Босорынкөп
```

`replace()` регистрді ескереді: `"мектепке"` ішіндегі кіші «м» ауыстырылмады. Жою үшін «жаңа» орнына бос жол `""` береміз.

## 5. find() — іздеу

`find(x)` — `x` бірінші рет кездесетін **индексті** қайтарады. Табылмаса — **-1**.

```python
s = "Алматы — алма қаласы"
print(s.find("алма"))     # кіші әріптен басталатын «алма»
print(s.find("Алма"))
print(s.find("Астана"))
print(s.find("а", 10))    # 10-индекстен бастап іздеу
```

Нәтижесі:
```text
9
0
-1
12
```

Тағы бір пайдалы әдіс: `rfind(x)` — **соңғы** кездесуді іздейді.

```python
email = "student.aidos@school.kz"
at = email.find("@")
print("Логин:", email[:at])
print("Домен:", email[at + 1:])
```

Нәтижесі:
```text
Логин: student.aidos
Домен: school.kz
```

### find() немесе in?

- Тек «бар ма, жоқ па?» керек болса — `in` (оқуға оңай).
- Қай жерде тұрғаны керек болса — `find()`.

```python
s = "Python"
print("th" in s)        # True
print(s.find("th"))     # 2
```

## 6. count() — санау

`count(x)` — `x` жолда неше рет кездесетінін қайтарады (бір-бірін жаппайтын кездесулер).

```python
song = "Бала-бала, бала-бала, балапан"
print(song.count("бала"))
print(song.lower().count("бала"))
print(song.count(","))
print("ааааа".count("аа"))
```

Нәтижесі:
```text
4
5
2
2
```

## 7. Әдістерді тізбектеу

Әр әдіс жаңа жол қайтаратындықтан, оларды тізбектей шақыруға болады — солдан оңға қарай орындалады:

```python
raw = "   ҚАЙЫРЛЫ ТАҢ, достар!   "
clean = raw.strip().lower().replace("достар", "оқушылар").capitalize()
print(clean)
```

Нәтижесі:
```text
Қайырлы таң, оқушылар!
```

## Жиі кездесетін қателер

**1. Нәтижені сақтамау**

```python
s = "сәлем"
s.upper()
print(s)          # сәлем — өзгермеді!
s = s.upper()
print(s)          # СӘЛЕМ
```

**2. Жақшаны ұмыту**

```python
s = "Алма"
print(s.upper)    # <built-in method upper ...> — әдіс шақырылмады
print(s.upper())  # АЛМА
```

**3. find() нәтижесін логикалық мән ретінде қолдану**

```python
s = "Абай"
# if s.find("А"):  — "А" 0-индексте, 0 → False болып кетеді!
if s.find("А") != -1:
    print("Табылды")
```

**4. Регистрді ескермеу**

```python
text = "Алматы алма"
print(text.count("алма"))           # 1
print(text.lower().count("алма"))   # 2
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Әдіс (method) | объектіге тиесілі функция, `объект.әдіс()` түрінде шақырылады |
| Регистр | әріптің бас (үлкен) немесе кіші түрі |
| `upper()` / `lower()` | бас / кіші әріпке түрлендіру |
| `strip()` | шеттердегі бос орындарды алып тастау |
| `replace(a, b)` | a бөлігін b-ға ауыстыру |
| `find(x)` | x-тің бірінші индексі, табылмаса -1 |
| `count(x)` | x-тің кездесу саны |

## Ескерту

- Жол әдістері бастапқы жолды ешқашан өзгертпейді — нәтижені айнымалыға қайта меншіктеу керек: `s = s.strip()`.
- Регистрді ескермей салыстыру үшін `lower()` орнына `casefold()` әдісі сенімдірек: ол кейбір тілдердің ерекше әріптерін де (мысалы, неміс `ß`) дұрыс өңдейді.
- `find()` табылмаса `-1` қайтарады, ал ұқсас `index()` әдісі `ValueError` қатесін шығарады. `-1` мәнін индекс ретінде қолданып жібермеңіз: `s[-1]` — соңғы символ.
- `isdigit()` теріс сандар мен бөлшектерге `False` береді: `"-5".isdigit()` және `"3.14".isdigit()` — `False`.
- Python 3.9-дан бастап жолдың басындағы/соңындағы бөлікті алып тастау үшін `removeprefix()` және `removesuffix()` әдістері бар; `strip("abc")` бөлікті емес, жеке символдарды алып тастайтынын ұмытпаңыз.
- Барлық әдістердің тізімі: https://docs.python.org/3/library/stdtypes.html#string-methods
