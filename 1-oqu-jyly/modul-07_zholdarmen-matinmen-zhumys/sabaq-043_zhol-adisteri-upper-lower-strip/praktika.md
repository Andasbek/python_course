# Сабақ 43. Практикалық тапсырмалар: жол әдістері

## Базалық деңгей

### 1-тапсырма. Атты дұрыс жазу
Пайдаланушы аты-жөнін кез келген түрде енгізеді (бос орындармен, әр түрлі регистрде). Бағдарлама оны әдемі түрге келтірсін.

Мысал:
```text
Аты-жөніңіз:    сӘТБАЕВ   қАНЫШ
Сәлеметсіз бе, Сәтбаев   Қаныш!
```
Кеңес: `strip()` және `title()`.

### 2-тапсырма. Викторина
Бағдарлама «Қазақстанның ең биік шыңы?» деп сұрайды. Дұрыс жауап — `Хан Тәңірі`. Пайдаланушы жауапты кез келген регистрде, артық бос орындармен жазса да, дұрыс деп қабылдансын.

### 3-тапсырма. Әріпті санау
Мәтін және бір әріп енгізіледі. Сол әріптің мәтінде неше рет кездесетінін шығарыңыз (бас және кіші әріп бірдей саналсын).

Мысал:
```text
Мәтін: Алматы — Алатаудың баурайындағы қала
Әріп: а
Саны: 10
```

### 4-тапсырма. Күнді түрлендіру
Пайдаланушы күнді `03/02/2027` форматында енгізеді. Бағдарлама оны `03.02.2027` түрінде шығарсын.

### 5-тапсырма. Email тексеру
Email енгізіледі. Бағдарлама `@` белгісінің орнын (индексін) шығарсын. Егер `@` жоқ болса, «Қате email» деп жазсын. Бар болса — логин мен доменді бөлек шығарсын.

## Кеңейтілген деңгей

### 6-тапсырма. Әдепсіз сөз сүзгісі
Чатқа хабар жазылады. «Тыйым салынған» сөздер тізімі: `["ақымақ", "жалқау", "топас"]`. Бағдарлама осы сөздердің әрқайсысын сөздің ұзындығындай жұлдызшаларға ауыстырсын (`for` циклі және `replace()` арқылы).

Мысал:
```text
Хабар: сен жалқау емессің, бірақ кейде жалқау боласың
Нәтиже: сен ****** емессің, бірақ кейде ****** боласың
```

### 7-тапсырма. Файл түрі
Файл атауы енгізіледі (мысалы `Сурет.Final.PNG`). Бағдарлама кеңейтілуін (соңғы нүктеден кейінгі бөлігін) кіші әріппен шығарсын және оның сурет екенін (`png`, `jpg`, `gif`) анықтасын. Кеңес: `rfind(".")`.

### 8-тапсырма. Барлық кездесулердің индекстері
Мәтін және ізделетін сөз енгізіледі. `find()` пен `while` циклі арқылы сөз кездесетін **барлық** индекстерді шығарыңыз.

Мысал:
```text
Мәтін: ата мен ана, ата-ана
Сөз: ата
Индекстер: 0 13
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Құпия сөздің күші
Пароль енгізіледі. Бағдарлама бағалайды:
- ұзындығы кемінде 8 символ;
- кемінде бір бас әріп бар;
- кемінде бір кіші әріп бар;
- кемінде бір цифр бар.

Әр орындалған шарт үшін 1 ұпай; нәтиже: 0–1 «Әлсіз», 2–3 «Орташа», 4 «Күшті». Кеңес: символдар бойынша цикл және `isupper()`, `islower()`, `isdigit()`.

### 10-тапсырма. Мәтінді түзету
Мәтінде қатар келген бірнеше бос орынды бір бос орынға айналдырыңыз (`while "  " in text:` идеясы). Сонымен қатар мәтіннің бірінші әрпін бас әріп етіңіз.

## Үй тапсырмасы

1. Сүйікті өлеңіңізден бір шумақты бағдарламаға жазып, ондағы «а», «е», «ы» әріптерінің санын шығарыңыз.
2. Пайдаланушы енгізген сөйлемде «мен» сөзін «біз» сөзіне ауыстырыңыз.
3. Өз әдістеріңіздің шпаргалкасын дәптерге жазыңыз: әр әдіске бір мысал.

**9-тапсырма**
```python
password = input("Пароль: ")
has_upper = False
has_lower = False
has_digit = False
for ch in password:
    if ch.isupper():
        has_upper = True
    if ch.islower():
        has_lower = True
    if ch.isdigit():
        has_digit = True
score = 0
if len(password) >= 8:
    score += 1
if has_upper:
    score += 1
if has_lower:
    score += 1
if has_digit:
    score += 1
if score <= 1:
    print("Әлсіз")
elif score <= 3:
    print("Орташа")
else:
    print("Күшті")
```
