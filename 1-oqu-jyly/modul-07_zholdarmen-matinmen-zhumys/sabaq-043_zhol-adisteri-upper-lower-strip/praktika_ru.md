# Урок 43. Практические задания: методы строк

## Базовый уровень

### Задание 1. Правильное написание имени
Пользователь вводит фамилию и имя в любом виде (с пробелами, в разном регистре). Программа должна привести их к аккуратному виду.

Пример:
```text
Ваши фамилия и имя:    сАТПАЕВ   кАНЫШ
Здравствуйте, Сатпаев   Каныш!
```
Подсказка: `strip()` и `title()`.

### Задание 2. Викторина
Программа спрашивает: «Самая высокая вершина Казахстана?» Правильный ответ — `Хан-Тенгри`. Ответ должен засчитываться как верный, даже если пользователь напишет его в любом регистре и с лишними пробелами.

### Задание 3. Подсчёт буквы
Вводятся текст и одна буква. Выведите, сколько раз эта буква встречается в тексте (заглавная и строчная буквы считаются одинаковыми).

Пример:
```text
Текст: Алматы — город у подножия Алатау
Буква: а
Количество: 5
```

### Задание 4. Преобразование даты
Пользователь вводит дату в формате `03/02/2027`. Программа должна вывести её в виде `03.02.2027`.

### Задание 5. Проверка email
Вводится email. Программа должна вывести позицию (индекс) знака `@`. Если `@` нет, вывести «Неверный email». Если есть — вывести отдельно логин и домен.

## Продвинутый уровень

### Задание 6. Фильтр грубых слов
В чат пишется сообщение. Список «запрещённых» слов: `["дурак", "лентяй", "тупица"]`. Программа должна заменить каждое из этих слов звёздочками в количестве, равном длине слова (с помощью цикла `for` и `replace()`).

Пример:
```text
Сообщение: ты не лентяй, но иногда ведёшь себя как лентяй
Результат: ты не ******, но иногда ведёшь себя как ******
```

### Задание 7. Тип файла
Вводится имя файла (например, `Рисунок.Final.PNG`). Программа должна вывести расширение (часть после последней точки) строчными буквами и определить, является ли файл изображением (`png`, `jpg`, `gif`). Подсказка: `rfind(".")`.

### Задание 8. Индексы всех вхождений
Вводятся текст и искомое слово. С помощью `find()` и цикла `while` выведите **все** индексы, где встречается слово.

Пример:
```text
Текст: мама и папа, мама-папа
Слово: мама
Индексы: 0 13
```

## ★ Олимпиадная / творческая задача

### Задание 9. Надёжность пароля
Вводится пароль. Программа оценивает:
- длина не меньше 8 символов;
- есть хотя бы одна заглавная буква;
- есть хотя бы одна строчная буква;
- есть хотя бы одна цифра.

За каждое выполненное условие — 1 балл; результат: 0–1 «Слабый», 2–3 «Средний», 4 «Сильный». Подсказка: цикл по символам и `isupper()`, `islower()`, `isdigit()`.

### Задание 10. Исправление текста
Замените несколько идущих подряд пробелов в тексте одним пробелом (идея `while "  " in text:`). Кроме того, сделайте первую букву текста заглавной.

## Домашнее задание

1. Запишите в программу одно четверостишие любимого стихотворения и выведите количество букв «а», «о», «е» в нём.
2. В предложении, введённом пользователем, замените слово «я» на «мы».
3. Запишите в тетрадь собственную шпаргалку по методам: по одному примеру на каждый метод.

**Задание 9**
```python
password = input("Пароль: ")
has_upper = False
has_lower = False
has_digit = False
for ch in password:
    if ch.isupper():
        has_upper = True
    if ch.islower():
        has_lower = True
    if ch.isdigit():
        has_digit = True
score = 0
if len(password) >= 8:
    score += 1
if has_upper:
    score += 1
if has_lower:
    score += 1
if has_digit:
    score += 1
if score <= 1:
    print("Слабый")
elif score <= 3:
    print("Средний")
else:
    print("Сильный")
```
