## 1. Что такое метод?

**Метод (method)** — функция, «принадлежащая» определённому типу. Он вызывается через точку:

```
строка.метод(аргументы)
```

Аналогия: у смартфона есть возможности «камера», «звонок» — они принадлежат самому телефону. Так и у строки есть свои «возможности» — методы.

**Самое важное правило:** поскольку строка неизменяема, методы строк **не изменяют** исходную строку, они **возвращают новую строку**.

```python
name = "абай"
name.upper()          # результат никуда не сохранился
print(name)
name = name.upper()   # заново присваиваем результат
print(name)
```

Результат:
```text
абай
АБАЙ
```

## 2. Методы изменения регистра

| Метод | Что делает | Пример | Результат |
|---|---|---|---|
| `upper()` | всё в заглавные буквы | `"Алматы".upper()` | `"АЛМАТЫ"` |
| `lower()` | всё в строчные буквы | `"АЛМАТЫ".lower()` | `"алматы"` |
| `capitalize()` | заглавная только первая буква | `"русский ЯЗЫК".capitalize()` | `"Русский язык"` |
| `title()` | каждое слово с заглавной буквы | `"каныш сатпаев".title()` | `"Каныш Сатпаев"` |
| `swapcase()` | меняет регистр на противоположный | `"PyThOn".swapcase()` | `"pYtHoN"` |

Казахские буквы (`ә, ғ, қ, ң, ө, ұ, ү, һ, і`) тоже правильно преобразуются:

```python
print("өнер, ғылым, ұлт".upper())
print("ҚАЗАҚСТАН".lower())
print("мұхтар әуезов".title())
```

Результат:
```text
ӨНЕР, ҒЫЛЫМ, ҰЛТ
қазақстан
Мұхтар Әуезов
```

### Методы проверки (возвращают True/False)

| Метод | Вопрос |
|---|---|
| `isupper()` / `islower()` | все буквы заглавные / строчные? |
| `isdigit()` | состоит только из цифр? |
| `isalpha()` | состоит только из букв? |
| `startswith(x)` / `endswith(x)` | начинается / заканчивается на x? |

```python
print("2027".isdigit())
print("Абай".isalpha())
print("photo.png".endswith(".png"))
```

Результат:
```text
True
True
True
```

### Применение: сравнение без учёта регистра

```python
answer = input("Столица Казахстана? ")
if answer.lower() == "астана":
    print("Верно!")
else:
    print("Неверно")
```

Даже если пользователь напишет `АСТАНА`, `Астана` или `астана` — всё будет засчитано как верный ответ.

## 3. strip() — удаление пробелов

| Метод | Что делает |
|---|---|
| `strip()` | удаляет пробелы и символы `\n`, `\t` с обеих сторон |
| `lstrip()` | только слева |
| `rstrip()` | только справа |
| `strip("x.")` | удаляет указанные символы с обеих сторон |

```python
login = "   aidana_07   "
print("[" + login + "]")
print("[" + login.strip() + "]")
print("[" + login.lstrip() + "]")
print("[" + login.rstrip() + "]")
print("...Привет!!!".strip(".!"))
```

Результат:
```text
[   aidana_07   ]
[aidana_07]
[aidana_07   ]
[   aidana_07]
Привет
```

**Важно:** `strip()` не трогает пробелы **в середине** строки: `"  Нур  Султан  ".strip()` → `"Нур  Султан"`.

На практике результат `input()` очищают сразу:

```python
city = input("Ваш город: ").strip().title()
print("Вы из города", city)
```

## 4. replace() — замена

```
строка.replace(старое, новое)           # заменяет все вхождения
строка.replace(старое, новое, число)    # только первые «число» вхождений
```

```python
text = "Я иду в школу. Школа большая."
print(text.replace("Школа", "Гимназия"))
print("2027-02-03".replace("-", "."))
print("мама-мама-мама".replace("мама", "рама", 2))
print("Много   пробелов   тут".replace(" ", ""))
```

Результат:
```text
Я иду в школу. Гимназия большая.
2027.02.03
рама-рама-мама
Многопробеловтут
```

`replace()` учитывает регистр: в слове `"школу"` со строчной «ш» замены не произошло. Для удаления вместо «нового» передаём пустую строку `""`.

## 5. find() — поиск

`find(x)` возвращает **индекс** первого вхождения `x`. Если не найдено — **-1**.

```python
s = "Алматы — город алма (яблок)"
print(s.find("алма"))     # «алма» со строчной буквы
print(s.find("Алма"))
print(s.find("Астана"))
print(s.find("а", 10))    # поиск начиная с индекса 10
```

Результат:
```text
15
0
-1
15
```

Ещё один полезный метод: `rfind(x)` — ищет **последнее** вхождение.

```python
email = "student.aidos@school.kz"
at = email.find("@")
print("Логин:", email[:at])
print("Домен:", email[at + 1:])
```

Результат:
```text
Логин: student.aidos
Домен: school.kz
```

### find() или in?

- Если нужно только «есть или нет?» — `in` (легче читается).
- Если нужно знать, где находится — `find()`.

```python
s = "Python"
print("th" in s)        # True
print(s.find("th"))     # 2
```

## 6. count() — подсчёт

`count(x)` возвращает, сколько раз `x` встречается в строке (непересекающиеся вхождения).

```python
song = "Мяу-мяу, мяу-мяу, мяукает котёнок"
print(song.count("мяу"))
print(song.lower().count("мяу"))
print(song.count(","))
print("ааааа".count("аа"))
```

Результат:
```text
4
5
2
2
```

## 7. Цепочки методов

Так как каждый метод возвращает новую строку, их можно вызывать цепочкой — они выполняются слева направо:

```python
raw = "   ДОБРОЕ УТРО, друзья!   "
clean = raw.strip().lower().replace("друзья", "ученики").capitalize()
print(clean)
```

Результат:
```text
Доброе утро, ученики!
```

## Частые ошибки

**1. Результат не сохраняют**

```python
s = "привет"
s.upper()
print(s)          # привет — не изменилось!
s = s.upper()
print(s)          # ПРИВЕТ
```

**2. Забывают скобки**

```python
s = "Каша"
print(s.upper)    # <built-in method upper ...> — метод не вызван
print(s.upper())  # КАША
```

**3. Использование результата find() как логического значения**

```python
s = "Абай"
# if s.find("А"):  — "А" стоит на индексе 0, а 0 → False!
if s.find("А") != -1:
    print("Найдено")
```

**4. Не учитывают регистр**

```python
text = "Арбуз и арбузик"
print(text.count("арбуз"))           # 1
print(text.lower().count("арбуз"))   # 2
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Метод (method) | функция, принадлежащая объекту, вызывается в виде `объект.метод()` |
| Регистр | заглавная (большая) или строчная (маленькая) форма буквы |
| `upper()` / `lower()` | преобразование в заглавные / строчные буквы |
| `strip()` | удаление пробелов по краям |
| `replace(a, b)` | замена части a на b |
| `find(x)` | первый индекс x, если не найдено — -1 |
| `count(x)` | количество вхождений x |

## Примечание

- Методы строк никогда не изменяют исходную строку — результат нужно заново присвоить переменной: `s = s.strip()`.
- Для сравнения без учёта регистра надёжнее метод `casefold()` вместо `lower()`: он правильно обрабатывает особые буквы некоторых языков (например, немецкую `ß`).
- `find()` при неудаче возвращает `-1`, а похожий метод `index()` вызывает `ValueError`. Не используйте `-1` как индекс по ошибке: `s[-1]` — это последний символ.
- `isdigit()` возвращает `False` для отрицательных чисел и дробей: `"-5".isdigit()` и `"3.14".isdigit()` — `False`.
- С Python 3.9 есть методы `removeprefix()` и `removesuffix()` для удаления части в начале/конце строки; помните, что `strip("abc")` удаляет не подстроку, а отдельные символы.
- Список всех методов: https://docs.python.org/3/library/stdtypes.html#string-methods
