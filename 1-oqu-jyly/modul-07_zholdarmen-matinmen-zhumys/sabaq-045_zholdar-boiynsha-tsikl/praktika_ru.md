# Урок 45. Практические задания: цикл по строкам

## Базовый уровень

### Задание 1. Буквы столбиком
Вводится слово. Выведите каждую его букву с номером (начиная с 1) на отдельной строке.

Пример:
```text
Слово: Арал
1 - А
2 - р
3 - а
4 - л
```

### Задание 2. Гласные и согласные
Вводится текст. Выведите отдельно количество гласных и количество согласных (остальных букв). Пробелы и знаки препинания не учитываются.

Пример:
```text
Текст: Родная земля
Гласных: 5
Согласных: 6
```

### Задание 3. Сумма цифр
Пользователь вводит целое число любой длины (как строку). Найдите сумму его цифр и наибольшую цифру.

Пример: `907415` → сумма `26`, наибольшая цифра `9`.

### Задание 4. Без пробелов
Вводится текст. С помощью цикла создайте новую строку, из которой удалены все пробелы (не используйте `replace()`).

### Задание 5. Заглавные буквы
Соберите в одну строку и выведите все заглавные буквы текста.

Пример: `Абай Кунанбайулы родился в Семее` → `АКС`

## Продвинутый уровень

### Задание 6. Смена регистра
Не используя метод `swapcase()`, с помощью цикла превратите заглавные буквы в строчные, а строчные — в заглавные.

Пример: `ПиТоН 2027` → `пИтОн 2027`

### Задание 7. Сжатие (RLE)
Сожмите идущие подряд одинаковые символы в вид «символ + количество».

Пример: `aaabccdddd` → `a3b1c2d4`

Подсказка: используйте счётчик и сравнивайте `s[i]` и `s[i + 1]` или запоминайте последний символ.

### Задание 8. Самая длинная серия одинаковых символов
Найдите длину и символ самой длинной серии одинаковых символов, стоящих подряд в строке.

Пример: `ааббббвв` → `б 4`

## ★ Олимпиадная / творческая задача

### Задание 9. Частота латинских букв
Вводится предложение на английском языке. С помощью `ord()` и `chr()` выведите, сколько раз встречается каждая буква от `a` до `z` (только встретившиеся буквы). Регистр не учитывается.

Пример:
```text
Текст: Hello World
d 1
e 1
h 1
l 3
o 2
r 1
w 1
```

### Задание 10. Баланс скобок
Вводится строка, состоящая только из символов `(` и `)`. Правильно ли расставлены скобки? (Каждая открытая скобка должна быть потом закрыта, и ни в какой момент закрытых не должно быть больше, чем открытых.)

Пример: `(()())` → `Верно`, `())(` → `Неверно`.

## Домашнее задание

1. Сделайте первую букву каждого слова предложения заглавной (с помощью цикла, не используя `title()`).
2. Вводится имя пользователя (логин). Если оно состоит только из латинских букв, цифр и знака `_` — выведите «Допустимый», иначе — «Недопустимый».
3. Выведите код Юникода каждой буквы своего имени.

for ch in s:
    if ch == "(":
        balance += 1
    else:
        balance -= 1
    if balance < 0:
        ok = False

if ok and balance == 0:
