## 1. Цикл for по строке

Строка — последовательность (как список), поэтому `for` выдаёт её символы один за другим:

```python
word = "Абай"
for ch in word:
    print(ch)
```

Результат:
```text
А
б
а
й
```

Аналогия: чтение книги буква за буквой, ведя пальцем по строчке. Палец — это переменная `ch`.

## 2. Алгоритм подсчёта (счётчик)

Шаблон: обнуляем счётчик → проверяем каждый символ → если условие выполнено, прибавляем 1.

```python
text = "Знание — сила"
vowels = "аеёиоуыэюя"
count = 0
for ch in text.lower():
    if ch in vowels:
        count += 1
print("Количество гласных:", count)
```

Результат:
```text
Количество гласных: 5
```

### Определение типа символа

| Метод | Когда True |
|---|---|
| `ch.isalpha()` | буква |
| `ch.isdigit()` | цифра |
| `ch.isspace()` | пробел, `\t`, `\n` |
| `ch.isupper()` / `ch.islower()` | заглавная / строчная буква |
| `ch.isalnum()` | буква или цифра |

```python
s = "Школа №25, 2027 год!"
letters = 0
digits = 0
spaces = 0
others = 0
for ch in s:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1
    else:
        others += 1
print("Букв:", letters, "Цифр:", digits, "Пробелов:", spaces, "Других:", others)
```

Результат:
```text
Букв: 8 Цифр: 6 Пробелов: 3 Других: 3
```

## 3. «Сборка» новой строки (фильтрация и преобразование)

Так как строка неизменяема, начинаем с пустой строки и постепенно добавляем символы.

### Оставить только цифры
```python
phone = "+7 (701) 555-12-34"
digits = ""
for ch in phone:
    if ch.isdigit():
        digits += ch
print(digits)
```

Результат:
```text
77015551234
```

### Преобразование каждого символа
```python
word = "казахстан"
result = ""
for ch in word:
    if ch in "аеёиоуыэюя":
        result += ch.upper()
    else:
        result += ch
print(result)
```

Результат:
```text
кАзАхстАн
```

### Разворот строки — с помощью цикла
```python
s = "Тараз"
rev = ""
for ch in s:
    rev = ch + rev       # добавляем символ в начало
print(rev)
```

Результат:
```text
зараТ
```

Это совпадает с результатом `s[::-1]`, но показывает, что происходит внутри алгоритма.

## 4. Цикл по индексу

Если нужна **позиция** символа или нужно сравнивать **соседние** символы, используем `range(len(s))`:

```python
s = "Python"
for i in range(len(s)):
    print(i, s[i])
```

Результат:
```text
0 P
1 y
2 t
3 h
4 o
5 n
```

### Какой способ выбрать?

| Задача | Способ |
|---|---|
| Нужен только сам символ | `for ch in s` |
| Нужен индекс символа | `for i in range(len(s))` |
| Соседние символы (s[i] и s[i+1]) | `for i in range(len(s) - 1)` |
| Стоящие на чётных/нечётных местах | `for i in range(0, len(s), 2)` |

### Одинаковые буквы, стоящие рядом

```python
word = "время аллея ассамблея"
for i in range(len(word) - 1):
    if word[i] == word[i + 1] and word[i] != " ":
        print("Двойная буква:", word[i] * 2, "индекс", i)
```

Результат:
```text
Двойная буква: лл индекс 7
Двойная буква: сс индекс 13
```

### Поиск всех позиций символа

```python
s = "банан"
for i in range(len(s)):
    if s[i] == "н":
        print("Индекс 'н':", i)
```

Результат:
```text
Индекс 'н': 2
Индекс 'н': 4
```

## 5. Коды символов: ord() и chr()

Компьютер хранит каждый символ как **число (код)**. Эти коды определены в таблице **Юникод** (Unicode). Для латинских букв и цифр эти коды совпадают со старой таблицей ASCII.

- `ord(символ)` → код символа;
- `chr(код)` → символ, соответствующий коду.

```python
print(ord("A"), ord("B"), ord("a"))
print(ord("0"), ord("9"))
print(ord("А"), ord("Ә"))      # кириллические буквы
print(chr(65), chr(97), chr(1178))
```

Результат:
```text
65 66 97
48 57
1040 1240
A a Қ
```

Латинские буквы расположены **подряд**: `A`=65, `B`=66, ..., `Z`=90; `a`=97, ..., `z`=122. Поэтому можно найти следующую букву:

```python
letter = "C"
print(chr(ord(letter) + 1))
for code in range(ord("a"), ord("f") + 1):
    print(chr(code), end=" ")
print()
```

Результат:
```text
D
a b c d e f 
```

На этом приёме основан **шифр Цезаря**: каждая буква сдвигается по алфавиту на заданное число позиций.

### Преобразование символа-цифры в число

```python
number = "2027"
total = 0
for ch in number:
    total += int(ch)
print("Сумма цифр:", total)
```

Результат:
```text
Сумма цифр: 11
```

## 6. Досрочная остановка: break

Цикл можно остановить, когда найден первый подходящий символ, — оператором `break`:

```python
s = "abc7de9"
for i in range(len(s)):
    if s[i].isdigit():
        print("Первая цифра:", s[i], "индекс:", i)
        break
```

Результат:
```text
Первая цифра: 7 индекс: 3
```

## Частые ошибки

**1. Выход за границы при проверке соседей**

```python
s = "аалма"
# for i in range(len(s)):            # s[i + 1] на последнем шаге даст IndexError
for i in range(len(s) - 1):
    if s[i] == s[i + 1]:
        print("Найдена двойная буква")
```

**2. Обнуление новой строки внутри цикла**

```python
s = "a1b2"
result = ""                 # правильно: ДО цикла
for ch in s:
    # result = ""           # ошибка: стирается на каждом шаге
    if ch.isdigit():
        result += ch
print(result)               # 12
```

**3. Сравнение символа-цифры с числом**

```python
ch = "5"
print(ch == 5)        # False — строка и число
print(int(ch) == 5)   # True
```

**4. Не учитывают регистр**

```python
text = "Арка"
print(text.count("а"))           # 1
print(text.lower().count("а"))   # 2
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Цикл по строке | `for ch in s` — поочерёдное получение каждого символа |
| Цикл по индексу | `for i in range(len(s))` — обращение по позиции |
| Счётчик | переменная, увеличивающаяся на 1 при каждом выполнении условия |
| Сборка строки | создание новой строки с помощью `+=`, начиная с пустой |
| Юникод (Unicode) | таблица кодов всех символов мира |
| `ord()` / `chr()` | символ → код / код → символ |

## Примечание

- Сборка строки через `+=` в цикле нормальна для небольших текстов, но для больших объёмов эффективнее добавлять символы в список через `append()` и в конце вызвать `"".join(...)`.
- Если нужны и индекс, и символ, вместо `range(len(s))` удобнее `enumerate()`: `for i, ch in enumerate(s):` — это больше соответствует стилю Python.
- `isdigit()` возвращает `True` не только для цифр 0–9, но и для некоторых цифр Юникода (например, `"²"`); для строгой проверки используйте `ch in "0123456789"` или `isdecimal()`.
- Коды кириллических букв идут не сплошь: казахские буквы (`Ә`=1240, `Қ`=1178, …) находятся вне основного русского алфавита (1040–1103), поэтому поиск «следующей буквы» через `ord()` надёжно работает только для латиницы.
- Документация: https://docs.python.org/3/library/functions.html#ord и https://docs.python.org/3/library/functions.html#enumerate
