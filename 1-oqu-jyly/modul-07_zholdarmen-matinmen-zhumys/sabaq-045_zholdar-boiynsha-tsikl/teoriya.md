## 1. for циклі жол бойынша

Жол — тізбек (тізім сияқты), сондықтан `for` оның символдарын бірінен соң бірін береді:

```python
word = "Абай"
for ch in word:
    print(ch)
```

Нәтижесі:
```text
А
б
а
й
```

Аналогия: кітапты әріп-әріп бойынша саусақпен жүргізіп оқу. Саусақ — `ch` айнымалысы.

## 2. Санау алгоритмі (санауыш)

Үлгі: санауышты 0-ге теңестіреміз → әр символды тексереміз → шарт орындалса, 1 қосамыз.

```python
text = "Білім — бақыт кілті"
vowels = "аәеёиоөуұүыіэюя"
count = 0
for ch in text.lower():
    if ch in vowels:
        count += 1
print("Дауысты дыбыстар саны:", count)
```

Нәтижесі:
```text
Дауысты дыбыстар саны: 6
```

### Символ түрін анықтау

| Әдіс | True болатын жағдай |
|---|---|
| `ch.isalpha()` | әріп |
| `ch.isdigit()` | цифр |
| `ch.isspace()` | бос орын, `\t`, `\n` |
| `ch.isupper()` / `ch.islower()` | бас / кіші әріп |
| `ch.isalnum()` | әріп немесе цифр |

```python
s = "Мектеп №25, 2027 жыл!"
letters = 0
digits = 0
spaces = 0
others = 0
for ch in s:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1
    else:
        others += 1
print("Әріп:", letters, "Цифр:", digits, "Бос орын:", spaces, "Басқа:", others)
```

Нәтижесі:
```text
Әріп: 9 Цифр: 6 Бос орын: 3 Басқа: 3
```

## 3. Жаңа жол «жинау» (сүзу және түрлендіру)

Жол өзгермейтіндіктен, бос жолдан бастап символдарды бірте-бірте қосамыз.

### Тек цифрларды қалдыру
```python
phone = "+7 (701) 555-12-34"
digits = ""
for ch in phone:
    if ch.isdigit():
        digits += ch
print(digits)
```

Нәтижесі:
```text
77015551234
```

### Әр символды түрлендіру
```python
word = "қазақстан"
result = ""
for ch in word:
    if ch in "аәеоөұүыі":
        result += ch.upper()
    else:
        result += ch
print(result)
```

Нәтижесі:
```text
қАзАқстАн
```

### Жолды кері аудару — цикл арқылы
```python
s = "Тараз"
rev = ""
for ch in s:
    rev = ch + rev       # символды алдына қосамыз
print(rev)
```

Нәтижесі:
```text
зараТ
```

Бұл — `s[::-1]` нәтижесімен бірдей, бірақ алгоритм ішінде не болып жатқанын көрсетеді.

## 4. Индекс бойынша цикл

Символдың **орны** керек болса немесе **көршілес** символдарды салыстыру қажет болса, `range(len(s))` қолданамыз:

```python
s = "Python"
for i in range(len(s)):
    print(i, s[i])
```

Нәтижесі:
```text
0 P
1 y
2 t
3 h
4 o
5 n
```

### Қай тәсілді таңдау керек?

| Міндет | Тәсіл |
|---|---|
| Тек символдың өзі керек | `for ch in s` |
| Символдың индексі керек | `for i in range(len(s))` |
| Көршілес символдар (s[i] және s[i+1]) | `for i in range(len(s) - 1)` |
| Жұп/тақ орындағылар | `for i in range(0, len(s), 2)` |

### Қатар тұрған бірдей әріптер

```python
word = "мәселе аллея ассамблея"
for i in range(len(word) - 1):
    if word[i] == word[i + 1] and word[i] != " ":
        print("Қос әріп:", word[i] * 2, "индекс", i)
```

Нәтижесі:
```text
Қос әріп: лл индекс 8
Қос әріп: сс индекс 14
```

### Символдың барлық орындарын табу

```python
s = "банан"
for i in range(len(s)):
    if s[i] == "н":
        print("'н' индексі:", i)
```

Нәтижесі:
```text
'н' индексі: 2
'н' индексі: 4
```

## 5. Символ кодтары: ord() және chr()

Компьютер әр символды **сан (код)** ретінде сақтайды. Бұл кодтар **Юникод** (Unicode) кестесінде анықталған. Латын әріптері мен цифрлар үшін бұл кодтар ескі ASCII кестесімен бірдей.

- `ord(символ)` → символдың коды;
- `chr(код)` → кодқа сәйкес символ.

```python
print(ord("A"), ord("B"), ord("a"))
print(ord("0"), ord("9"))
print(ord("А"), ord("Ә"))      # кирилл әріптері
print(chr(65), chr(97), chr(1178))
```

Нәтижесі:
```text
65 66 97
48 57
1040 1240
A a Қ
```

Латын әріптері **қатар** орналасқан: `A`=65, `B`=66, ..., `Z`=90; `a`=97, ..., `z`=122. Сондықтан келесі әріпті табуға болады:

```python
letter = "C"
print(chr(ord(letter) + 1))
for code in range(ord("a"), ord("f") + 1):
    print(chr(code), end=" ")
print()
```

Нәтижесі:
```text
D
a b c d e f 
```

Осы тәсіл **Цезарь шифрінің** негізінде жатыр: әр әріп алфавитте белгілі бір қадамға жылжытылады.

### Цифр символын санға айналдыру

```python
number = "2027"
total = 0
for ch in number:
    total += int(ch)
print("Цифрлар қосындысы:", total)
```

Нәтижесі:
```text
Цифрлар қосындысы: 11
```

## 6. Ерте тоқтату: break

Бірінші сәйкес символды тапқанда циклді `break` операторымен тоқтатуға болады:

```python
s = "abc7de9"
for i in range(len(s)):
    if s[i].isdigit():
        print("Бірінші цифр:", s[i], "индексі:", i)
        break
```

Нәтижесі:
```text
Бірінші цифр: 7 индексі: 3
```

## Жиі кездесетін қателер

**1. Көршілерді тексергенде шектен шығу**

```python
s = "аалма"
# for i in range(len(s)):            # s[i + 1] соңғы қадамда IndexError береді
for i in range(len(s) - 1):
    if s[i] == s[i + 1]:
        print("Қос әріп табылды")
```

**2. Жаңа жолды цикл ішінде нөлдеу**

```python
s = "a1b2"
result = ""                 # дұрыс: циклге ДЕЙІН
for ch in s:
    # result = ""           # қате: әр қадамда өшіріледі
    if ch.isdigit():
        result += ch
print(result)               # 12
```

**3. Цифр символын санмен салыстыру**

```python
ch = "5"
print(ch == 5)        # False — жол мен сан
print(int(ch) == 5)   # True
```

**4. Регистрді ескермеу**

```python
text = "Алма"
print(text.count("а"))           # 1
print(text.lower().count("а"))   # 2
```

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Жол бойынша цикл | `for ch in s` — әр символды кезекпен алу |
| Индекс бойынша цикл | `for i in range(len(s))` — орын арқылы қатынау |
| Санауыш | шарт орындалған сайын 1-ге артатын айнымалы |
| Жол жинау | бос жолдан бастап `+=` арқылы жаңа жол құру |
| Юникод (Unicode) | әлемдегі барлық символдардың кодтар кестесі |
| `ord()` / `chr()` | символ → код / код → символ |

## Ескерту

- Цикл ішінде жолды `+=` арқылы жинау шағын мәтіндер үшін қалыпты, бірақ үлкен көлемде тізімге `append()` жасап, соңында `"".join(...)` қолданған тиімдірек.
- Индекс те, символ да керек болса, `range(len(s))` орнына `enumerate()` ыңғайлы: `for i, ch in enumerate(s):` — бұл Python стиліне көбірек сай келеді.
- `isdigit()` тек 0–9 цифрларына емес, кейбір Юникод цифрларына да (мысалы, `"²"`) `True` береді; қатаң тексеру үшін `ch in "0123456789"` немесе `isdecimal()` қолданыңыз.
- Кириллица әріптерінің кодтары қатар тұрмайды: қазақ әріптері (`Ә`=1240, `Қ`=1178, …) негізгі орыс алфавитінен (1040–1103) тыс орналасқан, сондықтан `ord()` арқылы «келесі әріпті» табу тек латын әліпбиінде сенімді жұмыс істейді.
- Құжаттама: https://docs.python.org/3/library/functions.html#ord және https://docs.python.org/3/library/functions.html#enumerate
