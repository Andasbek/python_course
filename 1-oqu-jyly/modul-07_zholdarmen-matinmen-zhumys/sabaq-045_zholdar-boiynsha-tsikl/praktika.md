# Сабақ 45. Практикалық тапсырмалар: жолдар бойынша цикл

## Базалық деңгей

### 1-тапсырма. Әріптерді бағанмен
Сөз енгізіледі. Әр әрпін нөмірімен (1-ден бастап) жеке жолда шығарыңыз.

Мысал:
```text
Сөз: Ойыл
1 - О
2 - й
3 - ы
4 - л
```

### 2-тапсырма. Дауысты және дауыссыз
Мәтін енгізіледі. Дауысты дыбыстар мен дауыссыз дыбыстар (әріптердің қалғаны) санын бөлек шығарыңыз. Бос орын мен тыныс белгілері есептелмейді.

Мысал:
```text
Мәтін: Туған жер
Дауысты: 3
Дауыссыз: 5
```

### 3-тапсырма. Цифрлар қосындысы
Пайдаланушы кез келген ұзындықтағы бүтін сан енгізеді (жол ретінде). Цифрларының қосындысын және ең үлкен цифрын табыңыз.

Мысал: `907415` → қосынды `26`, ең үлкен цифр `9`.

### 4-тапсырма. Бос орындарсыз
Мәтін енгізіледі. Цикл арқылы барлық бос орындарды алып тастаған жаңа жол құрыңыз (`replace()` қолданбаңыз).

### 5-тапсырма. Бас әріптер
Мәтіндегі барлық бас әріптерді бір жолға жинап шығарыңыз.

Мысал: `Абай Құнанбайұлы Семейде туған` → `АҚС`

## Кеңейтілген деңгей

### 6-тапсырма. Регистрді ауыстыру
`swapcase()` әдісін қолданбай, цикл арқылы бас әріпті кішіге, кіші әріпті басқа айналдырыңыз.

Мысал: `ПиТоН 2027` → `пИтОн 2027`

### 7-тапсырма. Қысу (RLE)
Қатар тұрған бірдей символдарды «символ + саны» түрінде қысыңыз.

Мысал: `aaabccdddd` → `a3b1c2d4`

Кеңес: санауышты қолданып, `s[i]` мен `s[i + 1]`-ді салыстырыңыз немесе соңғы символды есте сақтаңыз.

### 8-тапсырма. Ең ұзын бірдей тізбек
Жолдағы қатар тұрған бірдей символдардың ең ұзын тізбегінің ұзындығы мен символын табыңыз.

Мысал: `ааббббвв` → `б 4`

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Латын әліппесінің жиілігі
Ағылшынша сөйлем енгізіледі. `ord()` және `chr()` арқылы `a`-дан `z`-ке дейінгі әр әріптің неше рет кездесетінін шығарыңыз (тек кездескен әріптерді). Регистр ескерілмейді.

Мысал:
```text
Мәтін: Hello World
d 1
e 1
h 1
l 3
o 2
r 1
w 1
```

### 10-тапсырма. Жақшалар балансы
Тек `(` және `)` таңбаларынан тұратын жол енгізіледі. Жақшалар дұрыс орналасқан ба? (Әр ашылған жақша кейін жабылуы керек, және ешбір кезде жабылғандары ашылғандарынан көп болмауы керек.)

Мысал: `(()())` → `Дұрыс`, `())(` → `Қате`.

## Үй тапсырмасы

1. Сөйлемдегі әр сөздің бірінші әрпін бас әріпке айналдырыңыз (цикл арқылы, `title()` қолданбай).
2. Пайдаланушы аты (логин) енгізіледі. Ол тек латын әріптерінен, цифрлардан және `_` белгісінен тұрса — «Жарамды», әйтпесе — «Жарамсыз» деп шығарыңыз.
3. Өз атыңыздың әр әрпінің Юникод кодын шығарыңыз.

**10-тапсырма**
```python
s = input("Жақшалар: ")
balance = 0
ok = True
for ch in s:
    if ch == "(":
        balance += 1
    else:
        balance -= 1
    if balance < 0:
        ok = False
        break
if ok and balance == 0:
    print("Дұрыс")
else:
    print("Қате")
```
