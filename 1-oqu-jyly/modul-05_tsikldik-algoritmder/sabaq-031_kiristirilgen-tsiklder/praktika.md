# Сабақ 31. Практикалық тапсырмалар: кірістірілген циклдер

## Базалық деңгей

### 1-тапсырма. Болжа және тексер
Әр кодтың нәтижесін және ішкі цикл денесінің орындалу санын қағазға жаз, содан кейін Thonny-де тексер:
```python
# а)
for i in range(2):
    for j in range(3):
        print(i, j)

# ә)
for i in range(1, 4):
    for j in range(i):
        print("#", end="")
    print()

# б)
count = 0
for a in range(5):
    for b in range(5):
        if a == b:
            count += 1
print(count)
```

### 3-тапсырма. Апта кестесі
Сыртқы цикл — апта күндерінің нөмірі (1–5), ішкі — сабақ нөмірі (1–4). Экранға `1-күн: 1-сабақ 2-сабақ 3-сабақ 4-сабақ` түрінде шығар.

### 4-тапсырма. Ойын сүйектері
Екі ойын сүйегін лақтырғанда қосындысы `S` болатын барлық нұсқаларды және олардың санын шығар (`S` енгізіледі, 2 ≤ S ≤ 12).

## Кеңейтілген деңгей

### 5-тапсырма. Электрондық сағат
00:00-ден 02:59-ға дейін әр 20 минут сайынғы уақытты `ЧЧ:ММ` пішімінде шығар.

### 6-тапсырма. Пифагор үштіктері
`a² + b² = c²` теңдігін қанағаттандыратын, `1 ≤ a < b < c ≤ 30` болатын барлық үштіктерді тап.

**Кеңес:** үш кірістірілген цикл; `b` циклі `a + 1`-ден, `c` циклі `b + 1`-ден басталсын.

### 7-тапсырма. Әр оқушының орташа бағасы
`n` оқушы бар, әр оқушының `k` бағасы енгізіледі. Әр оқушының орташа бағасын және бүкіл сыныптың орташа бағасын шығар.

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Ескі есеп
«100 теңгеге 100 құс сатып алу керек: қаз — 10 тг, үйрек — 5 тг, 2 балапан — 1 тг (бір балапан — 0,5 тг). Әр түрден кем дегенде біреу болуы керек.» Барлық нұсқаларды тап.

### 9-тапсырма. Сиқырлы сандар
1000-нан 9999-ға дейінгі сандардың ішінен алғашқы екі цифрының қосындысы соңғы екі цифрының қосындысына тең болатындар неше? (Кірістірілген циклсіз де шығаруға болады, бірақ 4 цифрды 4 кірістірілген цикл арқылы іріктеп көр.)

**7-тапсырма**
```python
n = int(input("Оқушылар саны: "))
k = int(input("Әр оқушының баға саны: "))
class_total = 0
for s in range(1, n + 1):
    total = 0
    for g in range(1, k + 1):
        total += int(input(f"{s}-оқушы, {g}-баға: "))
    print(f"{s}-оқушының орташа бағасы: {total / k:.2f}")
    class_total += total
print(f"Сынып бойынша орташа: {class_total / (n * k):.2f}")
```
