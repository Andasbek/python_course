## Базовый уровень

### Задание 1. Предскажи и проверь
Запиши на бумаге результат каждого кода и число выполнений тела внутреннего цикла, затем проверь в Thonny:
```python
# а)
for i in range(2):
    for j in range(3):
        print(i, j)

# б)
for i in range(1, 4):
    for j in range(i):
        print("#", end="")
    print()

# в)
count = 0
for a in range(5):
    for b in range(5):
        if a == b:
            count += 1
print(count)
```

**Задание 7**
```python
n = int(input("Количество учеников: "))
k = int(input("Количество оценок у каждого ученика: "))
class_total = 0
for s in range(1, n + 1):
    total = 0
    for g in range(1, k + 1):
        total += int(input(f"Ученик {s}, оценка {g}: "))
    print(f"Средняя оценка ученика {s}: {total / k:.2f}")
    class_total += total
print(f"Среднее по классу: {class_total / (n * k):.2f}")
```
