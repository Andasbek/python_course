## 1. Квадрат с помощью цикла

Без цикла:
```python
import turtle
t = turtle.Turtle()
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
turtle.done()
```

С циклом:
```python
import turtle
t = turtle.Turtle()
for i in range(4):
    t.forward(100)
    t.right(90)
turtle.done()
```
Повторяющийся «блок» — «иди вперёд + повернись». Повторяем его 4 раза.

## 2. Правильные многоугольники и правило углов

**Правильный многоугольник** — многоугольник, у которого все стороны и все углы равны.

**Правило полного оборота черепашки:** обходя любую замкнутую фигуру, черепашка в сумме поворачивается на **360°**. Поэтому угол поворота в каждой вершине (внешний угол):

```text
угол поворота = 360 / n        (n — число сторон)
```

| Фигура | `n` | Угол поворота | Внутренний угол (180 − внешний) |
|---|---|---|---|
| Треугольник | 3 | 120° | 60° |
| Квадрат | 4 | 90° | 90° |
| Пятиугольник | 5 | 72° | 108° |
| Шестиугольник | 6 | 60° | 120° |
| Восьмиугольник | 8 | 45° | 135° |
| 36-угольник | 36 | 10° | 170° |

**Частая ошибка:** при рисовании треугольника поворачивать черепашку на 60°. 60° — внутренний угол; черепашка должна поворачиваться на внешний угол (120°)!

### Любой многоугольник
```python
import turtle

t = turtle.Turtle()
t.shape("turtle")
n = int(input("Число сторон: "))
side = int(input("Длина стороны: "))
for i in range(n):
    t.forward(side)
    t.right(360 / n)
turtle.done()
```

Чем больше `n`, тем больше многоугольник похож на окружность. Например, `n = 60`, `side = 10` — почти окружность.

### Несколько многоугольников в одном окне (вложенный цикл)
```python
import turtle

t = turtle.Turtle()
t.speed(0)
for n in range(3, 11):           # от 3 до 10 сторон
    for i in range(n):
        t.forward(50)
        t.left(360 / n)
turtle.done()
```
Все многоугольники начинаются с одной стороны и располагаются друг в друге.

## 3. Звёзды

Чтобы нарисовать звезду, черепашка в каждой вершине поворачивается на **больший** угол. В пятиконечной звезде черепашка в сумме делает 2 полных оборота (720°):
```text
угол поворота = 720 / 5 = 144°
```

```python
import turtle

t = turtle.Turtle()
t.color("gold")
t.begin_fill()
for i in range(5):
    t.forward(150)
    t.right(144)
t.end_fill()
turtle.done()
```

Общее правило: для звезды с `n` (нечётным) вершинами `угол = 180 - 180 / n`. Например, семиконечная звезда: `180 - 180 / 7 ≈ 154.29°`.

## 4. Спирали

Спираль — «многоугольник», у которого длина стороны с каждым шагом **увеличивается**. Используем переменную цикла как длину шага:

### Квадратная спираль
```python
import turtle

t = turtle.Turtle()
t.speed(0)
for i in range(1, 100):
    t.forward(i * 3)
    t.right(90)
turtle.done()
```

### Изменим угол — получим новый узор
```python
import turtle

t = turtle.Turtle()
t.speed(0)
turtle.bgcolor("black")
t.color("cyan")
for i in range(150):
    t.forward(i * 2)
    t.right(91)          # не 90, а 91 — спираль «закручивается»
turtle.done()
```
Разница в один градус полностью меняет узор. Например, значения `right(89)`, `right(121)`, `right(144)`, `right(59)` дают совершенно разные узоры.

### Разноцветная спираль (`colormode(255)`)
В режиме `colormode(255)` цвет задаётся тремя числами `(красный, зелёный, синий)` (каждое 0–255). Цвет вычисляем из переменной цикла:
```python
import turtle

turtle.colormode(255)
turtle.bgcolor("black")
t = turtle.Turtle()
t.speed(0)
t.pensize(2)
for i in range(180):
    r = (i * 5) % 256
    g = (255 - i) % 256
    b = (i * 3) % 256
    t.pencolor(r, g, b)
    t.forward(i)
    t.left(59)
turtle.hideturtle()
turtle.done()
```

## 5. Узор (розетка): вращение фигуры

Способ рисования узора: нарисуй **одну фигуру** → немного повернись → повтори. Это вложенный цикл: внешний цикл вращает фигуру, внутренний рисует саму фигуру.

```python
import turtle

t = turtle.Turtle()
t.speed(0)
for k in range(36):          # внешний цикл: 36 поворотов
    for i in range(4):       # внутренний цикл: рисуем квадрат
        t.forward(100)
        t.right(90)
    t.right(10)              # 36 × 10 = 360°
turtle.hideturtle()
turtle.done()
```
Правило: `число поворотов × угол поворота = 360°`.

### Цветок из окружностей
`circle(r)` — рисует окружность радиуса `r`:
```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.color("purple")
for i in range(12):
    t.circle(80)
    t.right(30)
turtle.hideturtle()
turtle.done()
```

### Чередующиеся цвета (if внутри цикла)
```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(2)
for i in range(24):
    if i % 3 == 0:
        t.color("red")
    elif i % 3 == 1:
        t.color("orange")
    else:
        t.color("blue")
    t.circle(60)
    t.right(15)
turtle.hideturtle()
turtle.done()
```

### «Печати» черепашки: stamp()
`stamp()` — оставляет отпечаток формы черепашки в текущем месте, как «печать». Поставим печати вдоль спирали с помощью цикла:
```python
import turtle

t = turtle.Turtle()
t.shape("turtle")
t.color("green")
t.penup()                    # линию не рисуем, только ставим печати
for i in range(30):
    t.stamp()
    t.forward(10 + i * 2)
    t.right(24)
turtle.done()
```

## 6. Сетка и шахматная доска (вложенный цикл + goto)

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.hideturtle()
size = 40
for row in range(8):
    for col in range(8):
        x = -160 + col * size
        y = 160 - row * size
        t.penup()
        t.goto(x, y)
        t.pendown()
        if (row + col) % 2 == 0:
            t.fillcolor("black")
        else:
            t.fillcolor("white")
        t.begin_fill()
        for side in range(4):
            t.forward(size)
            t.right(90)
        t.end_fill()
turtle.done()
```
В этой программе **три** вложенных цикла: строки, столбцы и стороны квадрата.

### Ускорение рисования
Сложные узоры рисуются долго. Способы ускорения:
- `t.speed(0)` — максимальная скорость;
- `turtle.tracer(0)` рисует, не выводя рисунок на экран, а в конце `turtle.update()` показывает всё сразу.

```python
import turtle

turtle.tracer(0)
t = turtle.Turtle()
for i in range(360):
    t.forward(i)
    t.left(89)
turtle.update()
turtle.done()
```

## Частые ошибки

**1. Поворот на внутренний угол**
```python
import turtle
t = turtle.Turtle()
for i in range(3):
    t.forward(100)
    t.right(60)       # ОШИБКА: треугольник не замыкается, получается шестиугольник
turtle.done()
```
Правильно: `t.right(120)` или `t.right(360 / 3)`.

**2. Команда `turtle.done()` внутри цикла** — после первой итерации программа «зависает». `done()` — в самом конце, без отступа.

**3. `begin_fill()` / `end_fill()` неправильно расположены относительно цикла** — заливка выполняется после каждой стороны или не выполняется вовсе. `begin_fill()` — до цикла, `end_fill()` — после цикла.

**4. Назвать файл `turtle.py`** — `import turtle` импортирует твой собственный файл и выдаёт `AttributeError`. Назови файл иначе (например, `uzor.py`).

**5. Целочисленное деление угла**: `360 // 7` = 51 (целочисленное деление) — 7-угольник не замкнётся. Используй `360 / 7`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Правильный многоугольник | Многоугольник с равными сторонами и углами |
| Внешний угол | Угол поворота черепашки в вершине = `360 / n` |
| Правило полного оборота | В замкнутой фигуре черепашка в сумме поворачивается на 360° (в звезде — на 720°) |
| Спираль | Линия, у которой длина шага меняется на каждой итерации |
| Розетка (узор) | Многократный поворот одной фигуры по окружности |
| `speed(0)`, `tracer(0)` | Ускорение рисования |
| `colormode(255)` | Режим задания цвета тремя числами RGB |

## Примечание

- Модуль `turtle` основан на библиотеке `tkinter`. В некоторых дистрибутивах Linux её нужно установить отдельно (`sudo apt install python3-tk`), а в онлайн-редакторах и Jupyter графическое окно может не открываться.
- `turtle.done()` (или `turtle.mainloop()`) удерживает окно открытым; в IDLE окно иногда не закрывается и без него, но при запуске из терминала он обязателен.
- Углы по умолчанию задаются в градусах; для перехода на радианы есть `turtle.radians()`. `left`/`right` принимают и отрицательные значения: `t.left(-90)` ≡ `t.right(90)`.
- Значения `speed()`: от 1 (медленно) до 10 (быстро), а `0` — самый быстрый режим без анимации; значения больше 10 превращаются в 0.
- Чтобы посмотреть встроенные в Python демонстрации, запустите в терминале `python -m turtledemo`.
- Документация: https://docs.python.org/3/library/turtle.html
