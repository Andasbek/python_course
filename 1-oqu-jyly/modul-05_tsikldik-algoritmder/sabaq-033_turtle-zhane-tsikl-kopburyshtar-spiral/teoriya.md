## 1. Цикл арқылы шаршы

Циклсіз:
```python
import turtle
t = turtle.Turtle()
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
turtle.done()
```

Циклмен:
```python
import turtle
t = turtle.Turtle()
for i in range(4):
    t.forward(100)
    t.right(90)
turtle.done()
```
Қайталанатын «блок» — «алға жүр + бұрыл». Оны 4 рет қайталаймыз.

## 2. Дұрыс көпбұрыштар және бұрыштар ережесі

**Дұрыс көпбұрыш** — барлық қабырғалары мен бұрыштары тең көпбұрыш.

**Тасбақаның толық айналым ережесі:** тасбақа кез келген тұйық фигураны айналып шыққанда, барлығы **360°** бұрылады. Сондықтан әр төбеде бұрылу бұрышы (сыртқы бұрыш):

```text
бұрылу бұрышы = 360 / n        (n — қабырға саны)
```

| Фигура | `n` | Бұрылу бұрышы | Ішкі бұрышы (180 − сыртқы) |
|---|---|---|---|
| Үшбұрыш | 3 | 120° | 60° |
| Шаршы | 4 | 90° | 90° |
| Бесбұрыш | 5 | 72° | 108° |
| Алтыбұрыш | 6 | 60° | 120° |
| Сегізбұрыш | 8 | 45° | 135° |
| 36-бұрыш | 36 | 10° | 170° |

**Жиі қате:** үшбұрыш салғанда тасбақаны 60°-қа бұру. 60° — ішкі бұрыш; тасбақа сыртқы бұрышқа (120°) бұрылуы керек!

### Кез келген көпбұрыш
```python
import turtle

t = turtle.Turtle()
t.shape("turtle")
n = int(input("Қабырға саны: "))
side = int(input("Қабырға ұзындығы: "))
for i in range(n):
    t.forward(side)
    t.right(360 / n)
turtle.done()
```

`n` үлкен болған сайын көпбұрыш шеңберге ұқсайды. Мысалы, `n = 60`, `side = 10` — шеңбер дерлік.

### Бір терезеде бірнеше көпбұрыш (кірістірілген цикл)
```python
import turtle

t = turtle.Turtle()
t.speed(0)
for n in range(3, 11):           # 3-тен 10 қабырғаға дейін
    for i in range(n):
        t.forward(50)
        t.left(360 / n)
turtle.done()
```
Барлық көпбұрыштар бір қабырғадан басталып, бір-бірінің ішінде орналасады.

## 3. Жұлдыздар

Жұлдыз салу үшін тасбақа әр төбеде **үлкенірек** бұрышқа бұрылады. Бес бұрышты жұлдызда тасбақа барлығы 2 толық айналым (720°) жасайды:
```text
бұрылу бұрышы = 720 / 5 = 144°
```

```python
import turtle

t = turtle.Turtle()
t.color("gold")
t.begin_fill()
for i in range(5):
    t.forward(150)
    t.right(144)
t.end_fill()
turtle.done()
```

Жалпы ереже: `n` (тақ) төбелі жұлдыз үшін `бұрыш = 180 - 180 / n`. Мысалы, 7 төбелі жұлдыз: `180 - 180 / 7 ≈ 154.29°`.

## 4. Спиральдар

Спираль — әр қадам сайын қабырға ұзындығы **артатын** «көпбұрыш». Цикл айнымалысын қадам ұзындығы ретінде қолданамыз:

### Шаршы спираль
```python
import turtle

t = turtle.Turtle()
t.speed(0)
for i in range(1, 100):
    t.forward(i * 3)
    t.right(90)
turtle.done()
```

### Бұрышты өзгертсек — жаңа өрнек
```python
import turtle

t = turtle.Turtle()
t.speed(0)
turtle.bgcolor("black")
t.color("cyan")
for i in range(150):
    t.forward(i * 2)
    t.right(91)          # 90 емес, 91 — спираль «бұралады»
turtle.done()
```
Бір градустың айырмашылығы өрнекті мүлде өзгертеді. Мысалы, `right(89)`, `right(121)`, `right(144)`, `right(59)` мәндері әртүрлі өрнек береді.

### Түрлі түсті спираль (`colormode(255)`)
`colormode(255)` режимінде түс `(қызыл, жасыл, көк)` үш санымен беріледі (әрқайсысы 0–255). Түсті цикл айнымалысынан есептейміз:
```python
import turtle

turtle.colormode(255)
turtle.bgcolor("black")
t = turtle.Turtle()
t.speed(0)
t.pensize(2)
for i in range(180):
    r = (i * 5) % 256
    g = (255 - i) % 256
    b = (i * 3) % 256
    t.pencolor(r, g, b)
    t.forward(i)
    t.left(59)
turtle.hideturtle()
turtle.done()
```

## 5. Өрнек (розетка): фигураны айналдыру

Өрнек салудың тәсілі: **бір фигураны** сал → аздап бұрыл → қайтала. Бұл — кірістірілген цикл: сыртқы цикл фигураны айналдырады, ішкі цикл фигураның өзін салады.

```python
import turtle

t = turtle.Turtle()
t.speed(0)
for k in range(36):          # сыртқы цикл: 36 рет айналдыру
    for i in range(4):       # ішкі цикл: шаршы салу
        t.forward(100)
        t.right(90)
    t.right(10)              # 36 × 10 = 360°
turtle.hideturtle()
turtle.done()
```
Ереже: `айналдыру саны × бұрылу бұрышы = 360°`.

### Шеңберлерден гүл
`circle(r)` — радиусы `r` болатын шеңбер салады:
```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.color("purple")
for i in range(12):
    t.circle(80)
    t.right(30)
turtle.hideturtle()
turtle.done()
```

### Ауыспалы түстер (цикл ішіндегі if)
```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(2)
for i in range(24):
    if i % 3 == 0:
        t.color("red")
    elif i % 3 == 1:
        t.color("orange")
    else:
        t.color("blue")
    t.circle(60)
    t.right(15)
turtle.hideturtle()
turtle.done()
```

### Тасбақа «мөрлері»: stamp()
`stamp()` — тасбақаның пішінін ағымдағы орынға «мөр» сияқты басып қалдырады. Цикл арқылы спираль бойымен мөрлер басайық:
```python
import turtle

t = turtle.Turtle()
t.shape("turtle")
t.color("green")
t.penup()                    # сызық салмаймыз, тек мөр басамыз
for i in range(30):
    t.stamp()
    t.forward(10 + i * 2)
    t.right(24)
turtle.done()
```

## 6. Тор және шахмат тақтасы (кірістірілген цикл + goto)

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.hideturtle()
size = 40
for row in range(8):
    for col in range(8):
        x = -160 + col * size
        y = 160 - row * size
        t.penup()
        t.goto(x, y)
        t.pendown()
        if (row + col) % 2 == 0:
            t.fillcolor("black")
        else:
            t.fillcolor("white")
        t.begin_fill()
        for side in range(4):
            t.forward(size)
            t.right(90)
        t.end_fill()
turtle.done()
```
Бұл бағдарламада **үш** кірістірілген цикл бар: жолдар, бағандар және шаршының қабырғалары.

### Сурет салуды жылдамдату
Күрделі өрнектер ұзақ салынады. Жылдамдату тәсілдері:
- `t.speed(0)` — ең жоғары жылдамдық;
- `turtle.tracer(0)` суретті экранға шығармай салады, соңында `turtle.update()` бәрін бірден көрсетеді.

```python
import turtle

turtle.tracer(0)
t = turtle.Turtle()
for i in range(360):
    t.forward(i)
    t.left(89)
turtle.update()
turtle.done()
```

## Жиі кездесетін қателер

**1. Ішкі бұрышқа бұру**
```python
import turtle
t = turtle.Turtle()
for i in range(3):
    t.forward(100)
    t.right(60)       # ҚАТЕ: үшбұрыш тұйықталмайды, алтыбұрыш шығады
turtle.done()
```
Дұрысы: `t.right(120)` немесе `t.right(360 / 3)`.

**2. `turtle.done()` командасын цикл ішіне жазу** — бірінші итерациядан кейін бағдарлама «қатып» қалады. `done()` — ең соңында, шегініссіз.

**3. `begin_fill()` / `end_fill()` цикл ішінде дұрыс орналаспаған** — бояу әр қабырғадан кейін жасалады немесе мүлде жасалмайды. `begin_fill()` — циклге дейін, `end_fill()` — циклден кейін.

**4. Файлды `turtle.py` деп атау** — `import turtle` сенің өз файлыңды импорттайды да, `AttributeError` береді. Файлды басқаша ата (мысалы, `ornek.py`).

**5. Бұрышты бүтін санға бөлу**: `360 // 7` = 51 (бүтін бөлу) — 7-бұрыш тұйықталмайды. `360 / 7` қолдан.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Дұрыс көпбұрыш | Қабырғалары мен бұрыштары тең көпбұрыш |
| Сыртқы бұрыш | Тасбақаның төбедегі бұрылу бұрышы = `360 / n` |
| Толық айналым ережесі | Тұйық фигурада тасбақа барлығы 360° (жұлдызда 720°) бұрылады |
| Спираль | Қадам ұзындығы әр итерацияда өзгеретін сызық |
| Розетка (өрнек) | Бір фигураны шеңбер бойымен қайталап айналдыру |
| `speed(0)`, `tracer(0)` | Сурет салуды жылдамдату |
| `colormode(255)` | Түсті RGB үш санымен беру режимі |

## Ескерту

- `turtle` модулі `tkinter` кітапханасына негізделген. Кейбір Linux жинақтарында ол бөлек орнатылады (`sudo apt install python3-tk`), ал онлайн-редакторлар мен Jupyter-де графикалық терезе ашылмауы мүмкін.
- `turtle.done()` (немесе `turtle.mainloop()`) терезені ашық ұстайды; IDLE-де кейде оны жазбаса да терезе жабылмайды, бірақ терминалдан іске қосқанда міндетті.
- Бұрыштар әдепкіде градуспен беріледі; радианға көшу үшін `turtle.radians()` қолданылады. `left`/`right` теріс мәнді де қабылдайды: `t.left(-90)` ≡ `t.right(90)`.
- `speed()` мәндері: 1 (ең баяу) … 10 (жылдам), ал `0` — анимациясыз ең жылдам режим; 10-нан үлкен мәндер 0-ге айналады.
- Python-ның өзімен бірге келетін мысалдарды көру үшін терминалда `python -m turtledemo` іске қосыңыз.
- Құжаттама: https://docs.python.org/3/library/turtle.html
