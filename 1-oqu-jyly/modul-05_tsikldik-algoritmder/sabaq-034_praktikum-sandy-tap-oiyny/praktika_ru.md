1. **Уровень сложности:** в начале игры выбирается уровень: 1 — лёгкий (1–10, 5 попыток), 2 — средний (1–100, 7 попыток), 3 — сложный (1–1000, 10 попыток).

3. **Рекорд:** сохраняй наименьшее количество попыток за несколько игр и сообщай о новом рекорде.
4. **Очки:** в каждой игре начисляется `(max_attempts - attempts + 1) * 10` очков, в конце выводится общий счёт.
5. **Смена ролей:** режим, в котором компьютер находит твоё число двоичным поиском.

**Практикум — полный образец (с уровнем сложности и рекордом)**
```python
import random

print("=== ИГРА «УГАДАЙ ЧИСЛО» ===")
record = 0
total_score = 0
play = "да"
while play == "да":
    level = input("Уровень (1 - лёгкий, 2 - средний, 3 - сложный): ")
    if level == "1":
        top = 10
        max_attempts = 5
    elif level == "3":
        top = 1000
        max_attempts = 10
    else:
        top = 100
        max_attempts = 7
    secret = random.randint(1, top)
    attempts = 0
    won = False
    print(f"Я загадал число от 1 до {top}. Количество попыток: {max_attempts}")
    while attempts < max_attempts:
        guess = int(input(f"Попытка {attempts + 1}: "))
        if guess < 1 or guess > top:
            print(f"Число должно быть от 1 до {top}!")
            continue
        attempts += 1
        diff = abs(guess - secret)
        if diff == 0:
            won = True
            break
        if guess < secret:
            print("Больше!", end=" ")
        else:
            print("Меньше!", end=" ")
        if diff < 5:
            print("Очень горячо!")
        elif diff < 15:
            print("Тепло")
        else:
            print("Холодно")
    if won:
        score = (max_attempts - attempts + 1) * 10
        total_score += score
        print(f"Угадал! Попыток: {attempts}, очков: {score}")
        if record == 0 or attempts < record:
            record = attempts
            print("Новый рекорд!")
    else:
        print("Попытки закончились. Я загадал:", secret)
    play = input("Сыграешь ещё? (да/нет): ")
print("Общий счёт:", total_score, "Рекорд:", record)
```
`abs()` — модуль числа (встроенная функция); ученикам объясняется кратко.

**★ Камень-Ножницы-Бумага**
```python
import random

player_wins = 0
comp_wins = 0
while player_wins < 3 and comp_wins < 3:
    p = int(input("1 - Камень, 2 - Ножницы, 3 - Бумага: "))
    if p < 1 or p > 3:
        print("Неверный выбор!")
        continue
    c = random.randint(1, 3)
    print("Компьютер выбрал:", c)
    if p == c:
        print("Ничья!")
    elif (p == 1 and c == 2) or (p == 2 and c == 3) or (p == 3 and c == 1):
        print("Ты победил!")
        player_wins += 1
    else:
        print("Компьютер победил!")
        comp_wins += 1
    print(f"Счёт: {player_wins} : {comp_wins}")
if player_wins == 3:
    print("Игру выиграл ты!")
else:
    print("Игру выиграл компьютер!")
```
