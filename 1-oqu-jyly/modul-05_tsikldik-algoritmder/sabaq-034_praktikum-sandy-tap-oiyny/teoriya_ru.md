## 1. Циклы: краткий справочник (шпаргалка)

| Средство | Запись | Когда применяем |
|---|---|---|
| `for` + `range` | `for i in range(a, b, step):` | Число повторений известно |
| `while` | `while условие:` | Пока выполняется условие |
| Бесконечный цикл | `while True:` + `break` | Меню, игра, проверка ввода |
| Счётчик | `count += 1` | Подсчёт событий |
| Накопитель | `s += x`, `p *= x` | Сумма (с 0), произведение (с 1) |
| `break` | выход из цикла | Поиск, конец игры |
| `continue` | переход к следующей итерации | Фильтрация |
| Вложенный цикл | цикл внутри цикла | Таблицы, фигуры, перебор |

Что важно помнить: `range(5, 0, -2)` → 5, 3, 1; накопитель произведения начинается с 1; в `while` счётчик нужно изменять до `continue`; `break` во внутреннем цикле останавливает только внутренний цикл.

## 2. Модуль random

Чтобы игра была интересной, компьютер каждый раз должен загадывать **разное** число. Для этого используем стандартный модуль Python `random` (случайный).

```python
import random

x = random.randint(1, 100)   # от 1 до 100 (100 тоже входит!)
print(x)
```

**Обратите внимание:** в `randint(a, b)` **входят** оба числа `a` и `b`, а в `range(a, b)` число `b` не входит.

| Функция | Что возвращает | Пример |
|---|---|---|
| `random.randint(a, b)` | Случайное целое число от `a` до `b` (оба входят) | `randint(1, 6)` → игральный кубик |
| `random.random()` | Дробное число 0.0 ≤ x < 1.0 | `0.5372...` |
| `random.uniform(a, b)` | Дробное число между `a` и `b` | `uniform(36.0, 37.5)` |

Бросим игральный кубик 5 раз:
```python
import random

for i in range(5):
    print("Выпало:", random.randint(1, 6))
```
Результат (при каждом запуске разный):
```text
Выпало: 4
Выпало: 1
Выпало: 6
Выпало: 6
Выпало: 2
```

**Примечание:** не называй свой файл `random.py` — иначе `import random` импортирует твой файл.

## 3. Правила и алгоритм игры «Угадай число»

**Правила:** компьютер загадывает число от 1 до 100. Игрок пытается его угадать. Компьютер подсказывает: «Больше!» или «Меньше!». Игра продолжается, пока игрок не угадает. В конце выводится количество попыток.

Алгоритм (словесно):
1. Выбери случайное число `secret`; `attempts = 0`.
2. Спроси у игрока число `guess`; увеличь `attempts` на 1.
3. Если `guess < secret` — «Больше!»; если `guess > secret` — «Меньше!».
4. Если `guess == secret` — «Угадал!», выведи количество попыток и заверши игру.
5. Иначе вернись к шагу 2.

Блок-схема:
```text
   [Начало]
      │
 [secret = randint(1,100), attempts = 0]
      │
      ▼
 ┌─►[ввод guess, attempts += 1]
 │    │
 │  <guess == secret?> ── да ──► [«Угадал!», attempts] ──► [Конец]
 │    │ нет
 │  <guess < secret?> ── да ──► [«Больше!»] ──┐
 │    │ нет                                   │
 │  [«Меньше!»]                               │
 └────┴───────────────────────────────────────┘
```

## 4. Поэтапная разработка программы

Программисты не пишут большую программу сразу: сначала самый простой работающий вариант, затем — улучшения. Это называется **итеративной разработкой**.

### Этап 1: одна попытка
```python
import random

secret = random.randint(1, 100)
guess = int(input("Угадай число от 1 до 100: "))
if guess == secret:
    print("Угадал!")
else:
    print("Неверно. Я загадал число:", secret)
```

### Этап 2: повторять, пока не угадает (while)
```python
import random

secret = random.randint(1, 100)
guess = int(input("Введи число: "))
while guess != secret:
    if guess < secret:
        print("Больше!")
    else:
        print("Меньше!")
    guess = int(input("Введи число: "))
print("Угадал!")
```

### Этап 3: подсчёт попыток (счётчик)
```python
import random

secret = random.randint(1, 100)
attempts = 0
while True:
    guess = int(input("Введи число: "))
    attempts += 1
    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print(f"Угадал! Количество попыток: {attempts}")
        break
```

### Этап 4: ограниченное число попыток, проверка ввода, повторная игра
```python
import random

print("=== ИГРА «УГАДАЙ ЧИСЛО» ===")
play = "да"
while play == "да":
    secret = random.randint(1, 100)
    max_attempts = 7
    attempts = 0
    won = False
    print(f"Я загадал число от 1 до 100. У тебя {max_attempts} попыток.")
    while attempts < max_attempts:
        guess = int(input(f"Попытка {attempts + 1}: "))
        if guess < 1 or guess > 100:
            print("Число должно быть от 1 до 100!")
            continue                 # эта попытка не засчитывается
        attempts += 1
        if guess < secret:
            print("Больше!")
        elif guess > secret:
            print("Меньше!")
        else:
            won = True
            break
    if won:
        print(f"Поздравляю! Ты угадал за {attempts} попыток!")
    else:
        print(f"Попытки закончились. Я загадал число: {secret}")
    play = input("Сыграешь ещё? (да/нет): ")
print("Спасибо за игру!")
```

Эта программа объединяет все средства работы с циклами: `while`, `break`, `continue`, счётчик, флаг (`won`), вложенный цикл (внешний — игры, внутренний — попытки).

## 5. Выигрышная стратегия: двоичный поиск

Почему достаточно 7 попыток? Самая эффективная стратегия — каждый раз называть **середину** интервала:
- 1–100 → называем 50 → «Больше» → осталось 51–100;
- 51–100 → 75 → «Меньше» → 51–74;
- ... каждый раз интервал уменьшается вдвое.

100 → 50 → 25 → 13 → 7 → 4 → 2 → 1: не более **7** попыток. Это называется **двоичным (бинарным) поиском** — одним из важнейших алгоритмов в программировании.

### Поменяемся ролями: компьютер угадывает число
Теперь загадай число ты, а компьютер найдёт его двоичным поиском:
```python
low = 1
high = 100
attempts = 0
print("Загадай число от 1 до 100. Я его найду!")
while low <= high:
    middle = (low + high) // 2
    attempts += 1
    answer = input(f"Твоё число {middle}? (б — больше, м — меньше, д — да): ")
    if answer == "д":
        print(f"Нашёл! За {attempts} попыток.")
        break
    elif answer == "б":
        low = middle + 1
    elif answer == "м":
        high = middle - 1
else:
    print("Кажется, ты хитришь! :)")
```

## 6. Проверка программ со случайными числами

Случайное число меняется при каждом запуске, поэтому ошибку трудно воспроизвести. `random.seed(n)` возвращает генератор в начальное состояние: одинаковый `seed` всегда даёт одну и ту же последовательность чисел.

```python
import random

random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))
random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))   # те же самые числа
```

Правила проверки программы:
- проверять на нескольких разных вводах, в том числе на **граничных** значениях (1, 100, 0, 101);
- имя файла писать строчными буквами, разделяя слова `_` (PEP 8): `guess_game.py`;
- добавлять комментарии `#` к сложным местам кода.

## Частые ошибки

**1. Вызов `randint` внутри цикла**
```python
import random
guess = 0
while guess != 5:
    secret = random.randint(1, 10)   # ОШИБКА: число меняется при каждой попытке!
    guess = int(input())
```
Секретное число выбирается один раз **до** цикла.

**2. Не написали `import random`** → `NameError: name 'random' is not defined`.

**3. Увеличение счётчика в неправильном месте** — засчитываются и непроверенные (вне диапазона) вводы.

**4. Не различать проигрыш/выигрыш** — цикл завершается и когда кончились попытки, и когда число угадано; чтобы их различить, нужен флаг (`won`).

**5. Сравнение числа со строкой**: если не преобразовать результат `input()` в `int`, то `"50" == 50` — всегда `False`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Модуль `random` | Стандартный модуль для работы со случайными числами |
| `randint(a, b)` | Случайное целое число из отрезка `[a; b]` |
| Итеративная разработка | Поэтапное улучшение программы |
| Двоичный поиск | Поиск делением интервала пополам на каждом шаге |
| Флаг `won` | Переменная `bool`, хранящая, чем закончилась игра |

## Примечание

- Модуль `random` выдаёт псевдослучайные числа (алгоритм Mersenne Twister). Он подходит для игр и моделирования, но для паролей, токенов и других значений, связанных с безопасностью, используйте модуль `secrets`.
- `randint(a, b)` включает оба конца, а `random.randrange(a, b)` — как `range` — не включает `b`.
- Для выбора случайного элемента из списка есть `random.choice(...)`, для перемешивания — `random.shuffle(...)`.
- Двоичный поиск среди `n` элементов делает не более ⌈log₂(n+1)⌉ шагов: для 100 чисел — 7, для 1 000 000 — 20 шагов. Готовый двоичный поиск по отсортированному списку — модуль `bisect`.
- При вводе не числа `int(input())` вызывает `ValueError`; чтобы игра не падала, проверяйте ввод через `str.isdigit()` или `try/except ValueError`.
- Документация: https://docs.python.org/3/library/random.html
