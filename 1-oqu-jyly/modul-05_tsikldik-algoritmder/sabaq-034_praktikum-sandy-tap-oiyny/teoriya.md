## 1. Циклдер: қысқа анықтамалық (шпаргалка)

| Құрал | Жазылуы | Қашан қолданамыз |
|---|---|---|
| `for` + `range` | `for i in range(a, b, step):` | Қайталау саны белгілі |
| `while` | `while шарт:` | Шарт орындалғанша |
| Шексіз цикл | `while True:` + `break` | Мәзір, ойын, енгізуді тексеру |
| Санауыш | `count += 1` | Оқиғаларды санау |
| Жинақтауыш | `s += x`, `p *= x` | Қосынды (0-ден), көбейтінді (1-ден) |
| `break` | циклден шығу | Іздеу, ойынның соңы |
| `continue` | келесі итерацияға өту | Сүзгілеу |
| Кірістірілген цикл | цикл ішіндегі цикл | Кестелер, фигуралар, іріктеу |

Есте сақтайтын жайттар: `range(5, 0, -2)` → 5, 3, 1; көбейтінді жинақтауышы 1-ден басталады; `while` ішінде `continue`-ден бұрын санауышты өзгерту керек; ішкі циклдегі `break` тек ішкі циклді тоқтатады.

## 2. random модулі

Ойын қызықты болуы үшін компьютер әр жолы **әртүрлі** сан ойлауы керек. Ол үшін Python-ның стандартты `random` (кездейсоқ) модулін қолданамыз.

```python
import random

x = random.randint(1, 100)   # 1-ден 100-ге дейін (100 де кіреді!)
print(x)
```

**Назар аударыңдар:** `randint(a, b)` — `a` және `b` екеуі де **кіреді**, ал `range(a, b)`-да `b` кірмейді.

| Функция | Не қайтарады | Мысал |
|---|---|---|
| `random.randint(a, b)` | `a`-дан `b`-ге дейінгі кездейсоқ бүтін сан (екеуі де кіреді) | `randint(1, 6)` → ойын сүйегі |
| `random.random()` | 0.0 ≤ x < 1.0 бөлшек сан | `0.5372...` |
| `random.uniform(a, b)` | `a` мен `b` арасындағы бөлшек сан | `uniform(36.0, 37.5)` |

Ойын сүйегін 5 рет лақтыру:
```python
import random

for i in range(5):
    print("Түсті:", random.randint(1, 6))
```
Нәтижесі (әр іске қосқанда әртүрлі):
```text
Түсті: 4
Түсті: 1
Түсті: 6
Түсті: 6
Түсті: 2
```

**Ескерту:** өз файлыңды `random.py` деп атама — әйтпесе `import random` сенің файлыңды импорттайды.

## 3. «Санды тап» ойынының ережесі мен алгоритмі

**Ереже:** компьютер 1-ден 100-ге дейінгі сан ойлайды. Ойыншы санды болжайды. Компьютер «Көбірек!» немесе «Азырақ!» деп кеңес береді. Ойыншы тапқанша ойын жалғасады. Соңында әрекет саны шығады.

Алгоритм (сөзбен):
1. Кездейсоқ `secret` санын таңда; `attempts = 0`.
2. Ойыншыдан `guess` санын сұра; `attempts`-ті 1-ге арттыр.
3. Егер `guess < secret` — «Көбірек!»; егер `guess > secret` — «Азырақ!».
4. Егер `guess == secret` — «Таптың!» және әрекет санын шығарып, ойынды аяқта.
5. Әйтпесе 2-қадамға орал.

Блок-схема:
```text
   [Басы]
      │
 [secret = randint(1,100), attempts = 0]
      │
      ▼
 ┌─►[guess енгізу, attempts += 1]
 │    │
 │  <guess == secret?> ── иә ──► [«Таптың!», attempts] ──► [Соңы]
 │    │ жоқ
 │  <guess < secret?> ── иә ──► [«Көбірек!»] ──┐
 │    │ жоқ                                    │
 │  [«Азырақ!»]                                │
 └────┴────────────────────────────────────────┘
```

## 4. Бағдарламаны кезең-кезеңімен дамыту

Бағдарламашылар үлкен бағдарламаны бірден жазбайды: алдымен ең қарапайым жұмыс істейтін нұсқа, содан кейін — жақсартулар. Бұл **итерациялық әзірлеу** деп аталады.

### 1-кезең: бір рет болжау
```python
import random

secret = random.randint(1, 100)
guess = int(input("1-ден 100-ге дейінгі санды тап: "))
if guess == secret:
    print("Таптың!")
else:
    print("Қате. Мен ойлаған сан:", secret)
```

### 2-кезең: тапқанша қайталау (while)
```python
import random

secret = random.randint(1, 100)
guess = int(input("Санды енгіз: "))
while guess != secret:
    if guess < secret:
        print("Көбірек!")
    else:
        print("Азырақ!")
    guess = int(input("Санды енгіз: "))
print("Таптың!")
```

### 3-кезең: әрекеттерді санау (санауыш)
```python
import random

secret = random.randint(1, 100)
attempts = 0
while True:
    guess = int(input("Санды енгіз: "))
    attempts += 1
    if guess < secret:
        print("Көбірек!")
    elif guess > secret:
        print("Азырақ!")
    else:
        print(f"Таптың! Әрекет саны: {attempts}")
        break
```

### 4-кезең: шектеулі әрекет, қате енгізуді тексеру, қайта ойнау
```python
import random

print("=== «САНДЫ ТАП» ОЙЫНЫ ===")
play = "иә"
while play == "иә":
    secret = random.randint(1, 100)
    max_attempts = 7
    attempts = 0
    won = False
    print(f"Мен 1-ден 100-ге дейін сан ойладым. Сенде {max_attempts} әрекет бар.")
    while attempts < max_attempts:
        guess = int(input(f"{attempts + 1}-әрекет: "))
        if guess < 1 or guess > 100:
            print("Сан 1 мен 100 аралығында болуы керек!")
            continue                 # бұл әрекет есепке алынбайды
        attempts += 1
        if guess < secret:
            print("Көбірек!")
        elif guess > secret:
            print("Азырақ!")
        else:
            won = True
            break
    if won:
        print(f"Құттықтаймын! Сен {attempts} әрекетте таптың!")
    else:
        print(f"Әрекет таусылды. Мен ойлаған сан: {secret}")
    play = input("Тағы ойнайсың ба? (иә/жоқ): ")
print("Ойнағаныңа рахмет!")
```

Бұл бағдарлама циклдердің барлық құралын біріктіреді: `while`, `break`, `continue`, санауыш, жалауша (`won`), кірістірілген цикл (сыртқы — ойындар, ішкі — әрекеттер).

## 5. Жеңу стратегиясы: екілік іздеу

Неге 7 әрекет жеткілікті? Ең тиімді стратегия — әр жолы аралықтың **ортасын** айту:
- 1–100 → 50 айтамыз → «Көбірек» → 51–100 қалды;
- 51–100 → 75 → «Азырақ» → 51–74;
- ... әр жолы аралық екі есе кішірейеді.

100 → 50 → 25 → 13 → 7 → 4 → 2 → 1: ең көбі **7** әрекет. Бұл **екілік (бинарлы) іздеу** деп аталады — бағдарламалаудағы маңызды алгоритмдердің бірі.

### Рөлдерді ауыстыру: компьютер санды табады
Енді сен сан ойла, компьютер екілік іздеумен табады:
```python
low = 1
high = 100
attempts = 0
print("1-ден 100-ге дейін сан ойла. Мен табамын!")
while low <= high:
    middle = (low + high) // 2
    attempts += 1
    answer = input(f"Сенің саның {middle} ме? (к — көбірек, а — азырақ, и — иә): ")
    if answer == "и":
        print(f"Таптым! {attempts} әрекетте.")
        break
    elif answer == "к":
        low = middle + 1
    elif answer == "а":
        high = middle - 1
else:
    print("Сен алдап жүрсің-ау! :)")
```

## 6. Кездейсоқ сандары бар бағдарламаны тексеру

Кездейсоқ сан әр іске қосқанда өзгереді, сондықтан қатені қайталау қиын. `random.seed(n)` генераторды бастапқы күйге келтіреді: бірдей `seed` әрқашан бірдей сандар тізбегін береді.

```python
import random

random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))
random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))   # дәл сол сандар
```

Бағдарламаны тексеру ережелері:
- кемінде бірнеше түрлі енгізумен, соның ішінде **шекаралық** мәндермен (1, 100, 0, 101) тексеру;
- файл атауын кіші әріппен, сөздерді `_` арқылы жазу (PEP 8): `guess_game.py`;
- кодтың күрделі жерлеріне `#` түсініктемесін қосу.

## Жиі кездесетін қателер

**1. `randint`-ті цикл ішінде шақыру**
```python
import random
guess = 0
while guess != 5:
    secret = random.randint(1, 10)   # ҚАТЕ: сан әр әрекетте өзгереді!
    guess = int(input())
```
Құпия сан циклден **бұрын** бір рет таңдалады.

**2. `import random` жазбау** → `NameError: name 'random' is not defined`.

**3. Санауышты қате жерде арттыру** — тексерілмеген (аралықтан тыс) енгізулер де саналып кетеді.

**4. Жеңілісті/жеңісті ажыратпау** — цикл әрекет таусылғаннан да, тапқаннан да аяқталады; оларды ажырату үшін жалауша (`won`) керек.

**5. Сан мен жолды салыстыру**: `input()` нәтижесін `int`-ке түрлендірмесе, `"50" == 50` — әрқашан `False`.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `random` модулі | Кездейсоқ сандармен жұмыс істейтін стандартты модуль |
| `randint(a, b)` | `[a; b]` аралығындағы кездейсоқ бүтін сан |
| Итерациялық әзірлеу | Бағдарламаны кезең-кезеңімен жақсарту |
| Екілік іздеу | Аралықты әр қадамда екіге бөлу арқылы іздеу |
| Жалауша `won` | Ойынның қалай аяқталғанын сақтайтын `bool` айнымалы |

## Ескерту

- `random` модулі псевдокездейсоқ сандар береді (Mersenne Twister алгоритмі). Ол ойындар мен модельдеуге жарайды, бірақ құпия сөз, токен сияқты қауіпсіздікке қатысты мәндерге `secrets` модулін қолданыңыз.
- `randint(a, b)` екі шетті де қамтиды, ал `random.randrange(a, b)` — `range` сияқты `b`-ны қамтымайды.
- Тізімнен кездейсоқ элемент таңдау үшін `random.choice(...)`, араластыру үшін `random.shuffle(...)` бар.
- Екілік іздеу `n` элементте ең көбі ⌈log₂(n+1)⌉ қадам жасайды: 100 сан үшін — 7, 1 000 000 сан үшін — 20 қадам. Сұрыпталған тізімде дайын екілік іздеу — `bisect` модулі.
- Сан емес мәтін енгізілгенде `int(input())` `ValueError` береді; ойынды тұрақты ету үшін енгізуді `str.isdigit()` немесе `try/except ValueError` арқылы тексеріңіз.
- Құжаттама: https://docs.python.org/3/library/random.html
