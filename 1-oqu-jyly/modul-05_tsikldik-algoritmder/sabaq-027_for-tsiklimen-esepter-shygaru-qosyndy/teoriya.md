## 1. Құрама меншіктеу операторлары

Циклдік есептерде айнымалының мәнін өзгерту жиі кездеседі. Python-да мұны қысқа жазу бар:

| Толық жазу | Қысқа жазу | Мағынасы |
|---|---|---|
| `s = s + x` | `s += x` | қосу |
| `s = s - x` | `s -= x` | азайту |
| `p = p * x` | `p *= x` | көбейту |
| `a = a / x` | `a /= x` | бөлу |
| `c = c + 1` | `c += 1` | бірге арттыру |

```python
s = 10
s += 5
print(s)
s *= 2
print(s)
```
Нәтижесі:
```text
15
30
```

## 2. Жинақтауыш және қосынды

**Жинақтауыш (накопитель, accumulator)** — цикл барысында мәндерді біртіндеп жинайтын айнымалы.

Аналогия: шошқа-қорап (копилка). Басында ішінде 0 теңге. Әр күні оған ақша саламыз. Соңында ішінде барлық салынған ақшаның қосындысы болады.

Қосынды есептеу алгоритмі:
1. Жинақтауышқа бастапқы мән **0** береміз (циклден **бұрын**!).
2. Циклде әр санды жинақтауышқа қосамыз.
3. Циклден **кейін** нәтижені шығарамыз.

```python
s = 0                      # 1. бастапқы мән
for i in range(1, 101):    # 2. 1-ден 100-ге дейін
    s += i                 #    әр санды қосамыз
print("Қосынды:", s)       # 3. нәтиже
```
Нәтижесі:
```text
Қосынды: 5050
```

### Трассировка (1-ден 5-ке дейін)

```python
s = 0
for i in range(1, 6):
    s += i
print(s)
```

| Итерация | `i` | `s` (бұрын) | `s` (кейін) |
|---|---|---|---|
| — | — | — | 0 |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

Нәтиже: `15`.

**Thonny-де** «View → Variables» терезесін ашып, «Debug» (қоңыз белгісі) режимінде `s` пен `i` қалай өзгеретінін қадамдап көруге болады.

### Пернетақтадан енгізілген сандардың қосындысы

```python
n = int(input("Неше сан енгізесіз? "))
total = 0
for i in range(n):
    x = int(input(f"{i + 1}-сан: "))
    total += x
print("Қосындысы:", total)
```
Мысал:
```text
Неше сан енгізесіз? 3
1-сан: 12
2-сан: 7
3-сан: 21
Қосындысы: 40
```

## 3. Көбейтінді

Көбейтінді есептеуде жинақтауыштың бастапқы мәні **1** болуы керек. Неге? Егер 0 болса, кез келген санды 0-ге көбейткенде 0 шығады!

| Жинақтау түрі | Бастапқы мән | Себебі |
|---|---|---|
| Қосынды | 0 | `0 + x = x` |
| Көбейтінді | 1 | `1 * x = x` |
| Санауыш | 0 | әлі ештеңе саналмаған |

### Факториал

**Факториал** `n! = 1 · 2 · 3 · ... · n`. Мысалы, `5! = 120`.

```python
n = int(input("n = "))
p = 1
for i in range(1, n + 1):
    p *= i
print(f"{n}! = {p}")
```
Мысал:
```text
n = 5
5! = 120
```

Python-да бүтін сандардың шегі жоқ, сондықтан `30!` сияқты өте үлкен сандарды да есептей аламыз:
```python
p = 1
for i in range(1, 31):
    p *= i
print(p)
```
Нәтижесі:
```text
265252859812191058636308480000000
```

### Дәреже
`2` санының `10`-дәрежесін `**` амалынсыз есептейік:
```python
result = 1
for i in range(10):
    result *= 2
print(result)
```
Нәтижесі:
```text
1024
```

## 4. Орташа мән

**Орташа арифметикалық мән** = барлық сандардың қосындысы ÷ сандардың саны.

```python
n = int(input("Неше баға? "))
total = 0
for i in range(n):
    grade = int(input(f"{i + 1}-баға: "))
    total += grade
average = total / n
print(f"Орташа баға: {average:.2f}")
```
Мысал:
```text
Неше баға? 4
1-баға: 5
2-баға: 4
3-баға: 5
4-баға: 3
Орташа баға: 4.25
```
`:.2f` — f-жол пішімі: үтірден кейін 2 таңба.

**Назар аудар:** егер `n = 0` болса, `total / n` нөлге бөлу қатесін (`ZeroDivisionError`) береді. Мұны `if` арқылы тексеруге болады:
```python
n = int(input("Неше баға? "))
if n > 0:
    total = 0
    for i in range(n):
        total += int(input("Баға: "))
    print("Орташа:", total / n)
else:
    print("Бағалар жоқ")
```

## 5. Шартты қосынды және санау

Цикл ішінде `if` қолданып, тек белгілі бір шартқа сай сандарды қосуға немесе санауға болады.

**Санауыш (счётчик, counter)** — шарт неше рет орындалғанын санайтын айнымалы (`c += 1`).

```python
# 1-ден 100-ге дейінгі жұп сандардың қосындысы және саны
s = 0
count = 0
for i in range(1, 101):
    if i % 2 == 0:
        s += i
        count += 1
print("Жұп сандар саны:", count)
print("Олардың қосындысы:", s)
```
Нәтижесі:
```text
Жұп сандар саны: 50
Олардың қосындысы: 2550
```

### Оң және теріс сандарды бөлек санау

```python
n = int(input("Неше сан? "))
positive = 0
negative = 0
for i in range(n):
    x = int(input())
    if x > 0:
        positive += 1
    elif x < 0:
        negative += 1
print("Оң:", positive, "Теріс:", negative)
```

## 6. Бөлшектер қатарының қосындысы (циклдің қызықты қолданылуы)

Цикл айнымалысын формулада қолданып, түрлі қатарларды есептеуге болады:
```python
# 1 + 1/2 + 1/3 + ... + 1/10
s = 0
for k in range(1, 11):
    s += 1 / k
print(round(s, 4))
```
Нәтижесі:
```text
2.929
```

## Жиі кездесетін қателер

**1. Жинақтауышты цикл ішінде нөлдеу**
```python
for i in range(1, 6):
    s = 0          # ҚАТЕ: әр итерацияда 0-ге қайтады
    s += i
print(s)           # 5 шығады, 15 емес
```
Дұрысы: `s = 0` — циклден **бұрын**.

**2. Көбейтіндіні 0-ден бастау**
```python
p = 0
for i in range(1, 6):
    p *= i
print(p)   # 0 — қате!
```
Дұрысы: `p = 1`.

**3. Нәтижені цикл ішінде шығару**
```python
s = 0
for i in range(1, 4):
    s += i
    print(s)   # аралық нәтижелер шығады: 1, 3, 6
```
Тек соңғы нәтиже керек болса, `print` шегініссіз (циклден кейін) жазылады.

**4. Жинақтауышты мүлде анықтамау**
```text
for i in range(5):
    s += i
```
`NameError: name 's' is not defined`.

**5. Орташа мәнді цикл ішінде есептеу** — қосынды әлі толық жиналмаған, сондықтан орташа мәнді циклден кейін есептеу керек.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Жинақтауыш | Мәндерді біртіндеп жинайтын айнымалы (қосынды, көбейтінді) |
| Санауыш | Оқиғаның неше рет болғанын санайтын айнымалы (`c += 1`) |
| `+=`, `*=` | Құрама меншіктеу операторлары |
| Факториал `n!` | 1-ден n-ге дейінгі сандардың көбейтіндісі |
| Орташа мән | Қосынды ÷ саны |
| Бастапқы мән | Циклге дейін жинақтауышқа берілетін мән (0 немесе 1) |

## Ескерту

- Python-да сандар тізбегінің қосындысын дайын функциямен де табуға болады: `sum(range(1, 101))` → `5050`. Көбейтінді үшін Python 3.8+ нұсқасында `math.prod()` бар: `math.prod(range(1, 6))` → `120`, ал факториал үшін — `math.factorial(n)`.
- `/` операторы әрқашан `float` қайтарады (`10 / 2` → `5.0`). Бүтін бөлінді керек болса, `//` қолданыңыз.
- Бөлшек сандарды қосқанда дөңгелектеу қателігі болуы мүмкін: `0.1 + 0.2` → `0.30000000000000004`. Нәтижені `round()` немесе `:.2f` арқылы шығарыңыз; дәлдік маңызды болса, `math.fsum()` пайдаланыңыз.
- `sum`, `max`, `min` сияқты кірістірілген функциялардың атын айнымалыға бермеңіз (`sum = 0`) — содан кейін `sum()` функциясы жұмыс істемей қалады.
- Python 3.12-ден бастап `sum()` бөлшек сандарды дәлірек қосады (Neumaier алгоритмі).
- Құжаттама: https://docs.python.org/3/library/functions.html#sum, https://docs.python.org/3/library/math.html
