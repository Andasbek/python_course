# Урок 27. Практические задания: сумма, произведение, среднее значение

## Базовый уровень

### Задание 1. Сумма от 1 до N
Вводится `N`. Выведи сумму 1 + 2 + ... + N.

Пример:
```text
N = 10
Сумма: 55
```

### Задание 2. Сумма нечётных чисел
Найди сумму всех нечётных чисел от 1 до 99 (используй шаг `range`).

Ответ: `2500`.

### Задание 3. Факториал
Вводится `n` (0 ≤ n ≤ 20). Вычисли `n!`. Примечание: `0! = 1`.

Пример:
```text
n = 6
6! = 720
```

### Задание 4. Недельная температура
В течение недели (7 дней) вводится температура воздуха в Астане. Выведи среднюю температуру за неделю с одним знаком после запятой.

Пример:
```text
День 1: -5
День 2: -8
День 3: -3
День 4: 0
День 5: 2
День 6: -1
День 7: -6
Средняя температура: -3.0
```

### Задание 5. Чек магазина
Есть `n` товаров. Вводится цена каждого товара. Вычисли общую сумму и в конце выведи «К оплате: ... тенге».

## Продвинутый уровень

### Задание 6. Оценка «пять»
Вводятся оценки (2–5) `n` учеников класса. Программа должна вывести:
- среднюю оценку;
- количество учеников, получивших «5»;
- количество учеников, получивших «2».

### Задание 7. Депозит
В банк положили `S` тенге под `r`% годовых. В конце каждого года сумма увеличивается на `r`%. Найди сумму через `n` лет и выведи результат за каждый год.

Пример (`S = 100000`, `r = 10`, `n = 3`):
```text
Год 1: 110000.00
Год 2: 121000.00
Год 3: 133100.00
```

### Задание 8. Кратные 7
Вводятся `a` и `b`. Выведи количество и сумму чисел из отрезка `[a; b]`, делящихся на 7.

## ★ Олимпиадная / творческая задача

### Задание 9. Пшеница на шахматной доске
По легенде, изобретатель шахмат попросил у царя в награду на 1-ю клетку 1 зерно пшеницы, на 2-ю — 2, на 3-ю — 4 зерна, ... (на каждую следующую клетку вдвое больше). Найди общее количество зёрен на 64 клетках.

### Задание 10. Проверка формулой Гаусса
Вводится `N`. Вычисли сумму от 1 до `N` и с помощью цикла, и по формуле `N * (N + 1) // 2`; если результаты равны, выведи «Гаусс был прав!».

## Домашнее задание

1. Вводится `N`. Найди сумму 1² + 2² + ... + N².
2. Введи свои четвертные оценки по 5 предметам и найди среднюю оценку. Если среднее ≥ 4.5, выведи «Отличник», если ≥ 3.5 — «Хорошист», иначе — «Нужно постараться».
3. Вводятся `a` и `n`. Вычисли `a` в степени `n` с помощью цикла, не используя `**`.
