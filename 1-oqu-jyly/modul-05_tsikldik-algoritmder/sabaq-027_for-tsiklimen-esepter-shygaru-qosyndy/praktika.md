# Сабақ 27. Практикалық тапсырмалар: қосынды, көбейтінді, орташа мән

## Базалық деңгей

### 1-тапсырма. 1-ден N-ге дейінгі қосынды
`N` енгізіледі. 1 + 2 + ... + N қосындысын шығар.

Мысал:
```text
N = 10
Қосынды: 55
```

### 2-тапсырма. Тақ сандардың қосындысы
1-ден 99-ға дейінгі барлық тақ сандардың қосындысын тап (`range` қадамын қолдан).

Жауабы: `2500`.

### 3-тапсырма. Факториал
`n` енгізіледі (0 ≤ n ≤ 20). `n!` мәнін есепте. Ескерту: `0! = 1`.

Мысал:
```text
n = 6
6! = 720
```

### 4-тапсырма. Апталық температура
Апта бойы (7 күн) Астанадағы ауа температурасы енгізіледі. Аптаның орташа температурасын бір ондық таңбамен шығар.

Мысал:
```text
1-күн: -5
2-күн: -8
3-күн: -3
4-күн: 0
5-күн: 2
6-күн: -1
7-күн: -6
Орташа температура: -3.0
```

### 5-тапсырма. Дүкен чегі
`n` тауар бар. Әр тауардың бағасы енгізіледі. Жалпы соманы және ең соңында «Төлеуге: ... теңге» деп шығар.

## Кеңейтілген деңгей

### 6-тапсырма. Бес деген баға
Сыныптағы `n` оқушының бағасы (2–5) енгізіледі. Бағдарлама:
- орташа бағаны;
- «5» алған оқушылар санын;
- «2» алған оқушылар санын шығарсын.

### 7-тапсырма. Депозит
Банкке `S` теңге салынды, жылдық пайыз `r`%. Әр жылдың соңында сома `r`% өседі. `n` жылдан кейінгі соманы тап және әр жылдың нәтижесін шығар.

Мысал (`S = 100000`, `r = 10`, `n = 3`):
```text
1-жыл: 110000.00
2-жыл: 121000.00
3-жыл: 133100.00
```

### 8-тапсырма. 7-ге еселілер
`a` және `b` енгізіледі. `[a; b]` аралығындағы 7-ге бөлінетін сандардың санын және қосындысын шығар.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Шахмат тақтасындағы бидай
Аңыз бойынша шахмат ойлап тапқан адам патшадан сыйлық ретінде 1-ұяшыққа 1 бидай, 2-ұяшыққа 2, 3-ұяшыққа 4 бидай, ... (әр келесі ұяшыққа екі есе көп) сұраған. 64 ұяшықтағы бидайлардың жалпы санын тап.

### 10-тапсырма. Гаусс формуласымен тексеру
`N` енгізіледі. 1-ден `N`-ге дейінгі қосындыны цикл арқылы да, `N * (N + 1) // 2` формуласы арқылы да есептеп, нәтижелер тең болса «Гаусс дұрыс айтқан!» деп шығар.

## Үй тапсырмасы

1. `N` енгізіледі. 1² + 2² + ... + N² қосындысын тап.
2. 5 пәннен алған тоқсандық бағаларыңды енгізіп, орташа бағаны тап. Орташа ≥ 4.5 болса «Үздік», ≥ 3.5 болса «Екпінді», әйтпесе «Тырысу керек» деп шығар.
3. `a` және `n` енгізіледі. `a` санының `n`-дәрежесін `**` қолданбай цикл арқылы есепте.

**3-тапсырма**
```python
n = int(input("n = "))
p = 1
for i in range(1, n + 1):
    p *= i
print(f"{n}! = {p}")
```
`n = 0` болғанда цикл орындалмайды, `p = 1` қалады — дұрыс.

**4-тапсырма**

```python
total = 0
for day in range(1, 8):

    total += t

```

**5-тапсырма**

```python
n = int(input("Тауар саны: "))
```

**6-тапсырма**
```python
n = int(input("Оқушылар саны: "))
total = 0
fives = 0
twos = 0
for i in range(n):
    g = int(input(f"{i + 1}-оқушы бағасы: "))
    total += g
    if g == 5:
        fives += 1
    elif g == 2:
        twos += 1
print(f"Орташа баға: {total / n:.2f}")
print("«5» саны:", fives)
print("«2» саны:", twos)
```

**7-тапсырма**
```python
s = float(input("Сома: "))
r = float(input("Пайыз: "))
n = int(input("Жыл саны: "))
for year in range(1, n + 1):
    s = s * (1 + r / 100)
    print(f"{year}-жыл: {s:.2f}")
```

**8-тапсырма**
```python
a = int(input("a = "))
b = int(input("b = "))
count = 0
s = 0
for x in range(a, b + 1):
    if x % 7 == 0:
        count += 1
        s += x
print("Саны:", count, "Қосындысы:", s)
```

**10-тапсырма**
