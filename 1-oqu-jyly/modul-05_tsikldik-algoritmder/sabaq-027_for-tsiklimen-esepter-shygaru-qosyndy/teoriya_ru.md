## 1. Составные операторы присваивания

В циклических задачах часто приходится изменять значение переменной. В Python для этого есть краткая запись:

| Полная запись | Краткая запись | Смысл |
|---|---|---|
| `s = s + x` | `s += x` | сложение |
| `s = s - x` | `s -= x` | вычитание |
| `p = p * x` | `p *= x` | умножение |
| `a = a / x` | `a /= x` | деление |
| `c = c + 1` | `c += 1` | увеличение на единицу |

```python
s = 10
s += 5
print(s)
s *= 2
print(s)
```
Результат:
```text
15
30
```

## 2. Накопитель и сумма

**Накопитель (accumulator)** — переменная, которая в ходе цикла постепенно накапливает значения.

Аналогия: копилка. Вначале в ней 0 тенге. Каждый день мы кладём в неё деньги. В конце в ней сумма всех положенных денег.

Алгоритм вычисления суммы:
1. Присваиваем накопителю начальное значение **0** (**до** цикла!).
2. В цикле прибавляем каждое число к накопителю.
3. **После** цикла выводим результат.

```python
s = 0                      # 1. начальное значение
for i in range(1, 101):    # 2. от 1 до 100
    s += i                 #    прибавляем каждое число
print("Сумма:", s)         # 3. результат
```
Результат:
```text
Сумма: 5050
```

### Трассировка (от 1 до 5)

```python
s = 0
for i in range(1, 6):
    s += i
print(s)
```

| Итерация | `i` | `s` (до) | `s` (после) |
|---|---|---|---|
| — | — | — | 0 |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

Результат: `15`.

**В Thonny** можно открыть окно «View → Variables» и в режиме «Debug» (значок жука) пошагово посмотреть, как меняются `s` и `i`.

### Сумма чисел, введённых с клавиатуры

```python
n = int(input("Сколько чисел введёте? "))
total = 0
for i in range(n):
    x = int(input(f"Число {i + 1}: "))
    total += x
print("Сумма:", total)
```
Пример:
```text
Сколько чисел введёте? 3
Число 1: 12
Число 2: 7
Число 3: 21
Сумма: 40
```

## 3. Произведение

При вычислении произведения начальное значение накопителя должно быть **1**. Почему? Если будет 0, то любое число, умноженное на 0, даст 0!

| Вид накопления | Начальное значение | Причина |
|---|---|---|
| Сумма | 0 | `0 + x = x` |
| Произведение | 1 | `1 * x = x` |
| Счётчик | 0 | ещё ничего не посчитано |

### Факториал

**Факториал** `n! = 1 · 2 · 3 · ... · n`. Например, `5! = 120`.

```python
n = int(input("n = "))
p = 1
for i in range(1, n + 1):
    p *= i
print(f"{n}! = {p}")
```
Пример:
```text
n = 5
5! = 120
```

В Python у целых чисел нет предела, поэтому можно вычислять даже очень большие числа, например `30!`:
```python
p = 1
for i in range(1, 31):
    p *= i
print(p)
```
Результат:
```text
265252859812191058636308480000000
```

### Степень
Вычислим `2` в степени `10` без операции `**`:
```python
result = 1
for i in range(10):
    result *= 2
print(result)
```
Результат:
```text
1024
```

## 4. Среднее значение

**Среднее арифметическое** = сумма всех чисел ÷ количество чисел.

```python
n = int(input("Сколько оценок? "))
total = 0
for i in range(n):
    grade = int(input(f"Оценка {i + 1}: "))
    total += grade
average = total / n
print(f"Средняя оценка: {average:.2f}")
```
Пример:
```text
Сколько оценок? 4
Оценка 1: 5
Оценка 2: 4
Оценка 3: 5
Оценка 4: 3
Средняя оценка: 4.25
```
`:.2f` — формат f-строки: 2 знака после запятой.

**Обрати внимание:** если `n = 0`, то `total / n` вызовет ошибку деления на ноль (`ZeroDivisionError`). Это можно проверить с помощью `if`:
```python
n = int(input("Сколько оценок? "))
if n > 0:
    total = 0
    for i in range(n):
        total += int(input("Оценка: "))
    print("Среднее:", total / n)
else:
    print("Оценок нет")
```

## 5. Сумма и подсчёт по условию

Используя `if` внутри цикла, можно суммировать или подсчитывать только числа, удовлетворяющие определённому условию.

**Счётчик (counter)** — переменная, которая считает, сколько раз выполнилось условие (`c += 1`).

```python
# Сумма и количество чётных чисел от 1 до 100
s = 0
count = 0
for i in range(1, 101):
    if i % 2 == 0:
        s += i
        count += 1
print("Количество чётных чисел:", count)
print("Их сумма:", s)
```
Результат:
```text
Количество чётных чисел: 50
Их сумма: 2550
```

### Отдельный подсчёт положительных и отрицательных чисел

```python
n = int(input("Сколько чисел? "))
positive = 0
negative = 0
for i in range(n):
    x = int(input())
    if x > 0:
        positive += 1
    elif x < 0:
        negative += 1
print("Положительных:", positive, "Отрицательных:", negative)
```

## 6. Сумма ряда дробей (интересное применение цикла)

Используя переменную цикла в формуле, можно вычислять различные ряды:
```python
# 1 + 1/2 + 1/3 + ... + 1/10
s = 0
for k in range(1, 11):
    s += 1 / k
print(round(s, 4))
```
Результат:
```text
2.929
```

## Частые ошибки

**1. Обнуление накопителя внутри цикла**
```python
for i in range(1, 6):
    s = 0          # ОШИБКА: на каждой итерации возвращается к 0
    s += i
print(s)           # выводится 5, а не 15
```
Правильно: `s = 0` — **до** цикла.

**2. Начинать произведение с 0**
```python
p = 0
for i in range(1, 6):
    p *= i
print(p)   # 0 — ошибка!
```
Правильно: `p = 1`.

**3. Вывод результата внутри цикла**
```python
s = 0
for i in range(1, 4):
    s += i
    print(s)   # выводятся промежуточные результаты: 1, 3, 6
```
Если нужен только итоговый результат, `print` записывается без отступа (после цикла).

**4. Накопитель вообще не определён**
```text
for i in range(5):
    s += i
```
`NameError: name 's' is not defined`.

**5. Вычисление среднего внутри цикла** — сумма ещё не накоплена полностью, поэтому среднее нужно вычислять после цикла.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Накопитель | Переменная, постепенно накапливающая значения (сумма, произведение) |
| Счётчик | Переменная, считающая, сколько раз произошло событие (`c += 1`) |
| `+=`, `*=` | Составные операторы присваивания |
| Факториал `n!` | Произведение чисел от 1 до n |
| Среднее значение | Сумма ÷ количество |
| Начальное значение | Значение, присваиваемое накопителю до цикла (0 или 1) |

## Примечание

- Сумму последовательности чисел можно найти и встроенной функцией: `sum(range(1, 101))` → `5050`. Для произведения в Python 3.8+ есть `math.prod()`: `math.prod(range(1, 6))` → `120`, а для факториала — `math.factorial(n)`.
- Оператор `/` всегда возвращает `float` (`10 / 2` → `5.0`). Если нужно целое частное, используйте `//`.
- При сложении дробных чисел возможна ошибка округления: `0.1 + 0.2` → `0.30000000000000004`. Выводите результат через `round()` или `:.2f`; если важна точность, используйте `math.fsum()`.
- Не называйте переменные именами встроенных функций (`sum = 0`, `max = 0`) — после этого функция `sum()` перестанет работать.
- Начиная с Python 3.12, `sum()` складывает дробные числа точнее (алгоритм Неймайера).
- Документация: https://docs.python.org/3/library/functions.html#sum, https://docs.python.org/3/library/math.html
