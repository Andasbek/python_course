# Сабақ 29. Практикалық тапсырмалар: меню және шексіз циклден шығу

## Базалық деңгей

### 1-тапсырма. «Тағы бір рет?»
Пайдаланушы санды енгізеді, бағдарлама оның квадратын шығарады да «Жалғастырамыз ба? (иә/жоқ)» деп сұрайды. «жоқ» енгізілгенде бағдарлама «Сау бол!» деп аяқталады.

### 2-тапсырма. Эхо-бот
`while True` циклінде пайдаланушы енгізген сөзді «Бот: <сөз>» түрінде қайталайтын бот жаз. «сау бол» енгізілгенде бот «Бот: Кездескенше!» деп жауап беріп, жұмысын аяқтайды.

### 3-тапсырма. Температура түрлендіргіш
Мәзір:
```text
1. Цельсийден Фаренгейтке
2. Фаренгейттен Цельсийге
0. Шығу
```
Формулалар: `F = C * 9 / 5 + 32`, `C = (F - 32) * 5 / 9`. Қате таңдауға «Қате таңдау!» деп жауап бер.

### 4-тапсырма. Қарапайым калькулятор
Мәзір арқылы `+`, `-`, `*`, `/` амалдарын таңдап, екі санмен есептейтін калькулятор жаз. 0-ге бөлуге тырысса — «Нөлге бөлуге болмайды!» хабары. «0» — шығу.

## Кеңейтілген деңгей

### 5-тапсырма. Кофе автоматы
Автоматта: Американо — 600 тг, Капучино — 800 тг, Какао — 500 тг. Пайдаланушы сусынды таңдайды, автомат сұралған ақшаны алады (`input`), қайтарымды шығарады. Ақша жетпесе — «Ақша жеткіліксіз». Соңында (шығу кезінде) автомат неше сусын сатқанын және жалпы түсімді шығарсын.

### 6-тапсырма. Ұпай жинау ойыны
Ойыншының бастапқы ұпайы 0. Мәзір:
```text
1 - Жаттығу жасау (+10 ұпай)
2 - Демалу (+2 ұпай)
3 - Ұпайды көру
0 - Ойынды аяқтау
```
Ұпай 50-ге жеткенде «Деңгей көтерілді!» деп шығып, ойын автоматты түрде аяқталсын (жалаушаны қолдан).

### 7-тапсырма. Пароль үш әрекетпен
Дұрыс пароль — `qazaq2026`. Пайдаланушыда 3 әрекет бар. Әр қате әрекеттен кейін неше мүмкіндік қалғанын хабарла. 3 рет қате болса — «Аккаунт бұғатталды».

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. «Кітапхана есептегіші»
Мәзір: «1 — кітап алу», «2 — кітап қайтару», «3 — қалдықты көру», «0 — шығу». Кітапханада бастапқыда 20 кітап. Қолда жоқ кітапты беруге, ал 20-дан көп кітап қайтаруға болмайды. Шығу кезінде барлық операциялар санын шығар.

### 9-тапсырма. Өз мәзіріңді ойлап тап
Кем дегенде 4 пункті бар, бағдарлама күйін (айнымалыны) өзгертетін, қате енгізуді өңдейтін өз мәзір бағдарламаңды ойлап тауып жаз (мысалы: «Тамагочи», «Ғарыш станциясы», «Мектеп асханасы»).

## Үй тапсырмасы

1. «Бағалар журналы»: мәзір арқылы «1 — баға қосу», «2 — орташа бағаны көру», «0 — шығу». Бағалардың қосындысы мен санын айнымалыларда сақта.
2. 9-тапсырма бойынша өз мәзір бағдарламаңды аяқтап, келесі сабақта сыныпқа көрсетуге дайында.

**4-тапсырма**
```python
while True:
    op = input("Амал (+ - * /), 0 — шығу: ")
    if op == "0":
        print("Сау болыңыз!")
        break
    if op != "+" and op != "-" and op != "*" and op != "/":
        print("Мұндай амал жоқ!")
    else:
        a = float(input("a = "))
        b = float(input("b = "))
        if op == "+":
            print(a + b)
        elif op == "-":
            print(a - b)
        elif op == "*":
            print(a * b)
        elif b == 0:
            print("Нөлге бөлуге болмайды!")
        else:
            print(a / b)
```
Ескерту: келесі сабақта (30-сабақ) осы бағдарламаны `continue` операторымен ықшамдауды көрсетуге болады.

**5-тапсырма**
```python
sold = 0
income = 0
while True:
    print("1 - Американо (600)  2 - Капучино (800)  3 - Какао (500)  0 - Шығу")
    choice = input("> ")
    if choice == "0":
        break
    if choice == "1":
        price = 600
    elif choice == "2":
        price = 800
    elif choice == "3":
        price = 500
    else:
        print("Қате таңдау!")
        price = 0
    if price > 0:
        money = int(input(f"Бағасы {price} тг. Ақша салыңыз: "))
        if money < price:
            print("Ақша жеткіліксіз")
        else:
            print("Сусыныңызды алыңыз! Қайтарым:", money - price)
            sold += 1
            income += price
print("Сатылды:", sold, "Түсім:", income, "тг")
```

**8-тапсырма**
```python
books = 20
operations = 0
while True:
    choice = input("1 - алу, 2 - қайтару, 3 - қалдық, 0 - шығу: ")
    if choice == "1":
        if books > 0:
            books -= 1
            operations += 1
            print("Кітап берілді.")
        else:
            print("Кітап қалмады!")
    elif choice == "2":
        if books < 20:
            books += 1
            operations += 1
            print("Кітап қабылданды.")
        else:
            print("Барлық кітап орнында!")
    elif choice == "3":
        print("Қалдық:", books)
    elif choice == "0":
        break
    else:
        print("Қате таңдау!")
print("Операциялар саны:", operations)
```
