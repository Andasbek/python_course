## 1. Пайдаланушы басқаратын цикл

`while` циклі белгілі бір мәнге (мысалы, 0) жеткенде ғана емес, пайдаланушының шешімі бойынша да тоқтай алады.

```python
answer = "иә"
while answer == "иә":
    a = int(input("Бірінші сан: "))
    b = int(input("Екінші сан: "))
    print("Қосындысы:", a + b)
    answer = input("Тағы есептейміз бе? (иә/жоқ): ")
print("Сау болыңыз!")
```
Мысал:
```text
Бірінші сан: 3
Екінші сан: 4
Қосындысы: 7
Тағы есептейміз бе? (иә/жоқ): иә
Бірінші сан: 10
Екінші сан: 5
Қосындысы: 15
Тағы есептейміз бе? (иә/жоқ): жоқ
Сау болыңыз!
```

Мұнда шарт айнымалысы (`answer`) алдын ала `"иә"` мәнін алады — цикл кем дегенде бір рет орындалуы үшін.

## 2. Жалауша (флаг) айнымалысы

**Жалауша (флаг, flag)** — циклдің жалғасу-жалғаспауын білдіретін `bool` типті айнымалы. Аналогия: теміржол семафоры — жасыл (True) болса пойыз жүреді, қызыл (False) болса тоқтайды.

```python
running = True
while running:
    cmd = input("Пәрмен (сәлем/уақыт/шығу): ")
    if cmd == "сәлем":
        print("Сәлем, досым!")
    elif cmd == "уақыт":
        print("Қазір — Python уақыты!")
    elif cmd == "шығу":
        running = False
    else:
        print("Мұндай пәрмен жоқ.")
print("Бағдарлама аяқталды.")
```

Жалаушаның артықшылығы — циклден шығудың бірнеше себебін бір айнымалы арқылы басқаруға болады.

## 3. Шексіз цикл `while True` және одан шығу

`while True:` — шарты әрқашан ақиқат цикл, яғни **әдейі** жазылған шексіз цикл. Ол серверлерде, ойындарда, мәзірлерде қолданылады. Одан шығу үшін `break` операторы қолданылады — ол циклді **дереу** тоқтатады.

```python
while True:
    text = input("Сөз енгізіңіз (стоп — шығу): ")
    if text == "стоп":
        break
    print("Сіз енгіздіңіз:", text)
print("Цикл тоқтады.")
```
Мысал:
```text
Сөз енгізіңіз (стоп — шығу): Алматы
Сіз енгіздіңіз: Алматы
Сөз енгізіңіз (стоп — шығу): Астана
Сіз енгіздіңіз: Астана
Сөз енгізіңіз (стоп — шығу): стоп
Цикл тоқтады.
```

Шексіз циклден шығу тәсілдері:

| Тәсіл | Қалай | Қашан ыңғайлы |
|---|---|---|
| Шарт айнымалысы | `while answer == "иә":` | Бір қарапайым шарт |
| Жалауша | `running = False` | Бірнеше жерден шығу керек болғанда |
| `break` | `while True:` + `if ...: break` | Шығу шарты цикл ортасында тексерілгенде |

## 4. Мәтіндік меню құру

Меню бағдарламасының үлгісі:
1. Мәзірді экранға шығару;
2. Пайдаланушының таңдауын оқу;
3. `if...elif...else` арқылы таңдалған әрекетті орындау;
4. «Шығу» таңдалмаса — 1-қадамға оралу.

```python
while True:
    print()
    print("===== МӘЗІР =====")
    print("1. Шаршының ауданы")
    print("2. Тіктөртбұрыштың ауданы")
    print("3. Шеңбердің ауданы")
    print("0. Шығу")
    choice = input("Таңдауыңыз: ")

    if choice == "1":
        a = float(input("Қабырғасы: "))
        print("Ауданы:", a * a)
    elif choice == "2":
        a = float(input("Ұзындығы: "))
        b = float(input("Ені: "))
        print("Ауданы:", a * b)
    elif choice == "3":
        r = float(input("Радиусы: "))
        print(f"Ауданы: {3.14159 * r * r:.2f}")
    elif choice == "0":
        print("Сау болыңыз!")
        break
    else:
        print("Қате таңдау! 0–3 аралығындағы санды енгізіңіз.")
```

**Неліктен `choice`-ты `int`-ке түрлендірмедік?** Егер пайдаланушы әріп енгізсе, `int("а")` қате береді де, бағдарлама құлайды. Жол ретінде салыстыру (`"1"`, `"2"`) — қауіпсіз.

## 5. Бағдарлама күйін сақтау: «Банкомат»

Мәзір бағдарламасында айнымалылар цикл бойы өз мәнін сақтайды. Бұл — бағдарлама **күйі**.

```python
balance = 50000
pin = input("PIN-код: ")
attempts = 1
while pin != "1234" and attempts < 3:
    print("PIN қате!")
    pin = input("PIN-код: ")
    attempts += 1

if pin != "1234":
    print("Карта бұғатталды.")
else:
    working = True
    while working:
        print()
        print("1 - Баланс  2 - Салу  3 - Шешу  0 - Шығу")
        choice = input("> ")
        if choice == "1":
            print(f"Балансыңыз: {balance} теңге")
        elif choice == "2":
            amount = int(input("Сома: "))
            if amount > 0:
                balance += amount
                print("Салынды. Жаңа баланс:", balance)
            else:
                print("Сома оң болуы керек!")
        elif choice == "3":
            amount = int(input("Сома: "))
            if amount > balance:
                print("Қаражат жеткіліксіз!")
            elif amount <= 0:
                print("Сома оң болуы керек!")
            else:
                balance -= amount
                print("Ақшаңызды алыңыз. Қалдық:", balance)
        elif choice == "0":
            working = False
        else:
            print("Қате таңдау!")
    print("Картаңызды алыңыз. Сау болыңыз!")
```

Бұл бағдарлама бірнеше құралды біріктіреді: айнымалылар, `input`, тип түрлендіру, `if...elif...else`, құрама шарт `and`, `while` циклі және жалауша.

## 6. while-мен басқа есептер: «Сан қатары» статистикасы

```python
count = 0
total = 0
biggest = 0
while True:
    x = int(input("Оң сан (0 — аяқтау): "))
    if x == 0:
        break
    count += 1
    total += x
    if x > biggest:
        biggest = x
if count > 0:
    print("Саны:", count, "Қосындысы:", total, "Ең үлкені:", biggest)
else:
    print("Сандар енгізілмеді")
```

## Жиі кездесетін қателер

**1. Мәзірді циклден тыс шығару**
```text
print("1. ... 2. ... 0. Шығу")
while True:
    choice = input()
```
Мәзір тек бір рет көрсетіледі. Мәзірді цикл **ішіне** жаз.

**2. Санмен және жолмен салыстыруды шатастыру**
```python
choice = input("Таңдау: ")
if choice == 1:        # ешқашан True болмайды: "1" != 1
    print("Бірінші")
```
Дұрысы: `if choice == "1":`.

**3. Шығу жолын ұмыту** — `while True:` ішінде `break` немесе жалаушаны өзгерту жоқ болса, бағдарлама ешқашан тоқтамайды.

**4. Күй айнымалысын цикл ішінде қайта анықтау**
```text
while True:
    balance = 50000     # әр айналымда баланс қайта 50000 болады!
```
Бастапқы мәнді циклге **дейін** бер.

**5. `else` тармағын ұмыту** — қате таңдауға бағдарлама ештеңе айтпайды, пайдаланушы не болғанын түсінбейді.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Пайдаланушы басқаратын цикл | Жалғасу/тоқтау туралы шешімді пайдаланушы қабылдайтын цикл |
| Жалауша (флаг) | Цикл жалғасуын басқаратын `True/False` айнымалы |
| `while True` | Әдейі жазылған шексіз цикл |
| `break` | Циклді дереу тоқтататын оператор |
| Мәтіндік меню | Нөмірленген әрекеттер тізімі және таңдау |
| Бағдарлама күйі | Цикл бойы сақталатын айнымалылар мәні (баланс, ұпай) |

## Ескерту

- Пайдаланушы жауабын салыстырмас бұрын қалыпқа келтірген дұрыс: `input().strip().lower()` — артық бос орындар мен бас әріптер әсер етпейді (`" Иә "` → `"иә"`).
- Python 3.10+ нұсқасында мәзір таңдауын `match`/`case` арқылы жазуға болады: `match choice: case "1": ... case "0": break case _: print("Қате")`. Бұл ұзын `if...elif` тізбегіне балама.
- `while True:` ішіндегі `break` тек ең ішкі циклден шығады; кірістірілген циклдерде бүкіл бағдарламадан шығу үшін жалауша немесе функциядағы `return` қолданылады.
- Ақшаны `float` түрінде сақтамаған дұрыс (дөңгелектеу қателігі): бүтін тиындармен (`int`) немесе `decimal.Decimal` модулімен жұмыс істеңіз.
- Шексіз циклді Ctrl+C арқылы тоқтатқанда `KeyboardInterrupt` ерекшелігі шығады; оны `try/except KeyboardInterrupt` арқылы ұстап, бағдарламаны жайлап аяқтауға болады.
- Құжаттама: https://docs.python.org/3/tutorial/controlflow.html#match-statements
