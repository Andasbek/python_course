## 1. Цикл, управляемый пользователем

Цикл `while` может останавливаться не только при достижении определённого значения (например, 0), но и по решению пользователя.

```python
answer = "да"
while answer == "да":
    a = int(input("Первое число: "))
    b = int(input("Второе число: "))
    print("Сумма:", a + b)
    answer = input("Посчитаем ещё? (да/нет): ")
print("До свидания!")
```
Пример:
```text
Первое число: 3
Второе число: 4
Сумма: 7
Посчитаем ещё? (да/нет): да
Первое число: 10
Второе число: 5
Сумма: 15
Посчитаем ещё? (да/нет): нет
До свидания!
```

Здесь переменная условия (`answer`) заранее получает значение `"да"` — чтобы цикл выполнился хотя бы один раз.

## 2. Переменная-флажок (флаг)

**Флажок (флаг, flag)** — переменная типа `bool`, показывающая, продолжать цикл или нет. Аналогия: железнодорожный семафор — если зелёный (True), поезд едет, если красный (False) — останавливается.

```python
running = True
while running:
    cmd = input("Команда (привет/время/выход): ")
    if cmd == "привет":
        print("Привет, друг!")
    elif cmd == "время":
        print("Сейчас — время Python!")
    elif cmd == "выход":
        running = False
    else:
        print("Такой команды нет.")
print("Программа завершена.")
```

Преимущество флага — несколько причин выхода из цикла можно контролировать одной переменной.

## 3. Бесконечный цикл `while True` и выход из него

`while True:` — цикл, условие которого всегда истинно, то есть **намеренно** написанный бесконечный цикл. Он применяется в серверах, играх, меню. Для выхода из него используется оператор `break` — он **немедленно** останавливает цикл.

```python
while True:
    text = input("Введите слово (стоп — выход): ")
    if text == "стоп":
        break
    print("Вы ввели:", text)
print("Цикл остановлен.")
```
Пример:
```text
Введите слово (стоп — выход): Алматы
Вы ввели: Алматы
Введите слово (стоп — выход): Астана
Вы ввели: Астана
Введите слово (стоп — выход): стоп
Цикл остановлен.
```

Способы выхода из бесконечного цикла:

| Способ | Как | Когда удобен |
|---|---|---|
| Переменная условия | `while answer == "да":` | Одно простое условие |
| Флаг | `running = False` | Когда выходить нужно из нескольких мест |
| `break` | `while True:` + `if ...: break` | Когда условие выхода проверяется в середине цикла |

## 4. Создание текстового меню

Шаблон программы с меню:
1. Вывести меню на экран;
2. Прочитать выбор пользователя;
3. Выполнить выбранное действие с помощью `if...elif...else`;
4. Если не выбран «Выход» — вернуться к шагу 1.

```python
while True:
    print()
    print("===== МЕНЮ =====")
    print("1. Площадь квадрата")
    print("2. Площадь прямоугольника")
    print("3. Площадь круга")
    print("0. Выход")
    choice = input("Ваш выбор: ")

    if choice == "1":
        a = float(input("Сторона: "))
        print("Площадь:", a * a)
    elif choice == "2":
        a = float(input("Длина: "))
        b = float(input("Ширина: "))
        print("Площадь:", a * b)
    elif choice == "3":
        r = float(input("Радиус: "))
        print(f"Площадь: {3.14159 * r * r:.2f}")
    elif choice == "0":
        print("До свидания!")
        break
    else:
        print("Неверный выбор! Введите число от 0 до 3.")
```

**Почему мы не преобразовали `choice` в `int`?** Если пользователь введёт букву, `int("а")` вызовет ошибку, и программа аварийно завершится. Сравнение как строк (`"1"`, `"2"`) — безопасно.

## 5. Сохранение состояния программы: «Банкомат»

В программе с меню переменные сохраняют свои значения на протяжении всего цикла. Это — **состояние** программы.

```python
balance = 50000
pin = input("PIN-код: ")
attempts = 1
while pin != "1234" and attempts < 3:
    print("Неверный PIN!")
    pin = input("PIN-код: ")
    attempts += 1

if pin != "1234":
    print("Карта заблокирована.")
else:
    working = True
    while working:
        print()
        print("1 - Баланс  2 - Внести  3 - Снять  0 - Выход")
        choice = input("> ")
        if choice == "1":
            print(f"Ваш баланс: {balance} тенге")
        elif choice == "2":
            amount = int(input("Сумма: "))
            if amount > 0:
                balance += amount
                print("Внесено. Новый баланс:", balance)
            else:
                print("Сумма должна быть положительной!")
        elif choice == "3":
            amount = int(input("Сумма: "))
            if amount > balance:
                print("Недостаточно средств!")
            elif amount <= 0:
                print("Сумма должна быть положительной!")
            else:
                balance -= amount
                print("Заберите деньги. Остаток:", balance)
        elif choice == "0":
            working = False
        else:
            print("Неверный выбор!")
    print("Заберите карту. До свидания!")
```

Эта программа объединяет сразу несколько инструментов: переменные, `input`, преобразование типов, `if...elif...else`, составное условие `and`, цикл `while` и флаг.

## 6. Другие задачи с while: статистика «Ряд чисел»

```python
count = 0
total = 0
biggest = 0
while True:
    x = int(input("Положительное число (0 — конец): "))
    if x == 0:
        break
    count += 1
    total += x
    if x > biggest:
        biggest = x
if count > 0:
    print("Количество:", count, "Сумма:", total, "Наибольшее:", biggest)
else:
    print("Числа не введены")
```

## Частые ошибки

**1. Вывод меню вне цикла**
```text
print("1. ... 2. ... 0. Выход")
while True:
    choice = input()
```
Меню показывается только один раз. Пиши меню **внутри** цикла.

**2. Путаница при сравнении с числом и строкой**
```python
choice = input("Выбор: ")
if choice == 1:        # никогда не будет True: "1" != 1
    print("Первый")
```
Правильно: `if choice == "1":`.

**3. Забыли путь выхода** — если внутри `while True:` нет `break` или изменения флага, программа никогда не остановится.

**4. Переопределение переменной состояния внутри цикла**
```text
while True:
    balance = 50000     # на каждом проходе баланс снова становится 50000!
```
Начальное значение задавай **до** цикла.

**5. Забыли ветку `else`** — на неверный выбор программа ничего не сообщает, и пользователь не понимает, что произошло.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Цикл, управляемый пользователем | Цикл, в котором решение о продолжении/остановке принимает пользователь |
| Флажок (флаг) | Переменная `True/False`, управляющая продолжением цикла |
| `while True` | Намеренно написанный бесконечный цикл |
| `break` | Оператор, немедленно останавливающий цикл |
| Текстовое меню | Список пронумерованных действий и выбор |
| Состояние программы | Значения переменных, сохраняющиеся на протяжении цикла (баланс, очки) |

## Примечание

- Ответ пользователя лучше нормализовать перед сравнением: `input().strip().lower()` — лишние пробелы и заглавные буквы не мешают (`" Да "` → `"да"`).
- В Python 3.10+ выбор пункта меню можно записать через `match`/`case`: `match choice: case "1": ... case "0": break case _: print("Ошибка")`. Это альтернатива длинной цепочке `if...elif`.
- `break` внутри `while True:` выходит только из самого внутреннего цикла; чтобы выйти из вложенных циклов, используют флаг или `return` в функции.
- Деньги лучше не хранить во `float` (ошибки округления): работайте с целыми тиынами (`int`) или модулем `decimal.Decimal`.
- При остановке бесконечного цикла по Ctrl+C возникает исключение `KeyboardInterrupt`; его можно перехватить `try/except KeyboardInterrupt` и аккуратно завершить программу.
- Документация: https://docs.python.org/3/tutorial/controlflow.html#match-statements
