# Урок 29. Практические задания: меню и выход из бесконечного цикла

## Базовый уровень

### Задание 1. «Ещё раз?»
Пользователь вводит число, программа выводит его квадрат и спрашивает «Продолжим? (да/нет)». Если введено «нет», программа завершается словами «Пока!».

### Задание 2. Эхо-бот
Напиши бота, который в цикле `while True` повторяет введённое пользователем слово в виде «Бот: <слово>». Если введено «пока», бот отвечает «Бот: До встречи!» и завершает работу.

### Задание 3. Конвертер температуры
Меню:
```text
1. Из Цельсия в Фаренгейт
2. Из Фаренгейта в Цельсий
0. Выход
```
Формулы: `F = C * 9 / 5 + 32`, `C = (F - 32) * 5 / 9`. На неверный выбор отвечай «Неверный выбор!».

### Задание 4. Простой калькулятор
Напиши калькулятор, который через меню позволяет выбрать операцию `+`, `-`, `*`, `/` и вычисляет её для двух чисел. При попытке деления на 0 — сообщение «Делить на ноль нельзя!». «0» — выход.

## Продвинутый уровень

### Задание 5. Кофейный автомат
В автомате: Американо — 600 тг, Капучино — 800 тг, Какао — 500 тг. Пользователь выбирает напиток, автомат принимает деньги (`input`) и выдаёт сдачу. Если денег не хватает — «Недостаточно денег». В конце (при выходе) автомат должен вывести, сколько напитков продано, и общую выручку.

### Задание 6. Игра «Набери очки»
Начальное количество очков игрока — 0. Меню:
```text
1 - Тренироваться (+10 очков)
2 - Отдыхать (+2 очка)
3 - Посмотреть очки
0 - Завершить игру
```
Когда очки достигнут 50, вывести «Уровень повышен!», и игра должна автоматически завершиться (используй флаг).

### Задание 7. Пароль с тремя попытками
Правильный пароль — `qazaq2026`. У пользователя 3 попытки. После каждой неверной попытки сообщай, сколько попыток осталось. Если 3 раза неверно — «Аккаунт заблокирован».

## ★ Олимпиадная / творческая задача

### Задание 8. «Библиотечный учёт»
Меню: «1 — взять книгу», «2 — вернуть книгу», «3 — посмотреть остаток», «0 — выход». Изначально в библиотеке 20 книг. Нельзя выдать книгу, которой нет в наличии, и нельзя вернуть больше 20 книг. При выходе выведи общее количество операций.

### Задание 9. Придумай своё меню
Придумай и напиши свою программу с меню: не менее 4 пунктов, изменяет состояние программы (переменную), обрабатывает неверный ввод (например: «Тамагочи», «Космическая станция», «Школьная столовая»).

## Домашнее задание

1. «Журнал оценок»: через меню «1 — добавить оценку», «2 — посмотреть среднюю оценку», «0 — выход». Храни сумму и количество оценок в переменных.
2. Доработай свою программу с меню из задания 9 и подготовься показать её классу на следующем уроке.

**Задание 4**
```python
while True:
    op = input("Операция (+ - * /), 0 — выход: ")
    if op == "0":
        print("До свидания!")
        break
    if op != "+" and op != "-" and op != "*" and op != "/":
        print("Такой операции нет!")
    else:
        a = float(input("a = "))
        b = float(input("b = "))
        if op == "+":
            print(a + b)
        elif op == "-":
            print(a - b)
        elif op == "*":
            print(a * b)
        elif b == 0:
            print("Делить на ноль нельзя!")
        else:
            print(a / b)
```

**Задание 5**
```python
sold = 0
income = 0
while True:
    print("1 - Американо (600)  2 - Капучино (800)  3 - Какао (500)  0 - Выход")
    choice = input("> ")
    if choice == "0":
        break
    if choice == "1":
        price = 600
    elif choice == "2":
        price = 800
    elif choice == "3":
        price = 500
    else:
        print("Неверный выбор!")
        price = 0
    if price > 0:
        money = int(input(f"Цена {price} тг. Внесите деньги: "))
        if money < price:
            print("Недостаточно денег")
        else:
            print("Заберите напиток! Сдача:", money - price)
            sold += 1
            income += price
print("Продано:", sold, "Выручка:", income, "тг")
```

```python
books = 20
operations = 0

        if books > 0:
            books -= 1
            operations += 1

            print("Книг не осталось!")

            books += 1
            operations += 1
            print("Книга принята.")
        else:
            print("Все книги на месте!")
    elif choice == "3":
        print("Остаток:", books)
    elif choice == "0":
        break
    else:
        print("Неверный выбор!")
print("Количество операций:", operations)
```
