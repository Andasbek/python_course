# Сабақ 30. Практикалық тапсырмалар: break және continue

## Базалық деңгей

### 1-тапсырма. Нәтижені болжа
Компьютерсіз әр кодтың нәтижесін жаз, содан кейін тексер:
```python
# а)
for i in range(1, 8):
    if i == 4:
        break
    print(i, end=" ")
print()

# ә)
for i in range(1, 8):
    if i == 4:
        continue
    print(i, end=" ")
print()

# б)
k = 0
while k < 20:
    k += 3
    if k % 2 == 0:
        continue
    print(k, end=" ")
print()
```

### 2-тапсырма. Бірінші бөлінетін сан
`a`, `b` және `d` енгізіледі. `[a; b]` аралығындағы `d`-ға бөлінетін **бірінші** санды тап. Ондай сан болмаса «Табылмады» деп шығар (`for...else` қолдан).

### 3-тапсырма. 7-сіз санау
1-ден 30-ға дейінгі сандарды шығар, бірақ 7-ге бөлінетін сандарды өткізіп жібер (`continue`).

### 4-тапсырма. Жай сан ба?
Натурал сан енгізіледі. Оның жай сан екенін не емес екенін анықта (`break` қолдан).

### 5-тапсырма. Тек жұп сандардың қосындысы
Пайдаланушы 0 енгізгенше сандар енгізеді (`while True` + `break`). Тек жұп сандарды қос (тақ сандарды `continue` арқылы өткіз).

## Кеңейтілген деңгей

### 6-тапсырма. Жай сандар тізбегі
`N` енгізіледі. 2-ден `N`-ге дейінгі барлық жай сандарды шығар.

**Кеңес:** сыртқы цикл — сандар бойынша, ішкі — бөлгіштер бойынша, ішкі циклде `break` және `else`. (Кірістірілген циклдерді келесі сабақта толық өтеміз — бұл соған дайындық.)

### 7-тапсырма. Тест бағдарламасы
Бағдарлама пайдаланушыдан `7 * 8` нәтижесін сұрайды. Пайдаланушы «бас тарту» деп жазса — бағдарлама дұрыс жауапты айтып, тоқтайды. Дұрыс жауап берсе — «Дұрыс! Әрекет саны: ...». Қате болса — қайта сұрайды.

**Кеңес:** жауапты алдымен жол ретінде «бас тарту»-мен салыстыр, содан кейін ғана `int`-ке айналдыр.

### 8-тапсырма. Бақылау нүктесі
Жол бойындағы көліктердің жылдамдығы енгізіледі (0 — аяқтау). Жылдамдығы 0-ден аз немесе 300-ден көп болса «Қате өлшем» деп өткізіп жібер. 90 км/сағ-тан асқан көліктер санын және орташа жылдамдықты шығар.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Бақытты билет
Автобус билетінің нөмірі 6 таңбалы. Сол жақтағы үш цифрдың қосындысы оң жақтағы үш цифрдың қосындысына тең болса, билет «бақытты» саналады. `N` енгізіледі (100000 ≤ N ≤ 999999). `N`-нен бастап **бірінші** бақытты билетті тап.

### 10-тапсырма. Мінсіз сан
Мінсіз сан — өзінен басқа бөлгіштерінің қосындысына тең сан (6 = 1 + 2 + 3). 1-ден 10 000-ға дейінгі мінсіз сандарды тап. Бірінші мінсіз сан 1000-нан асқанда іздеуді `break` арқылы тоқтат.

## Үй тапсырмасы

1. `N` енгізіледі. `N`-нен үлкен бірінші жай санды тап.
2. Пайдаланушы сандар енгізеді. Енгізілген сан 100-ден асса — бағдарлама тоқтайды. Теріс сандар есепке алынбайды. Қалған сандардың санын және қосындысын шығар.
3. Өткен сабақтағы мәзір бағдарламаңды `while True` және `break` арқылы қайта жаз.

count = 0

fast = 0

**9-тапсырма**
```python
n = int(input("Билет нөмірі: "))
while n <= 999999:
    left = n // 1000
    right = n % 1000
    s1 = left // 100 + left // 10 % 10 + left % 10
    s2 = right // 100 + right // 10 % 10 + right % 10
    if s1 == s2:
        print("Бақытты билет:", n)
        break
    n += 1
```
