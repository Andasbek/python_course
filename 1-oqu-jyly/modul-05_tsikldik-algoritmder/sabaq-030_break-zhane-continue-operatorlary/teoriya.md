## 1. break операторы

`break` — циклді **дереу және толығымен** тоқтатады. Бағдарлама циклден кейінгі командаға көшеді.

```python
for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("Цикл тоқтады")
```
Нәтижесі:
```text
1
2
3
4
Цикл тоқтады
```
`i = 5` болғанда `break` орындалып, цикл аяқталды; 5 және одан кейінгі сандар шықпады.

### Іздеу есебі: бірінші сәйкес элементті табу
«100-ден 200-ге дейінгі 17-ге бөлінетін **бірінші** санды тап»:
```python
for n in range(100, 201):
    if n % 17 == 0:
        print("Табылды:", n)
        break
```
Нәтижесі:
```text
Табылды: 102
```
`break`-сіз цикл 17-ге бөлінетін барлық сандарды шығарар еді.

### while True + break
Шығу шарты цикл ортасында тексерілетін жағдайларда қолданылады. Мысалы, пайдаланушы оң сан енгізгенше сұрау:
```python
while True:
    x = int(input("Оң сан енгізіңіз: "))
    if x > 0:
        break
    print("Бұл оң сан емес, қайталаңыз.")
print("Рахмет, сіз енгіздіңіз:", x)
```

### Жай санды тексеру
**Жай сан** — тек 1-ге және өзіне бөлінетін 1-ден үлкен сан (2, 3, 5, 7, 11, ...). Бірінші бөлгіш табылғанда тексеруді тоқтатуға болады:
```python
n = int(input("Сан: "))
is_prime = n > 1
for d in range(2, n):
    if n % d == 0:
        is_prime = False
        print("Бөлгіш табылды:", d)
        break
if is_prime:
    print(n, "— жай сан")
else:
    print(n, "— жай сан емес")
```
Мысал:
```text
Сан: 91
Бөлгіш табылды: 7
91 — жай сан емес
```

## 2. continue операторы

`continue` — циклдің **ағымдағы итерациясының қалған бөлігін өткізіп жібереді** де, **келесі итерацияға** көшеді. Цикл тоқтамайды!

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    print(i, end=" ")
print()
```
Нәтижесі:
```text
1 2 4 5 7 8 10 
```
3, 6, 9 сандарында `continue` орындалды, сондықтан `print` өткізіліп жіберілді.

### Теріс сандарды елемеу
```python
total = 0
for i in range(5):
    x = int(input("Сан: "))
    if x < 0:
        print("Теріс сан есепке алынбайды")
        continue
    total += x
print("Оң сандардың қосындысы:", total)
```

### while циклінде continue — абай болыңдар!
```python
i = 0
while i < 10:
    i += 1              # өзгерісті continue-дан БҰРЫН жазамыз
    if i % 2 == 0:
        continue
    print(i, end=" ")
print()
```
Нәтижесі:
```text
1 3 5 7 9 
```
Егер `i += 1` жолы `continue`-дан кейін тұрса, жұп `i` мәнінде ол ешқашан орындалмай, **шексіз цикл** пайда болар еді.

## 3. break пен continue салыстыру

| | `break` | `continue` |
|---|---|---|
| Не істейді | Циклді толық тоқтатады | Тек ағымдағы итерацияны өткізеді |
| Кейін қайда көшеді | Циклден кейінгі командаға | Циклдің келесі итерациясына (шартты тексеруге) |
| Аналогия | Кітапты таптым — іздеуді доғардым | Бұл бет бос — келесі бетке көштім |
| Типтік қолданылуы | Іздеу, мәзірден шығу | Сүзгілеу, қате деректерді өткізу |

Схема:
```text
for ... :                     for ... :
    ...                           ...
    if шарт:                      if шарт:
        break  ───┐                   continue ──┐ (циклдің басына)
    ...           │               ...            │
<келесі команда> ◄┘           <келесі итерация> ◄┘
```

Екеуі де тек **өздері тұрған** циклге әсер етеді (кірістірілген циклдерде ішкі циклдегі `break` сыртқы циклді тоқтатпайды).

## 4. Циклдегі else блогы

Python-да `for` және `while` циклдерінде `else` блогы болуы мүмкін. Ол цикл **`break`-сіз, қалыпты аяқталғанда** ғана орындалады.

```python
n = int(input("Сан: "))
for d in range(2, n):
    if n % d == 0:
        print(n, "— жай сан емес, бөлгіші", d)
        break
else:
    print(n, "— жай сан")
```
Мысал:
```text
Сан: 13
13 — жай сан
```
Бұл жерде `is_prime` жалаушасы қажет болмады. Ескерту: `n` мәні 2-ден кіші болса бұл код қате жауап береді — оны `if` арқылы бөлек тексеру керек.

Тағы бір мысал — ізделген сан жоқ болса хабарлау:
```python
for x in range(1, 50):
    if x * x == 50:
        print("Табылды:", x)
        break
else:
    print("50 — толық квадрат емес")
```
Нәтижесі:
```text
50 — толық квадрат емес
```

## 5. pass операторы

`pass` — «ештеңе істеме» деген оператор. Python синтаксисі блокты бос қалдыруға рұқсат бермейді, сондықтан әлі жазылмаған жердің орнына `pass` қоямыз:
```python
for i in range(5):
    pass        # кейін толтырамын
print("Бағдарлама қате бермеді")
```
`pass` — `continue` емес! Ол итерацияны өткізіп жібермейді, тек бос орынды толтырады.

## 6. Біріктірілген мысал: «Сандар сүзгісі»

```python
count = 0
total = 0
while True:
    x = int(input("Сан (0 — аяқтау): "))
    if x == 0:
        break               # енгізуді аяқтаймыз
    if x < 0 or x > 100:
        print("0..100 аралығынан тыс — өткізілді")
        continue            # бұл санды есепке алмаймыз
    count += 1
    total += x
print("Қабылданған сандар:", count, "Қосындысы:", total)
```

## Жиі кездесетін қателер

**1. `break`-ті цикл сыртында жазу**
```text
x = 5
if x > 3:
    break
```
`SyntaxError: 'break' outside loop`. `break` пен `continue` тек цикл ішінде жұмыс істейді.

**2. `while`-да `continue` санауышты өзгертуді өткізіп жібереді**
```text
i = 0
while i < 10:
    if i == 5:
        continue      # i ешқашан 6 болмайды — шексіз цикл
    i += 1
```
Санауышты `continue`-дан **бұрын** өзгерт.

**3. `break`-тен кейінгі код орындалады деп ойлау**
```python
for i in range(3):
    break
    print("Бұл жол ешқашан орындалмайды")
```

**4. `continue` мен `pass`-ты шатастыру**: `pass` ештеңе өткізбейді, `continue` итерацияның қалғанын өткізеді.

**5. Циклдегі `else`-ті `if`-тің `else`-і деп ойлау** — шегініске қара: `for` деңгейінде тұрса, бұл циклдің `else`-і.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `break` | Циклді дереу тоқтатады |
| `continue` | Ағымдағы итерацияның қалғанын өткізіп, келесісіне көшеді |
| `for...else` / `while...else` | Цикл `break`-сіз аяқталса орындалатын блок |
| `pass` | Бос оператор, синтаксистік «толтырғыш» |
| Жай сан | Тек 1-ге және өзіне бөлінетін 1-ден үлкен натурал сан |
| Іздеу алгоритмі | Шартқа сай элементті табу; табылғанда `break` |

## Ескерту

- Python-да басқа кейбір тілдердегідей белгіленген `break label` (бірден бірнеше циклден шығу) жоқ. Оның орнына жалауша, `for...else` немесе кодты функцияға шығарып, `return` қолдану керек.
- Циклдің `else` блогын көп адам `if`-тің `else`-і деп қате түсінеді. Оны «егер `break` болмаса» (`nobreak`) деп оқыған жөн; анық болу үшін жанына түсініктеме жазыңыз.
- `while` циклінің де `else` блогы бар: шарт `False` болғанда орындалады, бірақ `break` арқылы шыққанда орындалмайды.
- Жай санды тексерудің тиімді тәсілі — бөлгіштерді `n`-ге дейін емес, `int(n ** 0.5)`-ке дейін (немесе Python 3.8+ `math.isqrt(n)`) іздеу.
- `try...finally` ішіндегі `break`/`continue` болса да `finally` блогы орындалады. Python 3.14-тен бастап `finally` ішінде `break`/`continue`/`return` жазу `SyntaxWarning` береді (PEP 765).
- Құжаттама: https://docs.python.org/3/tutorial/controlflow.html#break-and-continue-statements-and-else-clauses-on-loops
