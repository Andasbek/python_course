# Урок 30. Практические задания: break и continue

## Базовый уровень

### Задание 1. Предскажи результат
Без компьютера запиши результат каждого кода, затем проверь:
```python
# а)
for i in range(1, 8):
    if i == 4:
        break
    print(i, end=" ")
print()

# б)
for i in range(1, 8):
    if i == 4:
        continue
    print(i, end=" ")
print()

# в)
k = 0
while k < 20:
    k += 3
    if k % 2 == 0:
        continue
    print(k, end=" ")
print()
```

### Задание 2. Первое делящееся число
Вводятся `a`, `b` и `d`. Найди **первое** число из отрезка `[a; b]`, делящееся на `d`. Если такого числа нет, выведи «Не найдено» (используй `for...else`).

### Задание 3. Счёт без 7
Выведи числа от 1 до 30, но пропускай числа, делящиеся на 7 (`continue`).

### Задание 4. Простое ли число?
Вводится натуральное число. Определи, простое оно или нет (используй `break`).

### Задание 5. Сумма только чётных чисел
Пользователь вводит числа, пока не введёт 0 (`while True` + `break`). Складывай только чётные числа (нечётные пропускай с помощью `continue`).

## Продвинутый уровень

### Задание 6. Последовательность простых чисел
Вводится `N`. Выведи все простые числа от 2 до `N`.

**Подсказка:** внешний цикл — по числам, внутренний — по делителям, во внутреннем цикле `break` и `else`. (Вложенные циклы подробно пройдём на следующем уроке — это подготовка к нему.)

### Задание 7. Программа-тест
Программа спрашивает у пользователя результат `7 * 8`. Если пользователь пишет «сдаюсь» — программа сообщает правильный ответ и останавливается. Если ответ правильный — «Верно! Количество попыток: ...». Если неверный — спрашивает снова.

**Подсказка:** сначала сравни ответ как строку со «сдаюсь», и только потом преобразуй в `int`.

### Задание 8. Пост контроля
Вводится скорость автомобилей на дороге (0 — конец). Если скорость меньше 0 или больше 300, выведи «Ошибка измерения» и пропусти её. Выведи количество автомобилей, превысивших 90 км/ч, и среднюю скорость.

## ★ Олимпиадная / творческая задача

### Задание 9. Счастливый билет
Номер автобусного билета — 6-значный. Билет считается «счастливым», если сумма трёх левых цифр равна сумме трёх правых. Вводится `N` (100000 ≤ N ≤ 999999). Найди **первый** счастливый билет, начиная с `N`.

### Задание 10. Совершенное число
Совершенное число — число, равное сумме своих делителей, кроме самого себя (6 = 1 + 2 + 3). Найди совершенные числа от 1 до 10 000. Когда найдено первое совершенное число больше 1000, останови поиск с помощью `break`.

## Домашнее задание

1. Вводится `N`. Найди первое простое число, большее `N`.
2. Пользователь вводит числа. Если введённое число больше 100 — программа останавливается. Отрицательные числа не учитываются. Выведи количество и сумму остальных чисел.
3. Перепиши свою программу с меню с прошлого урока с помощью `while True` и `break`.

**Задание 7**

```python
attempts = 0
while True:
    answer = input("7 * 8 = ? ")
    if answer == "сдаюсь":
        print("Правильный ответ: 56")
        break
    attempts += 1
    if int(answer) == 56:
        print("Верно! Количество попыток:", attempts)
        break
    print("Неверно, попробуйте ещё.")
```

**Задание 8**
```python
count = 0
total = 0
fast = 0
while True:
    v = int(input("Скорость: "))
    if v == 0:
        break
    if v < 0 or v > 300:
        print("Ошибка измерения")
        continue
    count += 1
    total += v
    if v > 90:
        fast += 1
print("Превысили скорость:", fast)
if count > 0:
    print(f"Средняя скорость: {total / count:.1f}")
```

**Задание 9**
```python
n = int(input("Номер билета: "))
while n <= 999999:
    left = n // 1000
    right = n % 1000
    s1 = left // 100 + left // 10 % 10 + left % 10
    s2 = right // 100 + right // 10 % 10 + right % 10
    if s1 == s2:
        print("Счастливый билет:", n)
        break
    n += 1
```
