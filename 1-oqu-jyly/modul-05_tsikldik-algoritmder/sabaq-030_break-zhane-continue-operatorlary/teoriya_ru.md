## 1. Оператор break

`break` — **немедленно и полностью** останавливает цикл. Программа переходит к команде после цикла.

```python
for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("Цикл остановлен")
```
Результат:
```text
1
2
3
4
Цикл остановлен
```
Когда `i = 5`, выполнился `break` и цикл завершился; 5 и последующие числа не выведены.

### Задача поиска: найти первый подходящий элемент
«Найди **первое** число от 100 до 200, делящееся на 17»:
```python
for n in range(100, 201):
    if n % 17 == 0:
        print("Найдено:", n)
        break
```
Результат:
```text
Найдено: 102
```
Без `break` цикл вывел бы все числа, делящиеся на 17.

### while True + break
Применяется, когда условие выхода проверяется в середине цикла. Например, спрашивать, пока пользователь не введёт положительное число:
```python
while True:
    x = int(input("Введите положительное число: "))
    if x > 0:
        break
    print("Это не положительное число, повторите.")
print("Спасибо, вы ввели:", x)
```

### Проверка простого числа
**Простое число** — число больше 1, которое делится только на 1 и на себя (2, 3, 5, 7, 11, ...). Как только найден первый делитель, проверку можно остановить:
```python
n = int(input("Число: "))
is_prime = n > 1
for d in range(2, n):
    if n % d == 0:
        is_prime = False
        print("Найден делитель:", d)
        break
if is_prime:
    print(n, "— простое число")
else:
    print(n, "— не простое число")
```
Пример:
```text
Число: 91
Найден делитель: 7
91 — не простое число
```

## 2. Оператор continue

`continue` — **пропускает оставшуюся часть текущей итерации** цикла и переходит к **следующей итерации**. Цикл не останавливается!

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    print(i, end=" ")
print()
```
Результат:
```text
1 2 4 5 7 8 10 
```
На числах 3, 6, 9 выполнился `continue`, поэтому `print` был пропущен.

### Игнорирование отрицательных чисел
```python
total = 0
for i in range(5):
    x = int(input("Число: "))
    if x < 0:
        print("Отрицательное число не учитывается")
        continue
    total += x
print("Сумма положительных чисел:", total)
```

### continue в цикле while — будьте осторожны!
```python
i = 0
while i < 10:
    i += 1              # изменение пишем ДО continue
    if i % 2 == 0:
        continue
    print(i, end=" ")
print()
```
Результат:
```text
1 3 5 7 9 
```
Если бы строка `i += 1` стояла после `continue`, то при чётном `i` она никогда бы не выполнилась и возник бы **бесконечный цикл**.

## 3. Сравнение break и continue

| | `break` | `continue` |
|---|---|---|
| Что делает | Полностью останавливает цикл | Пропускает только текущую итерацию |
| Куда переходит | К команде после цикла | К следующей итерации цикла (к проверке условия) |
| Аналогия | Нашёл книгу — прекратил поиск | Эта страница пустая — перешёл к следующей |
| Типичное применение | Поиск, выход из меню | Фильтрация, пропуск ошибочных данных |

Схема:
```text
for ... :                     for ... :
    ...                           ...
    if условие:                   if условие:
        break  ───┐                   continue ──┐ (в начало цикла)
    ...           │               ...            │
<следующая команда> ◄┘        <следующая итерация> ◄┘
```

Оба оператора действуют только на цикл, **в котором они находятся** (во вложенных циклах `break` во внутреннем цикле не останавливает внешний).

## 4. Блок else в цикле

В Python у циклов `for` и `while` может быть блок `else`. Он выполняется только тогда, когда цикл **завершился нормально, без `break`**.

```python
n = int(input("Число: "))
for d in range(2, n):
    if n % d == 0:
        print(n, "— не простое число, делитель", d)
        break
else:
    print(n, "— простое число")
```
Пример:
```text
Число: 13
13 — простое число
```
Здесь флаг `is_prime` не понадобился. Примечание: если `n` меньше 2, этот код даст неверный ответ — это нужно проверить отдельно с помощью `if`.

Ещё один пример — сообщить, если искомого числа нет:
```python
for x in range(1, 50):
    if x * x == 50:
        print("Найдено:", x)
        break
else:
    print("50 — не полный квадрат")
```
Результат:
```text
50 — не полный квадрат
```

## 5. Оператор pass

`pass` — оператор «ничего не делать». Синтаксис Python не позволяет оставлять блок пустым, поэтому на место ещё не написанного кода ставим `pass`:
```python
for i in range(5):
    pass        # заполню позже
print("Программа не выдала ошибку")
```
`pass` — это не `continue`! Он не пропускает итерацию, а лишь заполняет пустое место.

## 6. Комбинированный пример: «Фильтр чисел»

```python
count = 0
total = 0
while True:
    x = int(input("Число (0 — конец): "))
    if x == 0:
        break               # завершаем ввод
    if x < 0 or x > 100:
        print("Вне диапазона 0..100 — пропущено")
        continue            # это число не учитываем
    count += 1
    total += x
print("Принято чисел:", count, "Сумма:", total)
```

## Частые ошибки

**1. `break` вне цикла**
```text
x = 5
if x > 3:
    break
```
`SyntaxError: 'break' outside loop`. `break` и `continue` работают только внутри цикла.

**2. В `while` оператор `continue` пропускает изменение счётчика**
```text
i = 0
while i < 10:
    if i == 5:
        continue      # i никогда не станет 6 — бесконечный цикл
    i += 1
```
Изменяй счётчик **до** `continue`.

**3. Думать, что код после `break` выполнится**
```python
for i in range(3):
    break
    print("Эта строка никогда не выполнится")
```

**4. Путать `continue` и `pass`**: `pass` ничего не пропускает, `continue` пропускает остаток итерации.

**5. Принимать `else` цикла за `else` от `if`** — смотри на отступ: если он стоит на уровне `for`, это `else` цикла.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| `break` | Немедленно останавливает цикл |
| `continue` | Пропускает остаток текущей итерации и переходит к следующей |
| `for...else` / `while...else` | Блок, выполняемый, если цикл завершился без `break` |
| `pass` | Пустой оператор, синтаксический «заполнитель» |
| Простое число | Натуральное число больше 1, делящееся только на 1 и на себя |
| Алгоритм поиска | Нахождение элемента, удовлетворяющего условию; при нахождении — `break` |

## Примечание

- В Python нет `break label` (выхода сразу из нескольких циклов), как в некоторых других языках. Вместо него используют флаг, `for...else` или выносят код в функцию и применяют `return`.
- Блок `else` у цикла часто ошибочно воспринимают как `else` от `if`. Лучше читать его как «если не было `break`» (`nobreak`) и для ясности оставлять рядом комментарий.
- У цикла `while` тоже есть `else`: он выполняется, когда условие стало `False`, но не выполняется при выходе через `break`.
- Эффективная проверка простого числа — искать делители не до `n`, а до `int(n ** 0.5)` (или `math.isqrt(n)` в Python 3.8+).
- Даже при `break`/`continue` внутри `try...finally` блок `finally` выполняется. Начиная с Python 3.14, `break`/`continue`/`return` внутри `finally` дают `SyntaxWarning` (PEP 765).
