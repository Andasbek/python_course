## 1. Что такое цикл while?

`while` (англ. «пока») — цикл, который повторяет тело цикла, **пока условие истинно (True)**.

```text
while <условие>:
    <тело цикла>
<команда после цикла>
```

Порядок работы:
1. Проверяется условие.
2. Если условие `True` — выполняется тело цикла и происходит возврат к шагу 1.
3. Если условие `False` — цикл завершается и выполняется следующая команда.

Блок-схема:
```text
        ┌──────────────┐
   ┌───►│  условие ?   │── нет ──► выход из цикла
   │    └──────────────┘
   │           │ да
   │    ┌──────────────┐
   └────│ тело цикла   │
        └──────────────┘
```

`while` — **цикл с предусловием**: условие проверяется до тела. Если условие изначально ложно, тело не выполнится ни разу.

## 2. Первые примеры

### Счёт от 1 до 5
```python
i = 1                 # начальное значение счётчика
while i <= 5:         # условие
    print(i)
    i += 1            # изменение счётчика (обязательно!)
print("Готово!")
```
Результат:
```text
1
2
3
4
5
Готово!
```

Трассировка:

| Шаг | `i` | `i <= 5` | Действие |
|---|---|---|---|
| 1 | 1 | True | print(1), i = 2 |
| 2 | 2 | True | print(2), i = 3 |
| 3 | 3 | True | print(3), i = 4 |
| 4 | 4 | True | print(4), i = 5 |
| 5 | 5 | True | print(5), i = 6 |
| 6 | 6 | False | выход из цикла |

### Сравнение for и while
Две программы, дающие одинаковый результат:

```python
for i in range(1, 6):
    print(i)
```

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

В `for` счётчик изменяет сам Python, а в `while` им управляем **мы сами**: задаём начальное значение, пишем условие, изменяем в теле.

| | `for` | `while` |
|---|---|---|
| Когда применяем | Число повторений известно | Число повторений неизвестно, известно условие |
| Счётчик | Автоматический | Вручную (`i += 1`) |
| Риск бесконечного цикла | Почти нет | Есть |
| Пример | «Напиши 10 раз» | «Спрашивай, пока не введут правильный пароль» |

## 3. Бесконечный цикл

Если условие никогда не становится ложным, цикл выполняется **бесконечно**.

```text
i = 1
while i <= 5:
    print(i)      # i никогда не изменяется — бесконечный цикл!
```

Программа не останавливается и бесконечно выводит на экран 1. Способы остановки:
- Thonny: красная кнопка **Stop** или **Ctrl+F2**;
- IDLE / терминал: **Ctrl+C** (`KeyboardInterrupt`).

Причины бесконечного цикла:
1. Переменная из условия не изменяется внутри цикла;
2. Переменная изменяется в неправильном направлении (`i += 1` вместо `i -= 1`);
3. Условие никогда не может стать ложным (`while i != 10`, а `i` прыгает через 2: 1, 3, 5, ..., 9, 11 ...).

Иногда бесконечный цикл пишут намеренно (`while True:`) — из такого цикла выходят с помощью оператора `break` (например, в программах с меню).

## 4. Счётчик и накопитель в цикле while

### Сложение чисел, пока не введён 0
Это классическая задача для `while`: неизвестно, сколько чисел будет введено.

```python
total = 0       # накопитель
count = 0       # счётчик
x = int(input("Введите число (0 — конец): "))
while x != 0:
    total += x
    count += 1
    x = int(input("Введите число (0 — конец): "))
print("Количество введённых чисел:", count)
print("Сумма:", total)
if count > 0:
    print("Среднее значение:", total / count)
```
Пример:
```text
Введите число (0 — конец): 10
Введите число (0 — конец): 20
Введите число (0 — конец): 30
Введите число (0 — конец): 0
Количество введённых чисел: 3
Сумма: 60
Среднее значение: 20.0
```

Здесь `0` — **сигнальная метка (sentinel)**: оно не обрабатывается, а лишь обозначает конец цикла.

### Пока сумма не достигнет предела
«Сколько чисел нужно сложить в сумме 1 + 2 + 3 + ..., чтобы она превысила 100?»
```python
s = 0
n = 0
while s <= 100:
    n += 1
    s += n
print("Количество чисел:", n, "сумма:", s)
```
Результат:
```text
Количество чисел: 14 сумма: 105
```

## 5. Работа с цифрами числа

Чаще всего цикл `while` применяется для разбиения числа на цифры. Нужны две операции:
- `n % 10` — последняя цифра числа;
- `n // 10` — «отбросить» последнюю цифру.

```python
n = int(input("Натуральное число: "))
digits = 0
digit_sum = 0
while n > 0:
    last = n % 10
    digit_sum += last
    digits += 1
    n = n // 10
print("Количество цифр:", digits)
print("Сумма цифр:", digit_sum)
```
Пример (ввод `2026`):
```text
Натуральное число: 2026
Количество цифр: 4
Сумма цифр: 10
```

Трассировка (`n = 2026`):

| `n` | `n % 10` | `digit_sum` | `digits` | `n // 10` |
|---|---|---|---|---|
| 2026 | 6 | 6 | 1 | 202 |
| 202 | 2 | 8 | 2 | 20 |
| 20 | 0 | 8 | 3 | 2 |
| 2 | 2 | 10 | 4 | 0 |
| 0 | — | цикл останавливается | | |

## 6. Проверка ввода

`while` удобен, чтобы переспрашивать пользователя, пока он не введёт правильное значение:
```python
age = int(input("Ваш возраст (7–18): "))
while age < 7 or age > 18:
    print("Ошибка! Возраст должен быть от 7 до 18.")
    age = int(input("Ваш возраст (7–18): "))
print("Спасибо! Ваш возраст:", age)
```

Запрос пароля:
```python
password = input("Пароль: ")
attempts = 1
while password != "python2026":
    print("Неверный пароль!")
    password = input("Пароль: ")
    attempts += 1
print("Вход выполнен! Количество попыток:", attempts)
```

## Частые ошибки

**1. Забыли изменить счётчик** → бесконечный цикл.
```text
i = 0
while i < 3:
    print("Привет")
```
Правильно:
```python
i = 0
while i < 3:
    print("Привет")
    i += 1
```

**2. Переменная не определена до цикла**
```text
while x != 0:
    x = int(input())
```
`NameError: name 'x' is not defined` — при проверке условия `x` ещё не существует.

**3. «Ошибка на единицу» в условии**
```python
i = 1
while i < 5:       # 5 не выводится!
    print(i)
    i += 1
```
Если нужно от 1 до 5, то `i <= 5`.

**4. Не запрашивать ввод повторно внутри цикла**
```text
x = int(input())
while x != 0:
    total += x       # x не меняется → бесконечный цикл
```

**5. Написать `==` вместо `!=`** — условие сразу ложно, и цикл не выполняется вовсе.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| `while` | Цикл, повторяющийся, пока условие истинно |
| Цикл с предусловием | Цикл, в котором условие проверяется до тела |
| Бесконечный цикл | Цикл, условие которого никогда не становится ложным |
| Счётчик | Переменная, увеличивающаяся на 1 при каждом событии |
| Накопитель | Переменная, накапливающая значения сложением/умножением |
| Сигнальная метка (sentinel) | Специальное значение, обозначающее конец ввода (например, 0) |
| `n % 10`, `n // 10` | Получить последнюю цифру / отбросить последнюю цифру |

## Примечание

- В Python нет цикла `do ... while` (с постусловием, выполняющегося хотя бы один раз), как в других языках. Вместо него используется шаблон `while True:` + внутри `if ...: break`.
- В Python 3.8+ есть «моржовый оператор» `:=`, объединяющий ввод с условием: `while (x := int(input())) != 0: total += x`. Это избавляет от двойного вызова `input()`.
- Не сравнивайте дробные числа в условии `while` через `==` / `!=`: `x = 0.0; while x != 1.0: x += 0.1` — бесконечный цикл, так как `0.1` хранится неточно. Используйте `<` или `<=`.
- Условием может быть любое значение: `while n:` равносильно `while n != 0:` (0, пустая строка, пустой список — это `False`).
- Если ввести не число, `int(input())` вызовет `ValueError`; для проверки ввода применяют `str.isdigit()` или `try/except`.
- Документация: https://docs.python.org/3/reference/compound_stmts.html#the-while-statement
