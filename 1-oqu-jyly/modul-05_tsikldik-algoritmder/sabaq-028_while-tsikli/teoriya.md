## 1. while циклі дегеніміз не?

`while` (ағылш. «әзірше», «... болғанша») — **шарт ақиқат (True) болғанша** цикл денесін қайталайтын цикл.

```text
while <шарт>:
    <цикл денесі>
<циклден кейінгі команда>
```

Жұмыс істеу реті:
1. Шарт тексеріледі.
2. Шарт `True` болса — цикл денесі орындалады да, 1-қадамға оралады.
3. Шарт `False` болса — цикл аяқталып, келесі командаға көшеді.

Блок-схема:
```text
        ┌──────────────┐
   ┌───►│   шарт ?     │── жоқ ──► циклден шығу
   │    └──────────────┘
   │           │ иә
   │    ┌──────────────┐
   └────│ цикл денесі  │
        └──────────────┘
```

`while` — **алғышартты цикл**: шарт денеден бұрын тексеріледі. Егер шарт басынан жалған болса, дене бірде-бір рет орындалмайды.

## 2. Алғашқы мысалдар

### 1-ден 5-ке дейін санау
```python
i = 1                 # санауыштың бастапқы мәні
while i <= 5:         # шарт
    print(i)
    i += 1            # санауышты өзгерту (міндетті!)
print("Дайын!")
```
Нәтижесі:
```text
1
2
3
4
5
Дайын!
```

Трассировка:

| Қадам | `i` | `i <= 5` | Әрекет |
|---|---|---|---|
| 1 | 1 | True | print(1), i = 2 |
| 2 | 2 | True | print(2), i = 3 |
| 3 | 3 | True | print(3), i = 4 |
| 4 | 4 | True | print(4), i = 5 |
| 5 | 5 | True | print(5), i = 6 |
| 6 | 6 | False | циклден шығу |

### for пен while салыстыру
Бірдей нәтиже беретін екі бағдарлама:

```python
for i in range(1, 6):
    print(i)
```

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

`for`-да санауышты Python өзі өзгертеді, ал `while`-да оны **біз өзіміз** басқарамыз: бастапқы мән береміз, шартты жазамыз, денеде өзгертеміз.

| | `for` | `while` |
|---|---|---|
| Қашан қолданамыз | Қайталау саны белгілі | Қайталау саны белгісіз, шарт белгілі |
| Санауыш | Автоматты | Қолмен (`i += 1`) |
| Шексіз цикл қаупі | Жоқ дерлік | Бар |
| Мысал | «10 рет жаз» | «Дұрыс пароль енгізгенше сұра» |

## 3. Шексіз цикл

Егер шарт ешқашан жалған болмаса, цикл **шексіз** орындалады.

```text
i = 1
while i <= 5:
    print(i)      # i ешқашан өзгермейді — шексіз цикл!
```

Бағдарлама тоқтамай, экранға 1-ді шексіз шығара береді. Тоқтату тәсілдері:
- Thonny: қызыл **Stop** батырмасы немесе **Ctrl+F2**;
- IDLE / терминал: **Ctrl+C** (`KeyboardInterrupt`).

Шексіз циклдің себептері:
1. Шарттағы айнымалы цикл ішінде өзгертілмейді;
2. Айнымалы қате бағытта өзгереді (`i -= 1` орнына `i += 1`);
3. Шарт ешқашан жалған бола алмайды (`while i != 10`, ал `i` 2-ден секіреді: 1, 3, 5, ..., 9, 11 ...).

Кейде шексіз цикл әдейі жазылады (`while True:`) — мұндай циклден `break` операторы арқылы шығады (мысалы, мәзір бағдарламаларында).

## 4. Санауыш пен жинақтауыш while циклінде

### Сандарды 0 енгізілгенше қосу
Бұл — `while`-дың классикалық есебі: неше сан енгізілетіні белгісіз.

```python
total = 0       # жинақтауыш
count = 0       # санауыш
x = int(input("Сан енгізіңіз (0 — аяқтау): "))
while x != 0:
    total += x
    count += 1
    x = int(input("Сан енгізіңіз (0 — аяқтау): "))
print("Енгізілген сандар саны:", count)
print("Қосындысы:", total)
if count > 0:
    print("Орташа мәні:", total / count)
```
Мысал:
```text
Сан енгізіңіз (0 — аяқтау): 10
Сан енгізіңіз (0 — аяқтау): 20
Сан енгізіңіз (0 — аяқтау): 30
Сан енгізіңіз (0 — аяқтау): 0
Енгізілген сандар саны: 3
Қосындысы: 60
Орташа мәні: 20.0
```

Мұнда `0` — **белгі-мән (сигнальная метка, sentinel)**: ол өңделмейді, тек циклдің соңын білдіреді.

### Қосынды шекке жеткенше
«1 + 2 + 3 + ... қосындысы 100-ден асу үшін неше сан қосу керек?»
```python
s = 0
n = 0
while s <= 100:
    n += 1
    s += n
print("Сандар саны:", n, "қосынды:", s)
```
Нәтижесі:
```text
Сандар саны: 14 қосынды: 105
```

## 5. Санның цифрларымен жұмыс

`while` циклінің ең жиі қолданылатын жері — санды цифрларға бөлу. Екі амал керек:
- `n % 10` — санның соңғы цифры;
- `n // 10` — соңғы цифрды «кесіп тастау».

```python
n = int(input("Натурал сан: "))
digits = 0
digit_sum = 0
while n > 0:
    last = n % 10
    digit_sum += last
    digits += 1
    n = n // 10
print("Цифрлар саны:", digits)
print("Цифрлар қосындысы:", digit_sum)
```
Мысал (енгізу `2026`):
```text
Натурал сан: 2026
Цифрлар саны: 4
Цифрлар қосындысы: 10
```

Трассировка (`n = 2026`):

| `n` | `n % 10` | `digit_sum` | `digits` | `n // 10` |
|---|---|---|---|---|
| 2026 | 6 | 6 | 1 | 202 |
| 202 | 2 | 8 | 2 | 20 |
| 20 | 0 | 8 | 3 | 2 |
| 2 | 2 | 10 | 4 | 0 |
| 0 | — | цикл тоқтайды | | |

## 6. Енгізуді тексеру

`while` пайдаланушы дұрыс мән енгізгенше қайта сұрауға ыңғайлы:
```python
age = int(input("Жасыңыз (7–18): "))
while age < 7 or age > 18:
    print("Қате! Жас 7 мен 18 аралығында болуы керек.")
    age = int(input("Жасыңыз (7–18): "))
print("Рахмет! Сіздің жасыңыз:", age)
```

Пароль сұрау:
```python
password = input("Пароль: ")
attempts = 1
while password != "python2026":
    print("Пароль қате!")
    password = input("Пароль: ")
    attempts += 1
print("Кіру сәтті! Әрекет саны:", attempts)
```

## Жиі кездесетін қателер

**1. Санауышты өзгертуді ұмыту** → шексіз цикл.
```text
i = 0
while i < 3:
    print("Сәлем")
```
Дұрысы:
```python
i = 0
while i < 3:
    print("Сәлем")
    i += 1
```

**2. Айнымалыны циклге дейін анықтамау**
```text
while x != 0:
    x = int(input())
```
`NameError: name 'x' is not defined` — шартты тексеру кезінде `x` әлі жоқ.

**3. Шарттағы «бір қадамға қателік»**
```python
i = 1
while i < 5:       # 5 шықпайды!
    print(i)
    i += 1
```
1-ден 5-ке дейін керек болса, `i <= 5`.

**4. Енгізуді цикл ішінде қайта сұрамау**
```text
x = int(input())
while x != 0:
    total += x       # x өзгермейді → шексіз цикл
```

**5. `!=` орнына `==` жазу** — шарт бірден жалған болып, цикл мүлде орындалмайды.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `while` | Шарт ақиқат болғанша қайталайтын цикл |
| Алғышартты цикл | Шарт денеден бұрын тексерілетін цикл |
| Шексіз цикл | Шарты ешқашан жалған болмайтын цикл |
| Санауыш | Әр оқиғада 1-ге артатын айнымалы |
| Жинақтауыш | Мәндерді қосып/көбейтіп жинайтын айнымалы |
| Белгі-мән (sentinel) | Енгізудің аяқталғанын білдіретін арнайы мән (мысалы, 0) |
| `n % 10`, `n // 10` | Соңғы цифрды алу / соңғы цифрды алып тастау |

## Ескерту

- Python-да басқа тілдердегідей `do ... while` (шартсыз кем дегенде бір рет орындалатын цикл) жоқ. Оның орнына `while True:` + ішінде `if ...: break` үлгісі қолданылады.
- Python 3.8+ нұсқасында «морж операторы» `:=` бар, ол енгізуді шартпен біріктіреді: `while (x := int(input())) != 0: total += x`. Бұл `input()`-ты екі рет жазуды болдырмайды.
- `while` шартында бөлшек сандарды `==` / `!=` арқылы салыстырмаңыз: `x = 0.0; while x != 1.0: x += 0.1` шексіз цикл болады, себебі `0.1` дәл сақталмайды. `<` немесе `<=` қолданыңыз.
- Кез келген мән шарт бола алады: `while n:` жазуы `while n != 0:` дегенмен бірдей (0, бос жол, бос тізім — `False`).
- Сан болмайтын мәтін енгізілсе, `int(input())` `ValueError` береді; енгізуді тексеру үшін `str.isdigit()` немесе `try/except` қолданылады.
- Құжаттама: https://docs.python.org/3/reference/compound_stmts.html#the-while-statement
