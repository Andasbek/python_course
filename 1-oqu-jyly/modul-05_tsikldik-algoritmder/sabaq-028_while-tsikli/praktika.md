# Сабақ 28. Практикалық тапсырмалар: while циклі, санауыш пен жинақтауыш

## Базалық деңгей

### 1-тапсырма. for-ды while-ға аудар
Төмендегі бағдарламаны `while` циклімен қайта жаз:
```python
for i in range(10, 101, 10):
    print(i)
```

### 2-тапсырма. Кері санау
`n` енгізіледі. `while` арқылы `n`-нен 1-ге дейін кері санап, соңында «Жаңа жыл құтты болсын!» деп шығар.

### 3-тапсырма. 0-ге дейін қосу
Пайдаланушы сандарды енгізеді, 0 енгізілгенде тоқтайды. Сандардың қосындысын және санын шығар.

Мысал:
```text
5
-2
7
0
Саны: 3
Қосындысы: 10
```

### 4-тапсырма. Цифрлар саны
Натурал сан енгізіледі. Оның неше цифрдан тұратынын `while` арқылы тап (`len`, `str` қолданба).

Мысал: `98765` → `5`.

### 5-тапсырма. Дұрыс баға
Баға енгізу сұралады. Баға 1-ден 5-ке дейін болмаса, «Қате баға!» деп қайта сұрасын. Дұрыс баға енгізілгенде «Баға қабылданды: ...» деп шығарсын.

## Кеңейтілген деңгей

### 6-тапсырма. Жинақ
Динара әр айда 15 000 теңге жинайды. Ол 200 000 теңгелік велосипед сатып алғысы келеді. Неше айдан кейін жеткілікті ақша жинайды? Әр айдың соңындағы соманы шығар.

### 7-тапсырма. Санды кері жазу
Натурал сан енгізіледі. Оның цифрларын кері ретпен шығаратын (`1234` → `4321`) бағдарлама жаз. Нәтиже **сан** түрінде құрастырылсын.

**Кеңес:** `rev = rev * 10 + n % 10`.

### 8-тапсырма. Халық саны
Қаланың халқы 2 000 000 адам, жыл сайын 3% өседі. Неше жылдан кейін халық саны 3 000 000-нан асады?

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Коллатц болжамы
Натурал `n` енгізіледі. Егер `n` жұп болса, оны 2-ге бөл, тақ болса — `3n + 1`. `n = 1` болғанша қайтала. Тізбекті шығар және неше қадам кеткенін тап.

Мысал (`n = 6`):
```text
6 3 10 5 16 8 4 2 1
Қадам саны: 8
```

### 10-тапсырма. ЕҮОБ (Евклид алгоритмі)
Екі натурал сан енгізіледі. Олардың ең үлкен ортақ бөлгішін Евклид алгоритмімен тап: үлкен саннан кішісін азайта бер, сандар тең болғанша.

Мысал: `48`, `18` → `6`.

## Үй тапсырмасы

1. Натурал сан енгізіледі. Оның цифрларының көбейтіндісін тап.
2. Пайдаланушыдан оң сандар сұрала береді; теріс сан енгізілгенде тоқтайды. Енгізілген оң сандардың ең үлкенін тап.
3. 1-ден бастап қанша натурал санның квадраттарын қосқанда қосынды 1000-нан асады?

**6-тапсырма**
```python
money = 0
month = 0
while money < 200000:
    month += 1

print("Қажетті ай саны:", month)
```
Жауабы: 14 ай (210 000 теңге).

**9-тапсырма**
```python
n = int(input("n = "))
steps = 0
print(n, end=" ")
while n != 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1
    steps += 1
    print(n, end=" ")
print()
print("Қадам саны:", steps)
```

**10-тапсырма**
```python
a = int(input("a = "))
b = int(input("b = "))
while a != b:
    if a > b:
        a -= b
    else:
        b -= a
print("ЕҮОБ =", a)
```
