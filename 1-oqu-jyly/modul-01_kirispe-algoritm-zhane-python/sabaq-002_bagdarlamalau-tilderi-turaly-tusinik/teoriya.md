## 1. Бағдарламалау тілі деген не?

Адамдар бір-бірімен **табиғи тілде** (қазақ, орыс, ағылшын) сөйлеседі. Бірақ табиғи тіл көп мағыналы: «Ол **жаз**ды» — «хат жазды» ма, әлде «жаз мезгілі» ме? Компьютер мұндай екіұштылықты түсінбейді.

**Бағдарламалау тілі** (язык программирования, programming language) — компьютерге нұсқау беруге арналған, қатаң ережелері (**синтаксисі**) бар жасанды тіл.

| Табиғи тіл | Бағдарламалау тілі |
|---|---|
| Көп мағыналы сөздер бар | Әр команданың бір ғана мағынасы бар |
| Қате айтсаңыз да түсінеді | Бір ғана қате таңба бүкіл бағдарламаны тоқтатады |
| Мыңдаған сөз | Аз ғана кілт сөздер (Python-да 35-ке жуық) |
| Адамдар арасында | Адам мен компьютер арасында |

## 2. Компьютер шын мәнінде қандай тілде «ойлайды»?

Компьютердің процессоры тек **екілік кодты** (0 және 1) түсінеді. Бұл — **машиналық код**. Мысалы, екі санды қосу командасы процессор үшін шамамен былай көрінуі мүмкін:

```text
10110000 00000101
00000100 00000011
```

Адамға мұндай кодпен жұмыс істеу өте қиын. Сондықтан тілдер біртіндеп «адамға жақындады».

### Бағдарламалау тілдерінің деңгейлері

| Деңгей | Сипаттамасы | Мысал |
|---|---|---|
| Машиналық код | 0 мен 1, процессор тікелей орындайды | `10110000 00000101` |
| Төменгі деңгейлі тіл (Ассемблер) | Машиналық командалардың қысқа ағылшынша атаулары | `MOV AL, 5` |
| Жоғары деңгейлі тіл | Адам тіліне жақын, түсінікті сөздер | `print(5 + 3)` |

Аналогия: машиналық код — кірпіштің әр түйіршігі, ассемблер — жеке кірпіштер, жоғары деңгейлі тіл — дайын қабырға панельдері. Панельмен үй тезірек тұрғызылады.

Бір есептің үш деңгейде жазылуы (5 пен 3-ті қосып, нәтижені шығару):

```text
Ассемблер (шамамен):          C тілі:                        Python:
  MOV AX, 5                     #include <stdio.h>             print(5 + 3)
  ADD AX, 3                     int main() {
  ; нәтижені шығару үшін            printf("%d", 5 + 3);
  ; тағы 10-15 жол керек            return 0;
                                }
```

## 3. Компилятор және интерпретатор

Жоғары деңгейлі тілде жазылған кодты компьютер тікелей түсінбейді — оны машиналық кодқа **аудару** керек. Аударатын арнайы бағдарламаның екі түрі бар.

| | Компилятор (compiler) | Интерпретатор (interpreter) |
|---|---|---|
| Қалай жұмыс істейді? | Бүкіл бағдарламаны алдын ала толық аударып, дайын файл (.exe) жасайды | Бағдарламаны жол-жолымен аударып, бірден орындайды |
| Аналогия | Кітапты толық аударып, басып шығарған аудармашы | Келіссөзде сөйлем сайын аударып тұратын ілеспе аудармашы |
| Артықшылығы | Дайын бағдарлама өте жылдам жұмыс істейді | Кодты тез тексеруге, қатені бірден көруге болады |
| Кемшілігі | Әр өзгерістен кейін қайта компиляциялау керек | Орындалу жылдамдығы төмендеу |
| Тілдер | C, C++, Go, Rust | Python, JavaScript, PHP |

> Python — **интерпретацияланатын** тіл. Сондықтан бір команданы жазып, Enter басқан бойда нәтижесін көре аламыз. Бұл үйренуге өте ыңғайлы.

## 5. Python тілінің тарихы

- **Авторы:** нидерландтық бағдарламашы **Гвидо ван Россум** (Guido van Rossum).
- **1989 жылдың желтоқсаны** — Рождество демалысында «уақыт өткізу үшін» жаңа тіл жаза бастады.
- **1991 жылы** — алғашқы нұсқасы (0.9.0) жарияланды.
- **2000 жылы** — Python 2.0.
- **2008 жылы** — Python 3.0 (тілдің жаңартылған, біз қолданатын нұсқасы).
- **2020 жылы** — Python 2 ресми түрде қолдаудан шықты.
- Бүгін: Python 3.10, 3.11, 3.12, 3.13 ... жаңа нұсқалары жыл сайын шығады.

**Атауы қайдан шыққан?** Жылан емес! Гвидо британдық «Monty Python's Flying Circus» комедиялық телешоуын жақсы көрген. Тілге қысқа, есте қаларлық, сәл жұмбақ атау іздеп, «Python» деп атаған. Кейін логотипке екі жылан бейнеленді.

**Python философиясы** (The Zen of Python) — тілдің негізгі ұстанымдары. Оны Python-ның өзінен оқуға болады:

```python
import this
```

Нәтижесі (басы):
```text
The Zen of Python, by Tim Peters

Beautiful is better than ugly.
Explicit is better than implicit.
Simple is better than complex.
...
```

Қазақша мағынасы: «Әдемі — ұсқынсыздан жақсы. Анық — жасырыннан жақсы. Қарапайым — күрделіден жақсы. Оқылымдылық маңызды.»

## 6. Python тілінің ерекшеліктері мен артықшылықтары

1. **Қарапайым, оқуға жеңіл синтаксис** — код ағылшын тіліндегі сөйлемге ұқсайды.
2. **Интерпретацияланатын тіл** — жазып, бірден орындап көруге болады.
3. **Тегін және ашық кодты** — кез келген адам жүктеп ала алады.
4. **Кросс-платформалы** — Windows, macOS, Linux жүйелерінде бірдей жұмыс істейді.
5. **Бай кітапханалар** — дайын «құрал-саймандар»: сурет салу (turtle), ойын (pygame), математика (math), деректер (pandas) т.б.
6. **Үлкен қауымдастық** — кез келген сұраққа интернеттен жауап табуға болады.
7. **Шегініс (отступ)** арқылы құрылым — код автоматты түрде ұқыпты жазылады.

Салыстыру: экранға «Сәлем, әлем!» шығару.

```text
Java:
public class Main {
    public static void main(String[] args) {
        System.out.println("Сәлем, әлем!");
    }
}
```

```python
print("Сәлем, әлем!")
```

Нәтижесі:
```text
Сәлем, әлем!
```

Java-да 5 жол, Python-да 1 жол!

**Кемшіліктері де бар:** C++-ке қарағанда баяулау жұмыс істейді; мобильді қосымшалар үшін сирек қолданылады. Бірақ бұл кемшіліктер оқуға және көп салаға кедергі емес.

## 8. Python-ның интерактивті режимі

Python интерпретаторы **интерактивті режимде** жұмыс істей алады: `>>>` белгісінен кейін команда жазып, Enter бассаңыз — жауап бірден шығады.

```text
>>> 2 + 3
5
>>> 100 * 12
1200
>>> print("Python — керемет!")
Python — керемет!
```

Python-ның қай нұсқасы орнатылғанын көру:

```python
import sys
print(sys.version)
```

Нәтижесі (мысалы):
```text
3.12.4 (main, Jun  6 2024, ...) [MSC v.1940 64 bit (AMD64)]
```

Нұсқаны пәрмен жолынан да білуге болады: `python --version` (Linux/macOS-та көбіне `python3 --version`).

## Жиі кездесетін қателер

**1. Python 2 мен Python 3-ті шатастыру.** Интернеттегі ескі мысалдарда `print` жақшасыз жазылады:

```text
print "Сәлем"
```

Python 3-те бұл `SyntaxError` береді. Дұрысы:

```python
print("Сәлем")
```

**2. «Компьютер түсінеді ғой» деп ойлау.** Табиғи тілде жазу:

```text
экранға сәлем жаз
```

Компьютер мұны түсінбейді — бұл Python командасы емес. Тек тілдің ережесімен жазамыз.

**3. Үлкен-кіші әріпті елемеу.** Python үлкен және кіші әріптерді ажыратады:

```text
Print("Сәлем")   -> NameError: name 'Print' is not defined
print("Сәлем")   -> Сәлем
```

**4. «Python — жылан туралы тіл» деген түсінік.** Атауы комедиялық шоудан алынған (жоғарыда қараңыз).

## Ескерту

- Нақтырақ айтсақ, CPython (Python-ның негізгі іске асырылуы) кодты алдымен **байт-кодқа** (`__pycache__` папкасындағы `.pyc` файлдары) компиляциялайды, содан кейін оны виртуалды машинамен орындайды. Сондықтан «компиляцияланатын/интерпретацияланатын» деген бөлу тілге емес, оның іске асырылуына қатысты.
- Өз Python нұсқаңыздың кілт сөздер тізімін былай көруге болады: `import keyword; print(keyword.kwlist)`. Оларды айнымалы аты ретінде қолдануға болмайды.
- Python-ның жаңа нұсқалары жыл сайын (қазан айында) шығады, әрқайсысы шамамен 5 жыл қолдау көреді. Қолдау мерзімдері: https://devguide.python.org/versions/
- CPython-нан басқа іске асырылулар да бар: PyPy (JIT-компиляция арқасында жылдамырақ), MicroPython (микроконтроллерлерге арналған).
- «Python дзенінің» толық мәтіні — PEP 20: https://peps.python.org/pep-0020/
