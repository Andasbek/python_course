## 1. Что такое язык программирования?

Люди общаются друг с другом на **естественном языке** (казахском, русском, английском). Но естественный язык многозначен: «**ключ**» — это ключ от двери, родник или скрипичный ключ? Компьютер такой двусмысленности не понимает.

**Язык программирования** (бағдарламалау тілі, programming language) — искусственный язык со строгими правилами (**синтаксисом**), предназначенный для того, чтобы давать инструкции компьютеру.

| Естественный язык | Язык программирования |
|---|---|
| Есть многозначные слова | У каждой команды только одно значение |
| Поймут, даже если вы скажете с ошибкой | Один неверный символ останавливает всю программу |
| Тысячи слов | Немного ключевых слов (в Python около 35) |
| Между людьми | Между человеком и компьютером |

## 2. На каком языке компьютер на самом деле «думает»?

Процессор компьютера понимает только **двоичный код** (0 и 1). Это **машинный код**. Например, команда сложения двух чисел для процессора может выглядеть примерно так:

```text
10110000 00000101
00000100 00000011
```

Человеку работать с таким кодом очень трудно. Поэтому языки постепенно «приближались к человеку».

### Уровни языков программирования

| Уровень | Описание | Пример |
|---|---|---|
| Машинный код | 0 и 1, процессор выполняет напрямую | `10110000 00000101` |
| Язык низкого уровня (Ассемблер) | Короткие английские названия машинных команд | `MOV AL, 5` |
| Язык высокого уровня | Близкие к человеческому языку, понятные слова | `print(5 + 3)` |

Аналогия: машинный код — каждая песчинка кирпича, ассемблер — отдельные кирпичи, язык высокого уровня — готовые стеновые панели. Из панелей дом строится быстрее.

Запись одной задачи на трёх уровнях (сложить 5 и 3 и вывести результат):

```text
Ассемблер (примерно):         Язык C:                        Python:
  MOV AX, 5                     #include <stdio.h>             print(5 + 3)
  ADD AX, 3                     int main() {
  ; чтобы вывести результат,        printf("%d", 5 + 3);
  ; нужно ещё 10-15 строк            return 0;
                                }
```

## 3. Компилятор и интерпретатор

Код, написанный на языке высокого уровня, компьютер напрямую не понимает — его нужно **перевести** в машинный код. Существует два вида специальных программ-переводчиков.

| | Компилятор (compiler) | Интерпретатор (interpreter) |
|---|---|---|
| Как работает? | Заранее полностью переводит всю программу и создаёт готовый файл (.exe) | Переводит программу строка за строкой и сразу выполняет |
| Аналогия | Переводчик, который полностью перевёл и напечатал книгу | Синхронный переводчик, переводящий на переговорах каждое предложение |
| Преимущество | Готовая программа работает очень быстро | Можно быстро проверить код, сразу увидеть ошибку |
| Недостаток | После каждого изменения нужно заново компилировать | Скорость выполнения ниже |
| Языки | C, C++, Go, Rust | Python, JavaScript, PHP |

> Python — **интерпретируемый** язык. Поэтому мы можем написать одну команду и увидеть результат сразу после нажатия Enter. Это очень удобно для обучения.

## 5. История языка Python

- **Автор:** нидерландский программист **Гвидо ван Россум** (Guido van Rossum).
- **Декабрь 1989 года** — на рождественских каникулах «чтобы занять время» начал писать новый язык.
- **1991 год** — опубликована первая версия (0.9.0).
- **2000 год** — Python 2.0.
- **2008 год** — Python 3.0 (обновлённая версия языка, которую мы используем).
- **2020 год** — официальная поддержка Python 2 прекращена.
- Сегодня: Python 3.10, 3.11, 3.12, 3.13 ... новые версии выходят каждый год.

**Откуда взялось название?** Не от змеи! Гвидо любил британское комедийное телешоу «Monty Python's Flying Circus». Он искал для языка короткое, запоминающееся, немного загадочное название и назвал его «Python». Позже на логотипе изобразили двух змей.

**Философия Python** (The Zen of Python) — основные принципы языка. Её можно прочитать в самом Python:

```python
import this
```

Результат (начало):
```text
The Zen of Python, by Tim Peters

Beautiful is better than ugly.
Explicit is better than implicit.
Simple is better than complex.
...
```

Смысл по-русски: «Красивое лучше, чем уродливое. Явное лучше, чем неявное. Простое лучше, чем сложное. Читаемость имеет значение.»

## 6. Особенности и преимущества языка Python

1. **Простой, лёгкий для чтения синтаксис** — код похож на предложения на английском языке.
2. **Интерпретируемый язык** — можно написать и сразу запустить.
3. **Бесплатный и с открытым исходным кодом** — любой может его скачать.
4. **Кроссплатформенный** — одинаково работает в Windows, macOS, Linux.
5. **Богатые библиотеки** — готовые «инструменты»: рисование (turtle), игры (pygame), математика (math), данные (pandas) и др.
6. **Большое сообщество** — ответ на любой вопрос можно найти в интернете.
7. **Структура с помощью отступов** — код автоматически получается аккуратным.

Сравнение: вывод на экран «Привет, мир!».

```text
Java:
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

```python
print("Привет, мир!")
```

Результат:
```text
Привет, мир!
```

В Java — 5 строк, в Python — 1 строка!

**Есть и недостатки:** работает медленнее, чем C++; редко используется для мобильных приложений. Но эти недостатки не мешают обучению и работе во многих областях.

## 8. Интерактивный режим Python

Интерпретатор Python может работать в **интерактивном режиме**: если после знака `>>>` написать команду и нажать Enter — ответ появится сразу.

```text
>>> 2 + 3
5
>>> 100 * 12
1200
>>> print("Python — это здорово!")
Python — это здорово!
```

Как узнать, какая версия Python установлена:

```python
import sys
print(sys.version)
```

Результат (например):
```text
3.12.4 (main, Jun  6 2024, ...) [MSC v.1940 64 bit (AMD64)]
```

Версию можно узнать и из командной строки: `python --version` (в Linux/macOS часто `python3 --version`).

## Частые ошибки
**1. Путать Python 2 и Python 3.** В старых примерах из интернета `print` пишется без скобок:

```text
print "Привет"
```

В Python 3 это вызывает `SyntaxError`. Правильно:

```python
print("Привет")
```

**2. Думать «компьютер же поймёт».** Запись на естественном языке:

```text
напиши на экране привет
```

Компьютер этого не поймёт — это не команда Python. Пишем только по правилам языка.

**3. Не обращать внимания на заглавные и строчные буквы.** Python различает заглавные и строчные буквы:

```text
Print("Привет")   -> NameError: name 'Print' is not defined
print("Привет")   -> Привет
```

**4. Представление «Python — язык о змеях».** Название взято из комедийного шоу (см. выше).

## Основные понятия

| Понятие | Определение |
|---|---|
| Язык программирования | Искусственный язык со строгими правилами для передачи инструкций компьютеру |
| Синтаксис | Правила записи команд в языке |
| Машинный код | Последовательность 0 и 1, которую процессор выполняет напрямую |
| Язык низкого уровня | Язык, близкий к машинному коду (Ассемблер) |
| Язык высокого уровня | Язык, близкий к человеческому (Python, Java, C++) |
| Компилятор | Программа, заранее переводящая всю программу в машинный код |
| Интерпретатор | Программа, переводящая программу строка за строкой и сразу выполняющая её |
| Библиотека (кітапхана, library) | Набор готовых функций и инструментов |
| Кроссплатформенный | Способный работать в разных операционных системах |

## Примечание

- Строго говоря, CPython (основная реализация Python) сначала компилирует код в **байт-код** (файлы `.pyc` в папке `__pycache__`), а затем выполняет его виртуальной машиной. Поэтому деление «компилируемый/интерпретируемый» относится к реализации, а не к языку.
- Список ключевых слов своей версии Python можно посмотреть так: `import keyword; print(keyword.kwlist)`. Их нельзя использовать как имена переменных.
- Новые версии Python выходят ежегодно (в октябре), каждая поддерживается около 5 лет. Сроки поддержки: https://devguide.python.org/versions/
- Кроме CPython существуют другие реализации: PyPy (быстрее за счёт JIT-компиляции), MicroPython (для микроконтроллеров).
- Полный текст «Дзена Python» — PEP 20: https://peps.python.org/pep-0020/
