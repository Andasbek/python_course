# Сабақ 2. Практикалық тапсырмалар: Бағдарламалау тілдері және Python

## Базалық деңгей

### 1-тапсырма. «Аудармашы» ойыны (компилятор мен интерпретатор)
Топ екіге бөлінеді. Педагог әр топқа 5 сөйлемнен тұратын қысқа мәтін береді (мысалы, «Ертегі»).
- **«Компилятор» тобы:** мәтінді түгел ағылшын (немесе орыс) тіліне аударып, қағазға жазып, содан кейін бір-ақ рет оқып береді.
- **«Интерпретатор» тобы:** бір оқушы сөйлемді қазақша оқиды, екіншісі оны бірден аударып айтады, сөйлем сайын.

**Талқылау:** Қай топ тезірек бастады? Қай топ соңында тезірек «орындады»? Мәтінде қате болса, қай топ оны ертерек байқайды?

### 2-тапсырма. Сәйкестендіру
Сол жақтағы ұғымды оң жақтағы анықтамамен сәйкестендіріңіз.

| 5. Синтаксис | | Д. Команда жазу ережелері |

### 3-тапсырма. Уақыт сызығы
Карточкалардағы тілдерді шығу жылы бойынша ретімен орналастырыңыз: Python, C, Java, Fortran, Scratch, JavaScript, C++, Pascal. Python-ды түспен белгілеңіз.

### 4-тапсырма. Онлайн-интерпретаторда алғашқы командалар
Педагог көрсеткен онлайн-интерпретаторды (немесе мұғалімнің компьютеріндегі IDLE-ді) ашып, мына командаларды кезекпен орындаңыз. Әр нәтижені дәптерге жазыңыз.

```python
print("Сәлем, Python!")
print(15 + 27)
print(2026 - 1991)
print("Python" * 3)
```

Сұрақ: Python тіліне биыл неше жыл толады? Оны қай команда есептеді?

### 5-тапсырма. Python философиясы

```text
    int main() { std::cout << "Сәлем!"; return 0; }

            System.out.println("Сәлем!");
        }
    }
```

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Екілік код
Компьютер сандарды екілік жүйеде сақтайды: `1 = 1`, `2 = 10`, `3 = 11`, `4 = 100`, `5 = 101`.
1. 6, 7, 8 сандары екілік жүйеде қалай жазылады?
2. Екілік `1010` саны ондық жүйеде нешеге тең?
3. Python-да тексеріңіз:

```python
print(bin(6), bin(7), bin(8))
print(int("1010", 2))
```

### 9-тапсырма. Өз тіліңді ойлап тап
Роботқа арналған өз «бағдарламалау тіліңізді» ойлап табыңыз: 5–6 команда (мысалы, `ЖҮР 3`, `БҰРЫЛ ОҢ`, `АЛ`, `ҚОЙ`), әр команданың нақты мағынасы және синтаксис ережесі. Осы тілде «роботты бөлменің бұрышынан есікке жеткізіп, қоқысты себетке салу» бағдарламасын жазыңыз.

## Үй тапсырмасы
1. «Python тілі туралы 5 қызықты дерек» атты шағын хабарлама дайындаңыз (жазбаша, 8–10 сөйлем).
2. Кестені толтырыңыз: сіз білетін 3 қосымша/ойын және олар қай тілде жазылған болуы мүмкін (интернеттен тексеріңіз).
3. Келесі сабаққа: таңертеңгі әрекеттеріңізді (оянғаннан мектепке шыққанға дейін) 8–10 қадаммен ретімен жазып келіңіз.
