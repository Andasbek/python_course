### 2-қадам. Бағдарлама қаңқасын жаз
`men_turaly.py` файлын құрып, алдымен тек сипаттама мен бөлім түсініктемелерін жазыңыз:

```python
"""
Бағдарлама: Мен туралы
Автор: ...
Күні: 23.09.2026
Сипаттамасы: ...
"""

# ----- Тақырып -----

# ----- Негізгі мәліметтер -----

# ----- Қызығушылықтарым -----

# ----- Қызықты сандар -----

# ----- Қоштасу -----
```

Іске қосыңыз — ештеңе шықпауы керек (түсініктемелер орындалмайды), бірақ қате де болмауы керек.

### 3-қадам. Бөлімдерді толтыр
Әр бөлімге `print()` командаларын жазыңыз. Әр бөлімнен кейін **іске қосып тексеріңіз**.

### 4-қадам. Есептеу қос
Кемінде бір «қызықты санды» Python есептесін. Идеялар:
- неше ай өмір сүрдім: `жас * 12`;
- неше апта өмір сүрдім: `жас * 52`;
- үйірмеге жылына неше сағат келемін: `36 * 4`;
- мектепке дейін неше қадам: `минут * 100` (шамамен).

## Кеңейтілген деңгей

### 6-тапсырма. Апталық кесте
`\t` арқылы апта күндері мен өз істеріңізді теңестірілген кесте түрінде шығарыңыз (кемінде 4 жол).

### 7-тапсырма. ASCII-сурет
Өзіңізге қатысты сурет қосыңыз (сүйікті жануар, хобби, спорт түрі). Кемінде 4 жол, үш тырнақшамен.

### 8-тапсырма. `sep` пен `end`
- Хоббилерді `sep=" | "` арқылы бір жолда шығарыңыз (тақырыптан кейін бөлгіш тұрып қалмайтындай етіп!).
- Туған күніңізді `sep="."` арқылы шығарыңыз.
- Қоштасу сөзін екі `print()` арқылы, бірақ бір жолда шығарыңыз (`end`).

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. «Жүктелу» анимациясының иллюзиясы
Бағдарламаның басында «жүктелу жолағын» шығарыңыз:
```text
Жүктелуде: [##########----------] 50%
Жүктелуде: [####################] 100%
```
Жолақтағы `#` пен `-` таңбаларын тек мәтінді көбейту арқылы жасаңыз (`"#" * 10`).

### 10-тапсырма. Үлкен әріптер
Өз атыңыздың бірінші әрпін немесе бүкіл атыңызды үлкен «баннер» әріптермен (5 жол биіктігінде) `#` таңбасынан салыңыз.

Мысал («А» әрпі):
```text
  ###
 #   #
 #####
 #   #
 #   #
```

## Үй тапсырмасы
1. «Мен туралы» бағдарламасын аяқтап, өзара тексеруде алған ұсыныстарды енгізіңіз.
2. «Менің досым туралы» немесе «Менің қалам туралы» (Алматы, Түркістан т.б.) бағдарламасын жазыңыз: кемінде 8 дерек, 1 есептеу, жақтаулы тақырып.
3. Ойланыңыз: егер «Мен туралы» бағдарламасында атыңыз 5 рет кездессе, оны өзгерту үшін 5 жерде түзету керек. Мұны қалай жеңілдетуге болады деп ойлайсыз? (Жауабы — келесі сабақта!)

## Бағалау критерийлері

| Критерий | Сипаттамасы | Ұпай |
|---|---|---|
| Бағдарламаның дұрыс жұмыс істеуі және талапқа сай келуі (40%) | Қатесіз іске қосылады (15); кемінде 8 дерек (10); тақырып пен қоштасу бар (5); есептеуді Python жасайды (10) | 40 |
| Шешімнің ұтымдылығы (25%) | `sep`, `end`, `\t`, `\n`, мәтінді көбейту орынды қолданылған (15); ASCII-сурет немесе кесте бар (10) | 25 |
| Кодтың оқылымдылығы (20%) | Сипаттама бар (5); кемінде 3 пайдалы түсініктеме (5); PEP 8 сақталған (5); бөлімдер бос жолмен бөлінген (5) | 20 |
| Дербестік және мерзім (15%) | Өз бетінше жасалған, үлгіден ерекшеленеді (10); сабақ соңында тапсырылды (5) | 15 |
| **Барлығы** | | **100** |

Меңгеру деңгейі: 85–100 — жоғары; 60–84 — орта; 40–59 — бастапқы.

**Толық үлгі (кеңейтілген деңгеймен):**
```python
"""
Бағдарлама: Мен туралы
Автор: Ерлан Қасымов
Күні: 23.09.2026
Сипаттамасы: өзім туралы мәліметтерді, апталық кестемді
және суретті экранға әдемі түрде шығарады.
"""

# ----- Жүктелу жолағы (★ тапсырма) -----
print("Жүктелуде: [" + "#" * 10 + "-" * 10 + "] 50%")
print("Жүктелуде: [" + "#" * 20 + "] 100%")
print()

# ----- Тақырып -----
print("*" * 40)
print("*" + " " * 13 + "МЕН ТУРАЛЫ" + " " * 15 + "*")
print("*" * 40)
print()

# ----- Негізгі мәліметтер -----
print("Аты-жөнім: Ерлан Қасымов")
print("Жасым: 13")
print("Туған күнім:", 14, 3, 2013, sep=".")
print("Қалам: Алматы")
print("Мектебім: №54 мектеп, 7-сынып")
print()

# ----- Қызығушылықтарым -----
print("Хоббиім:", end=" ")  # тақырыптан кейін бөлгіш тұрмауы үшін
print("футбол", "робототехника", "Python", sep=" | ")
print("Сүйікті пәнім: физика")
print("Арманым: робот жасайтын инженер болу")
print()

# ----- Қызықты сандар -----
print("Мен шамамен", 13 * 12, "ай өмір сүрдім")
print("Үйірмеде жылына", 36 * 4, "сағат оқимын")  # 36 апта, аптасына 4 сағат
print()

# ----- Апталық кестем -----
print("Күні\t\tІсім")
print("Дүйсенбі\tPython үйірмесі")
print("Сейсенбі\tфутбол")
print("Сәрсенбі\tPython үйірмесі")
print("Сенбі\t\tробототехника")
print()

# ----- Сурет -----
print("""
   [o_o]
  /|___|\\    Менің роботым!
   |   |
   d   b
""")

# ----- Қоштасу -----
print("Танысқаныңызға", end=" ")
print("рақмет!")
print("*" * 40)
```
