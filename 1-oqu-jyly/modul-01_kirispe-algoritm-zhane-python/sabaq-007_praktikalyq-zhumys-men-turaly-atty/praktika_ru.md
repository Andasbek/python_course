## Базовый уровень

### Шаг 2. Напиши каркас программы
Создайте файл `men_turaly.py` и сначала напишите только описание и комментарии-разделы:

```python
"""
Программа: Обо мне
Автор: ...
Дата: 23.09.2026
Описание: ...
"""

# ----- Заголовок -----

# ----- Основные сведения -----

# ----- Мои интересы -----

# ----- Интересные числа -----

# ----- Прощание -----
```

Запустите — ничего не должно вывестись (комментарии не выполняются), но и ошибок быть не должно.

### Шаг 3. Заполни разделы
Напишите команды `print()` для каждого раздела. После каждого раздела **запускайте и проверяйте**.

### Шаг 4. Добавь вычисление
Пусть Python вычислит хотя бы одно «интересное число». Идеи:
- сколько месяцев я прожил(а): `возраст * 12`;
- сколько недель я прожил(а): `возраст * 52`;
- сколько часов в год я хожу на кружок: `36 * 4`;
- сколько шагов до школы: `минуты * 100` (примерно).

## Продвинутый уровень

### Задание 6. Расписание на неделю
С помощью `\t` выведите дни недели и свои дела в виде выровненной таблицы (не менее 4 строк).

### Задание 7. ASCII-рисунок
Добавьте рисунок, связанный с вами (любимое животное, хобби, вид спорта). Не менее 4 строк, в тройных кавычках.

### Задание 8. `sep` и `end`
- Выведите хобби в одной строке с помощью `sep=" | "` (так, чтобы после заголовка не оставался разделитель!).
- Выведите свой день рождения с помощью `sep="."`.
- Выведите прощальные слова двумя `print()`, но в одной строке (`end`).

## ★ Олимпиадная / творческая задача

### Задание 9. Иллюзия анимации «загрузки»
В начале программы выведите «полосу загрузки»:
```text
Загрузка: [##########----------] 50%
Загрузка: [####################] 100%
```
Символы `#` и `-` в полосе создавайте только умножением текста (`"#" * 10`).

### Задание 10. Большие буквы
Нарисуйте первую букву своего имени или всё имя большими буквами-«баннерами» (высотой 5 строк) из символа `#`.

Пример (буква «А»):
```text
  ###
 #   #
 #####
 #   #
 #   #
```

```python
"""
Программа: Обо мне
Автор: Ерлан Касымов
Дата: 23.09.2026
Описание: красиво выводит на экран сведения обо мне,
моё расписание на неделю и рисунок.
"""

# ----- Полоса загрузки (★ задание) -----

print("Загрузка: [" + "#" * 20 + "] 100%")
print()

# ----- Заголовок -----
print("*" * 40)
print("*" + " " * 15 + "ОБО МНЕ" + " " * 16 + "*")
print("*" * 40)
print()

# ----- Основные сведения -----
print("Фамилия и имя: Ерлан Касымов")
print("Возраст: 13")
print("День рождения:", 14, 3, 2013, sep=".")
print("Город: Алматы")
print("Школа: школа №54, 7 класс")
print()

# ----- Мои интересы -----
print("Хобби:", end=" ")  # чтобы после заголовка не стоял разделитель
print("футбол", "робототехника", "Python", sep=" | ")
print("Любимый предмет: физика")
print("Мечта: стать инженером, который создаёт роботов")
print()

# ----- Интересные числа -----
print("Я прожил примерно", 13 * 12, "месяцев")
print("В кружке я занимаюсь", 36 * 4, "часа в год")  # 36 недель, по 4 часа в неделю
print()

# ----- Моё расписание на неделю -----
print("День\t\tДела")
print("Понедельник\tкружок Python")
print("Вторник\t\tфутбол")
print("Среда\t\tкружок Python")
print("Суббота\t\tробототехника")
print()

# ----- Рисунок -----
print("""
   [o_o]
  /|___|\\    Мой робот!
   |   |
   d   b
""")

# ----- Прощание -----
print("Спасибо за", end=" ")
print("знакомство!")
print("*" * 40)
```
