## 1. «Мен туралы» бағдарламасының құрылымы

«Мен туралы» бағдарламасы — «цифрлық визитка»: ол автор туралы мәліметтерді экранға шығарады. Тіпті шағын бағдарламаны да алдымен **жоспарлаған** ыңғайлы: оны бөлімдерге бөліп, әрқайсысына Python құралын таңдау.

| № | Бөлім | Мазмұны | Python құралы |
|---|---|---|---|
| 1 | Сипаттама | Атауы, авторы, күні, не істейтіні | `"""..."""` (құжаттама жолы) |
| 2 | Тақырып | «МЕН ТУРАЛЫ» жақтауда | `print("=" * 40)` |
| 3 | Негізгі мәлімет | Аты, жасы, мектебі, қаласы | бірнеше мәні бар `print()` |
| 4 | Қызығушылықтарым | Хобби, сүйікті пән, ойын | `print()`, `sep` |
| 5 | Қызықты сандар | Неше ай өмір сүрдім? | тырнақшасыз `12 * 12` есептеуі |
| 6 | Апталық кестем | Үйірме, спорт, музыка | бағандарды теңестіру үшін `\t` |
| 7 | Сурет | Мысық / ракета / ноутбук | үш тырнақшадағы көпжолды жол |
| 8 | Қоштасу | «Рақмет!» | `end` |

Блок-схема тұрғысынан бұл — **сызықтық алгоритм**: «Басы → шығару → шығару → ... → Соңы».

Ұқыпты безендірілген бағдарламаның белгілері:
- файлдың басында үш тырнақшадағы сипаттама бар;
- логикалық бөліктер **бос жолдармен** бөлініп, бөлгіш **түсініктемелермен** белгіленген;
- деректердің кем дегенде бір бөлігін қолмен емес, Python **есептейді**;
- код PEP 8-ге сай (үтірден кейін және операторлардың айналасында бос орын);
- бағдарлама **қатесіз** іске қосылады.

## 2. Бағдарлама мысалы

```python
"""
Бағдарлама: Мен туралы
Автор: Айдана Серікова
Күні: 23.09.2026
Сипаттамасы: өзім туралы мәліметтерді әдемі түрде экранға шығарады.
"""

# ----- Тақырып -----
print("=" * 40)
print("            МЕН ТУРАЛЫ")
print("=" * 40)
print()

# ----- Негізгі мәліметтер -----
print("Аты-жөнім:", "Айдана Серікова")
print("Жасым:", 12)
print("Қалам:", "Алматы")
print("Мектебім:", "№125 мектеп-гимназия, 6-сынып")
print()

# ----- Қызығушылықтарым -----
print("Хоббиім:", "сурет салу", "шахмат", "Python", sep=" | ")
print("Сүйікті пәнім: математика")
print("Арманым: ойын әзірлеуші болу")
print()

# ----- Қызықты сандар -----
# 12 жас толық болғандықтан, айды 12-ге көбейтіп шамамен есептейміз
print("Мен шамамен", 12 * 12, "ай өмір сүрдім")
print("Бұл шамамен", 12 * 365, "күн!")
print()

# ----- Апталық кестем -----
print("Күні\t\tІсім")
print("Дүйсенбі\tPython үйірмесі")
print("Сәрсенбі\tPython үйірмесі")
print("Жұма\t\tшахмат")
print()

# ----- Сурет -----
print("""
   /\\_/\\
  ( ^.^ )   Менің мысығым — Барсик
   > ^ <
""")

# ----- Қоштасу -----
print("Танысқаныңызға", end=" ")
print("рақмет!")
print("=" * 40)
```

Нәтижесі:
```text
========================================
            МЕН ТУРАЛЫ
========================================

Аты-жөнім: Айдана Серікова
Жасым: 12
Қалам: Алматы
Мектебім: №125 мектеп-гимназия, 6-сынып

Хоббиім: | сурет салу | шахмат | Python
Сүйікті пәнім: математика
Арманым: ойын әзірлеуші болу

Мен шамамен 144 ай өмір сүрдім
Бұл шамамен 4380 күн!

Күні		Ісім
Дүйсенбі	Python үйірмесі
Сәрсенбі	Python үйірмесі
Жұма		шахмат


   /\_/\
  ( ^.^ )   Менің мысығым — Барсик
   > ^ <

Танысқаныңызға рақмет!
========================================
```

**Назар аударыңыз:** «Хоббиім: | сурет салу» жолында бөлгіш тақырыптан кейін де қойылды. Бұл — шағын **логикалық қате**: `sep` барлық мәндердің арасына қойылады. Қалай түзетуге болады? Мысалы, тақырыпты бөлек `print("Хоббиім:", end=" ")` арқылы шығарып, қалғанын `sep=" | "` арқылы шығару. Нәтижені үнемі тексеріп отырудың маңызы осында!

## 3. Бағдарламаны қадамдап әзірлеу

Кәсіби бағдарламашылар кодты **шағын қадамдармен** жазып, әр қадамды тексереді (инкременттік әзірлеу):

1. **Жоспар.** Бағдарлама бөлімдерін және әрқайсысының құралдарын анықтаңыз (жоғарыдағы кесте).
2. **Қаңқа.** Сипаттама мен бөлім түсініктемелерін (`# ----- ... -----`) жазыңыз — бұл бағдарламаның «қаңқасы». Мұндай файлды іске қосуға болады: түсініктемелер орындалмайды.
3. **Толтыру.** Әр бөлімді біртіндеп толтырыңыз. **Әр 3–4 жолдан кейін іске қосып** тексеріңіз — өзгертілген код аз болғанда қатені табу оңай.
4. **Безендіру.** Жақтау, бос жолдар, кесте, сурет қосыңыз.
5. **Тестілеу.** Нақты шығысты күтілгенмен салыстырыңыз: есептеулер дұрыс па, бағандар тегіс пе, артық бөлгіштер жоқ па.

Бағдарлама қаңқасы:

```python
"""
Бағдарлама: Мен туралы
Автор: ...
"""

# ----- Тақырып -----

# ----- Негізгі мәліметтер -----

# ----- Қызықты сандар -----
```

## 4. Code review — кодты тексеру

**Code review** (кодты шолу) — кодты басқа бағдарламашы оқып, жақсарту ұсыныстарын айтатын тәжірибе. Неге назар аударады:
- бағдарлама жұмыс істей ме, нәтиже дұрыс па;
- түсініктемелер мен атаулар түсінікті ме;
- PEP 8 сақталған ба: үтірден кейін бос орын, операторлар айналасында бос орын, `(` алдында бос орын жоқ;
- жеңілдетуге болатын қайталанатын код жоқ па (мысалы, қырық `=` таңбасының орнына `"=" * 40`).

Ескертулер нақты айтылады («12-жолда үтірден кейін бос орын жоқ»), ал түзетуді кодтың авторы енгізеді.

## Жиі кездесетін қателер

**1. Санды тырнақшаға алып, есептеуді «өшіру».**
```python
print("Мен шамамен", "12 * 12", "ай өмір сүрдім")
```
Нәтижесі:
```text
Мен шамамен 12 * 12 ай өмір сүрдім
```
Дұрысы — өрнек тырнақшасыз:
```python
print("Мен шамамен", 12 * 12, "ай өмір сүрдім")
```

**2. Үш тырнақшадағы суретте `\` таңбасы.** `\` арнайы таңба, сондықтан суретте `\\` деп екі рет жазамыз (немесе суретті `\`-сыз саламыз).

**3. Кодты соңында бір-ақ рет іске қосу.** 40 жол жазып, бірден 5 қате шыққанда оларды табу қиын. Жиі іске қосыңыз!

**4. Файлды сақтамау.** IDLE іске қосар алдында файлды сақтауды талап етеді («Source Must Be Saved»), ал басқа редакторларда сақталмаған өзгерістер терминалдан іске қосқанда ескерілмейді. Әр іске қосудың алдында файлды сақтаңыз (Ctrl+S).

**5. Шегініс.** Барлық `print` жолдың басынан жазылады; артық бос орын `IndentationError` береді.

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Сызықтық бағдарлама | Командалары жоғарыдан төмен ретімен, бір реттен орындалатын бағдарлама |
| Жоспарлау | Кодты жазбас бұрын мазмұн мен құрылымды анықтау |
| Бағдарлама қаңқасы | Бөлімдерді белгілейтін түсініктемелерден тұратын бастапқы құрылым |
| Тестілеу | Бағдарламаны іске қосып, нәтижені күтілгенмен салыстыру |
| Code review (кодты шолу) | Кодты басқа бағдарламашының оқып, жақсарту ұсыныстарын айтуы |
| ASCII-сурет | Мәтіндік таңбалардан салынған сурет |

## Ескерту

- Жолды тек бүтін санға көбейтуге болады: `"=" * 40` жұмыс істейді, ал `"=" * 2.5` `TypeError` береді; `"=" * 0` бос жол береді.
- `\t` табуляциясы мәтінді 8-ге еселі позицияларға теңестіреді (көп консольде), сондықтан ұзын сөздерге екінші `\t` керек, ал қысқаларына — жоқ. Дәлірек теңестіруді f-жолдармен жасауға болады: `f"{'Сәрсенбі':<12}"`.
- Қарапайым жолда `\` арнайы тізбекті бастайды; ASCII-суреттер үшін `\` бір рет жазылатын `r"""..."""` «шикі» жолдары ыңғайлы.
- Модульдің құжаттама жолын бағдарламаның ішінен оқуға болады: `print(__doc__)`.
- Бағдарлама мен хабарлама мәтінін кез келген тілде жазуға болады (Python 3 Unicode-пен жұмыс істейді), бірақ файл атауларын латынша берген дұрыс: `men_turaly.py`.
