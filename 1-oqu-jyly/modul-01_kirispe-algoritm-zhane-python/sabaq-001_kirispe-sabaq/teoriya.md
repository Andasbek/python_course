## 1. Бағдарлама деген не?

**Бағдарлама** (программа, program) — компьютер орындайтын нұсқаулар (командалар) тізбегі. Бағдарламаны бағдарламалау тілінде жазады; жазылған мәтінді **код** дейді.

Компьютер командаларды **қатаң ретімен** — жоғарыдан төмен, жолма-жол — орындайды және «не айтқыңыз келгенін» емес, дәл не жазылғанын жасайды.

Python тіліндегі ең қарапайым бағдарлама — экранға сәлем жазу:

```python
print("Сәлем, «Python» үйірмесі!")
print("Бүгін біз бағдарламалау әлеміне қадам басамыз.")
```

Нәтижесі:
```text
Сәлем, «Python» үйірмесі!
Бүгін біз бағдарламалау әлеміне қадам басамыз.
```

## 2. Python бағдарламаны қалай орындайды

Python — **интерпретацияланатын** тіл: арнайы **интерпретатор** бағдарламасы (`python`) кодты оқып, бірден орындайды.

| Қадам | Не болады |
|---|---|
| 1. Жазу | Код `.py` кеңейтілуі бар мәтіндік файлға сақталады, мысалы `salem.py` |
| 2. Іске қосу | Интерпретатор файлды ашады (`python salem.py` немесе редактордағы Run батырмасы) |
| 3. Тексеру | Python синтаксисті тексереді; қате болса, `SyntaxError` хабарын шығарады және ештеңе орындамайды |
| 4. Орындау | Командалар жоғарыдан төмен кезекпен орындалады |
| 5. Нәтиже | Шығыс консольде (шығару терезесінде) пайда болады |

Python-ды **интерактивті режимде** де (`>>>` шақыруы) қолдануға болады: әр команда Enter басқан бойда орындалады. Бұл, мысалы, калькулятор ретінде ыңғайлы:

```python
print(2026 - 2014)
print(365 * 24)
```

Нәтижесі:
```text
12
8760
```

## 3. Python не істей алады: бағдарлама мысалдары

Тасбақа өрнек салады (`turtle` модулі):

```python
import turtle

t = turtle.Turtle()
t.color("blue")
for i in range(36):
    t.forward(100)
    t.right(170)
turtle.done()
```

Нәтижесі: экранда көк түсті жұлдыз тәрізді өрнек пайда болады.

«Сан табу» ойыны (`random` модулі, `while` циклі, `if` шарты):

```python
import random

secret = random.randint(1, 20)
print("Мен 1-ден 20-ға дейін сан ойладым. Табыңыз!")
guess = 0
while guess != secret:
    guess = int(input("Сіздің болжамыңыз: "))
    if guess < secret:
        print("Үлкенірек сан айтыңыз")
    elif guess > secret:
        print("Кішірек сан айтыңыз")
print("Құттықтаймын, таптыңыз!")
```

## 4. Python тілінің негізгі құрылымдары

Python-дағы кез келген бағдарлама осы «кірпіштерден» құралады:

| Құрылым | Мысал | Қызметі |
|---|---|---|
| Шығару | `print("Сәлем")` | Деректерді экранға көрсету |
| Айнымалы | `age = 12` | Мәнді атпен есте сақтау |
| Енгізу | `name = input()` | Пайдаланушыдан дерек алу |
| Шарт | `if age >= 18:` | Шартқа байланысты әрекетті таңдау |
| Цикл | `for i in range(5):` | Әрекеттерді бірнеше рет қайталау |
| Тізім | `nums = [1, 2, 3]` | Мәндер жинағын сақтау |
| Сөздік | `d = {"кот": "мысық"}` | «Кілт — мән» жұптарын сақтау |
| Функция | `def hello():` | Командалар тобына ат беріп, оны шақыру |
| Модуль | `import math` | Дайын құралдарды қосу |
| Файл | `open("data.txt")` | Деректерді дискіге жазу және оқу |

## 5. Python қай салада қолданылады

| Сала | Не жасайды | Python құралдары |
|---|---|---|
| Ойын әзірлеу | Компьютерлік ойындар | `pygame` |
| Веб-әзірлеу | Сайттар мен веб-қосымшалар | Django, Flask |
| Деректер талдау | Сандардан қорытынды, графиктер | pandas, matplotlib |
| Жасанды интеллект | Сөйлеуді және суретті танитын жүйелер | scikit-learn, PyTorch |
| Робототехника | Роботтар мен «ақылды» құрылғыларға арналған бағдарламалар | MicroPython |
| Жұмыс үстелі қосымшалары | Терезесі мен батырмалары бар бағдарламалар | `tkinter` |

## 6. Код файлдарын қалай сақтау керек

Бағдарлама файлдарын бір папкада, ішкі папкаларға бөліп сақтаған ыңғайлы:

```text
D:\Python_Uyirme\
    Familiya_Aty\
        sabaq01\
        sabaq02\
        ...
        zhobalar\
```

Ат қою ережелері:
- Папка мен файл атауларын **латын әріптерімен**, бос орынсыз жазамыз: `men_turaly.py`, `sabaq05`.
- Python код файлының кеңейтілуі — **`.py`**.
- Өз файлыңызды стандартты модульдің атымен (`turtle.py`, `random.py`, `math.py`) атауға болмайды: онда `import turtle` нағыз модульдің орнына сіздің файлыңызды жүктейді.

## Жиі кездесетін қателер

| Қате | Неге қауіпті? | Дұрысы |
|---|---|---|
| Файл `Жаңа файл (1).py` деп аталған | Атаудағы бос орын мен кирилл әрпі консольден іске қосуға және импорттауға кедергі келтіреді | `sabaq01_salem.py` |
| Файл `turtle.py` деп аталған | `import turtle` сіздің файлыңызды импорттайды, бағдарлама қатемен тоқтайды | `my_turtle.py` |
| Файл `.py` кеңейтілуінсіз сақталған | Редактор кодты бояп көрсетпейді, файл бағдарлама ретінде іске қосылмайды | `salem.py` |
| Кодтағы жолдың айналасында «шыршалы» тырнақша: `print(«Сәлем»)` | `SyntaxError` — Python тек `"` және `'` белгілерін түсінеді | `print("Сәлем")` |

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Бағдарлама (программа, program) | Компьютер орындайтын командалар тізбегі |
| Код | Бағдарламалау тілінде жазылған бағдарлама мәтіні |
| Бағдарламашы (программист) | Бағдарлама жазатын маман |
| Python | Қарапайым әрі қуатты, жалпы мақсаттағы бағдарламалау тілі |
| Интерпретатор | Python кодын оқып, орындайтын бағдарлама |
| `.py` файлы | Python тіліндегі бағдарлама коды бар мәтіндік файл |

## Ескерту

- Қазір **Python 3** қолданылады; Python 2 2020 жылдан бері ресми түрде қолдау көрмейді. Ескі кітаптардағы `print "Сәлем"` (жақшасыз) сияқты мысалдар Python 3-те қате береді.
- Python бас және кіші әріпті ажыратады: `print` пен `Print` — әртүрлі атаулар, `Print("Сәлем")` `NameError` береді.
- `>>>` интерактивті режимінде өрнектің мәні автоматты түрде шығады, ал `.py` файлында шығару үшін міндетті түрде `print()` керек.
- Ресми құжаттама мен оқулық: https://docs.python.org/3/tutorial/ (құжаттама интерфейсінің бірнеше тілге аудармасы бар).
- Жолдар (тырнақшадағы мәтін) кез келген таңбаны, соның ішінде кирилл мен қазақ әріптерін қамти алады, ал файлдар мен айнымалылардың атын латынша жазған дұрыс.
