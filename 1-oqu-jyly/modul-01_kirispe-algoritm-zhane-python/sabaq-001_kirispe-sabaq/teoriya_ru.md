## 1. Что такое программа?

**Программа** (бағдарлама, program) — последовательность инструкций (команд), которые выполняет компьютер. Программу пишут на языке программирования; написанный текст называют **кодом**.

Компьютер выполняет команды **строго по порядку** — сверху вниз, строка за строкой — и делает ровно то, что написано, а не то, что «имелось в виду».

Самая простая программа на Python — вывод приветствия на экран:

```python
print("Привет, кружок «Python»!")
print("Сегодня мы делаем шаг в мир программирования.")
```

Результат:
```text
Привет, кружок «Python»!
Сегодня мы делаем шаг в мир программирования.
```

## 2. Как Python выполняет программу

Python — **интерпретируемый** язык: специальная программа-**интерпретатор** (`python`) читает код и сразу выполняет его.

| Шаг | Что происходит |
|---|---|
| 1. Написание | Код сохраняется в текстовый файл с расширением `.py`, например `salem.py` |
| 2. Запуск | Интерпретатор открывает файл (`python salem.py` или кнопка Run в редакторе) |
| 3. Проверка | Python проверяет синтаксис; при ошибке выводит сообщение `SyntaxError` и ничего не выполняет |
| 4. Выполнение | Команды выполняются по очереди сверху вниз |
| 5. Результат | Вывод появляется в консоли (окне вывода) |

Python можно использовать и в **интерактивном режиме** (приглашение `>>>`): каждая команда выполняется сразу после нажатия Enter. Это удобно, например, как калькулятор:

```python
print(2026 - 2014)
print(365 * 24)
```

Результат:
```text
12
8760
```

## 3. Что умеет Python: примеры программ

Черепашка рисует узор (модуль `turtle`):

```python
import turtle

t = turtle.Turtle()
t.color("blue")
for i in range(36):
    t.forward(100)
    t.right(170)
turtle.done()
```

Результат: на экране появляется узор синего цвета в форме звезды.

Игра «Угадай число» (модуль `random`, цикл `while`, условие `if`):

```python
import random

secret = random.randint(1, 20)
print("Я загадал число от 1 до 20. Угадайте!")
guess = 0
while guess != secret:
    guess = int(input("Ваш вариант: "))
    if guess < secret:
        print("Назовите число побольше")
    elif guess > secret:
        print("Назовите число поменьше")
print("Поздравляю, вы угадали!")
```

## 4. Основные конструкции языка Python

Из этих «кирпичиков» строится любая программа на Python:

| Конструкция | Пример | Назначение |
|---|---|---|
| Вывод | `print("Привет")` | Показать данные на экране |
| Переменная | `age = 12` | Запомнить значение под именем |
| Ввод | `name = input()` | Получить данные от пользователя |
| Условие | `if age >= 18:` | Выбрать действие в зависимости от условия |
| Цикл | `for i in range(5):` | Повторить действия несколько раз |
| Список | `nums = [1, 2, 3]` | Хранить набор значений |
| Словарь | `d = {"кот": "мысық"}` | Хранить пары «ключ — значение» |
| Функция | `def hello():` | Дать имя группе команд и вызывать её |
| Модуль | `import math` | Подключить готовые инструменты |
| Файл | `open("data.txt")` | Читать и записывать данные на диск |

## 6. Как хранить файлы с кодом

Файлы программ удобно хранить в одной папке, разложив по подпапкам:

```text
D:\Python_Uyirme\
    Familiya_Aty\
        sabaq01\
        sabaq02\
        ...
        zhobalar\
```

Правила именования:
- Названия папок и файлов пишем **латинскими буквами**, без пробелов: `men_turaly.py`, `sabaq05`.
- Расширение файла с кодом Python — **`.py`**.
- Нельзя называть свой файл так же, как стандартный модуль (`turtle.py`, `random.py`, `math.py`): тогда `import turtle` загрузит ваш файл вместо настоящего модуля.

## Частые ошибки

| Ошибка | Чем опасна? | Правильно |
|---|---|---|
| Файл назван `Новый файл (1).py` | Пробелы и кириллица в имени мешают запуску из консоли и импорту | `sabaq01_salem.py` |
| Файл назван `turtle.py` | `import turtle` импортирует ваш файл, и программа падает с ошибкой | `my_turtle.py` |
| Файл сохранён без расширения `.py` | Редактор не подсвечивает код, файл не запускается как программа | `salem.py` |
| Кавычки «ёлочки» вокруг строки в коде: `print(«Привет»)` | `SyntaxError` — Python понимает только `"` и `'` | `print("Привет")` |

## Основные понятия

| Понятие | Определение |
|---|---|
| Программа (бағдарлама, program) | Последовательность команд, выполняемых компьютером |
| Код | Текст программы, написанный на языке программирования |
| Программист (бағдарламашы) | Специалист, который пишет программы |
| Python | Простой и мощный язык программирования общего назначения |
| Интерпретатор | Программа, которая читает и выполняет код Python |
| Файл `.py` | Текстовый файл с кодом программы на Python |

## Примечание

- Сейчас используется **Python 3**; Python 2 официально не поддерживается с 2020 года. Примеры из старых книг вида `print "Привет"` (без скобок) в Python 3 вызывают ошибку.
- Python чувствителен к регистру: `print` и `Print` — разные имена, `Print("Привет")` даст `NameError`.
- В интерактивном режиме `>>>` значение выражения выводится автоматически, а в файле `.py` для вывода обязательно нужен `print()`.
- Официальная документация и учебник: https://docs.python.org/3/tutorial/ (есть перевод интерфейса документации на разные языки).
- Строки (текст в кавычках) могут содержать любые символы, включая кириллицу и казахские буквы, а вот имена файлов и переменных лучше писать латиницей.
