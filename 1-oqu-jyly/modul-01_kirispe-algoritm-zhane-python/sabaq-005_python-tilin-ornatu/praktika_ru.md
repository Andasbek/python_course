# Урок 5. Практические задания: установка Python и print()

## Базовый уровень

### Задание 1. Проверка установки
1. Откройте командную строку (cmd) и выполните команду `python --version`. Запишите номер версии в тетрадь.
2. Откройте IDLE. В Shell (`>>>`) по очереди введите следующие выражения и перепишите результаты в тетрадь:
```text
>>> 15 + 27
>>> 100 - 37
>>> 12 * 12
>>> 2026 - 2014
```
3. Повторите то же самое в Thonny (если он установлен).

### Задание 2. Первый файл
Откройте в IDLE **File → New File** и наберите следующую программу. Сохраните её в своей папке под именем `sabaq05_salem.py` и запустите клавишей **F5**.

```python
print("Привет, мир!")
print("Я написал свою первую программу на Python!")
```

Ожидаемый результат:
```text
Привет, мир!
Я написал свою первую программу на Python!
```

### Задание 3. Визитка
Напишите программу, которая выводит 4 строки о вас (`vizitka.py`):

Пример вывода:
```text
Фамилия и имя: Сериков Айдар
Школа: г. Алматы, школа №125
Класс: 6
Хобби: футбол, шахматы
```

### Задание 4. Вычисли и выведи
Напишите программу, которая с помощью `print()` отвечает на следующие вопросы (пусть ответ вычисляет сам Python):
1. Сколько секунд в одном часе?
2. Сколько часов в 1 году (365 дней)?
3. 5 тетрадей по 180 тенге и 2 ручки по 250 тенге — сколько всего тенге?

Пример вывода:
```text
Количество секунд в часе: 3600
Количество часов в году: 8760
Всего (тенге): 1400
```
*Подсказка:* `print("Количество секунд в часе:", 60 * 60)`.

### Задание 5. sep и end
Выведите каждую строку одной командой `print()`:
1. Сегодняшняя дата: `16.09.2026` (числа передайте отдельно: 16, 9, 2026 — примечание: выведется «9», а не «09», это нормально).
2. `Алматы | Астана | Шымкент | Актобе`
3. С помощью двух `print()` в одной строке: `Python — это интересно!`

## Продвинутый уровень

### Задание 6. Рисунок из символов
С помощью команд `print()` нарисуйте рисунок не менее чем из 5 строк: дом, ёлку, робота или первую букву своего имени.

Пример (ёлка):
```text
    *
   ***
  *****
 *******
    |
```

### Задание 7. Таблица
С помощью символа `\t` выведите в виде таблицы дни, предмет и время занятий:
```text
День		Предмет		Время
Понедельник	Python		15:00
Среда		Python		15:00
```

### Задание 8. В трёх средах
Откройте программу из задания 3 в VS Code и запустите её кнопкой ▶. Затем запустите её в терминале командой `python vizitka.py`. Какая из трёх сред (IDLE, Thonny, VS Code) вам понравилась? Почему? Напишите 2–3 предложения.

## ★ Олимпиадная / творческая задача

### Задание 9. Один print — весь рисунок
Выведите рисунок из задания 6 **только одной** командой `print()` (двумя способами: с помощью `\n` и с помощью тройных кавычек `"""`).

### Задание 10. Узор через умножение
Используя умножение текста (`"*" * 5`), выведите следующий треугольник. Ни в одной строке нельзя писать символ `*` внутри кавычек несколько раз подряд:
```text
*
**
***
****
*****
```
