## 1. Установка Python

Python — бесплатный. Скачивать его правильно только с **официального сайта**: **https://www.python.org** (в файле, скачанном со сторонних сайтов, может быть вирус).

### Шаги установки в Windows
1. python.org → **Downloads** → нажмите кнопку «Download Python 3.x.x» (версия 3.10 или новее).
2. Откройте скачанный файл `python-3.x.x-amd64.exe`.
3. **Важно!** Поставьте галочку **«Add python.exe to PATH»** внизу окна. (Иначе Python не будет найден из командной строки.)
4. Нажмите кнопку **«Install Now»**.
5. Когда появится надпись «Setup was successful» — **Close**.

### macOS / Linux
- macOS: скачайте с python.org установщик `.pkg` и установите по инструкции.
- Linux: Python обычно уже установлен; если нет — устанавливается через менеджер пакетов.

### Проверка установки
Откройте Пуск → «cmd» (Командная строка) или «PowerShell» и введите команду:

```bash
python --version
```

Результат (например):
```text
Python 3.12.4
```

В macOS/Linux пишется `python3 --version`.

## 2. Среды программирования (IDE)

**Среда разработки** (даму ортасы, IDE — Integrated Development Environment) — программа для написания, запуска кода и поиска ошибок. Её можно сравнить с «текстовым редактором» писателя, но с множеством возможностей для программиста.

| Среда | Особенность | Кому удобна? |
|---|---|---|
| **IDLE** | Устанавливается автоматически вместе с Python; очень простая | Начинающим, для быстрой проверки |
| **Thonny** | Специально для учащихся; Python уже внутри; есть таблица переменных и пошаговое выполнение (debugger) | Начинающим учащимся — самая удобная |
| **VS Code** | Профессиональный бесплатный редактор; с помощью расширений (extensions) настраивается под любой язык | Для больших проектов и профессиональной работы |

### 2.1. IDLE
Пуск → **IDLE (Python 3.x)**. Открывшееся окно — **Python Shell** (интерактивный режим). Здесь команда, написанная после знака `>>>`, выполняется сразу при нажатии Enter.

```text
>>> print("Привет!")
Привет!
>>> 7 * 8
56
```

Создание файла: **File → New File** (Ctrl+N). Пишем код, сохраняем с расширением `.py` через **File → Save** (Ctrl+S), запускаем через **Run → Run Module** (**F5**).

### 2.2. Thonny
Сайт: **https://thonny.org**. Окно состоит из двух частей:
- **верхняя часть** — редактор (код в файле);
- **нижняя часть** — Shell (результат и интерактивный режим).

Запуск — зелёная кнопка ▶ или **F5**. Меню **View → Variables** показывает значения переменных. Пошаговое выполнение — кнопка 🐞 «Debug».

### 2.3. VS Code
Сайт: **https://code.visualstudio.com**. После установки:
1. В разделе **Extensions** (Ctrl+Shift+X) слева установите расширение **«Python»** (Microsoft).
2. **File → Open Folder** — откройте свою рабочую папку.
3. Создайте новый файл и сохраните его как `salem.py`.
4. Нажмите кнопку ▶ (**Run Python File**) в правом верхнем углу. Результат появится в нижней панели **Terminal**.

Можно запустить и из терминала:

```bash
python salem.py
```

## 3. Интерактивный режим и файловый режим

| | Интерактивный режим (Shell, `>>>`) | Файловый режим (файл `.py`) |
|---|---|---|
| Как работает? | Каждая команда выполняется сразу | Вся программа пишется, затем запускается |
| Сохраняется? | Нет — если закрыть окно, код пропадёт | Да — сохраняется в файле |
| Для чего? | Как калькулятор, быстрая проверка | Написание настоящих программ |
| Результат | Значение выражения выводится и без `print` | Выводится только через `print()` |

Важное отличие: если в Shell написать `2 + 3`, появится `5`. А если написать `2 + 3` в файле — **ничего не появится**, потому что мы не просили выводить результат на экран. В файле всегда пишем `print(2 + 3)`.

### Правила именования файлов
- Расширение — `.py`: `salem.py`, `men_turaly.py`.
- Только латинские буквы, цифры и `_`; без пробелов: `sabaq05_print.py`.
- Не называйте файл именами модулей Python: `turtle.py`, `random.py`, `math.py` — позже это вызовет ошибку!

## 4. Первая программа: функция print()

`print()` — функция **вывода** информации на экран (блок «вывод» — параллелограмм в блок-схеме). Что напишем в скобках, то она и выведет.

### 4.1. Вывод текста
Текст (строка, жол) берётся в **кавычки**: двойные `"..."` или одинарные `'...'`.

```python
print("Привет, мир!")
print('Меня зовут Айдана')
```

Результат:
```text
Привет, мир!
Меня зовут Айдана
```

Если внутри текста нужны кавычки, используем кавычки другого вида:

```python
print('Он сказал мне: "Учи Python!"')
print("It's Python")
```

Результат:
```text
Он сказал мне: "Учи Python!"
It's Python
```

### 4.2. Вывод чисел и вычислений
Числа пишутся без кавычек. Python сначала вычисляет выражение, а затем выводит результат.

```python
print(25)
print(12 + 30)
print(7 * 6)
print("7 * 6")
```

Результат:
```text
25
42
42
7 * 6
```

Обратите внимание на последнюю строку: `"7 * 6"` в кавычках не вычисляется — это просто текст!

### 4.3. Вывод нескольких значений
Можно передать несколько значений через запятую — они выводятся через **пробел**.

```python
print("В неделе", 7, "дней")
print("В сутках", 24 * 60, "минут")
```

Результат:
```text
В неделе 7 дней
В сутках 1440 минут
```

### 4.4. Пустая строка
`print()` с пустыми скобками выводит пустую строку:

```python
print("Первая строка")
print()
print("Третья строка")
```

Результат:
```text
Первая строка

Третья строка
```

### 4.5. Параметр sep — разделитель
По умолчанию между значениями ставится пробел. С помощью `sep=` задаём другой разделитель:

```python
print(2, 9, 2026, sep=".")
print("Алматы", "Астана", "Шымкент", sep=" -> ")
print("a", "b", "c", sep="")
```

Результат:
```text
2.9.2026
Алматы -> Астана -> Шымкент
abc
```

### 4.6. Параметр end — конец строки
По умолчанию в конце каждого `print()` происходит переход на новую строку. `end=` это меняет:

```python
print("Загрузка", end="")
print("...", end=" ")
print("готово!")
```

Результат:
```text
Загрузка... готово!
```

### 4.7. Специальные символы: \n и \t
- `\n` — новая строка;
- `\t` — табуляция (большой отступ, для выравнивания столбцов).

```python
print("Первая строка\nВторая строка")
print("Имя\tВозраст")
print("Ерлан\t12")
```

Результат:
```text
Первая строка
Вторая строка
Имя	Возраст
Ерлан	12
```

### 4.8. Многострочный текст и «рисунок»
Тройные кавычки `"""..."""` задают многострочный текст. С их помощью можно рисовать символами:

```python
print("""
   /\\_/\\
  ( o.o )
   > ^ <
Кошка передаёт привет!
""")
```

Результат:
```text

   /\_/\
  ( o.o )
   > ^ <
Кошка передаёт привет!

```

(`\\` выводит одну обратную косую черту, потому что символ `\` имеет в Python особое значение.)

### 4.9. «Умножение» текста
```python
print("=" * 20)
print("Ха" * 3)
```

Результат:
```text
====================
ХаХаХа
```

## Частые ошибки
**1. Забыли закрыть кавычку.**
```text
print("Привет)
SyntaxError: unterminated string literal
```
Правильно:
```python
print("Привет")
```

**2. Забыли закрыть скобку.**
```text
print("Привет"
SyntaxError: '(' was never closed
```
Правильно:
```python
print("Привет")
```

**3. Текст без кавычек.**
```text
print(Привет)
NameError: name 'Привет' is not defined
```
Слово без кавычек Python считает именем переменной. Правильно:
```python
print("Привет")
```

**4. Команда написана с заглавной буквы или с ошибкой.**
```text
Print("Привет")   -> NameError: name 'Print' is not defined
pritn("Привет")   -> NameError: name 'pritn' is not defined
```
Правильно: `print` — только строчными буквами.

**5. Кавычки «» или скобки из русской/казахской раскладки.**
```text
print(«Привет»)
SyntaxError: invalid character '«' (U+00AB)
```
При написании кода переключайте клавиатуру на **английскую** раскладку и используйте символ `"` (Shift + ').

**6. Лишний пробел в начале строки.**
```text
 print("Привет")
IndentationError: unexpected indent
```
Команды верхнего уровня пишутся с самого начала строки; отступ допустим только внутри блоков (`if`, `for`, `def` и т.п.).

**7. Запуск файла без сохранения или без расширения `.py`.** IDLE спросит «Source Must Be Saved» — сначала сохраните.

## Основные понятия

| Понятие | Определение |
|---|---|
| IDE (среда разработки) | Программа для написания, запуска кода и поиска ошибок |
| IDLE | Простая среда, устанавливаемая вместе с Python |
| Thonny | Среда Python для учащихся |
| VS Code | Профессиональный редактор кода с расширениями |
| Shell (интерактивный режим) | Режим, в котором команды выполняются сразу после знака `>>>` |
| Файл `.py` | Файл, в котором хранится программа на Python |
| `print()` | Функция, выводящая информацию на экран |
| Строка (жол, string) | Текст, заключённый в кавычки |
| `sep` | Разделитель между значениями в `print()` |
| `end` | Символ, который ставится в конце `print()` (по умолчанию — новая строка) |
| `\n`, `\t` | Символы новой строки и табуляции |

## Примечание

- При установке в Windows обязательно отметьте «Add python.exe to PATH»; если забыли — запустите установщик снова и выберите **Modify**, либо используйте лаунчер `py` (`py --version`, `py salem.py`).
- Полная сигнатура: `print(*objects, sep=' ', end='\n', file=None, flush=False)` — документация: https://docs.python.org/3/library/functions.html#print
- Чтобы символ `\` в строке не считался началом спецпоследовательности, используйте «сырые» строки: `print(r"C:\new\table")`.
- По PEP 8 после запятой ставится пробел, а перед открывающей скобкой вызова — нет: `print("a", "b")`, а не `print ("a","b")`.
- Тексты сообщений об ошибках зависят от версии: например, `'(' was never closed` и `unterminated string literal` появились в Python 3.10; в старых версиях сообщения менее понятные.
