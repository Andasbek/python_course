## 1. Python-ды орнату

Python — тегін. Оны тек **ресми сайттан** жүктеген дұрыс: **https://www.python.org** (бөгде сайттардан жүктелген файлда вирус болуы мүмкін).

### Windows жүйесінде орнату қадамдары
1. python.org → **Downloads** → «Download Python 3.x.x» батырмасын басыңыз (3.10 немесе одан жаңа нұсқа).
2. Жүктелген `python-3.x.x-amd64.exe` файлын ашыңыз.
3. **Маңызды!** Терезенің төменгі жағындағы **«Add python.exe to PATH»** белгісін қойыңыз. (Әйтпесе командалық жолдан Python табылмайды.)
4. **«Install Now»** батырмасын басыңыз.
5. «Setup was successful» жазуы шыққанда — **Close**.

### macOS / Linux
- macOS: python.org-тан `.pkg` орнатушысын жүктеп, нұсқау бойынша орнатасыз.
- Linux: Python әдетте орнатылған болады; жоқ болса пакет менеджері арқылы орнатылады.

### Орнатылғанын тексеру
Пуск → «cmd» (Командная строка) немесе «PowerShell» ашып, мына команданы жазыңыз:

```bash
python --version
```

Нәтижесі (мысалы):
```text
Python 3.12.4
```

macOS/Linux жүйелерінде `python3 --version` деп жазылады.

## 2. Бағдарламалау орталары (IDE)

**Даму ортасы** (среда разработки, IDE — Integrated Development Environment) — код жазуға, іске қосуға және қате табуға арналған бағдарлама. Оны жазушының «мәтіндік редакторына» ұқсатуға болады, бірақ бағдарламашыға арналған көп мүмкіндіктері бар.

| Орта | Ерекшелігі | Кімге ыңғайлы? |
|---|---|---|
| **IDLE** | Python-мен бірге автоматты түрде орнатылады; өте қарапайым | Бастауыштарға, жылдам тексеруге |
| **Thonny** | Арнайы оқушыларға арналған; ішінде Python бар; айнымалылар кестесі мен қадамдық орындау (debugger) бар | Жаңа бастаған оқушыларға — ең ыңғайлысы |
| **VS Code** | Кәсіби, тегін редактор; кеңейтімдер (extensions) арқылы кез келген тілге бейімделеді | Үлкен жобалар мен кәсіби жұмыс үшін |

### 2.1. IDLE
Пуск → **IDLE (Python 3.x)**. Ашылған терезе — **Python Shell** (интерактивті режим). Мұнда `>>>` белгісінен кейін жазылған команда Enter басқанда бірден орындалады.

```text
>>> print("Сәлем!")
Сәлем!
>>> 7 * 8
56
```

Файл құру: **File → New File** (Ctrl+N). Кодты жазып, **File → Save** (Ctrl+S) арқылы `.py` кеңейтімімен сақтаймыз, **Run → Run Module** (**F5**) арқылы іске қосамыз.

### 2.2. Thonny
Сайты: **https://thonny.org**. Терезесі екі бөліктен тұрады:
- **жоғарғы бөлік** — редактор (файлдағы код);
- **төменгі бөлік** — Shell (нәтиже және интерактивті режим).

Іске қосу — жасыл ▶ батырмасы немесе **F5**. **View → Variables** мәзірі айнымалылардың мәнін көрсетеді. Қадамдап орындау — 🐞 «Debug» батырмасы.

### 2.3. VS Code
Сайты: **https://code.visualstudio.com**. Орнатқаннан кейін:
1. Сол жақтағы **Extensions** (Ctrl+Shift+X) бөлімінен **«Python»** (Microsoft) кеңейтімін орнатыңыз.
2. **File → Open Folder** — өз жұмыс папкаңызды ашыңыз.
3. Жаңа файл құрып, оны `salem.py` деп сақтаңыз.
4. Оң жақ жоғарғы бұрыштағы ▶ (**Run Python File**) батырмасын басыңыз. Нәтиже төменгі **Terminal** панелінде шығады.

Терминалдан іске қосу да мүмкін:

```bash
python salem.py
```

## 3. Интерактивті режим және файлдық режим

| | Интерактивті режим (Shell, `>>>`) | Файлдық режим (`.py` файл) |
|---|---|---|
| Қалай жұмыс істейді? | Әр команда бірден орындалады | Бүкіл бағдарлама жазылып, сосын іске қосылады |
| Сақтала ма? | Жоқ — терезе жабылса, код жоғалады | Иә — файлда сақталады |
| Не үшін? | Калькулятор ретінде, жылдам тексеру | Нағыз бағдарламалар жазу |
| Нәтиже | Өрнектің мәні `print`-сіз де шығады | Тек `print()` арқылы шығады |

Маңызды айырмашылық: Shell-де `2 + 3` деп жазсаңыз, `5` шығады. Ал файлда `2 + 3` деп жазсаңыз — **ештеңе шықпайды**, себебі нәтижені экранға шығаруды сұрамадық. Файлда әрқашан `print(2 + 3)` деп жазамыз.

### Файлдарды атау ережелері
- Кеңейтімі — `.py`: `salem.py`, `men_turaly.py`.
- Тек латын әріптері, сандар және `_`; бос орынсыз: `sabaq05_print.py`.
- Файлды Python модульдерінің атымен атамаңыз: `turtle.py`, `random.py`, `math.py` — кейін қате тудырады!

## 4. Алғашқы бағдарлама: print() функциясы

`print()` — экранға мәлімет **шығару** функциясы (блок-схемадағы параллелограммның «шығару» блогы). Жақша ішіне не жазсақ, соны шығарады.

### 4.1. Мәтін шығару
Мәтін (жол, строка) **тырнақшаға** алынады: қос `"..."` немесе дара `'...'` тырнақша.

```python
print("Сәлем, әлем!")
print('Менің атым — Айдана')
```

Нәтижесі:
```text
Сәлем, әлем!
Менің атым — Айдана
```

Мәтіннің ішінде тырнақша қажет болса, екінші түрін қолданамыз:

```python
print('Ол маған: "Python үйрен!" деді')
print("It's Python")
```

Нәтижесі:
```text
Ол маған: "Python үйрен!" деді
It's Python
```

### 4.2. Сандар мен есептеулер шығару
Сандар тырнақшасыз жазылады. Python өрнекті алдымен есептеп, сосын нәтижесін шығарады.

```python
print(25)
print(12 + 30)
print(7 * 6)
print("7 * 6")
```

Нәтижесі:
```text
25
42
42
7 * 6
```

Соңғы жолға назар аударыңыз: тырнақша ішіндегі `"7 * 6"` — есептелмейді, ол жай мәтін!

### 4.3. Бірнеше мәнді шығару
Бірнеше мәнді үтір арқылы беруге болады — олар **бос орын** арқылы шығады.

```python
print("Бір апта", 7, "күн")
print("Бір тәулікте", 24 * 60, "минут бар")
```

Нәтижесі:
```text
Бір апта 7 күн
Бір тәулікте 1440 минут бар
```

### 4.4. Бос жол
Жақшасы бос `print()` бос жол шығарады:

```python
print("Бірінші жол")
print()
print("Үшінші жол")
```

Нәтижесі:
```text
Бірінші жол

Үшінші жол
```

### 4.5. sep параметрі — бөлгіш
Әдепкіде мәндер арасына бос орын қойылады. `sep=` арқылы басқа бөлгіш береміз:

```python
print(2, 9, 2026, sep=".")
print("Алматы", "Астана", "Шымкент", sep=" -> ")
print("a", "b", "c", sep="")
```

Нәтижесі:
```text
2.9.2026
Алматы -> Астана -> Шымкент
abc
```

### 4.6. end параметрі — жол соңы
Әдепкіде әр `print()` соңында жаңа жолға өтеді. `end=` оны өзгертеді:

```python
print("Жүктелуде", end="")
print("...", end=" ")
print("дайын!")
```

Нәтижесі:
```text
Жүктелуде... дайын!
```

### 4.7. Арнайы таңбалар: \n және \t
- `\n` — жаңа жол;
- `\t` — табуляция (үлкен бос орын, бағандарды теңестіру үшін).

```python
print("Бірінші жол\nЕкінші жол")
print("Аты\tЖасы")
print("Ерлан\t12")
```

Нәтижесі:
```text
Бірінші жол
Екінші жол
Аты	Жасы
Ерлан	12
```

### 4.8. Бірнеше жолдық мәтін және «сурет»
Үш тырнақша `"""..."""` бірнеше жолдық мәтін береді. Оның көмегімен таңбалардан сурет салуға болады:

```python
print("""
   /\\_/\\
  ( o.o )
   > ^ <
Мысық сәлем айтады!
""")
```

Нәтижесі:
```text

   /\_/\
  ( o.o )
   > ^ <
Мысық сәлем айтады!

```

(`\\` — бір кері қиғаш сызықты шығарады, себебі `\` таңбасы Python-да арнайы мағынаға ие.)

### 4.9. Мәтінді «көбейту»
```python
print("=" * 20)
print("Ха" * 3)
```

Нәтижесі:
```text
====================
ХаХаХа
```

## Жиі кездесетін қателер

**1. Тырнақшаны жабуды ұмыту.**
```text
print("Сәлем)
SyntaxError: unterminated string literal
```
Дұрысы:
```python
print("Сәлем")
```

**2. Жақшаны жабуды ұмыту.**
```text
print("Сәлем"
SyntaxError: '(' was never closed
```
Дұрысы:
```python
print("Сәлем")
```

**3. Мәтінді тырнақшасыз жазу.**
```text
print(Сәлем)
NameError: name 'Сәлем' is not defined
```
Тырнақшасыз сөзді Python айнымалының аты деп ойлайды. Дұрысы:
```python
print("Сәлем")
```

**4. Команданы бас әріппен немесе қате жазу.**
```text
Print("Сәлем")   -> NameError: name 'Print' is not defined
pritn("Сәлем")   -> NameError: name 'pritn' is not defined
```
Дұрысы: `print` — тек кіші әріппен.

**5. Орыс/қазақ раскладкасындағы тырнақша «» немесе жақша.**
```text
print(«Сәлем»)
SyntaxError: invalid character '«' (U+00AB)
```
Код жазғанда пернетақтаны **ағылшын** раскладкасына ауыстырып, `"` (Shift + ') таңбасын қолданыңыз.

**6. Жол басында артық бос орын.**
```text
 print("Сәлем")
IndentationError: unexpected indent
```
Жоғарғы деңгейдегі командалар жолдың ең басынан жазылады; шегініс тек блоктар ішінде (`if`, `for`, `def` т.б.) рұқсат етіледі.

**7. Файлды сақтамай іске қосу немесе `.py` кеңейтімін жазбау.** IDLE «Source Must Be Saved» деп сұрайды — алдымен сақтаңыз.

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| IDE (даму ортасы) | Код жазуға, іске қосуға, қате табуға арналған бағдарлама |
| IDLE | Python-мен бірге орнатылатын қарапайым орта |
| Thonny | Оқушыларға арналған Python ортасы |
| VS Code | Кеңейтімдері бар кәсіби код редакторы |
| Shell (интерактивті режим) | Командалар `>>>` белгісінен кейін бірден орындалатын режим |
| `.py` файл | Python бағдарламасы сақталатын файл |
| `print()` | Экранға мәлімет шығаратын функция |
| Жол (строка, string) | Тырнақшаға алынған мәтін |
| `sep` | `print()`-тегі мәндер арасындағы бөлгіш |
| `end` | `print()` соңына қойылатын таңба (әдепкіде жаңа жол) |
| `\n`, `\t` | Жаңа жол және табуляция таңбалары |

## Ескерту

- Windows-та орнатқанда «Add python.exe to PATH» белгісін міндетті түрде қойыңыз; ұмытып кетсеңіз — орнатқышты қайта іске қосып, **Modify** таңдаңыз немесе `py` іске қосқышын қолданыңыз (`py --version`, `py salem.py`).
- Толық сигнатурасы: `print(*objects, sep=' ', end='\n', file=None, flush=False)` — құжаттама: https://docs.python.org/3/library/functions.html#print
- Жолдағы `\` таңбасы арнайы тізбектің басы болып саналмауы үшін «шикі» жолдарды қолданыңыз: `print(r"C:\new\table")`.
- PEP 8 бойынша үтірден кейін бос орын қойылады, ал шақырудың ашылатын жақшасының алдында — жоқ: `print("a", "b")`, `print ("a","b")` емес.
- Қате хабарларының мәтіні нұсқаға байланысты: мысалы, `'(' was never closed` және `unterminated string literal` Python 3.10-да пайда болды; ескі нұсқаларда хабарлар түсініксіздеу.
