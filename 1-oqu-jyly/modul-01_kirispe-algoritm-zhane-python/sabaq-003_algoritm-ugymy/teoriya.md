## 1. Алгоритм деген не?

**Алгоритм** (алгоритм, algorithm) — белгілі бір нәтижеге жету үшін орындаушыға берілетін нақты, түсінікті әрі реттелген нұсқаулар (қадамдар) тізбегі.

Сөздің шығу тарихы — біз үшін ерекше мақтаныш: «алгоритм» сөзі IX ғасырда өмір сүрген ұлы ғалым **Мұхаммед әл-Хорезмидің** латынша аты *Algoritmi*-ден шыққан. Ол санау ережелерін жүйелі түрде сипаттаған. Ал біздің жерлесіміз **Әбу Насыр әл-Фараби** математика мен логика бойынша еңбектер жазған — алгоритмдік ойлау шығыс ғалымдарынан бастау алады.

Өмірдегі алгоритмдер:
- тамақ пісіру рецепті;
- банкоматтан ақша алу нұсқаулығы;
- Lego құрастыру нұсқаулығы;
- мектепке баратын жол;
- математикадағы бағанмен көбейту ережесі.

### Орындаушы

**Орындаушы** — алгоритмді орындайтын адам, жануар немесе құрылғы (робот, компьютер). Әр орындаушының **командалар жүйесі** болады — ол түсінетін және орындай алатын командалар жиынтығы.

| Орындаушы | Командалар жүйесі (мысал) |
|---|---|
| Робот-шаңсорғыш | алға жүр, бұрыл, сору, базаға қайт |
| Python интерпретаторы | `print`, `input`, `+`, `-`, `if`, `for` ... |
| Тасбақа (turtle) | `forward`, `left`, `right`, `penup` ... |
| Ит | «Отыр!», «Жат!», «Әкел!» |

Орындаушыға оның командалар жүйесінде жоқ команданы берсек, ол орындай алмайды. Мысалы, робот-шаңсорғышқа «ыдыс жу» деу мағынасыз.

## 2. Алгоритмнің қасиеттері

Кез келген нұсқаулар тізбегі алгоритм бола бермейді. Нағыз алгоритмнің **5 қасиеті** бар.

| Қасиет | Мағынасы | Бұзылған мысал |
|---|---|---|
| **Дискреттілік** (бөліктерге бөлінуі) | Алгоритм жеке, бір-бірінен бөлек қадамдардан тұрады; әр қадам аяқталған соң келесісі басталады | «Тамақ дайында» — бір ғана үлкен, бөлінбеген әрекет |
| **Түсініктілік** | Әр команда орындаушының командалар жүйесіне кіреді | Роботқа «көңіл күйіңді көтер» деу |
| **Анықтылық** (нақтылық) | Әр команда бір ғана мағынада түсініледі, «өз қалауынша» шешуге орын жоқ | «Тұзды шамалап сал», «біраз жүр» |
| **Нәтижелілік** | Алгоритм шектеулі қадамнан кейін нәтижеге жетеді | «1. Есікті аш. 2. Есікті жап. 3. 1-қадамға қайт» — шексіз |
| **Жалпылық** (көпшілікке арналғандық) | Алгоритм бір ғана емес, осы типтегі көптеген есепке жарайды | Тек «2 + 3» үшін ғана жазылған тәсіл; ал «кез келген екі санды қосу» — жалпы |

**Мысал: «Шай демдеу» алгоритмі.**

```text
1. Шәйнекке су құй.
2. Шәйнекті қос.
3. Су қайнағанша күт.
4. Шыныаяққа 1 шай пакетін сал.
5. Шыныаяққа 200 мл қайнаған су құй.
6. 3 минут күт.
7. Шай пакетін алып таста.
8. Қаласаң, 1 қасық қант салып, араластыр.
```

Қасиеттерін тексерейік: қадамдарға бөлінген (дискретті), әр қадам адамға түсінікті, нақты (200 мл, 3 минут), аяқталады (нәтижелі), кез келген шыныаяқ шай үшін жарайды (жалпы).

## 3. Алгоритмнің берілу тәсілдері

Бір алгоритмді әртүрлі тәсілмен жазуға болады.

| Тәсіл | Сипаттамасы | Қашан ыңғайлы? |
|---|---|---|
| **Сөздік** (табиғи тілде) | Нөмірленген сөйлемдер | Рецепт, нұсқаулық, адамға арналған |
| **Графиктік (блок-схема)** | Геометриялық фигуралар мен бағыттауыш сызықтар | Логиканы көрнекі көрсету, жоспарлау |
| **Псевдокод** | Бағдарламалау тіліне ұқсас, бірақ еркін «жартылай тіл» | Бағдарламашылар арасында идеяны талқылау |
| **Бағдарлама** | Бағдарламалау тілінде жазылған код | Компьютерде орындау |

Бір есеп — төрт тәсіл. **Есеп:** тіктөртбұрыштың ұзындығы мен енін біліп, ауданын табу.

**1) Сөздік тәсіл:**
```text
1. Ұзындықты (a) біл.
2. Енді (b) біл.
3. Ауданды есепте: S = a × b.
4. S мәнін жаз.
```

**2) Псевдокод:**
```text
алг Аудан
  енгізу a, b
  S := a * b
  шығару S
соңы
```

**3) Блок-схема** — төменде, 4-бөлімде.

**4) Python бағдарламасы** (`a`, `b`, `S` — айнымалылар, `*` — көбейту, `print()` — шығару):

```python
a = 8
b = 5
S = a * b
print(S)
```

Нәтижесі:
```text
40
```

## 4. Блок-схема элементтері

**Блок-схема** — алгоритмнің әр қадамын белгілі бір геометриялық фигура (блок) арқылы, ал орындалу ретін бағыттауыш сызықтар арқылы көрсететін сызба. Фигуралар халықаралық стандартпен (ГОСТ 19.701-90 / ISO 5807) бекітілген.

| Блок | Фигура | Мағынасы | Мысал жазуы |
|---|---|---|---|
| Басы / Соңы (терминатор) | Сопақ (дөңгелектенген тіктөртбұрыш) | Алгоритмнің басталуы және аяқталуы | «Басы», «Соңы» |
| Енгізу / Шығару | Параллелограмм | Деректерді енгізу немесе нәтижені шығару | «a, b енгізу», «S шығару» |
| Процесс (әрекет) | Тіктөртбұрыш | Есептеу, мән беру, әрекет | «S = a · b» |
| Шарт (шешім) | Ромб | Шартты тексеру, екі шығысы бар: «Иә»/«Жоқ» | «a > b ?» |
| Цикл (модификатор) | Алтыбұрыш | Қайталау басы (санауышпен) | «i = 1-ден 10-ға дейін» |
| Ішкі бағдарлама | Екі жақ шеті сызылған тіктөртбұрыш | Бөлек сипатталған алгоритмді шақыру | «Сұрыптау» |
| Байланыстырғыш | Кішкентай шеңбер | Схема бөліктерін байланыстыру (беттен бетке) | «А» |
| Бағыттауыш сызық | Сызық/нұсқар | Орындалу реті (әдетте жоғарыдан төмен, солдан оңға) | → |

Блоктардың мәтіндік бейнесі:

```text
   (  Басы  )          — сопақ: басы/соңы

   /  a, b  /          — параллелограмм: енгізу/шығару
  /енгізу  /

  +-----------+
  | S = a * b |        — тіктөртбұрыш: процесс
  +-----------+

       / \
      /   \
     < a>b?>           — ромб: шарт (Иә / Жоқ)
      \   /
       \ /
```

### Блок-схема құру ережелері
1. Әр схеманың бір «Басы» және кемінде бір «Соңы» блогы болады.
2. Орындалу жоғарыдан төмен қарай жүреді; басқа бағыт болса — нұсқармен көрсетіледі.
3. Процесс блогының бір кірісі, бір шығысы бар.
4. Шарт блогының бір кірісі және **екі шығысы** бар: «Иә» және «Жоқ».
5. Сызықтар бір-бірін қиып өтпеуге тырысу керек; блок ішіндегі жазу қысқа әрі түсінікті болуы тиіс.

### Мысал: тіктөртбұрыштың ауданы (блок-схема)

```text
        (   Басы   )
             |
             v
       /  a, b енгізу /
             |
             v
       +-------------+
       |  S = a * b  |
       +-------------+
             |
             v
       /  S шығару   /
             |
             v
        (   Соңы   )
```

### Мысал: шарт блогы бар схема — «Далаға шығу»

```text
          (  Басы  )
              |
              v
       / Ауа райын біл /
              |
              v
             / \
            /   \
    Иә <--< Жаңбыр  >--> Жоқ
    |       \ ма? /       |
    |        \   /        |
    v                     v
+------------+      +-------------+
| Қолшатыр   |      | Қолшатырсыз |
| ал         |      | шық         |
+------------+      +-------------+
    |                     |
    +----------+----------+
               v
          (  Соңы  )
```

Бұл — тармақталған алгоритм: әрі қарайғы жол шартқа байланысты таңдалады. Python-да мұндай тармақталу `if ... else` операторымен жазылады.

## Жиі кездесетін қателер

**1. Анық емес команда.**
```text
Қате:  3. Ұнға біраз су қос.
Дұрыс: 3. Ұнға 250 мл жылы су қос.
```

**2. Қадамдардың реті бұзылған.**
```text
Қате:  1. Хатты жібер. 2. Хатты жаз. 3. Мекенжайды енгіз.
Дұрыс: 1. Хатты жаз. 2. Мекенжайды енгіз. 3. Хатты жібер.
```

**3. Шексіз алгоритм (нәтижелілік бұзылған).**
```text
Қате:  1. Санды 1-ге көбейт. 2. Нәтиже 100-ден үлкен болса, тоқта. 3. 1-қадамға қайт.
       (1-ге көбейткенде сан өзгермейді — алгоритм ешқашан аяқталмайды)
Дұрыс: 1. Санды 2-ге көбейт. ... (сан өседі, бір кезде 100-ден асады)
```

**4. Блок-схемадағы фигураны шатастыру.**
```text
Қате:  «a, b енгізу» тіктөртбұрышқа жазылған.
Дұрыс: Енгізу/шығару — параллелограммда; есептеу — тіктөртбұрышта.
```

**5. Шарт блогынан бір ғана шығыс.**
```text
Қате:  Ромбтан тек «Иә» нұсқары шығады.
Дұрыс: Ромбтың әрқашан екі шығысы бар: «Иә» және «Жоқ».
```

## Ескерту

- Блок-схема мен бағдарлама қадамдары сәйкес болуы керек: параллелограммға әдетте `input()` немесе `print()`, тіктөртбұрышқа — мән беру немесе есептеу, ромбқа — `if` немесе `while` циклінің шарты сәйкес келеді.
- Блок-схема сызу үшін тегін diagrams.net (draw.io) редакторы және мәтін бойынша схема құратын онлайн-сервистер (мысалы, Mermaid) ыңғайлы.
- Псевдокодтың бірыңғай стандарты жоқ; бастысы — бір мағыналылық. Python-ды жиі «орындалатын псевдокод» деп атайды, өйткені оның синтаксисі псевдокодқа жақын.
- Бағдарламада «нәтижелілік» қасиеті шексіз циклдермен бұзылады: бағдарлама «қатып қалса», оны консольде Ctrl+C пернелер тіркесімімен тоқтатуға болады (`KeyboardInterrupt` пайда болады).
- Python-да `=` белгісі мән меншіктеуді білдіреді (псевдокодтағы `:=` баламасы), ал теңдікті салыстыру `==` деп жазылады.
