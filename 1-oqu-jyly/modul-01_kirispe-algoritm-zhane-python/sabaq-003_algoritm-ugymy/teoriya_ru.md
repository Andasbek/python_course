## 1. Что такое алгоритм?

**Алгоритм** (алгоритм, algorithm) — точная, понятная и упорядоченная последовательность инструкций (шагов), которая даётся исполнителю для достижения определённого результата.

История происхождения слова — предмет нашей особой гордости: слово «алгоритм» происходит от латинского имени *Algoritmi* великого учёного IX века **Мухаммеда аль-Хорезми**. Он систематически описал правила счёта. А наш земляк **Абу Наср аль-Фараби** написал труды по математике и логике — алгоритмическое мышление берёт начало у учёных Востока.

Алгоритмы в жизни:
- рецепт приготовления блюда;
- инструкция по снятию денег в банкомате;
- инструкция по сборке Lego;
- дорога в школу;
- правило умножения столбиком в математике.

### Исполнитель

**Исполнитель** — человек, животное или устройство (робот, компьютер), выполняющее алгоритм. У каждого исполнителя есть **система команд** — набор команд, которые он понимает и может выполнить.

| Исполнитель | Система команд (пример) |
|---|---|
| Робот-пылесос | двигаться вперёд, повернуть, всасывать, вернуться на базу |
| Интерпретатор Python | `print`, `input`, `+`, `-`, `if`, `for` ... |
| Черепашка (turtle) | `forward`, `left`, `right`, `penup` ... |
| Собака | «Сидеть!», «Лежать!», «Апорт!» |

Если дать исполнителю команду, которой нет в его системе команд, он не сможет её выполнить. Например, сказать роботу-пылесосу «помой посуду» бессмысленно.

## 2. Свойства алгоритма

Не всякая последовательность инструкций является алгоритмом. У настоящего алгоритма есть **5 свойств**.

| Свойство | Смысл | Пример нарушения |
|---|---|---|
| **Дискретность** (разделённость на части) | Алгоритм состоит из отдельных, обособленных шагов; следующий шаг начинается после завершения предыдущего | «Приготовь обед» — одно большое неразделённое действие |
| **Понятность** | Каждая команда входит в систему команд исполнителя | Сказать роботу «подними себе настроение» |
| **Определённость** (точность) | Каждая команда понимается однозначно, нет места решению «на своё усмотрение» | «Посоли по вкусу», «пройди немного» |
| **Результативность** | Алгоритм приводит к результату за конечное число шагов | «1. Открой дверь. 2. Закрой дверь. 3. Вернись к шагу 1» — бесконечно |
| **Массовость** (общность) | Алгоритм подходит не для одной, а для многих задач данного типа | Способ, написанный только для «2 + 3»; а «сложить любые два числа» — общий |

**Пример: алгоритм «Заварить чай».**

```text
1. Налей воду в чайник.
2. Включи чайник.
3. Подожди, пока вода закипит.
4. Положи в чашку 1 чайный пакетик.
5. Налей в чашку 200 мл кипятка.
6. Подожди 3 минуты.
7. Вытащи чайный пакетик.
8. По желанию положи 1 ложку сахара и размешай.
```

Проверим свойства: разделён на шаги (дискретный), каждый шаг понятен человеку, точный (200 мл, 3 минуты), завершается (результативный), подходит для любой чашки чая (массовый).

## 3. Способы записи алгоритма

Один и тот же алгоритм можно записать разными способами.

| Способ | Описание | Когда удобен? |
|---|---|---|
| **Словесный** (на естественном языке) | Пронумерованные предложения | Рецепт, инструкция, для человека |
| **Графический (блок-схема)** | Геометрические фигуры и соединительные линии со стрелками | Наглядное представление логики, планирование |
| **Псевдокод** | Свободный «полуязык», похожий на язык программирования | Обсуждение идеи между программистами |
| **Программа** | Код, написанный на языке программирования | Выполнение на компьютере |

Одна задача — четыре способа. **Задача:** зная длину и ширину прямоугольника, найти его площадь.

**1) Словесный способ:**
```text
1. Узнай длину (a).
2. Узнай ширину (b).
3. Вычисли площадь: S = a × b.
4. Запиши значение S.
```

**2) Псевдокод:**
```text
алг Площадь
  ввод a, b
  S := a * b
  вывод S
кон
```

**3) Блок-схема** — ниже, в разделе 4.

**4) Программа на Python** (`a`, `b`, `S` — переменные, `*` — умножение, `print()` — вывод):

```python
a = 8
b = 5
S = a * b
print(S)
```

Результат:
```text
40
```

## 4. Элементы блок-схемы

**Блок-схема** — схема, изображающая каждый шаг алгоритма определённой геометрической фигурой (блоком), а порядок выполнения — соединительными линиями со стрелками. Фигуры утверждены международным стандартом (ГОСТ 19.701-90 / ISO 5807).

| Блок | Фигура | Значение | Пример надписи |
|---|---|---|---|
| Начало / Конец (терминатор) | Овал (скруглённый прямоугольник) | Начало и окончание алгоритма | «Начало», «Конец» |
| Ввод / Вывод | Параллелограмм | Ввод данных или вывод результата | «Ввод a, b», «Вывод S» |
| Процесс (действие) | Прямоугольник | Вычисление, присваивание значения, действие | «S = a · b» |
| Условие (решение) | Ромб | Проверка условия, два выхода: «Да»/«Нет» | «a > b ?» |
| Цикл (модификатор) | Шестиугольник | Начало повторения (со счётчиком) | «i от 1 до 10» |
| Подпрограмма | Прямоугольник с двойными боковыми линиями | Вызов отдельно описанного алгоритма | «Сортировка» |
| Соединитель | Маленький круг | Соединение частей схемы (со страницы на страницу) | «А» |
| Линия потока | Линия/стрелка | Порядок выполнения (обычно сверху вниз, слева направо) | → |

Текстовое изображение блоков:

```text
   ( Начало )          — овал: начало/конец

   /  Ввод  /          — параллелограмм: ввод/вывод
  /  a, b  /

  +-----------+
  | S = a * b |        — прямоугольник: процесс
  +-----------+

       / \
      /   \
     < a>b?>           — ромб: условие (Да / Нет)
      \   /
       \ /
```

### Правила построения блок-схемы
1. У каждой схемы один блок «Начало» и как минимум один блок «Конец».
2. Выполнение идёт сверху вниз; если направление другое — оно показывается стрелкой.
3. У блока процесса один вход и один выход.
4. У блока условия один вход и **два выхода**: «Да» и «Нет».
5. Следует стараться, чтобы линии не пересекались; надписи внутри блоков должны быть краткими и понятными.

### Пример: площадь прямоугольника (блок-схема)

```text
        (  Начало  )
             |
             v
       /  Ввод a, b   /
             |
             v
       +-------------+
       |  S = a * b  |
       +-------------+
             |
             v
       /   Вывод S   /
             |
             v
        (  Конец   )
```

### Пример: схема с блоком условия — «Выход на улицу»

```text
          ( Начало )
              |
              v
       / Узнай погоду  /
              |
              v
             / \
            /   \
    Да <--< Идёт  >--> Нет
    |       \дождь?/      |
    |        \   /        |
    v                     v
+------------+      +-------------+
| Возьми     |      | Выйди без   |
| зонт       |      | зонта       |
+------------+      +-------------+
    |                     |
    +----------+----------+
               v
          ( Конец  )
```

Это разветвляющийся алгоритм: дальнейший путь выбирается в зависимости от условия. На Python такая развилка записывается оператором `if ... else`.

## Частые ошибки
**1. Неточная команда.**
```text
Ошибка:   3. Добавь в муку немного воды.
Правильно: 3. Добавь в муку 250 мл тёплой воды.
```

**2. Нарушен порядок шагов.**
```text
Ошибка:   1. Отправь письмо. 2. Напиши письмо. 3. Введи адрес.
Правильно: 1. Напиши письмо. 2. Введи адрес. 3. Отправь письмо.
```

**3. Бесконечный алгоритм (нарушена результативность).**
```text
Ошибка:   1. Умножь число на 1. 2. Если результат больше 100, остановись. 3. Вернись к шагу 1.
          (при умножении на 1 число не меняется — алгоритм никогда не завершится)
Правильно: 1. Умножь число на 2. ... (число растёт и когда-нибудь превысит 100)
```

**4. Путаница фигур в блок-схеме.**
```text
Ошибка:   «Ввод a, b» записан в прямоугольнике.
Правильно: Ввод/вывод — в параллелограмме; вычисление — в прямоугольнике.
```

**5. Только один выход из блока условия.**
```text
Ошибка:   Из ромба выходит только стрелка «Да».
Правильно: У ромба всегда два выхода: «Да» и «Нет».
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Алгоритм | Точная, упорядоченная последовательность инструкций, которая даётся исполнителю для достижения результата |
| Исполнитель | Человек, устройство или программа, выполняющие алгоритм |
| Система команд | Набор команд, понятных исполнителю |
| Дискретность | Разделённость алгоритма на отдельные шаги |
| Определённость | Однозначность каждой команды |
| Результативность | Достижение результата за конечное число шагов |
| Массовость | Пригодность для многих задач одного типа |
| Псевдокод | Свободный способ записи, похожий на язык программирования |
| Блок-схема | Графическое изображение алгоритма |

## Примечание

- Блок-схема и программа должны совпадать по шагам: каждому параллелограмму обычно соответствует `input()` или `print()`, прямоугольнику — присваивание или вычисление, ромбу — `if` или условие цикла `while`.
- Для рисования блок-схем удобны бесплатные редакторы diagrams.net (draw.io) и онлайн-сервисы, умеющие строить схемы по тексту (например, Mermaid).
- Псевдокод не имеет единого стандарта; главное — однозначность. Python часто называют «исполняемым псевдокодом», потому что его синтаксис близок к псевдокоду.
- Свойство «результативность» в программах нарушается бесконечными циклами: если программа «зависла», прервать её выполнение в консоли можно сочетанием Ctrl+C (возникает `KeyboardInterrupt`).
- В Python знак `=` означает присваивание (аналог `:=` из псевдокода), а сравнение на равенство записывается как `==`.
