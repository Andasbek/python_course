# Сабақ 6. Практикалық тапсырмалар: Код мәдениеті және қателерді түзету

Қатесі бар кодтарды өз компьютеріңізге теріп (немесе педагог берген файлдан ашып), іске қосыңыз, қате хабарламасын оқып, түзетіңіз. Әр қате үшін дәптерге кесте толтырыңыз:

| № | Жол | Қате түрі (хабарлама) | Себебі | Қалай түзеттім |
|---|---|---|---|---|

## Базалық деңгей

### 1-тапсырма. Ретке келтір (PEP 8)
Төмендегі код жұмыс істейді, бірақ ұқыпсыз жазылған. Оны PEP 8 бойынша ретке келтіріңіз (нәтиже өзгермеуі керек):

```python
print ( "САБАҚ КЕСТЕСІ" )
print("Дүйсенбі:","Математика","Python",sep =" | ")
print("Сәрсенбі:" ,"Ағылшын тілі",'Python', sep=" | ")
print( "Барлық сағат:",2*2+3 )
```

### 2-тапсырма. Түсініктеме қос
Мына бағдарламаға:
- файлдың басына үш тырнақшамен сипаттама (атауы, авторы, күні, не істейтіні);
- әр жолға пайдалы (не үшін екенін түсіндіретін) түсініктеме қосыңыз.

```python
print("ЖОЛ ЖҮРУ ЕСЕБІ")
print("Аптасына:", 10 * 200, "теңге")
print("Айына:", 4 * 10 * 200, "теңге")
print("Жылына (9 ай оқу):", 9 * 4 * 10 * 200, "теңге")
```

### 3-тапсырма. Қате аңшысы — 1

**А)**

```text
print("Сәлем, әлем!)
```

**Б)**

**В)**

**Д)**

### 4-тапсырма. Қате аңшысы — 2 (бірнеше қате)
Бағдарламада 5 қате бар. Барлығын тауып түзетіңіз. Python бірінші қатені ғана көрсететінін ұмытпаңыз — түзеткен сайын қайта іске қосыңыз.

```text
// Бағдарлама: Жануарлар туралы

prnt("Түйе судсыз 2 апта жүре алады")
print("Жылқы тік тұрып ұйықтай алады"

 print("Соңы")
```

### 5-тапсырма. Қатесі не туралы?
Хабарлама мен себепті сәйкестендіріңіз.

| Хабарлама | | Себебі |
|---|---|---|
| 1. `SyntaxError: unterminated string literal` | | А. Жолдың басында артық бос орын |
| 2. `NameError: name 'prin' is not defined` | | Б. Жақша жабылмаған |
| 3. `IndentationError: unexpected indent` | | В. Тырнақша жабылмаған |
| 4. `SyntaxError: '(' was never closed` | | Г. Команда қате жазылған |
| 5. `ZeroDivisionError: division by zero` | | Д. Нөлге бөлу |

## Кеңейтілген деңгей

### 6-тапсырма. Логикалық қате
Бағдарлама қатесіз іске қосылады, бірақ нәтижелерде **3 логикалық қате** бар. Табыңыз және түзетіңіз.

```python
# Тіктөртбұрыштың ұзындығы 8, ені 5
print("Периметрі:", 8 * 5)
print("Ауданы:", 8 + 5)
# 1 сағат 15 минут — неше минут?
print("Минут:", 1 * 100 + 15)
```

### 7-тапсырма. Өз қатеңді жаса
Жұппен жұмыс. Әрқайсыңыз 5–6 жолдық дұрыс бағдарлама жазып, оған жасырын түрде 3 қате енгізіңіз. Кодыңызды көршіңізге беріңіз — ол қатені тауып, түзетуі керек. Кім тезірек тапты?

## ★ Олимпиадалық / шығармашылық тапсырма

### 8-тапсырма. Ең көп қате
Бір ғана жолдан тұратын, Python-ның **үш түрлі** хабарламасын (бірінен соң бірін, түзеткен сайын) беретін код ойлап табыңыз. Мысалы, алдымен `IndentationError`, түзеткен соң `SyntaxError`, тағы түзеткен соң `NameError`.

### 9-тапсырма. «Резеңке үйрек»
4-тапсырмадағы түзетілген кодты көршіңізге жол-жолымен дауыстап түсіндіріңіз: әр жол не істейді, қандай таңба не үшін керек. Көршіңіз бағалайды: түсінікті болды ма?

## Үй тапсырмасы
1. Өткен сабақтағы `vizitka.py` және «Менің отбасым» бағдарламаларын PEP 8 бойынша ретке келтіріп, басына сипаттама және пайдалы түсініктемелер қосыңыз.
2. «Қате сөздігі»: дәптерге бүгін кездескен 5 қате хабарламасын, оның қазақша мағынасын және түзету жолын жазыңыз.
3. Келесі сабаққа: «Мен туралы» бағдарламасы үшін өзіңіз туралы 8–10 дерек (аты, жасы, мектебі, хоббиі, арманы, сүйікті тағамы...) және ASCII-сурет идеясын дайындап келіңіз.

**2-тапсырма:**
```python
"""
Бағдарлама: Жол жүру есебі
Автор: Оқушының аты-жөні
Күні: 21.09.2026
Сипаттамасы: автобус жол ақысына аптасына, айына

"""

print("ЖОЛ ЖҮРУ ЕСЕБІ")

```

**3-тапсырма:**
- А) Тырнақша жабылмаған (`SyntaxError: unterminated string literal`) → `print("Сәлем, әлем!")`.
- Б) Жақша жабылмаған (`'(' was never closed`) → `print("Менің жасым", 12)`.
- В) `NameError: name 'Print'...` → `print("Python")`.
- Г) Қате жоқ, бірақ екі жол үтірсіз қатар тұрса, Python оларды біріктіреді: `Қала:Алматы` (бос орынсыз). Дұрысы: `print("Қала:", "Алматы")` → `Қала: Алматы`.
- Д) `IndentationError: unexpected indent` → жол басындағы бос орындарды өшіру.
- Е) `SyntaxError: invalid character '«'` → `print("Тырнақша")`.

**4-тапсырма:**
```python
# Бағдарлама: Жануарлар туралы
print("Мысық — үй жануары")
print("Иттің жүрегі минутына", 70, "-", 120, "рет соғады")
print("Түйе судсыз 2 апта жүре алады")
print("Жылқы тік тұрып ұйықтай алады")
print('Пілдің салмағы шамамен', 5000, "кг")
print("Соңы")
```
Қателер: 1) `//` → `#`; 2) `70` пен `"-"` арасында үтір жоқ; 3) `prnt` → `print`; 4) жақша жабылмаған; 5) соңғы жолдағы шегініс. (Аралас тырнақша `'...'` — қате емес, бірақ PEP 8 бойынша бірізді ету ұсынылады.)

**5-тапсырма:** 1 — В; 2 — Г; 3 — А; 4 — Б; 5 — Д.
