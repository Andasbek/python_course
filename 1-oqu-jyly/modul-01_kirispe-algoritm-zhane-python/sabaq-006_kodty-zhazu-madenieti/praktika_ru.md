**Задание 3:**
- А) Не закрыта кавычка (`SyntaxError: unterminated string literal`) → `print("Привет, мир!")`.
- Б) Не закрыта скобка (`'(' was never closed`) → `print("Мне лет", 12)`.
- В) `NameError: name 'Print'...` → `print("Python")`.
- Г) Ошибки нет, но если две строки стоят рядом без запятой, Python их склеивает: `Город:Алматы` (без пробела). Правильно: `print("Город:", "Алматы")` → `Город: Алматы`.
- Д) `IndentationError: unexpected indent` → удалить пробелы в начале строки.
- Е) `SyntaxError: invalid character '«'` → `print("Кавычки")`.
