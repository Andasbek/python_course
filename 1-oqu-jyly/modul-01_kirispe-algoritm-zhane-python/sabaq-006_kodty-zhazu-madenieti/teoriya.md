## 1. Неліктен код мәдениеті маңызды?

Бағдарламашы кодты **бір рет жазады**, бірақ оны **ондаған рет оқиды** — өзі де, әріптестері де. Ұқыпсыз жазылған кодта қате табу қиын, оны түсіну көп уақыт алады.

> «Код компьютер үшін емес, адам үшін жазылады; компьютер оны тек орындайды.»

Аналогия: ұқыпты жазу. Ретсіз, сызылған жазбаны, тіпті бәрі дұрыс жазылса да, оқу қиын.

## 2. PEP 8 — Python кодының стилі

**PEP 8** — Python кодын қалай әдемі әрі бірізді жазу керектігін сипаттайтын ресми ұсыныстар жинағы (Python Enhancement Proposal 8). Біз қазір білетін командаларға қатысты негізгі ережелер:

| Ереже | Дұрыс | Дұрыс емес |
|---|---|---|
| Функция аты мен жақша арасында бос орын жоқ | `print("A")` | `print ("A")` |
| Үтірден кейін бір бос орын | `print(1, 2, 3)` | `print(1,2,3)` |
| Амал белгілерінің екі жағында бір бос орын | `print(5 + 3 * 2)` | `print(5+3*2)` |
| Жақша ішінде шетінде бос орын жоқ | `print(10)` | `print( 10 )` |
| Параметр атында `=` айналасында бос орын жоқ | `sep="-"` | `sep = "-"` |
| Жолдың ұзындығы — 79 таңбадан аспасын | Ұзын мәтінді бөлу | Экраннан асып кететін жол |
| Логикалық бөліктер арасында бір бос жол | Бөлімдер бос жолмен бөлінген | Бәрі бір үйіндіде |
| Тырнақша түрін бірізді қолдану | Бүкіл файлда `"..."` | Аралас `'...'` және `"..."` |

Мысал. Ретсіз код:

```python
print ("ДҮКЕН ЧЕГІ")
print("Нан:",2*180,"теңге")
print( "Сүт:" , 3*520 , "теңге" )
print("Барлығы:",2*180+3*520,'теңге')
```

PEP 8 бойынша ретке келтірілген:

```python
print("ДҮКЕН ЧЕГІ")
print("Нан:", 2 * 180, "теңге")
print("Сүт:", 3 * 520, "теңге")
print("Барлығы:", 2 * 180 + 3 * 520, "теңге")
```

Нәтижесі (екеуінде де бірдей):
```text
ДҮКЕН ЧЕГІ
Нан: 360 теңге
Сүт: 1560 теңге
Барлығы: 1920 теңге
```

Нәтиже өзгерген жоқ, бірақ екінші кодты оқу әлдеқайда жеңіл.

## 3. Түсініктемелер (комментарии, comments)

**Түсініктеме** — кодтың ішіндегі адамға арналған жазба. Python оны **елемейді** (орындамайды).

### 3.1. Бір жолдық түсініктеме: `#`
`#` таңбасынан бастап жолдың соңына дейінгі мәтін — түсініктеме.

```python
# Бұл бағдарлама дүкен чегін шығарады
# Авторы: Айдана Серікова, 21.09.2026

print("ДҮКЕН ЧЕГІ")  # тақырып
print("Нан:", 2 * 180, "теңге")  # 2 нан, әрқайсысы 180 теңге
```

Нәтижесі:
```text
ДҮКЕН ЧЕГІ
Нан: 360 теңге
```

PEP 8 ережелері:
- `#` таңбасынан кейін бір бос орын: `# түсініктеме`;
- код жолының соңындағы түсініктеме алдында кемінде **екі** бос орын: `print(1)  # бір`.

### 3.2. Көп жолдық түсініктеме
Бірнеше `#` жолы немесе үш тырнақшадағы мәтін (`"""..."""`) қолданылады. Үш тырнақшадағы мәтінді файлдың басына — бағдарламаның сипаттамасы ретінде жазу қалыптасқан:

```python
"""
Бағдарлама: Апта күндері
Автор: Ерлан Қасымов
Сипаттамасы: аптаның жұмыс күндерін экранға шығарады.
"""

print("Дүйсенбі, Сейсенбі, Сәрсенбі, Бейсенбі, Жұма")
```

Нәтижесі:
```text
Дүйсенбі, Сейсенбі, Сәрсенбі, Бейсенбі, Жұма
```

### 3.3. Түсініктемені уақытша «өшіру» үшін қолдану
Кодтың бір жолын жоймай, уақытша орындатпау үшін алдына `#` қоямыз (IDLE-де: **Format → Comment Out Region**, Alt+3; VS Code/Thonny-де: **Ctrl+/**).

```python
print("Бұл жол орындалады")
# print("Бұл жол уақытша өшірілген")
print("Бұл да орындалады")
```

Нәтижесі:
```text
Бұл жол орындалады
Бұл да орындалады
```

### 3.4. Жақсы және жаман түсініктеме
| Жаман (пайдасыз) | Жақсы (пайдалы) |
|---|---|
| `print(60 * 60)  # 60-ты 60-қа көбейтеміз` — код онсыз да мұны айтып тұр | `print(60 * 60)  # бір сағаттағы секунд саны` — **не үшін** екенін түсіндіреді |

Ереже: түсініктеме кодтың **не істейтінін** емес, **не үшін** істейтінін түсіндірсін.

## 4. Бағдарламадағы қателер

Бағдарламадағы қатені ағылшынша **bug** («қоңыз») дейді, ал қатені табу мен түзетуді **debugging** (жөндеу, отладка) дейді. 1947 жылы Гарвард университетіндегі Mark II компьютерінің ішінен нақты көбелек табылып, журналға «First actual case of bug being found» деп жапсырылған — бұл атау содан кең тарады.

### 4.1. Қателердің түрлері

| Түрі | Қашан шығады? | Мысал |
|---|---|---|
| **Синтаксистік қате** (SyntaxError, IndentationError) | Бағдарлама іске қосылмас бұрын; Python кодты «оқи» алмайды | Тырнақша жабылмаған |
| **Орындалу кезіндегі қате** (runtime error: NameError, TypeError, ZeroDivisionError) | Бағдарлама орындалып жатқанда, қате жолға жеткенде | `print(10 / 0)` |
| **Логикалық қате** | Python ешқандай қате шығармайды, бірақ нәтиже дұрыс емес | Периметр орнына ауданды есептеу |

Логикалық қате — ең қауіптісі, себебі компьютер оны көрсетпейді. Оны тек нәтижені тексеру арқылы табамыз: трассировкамен және алдын ала белгілі дұрыс жауаппен салыстыру арқылы.

### 4.2. Қате хабарламасын (traceback) оқу

Бағдарлама:

```text
print("Бірінші жол")
print("Екінші жол)
print("Үшінші жол")
```

Python-ның жауабы:

```text
  File "C:\Python_Uyirme\test.py", line 2
    print("Екінші жол)
          ^
SyntaxError: unterminated string literal (detected at line 2)
```

Қалай оқимыз:
1. **`line 2`** — қате 2-жолда (немесе одан сәл бұрын!).
2. **`^`** — қате болжамды орынды көрсетеді.
3. **`SyntaxError`** — қатенің түрі.
4. **`unterminated string literal`** — себебі: «жабылмаған жол (мәтін)».

Орындалу кезіндегі қатенің хабарламасы:

```text
Traceback (most recent call last):
  File "C:\Python_Uyirme\test.py", line 3, in <module>
    prnt("Сәлем")
NameError: name 'prnt' is not defined. Did you mean: 'print'?
```

Мұнда Python тіпті кеңес береді: «Did you mean: 'print'?» — «'print' деп айтқыңыз келді ме?» Хабарламаның **соңғы жолын** әрқашан мұқият оқыңыз!

Назар аударыңыз: синтаксистік қате болса, бағдарламаның **бірде-бір жолы** орындалмайды. Ал орындалу қатесінде — қатеге дейінгі жолдар орындалып үлгереді.

### 4.3. Жиі кездесетін қате хабарламаларының «сөздігі»

| Хабарлама | Қазақша мағынасы | Ықтимал себебі |
|---|---|---|
| `SyntaxError: invalid syntax` | Синтаксис қате | Артық/жетіспейтін таңба, қате сөз |
| `SyntaxError: unterminated string literal` | Жол (мәтін) жабылмаған | Тырнақша жоқ |
| `SyntaxError: '(' was never closed` | Жақша жабылмаған | `)` жоқ |
| `SyntaxError: unmatched ')'` | Артық жабатын жақша | `)` артық |
| `SyntaxError: invalid character '«'` | Рұқсат етілмеген таңба | «» тырнақшасы, кириллица «с» т.б. |
| `SyntaxError: invalid syntax. Perhaps you forgot a comma?` | Үтірді ұмыттыңыз ба? | Мәндер арасында үтір жоқ |
| `IndentationError: unexpected indent` | Күтілмеген шегініс | Жол басында артық бос орын |
| `NameError: name '...' is not defined` | Бұл атау анықталмаған | Команда қате жазылған, мәтін тырнақшасыз |
| `TypeError` | Тип қатесі | Мәтін мен санды қосу: `"5" + 3` |
| `ZeroDivisionError: division by zero` | Нөлге бөлу | `print(5 / 0)` |

### 4.4. Қате іздеу стратегиясы (5 қадам)
1. **Тыныштал** — қате хабарламасы ұрыспайды, ол көмектеседі!
2. **Соңғы жолды оқы** — қатенің түрі мен себебі.
3. **Жол нөміріне бар** — сол жолды және **алдыңғы жолды** тексер (жабылмаған жақша келесі жолда байқалуы мүмкін).
4. **Типтік себептерді тексер:** тырнақша, жақша, үтір, раскладка, үлкен/кіші әріп, жол басындағы бос орын.
5. **Түзетіп, қайта іске қос.** Бір ғана өзгеріс енгізіп, нәтижені тексер. Бірнеше қате болса — біртіндеп, жоғарыдан төмен түзет.

Қосымша тәсілдер:
- **«Резеңке үйрек» әдісі** — кодыңызды жол-жолымен біреуге (немесе ойыншық үйрекке!) дауыстап түсіндіріңіз. Түсіндіріп отырып қатені жиі өзіңіз табасыз.
- Күмәнді жолды `#` арқылы уақытша өшіріп, қате жойылғанын тексеріңіз.

## Жиі кездесетін қателер

**1. `#`-ты тырнақша ішіне жазу.**
```python
print("Сәлем # бұл түсініктеме емес")
```
Нәтижесі:
```text
Сәлем # бұл түсініктеме емес
```
Тырнақша ішіндегі `#` — мәтіннің бөлігі. Түсініктеме тырнақшадан тыс жазылады:
```python
print("Сәлем")  # бұл — түсініктеме
```

**2. Түсініктемені `//` арқылы жазу (басқа тілдердегідей).**
```text
// бұл түсініктеме
SyntaxError: invalid syntax
```
Python-да тек `#`:
```python
# бұл түсініктеме
```

**3. Мәндер арасында үтір жоқ.**
```text
print("Жасым" 12)
SyntaxError: invalid syntax. Perhaps you forgot a comma?
```
Дұрысы:
```python
print("Жасым", 12)
```

**4. Қате жолды емес, келесі жолды «түзету».** Жақша 3-жолда жабылмаса, Python кейде 4-жолды көрсетеді. Әрқашан алдыңғы жолды да тексеріңіз.

**5. Кириллица әрпі латын сөздің ішінде.** `print` сөзіндегі «р» орыс әрпімен терілсе, сыртынан бірдей көрінеді, бірақ `NameError` береді. Шешімі — сөзді ағылшын раскладкасында қайта теру.

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Код мәдениеті | Кодты оқылымды, бірізді жазу ережелері |
| PEP 8 | Python кодын жазу стилінің ресми ұсыныстары |
| Түсініктеме (comment) | Python елемейтін, адамға арналған жазба (`#`) |
| Баг (bug) | Бағдарламадағы қате |
| Жөндеу (debugging, отладка) | Қатені табу және түзету процесі |
| Синтаксистік қате | Тіл ережелерінің бұзылуы; бағдарлама мүлде іске қосылмайды |
| Орындалу қатесі | Бағдарлама жұмыс істеп жатқанда пайда болатын қате |
| Логикалық қате | Бағдарлама жұмыс істейді, бірақ нәтиже қате |
| Traceback | Қатенің орны мен түрін көрсететін Python хабарламасы |

## Ескерту

- PEP 8-дің толық мәтіні (ағылшынша): https://peps.python.org/pep-0008/ . Стиль ережелерін `flake8`, `pycodestyle`, `ruff` құралдары автоматты түрде тексереді, ал `black` автоформаттаушысы кодты өзі бірыңғай түрге келтіреді.
- Файл басындағы үш тырнақшадағы жол — түсініктеме емес, **құжаттама жолы** (docstring, PEP 257): Python оны модульдің `__doc__` атрибутында сақтайды, оны `help()` көрсетеді.
- `Did you mean: 'print'?` сияқты кеңестер мен нақтырақ қате хабарлары Python 3.10–3.12-де пайда болды; ескі нұсқаларда көбіне жай `invalid syntax` шығады.
- `# -*- coding: utf-8 -*-` түріндегі бірінші жол Python 3-те қажет емес: бастапқы файлдар әдепкі бойынша UTF-8 кодтауында оқылады.
- Кодқа сәйкес келмейтін түсініктеме түсініктеменің мүлде болмауынан да жаман: кодты өзгерткенде түсініктемені де жаңартыңыз (PEP 8 ережесі).
