## 1. Алгоритмнің негізгі түрлері (құрылымдары)

Кез келген алгоритм, тіпті ең күрделі ойын бағдарламасы да, тек **үш негізгі құрылымнан** құралады. Бұл — құрылымдық бағдарламалаудың негізгі идеясы.

| Түрі | Мағынасы | Өмірдегі мысал | Python-да |
|---|---|---|---|
| **Сызықтық** | Қадамдар бірінен соң бірі, ретімен, бір рет орындалады | Шай демдеу | Командалар тізбегі |
| **Тармақталған** | Шартқа байланысты әртүрлі жолмен жүреді | Жаңбыр жауса — қолшатыр аламын | `if`, `else`, `elif` |
| **Циклдік** | Қадамдар бірнеше рет қайталанады | 10 рет отырып-тұру | `for`, `while` |

## 2. Сызықтық алгоритм

**Сызықтық алгоритм** — командалары жазылу ретімен, әрқайсысы тек бір рет орындалатын алгоритм. Блок-схемасы — тармақсыз, «түзу сызық».

**Есеп:** Сатып алынған алманың салмағы (кг) мен 1 кг бағасы енгізіледі. Төлейтін соманы есепте.

```text
          (   Басы   )
               |
               v
     / салмақ, баға енгізу /
               |
               v
     +---------------------+
     | сома = салмақ * баға|
     +---------------------+
               |
               v
         / сома шығару /
               |
               v
          (   Соңы   )
```

Бұл алгоритм Python-да былай жазылады:

```python
weight = 2
price = 650
total = weight * price
print(total)
```

Нәтижесі:
```text
1300
```

## 3. Тармақталған алгоритм

**Тармақталған алгоритм** — шарттың орындалуына (ақиқат/жалған) байланысты әрекеттердің бірі ғана орындалатын алгоритм. Шарт **ромбпен** белгіленеді, одан екі жол шығады: «Иә» және «Жоқ».

### 3.1. Толық тармақталу
Екі тармақта да әрекет бар: «егер ... онда А, әйтпесе Б».

**Есеп:** Оқушының жасы енгізіледі. 16 және одан жоғары болса — «Ересектер тобы», әйтпесе — «Кіші топ».

```text
             (  Басы  )
                 |
          / жас енгізу /
                 |
                / \
       Иә     /     \     Жоқ
     +-------< жас>=16 >-------+
     |        \  ?  /          |
     |         \   /           |
     v                         v
/ «Ересектер   /        / «Кіші топ»  /
/  тобы» шығару/        /  шығару     /
     |                         |
     +------------+------------+
                  v
             (  Соңы  )
```

### 3.2. Толық емес тармақталу
Тек бір тармақта әрекет бар: «егер ... онда А» (әйтпесе ештеңе істемейміз).

**Есеп:** Сатып алу сомасы енгізіледі. Сома 10 000 теңгеден асса, 10% жеңілдік беріледі. Төлейтін соманы шығар.

```text
           (  Басы  )
               |
        / сома енгізу /
               |
              / \
     Иә     /     \    Жоқ
   +-------< сома > >------+
   |        \10000?/       |
   v         \   /         |
+---------------------+    |
| сома = сома * 0.9   |    |
+---------------------+    |
   |                       |
   +-----------+-----------+
               v
        / сома шығару /
               |
           (  Соңы  )
```

### 3.3. Шарттар тізбегі (көп тармақ)
Шарт блоктарын бірінен соң бірін қоюға болады. Мысалы, бағаны анықтау: балл ≥ 85 → «5»; әйтпесе балл ≥ 65 → «4»; әйтпесе балл ≥ 40 → «3»; әйтпесе → «2». Python-да мұндай алгоритмдер `if...elif...else` арқылы жазылады.

## 4. Циклдік алгоритм

**Цикл** — бір әрекеттер тобының бірнеше рет қайталануы. Қайталанатын бөлікті **цикл денесі** дейді. Әр қайталау — **итерация**.

Циклдің екі негізгі түрі бар.

### 4.1. Шарты бар цикл («әзірше» циклі, while)
Шарт ақиқат **болғанша** цикл денесі қайталанады. Шарт әр итерация алдында тексеріледі.

**Мысал:** Шелек толғанша оған бір кеседен су құя бер.

**Есеп:** 1-ден 5-ке дейінгі сандарды экранға шығар.

```text
            (  Басы  )
                |
          +-----------+
          |   i = 1   |
          +-----------+
                |
                v
               / \  <--------------------+
              /   \                      |
     Жоқ <---< i<=5 >                     |
      |       \ ?  /                     |
      |        \ /                       |
      |         | Иә                     |
      |   /  i шығару  /                 |
      |         |                        |
      |   +-----------+                  |
      |   | i = i + 1 |------------------+
      |   +-----------+
      v
  (  Соңы  )
```

Мұнда `i` — **санауыш** (счётчик): әр итерацияда 1-ге артады. Егер `i = i + 1` қадамын ұмытсақ — `i` әрқашан 1 болып қалады, шарт әрқашан ақиқат, цикл **шексіз** болады (нәтижелілік қасиеті бұзылады!).

### 4.2. Санауышы бар цикл (параметрлі цикл, for)
Қайталау саны алдын ала белгілі. Блок-схемада **алтыбұрыш** (модификатор) арқылы көрсетіледі.

```text
          (  Басы  )
              |
      +----------------+
      |  i = 1 .. 5    | <---+     — алтыбұрыш: i 1-ден 5-ке дейін
      +----------------+     |
              |              |
        / i шығару /---------+
              |
          (  Соңы  )   (цикл біткенде)
```

### 4.3. Трассировка кестесі
**Трассировка** — алгоритмді «қолмен», қадам бойынша орындап, айнымалылардың мәнін кестеге жазу. Бұл алгоритмнің дұрыстығын тексерудің ең жақсы тәсілі.

**Есеп:** 1-ден 4-ке дейінгі сандардың қосындысын тап. Алгоритм: `S = 0, i = 1`; әзірше `i <= 4`: `S = S + i`, `i = i + 1`; соңында `S`-ті шығар.

| Қадам | i | i <= 4 ? | S |
|---|---|---|---|
| Басы | 1 | — | 0 |
| 1-итерация | 1 | Иә | 0 + 1 = 1 |
| 2-итерация | 2 | Иә | 1 + 2 = 3 |
| 3-итерация | 3 | Иә | 3 + 3 = 6 |
| 4-итерация | 4 | Иә | 6 + 4 = 10 |
| Тексеру | 5 | Жоқ → шығу | 10 |

Жауап: **10**.

Python-да бұл алгоритм былай жазылады:

```python
S = 0
i = 1
while i <= 4:
    S = S + i
    i = i + 1
print(S)
```

Нәтижесі:
```text
10
```

## 5. Аралас алгоритмдер

Нақты есептерде құрылымдар біріктіріледі: цикл ішінде шарт, шарт ішінде сызықтық бөлік т.б.

**Мысал:** 1-ден 10-ға дейінгі сандардың ішінен тек жұптарын шығару: цикл (i = 1..10) → шарт («i 2-ге бөлінгенде қалдық 0 ме?») → Иә: «i шығару».

```text
     (Басы) → [ i = 1 .. 10 ] → < i жұп па? > --Иә--> / i шығару / --+
                     ^                |                               |
                     |               Жоқ                              |
                     +----------------+-------------------------------+
     цикл біткенде → (Соңы)
```

## 6. Блок-схема құру реті

1. **Есепті түсін:** не берілген (кіріс), не табу керек (шығыс)?
2. **Шешім жолын сөзбен жаз** (сөздік алгоритм).
3. **Түрін анықта:** тек есептеу ме (сызықтық)? таңдау бар ма (тармақталу)? қайталау бар ма (цикл)?
4. **Схеманы сыз:** Басы → енгізу → өңдеу → шығару → Соңы.
5. **Тексер (трассировка):** 2–3 мысал мәнмен «қолмен» орында.

## Жиі кездесетін қателер

**1. Циклде санауышты өзгертуді ұмыту → шексіз цикл.**
```text
Қате:  i = 1; әзірше i <= 5: i шығару        (i ешқашан өзгермейді)
Дұрыс: i = 1; әзірше i <= 5: i шығару; i = i + 1
```

**2. Тармақтар қайта қосылмайды.**
```text
Қате:  «Иә» тармағы Соңына жетеді, ал «Жоқ» тармағы ауада қалады.
Дұрыс: Екі тармақ та бір нүктеде қосылып, ары қарай жалғасады.
```

**3. Циклдің кері нұсқары қате жерге қайтады.**
```text
Қате:  Нұсқар «i = 1» блогына қайтады → санауыш әр рет 1-ге қайта тең болады.
Дұрыс: Нұсқар шарт блогына (ромбқа) қайтады.
```

**4. Шарт шекарасындағы қате.**
```text
Есеп:  «16 жастан бастап» ересектер тобы.
Қате:  жас > 16    (16 жастағы оқушы кіші топқа түсіп қалады)
Дұрыс: жас >= 16
```

## Негізгі ұғымдар

| Ұғым | Анықтамасы |
|---|---|
| Сызықтық алгоритм | Командалар ретімен, бір реттен орындалатын алгоритм |
| Тармақталған алгоритм | Шартқа байланысты әртүрлі әрекет орындалатын алгоритм |
| Толық тармақталу | Шарттың екі нәтижесінде де әрекет бар («егер–онда–әйтпесе») |
| Толық емес тармақталу | Тек шарт ақиқат болғанда әрекет орындалады |
| Циклдік алгоритм | Әрекеттер тобы бірнеше рет қайталанатын алгоритм |
| Цикл денесі | Циклде қайталанатын командалар |
| Итерация | Цикл денесінің бір рет орындалуы |
| Санауыш | Әр итерацияда өзгеріп, қайталау санын бақылайтын айнымалы |
| Трассировка | Алгоритмді қолмен қадамдап орындап, айнымалылар мәнін кестеге жазу |

## Ескерту

- Python-да C немесе Pascal-дағыдай бөлек «соңғы шартты» цикл (do-while) жоқ; оны `while True:` және `break` арқылы жасайды.
- «i 1-ден 5-ке дейін» санауышты циклі Python-да `for i in range(1, 6):` деп жазылады — `range` оң шекарасы **кірмейді**.
- Блок-схемалар мен бағдарламаларда жұптылықты бөлудің қалдығы арқылы тексереді: `i % 2 == 0`.
- Бём — Якопини теоремасы (1966) кез келген алгоритмді үш құрылымнан: тізбектен, тармақталудан және циклден құруға болатынын дәлелдейді; құрылымдық бағдарламалау осыған негізделген.
- Python кодын трассировкалау үшін қадамдық жөндегіш (мысалы, Thonny-да) және әр қадамда айнымалылар мәнін көрсететін pythontutor.com сайты ыңғайлы.
