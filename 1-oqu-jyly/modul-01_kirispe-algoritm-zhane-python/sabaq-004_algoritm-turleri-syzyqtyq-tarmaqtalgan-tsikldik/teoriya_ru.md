## 1. Основные виды (структуры) алгоритмов

Любой алгоритм, даже самая сложная игровая программа, состоит всего из **трёх основных структур**. Это основная идея структурного программирования.

| Вид | Смысл | Пример из жизни | В Python |
|---|---|---|---|
| **Линейный** | Шаги выполняются один за другим, по порядку, по одному разу | Заварить чай | Последовательность команд |
| **Разветвляющийся** | В зависимости от условия идёт разными путями | Если идёт дождь — беру зонт | `if`, `else`, `elif` |
| **Циклический** | Шаги повторяются несколько раз | 10 раз присесть | `for`, `while` |

## 2. Линейный алгоритм

**Линейный алгоритм** — алгоритм, команды которого выполняются в порядке записи, каждая только один раз. Его блок-схема — без ветвлений, «прямая линия».

**Задача:** вводятся вес купленных яблок (кг) и цена 1 кг. Вычислить сумму к оплате.

```text
          (  Начало  )
               |
               v
     /  Ввод вес, цена     /
               |
               v
     +---------------------+
     | сумма = вес * цена  |
     +---------------------+
               |
               v
         / Вывод сумма /
               |
               v
          (  Конец   )
```

На Python этот алгоритм записывается так:

```python
weight = 2
price = 650
total = weight * price
print(total)
```

Результат:
```text
1300
```

## 3. Разветвляющийся алгоритм

**Разветвляющийся алгоритм** — алгоритм, в котором в зависимости от выполнения условия (истина/ложь) выполняется только одно из действий. Условие обозначается **ромбом**, из которого выходят два пути: «Да» и «Нет».

### 3.1. Полное ветвление
Действие есть в обеих ветвях: «если ... то А, иначе Б».

**Задача:** вводится возраст учащегося. Если 16 лет и больше — «Старшая группа», иначе — «Младшая группа».

```text
             ( Начало )
                 |
          / Ввод возраст /
                 |
                / \
       Да     /     \     Нет
     +-------<возраст>-------+
     |        \>=16?/        |
     |         \   /         |
     v                       v
/ Вывод        /      / Вывод         /
/ «Старшая     /      / «Младшая      /
/  группа»     /      /  группа»      /
     |                       |
     +-----------+-----------+
                 v
             ( Конец  )
```

### 3.2. Неполное ветвление
Действие есть только в одной ветви: «если ... то А» (иначе ничего не делаем).

**Задача:** вводится сумма покупки. Если сумма больше 10 000 тенге, предоставляется скидка 10%. Вывести сумму к оплате.

```text
           ( Начало )
               |
        / Ввод сумма /
               |
              / \
     Да     /     \    Нет
   +-------< сумма >-------+
   |        \>10000?/      |
   v         \   /         |
+---------------------+    |
| сумма = сумма * 0.9 |    |
+---------------------+    |
   |                       |
   +-----------+-----------+
               v
        / Вывод сумма /
               |
           ( Конец  )
```

### 3.3. Цепочка условий (множественное ветвление)
Блоки условий можно ставить один за другим. Например, определение оценки: балл ≥ 85 → «5»; иначе балл ≥ 65 → «4»; иначе балл ≥ 40 → «3»; иначе → «2». В Python такие алгоритмы записываются с помощью `if...elif...else`.

## 4. Циклический алгоритм

**Цикл** — многократное повторение одной группы действий. Повторяющаяся часть называется **телом цикла**. Каждое повторение — **итерация**.

Существует два основных вида цикла.

### 4.1. Цикл с условием (цикл «пока», while)
Тело цикла повторяется, **пока** условие истинно. Условие проверяется перед каждой итерацией.

**Пример:** пока ведро не наполнится, продолжай наливать в него воду по одной кружке.

**Задача:** вывести на экран числа от 1 до 5.

```text
            ( Начало )
                |
          +-----------+
          |   i = 1   |
          +-----------+
                |
                v
               / \  <--------------------+
              /   \                      |
     Нет <---< i<=5 >                     |
      |       \ ?  /                     |
      |        \ /                       |
      |         | Да                     |
      |    /  Вывод i  /                 |
      |         |                        |
      |   +-----------+                  |
      |   | i = i + 1 |------------------+
      |   +-----------+
      v
  ( Конец  )
```

Здесь `i` — **счётчик**: на каждой итерации он увеличивается на 1. Если забыть шаг `i = i + 1` — `i` всегда останется равным 1, условие всегда будет истинным, цикл станет **бесконечным** (нарушается свойство результативности!).

### 4.2. Цикл со счётчиком (цикл с параметром, for)
Количество повторений известно заранее. В блок-схеме изображается **шестиугольником** (модификатор).

```text
          ( Начало )
              |
      +----------------+
      |  i = 1 .. 5    | <---+     — шестиугольник: i от 1 до 5
      +----------------+     |
              |              |
        / Вывод i  /---------+
              |
          ( Конец  )   (когда цикл закончится)
```

### 4.3. Таблица трассировки
**Трассировка** — выполнение алгоритма «вручную», шаг за шагом, с записью значений переменных в таблицу. Это лучший способ проверить правильность алгоритма.

**Задача:** найти сумму чисел от 1 до 4. Алгоритм: `S = 0, i = 1`; пока `i <= 4`: `S = S + i`, `i = i + 1`; в конце вывести `S`.

| Шаг | i | i <= 4 ? | S |
|---|---|---|---|
| Начало | 1 | — | 0 |
| 1-я итерация | 1 | Да | 0 + 1 = 1 |
| 2-я итерация | 2 | Да | 1 + 2 = 3 |
| 3-я итерация | 3 | Да | 3 + 3 = 6 |
| 4-я итерация | 4 | Да | 6 + 4 = 10 |
| Проверка | 5 | Нет → выход | 10 |

Ответ: **10**.

На Python этот алгоритм записывается так:

```python
S = 0
i = 1
while i <= 4:
    S = S + i
    i = i + 1
print(S)
```

Результат:
```text
10
```

## 5. Смешанные алгоритмы

В реальных задачах структуры комбинируются: условие внутри цикла, линейная часть внутри условия и т.д.

**Пример:** из чисел от 1 до 10 вывести только чётные: цикл (i = 1..10) → условие («остаток от деления i на 2 равен 0?») → Да: «вывод i».

```text
     (Начало) → [ i = 1 .. 10 ] → < i чётное? > --Да--> / Вывод i / --+
                     ^                |                               |
                     |               Нет                              |
                     +----------------+-------------------------------+
     когда цикл закончится → (Конец)
```

## 6. Порядок построения блок-схемы

1. **Пойми задачу:** что дано (вход), что нужно найти (выход)?
2. **Запиши путь решения словами** (словесный алгоритм).
3. **Определи вид:** только вычисление (линейный)? есть выбор (ветвление)? есть повторение (цикл)?
4. **Начерти схему:** Начало → ввод → обработка → вывод → Конец.
5. **Проверь (трассировка):** выполни «вручную» на 2–3 примерах значений.

## Частые ошибки
**1. Забыли изменить счётчик в цикле → бесконечный цикл.**
```text
Ошибка:    i = 1; пока i <= 5: вывод i        (i никогда не меняется)
Правильно: i = 1; пока i <= 5: вывод i; i = i + 1
```

**2. Ветви не соединяются.**
```text
Ошибка:    Ветвь «Да» доходит до Конца, а ветвь «Нет» висит в воздухе.
Правильно: Обе ветви соединяются в одной точке и продолжаются дальше.
```

**3. Обратная стрелка цикла возвращается не туда.**
```text
Ошибка:    Стрелка возвращается к блоку «i = 1» → счётчик каждый раз снова становится равен 1.
Правильно: Стрелка возвращается к блоку условия (ромбу).
```

**4. Ошибка на границе условия.**
```text
Задача:    старшая группа — «с 16 лет».
Ошибка:    возраст > 16    (учащийся 16 лет попадёт в младшую группу)
Правильно: возраст >= 16
```

## Основные понятия

| Понятие | Определение |
|---|---|
| Линейный алгоритм | Алгоритм, команды которого выполняются по порядку, по одному разу |
| Разветвляющийся алгоритм | Алгоритм, в котором в зависимости от условия выполняются разные действия |
| Полное ветвление | Действие есть при обоих результатах условия («если–то–иначе») |
| Неполное ветвление | Действие выполняется только тогда, когда условие истинно |
| Циклический алгоритм | Алгоритм, в котором группа действий повторяется несколько раз |
| Тело цикла | Команды, повторяющиеся в цикле |
| Итерация | Однократное выполнение тела цикла |
| Счётчик | Переменная, которая меняется на каждой итерации и контролирует число повторений |
| Трассировка | Пошаговое выполнение алгоритма вручную с записью значений переменных в таблицу |

## Примечание

- В Python нет отдельного цикла «с постусловием» (do-while), как в C или Pascal; его имитируют с помощью `while True:` и `break`.
- Цикл со счётчиком «i от 1 до 5» в Python записывается как `for i in range(1, 6):` — правая граница `range` **не включается**.
- Чётность в блок-схемах и программах проверяют через остаток от деления: `i % 2 == 0`.
- Теорема Бёма — Якопини (1966) доказывает, что любой алгоритм можно построить из трёх структур: следования, ветвления и цикла; на этом основано структурное программирование.
- Для трассировки кода на Python удобны пошаговый отладчик (например, в Thonny) и сайт pythontutor.com, который показывает значения переменных на каждом шаге.
