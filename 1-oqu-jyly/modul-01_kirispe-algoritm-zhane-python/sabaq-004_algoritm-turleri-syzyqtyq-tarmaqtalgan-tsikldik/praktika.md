# Сабақ 4. Практикалық тапсырмалар: Алгоритм түрлері және блок-схема құру

Барлық блок-схемаларды қағазда немесе draw.io (diagrams.net) сервисінде сызыңыз. draw.io-да: сол жақтағы «Flowchart» бөлімінен фигураларды сүйреп әкеліп, нұсқармен байланыстырыңыз; файлды `sabaq04_<есеп нөмірі>.png` деп өз папкаңызға экспорттаңыз.

## Базалық деңгей

### 1-тапсырма. Алгоритм түрін анықта
Әр алгоритмнің түрін жазыңыз (сызықтық / тармақталған / циклдік):
1. Нан сатып алу: дүкенге бар, нан ал, төле, үйге қайт.
2. Бағдаршам жасыл болса — жүр, әйтпесе — тұр.
3. Әр сабақтан кейін 1 минут көзге жаттығу жаса (күніне 6 сабақ).
4. Қоңырау соғылғанша есепті шығара бер.
5. Шаршының ауданын есепте: a-ны біл, S = a · a, S-ті жаз.
6. Құпиясөз дұрыс болса — кіруге рұқсат, әйтпесе — «Қате құпиясөз».

### 2-тапсырма. Сызықтық алгоритм: «Жол ақысы»
Алматыда автобус жол ақысы — 200 теңге (Onay картасымен). Оқушы аптасына неше рет жүретіні (n) енгізіледі. Аптасына жол ақысына кететін соманы есептейтін блок-схема сызыңыз.
- *Мысал:* n = 10 → 2000.

### 3-тапсырма. Толық тармақталу: «Жұп немесе тақ»
Бүтін сан енгізіледі. Сан жұп болса «Жұп», әйтпесе «Тақ» деп шығаратын блок-схема сызыңыз.
- *Кеңес:* сан 2-ге қалдықсыз бөлінсе, ол — жұп.
- *Мысал:* 14 → «Жұп»; 7 → «Тақ».

### 4-тапсырма. Толық емес тармақталу: «Абсолют шама»
Сан енгізіледі. Егер сан теріс болса, оны -1-ге көбейтеміз. Нәтижені шығарамыз.
- *Мысал:* -8 → 8; 5 → 5.

### 5-тапсырма. Цикл: «Санау»
10-нан 1-ге дейін кері санап (ракета ұшыру сияқты), соңында «Ұш!» деп шығаратын блок-схема сызыңыз. Трассировка кестесінің алғашқы 3 жолын толтырыңыз.

## Кеңейтілген деңгей

### 6-тапсырма. Үш тармақ: «Термометр»
Ауа температурасы енгізіледі:
- 0-ден төмен → «Аяз, жылы киін!»
- 0-ден 20-ға дейін (20 кірмейді) → «Салқын, күртке ки»
- 20 және одан жоғары → «Жылы, футболкамен шық»

Блок-схемасын сызып, -5, 10, 20 мәндерімен трассировка жасаңыз.

### 7-тапсырма. Цикл + жинақтауыш: «Жинақ»
Айдар әр апта қорапшасына 500 теңге салады. 10 000 теңге жинау үшін неше апта керек? Блок-схемасын (while циклімен) сызып, трассировка арқылы жауабын табыңыз.

### 8-тапсырма. Блок-схеманы «оқы» және трассировка жаса
```text
( Басы ) → [ a = 1, k = 0 ] → < a < 50 ? > --Жоқ--> / k шығару / → ( Соңы )
                                   |  ^
                                  Иә  |
                                   v  |
                            [ a = a * 3 ]
                                   |  |
                            [ k = k + 1 ]--+
```
Трассировка кестесін толтырыңыз. Не шығады? Алгоритм не есептейді?

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Ең үлкені
Үш сан (a, b, c) енгізіледі. Ең үлкенін табатын блок-схеманы **ең аз шарт блогымен** сызыңыз. Неше ромб қажет болды?

### 10-тапсырма. Евклид алгоритмі
Екі натурал санның ең үлкен ортақ бөлгішін (ЕҮОБ) табудың ежелгі тәсілі: «Сандар тең болмағанша, үлкенінен кішісін азайта бер. Сандар теңескенде — бұл ЕҮОБ». Блок-схемасын сызып, (48, 18) жұбы үшін трассировка жасаңыз.

## Үй тапсырмасы
1. Өмірден өзіңіз ойлап тапқан сызықтық, тармақталған және циклдік алгоритмге бір-бір мысал жазып, әрқайсысының блок-схемасын сызыңыз.
2. «Сынып жетекшісі 25 оқушының бойын өлшейді. 160 см-ден биік оқушыларды санау керек» есебінің блок-схемасын сызыңыз (цикл ішінде шарт).
3. Келесі сабаққа: үйде компьютер болса, ата-анаңызбен бірге python.org сайтын ашып, «Downloads» бөлімін қарап келіңіз (әзірге орнатпаңыз).

**1-тапсырма:** 1 — сызықтық; 2 — тармақталған; 3 — циклдік; 4 — циклдік (шарт бойынша); 5 — сызықтық; 6 — тармақталған.

**2-тапсырма:**
```text
( Басы ) → / n енгізу / → [ S = n * 200 ] → / S шығару / → ( Соңы )
```

**3-тапсырма:**
```text
( Басы ) → / x енгізу / → < x % 2 == 0 ? >
              Иә → / «Жұп» шығару /    Жоқ → / «Тақ» шығару /
              екі тармақ қосылады → ( Соңы )
```

**4-тапсырма:**
```text
( Басы ) → / x енгізу / → < x < 0 ? > --Иә--> [ x = x * (-1) ] --+
                               | Жоқ                              |
                               +----------------------------------+→ / x шығару / → ( Соңы )
```

**5-тапсырма:**
```text
( Басы ) → [ i = 10 ] → < i >= 1 ? > --Иә--> / i шығару / → [ i = i - 1 ] → (ромбқа қайту)
                             | Жоқ
                             v
                      / «Ұш!» шығару / → ( Соңы )
```
| i | i >= 1 ? | Шығыс |
|---|---|---|
| 10 | Иә | 10 |
| 9 | Иә | 9 |
| 8 | Иә | 8 |

**6-тапсырма:** екі ромб: `t < 0 ?` (Иә → «Аяз...»; Жоқ → `t < 20 ?` (Иә → «Салқын...»; Жоқ → «Жылы...»)).
Трассировка: -5 → «Аяз, жылы киін!»; 10 → «Салқын, күртке ки»; 20 → «Жылы, футболкамен шық».

**7-тапсырма:**
```text
( Басы ) → [ S = 0, n = 0 ] → < S < 10000 ? > --Иә--> [ S = S + 500 ] → [ n = n + 1 ] → (ромбқа)
                                     | Жоқ
                                     v
                               / n шығару / → ( Соңы )
```
Жауабы: 20 апта.

Python-дағы баламасы (V модульде өтеміз):
```python
S = 0
n = 0
while S < 10000:
    S = S + 500
    n = n + 1
print(n)
```

**8-тапсырма:**
| a | k | a < 50 ? |
|---|---|---|
| 1 | 0 | Иә |
| 3 | 1 | Иә |
| 9 | 2 | Иә |
| 27 | 3 | Иә |
| 81 | 4 | Жоқ |

Шығыс: `4`. Алгоритм 1-ден бастап 3-ке көбейте отырып, 50-ден асу үшін неше рет көбейту керек екенін есептейді.

**9-тапсырма:** 2 ромб жеткілікті:
```text
[ max = a ] → < b > max ? > --Иә--> [ max = b ] → < c > max ? > --Иә--> [ max = c ] → / max шығару /
```
(Әр «Жоқ» тармағы келесі қадамға өтеді.)

**10-тапсырма:**
```text
( Басы ) → / a, b енгізу / → < a != b ? > --Жоқ--> / a шығару / → ( Соңы )
                                   | Иә
                              < a > b ? > --Иә--> [ a = a - b ] --+
                                   | Жоқ                          |
                              [ b = b - a ] ----------------------+→ (бірінші ромбқа)
```
Трассировка (48, 18): (30,18) → (12,18) → (12,6) → (6,6). ЕҮОБ = **6**.
