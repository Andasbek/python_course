Все блок-схемы чертите на бумаге или в сервисе draw.io (diagrams.net). В draw.io: перетащите фигуры из раздела «Flowchart» слева и соедините их стрелками; экспортируйте файл в свою папку под именем `sabaq04_<номер задачи>.png`.

## Базовый уровень

### Задание 1. Определи вид алгоритма
Запишите вид каждого алгоритма (линейный / разветвляющийся / циклический):
1. Покупка хлеба: сходи в магазин, возьми хлеб, заплати, вернись домой.
2. Если светофор зелёный — иди, иначе — стой.
3. После каждого урока делай 1 минуту гимнастику для глаз (6 уроков в день).
4. Решай задачу, пока не прозвенит звонок.
5. Вычисли площадь квадрата: узнай a, S = a · a, запиши S.
6. Если пароль верный — вход разрешён, иначе — «Неверный пароль».

### Задание 2. Линейный алгоритм: «Проезд»
В Алматы проезд в автобусе стоит 200 тенге (по карте Onay). Вводится, сколько раз в неделю ездит учащийся (n). Начертите блок-схему, вычисляющую сумму, которая уходит на проезд за неделю.
- *Пример:* n = 10 → 2000.

### Задание 3. Полное ветвление: «Чётное или нечётное»
Вводится целое число. Начертите блок-схему, которая выводит «Чётное», если число чётное, иначе — «Нечётное».
- *Подсказка:* если число делится на 2 без остатка, оно чётное.
- *Пример:* 14 → «Чётное»; 7 → «Нечётное».

### Задание 4. Неполное ветвление: «Модуль числа»
Вводится число. Если число отрицательное, умножаем его на -1. Выводим результат.
- *Пример:* -8 → 8; 5 → 5.

### Задание 5. Цикл: «Обратный отсчёт»
Начертите блок-схему, которая ведёт обратный отсчёт от 10 до 1 (как при запуске ракеты), а в конце выводит «Пуск!». Заполните первые 3 строки таблицы трассировки.

## Продвинутый уровень

### Задание 6. Три ветви: «Термометр»
Вводится температура воздуха:
- ниже 0 → «Мороз, одевайся тепло!»
- от 0 до 20 (20 не включается) → «Прохладно, надень куртку»
- 20 и выше → «Тепло, выходи в футболке»

Начертите блок-схему и выполните трассировку для значений -5, 10, 20.

### Задание 7. Цикл + накопитель: «Копилка»
Айдар каждую неделю кладёт в копилку 500 тенге. Сколько недель нужно, чтобы накопить 10 000 тенге? Начертите блок-схему (с циклом while) и найдите ответ с помощью трассировки.

### Задание 8. «Прочитай» блок-схему и выполни трассировку
```text
( Начало ) → [ a = 1, k = 0 ] → < a < 50 ? > --Нет--> / Вывод k / → ( Конец )
                                   |  ^
                                  Да  |
                                   v  |
                            [ a = a * 3 ]
                                   |  |
                            [ k = k + 1 ]--+
```
Заполните таблицу трассировки. Что будет выведено? Что вычисляет алгоритм?

## ★ Олимпиадная / творческая задача

### Задание 9. Наибольшее
Вводятся три числа (a, b, c). Начертите блок-схему, находящую наибольшее из них, **с наименьшим числом блоков условия**. Сколько ромбов понадобилось?

### Задание 10. Алгоритм Евклида
Древний способ нахождения наибольшего общего делителя (НОД) двух натуральных чисел: «Пока числа не равны, вычитай из большего меньшее. Когда числа станут равны — это НОД». Начертите блок-схему и выполните трассировку для пары (48, 18).

**Задание 6:** два ромба: `t < 0 ?` (Да → «Мороз...»; Нет → `t < 20 ?` (Да → «Прохладно...»; Нет → «Тепло...»)).

**Задание 7:**
```text
( Начало ) → [ S = 0, n = 0 ] → < S < 10000 ? > --Да--> [ S = S + 500 ] → [ n = n + 1 ] → (к ромбу)
                                     | Нет
                                     v
                               / Вывод n / → ( Конец )
```
Ответ: 20 недель.

Аналог на Python (пройдём в V модуле):
```python
S = 0
n = 0
while S < 10000:
    S = S + 500
    n = n + 1
print(n)
```
