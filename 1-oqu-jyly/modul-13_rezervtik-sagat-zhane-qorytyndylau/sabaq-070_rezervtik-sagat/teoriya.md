## 1. Шпаргалка: алгоритм, айнымалылар, деректер типтері

- **Алгоритм** – мақсатқа жетуге арналған нақты әрекеттер тізбегі. Қасиеттері: дискреттілік, түсініктілік, анықтылық, нәтижелілік, жалпылық. Түрлері: сызықтық, тармақталған, циклдік.
- **Айнымалы** – мәнге берілген ат. Аты: латын әріптері, цифр (басында емес), `_`; кілт сөз болмауы керек.
- **Типтер:** `int` (бүтін), `float` (бөлшек), `str` (жол), `bool` (`True`/`False`); `type()` – типті анықтау.
- **Амалдар:** `+ - * /`, `//` (бүтін бөлу), `%` (қалдық), `**` (дәреже). Реті: `**` → `* / // %` → `+ -`.
- **Енгізу/шығару:** `input()` әрқашан **жол** қайтарады → `int()`, `float()` арқылы түрлендіреміз.
- **f-жол:** `f"{name}, {price:.2f} теңге"`.

```python
name = input("Атың: ")
price = float(input("Тауар бағасы: "))
count = int(input("Саны: "))
total = price * count
print(f"{name}, төлеуге: {total:.2f} теңге")
print("Бүтін бөлу:", 17 // 5, "Қалдық:", 17 % 5, "Дәреже:", 2 ** 5)
```

Нәтижесі:
```text
Атың: Айгерім
Тауар бағасы: 250
Саны: 3
Айгерім, төлеуге: 750.00 теңге
Бүтін бөлу: 3 Қалдық: 2 Дәреже: 32
```

## 2. Шпаргалка: turtle графикасы

| Команда | Әрекеті |
|---|---|
| `forward(n)`, `back(n)` | Алға/артқа n қадам |
| `right(a)`, `left(a)` | Оңға/солға a градусқа бұрылу |
| `penup()`, `pendown()` | Қаламды көтеру/түсіру |
| `pencolor("red")`, `pensize(3)` | Түс, қалыңдық |
| `fillcolor(...)`, `begin_fill()`, `end_fill()` | Бояу |
| `goto(x, y)` | Координатаға көшу |
| `circle(r)` | Шеңбер |

```python
import turtle

t = turtle.Turtle()
t.pensize(3)
t.fillcolor("gold")
t.begin_fill()
for _ in range(5):          # бес бұрышты жұлдыз
    t.forward(150)
    t.right(144)
t.end_fill()
turtle.done()
```

## 3. Шпаргалка: тармақталу

- Салыстыру: `== != > < >= <=`; логикалық амалдар: `and`, `or`, `not`.
- `if` → `elif` → `else`; шегініс (4 бос орын) міндетті.

```python
age = 13
if age < 7 or age >= 65:     # балалар мен зейнеткерлерге тегін
    price = 0
elif age < 18:
    price = 500
else:
    price = 1500
print("Билет бағасы:", price, "теңге")
```

Нәтижесі:
```text
Билет бағасы: 500 теңге
```

## 4. Шпаргалка: циклдер

- `for i in range(start, stop, step)` – белгілі рет қайталау (`stop` кірмейді).
- `while шарт:` – шарт ақиқат болғанша қайталау.
- `break` – циклден шығу, `continue` – келесі қадамға өту.
- Кірістірілген цикл – цикл ішіндегі цикл.

```python
total = 0
for i in range(1, 11):
    if i % 3 == 0:
        continue            # 3-ке бөлінетіндерді өткіземіз
    total += i
print("Қосынды:", total)

for row in range(1, 4):
    print("*" * row)
```

Нәтижесі:
```text
Қосынды: 37
*
**
***
```

## 5. Шпаргалка: тізім, кортеж, жол

| Әрекет | Тізім | Жол |
|---|---|---|
| Индекс | `a[0]`, `a[-1]` | `s[0]`, `s[-1]` |
| Кесінді | `a[1:3]`, `a[::-1]` | `s[:5]`, `s[::-1]` |
| Ұзындығы | `len(a)` | `len(s)` |
| Өзгерту | `append`, `insert`, `remove`, `pop`, `del`, `sort` | өзгермейді! жаңасы жасалады |
| Әдістер | `sum`, `min`, `max`, `sorted` | `upper`, `lower`, `strip`, `replace`, `find`, `count`, `split`, `join` |

Кортеж `(1, 2)` – өзгермейтін тізім. Тізім генераторы: `[x * x for x in range(5)]`.

```python
grades = [5, 3, 4, 5, 2, 5]
grades.append(4)
print("Орташа:", round(sum(grades) / len(grades), 2))
print("Сұрыпталған:", sorted(grades))
print("Тек 5-тер:", [g for g in grades if g == 5])

text = "  python - керемет тіл  "
words = text.strip().split()
print(words, "->", "_".join(words).upper())
```

Нәтижесі:
```text
Орташа: 4.0
Сұрыпталған: [2, 3, 4, 4, 5, 5, 5]
Тек 5-тер: [5, 5, 5]
['python', '-', 'керемет', 'тіл'] -> PYTHON_-_КЕРЕМЕТ_ТІЛ
```

## 7. Шпаргалка: функциялар

- `def name(param, default=1):` – жариялау; `return` – мән қайтару.
- Жергілікті айнымалы тек функция ішінде көрінеді.
- Рекурсия – функцияның өзін-өзі шақыруы (міндетті түрде тоқтау шарты бар).

```python
def rectangle(a, b=1):
    """Тіктөртбұрыштың ауданы мен периметрін қайтарады."""
    return a * b, 2 * (a + b)


def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)


area, perimeter = rectangle(4, 5)
print(area, perimeter, rectangle(3))
print("5! =", factorial(5))
```

Нәтижесі:
```text
20 18 (3, 8)
5! = 120
```

## 8. Шпаргалка: қателер, файлдар, модульдер

```python
import math
import random
from datetime import date

try:
    n = int("42")
    print(math.sqrt(n), random.randint(1, 6), date(2027, 5, 17).strftime("%d.%m.%Y"))
except ValueError:
    print("Сан емес!")

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Бірінші жол\n")
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("Екінші жол\n")
with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

Нәтижесі (кездейсоқ сан әртүрлі):
```text
6.48074069840786 4 17.05.2027
Бірінші жол
Екінші жол
```

| Режим | Мағынасы |
|---|---|
| `"r"` | оқу (файл болуы керек) |
| `"w"` | жазу (ескісін өшіреді) |
| `"a"` | соңына қосу |

## Жиі кездесетін қателер

| Қате | Мысал | Түзету |
|---|---|---|
| `input` нәтижесін санға айналдырмау | `input() + 1` → `TypeError` | `int(input()) + 1` |
| `=` мен `==` шатастыру | `if x = 5:` | `if x == 5:` |
| `:` және шегіністі ұмыту | `for i in range(3)` | `for i in range(3):` + 4 бос орын |
| `range` соңғы мәнді қамтымайды | `range(1, 10)` → 1..9 | `range(1, 11)` |
| Тізім шегінен шығу | `a[len(a)]` | `a[len(a) - 1]` немесе `a[-1]` |
| Функция `return`-сіз | `x = f()` → `None` | функцияға `return` қос |
| `encoding`-сіз файл | қазақ әріптері бұзылады | `encoding="utf-8"` |

## Ескерту

- Кірістірілген анықтама әрқашан қол астында: `help(str)`, `help(list.sort)`, `dir(dict)` – типтің әдістер тізімі.
- Теріс сандар үшін бүтін бөлу мен қалдық төмен қарай дөңгелектенеді: `-7 // 2` → `-4`, `-7 % 2` → `1`.
- `sort()` тізімді өзгертіп, `None` қайтарады, ал `sorted()` жаңа тізім құрады – `x = a.sort()` қатесінің жиі себебі.
- Python 3.7-ден бастап сөздіктер кілттерді қосу ретін сақтайды; жиындар ретті сақтамайды.
- f-жолдар `f"{x=}"` жөндеу түрін қолдайды (Python 3.8+), ол атауын да, мәнін де шығарады: `x=5`.
