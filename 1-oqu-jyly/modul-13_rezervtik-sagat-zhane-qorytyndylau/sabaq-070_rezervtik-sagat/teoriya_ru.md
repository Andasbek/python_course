## 1. Шпаргалка: алгоритм, переменные, типы данных

- **Алгоритм** – точная последовательность действий для достижения цели. Свойства: дискретность, понятность, определённость, результативность, массовость. Виды: линейный, разветвляющийся, циклический.
- **Переменная** – имя, данное значению. Имя: латинские буквы, цифры (не в начале), `_`; не должно быть ключевым словом.
- **Типы:** `int` (целое), `float` (дробное), `str` (строка), `bool` (`True`/`False`); `type()` – определение типа.
- **Операции:** `+ - * /`, `//` (целочисленное деление), `%` (остаток), `**` (степень). Порядок: `**` → `* / // %` → `+ -`.
- **Ввод/вывод:** `input()` всегда возвращает **строку** → преобразуем через `int()`, `float()`.
- **f-строка:** `f"{name}, {price:.2f} тенге"`.

```python
name = input("Твоё имя: ")
price = float(input("Цена товара: "))
count = int(input("Количество: "))
total = price * count
print(f"{name}, к оплате: {total:.2f} тенге")
print("Целочисленное деление:", 17 // 5, "Остаток:", 17 % 5, "Степень:", 2 ** 5)
```

Результат:
```text
Твоё имя: Айгерим
Цена товара: 250
Количество: 3
Айгерим, к оплате: 750.00 тенге
Целочисленное деление: 3 Остаток: 2 Степень: 32
```

## 2. Шпаргалка: графика turtle

| Команда | Действие |
|---|---|
| `forward(n)`, `back(n)` | Вперёд/назад на n шагов |
| `right(a)`, `left(a)` | Поворот вправо/влево на a градусов |
| `penup()`, `pendown()` | Поднять/опустить перо |
| `pencolor("red")`, `pensize(3)` | Цвет, толщина |
| `fillcolor(...)`, `begin_fill()`, `end_fill()` | Заливка |
| `goto(x, y)` | Переход в точку с координатами |
| `circle(r)` | Окружность |

```python
import turtle

t = turtle.Turtle()
t.pensize(3)
t.fillcolor("gold")
t.begin_fill()
for _ in range(5):          # пятиконечная звезда
    t.forward(150)
    t.right(144)
t.end_fill()
turtle.done()
```

## 3. Шпаргалка: ветвление

- Сравнение: `== != > < >= <=`; логические операции: `and`, `or`, `not`.
- `if` → `elif` → `else`; отступ (4 пробела) обязателен.

```python
age = 13
if age < 7 or age >= 65:     # детям и пенсионерам бесплатно
    price = 0
elif age < 18:
    price = 500
else:
    price = 1500
print("Цена билета:", price, "тенге")
```

Результат:
```text
Цена билета: 500 тенге
```

## 4. Шпаргалка: циклы

- `for i in range(start, stop, step)` – повторение заданное число раз (`stop` не входит).
- `while условие:` – повторение, пока условие истинно.
- `break` – выход из цикла, `continue` – переход к следующему шагу.
- Вложенный цикл – цикл внутри цикла.

```python
total = 0
for i in range(1, 11):
    if i % 3 == 0:
        continue            # пропускаем числа, делящиеся на 3
    total += i
print("Сумма:", total)

for row in range(1, 4):
    print("*" * row)
```

Результат:
```text
Сумма: 37
*
**
***
```

## 5. Шпаргалка: список, кортеж, строка

| Действие | Список | Строка |
|---|---|---|
| Индекс | `a[0]`, `a[-1]` | `s[0]`, `s[-1]` |
| Срез | `a[1:3]`, `a[::-1]` | `s[:5]`, `s[::-1]` |
| Длина | `len(a)` | `len(s)` |
| Изменение | `append`, `insert`, `remove`, `pop`, `del`, `sort` | не изменяется! создаётся новая |
| Методы | `sum`, `min`, `max`, `sorted` | `upper`, `lower`, `strip`, `replace`, `find`, `count`, `split`, `join` |

Кортеж `(1, 2)` – неизменяемый список. Генератор списка: `[x * x for x in range(5)]`.

```python
grades = [5, 3, 4, 5, 2, 5]
grades.append(4)
print("Среднее:", round(sum(grades) / len(grades), 2))
print("Отсортированные:", sorted(grades))
print("Только пятёрки:", [g for g in grades if g == 5])

text = "  python - отличный язык  "
words = text.strip().split()
print(words, "->", "_".join(words).upper())
```

Результат:
```text
Среднее: 4.0
Отсортированные: [2, 3, 4, 4, 5, 5, 5]
Только пятёрки: [5, 5, 5]
['python', '-', 'отличный', 'язык'] -> PYTHON_-_ОТЛИЧНЫЙ_ЯЗЫК
```

## 6. Шпаргалка: словарь и множество

```python
capitals = {"Казахстан": "Астана", "Кыргызстан": "Бишкек"}
capitals["Узбекистан"] = "Ташкент"      # добавление
capitals["Кыргызстан"] = "Бишкек"       # изменение
del capitals["Узбекистан"]              # удаление
for country, city in capitals.items():
    print(country, "–", city)
print(capitals.get("Таджикистан", "неизвестно"))

a = {1, 2, 3, 4}
b = {3, 4, 5}
print(a | b, a & b, a - b)
```

Результат:
```text

Кыргызстан – Бишкек
неизвестно
{1, 2, 3, 4, 5} {3, 4} {1, 2}
```

## 7. Шпаргалка: функции

- `def name(param, default=1):` – объявление; `return` – возврат значения.
- Локальная переменная видна только внутри функции.
- Рекурсия – вызов функцией самой себя (обязательно с условием остановки).

```python
def rectangle(a, b=1):
    """Возвращает площадь и периметр прямоугольника."""
    return a * b, 2 * (a + b)


def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)


area, perimeter = rectangle(4, 5)
print(area, perimeter, rectangle(3))
print("5! =", factorial(5))
```

Результат:
```text
20 18 (3, 8)
5! = 120
```

## 8. Шпаргалка: ошибки, файлы, модули

```python
import math
import random
from datetime import date

try:
    n = int("42")
    print(math.sqrt(n), random.randint(1, 6), date(2027, 5, 17).strftime("%d.%m.%Y"))
except ValueError:
    print("Не число!")

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("Вторая строка\n")
with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

Результат (случайное число будет разным):
```text
6.48074069840786 4 17.05.2027
Первая строка
Вторая строка
```

| Режим | Смысл |
|---|---|
| `"r"` | чтение (файл должен существовать) |
| `"w"` | запись (стирает старое) |
| `"a"` | добавление в конец |

## Частые ошибки

| Ошибка | Пример | Исправление |
|---|---|---|
| Не преобразовали результат `input` в число | `input() + 1` → `TypeError` | `int(input()) + 1` |
| Путаница `=` и `==` | `if x = 5:` | `if x == 5:` |
| Забыли `:` и отступ | `for i in range(3)` | `for i in range(3):` + 4 пробела |
| `range` не включает последнее значение | `range(1, 10)` → 1..9 | `range(1, 11)` |
| Выход за пределы списка | `a[len(a)]` | `a[len(a) - 1]` или `a[-1]` |
| Функция без `return` | `x = f()` → `None` | добавить в функцию `return` |
| Файл без `encoding` | русские и казахские буквы искажаются | `encoding="utf-8"` |

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Тип данных | Вид значения: `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set` |
| Изменяемый тип | Объект можно менять на месте: `list`, `dict`, `set` |
| Неизменяемый тип | Объект нельзя изменить: `int`, `float`, `str`, `tuple` |
| Срез | Часть последовательности: `s[start:stop:step]` |
| Генератор списка | Краткая запись создания списка: `[x * x for x in range(5)]` |
| Контекстный менеджер (`with`) | Конструкция, автоматически закрывающая файл |

## Примечание

- Встроенная справка всегда под рукой: `help(str)`, `help(list.sort)`, `dir(dict)` – список методов типа.
- Целочисленное деление и остаток для отрицательных чисел округляют вниз: `-7 // 2` → `-4`, `-7 % 2` → `1`.
- `sort()` изменяет список и возвращает `None`, а `sorted()` создаёт новый список – частая причина ошибки `x = a.sort()`.
- Начиная с Python 3.7 словари сохраняют порядок добавления ключей; множества порядок не сохраняют.
- f-строки поддерживают отладочную форму `f"{x=}"` (Python 3.8+), которая выводит и имя, и значение: `x=5`.
- Документация: [Python Tutorial](https://docs.python.org/3/tutorial/index.html), [Built-in Functions](https://docs.python.org/3/library/functions.html), [Built-in Types](https://docs.python.org/3/library/stdtypes.html).
