## 1. Негізгі тақырыптар картасы

| Тақырып | Негізгі ұғымдар мен конструкциялар |
|---|---|
| Алгоритм және алғашқы бағдарлама | алгоритм, блок-схема, IDLE/Thonny, `print`, `#` түсініктемесі |
| Айнымалылар және типтер | `int`, `float`, `str`, `bool`, арифметикалық амалдар, `input`, f-жол |
| turtle графикасы | `forward`, `left`, `goto`, түс, бояу |
| Тармақталу | `if/elif/else`, `and/or/not` |
| Циклдер | `for`, `range`, `while`, `break`, `continue`, кірістірілген циклдер |
| Тізімдер және кортеждер | индекс, әдістер, сұрыптау, кесінді, тізім генераторы, `tuple` |
| Жолдар | жол әдістері, `split`/`join`, символдарды талдау |
| Сөздіктер және жиындар | кілт-мән, `items()`, жиын амалдары |
| Функциялар | `def`, параметрлер, `return`, көріну аймағы, рекурсия |
| Қателер және файлдар | қате түрлері, `try/except`, `open`, `with`, `r`/`w`/`a` режимдері |
| Стандартты модульдер | `import`, `math`, `random`, `time`, `datetime` |
| Жобаны әзірлеу | ТТ, MVP, декомпозиция, тестілеу, README |

### Тақырыптар қалай байланысқан?

```text
  Алгоритм ──► Айнымалылар, типтер ──► Тармақталу ──► Циклдер
                                                        │
          ┌─────────────────────────────────────────────┘
          ▼
   Тізім, жол, сөздік, жиын (деректер құрылымдары)
          │
          ▼
      Функциялар (кодты ұйымдастыру)
          │
          ▼
   Қателер + Файлдар + Модульдер (сенімділік, жады, дайын құралдар)
          │
          ▼
      ӨЗ ЖОБАҢ  ──►  ОБП, GUI, деректер, веб
```

Әр тақырып алдыңғысына сүйенеді: цикл тармақталусыз, функция циклсіз, жоба функцияларсыз мүмкін емес.

## 2. Барлық негізгі тақырыптар бір бағдарламада

Төмендегі шағын бағдарлама тілдің негізгі конструкцияларының барлығын дерлік қолданады; түсініктемелерде жолда қай тақырып қолданылғаны көрсетілген.

```python
import random                                   # модуль
from datetime import date                       # datetime

FILE_NAME = "year_results.txt"                  # айнымалы (тұрақты)


def make_question():                            # функция
    """Кездейсоқ көбейту мысалын және жауабын қайтарады."""
    a = random.randint(2, 9)
    b = random.randint(2, 9)
    return f"{a} x {b}", a * b                  # кортеж қайтару


def ask(question, answer):
    while True:                                 # while цикл
        try:                                    # try...except
            user = int(input(question + " = "))
            return user == answer               # логикалық өрнек
        except ValueError:
            print("Сан енгіз!")


name = input("Атың: ").strip().title()          # жол әдістері
stats = {"дұрыс": 0, "қате": 0}                 # сөздік
mistakes = []                                   # тізім
for i in range(5):                              # for цикл
    q, ans = make_question()
    if ask(q, ans):                             # тармақталу
        stats["дұрыс"] += 1
    else:
        stats["қате"] += 1
        mistakes.append(f"{q} = {ans}")

print(f"{name}, нәтижең: {stats['дұрыс']}/5")    # f-жол
if mistakes:
    print("Қайталау керек:", ", ".join(mistakes))
with open(FILE_NAME, "a", encoding="utf-8") as f:   # файл
    f.write(f"{date.today()};{name};{stats['дұрыс']}\n")
```

Тек `turtle` қолданылмаған – оны нәтижені көрнекі шығару үшін қосуға болады (мысалы, дұрыс жауаптар санына қарай жұлдыз салу).

## 3. Python-ның 12 алтын ережесі

1. `input()` әрқашан жол қайтарады – санға айналдыруды ұмытпа.
2. `:` және шегініс (4 бос орын) – Python-ның «тыныс белгілері».
3. `=` – меншіктеу, `==` – салыстыру.
4. `range(a, b)` – `b` кірмейді; индекстер 0-ден басталады.
5. Белгілі рет қайталау – `for`, шарт бойынша – `while`.
6. Жол өзгермейді – әдістер жаңа жол қайтарады.
7. Тізім – реттелген, сөздік – кілт бойынша, жиын – қайталанбайтын.
8. Функция бір нәрсені жақсы істейді және нәтижені `return` арқылы береді.
9. Қате – досың: Traceback-ті төменнен жоғары оқы.
10. Файлды `with open(..., encoding="utf-8")` арқылы аш.
11. Дайын модульді қолдан – «дөңгелекті қайта ойлап таппа».
12. Кішкене қадам → тексеру → сақтау.

## 4. Даму бағыттары: Python-да әрі қарай не бар

Негіздерді меңгергеннен кейін шағын консольдік бағдарламалардан **нақты қосымшаларға** көшуге болады. Негізгі бағыттар мен технологиялар:

| Бағыт | Технология | Бағдарлама мысалдары |
|---|---|---|
| Әзірлеуші құралдары | VS Code, venv, pip, **Git**, **GitHub** | Кәсіби орта, жобалар репозиторийі |
| Объектіге бағытталған бағдарламалау (ОБП) | `class`, объект, мұрагерлік | «Оқушы», «Ойыншы», «Банк шоты» кластары |
| Графикалық интерфейс | **Tkinter** | Терезелі қосымшалар: калькулятор, күнделік |
| Компьютерлік ойындар | **Pygame** | Графикасы мен дыбысы бар 2D ойындар |
| Деректерді сақтау | CSV, JSON, **SQLite** | Деректер қоры бар қосымша |
| Интернетпен жұмыс | **requests**, API, BeautifulSoup | Ауа райы, валюта бағамы бағдарламалары |
| Деректерді талдау | **Pandas**, **Matplotlib** | Графиктер мен диаграммалар |
| Код сапасы | PEP 8, тестілеу (`pytest`), құжаттама | Сапалы, тексерілген код |

### Осы бағыттардағы код мысалдары

**ОБП – өз класың.** Деректер (сөздіктегідей) және олармен жұмыс істейтін функциялар объектіге біріктіріледі:

```python
class Student:
    """Оқушы туралы мәліметтерді сақтайтын класс."""

    def __init__(self, name, grades):
        self.name = name
        self.grades = grades

    def average(self):
        return sum(self.grades) / len(self.grades)


aigerim = Student("Айгерім", [5, 5, 4])
print(aigerim.name, round(aigerim.average(), 2))
```

Нәтижесі:
```text
Айгерім 4.67
```

**Tkinter – алғашқы терезе.** Консоль орнына – батырмасы бар терезе:

```python
import tkinter as tk


def say_hello():
    label.config(text="Сәлем, " + entry.get() + "!")


window = tk.Tk()
window.title("Менің алғашқы терезем")
entry = tk.Entry(window, font=("Arial", 14))
entry.pack(padx=20, pady=10)
button = tk.Button(window, text="Сәлемдесу", command=say_hello)
button.pack(pady=5)
label = tk.Label(window, text="", font=("Arial", 16))
label.pack(pady=10)
window.mainloop()
```

**API – интернеттен деректер.** `requests` кітапханасы тегін ашық API-дан Алматының ауа райын алады:

```python
import requests

url = "https://api.open-meteo.com/v1/forecast"
params = {"latitude": 43.24, "longitude": 76.89, "current_weather": "true"}
data = requests.get(url, params=params, timeout=10).json()
print("Алматыда қазір:", data["current_weather"]["temperature"], "°C")
```

(Іске қоспас бұрын кітапхананы орнату керек: `pip install requests`.)

## Жиі кездесетін қателер

Бес типтік қате – кодта түзетілген нұсқасы көрсетілген:

```python
# 1. Типті түрлендіруді ұмыту
age = int("13")
print(age + 1)

# 2. Тізім шегінен шығу
items = ["а", "ә", "б"]
print(items[len(items) - 1])

# 3. return орнына print
def double(x):
    return x * 2
print(double(4) + 1)

# 4. Сөздікте жоқ кілт
d = {"алма": 5}
print(d.get("алмұрт", 0))

# 5. Файлды кодтаусыз ашу
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Сәлем!")
```

Нәтижесі:
```text
14
б
9
0
```
