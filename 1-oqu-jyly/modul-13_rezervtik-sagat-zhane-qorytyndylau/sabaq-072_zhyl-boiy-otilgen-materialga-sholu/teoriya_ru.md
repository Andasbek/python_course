## 2. Все основные темы в одной программе

Небольшая программа ниже использует почти все основные конструкции языка; в комментариях указано, какая тема задействована в строке.

```python
import random                                   # модуль
from datetime import date                       # datetime

FILE_NAME = "year_results.txt"                  # переменная (константа)


def make_question():                            # функция
    """Возвращает случайный пример на умножение и ответ."""
    a = random.randint(2, 9)
    b = random.randint(2, 9)
    return f"{a} x {b}", a * b                  # возврат кортежа


def ask(question, answer):
    while True:                                 # цикл while
        try:                                    # try...except
            user = int(input(question + " = "))
            return user == answer               # логическое выражение
        except ValueError:
            print("Введи число!")


name = input("Твоё имя: ").strip().title()      # методы строк
stats = {"верно": 0, "неверно": 0}              # словарь
mistakes = []                                   # список
for i in range(5):                              # цикл for
    q, ans = make_question()
    if ask(q, ans):                             # ветвление
        stats["верно"] += 1
    else:
        stats["неверно"] += 1
        mistakes.append(f"{q} = {ans}")

print(f"{name}, твой результат: {stats['верно']}/5")   # f-строка
if mistakes:
    print("Нужно повторить:", ", ".join(mistakes))
with open(FILE_NAME, "a", encoding="utf-8") as f:   # файл
    f.write(f"{date.today()};{name};{stats['верно']}\n")
```

Не используется только `turtle` – его можно подключить для наглядного вывода результата (например, рисовать звёзды по числу верных ответов).

## 3. 12 золотых правил Python

1. `input()` всегда возвращает строку – не забывай преобразовывать в число.
2. `:` и отступ (4 пробела) – «знаки препинания» Python.
3. `=` – присваивание, `==` – сравнение.
4. `range(a, b)` – `b` не входит; индексы начинаются с 0.
5. Повторение заданное число раз – `for`, по условию – `while`.
6. Строка не изменяется – методы возвращают новую строку.
7. Список – упорядоченный, словарь – по ключу, множество – без повторов.
8. Функция хорошо делает одно дело и отдаёт результат через `return`.
9. Ошибка – твой друг: читай Traceback снизу вверх.
10. Открывай файл через `with open(..., encoding="utf-8")`.
11. Используй готовый модуль – «не изобретай велосипед».
12. Маленький шаг → проверка → сохранение.

## 4. Направления развития: что дальше в Python

Освоив основы, можно переходить от небольших консольных программ к **настоящим приложениям**. Основные направления и технологии:

| Направление | Технология | Примеры программ |
|---|---|---|
| Инструменты разработчика | VS Code, venv, pip, **Git**, **GitHub** | Профессиональная среда, репозиторий с проектами |
| Объектно-ориентированное программирование (ООП) | `class`, объект, наследование | Классы «Ученик», «Игрок», «Банковский счёт» |
| Графический интерфейс | **Tkinter** | Оконные приложения: калькулятор, дневник |
| Компьютерные игры | **Pygame** | 2D-игры с графикой и звуком |
| Хранение данных | CSV, JSON, **SQLite** | Приложение с базой данных |
| Работа с интернетом | **requests**, API, BeautifulSoup | Программы погоды, курса валют |
| Анализ данных | **Pandas**, **Matplotlib** | Графики и диаграммы |
| Качество кода | PEP 8, тестирование (`pytest`), документация | Качественный, проверенный код |

### Примеры кода из этих направлений

**ООП – свой класс.** Данные (как в словаре) и функции для работы с ними объединяются в объект:

```python
class Student:
    """Класс, хранящий сведения об ученике."""

    def __init__(self, name, grades):
        self.name = name
        self.grades = grades

    def average(self):
        return sum(self.grades) / len(self.grades)


aigerim = Student("Айгерим", [5, 5, 4])
print(aigerim.name, round(aigerim.average(), 2))
```

Результат:
```text
Айгерим 4.67
```

**Tkinter – первое окно.** Вместо консоли – окно с кнопкой:

```python
import tkinter as tk


def say_hello():
    label.config(text="Привет, " + entry.get() + "!")


window = tk.Tk()
window.title("Моё первое окно")
entry = tk.Entry(window, font=("Arial", 14))
entry.pack(padx=20, pady=10)
button = tk.Button(window, text="Поздороваться", command=say_hello)
button.pack(pady=5)
label = tk.Label(window, text="", font=("Arial", 16))
label.pack(pady=10)
window.mainloop()
```

**API – данные из интернета.** Библиотека `requests` получает погоду в Алматы из бесплатного открытого API:

```python
import requests

url = "https://api.open-meteo.com/v1/forecast"
params = {"latitude": 43.24, "longitude": 76.89, "current_weather": "true"}
data = requests.get(url, params=params, timeout=10).json()
print("Сейчас в Алматы:", data["current_weather"]["temperature"], "°C")
```

(Перед запуском нужно установить библиотеку: `pip install requests`.)

## Частые ошибки

Пять типичных ошибок – в коде показан исправленный вариант:

```python
# 1. Забыли преобразовать тип
age = int("13")
print(age + 1)

# 2. Выход за пределы списка
items = ["а", "б", "в"]
print(items[len(items) - 1])

# 3. print вместо return
def double(x):
    return x * 2
print(double(4) + 1)

# 4. Отсутствующий ключ в словаре
d = {"яблоко": 5}
print(d.get("груша", 0))

# 5. Открытие файла без кодировки
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Привет!")
```

Результат:
```text
14
в
9
0
```

## Основные понятия

| Понятие | Пояснение |
|---|---|
| ООП (OOP) | Объектно-ориентированное программирование: программа из объектов (данные + методы) |
| Графический интерфейс (GUI) | Управление через окна, кнопки |
| База данных (SQLite) | Система структурированного хранения данных |
| API | Способ обмена данными между программами |
| Git / GitHub | Система управления версиями кода / платформа для публикации проектов |
| Класс / объект | Описание нового типа данных / конкретный экземпляр этого типа |

## Примечание

- Python развивается: новая версия выходит ежегодно в октябре. Полезные новшества последних лет – f-строки (3.6), `match` (3.10), подробные сообщения об ошибках (3.10–3.12). Узнать свою версию: `python --version`.
- Python 2 официально не поддерживается с 2020 года; примеры с `print "text"` без скобок устарели и в Python 3 не работают.
- `tkinter` входит в стандартную библиотеку (на Linux иногда ставится отдельным пакетом `python3-tk`), а `requests`, `pygame`, `pandas`, `matplotlib` устанавливаются через `pip`.
- Для работы с интернетом без сторонних библиотек есть стандартный модуль `urllib.request`, но `requests` проще и стал фактическим стандартом.
- Официальные ресурсы: [Python Tutorial](https://docs.python.org/3/tutorial/index.html), [Standard Library](https://docs.python.org/3/library/index.html), [Python Package Index (PyPI)](https://pypi.org/), [PEP 8](https://peps.python.org/pep-0008/).
