## Бағалау критерийлері

Брейн-ринг командалық ойын ретінде бағаланады (ұпайлар қосындысы). Жылдық қорытынды баға мониторинг кестесі бойынша шығарылады:

| Бақылау түрі | Құрамы | Үлесі |
|---|---|---|
| Ағымдағы бақылау | Сабақтағы практикалық жұмыстар, кодты өзара рецензиялау | 30% |
| Аралық бақылау | Өзіндік жұмыстар №1–№6 | 40% |
| Қорытынды бақылау | Қорытынды жобаны әзірлеу және қорғау | 30% |

Меңгеру деңгейлері: **жоғары (85–100%)**, **орта (60–84%)**, **бастапқы (40–59%)**.

*Ескерту: үлестер ұсынылатын үлгі; педагог оны үйірменің ішкі ережесіне сай өзгерте алады.*

import turtle


def draw_stars(count):
    t = turtle.Turtle()
    t.speed(0)
    t.color("gold")
    t.penup()
    t.goto(-250, 0)
    for _ in range(count):
        t.pendown()
        t.begin_fill()
        for _ in range(5):
            t.forward(60)
            t.right(144)
        t.end_fill()
        t.penup()
        t.forward(100)
    turtle.done()

import turtle

labels = ["ӨЖ1", "ӨЖ2", "ӨЖ3", "ӨЖ4", "ӨЖ5", "ӨЖ6", "Жоба"]
values = [80, 75, 90, 85, 70, 95, 92]
t = turtle.Turtle()
t.speed(0)
t.penup()
x = -300
for i in range(len(values)):
    t.goto(x, -150)
    t.pendown()
    t.fillcolor("skyblue" if values[i] < 85 else "seagreen")
    t.begin_fill()
    for side in [50, values[i] * 3, 50, values[i] * 3]:
        t.forward(side)
        t.left(90)
    t.end_fill()
    t.penup()
    t.goto(x + 25, -150 + values[i] * 3 + 5)
    t.write(f"{values[i]}%", align="center")
    t.goto(x + 25, -175)
    t.write(labels[i], align="center")
    x += 85
t.hideturtle()
turtle.done()

**8-тапсырма:**

```python
class Student:
    def __init__(self, name, grades):
        self.name = name
        self.grades = grades

    def average(self):
        return sum(self.grades) / len(self.grades)

    def add_grade(self, grade):
        if 1 <= grade <= 5:
            self.grades.append(grade)

    def is_excellent(self):
        return self.average() >= 4.5


s = Student("Дана", [5, 4])
s.add_grade(5)
print(s.name, round(s.average(), 2), s.is_excellent())
```
