# Сабақ 39. Практикалық тапсырмалар: кесінділер және тізім генераторлары

## Базалық деңгей

### 1-тапсырма. Кесінділерді болжа
```python
letters = ["а", "б", "в", "г", "д", "е", "ж", "з"]
```
Компьютерсіз жаз, содан кейін тексер:
1. `letters[2:5]`
2. `letters[:4]`
3. `letters[5:]`
4. `letters[-3:]`
5. `letters[::3]`
6. `letters[::-2]`
7. `letters[6:2:-1]`
8. `letters[3:3]`

### 2-тапсырма. Апта бөліктері
`week = ["Дүйсенбі", "Сейсенбі", "Сәрсенбі", "Бейсенбі", "Жұма", "Сенбі", "Жексенбі"]`. Кесінділер арқылы шығар:
- жұмыс күндері (алғашқы 5);
- демалыс күндері (соңғы 2);
- аптаның ортасы (Сейсенбіден Бейсенбіге дейін);
- кері ретпен барлық күндер.

### 3-тапсырма. Циклді генераторға аудар
Әр бағдарламаны тізім генераторымен бір жолға қайта жаз:
```python
# а)
cubes = []
for i in range(1, 8):
    cubes.append(i ** 3)

# ә)
odd = []
for i in range(1, 30):
    if i % 2 == 1:
        odd.append(i)

# б)
doubled = []
for x in [3, 8, 1, 6]:
    doubled.append(x * 2)
```

### 4-тапсырма. Бағаны теңгеге аудару
Долларлық бағалар тізімі: `usd = [12.5, 40, 7.99, 120]`. Бағам 1 USD = 505 теңге деп алып, генератор арқылы теңгедегі бағалар тізімін құр (бүтін санға дөңгелектеп).

### 5-тапсырма. Сүзгі
`words = ["алма", "кітап", "ит", "компьютер", "үй", "мектеп", "су"]`. Генератор арқылы:
- 3 әріптен ұзын сөздер тізімін;
- әр сөздің ұзындығы тізімін құр.

## Кеңейтілген деңгей

### 6-тапсырма. Көшірме ме, сілтеме ме?
Төмендегі кодтың нәтижесін болжап, түсіндір. Содан кейін `original` өзгермейтіндей етіп түзет:
```python
original = [1, 2, 3]
copy = original
copy[0] = 100
print(original)
```

### 7-тапсырма. Бағалар статистикасы
Пайдаланушы `n` баға енгізеді (генератор арқылы). Шығар:
- соңғы 3 бағаны (кесінді);
- «4» және «5» бағаларының тізімін (генератор + шарт);
- әр бағаның мәртебесін: 4 және одан жоғары — «жақсы», әйтпесе — «жақсарту керек» (тернарлы өрнек).

### 8-тапсырма. Ортаңғы элементтер
Тізім берілген. Егер элементтер саны тақ болса — ортаңғы бір элементті, жұп болса — ортаңғы екі элементті кесінді арқылы шығар.

Мысал: `[1, 2, 3, 4, 5]` → `[3]`, `[1, 2, 3, 4, 5, 6]` → `[3, 4]`.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Тізімді айналдыру (циклдік ығысу)
Тізім мен `k` саны берілген. Тізімді оңға `k` позицияға циклдік ығыстыр — кесінділер арқылы, бір жолда.

Мысал: `[1, 2, 3, 4, 5]`, `k = 2` → `[4, 5, 1, 2, 3]`.

### 10-тапсырма. Жай сандар генераторы
2-ден 100-ге дейінгі жай сандардың тізімін **бір** генератор арқылы құр.

**Кеңес:** ішкі генератор: `[d for d in range(2, x) if x % d == 0]` бос болса — сан жай.

## Үй тапсырмасы

1. Өз есіміңді кері ретпен кесінді арқылы шығар. Есімің палиндром ба (`name == name[::-1]`)?
2. 1-ден 20-ға дейінгі сандардың квадраттарынан генератор арқылы тізім құр, одан тек 5-ке бөлінбейтіндерін қалдыр.
3. `temps = [-3, 2, 5, -1, 8, 12, -4, 6, 10, 3]` (10 күн). Алғашқы 5 күн мен соңғы 5 күннің орташа температурасын кесінділер арқылы есептеп, салыстыр.

**8-тапсырма**
```python
a = [1, 2, 3, 4, 5, 6]
n = len(a)
if n % 2 == 1:
    print(a[n // 2:n // 2 + 1])

```

**9-тапсырма**
```python
a = [1, 2, 3, 4, 5]
k = 2
k = k % len(a)
rotated = a[-k:] + a[:-k] if k else a[:]
print(rotated)
```
`k % len(a)` — `k` тізім ұзындығынан үлкен болған жағдай үшін; `k = 0` болса `a[-0:]` бүкіл тізімді береді, сондықтан бөлек тексереміз.
