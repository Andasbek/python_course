## Базовый уровень

### Задание 1. Предскажи срезы
```python
letters = ["а", "б", "в", "г", "д", "е", "ж", "з"]
```

7. `letters[6:2:-1]`

### Задание 2. Части недели
`week = ["Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"]`. С помощью срезов выведи:
- рабочие дни (первые 5);
- выходные дни (последние 2);
- середину недели (со вторника по четверг);
- все дни в обратном порядке.

### Задание 3. Переведи цикл в генератор
Перепиши каждую программу в одну строку с помощью генератора списка:
```python
# а)
cubes = []
for i in range(1, 8):
    cubes.append(i ** 3)

# б)
odd = []
for i in range(1, 30):
    if i % 2 == 1:
        odd.append(i)

# в)
doubled = []
for x in [3, 8, 1, 6]:
    doubled.append(x * 2)
```

### Задание 4. Перевод цен в тенге

### Задание 5. Фильтр

- список слов длиннее 3 букв;
- список длин каждого слова.

## Продвинутый уровень

### Задание 6. Копия или ссылка?
Предскажи и объясни результат следующего кода. Затем исправь так, чтобы `original` не изменялся:

### Задание 7. Статистика оценок
Пользователь вводит `n` оценок (с помощью генератора). Выведи:
- последние 3 оценки (срез);
- список оценок «4» и «5» (генератор + условие);
- статус каждой оценки: 4 и выше — «хорошо», иначе — «нужно улучшить» (тернарное выражение).

### Задание 8. Средние элементы
Дан список. Если количество элементов нечётное — выведи с помощью среза один средний элемент, если чётное — два средних элемента.

Пример: `[1, 2, 3, 4, 5]` → `[3]`, `[1, 2, 3, 4, 5, 6]` → `[3, 4]`.

## ★ Олимпиадная / творческая задача

### Задание 9. Вращение списка (циклический сдвиг)
Даны список и число `k`. Циклически сдвинь список вправо на `k` позиций — с помощью срезов, в одну строку.

Пример: `[1, 2, 3, 4, 5]`, `k = 2` → `[4, 5, 1, 2, 3]`.

### Задание 10. Генератор простых чисел
Создай список простых чисел от 2 до 100 с помощью **одного** генератора.

**Подсказка:** если внутренний генератор `[d for d in range(2, x) if x % d == 0]` пуст — число простое.

**Задание 9**
```python
a = [1, 2, 3, 4, 5]
k = 2
k = k % len(a)
rotated = a[-k:] + a[:-k] if k else a[:]
print(rotated)
```
`k % len(a)` — на случай, если `k` больше длины списка; при `k = 0` `a[-0:]` даёт весь список, поэтому проверяем отдельно.
