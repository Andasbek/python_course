# Урок 35. Практические задания: создание списка и индексы

## Базовый уровень

### Задание 1. Мои списки
Создай три списка и выведи их на экран:
- 4 твоих любимых блюда;
- возраст 5 твоих друзей;
- 5 областных центров Казахстана.

Отдельно выведи первый и последний элементы каждого списка.

### Задание 2. Предскажи индекс
```python
rivers = ["Иртыш", "Сырдарья", "Или", "Ишим", "Урал", "Тобол"]
```
Запиши без компьютера, затем проверь:
1. `rivers[1]`
2. `rivers[-1]`
3. `rivers[3]`
4. `rivers[-4]`
5. `rivers[0] + " и " + rivers[2]`
6. `rivers[6]` — что произойдёт?

### Задание 3. Название месяца
Создай список из 12 названий месяцев. Пользователь вводит номер месяца (1–12), программа выводит название месяца. Если номер вне диапазона 1–12, вывести «Такого месяца нет».

Пример:
```text
Номер месяца: 9
Сентябрь
```

### Задание 4. Исправление оценки
`grades = [4, 3, 5, 2, 4]`. Учитель изменил оценку 4-го ученика на 3, а оценку последнего ученика — на 5. Внеси изменения по индексу и выведи новый список.

### Задание 5. Есть или нет?
Дан список учеников класса: `["Али", "Мадина", "Нурлан", "Томирис", "Санжар"]`. Пользователь вводит имя. Программа отвечает «Да, этот ученик в этом классе» или «Такого ученика нет».

## Продвинутый уровень

### Задание 6. Заполнение списка с клавиатуры
Создай список `[0] * 5` из 5 элементов. С помощью цикла запроси у пользователя 5 чисел и запиши их в список по индексу. Затем выведи список и сумму первого и последнего элементов.

### Задание 7. Шаги за неделю
Количество шагов за 7 дней недели дано в списке:
`steps = [8500, 12000, 6400, 10300, 9100, 15000, 4300]`. С помощью цикла (по индексам) найди:
- сумму всех шагов;
- количество дней, когда шагов было больше 10 000;
- номер дня с наибольшим количеством шагов (не используй `max()`).

### Задание 8. Поменяй первый и последний
Пользователь вводит 4 слова (они записываются в список). Поменяй местами первый и последний элементы и выведи список.

## ★ Олимпиадная / творческая задача

### Задание 9. Разворот списка
Расположи список `a = [1, 2, 3, 4, 5, 6, 7]` в обратном порядке, **не создавая новый список**, только с помощью перестановок (не используй `reverse()` и срезы — мы их пройдём позже).

**Подсказка:** меняй `i`-й элемент с элементом `-1 - i`; цикл идёт до половины.

### Задание 10. Игра со списком: «Магический шар»
Создай список из 10 разных ответов («Да», «Нет», «Возможно», «Спроси позже», ...). Пользователь вводит вопрос, программа выбирает случайный ответ с помощью `random.randint(0, 9)`. Продолжать, пока не введено «стоп».

## Домашнее задание

1. Создай два списка: имена членов семьи и их возраст (в одинаковом порядке). Выведи по индексу в виде «Папа — 42 года».
2. Создай список своих четвертных оценок по 5 предметам. С помощью цикла вычисли среднюю оценку.
3. С помощью `list(range(...))` создай список чисел, кратных 5, от 5 до 50 и выведи его 3-й элемент и 2-й с конца.

**Задание 7**
```python
steps = [8500, 12000, 6400, 10300, 9100, 15000, 4300]
total = 0
active_days = 0
best_day = 0
for i in range(7):
    total += steps[i]
    if steps[i] > 10000:
        active_days += 1
    if steps[i] > steps[best_day]:
        best_day = i
print("Всего:", total)
print("Дней больше 10 000:", active_days)
print("Самый активный день:", best_day + 1)
```
Результат: 65600, 3, 6.
