## 1. Әдіс (метод) деген не?

**Әдіс (метод, method)** — белгілі бір типтегі объектіге тиесілі функция. Ол объектінің атынан кейін **нүкте** арқылы шақырылады:

```text
<тізім>.<әдіс>(<аргументтер>)
```

Мысалы, `fruits.append("алма")` — «`fruits` тізіміне "алма"-ны қос». Әдістер тізімнің **өзін** өзгертеді.

| Әдіс / оператор | Не істейді |
|---|---|
| `append(x)` | Соңына `x` қосады |
| `insert(i, x)` | `i` индексіне `x` қояды |
| `extend(lst2)` | Соңына басқа тізімнің барлық элементтерін қосады |
| `remove(x)` | Бірінші кездескен `x` мәнін жояды |
| `pop()` | Соңғы элементті жойып, оны **қайтарады** |
| `pop(i)` | `i` индексіндегі элементті жойып, қайтарады |
| `del lst[i]` | `i` индексіндегі элементті жояды (оператор) |
| `clear()` | Барлық элементтерді жояды |

## 2. append() — соңына қосу

```python
shopping = ["нан", "сүт"]
shopping.append("жұмыртқа")
shopping.append("ірімшік")
print(shopping)
```
Нәтижесі:
```text
['нан', 'сүт', 'жұмыртқа', 'ірімшік']
```

### Бос тізімді цикл арқылы толтыру
Бұл — ең жиі қолданылатын тәсіл: бос тізім құрамыз да, циклде `append` жасаймыз.
```python
grades = []
for i in range(5):
    g = int(input(f"{i + 1}-баға: "))
    grades.append(g)
print("Бағалар:", grades)
```
Мысал:
```text
1-баға: 5
2-баға: 4
3-баға: 5
4-баға: 3
5-баға: 4
Бағалар: [5, 4, 5, 3, 4]
```

### Элементтер саны белгісіз болса (while)
```python
names = []
while True:
    name = input("Есім (бос жол — аяқтау): ")
    if name == "":
        break
    names.append(name)
print("Тізім:", names)
```

### Шарт бойынша тізім құру
```python
squares = []
for n in range(1, 11):
    if n % 2 == 0:
        squares.append(n * n)
print(squares)
```
Нәтижесі:
```text
[4, 16, 36, 64, 100]
```

## 3. insert() — белгілі орынға қою

`insert(i, x)` — `x`-ті `i` индексіне қояды; одан кейінгі элементтер оңға «жылжиды».
```python
queue = ["Асқар", "Бота", "Дәулет"]
queue.insert(1, "Ерлан")     # 1-орынға
print(queue)
queue.insert(0, "Ана мен бала")   # ең басына
print(queue)
```
Нәтижесі:
```text
['Асқар', 'Ерлан', 'Бота', 'Дәулет']
['Ана мен бала', 'Асқар', 'Ерлан', 'Бота', 'Дәулет']
```

Индекс тізім ұзындығынан үлкен болса, элемент соңына қосылады (қате болмайды): `queue.insert(100, "Зарина")`.

## 4. extend() және + — тізімдерді біріктіру

```python
a = [1, 2, 3]
b = [4, 5]
a.extend(b)
print(a)

c = [10]
c.append([20, 30])   # тізім БІР элемент ретінде қосылады
print(c)
```
Нәтижесі:
```text
[1, 2, 3, 4, 5]
[10, [20, 30]]
```
`append` пен `extend` айырмашылығына назар аудар!

## 5. remove() — мәні бойынша жою

`remove(x)` — тізімнен **бірінші кездескен** `x` мәнін жояды:
```python
pets = ["мысық", "ит", "балық", "ит"]
pets.remove("ит")
print(pets)
```
Нәтижесі:
```text
['мысық', 'балық', 'ит']
```

Егер мән тізімде болмаса — `ValueError`:
```text
pets.remove("тотықұс")
ValueError: list.remove(x): x not in list
```
Сондықтан алдымен `in` арқылы тексерген дұрыс:
```python
pets = ["мысық", "ит", "балық"]
animal = input("Қай жануарды өшірейік? ")
if animal in pets:
    pets.remove(animal)
    print("Өшірілді:", pets)
else:
    print("Мұндай жануар тізімде жоқ")
```

Барлық кездесулерді жою үшін — `while` циклі:
```python
nums = [1, 0, 2, 0, 3, 0]
while 0 in nums:
    nums.remove(0)
print(nums)
```
Нәтижесі:
```text
[1, 2, 3]
```

## 6. pop() — индекс бойынша жою және қайтару

`pop()` элементті жояды **және оны қайтарады** — оны айнымалыға сақтап, әрі қарай қолдануға болады.
```python
stack = ["1-кітап", "2-кітап", "3-кітап"]
top = stack.pop()          # соңғысын алу
print("Алынды:", top)
print("Қалды:", stack)

first = stack.pop(0)       # бірінші элементті алу
print("Алынды:", first)
print("Қалды:", stack)
```
Нәтижесі:
```text
Алынды: 3-кітап
Қалды: ['1-кітап', '2-кітап']
Алынды: 1-кітап
Қалды: ['2-кітап']
```

Бос тізімнен `pop()` → `IndexError: pop from empty list`.

### Кезек (очередь) моделі
```python
queue = ["Айбек", "Гүлназ", "Мирас"]
queue.append("Сая")              # кезекке жаңа адам келді
served = queue.pop(0)            # кезектегі бірінші адамға қызмет көрсетілді
print("Қызмет көрсетілді:", served)
print("Кезекте:", queue)
```
Нәтижесі:
```text
Қызмет көрсетілді: Айбек
Кезекте: ['Гүлназ', 'Мирас', 'Сая']
```

## 7. del операторы және clear()

`del` — Python операторы (әдіс емес!), индекс бойынша жояды, мәнді қайтармайды:
```python
letters = ["а", "ә", "б", "в", "г"]
del letters[1]
print(letters)
del letters[-1]
print(letters)
```
Нәтижесі:
```text
['а', 'б', 'в', 'г']
['а', 'б', 'в']
```

`clear()` — тізімді толық тазалайды:
```python
basket = ["алма", "банан"]
basket.clear()
print(basket)
```
Нәтижесі:
```text
[]
```

## 8. Жою тәсілдерін салыстыру

| Тәсіл | Неге сүйенеді | Мәнді қайтара ма | Элемент жоқ болса |
|---|---|---|---|
| `remove(x)` | **мәнге** | Жоқ | `ValueError` |
| `pop()` / `pop(i)` | **индекске** (әдепкіде соңғы) | **Иә** | `IndexError` |
| `del lst[i]` | **индекске** | Жоқ | `IndexError` |
| `clear()` | барлығы | Жоқ | — |

Қашан қайсысын қолданамыз?
- Нені өшіретінімді білемін, бірақ орнын білмеймін → `remove`.
- Орнын білемін және өшірілгенді қолданамын → `pop`.
- Орнын білемін, мән керек емес → `del`.

## 9. Біріктірілген мысал: «Сатып алу тізімі» мәзірі

```python
shopping = []
while True:
    print("\n1 - Қосу  2 - Ортаға қосу  3 - Өшіру  4 - Соңғысын алу  5 - Көру  0 - Шығу")
    choice = input("> ")
    if choice == "1":
        shopping.append(input("Тауар: "))
    elif choice == "2":
        pos = int(input("Нешінші орынға (1-ден): "))
        shopping.insert(pos - 1, input("Тауар: "))
    elif choice == "3":
        item = input("Қай тауарды өшіреміз: ")
        if item in shopping:
            shopping.remove(item)
        else:
            print("Ондай тауар жоқ")
    elif choice == "4":
        if shopping:
            print("Сатып алынды:", shopping.pop())
        else:
            print("Тізім бос")
    elif choice == "5":
        print("Тізім:", shopping)
    elif choice == "0":
        break
    else:
        print("Қате таңдау")
```
`if shopping:` — бос тізім `False` ретінде, бос емес тізім `True` ретінде қабылданады.

## Жиі кездесетін қателер

**1. Әдістің нәтижесін тізімге меншіктеу**
```python
nums = [1, 2]
nums = nums.append(3)
print(nums)      # None! append жаңа тізім қайтармайды
```
Дұрысы: жай ғана `nums.append(3)`.

**2. `append`-ке бірнеше аргумент беру**
```text
nums.append(3, 4)     # TypeError: append() takes exactly one argument
```
Бірнеше элемент үшін — `extend([3, 4])`.

**3. `remove`-ке индекс беру**
```python
nums = [10, 20, 30]
nums.remove(0)      # ValueError: 0 мәні жоқ (индекс емес, МӘН ізделеді)
```
Индекс бойынша — `pop(0)` немесе `del nums[0]`.

**4. `insert` аргументтерінің ретін шатастыру** — алдымен индекс, сосын мән: `insert(индекс, мән)`.

**5. Цикл ішінде тізімнің индекстері бойынша жүріп, элементтерді өшіру** — индекстер жылжиды да, кейбір элементтер өткізіліп кетеді. Ондай жағдайда `while x in lst: lst.remove(x)` немесе жаңа тізім құру тәсілін қолдан.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Әдіс (метод) | Объектіге тиесілі, нүкте арқылы шақырылатын функция |
| `append(x)` | Соңына қосу |
| `insert(i, x)` | `i` орнына қою |
| `extend(lst)` | Басқа тізімнің элементтерін соңына қосу |
| `remove(x)` | Мәні бойынша (бірінші кездесуін) жою |
| `pop(i)` | Индекс бойынша жою және қайтару |
| `del` | Индекс бойынша жою операторы |
| `clear()` | Тізімді тазалау |
| `ValueError` | Мән табылмағандағы қате (`remove`) |
| `None` | «Ештеңе» мәні; `append` сияқты әдістер осыны қайтарады |

## Ескерту

- Әдістердің жылдамдығы әртүрлі: `append()` және `pop()` (соңынан) өте жылдам (O(1)), ал `insert(0, x)` және `pop(0)` барлық элементтерді жылжытады (O(n)). Кезек (очередь) үшін `collections.deque` және оның `popleft()` әдісін қолданған тиімді.
- Тізімді өзгертетін әдістер (`append`, `insert`, `remove`, `sort`, `clear` т.б.) `None` қайтарады — бұл Python-ның әдейі жасалған ережесі: «орнында өзгерту» мен «жаңа мән қайтару» шатаспауы үшін.
- `del` кесіндімен де жұмыс істейді: `del lst[1:3]` бірнеше элементті бірден жояды; `del lst` айнымалының өзін жояды.
- `lst += [x]` жазуы `lst.extend([x])`-ке тең және тізімді орнында өзгертеді, ал `lst = lst + [x]` жаңа тізім жасайды.
- Тізімді аралап жүріп одан элемент жоюдың қауіпсіз тәсілі — жаңа тізім құру: `nums = [x for x in nums if x != 0]`.
- Құжаттама: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
