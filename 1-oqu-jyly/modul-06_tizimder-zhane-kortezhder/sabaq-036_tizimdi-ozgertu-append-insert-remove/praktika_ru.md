## Продвинутый уровень

### Задание 6. Удаление всех отрицательных чисел
`nums = [4, -2, 7, -5, -1, 9, 0, -3]`. Удали все отрицательные числа и выведи список. Реши двумя способами:
а) создать новый список и делать `append` только неотрицательных чисел;

### Задание 7. Стек: кнопка «Назад»
Смоделируй историю браузера в виде списка. Команды:
- `открыть <сайт>` — добавить сайт в историю (`append`);
- `назад` — убрать последний сайт из истории и вывести, на каком сайте мы сейчас находимся (`pop`);
- `история` — вывести весь список;
- `выход`.

Команду можно читать двумя отдельными `input`: сначала действие, при необходимости — название сайта.

### Задание 8. Объединение списков
Даны списки учеников двух классов. Объедини их с помощью `extend`, затем, если в обоих классах есть ученики с одинаковыми именами (например, два «Армана»), удали повторы так, чтобы в объединённом списке каждое имя осталось только один раз.

## ★ Олимпиадная / творческая задача

### Задание 9. Считалка (задача Иосифа)
`n` детей стоят по кругу (пронумерованы от 1 до `n`). Счёт начинается с 1-го ребёнка, каждый `k`-й ребёнок выходит из круга. Счёт продолжается со следующего ребёнка. Найди номер последнего оставшегося ребёнка. Выведи также порядок выбывания.

Пример (`n = 7`, `k = 3`): порядок выбывания `3 6 2 7 5 1`, последний оставшийся — `4`.

**Подсказка:** `children = list(range(1, n + 1))`, текущий индекс `idx = (idx + k - 1) % количество`, `pop(idx)`. Храни количество элементов в переменной-счётчике (`len()` пройдём на следующем уроке — но использовать можно).

### Задание 10. «Менеджер задач»
To-Do программа, работающая через меню: добавить задачу, удалить по номеру (`pop`), добавить срочную задачу на первое место (`insert`), посмотреть все (с номерами), очистить все (`clear`).

**Задание 6**
```python
# а)
nums = [4, -2, 7, -5, -1, 9, 0, -3]
result = []
for i in range(8):
    if nums[i] >= 0:
        result.append(nums[i])
print(result)

# б)
nums = [4, -2, 7, -5, -1, 9, 0, -3]
i = 0
while i < len(nums):
    if nums[i] < 0:
        del nums[i]          # индекс не меняется — следующий элемент сдвинулся на это место
    else:
        i += 1
print(nums)
```
Результат: `[4, 7, 9, 0]`. В способе (б) `len()` подробно объясняется на следующем уроке; ученикам важна идея решения: при удалении не увеличивать индекс.

**Задание 7**
```python
history = []
while True:
    cmd = input("Команда (открыть/назад/история/выход): ")
    if cmd == "открыть":
        site = input("Сайт: ")
        history.append(site)
        print("Открыт:", site)
    elif cmd == "назад":
        if history:
            history.pop()
            if history:
                print("Сейчас:", history[-1])
            else:
                print("История пуста")
        else:
            print("Назад идти некуда")
    elif cmd == "история":
        print(history)
    elif cmd == "выход":
        break
    else:
        print("Неизвестная команда")
```
