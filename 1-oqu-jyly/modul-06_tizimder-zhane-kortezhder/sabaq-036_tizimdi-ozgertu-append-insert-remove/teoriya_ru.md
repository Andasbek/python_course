## 1. Что такое метод?

**Метод (method)** — функция, принадлежащая объекту определённого типа. Он вызывается после имени объекта через **точку**:

```text
<список>.<метод>(<аргументы>)
```

Например, `fruits.append("яблоко")` — «добавь "яблоко" в список `fruits`». Методы изменяют **сам** список.

| Метод / оператор | Что делает |
|---|---|
| `append(x)` | Добавляет `x` в конец |
| `insert(i, x)` | Ставит `x` на место с индексом `i` |
| `extend(lst2)` | Добавляет в конец все элементы другого списка |
| `remove(x)` | Удаляет первое встретившееся значение `x` |
| `pop()` | Удаляет последний элемент и **возвращает** его |
| `pop(i)` | Удаляет элемент с индексом `i` и возвращает его |
| `del lst[i]` | Удаляет элемент с индексом `i` (оператор) |
| `clear()` | Удаляет все элементы |

## 2. append() — добавление в конец

```python
shopping = ["хлеб", "молоко"]
shopping.append("яйца")
shopping.append("сыр")
print(shopping)
```
Результат:
```text
['хлеб', 'молоко', 'яйца', 'сыр']
```

### Заполнение пустого списка с помощью цикла
Это самый распространённый способ: создаём пустой список и в цикле делаем `append`.
```python
grades = []
for i in range(5):
    g = int(input(f"Оценка {i + 1}: "))
    grades.append(g)
print("Оценки:", grades)
```
Пример:
```text
Оценка 1: 5
Оценка 2: 4
Оценка 3: 5
Оценка 4: 3
Оценка 5: 4
Оценки: [5, 4, 5, 3, 4]
```

### Если количество элементов неизвестно (while)
```python
names = []
while True:
    name = input("Имя (пустая строка — конец): ")
    if name == "":
        break
    names.append(name)
print("Список:", names)
```

### Создание списка по условию
```python
squares = []
for n in range(1, 11):
    if n % 2 == 0:
        squares.append(n * n)
print(squares)
```
Результат:
```text
[4, 16, 36, 64, 100]
```

## 3. insert() — вставка в определённое место

`insert(i, x)` — ставит `x` на место с индексом `i`; последующие элементы «сдвигаются» вправо.
```python
queue = ["Аскар", "Бота", "Даулет"]
queue.insert(1, "Ерлан")     # на 1-е место
print(queue)
queue.insert(0, "Мама с ребёнком")   # в самое начало
print(queue)
```
Результат:
```text
['Аскар', 'Ерлан', 'Бота', 'Даулет']
['Мама с ребёнком', 'Аскар', 'Ерлан', 'Бота', 'Даулет']
```

Если индекс больше длины списка, элемент добавляется в конец (ошибки не будет): `queue.insert(100, "Зарина")`.

## 4. extend() и + — объединение списков

```python
a = [1, 2, 3]
b = [4, 5]
a.extend(b)
print(a)

c = [10]
c.append([20, 30])   # список добавляется как ОДИН элемент
print(c)
```
Результат:
```text
[1, 2, 3, 4, 5]
[10, [20, 30]]
```
Обрати внимание на разницу между `append` и `extend`!

## 5. remove() — удаление по значению

`remove(x)` — удаляет из списка **первое встретившееся** значение `x`:
```python
pets = ["кошка", "собака", "рыбка", "собака"]
pets.remove("собака")
print(pets)
```
Результат:
```text
['кошка', 'рыбка', 'собака']
```

Если значения нет в списке — `ValueError`:
```text
pets.remove("попугай")
ValueError: list.remove(x): x not in list
```
Поэтому лучше сначала проверить с помощью `in`:
```python
pets = ["кошка", "собака", "рыбка"]
animal = input("Какое животное удалить? ")
if animal in pets:
    pets.remove(animal)
    print("Удалено:", pets)
else:
    print("Такого животного нет в списке")
```

Чтобы удалить все вхождения — цикл `while`:
```python
nums = [1, 0, 2, 0, 3, 0]
while 0 in nums:
    nums.remove(0)
print(nums)
```
Результат:
```text
[1, 2, 3]
```

## 6. pop() — удаление по индексу с возвратом

`pop()` удаляет элемент **и возвращает его** — его можно сохранить в переменную и использовать дальше.
```python
stack = ["книга 1", "книга 2", "книга 3"]
top = stack.pop()          # взять последнюю
print("Взято:", top)
print("Осталось:", stack)

first = stack.pop(0)       # взять первый элемент
print("Взято:", first)
print("Осталось:", stack)
```
Результат:
```text
Взято: книга 3
Осталось: ['книга 1', 'книга 2']
Взято: книга 1
Осталось: ['книга 2']
```

`pop()` из пустого списка → `IndexError: pop from empty list`.

### Модель очереди
```python
queue = ["Айбек", "Гульназ", "Мирас"]
queue.append("Сая")              # в очередь пришёл новый человек
served = queue.pop(0)            # первого в очереди обслужили
print("Обслужен:", served)
print("В очереди:", queue)
```
Результат:
```text
Обслужен: Айбек
В очереди: ['Гульназ', 'Мирас', 'Сая']
```

## 7. Оператор del и clear()

`del` — оператор Python (не метод!), удаляет по индексу, значение не возвращает:
```python
letters = ["а", "б", "в", "г", "д"]
del letters[1]
print(letters)
del letters[-1]
print(letters)
```
Результат:
```text
['а', 'в', 'г', 'д']
['а', 'в', 'г']
```

`clear()` — полностью очищает список:
```python
basket = ["яблоко", "банан"]
basket.clear()
print(basket)
```
Результат:
```text
[]
```

## 8. Сравнение способов удаления

| Способ | На что опирается | Возвращает значение? | Если элемента нет |
|---|---|---|---|
| `remove(x)` | на **значение** | Нет | `ValueError` |
| `pop()` / `pop(i)` | на **индекс** (по умолчанию последний) | **Да** | `IndexError` |
| `del lst[i]` | на **индекс** | Нет | `IndexError` |
| `clear()` | все | Нет | — |

Когда что использовать?
- Знаю, что удалить, но не знаю, где оно → `remove`.
- Знаю место и буду использовать удалённое → `pop`.
- Знаю место, значение не нужно → `del`.

## 9. Комбинированный пример: меню «Список покупок»

```python
shopping = []
while True:
    print("\n1 - Добавить  2 - Вставить  3 - Удалить  4 - Взять последний  5 - Показать  0 - Выход")
    choice = input("> ")
    if choice == "1":
        shopping.append(input("Товар: "))
    elif choice == "2":
        pos = int(input("На какое место (с 1): "))
        shopping.insert(pos - 1, input("Товар: "))
    elif choice == "3":
        item = input("Какой товар удалить: ")
        if item in shopping:
            shopping.remove(item)
        else:
            print("Такого товара нет")
    elif choice == "4":
        if shopping:
            print("Куплено:", shopping.pop())
        else:
            print("Список пуст")
    elif choice == "5":
        print("Список:", shopping)
    elif choice == "0":
        break
    else:
        print("Неверный выбор")
```
`if shopping:` — пустой список воспринимается как `False`, непустой — как `True`.

## Частые ошибки

**1. Присвоить результат метода списку**
```python
nums = [1, 2]
nums = nums.append(3)
print(nums)      # None! append не возвращает новый список
```
Правильно: просто `nums.append(3)`.

**2. Передать `append` несколько аргументов**
```text
nums.append(3, 4)     # TypeError: append() takes exactly one argument
```
Для нескольких элементов — `extend([3, 4])`.

**3. Передать `remove` индекс**
```python
nums = [10, 20, 30]
nums.remove(0)      # ValueError: значения 0 нет (ищется ЗНАЧЕНИЕ, а не индекс)
```
По индексу — `pop(0)` или `del nums[0]`.

**4. Перепутать порядок аргументов `insert`** — сначала индекс, потом значение: `insert(индекс, значение)`.

**5. Удалять элементы, проходя по индексам списка в цикле** — индексы сдвигаются, и некоторые элементы пропускаются. В таком случае используй `while x in lst: lst.remove(x)` или создание нового списка.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Метод | Функция, принадлежащая объекту и вызываемая через точку |
| `append(x)` | Добавление в конец |
| `insert(i, x)` | Вставка на место `i` |
| `extend(lst)` | Добавление в конец элементов другого списка |
| `remove(x)` | Удаление по значению (первого вхождения) |
| `pop(i)` | Удаление по индексу с возвратом |
| `del` | Оператор удаления по индексу |
| `clear()` | Очистка списка |
| `ValueError` | Ошибка, когда значение не найдено (`remove`) |
| `None` | Значение «ничего»; его возвращают методы вроде `append` |

## Примечание

- Методы работают с разной скоростью: `append()` и `pop()` (с конца) очень быстрые (O(1)), а `insert(0, x)` и `pop(0)` сдвигают все элементы (O(n)). Для очереди эффективнее `collections.deque` и его метод `popleft()`.
- Методы, изменяющие список (`append`, `insert`, `remove`, `sort`, `clear` и др.), возвращают `None` — это намеренное правило Python, чтобы не путать «изменение на месте» и «возврат нового значения».
- `del` работает и со срезами: `del lst[1:3]` удаляет сразу несколько элементов; `del lst` удаляет саму переменную.
- Запись `lst += [x]` равносильна `lst.extend([x])` и изменяет список на месте, а `lst = lst + [x]` создаёт новый список.
- Безопасный способ удалить элементы при обходе списка — построить новый список: `nums = [x for x in nums if x != 0]`.
- Документация: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
