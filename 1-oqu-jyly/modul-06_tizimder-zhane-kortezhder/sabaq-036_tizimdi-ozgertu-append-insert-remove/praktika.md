# Сабақ 36. Практикалық тапсырмалар: append, insert, remove, pop, del

## Базалық деңгей

### 1-тапсырма. Қадамдап орында
Әр қадамнан кейін тізімнің қандай болатынын қағазға жаз, содан кейін бағдарламамен тексер:
```python
colors = ["қызыл", "сары", "жасыл"]
colors.append("көк")
colors.insert(1, "қызғылт сары")
colors.remove("жасыл")
last = colors.pop()
del colors[0]
print(colors, last)
```

### 2-тапсырма. Бағалар журналы
Бос тізім құр. Пайдаланушыдан 6 баға енгізуді сұрап, `append` арқылы тізімге қос. Тізімді шығар.

### 3-тапсырма. Жұп сандар жинағы
Пайдаланушы 0 енгізгенше сандар енгізеді. Тек жұп сандарды тізімге қос. Соңында тізімді шығар.

Мысал:
```text
3
8
12
7
0
[8, 12]
```

### 4-тапсырма. Кезекті басқару
`queue = ["Айдана", "Бауыржан", "Венера"]`. Бағдарлама:
1. Кезекке «Ғалым» келіп, соңына тұрды;
2. Кезектің басына «Зейнеп әже» (кезексіз) тұрды;
3. Бірінші адамға қызмет көрсетілді (`pop(0)`) — оның есімін шығар;
4. «Бауыржан» кезектен кетті (`remove`);
5. Қалған кезекті шығар.

### 5-тапсырма. Қауіпсіз жою
Тізім: `["математика", "физика", "химия", "тарих", "ағылшын"]`. Пайдаланушы пән атауын енгізеді. Пән тізімде болса — өшір және жаңа тізімді шығар, болмаса — «Мұндай пән жоқ».

## Кеңейтілген деңгей

### 6-тапсырма. Барлық теріс сандарды жою
`nums = [4, -2, 7, -5, -1, 9, 0, -3]`. Барлық теріс сандарды жойып, тізімді шығар. Екі тәсілмен шығар:
а) жаңа тізім құрып, тек теріс емес сандарды `append` ету;
ә) `while` циклімен ағымдағы тізімнен жою.

### 7-тапсырма. Стек: «Артқа» батырмасы
Браузер тарихын тізім ретінде модельде. Пәрмендер:
- `ашу <сайт>` — сайтты тарихқа қосу (`append`);
- `артқа` — соңғы сайтты тарихтан алып тастап, енді қай сайтта тұрғанымызды шығару (`pop`);
- `тарих` — бүкіл тізімді шығару;
- `шығу`.

Пәрменді екі бөлек `input` арқылы оқуға болады: алдымен әрекет, қажет болса сайт атауы.

### 8-тапсырма. Тізімді біріктіру
Екі сыныптың оқушылар тізімі берілген. `extend` арқылы біріктір, содан кейін екі сыныпта да бірдей есімді оқушылар болса (мысалы, екі «Арман»), біріктірілген тізімде есім тек бір рет қалатындай етіп, қайталанғандарды жой.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Санамақ (Иосиф есебі)
`n` бала шеңбер бойымен тұрады (1-ден `n`-ге дейін нөмірленген). Санау 1-баладан басталады, әр `k`-шы бала шеңберден шығады. Санау келесі баладан жалғасады. Соңғы қалған баланың нөмірін тап. Шығу ретін де шығар.

Мысал (`n = 7`, `k = 3`): шығу реті `3 6 2 7 5 1`, соңғы қалған — `4`.

**Кеңес:** `children = list(range(1, n + 1))`, ағымдағы индекс `idx = (idx + k - 1) % саны`, `pop(idx)`. Элементтер санын санауыш айнымалыда сақта (`len()`-ді келесі сабақта өтеміз — бірақ қолдануға болады).

### 10-тапсырма. «Тапсырмалар менеджері»
Мәзір арқылы жұмыс істейтін To-Do бағдарламасы: тапсырма қосу, нөмірі бойынша жою (`pop`), бірінші орынға шұғыл тапсырма қосу (`insert`), барлығын көру (нөмірлерімен), барлығын тазалау (`clear`).

```python
nums = [4, -2, 7, -5, -1, 9, 0, -3]
i = 0
while i < len(nums):
    if nums[i] < 0:
        del nums[i]          # индекс өзгермейді — келесі элемент осы орынға жылжыды
```

**7-тапсырма**

```python
history = []
while True:
    cmd = input("Пәрмен (ашу/артқа/тарих/шығу): ")
    if cmd == "ашу":
        site = input("Сайт: ")
        history.append(site)
        print("Ашылды:", site)
    elif cmd == "артқа":
        if history:
            history.pop()
            if history:
                print("Қазір:", history[-1])
            else:
                print("Тарих бос")
        else:
            print("Артқа баратын жер жоқ")
    elif cmd == "тарих":
        print(history)
    elif cmd == "шығу":
        break
    else:
        print("Белгісіз пәрмен")
```

**9-тапсырма**

```python
n = int(input("n = "))
k = int(input("k = "))
children = list(range(1, n + 1))
count = n
idx = 0
order = []
while count > 1:
    idx = (idx + k - 1) % count
    order.append(children.pop(idx))
    count -= 1
print("Шығу реті:", order)

```

```python
tasks = []
while True:
    print("\n1 - Қосу  2 - Шұғыл қосу  3 - Жою  4 - Көру  5 - Тазалау  0 - Шығу")

        if 1 <= num <= len(tasks):

            print("Мұндай нөмір жоқ")
    elif choice == "4":
        for i in range(len(tasks)):
            print(f"{i + 1}. {tasks[i]}")
    elif choice == "5":
        tasks.clear()
        print("Тізім тазаланды")
    elif choice == "0":
        break
    else:
        print("Қате таңдау")
```
