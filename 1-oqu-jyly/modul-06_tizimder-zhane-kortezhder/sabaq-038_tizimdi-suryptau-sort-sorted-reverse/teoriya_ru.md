## 1. Что такое сортировка?

**Сортировка (sorting)** — расположение элементов списка в определённом порядке:
- **по возрастанию**: `1, 3, 5, 8`;
- **по убыванию**: `8, 5, 3, 1`.

Числа сравниваются по величине, строки — по **алфавиту** (точнее, по кодам символов).

## 2. Метод sort() — сортировка самого списка

```python
scores = [78, 95, 62, 88, 71]
scores.sort()
print(scores)
```
Результат:
```text
[62, 71, 78, 88, 95]
```
`sort()` изменяет **сам** список (сортирует на месте) и возвращает `None`. Исходный порядок теряется.

### По убыванию
```python
scores = [78, 95, 62, 88, 71]
scores.sort(reverse=True)
print(scores)
```
Результат:
```text
[95, 88, 78, 71, 62]
```

## 3. Функция sorted() — новый отсортированный список

`sorted()` **не изменяет** исходный список, а возвращает **новый** отсортированный список:
```python
prices = [1200, 350, 800, 4500]
cheap_first = sorted(prices)
expensive_first = sorted(prices, reverse=True)
print("Исходный:", prices)
print("От дешёвых:", cheap_first)
print("От дорогих:", expensive_first)
```
Результат:
```text
Исходный: [1200, 350, 800, 4500]
От дешёвых: [350, 800, 1200, 4500]
От дорогих: [4500, 1200, 800, 350]
```

### Сравнение sort() и sorted()

| | `lst.sort()` | `sorted(lst)` |
|---|---|---|
| Вид | Метод списка | Встроенная функция |
| Исходный список | **Изменяется** | Не изменяется |
| Что возвращает | `None` | Новый список |
| Когда применяем | Исходный порядок не нужен | Исходный порядок нужно сохранить |
| С другими типами | Только список | Любая последовательность (строка, кортеж, range) |

```python
print(sorted("python"))
print(sorted(range(5, 0, -1)))
```
Результат:
```text
['h', 'n', 'o', 'p', 't', 'y']
[1, 2, 3, 4, 5]
```

## 4. reverse() — разворот

`reverse()` **не сортирует** список, а лишь меняет порядок элементов **на обратный**:
```python
days = ["Пн", "Вт", "Ср", "Чт", "Пт"]
days.reverse()
print(days)
```
Результат:
```text
['Пт', 'Чт', 'Ср', 'Вт', 'Пн']
```

**Важное различие:**
```python
a = [3, 1, 2]
b = [3, 1, 2]
a.reverse()              # просто обратный порядок
b.sort(reverse=True)     # сортировка по убыванию
print(a)
print(b)
```
Результат:
```text
[2, 1, 3]
[3, 2, 1]
```

Чтобы получить перевёрнутый список как новый, можно использовать функцию `reversed()` вместе с `list()`: `list(reversed(days))`. Также можно использовать срез: `days[::-1]`.

## 5. Сортировка строк

```python
names = ["Нурсултан", "Айым", "Бекарыс", "Дария", "Ерлан"]
names.sort()
print(names)
```
Результат:
```text
['Айым', 'Бекарыс', 'Дария', 'Ерлан', 'Нурсултан']
```

**Особенности:**
1. Заглавные буквы стоят **раньше** строчных: `sorted(["яблоко", "Банан"])` → `['Банан', 'яблоко']`.
2. Python сравнивает строки по кодам Юникода. Коды специфических казахских букв (`ә, ғ, қ, ң, ө, ұ, ү, һ, і`) идут после русских букв, поэтому они могут оказаться не на «правильном» месте по алфавиту (то же касается русской буквы `ё`):
```python
print(sorted(["қала", "кітап", "ауыл", "әже"]))
```
Результат:
```text
['ауыл', 'кітап', 'қала', 'әже']
```
(В казахском алфавите «әже» должно идти сразу после «ауыл».) Это важное замечание в программировании: компьютер понимает «алфавит» по-своему.

## 6. Параметр key: сортировка по признаку

В параметр `key` передаётся функция — сравнение идёт по результату этой функции. Например, сортировка слов по **длине**:
```python
words = ["як", "лошадь", "кот", "овца", "коза"]
words.sort(key=len)
print(words)
print(sorted(words, key=len, reverse=True))
```
Результат:
```text
['як', 'кот', 'овца', 'коза', 'лошадь']
['лошадь', 'овца', 'коза', 'кот', 'як']
```
Элементы одинаковой длины сохраняют исходный порядок между собой (сортировка в Python **устойчивая**).

`key=abs` — сортировка чисел по модулю:
```python
print(sorted([-7, 3, -1, 5, -4], key=abs))
```
Результат:
```text
[-1, 3, -4, 5, -7]
```

## 7. Польза отсортированного списка

```python
results = [12.4, 11.8, 13.1, 12.0, 11.5, 12.9]   # бег 100 м, секунды
results.sort()
print("Время победителя:", results[0])
print("Лучшая тройка:", results[0], results[1], results[2])
print("Самый медленный:", results[-1])
# Медиана — значение в середине отсортированного списка
n = len(results)
if n % 2 == 1:
    median = results[n // 2]
else:
    median = (results[n // 2 - 1] + results[n // 2]) / 2
print("Медиана:", median)
```
Результат:
```text
Время победителя: 11.5
Лучшая тройка: 11.5 11.8 12.0
Самый медленный: 13.1
Медиана: 12.2
```

**Медиана** — серединное значение отсортированных данных. В отличие от среднего, она мало зависит от слишком больших/малых «выбросов».

## 8. Что происходит внутри алгоритма сортировки? Сортировка пузырьком

`sort()` работает одной строкой, но внутри у него сложный алгоритм. Самый простой алгоритм сортировки — **сортировка пузырьком (bubble sort)**: сравниваем соседние элементы и, если они стоят в неправильном порядке, меняем их местами. За каждый проход наибольший элемент «всплывает, как пузырёк» в конец.

```python
nums = [5, 2, 9, 1, 6]
n = len(nums)
for p in range(n - 1):              # число проходов
    for i in range(n - 1 - p):      # соседние пары
        if nums[i] > nums[i + 1]:
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
    print(f"После прохода {p + 1}:", nums)
```
Результат:
```text
После прохода 1: [2, 5, 1, 6, 9]
После прохода 2: [2, 1, 5, 6, 9]
После прохода 3: [1, 2, 5, 6, 9]
После прохода 4: [1, 2, 5, 6, 9]
```

Этот алгоритм объединяет вложенные циклы и перестановку элементов (`a, b = b, a`). Метод `sort()` в Python использует гораздо более быстрый алгоритм (Timsort).

## Частые ошибки

**1. Присвоение результата `sort()`**
```python
nums = [3, 1, 2]
nums = nums.sort()
print(nums)    # None — список потерян!
```
Правильно: `nums.sort()` или `nums = sorted(nums)`.

**2. Думать, что `sorted()` изменяет список**
```python
nums = [3, 1, 2]
sorted(nums)
print(nums)    # [3, 1, 2] — не изменился
```

**3. Считать `reverse()` сортировкой по убыванию** — он лишь переворачивает.

**4. Сортировка чисел и строк вместе**
```text
sorted([3, "два", 1])   # TypeError: '<' not supported between 'str' and 'int'
```

**5. Сортировка введённых чисел без преобразования в `int`**: `["10", "9", "100"]` как строки сортируются в `['10', '100', '9']`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Сортировка | Расположение элементов в определённом порядке |
| `lst.sort()` | Сортирует сам список, возвращает `None` |
| `sorted(lst)` | Возвращает новый отсортированный список |
| `reverse=True` | Параметр сортировки по убыванию |
| `lst.reverse()` | Разворот списка (не сортирует) |
| `key=...` | Функция, задающая критерий сравнения (`len`, `abs`) |
| Медиана | Серединное значение отсортированного списка |
| Сортировка пузырьком | Алгоритм сравнения и перестановки соседних элементов |

## Примечание

- `sort()` / `sorted()` в Python используют алгоритм Timsort: O(n log n) в среднем и худшем случае и очень быстро на частично отсортированных данных. Сортировка **устойчивая** (stable) — порядок равных элементов сохраняется.
- Для сортировки без учёта регистра используйте `key=str.lower` (или точнее для Юникода `key=str.casefold`): `sorted(words, key=str.casefold)`.
- Для сортировки по настоящему алфавиту конкретного языка применяют ключ `locale.strxfrm` (после `locale.setlocale(...)`) или внешнюю библиотеку `PyICU`.
- `reversed()` возвращает не список, а итератор — его можно обойти только один раз; если нужен список, пишите `list(reversed(lst))`.
- В Python 3 значения разных типов (`int` и `str`) сравнивать нельзя — `TypeError`; в Python 2 это было разрешено.
- Документация: https://docs.python.org/3/howto/sorting.html
