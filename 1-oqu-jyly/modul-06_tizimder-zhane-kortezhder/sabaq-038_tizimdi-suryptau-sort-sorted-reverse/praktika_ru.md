## Базовый уровень

### Задание 2. Рейтинг баллов
Пользователь вводит баллы за тест 6 учеников. Выведи баллы по возрастанию и по убыванию. Исходный порядок ввода тоже должен сохраниться и быть выведен (используй `sorted`).

### Задание 3. Список класса по алфавиту
`students = ["Санжар", "Әйгерім", "Арсен", "Мөлдір", "Бауыржан", "Ділназ"]`. Отсортируй список по алфавиту и выведи с номерами. Глядя на результат, объясни, почему имя на букву «Ә» оказалось в конце.

### Задание 4. Лучшая тройка
Баллы 8 участников соревнования: `[34, 51, 47, 29, 51, 40, 38, 45]`. Выведи 3 самых высоких балла и 2 самых низких.

### Задание 5. Обратный порядок
Пользователь вводит 5 городов. Выведи список: а) в порядке ввода; б) в обратном порядке (`reverse()`); в) в обратном алфавитном порядке (`sort(reverse=True)`).

## Продвинутый уровень

### Задание 6. Медиана и среднее
Пользователь вводит `n` чисел. Найди среднее и медиану чисел (для чётного и нечётного `n`). Когда среднее и медиана сильно различаются? Приведи пример: `[30, 32, 35, 31, 300]`.

### Задание 7. По длине
Пользователь вводит слова, пока не введёт 0 (они собираются в список). Отсортируй слова по длине по возрастанию и выведи, в конце выведи самое короткое и самое длинное слово.

### Задание 8. Справедливые судьи
В гимнастике оценки ставят 7 судей (0–10). Самая высокая и самая низкая оценки отбрасываются, среднее остальных — итоговая оценка. Реши с помощью сортировки.

Пример: `[9.1, 8.7, 9.5, 9.0, 8.2, 9.3, 9.4]` → `9.1`.

## ★ Олимпиадная / творческая задача

### Задание 9. Улучшение сортировки пузырьком
Напиши код сортировки пузырьком. Если за один проход не было ни одной перестановки, значит, список отсортирован — останови с помощью `break`. Выведи общее количество перестановок.

### Задание 10. Сортировка выбором (selection sort)
Алгоритм: найди наименьший элемент списка и поставь его на 0-е место; наименьший из оставшейся части — на 1-е место; и т. д. Реализуй без `sort()` и выводи список после каждого шага.

2. Отсортируй список `nums = [15, -3, 8, -12, 0, 7, -1]` по модулю (`key=abs`).

**Задание 6**
```python
n = int(input("n = "))
nums = []
for i in range(n):
    nums.append(float(input()))
avg = sum(nums) / n
s = sorted(nums)
if n % 2 == 1:
    median = s[n // 2]
else:
    median = (s[n // 2 - 1] + s[n // 2]) / 2
print("Среднее:", avg, "Медиана:", median)
```
`[30, 32, 35, 31, 300]`: среднее 85.6, медиана 32 — одно большое значение «утягивает» среднее.

**Задание 8**
```python
marks = [9.1, 8.7, 9.5, 9.0, 8.2, 9.3, 9.4]
marks.sort()
middle = []
for i in range(1, len(marks) - 1):   # пропускаем первый и последний
    middle.append(marks[i])
print(round(sum(middle) / len(middle), 2))
```
Результат: `9.1` (8.7 + 9.0 + 9.1 + 9.3 + 9.4 = 45.5; 45.5 / 5 = 9.1). Компактный вариант (срезы пройдём на следующем уроке): `sum(marks[1:-1]) / 5`.

**Задание 9**
```python
nums = [5, 1, 4, 2, 8, 3]
n = len(nums)
swaps = 0
for p in range(n - 1):
    swapped = False
    for i in range(n - 1 - p):
        if nums[i] > nums[i + 1]:
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
            swaps += 1
            swapped = True
    if not swapped:
        break
print(nums, "Перестановок:", swaps)
```

**Задание 10**
```python
nums = [29, 10, 14, 37, 13]
n = len(nums)
for i in range(n - 1):
    min_idx = i
    for j in range(i + 1, n):
        if nums[j] < nums[min_idx]:
            min_idx = j
    nums[i], nums[min_idx] = nums[min_idx], nums[i]
    print(f"Шаг {i + 1}:", nums)
```
