## 1. Сұрыптау дегеніміз не?

**Сұрыптау (сортировка, sorting)** — тізім элементтерін белгілі бір ретпен орналастыру:
- **өсу ретімен** (по возрастанию): `1, 3, 5, 8`;
- **кему ретімен** (по убыванию): `8, 5, 3, 1`.

Сандар шамасы бойынша, жолдар **әліпби** (дәлірек айтқанда, символ кодтары) бойынша салыстырылады.

## 2. sort() әдісі — тізімнің өзін сұрыптау

```python
scores = [78, 95, 62, 88, 71]
scores.sort()
print(scores)
```
Нәтижесі:
```text
[62, 71, 78, 88, 95]
```
`sort()` тізімнің **өзін** өзгертеді (орнында сұрыптайды) және `None` қайтарады. Бастапқы рет жоғалады.

### Кему ретімен
```python
scores = [78, 95, 62, 88, 71]
scores.sort(reverse=True)
print(scores)
```
Нәтижесі:
```text
[95, 88, 78, 71, 62]
```

## 3. sorted() функциясы — жаңа сұрыпталған тізім

`sorted()` бастапқы тізімді **өзгертпейді**, сұрыпталған **жаңа** тізім қайтарады:
```python
prices = [1200, 350, 800, 4500]
cheap_first = sorted(prices)
expensive_first = sorted(prices, reverse=True)
print("Бастапқы:", prices)
print("Арзаннан:", cheap_first)
print("Қымбаттан:", expensive_first)
```
Нәтижесі:
```text
Бастапқы: [1200, 350, 800, 4500]
Арзаннан: [350, 800, 1200, 4500]
Қымбаттан: [4500, 1200, 800, 350]
```

### sort() пен sorted() салыстыру

| | `lst.sort()` | `sorted(lst)` |
|---|---|---|
| Түрі | Тізімнің әдісі | Кіріктірілген функция |
| Бастапқы тізім | **Өзгереді** | Өзгермейді |
| Не қайтарады | `None` | Жаңа тізім |
| Қашан қолданамыз | Бастапқы рет керек емес | Бастапқы рет сақталуы керек |
| Басқа типтермен | Тек тізім | Кез келген тізбек (жол, кортеж, range) |

```python
print(sorted("python"))
print(sorted(range(5, 0, -1)))
```
Нәтижесі:
```text
['h', 'n', 'o', 'p', 't', 'y']
[1, 2, 3, 4, 5]
```

## 4. reverse() — кері айналдыру

`reverse()` тізімді **сұрыптамайды**, тек элементтер ретін **керісінше** етеді:
```python
days = ["Дс", "Сс", "Ср", "Бс", "Жм"]
days.reverse()
print(days)
```
Нәтижесі:
```text
['Жм', 'Бс', 'Ср', 'Сс', 'Дс']
```

**Маңызды айырмашылық:**
```python
a = [3, 1, 2]
b = [3, 1, 2]
a.reverse()              # жай кері рет
b.sort(reverse=True)     # кему ретімен сұрыптау
print(a)
print(b)
```
Нәтижесі:
```text
[2, 1, 3]
[3, 2, 1]
```

Жаңа тізім ретінде кері айналдыру үшін `reversed()` функциясын `list()`-пен бірге қолдануға болады: `list(reversed(days))`. Сондай-ақ кесінді арқылы да болады: `days[::-1]`.

## 5. Жолдарды сұрыптау

```python
names = ["Нұрсұлтан", "Айым", "Бекарыс", "Дария", "Ерлан"]
names.sort()
print(names)
```
Нәтижесі:
```text
['Айым', 'Бекарыс', 'Дария', 'Ерлан', 'Нұрсұлтан']
```

**Ерекшеліктер:**
1. Бас әріптер кіші әріптерден **бұрын** тұрады: `sorted(["алма", "Банан"])` → `['Банан', 'алма']`.
2. Python жолдарды Юникод кодтары бойынша салыстырады. Қазақ тіліне тән әріптердің (`ә, ғ, қ, ң, ө, ұ, ү, һ, і`) кодтары орыс әріптерінен кейін тұрады, сондықтан олар әліпбидегі «дұрыс» орнында болмауы мүмкін:
```python
print(sorted(["қала", "кітап", "ауыл", "әже"]))
```
Нәтижесі:
```text
['ауыл', 'кітап', 'қала', 'әже']
```
(Қазақ әліпбиінде «әже» «ауыл»-дан кейін бірден келуі керек еді.) Бұл — бағдарламалаудағы маңызды ескерту: компьютер «әліпбиді» өзінше түсінеді.

## 6. key параметрі: өлшем бойынша сұрыптау

`key` параметріне функция беріледі — салыстыру сол функцияның нәтижесі бойынша жүреді. Мысалы, сөздерді **ұзындығы** бойынша сұрыптау:
```python
words = ["ит", "жылқы", "қой", "түйе", "сиыр"]
words.sort(key=len)
print(words)
print(sorted(words, key=len, reverse=True))
```
Нәтижесі:
```text
['ит', 'қой', 'түйе', 'сиыр', 'жылқы']
['жылқы', 'түйе', 'сиыр', 'қой', 'ит']
```
Ұзындығы бірдей элементтер өзара бастапқы ретін сақтайды (Python сұрыптауы **тұрақты**).

`key=abs` — сандарды модулі бойынша сұрыптау:
```python
print(sorted([-7, 3, -1, 5, -4], key=abs))
```
Нәтижесі:
```text
[-1, 3, -4, 5, -7]
```

## 7. Сұрыпталған тізімнің пайдасы

```python
results = [12.4, 11.8, 13.1, 12.0, 11.5, 12.9]   # 100 м жүгіру, секунд
results.sort()
print("Жеңімпаз уақыты:", results[0])
print("Үздік үштік:", results[0], results[1], results[2])
print("Ең баяу:", results[-1])
# Медиана — сұрыпталған тізімнің ортасындағы мән
n = len(results)
if n % 2 == 1:
    median = results[n // 2]
else:
    median = (results[n // 2 - 1] + results[n // 2]) / 2
print("Медиана:", median)
```
Нәтижесі:
```text
Жеңімпаз уақыты: 11.5
Үздік үштік: 11.5 11.8 12.0
Ең баяу: 13.1
Медиана: 12.2
```

**Медиана** — сұрыпталған мәндердің ортасындағысы. Орташа мәннен айырмашылығы — тым үлкен/кіші «шашыраңқы» мәндерге аз тәуелді.

## 8. Сұрыптау алгоритмі ішінде не болады? Көпіршікті сұрыптау

`sort()` бір жолмен жұмыс істейді, бірақ ішінде күрделі алгоритм бар. Ең қарапайым сұрыптау алгоритмі — **көпіршікті сұрыптау (bubble sort)**: көрші элементтерді салыстырып, қате ретте тұрса орындарын ауыстырамыз. Әр өтуде ең үлкен элемент «көпіршік сияқты» соңына шығады.

```python
nums = [5, 2, 9, 1, 6]
n = len(nums)
for p in range(n - 1):              # өтулер саны
    for i in range(n - 1 - p):      # көрші жұптар
        if nums[i] > nums[i + 1]:
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
    print(f"{p + 1}-өтуден кейін:", nums)
```
Нәтижесі:
```text
1-өтуден кейін: [2, 5, 1, 6, 9]
2-өтуден кейін: [2, 1, 5, 6, 9]
3-өтуден кейін: [1, 2, 5, 6, 9]
4-өтуден кейін: [1, 2, 5, 6, 9]
```

Бұл алгоритм кірістірілген циклдерді және элементтерді орын ауыстыруды (`a, b = b, a`) біріктіреді. Python-ның `sort()` әдісі әлдеқайда жылдам алгоритмді (Timsort) қолданады.

## Жиі кездесетін қателер

**1. `sort()` нәтижесін меншіктеу**
```python
nums = [3, 1, 2]
nums = nums.sort()
print(nums)    # None — тізім жоғалды!
```
Дұрысы: `nums.sort()` немесе `nums = sorted(nums)`.

**2. `sorted()` тізімді өзгертеді деп ойлау**
```python
nums = [3, 1, 2]
sorted(nums)
print(nums)    # [3, 1, 2] — өзгермеді
```

**3. `reverse()`-ті кему ретімен сұрыптау деп ойлау** — ол тек кері айналдырады.

**4. Сандар мен жолдарды бірге сұрыптау**
```text
sorted([3, "екі", 1])   # TypeError: '<' not supported between 'str' and 'int'
```

**5. Енгізілген сандарды `int`-ке айналдырмай сұрыптау**: `["10", "9", "100"]` жолдар ретінде `['10', '100', '9']` болып сұрыпталады.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Сұрыптау | Элементтерді белгілі ретпен орналастыру |
| `lst.sort()` | Тізімнің өзін сұрыптайды, `None` қайтарады |
| `sorted(lst)` | Жаңа сұрыпталған тізім қайтарады |
| `reverse=True` | Кему ретімен сұрыптау параметрі |
| `lst.reverse()` | Тізімді кері айналдыру (сұрыптамайды) |
| `key=...` | Салыстыру критерийін беретін функция (`len`, `abs`) |
| Медиана | Сұрыпталған тізімнің ортаңғы мәні |
| Көпіршікті сұрыптау | Көрші элементтерді салыстырып ауыстыру алгоритмі |

## Ескерту

- Python-ның `sort()` / `sorted()` функциялары Timsort алгоритмін қолданады: орташа және ең нашар жағдайда O(n log n), ал жартылай сұрыпталған деректерде өте жылдам. Сұрыптау **тұрақты** (stable) — тең элементтердің реті сақталады.
- Регистрге тәуелсіз сұрыптау үшін `key=str.lower` (немесе Юникодқа дәлірек `key=str.casefold`) қолданыңыз: `sorted(words, key=str.casefold)`.
- Тілдің нақты әліпбиі бойынша сұрыптау үшін `locale.strxfrm` кілтін (`locale.setlocale(...)` орнатылған соң) немесе сыртқы `PyICU` кітапханасын пайдаланады.
- `reversed()` тізім емес, итератор қайтарады — оны бір рет қана аралауға болады; тізім керек болса `list(reversed(lst))` жазыңыз.
- Python 3-те әртүрлі типті мәндерді (`int` және `str`) салыстыруға болмайды — `TypeError`; Python 2-де бұл рұқсат етілген еді.
- Құжаттама: https://docs.python.org/3/howto/sorting.html
