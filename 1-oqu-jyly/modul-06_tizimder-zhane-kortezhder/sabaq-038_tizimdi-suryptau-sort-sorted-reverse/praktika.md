# Сабақ 38. Практикалық тапсырмалар: sort(), sorted(), reverse()

## Базалық деңгей

### 1-тапсырма. Болжа
Компьютерсіз нәтижесін жаз, содан кейін тексер:
```python
a = [7, 2, 9, 4]
b = sorted(a)
a.reverse()
print(a)
print(b)
a.sort(reverse=True)
print(a)
c = a.sort()
print(c)
```

### 2-тапсырма. Бағалар рейтингі
Пайдаланушы 6 оқушының тест ұпайын енгізеді. Ұпайларды өсу ретімен және кему ретімен шығар. Бастапқы енгізу реті де сақталып, шығарылсын (`sorted` қолдан).

### 3-тапсырма. Әліпби бойынша сынып тізімі
`students = ["Санжар", "Әйгерім", "Арсен", "Мөлдір", "Бауыржан", "Ділназ"]`. Тізімді әліпби бойынша сұрыптап, нөмірімен шығар. Нәтижеге қарап, «Ә» әрпімен басталатын есім неге соңында тұрғанын түсіндір.

### 4-тапсырма. Үздік үштік
Жарыстағы 8 қатысушының ұпайлары: `[34, 51, 47, 29, 51, 40, 38, 45]`. Ең жоғары 3 ұпайды және ең төмен 2 ұпайды шығар.

### 5-тапсырма. Кері реттеу
Пайдаланушы 5 қаланы енгізеді. Тізімді: а) енгізілген ретпен; ә) кері ретпен (`reverse()`); б) әліпбидің кері ретімен (`sort(reverse=True)`) шығар.

## Кеңейтілген деңгей

### 6-тапсырма. Медиана және орташа
Пайдаланушы `n` сан енгізеді. Сандардың орташасын және медианасын тап (жұп және тақ `n` үшін). Қай кезде орташа мен медиана қатты ерекшеленеді? Мысал келтір: `[30, 32, 35, 31, 300]`.

### 7-тапсырма. Ұзындық бойынша
Пайдаланушы 0 енгізгенше сөздер енгізеді (тізімге жинақталады). Сөздерді ұзындығы бойынша өсу ретімен сұрыптап шығар, соңында ең қысқа және ең ұзын сөзді шығар.

### 8-тапсырма. Әділ төрешілер
Гимнастикада 7 төреші баға береді (0–10). Ең жоғары және ең төмен бағалар алынып тасталады, қалғандарының орташасы — қорытынды баға. Сұрыптау арқылы шығар.

Мысал: `[9.1, 8.7, 9.5, 9.0, 8.2, 9.3, 9.4]` → `9.1`.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Көпіршікті сұрыптауды жақсарту
Көпіршікті сұрыптау кодын жаз. Егер бір өтуде бірде-бір орын ауыстыру болмаса, тізім сұрыпталған деген сөз — `break` арқылы тоқтат. Орын ауыстырулардың жалпы санын шығар.

### 10-тапсырма. Таңдау арқылы сұрыптау (selection sort)
Алгоритм: тізімнің ең кіші элементін тауып, оны 0-ші орынға қой; қалған бөліктің ең кішісін 1-ші орынға қой; т.с.с. `sort()` қолданбай жүзеге асыр және әр қадамнан кейінгі тізімді шығар.

## Үй тапсырмасы

1. Отбасы мүшелерінің жасын тізімге енгізіп, үлкенінен кішісіне қарай сұрыпта. Ең кіші мен ең үлкен жас айырмасын тап.
2. `nums = [15, -3, 8, -12, 0, 7, -1]` тізімін модулі бойынша (`key=abs`) сұрыпта.
3. Сұрыпталған тізімге жаңа сан келді. Тізімді қайта сұрыптамай, санды дұрыс орынға `insert` арқылы қой (кеңес: бірінші өзінен үлкен элементтің индексін тап).

**6-тапсырма**
```python
n = int(input("n = "))
nums = []
for i in range(n):
    nums.append(float(input()))
avg = sum(nums) / n
s = sorted(nums)
if n % 2 == 1:
    median = s[n // 2]
else:
    median = (s[n // 2 - 1] + s[n // 2]) / 2
print("Орташа:", avg, "Медиана:", median)
```

**8-тапсырма**
```python
marks = [9.1, 8.7, 9.5, 9.0, 8.2, 9.3, 9.4]
marks.sort()
middle = []
for i in range(1, len(marks) - 1):   # бірінші мен соңғысын өткіземіз
    middle.append(marks[i])
print(round(sum(middle) / len(middle), 2))
```
Нәтижесі: `9.1` (8.7 + 9.0 + 9.1 + 9.3 + 9.4 = 45.5; 45.5 / 5 = 9.1). Ықшам түрі (кесінділерді келесі сабақта өтеміз): `sum(marks[1:-1]) / 5`.

**9-тапсырма**
```python
nums = [5, 1, 4, 2, 8, 3]
n = len(nums)
swaps = 0
for p in range(n - 1):
    swapped = False
    for i in range(n - 1 - p):
        if nums[i] > nums[i + 1]:
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
            swaps += 1
            swapped = True
    if not swapped:
        break
print(nums, "Ауыстырулар:", swaps)
```

**10-тапсырма**
```python
nums = [29, 10, 14, 37, 13]
n = len(nums)
for i in range(n - 1):
    min_idx = i
    for j in range(i + 1, n):
        if nums[j] < nums[min_idx]:
            min_idx = j
    nums[i], nums[min_idx] = nums[min_idx], nums[i]
    print(f"{i + 1}-қадам:", nums)
```
