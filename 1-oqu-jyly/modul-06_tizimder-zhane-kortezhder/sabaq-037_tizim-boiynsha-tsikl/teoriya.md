## 1. len() — элементтер саны

`len()` (ағылш. length — ұзындық) — тізімдегі элементтер санын қайтарады:
```python
grades = [5, 4, 3, 5, 5, 4]
print(len(grades))
print(len([]))
```
Нәтижесі:
```text
6
0
```
Ең үлкен индекс әрқашан `len(lst) - 1`. Соңғы элемент: `lst[len(lst) - 1]` (немесе қысқаша `lst[-1]`).

`len()` жолдармен де жұмыс істейді: `len("Алматы")` → `6`.

## 2. Тізім бойынша циклдің екі тәсілі

### 1-тәсіл: элементтер бойынша
```python
cities = ["Алматы", "Астана", "Шымкент"]
for city in cities:
    print("Қала:", city)
```
Нәтижесі:
```text
Қала: Алматы
Қала: Астана
Қала: Шымкент
```
Цикл айнымалысы `city` әр итерацияда тізімнің келесі **элементін** алады. Бұл тәсіл қарапайым әрі түсінікті.

### 2-тәсіл: индекстер бойынша
```python
cities = ["Алматы", "Астана", "Шымкент"]
for i in range(len(cities)):
    print(i + 1, cities[i])
```
Нәтижесі:
```text
1 Алматы
2 Астана
3 Шымкент
```
Цикл айнымалысы `i` — **индекс**. Бұл тәсіл керек болғанда:
- элементтің нөмірі (орны) қажет;
- тізімдегі элементтерді **өзгерту** керек;
- көрші элементтерді салыстыру керек (`lst[i]` және `lst[i + 1]`).

| Қажеттілік | Тәсіл |
|---|---|
| Тек мәндерді оқу | `for x in lst:` |
| Нөмір/орын керек | `for i in range(len(lst)):` |
| Элементтерді өзгерту | `for i in range(len(lst)):` |
| Нөмір де, мән де керек (ықшам) | `for i, x in enumerate(lst):` |

### Элементтерді өзгерту — тек индекс арқылы!
```python
prices = [100, 250, 400]
for p in prices:
    p = p * 2          # тізім ӨЗГЕРМЕЙДІ — p тек көшірме
print(prices)

for i in range(len(prices)):
    prices[i] = prices[i] * 2
print(prices)
```
Нәтижесі:
```text
[100, 250, 400]
[200, 500, 800]
```

### enumerate() — нөмір мен мән бірге
```python
students = ["Аружан", "Бекжан", "Әсем"]
for num, name in enumerate(students, start=1):
    print(f"{num}. {name}")
```
Нәтижесі:
```text
1. Аружан
2. Бекжан
3. Әсем
```

## 3. sum(), min(), max() — кіріктірілген функциялар

```python
temps = [-5, -8, 2, 4, -1, 0, 3]
print("Қосынды:", sum(temps))
print("Ең төмен:", min(temps))
print("Ең жоғары:", max(temps))
print("Орташа:", sum(temps) / len(temps))
```
Нәтижесі:
```text
Қосынды: -5
Ең төмен: -8
Ең жоғары: 4
Орташа: -0.7142857142857143
```

| Функция | Не қайтарады | Ескерту |
|---|---|---|
| `len(lst)` | элементтер саны | бос тізімге 0 |
| `sum(lst)` | сандардың қосындысы | тек сандар тізіміне |
| `min(lst)` | ең кіші элемент | бос тізімге `ValueError` |
| `max(lst)` | ең үлкен элемент | бос тізімге `ValueError` |

`min` және `max` жолдармен де жұмыс істейді (әліпби ретімен салыстырады): `max(["алма", "өрік", "банан"])` → `'өрік'`.

### Орташа мәнді дөңгелектеу
```python
grades = [5, 4, 4, 3, 5]
avg = sum(grades) / len(grades)
print(f"Орташа баға: {avg:.1f}")
print("Дөңгелектенген:", round(avg))
```
Нәтижесі:
```text
Орташа баға: 4.2
Дөңгелектенген: 4
```

## 4. Сол функцияларды цикл арқылы жазу

Кіріктірілген функциялар ыңғайлы, бірақ олардың **ішінде** не болатынын түсіну маңызды. Сонда ғана күрделі есептерді шеше аламыз (мысалы, ең үлкен элементтің **индексін** табу).

### Қосынды
```python
nums = [3, 8, 1, 6]
total = 0
for x in nums:
    total += x
print(total)
```
Нәтижесі: `18`.

### Ең үлкен элемент және оның индексі
Алгоритм: бірінші элементті «әзірге ең үлкен» деп аламыз, қалғандарын онымен салыстырамыз.
```python
heights = [152, 165, 148, 171, 160]
max_value = heights[0]
max_index = 0
for i in range(1, len(heights)):
    if heights[i] > max_value:
        max_value = heights[i]
        max_index = i
print("Ең ұзын бой:", max_value, "см, оқушы нөмірі:", max_index + 1)
```
Нәтижесі:
```text
Ең ұзын бой: 171 см, оқушы нөмірі: 4
```

Трассировка:

| `i` | `heights[i]` | `> max_value?` | `max_value` | `max_index` |
|---|---|---|---|---|
| — | — | — | 152 | 0 |
| 1 | 165 | иә | 165 | 1 |
| 2 | 148 | жоқ | 165 | 1 |
| 3 | 171 | иә | 171 | 3 |
| 4 | 160 | жоқ | 171 | 3 |

**Неге `max_value = 0` деп бастамаймыз?** Барлық элементтер теріс болса (мысалы, қыстағы температура), 0 ешқашан ауыспайды — нәтиже қате болады.

## 5. Тізімді өңдеудің типтік алгоритмдері

### Шарт бойынша санау
```python
grades = [5, 3, 4, 5, 2, 5, 4]
fives = 0
for g in grades:
    if g == 5:
        fives += 1
print("«5» саны:", fives)
```
Нәтижесі: `«5» саны: 3`.

Дәл мәнді санау үшін дайын әдіс бар: `grades.count(5)` → `3`.

### Сүзгілеу (жаңа тізім құру)
```python
temps = [-5, -8, 2, 4, -1, 0, 3]
warm = []
for t in temps:
    if t > 0:
        warm.append(t)
print("Жылы күндер:", warm, "саны:", len(warm))
```
Нәтижесі:
```text
Жылы күндер: [2, 4, 3] саны: 3
```

### Іздеу (бірінші сәйкес элемент)
```python
names = ["Ақбота", "Дамир", "Ерасыл", "Дана"]
target = input("Кімді іздейміз? ")
found = False
for i in range(len(names)):
    if names[i] == target:
        print("Табылды, орны:", i + 1)
        found = True
        break
if not found:
    print("Табылмады")
```
Дайын әдіс: `names.index("Ерасыл")` → `2` (элемент жоқ болса — `ValueError`, сондықтан алдымен `in` арқылы тексер).

### Барлық элементтерді түрлендіру
```python
celsius = [0, 15, 25, 37]
fahrenheit = []
for c in celsius:
    fahrenheit.append(c * 9 / 5 + 32)
print(fahrenheit)
```
Нәтижесі:
```text
[32.0, 59.0, 77.0, 98.6]
```

### Көрші элементтерді салыстыру
```python
prices = [450, 470, 465, 480, 500]
for i in range(len(prices) - 1):
    diff = prices[i + 1] - prices[i]
    if diff > 0:
        print(f"{i + 2}-күні баға {diff} теңгеге өсті")
    else:
        print(f"{i + 2}-күні баға {-diff} теңгеге төмендеді")
```
Нәтижесі:
```text
2-күні баға 20 теңгеге өсті
3-күні баға 5 теңгеге төмендеді
4-күні баға 15 теңгеге өсті
5-күні баға 20 теңгеге өсті
```
`range(len(prices) - 1)` — соңғы элементте `i + 1` шектен шықпауы үшін.

## 6. Толық мысал: «Бағаларды талдау»

```python
grades = []
n = int(input("Оқушылар саны: "))
for i in range(n):
    grades.append(int(input(f"{i + 1}-оқушының бағасы: ")))

print("Бағалар:", grades)
print("Орташа:", round(sum(grades) / len(grades), 2))
print("Ең жоғары:", max(grades), "| Ең төмен:", min(grades))
for mark in range(5, 1, -1):
    print(f"«{mark}» алғандар: {grades.count(mark)}")
```

## Жиі кездесетін қателер

**1. `range(lst)` деп жазу**
```text
for i in range(grades):   # TypeError: 'list' object cannot be interpreted as an integer
```
Дұрысы: `range(len(grades))`.

**2. `for x in lst` арқылы тізімді өзгертуге тырысу** — `x` тек көшірме, тізім өзгермейді. Индекс қолдан.

**3. Бос тізімнің орташасы** — `sum([]) / len([])` → `ZeroDivisionError`. Алдымен `if len(lst) > 0:` тексер.

**4. `max_value = 0` бастау** — теріс сандар тізімінде қате нәтиже. Бірінші элементтен баста.

**5. `sum()`-ды жолдар тізіміне қолдану**
```text
sum(["a", "b"])   # TypeError
```

**6. `lst[i + 1]` кезінде шектен шығу** — цикл `range(len(lst) - 1)` болуы керек.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| `len()` | Элементтер саны |
| `sum()` | Сандар қосындысы |
| `min()` / `max()` | Ең кіші / ең үлкен элемент |
| `for x in lst` | Элементтер бойынша цикл |
| `for i in range(len(lst))` | Индекстер бойынша цикл |
| `enumerate()` | Нөмір мен элементті қатар береді |
| `count(x)` | `x` мәнінің кездесу саны |
| `index(x)` | `x` мәнінің бірінші кездесетін индексі |
| Сүзгілеу | Шартқа сай элементтерден жаңа тізім құру |

## Ескерту

- `round()` «банкирлік» дөңгелектеуді қолданады: .5 жағдайында ең жақын **жұп** санға дөңгелектейді — `round(2.5)` → `2`, `round(3.5)` → `4`. Мектептегі «.5 әрқашан жоғары» ережесі керек болса, `decimal` модулін қолданыңыз.
- `min()` / `max()` бос тізімде `ValueError` береді; Python 3.4+ нұсқасында `default` параметрі бар: `max(lst, default=0)`.
- `min`/`max`/`sorted` функцияларына `key` параметрін беруге болады: `max(names, key=len)` — ең ұзын есім.
- Ең үлкен элементтің индексін қысқаша табу: `lst.index(max(lst))` (бірінші кездескен ең үлкен элементтің индексі).
- Орташа мән, медиана, мода үшін стандарт кітапханада `statistics` модулі бар: `statistics.mean(lst)`, `statistics.median(lst)`.
- PEP 8 стилі бойынша `for i in range(len(lst))` орнына, мүмкін болса, `for x in lst` немесе `enumerate(lst)` жазылады. Құжаттама: https://docs.python.org/3/library/functions.html
