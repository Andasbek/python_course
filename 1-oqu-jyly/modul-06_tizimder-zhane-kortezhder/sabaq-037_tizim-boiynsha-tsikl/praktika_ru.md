# Урок 37. Практические задания: цикл по списку, len, sum, min, max

## Базовый уровень

### Задание 1. Нумерованный список
`subjects = ["Казахский язык", "Математика", "Информатика", "История", "Биология"]`. Выведи предметы с номерами:
```text
1. Казахский язык
2. Математика
...
```
Напиши двумя способами: `range(len(...))` и `enumerate()`.

### Задание 2. Недельная температура
`temps = [-12, -15, -9, -4, -7, -11, -14]` (Астана, январь). Выведи:
- количество дней (`len`);
- среднюю температуру (с 1 знаком после запятой);
- самую холодную и самую тёплую температуру.

### Задание 3. Сумма товаров
Пользователь вводит цены `n` товаров (собираются в список). Выведи общую сумму, цену самого дорогого и самого дешёвого товара. Если сумма больше 10 000 тенге — дай скидку 5% и выведи сумму к оплате.

### Задание 4. Пятёрки
`grades = [5, 4, 5, 3, 5, 4, 2, 5, 4, 3]`. С помощью цикла (без count) найди количество оценок «5», «4», «3», «2». Проверь результат методом `count()`.

### Задание 5. Фильтр чётных чисел
`nums = [12, 7, 3, 18, 25, 40, 9, 2]`. Создай новый список из чётных чисел и выведи его и его сумму.

## Продвинутый уровень

### Задание 6. Минимум без функции
Найди наименьший элемент списка из 7 чисел, введённых пользователем, и его **место** (начиная с 1), не используя `min()`.

### Задание 7. Выше среднего
Рост учеников класса дан в списке: `[148, 155, 162, 151, 170, 158, 149, 165]`. Вычисли средний рост, выведи количество учеников выше среднего и их номера.

### Задание 8. Рост очков
Очки игрока за 8 раундов даны в списке. Найди количество раундов, в которых очки выросли по сравнению с предыдущим раундом, и выведи наибольший прирост.

Пример: `[10, 15, 12, 20, 25, 18, 30, 31]` → раундов с ростом: 5, наибольший прирост: 12.

## ★ Олимпиадная / творческая задача

### Задание 9. Второе место
Результаты олимпиады даны в списке (баллы могут повторяться). Найди **второй** по величине балл (наибольшее значение, меньшее максимума). Не используй сортировку и `remove`, пройди список один раз.

Пример: `[87, 95, 78, 95, 90]` → `90`.

### Задание 10. Самый длинный возрастающий участок
Найди длину самого длинного участка списка из подряд идущих элементов, в котором каждый следующий элемент больше предыдущего.

Пример: `[3, 5, 7, 2, 4, 6, 8, 1]` → `4` (2, 4, 6, 8).

**Задание 9**
```python
# Простой вариант (два прохода: сначала max, затем наибольшее из меньших)
scores = [87, 95, 78, 95, 90]
first = max(scores)
second = None
for s in scores:
    if s < first:
        if second is None or s > second:
            second = s
print(second)
```
Вариант с одним проходом (без max):
```python
scores = [87, 95, 78, 95, 90]
first = scores[0]
second = None
for i in range(1, len(scores)):
    s = scores[i]
    if s > first:
        second = first
        first = s
    elif s < first and (second is None or s > second):
        second = s
print(second)
```
Результат: `90`. `None` означает «значения пока нет».
