## 1. len() — количество элементов

`len()` (англ. length — длина) — возвращает количество элементов в списке:
```python
grades = [5, 4, 3, 5, 5, 4]
print(len(grades))
print(len([]))
```
Результат:
```text
6
0
```
Наибольший индекс всегда `len(lst) - 1`. Последний элемент: `lst[len(lst) - 1]` (или короче `lst[-1]`).

`len()` работает и со строками: `len("Алматы")` → `6`.

## 2. Два способа цикла по списку

### Способ 1: по элементам
```python
cities = ["Алматы", "Астана", "Шымкент"]
for city in cities:
    print("Город:", city)
```
Результат:
```text
Город: Алматы
Город: Астана
Город: Шымкент
```
Переменная цикла `city` на каждой итерации получает следующий **элемент** списка. Этот способ простой и понятный.

### Способ 2: по индексам
```python
cities = ["Алматы", "Астана", "Шымкент"]
for i in range(len(cities)):
    print(i + 1, cities[i])
```
Результат:
```text
1 Алматы
2 Астана
3 Шымкент
```
Переменная цикла `i` — **индекс**. Этот способ нужен, когда:
- нужен номер (место) элемента;
- нужно **изменять** элементы списка;
- нужно сравнивать соседние элементы (`lst[i]` и `lst[i + 1]`).

| Потребность | Способ |
|---|---|
| Только читать значения | `for x in lst:` |
| Нужен номер/место | `for i in range(len(lst)):` |
| Изменять элементы | `for i in range(len(lst)):` |
| Нужны и номер, и значение (компактно) | `for i, x in enumerate(lst):` |

### Изменять элементы — только через индекс!
```python
prices = [100, 250, 400]
for p in prices:
    p = p * 2          # список НЕ МЕНЯЕТСЯ — p лишь копия
print(prices)

for i in range(len(prices)):
    prices[i] = prices[i] * 2
print(prices)
```
Результат:
```text
[100, 250, 400]
[200, 500, 800]
```

### enumerate() — номер и значение вместе
```python
students = ["Аружан", "Бекжан", "Асем"]
for num, name in enumerate(students, start=1):
    print(f"{num}. {name}")
```
Результат:
```text
1. Аружан
2. Бекжан
3. Асем
```

## 3. sum(), min(), max() — встроенные функции

```python
temps = [-5, -8, 2, 4, -1, 0, 3]
print("Сумма:", sum(temps))
print("Минимум:", min(temps))
print("Максимум:", max(temps))
print("Среднее:", sum(temps) / len(temps))
```
Результат:
```text
Сумма: -5
Минимум: -8
Максимум: 4
Среднее: -0.7142857142857143
```

| Функция | Что возвращает | Примечание |
|---|---|---|
| `len(lst)` | количество элементов | для пустого списка 0 |
| `sum(lst)` | сумму чисел | только для списка чисел |
| `min(lst)` | наименьший элемент | для пустого списка `ValueError` |
| `max(lst)` | наибольший элемент | для пустого списка `ValueError` |

`min` и `max` работают и со строками (сравнивают в алфавитном порядке): `max(["яблоко", "абрикос", "банан"])` → `'яблоко'`.

### Округление среднего значения
```python
grades = [5, 4, 4, 3, 5]
avg = sum(grades) / len(grades)
print(f"Средняя оценка: {avg:.1f}")
print("Округлённая:", round(avg))
```
Результат:
```text
Средняя оценка: 4.2
Округлённая: 4
```

## 4. Запись тех же функций через цикл

Встроенные функции удобны, но важно понимать, что происходит **внутри** них. Только тогда мы сможем решать более сложные задачи (например, находить **индекс** наибольшего элемента).

### Сумма
```python
nums = [3, 8, 1, 6]
total = 0
for x in nums:
    total += x
print(total)
```
Результат: `18`.

### Наибольший элемент и его индекс
Алгоритм: берём первый элемент как «пока наибольший» и сравниваем с ним остальные.
```python
heights = [152, 165, 148, 171, 160]
max_value = heights[0]
max_index = 0
for i in range(1, len(heights)):
    if heights[i] > max_value:
        max_value = heights[i]
        max_index = i
print("Самый высокий рост:", max_value, "см, номер ученика:", max_index + 1)
```
Результат:
```text
Самый высокий рост: 171 см, номер ученика: 4
```

Трассировка:

| `i` | `heights[i]` | `> max_value?` | `max_value` | `max_index` |
|---|---|---|---|---|
| — | — | — | 152 | 0 |
| 1 | 165 | да | 165 | 1 |
| 2 | 148 | нет | 165 | 1 |
| 3 | 171 | да | 171 | 3 |
| 4 | 160 | нет | 171 | 3 |

**Почему не начинаем с `max_value = 0`?** Если все элементы отрицательные (например, зимняя температура), 0 никогда не заменится — результат будет неверным.

## 5. Типовые алгоритмы обработки списка

### Подсчёт по условию
```python
grades = [5, 3, 4, 5, 2, 5, 4]
fives = 0
for g in grades:
    if g == 5:
        fives += 1
print("Количество «5»:", fives)
```
Результат: `Количество «5»: 3`.

Для подсчёта точного значения есть готовый метод: `grades.count(5)` → `3`.

### Фильтрация (создание нового списка)
```python
temps = [-5, -8, 2, 4, -1, 0, 3]
warm = []
for t in temps:
    if t > 0:
        warm.append(t)
print("Тёплые дни:", warm, "количество:", len(warm))
```
Результат:
```text
Тёплые дни: [2, 4, 3] количество: 3
```

### Поиск (первый подходящий элемент)
```python
names = ["Акбота", "Дамир", "Ерасыл", "Дана"]
target = input("Кого ищем? ")
found = False
for i in range(len(names)):
    if names[i] == target:
        print("Найден, место:", i + 1)
        found = True
        break
if not found:
    print("Не найден")
```
Готовый метод: `names.index("Ерасыл")` → `2` (если элемента нет — `ValueError`, поэтому сначала проверь через `in`).

### Преобразование всех элементов
```python
celsius = [0, 15, 25, 37]
fahrenheit = []
for c in celsius:
    fahrenheit.append(c * 9 / 5 + 32)
print(fahrenheit)
```
Результат:
```text
[32.0, 59.0, 77.0, 98.6]
```

### Сравнение соседних элементов
```python
prices = [450, 470, 465, 480, 500]
for i in range(len(prices) - 1):
    diff = prices[i + 1] - prices[i]
    if diff > 0:
        print(f"На {i + 2}-й день цена выросла на {diff} тенге")
    else:
        print(f"На {i + 2}-й день цена снизилась на {-diff} тенге")
```
Результат:
```text
На 2-й день цена выросла на 20 тенге
На 3-й день цена снизилась на 5 тенге
На 4-й день цена выросла на 15 тенге
На 5-й день цена выросла на 20 тенге
```
`range(len(prices) - 1)` — чтобы на последнем элементе `i + 1` не вышел за границы.

## 6. Полный пример: «Анализ оценок»

```python
grades = []
n = int(input("Количество учеников: "))
for i in range(n):
    grades.append(int(input(f"Оценка ученика {i + 1}: ")))

print("Оценки:", grades)
print("Среднее:", round(sum(grades) / len(grades), 2))
print("Максимум:", max(grades), "| Минимум:", min(grades))
for mark in range(5, 1, -1):
    print(f"Получили «{mark}»: {grades.count(mark)}")
```

## Частые ошибки

**1. Писать `range(lst)`**
```text
for i in range(grades):   # TypeError: 'list' object cannot be interpreted as an integer
```
Правильно: `range(len(grades))`.

**2. Пытаться изменить список через `for x in lst`** — `x` лишь копия, список не меняется. Используй индекс.

**3. Среднее пустого списка** — `sum([]) / len([])` → `ZeroDivisionError`. Сначала проверь `if len(lst) > 0:`.

**4. Начинать с `max_value = 0`** — неверный результат для списка отрицательных чисел. Начинай с первого элемента.

**5. Применять `sum()` к списку строк**
```text
sum(["a", "b"])   # TypeError
```

**6. Выход за границы при `lst[i + 1]`** — цикл должен быть `range(len(lst) - 1)`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| `len()` | Количество элементов |
| `sum()` | Сумма чисел |
| `min()` / `max()` | Наименьший / наибольший элемент |
| `for x in lst` | Цикл по элементам |
| `for i in range(len(lst))` | Цикл по индексам |
| `enumerate()` | Даёт номер и элемент одновременно |
| `count(x)` | Количество вхождений значения `x` |
| `index(x)` | Индекс первого вхождения значения `x` |
| Фильтрация | Создание нового списка из элементов, удовлетворяющих условию |

## Примечание

- `round()` использует «банковское» округление: при .5 округляет к ближайшему **чётному** — `round(2.5)` → `2`, `round(3.5)` → `4`. Если нужно школьное правило «.5 всегда вверх», используйте модуль `decimal`.
- `min()` / `max()` на пустом списке вызывают `ValueError`; в Python 3.4+ есть параметр `default`: `max(lst, default=0)`.
- В `min`/`max`/`sorted` можно передать параметр `key`: `max(names, key=len)` — самое длинное имя.
- Короткий способ найти индекс наибольшего элемента: `lst.index(max(lst))` (индекс первого из наибольших).
- Для среднего, медианы и моды в стандартной библиотеке есть модуль `statistics`: `statistics.mean(lst)`, `statistics.median(lst)`.
- По стилю (PEP 8) вместо `for i in range(len(lst))` по возможности пишут `for x in lst` или `enumerate(lst)`. Документация: https://docs.python.org/3/library/functions.html
