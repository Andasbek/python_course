# Сабақ 37. Практикалық тапсырмалар: тізім бойынша цикл, len, sum, min, max

## Базалық деңгей

### 1-тапсырма. Нөмірленген тізім
`subjects = ["Қазақ тілі", "Математика", "Информатика", "Тарих", "Биология"]`. Пәндерді нөмірімен шығар:
```text
1. Қазақ тілі
2. Математика
...
```
Екі тәсілмен жаз: `range(len(...))` және `enumerate()`.

### 2-тапсырма. Апталық температура
`temps = [-12, -15, -9, -4, -7, -11, -14]` (Астана, қаңтар). Шығар:
- күндер санын (`len`);
- орташа температураны (1 ондық таңбамен);
- ең суық және ең жылы температураны.

### 3-тапсырма. Тауарлар сомасы
Пайдаланушы `n` тауардың бағасын енгізеді (тізімге жинақталады). Жалпы соманы, ең қымбат және ең арзан тауар бағасын шығар. Егер сома 10 000 теңгеден асса — 5% жеңілдік беріп, төленетін соманы шығар.

### 4-тапсырма. Бестіктер
`grades = [5, 4, 5, 3, 5, 4, 2, 5, 4, 3]`. Цикл арқылы (count-сыз) «5», «4», «3», «2» бағаларының санын тап. Нәтижені `count()` әдісімен тексер.

### 5-тапсырма. Жұп сандарды сүзу
`nums = [12, 7, 3, 18, 25, 40, 9, 2]`. Жұп сандардан жаңа тізім құрып, оны және оның қосындысын шығар.

## Кеңейтілген деңгей

### 6-тапсырма. Максимум функциясыз
Пайдаланушы енгізген 7 саннан тұратын тізімнің ең кіші элементін және оның **орнын** (1-ден бастап) `min()` қолданбай тап.

### 7-тапсырма. Орташадан жоғары
Сыныптағы оқушылардың бойы тізімде: `[148, 155, 162, 151, 170, 158, 149, 165]`. Орташа бойды есепте, орташадан ұзын оқушылардың санын және олардың нөмірлерін шығар.

### 8-тапсырма. Ұпайлар өсімі
Ойыншының 8 раундтағы ұпайы тізімде. Ұпай алдыңғы раундтан өскен раундтар санын тап және ең үлкен өсімді шығар.

Мысал: `[10, 15, 12, 20, 25, 18, 30, 31]` → өскен раундтар: 5, ең үлкен өсім: 12.

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Екінші орын
Олимпиаданың нәтижелері тізімде (ұпайлар қайталануы мүмкін). **Екінші** ең жоғары ұпайды тап (максимумнан кіші ең үлкен мән). Сұрыптау мен `remove` қолданба, тізімді бір рет аралап шық.

Мысал: `[87, 95, 78, 95, 90]` → `90`.

### 10-тапсырма. Ең ұзын өспелі бөлік
Тізімнің қатарынан тұрған, әр келесі элементі алдыңғысынан үлкен болатын ең ұзын бөлігінің ұзындығын тап.

Мысал: `[3, 5, 7, 2, 4, 6, 8, 1]` → `4` (2, 4, 6, 8).

## Үй тапсырмасы

1. Өз отбасыңның 7 күндік шығындарын (теңге) тізімге енгіз. Жалпы шығын, орташа күндік шығын, ең көп шығын болған күн нөмірін шығар.
2. `words = ["кітап", "дәптер", "қалам", "сызғыш", "өшіргіш"]` — ең ұзын сөзді және оның ұзындығын тап (`len()` жолға да қолданылады).
3. Тізімдегі элементтердің әрқайсысын орташа мәннен айырмасымен ауыстыр (индекстер бойынша цикл).

scores = [10, 15, 12, 20, 25, 18, 30, 31]
grow = 0

**9-тапсырма**
```python
# Қарапайым нұсқа (екі өту: алдымен max, сосын одан кіші ең үлкені)
scores = [87, 95, 78, 95, 90]
first = max(scores)
second = None
for s in scores:
    if s < first:
        if second is None or s > second:
            second = s
print(second)
```
Бір рет аралайтын нұсқасы (max-сыз):
```python
scores = [87, 95, 78, 95, 90]
first = scores[0]
second = None
for i in range(1, len(scores)):
    s = scores[i]
    if s > first:
        second = first
        first = s
    elif s < first and (second is None or s > second):
        second = s
print(second)
```
Нәтижесі: `90`. `None` — «мән әлі жоқ» дегенді білдіреді.
