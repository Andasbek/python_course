## 1. Что такое кортеж?

**Кортеж (tuple)** — **неизменяемый (immutable)** упорядоченный набор значений. Он похож на список, но после создания его нельзя изменить.

Кортеж записывается в **круглых скобках**:
```python
days = ("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс")
point = (43.24, 76.95)          # координаты Алматы (широта, долгота)
rgb = (0, 175, 202)             # голубой цвет флага Казахстана
print(days)
print(point)
print(type(rgb))
```
Результат:
```text
('Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Вс')
(43.24, 76.95)
<class 'tuple'>
```

## 2. Способы создания кортежа

```python
empty = ()                    # пустой кортеж
t1 = (1, 2, 3)
t2 = 4, 5, 6                  # без скобок — это тоже кортеж!
t3 = tuple([7, 8, 9])         # из списка
t4 = tuple("abc")             # из строки
t5 = tuple(range(3))          # из range
print(empty, t1, t2, t3, t4, t5)
```
Результат:
```text
() (1, 2, 3) (4, 5, 6) (7, 8, 9) ('a', 'b', 'c') (0, 1, 2)
```

### Кортеж из одного элемента — запятая обязательна!
```python
not_tuple = (5)
real_tuple = (5,)
print(type(not_tuple))
print(type(real_tuple))
```
Результат:
```text
<class 'int'>
<class 'tuple'>
```
Кортеж создают не скобки, а **запятая**. `(5)` — просто число в скобках.

## 3. Доступ к элементам: индекс, срез, цикл

Как в списке:
```python
planets = ("Меркурий", "Венера", "Земля", "Марс")
print(planets[0])
print(planets[-1])
print(planets[1:3])
print(len(planets))
for p in planets:
    print("-", p)
```
Результат:
```text
Меркурий
Марс
('Венера', 'Земля')
4
- Меркурий
- Венера
- Земля
- Марс
```

Срез кортежа — тоже **кортеж**.

Функции и операторы, применимые к кортежу: `len()`, `sum()`, `min()`, `max()`, `sorted()` (возвращает список!), `in`, `+`, `*`.

```python
nums = (5, 2, 8, 1)
print(sum(nums), min(nums), max(nums))
print(sorted(nums))
print(8 in nums)
print(nums + (10, 20))
print(("ha",) * 3)
```
Результат:
```text
16 1 8
[1, 2, 5, 8]
True
(5, 2, 8, 1, 10, 20)
('ha', 'ha', 'ha')
```

У кортежа только **два метода**: `count()` и `index()`:
```python
votes = ("да", "нет", "да", "да", "воздержался")
print(votes.count("да"))
print(votes.index("нет"))
```
Результат:
```text
3
1
```

## 4. Кортеж не изменяется

```text
days = ("Пн", "Вт", "Ср")
days[0] = "Вс"
TypeError: 'tuple' object does not support item assignment
```
```text
days.append("Чт")
AttributeError: 'tuple' object has no attribute 'append'
```
У кортежа **нет** методов `append`, `insert`, `remove`, `pop`, `sort`, `reverse`.

Если нужно «изменить» — создаём **новый** кортеж:
```python
days = ("Пн", "Вт", "Ср")
days = days + ("Чт",)       # новый кортеж, переменная ссылается на новый
print(days)
```
Результат:
```text
('Пн', 'Вт', 'Ср', 'Чт')
```

Или превращаем в список, изменяем и снова превращаем в кортеж:
```python
colors = ("красный", "зелёный", "синий")
temp = list(colors)
temp[1] = "жёлтый"
colors = tuple(temp)
print(colors)
```
Результат:
```text
('красный', 'жёлтый', 'синий')
```

## 5. Распаковка кортежа

Элементы кортежа можно сразу присвоить нескольким переменным:
```python
student = ("Айбар", 14, 7)
name, age, grade = student
print(f"{name} — {age} лет, {grade}-й класс")
```
Результат:
```text
Айбар — 14 лет, 7-й класс
```
Количество переменных должно быть **равно** количеству элементов, иначе `ValueError: too many values to unpack`.

### Обмен значениями — это тоже кортеж!
```python
a = 5
b = 10
a, b = b, a       # справа создаётся кортеж (b, a), слева он распаковывается
print(a, b)
```
Результат:
```text
10 5
```

### Распаковка кортежа в цикле
```python
points = [(0, 0), (3, 4), (6, 8)]
for x, y in points:
    distance = (x ** 2 + y ** 2) ** 0.5
    print(f"Расстояние от точки ({x}, {y}) до начала координат: {distance}")
```
Результат:
```text
Расстояние от точки (0, 0) до начала координат: 0.0
Расстояние от точки (3, 4) до начала координат: 5.0
Расстояние от точки (6, 8) до начала координат: 10.0
```
`for i, x in enumerate(lst)` — тоже распаковка кортежа: `enumerate` выдаёт пары `(индекс, элемент)`.

## 6. Список кортежей — создание «таблицы»

Каждый элемент списка — одна «запись» (кортеж):
```python
results = [
    ("Аружан", 92),
    ("Ербол", 78),
    ("Дильназ", 95),
    ("Нурасыл", 85),
]
for name, score in results:
    print(f"{name:10} {score:3d}")

best = results[0]
for r in results:
    if r[1] > best[1]:
        best = r
print("Лучший:", best[0], best[1])
```
Результат:
```text
Аружан      92
Ербол       78
Дильназ     95
Нурасыл     85
Лучший: Дильназ 95
```
`{name:10}` — отводит строке 10 позиций (выравнивание по левому краю).

### Сортировка списка кортежей
Кортежи сравниваются по первому элементу, а если он равен — по второму. Чтобы отсортировать по баллам, передаём в параметр `key` функцию «взять второй элемент» — `lambda` (маленькая анонимная функция из одного выражения):
```python
results = [("Аружан", 92), ("Ербол", 78), ("Дильназ", 95)]
by_score = sorted(results, key=lambda r: r[1], reverse=True)
print(by_score)
```
Результат:
```text
[('Дильназ', 95), ('Аружан', 92), ('Ербол', 78)]
```

## 7. zip() — объединение двух списков в пары

`zip()` объединяет элементы нескольких списков в **пары-кортежи**:
```python
names = ["Алматы", "Астана", "Шымкент"]
population = [2.2, 1.4, 1.2]       # миллионов человек (приблизительно)
for city, p in zip(names, population):
    print(f"{city}: {p} млн")
print(list(zip(names, population)))
```
Результат:
```text
Алматы: 2.2 млн
Астана: 1.4 млн
Шымкент: 1.2 млн
[('Алматы', 2.2), ('Астана', 1.4), ('Шымкент', 1.2)]
```

## 8. Различие между списком и кортежем

| Признак | Список `list` | Кортеж `tuple` |
|---|---|---|
| Запись | `[1, 2, 3]` | `(1, 2, 3)` |
| Изменяемый ли | **Да** (mutable) | **Нет** (immutable) |
| Методы | много: `append`, `insert`, `remove`, `pop`, `sort`, ... | только `count`, `index` |
| Индекс, срез, цикл, `len`, `in` | Да | Да |
| Скорость, память | чуть медленнее, больше памяти | чуть быстрее, меньше памяти |
| Может ли быть ключом словаря (dict) | Нет | Да |
| Когда используем | Изменяемый набор: журнал оценок, список покупок | Постоянные данные: координаты, дата, цвет, месяцы, «запись» |

**Аналогия:** список — тетрадь, написанная карандашом (можно стереть и написать заново); кортеж — надпись, высеченная на камне (не меняется).

Зачем нужен кортеж?
1. **Безопасность** — защищает данные от случайного изменения.
2. **Смысл** — подсказывает читающему программу, что «эти данные постоянны».
3. **Эффективность** — занимает меньше памяти, работает быстрее.
4. Возврат нескольких значений из функции: `return a, b` возвращает кортеж.

## Частые ошибки

**1. Забыть запятую в кортеже из одного элемента**
```python
t = ("один")
print(type(t))     # <class 'str'>
```
Правильно: `("один",)`.

**2. Пытаться изменить кортеж** — `TypeError`. Создай новый кортеж или используй список.

**3. Вызов `append` у кортежа** — `AttributeError`.

**4. Несовпадение количества переменных при распаковке**
```text
a, b = (1, 2, 3)   # ValueError: too many values to unpack
```

**5. Думать, что `sorted(кортеж)` возвращает кортеж** — возвращает список. Если нужен кортеж: `tuple(sorted(t))`.

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Кортеж (tuple) | Неизменяемый упорядоченный набор `(a, b, c)` |
| Неизменяемый (immutable) | Объект, который нельзя изменить после создания |
| `(x,)` | Кортеж из одного элемента |
| Распаковка | `a, b, c = кортеж` |
| `tuple()` / `list()` | Преобразование список ↔ кортеж |
| `zip()` | Объединение нескольких списков в пары-кортежи |
| `count()`, `index()` | Два метода кортежа |

## Примечание

- Неизменяемость кортежа «поверхностная»: если внутри лежит список, его можно менять — `t = (1, [2, 3]); t[1].append(4)` выполнится без ошибки. Такой кортеж не хешируется и не может быть ключом словаря.
- Расширенная распаковка со звёздочкой (Python 3+): `first, *rest = (1, 2, 3, 4)` → `first = 1`, `rest = [2, 3, 4]` (`rest` — список).
- Для доступа к полям по имени есть `collections.namedtuple` и `typing.NamedTuple`: `p.x`, `p.y` — понятнее, чем `p[0]`.
- `zip()` останавливается на самом коротком списке; в Python 3.10+ `zip(a, b, strict=True)` вызывает `ValueError` при разной длине, а чтобы идти до самого длинного — `itertools.zip_longest`.
- PEP 8: в кортеже из одного элемента закрывайте скобку сразу после запятой — `(5,)`; при многострочной записи «таблицы» рекомендуется ставить запятую и после последнего элемента (trailing comma).
- Документация: https://docs.python.org/3/tutorial/datastructures.html#tuples-and-sequences
