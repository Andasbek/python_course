## 1. Кортеж дегеніміз не?

**Кортеж (кортеж, tuple)** — **өзгермейтін (immutable)**, реттелген мәндер жиынтығы. Ол тізімге ұқсас, бірақ құрылғаннан кейін оны өзгертуге болмайды.

Кортеж **дөңгелек жақшамен** жазылады:
```python
days = ("Дс", "Сс", "Ср", "Бс", "Жм", "Сб", "Жс")
point = (43.24, 76.95)          # Алматының координаталары (ендік, бойлық)
rgb = (0, 175, 202)             # Қазақстан туының көгілдір түсі
print(days)
print(point)
print(type(rgb))
```
Нәтижесі:
```text
('Дс', 'Сс', 'Ср', 'Бс', 'Жм', 'Сб', 'Жс')
(43.24, 76.95)
<class 'tuple'>
```

## 2. Кортеж құру тәсілдері

```python
empty = ()                    # бос кортеж
t1 = (1, 2, 3)
t2 = 4, 5, 6                  # жақшасыз — бұл да кортеж!
t3 = tuple([7, 8, 9])         # тізімнен
t4 = tuple("abc")             # жолдан
t5 = tuple(range(3))          # range-тен
print(empty, t1, t2, t3, t4, t5)
```
Нәтижесі:
```text
() (1, 2, 3) (4, 5, 6) (7, 8, 9) ('a', 'b', 'c') (0, 1, 2)
```

### Бір элементті кортеж — үтір міндетті!
```python
not_tuple = (5)
real_tuple = (5,)
print(type(not_tuple))
print(type(real_tuple))
```
Нәтижесі:
```text
<class 'int'>
<class 'tuple'>
```
Кортежді жақша емес, **үтір** жасайды. `(5)` — жай жақшадағы сан.

## 3. Элементтерге қатынау: индекс, кесінді, цикл

Тізімдегідей:
```python
planets = ("Меркурий", "Шолпан", "Жер", "Марс")
print(planets[0])
print(planets[-1])
print(planets[1:3])
print(len(planets))
for p in planets:
    print("-", p)
```
Нәтижесі:
```text
Меркурий
Марс
('Шолпан', 'Жер')
4
- Меркурий
- Шолпан
- Жер
- Марс
```

Кортеждің кесіндісі де — **кортеж**.

Кортежге қолданылатын функциялар мен операторлар: `len()`, `sum()`, `min()`, `max()`, `sorted()` (тізім қайтарады!), `in`, `+`, `*`.

```python
nums = (5, 2, 8, 1)
print(sum(nums), min(nums), max(nums))
print(sorted(nums))
print(8 in nums)
print(nums + (10, 20))
print(("ha",) * 3)
```
Нәтижесі:
```text
16 1 8
[1, 2, 5, 8]
True
(5, 2, 8, 1, 10, 20)
('ha', 'ha', 'ha')
```

Кортежде тек **екі әдіс** бар: `count()` және `index()`:
```python
votes = ("иә", "жоқ", "иә", "иә", "қалыс")
print(votes.count("иә"))
print(votes.index("жоқ"))
```
Нәтижесі:
```text
3
1
```

## 4. Кортеж өзгермейді

```text
days = ("Дс", "Сс", "Ср")
days[0] = "Жс"
TypeError: 'tuple' object does not support item assignment
```
```text
days.append("Бс")
AttributeError: 'tuple' object has no attribute 'append'
```
Кортежде `append`, `insert`, `remove`, `pop`, `sort`, `reverse` әдістері **жоқ**.

«Өзгерту» керек болса — **жаңа** кортеж құрамыз:
```python
days = ("Дс", "Сс", "Ср")
days = days + ("Бс",)       # жаңа кортеж, айнымалы жаңаға сілтейді
print(days)
```
Нәтижесі:
```text
('Дс', 'Сс', 'Ср', 'Бс')
```

Немесе тізімге айналдырып, өзгертіп, қайта кортежге айналдырамыз:
```python
colors = ("қызыл", "жасыл", "көк")
temp = list(colors)
temp[1] = "сары"
colors = tuple(temp)
print(colors)
```
Нәтижесі:
```text
('қызыл', 'сары', 'көк')
```

## 5. Кортежді ашу (распаковка)

Кортеждің элементтерін бірден бірнеше айнымалыға меншіктеуге болады:
```python
student = ("Айбар", 14, 7)
name, age, grade = student
print(f"{name} — {age} жаста, {grade}-сынып")
```
Нәтижесі:
```text
Айбар — 14 жаста, 7-сынып
```
Айнымалылар саны элементтер санына **тең** болуы керек, әйтпесе `ValueError: too many values to unpack`.

### Мәндерді алмастыру — бұл да кортеж!
```python
a = 5
b = 10
a, b = b, a       # оң жақта (b, a) кортежі құрылып, сол жақта ашылады
print(a, b)
```
Нәтижесі:
```text
10 5
```

### Кортеж ашу циклде
```python
points = [(0, 0), (3, 4), (6, 8)]
for x, y in points:
    distance = (x ** 2 + y ** 2) ** 0.5
    print(f"({x}, {y}) нүктесінің бас нүктеден қашықтығы: {distance}")
```
Нәтижесі:
```text
(0, 0) нүктесінің бас нүктеден қашықтығы: 0.0
(3, 4) нүктесінің бас нүктеден қашықтығы: 5.0
(6, 8) нүктесінің бас нүктеден қашықтығы: 10.0
```
`for i, x in enumerate(lst)` те — кортежді ашу: `enumerate` `(индекс, элемент)` жұптарын береді.

## 6. Кортеждер тізімі — «кесте» құру

Тізімнің әр элементі — бір «жазба» (кортеж):
```python
results = [
    ("Аружан", 92),
    ("Ербол", 78),
    ("Дильназ", 95),
    ("Нұрасыл", 85),
]
for name, score in results:
    print(f"{name:10} {score:3d}")

best = results[0]
for r in results:
    if r[1] > best[1]:
        best = r
print("Үздік:", best[0], best[1])
```
Нәтижесі:
```text
Аружан      92
Ербол       78
Дильназ     95
Нұрасыл     85
Үздік: Дильназ 95
```
`{name:10}` — жолға 10 таңбалық орын береді (солға тураланған).

### Кортеждер тізімін сұрыптау
Кортеждер бірінші элементі бойынша, ол тең болса екіншісі бойынша салыстырылады. Ұпай бойынша сұрыптау үшін `key` параметріне «екінші элементті ал» деген функция береміз — `lambda` (бір өрнектен тұратын кіші анонимді функция):
```python
results = [("Аружан", 92), ("Ербол", 78), ("Дильназ", 95)]
by_score = sorted(results, key=lambda r: r[1], reverse=True)
print(by_score)
```
Нәтижесі:
```text
[('Дильназ', 95), ('Аружан', 92), ('Ербол', 78)]
```

## 7. zip() — екі тізімді жұптастыру

`zip()` бірнеше тізімнің элементтерін **кортеж-жұптарға** біріктіреді:
```python
names = ["Алматы", "Астана", "Шымкент"]
population = [2.2, 1.4, 1.2]       # миллион адам (шамамен)
for city, p in zip(names, population):
    print(f"{city}: {p} млн")
print(list(zip(names, population)))
```
Нәтижесі:
```text
Алматы: 2.2 млн
Астана: 1.4 млн
Шымкент: 1.2 млн
[('Алматы', 2.2), ('Астана', 1.4), ('Шымкент', 1.2)]
```

## 8. Тізім мен кортеждің айырмашылығы

| Белгі | Тізім `list` | Кортеж `tuple` |
|---|---|---|
| Жазылуы | `[1, 2, 3]` | `(1, 2, 3)` |
| Өзгермелі ме | **Иә** (mutable) | **Жоқ** (immutable) |
| Әдістері | көп: `append`, `insert`, `remove`, `pop`, `sort`, ... | тек `count`, `index` |
| Индекс, кесінді, цикл, `len`, `in` | Иә | Иә |
| Жылдамдық, жады | сәл баяу, көбірек жады | сәл жылдам, азырақ жады |
| Сөздіктің (dict) кілті бола ала ма | Жоқ | Иә |
| Қашан қолданамыз | Өзгеретін жиынтық: бағалар журналы, сатып алу тізімі | Тұрақты мәліметтер: координаталар, күн, түс, айлар, «жазба» |

**Аналогия:** тізім — қарындашпен жазылған дәптер (өшіріп, қайта жазуға болады); кортеж — тасқа қашалған жазу (өзгермейді).

Неге кортеж керек?
1. **Қауіпсіздік** — мәліметті кездейсоқ өзгертіп алудан қорғайды.
2. **Мағына** — «бұл деректер тұрақты» деп бағдарламаны оқитын адамға белгі береді.
3. **Тиімділік** — аз жады алады, жылдамырақ.
4. Функциядан бірнеше мән қайтару: `return a, b` кортеж қайтарады.

## Жиі кездесетін қателер

**1. Бір элементті кортежде үтірді ұмыту**
```python
t = ("жалғыз")
print(type(t))     # <class 'str'>
```
Дұрысы: `("жалғыз",)`.

**2. Кортежді өзгертуге тырысу** — `TypeError`. Жаңа кортеж құр немесе тізім қолдан.

**3. Кортежге `append` шақыру** — `AttributeError`.

**4. Ашу кезіндегі айнымалылар санының сәйкес келмеуі**
```text
a, b = (1, 2, 3)   # ValueError: too many values to unpack
```

**5. `sorted(кортеж)` кортеж қайтарады деп ойлау** — тізім қайтарады. Кортеж керек болса: `tuple(sorted(t))`.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Кортеж (tuple) | Өзгермейтін реттелген жиынтық `(a, b, c)` |
| Өзгермейтін (immutable) | Құрылғаннан кейін өзгертуге болмайтын объект |
| `(x,)` | Бір элементті кортеж |
| Ашу (распаковка) | `a, b, c = кортеж` |
| `tuple()` / `list()` | Тізім ↔ кортеж түрлендіру |
| `zip()` | Бірнеше тізімді кортеж-жұптарға біріктіру |
| `count()`, `index()` | Кортеждің екі әдісі |

## Ескерту

- Кортеж «таяз» өзгермейді: оның ішінде тізім болса, сол тізімді өзгертуге болады — `t = (1, [2, 3]); t[1].append(4)` қатесіз орындалады. Мұндай кортеж хэштелмейді және сөздік кілті бола алмайды.
- Жұлдызшамен кеңейтілген ашу (Python 3+): `first, *rest = (1, 2, 3, 4)` → `first = 1`, `rest = [2, 3, 4]` (`rest` — тізім).
- Өрістерге атпен қатынау үшін `collections.namedtuple` немесе `typing.NamedTuple` бар: `p.x`, `p.y` — `p[0]`-ден түсініктірек.
- `zip()` ең қысқа тізім біткенде тоқтайды; Python 3.10+ нұсқасында `zip(a, b, strict=True)` ұзындықтар тең болмаса `ValueError` береді, ал ең ұзынына дейін жүру үшін — `itertools.zip_longest`.
- PEP 8: бір элементті кортеждегі үтірден кейін жақшаны бірден жабыңыз — `(5,)`; ал көп жолды «кесте» жазғанда соңғы элементтен кейін де үтір қою (`trailing comma`) ұсынылады.
- Құжаттама: https://docs.python.org/3/tutorial/datastructures.html#tuples-and-sequences
