## Базовый уровень

### Задание 1. Создай кортежи
Сохрани следующие данные в виде кортежей и выведи на экран:

### Задание 2. Предскажи

### Задание 3. Название месяца и количество дней
Сохрани названия месяцев и количество дней в каждом месяце в двух кортежах (невисокосный год). Пользователь вводит номер месяца — программа выводит в виде «Февраль — 28 дней».

### Задание 4. Распаковка кортежа
`book = ("Путь Абая", "Мухтар Ауэзов", 1942)`. Распакуй кортеж в три переменные и выведи «Роман "Путь Абая" Мухтар Ауэзов начал писать в 1942 году».

### Задание 5. Обмен значениями
Пользователь вводит числа `a`, `b`, `c`. С помощью кортежа сдвинь значения «по кругу»: `a` ← `b`, `b` ← `c`, `c` ← `a` (без временной переменной).

### Задание 8. Точки

**Задание 6**
```python
products = [("Хлеб", 250), ("Молоко", 520), ("Сыр", 1850), ("Яблоки", 690), ("Чай", 1200)]
for name, price in products:
    print(f"{name:.<12}{price:>6} тг")
expensive = products[0]
cheap = products[0]
for p in products:
    if p[1] > expensive[1]:
        expensive = p
    if p[1] < cheap[1]:
        cheap = p
print("Самый дорогой:", expensive[0], "| Самый дешёвый:", cheap[0])
print("Дешевле 1000 тг:", [name for name, price in products if price < 1000])
```

**Задание 8**
```python
points = [(2, 3), (-1, 5), (4, -2), (0, 0), (-3, -3)]
nearest = None
for x, y in points:
    if x > 0 and y > 0:
        place = "I четверть"
    elif x < 0 and y > 0:
        place = "II четверть"
    elif x < 0 and y < 0:
        place = "III четверть"
    elif x > 0 and y < 0:
        place = "IV четверть"
    else:
        place = "на оси"
    print((x, y), place)
    if (x, y) != (0, 0):
        d = (x * x + y * y) ** 0.5
        if nearest is None or d < nearest[1]:
            nearest = ((x, y), d)
print("Ближайшая:", nearest[0])
```
Ближайшая: `(2, 3)` (≈3.61).

**Задание 9**
```python
lessons = [((8, 30), (9, 15)), ((9, 25), (10, 10)), ((10, 30), (11, 15)), ((11, 25), (12, 10))]
longest = 0
for i in range(len(lessons) - 1):
    end_h, end_m = lessons[i][1]
    start_h, start_m = lessons[i + 1][0]
    brk = (start_h * 60 + start_m) - (end_h * 60 + end_m)
    print(f"Перемена {i + 1}: {brk} мин")
    if brk > longest:
        longest = brk
print("Самая длинная перемена:", longest, "мин")
```
Результат: 10, 20, 10 мин; самая длинная — 20 мин.
