# Сабақ 40. Практикалық тапсырмалар: кортеж (tuple)

## Базалық деңгей

### 1-тапсырма. Кортеждерді құр
Мына мәліметтерді кортеж түрінде сақта және экранға шығар:
- жыл мезгілдері;
- өзіңнің туған күнің `(күн, ай, жыл)`;
- Астананың координаталары `(51.17, 71.43)`;
- бір элементті кортеж: сүйікті пәнің.

Әрқайсысының типін `type()` арқылы тексер.

### 2-тапсырма. Болжа
```python
t = (10, 20, 30, 40, 50, 20)
```
Компьютерсіз жаз, сосын тексер:
1. `t[3]`
2. `t[-2]`
3. `t[1:4]`
4. `t.count(20)`
5. `t.index(30)`
6. `len(t)`
7. `t + (60,)`
8. `t[0] = 5` — не болады?

### 3-тапсырма. Ай атауы мен күндер саны
Ай атаулары мен әр айдағы күн санын екі кортежде сақта (кібісе емес жыл). Пайдаланушы ай нөмірін енгізеді — бағдарлама «Ақпан — 28 күн» түрінде шығарады.

### 4-тапсырма. Кортежді ашу
`book = ("Абай жолы", "Мұхтар Әуезов", 1942)`. Кортежді үш айнымалыға аш және «"Абай жолы" романын Мұхтар Әуезов 1942 жылы жаза бастаған» деп шығар.

### 5-тапсырма. Мәндерді алмастыру
Пайдаланушы `a`, `b`, `c` сандарын енгізеді. Кортеж арқылы мәндерді «шеңбер бойымен» ығыстыр: `a` ← `b`, `b` ← `c`, `c` ← `a` (уақытша айнымалысыз).

## Кеңейтілген деңгей

### 6-тапсырма. Кортеждер тізімі: тауарлар
```python
products = [("Нан", 250), ("Сүт", 520), ("Ірімшік", 1850), ("Алма", 690), ("Шай", 1200)]
```
Шығар:
- барлық тауарды «Нан ...... 250 тг» түрінде;
- ең қымбат және ең арзан тауардың атауын;
- 1000 теңгеден арзан тауарлар тізімін (генератор).

### 7-тапсырма. zip арқылы журнал
Екі тізім: `names = ["Аян", "Бибігүл", "Диас", "Жанель"]`, `scores = [87, 93, 76, 90]`. `zip` арқылы `(есім, ұпай)` кортеждерінің тізімін құр, ұпай бойынша кему ретімен сұрыпта және орындарымен шығар.

### 8-тапсырма. Нүктелер
Жазықтықтағы нүктелер кортеждер тізімінде: `[(2, 3), (-1, 5), (4, -2), (0, 0), (-3, -3)]`. Әр нүктенің қай ширекте (I, II, III, IV) немесе осьте жатқанын анықта, бас нүктеге ең жақын нүктені тап (бас нүкте өзінен басқа).

## ★ Олимпиадалық / шығармашылық тапсырма

### 9-тапсырма. Уақыт кортеждері
Сабақ кестесі `(басталуы, аяқталуы)` кортеждері түрінде берілген, уақыт — `(сағат, минут)`:
```python
lessons = [((8, 30), (9, 15)), ((9, 25), (10, 10)), ((10, 30), (11, 15)), ((11, 25), (12, 10))]
```
Әр үзілістің ұзақтығын минутпен есепте және ең ұзақ үзілісті тап.

### 10-тапсырма. Ойыншылар рейтингі
Ойыншылар туралы мәліметтер: `(есім, ұпай, уақыт_секунд)`. Ойыншыларды ұпай бойынша кему ретімен сұрыпта; ұпайлары тең болса — уақыты аз ойыншы жоғары тұрсын.

**Кеңес:** `key=lambda p: (-p[1], p[2])` — кортеж бойынша сұрыптау.

## Үй тапсырмасы

1. Отбасы мүшелері туралы мәліметтерді кортеждер тізімінде сақта: `(есім, туыстығы, жасы)`. Ең жас және ең үлкен мүшені тап, орташа жасты есепте.
2. Тізім мен кортеждің айырмашылығы туралы 5 сұрақтан тұратын шағын тест дайында (жауаптарымен).
3. Келесі сабаққа (практикум) дайындық: тізімдер модулінің барлық әдістерін (`append`, `insert`, `remove`, `pop`, `sort`, `len`, `sum`, `min`, `max`, кесінді, генератор) қайтала.

**6-тапсырма**
```python
products = [("Нан", 250), ("Сүт", 520), ("Ірімшік", 1850), ("Алма", 690), ("Шай", 1200)]
for name, price in products:
    print(f"{name:.<12}{price:>6} тг")
expensive = products[0]
cheap = products[0]
for p in products:
    if p[1] > expensive[1]:
        expensive = p
    if p[1] < cheap[1]:
        cheap = p
print("Ең қымбат:", expensive[0], "| Ең арзан:", cheap[0])
print("1000 тг-ден арзан:", [name for name, price in products if price < 1000])
```
`{name:.<12}` — жолды 12 таңбаға дейін нүктелермен толтырады.

**8-тапсырма**
```python
points = [(2, 3), (-1, 5), (4, -2), (0, 0), (-3, -3)]
nearest = None
for x, y in points:
    if x > 0 and y > 0:
        place = "I ширек"
    elif x < 0 and y > 0:
        place = "II ширек"
    elif x < 0 and y < 0:
        place = "III ширек"
    elif x > 0 and y < 0:
        place = "IV ширек"
    else:
        place = "осьте"
    print((x, y), place)
    if (x, y) != (0, 0):
        d = (x * x + y * y) ** 0.5
        if nearest is None or d < nearest[1]:
            nearest = ((x, y), d)
print("Ең жақын:", nearest[0])
```
Ең жақыны: `(2, 3)` (≈3.61).

**9-тапсырма**
```python
lessons = [((8, 30), (9, 15)), ((9, 25), (10, 10)), ((10, 30), (11, 15)), ((11, 25), (12, 10))]
longest = 0
for i in range(len(lessons) - 1):
    end_h, end_m = lessons[i][1]
    start_h, start_m = lessons[i + 1][0]
    brk = (start_h * 60 + start_m) - (end_h * 60 + end_m)
    print(f"{i + 1}-үзіліс: {brk} мин")
    if brk > longest:
        longest = brk
print("Ең ұзақ үзіліс:", longest, "мин")
```
Нәтижесі: 10, 20, 10 мин; ең ұзағы — 20 мин.
