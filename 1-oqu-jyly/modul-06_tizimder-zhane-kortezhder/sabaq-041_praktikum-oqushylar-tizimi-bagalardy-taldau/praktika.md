## I бөлім. Практикум

### 1-жоба. «Оқушылар тізімі»

Мәзір арқылы басқарылатын сынып журналы бағдарламасын жаз. Деректер кортеждер тізімінде сақталады: `(есім, баға)`.

**Мәзір:**
```text
===== СЫНЫП ЖУРНАЛЫ =====
1. Оқушы қосу
2. Барлық оқушыларды көрсету
3. Оқушыны жою
4. Оқушыны іздеу
5. Бағасын өзгерту
6. Әліпби бойынша сұрыптау
7. Баға бойынша сұрыптау (жоғарыдан төмен)
0. Шығу
```

**Қадамдар:**

| Қадам | Тапсырма | Тексеру |
|---|---|---|
| 1 | Бастапқы тізім: 3–4 оқушы, мәзір циклі, «0 — Шығу», қате таңдау | Мәзір қайталана ма? |
| 2 | «Қосу»: есім мен баға (2–5) енгізу, тексеру, `append` | 6 деген баға қабылданбауы керек |
| 3 | «Көрсету»: нөмірлеп шығару (`enumerate`), тізім бос болса — хабарлама | |
| 4 | «Жою»: нөмір бойынша `pop` (нөмірді тексеру) | 0 немесе 100 нөмірі қате береді ме? |
| 5 | «Іздеу»: есім бойынша, табылса бағасы, табылмаса хабарлама | |
| 6 | «Бағасын өзгерту»: нөмір бойынша, жаңа кортеж құрып ауыстыру | |
| 7 | Сұрыптау: `sort()` және `sort(key=..., reverse=True)` | |
| 8 | Код мәдениеті: түсініктемелер, айнымалы атаулары | |

### 2-жоба. «Бағаларды талдау»

Бағдарлама сынып бағаларын енгізіп, толық талдау жасайды.

**Енгізу:** оқушылар саны `n`, содан кейін әр оқушының есімі мен бағасы (2–5; қате болса қайта сұрау).

**Шығару (есеп):**
```text
===== БАҒАЛАР ТАЛДАУЫ =====
Оқушылар саны: 8
Орташа баға: 3.88
Медиана: 4.0
Ең жоғары баға: 5 (Аружан, Ерасыл)
Ең төмен баға: 2 (Бекзат)
Үлестірім:
  «5»: ██ 2
  «4»: ████ 4
  «3»: █ 1
  «2»: █ 1
Сапа көрсеткіші: 75.0%
Үлгерім көрсеткіші: 87.5%
Орташадан жоғары: Аружан, Ерасыл, ...
```

**Қадамдар:**
1. Деректерді енгізу (параллель тізімдер **немесе** кортеждер тізімі — өзің таңда).
2. Орташа, медиана, максимум, минимум.
3. Ең жоғары/төмен баға алған **барлық** оқушылардың есімдері (генератор).
4. Үлестірім және мәтіндік диаграмма.
5. Сапа және үлгерім көрсеткіштері (`:.1f`).
6. Орташадан жоғары оқушылар тізімі.
7. ★ Қосымша: «2» алған оқушыларға «Қосымша сабаққа шақырылады» хабарламасы; рейтинг кестесі (орын, есім, баға).

### Практикум бағалау критерийлері

| Критерий | Ұпай |
|---|---|
| Деректер дұрыс сақталады (тізім/кортеж), бастапқы күй циклге дейін | 2 |
| Мәзір / енгізу циклі дұрыс жұмыс істейді | 2 |

| Шекаралық жағдайлар өңделген (бос тізім, қате нөмір/баға) | 2 |
| Шығару түсінікті, пішімделген | 1 |
| Код мәдениеті | 2 |
| **Барлығы** | **15** |

**1-жоба. «Оқушылар тізімі» — үлгі шешім**
```python
students = [("Айгерім", 5), ("Бекзат", 4), ("Дана", 3)]

while True:
    print("\n===== СЫНЫП ЖУРНАЛЫ =====")
    print("1. Оқушы қосу")
    print("2. Барлық оқушыларды көрсету")
    print("3. Оқушыны жою")
    print("4. Оқушыны іздеу")
    print("5. Бағасын өзгерту")
    print("6. Әліпби бойынша сұрыптау")
    print("7. Баға бойынша сұрыптау")
    print("0. Шығу")
    choice = input("Таңдауыңыз: ")

    if choice == "1":
        name = input("Есімі: ")
        grade = int(input("Бағасы (2-5): "))
        while grade < 2 or grade > 5:
            grade = int(input("Қате! Баға 2-ден 5-ке дейін: "))
        students.append((name, grade))
        print("Қосылды!")
    elif choice == "2":
        if not students:
            print("Тізім бос")
        for num, (name, grade) in enumerate(students, start=1):
            print(f"{num}. {name:<12} {grade}")
    elif choice == "3":
        num = int(input("Оқушы нөмірі: "))
        if 1 <= num <= len(students):
            removed = students.pop(num - 1)
            print("Жойылды:", removed[0])
        else:
            print("Мұндай нөмір жоқ")
    elif choice == "4":
        target = input("Есім: ")
        found = False
        for name, grade in students:
            if name == target:
                print(f"{name} — бағасы {grade}")
                found = True
        if not found:
            print("Табылмады")
    elif choice == "5":
        num = int(input("Оқушы нөмірі: "))
        if 1 <= num <= len(students):
            new_grade = int(input("Жаңа баға: "))
            if 2 <= new_grade <= 5:
                name = students[num - 1][0]
                students[num - 1] = (name, new_grade)
                print("Өзгертілді")
            else:
                print("Қате баға")
        else:
            print("Мұндай нөмір жоқ")
    elif choice == "6":
        students.sort()
        print("Әліпби бойынша сұрыпталды")
    elif choice == "7":
        students.sort(key=lambda s: s[1], reverse=True)
        print("Баға бойынша сұрыпталды")
    elif choice == "0":
        print("Сау болыңыз!")
        break
    else:
        print("Қате таңдау")
```

**2-жоба. «Бағаларды талдау» — үлгі шешім (параллель тізімдер)**
```python
n = int(input("Оқушылар саны: "))
names = []
grades = []
for i in range(n):
    names.append(input(f"{i + 1}-оқушының есімі: "))
    g = int(input("Бағасы: "))
    while g < 2 or g > 5:
        g = int(input("Қате! 2-5: "))
    grades.append(g)

if n > 0:
    avg = sum(grades) / n
    s = sorted(grades)
    if n % 2 == 1:
        median = s[n // 2]
    else:
        median = (s[n // 2 - 1] + s[n // 2]) / 2
    top = max(grades)
    low = min(grades)
    top_names = [names[i] for i in range(n) if grades[i] == top]
    low_names = [names[i] for i in range(n) if grades[i] == low]

    print("===== БАҒАЛАР ТАЛДАУЫ =====")
    print("Оқушылар саны:", n)
    print(f"Орташа баға: {avg:.2f}")
    print("Медиана:", median)
    print(f"Ең жоғары баға: {top} ({', '.join(top_names)})")
    print(f"Ең төмен баға: {low} ({', '.join(low_names)})")
    print("Үлестірім:")
    for mark in range(5, 1, -1):
        c = grades.count(mark)
        print(f"  «{mark}»: {'█' * c} {c}")
    quality = (grades.count(4) + grades.count(5)) / n * 100
    success = (n - grades.count(2)) / n * 100
    print(f"Сапа көрсеткіші: {quality:.1f}%")
    print(f"Үлгерім көрсеткіші: {success:.1f}%")
    above = [names[i] for i in range(n) if grades[i] > avg]
    print("Орташадан жоғары:", above)
    for i in range(n):
        if grades[i] == 2:
            print(names[i], "— қосымша сабаққа шақырылады")
else:
    print("Деректер жоқ")
```
`', '.join(...)` — тізімдегі жолдарды үтірмен біріктіреді (44-сабақта толық өтіледі); оның орнына тізімді жай `print` етуге де болады.
