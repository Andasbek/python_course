## 1. Списки и кортежи: краткий справочник (шпаргалка)

| Операция | Список `list` | Кортеж `tuple` |
|---|---|---|
| Создание | `a = [1, 2, 3]`, `[]`, `list(range(5))` | `t = (1, 2, 3)`, `(5,)`, `tuple(a)` |
| Индекс | `a[0]`, `a[-1]` | `t[0]`, `t[-1]` |
| Срез | `a[1:3]`, `a[::-1]` | `t[1:3]` |
| Изменение | `a[0] = 10` | нельзя |
| Добавление | `append(x)`, `insert(i, x)`, `extend(b)` | нельзя (создать новый: `t + (x,)`) |
| Удаление | `remove(x)`, `pop(i)`, `del a[i]`, `clear()` | нельзя |
| Сортировка | `a.sort()`, `sorted(a)`, `a.reverse()` | `sorted(t)` → список |
| Функции | `len`, `sum`, `min`, `max` | `len`, `sum`, `min`, `max` |
| Поиск | `x in a`, `a.index(x)`, `a.count(x)` | `x in t`, `t.index(x)`, `t.count(x)` |
| Цикл | `for x in a`, `for i in range(len(a))`, `enumerate(a)` | точно так же |
| Генератор | `[x * 2 for x in a if x > 0]` | — |

Что важно помнить: `remove` удаляет по значению, `pop` — по индексу; `(4)` — число, `(4,)` — кортеж; `b = a` — ссылка, `b = a[:]` — копия; `[x for x in range(10) if x % 3 == 0]` → `[0, 3, 6, 9]`.

## 2. Способы хранения связанных данных

В «Списке учеников» у каждого ученика есть **имя** и **оценка**. Два способа их хранения:

### Способ 1: параллельные списки
```python
names = ["Айгерим", "Бекзат", "Дана"]
grades = [5, 4, 3]
for i in range(len(names)):
    print(names[i], grades[i])
```
Правило: данные одного ученика стоят **на одном и том же индексе**. Недостаток: если удалить элемент из одного списка и забыть удалить из другого — данные «перемешаются».

### Способ 2: список кортежей
```python
students = [("Айгерим", 5), ("Бекзат", 4), ("Дана", 3)]
for name, grade in students:
    print(name, grade)
```
Все данные одного ученика — в одном кортеже, они никогда не разделятся. Сортировка и удаление — просты.

| | Параллельные списки | Список кортежей |
|---|---|---|
| Простота | Понятно новичку | Немного сложнее |
| Целостность данных | Может нарушиться | Сохраняется |
| Сортировка | Сложно (два списка вместе) | Легко (`key=lambda s: s[1]`) |
| Изменение оценки | `grades[i] = 5` | `students[i] = (name, 5)` — новый кортеж |

Третий, чаще всего самый удобный способ — словарь (`dict`): `{"Айгерим": 5, "Бекзат": 4}`, где оценку можно сразу найти по имени.

## 3. Структура программы с меню

Объединим шаблон меню (`while True` + `if...elif`) со списками:
```text
данные = [...]                   ← начальное состояние (до цикла)
while True:
    вывести меню
    прочитать выбор
    if выбор == "1": ... добавление (append)
    elif выбор == "2": ... показ (for)
    elif выбор == "3": ... удаление (remove/pop)
    elif выбор == "4": ... поиск (in, index)
    elif выбор == "5": ... сортировка (sort/sorted)
    elif выбор == "0": break
    else: неверный выбор
```

Каждый пункт — 3–8 строк кода. Программу пишем **поэтапно**: сначала «добавление» и «показ», проверка, затем следующий пункт.

## 4. Анализ оценок: какие показатели нужны?

| Показатель | Как вычисляем |
|---|---|
| Количество учеников | `len(grades)` |
| Средняя оценка | `sum(grades) / len(grades)` |
| Наивысшая / наименьшая | `max(grades)`, `min(grades)` |
| Медиана | середина отсортированного списка |
| Количество каждой оценки (распределение) | `grades.count(5)` или цикл |
| Показатель качества | (количество «4» + «5») / всего × 100% |
| Показатель успеваемости | (оценки выше 2) / всего × 100% |
| Ученики выше среднего | генератор: `[n for n, g in students if g > avg]` |

**Качество** и **успеваемость** — показатели, которые действительно используются в школах. Например, если из 20 учеников 12 получили «4» или «5», качество = 12 / 20 × 100 = 60%.

### Текстовая диаграмма
Распределение можно наглядно вывести символами (умножение строки):
```python
grades = [5, 4, 4, 3, 5, 2, 4, 5, 3, 4]
for mark in range(5, 1, -1):
    c = grades.count(mark)
    print(f"«{mark}»: {'█' * c} {c}")
```
Результат:
```text
«5»: ███ 3
«4»: ████ 4
«3»: ██ 2
«2»: █ 1
```

## 5. Программа, устойчивая к ошибкам

Ситуации, которые нужно учесть в программе:
- **пустой список**: перед вычислением среднего проверить `if grades:` (чтобы не было `ZeroDivisionError`, `ValueError`);
- **удаление несуществующего элемента**: перед `remove` — `in`;
- **неверный номер**: перед `pop(n - 1)` — `1 <= n <= len(lst)`;
- **диапазон оценок**: не принимать оценку вне диапазона 2–5.

## 6. Полный пример: программа «Список учеников»

Программа, объединяющая все части выше (данные — список кортежей):
```python
students = []                         # список кортежей (имя, оценка)
while True:
    print("\n1 - Добавить  2 - Показать  3 - Удалить  4 - Анализ  0 - Выход")
    choice = input("> ")
    if choice == "1":
        name = input("Имя: ")
        grade = int(input("Оценка (2–5): "))
        if 2 <= grade <= 5:
            students.append((name, grade))
        else:
            print("Оценка должна быть от 2 до 5")
    elif choice == "2":
        for i, (name, grade) in enumerate(students, start=1):
            print(f"{i}. {name:12} {grade}")
    elif choice == "3":
        n = int(input("Номер: "))
        if 1 <= n <= len(students):
            print("Удалён:", students.pop(n - 1)[0])
        else:
            print("Такого номера нет")
    elif choice == "4":
        if students:
            grades = [g for _, g in students]
            avg = sum(grades) / len(grades)
            good = len([g for g in grades if g >= 4])
            print(f"Среднее: {avg:.2f}, качество: {good / len(grades) * 100:.0f}%")
            print("Выше среднего:", [n for n, g in students if g > avg])
        else:
            print("Список пуст")
    elif choice == "0":
        break
    else:
        print("Неверный выбор")
```
`for i, (name, grade) in enumerate(...)` — вложенная распаковка: `enumerate` выдаёт пару `(номер, кортеж)`, а кортеж сразу распаковывается в `name` и `grade`.

## Частые ошибки

**1. Удаление только из одного из параллельных списков**
```python
names = ["Айгерим", "Бекзат", "Дана"]
grades = [5, 4, 3]
names.remove("Бекзат")
# Нужно удалить и из grades! Иначе получится, что Дана получила 4.
```
Правильно: сначала найти индекс, затем сделать `pop` из обоих:
```python
names = ["Айгерим", "Бекзат", "Дана"]
grades = [5, 4, 3]
i = names.index("Бекзат")
names.pop(i)
grades.pop(i)
print(names, grades)
```

**2. Среднее пустого списка** → `ZeroDivisionError`.

**3. Присвоение результата `sort()`** → `None`.

**4. Попытка изменить кортеж** → `TypeError`; нужно создать новый кортеж.

**5. Забыть о разнице между номером пользователя (с 1) и индексом (с 0).**

## Основные понятия

| Понятие | Объяснение |
|---|---|
| Параллельные списки | Несколько списков, где связанные данные стоят на одном индексе |
| Список кортежей | Каждая запись — один кортеж |
| Распределение | Сколько раз встречается каждое значение |
| Показатель качества | Доля оценок «4» и «5» (%) |
| Показатель успеваемости | Доля удовлетворительных оценок (%) |
| Медиана | Середина отсортированных значений |

## Примечание

- При вычислении процентов лучше сначала умножать, потом делить: `good * 100 / total` — так точность дробного результата сохраняется лучше; выводите результат через `:.1f`.
- Если связанные данные всё же хранятся в параллельных списках, обходите их вместе через `zip(names, grades)` — это безопаснее работы с индексами.
- Для подсчёта распределения оценок в одну строку удобен `collections.Counter(grades)`: `Counter([5, 4, 5])` → `Counter({5: 2, 4: 1})`, а `most_common()` возвращает самые частые значения.
- Для медианы и среднего есть готовые `statistics.median()` и `statistics.mean()` (Python 3.4+).
- `int(input())` вызывает `ValueError` на нечисловом вводе — чтобы программа с меню не падала, оборачивайте ввод в `try/except ValueError`.
- Документация: https://docs.python.org/3/library/collections.html#collections.Counter, https://docs.python.org/3/library/statistics.html
