## 1. Тізімдер мен кортеждер: қысқа анықтамалық (шпаргалка)

| Амал | Тізім `list` | Кортеж `tuple` |
|---|---|---|
| Құру | `a = [1, 2, 3]`, `[]`, `list(range(5))` | `t = (1, 2, 3)`, `(5,)`, `tuple(a)` |
| Индекс | `a[0]`, `a[-1]` | `t[0]`, `t[-1]` |
| Кесінді | `a[1:3]`, `a[::-1]` | `t[1:3]` |
| Өзгерту | `a[0] = 10` | болмайды |
| Қосу | `append(x)`, `insert(i, x)`, `extend(b)` | болмайды (жаңасын құру: `t + (x,)`) |
| Жою | `remove(x)`, `pop(i)`, `del a[i]`, `clear()` | болмайды |
| Сұрыптау | `a.sort()`, `sorted(a)`, `a.reverse()` | `sorted(t)` → тізім |
| Функциялар | `len`, `sum`, `min`, `max` | `len`, `sum`, `min`, `max` |
| Іздеу | `x in a`, `a.index(x)`, `a.count(x)` | `x in t`, `t.index(x)`, `t.count(x)` |
| Цикл | `for x in a`, `for i in range(len(a))`, `enumerate(a)` | дәл солай |
| Генератор | `[x * 2 for x in a if x > 0]` | — |

Есте сақтайтын жайттар: `remove` мәні бойынша, `pop` индексі бойынша жояды; `(4)` — сан, `(4,)` — кортеж; `b = a` — сілтеме, `b = a[:]` — көшірме; `[x for x in range(10) if x % 3 == 0]` → `[0, 3, 6, 9]`.

## 2. Байланысқан деректерді сақтау тәсілдері

«Оқушылар тізімінде» әр оқушының **есімі** және **бағасы** бар. Оларды сақтаудың екі тәсілі:

### 1-тәсіл: параллель тізімдер
```python
names = ["Айгерім", "Бекзат", "Дана"]
grades = [5, 4, 3]
for i in range(len(names)):
    print(names[i], grades[i])
```
Ереже: бір оқушының деректері **бірдей индексте** тұрады. Кемшілігі: бір тізімнен элемент жойып, екіншісінен жоюды ұмытсаң — деректер «араласып» кетеді.

### 2-тәсіл: кортеждер тізімі
```python
students = [("Айгерім", 5), ("Бекзат", 4), ("Дана", 3)]
for name, grade in students:
    print(name, grade)
```
Бір оқушының барлық деректері бір кортежде — олар ешқашан ажырамайды. Сұрыптау, жою оңай.

| | Параллель тізімдер | Кортеждер тізімі |
|---|---|---|
| Қарапайымдылығы | Жаңадан бастаушыға түсінікті | Сәл күрделірек |
| Деректер тұтастығы | Бұзылуы мүмкін | Сақталады |
| Сұрыптау | Қиын (екі тізімді бірге) | Оңай (`key=lambda s: s[1]`) |
| Бағаны өзгерту | `grades[i] = 5` | `students[i] = (name, 5)` — жаңа кортеж |

Үшінші, көбіне ең ыңғайлы тәсіл — сөздік (`dict`): `{"Айгерим": 5, "Бекзат": 4}`, мұнда есім бойынша бағаны бірден табуға болады.

## 3. Мәзір бағдарламасының құрылымы

Мәзір үлгісін (`while True` + `if...elif`) тізімдермен біріктіреміз:
```text
деректер = [...]                 ← бастапқы күй (циклге дейін)
while True:
    мәзірді шығару
    таңдауды оқу
    if таңдау == "1": ... қосу (append)
    elif таңдау == "2": ... көрсету (for)
    elif таңдау == "3": ... жою (remove/pop)
    elif таңдау == "4": ... іздеу (in, index)
    elif таңдау == "5": ... сұрыптау (sort/sorted)
    elif таңдау == "0": break
    else: қате таңдау
```

Әр пункт — 3–8 жол код. Бағдарламаны **кезең-кезеңімен** жазамыз: алдымен «қосу» мен «көрсету», тексеру, сосын келесі пункт.

## 4. Бағаларды талдау: қандай көрсеткіштер керек?

| Көрсеткіш | Қалай есептейміз |
|---|---|
| Оқушылар саны | `len(grades)` |
| Орташа баға | `sum(grades) / len(grades)` |
| Ең жоғары / төмен | `max(grades)`, `min(grades)` |
| Медиана | сұрыпталған тізімнің ортасы |
| Әр бағаның саны (үлестірім) | `grades.count(5)` немесе цикл |
| Сапа көрсеткіші | («4» + «5» саны) / барлығы × 100% |
| Үлгерім көрсеткіші | (2-ден жоғары бағалар) / барлығы × 100% |
| Орташадан жоғары оқушылар | генератор: `[n for n, g in students if g > avg]` |

**Сапа** және **үлгерім** — мектептерде шынымен қолданылатын көрсеткіштер. Мысалы, 20 оқушының 12-сі «4» не «5» алса, сапа = 12 / 20 × 100 = 60%.

### Мәтіндік диаграмма
Үлестірімді көрнекі түрде жұлдызшалармен шығаруға болады (жолды көбейту):
```python
grades = [5, 4, 4, 3, 5, 2, 4, 5, 3, 4]
for mark in range(5, 1, -1):
    c = grades.count(mark)
    print(f"«{mark}»: {'█' * c} {c}")
```
Нәтижесі:
```text
«5»: ███ 3
«4»: ████ 4
«3»: ██ 2
«2»: █ 1
```

## 5. Қателерге төзімді бағдарлама

Бағдарламада ескеретін жағдайлар:
- **бос тізім**: орташаны есептеуден бұрын `if grades:` тексеру (`ZeroDivisionError`, `ValueError` болмас үшін);
- **жоқ элементті жою**: `remove` алдында `in`;
- **қате нөмір**: `pop(n - 1)` алдында `1 <= n <= len(lst)`;
- **баға аралығы**: 2–5 аралығынан тыс бағаны қабылдамау.

## 6. Толық мысал: «Оқушылар тізімі» бағдарламасы

Жоғарыдағы барлық бөліктерді біріктіретін бағдарлама (деректер — кортеждер тізімі):
```python
students = []                         # (есім, баға) кортеждерінің тізімі
while True:
    print("\n1 - Қосу  2 - Көрсету  3 - Жою  4 - Талдау  0 - Шығу")
    choice = input("> ")
    if choice == "1":
        name = input("Есімі: ")
        grade = int(input("Бағасы (2–5): "))
        if 2 <= grade <= 5:
            students.append((name, grade))
        else:
            print("Баға 2–5 аралығында болуы керек")
    elif choice == "2":
        for i, (name, grade) in enumerate(students, start=1):
            print(f"{i}. {name:12} {grade}")
    elif choice == "3":
        n = int(input("Нөмірі: "))
        if 1 <= n <= len(students):
            print("Жойылды:", students.pop(n - 1)[0])
        else:
            print("Мұндай нөмір жоқ")
    elif choice == "4":
        if students:
            grades = [g for _, g in students]
            avg = sum(grades) / len(grades)
            good = len([g for g in grades if g >= 4])
            print(f"Орташа: {avg:.2f}, сапа: {good / len(grades) * 100:.0f}%")
            print("Орташадан жоғары:", [n for n, g in students if g > avg])
        else:
            print("Тізім бос")
    elif choice == "0":
        break
    else:
        print("Қате таңдау")
```
`for i, (name, grade) in enumerate(...)` — кірістірілген ашу: `enumerate` `(нөмір, кортеж)` жұбын береді, ал кортеж бірден `name` пен `grade`-ке ашылады.

## Жиі кездесетін қателер

**1. Параллель тізімдердің бірінен ғана жою**
```python
names = ["Айгерім", "Бекзат", "Дана"]
grades = [5, 4, 3]
names.remove("Бекзат")
# grades-тен де жою керек! Әйтпесе Дана енді 4 алған болып шығады.
```
Дұрысы: алдымен индексті тап, сосын екеуінен де `pop`:
```python
names = ["Айгерім", "Бекзат", "Дана"]
grades = [5, 4, 3]
i = names.index("Бекзат")
names.pop(i)
grades.pop(i)
print(names, grades)
```

**2. Бос тізімнің орташасы** → `ZeroDivisionError`.

**3. `sort()` нәтижесін меншіктеу** → `None`.

**4. Кортежді өзгертуге тырысу** → `TypeError`; жаңа кортеж құру керек.

**5. Пайдаланушы нөмірі (1-ден) мен индекстің (0-ден) айырмасын ұмыту.**

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Параллель тізімдер | Байланысқан деректер бірдей индексте тұратын бірнеше тізім |
| Кортеждер тізімі | Әр жазба — бір кортеж |
| Үлестірім | Әр мәннің неше рет кездесетіні |
| Сапа көрсеткіші | «4» және «5» бағаларының үлесі (%) |
| Үлгерім көрсеткіші | Қанағаттанарлық бағалардың үлесі (%) |
| Медиана | Сұрыпталған мәндердің ортасы |

## Ескерту

- Пайыздарды есептегенде алдымен көбейтіп, сосын бөлген дұрыс: `good * 100 / total` — бұлай бөлшек сан дәлдігі жақсырақ сақталады; нәтижені `:.1f` арқылы шығарыңыз.
- Тиісті деректерді параллель тізімдерде сақтау қажет болса, оларды бірге аралау үшін `zip(names, grades)` қолданыңыз — индекстермен жұмыстан гөрі қауіпсіз.
- Бағалардың таралуын бір жолда санау үшін `collections.Counter(grades)` ыңғайлы: `Counter([5, 4, 5])` → `Counter({5: 2, 4: 1})`, ал `most_common()` ең жиі мәндерді береді.
- Медиана мен орташа үшін `statistics.median()` және `statistics.mean()` дайын функциялары бар (Python 3.4+).
- `int(input())` сан емес мәтінде `ValueError` береді — мәзір бағдарламасын тұрақты ету үшін енгізуді `try/except ValueError` ішіне алыңыз.
- Құжаттама: https://docs.python.org/3/library/collections.html#collections.Counter, https://docs.python.org/3/library/statistics.html
