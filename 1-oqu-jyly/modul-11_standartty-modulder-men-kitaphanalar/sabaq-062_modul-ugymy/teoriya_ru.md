## 1. Что такое модуль?

**Модуль** (module) – отдельный файл `.py`, в котором собраны функции, переменные (константы) и другой код. Модуль можно **подключить** (импортировать) к другой программе и пользоваться его готовыми инструментами.

**Аналогия.** Модуль – это ящик с инструментами. Чтобы забить гвоздь в доску, ты не куёшь молоток сам – берёшь его из ящика. `math` – ящик математических инструментов, `random` – ящик случайностей, `turtle` – ящик для рисования.

### Виды модулей

| Вид | Описание | Примеры |
|---|---|---|
| Встроенные функции (built-in) | Всегда доступны без импорта | `print`, `len`, `int`, `max`, `round` |
| Стандартная библиотека | Устанавливается вместе с Python, нужен `import` | `math`, `random`, `time`, `datetime`, `turtle`, `os` |
| Внешние (сторонние) библиотеки | Устанавливаются отдельно через `pip` | `pygame`, `requests`, `pandas`, `matplotlib` |
| Свой модуль | Файл `.py`, написанный тобой | `my_tools.py` |

**Библиотека** (library) – набор модулей, предназначенных для одной цели. В стандартной библиотеке Python более 200 модулей – поэтому про Python говорят «батарейки в комплекте» (batteries included).

> Внешние библиотеки устанавливаются командой в терминале: `pip install requests` (в Thonny – через **Tools → Manage packages**). После установки они импортируются так же, как стандартные модули.

## 2. Оператор import

### Способ 1: импорт всего модуля

```python
import math

print(math.pi)
print(math.sqrt(16))
```

Результат:
```text
3.141592653589793
4.0
```

К функции внутри модуля обращаемся через **точку**: `модуль.функция()`. Это означает «возьми инструмент sqrt из ящика math».

### Способ 2: импорт только нужных функций

```python
from math import sqrt, pi

print(sqrt(25))
print(pi * 2)
```

Результат:
```text
5.0
6.283185307179586
```

Теперь писать `math.` не нужно. Но другие функции модуля `math` недоступны.

### Способ 3: импорт с псевдонимом (alias)

```python
import math as m

print(m.floor(7.9))
```

Результат:
```text
7
```

Удобно для модулей с длинными названиями. Общепринятые псевдонимы: `import pandas as pd`, `import numpy as np`, `import matplotlib.pyplot as plt`.

### Способ 4: импорт всего (не рекомендуется)

```python
from math import *

print(sqrt(81), pi)
```

Этот способ опасен: имена из модуля могут **конфликтовать** с твоими переменными, и становится непонятно, откуда взялась та или иная функция.

| Запись | Использование | Преимущество / недостаток |
|---|---|---|
| `import math` | `math.sqrt(9)` | Явно, нет конфликтов; пишется длиннее |
| `from math import sqrt` | `sqrt(9)` | Коротко; доступно только указанное |
| `import math as m` | `m.sqrt(9)` | Коротко и явно |
| `from math import *` | `sqrt(9)` | Не рекомендуется |

> **Правило (PEP 8).** Все строки `import` пишутся в **самом начале** файла.

## 3. Получение справки о модуле

```python
import math

print(dir(math)[:12])     # часть имён в модуле
help(math.gcd)            # описание функции gcd
```

Результат (сокращённо):
```text
['__doc__', '__loader__', '__name__', '__package__', '__spec__', 'acos', 'acosh', 'asin', 'asinh', 'atan', 'atan2', 'atanh']
Help on built-in function gcd in module math:

gcd(*integers)
    Greatest Common Divisor.
```

- `dir(модуль)` – список всех имён в модуле;
- `help(функция)` – описание функции (на английском);
- официальная документация Python – docs.python.org.

## 4. Модуль math

### Константы

| Название | Значение | Смысл |
|---|---|---|
| `math.pi` | 3.141592653589793 | Число π |
| `math.e` | 2.718281828459045 | Число Эйлера |
| `math.inf` | ∞ | Бесконечность |

### Основные функции

| Функция | Смысл | Пример | Результат |
|---|---|---|---|
| `sqrt(x)` | Квадратный корень | `math.sqrt(49)` | `7.0` |
| `pow(x, y)` | x в степени y (float) | `math.pow(2, 10)` | `1024.0` |
| `ceil(x)` | Округление вверх | `math.ceil(4.1)` | `5` |
| `floor(x)` | Округление вниз | `math.floor(4.9)` | `4` |
| `trunc(x)` | Отбрасывание дробной части | `math.trunc(-4.9)` | `-4` |
| `fabs(x)` | Модуль (абсолютная величина) | `math.fabs(-7)` | `7.0` |
| `factorial(n)` | n! | `math.factorial(5)` | `120` |
| `gcd(a, b)` | НОД | `math.gcd(36, 48)` | `12` |
| `lcm(a, b)` | НОК (Python 3.9+) | `math.lcm(4, 6)` | `12` |
| `hypot(a, b)` | Гипотенуза √(a²+b²) | `math.hypot(3, 4)` | `5.0` |
| `log(x, base)` | Логарифм | `math.log(8, 2)` | `3.0` |
| `log10(x)` | Десятичный логарифм | `math.log10(1000)` | `3.0` |
| `sin(x)`, `cos(x)`, `tan(x)` | Тригонометрия (в радианах) | `math.sin(0)` | `0.0` |
| `radians(d)` | Градусы в радианы | `math.radians(180)` | `3.14159...` |
| `degrees(r)` | Радианы в градусы | `math.degrees(math.pi)` | `180.0` |

### Разница между ceil, floor и round

```python
import math

for x in [2.3, 2.5, 2.7, -2.3]:
    print(x, "-> ceil:", math.ceil(x), "floor:", math.floor(x), "round:", round(x))
```

Результат:
```text
2.3 -> ceil: 3 floor: 2 round: 2
2.5 -> ceil: 3 floor: 2 round: 2
2.7 -> ceil: 3 floor: 2 round: 3
-2.3 -> ceil: -2 floor: -3 round: -2
```

> **Интересный факт.** `round(2.5)` даёт не 3, а **2**! Python использует «банковское округление»: число ровно посередине округляется к ближайшему **чётному** числу (`round(3.5)` → 4).

**Жизненный пример – ceil.** В классе 27 учеников, в автобус помещается 12 человек. Сколько нужно автобусов?

```python
import math

students = 27
seats = 12
buses = math.ceil(students / seats)
print("Нужно автобусов:", buses)
```

Результат:
```text
Нужно автобусов: 3
```

(`27 // 12` = 2 – двух автобусов не хватит!)

### Задачи по геометрии

```python
import math

r = float(input("Радиус окружности (см): "))
area = math.pi * r ** 2
length = 2 * math.pi * r
print(f"Площадь: {area:.2f} см²")
print(f"Длина: {length:.2f} см")
```

Результат:
```text
Радиус окружности (см): 5
Площадь: 78.54 см²
Длина: 31.42 см
```

Расстояние между двумя точками:

```python
import math

x1, y1 = 0, 0
x2, y2 = 6, 8
distance = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print("Расстояние:", distance)
print("Через hypot:", math.hypot(x2 - x1, y2 - y1))
```

Результат:
```text
Расстояние: 10.0
Через hypot: 10.0
```

### Тригонометрия: градусы и радианы

Тригонометрические функции модуля `math` принимают угол **в радианах**. Из градусов в радианы переводим с помощью `math.radians()`:

```python
import math

angle = 30
print("sin 30° =", round(math.sin(math.radians(angle)), 4))
print("cos 60° =", round(math.cos(math.radians(60)), 4))
```

Результат:
```text
sin 30° = 0.5
cos 60° = 0.5
```

**Пример: высота лестницы.** Лестница длиной 5 м приставлена к стене под углом 60°. До какой высоты она достаёт?

```python
import math

ladder = 5
height = ladder * math.sin(math.radians(60))
print(f"Лестница достаёт до высоты {height:.2f} м")
```

Результат:
```text
Лестница достаёт до высоты 4.33 м
```

### Факториал, НОД, НОК

Сравним рекурсивный факториал, написанный вручную, с готовой функцией:

```python
import math

def my_factorial(n):
    if n <= 1:
        return 1
    return n * my_factorial(n - 1)

print(my_factorial(10), math.factorial(10))
print("36 и 48: НОД =", math.gcd(36, 48), " НОК =", math.lcm(36, 48))
```

Результат:
```text
3628800 3628800
36 и 48: НОД = 12  НОК = 144
```

**Пример: сокращение дроби.**

```python
import math

a, b = 18, 24
g = math.gcd(a, b)
print(f"{a}/{b} = {a // g}/{b // g}")
```

Результат:
```text
18/24 = 3/4
```

## 5. Создание своего модуля

Любой файл `.py` – это модуль! Создай файл `geometry.py` и напиши в нём функции:

```python
# geometry.py – мой геометрический модуль
import math

def circle_area(r):
    """Площадь круга."""
    return math.pi * r ** 2

def rectangle_area(a, b):
    """Площадь прямоугольника."""
    return a * b

def triangle_area(a, b, c):
    """Площадь треугольника (формула Герона)."""
    p = (a + b + c) / 2
    return math.sqrt(p * (p - a) * (p - b) * (p - c))
```

Теперь **в той же папке** создай `main.py` и импортируй модуль:

```python
# main.py
import geometry

print(round(geometry.circle_area(3), 2))
print(geometry.rectangle_area(4, 5))
print(geometry.triangle_area(3, 4, 5))
```

Результат:
```text
28.27
20
6.0
```

> **Важно.** Не называй свой файл именем стандартного модуля! Если сохранить его как `math.py`, `random.py`, `turtle.py`, Python импортирует твой файл вместо стандартного модуля, и программа сломается.

## Частые ошибки

**1. Использование без импорта.**

```text
print(math.sqrt(16))
NameError: name 'math' is not defined
```

Решение: напиши в начале файла `import math`.

**2. Не указано имя модуля.**

```python
import math
# print(sqrt(16))  -> NameError: name 'sqrt' is not defined
print(math.sqrt(16))
```

**3. Корень из отрицательного числа.**

```python
import math
try:
    print(math.sqrt(-4))
except ValueError as e:
    print("Ошибка:", e)
```

Результат:
```text
Ошибка: math domain error
```

**4. Передача градусов в тригонометрию.** `math.sin(30)` – не 0.5, а `-0.988`! Потому что 30 считается в радианах. Правильно: `math.sin(math.radians(30))`.

**5. Файл назван `math.py`.** В результате `AttributeError: module 'math' has no attribute 'sqrt'`. Переименуй файл и удали папку `__pycache__` в этой директории.

**6. Неверно написано имя модуля.** `import Math` – `ModuleNotFoundError: No module named 'Math'`. Названия модулей пишутся строчными буквами.

## Основные понятия

| Понятие | Пояснение |
|---|---|
| Модуль (module) | Файл `.py` с набором функций и переменных |
| Библиотека (library) | Набор модулей |
| Стандартная библиотека | Модули, поставляемые вместе с Python |
| `import` | Оператор подключения модуля к программе |
| `from ... import ...` | Подключение из модуля только нужных имён |
| `as` | Присвоение модулю псевдонима |
| `math` | Модуль математических функций |
| `dir()`, `help()` | Справка о модуле/функции |
| `ModuleNotFoundError` | Ошибка, возникающая, если модуль не найден |

## Примечание

- При первом `import` Python выполняет весь код модуля один раз и кэширует его в `sys.modules`; повторный `import` ничего не перевыполняет. Скомпилированные копии сохраняются в папке `__pycache__`.
- Чтобы код модуля не выполнялся при импорте (например, тестовые `print`), его помещают в блок `if __name__ == "__main__":` – он срабатывает только при прямом запуске файла.
- Порядок импорта по PEP 8: сначала стандартная библиотека, затем сторонние пакеты, затем свои модули – каждая группа отделяется пустой строкой.
- Модули ищутся по путям из `sys.path`: первой идёт папка запускаемого скрипта – поэтому свой `math.py` или `random.py` «перекрывает» стандартный.
- `math.isqrt(n)` (Python 3.8+) возвращает целый корень без погрешности `float`; `math.lcm` и `gcd` с несколькими аргументами – с Python 3.9; `math.isclose(a, b)` правильно сравнивает дробные числа.
- Документация: [Modules (tutorial)](https://docs.python.org/3/tutorial/modules.html), [math](https://docs.python.org/3/library/math.html), [список модулей стандартной библиотеки](https://docs.python.org/3/library/index.html).
