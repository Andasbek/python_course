## 1. Модуль деген не?

**Модуль** (module) – функциялар, айнымалылар (тұрақтылар) және басқа да код жиналған жеке `.py` файл. Модульді басқа бағдарламаға **қосып** (импорттап), оның ішіндегі дайын құралдарды пайдалана аламыз.

**Аналогия.** Модуль – құрал-сайман жәшігі. Тақтайға шеге қағу үшін балғаны өзің соғып жасамайсың – жәшіктен аласың. `math` – математикалық құралдар жәшігі, `random` – кездейсоқтық жәшігі, `turtle` – сурет салу жәшігі.

### Модульдердің түрлері

| Түрі | Сипаттамасы | Мысалдар |
|---|---|---|
| Кірістірілген функциялар (built-in) | Импортсыз әрқашан қолжетімді | `print`, `len`, `int`, `max`, `round` |
| Стандартты кітапхана | Python-мен бірге орнатылады, `import` керек | `math`, `random`, `time`, `datetime`, `turtle`, `os` |
| Сыртқы (үшінші тарап) кітапханалар | `pip` арқылы бөлек орнатылады | `pygame`, `requests`, `pandas`, `matplotlib` |
| Өз модулің | Өзің жазған `.py` файл | `my_tools.py` |

**Кітапхана** (library) – бір мақсатқа арналған модульдер жиынтығы. Python-ның стандартты кітапханасында 200-ден астам модуль бар – сондықтан Python туралы «батарейкалар қоса берілген» (batteries included) деп айтады.

> Сыртқы кітапханалар терминалда команда арқылы орнатылады: `pip install requests` (Thonny-де – **Tools → Manage packages** арқылы). Орнатылғаннан кейін олар стандартты модульдер сияқты импортталады.

## 2. import операторы

### 1-тәсіл: бүкіл модульді импорттау

```python
import math

print(math.pi)
print(math.sqrt(16))
```

Нәтижесі:
```text
3.141592653589793
4.0
```

Модульдің ішіндегі функцияға **нүкте** арқылы қатынаймыз: `модуль.функция()`. Бұл «math жәшігінен sqrt құралын ал» дегенді білдіреді.

### 2-тәсіл: тек керекті функцияларды импорттау

```python
from math import sqrt, pi

print(sqrt(25))
print(pi * 2)
```

Нәтижесі:
```text
5.0
6.283185307179586
```

Енді `math.` деп жазудың қажеті жоқ. Бірақ `math` модулінің басқа функциялары қолжетімсіз.

### 3-тәсіл: бүркеншік атпен (alias) импорттау

```python
import math as m

print(m.floor(7.9))
```

Нәтижесі:
```text
7
```

Ұзын атаулы модульдерге ыңғайлы. Жалпы қабылданған бүркеншік аттар: `import pandas as pd`, `import numpy as np`, `import matplotlib.pyplot as plt`.

### 4-тәсіл: барлығын импорттау (ұсынылмайды)

```python
from math import *

print(sqrt(81), pi)
```

Бұл тәсіл қауіпті: модульдегі атаулар сенің айнымалыларыңмен **қақтығысуы** мүмкін, және қай функция қайдан келгені түсініксіз болады.

| Жазылуы | Қолдану | Артықшылығы / кемшілігі |
|---|---|---|
| `import math` | `math.sqrt(9)` | Айқын, қақтығыс жоқ; ұзынырақ жазылады |
| `from math import sqrt` | `sqrt(9)` | Қысқа; тек аталғаны қолжетімді |
| `import math as m` | `m.sqrt(9)` | Қысқа әрі айқын |
| `from math import *` | `sqrt(9)` | Ұсынылмайды |

> **Ереже (PEP 8).** Барлық `import` жолдары файлдың **ең басында** жазылады.

Нәтижесі (қысқартылған):

- Python ресми құжаттамасы – docs.python.org.

## 4. math модулі

### Тұрақтылар

| Атауы | Мәні | Мағынасы |
|---|---|---|
| `math.pi` | 3.141592653589793 | π саны |
| `math.e` | 2.718281828459045 | Эйлер саны |
| `math.inf` | ∞ | Шексіздік |

### Негізгі функциялар

| Функция | Мағынасы | Мысал | Нәтиже |
|---|---|---|---|
| `sqrt(x)` | Квадрат түбір | `math.sqrt(49)` | `7.0` |
| `pow(x, y)` | x-тің y дәрежесі (float) | `math.pow(2, 10)` | `1024.0` |
| `ceil(x)` | Жоғары қарай дөңгелектеу | `math.ceil(4.1)` | `5` |
| `floor(x)` | Төмен қарай дөңгелектеу | `math.floor(4.9)` | `4` |
| `trunc(x)` | Бөлшек бөлігін алып тастау | `math.trunc(-4.9)` | `-4` |
| `fabs(x)` | Модуль (абсолют шама) | `math.fabs(-7)` | `7.0` |
| `factorial(n)` | n! | `math.factorial(5)` | `120` |
| `gcd(a, b)` | ЕҮОБ | `math.gcd(36, 48)` | `12` |
| `lcm(a, b)` | ЕКОЕ (Python 3.9+) | `math.lcm(4, 6)` | `12` |
| `hypot(a, b)` | Гипотенуза √(a²+b²) | `math.hypot(3, 4)` | `5.0` |
| `log(x, base)` | Логарифм | `math.log(8, 2)` | `3.0` |
| `log10(x)` | Ондық логарифм | `math.log10(1000)` | `3.0` |
| `sin(x)`, `cos(x)`, `tan(x)` | Тригонометрия (радианмен) | `math.sin(0)` | `0.0` |
| `radians(d)` | Градусты радианға | `math.radians(180)` | `3.14159...` |
| `degrees(r)` | Радианды градусқа | `math.degrees(math.pi)` | `180.0` |

### ceil, floor және round айырмашылығы

```python
import math

for x in [2.3, 2.5, 2.7, -2.3]:
    print(x, "-> ceil:", math.ceil(x), "floor:", math.floor(x), "round:", round(x))
```

Нәтижесі:
```text
2.3 -> ceil: 3 floor: 2 round: 2
2.5 -> ceil: 3 floor: 2 round: 2
2.7 -> ceil: 3 floor: 2 round: 3
-2.3 -> ceil: -2 floor: -3 round: -2
```

> **Қызық факт.** `round(2.5)` нәтижесі 3 емес, **2**! Python «банкирлік дөңгелектеуді» қолданады: дәл ортасындағы сан ең жақын **жұп** санға дөңгелектенеді (`round(3.5)` → 4).

**Өмірлік мысал – ceil.** Сыныпта 27 оқушы, автобусқа 12 адам сыяды. Неше автобус керек?

```python
import math

students = 27
seats = 12
buses = math.ceil(students / seats)
print("Қажетті автобустар саны:", buses)
```

Нәтижесі:
```text
Қажетті автобустар саны: 3
```

(`27 // 12` = 2 болар еді – екі автобус жетпейді!)

### Геометрия есептері

```python
import math

r = float(input("Шеңбер радиусы (см): "))
area = math.pi * r ** 2
length = 2 * math.pi * r
print(f"Ауданы: {area:.2f} см²")
print(f"Ұзындығы: {length:.2f} см")
```

Нәтижесі:
```text
Шеңбер радиусы (см): 5
Ауданы: 78.54 см²
Ұзындығы: 31.42 см
```

Екі нүкте арасындағы қашықтық:

```python
import math

x1, y1 = 0, 0
x2, y2 = 6, 8
distance = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print("Қашықтық:", distance)
print("hypot арқылы:", math.hypot(x2 - x1, y2 - y1))
```

Нәтижесі:
```text
Қашықтық: 10.0
hypot арқылы: 10.0
```

### Тригонометрия: градус пен радиан

`math` модулінің тригонометриялық функциялары бұрышты **радианмен** қабылдайды. Градустан радианға `math.radians()` арқылы көшеміз:

```python
import math

angle = 30
print("sin 30° =", round(math.sin(math.radians(angle)), 4))
print("cos 60° =", round(math.cos(math.radians(60)), 4))
```

Нәтижесі:
```text
sin 30° = 0.5
cos 60° = 0.5
```

**Мысал: сатының биіктігі.** Ұзындығы 5 м саты қабырғаға 60° бұрышпен сүйеніп тұр. Қандай биіктікке жетеді?

```python
import math

ladder = 5
height = ladder * math.sin(math.radians(60))
print(f"Саты {height:.2f} м биіктікке жетеді")
```

Нәтижесі:
```text
Саты 4.33 м биіктікке жетеді
```

### Факториал, ЕҮОБ, ЕКОЕ

Қолмен жазылған рекурсивті факториалды дайын функциямен салыстырайық:

```python
import math

def my_factorial(n):
    if n <= 1:
        return 1
    return n * my_factorial(n - 1)

print(my_factorial(10), math.factorial(10))
print("36 және 48: ЕҮОБ =", math.gcd(36, 48), " ЕКОЕ =", math.lcm(36, 48))
```

Нәтижесі:
```text
3628800 3628800
36 және 48: ЕҮОБ = 12  ЕКОЕ = 144
```

**Мысал: бөлшекті қысқарту.**

```python
import math

a, b = 18, 24
g = math.gcd(a, b)
print(f"{a}/{b} = {a // g}/{b // g}")
```

Нәтижесі:
```text
18/24 = 3/4
```

## 5. Өз модуліңді құру

Кез келген `.py` файл – модуль! `geometry.py` файлын құрып, оған функциялар жаз:

```python
# geometry.py – менің геометриялық модулім
import math

def circle_area(r):
    """Шеңбер ауданы."""
    return math.pi * r ** 2

def rectangle_area(a, b):
    """Тіктөртбұрыш ауданы."""
    return a * b

def triangle_area(a, b, c):
    """Үшбұрыш ауданы (Герон формуласы)."""
    p = (a + b + c) / 2
    return math.sqrt(p * (p - a) * (p - b) * (p - c))
```

Енді **сол папкада** `main.py` құрып, модульді импортта:

```python
# main.py
import geometry

print(round(geometry.circle_area(3), 2))
print(geometry.rectangle_area(4, 5))
print(geometry.triangle_area(3, 4, 5))
```

Нәтижесі:
```text
28.27
20
6.0
```

> **Маңызды.** Өз файлыңды стандартты модульдің атымен атама! `math.py`, `random.py`, `turtle.py` деп сақтасаң, Python стандартты модульдің орнына сенің файлыңды импорттайды да, бағдарлама бұзылады.

## Жиі кездесетін қателер

**1. Импорттамай қолдану.**

```text
print(math.sqrt(16))
NameError: name 'math' is not defined
```

Шешімі: файлдың басына `import math` жаз.

**2. Модуль атауын жазбау.**

```python
import math
# print(sqrt(16))  -> NameError: name 'sqrt' is not defined
print(math.sqrt(16))
```

**3. Теріс санның түбірі.**

```python
import math
try:
    print(math.sqrt(-4))
except ValueError as e:
    print("Қате:", e)
```

Нәтижесі:
```text
Қате: math domain error
```

**4. Тригонометрияға градусты беру.** `math.sin(30)` – 0.5 емес, `-0.988`! Себебі 30 радиан деп есептелді. Дұрысы: `math.sin(math.radians(30))`.

**5. Файлды `math.py` деп атау.** Нәтижесінде `AttributeError: module 'math' has no attribute 'sqrt'`. Файлдың атын өзгертіп, папкадағы `__pycache__` бумасын жой.

**6. Модуль атауын қате жазу.** `import Math` – `ModuleNotFoundError: No module named 'Math'`. Модуль атаулары кіші әріппен жазылады.

## Негізгі ұғымдар

| Ұғым | Түсіндірме |
|---|---|
| Модуль (module) | Функциялар мен айнымалылар жиналған `.py` файл |
| Кітапхана (library) | Модульдер жиынтығы |
| Стандартты кітапхана | Python-мен бірге келетін модульдер |
| `import` | Модульді бағдарламаға қосу операторы |
| `from ... import ...` | Модульден тек керекті атауларды қосу |
| `as` | Модульге бүркеншік ат беру |
| `math` | Математикалық функциялар модулі |
| `dir()`, `help()` | Модуль/функция туралы анықтама |
| `ModuleNotFoundError` | Модуль табылмағанда туатын қате |

## Ескерту

- Алғашқы `import` кезінде Python модульдің бүкіл кодын бір рет орындап, оны `sys.modules`-та кэштейді; қайталанған `import` ештеңені қайта орындамайды. Компиляцияланған көшірмелер `__pycache__` папкасында сақталады.
- Модуль коды импорт кезінде орындалмауы үшін (мысалы, тексеру `print`-тері) оны `if __name__ == "__main__":` блогына салады – ол файл тікелей іске қосылғанда ғана орындалады.
- PEP 8 бойынша импорт реті: алдымен стандартты кітапхана, содан кейін сыртқы пакеттер, соңында өз модульдерің – әр топ бос жолмен бөлінеді.
- Модульдер `sys.path` жолдары бойынша ізделеді: бірінші болып іске қосылған скрипт папкасы тексеріледі – сондықтан өзіңнің `math.py` немесе `random.py` файлың стандартты модульді «жауып» қалады.
- `math.isqrt(n)` (Python 3.8+) `float` қателігінсіз бүтін түбірді қайтарады; `math.lcm` және бірнеше аргументті `gcd` – Python 3.9-дан бастап; `math.isclose(a, b)` бөлшек сандарды дұрыс салыстырады.
- Құжаттама: [Modules (tutorial)](https://docs.python.org/3/tutorial/modules.html), [math](https://docs.python.org/3/library/math.html), [стандартты кітапхана модульдерінің тізімі](https://docs.python.org/3/library/index.html).
